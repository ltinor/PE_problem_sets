# 平方根逼近

## 题目描述

√2 的平方根可以表示为如下无限连分数：

√2 = 1 + 1/(2 + 1/(2 + 1/(2 + ...)))

将这个连分数进行迭代展开，分别可以得到分数：

第 1 次展开：3/2 = 1.5
第 2 次展开：7/5 = 1.4
第 3 次展开：17/12 = 1.41666...
第 4 次展开：41/29 = 1.41379...

第 8 次展开得到 1393/985，分子的位数第一次超过分母的位数。

现在将问题一般化：给定整数 N，求前 N 次展开中，有多少个分数满足分子位数多于分母位数。

---

## 输入格式

输入包含多组测试数据（至文件末尾 EOF），每组一行，一个整数 N。不带组数 T。

---

## 输出格式

对于每组数据，输出一行一个整数：满足条件的分数个数。

---

## 样例

### 输入

```
1000
```

### 输出

```
153
```

---

## 数据范围

- 1 ≤ N ≤ 1000
- 测试数据组数不超过 10 组
