# 不可变质数的平立方数

## 题目描述

平立方数（sqube）定义为可以写成 p²q³ 形式的数，其中 p 和 q 为不同的素数。

不可变质数（prime-proof）的数是指：改变该数的任意一位数字（不能有前导零），得到的数都不是素数。

例如，200 = 5² × 2³ 是一个平立方数，同时也是不可变质数。下一个包含连续子串"200"且不可变质数的平立方数是 1992008。

给定 K，求第 K 个满足以下条件的平立方数：
1. 是平立方数
2. 包含连续子串 "200"
3. 是不可变质数

---

## 输入格式

一行，一个整数 K（1 ≤ K ≤ 200）。

---

## 输出格式

一个整数，表示第 K 个符合条件的平立方数。

---

## 样例

### 输入
```
1
```

### 输出
```
1992008
```

---

## 数据范围

- 1 ≤ K ≤ 200
- PE 答案: K=200 → 229161792008
