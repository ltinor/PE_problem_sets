# Prime-proof Sqube

来源：改编自 Project Euler Problem 200

## 原题意

平立方数（sqube）定义为 p²q³，p,q 为不同素数。不可变质数（prime-proof）指改变任意一位数字都无法得到素数。求第200个包含"200"子串且不可变质数的平立方数。

## 题目

给定 K（1 ≤ K ≤ 200），求第 K 个满足以下条件的平立方数：
1. 是平立方数（p²q³，p≠q 为素数）
2. 包含连续子串 "200"
3. 是不可变质数（改变任意一位数字均非素数）

## 数据范围

- 1 ≤ K ≤ 200
- PE 答案: K=200 → 229161792008

## 算法

枚举平立方数（按大小排序用优先队列），Miller-Rabin 判素。筛法预处理素数表。
