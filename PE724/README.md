# PE724 — Drone Delivery (无人机快递)

来源：改编自 Project Euler Problem 724

## 原题意

仓库使用 $n$ 架无人机沿一条长直马路分发包裹。初始所有无人机静止并各装有一个包裹。

每秒随机选择一架无人机发送指令：
- 若静止，开始以 1 cm/s 速度前进；
- 若运动中，速度增加 1 cm/s。

当最后一架无人机首次收到指令并恰好前进 1 cm 时，所有无人机同时投放包裹。

定义 $E(n)$ 为包裹落点距离仓库的期望距离（cm）。已知：
- $E(2)=7/2=3.5$
- $E(5)=12019/720\approx 16.693$
- $E(100)\approx 1427.193470$

求 $E(10^8)$，四舍五入取整。

PE 答案：18128201710。

## 算法

1. **总距离公式**：设 $T$ 为优惠券收集时间（所有 $n$ 架无人机均被激活所需的秒数）。过程在时刻 $T+1$ 结束。总飞行距离为：
   $$\sum_i\text{dist}_i=\sum_{t=0}^{T}t=\frac{T(T+1)}{2}$$

2. **期望推导**：$T=\sum_{k=1}^{n}G_k$，其中 $G_k\sim\text{Geometric}((n-k+1)/n)$ 独立。
   $$E[T]=nH_n,\quad\text{Var}[T]=n^2\sum_{j=1}^{n}\frac{1}{j^2}-nH_n$$
   $$E[T^2]+E[T]=n^2\left(H_n^2+\sum_{j=1}^{n}\frac{1}{j^2}\right)$$
   $$E(n)=\frac{E[T^2+T]}{2n}=\frac{n}{2}\left(H_n^2+\sum_{j=1}^{n}\frac{1}{j^2}\right)$$

3. **渐近计算**：对 $n=10^8$，使用调和数的渐近展开：
   $$H_n=\ln n+\gamma+\frac{1}{2n}-\frac{1}{12n^2}+O(n^{-4})$$
   $$\sum_{j=1}^{n}\frac{1}{j^2}=\frac{\pi^2}{6}-\frac{1}{n}+O(n^{-2})$$
   代入计算得 $E(10^8)\approx 1.8128\times 10^{10}$，四舍五入为 18128201710。

4. **精度要求**：$10^8$ 量级下，渐近公式误差远小于 0.5，确保取整正确。

## 改编方向

1. 改变无人机数量 $n$ 或初始速度分布
2. 使用非均匀随机选择概率
3. 改变指令规则（如速度加倍而非线性增加）
4. 限制最大速度或有其他终止条件
