# Factorisation Nim（因数分解取石子游戏）

来源：改编自 Project Euler Problem 953

## 原题意

经典取石子游戏（Nim）：两位玩家轮流从一堆中移除任意正数枚石子，无法移动者输。

在因数分解取石子游戏中，初始局面由自然数 n 的质因数分解决定：每个质因数（含重数）对应一堆石子。例如 n=12=2×2×3，初始有三堆：两堆 2 枚、一堆 3 枚。

可验证 n=1 与 n=70 时先手必败。设 S(N) 为 1≤n≤N 中先手必败的 n 之和，已知 S(10)=14、S(100)=455，求 S(10^14) mod 1e9+7。

## 题目

给定正整数 N，求 S(N) = 1≤n≤N 中先手必败的 n 之和。

## 数据范围

1 ≤ N ≤ 10^7

## 算法

标准 Nim（Bouton 定理）：先手必败 iff 所有堆大小异或（nim-sum）为 0。

设 n = ∏ p_i^{e_i}，堆为每个 p_i 重复 e_i 次，其异或 = xor_i (e_i 为奇数 ? p_i : 0)，即 n 的奇数次质因子的异或（等价于 n 平方自由部分中互异质因子的异或）。

用最小质因子筛 (SPF) 对 1..N 逐 n 分解，累加异或为 0 的 n，复杂度 O(N log N)。

## 改编方向

1. 原题求 S(10^14) mod 1e9+7，需要"平方自由部分异或计数"的高级算法（GF(2) 线性基 / meet-in-the-middle 等），缩数据后可直接枚举。
2. 可改为多组输入，或输出"必败 n 的个数"而非 n 之和。
3. 可改为直接判单点 nim(n) 是否为 0（对应 n=1、n=70 验证点）。
