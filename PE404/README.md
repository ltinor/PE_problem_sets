# PE404 - 交叉椭圆

来源：改编自 Project Euler Problem 404

## 原题意

E_a 是椭圆 x²+4y²=4a²。E_a' 是 E_a 绕原点旋转 θ (0°<θ<90°) 的图像。
两个椭圆交于四点，b 为距原点较近的交点距离，c 为较远的距离。
规范三元组 (a,b,c) 满足 a<b<c 均为正整数。
C(N) = a≤N 的规范三元组数量。原题 N=10^17，PE 答案：1199216165080853。

## 题目

给定 N，求 C(N)。（N ≤ 10000）

## 算法

- 从几何推导交点距离关系：1/b² + 1/c² = 5/(4a²)
- 约束：a < b < c ≤ 2a（因为 E_a 上点距原点最远为 2a）
- 从关系式解出 c：c² = 4a²b² / (5b² - 4a²)
- 枚举 a 从 1 到 N，b 从 a+1 到 2a-1
  1. 计算分母 den = 5b² - 4a²，需 den > 0
  2. 计算分子 num = 4a²b²，需 den | num
  3. 计算 c = √(num/den)，验证 c 是整数、c > b、c ≤ 2a
- 时间复杂度 O(N²)，N=10000 时约 10⁸ 次迭代
- 优化：提前计算 a² 和 4a² 减少重复运算

## 改编方向

1. **使用不同的椭圆方程**：改变半轴比
2. **三维椭球**：椭球交点的格点问题
3. **改变旋转角度**：限定 θ 为特定值
4. **考虑更多交点**：不同类型的交点分类
5. **添加格点约束**：交点必须为格点
