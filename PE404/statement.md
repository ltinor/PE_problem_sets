# 交叉椭圆

## 题目描述

E_a 是椭圆 x²+4y²=4a²。E_a' 是 E_a 绕原点逆时针旋转一定角度 θ (0°<θ<90°) 得到的椭圆。

b 是两个椭圆交点中距原点较近的距离，c 是较远的距离。

若有序三元组 (a,b,c) 中 a,b,c 均为正整数，称之为规范椭圆三元组。例如 (209,247,286) 是一组。

记 C(N) 为所有满足 a ≤ N 的规范椭圆三元组的数量。

给定 N，求 C(N)。

---

## 输入格式

一个整数 N。

---

## 输出格式

一个整数，表示 C(N)。

---

## 样例

### 输入
```
1000
```

### 输出
```
7
```

---

## 数据范围

- 对于 20% 数据：N ≤ 200
- 对于 50% 数据：N ≤ 2000
- 对于 100% 数据：N ≤ 10000
