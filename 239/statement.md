# 素数移位

## 题目描述

将标有 $1$ 到 $N$ 的 $N$ 个盘子随机排成一排。

求在这个随机排列中，恰好有 $K$ 个素数盘子不在其自然位置上的概率。

将答案四舍五入保留 $12$ 位小数，格式为 `0.abcdefghijkl`。

---

## 输入格式

一行两个整数 $N$ 和 $K$。

---

## 输出格式

输出概率，四舍五入保留 $12$ 位小数。

---

## 样例

### 输入
```
100 22
```

### 输出
```
0.001750680826
```

---

## 数据范围

$1 \le N \le 200$，$0 \le K \le \pi(N)$（$N$ 以内的素数个数）。
