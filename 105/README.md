# 105 — Special Subset Sums: Testing（特殊的子集和：检验）

来源：改编自 Project Euler Problem 105

## 原题意

从 `sets.txt` 读取 100 个集合，找出所有特殊和集并求元素和之和。答案：73702。

## 题目

输入 $N$，然后 $N$ 行，每行先一个整数 $m$ 表示集合大小，再 $m$ 个整数表示集合元素。输出所有满足特殊和集条件的集合的元素总和的和。

特殊和集定义：
1. 任意两个非空不相交子集的和不同
2. 若 $|B| > |C|$ 则 $S(B) > S(C)$

## 数据范围

- $1 \le N \le 100$
- $7 \le m \le 12$（与原题一致）
- $1 \le a_i \le 10^4$

## 算法

对每个集合排序后：
1. 检查条件 2（$O(m)$）：对 $k=1..\lfloor (m-1)/2 \rfloor$，验证最小 $k+1$ 之和 $>$ 最大 $k$ 之和
2. 检查条件 1（$O(2^m)$）：位掩码枚举所有子集和，排序后检查重复。$m \le 12$ 时 $2^m \le 4096$，非常快

时间复杂度 $O(N \cdot 2^m \cdot m)$，对于 $N=100, m \le 12$ 可以瞬间完成。

## 改编方向与取舍

### 改编方向
1. **标准输入替代文件** → 去掉外部文件依赖（本题采用）
2. **扩展参数范围** → $m \le 20$，需要用 meet-in-the-middle 或动态规划优化条件 1 的检查
3. **条件弱化** → 只检查条件 2（近似特殊和集），输出 "近似" 和
4. **条件 1 逆问题** → 找出所有存在等和子集对的集合（不满足条件 1）

### 取舍理由
- 选择标准输入：与 PE 102 一致，统一采用 OJ 友好的格式
- $m$ 保留在原题范围（7-12）：位运算枚举足够快，不需要引入更复杂的算法
- 不弱化条件：失去了原题的数学意义
