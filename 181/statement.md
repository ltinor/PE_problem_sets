# 物体分组

## 题目描述

有 $B$ 个黑色物体和 $W$ 个白色物体。相同颜色的物体不可区分。将所有这些物体分成若干个组（至少一组），问有多少种不同的分组方式？

分组时，组内物体的顺序和组之间的顺序都不重要。两个分组方式相同，当且仅当各组的多重集（以 (黑数, 白数) 表示）完全相同。

例如，$B=3,W=1$ 时有 $7$ 种分组方式：

| 分组 |
|------|
| (BBBW) |
| (B,BBW) |
| (B,B,BW) |
| (B,B,B,W) |
| (B,BB,W) |
| (BBB,W) |
| (BB,BW) |

---

## 输入格式

第一行一个整数 $T$，表示测试数据组数。
接下来 $T$ 行，每行两个整数 $B$ 和 $W$。

---

## 输出格式

对于每组数据，输出一行一个整数，表示答案。

---

## 样例

### 输入
```
1
3 1
```

### 输出
```
7
```

---

## 数据范围

- $1 \le T \le 10$
- $0 \le B, W \le 60$
- 答案可能很大，但保证不超过 $2^{127}-1$
