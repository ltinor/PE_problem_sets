# 单位圆网格覆盖

## 题目描述

直角网格由 N+2 条水平线和 N+2 条竖直线组成，最外侧四条线的方程为 x = ±1, y = ±1。与单位圆（圆心在原点，半径 1）有重叠的网格染红色。

给定 N，求最优放置内层 N 条水平线和 N 条竖直线（非等距），使红色面积最小。输出红色面积，保留 10 位小数。

---

## 输入格式

一个整数 N。

---

## 输出格式

一个浮点数，表示最小红色面积，四舍五入到小数点后 10 位。

---

## 样例

### 输入
```
10
```

### 输出
```
3.3469640797
```

---

## 数据范围

- 对于 30% 数据：N ≤ 10
- 对于 60% 数据：N ≤ 100
- 对于 100% 数据：N ≤ 400
