# PE770 — B-tourism（B旅游）

来源：改编自 Project Euler Problem 770

## 原题意

"B-tourism" 是关于一位旅行者的优化问题。旅行者需要在一条直线上（或网格/图中）访问所有 $N$ 个地点，但每次移动的最大距离限制为 $B$。旅行者从某个起点出发，需要访问每个地点恰好一次。

问题可能要求：计算满足约束的合法旅行路线总数，或对所有可能的 $B$ 求和，或求最优路线的总旅行距离。

PE 答案：1273112231728726740（约 $1.27 \times 10^{18}$）。

## 算法

1. **DP 状态表示**：$dp[\text{mask}][\text{last}]$ = 已访问位置集合为 mask、当前位置为 last 的合法路线数。
2. **转移**：枚举下一个未访问的位置 $nxt$，需满足 $|nxt - last| \le B$。
3. **小规模暴力**：$N \le 20$ 时可用 $O(2^N \cdot N^2)$ 的 DP 完全计算。
4. **大规模分析**：利用转移矩阵的特殊结构（带状矩阵），使用矩阵幂或递推加速。
5. **组合公式**：对特定 $B$（如 $B=1$），结果为简单的闭式公式。

## 改编方向

1. 推广到二维网格上的旅行（2D B-tourism）
2. 加入时间窗口约束（必须在特定时间到达）
3. 多个旅行者协作覆盖
4. 加权版本：不同边的旅行代价不同
5. 随机版本：地点随机分布，计算期望路线数
