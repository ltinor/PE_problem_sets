# PE396 - 弱古德斯坦序列（缩数据简单版）

来源：改编自 Project Euler Problem 396

## 原题意

弱古德斯坦序列：每次将数用 k 进制写出，解释为 k+1 进制再减 1。
原题求 ΣG(n) for n=1..15 的最后 9 位数字（答案 173214653）。

## 缩数据改编

原题 n<16 时 G(n) 呈 Ackermann 级增长，直接模拟不可行（G(8) 已含上亿位数级迭代次数），
需要针对「换底 + 减一」动力学做模 10^9 的高阶分析。

本仓库为**缩数据简单版**：将 N 限制在 [2, 8]，此时 G(n) 规模可控（G(7)=2045），
直接模拟进制转换即可求出 ΣG(n)，无需硬编码。

## 算法

- 对每个 n ∈ [1, N)，从 g=n、k=2 开始迭代：
  - 将 g 拆成 k 进制位，按 k+1 进制重新解释，再减 1。
  - 每次迭代计入非零元素个数，直到 g=0。
- 累加所有 G(n) 得到答案。
- Goodstein 定理保证序列总会终止。

## 验证点

- 第 6 个弱古德斯坦序列开头为 6, 11, 17, 25
- G(2)=3, G(4)=21, G(6)=381
- ΣG(n)=2517 for 1≤n<8（即输入 N=8 输出 2517）
