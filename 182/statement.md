# RSA 加密

## 题目描述

RSA 加密基于以下流程：

生成两个不同的素数 $p$ 和 $q$。计算 $n=pq$ 以及 $\varphi = (p-1)(q-1)$。
找到整数 $e$，满足 $1<e<\varphi$，且 $\gcd(e,\varphi)=1$。

对于满足 $m^e \bmod n = m$ 的消息 $m$，我们称为**未加密消息**。

在选择 $e$ 时，很重要的一点就是不应该有太多未加密消息。可以证明，对于给定的 $p,q,e$，未加密消息的数量为：

$$U(e) = (1 + \gcd(e-1, p-1)) \cdot (1 + \gcd(e-1, q-1))$$

给定两个素数 $p$ 和 $q$，找出所有满足 $1<e<\varphi$ 且 $\gcd(e,\varphi)=1$ 的 $e$，并使得 $U(e)$ 最小。求所有这些 $e$ 的和。

---

## 输入格式

一行两个整数 $p$ 和 $q$。

---

## 输出格式

一行一个整数，表示答案。

---

## 样例

### 输入
```
1009 3643
```

### 输出
```
399788195976
```

---

## 数据范围

- $3 \le p, q \le 5000$，$p \neq q$，$p,q$ 均为素数
