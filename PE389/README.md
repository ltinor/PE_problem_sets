# PE389 - 柏拉图多面体骰子

来源：改编自 Project Euler Problem 389

## 原题意

嵌套掷骰子过程（4面→6面→8面→12面→20面），求最终点数 I 的方差。

## 题目

求嵌套随机过程结果的方差。可使用全方差公式解析计算。

## 算法

- 全期望公式：E[I] = E[E[I|D]] = ...
- 全方差公式：Var[I] = E[Var[I|D]] + Var[E[I|D]]
- 单次掷 k 面骰子 n 次的均值 = n(k+1)/2，方差 = n(k^2-1)/12

## 改编方向

1. **蒙特卡洛验证**：给定模拟次数 M，用 MC 方法估算方差并输出
2. **修改骰子类型**：改变面数序列为任意输入序列
3. **求分位数**：求 I 的 95% 分位数而非方差
4. **改变初始分布**：初始掷骰用非均匀分布
