# 柏拉图多面体骰子

## 题目描述

进行以下嵌套掷骰子过程：
1. 掷一个公平的正四面体骰子（1~4），记点数为 T；
2. 掷 T 个公平的正六面体骰子（1~6），记点数之和为 C；
3. 掷 C 个公平的正八面体骰子（1~8），记点数之和为 O；
4. 掷 O 个公平的正十二面体骰子（1~12），记点数之和为 D；
5. 掷 D 个公平的正二十面体骰子（1~20），记点数之和为 I。

求 I 的方差。答案四舍五入保留 4 位小数。

---

## 输入格式

无输入（或输入模拟次数用于验证）。

---

## 输出格式

一个浮点数，表示 I 的方差，四舍五入到小数点后 4 位。

---

## 样例

### 输出
```
2406376.3623
```

---

## 数据范围

- 本题为固定答案问题，也可通过蒙特卡洛模拟验证。
