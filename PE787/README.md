# PE787 — Bezout's Game（Bezout游戏）

来源：改编自 Project Euler Problem 787

## 原题意

两名玩家进行基于 Bezout 恒等式的游戏：对任意整数 $a,b$，存在整数 $x,y$ 使得 $ax+by=\gcd(a,b)$。游戏可能涉及玩家轮流操作，利用欧几里得算法或扩展欧几里得算法进行博弈，计算必胜/必败局面的个数。

PE 答案：202676543（约 $2.03 \times 10^8$）。

## 算法

1. **欧几里得算法**：计算 $\gcd$ 所需的步数与商之和（$a/b$ 的累加）。
2. **扩展欧几里得**：求 Bezout 系数 $x,y$，可计算模逆元。
3. **Grundy 数**：若游戏为 impartial game，可用 Grundy 数分析必胜策略。
4. **$\gcd$ 和统计**：$\sum_{a,b=1}^N \gcd(a,b)$ 是经典数论求和问题。
5. **互素数对计数**：统计特定范围内最大公因数为 $g$ 的数对数量。

## 改编方向

1. 推广到多玩家 Bezout 游戏
2. 限制操作次数或取值范围
3. 与 Nim 游戏、Euclid 游戏结合
4. 计算特定范围内的必胜局面之和
5. 引入非对称操作（玩家有不同的可选操作集合）
