# 全数字素数集合

## 题目描述

使用数字 1 到 N 各**恰好一次**，将它们自由连接形成十进制整数，构成一个集合。集合中的每个元素必须由使用到的若干连续数字拼接而成。

一个集合被称为"全数字素数集合"，当且仅当：
- 集合中每个元素都是素数
- 所有数字 1~N 恰好各出现一次

例如，当 N = 9 时，{2, 5, 47, 89, 631} 是一个合法的全数字素数集合（2、5、47、89、631 都是素数，且使用了 1~9 各一次）。

注意：集合中元素的顺序无关，即 {2, 5} 和 {5, 2} 视为同一个集合。

给定 N，求不同的全数字素数集合的数量。

---

## 输入格式

一行，一个整数 N。

---

## 输出格式

一行，一个整数，表示答案。

---

## 样例

### 输入
```
1
```

### 输出
```
0
```

### 输入
```
4
```

### 输出
```
9
```

### 输入
```
9
```

### 输出
```
44680
```

### 说明
- N=1：数字 1 不是素数，无合法集合
- N=4：共 9 个合法集合

---

## 数据范围

- 1 ≤ N ≤ 9
