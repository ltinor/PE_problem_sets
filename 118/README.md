# 118 — 全数字素数集合

来源：改编自 Project Euler Problem 118

## 原题意

使用 1~9 的所有数字恰好一次，自由连接形成十进制整数，构成集合。求所有元素均为素数的集合个数。原题答案：44680。

## 题目

输入 N（≤ 9），使用 1~N 的每个数字恰好一次，构成一个集合（集合中每个数由若干连续数字拼接而成），要求集合中所有数均为素数。求不同集合的数量（集合中元素顺序无关，即 {2,5} 和 {5,2} 视为同一集合）。

## 数据范围

- 1 ≤ N ≤ 9

## 算法

1. 生成 1~N 的所有排列（N! 种）
2. 对每个排列，枚举所有分割方式（共 2^(N-1) 种，用位掩码表示分割点）
3. 对每种分割，检查每个片段是否素数
4. 将合法集合排序后放入 set 去重

N=9 时总检查次数约 9! × 2^8 ≈ 9300 万，使用简单试除法判素可接受。

素数判定：试除到 √x，对于最大 9 位数（≤ 987654321），√x ≤ 31427。

## 改编方向与取舍

### 改编方向
1. **参数化 N** → 输入 N 求集合数（本题采用）
2. **更大 N（N > 9）** → 需要更高效的判素和剪枝
3. **允许重复数字** → 集合元素可包含重复数字
4. **只计数不枚举** → 直接输出数字不构造集合

### 取舍理由
- 选择参数化 N：覆盖 1~9，原题 N=9 包含在内
- N ≤ 9：排列数可控，无需复杂剪枝
- 直接枚举：N 小时暴力可过，代码简洁
