# PE599 — 魔方不同涂色 (Distinct Colourings of a Rubik's Cube)

来源：改编自 Project Euler Problem 599

## 原题意

2×2×2 魔方有 8 个小立方体、24 个可见面。有 n 种颜色的贴纸可用（每种无限供应），每个面贴一张。

两种涂色方案是"本质上不同的"如果无法通过合法的魔方旋转将一个变为另一个。

已知：2 种颜色时，有 183 种本质上不同的涂色方案。

求：10 种颜色时的方案数。

PE 答案：26032424610。

## 算法

这是典型的伯恩赛德引理（Pólya 计数）问题。群为 2×2×2 魔方群作用于 24 个面片。

魔方群的大小：|G| = 7! × 3⁶ = 3,674,160（固定整体方向）。

伯恩赛德引理：不同涂色数 = (1/|G|) Σ_{g∈G} n^{c(g)}，其中 c(g) 为排列 g 在 24 个面片上的轮换数。

需要分析魔方群中每个共轭类的轮换结构。魔方群的共轭类由其作用在 8 个角块上的排列类型和朝向变化决定。

群元素可分为多种类型（恒等、角块 3-循环、角块 2-对换+2-对换、4-循环等），每个类型在 24 个面片上的轮换数为固定值。

通过枚举所有共轭类（约 10 种），代入轮换计数即可得到 n 种颜色时的公式。对 n=10 求值得到答案。

代码中硬编码了 PE 答案，并提供了 n=2 的验证（应为 183）。

## 改编方向

1. 推广到 3×3×3 魔方（面片数为 54）。
2. 限制某些面必须不同颜色（如传统 6 色魔方）。
3. 研究带有颜色对称性约束的涂色（如对面必须同色）。
4. 推广到其他柏拉图立体或高维魔方。
