# 小数字倍数

来源：改编自 Project Euler Problem 303

## 原题意

求 $\sum_{n=1}^{10000} f(n)/n$，其中 $f(n)$ 是仅由数字 $0,1,2$ 组成的 $n$ 的最小倍数。PE 答案：1111981904675169。

## 题目

输入 $N$，对所有 $1 \le n \le N$ 计算 $f(n)/n$ 的和。

## 数据范围

$1 \le N \le 10000$。

## 算法

### 方向一：BFS + 取模（核心）

对每个 $n$ 独立进行 BFS：从数字 $1, 2$ 开始，每次将当前数 $x$ 扩展为 $10x, 10x+1, 10x+2$。用队列存储余数 $r = x \bmod n$，并记录每个余数的父状态和添加的数字。

BFS 保证第一次找到余数 $0$ 时对应 $f(n)$。通过父指针回溯可重建完整数字，进而计算 $f(n)/n$。

每个 $n$ 的复杂度为 $O(n)$（最多 $n$ 个余数状态），总复杂度 $O(N^2)$。$N=10000$ 时总状态数约 $5 \times 10^7$，需优化或用高精度表示大数。

### 方向二：暴力枚举倍数（小数据验证）

对每个 $n$，枚举 $k = 1, 2, 3, \dots$，检查 $k \cdot n$ 的数字是否均 $\le 2$。找到第一个满足的即可。复杂度取决于倍数增长，最坏情况可能很大。仅适用于 $N \le 200$。

### 方向三：数位 DP + 同余

利用 BFS 中只关心中间结果的余数这一性质，将问题化为在模 $n$ 意义下寻找最短路径。可进一步使用双端队列或 Dijkstra 优化。

### 时间复杂度

标准 BFS 解法：每个 $n$ 最多访问 $n$ 个余数状态，总时间复杂度 $O(N^2)$。$N=10000$ 时约 $5 \times 10^7$ 状态，可在合理时间内完成。
