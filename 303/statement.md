# 小数字倍数

## 题目描述

对于正整数 $n$，定义 $f(n)$ 为 $n$ 的最小正倍数，使其十进制表示中所有数字均不超过 $2$。

换句话说，$f(n)$ 是只由数字 $0, 1, 2$ 组成的 $n$ 的最小倍数。

已知：
- $f(2)=2, f(3)=12, f(7)=21, f(42)=210, f(89)=1121222$
- $\sum_{n=1}^{100} \frac{f(n)}{n} = 11363107$

给定 $N$，求 $\sum_{n=1}^{N} \frac{f(n)}{n}$。

---

## 输入格式

一行一个整数 $N$。

---

## 输出格式

一行一个整数，表示 $\sum_{n=1}^{N} \frac{f(n)}{n}$ 的值。

---

## 样例

### 输入
```
10
```

### 输出
```
1389
```

### 输入
```
100
```

### 输出
```
11363107
```

---

## 数据范围

- $1 \le N \le 10000$
