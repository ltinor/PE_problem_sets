# 素数三元组

## 题目描述

将所有正整数排列成三角形，第n行有n个数：第n行的起始数是 T_{n-1}+1 = n(n-1)/2+1，最后一个是 T_n = n(n+1)/2。

每个正整数在三角形中最多有8个邻居（上、下、左、右及对角线方向）。

如果三个素数中，其中一个素数的另外两个邻居也都是素数，则这三个素数称为素数三元组。

记 S(n) 为第n行中属于任意素数三元组的素数之和。

给定两个行号 r1 和 r2，求 S(r1) + S(r2)。

---

## 输入格式

一行，两个整数 r1, r2。

---

## 输出格式

一个整数，表示 S(r1) + S(r2)。

---

## 样例

### 输入
```
8 9
```

### 输出
```
97
```

（S(8)=60，S(9)=37）

---

## 数据范围

- 2 ≤ r1, r2 ≤ 10^7
- 原题 PE 答案: S(5678027) + S(7208785) = 322303240771079935
