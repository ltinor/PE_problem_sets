可以表示为n<sup>15</sup>+1的数，对于任意n &gt; 1都是合数。
对于正整数n和m，记s(n,m)为n<sup>15</sup>+1所有不超过m的不同质因数之和。

例如，2<sup>15</sup>+1 = 3×3×11×331。
因此s(2,10) = 3，而s(2,1000) = 3+11+331 = 345。

同样地，10<sup>15</sup>+1 = 7×11×13×211×241×2161×9091。
因此s(10,100) = 31而s(10,1000) = 483。

对于1 ≤ n ≤ 10<sup>11</sup>，求∑ s(n,10<sup>8</sup>)。
