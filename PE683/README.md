# PE683 — The Chase II (追赶游戏II)

来源：改编自 Project Euler Problem 683

## 原题意

$n$ 名玩家围坐在圆桌旁，使用两个骰子进行游戏。游戏共 $n-1$ 轮，每轮淘汰一名玩家。
被淘汰的玩家需向奖池支付 $s^2$，其中 $s$ 为该轮完成的回合数。最终存活的玩家获得全部奖池金额。

每轮开始时，两个骰子随机交给两名玩家（可能为同一人）。每回合：
- 持有骰子的玩家各掷一次骰子
- 掷出 1 或 2（概率 1/3）：骰子传给左侧玩家
- 掷出 3 或 4（概率 1/3）：保留骰子
- 掷出 5 或 6（概率 1/3）：骰子传给右侧玩家

当某回合开始时一名玩家同时持有两个骰子，该轮结束，该玩家淘汰。

记 $G(n)$ 为获胜者获得奖金的期望值。已知 $G(5) \approx 96.544$，$G(50) \approx 2.82491788 \times 10^6$。
求 $G(500)$，用科学计数法表示并保留 9 位有效数字。

PE 答案：2.43225697（科学计数法尾数）。

## 算法

1. **随机游走模型**：相对位置 $D = d_1 - d_2 \pmod{m}$（$m$ 为剩余玩家数）。
   每回合 $D$ 的变化 $\Delta D \in \{-2,-1,0,1,2\}$，概率分别为 $\{1/9, 2/9, 1/3, 2/9, 1/9\}$。

2. **期望步数**：设 $E[d]$ 为从距离 $d$ 出发到相遇的期望回合数，$E_2[d]$ 为期望回合数的平方。
   解线性方程组：
   $$E[d] = 1 + \sum_{\delta} P(\Delta D=\delta) \cdot E[(d+\delta) \bmod m]$$
   $$E_2[d] = 1 + \sum_{\delta} P(\Delta D=\delta) \cdot (E_2[(d+\delta) \bmod m] + 2E[(d+\delta) \bmod m])$$

3. **初始分布**：两骰子独立均匀随机放置，距离分布为 $P(d=0)=1/m$，$P(d=k)=2/m$（$k=1..\lfloor(m-1)/2\rfloor$）。

4. **累加**：$G(n) = \sum_{m=2}^{n} \mathbb{E}[s^2]$，其中 $\mathbb{E}[s^2]$ 为 $m$ 名玩家时一轮的期望支付（$=E_2$ 的初始加权平均）。

5. **求解**：对每个 $m=2..500$，建立并求解约 $m/2$ 元的五对角线性方程组。

## 改编方向

1. 参数化 $n$ 的范围
2. 修改骰子概率分布
3. 考虑非均匀初始骰子分配
4. 修改支付函数 $f(s)$（如 $s^3$ 等）
