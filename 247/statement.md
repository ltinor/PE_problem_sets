# 双曲线下的正方形

## 题目描述

考虑由 x ≥ 1 和 0 ≤ y ≤ 1/x 所界定的区域。

记 S₁ 是能够放入该区域的最大正方形。
记 S₂ 是能够在剩余区域中放入的最大正方形，依此类推。

S_n 的「索引」是一个数对 (left, below)，分别表示在 S_n 左侧的正方形数目和在 S_n 下方的正方形数目。

已知 S₂ 的索引为 (1, 0)，S₃₂ 的索引为 (1, 1)，S₅₀ 的索引也为 (1, 1)。使得 S_n 的索引为 (1, 1) 的最大 n 是 50。

给定 K，求使得 S_n 的索引为 (K, K) 的最大 n。

---

## 输入格式

一行一个整数 K。

---

## 输出格式

一行一个整数，表示答案。

---

## 样例

### 输入
```
1
```

### 输出
```
50
```

（使得索引为 (1, 1) 的最大 n 是 50。）

### 输入
```
3
```

### 输出
```
782252
```

---

## 数据范围

- 对于 30% 的数据：K ≤ 1
- 对于 60% 的数据：K ≤ 2  
- 对于 100% 的数据：K ≤ 3
