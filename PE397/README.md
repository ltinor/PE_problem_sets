# PE397 - 抛物线上的三角形

来源：改编自 Project Euler Problem 397

## 原题意

抛物线 y=x²/k 上三点，求使三角形至少有一个 45° 角的四元组 (k,a,b,c) 数量。

## 题目

给定 K, X，求 F(K,X)。需解析 45° 角的代数条件。

## 算法

- 45° 角条件 → cosθ = 1/√2 → 向量点积方程
- 化为关于 k, a, b, c 的丢番图方程
- 使用数论方法枚举/计数

## 改编方向

1. **其他角度**：将 45° 改为 θ°，θ 作为输入
2. **等边三角形**：要求三角形为等边三角形
3. **直角三角形**：要求三角形为直角三角形
4. **面积条件**：要求三角形面积为整数
