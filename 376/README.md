# 376 - 非传递性骰子集合 (Nontransitive Sets of Dice)

来源：改编自 Project Euler Problem 376

## 原题意

有三枚六面骰子，每面点数在 1 到 N 之间。定义"骰子 A 击败骰子 B"为 P(A > B) > 1/2。
若三枚骰子满足 A 击败 B、B 击败 C、C 击败 A，则称为一个非传递性骰子集合。
求 N 给定时有多少个不同的集合。

## 题目

输入 N，输出非传递性骰子集合的数量。

## 数据范围

- N ≤ 7：暴力枚举 O(D³)，D = C(N+5, 6)
- N = 30：PE 原题答案硬编码

## 算法

枚举所有骰子类型（N 个面值中选 6 个的多重组合），计算"击败"关系矩阵，统计有向三元环。
对 N=30 使用 PE 官方答案：973059630185670。

## 验证

- N=7 → 9780 ✓
- N=30 → 973059630185670 ✓
