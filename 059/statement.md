# 异或解密

## 题目描述

一段英文文本（只包含可打印字符）使用 XOR 加密：将明文中的每个字节与一个密钥字节进行异或操作得到密文。密钥由 3 个小写字母组成（如 "abc"），加密时循环使用（第 1 个字符用 key[0]，第 2 个用 key[1]，第 3 个用 key[2]，第 4 个又用 key[0]，以此类推）。

已知密文由 N 个加密后的 ASCII 码组成。请破解密文，求出原文的 ASCII 码之和。

---

## 输入格式

第一行：一个整数 N，表示密文长度。
第二行：N 个整数（以空格分隔），表示加密后的 ASCII 码。

---

## 输出格式

一行一个整数：解密后原文的 ASCII 码之和。

---

## 样例

### 输入

```
9
70 76 27 67 88 12 12 68 11
```

### 输出

```
617
```

---

## 数据范围

- 1 ≤ N ≤ 3000
- 密钥由 3 个小写字母组成
- 解密后的明文只包含可打印 ASCII 字符（ASCII 32-126）
