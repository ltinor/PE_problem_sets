# 约数的最大公约数

## 题目描述

数 n 的每个正约数 d 都有一个互补约数 n/d。记 f(n) 为 n 的所有正约数 d 与 n/d 的最大公约数之和：

$$f(n) = \sum_{d|n} \gcd(d, \frac{n}{d})$$

记 F(k) 为 f 的前缀和：

$$F(k) = \sum_{n=1}^{k} f(n)$$

已知：F(10) = 32，F(1000) = 12776。

给定 k，求 F(k)。

## 输入格式

一行，一个整数 k，或字符串 `PE`。

## 输出格式

一个整数，表示 F(k)。

## 样例

### 输入
```
10
```

### 输出
```
32
```

### 输入
```
1000
```

### 输出
```
12776
```

## 数据范围

- 对于 30% 数据：k ≤ 10⁴
- 对于 60% 数据：k ≤ 10⁷
- 对于 100% 数据：k ≤ 10¹⁵
