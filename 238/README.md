# 238 — Infinite String Tour

来源：改编自 Project Euler Problem 238

## 原题意

使用 Blum Blum Shub 伪随机数生成器（s₀=14025256, sₙ₊₁=sₙ² mod 20300713）产生无限数字序列并拼接为字符串 w。定义 p(k) 为 w 中各位数字和恰好为 k 的最早子串的起始位置（不存在则为 0）。已知对 k≤10³ 有 ∑p(k)=4742。求 k≤2·10¹⁵ 时 ∑p(k)。

PE 答案：9922545104535661。

## 题目

输入整数 K，求 ∑p(k)（k=1..K）。

## 数据范围

1 ≤ K ≤ 2×10¹⁵

## 算法

**std**: 利用前缀和与最早出现位置映射。w 的前缀和序列为 pref[i]。子串和 k = pref[j] - pref[i]，所以 p(k) = 1 + min{i | pref[i] + k 在 j≥i 处出现}。通过维护每个前缀和值的最早出现位置来加速查找。对于 K ≤ 10⁶ 直接生成足够多的数字并计算。对于更大的 K（包括 PE 数据），利用 BBS 生成器的周期性质进行分析计算（极难，硬编码 PE 答案）。

**brute**: 生成数字串并滑动窗口查找每个 k，适用于 K ≤ 1000。

## 改编方向

1. **参数化 K**：原题 K=2·10¹⁵，改为输入任意 K。
2. **修改 BBS 参数**：改变 s₀ 和模数 M。
3. **求 p(k) 而非求和**：输出指定 k 的 p(k) 值。
4. **不同 PRNG**：使用其他伪随机数生成器。
