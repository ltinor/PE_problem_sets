# 幂的数字和

## 题目描述

给定两个整数 $a$ 和 $b$，求 $a^b$ 的各位数字之和。

例如，$2^{15} = 32768$，各位数字之和为 $3+2+7+6+8 = 26$。

---

## 输入格式

第一行一个整数 $T$，表示测试数据组数。

接下来 $T$ 行，每行两个整数 $a$ 和 $b$，空格分隔。

---

## 输出格式

对于每组数据，输出一行一个整数表示 $a^b$ 的各位数字之和。

---

## 样例

### 输入
```
3
2 15
2 1000
10 100
```

### 输出
```
26
1366
1
```

**样例说明**：$10^{100}$ 是 $1$ 后面跟 $100$ 个 $0$，各位数字之和为 $1$。

---

## 数据范围

- $1 \le T \le 10$
- $2 \le a \le 100$
- $1 \le b \le 1000$
