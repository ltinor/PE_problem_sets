# 斐波那契字

## 题目描述

对于两个数字串 $A$ 和 $B$，定义 $F_{A,B}$ 为序列 $(A, B, AB, BAB, ABBAB, \\dots)$，其中每一项由前两项拼接而成。

进一步定义 $D_{A,B}(n)$ 为 $F_{A,B}$ 中首个包含至少 $n$ 个数字的项的第 $n$ 位数字。

例如，取 $A=1415926535$，$B=8979323846$。$F_{A,B}$ 的前几项为：
```
1415926535
8979323846
14159265358979323846
897932384614159265358979323846
14159265358979323846897932384614159265358979323846
```
$D_{A,B}(35)$ 是第 5 项的第 35 位数字，即 9。

给定 $A$、$B$ 和 $n$，求 $D_{A,B}(n)$。

---

## 输入格式

第一行：字符串 $A$
第二行：字符串 $B$
第三行：整数 $n$

---

## 输出格式

输出一个数字（0-9），即所求的第 $n$ 位。

---

## 样例

### 输入
```
1415926535
8979323846
35
```

### 输出
```
9
```

---

## 数据范围

$|A|, |B| \\le 100$，$1 \\le n \\le 10^{16}$
