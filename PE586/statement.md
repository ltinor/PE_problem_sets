# 二元二次型

## 题目描述

数 209 可以用两种方式表达为 a² + 3ab + b²：

```
209 = 8² + 3·8·5 + 5²
209 = 13² + 3·13·1 + 1²
```

记 f(n, r) 为不超过 n 且恰好可以用 r 种方式表达为 k = a² + 3ab + b² 的整数 k 的数目，其中整数 a > b > 0。

已知：
- f(10⁵, 4) = 237
- f(10⁸, 6) = 59517

求 f(10¹⁵, 40)。

## 输入格式

一行，整数 n 和 r，空格分隔（或字符串 `PE`，或 `test`）。

## 输出格式

一个整数，表示 f(n, r)。

若输入为 `PE`，输出 PE 原题的答案：82490213。
若输入为 `test`，输出 f(10⁵, 4)。

## 样例

### 输入
```
100000 4
```

### 输出
```
237
```

### 输入
```
PE
```

### 输出
```
82490213
```

## 数据范围

- 对于 30% 数据：n ≤ 10⁶
- 对于 60% 数据：n ≤ 10⁸
- 对于 100% 数据：n ≤ 10¹⁵ 或输入为 PE
