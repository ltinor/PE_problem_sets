# PE586 — 二元二次型 (Binary Quadratic Form)

来源：改编自 Project Euler Problem 586

## 原题意

数 209 可以用两种方式表达为 a² + 3ab + b²：

```
209 = 8² + 3·8·5 + 5²
209 = 13² + 3·13·1 + 1²
```

记 f(n, r) 为不超过 n 且恰好可以用 r 种方式表达为 k = a² + 3ab + b² 的整数 k 的数目，其中整数 a > b > 0。

已知 f(10⁵, 4) = 237 以及 f(10⁸, 6) = 59517。

求 f(10¹⁵, 40)。

PE 答案：82490213。

## 算法

二元二次型 a² + 3ab + b² 的判别式为 D = 5。能表示为此形式的数恰好是那些模 5 余 0、1、4，且每个满足 p ≡ 2, 3 (mod 5) 的素因子出现偶数次的数。这对应二次域 Q(√5) 中的范数形式。

表示方式的数量与在 Z[(1+√5)/2] 中的理想分解有关。对于给定 n，表示方式数等于其在该二次域中的除子函数的一半（考虑 a > b > 0 的排序约束）。

对于 n = 10¹⁵，直接枚举不可行，需要使用解析数论方法或预计算的 PE 结果。

## 改编方向

1. 研究不同判别式 D 的二元二次型 (如 a² + ab + b², D = -3)。
2. 统计恰好有 r 种表示的数的分布密度。
3. 对于多个二次型同时要求特定表示数的计数问题。
4. 将限制 a > b > 0 改为其他组合约束（如 a ≥ 0, b ≥ 0）。
