# PE452 - 长乘积 (Long Products)

来源：改编自 Project Euler Problem 452

## 原题意

记 F(m,n) 为所有乘积不超过 m 的 n 元正整数组的数目。

例如：F(10, 10) = 571。

验证：F(10^6, 10^6) mod 1234567891 = 252903833。

原题求 F(10^9, 10^9) mod 1234567891 = 345558983。

## 题目

给定 m, n，求 F(m,n) 对 MOD 取模的值。

## 算法

- τ_n(k) = 将 k 写成 n 个正整数乘积的方式数（有序）
- τ_n 是积性函数：若 k = ∏ p_i^{e_i}，τ_n(k) = ∏ C(e_i+n-1, n-1)
- F(m,n) = Σ_{k=1}^{m} τ_n(k)
- 可递推：F(m,n) = Σ_{d=1}^{m} F(m/d, n-1)
- 使用整除分块加速

## 改编方向

1. **限制范围**：求乘积在 [L,R] 内的 n 元组数
2. **无序元组**：求无序 n 元组数目
3. **不同因子**：要求 n 个元素两两不同
