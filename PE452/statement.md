# 长乘积

## 题目描述

记 F(m,n) 为所有满足以下条件的 n 元正整数组 (a₁, a₂, ..., aₙ) 的数目：
a₁ × a₂ × ... × aₙ ≤ m

例如：F(10, 10) = 571。

给定 m 和 n，求 F(m,n) mod 1234567891。

---

## 输入格式

两个整数 m, n (1 ≤ m, n ≤ 10^9)。

---

## 输出格式

一个整数，表示 F(m,n) mod 1234567891。

---

## 样例

### 输入
```
10 10
```

### 输出
```
571
```

---

## 数据范围

- 对于 30% 数据：m, n ≤ 10
- 对于 60% 数据：m, n ≤ 1000
- 对于 100% 数据：m, n ≤ 10^9
