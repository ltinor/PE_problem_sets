# 交换筹码

## 题目描述

在一行 $2n+1$ 个水平方格上，一端摆有 $n$ 个红色筹码，另一端摆有 $n$ 个蓝色筹码，中间用一个空格分开。

筹码可以从一格移到下一格（滑动）或者在目的地为空格时跳过另一个筹码（跳跃）。

记 $M(n)$ 是完全逆转彩色筹码位置所需的最小步数。可以验证 $M(3)=15$，恰好是一个三角形数。

若将使得 $M(n)$ 为三角形数的 $n$ 取出构成数列，其前五项为 $1, 3, 10, 22, 63$，和为 $99$。

给定 $K$，求该数列前 $K$ 项的和。

---

## 输入格式

一行一个整数 $K$。

---

## 输出格式

一行一个整数，表示数列前 $K$ 项的和。

---

## 样例

### 输入

```
5
```

### 输出

```
99
```

### 输入

```
40
```

### 输出

```
2470433131948040
```

---

## 数据范围

- $1 \le K \le 40$
