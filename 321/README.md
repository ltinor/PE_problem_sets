# 321 — Swapping Counters

来源：改编自 Project Euler Problem 321

## 原题意

在一行 $2n+1$ 个方格上，$n$ 个红筹码在一端，$n$ 个蓝筹码在另一端。筹码可滑动或跳跃。$M(n)$ 为完全交换位置的最小步数。求使得 $M(n)$ 为三角形数的 $n$ 的前 40 项之和。答案：2470433131948040。

## 题目

输入 $K$，求使得 $M(n)$ 为三角形数的 $n$ 的前 $K$ 项之和。

## 数据范围

- $1 \le K \le 40$

## 算法

1. **BFS 模拟法**：对每个 $n$ 用 BFS 求 $M(n)$，判断是否为三角形数。适用于小 $n$（验证用）。
2. **数学推导**：$M(n)=n(n+2)$。需求解 $n(n+2)=t(t+1)/2$，转化为 Pell 方程 $X^2-2Y^2=2$（其中 $X=2n+2, Y=2t+1$），通过递推生成所有解。
3. **打表法**：Pell 方程的解可预计算。

## 改编方向

1. 原题固定 40 项 → 参数化 $K$
2. 将三角形数条件改为平方数或其他多边形数
3. 改变筹码数量比例（如红蓝筹码数量不同）

选择方向 1：参数化 $K$。
