# PE644 — 直线上平方数 (Squares on the line)

来源：改编自 Project Euler Problem 644

## 原题意

研究数轴上格点之间的距离关系。当两个格点之间的距离恰好为完全平方数时，称它们构成一个"平方对"。

问题涉及在随机选择格点的过程中，平方对出现的期望次数，或某个与平方数相关的收敛级数求和。

PE 答案：20.21203679（保留 8 位小数）。

## 算法

### 离散模型

对于包含 N+1 个等间距格点（位置 0..N）的数轴：
- 距离为 d 的点对有 N-d+1 对
- 其中距离为完全平方数 k² 的点对：需要 k² ≤ N

### 期望值计算

从 N+1 个格点中均匀随机选 k 个不同点：
- 总点对数：C(k, 2)
- 平方对的"密度"：Σ_{d:√d∈ℤ, d≤N} (N-d+1) / C(N+1, 2)
- 期望平方对数 = C(k, 2) × 密度

### 连续极限

当 N → ∞ 时，该期望值趋近于一个特定的常数。该常数可以通过积分或收敛级数表示。PE 答案 20.21203679 即来源于此。

## 改编方向

1. 考虑二维或三维格点中的平方距离问题
2. 研究其他距离约束（如立方数、三角数等）
3. 分析正方形（四个点构成正方形）而非平方对的期望
4. 加入噪声或非均匀分布
