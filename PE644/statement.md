# 直线上平方数

## 题目描述

在数轴上的区间 [0, N] 中，均匀分布着 N+1 个等间距的格点（位置 0, 1, 2, ..., N）。

从中随机选取 k 个不同的格点，定义一次"成功"为：所选格点中存在两个点，使得它们之间的距离是一个完全平方数（即距离为 1², 2², 3², ...）。

记 P(N, k) 为该事件发生的概率，求某个涉及平方数的期望值或极限值。

PE 答案为 20.21203679（精确到小数点后 8 位），该值来源于一个特定的数学常数或级数求和。

## 输入格式

一行，字符串 `PE` 或 `verify` 或 `compute`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案（保留 8 位小数）。

若输入为 `verify`，输出小规模期望值计算和级数求和结果。

若输入为 `compute`，计算级数的近似值。

## 样例

### 输入
```
PE
```

### 输出
```
20.21203679
```

## 数据范围

- 完整问题：答案为超越常数
- 精度要求：小数点后 8 位
