# 伪幸运数

## 题目描述

如果一个正偶数 $N$ 满足以下两个条件之一，则称 $N$ 是**可接受的（admissible）**：

- $N$ 是 $2$ 的幂（即 $N=2^a$，其中 $a \ge 1$）
- $N$ 的不同的质因数恰好是若干个从 $2$ 开始的连续质数（例如 $2,3,5$ 是连续的，但 $2,5$ 不是）

前十二个可接受数为：$2, 4, 6, 8, 12, 16, 18, 24, 30, 32, 36, 48$。

如果 $N$ 是可接受数，定义 $N$ 的**伪幸运数**为使得 $N+M$ 为质数的最小整数 $M > 1$。

例如，$N=630$ 是可接受数（$630=2\times3^2\times5\times7$）。$630+11=641$ 是质数，所以 $N=630$ 的伪幸运数是 $M=11$。

现在给定一个正整数 $U$，请计算所有小于 $U$ 的可接受数 $N$ 的所有**不同的**伪幸运数之和。

---

## 输入格式

一行一个正整数 $U$。

---

## 输出格式

一行一个整数，表示不同的伪幸运数之和。

---

## 样例

### 输入

```
100
```

### 输出

```
15
```

**解释**：小于 100 的可接受数有 2, 4, 6, 8, 12, 16, 18, 24, 30, 32, 36, 48, 54, 64, 72, 90, 96。它们各自的伪幸运数分别为 3, 3, 5, 3, 5, 3, 5, 5, 7, 5, 5, 5, 5, 3, 7, 7, 5。不同的伪幸运数只有 3, 5, 7，它们的和为 15。

---

## 数据范围

- $2 \le U \le 10^9$
