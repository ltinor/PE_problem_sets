## 原题描述

原题及更多讨论见 [https://projecteuler.net/problem=326](https://projecteuler.net/problem=326)。

数列a<sub>n</sub>按如下方式递归定义：$a\_1=1, a\_n=(\sum_{k=1}^{n-1}k·a_k) \text{ mod } n$。

因此a<sub>n</sub>的前10项分别是：1,1,0,3,0,3,5,4,1,9。

记f(N,M)为满足如下条件的数对(p,q)的数目：

$$ 1 \le p \le q \le N \text{ 且 } (\sum_{t=p}^{q}a_i) \text{ mod } M=0$$

可以看出f(10,10)=4，这4个数对分别是(3,3)、(5,5)、(7,9)和(9,10)。

此外还已知f(10<sup>4</sup>,10<sup>3</sup>)=97158。

求f(10<sup>12</sup>,10<sup>6</sup>)。
