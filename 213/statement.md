# 跳蚤马戏团

## 题目描述

在一个 N×N 的方形网格上，初始状态下每个方格上有一只跳蚤。每响起一次钟声，每只跳蚤等概率随机跳向一个相邻的方格（边界上的跳蚤有 3 个选择，角上的有 2 个选择，其余有 4 个选择）。

求 R 次钟声后，没有跳蚤的方格的期望数目。答案四舍五入到六位小数。

---

## 输入格式

一行，两个整数 N 和 R（1 ≤ N ≤ 30，1 ≤ R ≤ 50）。

---

## 输出格式

一个实数，保留 6 位小数。

---

## 样例

### 输入
```
2 1
```

### 输出
```
0.500000
```

---

## 数据范围

- 1 ≤ N ≤ 30
- 1 ≤ R ≤ 50
- PE 答案: N=30, R=50 → 330.721154
