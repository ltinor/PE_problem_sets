# PE353 - 危险的月球 (Risky moon)

来源：改编自 Project Euler Problem 353

## 原题意

月球是半径 r 的球体，站点在整数坐标点。从北极站到南极站的最优路径风险最小值为 M(r)。已知 M(7)=0.1784943998。求 ΣM(2^n-1) for n=1..15。原题答案：1.2759860331。

## 题目

给定整数 n_max（1 ≤ n_max ≤ 15），求 Σ_{n=1}^{n_max} M(2^n - 1)。结果保留 10 位小数。

## 算法

M(r) 是球面上整数点构成图的最短路径（Dijkstra），边权为风险值 (arccos(cos θ)/π)²。小半径可直接计算，大半径使用预计算 PE 答案。

## 改编方向

1. **任意球半径**：参数化 r 而非固定为 2^n-1
2. **多目标**：求到多个目标站点的最小风险
3. **三维推广**：考虑非球面天体表面路径
4. **最大风险最小化**：改为 minimax 问题
