# 危险的月球

## 题目描述

月球是半径为 r 的球体 C(r)，中心在原点。站点在球面整数坐标点上，北极站 (0,0,r)，南极站 (0,0,-r)。

两站点间的路径危险程度为 (d/(πr))²，其中 d 是沿大圆的路径长度。一次旅行（经过多个站点）的危险程度为各段路径危险程度之和。

M(r) 表示从北极站到南极站的最小危险程度。已知 M(7)=0.1784943998。

给定 n_max，求 Σ_{n=1}^{n_max} M(2^n - 1)。

---

## 输入格式

一个整数 n_max。

---

## 输出格式

一个浮点数，保留 10 位小数。

---

## 样例

### 输入
```
3
```

### 输出
```
1.6784943998
```

### 输入
```
7
```

### 输出
```
1.1558585444
```

---

## 数据范围

- 对于 30% 数据：n_max ≤ 4
- 对于 60% 数据：n_max ≤ 8
- 对于 100% 数据：n_max ≤ 15
