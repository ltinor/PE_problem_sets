# PE841 — Regular Star Polygons（正星多边形）

来源：改编自 Project Euler Problem 841

## 原题意

正星多边形 $\{n/k\}$ 由正 $n$ 边形的顶点按间隔 $k$ 依次连接而成。当 $\gcd(n,k)=1$ 时，形成一条闭合的星形路径；当 $\gcd(n,k)=g>1$ 时，得到 $g$ 个 $\{n/g, k/g\}$ 星形的组合。

本题可能涉及计算与正星多边形相关的量，如区域数、交点数目、或对所有有效 $(n,k)$ 求和。

PE 答案：540610990902316。

## 算法

1. **欧拉函数 $\varphi(n)$**：计算与 $n$ 互素的 $k$ 的个数（$1 \leq k \leq n/2$），即不同星多边形的个数。
2. **星多边形计数**：$\lfloor\varphi(n)/2\rfloor$ 为 $n$ 的不同连通星多边形数量。
3. **莫比乌斯函数**：可用于对星多边形属性求和的反演计算。
4. **几何性质**：星多边形 $\{n/k\}$ 的顶点角度为 $2\pi \cdot j \cdot k/n$，边连接顶点 $j$ 到 $(j+k)\bmod n$。
