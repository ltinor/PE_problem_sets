# 比赛

## 题目描述

两个玩家进行一场比赛，先达到 $S$ 分者获胜（同时达到则平局）。玩家交替进行回合。

- **玩家 1 的回合**：投掷一枚公平硬币。若为正面，得 1 分；反面不得分。
- **玩家 2 的回合**：选择一个正整数 $T$，然后投掷 $T$ 枚公平硬币。若全部正面，得 $2^{T-1}$ 分；否则不得分。

玩家 2 总是采取最优策略来最大化自己的胜率。双方均从 0 分开始。假设玩家 1 先手。

给定 $S$，求玩家 2 的胜率（以浮点数输出，保留 8 位小数）。

---

## 输入格式

输入一行，一个整数 $S$（$1 \le S \le 100$）。

---

## 输出格式

输出一个浮点数，表示玩家 2 的胜率，保留 8 位小数。

---

## 样例

### 输入
```
100
```

### 输出
```
0.83648566
```

---

## 数据范围

$1 \le S \le 100$
