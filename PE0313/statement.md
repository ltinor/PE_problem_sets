# 滑动游戏

## 题目描述

在一个 m × n 的网格上，每个格子放有一个筹码。其中一个红色筹码初始位于左上角 (1,1)，一个空格位于右下角 (m,n)。每次操作可以将一个筹码水平或垂直地滑入相邻的空格。

游戏的目标是将红色筹码移动到右下角 (m,n)。设 S(m,n) 为完成游戏所需的最少步数。

例如，S(2,2) = 5，S(5,4) = 25。

求有多少个不同的网格 (m,n)（m,n ≥ 2，且 (m,n) 与 (n,m) 视为同一个网格）满足 S(m,n) = p²，其中 p 为小于 P 的素数。

---

## 输入格式

一行一个整数 P。

---

## 输出格式

一行一个整数，表示满足条件的网格数量。

---

## 样例

### 输入
```
100
```

### 输出
```
5482
```

---

## 数据范围

- $2 \le P \le 10^6$
