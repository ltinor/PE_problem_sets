# 滑动游戏 (Sliding Game)

来源：改编自 Project Euler Problem 313

## 原题意

在 m×n 网格上，红色筹码从左上角移动到右下角，空格初始在右下角。求 S(m,n) = p²（p 为素数）的网格数。PE 答案：2057777371816。

## 题目

输入素数上限 P，输出满足 S(m,n) = p²（p < P，p 为素数）且 m,n ≥ 2 的网格 (m,n) 数量。

规定：S(m,n) 为完成游戏的最少步数。最优策略为交替移动（俗称"之字形"）。

## 数据范围

$2 \le P \le 10^6$。

## 算法

### 方向一：公式推导

对于 m,n ≥ 3，最优步数为 S(m,n) = 4(m+n) - 11。

由 S(m,n) = p² 得 m+n = (p² + 11)/4。对每个奇素数 p，计数满足 3 ≤ m ≤ n 的 (m,n) 对数：floor((p²+11)/8) - 2。

对于 m=2：S(2,n) = 6n - 9（n ≥ 3），S(2,2) = 5。仅 p=3 时 S(2,3) = 9 = 3² 成立。

### 方向二：素数筛 + 累加

使用埃氏筛生成 [2, P) 内所有素数。对每个素数 p，O(1) 计算贡献并累加。

### 方向三：数学优化

公式为闭式，可直接用素数定理估算，但精确计数需遍历素数。复杂度 O(P log log P + π(P))。

### 时间复杂度

P ≤ 10^6 时约 0.1s。
