# 字典序排列

## 题目描述

给定 $N$ 和 $K$，求数字 $0, 1, \dots, N-1$ 的字典序排列中，第 $K$ 个排列是什么。

例如，当 $N=3$ 时，所有字典序排列为：

$$012,\quad 021,\quad 102,\quad 120,\quad 201,\quad 210$$

第 $1$ 个排列是 $012$，第 $6$ 个排列是 $210$。

---

## 输入格式

第一行一个整数 $T$，表示测试数据组数。  
接下来 $T$ 行，每行两个整数 $N$ 和 $K$。

---

## 输出格式

对于每组数据，输出一行，为数字 $0 \sim N-1$ 的字典序排列中第 $K$ 个排列（数字连写，不含空格）。

---

## 样例

### 输入
```
3
3 1
3 6
4 24
```

### 输出
```
012
210
3210
```

---

## 数据范围

- $1 \le N \le 10$
- $1 \le K \le N!$
- $1 \le T \le 10$
