# 可逆数

## 题目描述

有些正整数 n 满足：n + rev(n)（rev(n) 是 n 的十进制逆序）的十进制表示只包含奇数字。例如 36+63=99, 409+904=1313。我们称这样的数为可逆数。n 和 rev(n) 均不能有前导零。

给定 D，求小于 10^D 的所有可逆数的个数。

---

## 输入格式

一行一个整数 D (1 ≤ D ≤ 9)。

---

## 输出格式

一行一个整数，表示小于 10^D 的可逆数个数。

---

## 样例

### 输入

```
3
```

### 输出

```
120
```

（小于 1000 的可逆数有 120 个）

---

## 数据范围

- 1 ≤ D ≤ 9
