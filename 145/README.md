# 可逆数 (Reversible Numbers)

来源：改编自 Project Euler Problem 145

## 原题意

n + rev(n) 的十进制所有位均为奇数字。称 n 为"可逆数"。求小于十亿（10⁹）的可逆数个数。

原题答案：608720

## 题目

给定 D（≤9），求小于 10^D 的可逆数个数。

## 数据范围

- 1 ≤ D ≤ 9

## 算法

### 方法1：组合计数（std）

将数字按位配对处理（d[i] 与 d[D-1-i]）。对每对数字，和+进位必须为奇数。

- 最高位和最低位不能为 0（避免前导零）
- 进位只能是 0 或 1（最大和 9+9+1=19）
- DP：从中间向外处理，状态为当前进位值

时间复杂度 O(D)。

### 方法2：暴力枚举（brute）

对较小的 D（≤7），直接枚举所有 n < 10^D，计算 rev(n) 并检查。

时间复杂度 O(10^D)。
