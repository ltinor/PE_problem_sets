# Nim 游戏

## 题目描述

Nim 是一种取石子游戏。三堆版本规则：初始有三堆石子，每堆分别有 $n_1, n_2, n_3$ 枚。玩家轮流从任意一堆取走任意正数枚石子，无法操作者输。

定义 $X(n_1, n_2, n_3) = n_1 \oplus n_2 \oplus n_3$（按位异或），根据 Bouton 定理：$X = 0$ 时先手必败，否则先手必胜。

给定 $N$，求有多少个正整数 $n \le N$ 满足 $X(n, 2n, 3n) = 0$。

---

## 输入格式

一行一个整数 $N$。

---

## 输出格式

一行一个整数，表示满足条件的 $n$ 的个数。

---

## 样例

### 输入
```
10
```

### 输出
```
2
```

（$n = 1, 2$ 时满足条件）

### 输入
```
100
```

### 输出
```
5
```

---

## 数据范围

- $1 \le N \le 2^{30}$
