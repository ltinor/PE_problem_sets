# 最小公倍数

## 题目描述

给定一个正整数 $n$，求最小的正整数 $x$，使得：

$x$ 能被 $1,2,3,\dots,n$ 中的所有整数整除。

由于答案可能很大，请输出：

$$
x \bmod (10^9 + 7)
$$

---

## 输入格式

第一行一个整数 $T$，表示测试数据组数。

接下来 $T$ 行，每行一个整数 $n$。

---

## 输出格式

对于每组数据，输出一行一个整数表示答案。

---

## 样例

### 输入
```
1
10
```
### 输出
```
2520
```
---

## 数据范围

- $1 \le T \le 10^4$
- $1 \le n \le 10^5$
