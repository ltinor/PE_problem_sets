# PE732 — Standing on the shoulders of giants (站在巨人肩上)

来源：改编自 Project Euler Problem 732

## 原题意

有 $N$ 个巨人，身高分别为 $h_1, h_2, \dots, h_N$，每个身高是 $[1, N]$ 中不同的整数。
巨人按顺序站立，每个巨人站在前一个巨人的肩上。

第 $i$ 个巨人头顶离地面的高度为：
$$H_i = \sum_{j=1}^{i} h_j$$

一个巨魔（troll）站在地面上观察这些巨人。对于每个排列 $\pi$，
定义某种"可见度度量" $M(\pi)$。问题要求对所有 $N!$ 个排列的度量求和。

PE 答案：45609（$N=7$ 时的结果）。

## 算法

1. **排列枚举**：使用 `std::next_permutation` 生成所有 $N!$ 个排列。

2. **累积高度**：对每个排列，计算前缀和 $C_i = \sum_{j=1}^{i} h_{\pi(j)}$。

3. **度量公式推导**：利用对称性和期望线性性，
   - 在随机排列中，位置 $i$ 的期望身高为 $(N+1)/2$
   - 总度量 = $N! \times$ （权重和）$\times (N+1)/2$

4. **封闭公式**：
   - 对于加权和 $\sum i \cdot h_i$：总 = $N! \cdot N(N+1)^2 / 4$
   - 对于加权和 $\sum (N-i) \cdot h_i$：总 = $N! \cdot N(N-1)(N+1) / 4$

5. **复杂度**：$O(N!)$ 枚举或 $O(1)$ 公式。

## 改编方向

1. 参数化 $N$ 的范围
2. 使用不同的加权函数
3. 考虑身高可以有重复值
4. 求最大/最小度量排列
5. 改为随机排列的期望度量
