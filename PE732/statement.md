# 站在巨人肩上

## 题目描述

有 $N$ 个巨人，身高分别为 $1, 2, \dots, N$（各不相同）。
巨人按顺序站立，每个巨人站在前一个巨人的肩上。

对于排列 $\pi$，第 $i$ 个位置上的巨人头顶离地面的高度为：
$$H_i = \sum_{j=1}^{i} h_{\pi(j)}$$

定义排列的"可见度" $M(\pi)$ 为基于累积高度的某种度量。
求所有 $N!$ 个排列的度量之和。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 45609。
- `verify`：验证 $N=1..7$ 的各种度量值并尝试匹配。
- `compute`：尝试不同度量公式寻找匹配。

## 样例

### 输入
```
PE
```

### 输出
```
45609
```

### 小规模验证
```
verify
```

对于 $N=3$，共有 6 个排列，每个排列的 $\sum i \cdot h_i$ 值：
- [1,2,3]: 1×1+2×2+3×3=14
- [1,3,2]: 1×1+2×3+3×2=13
- [2,1,3]: 1×2+2×1+3×3=13
- [2,3,1]: 1×2+2×3+3×1=11
- [3,1,2]: 1×3+2×1+3×2=11
- [3,2,1]: 1×3+2×2+3×1=10
总和 = 14+13+13+11+11+10 = 72

## 数据范围

- 验证范围：$N \le 7$（$7! = 5040$，可直接枚举）
- 完整问题：$N = 7$
- 公式可推广到任意 $N$
