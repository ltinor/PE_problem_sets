# 162 — 十六进制数

来源：改编自 Project Euler Problem 162

## 原题意

求至多 16 位的十六进制数中，同时包含数字 0、1、A 至少一次的数的个数（答案用十六进制表示）。原题答案：3D58725572C62302。

## 题目

参数化 D：输入 D (≤ 16)，求至多 D 位的十六进制数中同时包含 0、1、A 至少一次的个数，用十六进制输出。

## 数据范围

- 1 ≤ D ≤ 16

## 算法

**std**: 容斥原理。对每个长度 L，总数 = 15×16^(L-1)（首位非零），减去缺少 0、1、A 的情况，加回重复扣除的。使用 `__int128` 进行大整数运算，最后转为十六进制字符串输出。

**brute**: 同算法验证。

## 改编方向

1. **参数化 D**：将固定 D=16 改为输入参数。
2. **容斥原理**：标准的集合计数方法。
3. **PE 答案验证**：(D=16) 输出 3D58725572C62302。
