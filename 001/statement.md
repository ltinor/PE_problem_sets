# $3$ 或 $5$ 的倍数

## 题目描述

给定一个正整数 $n$，请计算所有小于 $n$ 的自然数中，
能够被 $3$ 或 $5$ 整除的数的和。

例如，小于 10 的自然数中：

$3$, $5$, $6$, $9$

它们的和为：

$23$

现在请计算小于 $n$ 的所有满足条件的数之和。

---

## 输入格式

输入一行，一个整数 n。

---

## 输出格式

输出一个整数。

表示所有小于 n 且能被 3 或 5 整除的数之和。

---

## 样例

### 输入
```
10
```
### 输出
```
23
```


---

## 数据范围

$n ≤ 10^{12}$
