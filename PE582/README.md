# PE582 — 几乎等腰120度三角形 (Nearly isosceles 120 degree triangles / Simplex)

来源：改编自 Project Euler Problem 582

## 原题意

记有一个角为 120 度的整数边长三角形的三边长为 a, b, c，满足 a ≤ b ≤ c 且 b-a ≤ 100。记 T(n) 为满足 c ≤ n 的上述三角形的数目。

已知：T(1000) = 235，T(10⁸) = 1245。
求 T(10¹⁰⁰)。

PE 答案：199029329684864。

## 算法

由余弦定理（120°）：c² = a² + b² - 2ab·cos(120°) = a² + ab + b²。

该方程可以通过爱森斯坦整数参数化。对于 gcd(m,n)=1 且 m≢n (mod 3)：
- a = d·(m² - n²)
- b = d·(2mn + n²)
- c = d·(m² + mn + n²)

约束 b-a ≤ 100 转化为关于 m,n 的二次型不等式，可以用佩尔方程的方法求解。

对于较小的 c（≤10⁶），可以使用暴力枚举。对于 c ≤ 10¹⁰⁰，需要使用参数化方法和渐近计数公式。

## 改编方向

1. 改变角度（如 60°、90°、150°），研究解的结构。
2. 改变约束条件（如 b-a ≤ k，研究 T(n) 随 k 的变化）。
3. 推广到三维或更高维的单纯形。
4. 研究 T(n) 的渐近增长率与 n 的关系。
