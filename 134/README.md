# 134 — Prime Pair Connection

来源：改编自 Project Euler Problem 134

## 原题意

对于 5 ≤ p₁ ≤ 10⁶ 的所有连续质数对 (p₁, p₂)，求最小的 S（末尾是 p₁ 且能被 p₂ 整除）之和。

原题答案：18613426663617118。

## 题目

参数化 M：输入 M (≤ 10⁶)，求 p₁ ≤ M 的所有连续质数对的 S 之和。

## 数据范围

- M ≤ 10⁶

## 算法

**std**: 对每对 (p₁, p₂)：S = p₁ + k · 10^len(p₁)，需 (p₁ + k · pow10) % p₂ = 0。解 k ≡ (-p₁) · inv(pow10, p₂) (mod p₂)。使用 __int128 避免溢出。

**brute**: 同上。

## 改编方向

1. **参数化 M**：将原题固定 M=10⁶ 改为输入参数。
2. **小范围版本**：M ≤ 10000 可用于对拍验证。
3. **固定答案验证**：M=10⁶ 作为测试点，输出 18613426663617118。
