# 质数对连接

## 题目描述

对于连续质数 p₁ 和 p₂ (p₂ > p₁)，定义 S 为最小的数满足：S 的末尾数字构成 p₁，且 S 能被 p₂ 整除。

给定整数 M，对于所有满足 5 ≤ p₁ ≤ M 的连续质数对，求 ∑ S。

---

## 输入格式

一行一个整数 M (5 ≤ M ≤ 10⁶)。

---

## 输出格式

一行一个整数，表示所有满足条件的 S 之和。

---

## 样例

### 输入

```
100
```

### 输出

```
488356
```

（p₁ < 100 的连续质数对的 S 之和）

---

## 数据范围

- 5 ≤ M ≤ 10⁶
