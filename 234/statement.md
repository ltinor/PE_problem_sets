# 半可除数

## 题目描述

对于一个整数 $n \ge 4$，我们定义：

- $\operatorname{lps}(n)$：不超过 $\sqrt{n}$ 的最大素数
- $\operatorname{ups}(n)$：不小于 $\sqrt{n}$ 的最小素数

例如，对于 $n = 15$，$\sqrt{15} \approx 3.87$：
- $\operatorname{lps}(15) = 3$（$\le 3.87$ 的最大素数）
- $\operatorname{ups}(15) = 5$（$\ge 3.87$ 的最小素数）

我们称一个整数 $n$ 为「半可除数」（semidivisible），如果它恰好被 $\operatorname{lps}(n)$ 和 $\operatorname{ups}(n)$ 中的一个整除（不能同时整除，也不能都不整除）。

例如：$n = 15$，$3 \mid 15$ 但 $5 \mid 15$，同时整除了两个，故 15 不是半可除数。

给定 $N$，求所有 $4 \le n \le N$ 中的半可除数之和。

---

## 输入格式

输入一行，一个整数 $N$（$4 \le N \le 10^{12}$）。

---

## 输出格式

输出一个整数，表示所有半可除数之和。

---

## 样例

### 输入
```
15
```

### 输出
```
0
```

（注：$n=15$ 不是半可除数；$n \in [4,14]$ 中可能没有/有少量半可除数。）

---

## 数据范围

$4 \le N \le 10^{12}$
