# 整数英文表达的字母计数

## 题目描述

把正整数写成英文单词（英式英语规则），不计空格和连字符，计算所用字母的总数。

数字英文写法规则（英式）：
- $1$ 到 $19$ 有各自对应的单词：one(3)、two(3)、three(5)、...、nineteen(8)。
- $20$ 到 $90$ 的整十数：twenty(6)、thirty(6)、forty(5)、fifty(5)、sixty(5)、seventy(7)、eighty(6)、ninety(6)。
- 对于 $21$ 到 $99$ 的非整十数，用"几十-几"的形式，如 twenty-one(6+3=9)，但字母计数时不包含连字符。
- 对于 $100$ 到 $999$：用"几百 and ..."的形式（百位和十位/个位之间必须有 and）。如 three hundred and forty-two：不含空格共 $23$ 个字母。

给定一个正整数 $n$，求将 $1$ 到 $n$ 的所有整数写成英文单词时，所用字母的总数。

---

## 输入格式

第一行一个整数 $T$，表示测试数据组数。

接下来 $T$ 行，每行一个整数 $n$。

---

## 输出格式

对于每组数据，输出一行一个整数表示字母总数。

---

## 样例

### 输入
```
3
5
342
1000
```

### 输出
```
19
6117
21124
```

**样例说明**：
- $n=5$：one(3)+two(3)+three(5)+four(4)+five(4)=19
- $n=342$：$1$ 到 $342$ 所有数字的字母总数
- $n=1000$：对应 Project Euler 原题答案

---

## 数据范围

- $1 \le T \le 10$
- $1 \le n \le 10^6$
