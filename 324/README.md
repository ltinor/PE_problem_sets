# 324 — Building a Tower

来源：改编自 Project Euler Problem 324

## 原题意

用 2×1×1 的砖块填充 3×3×n 的塔，砖块可以任意旋转。求方案数 f(n)。塔的旋转/翻转视为不同方案。

已知：f(2)=229, f(4)=117805, f(10) mod 100000007 = 96149360, f(10³) mod q = 24806056, f(10⁶) mod q = 30808124。
求 f(10^10000) mod 100000007。

答案：96972774。

## 题目

输入 n（可能非常大，以字符串形式给出），求 f(n) mod 100000007。

## 数据范围

- 1 ≤ n ≤ 10^10000

## 算法

1. **状压 DP + 矩阵快速幂**：将 3×3 横截面视为 9-bit 状态。状态表示从下层延伸上来的垂直砖块占用的格子。转移矩阵 M[S][T] = 在给定传入状态 S 和传出状态 T 下，用水平多米诺填充剩余格子的方案数。f(n) = Σ_j (M^n)[0][j]。
2. **线性递推**：矩阵特征多项式给出线性递推，用 Berlekamp-Massey + 快速线性递推处理大 n。
3. **周期检测**：模数 100000007 下矩阵幂存在周期，利用周期简化大指数。

## 改编方向

1. 原题固定 n=10^10000 → 参数化 n
2. 改变塔的尺寸（如 2×2×n 或 4×4×n）
3. 改变砖块尺寸（如 3×1×1 或 L 形）

选择方向 1：参数化 n，保留原题核心（状压 DP + 矩阵幂）。
