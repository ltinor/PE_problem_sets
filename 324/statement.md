# 建塔

## 题目描述

用 2×1×1 的砖块建造一座 3×3×n 的塔。砖块可以任意旋转（有 3 种朝向）。塔的旋转或翻转视作不同的建造方式。

记 f(n) 为建造一座 3×3×n 的塔的不同方案数。

例如：
- f(2) = 229
- f(4) = 117805
- f(10) mod 100000007 = 96149360
- f(1000) mod 100000007 = 24806056
- f(1000000) mod 100000007 = 30808124

给定 n，求 f(n) mod 100000007。

---

## 输入格式

一行一个整数 n（可能非常大）。

---

## 输出格式

一行一个整数，表示 f(n) mod 100000007。

---

## 样例

### 输入

```
2
```

### 输出

```
229
```

### 输入

```
4
```

### 输出

```
117805
```

### 输入

```
10
```

### 输出

```
96149360
```

### 输入

```
1000
```

### 输出

```
24806056
```

---

## 数据范围

- 1 ≤ n ≤ 10^10000
