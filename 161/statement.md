# 三联骨牌

## 题目描述

三联骨牌是由三个正方形方块拼接而成的骨牌，计入旋转后共有六种形状。给定一个 W×H 的网格（保证 W×H 可被 3 整除），求用这六种三联骨牌拼满整个网格的方案数。

注意：翻转或旋转后得到的拼法视为不同方案。

## 输入格式

一行两个整数 W H，表示网格的宽度和高度。

## 输出格式

一行一个整数，表示拼法总数。

---

## 样例

### 输入
```
2 3
```

### 输出
```
11
```

### 输入
```
2 9
```

### 输出
```
41
```

---

## 数据范围

- 2 ≤ W, H ≤ 12
- W×H 是 3 的倍数

---

## 提示

PE 原题 W=9, H=12 时答案为 20574308184277971。
