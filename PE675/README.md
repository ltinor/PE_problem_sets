# PE675 — 2^ω(n) (2的ω(n)次方)

来源：改编自 Project Euler Problem 675

## 原题意

定义 ω(n) 为 n 的不同素因子个数。令 f(n) = 2^ω(n)，即 n 的无平方因子约数（squarefree divisor）的个数。

问题要求计算与 f(n) = 2^ω(n) 相关的求和，如：
S(N) = Σ_{n=1}^{N} 2^ω(n)

或者更复杂的表达式，如加权和、前缀积等。

PE 答案：41653068862124600。

## 算法

1. **ω(n) 的筛法计算**：
   - 使用埃氏筛：对每个素数 p，将 p 的所有倍数的 ω 值加 1
   - 时间复杂度 O(N log log N)

2. **2^ω(n) 的计算**：
   - 由于 ω(n) 通常较小（log log n），2^ω(n) 可以用位移运算高效计算
   - 对于 n ≤ 10^7，ω(n) ≤ 8（2×3×5×7×11×13×17×19 = 9699690）

3. **前缀和**：
   - 直接累加所有 1 ≤ n ≤ N 的 2^ω(n) 值
   - 对于更大的 N，可以利用 2^ω(n) 的积性性质使用 Dirichlet 卷积加速

4. **积性函数性质**：
   - 2^ω(n) 是积性函数：若 gcd(a,b)=1，则 2^ω(ab) = 2^ω(a) × 2^ω(b)
   - 可以利用此性质进行快速计算
