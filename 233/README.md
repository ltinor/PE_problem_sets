# 233 — Lattice points on a circle

来源：改编自 Project Euler Problem 233

## 原题意

定义 $f(N)$ 为经过 $(0,0), (N,0), (0,N), (N,N)$ 四点的圆上的整点（格点）个数。求所有 $N \le 10^{11}$ 且 $f(N) = 420$ 的 $N$ 之和。
原题答案：271204031455541309。

## 题目

本题改编为：给定 $N$，计算 $f(N)$。

## 数据范围

$1 \le N \le 10^{12}$

## 算法

圆过四点 $\to$ 圆心 $(N/2, N/2)$，半径 $N/\sqrt{2}$。
整点条件：$(2x-N)^2 + (2y-N)^2 = 2N^2$。

令 $u = 2x-N, v = 2y-N$，则 $u^2 + v^2 = 2N^2$。所有解自动满足 $u, v$ 与 $N$ 同奇偶，因此一一对应格点 $(x,y)$。

$$f(N) = r_2(2N^2) = 4 \prod_{p \mid N, \; p \equiv 1 \pmod 4} (2e_p + 1)$$

其中 $e_p$ 是 $p$ 在 $N$ 中的指数。

对 $N$ 做质因数分解即可 $O(\sqrt{N})$ 求解。

**brute**: 枚举所有 $(x, y) \in [0, N]^2$ 并检验，适用于 $N \le 5000$。

## 改编方向

1. **改为求 $f(N)$**：原题是找满足 $f(N)=420$ 的 $N$（极难），改为求单个 $N$ 的 $f(N)$（中等）。
2. **参数化目标值**：给定 $N$ 和 $K$，判断是否 $f(N) = K$。
3. **保留原题**：可标注为压轴题，但 OJ 时限内极难完成。
