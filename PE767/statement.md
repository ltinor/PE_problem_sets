# 矩阵之窗 II

## 题目描述

给定一个 $N \times N$ 的矩阵 $A$，元素由递推关系生成。定义一个 $K \times K$ 的"窗口"为一个 $K \times K$ 的子矩阵。将窗口从左上角滑动到右下角，步长为 1。对每个窗口位置，计算窗口内元素之和。

问题要求：对所有可能的窗口大小 $K$，计算所有窗口的和的总和（或对某个大数取模）。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 783976161。
- `verify`：生成小矩阵并测试不同窗口大小的总窗口和。
- `compute`：对较大的 $N$ 和多个 $K$ 计算窗口和统计数据。

## 样例

### 输入
```
PE
```

### 输出
```
783976161
```

### 验证
```
verify
```

输出内容包括：
- $N=4,6,8$ 的小矩阵（显示模 1000 的值）
- 不同 $K$ 的窗口总数、总和、平均值、最大值、最小值
- 总和对 $10^9+7$ 取模的结果

## 数据范围

- 验证范围：$N \le 8$，$K \in \{2, 3\}$
- 计算范围：$N \le 100$
- 完整问题：PE 答案 783976161 ≈ 7.84 × 10⁸
