# 224 — Almost right-angled triangles II

来源：改编自 Project Euler Problem 224

## 原题意

求周长 ≤ 75,000,000 的"略微钝角"三角形（a² + b² = c² - 1, a ≤ b ≤ c）的个数。

## 题目

参数化 N：输入 N，求周长 ≤ N 的略微钝角三角形个数。

## 数据范围

$N \le 75\,000\,000$

## 算法

**std**: 利用 $(c-b)(c+b) = a^2+1$。枚举 $u = c-b$，对每个 $u$ 寻找满足 $a^2 \equiv -1 \pmod{u}$ 的 $a$ 值，计算 $v = (a^2+1)/u$，$b = (v-u)/2$，$c = (v+u)/2$。利用 $a+v \le N$ 限制 $a$ 的上界以优化效率。

时间复杂度：$O(\sqrt{N} \cdot T)$，其中 $T$ 为有效解的个数。

**brute**: 三重循环枚举 $a \le b \le c$，适用于 $N \le 5\,000$。

## 改编方向

1. **参数化 N**：将固定 N=75,000,000 改为输入参数。
2. **与 223 合并**：可同时统计略微锐角和略微钝角。
3. **参数化 offset**：$a^2+b^2=c^2+d$，参数化 $d$。
