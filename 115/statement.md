# 方格组合计数 II

## 题目描述

用长度为 1 的黑色方块和**最短长度为 M** 的红色方块摆成长度为 n 的一行，要求任意两个红色方块（长度可以不同）之间至少有一个黑色方块。

定义 F(M,n) 为符合要求的摆法数目。

给定 M 和 K，求使得 F(M,n) > K 的最小 n。

---

## 输入格式

一行两个整数 M K，空格分隔。

---

## 输出格式

一行一个整数 n。

---

## 样例

### 输入
```
3 1000000
```

### 输出
```
30
```

### 输入
```
10 1000000
```

### 输出
```
57
```

### 输入
```
50 1000000
```

### 输出
```
168
```

---

## 数据范围

- 2 ≤ M ≤ 50
- 1 ≤ K ≤ 10^6
