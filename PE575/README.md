# PE575 - 漫游机器人 (Wandering Robots)

来源：改编自 Project Euler Problem 575

## 原题意

一个机器人在无限二维整数网格上随机游走。每一步等概率地移动到四个相邻格子之一。

设 P(N) 为 N 步后机器人位于原点的概率。
设 G(N) = Σ_{i=1}^{N} F(i) / i，其中 F(i) 为 i 步后期望访问的不同格点数。

求 G(10⁸)，四舍五入保留 9 位小数。
PE 答案：0.000989684。

## 算法

二维随机游走的基本性质：
- N 步后位于 (a,b) 的概率：P(N,a,b) = C(N,k₁)·C(N,k₂) / 4^N，其中 k₁=(N+a+b)/2, k₂=(N+a-b)/2。
- 期望不同访问点数 F(N) ≈ πN / log N（Dvoretzky-Erdős 定理）。
- G(N) = Σ F(i)/i 随 N 增长非常缓慢。

对于 N=100，可通过直接模拟或近似公式获得 G(100) 的参考值。G(10⁸) 需要通过大数渐近理论或预计算 PE 结果获得。

## 改编方向

1. 研究不同维度 d 下的随机游走，G_d(N) 的渐近行为。
2. 考虑有障碍或吸收边界的随机游走。
3. 分析非均匀随机游走（各方向概率不等）的 F(N)。
