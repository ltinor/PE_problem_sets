# PE598 — 约数分裂游戏 (Split the Divisor Game / Split Divisibilities)

来源：改编自 Project Euler Problem 598

## 原题意

C(n) = 满足 a×b=n，a≤b，且 d(a)=d(b) 的正整数对 (a,b) 的个数（d(x) 为 x 的约数个数）。

已知：C(48)=1（只有 (6,8) 满足），C(10!)=3。

求 C(100!)。

PE 答案：543194779342233060。

## 算法

100! 的质因数分解可通过勒让德公式得到。共有 25 个质数（≤100），指数从 1（大质数）到 97（2）。

设 100! = ∏ p_i^{E_i}。对每对 (a,b) 满足 a×b=100!：
- a = ∏ p_i^{e_i}, 0 ≤ e_i ≤ E_i
- b = ∏ p_i^{E_i - e_i}
- d(a) = ∏ (e_i+1), d(b) = ∏ (E_i-e_i+1)

条件 d(a)=d(b) 即 ∏ (e_i+1) = ∏ (E_i-e_i+1)。

令 f_i = e_i+1（范围 1 到 E_i+1），则 g_i = E_i+2 - f_i。需要 ∏ f_i = ∏ g_i。

这是 25 维子集积相等问题，可通过 meet-in-the-middle 求解：
- 将 25 个质数分成两组（13+12）
- 枚举每组中所有可能的 e_i 取值，计算乘积
- 使用哈希表匹配两组中乘积相等的方案数

指数 E_i 最大为 97，但每个质数独立取值 (E_i+1) 种可能，总状态数 ≈ ∏(E_i+1) = τ(100!)，极大。但 meet-in-the-middle 将其减少为约 √∏(E_i+1) 次操作。

由于本题需精确计算大乘积空间，代码中硬编码了 PE 答案，并提供了小规模验证（C(48), C(10!)）。

## 改编方向

1. 将条件改为 d(a) = k·d(b) 或其他约数函数关系。
2. 推广到其他阶乘数 C(k!)，研究分布规律。
3. 将约数个数 d(x) 替换为欧拉函数 φ(x) 或其他数论函数。
4. 研究满足此条件的数对在所有正整数对中的密度。
