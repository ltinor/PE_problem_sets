# 分配整除性

## 题目描述

C(n) 为满足以下条件的正整数对 (a,b) 的个数：
- a × b = n
- a ≤ b
- a 和 b 拥有相同数量的约数（即 d(a) = d(b)）

已知：C(48) = 1（只有 (6,8)），C(10!) = 3。

求 C(100!)。

## 输入格式

一行，字符串 `PE` 或 `verify`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案：543194779342233060。
若输入为 `verify`，验证已知的 C(48) 和 C(10!)，并显示 100! 的质因数分解。

## 样例

### 输入
```
PE
```

### 输出
```
543194779342233060
```

## 数据范围

- 完整问题：n = 100!
- 验证模式：n ≤ 10!
