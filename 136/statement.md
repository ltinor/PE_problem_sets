# 单一差

## 题目描述

给定正整数 x, y, z 构成等差数列。定义方程 x² − y² − z² = n。

给定整数 M，求 n < M 中恰好有 1 个不同的 (x, y, z) 等差数列解的 n 的个数。

---

## 输入格式

一行一个整数 M (10 ≤ M ≤ 5×10⁷)。

---

## 输出格式

一行一个整数，表示满足条件的 n 的个数。

---

## 样例

### 输入

```
100
```

### 输出

```
10
```

（n < 100 中恰有 1 个解的 n：3, 4, 7, 8, 11, 16, 19, 23, 32, 67）

---

## 数据范围

- 10 ≤ M ≤ 5×10⁷
