# PE748 — Upside down Diophantine equation（颠倒丢番图方程）

来源：改编自 Project Euler Problem 748

## 原题意

考虑"颠倒数字"——当数字在计算器显示屏上被颠倒阅读时，某些数字会变成其他数字：
- 0→0, 1→1, 2→2, 5→5, 6→9, 8→8, 9→6
- 3、4、7 颠倒后无效

定义"可颠倒数"为所有数位都属于 {0,1,2,5,6,8,9} 的数。一个可颠倒数 $n$ 的"颠倒值" $f(n)$ 是将 $n$ 的数位反转后逐位应用上述变换得到的数。

问题要求解某个涉及可颠倒数的丢番图方程，例如求所有满足 $n^2 + f(n)^2 = m^2$ 的 $n$ 之和，或其他涉及颠倒数的方程。

PE 答案：276402862。

## 算法

1. **数位翻转映射**：建立 0→0, 1→1, 2→2, 5→5, 6→9, 8→8, 9→6 的映射表。
2. **可颠倒数验证**：检查数的每一位是否在合法集合中。
3. **颠倒值计算**：$O(\log n)$ 时间内计算数字的颠倒值。
4. **丢番图方程求解**：对候选数枚举验证是否满足方程约束。
5. **优化**：利用可颠倒数的计数公式（$k$ 位可颠倒数有 $6 \times 7^{k-1}$ 个）缩小搜索空间。

## 改编方向

1. 推广到其他进制
2. 多步颠倒（连续颠倒多次）
3. 颠倒后保持某种性质（如素数、平方数）
4. 其他类型的丢番图方程约束
5. 容许 3、4、7 的替代映射
