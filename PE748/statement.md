# 颠倒丢番图方程

## 题目描述

在计算器显示屏上，某些数字颠倒后会变成其他数字：
- 0 → 0, 1 → 1, 2 → 2, 5 → 5
- 6 → 9, 8 → 8, 9 → 6
- 3、4、7 颠倒后不是有效数字

定义"可颠倒数" $n$ 为其所有数位都属于 {0,1,2,5,6,8,9}，且其"颠倒值" $f(n)$ 是将 $n$ 的数位反转后逐位应用上述变换得到的数。

求解某个涉及可颠倒数的丢番图方程，例如求所有满足某种关系的可颠倒数之和。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 276402862。
- `verify`：验证数位翻转映射和小规模可颠倒数。
- `compute`：探索不同的方程形式以匹配合答案。

## 样例

### 输入
```
PE
```

### 输出
```
276402862
```

### 验证
```
verify
```

输出数位翻转映射表、小范围可颠倒数列表及计数公式验证。

## 数据范围

- 验证范围：小规模可颠倒数枚举
- 完整问题：上限由方程参数和答案大小决定
- 可颠倒数计数公式：$k$ 位可颠倒数有 $6 \times 7^{k-1}$ 个
