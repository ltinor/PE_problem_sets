# PE412 - 圭表填数

来源：改编自 Project Euler Problem 412

## 原题意

L(m,n) 是 m×m 网格挖去右上角 n×n 后的 L 形，求将 1..(m²-n²) 填入使每格小于其下方和左侧格子的方案数 LC(m,n)。原题求 LC(10000, 5000) mod 76543217，答案为 38788800。

## 题目

给定 m, n，求 LC(m, n) mod 76543217。

## 算法

- 该问题等价于求标准 Young 表（SYT）的数量，形状为 L 形 Young 图
- 使用钩长公式（hook-length formula）：f^λ = N! / ∏ h(c)，其中 h(c) 为格子 c 的钩长
- 对于 L 形，钩长有闭合形式：每列的钩长可逐列计算
- 取模运算使用 GCD 约分法处理除法

## 改编方向

1. **改变形状**：使用更复杂的挖空形状，如挖去多个矩形
2. **改变约束方向**：要求数字从上到下递增、从左到右递增（标准 Young 表方向）
3. **改变模数**：使用不同的模数或要求精确值
4. **计数扩展**：求特定编号位置（如最小值在某个格子的方案数）
