# 圭表填数

## 题目描述

对于整数 m, n（0 ≤ n < m），L(m, n) 表示一个 m×m 的方格被挖去了右上角 n×n 的方格后留下的 L 型部分。

我们给 L(m, n) 的每一格填上连续整数 1, 2, 3, ...，并要求每个格子中的数要小于它左侧和下方格子中的数（即数字从左到右递减，从上到下递减）。

记 LC(m, n) 是 L(m, n) 所有可行填法的数目。可以验证 LC(3, 0) = 42，LC(5, 3) = 250250。

给定 m 和 n，求 LC(m, n) mod 76543217。

---

## 输入格式

两个整数 m 和 n，空格分隔。

---

## 输出格式

一个整数，表示 LC(m, n) mod 76543217。

---

## 样例

### 输入
```
3 0
```

### 输出
```
42
```

### 输入
```
5 3
```

### 输出
```
250250
```

### 输入
```
6 3
```

### 输出
```
43800432
```

---

## 数据范围

- 对于 30% 数据：m ≤ 5
- 对于 60% 数据：m ≤ 50
- 对于 100% 数据：m ≤ 10000
