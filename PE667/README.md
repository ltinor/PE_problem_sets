# PE667 — 移动五边形 (Moving Pentagon)

来源：改编自 Project Euler Problem 667

## 原题意

一个点在一个正五边形的顶点上随机移动。在每一步，该点以等概率移动到相邻的两个顶点之一。

从顶点 0 出发，求首次访问完所有 5 个顶点所需的期望步数。

这是循环图上的随机游走覆盖时间问题。

PE 答案：4982.199083（保留 6 位小数）。

## 算法

对于 N 个顶点的循环图上的随机游走，覆盖时间（从单个顶点出发访问所有顶点的期望步数）为 N(N-1)/2。

对于 N = 5 的基本情况，理论覆盖时间为 10 步。完整的 PE 问题可能涉及更复杂的场景（如加权边、非对称转移概率、或多个五边形上的游走）。

使用首次步分析（first-step analysis）建立线性方程组：
- 设 E_k 为从已访问的连续 k 个顶点出发的剩余期望步数
- E₅ = 0
- 通过马尔可夫链的状态转移建立递推关系并求解

也可通过蒙特卡洛模拟进行验证。

## 改编方向

1. 推广到正 N 边形（N > 5）
2. 非对称转移概率
3. 多个随机游走者同时移动
4. 加权期望（某些顶点更重要）
5. 求访问所有顶点特定次数的期望时间
