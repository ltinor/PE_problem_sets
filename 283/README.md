# Integer Triangles with Integral Area-Perimeter Ratio

来源：改编自 Project Euler Problem 283

## 原题意

求所有面积周长比为不超过 1000 的正整数的整数边三角形的周长之和。PE 答案：28038042525570324。

## 题目

给定 R，求所有满足面积/周长 = k（1 ≤ k ≤ R）的整数边三角形的周长之和。

## 数据范围

- 1 ≤ R ≤ 1000
- PE 答案: R=1000 → 28038042525570324

## 改编思路

### 方向一：参数化 R
将固定 1000 改为可变输入 R。✅ 采用

### 方向二：输出三角形而非周长和
要求输出具体的三角形三边长。数据量过大，不实用。❌ 不采用

### 方向三：求满足条件的三角形个数
计数而非周长和。与原题等价，只是输出形式不同。❌ 不采用

## 算法

利用内切圆半径 r = 2k，设 x=s-a, y=s-b, z=s-c，解得 xyz = 4k²(x+y+z)。枚举 x ≤ y，检查 z 是否为整数。使用 __int128 防溢出。
