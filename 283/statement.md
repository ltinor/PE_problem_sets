# 整数比三角形

## 题目描述

对于一个三边长均为整数的三角形，记其面积为 A，周长为 P。

若面积与周长之比 A/P 为正整数 k，则称该三角形为 k-三角形。

给定 R，求所有满足 1 ≤ k ≤ R 的 k-三角形的周长之和。

---

## 输入格式

一行，一个整数 R（1 ≤ R ≤ 1000）。

---

## 输出格式

一个整数，表示所有满足条件的三角形的周长之和。

---

## 样例

### 输入
```
2
```

### 输出
```
162
```

（k=1: 三角形(6,8,10)，周长24；k=2: (13,14,15)等，周长和138）

---

## 数据范围

- 1 ≤ R ≤ 1000
- PE 答案: R = 1000 → 28038042525570324
