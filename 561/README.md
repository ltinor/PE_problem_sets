# 561 - 约数对 (Divisor Pairs)

来源：改编自 Project Euler Problem 561

## 原题意

记 S(n) 为 n 的不同约数组成的约数对 (a,b) 的数目，其中 a 整除 b。
记 p_m# 是前 m 个素数的乘积。记 E(m,n) 为使得 2^k 整除 S((p_m#)^n) 的最大整数 k。
记 Q(n) = Σ_{i=1}^n E(904961, i)。
已知 Q(8)=2714886，求 Q(10^12)。

PE 答案：45248099998823554。

## 题目

给定 N，求 Q(N) = Σ_{i=1}^N E(904961, i)。

## 数据范围

- 1 ≤ N ≤ 10^12

## 算法

**公式推导**：

对于 n = ∏ p_i^{e_i}，有 S(n) = ∏ (e_i+1)(e_i+2)/2 - ∏ (e_i+1)。

对于 (p_m#)^n，所有 e_i = n，故：
S = ((n+1)(n+2)/2)^m - (n+1)^m

记 A = (n+1)(n+2)/2, B = n+1, m = 904961 (奇数)。

使用 2-进赋值分析（LTE 引理）：

- n ≡ 0 (mod 4): A,B 均为奇数 → E = v_2(A-B) = v_2(n) - 1
- n ≡ 3 (mod 4): v_2(A) < v_2(B) → E = m · (v_2(n+1) - 1)
- n ≡ 1,2 (mod 4): E = 0

令 k = n/4 (n≡0) 或 k = (n+1)/4 - 1 (n≡3)：
- n = 4k (k≥1): E = v_2(k) + 1
- n = 4k+3 (k≥0): E = m · (v_2(k+1) + 1)

因此：
Q(N) = (m+1) · (⌊N/4⌋ + S(⌊N/4⌋))

其中 S(x) = Σ_{i≥1} ⌊x/2^i⌋ = x - popcount(x)。

时间复杂度 O(log N)。

## 改编方向

1. **不同 m 值**：更换 m，研究不同的 primorial 指数。
2. **其他素数 p**：求 v_p(S((p_m#)^n)) 而非 v_2。
3. **约数对计数通式**：直接求 S(n) 的质因数分解。
4. **区间求和**：求 Q(L,R) = Σ_{i=L}^R E(m,i)。
