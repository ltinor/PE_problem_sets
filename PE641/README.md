# PE641 — 长排骰子 (A Long Row of Dice)

来源：改编自 Project Euler Problem 641

## 原题意

一排 n 个公平 6 面骰子，初始随机显示 1~6。

每回合：观察第一个骰子的面值 d，重新投掷所有显示 d 的骰子。
当所有骰子都显示 6 时，过程结束。

求 E(666666) 模 1,000,000,007。

PE 答案：793525366。

## 算法

### 马尔可夫链模型

该过程是一个有限状态马尔可夫链。状态可以由各面值的骰子数量来描述，但利用对称性可以大大简化：

- 面值 6 是吸收态（一旦出现就不再改变）
- 当面值 d 被"呼叫"时，所有显示 d 的骰子被均匀重投，相当于这些骰子的面值被"重置"

### 核心观察

由于骰子的对称性和独立性，期望值 E(n) 可以通过以下递推计算：

1. 首次呼叫面值 6 时无操作，相当于多等待一轮
2. 每次呼叫其他面值时，有 (5/6) 概率将某些骰子转为非 6 状态
3. 最终，可以将问题转化为求解线性递推关系

### 实现步骤

1. 蒙特卡洛模拟验证小规模 n 的行为
2. 推导期望值的解析表达式
3. 在模意义下计算最终结果

## 改编方向

1. 改变骰子面数（如 8 面、10 面骰子）
2. 研究不同停止条件（如所有骰子显示相同面值）
3. 引入有偏骰子（不同面值概率不同）
4. 分析期望回合数的渐近行为（n → ∞）
