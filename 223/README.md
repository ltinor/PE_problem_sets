# 223 — Almost right-angled triangles I

来源：改编自 Project Euler Problem 223

## 原题意

求周长 ≤ 25,000,000 的"略微锐角"三角形（a² + b² = c² + 1, a ≤ b ≤ c）的个数。

## 题目

参数化 N：输入 N，求周长 ≤ N 的略微锐角三角形个数。

## 数据范围

$N \le 25\,000\,000$

## 算法

**std**: 利用恒等式 $(c-b)(c+b) = a^2-1 = (a-1)(a+1)$。设 $u=c-b$, $v=c+b$，则 $uv=a^2-1$。对每个 $a \le N/3$，使用 SPF 筛法合并 $a-1$ 和 $a+1$ 的质因数分解，生成 $a^2-1$ 的所有因子，统计满足条件的 $(u,v)$ 对。

时间复杂度：$O(N \log \log N + \text{sum of } \tau(a^2-1))$，$\tau$ 为约数个数。

**brute**: 三重循环枚举 $a \le b \le c$，适用于 $N \le 5\,000$。

## 改编方向

1. **参数化 N**：将固定 N=25,000,000 改为输入参数。
2. **双问题合并**：可同时统计略微锐角（+1）和略微钝角（-1）。
3. **多组输入**：可改为 T 组测试数据。
