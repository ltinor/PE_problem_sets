# 纵横交错

## 题目描述

一个 4×4 方阵填满了 0 ≤ d ≤ 9 的数字。在如下方阵中：

```
6 3 3 0
5 0 4 3
0 7 1 4
1 2 4 5
```

每一行和每一列的和都是 12，而且对角线上的数字和也都是 12。

求在 4×4 方阵中填入 0-9 的数字，使得每一行、每一列和对角线上的和都是相同数的不同填法总数。

## 输入格式

一行一个整数（占位符，恒为 1）。

## 输出格式

一行一个整数，表示总方案数。

---

## 样例

### 输入
```
1
```

### 输出
```
7130034
```

---

## 数据范围

- 输入恒为 1

---

## 提示

PE 原题答案为 7130034。
