# PE876 — Sum of Digits, Sequence of Numbers（数字和数列）

来源：改编自 Project Euler Problem 876

## 原题意

从一个数开始，定义序列的下一项由前一项的各位数字和计算得出。题目要求计算与数字和相关的序列的和或统计量。

给定起始数与递推规则，求序列在一定范围内的各项数字和之和。

PE 答案：316086996128331296。

## 算法

1. **数字和计算**：对整数 n，digit_sum(n) = Σ n_i，其中 n_i 是 n 的十进制各位数字。
2. **序列生成**：根据递推规则 a_{k+1} = a_k + (digit_sum(a_k))^2 等方式生成序列。
3. **数字和求和**：使用数位 DP（digit DP）计算 1 到 N 范围内所有数字的数字和之和。
   - 对每一位位置，计算该位上各数字（0-9）的出现次数，加权求和。
   - 复杂度：O(log N) 即 O(位数)。
4. **大范围求和**：当 N 很大时（如 10^k 量级），使用公式快速计算。
5. **递推序列分析**：研究序列的周期性、收敛性等性质。

## 改编方向

1. 改变递推规则（如用数字乘积替代数字和）
2. 推广到其他进制（二进制、十六进制等）
3. 研究序列的渐近行为和极限
4. 考虑多位数字操作（如数字的平方和 → 快乐数问题）
5. 与自守数、Kaprekar 常数等经典数字游戏结合
