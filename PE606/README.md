# PE606 — 整除链II (Gozinta Chains II)

来源：改编自 Project Euler Problem 606

## 原题意

n 的**因子链**（gozinta chain）是一个序列 {1, a, b, ..., n}，其中每个元素都整除后一个元素。

S(n) = 所有不超过 n 且恰好有 252 条不同因子链的整数 k 的和。

已知：S(10⁶) = 8462952，S(10¹²) = 623291998881978。

求 S(10³⁶)，给出最后九位数字。

PE 答案：158452642。

## 算法

因子链的数量 g(n) 仅取决于 n 的素因子指数向量 (e₁, ..., eₖ)：

- 递推：g(0,...,0) = 1，g(e) = Σ_{a≠0, a≤e} g(e - a)
- 单素数：g(pᵉ) = 2ᵉ⁻¹
- 生成函数：F(x) = 1 / (2 - ∏ 1/(1-xᵢ))

需要 g(n) = 252 = 2² × 3² × 7。通过枚举指数配置（最多约 6 个不同素数），找出所有满足条件的指数向量，再在 ≤ 10³⁶ 内分配素数生成合法数字，求和取后 9 位。

## 改编方向

1. 研究不同目标值（如 252 改成其他数）的 S(N) 行为。
2. 分析 g(n) 在素数因子数不同的情况下的渐近公式。
3. 推广到含多个限制条件（如同时要求因子链数为特定值的数字的和）。
4. 计算 g(n) 的模意义下的分布规律。
