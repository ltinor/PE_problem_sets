```
├── docs/reports/           审计报告与算法分析笔记

```

## 使用

```bash
# 编译
g++ -std=c++17 -O2 001/code/std.cpp -o std

# 运行 (输入格式见题面)
echo "PE" | ./std     # 输出原题官方答案
echo "参数" | ./std   # 参数化计算

# 验证
./std < 001/data/01.in   # 应输出 001/data/01.out 内容
```
