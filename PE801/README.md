# PE801 — Equable Matrices（公正矩阵）

来源：改编自 Project Euler Problem 801

## 原题意

定义一个 n×n 矩阵为"公正矩阵"（Equable Matrix），如果矩阵的每个元素取自 {1, 2, ..., n}，且所有行和与所有列和都相等（即存在一个公共值 S，使得每一行之和 = 每一列之和 = S）。令 f(n) 表示所有满足条件的 n×n 公正矩阵的数量。求 f(M) 的值（M 为某特定值）。

PE 答案：7937995。

## 算法

1. **线性丢番图方程**：每行和 = 每列和 = S，总计 n×S = 所有元素之和。
2. **生成函数方法**：使用容斥原理或生成函数计数满足行列约束的矩阵数量。
3. **小规模暴力枚举**：n ≤ 3 时可以直接枚举所有可能矩阵并验证。
4. **组合数学**：对于更大规模，使用 contingency table 计数理论，涉及 Birkhoff 多面体和整数流计数。

## 改编方向

1. 推广到不同取值范围的矩阵元素
2. 增加对角线约束（幻方变体）
3. 允许不同行/列有不同的固定和值
4. 扩展到三维张量（矩阵立方体）
5. 计数矩阵模某个数的同余类
