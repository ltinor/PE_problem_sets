# 平方和与和平方之差

## 题目描述

前十个正整数的平方和是

$$1^2+2^2+\ldots +10^2=385$$

前十个正整数的和平方是

$$(1+2+\ldots+10)^2 = 55^2 = 3025$$

因此，前十个正整数的平方和与和平方之差是$3025 − 385 = 2640$。

求前$K$个正整数的平方和与和平方之差。

---

## 输入格式

第一行一个整数 $T$ $(1 \le T \le 10^5)$，表示测试用例组数。
接下来的 $T$ 行，每行一个整数 $K$ $(1 \le K \le 10^5)$。

---

## 输出格式

对每个测试用例输出一行，表示平方和与和平方之差。


---

## 样例

### 输入
```
1
10
```
### 输出
```
2640
```
---

## 数据范围

K
