# PE398 - 割绳子

来源：改编自 Project Euler Problem 398

## 原题意

长 n 的绳子上随机选 m-1 个等距点切割，求第二短段的期望长度 E(n,m)。求 E(10^7, 100)。

## 题目

给定 n, m，求 E(n,m)。组合数学与期望计算。

## 算法

- 等价于在 [0,n] 上均匀随机撒 m-1 个点
- 顺序统计量的联合分布
- 第二小的间距期望可通过积分计算

## 改编方向

1. **第 k 短段**：改为求第 k 短的期望长度
2. **最长段**：求最长段的期望长度
3. **非均匀切割**：切点概率与位置有关
4. **环形绳子**：绳子首尾相连（圆环切割）
