# 割绳子

## 题目描述

有一条长为 n 的绳子，上面分布有间距为 1 的 n-1 个点。从中随机均匀选择 m-1 个点切开，得到 m 段绳子。

记 E(n, m) 为第二短的分段长度的期望值。若有多段同时为最短，则第二短长度等于最短长度。

给定 n 和 m，求 E(n, m)，保留 5 位小数。

---

## 输入格式

两个整数 n, m。

---

## 输出格式

一个浮点数，四舍五入到小数点后 5 位。

---

## 样例

### 输入
```
3 2
```

### 输出
```
2.00000
```

### 输入
```
8 3
```

### 输出
```
2.28571
```

---

## 数据范围

- 对于 30% 数据：n ≤ 20, m ≤ 5
- 对于 60% 数据：n ≤ 10^4, m ≤ 10
- 对于 100% 数据：n ≤ 10^7, m ≤ 100
