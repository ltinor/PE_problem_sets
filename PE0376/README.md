# 非传递性骰子集合

来源：改编自 Project Euler Problem 376

## 原题意

三枚六面骰子，点数 1~N。求"非传递性"骰子集合（A<B<C<A）的数量。PE 答案：973059630185670 (N=30)。

## 题目

给定 N（六面骰子最大点数），求非传递性骰子集合数。

## 数据范围

N ≤ 30

## 算法

### 方向一：枚举 + 剪枝

每个骰子可用多重集表示（6 个排序点数）。枚举 A 的所有可能，对每个 A 枚举 B（满足 P(A>B)>0.5 但 B 非传递于 A），再枚举 C。

### 方向二：DP + 组合计数

将骰子编码为 6 元组的非降序列。用 DP 生成所有可能的骰子，然后三重循环检查非传递性条件。

### 方向三：概率快速比较

两枚骰子 X vs Y 的获胜概率 = Σ_{i=1}^6 Σ_{j=1}^6 [X_i > Y_j] / 36。预计算所有骰子对的获胜概率矩阵，O(K³) 检查三元组。

### 时间复杂度

骰子总数 K ≈ C(N+5, 6)，N=30 时 K ≈ 1.6×10^6。需进一步优化。
