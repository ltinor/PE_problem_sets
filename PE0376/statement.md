# 非传递性骰子集合

## 题目描述

三枚六面骰子，点数 1~N。

定义"非传递性"：无论先手选哪枚骰子，后手都能选另一枚使胜率 > 50%。

例如：A: 1 4 4 4 4 4, B: 2 2 2 5 5 5, C: 3 3 3 3 3 6。
P(B胜A)=7/12, P(C胜B)=7/12, P(A胜C)=25/36。

集合 {A,B,C}、{B,C,A}、{C,A,B} 视为相同。

给定 N，求非传递性骰子集合的数量。

---

## 输入格式

一个整数 N。

---

## 输出格式

一个整数，非传递性骰子集合数。

---

## 样例

### 输入
```
7
```

### 输出
```
9780
```

---

## 数据范围

1 ≤ N ≤ 30
