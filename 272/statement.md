# 立方取模 II

## 题目描述

对于正整数 n，定义 C(n) 为满足以下条件的整数 x 的个数：
- 1 < x < n
- x³ ≡ 1 (mod n)

给定 N 和 K，求所有 n ≤ N 且 C(n) = K 的 n 的和。

例如，n = 91 时 C(91) = 8。

---

## 输入格式

一行两个整数 N K，空格分隔。

---

## 输出格式

一行一个整数，表示满足条件的 n 的和。

---

## 样例

### 输入

```
91 8
```

### 输出

```
91
```

（因为 n ≤ 91 中只有 n = 91 满足 C(n) = 8）

---

## 数据范围

- N ≤ 10¹¹
- K ≥ 0
