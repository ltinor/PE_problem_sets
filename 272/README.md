# 272 — 立方取模 II

来源：改编自 Project Euler Problem 272

## 原题意

对于正整数 n，定义 C(n) 为满足 1 < x < n 且 x³ ≡ 1 (mod n) 的整数 x 的个数。

求所有满足 C(n) = 242 的正整数 n ≤ 10¹¹ 的和。

原题答案：8495585919506151122。

## 题目

参数化 N 和 K：输入 N 和 K，求所有 n ≤ N 且 C(n) = K 的 n 的和。

## 数据范围

- N ≤ 10¹¹, K ≥ 0

## 算法

**std**: C(n) = ∏ c(p^e) − 1，其中 c(p^e) = 3（p ≡ 1 mod 3 或 p = 3, e ≥ 2）否则 c = 1。C(n) = K 即 ∏ c = K+1 = 3^t。DFS 枚举所有满足条件的质因数组合。

**brute**: 直接枚举 n ≤ N，对每个 n 枚举 x 检查 x³ ≡ 1 (mod n)。

## 改编方向

1. **参数化 N, K**：将原题固定的 N = 10¹¹, K = 242 改为输入参数。
2. **小数据对拍**：N ≤ 1000 可用暴力验证。
3. **固定答案验证**：(N = 10¹¹, K = 242) 作为测试点，输出 8495585919506151122。
