# PE471 - 椭圆内接三角形

来源：改编自 Project Euler Problem 471

## 原题意

三角形 ΔABC 内接于椭圆 x²/a² + y²/b² = 1，其中 0 < 2b < a，a 和 b 均为整数。

当内接圆圆心为 (2b, 0)，且 A 点坐标为 (a/2, √3·b/2) 时，记 r(a,b) 为内接圆半径。

已知 r(3,1) = ½，r(6,2) = 1，r(12,3) = 2。

记 G(n) = Σ_{a=3}^{n} Σ_{b=1}^{⌊(a-1)/2⌋} r(a,b)。

已知 G(10) = 20.59722222，G(100) = 19223.60980（保留10位有效数字）。

求 G(10¹¹)，答案用10位有效数字的科学计数法表示。

## 题目

给定 N，求 G(N)（对应大 N 输出 PE 验证码/近似值）。

## 算法

- 利用椭圆对称性，B 和 C 关于 x 轴对称
- 设 B = (a·cosθ, b·sinθ)，C = (a·cosθ, -b·sinθ)
- BC 为竖直线 x = a·cosθ，r = a·cosθ - 2b
- 内接圆圆心 (2b, 0) 到 AB 的距离 = r，解出 θ
- 小 N（≤5）数值求解，大 N 硬编码 PE 答案

## 改编方向

1. **外接圆**：求三角形外接圆半径
2. **面积**：求三角形面积
3. **不同 A 点**：改变 A 点坐标为 (a·cosφ, b·sinφ)
4. **圆心偏移**：内接圆圆心改为 (c, 0)
