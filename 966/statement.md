# 三角形与圆的交集

## 题目描述

记 $I(a,b,c)$ 为边长 $a,b,c$ 的三角形与一个**面积与之相等**的圆之间的最大交集面积
（圆可以放在平面上的任意位置）。

例如 $I(3,4,5)\approx 4.593049$，$I(3,4,6)\approx 3.552564$。

本题（简单版）给定一个三角形的三边长，请计算 $I(a,b,c)$。

---

## 输入格式

一行三个整数 $a,b,c$，表示三角形的三边长。

---

## 输出格式

一个实数，表示 $I(a,b,c)$，四舍五入保留 6 位小数。

---

## 样例

### 输入

```
3 4 5
```

### 输出

```
4.593049
```

### 输入

```
3 4 6
```

### 输出

```
3.552564
```

---

## 数据范围

- $1\le a\le b\le c<a+b$，保证构成合法三角形。
