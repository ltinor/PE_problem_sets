# 幂的数字和

## 题目描述

古戈尔（$10^{100}$）是一个巨大的数字：1 后面跟着 100 个零。$100^{100}$ 更惊人：1 后面 200 个零。但它们的各位数字和只有 $1$。

对于给定的整数 $A$ 和 $B$，考虑所有形如 $a^b$ 的自然数，其中 $1 \leq a < A$，$1 \leq b < B$。求这些数中最大的各位数字之和。

---

## 输入格式

一行两个整数 $A$ 和 $B$，以空格分隔。

---

## 输出格式

输出一个整数，表示最大的各位数字和。

---

## 样例

### 输入
```
10 10
```

### 输出
```
45
```

---

## 数据范围

- $2 \leq A \leq 100$
- $2 \leq B \leq 100$
- 注意：$a^b$ 可能非常大（最多约 200 位），需要使用大整数运算
