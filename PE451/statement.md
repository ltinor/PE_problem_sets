# 模逆元和

## 题目描述

对于正整数 n，记 I(n) 为满足以下条件的最大正整数 m：
- m < n - 1
- m 在模 n 下的逆元等于自身（即 m² ≡ 1 (mod n)）

例如：
- I(15) = 11（因为 11² = 121 ≡ 1 (mod 15)，且 11 < 14）
- I(100) = 51
- I(7) = 1（只有平凡解 1 和 6，但 6 = 7-1 被排除）

求 Σ_{n=3}^{N} I(n)。

---

## 输入格式

一个整数 N (3 ≤ N ≤ 10^7)。

---

## 输出格式

一个整数，表示 Σ_{n=3}^{N} I(n)。

---

## 样例

### 输入
```
100
```

### 输出
```
1634
```

---

## 数据范围

- 对于 30% 数据：N ≤ 1000
- 对于 60% 数据：N ≤ 10^5
- 对于 100% 数据：N ≤ 10^7
