# PE693 — Finite sequences generator (有限序列生成器)

来源：改编自 Project Euler Problem 693

## 原题意

定义一个有限序列生成器，从正整数 $x$ 开始：
- 如果 $x=1$，序列终止。
- 如果 $x$ 为偶数，下一项为 $x/2$。
- 如果 $x$ 为奇数，下一项可以是 $\lfloor x/2 \rfloor$ 或 $3x+1$（两种选择）。

生成器产生所有可能通过上述选择得到的有限序列。
定义 $M(n)$ 为从 $n$ 出发可以生成的不同有限序列的数量。
求 $\sum_{n=1}^{N} M(n)$ 对某模数的值（或 $N=1000$ 时的值）。

PE 答案：699161。

## 算法

1. **递归/DP**：$M(1) = 1$。对于 $n > 1$：
   - 若 $n$ 为偶数：$M(n) = M(n/2)$
   - 若 $n$ 为奇数：$M(n) = M(\lfloor n/2 \rfloor) + M(3n+1)$
   使用记忆化搜索避免重复计算。

2. **Collatz 相关**：该问题与 Collatz 猜想密切相关。序列在 Collatz 猜想成立的前提下总是有限的
   （因为无论哪种选择都最终会到达 $1$）。

3. **复杂度**：对于 $n \le 1000$，绝大多数 $n$ 的 Collatz 路径较短，
   记忆化搜索可以在可接受的时间内完成。

## 改编方向

1. 参数化 $N$ 的上限
2. 增加可选的转移函数（如 $5x+1$ 等）
3. 求最长/最短序列的长度
4. 统计经过特定数值的序列数
5. 考虑模数下的序列数量
