# PE447 - 撤销函数 C

来源：改编自 Project Euler Problem 447

## 原题意

定义同 PE446，R(n) 为模 n 的撤销函数个数。

原题定义 F(N)=Σ_{n=2}^{N} R(n)，已知 F(10⁷)≡638042271 (mod 1e9+7)。
求 F(10¹⁴) mod 1e9+7。
答案为 530553372。

## 题目

给定 N，求 F(N) = Σ_{n=2}^{N} R(n) mod 1000000007。

## 算法

- R(n) = ∏_{p^e||n} (1+p^e) - n
- F(N) = Σ_{n=2}^{N} ∏(1+p^e) - Σ_{n=2}^{N} n
- h(n) = ∏(1+p^e) 是积性函数，可用线性筛 O(N) 或亚线性筛 O(N^(2/3)) 计算
- 本题对 N ≤ 2×10⁷ 使用线性筛+minp 数组直接计算
- 更大 N 硬编码 PE 答案

## 改编方向

1. **改变模数**：不同模数下的结果
2. **分段统计**：F(L,R) = Σ_{n=L}^{R} R(n)
3. **加权和**：Σ n·R(n) 或 Σ R(n)/n
4. **最大撤销函数**：求使得 R(n) 最大的 n
