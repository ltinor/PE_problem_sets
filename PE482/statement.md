# 三角形的内心

## 题目描述

对于边长均为整数的三角形，其内心 $I$ 的重心坐标为 $(a : b : c)$，其中 $a, b, c$ 为三角形的三边长。

考虑所有满足周长 $\le N$ 的整数边三角形（忽略退化情形）。对于每个三角形，计算内心相关的某个量，求所有三角形该量之和。

---

## 输入格式

一个整数 $N$。

---

## 输出格式

一个整数，表示所求之和。

---

## 样例

### 输入
```
5
```

### 输出
```
...
```

---

## 数据范围

- 对于 30% 数据：$N \le 10$
- 对于 60% 数据：$N \le 100$
- 对于 100% 数据：$N \le 1000$
