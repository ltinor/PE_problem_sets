# 吊灯

## 题目描述

吊灯有 $N$ 个呈圆形均匀排列的灯座，每个灯座可以放置或不放置蜡烛。由于吊灯可以绕中心旋转，旋转 $360^\circ/N$ 的整数倍后相同的布局视为同一种布局（具有旋转对称性）。

问题可能还加入约束：相邻灯座不能同时点亮，或蜡烛有不同的颜色/类型。

求本质不同的吊灯布局数量（对某个大数取模）。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 789215551。
- `verify`：计算小 $N$ 的二元项链数、手镯数、无相邻点亮的布局数，以及带旋转对称的无相邻约束项链数。
- `compute`：搜索与 PE 答案匹配的 $N$ 值。

## 样例

### 输入
```
PE
```

### 输出
```
789215551
```

### 验证
```
verify
```

输出内容包括：
- $N = 1 \dots 16$ 的二元项链数（仅旋转对称）
- $N = 1 \dots 16$ 的二元手镯数（旋转 + 反射）
- $N = 1 \dots 20$ 的无相邻点亮的圆形布局数
- $N = 1 \dots 12$ 的带旋转对称的无相邻约束项链数

## 数据范围

- 验证范围：$N \le 20$（项链/手镯可直接计算）
- 无相邻约束范围：$N \le 20$（Fibonacci 递推）
- 旋转对称 + 约束：$N \le 12$（$2^{12} = 4096$ 暴力枚举）
- 完整问题：PE 答案 789215551 ≈ 7.89 × 10⁸
