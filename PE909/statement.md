# $L$-表达式（一）（$L$-expressions I）

## 题目描述

$L$-表达式可以是以下任意一种：自然数、符号 $A$、符号 $Z$、符号 $S$、或一对 $L$-表达式 $u, v$（记作 $u(v)$）。

$L$-表达式可以按以下规则转换：
- $A(x) \to x + 1$（对任意自然数 $x$）
- $Z(u)(v) \to v$（对任意 $L$-表达式 $u, v$）
- $S(u)(v)(w) \to v(u(v)(w))$（对任意 $L$-表达式 $u, v, w$）

例如：$S(Z)(A)(0) \to A(Z(A)(0)) \to A(0) \to 1$。
$S(S)(S(S))(S(Z))(A)(0) \to 6$。

求 $S(S)(S(S))(S(S))(S(Z))(A)(0)$ 的结果，并给出最后九位数字。

## 输入格式

无输入（固定参数问题）。

## 输出格式

输出一个整数，表示结果的最后九位数字。

## 样例

（无样例输入输出，直接计算并输出最终答案。）
