# 数长方形

## 题目描述

在一个 $m \times n$（$m$ 行 $n$ 列）的矩形网格中，可以找出许多不同大小的长方形。例如，一个 $3 \times 2$ 的网格中恰好包含 $18$ 个长方形。

一般地，$m \times n$ 的网格中包含的长方形总数为：

$$\frac{m(m+1) \cdot n(n+1)}{4}$$

现在给定一个目标数值 $T$，请你找出一对正整数 $m, n$，使得 $m \times n$ 网格中的长方形总数与 $T$ 的差的绝对值最小。输出该网格的面积 $m \times n$。如果有多个答案，输出面积最小的那个。

---

## 输入格式

一行一个整数 $T$，表示目标长方形数量。

---

## 输出格式

一行一个整数，表示最接近 $T$ 的网格面积 $m \times n$。

---

## 样例

### 输入
```
2000000
```

### 输出
```
2772
```

**解释**：$36 \times 77 = 2772$ 的网格中包含 $36 \times 37 \times 77 \times 78 / 4 = 1999998$ 个长方形，与 $2000000$ 的差仅为 $2$，是所有网格中最接近的。

---

## 数据范围

$1 \le T \le 10^7$
