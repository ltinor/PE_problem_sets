# PE544 - 彩色谜题 (Chromatic Conundrum)

来源：改编自 Project Euler Problem 544

## 原题意

用至多 n 种颜色填充 r×c 网格，相邻格（上下左右）颜色不同，对角线相邻不算。记总填色方案数为 F(r,c,n)。

例如 F(2,2,3)=18，F(2,2,20)=130340，F(3,4,6)=102923670。

令 S(r,c,n) = Σ_{k=1}^n F(r,c,k)。已知 S(4,4,15) mod 10^9+7 = 325951319。

求 S(9,10,1112131415) mod 10^9+7。

PE 答案：640432376。

## 题目

给定 r, c, n，求 S(r,c,n) = Σ_{k=1}^n F(r,c,k) mod (10^9+7)。

## 算法

- F(r,c,n) 是 r×c 网格图的色多项式（次数 r×c）。
- S(r,c,n) 是 n 的 r×c+1 次多项式。只需求出 k=0..r×c 时的 F 值，再插值求 S。
- **关键方法：列模式的传递矩阵**
  - 一列的染色模式是该列 r 个格子的颜色等价类划分（集合划分）。
  - Bell 数 B_9 = 21147：枚举 r=9 的所有列模式。
  - 对每个模式 P（含 b 个块），用 n 种颜色实现的方案数为下降阶乘 (n)_b。
  - 相邻两列模式 P→Q 的转移数：在满足"同行不同色"约束下为联合划分分配颜色的方案数。
  - 通过容斥原理计算转移矩阵，复杂度与 Bell 数平方成正比。
- 由于 r=9, c=10 固定，可预计算转移矩阵，对 k=0..90 分别求 F(9,10,k)，再累加得 S(k) 在插值点上的值。
- 最终用拉格朗日插值或牛顿前向差分求 S(9,10,1112131415) mod M。

## 改编方向

1. **不同网格**：改变 r, c 大小或形状（如三角网格、六边形网格）。
2. **额外约束**：某些格子固定颜色、某些颜色必须/不能使用。
3. **计数变体**：求恰好使用 n 种颜色（而非至多 n 种）的方案数。
4. **带权计数**：每种颜色有不同的"权重"，求带权和。
