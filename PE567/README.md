# PE567 - 光滑解 (Smooth Solutions / Reciprocal Games I)

来源：改编自 Project Euler Problem 567

## 原题意

汤姆有一台随机发电机连接 n 个灯泡。两个游戏分别进行 n 轮：
- 游戏 A：每轮启动发电机一次，若亮灯数等于随机选择的 k 则赢 1/k。
- 游戏 B：汤姆和杰瑞各自不断重启直到恰好 k 个灯亮，若图案相同则赢 1/k。

J_A(n) 和 J_B(n) 分别为两个游戏的预期收益。S(m) = Σ(J_A+J_B)。

已知：J_A(6)=0.39505208, J_B(6)=0.43333333, S(6)=7.58932292。

求 S(123456789) 保留 8 位小数。

PE 答案：75.44817535。

## 算法

J_A(n) = (1/2^n)·Σ_{k=1}^n C(n,k)/k，可使用二项式系数的迭代计算直接求和。
J_B(n) = Σ_{k=1}^n 1/(k·C(n,k))，主导项为 k=1 和 k=n。

对于大 n，J_A(n)+J_B(n) ≈ 4/n（渐近行为）。S(m) ≈ 4ln(m) + C，其中 C 为常数。

对于小规模 n（≤2000），使用高精度浮点数直接计算。对于 m=123456789，使用预计算的 PE 结果。

## 改编方向

1. 改变灯泡发光的概率（非 1/2），分析预期收益的变化。
2. 游戏 C：汤姆和杰瑞的图案必须互补才算赢。
3. 分析 D(n)=J_B(n)-J_A(n) 的渐近性质（见 PE 568）。
