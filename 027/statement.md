# 素数生成二次多项式

## 题目描述

对于二次多项式 $n^2 + an + b$（$n$ 从 $0$ 开始），给定界限 $A$ 和 $B$（$|a| < A$，$|b| \le B$），求一对 $(a,b)$ 使得该多项式连续生成素数的个数最多，输出 $a \times b$ 的值。

欧拉曾发现 $n^2 + n + 41$ 能连续生成 40 个素数，而 $n^2 - 79n + 1601$ 能连续生成 80 个素数。

---

## 输入格式

第一行一个整数 $T$，表示测试数据组数。  
接下来 $T$ 行，每行两个整数 $A, B$，用空格分隔。

---

## 输出格式

对于每组数据，输出一行一个整数，表示 $a \times b$ 的值。

---

## 样例

### 输入
```
1
42 42
```

### 输出
```
-41
```

**解释**：$|a|<42$，$|b|\le42$ 时，最优解为 $a=-1, b=41$，多项式 $n^2 - n + 41$ 能连续生成 41 个素数（$n=0$ 到 $n=40$）。乘积为 $-1 \times 41 = -41$。

---

## 数据范围

- $1 \le T \le 10$
- $2 \le A, B \le 1000$
