# 平方空间谷仓

## 题目描述

农夫弗雷德有一个半径为 R 的圆柱形谷仓。谷物从顶部某点落下，形成圆锥形堆，静止角为 α（谷物自然堆积的坡角）。

当落点偏离中心 x 米时，浪费的空间为 V(x) 立方米。求所有使得 V(x) 为完全平方数的 x 值之和 Σx（保留 9 位小数）。

已知当 R=3, α=30° 时，x=1.114785284 处 V≈36，x=2.511167869 处 V≈49。

---

## 输入格式

第一行：模式标识（"pe" 表示原题参数，"test1" 表示测试样例，"small" 后跟 R 和 α）

---

## 输出格式

一个浮点数，保留 9 位小数，表示 Σx。

---

## 样例

### 输入
```
test1
```

### 输出
```
3.625953153
```

### 输入
```
pe
```

### 输出
```
1994892.422700000
```

---

## 数据范围

- 对于 30% 数据：R ≤ 3
- 对于 60% 数据：R ≤ 5
- 对于 100% 数据：R ≤ 6, 20° ≤ α ≤ 50°
