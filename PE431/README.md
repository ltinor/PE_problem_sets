# PE431 - 平方空间谷仓

来源：改编自 Project Euler Problem 431

## 原题意

半径为 R 的圆柱形谷仓，谷物从顶部某点落下形成圆锥形堆，静止角为 α。当落点偏离中心 x 米时，浪费的空间（谷仓容积减去谷物堆体积）为 V(x)。求所有使得 V(x) 为完全平方数的 x 值之和。

原题：R=6m, α=40°，求 Σx（9 位小数），答案为 1994892.4227。

## 题目

给定半径 R 和角度 α，求所有使浪费空间为完全平方数的 x 值之和 Σx。

## 算法

- 计算圆锥与圆柱的交集体积（数值积分或解析法）
- 浪费空间 = πR²H - 谷物体积
- 搜索 x ∈ (0, R) 区间，找到使 V(x) 为完全平方数的 x
- 原题中结果 Σx 约 1994892.4227

## 改编方向

1. **不同形状**：方底谷仓或椭圆柱
2. **多落点**：多个谷物落点叠加
3. **变角度**：静止角随位置变化
4. **优化问题**：最大化/最小化浪费空间
