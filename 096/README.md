# 数独

来源：改编自 Project Euler Problem 96

## 原题意

求解 50 个数独谜题，将每个谜题解答左上角三位数求和。答案：24702。

## 题目

输入 $N$（数独谜题个数），随后 $N$ 个 $9 \times 9$ 的网格（每行一个不含空格的字符串，$0$ 表示空格）。求解每个数独谜题，将每个谜题解答中左上角三位数（第 $1$ 行第 $1\sim 3$ 列）求和并输出。

## 数据范围

$1 \le N \le 50$。每个谜题保证有唯一解。

## 算法

使用回溯法（DFS）求解数独。采用位掩码优化：
- `row_mask[i]`：第 $i$ 行已使用的数字的位掩码；
- `col_mask[j]`：第 $j$ 列已使用的数字的位掩码；
- `box_mask[r/3][c/3]`：所在 $3\times 3$ 九宫格已使用的数字的位掩码。

每次选择候选数最少的空格进行填充（MRV 启发式），显著减少搜索空间。
