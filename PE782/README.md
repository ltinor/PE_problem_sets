# PE782 — Distinct Rows and Columns（不同行列）

来源：改编自 Project Euler Problem 782

## 原题意

考虑一个 $m \times n$ 的 01 矩阵，要求所有行互不相同且所有列也互不相同。问题可能要求计算满足条件的矩阵个数，或对某些 $(m, n)$ 求某种和。

PE 答案：325499120（约 $3.25 \times 10^8$）。

## 算法

1. **组合上限**：行互不相同要求 $m \le 2^n$，列互不相同要求 $n \le 2^m$。
2. **上界估计**：只考虑行约束时，从 $2^n$ 种可能行中选 $m$ 个排列，共 $P(2^n, m)$ 种。
3. **同时满足行列约束**涉及集合系统和组合设计（combinatorial designs）。
4. **暴力枚举**：对极小矩阵（$mn \le 16$）可直接枚举所有 $2^{mn}$ 种可能。
5. **对称矩阵特例**：$m=n$ 时矩阵是一个对称设计。

## 改编方向

1. 推广到非二进制（$k$ 进制）矩阵
2. 添加行列和的约束（如每行/列恰好有 $r$ 个 1）
3. 限定矩阵的某种代数性质（如满秩等）
4. 计算所有满足条件的矩阵的某种特征值之和
5. 与拉丁方（Latin square）和正交阵列（orthogonal array）建立联系
