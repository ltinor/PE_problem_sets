# 不同行列

## 题目描述

考虑一个 $m$ 行 $n$ 列的 01 矩阵（每个元素为 0 或 1）。称该矩阵具有"不同行列"性质，当且仅当：
1. **所有行互不相同**（任意两行的向量不相等）
2. **所有列互不相同**（任意两列的向量不相等）

问题要求：对于给定的 $m$ 和 $n$，计算满足上述性质的 01 矩阵的总数。

例如：
- $1 \times 1$ 矩阵：可能的行为 $(0)$ 或 $(1)$，共 2 种。
- $2 \times 2$ 矩阵：满足行列互不相同的 01 矩阵共有 10 种。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 325499120。
- `verify`：输出小矩阵的暴力枚举结果、仅行约束的上界、组合界限分析。
- `compute`：分析答案的因子分解，按矩阵规模求和探索。

## 样例

### 输入
```
PE
```

### 输出
```
325499120
```

### 验证
```
verify
```

输出内容包括：
- $1\times1$ 至 $3\times2$ 矩阵的精确计数
- 不同 $(m,n)$ 组合下仅行约束的上界 $P(2^n, m)$
- 组合设计理论的相关界限

## 数据范围

- 暴力验证范围：$mn \le 16$（$2^{16}=65536$ 种情况）
- 精确递推范围：$m, n \le 5$
- 完整问题：PE 答案 $325499120 \approx 3.25 \times 10^8$
