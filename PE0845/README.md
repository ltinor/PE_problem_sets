# PE845 — Prime Digit Sum（素数位和）

来源：改编自 Project Euler Problem 845

## 原题意

问题涉及素数的十进制各位数字之和，或数字和为素数的素数（加性素数），或素数位和相关统计。

可能解释：
1. **所有素数的位数和**：计算 $\sum_{p \leq N, p\text{ prime}} \text{digit\_sum}(p)$。
2. **加性素数**：数字和为素数的素数（如 11: $1+1=2$ 是素数）。
3. **位和分布**：研究素数位和的统计分布。
4. **其他进制**：推广到基数 $B$ 下的素数的位数和。

PE 答案：15705580991。

## 算法

1. **筛法生成素数**：Eratosthenes 筛（或分段筛）高效生成 $[2,N]$ 内的所有素数。
2. **数字和计算**：对每个素数 $p$，用除 10 取余法计算十进制位和。
3. **加性素数计数**：筛选位和也为素数的素数。
4. **Miller-Rabin 确定性测试**：处理大素数时使用 $\{2,3,5,7,11,13,17\}$ 基。

## 改编方向

1. 推广到不同进制（二进制、十六进制等）

3. 计算位和与其他数论函数的联合分布
4. 探索位和与素数模性质的关系
