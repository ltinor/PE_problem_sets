# PE528 - 约束切分

来源：改编自 Project Euler Problem 528

## 原题意

记 S(n,k,b) 为满足 x₁ + x₂ + ... + xₖ ≤ n 且 0 ≤ xₘ ≤ bᵐ（1 ≤ m ≤ k）的解的个数。

已知：S(14,3,2) = 135，S(200,5,3) = 12949440，S(1000,10,5) mod 10⁹+7 = 624839075。

求 (∑_{10≤k≤15} S(10ᵏ, k, k)) mod 10⁹+7。

PE 答案：779027988。

## 题目

给定 n, k, b，计算 S(n,k,b) mod 10⁹+7。

## 算法

- 使用生成函数方法：S(n,k,b) = [xⁿ] ∏(1−x^{bⁱ⁺¹}) / (1−x)^{k+1}。
- 通过容斥原理展开分子：S(n,k,b) = Σ_{S⊆[k]} (−1)^{|S|} C(n − Σ_{i∈S}(bⁱ+1) + k, k)。
- 由于 k ≤ 15，枚举全部 2ᵏ 种子集即可。
- 组合数 C(N, k) 对 N 很大（~10¹⁵）但 k 很小（≤15）时直接用公式 O(k) 计算。
- 对于 bⁱ+1 > n+k 的子集，贡献为 0，可剪枝跳过。

## 改编方向

1. **严格等式**：将 ≤ n 改为 = n。
2. **下界约束**：增加 xₘ ≥ Lₘ 的条件。
3. **非线性上界**：将 bᵐ 改为其他函数如 m! 或 Fibonacci。
4. **多变量乘积约束**：增加 x₁x₂... 的限制。
