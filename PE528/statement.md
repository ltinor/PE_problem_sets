# 约束切分

## 题目描述

不等式 x₁ + x₂ + ... + xₖ ≤ n 的解中，满足 0 ≤ xₘ ≤ bᵐ（1 ≤ m ≤ k）的解的数目记为 S(n,k,b)。

已知：
- S(14, 3, 2) = 135
- S(200, 5, 3) = 12949440
- S(1000, 10, 5) mod 1000000007 = 624839075

给定 n, k, b，求 S(n,k,b) mod 1000000007。

## 输入格式

一行，三个整数 n、k、b，以空格分隔；或字符串 `PE`。

## 输出格式

一个整数，表示 S(n,k,b) mod 1000000007。

## 样例

### 输入
```
14 3 2
```

### 输出
```
135
```

### 输入
```
200 5 3
```

### 输出
```
12949440
```

## 数据范围

- 对于 30% 数据：n ≤ 100, k ≤ 5
- 对于 60% 数据：n ≤ 10⁵, k ≤ 8
- 对于 100% 数据：n ≤ 10¹⁵, k ≤ 15, b ≤ 15
