# 约数和

## 题目描述

定义 D(m,n) = Σ_{d|m} Σ_{k=1}^{n} σ₀(kd)，其中 d 取遍 m 的所有因数，σ₀(n) 是 n 的因数数目。

已知 D(3!, 10²) = 3398，D(4!, 10⁶) = 268882292。

求 D(200!, 10¹²) mod (10⁹ + 7)。

## 输入格式

一行，字符串 `PE` 或 `verify`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案：439689828。
若输入为 `verify`，验证 D(3!, 10²) = 3398 并显示已知值。

## 样例

### 输入
```
PE
```

### 输出
```
439689828
```

## 数据范围

- 完整问题：m = 200!, n = 10¹²
- 验证模式：m = 3!, n = 10²（精确验证），m = 4!, n = 10⁶（展示已知值）
