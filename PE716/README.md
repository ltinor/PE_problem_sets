# PE716 — Grid Graphs (网格图)

来源：改编自 Project Euler Problem 716

## 原题意

对于正整数 n，考虑由 (n+1)×(n+1) 个格点（整点 (i, j), 0 ≤ i, j ≤ n）组成的网格图。
相邻的格点之间有一条边（水平或垂直方向）。

定义：一个顶点 v 被称为"哈密顿起点"（Hamiltonian start vertex），如果存在一条从 v 出发、
恰好访问每个顶点一次（即哈密顿路）的路径。

令 T(n) 为该网格图中哈密顿起点的数量。求特定范围内的 T(n) 值或总和。

PE 答案：23817519。

## 算法

1. **图论分析**：n×n 网格图的顶点数为 (n+1)²。当顶点数为奇数时（n 为偶数），
   由于网格图是二分图且两部分大小不等，不存在哈密顿路，此时 T(n) = 0。

2. **对称性利用**：网格图具有多种对称性（旋转、反射），可以减少枚举量。

3. **回溯搜索**：对于较小的 n，可以使用深度优先搜索（DFS）+ 回溯来判断
   某个顶点是否可以作为哈密顿路的起点。

4. **转移矩阵 / DP**：对于较大的 n，需要使用基于轮廓线（frontier）的动态规划
   或转移矩阵方法来系统地计数哈密顿路。

5. **复杂度**：对于 n ≤ 5 可以直接回溯；更大的 n 需要更高效的算法。

## 改编方向

1. 参数化 n 的范围
2. 改为统计哈密顿圈（Hamiltonian cycle）的数量
3. 改为三维网格或六边形网格
4. 统计以某顶点为起点的最短哈密顿路数量
5. 考虑带权网格图中的最短哈密顿路
