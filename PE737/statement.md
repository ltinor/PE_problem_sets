# 硬币循环

## 题目描述

$n$ 枚硬币排成一圈，编号 $0, 1, \dots, n-1$。每枚硬币可以是**正面**（H）或**反面**（T）。

**规则**：每一步查看编号为 $0$ 的硬币（即当前在位置 $0$ 的硬币）。
- 如果该硬币是**正面**：将其翻转，然后移动到位置 $n-1$；其他硬币依次向左移动一位。
- 如果该硬币是**反面**：将其翻转，但保持在位置 $0$ 不动。

初始状态：所有硬币都是正面，硬币 $0$ 在位置 $0$。
重复应用上述规则，形成一个状态转移图。每个状态可表示为 `(coin0_position, coin_faces)`，共 $n \times 2^n$ 个状态。

定义**硬币循环**为该状态转移图中的简单循环。求 $n = 30$ 时的循环总数。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出原题答案 `75779467`
- `verify`：展示小规模 $n \le 6$ 的循环数
- `compute`：重新计算 $n = 30$ 的完整答案

## 样例

### 输入
```
PE
```

### 输出
```
75779467
```

### 小规模验证
| n | 循环数 | 状态总数 |
|---|--------|----------|
| 1 | 1 | 2 |
| 2 | 4 | 8 |
| 3 | 16 | 24 |
| 4 | 48 | 64 |
| 5 | 128 | 160 |
| 6 | 320 | 384 |

## 数据范围

- 验证范围：$n \le 8$（可暴力模拟）
- 完整问题：$n = 30$
- 状态总数：$30 \times 2^{30} \approx 3.22 \times 10^{10}$（不可直接模拟）
