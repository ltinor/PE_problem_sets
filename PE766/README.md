# PE766 — Sliding Block Puzzle（滑块拼图）

来源：改编自 Project Euler Problem 766

## 原题意

在一个 $n \times n$ 的棋盘上，某些格子中有 $1 \times 1$ 的方块。一个方块可以沿东南西北四个方向之一滑动。滑动时，方块沿直线移动，直到碰到另一个方块或棋盘边缘才停止。

给定一个初始方块布局，考虑状态图：顶点是通过单次滑动可达的布局，边对应一次合法滑动。

问题要求计算从某个特定初始布局出发的最短路径距离之和，或在有限步数内可达的布局总数。

PE 答案：26137442150。

## 算法

1. **状态编码**：用位掩码（bitmask）编码 $n \times n$ 的棋盘状态，每个格子用 1 bit 表示是否有方块。
2. **BFS / 最短路**：在状态图上进行广度优先搜索，计算从初始状态到所有可达状态的最短距离。
3. **滑动模拟**：对每个方块和每个方向，模拟滑动直到停止。复杂度 $O(k \cdot n)$，其中 $k$ 为方块数。
4. **组合公式**：对所有状态的距离求和（或根据对称性推导闭式公式）。
5. **复杂度**：状态空间高达 $2^{n^2}$，适用 $n \le 4$ 时暴力 BFS。

## 改编方向

1. 推广到不同形状的方块（$1 \times 2$ 多米诺骨牌等）
2. 允许方块在滑动中推动其他方块
3. 三维棋盘推广
4. 目标状态不唯一，求任意目标状态的最短路径
5. 加入重力效应（方块向下掉落）
