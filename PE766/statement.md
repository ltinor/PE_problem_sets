# 滑块拼图

## 题目描述

在一个 $n \times n$ 的棋盘上放置若干个 $1 \times 1$ 的方块。每次操作：选择一个方块，沿上下左右某个方向滑动。方块沿直线移动直到碰到其他方块或棋盘边缘。

从初始布局出发，定义状态图（顶点为可达布局，边为一次滑动）。求从初始布局到所有可达布局的最短距离之和。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 26137442150。
- `verify`：在 $n \le 3$ 的小棋盘上 BFS 计算所有布局的可达性和距离分布。
- `compute`：扩展到 $n \le 4$，分析状态空间的增长规律。

## 样例

### 输入
```
PE
```

### 输出
```
26137442150
```

### 验证
```
verify
```

输出内容包括：
- 单个方块的可达距离分布
- 两个方块不同布局的可达状态数
- 所有可能的布局总数（$2^{n^2}$）

## 数据范围

- 验证范围：$n \le 3$（最多 512 种状态，可完全 BFS）
- 计算范围：$n \le 4$（最多 65536 种状态）
- 完整问题：PE 答案 26137442150 ≈ 2.61 × 10¹⁰
