# 素数数字替换

## 题目描述

给定整数 $K$（$1 \le K \le 9$），求最小的素数 $p$，使得存在一个非空的位置集合（所有位置上的原始数字必须相同），将这些位置替换为相同的数字，恰能得到 $K$ 个素数。

例如，$K=6$ 时，最小的素数是 $13$（将 `*3` 的第一位替换，得到 $13, 23, 43, 53, 73, 83$ 共六个素数）。

$K=7$ 时，最小的素数是 $56003$（将 `56**3` 中两个 `0` 替换，得到 $56003, 56113, 56333, 56443, 56663, 56773, 56993$ 共七个素数）。

---

## 输入格式

一行一个整数 $K$。

---

## 输出格式

一行一个整数，表示满足条件的最小素数。

---

## 样例

### 输入

```
6
```

### 输出

```
13
```

### 输入

```
8
```

### 输出

```
121313
```

---

## 数据范围

- $1 \le K \le 9$
