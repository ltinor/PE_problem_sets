# 素数数字替换 (Prime Digit Replacements)

来源：改编自 Project Euler Problem 51

## 原题意

将两位数 `*3` 的第一位数字替换为任意数字，在九个可能值中有六个是素数。将五位数 `56**3` 的第三和第四位数字替换为相同的任意数字，得到了七个素数。求最小的素数，通过将部分数字（不一定相邻）替换为相同的任意数字，能够得到八个素数。

## 题目

给定整数 $K$（$1 \le K \le 9$），求最小的素数 $p$，使得存在一个非空的位置集合（所有位置上的原始数字必须相同），将这些位置替换为相同的数字 $d$（$0 \le d \le 9$），恰能得到 $K$ 个素数。

注意：如果替换的位置包含首位（最高位），则 $d=0$ 的情况不计入（因为会产生前导零）。

## 数据范围

- $1 \le K \le 9$

## 算法

- **std**: 使用筛法预计算素数表（上限 $5 \times 10^6$），枚举素数并枚举替换模式（位掩码），检查替换结果中素数的个数。若预计算素数表中未找到答案，则继续向上搜索。
- **brute**: 从 $2$ 开始逐个检查素数（使用试除法判断素性），其他逻辑与 std 相同。
