# 伪素数Nim（Pseudoprime Nimbers）

## 题目描述

在组合博弈论中，一个游戏局面的 **Nim 值**（Grundy 数）决定了在该局面下先手是否必胜。对于自然数 $n$，定义以下游戏：玩家可以选择 $n$ 的一个真因子 $d$（$1 < d < n$），将 $n$ 替换为 $d$。无法操作者输。

一个合数 $n$ 如果其 Nim 值等于某个素数在同游戏中的 Nim 值，则称 $n$ 为**伪素数 Nimber**。

求不超过 $N$ 的所有伪素数 Nimber 的总和。

## 输入格式

无输入（固定参数问题）。

## 输出格式

输出一个整数，表示伪素数 Nimber 的总和。

（无样例输入输出，直接计算并输出最终答案。）
