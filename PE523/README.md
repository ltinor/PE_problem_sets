# PE523 - 首位排序 I

来源：改编自 Project Euler Problem 523

## 原题意

算法：从左到右扫描相邻对。若逆序，将较小元移至首位并重新开始。
F(L) = 排序数列 L 所需的移至首位次数。
E(n) = 所有 n! 个排列的 F(P) 期望值。
E(4)=3.25，E(10)=115.725。
求 E(30)，四舍五入保留两位小数。

PE 答案：37125450.44。

## 题目

给定 n，计算 E(n)，保留两位小数。

## 算法

- 模拟算法：用 while 循环扫描，遇到逆序交换并计数。
- 小 n（≤ 10）可直接枚举所有排列求平均。
- 大 n 使用数学推导：E(n) 与排列的逆序数和左到右最小值有关。
- 复杂度：小 n 为 O(n!·n²)，大 n 为 O(1) 查表。

## 改编方向

1. **改变算法**：移至末尾、交换相邻、冒泡等。
2. **非均匀分布**：带权排列。
3. **特定排列**：求最大/最小 F(P) 或特定 k 的排列数。
4. **多维排列**：矩阵或序列的排序算法。
