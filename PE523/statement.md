# 首位排序 I

## 题目描述

考虑如下排序算法：

1. 从数列起始位置开始，逐一比较相邻两数。
2. 若相邻两数顺序有误（左边大于右边），将较小的数移至数列首位，回到第 1 步。
3. 若所有相邻对均已有序，算法结束。

例如，对数列 {4, 1, 3, 2}，移至首位共执行 5 次：
4 1 3 2 → 1 4 3 2 → 3 1 4 2 → 1 3 4 2 → 2 1 3 4 → 1 2 3 4。

记 F(L) 为数列 L 排序过程中"移至首位"的执行次数。

对于 {1, 2, ..., n} 的所有排列 P，记 E(n) 为 F(P) 的期望值（即平均值）。

已知 E(4) = 3.25，E(10) = 115.725。

给定 n，求 E(n)，四舍五入保留两位小数。

## 输入格式

一行，一个整数 n，或字符串 `PE`。

## 输出格式

一个浮点数，保留两位小数，表示 E(n)。

## 样例

### 输入
```
4
```

### 输出
```
3.25
```

### 输入
```
10
```

### 输出
```
115.73
```

## 数据范围

- 对于 30% 数据：n ≤ 8
- 对于 60% 数据：n ≤ 10
- 对于 100% 数据：n ≤ 30
