# 最小分数期望值

## 题目描述

记 $\{x\}$ 为实数 $x$ 的小数部分（$0 \le \{x\} < 1$）。

定义 $f_N(x)$ 为所有满足 $0 < n \le N$ 的整数 $n$ 中 $\{n x\}$ 的**最小**值，
$F(N)$ 为当 $x$ 在 $[0,1]$ 上均匀随机选取时 $f_N(x)$ 的期望值。

已知 $F(1)=\frac12$，$F(4)=\frac14$，$F(10)\approx 0.1319444444444$。

给定整数 $N$，求 $F(N)$，四舍五入到小数点后 13 位。

---

## 输入格式

一行一个整数 $N$。

---

## 输出格式

一行一个实数，表示 $F(N)$，四舍五入到小数点后 13 位。

---

## 样例

### 输入

```
10
```

### 输出

```
0.1319444444444
```

---

## 数据范围

- $1 \le N \le 10^4$
