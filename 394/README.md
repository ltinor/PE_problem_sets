# PE394 - 吃馅饼

来源：改编自 Project Euler Problem 394

## 原题意

随机切馅饼过程，每次吃掉随机两片。求期望步骤数 E(x)（F=1/x 时）。求 E(40)。

## 题目

给定 x（F=1/x），求期望执行次数。连续随机过程的期望计算。

## 算法

- 建立关于剩余比例的微分方程
- E(y) = 期望从比例 y 开始还需的步骤数
- E(y) = 0 for y < F; for y ≥ F, E(y) = 1 + E[E(y - max(U1,U2)*y)]

## 改编方向

1. **改变切法**：选 k 个点（而非 2 个），求期望
2. **改变吃法**：吃第 k 片而非前两片
3. **离散版本**：馅饼按角度等分，每次随机选
4. **最小化期望**：选择最优切法使期望步骤最小化
