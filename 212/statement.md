# 立方体组合体积

## 题目描述

一个与轴平行的立方体可以用参数 { (x₀, y₀, z₀), (dx, dy, dz) } 表示，包含所有满足 x₀ ≤ X ≤ x₀+dx, y₀ ≤ Y ≤ y₀+dy, z₀ ≤ Z ≤ z₀+dz 的点。一系列立方体的组合体积是它们并的体积。

给定 K，使用以下延迟斐波那契生成器生成前 K 个立方体的参数：

对于 1 ≤ k ≤ 55: Sₖ = [100003 − 200003k + 300007k³] (mod 1000000)
对于 56 ≤ k: Sₖ = [Sₖ₋₂₄ + Sₖ₋₅₅] (mod 1000000)

第 n 个立方体 Cₙ 的参数为：
- x₀ = S₆ₙ₋₅ mod 10000
- y₀ = S₆ₙ₋₄ mod 10000
- z₀ = S₆ₙ₋₃ mod 10000
- dx = 1 + (S₆ₙ₋₂ mod 399)
- dy = 1 + (S₆ₙ₋₁ mod 399)
- dz = 1 + (S₆ₙ mod 399)

求前 K 个立方体的组合体积。

---

## 输入格式

一行，一个整数 K（1 ≤ K ≤ 50000）。

---

## 输出格式

一个整数，表示组合体积。

---

## 样例

### 输入
```
100
```

### 输出
```
723581599
```

---

## 数据范围

- 1 ≤ K ≤ 50000
- PE 答案: K = 50000 → 328968937309
