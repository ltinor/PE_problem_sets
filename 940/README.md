# 940 二维递归（简单版本）

来源：改编自 Project Euler Problem 940 (Two-Dimensional Recurrence)

## 原题意

定义函数 A(m,n)：A(0,0)=0, A(0,1)=1，且
A(m+1,n)=A(m,n+1)+A(m,n)，A(m+1,n+1)=2·A(m+1,n)+A(m,n)。
S(k)=Σ_{i=2..k}Σ_{j=2..k} A(f_i,f_j)（f 为斐波那契）。原题求 S(50) mod 1123581313。

## 题目（简单版本）

输入一个整数 k，输出 S(k) mod 1123581313。

## 数据范围

- 简单版本：2 ≤ k ≤ 20（f₂₀=6765，几秒内算出）。

## 算法

由原始递推消元得单向递推 A(m+2,n)=3A(m+1,n)+A(m,n)、A(m,n+2)=A(m,n+1)+3A(m,n)；
先递推 A(0,*)、A(1,*)，再对每个需要的列 n=f_j 沿 m 方向填满求和。O(k·f_k)。

验证：S(3)=30，S(5)=10396。
