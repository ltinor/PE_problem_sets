# 全数字的乘积

## 题目描述

如果一个 $n$ 位数包含了 $1$ 至 $n$ 的所有数字恰好一次，我们称它为全数字的。例如，五位数 $15234$ 就是 $1$ 至 $5$ 全数字的。

考虑乘法等式 $a \times b = c$，其中 $a$、$b$、$c$ 均为正整数。如果 $a$、$b$、$c$ 的十进制表示合在一起恰好使用数字 $1$ 至 $N$ 各一次（不包含数字 $0$），则称该等式为 $1$ 至 $N$ 全数字的乘法等式。

例如，当 $N=9$ 时，$39 \times 186 = 7254$ 是一个全数字乘法等式，因为 $39$、$186$、$7254$ 合起来恰好使用了 $1$ 到 $9$ 各一次。

给定 $N$，求所有 $1$ 至 $N$ 全数字的乘法等式中，不同乘积 $c$ 的和。

注意：有些乘积可能从多个乘法等式中得到，但在求和时只计算一次。

---

## 输入格式

一行一个正整数 $N$。

---

## 输出格式

一行一个整数，表示所有满足条件的乘积之和。

---

## 样例

### 输入

```
9
```

### 输出

```
45228
```

---

## 数据范围

- $1 \leq N \leq 9$
