# 全数字的乘积 (Pandigital Products)

来源：改编自 Project Euler Problem 32

## 原题意

找出所有 a × b = c 的等式，使得 a, b, c 合起来恰好使用数字 1~9 各一次。求所有满足条件的乘积 c 的和（去重）。

原题答案：45228（N=9）。

## 改编方向

将固定使用数字 1~9 参数化为使用数字 1~N（1 ≤ N ≤ 9）。输入 N，求所有满足 a × b = c 且 a, b, c 合起来恰好使用 1~N 各一次的等式中，所有不同乘积 c 的和。

## 题目

输入一个整数 N（1 ≤ N ≤ 9），求所有满足以下条件的乘积 c 的和（去重）：
- 存在正整数 a, b 使得 a × b = c
- a, b, c 的十进制表示合在一起，恰好使用数字 1~N 各一次（不含数字 0）

## 数据范围

- 1 ≤ N ≤ 9

## 算法

std：枚举 a 和 b 的位数组合，使 a, b, c 总位数恰好为 N。在每种位数组合下枚举 a 和 b，计算 c = a × b，验证全数字性。用 set 去重。

brute：生成 1~N 的所有排列，枚举分割点分成 a, b, c，验证 a × b = c。

## 验证

- 原题答案：N=9 → 45228 ✓
- 10 组随机小数据对拍（std vs brute）：全部 AC
- 10 组正式数据对拍（std vs brute）：全部 AC
