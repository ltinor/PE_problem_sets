# 山脉路径

## 题目描述

给定海拔函数

$$h(x,y) = \left(5000 - \frac{0.005}{S^2}(x^2+y^2+xy) + \frac{12.5}{S}(x+y)\right) \cdot \exp\left(-\left|\frac{0.000001}{S^2}(x^2+y^2) - \frac{0.0015}{S}(x+y) + 0.7\right|\right)$$

定义在区域 $0 \le x, y \le 16S$ 上。一只蚊子从点 $A(2S, 2S)$ 出发，先垂直飞到海拔 $f$，然后保持海拔 $f$ 不变飞往点 $B(14S, 14S)$ 上方。

求允许从 $A$ 通行至 $B$ 的**最小海拔** $f_{\min}$，以及在此高度下从 $A'$ 到 $B'$ 的**最短路径长度**。

---

## 输入格式

一行，一个整数 $S$，表示缩放因子。

---

## 输出格式

一行，两个实数，分别表示 $f_{\min}$ 和最短路径长度，四舍五入保留三位小数，空格分隔。

---

## 样例

### 输入
```
100
```

### 输出
```
721.326 2531.205
```

**解释**：$S=100$ 即原题，区域 $0\le x,y\le 1600$，$A(200,200)$，$B(1400,1400)$。

### 输入
```
10
```

### 输出
```
738.945 251.731
```

---

## 数据范围

- $1 \le S \le 100$
