# 262 — Mountain Range（山脉路径）

来源：改编自 Project Euler Problem 262

## 原题意

给定海拔函数 h(x,y) = (5000-0.005(x²+y²+xy)+12.5(x+y))·exp(-|0.000001(x²+y²)-0.0015(x+y)+0.7|)，区域 0≤x,y≤1600。蚊子从 A(200,200) 先垂直升至海拔 f，然后保持海拔 f 绕过山脉飞至 B(1400,1400) 上方。求允许通行 A→B 的最小海拔 f_min 和在此高度下 A' 到 B' 的最短路径长度（保留三位小数）。答案：2531.205。

## 题目

输入一个缩放因子 S（1≤S≤100），区域变为 0≤x,y≤16·S，A=(2S,2S)，B=(14S,14S)。函数相应缩放：h(x,y) = (5000-0.005/S²·(x²+y²+xy)+12.5/S·(x+y))·exp(-|0.000001/S²·(x²+y²)-0.0015/S·(x+y)+0.7|)。求对应 S 下的最短路径长度（保留三位小数）。当 S=100 时对应原题。

## 数据范围

- 1 ≤ S ≤ 100

## 算法

对海拔函数进行网格离散化（网格分辨率自适应于 S），二分搜索 f_min（BFS/并查集判定连通性），然后在 f_min 高度运行 Dijkstra 求曲面上两点间最短路径。时间复杂度 O(N²logN)，其中 N 为每维网格点数。

## 改编方向与取舍

### 改编方向
1. **缩放因子 S** → 缩放区域和函数（本题采用），原题 S=100
2. **自定义起点终点** → 输入坐标，求任意两点间路径
3. **自定义函数参数** → 参数化海拔函数系数
4. **仅输出 f_min** → 只求最小海拔，省略路径长度

### 取舍理由
- 选择缩放因子 S：保持函数几何结构不变，计算量与 S² 成正比，S≤100 可行
- 不选自定义起终点：增加输入复杂度，且需额外验证可达性
- 不选自定义函数参数：难以保证函数仍有意义（可能无山峰）
- 保留路径长度：它是原题的核心输出（未拆分）
