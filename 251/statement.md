# 卡尔达诺三元组

## 题目描述

若正整数三元组 (a,b,c) 满足

$$
\sqrt[3]{a+b\sqrt{c}} + \sqrt[3]{a-b\sqrt{c}} = 1
$$

则称为卡尔达诺三元组（Cardano Triplet）。

例如，(2,1,5) 是一个卡尔达诺三元组。

给定 N，求有多少个卡尔达诺三元组满足 a + b + c ≤ N。

---

## 输入格式

一行一个整数 N。

---

## 输出格式

一行一个整数，表示满足条件的卡尔达诺三元组个数。

---

## 样例

### 输入
```
1000
```

### 输出
```
149
```

### 输入
```
100
```

### 输出
```
11
```

---

## 数据范围

- 对于 30% 的数据：N ≤ 10,000
- 对于 60% 的数据：N ≤ 100,000
- 对于 100% 的数据：N ≤ 2,000,000
