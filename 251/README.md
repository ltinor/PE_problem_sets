# 251 — Cardano's Triplet

来源：改编自 Project Euler Problem 251

## 原题意

若正整数三元组 (a,b,c) 满足 ∛(a+b√c) + ∛(a-b√c) = 1，则称为卡尔达诺三元组。
已知 a+b+c ≤ 1000 时有 149 个卡尔达诺三元组。
求 a+b+c ≤ 110,000,000 时的卡尔达诺三元组个数。答案: 18946051。

## 题目

给定正整数 N，求满足以下条件的正整数三元组 (a,b,c) 的个数：
1. ∛(a+b√c) + ∛(a-b√c) = 1
2. a + b + c ≤ N

## 数据范围

N ≤ 2,000,000。共 10 个测试点，包含原题数据和随机数据。

## 算法

1. **代数化简**: 立方程两边三次方，得 8a³+15a²+6a-1 = 27b²c。所有解满足 a ≡ 2 (mod 3)。令 x = (a+1)/3，则 b²c = x²(8x-3)。

2. **参数化**: 令 g = gcd(x, b), z = b/g, y = x/g (gcd(y, z) = 1)。则 z² | y(8gy-3)? → z² | (8gy-3)。

3. **枚举 (g, z)**: 对每个 g 和奇数 z（偶数 z 无解），满足 gcd(g, z²) ∈ {1, 3}。解线性同余 8g·y ≡ 3 (mod z²)，再枚举 y = y₀ + k·z²/gcd 直到 a+b+c > N。

4. **复杂度**: O(N log N)，使用 __int128 避免溢出。N ≤ 2,000,000 时在 1s 内通过。

## 改编方向

1. **参数化 N**: 原题固定 N=110,000,000，改编为输入 N。
2. **多组测试数据**: 多个 N 值测试不同规模。
3. **降低数据范围**: 原题 N=1.1e8 需要高级数论优化，改编降低至 2e6 可在 1s 内用枚举法通过。
