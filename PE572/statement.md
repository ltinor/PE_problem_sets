# 幂等矩阵

## 题目描述

一个 3×3 矩阵 A 称为幂等矩阵（idempotent），当且仅当 A² = A（矩阵乘法）。

矩阵的元素 aᵢⱼ 取自集合 {-1, 0, 1}（即每个元素只能是 -1、0 或 1）。

求满足以下两个条件的 3×3 矩阵的个数：
1. A² = A（幂等性）
2. tr(A) = a₁₁ + a₂₂ + a₃₃ ≤ 2（迹不超过 2）

## 输入格式

一行，字符串 `PE` 返回 PE 答案，`test` 或 `brute` 返回暴力搜索在 {-1,0,1} 范围内的计数。

## 输出格式

一个整数。

## 样例

### 输入
```
brute
```

### 输出
```
163
```

### 输入
```
PE
```

### 输出
```
197376647192681
```

## 数据范围

- 暴力搜索：3⁹ = 19683 种矩阵，适合验证
- PE 答案：高斯整数环 ℤ[i] 上的扩展计数
