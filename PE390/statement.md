# 无理数边长的整数面积三角形

## 题目描述

考虑正整数 b 和 c，三角形的三边长为 √(1+b²)、√(1+c²) 和 √(b²+c²)。

可以证明，该三角形的面积为 √(b²c² + b² + c²) / 2。

记 S(n) 为所有满足面积（bc/2）为不超过 n 的整数的三角形面积之和。

给定 n，求 S(n)。

---

## 输入格式

一个整数 n。

---

## 输出格式

一个整数，表示 S(n)。

---

## 样例

### 输入
```
100
```

### 输出
```
75
```

### 输入
```
1000000
```

### 输出
```
18018206
```

---

## 数据范围

- 对于 30% 数据：n ≤ 10^4
- 对于 60% 数据：n ≤ 10^6
- 对于 100% 数据：n ≤ 10^10
