# 角平分线与切线

## 题目描述

给定一个各边长均为整数且满足 $BC \le AC \le AB$ 的三角形 $ABC$：

- $k$ 是 $\angle ACB$ 的角平分线
- $m$ 是 $ABC$ 外接圆在 $C$ 点的切线
- $n$ 是过 $B$ 点平行于 $m$ 的直线
- $n$ 和 $k$ 的交点记为 $E$

现在给定一个正整数 $P$，请你计算有多少个周长不超过 $P$ 且满足上述条件的三角形 $ABC$，使得 $BE$ 的长度是整数。

---

## 输入格式

一行一个正整数 $P$。

---

## 输出格式

一行一个整数，表示满足条件的三角形个数。

---

## 样例

### 输入

```
50
```

### 输出

```
45
```

---

## 数据范围

- $1 \le P \le 100000$
