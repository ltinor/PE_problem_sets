## 原题描述

原题及更多讨论见 [https://projecteuler.net/problem=423](https://projecteuler.net/problem=423)。

取正整数n。
连续掷一个六面骰子n次，记c是连续两次掷出同样点数的次数。

例如，如果n = 7，掷出的点数分别是(1,1,5,6,6,6,3)，那么如下几组是连续两次掷出同样的点数：
(<u>1,1</u>,5,6,6,6,3)
(1,1,5,<u>6,6</u>,6,3)
(1,1,5,6,<u>6,6</u>,3)
因此，对于(1,1,5,6,6,6,3)来说，c = 3。

记C(n)是当连续掷一个六面骰子n次时，连续两次掷出同样点数的次数c不超过π(n)的结果数。<sup>1</sup>
例如，C(3) = 216，C(4) = 1290，C(11) = 361912500，而C(24) = 4727547363281250000。

对于1 ≤ n ≤ L，定义S(L)为∑ C(n)。
例如，S(50) mod 1&nbsp;000&nbsp;000&nbsp;007 = 832833871。

求S(50&nbsp;000&nbsp;000) mod 1&nbsp;000&nbsp;000&nbsp;007。

<sup>1</sup> π表示的是**素数计数函数**，也就是说，π(n)表示 ≤ n的素数个数。
