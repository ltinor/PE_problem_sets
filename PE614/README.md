# PE614 — 特殊分划2 (Special Partitions 2)

来源：改编自 Project Euler Problem 614

## 原题意

整数分划是将 n 写成正整数之和的方式，顺序不同视为相同。

称一个整数分划为特殊分划，若：(1) 所有加数互不相同；(2) 所有偶数加数都能被 4 整除。即加数只能是奇数或 4 的倍数。

记 P(n) 为 n 的特殊分划数。已知 P(1)=1，P(2)=0，P(3)=1，P(6)=1，P(10)=3，P(100)=37076，P(1000)=3699177285485660336。

求 Σ_{i=1}^{10⁷} P(i) mod (10⁹+7)。

PE 答案：130694090。

## 算法

1. **生成函数**：F(x) = ∏_{k 为奇数} (1+x^k) · ∏_{k≥1} (1+x^{4k})。
2. 定义集合 S = {n : n 为奇数或 n ≡ 0 (mod 4)}。P(n) 是 ∏_{k∈S} (1+x^k) 中 x^n 的系数。
3. **递推关系**：n·P(n) = Σ_{k=1}^{n} P(n-k) · a(k)，其中 a(k) = Σ_{d∈S, d|k} d · (-1)^{k/d - 1}。
4. 预处理 a(k)（k ≤ 10⁷），通过枚举 d∈S 并累加到其倍数上，时间复杂度 O(N log N)。
5. 使用五边形数定理的变体进行加速计算。

## 改编方向

1. 修改特殊条件（如偶数加数能被 6 整除，加数允许重复但受限制）。
2. 求 P(n) 的生成函数系数模不同素数。
3. 研究特殊分划数的渐近公式。
4. 多约束条件的分划问题（如同时限制加数大小和奇偶性）。
