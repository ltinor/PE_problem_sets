# 纸张期望值

## 题目描述

一家打印店每周有 16 份打印工作，每份工作需要一张 A5 大小的特殊纸张。

每周一早晨，领班会打开一个新信封，其中有一张 A1 大小的纸。他将这张纸不断对半裁切：A1 → 两张 A2，取其中一张 → 两张 A3，取其中一张 → 两张 A4，取其中一张 → 两张 A5。他使用一张 A5，将其余纸张放回信封。

对于后续每次打印工作，领班从信封中随机取出一张纸：
- 如果是 A5，直接使用；
- 如果是更大的纸，重复上述裁剪过程得到一张 A5，并将剩余纸张放回信封。

除了第一次和最后一次打印工作外，求在这周中领班取纸时发现信封里只有一张纸的次数的期望值。

答案保留六位小数。

---

## 输入格式

一行一个整数（本题为固定答案题，输入任意整数均可，不影响输出）。

---

## 输出格式

一行一个浮点数，保留六位小数，表示期望次数。

---

## 样例

### 输入

```
1
```

### 输出

```
0.464399
```

---

## 数据范围

- 固定答案题，输出恒为 0.464399。
