# 111 — Primes with Runs

来源：改编自 Project Euler Problem 111

## 原题意

对于 n 位素数，定义 M(n,d) 为数字 d 重复出现的最大次数，N(n,d) 为满足该条件的素数个数，S(n,d) 为这些素数的和。原题求所有 S(10,d) (d=0..9) 的和。答案：612407567715。

## 题目

输入整数 n（1 ≤ n ≤ 10），求所有 S(n,d) (d=0..9) 的和。

## 数据范围

- 1 ≤ n ≤ 10

## 算法

对每个数字 d（0..9），从最大可能重复次数 k=n-1 开始递减尝试。对于每个 k，枚举 n 个位置中选 k 个放置 d，剩余 n-k 个位置填入非 d 数字（首位不能为 0），生成候选数后判断素数（试除法到 √x）。找到第一个有解的 k 即返回 S(n,d)。

对于 n ≤ 10，k 通常接近 n-1，搜索空间很小（例如 n=10, k=8 时约 3645 个候选数），算法高效。

## 改编方向与取舍

### 改编方向
1. **参数化 n** → 支持 n ≤ 10（本题采用），保留原题核心算法
2. **大范围 n** → n ≤ 18，需要 Miller-Rabin 判素，答案需大整数
3. **单独查询 S(n,d)** → 输入 n 和 d，输出单个 S(n,d) 值
4. **输出所有 N(n,d)** → 同时输出每个 d 的素数个数

### 取舍理由
- 选择参数化 n (≤10)：最直接，保留原题核心搜索策略
- n 限制在 10：原题范围，答案在 64 位整数内
- 不选择大范围：n=18 时需大整数和大范围素性测试，脱离原题难度
