# 有重复数字的素数

## 题目描述

考虑 n 位素数。记 M(n,d) 为 n 位素数中数字 d 重复出现的最多次数，S(n,d) 为达到该最大重复次数的所有 n 位素数的和。

例如 n=4、d=1 时，M(4,1)=3（4 位素数中 1 最多出现 3 次），S(4,1)=22275。

对于 d=0 到 9，求所有 S(n,d) 的总和。

---

## 输入格式

一行一个整数 n。

---

## 输出格式

一行一个整数，表示所有 S(n,d) 的总和。

---

## 样例

### 输入
```
4
```

### 输出
```
273700
```

### 输入
```
1
```

### 输出
```
17
```

---

## 数据范围

- 1 ≤ n ≤ 10
