# n写成k个数乘积

## 题目描述

记 $W(n, k)$ 为将正整数 $n$ 写成 $k$ 个正整数乘积的方式数，即：

$$W(n, k) = |\{(a_1, a_2, \dots, a_k) : a_i \in \mathbb{N}^+, \prod_{i=1}^k a_i = n\}|$$

注意顺序是区分的：$(2, 3)$ 和 $(3, 2)$ 视为不同方式。

给定 $n$ 和 $k$，求 $W(n, k) \bmod 1000000007$。

## 输入格式

两个整数 $n$ 和 $k$，或字符串 `PE`。

## 输出格式

一个整数，表示 $W(n, k) \bmod 1000000007$。

## 样例

### 输入
```
6 2
```

### 输出
```
4
```

（6 = 1×6 = 6×1 = 2×3 = 3×2，共 4 种）

## 数据范围

- 对于 30% 数据：$n \le 100, k \le 5$
- 对于 60% 数据：$n \le 10^5, k \le 20$
- 对于 100% 数据：$n \le 10^6, k \le 100$
