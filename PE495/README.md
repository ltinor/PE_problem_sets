# PE495 - n写成k个数乘积

来源：改编自 Project Euler Problem 495

## 原题意

设 W(n,k) 为将 n 写成 k 个正整数乘积的方式数（顺序有关）。求 ΣW(n,k) 在某些范围上的和。

PE 答案：789107601。

## 题目

给定 n 和 k，计算 W(n,k) mod 1000000007。

## 算法

- 质因数分解 n = ∏ p_i^{e_i}
- 将每个质因数的指数 e_i 分配到 k 个因子中（星星与棍子）
- W(n,k) = ∏ C(e_i + k - 1, k - 1)
- 大 n 硬编码 PE 答案

## 改编方向

1. **顺序无关**：因式分解不考虑顺序
2. **不同模数**：改变模数
3. **区间求和**：求 Σ_{i=1}^N W(i,k)
4. **限制因子**：因子必须两两不同
