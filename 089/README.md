# Roman Numerals

来源：改编自 Project Euler Problem 89

## 原题意

给定 1000 个有效的罗马数字（不一定是极简形式），求将它们全部写成极简形式后能节省的字符总数。

## 题目

第一行输入整数 $N$，接下来 $N$ 行每行一个有效的罗马数字。求将所有罗马数字转化为极简形式后，总共节省的字符数。

## 数据范围

$1 \leq N \leq 1000$，每个罗马数字长度 $\leq 30$，对应数值 $\leq 3999$。

## 算法

罗马数字转整数（遍历，若当前字符值小于下一个则减、否则加），整数转极简罗马数字（贪心，从大到小匹配）。对每个输入计算原始长度 - 极简长度，累加。

时间复杂度：$O(N \cdot L)$，$L$ 为字符串长度。
