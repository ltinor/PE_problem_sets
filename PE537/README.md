# PE537 - 元组计数 (Counting Tuples)

来源：改编自 Project Euler Problem 537

## 原题意

设 $\pi(x)$ 为不超过 $x$ 的素数个数。考虑由互异素数组成的元组 $(p_1, p_2, \ldots, p_k)$，满足 $p_1 < p_2 < \cdots < p_k$ 且 $\prod_{i=1}^{k} p_i \le N$。
求所有这样的元组（任意长度 $k \ge 1$）的总数，对 $N = 2 \times 10^7$ 取模 $1000000007$。

PE 答案：779429131。

## 题目

给定 N，计算所有由互异素数组成的子集，使得子集中所有元素的乘积不超过 N 的子集个数。

## 算法

- 使用素数筛法生成所有不超过 N 的素数。
- 动态规划：设 `dp[x]` 表示乘积恰好为 x 的子集个数。
  - 初始：`dp[1] = 1`（空乘积）。
  - 对于每个素数 p，逆序更新：`dp[x] += dp[x/p]`（当 p | x 时）。
  - 这保证了每个素数在每个子集中最多使用一次。
- 时间复杂度：$O(\pi(N) \cdot N)$（小数据），大规模需优化。

## 改编方向

1. **允许重复**：元组中素数可以重复（即考虑素数的多重集）。
2. **不同约束**：要求 $\sum p_i \le N$ 而非 $\prod p_i \le N$。
3. **固定长度**：只统计恰好 k 个元素的元组。
4. **非素数版本**：使用斐波那契数、平方数等其他序列。
