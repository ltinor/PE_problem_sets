# Iterative Circle Packing

来源：改编自 Project Euler Problem 199

## 原题意

在大圆内放入三个等大且两两相切的小圆。迭代地在每个空隙中放入最大可能的圆。求10轮迭代后未覆盖面积的比例。

## 题目

给定迭代轮数 K（0 ≤ K ≤ 10），求 K 轮迭代后未被圆覆盖的面积比例，保留8位小数。

## 数据范围

- 0 ≤ K ≤ 10
- PE 答案: K=10 → 0.00396087

## 算法

笛卡尔定理（Descartes' theorem）：四个两两相切圆的曲率满足 (k₁+k₂+k₃+k₄)² = 2(k₁²+k₂²+k₃²+k₄²)。给定三个曲率，第四个为 k₄ = k₁+k₂+k₃ ± 2√(k₁k₂+k₁k₃+k₂k₃)。

取外圆曲率为-1（半径=1），三个内圆曲率为 1+2/√3。迭代填充空隙（每个空隙为三圆相切），面积 = π/k²。
