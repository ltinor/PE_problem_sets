# 三角形内的椭圆

## 题目描述

对于平面上的任意三角形，可以证明存在唯一的最大面积椭圆完全包含在三角形内部。

考虑整点三角形：顶点坐标绝对值都不超过 n，且最大内椭圆的焦点恰为 (√13, 0) 和 (-√13, 0)。

给定 n，求所有满足条件的三角形面积之和。

---

## 输入格式

一个整数 n。

---

## 输出格式

一个整数，表示答案。

---

## 样例

### 输入
```
8
```

### 输出
```
72
```

### 输入
```
100
```

### 输出
```
34632
```

---

## 数据范围

- 对于 30% 数据：n ≤ 100
- 对于 60% 数据：n ≤ 10^6
- 对于 100% 数据：n ≤ 10^9
