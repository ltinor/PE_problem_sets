# PE418 - 因数三元组

来源：改编自 Project Euler Problem 418

## 原题意

对正整数 n，因数三元组 (a,b,c) 满足 a≤b≤c 且 abc=n。f(n) 为最小化 c/a 的三元组的 a+b+c。原题求 f(43!)，答案为 1177163565297340320。

## 题目

给定 n，求 f(n)。若 n 为 k（≤43），表示求 f(k!)。

## 算法

- 枚举 n 的所有因子
- 对所有满足 a≤b≤c 且 abc=n 的三元组，计算 c/a
- 取 c/a 最小的三元组，输出 a+b+c
- 对 n!，需先分解阶乘的质因数

## 改编方向

1. **最大化 c/a**：求使 c/a 最大的三元组
2. **求三元组个数**：求所有满足条件的三元组数目
3. **扩展维度**：求四元组 (a,b,c,d) 使 abcd=n
4. **区间最小值**：求 [l,r] 内最小 f(n) 的 n
