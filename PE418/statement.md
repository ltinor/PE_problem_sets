# 因数三元组

## 题目描述

正整数 n 的因数三元组 (a,b,c) 满足：
- 1 ≤ a ≤ b ≤ c
- a·b·c = n

f(n) 定义为使 c/a 最小的三元组的 a+b+c（该三元组唯一）。

已知：f(165)=19, f(100100)=142, f(20!)=4034872。

给定整数 n（n ≤ 43 时表示求 f(n!)，否则求 f(n)），求 f(n)。

---

## 输入格式

一个整数 n。

---

## 输出格式

一个整数，表示 f(n)。

---

## 样例

### 输入
```
165
```

### 输出
```
19
```

### 输入
```
100100
```

### 输出
```
142
```

### 输入
```
20
```

### 输出
```
4034872
```

---

## 数据范围

- 对于 30% 数据：n ≤ 10^6
- 对于 60% 数据：n ≤ 10^12
- 对于 100% 数据：n ≤ 43（表示为阶乘）
