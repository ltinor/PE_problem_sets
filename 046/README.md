# 哥德巴赫的另一个猜想 (Goldbach's Other Conjecture)

来源：改编自 Project Euler Problem 46

## 原题意

哥德巴赫曾猜想每个奇合数都可以写成一个素数和一个平方的两倍之和。最终该猜想被推翻。求最小的不能写成 prime + 2×s² 的奇合数。

原题答案：5777。

## 改编方向

将问题参数化：输入 K，求第 K 个不能写成 prime + 2×s² 的奇合数。

## 题目

给定正整数 K，求第 K 个不能写成一个素数与一个平方的两倍之和的奇合数。

## 数据范围

- K ≤ 10
- 答案在 32 位有符号整数范围内

## 算法

使用埃拉托色尼筛法生成素数表。从小到大枚举奇合数，对每个奇合数检查是否存在素数 p 和整数 s 使得 odd = p + 2×s²。即检查 odd - 2×s² 是否为素数。找到第 K 个不满足条件的数。

brute 使用独立实现的筛法和预计算 2×s² 数组，用二分查找验证。

## 验证

- 原题答案：K=1 → 5777 ✓
