# PE623 — Lambda 计数 (Lambda Count)

来源：改编自 Project Euler Problem 623

## 原题意

Λ(n) = 可以用至多 n 个符号表示的不同闭合 lambda 项（combinator）的数目。α-等价的项只计一次。符号包括括号、λ、点号和变量名。

已知：Λ(6)=1，Λ(9)=2，Λ(15)=20，Λ(35)=3166438。

求 Λ(2000) mod 1,000,000,007。

PE 答案：3999787880。

## 算法

这是一个组合枚举问题，可以通过动态规划求解。

Lambda 项的语法：
- 变量（variable）：1 个符号
- λ 抽象（abstraction）：λx.M，共 3 + |M| 个符号（λ + 变量 + 点 + M）
- 应用（application）：(M N)，共 2 + |M| + |N| 个符号

闭合项（无自由变量）的生成规则：
- λx.M，其中 M 的自由变量 ⊆ {x}（即 M 有 0 或 1 个自由变量）
- (M N)，其中 M、N 均为闭合项

定义 A[n] = 大小为 n 的闭合项数，B[n] = 大小为 n 的含一个自由变量的项数。

递推关系：
- A[n] = Σ_{i+j=n-2} A[i]·A[j] + B[n-3]（应用 + 抽象）
- B[n] = …（涉及一个和两个自由变量的项）

通过 DP 枚举所有可能的项结构，可计算到 n=2000。时间复杂度约为 O(n³) 在朴素实现中，但可利用生成函数和卷积加速。

## 改编方向

1. 仅计数某种特定类型的 lambda 项（如只使用单个变量）。
2. 求生成函数的解析性质。
3. 增加符号种类的权重（如给不同符号分配不同代价）。
4. 计数含指定数量 redex 的项。
