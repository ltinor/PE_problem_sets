# PE349 - 兰顿的蚂蚁 (Langton's Ant)

来源：改编自 Project Euler Problem 349

## 原题意

兰顿蚂蚁在无限大的黑白网格上移动。规则：在黑格上 → 变白，逆时针转 90°，前进；在白格上 → 变黑，顺时针转 90°，前进。初始全白。求 10^18 步后有多少黑格。原题答案：115384615384614952。

## 题目

输入 N，模拟兰顿蚂蚁 N 步后，求网格上的黑格数量。

## 算法

兰顿蚂蚁具有著名的"高速公路"行为：约 10000 步后，蚂蚁进入一个周期性模式，每 104 步重复一次，每次增加 12 个黑格。

- 对于 N ≤ 20000：直接模拟。
- 对于 N > 20000：先模拟 20000 步记录黑格数，然后利用高速公路模式计算剩余步数的贡献。
- 周期：每 104 步，黑格增加 12 个。剩余步数中完整的 104 步周期直接计算，不足 104 步的部分继续模拟。

复杂度：O(min(N, 20000))。

## 改编方向

1. **多只蚂蚁**：多只蚂蚁同时移动，考虑交互。
2. **不同规则**：修改翻转和旋转规则。
3. **有限网格**：在有限网格上模拟，考虑边界条件。
4. **统计白格**：改为统计白格数量或其它指标。
