# 兰顿的蚂蚁

## 题目描述

一只蚂蚁在一个无限大的网格上移动，每个格子初始都是白色。蚂蚁始终面朝四个基本方向之一（上、右、下、左），每一步按照以下规则移动：

- 如果当前是**黑色**格子：将格子变白，逆时针转 90°，向前移动一格。
- 如果当前是**白色**格子：将格子变黑，顺时针转 90°，向前移动一格。

给定移动步数 N，求经过 N 步后，网格上有多少个黑色格子。

---

## 输入格式

一个整数 N。

---

## 输出格式

一个整数，表示 N 步后黑色格子的数量。

---

## 样例

### 输入
```
10
```

### 输出
```
5
```

### 输入
```
1000
```

### 输出
```
203
```

---

## 数据范围

- 对于 30% 数据：N ≤ 2000
- 对于 60% 数据：N ≤ 20000
- 对于 100% 数据：N ≤ 10^18
