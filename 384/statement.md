# 鲁丁-夏皮罗序列

## 题目描述
定义序列 a(n) 为 n 的二进制表示中相邻的两个 1 的对数（可重叠）。
定义 b(n) = (-1)^{a(n)}。
定义 s(n) = Σ_{i=0}^n b(i)（部分和序列）。

性质：每个正整数 k 恰好在 s 中出现 k 次。

定义 g(t, c) 为 t 在 s 中第 c 次出现时的下标。
定义 F(n) 为斐波那契数列：F(0)=F(1)=1，F(n)=F(n-1)+F(n-2)。
定义 GF(t) = g(F(t), F(t-1))。

给定区间 [L, R]，求 Σ_{t=L}^R GF(t)。

---
## 输入格式
两个整数 L 和 R。

---
## 输出格式
Σ GF(t) for t=L..R。

---
## 样例
### 输入
```
2 5
```
### 输出
```
29
```

---
## 数据范围
- 2 ≤ L ≤ R ≤ 45
