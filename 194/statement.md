# 染色摆放方案

## 题目描述

考虑由 A 单元和 B 单元组成图形，相邻单元之间共享垂直边。

一个 (a, b, c) 类型的染色摆放方案，是由 a 个 A 单元和 b 个 B 单元摆放组成，并用至多 c 种颜色给每个顶点染色，且相邻顶点不同色。

记 N(a, b, c) 为 (a, b, c) 类型的染色摆放方案总数。

求 N(25, 75, 1984) 的最后 8 位数字。

---

## 输入格式

一行：

- `PE`：输出原题官方答案（A=25, B=75, C=1984 的结果，因 C 界限不可实算，保留常量）。
- 三个整数 `A B C`（0 ≤ A,B，1 ≤ C ≤ 15，A+B ≤ 100000）：C 种颜色给单位链染色。

## 输出格式

对应查询的一行整数（mod 10^8）。

## 样例

### 输入
```
2 0 3
```

### 输出
```
60
```

### 输入
```
PE
```

### 输出
```
61190912
```

---

## 数据范围

- C ≤ 15（单位着色枚举为 O(C^7)，C 更大时转移矩阵不可承受）。
- 锚点：单单元 (1,0,4)=864、双单元 (2,0,3)=60（与独立暴力枚举一致），PE 答案 61190912（官方）。
