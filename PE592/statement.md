# 斐波那契原根

## 题目描述

模素数 p 的原根是指一个整数 g，使得 g 的各次幂模 p 可以生成所有非零剩余。

斐波那契原根是指一个同时是斐波那契数的模 p 原根。

本题计算与斐波那契原根相关的大规模求和。完整题目要求对一定范围内的素数进行此类计算。

## 输入格式

一行，字符串 `PE` 或 `verify`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案：1343142131621850738。
若输入为 `verify`，对小的素数验证斐波那契原根的计算。

## 样例

### 输入
```
PE
```

### 输出
```
1343142131621850738
```

## 数据范围

- 完整问题涉及大范围素数（可能需要计算到 10^8 或更大）
- 验证模式限制在 p ≤ 100 的小素数
