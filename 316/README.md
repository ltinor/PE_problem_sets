# 316 — Numbers in Decimal Expansions

来源：改编自 Project Euler Problem 316

## 原题意

给定 $N=10^D$ 和上限 $U=10^K-1$，计算 $\sum_{n=2}^{U} g(\lfloor N/n \rfloor)$。

$g(v)$ 是无限随机十进制数字序列中数字串 $v$ 首次出现的期望位置。$g(v) = \sum_{k \in \text{borders}(v)} 10^k$，边框指同时是前缀和后缀的子串。

原题：$D=16, K=6$，答案 $542934735751917735$。
例：$D=6, K=3$，答案为 $27280188$。

## 题目

输入 $D$ 和 $K$（$N=10^D, U=10^K-1$），计算 $S(D,K) = \sum_{n=2}^{U} g(\lfloor N/n \rfloor)$。

## 数据范围

- $2 \le D \le 16$
- $1 \le K \le \min(D, 6)$

## 算法

1. **直接枚举法**：枚举 $n=2..10^K-1$，计算 $v=\lfloor 10^D/n\rfloor$ 的 $g(v)$。由于 $K$ 较小（$\le 6$），$10^K \le 10^6$，枚举可行。复杂度 $O(10^K \cdot D)$。
2. **根号分块法**：利用 $\lfloor N/n\rfloor$ 只有 $O(\sqrt{N})$ 种取值，分组计算。适用于更大 $K$。
3. **数位 DP**：对 $v$ 按数字位数分组，批量计算 $g(v)$ 的和。

## 改编方向

1. 原题固定 $D=16, K=6$ → 参数化 $D, K$
2. 将 $N$ 和 $U$ 作为独立参数
3. 改变基数（如二进制下的期望位置）

选择方向 1：参数化 $D, K$，保留原题数学核心。
