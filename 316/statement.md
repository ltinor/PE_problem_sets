# 十进制小数中的数字

## 题目描述

设 $p = p_1 p_2 p_3 \dots$ 为无限随机十进制数字序列，每位数字从 $\{0,1,\dots,9\}$ 中等概率选取。

对于任意十进制正整数 $v$（设 $d$ 位数字），记 $k$ 为满足 $p_k, p_{k+1}, \dots, p_{k+d-1}$ 恰好构成 $v$ 的各位数字的**最小下标**。定义 $g(v)$ 为 $k$ 的期望值（可以证明 $g(v)$ 总是整数）。

给定整数 $D$ 和 $K$，令 $N = 10^D$，$U = 10^K - 1$。计算：

$$S(D,K) = \sum_{n=2}^{U} g\left(\left\lfloor \frac{N}{n} \right\rfloor\right)$$

---

## 输入格式

一行两个整数 $D$ 和 $K$。

---

## 输出格式

一行一个整数，表示 $S(D,K)$ 的值。

---

## 样例

### 输入

```
6 3
```

### 输出

```
27280188
```

### 输入

```
16 6
```

### 输出

```
542934735751917735
```

---

## 数据范围

- $2 \le D \le 16$
- $1 \le K \le \min(D, 6)$
