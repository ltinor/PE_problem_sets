# 跳跃游戏

## 题目描述

记 sk 为 0 到 k 的二进制表示中所有"1"的个数之和。序列 S = {sk : k ≥ 0} 的前几项为 {0, 1, 2, 4, 5, 7, 9, 12, ...}。

两名玩家玩游戏。先选定一个数 n。计数器 c 从 0 开始。每回合玩家从 1 到 n 中选一个数加到 c 上，结果必须仍在 S 中。无法操作者输。

记 M(n) 为先手在保证必胜的前提下第一轮能选择的最大数；若无必胜策略则 M(n)=0。

给定 N，求 Σ_{n=1}^{N} (M(n))^3。

---

## 输入格式

一个整数 N。

---

## 输出格式

一个整数，表示 Σ(M(n))^3。

---

## 样例

### 输入
```
20
```

### 输出
```
8150
```

---

## 数据范围

- 对于 30% 数据：N ≤ 20
- 对于 60% 数据：N ≤ 200
- 对于 100% 数据：N ≤ 1000
