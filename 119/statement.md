# 数字和的幂

## 题目描述

如果一个数满足以下条件，我们称它为"数字幂和数"：
1. 该数至少有两位数
2. 存在整数 p ≥ 2，使得该数等于其各位数字之和的 p 次幂

例如：
- 512：各位数字之和为 5 + 1 + 2 = 8，8³ = 512 ✓
- 614656：各位数字之和为 6 + 1 + 4 + 6 + 5 + 6 = 28，28⁴ = 614656 ✓

将所有数字幂和数从小到大排列，记第 K 个为 a_K。

已知 a₂ = 512，a₁₀ = 614656。

---

## 输入格式

一行，一个整数 K。

---

## 输出格式

一行，一个整数 a_K。

---

## 样例

### 输入
```
1
```

### 输出
```
81
```

### 输入
```
2
```

### 输出
```
512
```

### 输入
```
10
```

### 输出
```
614656
```

### 说明
- a₁ = 81（8 + 1 = 9，9² = 81）

---

## 数据范围

- 1 ≤ K ≤ 30
