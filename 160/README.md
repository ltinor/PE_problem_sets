# 160 — 阶乘的尾数

来源：改编自 Project Euler Problem 160

## 原题意

求 N = 10^12 时 N! 除去末尾零后的最后五位数字。

原题答案：16576。

## 题目

参数化 N：输入 N (≤ 10^12)，求 f(N) = N! 除去末尾零的最后五位数字。

## 数据范围

- N ≤ 10^12

## 算法

**std**: 分治 + 周期优化。N! = 2^cnt2 × 5^cnt5 × R，其中 R 与 10 互质。f(N) = R × 2^(cnt2-cnt5) mod 10^5。计算 R 的方法：对 n = N, N/5, N/25, ... 累乘所有奇且不被 5 整除的数。利用模 10^5 的周期性（周期 10^5），预处理一个周期乘积，O(log N) 时间内完成。总复杂度 O(log N)。

**brute**: 对 N ≤ 20 直接计算阶乘后去除尾部零。对更大 N 使用与 std 相同的算法验证。

## 改编方向

1. **参数化 N**：将固定 N=10^12 改为输入参数。
2. **分治分解**：利用 N! 中 2 和 5 因子的独立性。
3. **周期优化**：模 10^5 下奇数次不与 5 互质数的乘积具有周期 10^5。
4. **PE 答案验证**：(N=10^12) 输出 16576。
