# PE483 - 重复排列

来源：改编自 Project Euler Problem 483

## 原题意

对 $n$ 元排列重复应用。排列的阶（所有循环长度的 LCM）决定了元素回到原位所需的步数。

求所有 $n!$ 个排列的阶之和（或期望值乘以 $n!$）。PE 答案：32153032097171877。

## 题目

给定 n，求所有排列的阶之和。

## 算法

- 排列的阶 = 各循环长度的 LCM
- 使用整数分拆 DP：dp[sum] = 具有特定循环结构的排列数 × LCM
- 对于循环长度 $l$ 出现 $k$ 次：贡献因子为 $l$
- 直接枚举所有分拆复杂度为 $O(p(n))$，$p(100) ≈ 1.9×10^8$，需优化
- 可使用 DP over LCM 值或使用生成函数

## 改编方向

1. **不同统计量**：最大循环长度、循环数
2. **带权排列**：每个排列有权重
3. **限制排列类型**：对合、交错排列
4. **多排列复合**：两个排列的复合阶
