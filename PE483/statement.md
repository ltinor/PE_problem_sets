# 重复排列

## 题目描述

对一个 $n$ 元排列 $P$，重复地将 $P$ 应用到 $[1, 2, \ldots, n]$ 上。每个元素最终会回到其原始位置。

考虑所有 $n!$ 种排列。对每个排列，将其所有循环长度的最小公倍数（LCM）记为 $L(P)$，即排列的阶。

求所有 $n!$ 个排列的 $L(P)$ 之和（或其期望值）。

---

## 输入格式

一个整数 $n$。

---

## 输出格式

一个整数，表示所求之和。

---

## 样例

### 输入
```
3
```

### 输出
```
15
```

---

## 数据范围

- 对于 30% 数据：$n \le 5$
- 对于 60% 数据：$n \le 10$
- 对于 100% 数据：$n \le 100$
