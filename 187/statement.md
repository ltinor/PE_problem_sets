# 半素数

## 题目描述

如果一个正整数 $n$ 可以表示为两个质数的乘积（$n = p \times q$，$p$ 和 $q$ 都是质数，允许 $p = q$），则称 $n$ 为半素数（semiprime）。

例如，$n < 30$ 的半素数有：$4, 6, 9, 10, 14, 15, 21, 22, 25, 26$，共 $10$ 个。

给定 $N$，求 $n < N$ 的半素数的个数。

---

## 输入格式

一行，一个正整数 $N$。

---

## 输出格式

一行，一个整数，表示半素数的个数。

---

## 样例

### 输入
```
30
```

### 输出
```
10
```

---

## 数据范围

- $4 \le N \le 10^8$
