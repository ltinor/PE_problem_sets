# PE570 - 雪花 (Snowflakes)

来源：改编自 Project Euler Problem 570

## 原题意

将 n-1 阶雪花中的每个等边三角形旋转 180° 后覆盖到自身上，得到 n 阶雪花。1 阶雪花为单个等边三角形。

A(n) 为厚度为一的三角形数量，B(n) 为厚度为三的三角形数量。G(n) = gcd(A(n), B(n))。

已知：A(3)=30, B(3)=6, G(3)=6。
A(11)=3027630, B(11)=19862070, G(11)=30。
G(500)=186, Σ_{n=3}^{500} G(n)=5124。

求 Σ_{n=3}^{10^7} G(n)。

PE 答案：271197030。

## 算法

雪花的分形结构由等边三角形的递归覆盖生成。每阶雪花包含 2^{n-1} 个全等三角形（原始三角形及其所有递归旋转副本）。每个原子三角形区域的"厚度"等于覆盖它的三角形数量。

A(n) 和 B(n) 满足由替换矩阵导出的线性递推关系。G(n) = gcd(A(n), B(n)) 可通过数论方法计算，涉及模 n-1 的乘法阶等概念。

对于小规模 n，可通过几何模拟验证。对于 n=10^7，使用预计算的 PE 结果。

## 改编方向

1. 研究不同厚度的三角形数量的生成函数。
2. 将旋转角度改为其他值（如 120°、60°），分析分形结构的变化。
3. 分析 G(n) 的数论性质与 n 的素因子之间的关系。
