# 丢番图倒数 II

## 题目描述

考虑方程：

$$\\frac{1}{x}+\\frac{1}{y}=\\frac{1}{n}$$

其中 $x, y, n$ 均为正整数。对于给定的 $n$，该方程有若干不同的正整数解 $(x, y)$（$x \\le y$）。

求最小的正整数 $n$，使得不同解的个数**严格大于** $K$。

---

## 输入格式

一行一个整数 $K$。

---

## 输出格式

一行一个整数，表示最小的满足条件的 $n$。

---

## 样例

### 输入
```
100
```

### 输出
```
1260
```

**解释**：$n=1260$ 时有 113 个不同解，是第一个超过 100 个解的 $n$。

### 输入
```
4000000
```

### 输出
```
9350130049860600
```

---

## 数据范围

- $1 \\le K \\le 4 \\times 10^6$
- 注意：答案可能很大，使用 64 位整数存储（最大约 $9.35 \\times 10^{15}$）
