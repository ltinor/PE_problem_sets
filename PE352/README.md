# PE352 - 血液检测 (Blood tests)

来源：改编自 Project Euler Problem 352

## 原题意

每只羊独立以概率 p 感染病毒。混合血液样本检测能一次判断组内是否有感染者。求最优分组策略下的期望检测次数 T(s,p)。求 ΣT(10000, p) for p=0.01..0.50。原题答案：378572.8144（四舍五入到6位小数）。

## 题目

给定羊的数量 S 和感染概率 p，求最优策略下的期望检测次数 T(S, p)。结果保留6位小数。

## 算法

动态规划。令 T[n] 为 n 只羊的最优期望检测次数，G[k] 为 k 只已知至少有一只感染的羊的最优期望检测次数。

- T[0] = 0，G[1] = 0
- T[n] = min_{1≤k≤n} { 1 + q^k·T[n-k] + (1-q^k)·(G[k] + T[n-k]) }
- G[k] = min(逐个检测, 顺序检测, 子组混合检测)

其中 q = 1-p。复杂度 O(N²)，N ≤ 10000 实际限制 k ≤ 300 优化到 O(N·K)。

## 改编方向

1. **多病毒版本**：多种病毒各自有不同感染率
2. **批量限制**：限制最大混合样本数
3. **假阳性/假阴性**：引入检测误差
4. **最小化最坏情况**：改为最小化最坏情况检测次数
