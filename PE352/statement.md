# 血液检测

## 题目描述

每只羊独立以概率 p 感染某种病毒。我们可以进行血液检测：将若干羊的血液样品混合后进行一次检测，若结果为阴性则这些羊均未感染，若为阳性则其中至少有一只感染。

检测策略的限制：一旦开始检测一份混合样品，必须先完全确认该样品中所有羊的感染状态后，才能检测其它羊。

记 T(s, p) 为 s 只羊、感染率 p 时的最优策略期望检测次数。

例如：T(25, 0.02) = 4.155452，T(25, 0.10) = 12.702124。

给定 S 和 p，求 T(S, p)。结果四舍五入保留 6 位小数。

---

## 输入格式

一行，一个整数 S 和一个浮点数 p（保留两位小数），空格分隔。

---

## 输出格式

一个浮点数，保留 6 位小数。

---

## 样例

### 输入
```
25 0.02
```

### 输出
```
4.155452
```

### 输入
```
25 0.10
```

### 输出
```
12.702124
```

---

## 数据范围

- 对于 30% 数据：S ≤ 25
- 对于 60% 数据：S ≤ 500
- 对于 100% 数据：S ≤ 10000，0.01 ≤ p ≤ 0.50
