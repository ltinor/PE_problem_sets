# 阿克曼函数

## 题目描述

阿克曼函数 A(m,n) 定义如下（m, n 为非负整数）：

- A(0, n) = n + 1
- A(m, 0) = A(m - 1, 1)（m > 0）
- A(m, n) = A(m - 1, A(m, n - 1))（m, n > 0）

给定 m, n, M，求 A(m,n) mod M。

---

## 输入格式

一行三个整数 m, n, M（0 ≤ m ≤ 3, 0 ≤ n ≤ 10^9, 1 ≤ M ≤ 10^9）。

---

## 输出格式

一个整数，表示 A(m,n) mod M。

---

## 样例

### 输入
```
3 4 1000
```

### 输出
```
125
```

（A(3,4) = 2^7 - 3 = 125）

---

## 数据范围

- 0 ≤ m ≤ 3
- 0 ≤ n ≤ 10^9
- 1 ≤ M ≤ 10^9
- PE 答案（原题）: Σ_{n=0}^{6} A(n,n) mod 14^8 = 1098988351
