# 拥有等长直角边的直角三角形

## 题目描述

考虑整数边长的直角三角形。对于一个整数 c，求有多少个不同的整数边长直角三角形拥有一条长为 c 的直角边。

例如，有如下四个直角三角形拥有一条长为 12 的直角边：
- (9, 12, 15)
- (12, 16, 20)
- (5, 12, 13)
- (12, 35, 37)

可以证明不存在其它整数边长直角三角形拥有一条长为 12 的直角边。

对于给定的整数 K，求使得恰好有 K 个不同的整数边长直角三角形拥有该长度直角边的最小整数。

## 输入格式

一行一个整数 K（1 ≤ K ≤ 47547）。

## 输出格式

一行一个整数，表示最小的满足条件的直角边长。

---

## 样例

### 输入
```
1
```

### 输出
```
3
```

### 输入
```
2
```

### 输出
```
8
```

### 输入
```
4
```

### 输出
```
12
```

---

## 数据范围

- 1 ≤ K ≤ 47547
- 答案可能很大，PE 原题 K=47547 时答案为 96818198400000。

---

## 提示

设 c = 2^k × m（m 为奇数）。记 d(n) 为 n 的约数个数。

- 若 k = 0（c 为奇数）：解的个数 = (d(c²) - 1) / 2
- 若 k > 0（c 为偶数）：解的个数 = ((2k - 1) × d(m²) - 1) / 2

可以通过分解 c 计算 d(c²) 和 d(m²)，从而求出解的个数。
