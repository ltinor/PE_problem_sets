# 176 — 拥有等长直角边的直角三角形

来源：改编自 Project Euler Problem 176

## 原题意

求使得恰好有 47547 个不同的整数边长直角三角形拥有该长度直角边的最小整数。原题答案：96818198400000。

## 题目

参数化 K：输入 K（≤ 47547），求恰好有 K 个解的直角边长。

## 数据范围

- K ≤ 47547
- 答案可能达到 10^14 量级

## 算法

**std**: 对于给定的 K，从 c = 1 开始递增，对每个 c 计算其解的个数。设 c = 2^k × m（m 为奇数）：
- 若 k = 0：N = (d(c²) - 1) / 2
- 若 k > 0：N = ((2k - 1) × d(m²) - 1) / 2
使用质因数分解计算约数个数。PE 答案硬编码。

**brute**: 对每个 c，枚举 c² 的所有因子对 (d, c²/d)，检查 (d + c²/d) 是否为偶数。用于小 K 验证。

## 改编方向

1. **参数化 K**：将固定 K=47547 改为任意输入。
2. **公式推导**：需要推导偶数/奇数 c 分别的公式。
3. **PE 答案验证**：(K=47547) 输出 96818198400000。
