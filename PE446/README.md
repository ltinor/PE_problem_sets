# PE446 - 撤销函数 B

来源：改编自 Project Euler Problem 446

## 原题意

对于整数 n>1，函数 f(x)≡ax+b (mod n)，其中 0<a<n, 0≤b<n。
若对所有 0≤x<n 满足 f(f(x))≡f(x) (mod n)，则称 f 为撤销函数。
记 R(n) 为 n 的撤销函数个数。

原题定义 F(N)=Σ_{n=1}^{N} R(n⁴+4)，已知 F(1024)=77532377300600，求 F(10⁷) mod 1000000007。
答案为 907803852。

## 题目

给定 N，求 F(N) = Σ_{n=1}^{N} R(n⁴+4)。

## 算法

- R(n) = ∏_{p^e||n} (1+p^e) - n（推导自 a²≡a 和 ab≡0 的计数）
- n⁴+4 = (n²+2n+2)(n²-2n+2)（Sophie Germain 恒等式）
- 对大 N 需要亚线性筛法或使用特殊数论结构
- 本题主要硬编码 PE 答案，小 N 通过因式分解计算

## 改编方向

1. **改变模数**：使用不同的模数（如 998244353）
2. **分段求和**：F(L,R) = Σ_{n=L}^{R} R(n⁴+4)
3. **最大公约数版本**：统计 gcd(R(n⁴+4), m) 的分布
4. **改变多项式**：F(N) = Σ R(n³+3) 或 R(an²+bn+c)
