# 整数梯子 (Integer Ladders)

来源：改编自 Project Euler Problem 309

## 原题意

两架梯子长度 x 和 y 靠在街道两侧，相交高度 h，街道宽度 w。满足 `1/h = 1/√(x²-w²) + 1/√(y²-w²)`。
求 x < y < 1,000,000 时，(x, y, h) 三元组使得 w 为整数的个数。PE 答案：210139。

## 题目

输入 N，求满足 x < y < N 且 w 为整数的 (x, y, h) 三元组个数。

## 数据范围

$2 \\le N \\le 2 \\times 10^5$。

## 算法

### 方向一：勾股三元组参数化

由 $x^2 = w^2 + a^2$ 知 (w, a, x) 构成勾股三元组，同理 (w, b, y)。w 为两个勾股三元组的公共直角边。枚举所有勾股三元组，按 w 分组，对每组内两两检查 $h = ab/(a+b)$ 是否为整数。

### 方向二：枚举原始勾股三元组

对 m > n > 0，gcd(m,n)=1，m-n 为奇数，生成原始勾股三元组并缩放。

### 时间复杂度

枚举所有勾股三元组 O(N log N)，分组后检查 O(deg²) 但 deg 很小。N=2×10⁵ 约 0.5s。
