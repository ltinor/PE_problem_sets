# PE844 — Convergents of e（e的渐近分数）

来源：改编自 Project Euler Problem 844

## 原题意

欧拉数 $e$ 的连分数展开为：
$$e = [2; 1, 2, 1, 1, 4, 1, 1, 6, 1, 1, 8, 1, \ldots]$$

规律：$a_0=2$，对 $k \geq 1$：$a_{3k-2}=1$, $a_{3k-1}=2k$, $a_{3k}=1$。

渐近分数（收敛子）$p_n/q_n$ 是 $e$ 的最佳有理逼近，通过截断连分数得到。递推公式：
$$p_{-1}=1,\ p_0=a_0;\quad q_{-1}=0,\ q_0=1$$
$$p_n = a_n \cdot p_{n-1} + p_{n-2}$$
$$q_n = a_n \cdot q_{n-1} + q_{n-2}$$

PE 答案：280245879518483。

## 算法

1. **生成连分数系数**：按三元素周期 $[1,2k,1]$ 生成 $e$ 的连分数项。
2. **计算渐近分数**：使用递推公式逐项计算 $p_n, q_n$（使用 `__int128` 处理大数）。
3. **模运算版本**：对大 $n$ 使用模 $M$ 计算和求值。
4. **误差分析**：$|e - p_n/q_n| \sim 1/q_n^2$，渐近分数是最佳有理逼近。
