# 空椅子

## 题目描述

在一间屋子中，围绕圆桌摆了 N 把椅子。

骑士们依次进入屋子，并且**随机**选择一把合适的空椅子坐下。为了保证手肘不相互撞击，相邻的骑士之间至少要空出一张空椅子。

当剩下的空椅子都不能坐时（即每张空椅子都至少与一名骑士相邻），游戏结束。此时可以计算出空椅子的比例 C = (空椅子数) / N。

记 E(N) 为 C 的**期望值**（假设骑士选择椅子的每一步都是均匀随机的）。

可以验证：
- E(4) = 1/2
- E(6) = 5/9 ≈ 0.555555555556

给定 N，求 E(N)，保留 12 位小数。

---

## 输入格式

一个整数 N (4 ≤ N ≤ 10000)。

---

## 输出格式

一个小数，保留 12 位小数，表示 E(N)。

---

## 样例

### 输入
```
4
```

### 输出
```
0.500000000000
```

### 输入
```
6
```

### 输出
```
0.555555555556
```

---

## 数据范围

- 对于 30% 数据：N ≤ 10
- 对于 60% 数据：N ≤ 100
- 对于 100% 数据：N ≤ 10000
