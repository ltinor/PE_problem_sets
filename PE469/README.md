# PE469 - 空椅子 / 白骑士 (Empty chairs)

来源：改编自 Project Euler Problem 469

## 原题意

N 把椅子围成一圈。骑士依次进入，随机选择一把可用的空椅子坐下。
相邻骑士之间至少空出一张椅子（保证手肘空间）。

当没有合适的椅子可坐时，统计空椅子的比例 C。E(N) 为 C 的期望值。

验证：E(4)=1/2, E(6)=5/9。

原题求 E(10^18) ≈ 0.567667992618（14 位小数）。

## 题目

给定 N，求 E(N)，保留 12 位小数。

## 算法

- 路径 DP：E_path(L, left_occ, right_occ) = 在长度为 L 的路径上（两端可能有骑士）的期望骑士数
- 椅子可用的条件：两个邻居都不是骑士（被"保留空位"可以）
- 放置骑士后，路径分裂为两个子路径，递归计算期望
- 循环：E_cycle(N) = 1 + E_path(N-3, false, false)
- E(N) = 1 - E_cycle(N) / N
- 大 N 时收敛于约 0.567667992618

## 改编方向

1. **不同间距要求**：至少 k 张空椅子
2. **非随机策略**：骑士采取最优策略最小化/最大化空椅子
3. **不同拓扑**：直线排列、网格等
