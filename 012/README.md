# 有很多约数的三角形数

来源：改编自 Project Euler Problem 12

## 原题意

三角形数是通过累加自然数所得到的数。例如，第$7$个三角形数是$1 + 2 + 3 + 4 + 5 + 6 + 7 = 28$。前十个三角形数分别是：

$$1, 3, 6, 10, 15, 21, 28, 36, 45, 55, \ldots $$

$28$是第一个约数数量超过五的三角形数。求第一个约数数量超过五百的三角形数。

原题答案：76576500（第12375个三角形数，有576个约数）。

## 题目

给定一个正整数 $K$，请你求出第一个约数数量超过 $K$ 的三角形数。

## 数据范围

$1 \le K \le 10^3$

## 改编思路

### 方向一：参数化阈值 K（当前方案）
- 做法：将原题固定阈值 500 改为输入参数 $K$（$1 \le K \le 10^3$）
- 优点：保留原题核心数学模型（三角形数 + 约数个数），参数化后适合 OJ 评测，暴力与正解可对拍验证
- 缺点：$K$ 上限受限——$K$ 过大时答案三角形数将超出 64 位整数范围
- 结论：✅ 采用

### 方向二：多组测试数据
- 做法：第一行输入 $T$，随后 $T$ 行每行一个 $K$，对每组输出答案
- 优点：批量验证更方便，符合 OJ 常见格式；可利用 gen_data 生成 10 组不同数据
- 缺点：每组独立计算，无共享预处理空间
- 结论：✅ 采用（通过 gen_data.cpp 生成多测例文件）

### 方向三：扩大 K 上界 + 输出答案 mod M
- 做法：$K \le 10^5$，输出答案对 $M = 10^9+7$ 取模
- 优点：突破 64 位限制，更考验算法优化（需预处理素数）
- 缺点：暴力无法对拍（答案过大），且取模破坏了"求出具体三角形数"的直观性
- 结论：❌ 不采用

### 方向四：逆问题——给定三角形数 $T$，判断其约数个数是否超过 $K$
- 做法：输入 $T$ 和 $K$，输出 YES/NO
- 优点：简化为判定问题，适合低难度入门
- 缺点：完全失去原题"搜索第一个满足条件的三角形数"的核心趣味
- 结论：❌ 不采用

### 方向五：输出最小满足条件的 $n$（三角形数序号）
- 做法：不是输出三角形数本身，而是输出其序号 $n$（即 $T_n$ 的 $n$）
- 优点：轻量变体，验证对三角形数编号的理解
- 缺点：与原题区别太小，无实质变化
- 结论：❌ 不采用

### 方向六：求第 $M$ 个满足约数个数 $>K$ 的三角形数
- 做法：输入 $K$ 和 $M$，输出第 $M$ 个约数个数超过 $K$ 的三角形数
- 优点：增加层次，考验枚举和计数能力
- 缺点：$M$ 稍大就需要搜索很远，偏离"第一个"的趣味
- 结论：❌ 不采用

## 算法

约数个数定理 + 互质分解

对于三角形数 $T_n = n(n+1)/2$，利用 $n$ 与 $n+1$ 互质的性质：
- 若 $n$ 为偶数：$T_n = (n/2) \times (n+1)$，约数个数 $d(T_n) = d(n/2) \times d(n+1)$
- 若 $n$ 为奇数：$T_n = n \times ((n+1)/2)$，约数个数 $d(T_n) = d(n) \times d((n+1)/2)$

时间复杂度：$O(\sqrt{n})$ 求单个数约数，总体枚举到答案为止。对于 $K \le 10^3$，答案三角形数约为 $T_{12000} \approx 7.6\times 10^7$，完全在可行范围内。
