# 满足素数循环单位数性质的合数

## 题目描述

只包含数字 1 的数称为循环单位数。定义 R(k) 为长度为 k 的循环单位数。定义 A(n) 为最小的 k 使得 R(k) 能被 n 整除。

已知对素数 p > 5，p−1 能被 A(p) 整除。然而有少数合数也满足这一性质。

给定整数 K，求前 K 个满足 gcd(n,10)=1 且 (n−1) 能被 A(n) 整除的合数 n 的和。

---

## 输入格式

一行一个整数 K (1 ≤ K ≤ 25)。

---

## 输出格式

一行一个整数，表示前 K 个满足条件的合数之和。

---

## 样例

### 输入

```
5
```

### 输出

```
1985
```

（前 5 个合数：91, 259, 451, 481, 703）

---

## 数据范围

- 1 ≤ K ≤ 25
