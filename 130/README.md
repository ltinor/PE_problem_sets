# 130 — Composites with Prime Repunit Property

来源：改编自 Project Euler Problem 130

## 原题意

求前 25 个满足 gcd(n,10)=1 且 (n−1) 能被 A(n) 整除的合数 n 之和。

原题答案：149253。

## 题目

参数化 K：输入 K (≤ 25)，求前 K 个满足条件的合数之和。

## 数据范围

- K ≤ 25

## 算法

枚举奇数 n（跳过 5 的倍数），判断是否为素数（跳过素数）。对合数 n 计算 A(n)（使用余数递推），检查 (n−1) % A(n) == 0。满足条件则加入结果集，收集到 K 个后求和。

## 改编方向

1. **参数化 K**：将原题固定 K=25 改为输入参数。
2. **小范围版本**：K ≤ 10 可用于对拍验证。
3. **固定答案验证**：K=25 作为测试点，输出 149253。
