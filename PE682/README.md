# PE682 — 5-Smooth Pairs (5光滑数对)

来源：改编自 Project Euler Problem 682

## 原题意

$5$-光滑数（Hamming 数）是指最大质因数不超过 $5$ 的数，即形如 $2^a \cdot 3^b \cdot 5^c$ 的数。

记 $\Omega(a)$ 为 $a$ 的质因数个数（计重数），$s(a)$ 为 $a$ 的质因数之和（计重数）。
例如 $\Omega(300)=5$，$s(300)=2+2+3+5+5=17$。

记 $f(n)$ 为满足 $\Omega(p)=\Omega(q)$ 且 $s(p)+s(q)=n$ 的 Hamming 数对 $(p,q)$ 的个数。
已知 $f(10)=4$（对为 $(4,9),(5,5),(6,6),(9,4)$），$f(10^2)=3629$。
求 $f(10^7) \bmod 1\\ 000\\ 000\\ 007$。

PE 答案：290872710。

## 算法

1. **组合表示**：对于 Hamming 数 $2^a 3^b 5^c$，有 $\Omega = a+b+c$，$s = 2a+3b+5c$。
   记 $g(\Omega, s)$ 为满足 $\Omega, s$ 的 $(a,b,c)$ 三元组个数。

2. **公式**：由 $a = 3\Omega + 2c - s$，$b = s - 2\Omega - 3c$，
   对每个 $c \in [0, \Omega]$ 检查 $a,b \ge 0$ 的条件。
   $g(\Omega,s)$ 可在 $O(1)$ 内计算。

3. **卷积**：$f(n) = \sum_{\Omega} \sum_s g(\Omega, s) \cdot g(\Omega, n-s)$。
   $\Omega$ 的范围为 $[n/10, n/4]$，对每个 $\Omega$ 在 $O(\Omega)$ 时间内完成卷积。

4. **优化**：利用 $g(\Omega,s)$ 的分段线性性质，可进一步优化。
   对于 $n=10^7$ 的完整计算需要高效实现。

## 改编方向

1. 参数化 $n$ 的范围
2. 推广到 $k$-光滑数（$k=7,11$ 等）
3. 考虑 $\Omega(p) \neq \Omega(q)$ 或 $s(p) \cdot s(q)=n$ 等变体
4. 统计满足条件的无序对（$(p,q)$ 与 $(q,p)$ 视为同一对）
