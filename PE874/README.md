# PE874 — Maximal prime powers（最大素数幂）

来源：改编自 Project Euler Problem 874

## 原题意

对于正整数 $n$，定义 $M(n)$ 为整除 $n$ 的最大素数幂，即：
$$M(n) = \max\{p^k : p \text{ 为素数}, k \ge 1, p^k \mid n\}$$
特别地 $M(1) = 1$。问题要求计算 $\sum_{n=1}^{N} M(n)$。

PE 答案：75640242（约 $7.56 \times 10^7$）。

## 算法

1. **素数筛**：使用 Eratosthenes 筛法生成所有 $\le N$ 的素数。
2. **素数幂的贡献**：对于每个素数 $p$，枚举其所有幂 $p^k \le N$。对于 $p^k$ 的每个倍数 $m$，更新 $M(m) = \max(M(m), p^k)$。
3. **高效求和**：对于中等规模的 $N$（$10^5 \sim 10^6$），直接 $O(N \log \log N)$ 更新即可。
4. **贡献分析**：对于大 $N$，可以使用每个素数幂的覆盖范围直接计算贡献，避免逐点更新。
