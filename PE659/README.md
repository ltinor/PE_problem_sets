# PE659 — 最大的素数 (Largest prime)

来源：改编自 Project Euler Problem 659

## 原题意

对于序列 n²+k²，P(k) = 能同时整除某相邻两项的最大素数。

可证 P(k) = 4k²+1 的最大素因子。

求 Σ_{k=1}^{10,000,000} P(k) 的最后 18 位数字。

PE 答案：796144972。

## 算法

### 推导
p 整除 n²+k² 和 (n+1)²+k² ⟺ p|2n+1 且 p|n²+k²
⟹ p | 4k²+1（令 n≡(p−1)/2 mod p）

因此 P(k) = max{素数 p : p | 4k²+1}。

### 筛法
4k²+1 ≤ 4×10^14，√max = 2×10^7。

1. 筛出所有 ≤2×10^7 且 ≡ 1 (mod 4) 的素数
2. 对每个素数 p，解 (2k)² ≡ −1 (mod p) 找到两个 k 的剩余类
3. 对每个剩余类中的 k，从 4k²+1 中除去素因子 p，并更新 P(k) = max(P(k), p)
4. 筛完后剩余的 v_k > 1 即为 >2×10^7 的素因子（必为素数）

复杂度 O(N log log M + π(M))，其中 M = 2×10^7。

## 改编方向

1. 改为求相邻三项的最大公因子
2. 推广到序列 n^m + k^m
3. 求 P(k) 在 k 的不同范围下的统计性质
4. 限制 k 为素数或特殊数列
