# 丢番图倒数 III

## 题目描述

考虑丢番图方程：
1/x + 1/y = 1/n

其中 x, y, n 均为正整数。

对于给定的上界 L，记 F(L) 为满足 x < y ≤ L 的所有解 (x, y, n) 的数目。

例如：
- F(15) = 4（解为：(2,3,6), (3,4,12), (4,6,12), (6,10,15)）
- F(1000) = 1069

给定 L，求 F(L)。

---

## 输入格式

一个整数 L (2 ≤ L ≤ 10^12)。

---

## 输出格式

一个整数，表示 F(L)。

---

## 样例

### 输入
```
15
```

### 输出
```
4
```

---

## 数据范围

- 对于 30% 数据：L ≤ 100
- 对于 60% 数据：L ≤ 10^5
- 对于 100% 数据：L ≤ 10^12
