# 点·创世纪

## 题目描述

起初，平面上所有点都是白色的，除了 3 个红点和 2 个蓝点。

每一天，构造所有经过一个红点和一个蓝点的直线；随后，任意两条这样的不同直线相交处的白点变成蓝点。

记 $g(n)$ 为 $n$ 天之后蓝点数量的最大可能值（即取使蓝点数最大的初始位置）。

已知 $g(1)=8$，$g(2)=28$。

给定 $n$，求 $g(n)$。

## 输入格式

一个整数 $n$（$1 \le n \le 4$）。

## 输出格式

一个整数，表示 $g(n)$。

## 样例

### 输入 1

```
1
```

### 输出 1

```
8
```

### 输入 2

```
2
```

### 输出 2

```
28
```

## 数据范围

- $1 \le n \le 4$
- 参考值：$g(1)=8$，$g(2)=28$，$g(3)=183$，$g(4)=1643$

## 说明

原题为 Project Euler Problem 957，要求 $g(16)$。点数随天数呈超指数增长，原规模需刻画无穷远的入射结构等更高阶方法。此处缩数据为 $n \le 4$，可用齐次坐标精确几何模拟直接计算。
