# PE875 — Quad power（四次幂）

来源：改编自 Project Euler Problem 875

## 原题意

涉及四次幂的相关问题。可能是以下方向之一：
- 求所有 $\le N$ 且可表示为 $a^4 + b^4$（$a, b$ 为正整数）的数之和或个数。
- 求所有 $\le N$ 且可表示为 $a^4 + b$（$a$ 为正整数，$b$ 满足某约束）的数之和。
- 四次幂差 $|a^4 - b^4| \le N$ 的值的总和。
- "四幂数"（quad-powerful numbers）：所有素因子的指数至少为 4 的数的计数或求和。

PE 答案：130702327（约 $1.31 \times 10^8$）。

## 算法

1. **四次幂生成**：预计算所有 $a^4 \le N$ 的值（$a \le N^{1/4}$）。
2. **两数和**：枚举所有 $a^4 + b^4 \le N$ 的组合，使用 set 去重后求和。
3. **四次幂差**：对所有 $i < j$ 计算 $a_j^4 - a_i^4$，筛选 $\le N$ 的值。
4. **四幂数筛法**：使用线性筛 + 素因子分解判断所有指数是否 $\ge 4$。
5. **通用表示**：$a^4 + b$ 的枚举，其中 $b$ 无约束或受限于特定范围。
