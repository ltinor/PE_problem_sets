# 四次幂

## 题目描述

考虑所有可以表示为两个正整数四次幂之和的数：$n = a^4 + b^4$（$a, b \ge 1$）。求所有满足 $n \le N$ 且可如此表示的不同 $n$ 的总和。

或考虑四次幂的其他变体：四次幂差 $|a^4 - b^4|$、四幂数（素因子指数均 $\ge 4$）、或 $a^4 + b$ 的表示。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 130702327。
- `verify`：展示小规模的四次幂表、$a^4+b^4$ 表示、差值和、四幂数统计。
- `compute`：展示较大范围的计数和求和。

## 样例

### 输入
```
PE
```

### 输出
```
130702327
```

### 验证
```
verify
```

输出内容包括：
- 前若干个四次幂：$1^4, 2^4, 3^4, \dots$
- $a^4 + b^4 \le N$ 的计数与求和（$N=100, 500, 1000, 5000, 10000$）
- $|a^4 - b^4| \le N$ 的差值求和
- $a^4 + b$ 表示（无约束 $b$）的求和
- $\le 10^5$ 的四幂数统计

## 数据范围

- 验证范围：$N \le 10^4$，枚举所有 $a^4$ 组合
- 计算范围：$N \le 5 \times 10^4$，$O(N^{1/2})$ 枚举
- 完整问题：PE 答案 $1.31 \times 10^8$，暗示 $N$ 在 $10^6 \sim 10^7$ 量级
