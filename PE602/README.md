# PE602 — 头数乘积 (Product of Head Counts)

来源：改编自 Project Euler Problem 602

## 原题意

Alice 和 n 个朋友围坐一圈，用一枚不均匀硬币生成随机数。从 Alice 开始轮流抛硬币。每人记录自己抛出的正面次数。当 Alice 抛出正面时，游戏结束。Alice 将所有朋友的正面次数相乘得到随机数。

硬币抛出反面的概率为 p（正面概率为 1-p）。

定义 e(n, p) 为期望值。对于固定的 n，e(n, p) 总是 p 的多项式。例如 e(3, p) = p³ + 4p² + p。

定义 c(n, k) 为 e(n, p) 中 pᵏ 项的系数。已知 c(100, 40) ≡ 986699437 (mod 10⁹+7)。

求 c(10⁷, 4×10⁶) mod (10⁹+7)。

PE 答案：269496760（取模 10⁹+7）。

## 算法

设 T 为 Alice 抛出正面前的完整轮数。T ~ Geometric(1-p)：P(T=t) = pᵗ(1-p)，t ≥ 0。

在每轮中，每个朋友独立地以概率 1-p 抛出正面。给定 T=t，朋友 j 的正面数 H_j ~ Binomial(t, 1-p)。E[H_j|T=t] = t(1-p)。

由于 H_j 条件独立于 T：E[∏H_j|T=t] = (t(1-p))ⁿ。

因此：
e(n, p) = Σ_{t≥0} pᵗ(1-p)(t(1-p))ⁿ = (1-p)ⁿ⁺¹ Σ_{t≥0} tⁿ pᵗ

利用生成函数恒等式：
Σ_{t≥0} tⁿ pᵗ = p·A_n(p) / (1-p)ⁿ⁺¹

其中 A_n(p) = Σ_{k=0}^{n-1} A(n,k) pᵏ 为欧拉多项式，A(n,k) 为欧拉数。

故 e(n, p) = p·A_n(p)，c(n, k) = A(n, k-1)（k ≥ 1）。

欧拉数的显式公式：
A(n, m) = Σ_{j=0}^{m} (-1)ʲ · C(n+1, j) · (m+1-j)ⁿ

计算 c(10⁷, 4×10⁶) = A(10⁷, 3999999)，需 O(10⁷) 预处理阶乘 + O(4×10⁶) 项求和。每项使用快速幂 O(log n)，总复杂度可行。

## 改编方向

1. 改变概率分布（非均匀硬币、非独立抛掷）。
2. 改变随机数的生成方式（如求和代替求积）。
3. 分析 e(n, p) 的渐近性质。
4. 推广到一般排列顺序（非循环轮流）。
