# 不同的幂

## 题目描述

考虑所有形如 $a^b$ 的整数幂，其中 $2 \le a \le A_{\max}$，$2 \le b \le B_{\max}$。这些幂中有多少个不同的值？

例如，当 $A_{\max}=5, B_{\max}=5$ 时：
- $2^2=4, 2^3=8, 2^4=16, 2^5=32$
- $3^2=9, 3^3=27, 3^4=81, 3^5=243$
- $4^2=16$（与 $2^4$ 重复）
- $4^3=64, 4^4=256, 4^5=1024$
- $5^2=25, 5^3=125, 5^4=625, 5^5=3125$

共有 $15$ 个不同的值。

---

## 输入格式

第一行一个整数 $T$，表示测试数据组数。  
接下来 $T$ 行，每行两个整数 $A_{\max}, B_{\max}$，用空格分隔。

---

## 输出格式

对于每组数据，输出一行一个整数，表示不同幂值的个数。

---

## 样例

### 输入
```
1
5 5
```

### 输出
```
15
```

---

## 数据范围

- $1 \le T \le 10$
- $2 \le A_{\max}, B_{\max} \le 100$
