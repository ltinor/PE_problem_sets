# PE029 — 不同的幂

来源：改编自 Project Euler Problem 29

## 原题意

考虑所有 $a^b$，其中 $2 \le a \le 100$，$2 \le b \le 100$。这些幂中有多少个不同的值？

## 题目

给定两个整数 $A_{\max}$ 和 $B_{\max}$，求所有 $a^b$（$2 \le a \le A_{\max}$，$2 \le b \le B_{\max}$）中去重后有多少个不同的值。

## 数据范围

- $A_{\max}, B_{\max} \le 100$
- 多组测试数据

## 算法

- **std**：对每个底数 $a$ 进行质因数分解，对于指数 $b$，将质因数指数乘以 $b$ 得到 $a^b$ 的质因数分解形式。将其转化为规范化的字符串 key（如 `"2^4,3^2"` 表示 $2^4 \cdot 3^2$），存入 `set<string>` 去重。时间复杂度 $O(A_{\max} \cdot B_{\max} \cdot \log A_{\max})$。
- **brute**：使用大整数乘法直接计算 $a^b$ 的字符串表示，存入 `set<string>` 去重。仅适用于小范围（最大 $100^{100}$ 约有 200 位十进制数，字符串表示仍可管理）。
