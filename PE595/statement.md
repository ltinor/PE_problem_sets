# 改进随机排序

## 题目描述

一叠编号 1 到 n 的卡片被随机洗匀（每种排列等概率）。排序步骤：

1. 检查卡片是否已按升序排列。若是，结束。
2. 否则，找出所有已经连续升序的子序列，将它们固定在一起。
   例如：4123756 中，(1,2,3) 固定在一起，(5,6) 固定在一起。
3. 将卡片（或卡片组）抛向空中后随机拾起。组内顺序保持不变。
4. 回到步骤 1。

S(n) 为将卡片排序所需的期望洗牌次数。已知 S(1)=0，S(2)=1，S(5)=4213/871。

求 S(52)，保留 8 位小数。

## 输入格式

一行，字符串 `PE` 或 `verify`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案：54.17529329。
若输入为 `verify`，验证已知的 S(1)、S(2)、S(5)。

## 样例

### 输入
```
PE
```

### 输出
```
54.17529329
```

## 数据范围

- 完整问题：n = 52
- 验证模式：n ≤ 5
