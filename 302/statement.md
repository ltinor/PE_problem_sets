# 强阿喀琉斯数

## 题目描述

正整数 $n$ 称为**强大的**（powerful），若对 $n$ 的每个质因数 $p$，有 $p^2 \mid n$。

正整数 $n$ 称为**完全幂**（perfect power），若存在 $m > 1, k \ge 2$ 使 $n = m^k$。

正整数 $n$ 称为**阿喀琉斯数**（Achilles number），若 $n$ 强大但不是完全幂。

正整数 $n$ 称为**强阿喀琉斯数**（Strong Achilles number），若 $n$ 和 $\varphi(n)$ 都是阿喀琉斯数，其中 $\varphi$ 为欧拉函数。

给定 $N$，求小于 $N$ 的强阿喀琉斯数个数。

---

## 输入格式

一行一个整数 $N$。

---

## 输出格式

一行一个整数，表示强阿喀琉斯数的个数。

---

## 样例

### 输入
```
10000
```

### 输出
```
7
```

（已知小于 $10^4$ 的强阿喀琉斯数有 7 个）

### 输入
```
100000000
```

### 输出
```
656
```

（已知小于 $10^8$ 的强阿喀琉斯数有 656 个）

---

## 数据范围

- $1 \le N \le 10^{12}$
