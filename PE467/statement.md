# 超级整数

## 题目描述

整数 s 被称为另一个整数 n 的**超级整数**，当且仅当 n 的数字串是 s 的数字串的子序列（即可以从 s 中删除一些数字得到 n）。

例如：2718281828 是 18828 的超级整数，而 314159 不是 151 的超级整数。

记 p(n) 为第 n 个质数，c(n) 为第 n 个合数。例如 p(1)=2, p(10)=29, c(1)=4, c(10)=18。

记数字根 dr(x) = 1 + (x-1) mod 9（即各位数字之和反复进行直到一位数）。

记 P^D 为 {p(i)} 的数字根序列，C^D 为 {c(i)} 的数字根序列：
- P^D = {2, 3, 5, 7, 2, 4, 8, 1, 5, 2, ...}
- C^D = {4, 6, 8, 9, 1, 3, 5, 6, 7, 9, ...}

记 P_n 为 P^D 前 n 项连接成的整数，C_n 同理：
- P_10 = 2357248152
- C_10 = 4689135679

记 f(n) 为 P_n 和 C_n 的**最小公共超级整数**。

例如：f(10) = 2357246891352679。

给定 n，求 f(n)，若 n ≤ 10 请输出完整整数，否则输出 f(n) mod 1,000,000,007。

---

## 输入格式

一个整数 n (1 ≤ n ≤ 500)。

---

## 输出格式

若 n ≤ 10，输出完整整数；否则输出 f(n) mod 1,000,000,007。

---

## 样例

### 输入
```
10
```

### 输出
```
2357246891352679
```

### 输入
```
100
```

### 输出
```
771661825
```

---

## 数据范围

- 对于 30% 数据：n ≤ 10
- 对于 60% 数据：n ≤ 100
- 对于 100% 数据：n ≤ 500
