# PE808 — Reversible Prime Squares（可逆素数平方）

来源：改编自 Project Euler Problem 808

## 原题意

若素数 $p$ 满足以下条件，称 $p$ 为**可逆素数平方**：

- $p^2$ 的十进制反转也是一个完全平方数，且平方根 $q$ 也是一个素数；
- $p \neq q$（排除回文平方的情况）。

例如：$13^2 = 169$，反转得 $961 = 31^2$，且 $13$ 和 $31$ 均为素数，因此 $13$ 和 $31$ 都是可逆素数平方。

求前 50 个可逆素数平方对应的素数 $p$ 之和。

PE 答案：380750427699465。

## 算法

1. **枚举素数**：从小到大生成素数 $p$。
2. **反转检查**：计算 $p^2$，反转后判断是否为完全平方数。
3. **素性验证**：若反转平方数的平方根 $q$ 也是素数且 $p \neq q$，则 $p$ 满足条件。
4. **大数处理**：$p$ 可达 $10^7$ 量级，$p^2$ 和反转值可能超过 64 位整数范围，需使用大整数或 $\_\_int128$。
