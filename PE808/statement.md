# 可逆素数平方（Reversible Prime Squares）

## 题目描述

对于一个素数 $p$，考虑它的平方 $p^2$。将 $p^2$ 在十进制下的数字反转，得到 $R(p^2)$。如果存在另一个素数 $q$（$q \neq p$）使得 $R(p^2) = q^2$，则称 $p$ 和 $q$ 为一对**可逆素数平方**。

例如：
- $13^2 = 169$，$R(169) = 961 = 31^2$，$13$ 和 $31$ 均是素数。
- $17^2 = 289$，$R(289) = 982$，$982$ 不是完全平方数，故 $17$ 不满足。

请找出所有可逆素数平方对，并按 $p$ 从小到大排序，计算前 50 个 $p$ 的总和。

## 输入格式

无输入（固定参数问题）。

## 输出格式

输出一个整数，表示前 50 个可逆素数平方对应的较小素数之和。

## 样例

（无样例输入输出，直接计算并输出最终答案。）
