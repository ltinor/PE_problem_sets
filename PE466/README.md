# PE466 - 乘法表中的不同项 (Distinct terms in a multiplication table)

来源：改编自 Project Euler Problem 466

## 原题意

P(m,n) 是 m×n 乘法表中不同项的个数。

例如，3×4 乘法表中有 8 个不同项 {1,2,3,4,6,8,9,12}，因此 P(3,4) = 8。

验证：P(64,64) = 1263, P(12,345) = 1998, P(32,10^15) = 13826382602124302。

原题求 P(64,10^16) = 258381958195474745。

## 题目

给定 m 和 n，求 P(m,n)。

## 算法

- 容斥原理：P(m,n) = Σ_{∅≠T⊆[1,m]} (-1)^{|T|+1} ⌊n·min(T)/lcm(T)⌋
- 使用 DFS 枚举子集，剪枝条件：lcm(T) > n·min(T)
- 从大到小枚举元素以提高剪枝效率
- 对于较小的 m（≤25），可直接使用容斥 DFS
- 对于较大的 m，分区间统计缺失数

## 改编方向

1. **固定 m 求通项**：固定 m=64，求 P(64,n) 对任意 n 的公式
2. **方表推广**：P(n,n) 的渐近行为
3. **高维推广**：P(m,n,k) 三维乘法表的不同项数
