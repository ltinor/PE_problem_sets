# 图案圆柱

## 题目描述

一根无限长圆柱体的侧面被长方形贴纸完全贴满，这些贴纸除了颜色不同之外没有区别，相互间也没有重叠。贴纸与圆柱体对齐，有两条边平行于圆柱体的轴。

沿圆柱体轴向，每 a 张贴纸颜色模式重复一次（a > 0）。记 b 为环绕圆柱一周的贴纸数目。

定义 f(m,a,b) 为恰好使用 m 种不同颜色的颜色模式数目。经过平移、旋转、翻转（或组合）后能重叠的模式视为相同。

已知：
- f(2,2,3) = 11
- f(3,2,3) = 56
- f(2,3,4) = 156
- f(8,13,21) ≡ 49718354 (mod 1000000007)
- f(13,144,233) ≡ 907081451 (mod 1000000007)

求 Σ_{i=4}^{40} f(i, F_{i-1}, F_i) mod 1000000007，其中 F_i 是 Fibonacci 数列（F_0=0, F_1=1）。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 448233151。
- `verify`：验证已知小样例。
- `compute`：重新计算完整答案（较慢）。

## 样例

### 输入
```
PE
```

### 输出
```
448233151
```

## 数据范围

- 完整问题：i = 4..40，a = F_{i-1}，b = F_i，F_{40} ≈ 1.02×10^8
- 模数：1000000007
