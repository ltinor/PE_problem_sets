# PE684 — Inverse Digit Sum (数字和的逆函数)

来源：改编自 Project Euler Problem 684

## 原题意

记 $s(n)$ 为最小的各位数字之和等于 $n$ 的数。例如 $s(10)=19$。
记 $S(k) = \sum_{n=1}^{k} s(n)$。已知 $S(20)=1074$。

记 $f_i$ 为斐波那契数列：$f_0=0, f_1=1$，$f_i = f_{i-2} + f_{i-1}$（$i \ge 2$）。

求 $\sum_{i=2}^{90} S(f_i) \bmod 1\\ 000\\ 000\\ 007$。

PE 答案：922058210。

## 算法

1. **$s(n)$ 的封闭形式**：
   - 若 $n = 9q + r$，$0 \le r < 9$，$r > 0$：$s(n) = (r+1) \cdot 10^q - 1$
   - 若 $r = 0$：$s(n) = 10^q - 1$

2. **$S(k)$ 的封闭形式**：令 $k = 9Q + r$，$0 \le r < 9$：
   - 若 $r = 0$：$S(k) = 6 \cdot 10^Q - 6 - 9Q$
   - 若 $r > 0$：$S(k) = 10^Q \cdot \left(6 + \frac{r^2+3r}{2}\right) - 6 - 9Q - r$

3. **模运算**：$f_{90} \approx 2.88 \times 10^{18}$，需用 64 位整数存储。
   计算 $10^Q \bmod (10^9+7)$ 用快速幂，注意 $Q$ 可达 $\sim 3 \times 10^{17}$。

4. **复杂度**：对每个 $f_i$ 在 $O(\log f_i)$ 时间内计算 $S(f_i) \bmod M$，总共 89 项。

## 改编方向

1. 参数化 $i$ 的上限（如 $i=2$ 到 $100$）
2. 使用其他数列（如卢卡斯数列、三角数等）替代斐波那契
3. 计算 $\sum S(f_i)$ 的不同模数
4. 考虑 $s(n)$ 的变体（如次小的数字和为 $n$ 的数）
