## 原题描述

原题及更多讨论见 [https://projecteuler.net/problem=403](https://projecteuler.net/problem=403)。

对于正整数a和b，我们用D(a, b)表示被双曲线y = x<sup>2</sup>和直线y = a·x + b包围的区域：
D(a, b) = { (x, y) | x<sup>2</sup> ≤ y ≤ a·x + b }.

定义L(a, b)为D(a, b)内的格点数目。
例如，L(1, 2) = 8，以及L(2, -1) = 1。

若整数对(a, b)满足D(a, b)的面积是有理数，且|a|,|b| ≤ N，我们定义所有相应的L(a, b)的和为S(N)。
我们可以验证S(5) = 344以及S(100) = 26709528。

求S(10<sup>12</sup>)。将你的答案模10<sup>8</sup>取余。
