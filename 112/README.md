# 112 — Bouncy Numbers

来源：改编自 Project Euler Problem 112

## 原题意

定义"弹跳数"：既不是上升数（每位 ≥ 左边）也不是下降数（每位 ≤ 左边）的正整数。求弹跳数比例首次恰好达到 99% 的最小数。答案：1587000。

## 题目

输入整数 P（0 < P < 100），求弹跳数比例首次达到 ≥P% 的最小数 n（即 n 个数中弹跳数比例 ≥ P%）。

## 数据范围

- 0 < P < 100

## 算法

从 n=1 开始逐数检查是否为弹跳数（转字符串比较相邻字符单调性），累计弹跳计数。当 bouncy/n × 100 ≥ P 时输出 n。时间复杂度 O(n)，n 上限约 1.6×10^6（P=99）。

## 改编方向与取舍

### 改编方向
1. **参数化 P** → 支持任意 0<P<100（本题采用）
2. **返回第 K 个弹跳数** → 输入 K，输出第 K 个弹跳数
3. **区间查询** → 输入 L,R，输出 [L,R] 内的弹跳数个数
4. **弹跳数密度函数** → 输出弹跳数比例随 n 的变化曲线数据

### 取舍理由
- 选择参数化 P：最自然，保留原题核心
- 保持线性枚举：算法简单，原题规模小，无需更复杂方法
- 不选择密度函数：需要大量输出，不适合 OJ 格式
