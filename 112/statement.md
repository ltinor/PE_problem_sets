# 弹跳数

## 题目描述

从左往右，如果每一位数字都大于等于其左边的数字，这样的数被称为**上升数**（如 134468）。
如果每一位数字都大于等于其右边的数字，被称为**下降数**（如 66420）。
如果一个正整数既不是上升数也不是下降数，称之为**弹跳数**（如 155349）。

给定百分比 P，求使得弹跳数的比例首次达到 ≥P% 的最小数 n（即在前 n 个正整数中，弹跳数的比例 ≥P%）。

---

## 输入格式

一行一个整数 P（0 < P < 100）。

---

## 输出格式

一行一个整数 n。

---

## 样例

### 输入
```
50
```

### 输出
```
538
```

### 输入
```
90
```

### 输出
```
21780
```

### 输入
```
99
```

### 输出
```
1587000
```

---

## 数据范围

- 0 < P < 100
