# PE351 - 六边形果园 (Hexagonal orchards)

来源：改编自 Project Euler Problem 351

## 原题意

n 阶六边形果园是在边长为 n 的正六边形中的三角形网格。站在中间向外看，某些点会被更近的点挡住。记 H(n) 为被挡住的点的数目。
已知 H(5)=30, H(10)=138, H(1000)=1177848。求 H(100,000,000)。原题答案：11762187201804552。

## 题目

给定整数 N，求 H(N) —— N 阶六边形果园中从中心看去被挡住的点的数量。

## 算法

六边形果园的三角形网格可以用二维坐标表示。从中心可见的点对应 gcd(x, y)=1 的坐标。总点数减去可见点数即可。

H(n) = 6 × (n(n+1)/2 - Σ_{k=1}^{n} φ(k))

使用线性筛法计算 φ(k)（1 到 N），复杂度 O(N)。

## 改编方向

1. **三维扩展**：推广到三维空间中的正八面体网格
2. **多种中心**：求从多个不同观察点看去的被挡点数
3. **部分可见**：引入半透明遮挡，部分可见性
4. **不规则网格**：推广到一般三角形网格
