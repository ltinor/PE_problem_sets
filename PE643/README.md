# PE643 — 朋友与字符串 (Friends and Strings)

来源：改编自 Project Euler Problem 643

## 原题意

两个正整数 a, b 是"朋友"当且仅当 φ(a)/a = φ(b)/b。
等价地，它们具有完全相同的不重复质因子集合（相同的 radical）。

定义 F(N) 为 1 ≤ a < b ≤ N 中朋友对的数量。求 F(10¹¹) mod 1000000007。

PE 答案：968274181。

## 算法

### 核心观察

φ(n)/n = Π_{p|n} (1 - 1/p)

该值仅取决于 n 的 radical（不重复质因子的乘积）。因此：

- 所有具有相同 radical r 的数构成一个朋友群
- 群的大小 = #{n ≤ N : rad(n) = r}

### 分组计数

对于每个 radical r ≤ N，令 g(r) 为 radical 等于 r 的数 ≤ N 的个数。

则 F(N) = Σ_{r} C(g(r), 2)（每个群内部任意两数都是朋友）

### 实现步骤

1. 筛出所有质数 ≤ N
2. 对每个 n ≤ N 计算其 radical
3. 将数按 radical 分组
4. 对每组大小为 s 的组，贡献 C(s, 2) 对

### 大规模优化

对于 N = 10¹¹，需要利用 radical 的结构特性：

- 大部分数的 radical 较小
- 可以使用递归枚举的方式生成所有具有相同 radical 的数
- 对于每个 radical，用 DFS 枚举其光滑数倍数

## 改编方向

1. 研究"朋友度"——两数共享质因子的比例
2. 定义不同等价关系（如 σ(n)/n = σ(m)/m）
3. 分析朋友群大小的分布统计
4. 扩展到三数或更多数的"朋友圈"
