# PE618 — 给定质因数和的整数 (Numbers with a given prime factor sum)

来源：改编自 Project Euler Problem 618

## 原题意

记 $S(k)$ 为所有质因数和（包括重复）为 $k$ 的整数 $n$ 的和。

例如：$S(1)=0$，$S(2)=2$，$S(3)=3$，$S(5)=5+6=11$，$S(8)=15+16+18=49$。

斐波那契数列：$F_1=1$，$F_2=1$，$F_3=2$，$F_4=3$，$F_5=5$，$\ldots$

求 $\sum_{k=2}^{24} S(F_k)$ 的最后九位数字。

PE 答案：634212216。

## 算法

这是一个 DP/背包问题。对于每个目标和 $k$，需要找到所有质因数之和等于 $k$ 的数。

定义 $\text{dp}[s]$ 为所有质因数之和等于 $s$ 的数的总和。按标准硬币找零方式逐个处理质数：

```
dp[0] = 1 （空积 = 1）
对于每个质数 p：
  对于 s = p 到 max_k：
    dp[s] += p * dp[s-p]
```

这按质数迭代顺序恰好计数每个多重集一次。

最大需要的 $k$ 是 $F_{24} = 46368$。
小于等于 46368 的质数约有 4800 个。
总操作数：$\approx 4800 \times 46368 \approx 2.2 \times 10^8$，在 C++ 中可行。

使用模 $10^9$（只需求最后九位数字）。

注意：S(k) 中的数字 $n$ 可能天文数字般大（例如全部用 2 分解 $F_{24}/2 \approx 23184$ 个 2，得到 $2^{23184}$），但只需其和对 $10^9$ 取模。
