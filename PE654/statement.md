# 相邻约束

## 题目描述

记 T(m,n) 为任意相邻元素之和 ≤ n 的所有 m 元正整数组的数目。

例如，T(3,4) = 8，这 8 个 4 元组是：
(1,1,1,1), (1,1,1,2), (1,1,2,1), (1,2,1,1),
(1,2,1,2), (2,1,1,1), (2,1,1,2), (2,1,2,1)

已知：
- T(5,5) = 246
- T(10, 10²) ≡ 862820094 (mod 1000000007)
- T(10², 10) ≡ 782136797 (mod 1000000007)

求 T(5000, 10¹²) mod 1000000007。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 815868280。
- `verify`：验证已知小样例。
- `compute`：计算 T(m,n)（仅适用于小规模 n）。

## 样例

### 输入
```
PE
```

### 输出
```
815868280
```

## 数据范围

- 完整问题：m = 5000, n = 10¹²
- 模数：1000000007
