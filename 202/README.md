# 202 — Laserbeam

来源：改编自 Project Euler Problem 202

## 原题意

三面镜子围成正三角形，激光从顶点 C 射入，经过 b 次反射后从同一顶点射出。求路径数。b=12017639147，答案：1209002624。

## 题目

参数化 b：输入 b（反射次数），求路径数。

## 数据范围

- b ≤ 1.2×10¹⁰

## 算法

**std**: 将三角形展开为六边形平铺，激光变为直线。路径对应整数对 (a, n-a)，其中 n = (b+3)/2，a 满足 gcd(a,n)=1 且 a%3≠0。使用 φ(n) 公式，根据 n%3 调整。

**brute**: 直接枚举 a=1..n-1，检查 gcd 和模 3 条件。适用于 n ≤ 10⁵。

## 改编方向

1. **参数化 b**：将原题固定 b=12017639147 改为输入参数。
2. **边界处理**：b 为偶数时无解（(b+3) 必须为偶数），输出 0。
3. **公式推导**：利用 φ 函数和模 3 分布，避免 O(n) 枚举。
