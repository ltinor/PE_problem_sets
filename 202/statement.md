# 激光束

## 题目描述

三面镜子围成一个正三角形，反射面朝内。三角形的顶点处各有一个无穷小的间隙，可供激光束通过。

记三个顶点为 A、B、C。一束激光从顶点 C 射入，在三角形内部经过若干次反射后，从同一个顶点 C 射出。

给定反射次数 b，求满足条件的激光路径总数。

已知：
- b=11 时，有 2 条路径
- b=1000001 时，有 80840 条路径

---

## 输入格式

一行一个整数 b (1 ≤ b ≤ 1.2×10¹⁰)，表示反射次数。

---

## 输出格式

一行一个整数，表示路径总数。

---

## 样例

### 输入

```
11
```

### 输出

```
2
```

### 输入

```
1000001
```

### 输出

```
80840
```

### 输入

```
12017639147
```

### 输出

```
1209002624
```

---

## 数据范围

- 1 ≤ b ≤ 1.2×10¹⁰
