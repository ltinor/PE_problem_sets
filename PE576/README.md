# PE576 - 被激怒的司机 (Irritated Drivers)

来源：改编自 Project Euler Problem 576

## 原题意

圆形跑道上有等间距标记。两名跑步者从起点出发。A 匀速前进，B 随机游走（每步 ±1，等概率）。每当两人位于同一位置时产生一次"激怒事件"。求一段时间内的期望激怒事件总数。

PE 答案：398149376813293。

## 算法

问题本质是计算圆周上随机游走与确定性运动的相遇期望。可通过概率转移矩阵或生成函数分析。对于大参数，使用数论方法化简期望值的闭合形式。

## 改编方向

1. 改变 B 的随机游走规则（如非均匀步长）
2. 考虑多个跑步者的交互激怒模型
3. 分析期望值的渐近行为与参数的数论性质
