# 三角披萨

## 题目描述

在一个圆形披萨的圆周上随机放置 $M$ 个点，连接所有点对之间的弦。这些弦将披萨分割成若干区域。

定义"三角形区域"为由弦和/或弧界定的三角形。求当 $M$ 个点随机放置时，三角形区域的总数（或期望值）。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 681813395。
- `verify`：验证小规模 $M$ 值的区域计数和三角形计数。
- `compute`：计算大规模值的不同公式。

## 样例

### 输入
```
PE
```

### 输出
```
681813395
```

### 小规模验证
```
verify
```

对于 $M=3$ 个点，连接三条弦形成 1 个三角区域。
对于 $M=4$ 个点，所有弦交叉形成若干三角区域和其他形状。

## 数据范围

- 验证范围：$M \le 12$（可完全枚举或直接计算）
- 完整问题：$M$ 由答案反推确定
