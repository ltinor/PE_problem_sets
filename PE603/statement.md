# 素数拼接的子串和

## 题目描述

定义 S(n) 为整数 n 的所有连续子串之和（同值子串重复计算）。
定义 P(n) 为前 n 个素数拼接成的整数。
定义 C(n, k) 为 k 份 P(n) 拼接成的整数。

已知：S(2024) = 2304，P(7) = 2357111317。

求 S(C(10⁶, 10¹²)) mod (10⁹+7)。

## 输入格式

一行，字符串 `PE` 或 `verify`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案：879476477。
若输入为 `verify`，验证 S(2024) 和 S(P(7)) 的值。

## 样例

### 输入
```
PE
```

### 输出
```
879476477
```

## 数据范围

- 完整问题：n = 10⁶，k = 10¹²
- P(10⁶) 约 7×10⁶ 位数字，C(10⁶, 10¹²) 约 7×10¹⁸ 位
- 所有计算取模 10⁹+7
