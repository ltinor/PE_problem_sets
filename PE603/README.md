# PE603 — 子串和 (Substring sums of prime concatenations)

来源：改编自 Project Euler Problem 603

## 原题意

定义 S(n) 为整数 n 的所有连续子串之和（相同子串重复计算）。
例如 S(2024) = 2+0+2+4+20+02+24+202+024+2024 = 2304。

定义 P(n) 为前 n 个素数拼接而成的整数。例如 P(7) = 2357111317。

定义 C(n, k) 为 k 份 P(n) 拼接而成的整数。例如 C(7, 3) = 235711131723571113172357111317。

求 S(C(10⁶, 10¹²)) mod (10⁹+7)。

PE 答案：879476477。

## 算法

设数字串 D 的长度为 L，D_i 为第 i 位数字（1-索引）。子串 D[i..j] 的数值为 Σ_{t=i}^{j} D_t · 10^{j-t}。

数字 D_t 在所有包含它的子串中的贡献总和为：
contrib(t) = D_t · t · (10^{L-t+1} - 1) / 9

因此 S(D) = Σ_{t=1}^{L} D_t · t · (10^{L-t+1} - 1) · inv(9) mod MOD。

对于 C(n, k) = B 重复 k 次（B = P(n)，长度 L₀）：
总长度 L = k·L₀。位置分解为块 p（0..k-1）和块内偏移 t（1..L₀）。

S(C(n,k)) = Σ_{p=0}^{k-1} Σ_{t=1}^{L₀} D_t · (p·L₀ + t) · (10^{k·L₀ - (p·L₀+t) + 1} - 1) · inv(9)

展开后为关于 10^{L₀} 的等比数列求和，可用模运算高效计算。关键使用 10^{L₀} mod MOD 和 inv(9) mod MOD。

实际计算时，需先生成前 10⁶ 个素数并拼接为数字串（约 7×10⁶ 位），然后应用上述公式。

## 改编方向

1. 改变底数（如用 2 进制或其他进制）。
2. 拼接其他序列（斐波那契数、平方数等）。
3. 求不同子串（去重）之和。
4. 固定子串长度范围的和。
