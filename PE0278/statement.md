# 半素数线性组合

## 题目描述

给定整数 $1 < a_1 < a_2 < \dots < a_n$，考虑其线性组合：

$$q_1 a_1 + q_2 a_2 + \dots + q_n a_n = b$$

其中 $q_k \ge 0$ 均为整数。记 $f(a_1, \dots, a_n)$ 为**不能**被表示的最大 $b$ 值（Frobenius 数）。

例如：$f(5, 7) = 23$，$f(6, 10, 15) = 29$，$f(14, 22, 77) = 195$。

给定上界 $B$，对于所有素数 $p < q < r < B$，求：

$$\sum_{p < q < r < B} f(p\cdot q,\; p\cdot r,\; q\cdot r)$$

---

## 输入格式

一行一个整数 $B$。

---

## 输出格式

一行一个整数，表示答案。

---

## 样例

### 输入
```
8
```

### 输出
```
292
```

（$p<q<r<8$ 的素数三元组共 4 个，$f$ 值之和为 $29+43+81+139=292$）

---

## 数据范围

- $5 \le B \le 5000$
