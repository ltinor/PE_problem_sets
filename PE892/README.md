# PE892 — Zebra Irrationals（斑马无理数）

来源：改编自 Project Euler Problem 892

## 原题意

"斑马数"（Zebra numbers）是指十进制数字按奇偶交替排列的数。例如：1212（奇偶奇偶）、1030（奇偶奇偶）都是斑马数。

"斑马无理数"进一步指无限不循环的斑马数字序列，或具有斑马数字模式的连分数。

问题可能涉及：统计斑马数的个数、求和、或研究斑马连分数的收敛性质。

## 算法

1. **组合计数**：
   - $d$ 位斑马数的个数 = $9 \cdot 5^{d-1}$（$d \geq 1$）
   - 首位：奇数（1,3,5,7,9）或偶数（2,4,6,8）
   - 后续每位：5 种选择（与上一位奇偶相反）

2. **数位 DP**：
   - 对于给定上界 $N$，用 DP 统计不超过 $N$ 的斑马数
   - 状态：(位置, 上一位奇偶性, 是否受限)

3. **求和**：
   - 利用每位数字贡献的对称性
   - 奇偶位置分别有 5 种选择，数字期望值不同
