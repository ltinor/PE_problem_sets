# 首位排序 II

## 题目描述

使用与"首位排序 I"相同的算法。

将 {1, 2, ..., n} 的所有排列按字典序排列，给每个排列 P 指定一个从 1 到 n! 的索引 I_n(P)（即字典序位置）。

对于恰好需要 k 次"移至首位"操作才能排序完成的排列，记 Q(n, k) 为这些排列中最小的 I_n(P)（即字典序最早出现的那个）。若不存在满足 F(P) = k 的排列，则 Q(n, k) 未定义。

记 R(k) = min{Q(n, k)}，即遍历所有使 Q(n, k) 有定义的 n，取 Q(n, k) 的最小值。

给定 k，求 R(k)。

## 输入格式

一行，一个整数 k，或字符串 `PE`。

## 输出格式

一个整数，表示 R(k)。若不存在任何排列恰好需要 k 次操作，输出 -1。

## 样例

### 输入
```
7
```

### 输出
```
19
```

解释：对于 n=4，需要恰好 7 次操作的排列的字典序最小位置是 19（第 19 个排列 {4, 1, 2, 3}）。

## 数据范围

- 对于 30% 数据：k ≤ 20
- 对于 60% 数据：k ≤ 500
- 对于 100% 数据：k ≤ 10⁵
