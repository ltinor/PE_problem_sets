# 整数角度四边形

## 题目描述

ABCD 是一个凸四边形，对角线为 AC 和 BD。在四边形的每个顶点，对角线和相邻的两条边各构成一个角，总共构成八个这样的角。

当一个四边形的所有八个角均为整数角度时，称其为"整数角度四边形"。一个例子是正方形，它的八个角都是 45°。另一个例子是：DAC = 20°, BAC = 60°, ABD = 50°, CBD = 30°, BCA = 40°, DCA = 30°, CDB = 80°, ADB = 50°。

不考虑相似，求整数角度四边形的总数。

## 输入格式

无需输入（程序忽略输入）。

## 输出格式

一行一个整数，表示答案。

---

## 样例

### 输出
```
129325
```

---

## 数据范围

- 固定答案题，输出 PE 答案 129325。

---

## 提示

使用正弦定理约束：在四边形中，对角线分割出四个三角形，利用正弦定理得到角度关系。枚举八个整角（1° 到 179°）并验证约束。
