# 191 — Prize Strings

来源：改编自 Project Euler Problem 191

## 原题意

30 天出勤字符串中可得奖的个数。原题答案：1918080160。

## 题目

参数化 N：输入 N（≤ 30），求 N 天可得奖字符串数。

## 数据范围

- N ≤ 30

## 算法

**std**: DP[i][l][a]：i 天结束时迟到 l 次（0/1）、连续缺席 a 天（0/1/2）的方案数。递推 O(N·2·3)。

**brute**: DFS 枚举所有字符串，仅适用于 N ≤ 15。

## 改编方向

1. **参数化 N**：将原题固定 N=30 改为输入参数。
2. **小范围验证**：N ≤ 15 可用 brute 对拍。
3. **固定答案验证**：N=30 输出 1918080160。
