# 出勤奖励字符串

## 题目描述

某所学校给有出勤和守时表现良好的孩子发放现金奖励。如果孩子连续三天缺席（A），或是有多于一次迟到（L），则拿不到这份奖励。

给定 N 天，用 L（迟到）、O（准时）和 A（缺席）可以组成 3^N 种字符串。求其中可以获得奖励的字符串数量。

---

## 输入格式

一行一个整数 N (1 ≤ N ≤ 30)。

---

## 输出格式

一行一个整数，表示 N 天中可以获得奖励的字符串数量。

---

## 样例

### 输入

```
4
```

### 输出

```
43
```

（N=4 时共 81 种字符串，其中 43 种可获得奖励。）

### 输入

```
30
```

### 输出

```
1918080160
```

---

## 数据范围

- 1 ≤ N ≤ 30
