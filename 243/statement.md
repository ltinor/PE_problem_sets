# 不可约度

## 题目描述

对于一个正整数 d，考虑所有分子小于分母的真分数：1/d, 2/d, ..., (d-1)/d。

如果一个分数不能约简（即分子与分母互质），则称该分数为**不可约分数**。

定义分母 d 的**不可约度** R(d) 为：真分数中不可约分数所占的比例。

例如，d = 12 时，真分数有 11 个：
1/12, 2/12, 3/12, 4/12, 5/12, 6/12, 7/12, 8/12, 9/12, 10/12, 11/12

其中不可约的有：1/12, 5/12, 7/12, 11/12（共 4 个）。
因此 R(12) = 4/11。

事实上，R(d) = φ(d) / (d-1)，其中 φ 为欧拉函数。

给定两个正整数 a 和 b（a < b），求满足 R(d) < a/b 的最小分母 d。

---

## 输入格式

一行两个整数 a, b。

---

## 输出格式

一行一个整数 d，表示满足条件的最小分母。

---

## 样例

### 输入
```
4 10
```

### 输出
```
12
```

（R(12) = 4/11 < 4/10）

### 输入
```
15499 94744
```

### 输出
```
892371480
```

---

## 数据范围

- 对于 30% 的数据：a, b ≤ 100
- 对于 100% 的数据：1 ≤ a < b ≤ 10^5
