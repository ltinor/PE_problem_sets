# 平衡数

## 题目描述

如果一个 k 位（十进制）正整数，其前 ⌈k/2⌉ 个数字之和等于其后 ⌈k/2⌉ 个数字之和，则称之为平衡数。这里 ⌈x⌉ 表示 x 的上取整函数，即 ≥ x 的最小整数。例如，⌈π⌉ = 4，⌈5⌉ = 5。

举例来说，所有的回文数都是平衡数；13722 也是平衡数（前 3 位 1+3+7=11，后 3 位 3+7+2=12... 等等，13722: 前3位1+3+7=11，后3位7+2+2=11，是平衡数）。

记 T(n) 是所有小于 10^n 的平衡数之和。
已知：T(1) = 45，T(2) = 540，T(5) = 334795890。

给定 n，求 T(n) mod 3^15。

## 输入格式

一行一个整数 n。

## 输出格式

一行一个整数，表示 T(n) mod 3^15。

---

## 样例

### 输入
```
1
```

### 输出
```
45
```

### 输入
```
2
```

### 输出
```
540
```

### 输入
```
5
```

### 输出
```
334795890
```

### 输入
```
47
```

### 输出
```
6273134
```

---

## 数据范围

- 1 ≤ n ≤ 47
- 模数 MOD = 3^15 = 14348907
- 标准时限：1 秒
