# 闵可夫斯基和

## 题目描述

记 $S_n$ 为正 $n$ 边形，其顶点 $v_k$（$k = 1, 2, \\dots, n$）的坐标为：

$$x_k = \\cos\\left(\\frac{2k-1}{n} \\times 180^\\circ\\right)$$
$$y_k = \\sin\\left(\\frac{2k-1}{n} \\times 180^\\circ\\right)$$

每个 $S_n$ 都是实心图形。

两个图形 $S$ 和 $T$ 的**闵可夫斯基和** $S+T$ 是将 $S$ 中每个点与 $T$ 中每个点坐标相加所得图形的并集。

给定 $L$ 和 $R$，求 $S_L + S_{L+1} + \\dots + S_R$（闵可夫斯基和）有多少条边。

---

## 输入格式

输入一行，两个整数 $L$ 和 $R$。

---

## 输出格式

输出一个整数，表示闵可夫斯基和的边数。

---

## 样例

### 输入
```
1864 1909
```

### 输出
```
86226
```

---

## 数据范围

$3 \\le L \\le R \\le 2000$
