# 133 — Repunit Nonfactors

来源：改编自 Project Euler Problem 133

## 原题意

求 p < 100000 永不能整除 R(10ⁿ) 的素数之和。

原题答案：453647705。

## 题目

参数化 M：输入 M (≤ 100000)，求 p < M 永不能整除 R(10ⁿ) 的素数之和。

## 数据范围

- M ≤ 100000

## 算法

**std**: 对每个素数 p，计算 A(p)（最小的 k 使 R(k) % p = 0）。若 A(p) 的质因子只含 2 和 5，则对充分大的 n，A(p) | 10ⁿ，即 p 能整除 R(10ⁿ)。筛出 A(p) 含其他质因子的素数，求和。

**brute**: 同上。

## 改编方向

1. **参数化 M**：将原题固定 M=100000 改为输入参数。
2. **小范围版本**：M ≤ 10000 可用于对拍验证。
3. **固定答案验证**：M=100000 作为测试点，输出 453647705。
