# PE725 — Digit sum numbers (数字和数)

来源：改编自 Project Euler Problem 725

## 原题意

若一个数中有一位数字等于**其他**数字之和，则称该数为**数字和数**（DS-数）。例如 $352$、$3003$ 和 $32812$ 都是 DS-数。

定义 $S(n)$ 为所有不超过 $n$ 位的 DS-数之和。已知：
- $S(3)=63270$
- $S(7)=85499991450$

求 $S(2020)\bmod 10^{16}$。

PE 答案：4598797036650685。

## 算法

1. **充要条件**：设数字总位数和为 $T$，则 DS-数的条件等价于：$T$ 为偶数，$T\in[2,18]$，且数字 $s=T/2$ 在数中出现。

2. **总和小定理**：由于 $T\leq 18$，一个 DS-数最多有 18 个非零位。对于 $d\leq 2020$ 位数，绝大多数位为 0。

3. **生成函数计数**：使用 DP 计算：
   - $Q(k,S)$：用 $k$ 个数字（每数字 0-9）组成和为 $S$ 的方案数
   - $Q_{\text{excl}}(k,S,e)$：同上但不含数字 $e$
   - $P(k,S)$：$k$ 位数（首位 ≥1）和为 $S$ 的方案数
   - $P_{\text{excl}}(k,S,e)$：同上但不含数字 $e$

   $B(d,2s,s)=P(d,2s)-P_{\text{excl}}(d,2s,s)$ 即为 $d$ 位 DS-数个数。

4. **值和计算**：对每位 $p$（权重 $10^p$）和每位可能的数字值 $v$，乘以对应的方案数后累加。需考虑"包含 $s$"条件是否由当前位满足。

5. **复杂度**：$O(n\cdot \text{MAX\_T}\cdot 10^2)$，其中 $n=2020$，$\text{MAX\_T}=18$。状态空间极小，DP 可瞬间完成。

## 改编方向

1. 改变数字基数（如二进制、十六进制）
2. 修改 DS-数的定义（如"一位等于其他数字的平方和"）
3. 计数 DS-数的个数而非求和
4. 限制数字范围或添加额外约束（如不含连续相同数字）
