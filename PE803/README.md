# PE803 — Pseudorandom Sequence（伪随机序列）

来源：改编自 Project Euler Problem 803

## 原题意

使用特定伪随机数生成算法产生一个长序列，将该序列转换为文本/数字字符串，在该字符串中搜索特定模式或计算相关统计量。典型问题涉及：

- 线性同余生成器（LCG）：x_{n+1} = (a·x_n + c) mod m
- 将生成的数字映射为字符（如 ASCII 码、十进制数字等）
- 在生成的文本中搜索指定单词/模式出现的位置
- 计算模式出现位置之和或其他聚合统计

PE 答案：150056452701858318。

## 算法

1. **PRNG 实现**：按照题目指定的算法生成伪随机序列。
2. **文本生成**：将数字映射为字符（十进制数字、字母等）。
3. **模式匹配**：使用 KMP（Knuth-Morris-Pratt）等高效字符串搜索算法。
4. **优化技巧**：
   - 利用 PRNG 的周期性进行跳跃计算
   - Floyd 判圈算法检测循环
   - 分段并行搜索

## 改编方向

1. 使用不同的 PRNG 算法（Xorshift、Mersenne Twister 等）
2. 改变字符映射规则
3. 搜索多个模式
4. 计算模式密度的统计特性
5. 引入多位编码（base-n 表示）
