# PE871 — Drilling（钻孔）

来源：改编自 Project Euler Problem 871

## 原题意

在一个 $n \times n$ 的点阵上进行钻孔操作。钻头从左上角 $(0,0)$ 出发，每次只能向右或向下移动一格，需要在每个格点恰好钻一次孔，最终到达右下角 $(n-1, n-1)$。问题是计算满足条件的钻孔路径数量，或某种带约束的钻孔方案总数。

PE 答案：497300941（约 $4.97 \times 10^8$）。

## 算法

1. **网格路径计数**：使用 DP 计算 $n \times m$ 网格中从 $(0,0)$ 到 $(n,m)$ 的单调（仅右/下）路径数，经典组合数 $\binom{n+m}{n}$。
2. **钻孔序列**：考虑钻孔的先后顺序约束，将问题转化为有向无环图上的拓扑排序计数问题。
3. **Catalan 相关结构**：部分钻孔约束可转化为括号匹配或 Catalan 数结构。
4. **模运算**：使用 $10^9+7$ 作为标准模数进行计算。

## 改编方向

1. 推广到三维点阵的钻孔路径
2. 允许钻头斜向移动的路径计数
3. 钻孔顺序的部分有序约束
4. 多个钻头并行工作的调度问题
5. 钻孔深度不同的加权路径问题
