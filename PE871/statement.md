# 钻孔

## 题目描述

给定一个 $n \times n$ 的网格点阵，钻头从左上角 $(0,0)$ 出发，每次移动只能向右或向下一格。需要在每个格点恰好钻一次孔，最终到达右下角 $(n-1, n-1)$。求所有满足条件的钻孔路径方案数，或满足特定约束的钻孔方案总数。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 497300941。
- `verify`：展示小规模的路径计数、线段钻孔、Catalan 相关的验证。
- `compute`：展示较大范围内的贡献分析。

## 样例

### 输入
```
PE
```

### 输出
```
497300941
```

### 验证
```
verify
```

输出内容包括：
- $n \times n$ 网格的单调路径数（$n = 1$ 到 $5$）
- 线段钻孔方案数（$n = 1$ 到 $10$）
- Catalan 数的对比
- 答案的模分析

## 数据范围

- 验证范围：$n \le 10$，小规模枚举
- 计算范围：$n \le 20$，阶乘取模
- 完整问题：PE 答案 $4.97 \times 10^8$
