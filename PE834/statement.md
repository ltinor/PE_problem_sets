# 加与除（Add and Divide）

## 题目描述

定义函数 $f(n)$ 如下：

$$f(n) = \begin{cases} n/2, & \text{若 } n \text{ 为偶数} \\ n+1, & \text{若 } n \text{ 为奇数} \end{cases}$$

对给定的正整数 $N$，对于所有 $1 \leq n \leq N$，计算从 $n$ 出发反复应用 $f$ 直到 $n=1$ 所需的步数之和。由于答案可能很大，结果对 $M$ 取模。

## 输入格式

无输入（固定参数问题）。

## 输出格式

输出一个整数，表示步数之和模 $M$ 的结果。

## 样例

（无样例输入输出，直接计算并输出最终答案。）
