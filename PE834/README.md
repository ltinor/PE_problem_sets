# PE834 — Add and Divide（加与除）

来源：改编自 Project Euler Problem 834

## 原题意

考虑一个迭代过程：从正整数 $n$ 开始，反复执行以下操作：
- 若 $n$ 为偶数：$n \leftarrow n/2$
- 若 $n$ 为奇数：$n \leftarrow n+1$

直到 $n = 1$ 为止。统计所需步数，并对所有 $n \in [1, N]$ 求和。

这一问题与二进制表示密切相关。奇数加 $1$ 后变为偶数，下一步必定除以 $2$——实际上等价于「向上取整除以二」操作序列。但对于步数计数，奇数步的「加 1」和后续步的「除 2」是两个分开的步骤。

PE 答案：151813236553797599（约 $1.5 \times 10^{17}$，对应极大的 $N$）。

## 算法

1. **直接模拟**：适用于小 $n$，逐步追踪 $n$ 的变化。
2. **递推公式**：
   - $S(0) = 0$
   - $S(N) = \lfloor N/2 \rfloor + 2\lceil N/2 \rceil + S(\lfloor N/2 \rfloor) + S(\lceil N/2 \rceil)$
3. **记忆化递归**：递推式将 $N$ 每次减半，递归深度为 $O(\log N)$，可在 $O(\log N)$ 时间内计算 $S(N)$。
4. **渐进分析**：$S(N) \sim N \log_2 N$。
