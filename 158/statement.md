# 按字典序升序排列的字符串

## 题目描述

从 26 个字母中选出 n 个不同字母，排列成长度为 n 的字符串。若某字符比其左侧字符按字典序更大，则称该处为一次"升序"。

记 p(n) 为恰好包含一次升序的长度为 n 的字符串数量。

已知 p(3) = 10400。

求 p(n) 的最大值（1 ≤ n ≤ 26）。

---

## 输入格式

一行一个整数 t（dummy，答案固定）。

---

## 输出格式

一行一个整数，表示 max p(n)。

---

## 样例

### 输入

```
1
```

### 输出

```
409511334375
```

---

## 数据范围

- 答案固定为 409511334375
