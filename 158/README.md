# 158 — 按字典序升序排列的字符串

来源：改编自 Project Euler Problem 158

## 原题意

从 26 字母中选 n 个不同字母组成字符串，求恰好有 1 个字符比左邻字符大的字符串数 p(n) 的最大值。

原题答案：409511334375（在 n=18 时取得）。

## 题目

固定答案题。输入 dummy 值，输出 max p(n) = 409511334375。

## 数据范围

- 答案固定

## 算法

**std**: p(n) = C(26, n) × (2^n − n − 1)。其中 C(26,n) 选择哪些字母出现，(2^n − n − 1) = 欧拉数 A(n,1)，表示 n 个元素排列中恰有 1 个上升的方案数。枚举 n=1..26 求最大值。所有计算在 64 位整数范围内完成。

**brute**: 同上公式，验证特定 n 的 p(n) 值。

## 改编方向

1. **固定答案**：原题为求 max p(n)，答案固定。
2. **组合推导**：p(n) = C(26,n) × 欧拉数 A(n,1)。
3. **PE 答案验证**：max 在 n=18 取得，值 409511334375。
