# 醉汉汉诺塔

## 题目描述

经典的汉诺塔问题有 3 根柱子和 n 个大小不同的盘子。每次只能移动一个盘子，且大盘子不能放在小盘子上面。

"醉汉"版本：每次从当前状态的所有合法移动中均匀随机选择一个。初始时所有盘子在柱 1，目标是将所有盘子移到柱 3。

给定 n，求从初始状态到目标状态的期望移动步数（四舍五入到整数）。

## 输入格式

一个整数 n（1 ≤ n ≤ 100），或字符串 `PE`。

## 输出格式

一个整数，表示期望步数。

## 样例

### 输入
```
1
```

### 输出
```
2
```

（1 个盘子：从柱 1 有 2 个合法移动（到柱 2 或柱 3），期望 2 步到达柱 3）

## 数据范围

- 对于 30% 数据：n ≤ 3
- 对于 60% 数据：n ≤ 10
- 对于 100% 数据：n ≤ 100
