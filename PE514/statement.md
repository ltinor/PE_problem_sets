# 几何板图形期望面积

## 题目描述

N 阶几何板是一个含有 (N+1)² 个均匀分布格点的正方形板，格点坐标为 (x, y)，其中 0 ≤ x, y ≤ N。

在每个格点上，以概率 p = 1/(N+1) 放置一根大头针（各格点独立）。所有放置完成后，用橡皮筋圈住所有大头针，形成一个凸多边形 S。若大头针数量不足三个或所有大头针共线，则 S 的面积定义为 0。

记 E(N) 为 S 面积的期望值。给定 N，计算 E(N) 并四舍五入保留五位小数。

## 输入格式

一行，一个整数 N，或字符串 `PE`。

## 输出格式

一个小数，四舍五入保留五位小数，表示期望面积 E(N)。

## 样例

### 输入
```
1
```

### 输出
```
0.18750
```

### 输入
```
2
```

### 输出
```
0.94335
```

### 输入
```
10
```

### 输出
```
55.03013
```

## 数据范围

- 对于 30% 数据：N ≤ 2
- 对于 60% 数据：N ≤ 6
- 对于 100% 数据：N ≤ 100
