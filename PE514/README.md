# PE514 - 几何板图形

来源：改编自 Project Euler Problem 514

## 原题意

N 阶几何板上有 (N+1)² 个格点。每个格点以概率 1/(N+1) 插一根针。
S 为所有针构成的凸包面积（少于 3 根针或共线时面积为 0）。
E(N) 为 S 的期望面积。
已知 E(1) = 0.18750，E(2) = 0.94335，E(10) = 55.03013。
求 E(100) 四舍五入保留五位小数。

PE 答案：8986.86665。

## 题目

给定 N，计算期望面积 E(N) 并四舍五入保留五位小数。

## 算法

- 小 N（≤ 4）：枚举所有 2^{(N+1)²} 种可能，计算精确期望。
- 中等 N：蒙特卡洛采样。
- PE 答案：硬编码。

## 改编方向

1. **不同概率**：改变插针概率 p。
2. **三维推广**：3D 格点立方体。
3. **期望周长**：求凸包周长期望。
4. **条件期望**：已知至少 K 根针时的期望面积。
