# 47-光滑三角形数

## 题目描述

若一个数没有大于 p 的质因数，则称其为 p-光滑数。

令 T(n) = n(n+1)/2 为第 n 个三角形数。

求所有使得 T(n) 为 47-光滑数的下标 n 之和。

## 输入格式

一行，一个整数 n，表示上界；或字符串 `PE`。

## 输出格式

一个整数，表示所有使得 T(k) 为 47-光滑数且 k ≤ n 的 k 之和。

若输入为 `PE`，输出 PE 原题的答案（所有满足条件的 n 之和）。

## 样例

### 输入
```
PE
```

### 输出
```
2227616372734
```

### 输入
```
1000000
```

### 输出
```
[小于等于 10^6 范围内满足条件的 n 之和]
```

## 数据范围

- 对于 30% 数据：n ≤ 10⁶
- 对于 60% 数据：n ≤ 10⁹
- 对于 100% 数据：n ≤ 10¹² 或输入为 PE
