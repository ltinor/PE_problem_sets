# 丢番图方程

## 题目描述

考虑如下形式的二次丢番图方程：

x² - D·y² = 1

例如，当 D = 13 时，最小正整数解为 649² − 13×180² = 1。

当 D 是平方数时，该方程无正整数解。

对于 D ≤ 7，最小 x 解最大的 D 是 5（此时 x = 9）。

给定 M，在 D ≤ M 中，求使得最小 x 解最大的那个 D 的值。

---

## 输入格式

第一行一个整数 T，表示测试数据组数。
接下来 T 行，每行一个整数 M。

---

## 输出格式

对于每组数据，输出一行一个整数，表示答案。

---

## 样例

### 输入
```
1
7
```

### 输出
```
5
```

---

## 数据范围

- 1 ≤ T ≤ 100
- 1 ≤ M ≤ 1000
