# PE066 丢番图方程

来源：改编自 Project Euler Problem 66

## 原题意

D ≤ 1000，求 Pell 方程 x² - D·y² = 1 最小解中 x 最大的 D。答案: 661。

## 题目

输入 M，求 D ≤ M 中 Pell 方程最小 x 解最大的 D。

## 数据范围

M ≤ 1000，多组输入。

## 算法

Pell 方程通解通过 √D 的连分数展开求得。Chakravala / 连分数法：计算 √D 连分数周期 L，若 L 为奇数则取 2L 个逼近值，得到的 (p, q) 即为最小解。x 可达极大值（>10³⁷），需要大整数。
