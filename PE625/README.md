# PE625 — 最大公约数和 (Gcd sum)

来源：改编自 Project Euler Problem 625

## 原题意

G(N) = Σ_{j=1}^{N} Σ_{i=1}^{j} gcd(i, j)

已知 G(10) = 122。

求 G(10¹¹) mod 998244353。

PE 答案：551614306。

## 算法

直接 O(N²) 不可行。利用除数求和的变换：

G(N) = Σ_{j=1}^{N} Σ_{i=1}^{j} Σ_{d|i, d|j} φ(d)
     = Σ_{d=1}^{N} φ(d) · ⌊N/d⌋ · (⌊N/d⌋ + 1) / 2

这个式子的计算需要 φ 的前缀和 Φ(n) = Σ_{i=1}^{n} φ(i)。

虽然 ⌊N/d⌋ 只有 O(√N) 个不同取值，但需要快速计算任意 n ≤ N 的 Φ(n)。

利用 Dirichlet 双曲线法（Mertens 函数类似方法）：

由 Σ_{d=1}^{n} φ(d) · ⌊n/d⌋ = n(n+1)/2 可得：
Φ(n) = n(n+1)/2 - Σ_{d=2}^{n} Φ(⌊n/d⌋)

递归计算 Φ(n)，对不同的 ⌊n/d⌋ 进行分块。结合预计算到 N^(2/3) ≈ 5×10⁶ 的 φ 值，可在 O(N^(2/3)) 时间内完成。

求得 Φ 后，同样对 d 进行分块计算 G(N)，每次区间 [L, R] 使用 Φ(R) - Φ(L-1) 乘以对应的二次项即可。

## 改编方向

1. 推广到 Σ Σ gcd(i, j)^k 或 Σ Σ lcm(i, j)。
2. 修改求和的上下界（如 i 从 a 到 b，j 从 c 到 d）。
3. 增加对 i 和 j 的互质性或其他条件的约束。
4. 研究 G(N) 的渐近展开式。
