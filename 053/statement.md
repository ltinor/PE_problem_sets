# 组合选择

## 题目描述

组合数定义为 $\displaystyle \binom{n}{r} = \frac{n!}{r!(n-r)!}$，其中 $r \le n$，$n! = n \times (n-1) \times \ldots \times 1$，且 $0! = 1$。

给定 $N$ 和 $T$，求对于 $1 \le n \le N$，有多少个组合数 $\binom{n}{r}$（$0 \le r \le n$）的值严格大于 $T$。

---

## 输入格式

第一行一个整数 $Q$，表示询问组数。
接下来 $Q$ 行，每行两个整数 $N$ 和 $T$。

---

## 输出格式

$Q$ 行，每行一个整数表示答案。

---

## 样例

### 输入

```
1
100 1000000
```

### 输出

```
4075
```

### 输入

```
2
23 1000000
10 100
```

### 输出

```
4
7
```

---

## 数据范围

- $1 \le Q \le 10$
- $1 \le N \le 100$
- $0 \le T \le 10^{12}$
