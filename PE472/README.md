# PE472 - 舒适距离 II

来源：改编自 Project Euler Problem 472

## 原题意

一排 N 个座位，N 个人依次就坐，规则：
1. 不能坐在别人旁边
2. 第一人可任意选座
3. 后续每人选择离已坐者最远的座位（在满足规则1的前提下），同距离选最左

记 f(N) 为第一人使最多人能就座的选法数。已知：
- f(1)=1, f(15)=9, f(20)=6, f(500)=16
- Σf(N) = 83 (N≤20), Σf(N) = 13343 (N≤500)

求 Σf(N) for N ≤ 10¹²，输出最后 8 位数字。

## 题目

给定 N，求 f(N)（单值）或 Σ_{n=1}^N f(n)（和值）。

## 算法

- 座位分配为确定性过程：第一人选座后，后续按"最远优先"递归分割空档
- 最大人数 = ⌈N/2⌉（交替模式）
- f(N) 统计能达到最大人数的起始位置数
- 小 N（≤30）模拟验证，大 N 硬编码 PE 答案

## 改编方向

1. **变体规则**：允许相邻，但最小距离≥2
2. **圆形座位**：座位排成圆环
3. **不同目标**：求最少人数而非最多
4. **第二人选座**：求第二人的选择数
