# PE332 - 球面三角形 (Spherical Triangles)

来源：改编自 Project Euler Problem 332
PE 答案：2717.751525

## 原题意

球面三角形由球面上三条大圆圆弧两两相交构成。C(r) 是中心在原点、半径为 r 的球。Z(r) 是 C(r) 表面上的整数坐标点。A(r) 是顶点在 Z(r) 中的最小非退化球面三角形的面积。

求 Σ_{r=1}^{50} A(r)，四舍五入到六位小数。

## 题目（改编）

给定 R（≤ 50），求 Σ_{r=1}^{R} A(r)。

## 算法

- 枚举球面整数点：x²+y²+z²=r²
- 枚举所有三元组，排除退化情况（三点共大圆 = 与原点共面 = 混合积为 0）
- 计算球面三角形面积：使用球面角超公式 Area = (A+B+C−π)·r²
- 顶点角度通过平面法向量夹角计算

## 复杂度

- 时间：O(R · P³)，其中 P 是每层球面上的整数点数（最坏约 O(r²) 个点）
- 空间：O(P)

## 改编方向

1. **更大半径**：预处理球面整数点，优化到 O(P²) 或 O(P²log P)
2. **最大面积**：改为求最大球面三角形面积
3. **四维球面**：推广到四维超球面上的三角形
