# 三阶斐波那契数的非约数

## 题目描述

序列 $T_1 = T_2 = T_3 = 1$，$T_n = T_{n-1} + T_{n-2} + T_{n-3}$（$n \ge 4$）。

可以证明，$27$ 不能整除这个序列中的任何一项。事实上，$27$ 是第一个拥有这一性质的奇数。

给定 $K$，求第 $K$ 个不能整除上述序列中任何一项的奇数。

---

## 输入格式

输入一行，一个整数 $K$。

---

## 输出格式

输出一个整数，表示第 $K$ 个满足条件的奇数。

---

## 样例

### 输入
```
124
```

### 输出
```
2009
```

---

## 数据范围

$K \le 500$
