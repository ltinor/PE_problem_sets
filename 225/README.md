# 225 — Tribonacci non-divisors

来源：改编自 Project Euler Problem 225

## 原题意

求第 124 个不能整除任何 Tribonacci 数列项的奇数。原题答案：2009。

## 题目

参数化 K：输入 K (≤500)，求第 K 个 Tribonacci 非约数奇数。

## 数据范围

$K \le 500$

## 算法

**std**: 对每个奇数 $n$，计算 Tribonacci 数列模 $n$ 的值直到遇到 $0$ 或检测到循环。使用 `unordered_set` 记录已访问的状态 $(T_i, T_{i+1}, T_{i+2})$ 模 $n$，将三个值编码为单个 64 位整数以加速查找。设最大步数限制为 $\min(10^7, n^3)$。

**brute**: 同样算法，使用 `set` 实现，适用于 $K \le 200$。

## 改编方向

1. **参数化 K**：将固定 K=124 改为输入参数。
2. **扩展范围**：可增大 K 上限，但需要优化循环检测（如 Floyd 判圈法）。
3. **通用递归**：参数化递推公式系数。
