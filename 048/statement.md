# 自幂

## 题目描述

自幂级数的前十项和为：1¹ + 2² + 3³ + ... + 10¹⁰ = 10405071317。

原题求：1¹ + 2² + 3³ + ... + 1000¹⁰⁰⁰ 的最后 10 位数字（答案为 9110846700）。

现在将问题一般化：给定正整数 N，求 S(N) = 1¹ + 2² + 3³ + ... + N^N 的最后 10 位数字。

---

## 输入格式

多组测试数据。每组数据一行，包含一个整数 N。

---

## 输出格式

对于每组数据，输出一行，为 S(N) 的最后 10 位数字。如果不足 10 位，需要用前导零补齐。

---

## 样例

### 输入

```
1000
```

### 输出

```
9110846700
```

---

## 数据范围

- 1 ≤ N ≤ 10⁶
- 测试数据组数不超过 10 组
