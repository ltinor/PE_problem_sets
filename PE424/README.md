# PE424 - 数和谜题 (Kakuro)

来源：改编自 Project Euler Problem 424

## 原题意

200 个加密的数和谜题（5×5 或 6×6），每个有字母 A-J 映射到数字 0-9。答案基于字母到数字的映射拼接。前 10 个谜题答案和为 64414157580，200 个谜题答案和为 1059760019628。

## 题目

给定加密的数和谜题描述，求解并按字母顺序输出映射。

## 算法

- 解析加密格式：首个数字表示大小（6=5×5，7=6×6），后续逗号分隔描述每个格子
- X=灰色块，O=白色空格，A-J=变量字母，(hXX)=横和，(vXX)=竖和
- 约束回溯搜索：对每个白格尝试 1-9，检查行列和约束与唯一性约束
- 字母映射：A-J 对应 0-9，至少 9 个字母已知，剩余自动确定

## 改编方向

1. **更大面板**：扩展到 9×9 或更大
2. **不同数字范围**：允许 0-9 或 1-16（十六进制）
3. **多解计数**：统计满足条件的映射数
