# 数和谜题 (Kakuro)

## 题目描述

数和（Kakuro）是一种数字谜题。在一个网格中，需要在白色格子中填入数字 1-9，使得：
- 每行/列中白色格子的数字之和等于该行/列头部指定的和
- 同一行/列的白色格子中的数字互不相同

谜题以加密形式给出：每个格子用字母 A-J 表示（分别映射到 0-9 中的一个数字），行和与列和也以字母形式加密。

给定一个谜题的加密描述，求解该谜题并将答案以字母 A-J 对应数字的字符串形式输出（按字母顺序拼接）。

---

## 输入格式

第一行一个字符串，为谜题的加密描述。

---

## 输出格式

一个字符串，表示所有字母 A-J 对应的数字（按字母顺序拼接）。若某字母未出现，则自动填充。

---

## 样例

### 输入
```
6,X,X,(vCC),(vI),X,X,X,(hH),B,O,(vCA),(vJE),X,(hFE,vD),O,O,O,O,(hA),O,I,(hJC,vB),O,O,(hJC),H,O,O,O,X,X,X,(hJE),O,O,X
```

### 输出
```
8426039571
```

---

## 数据范围

- 单个谜题：5×5 或 6×6 面板
- 多谜题模式下最多 200 个谜题
