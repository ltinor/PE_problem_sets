# $4 \times n$ 棋盘上的巡游

## 题目描述

对于一个 $4 \times n$ 的棋盘，定义 $T(n)$ 为满足以下条件的巡游路径数量：
- 巡游从左上角 $(0,0)$ 开始；
- 每一步可以向上、下、左、右移动一格；
- 巡游经过每个格子恰好一次；
- 巡游在左下角 $(3,0)$ 结束。

给定 $n$，求 $T(n) \bmod 10^8$。

---

## 输入格式

一行一个整数 $n$。

---

## 输出格式

输出 $T(n) \bmod 10^8$。

---

## 样例

### 输入
```
10
```

### 输出
```
2329
```

---

## 数据范围

$1 \le n \le 10^{12}$
