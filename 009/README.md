# Special Pythagorean Triplet
来源：改编自 Project Euler Problem 9

## 原题意
毕达哥拉斯三元组由三个自然数$a<b<c$组成，并满足

$$a^2+b^2=c^2$$

例如，$3^2+4^2=9+16=25=5^2$。

有且只有一个毕达哥拉斯三元组满足 $a + b + c = 1000$。求这个三元组的乘积$abc$。


## 题目

毕达哥拉斯三元组由三个自然数 $a < b < c$ 组成，并满足

$$a^2 + b^2 = c^2$$

例如：

$$3^2 + 4^2 = 9 + 16 = 25 = 5^2$$

现在给定一个整数 $S$，请你找出 **任意一个** 满足条件的三元组 $(a,b,c)$，使得：

$$a + b + c = S$$

并输出三元组的乘积 $abc$。  

- 如果不存在符合条件的三元组，请输出 $0$。  
- 如果存在多个解，输出任意一个。

## 数据范围

$1 \le T \le 1000$
$1 \le S \le 3000$
