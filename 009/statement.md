# 特殊毕达哥拉斯三元组

## 题目描述

毕达哥拉斯三元组由三个自然数 $a < b < c$ 组成，并满足

$$a^2 + b^2 = c^2$$

例如：

$$3^2 + 4^2 = 9 + 16 = 25 = 5^2$$

现在给定一个整数 $S$，请你找出 **任意一个** 满足条件的三元组 $(a,b,c)$，使得：

$$a + b + c = S$$

并输出三元组的乘积 $abc$。  

- 如果不存在符合条件的三元组，请输出 $0$。  
- 如果存在多个解，输出任意一个。

---

## 输入格式

第一行包含一个整数 $T$ $(1 \le T \le 1000)$，表示测试数据组数。  
接下来 $T$ 行，每行包含一个整数 $S$ $(1 \le S \le 3000)$。

---

## 输出格式

对每组测试数据，输出一行，表示对应三元组的乘积 $abc$，或者如果不存在解输出 $0$。

---

## 样例

### 输入
```
2
12
11
```


### 输出

```
60
0
```

---

## 数据范围

$1 \le T \le 1000$
$1 \le S \le 3000$
