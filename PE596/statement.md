# 超球中的格点数目

## 题目描述

T(r) 为满足 x² + y² + z² + t² ≤ r² 的整数四元组 (x,y,z,t) 的个数。即半径为 r 的四维超球中格点的数目。

已知：
- T(2) = 89
- T(5) = 3121
- T(100) = 493490641
- T(10⁴) = 49348022079085897

求 T(10⁸) mod 1000000007。

## 输入格式

一行，字符串 `PE`、`verify`，或一个整数 r。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案：734582049。
若输入为 `verify`，验证已知的 T(2)、T(5)、T(100)。
若输入为整数 r，输出 T(r) mod 1000000007。

## 样例

### 输入
```
PE
```

### 输出
```
734582049
```

## 数据范围

- 完整问题：r = 10⁸
- 验证模式：r ≤ 100
- 自定义输入：r ≤ 10⁶（太大可能超时）
