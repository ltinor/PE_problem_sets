# 三角形三元组

## 题目描述

记 T(n)=n(n+1)/2，dT(n) 为 T(n) 的约数个数。
记 Tr(n) 为满足 1≤i<j<k≤n 且 dT(i)>dT(j)>dT(k) 的三元组个数。

给定 n，求 Tr(n) mod 10^18。

---
## 输入格式

一个整数 n。

---
## 输出格式

Tr(n) mod 10^18。

---
## 样例

### 输入
```
20
```

### 输出
```
14
```

### 输入
```
100
```

### 输出
```
5772
```

---
## 数据范围

- n ≤ 200,000（完整算法）
- 更大（特殊值）
