# PE771 — Pseudo-geometric sequences（伪几何序列）

来源：改编自 Project Euler Problem 771

## 原题意

一个伪几何序列由初始值 $s$ 和有理数乘子 $r = a/b$（最简分数）定义：
$$x_0 = s,\quad x_{n+1} = \text{round}(x_n \times a / b)$$

即每项由前一项乘以分数 $a/b$ 并四舍五入得到。问题考虑不同的 $(a, b)$ 对和起始值，要求计算所有伪几何序列中出现的不同值的总和，或在某范围内满足特定性质的序列个数。

PE 答案：205836930055736842（约 $2.06 \times 10^{17}$）。

## 算法

1. **序列生成**：使用 __int128 处理大整数乘法，实现 round/floor/ceil 三种取整方式。
2. **参数枚举**：对所有最简分数 $a/b$（$1 \le a, b \le M$）生成序列并收集不同值。
3. **去重与求和**：使用 set 或 hash 表对序列值去重，求和后对 MOD 取模。
4. **大规模优化**：利用序列的周期性/收敛性质，直接推导贡献公式而非逐项模拟。
5. **模运算**：使用 $10^9+7$ 作为标准模数进行取模计算。

## 改编方向

1. 推广到其他取整方式（floor、ceil）的比较
2. 多起始值的并行序列分析
3. 约束 $a/b$ 分子分母互质的计数
4. 序列周期性检测与循环分析
5. 推广到三维序列（三个前项决定后项）
