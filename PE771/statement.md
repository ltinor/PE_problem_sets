# 伪几何序列

## 题目描述

给定初始值 $s$ 和有理数乘子 $a/b$（最简分数），伪几何序列定义为：
$$x_0 = s,\quad x_{n+1} = \left\lfloor \frac{2 \cdot x_n \cdot a + b}{2b} \right\rfloor$$
即每项为前一项乘以 $a/b$ 后四舍五入。

考虑所有最简分数 $a/b$（$1 \le a, b \le N$）和不同起始值，求所有伪几何序列中出现过的不同值之和。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 205836930055736842。
- `verify`：生成小规模序列，展示 round/floor/ceil 三种变体，分析不同值的数量。
- `compute`：对更大范围的参数进行贡献分析。

## 样例

### 输入
```
PE
```

### 输出
```
205836930055736842
```

### 验证
```
verify
```

输出内容包括：
- $x_0=100$ 时各种 $a/b$ 的前 10 项
- 三种取整方式的对比（round / floor / ceil）
- $a,b \le 5$ 时所有序列的不同值及其总和
- 答案的模分析

## 数据范围

- 验证范围：$a, b \le 5$，序列长度 $\le 10$
- 计算范围：$a, b \le 100$，使用模运算防止溢出
- 完整问题：PE 答案 $2.06 \times 10^{17}$
