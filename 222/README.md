# 222 — Sphere Packing

来源：改编自 Project Euler Problem 222

## 原题意

将 21 个半径分别为 30mm 到 50mm 的球装入内径 50mm 的管子，求最短管长（μm）。原题答案：1590933。

## 题目

参数化 N, R：输入 N (≤21) 和管半径 R，球半径为 30, 31, ..., 30+N-1。求最短管长（微米，四舍五入）。

## 数据范围

- $N \le 21$，$R \le 60$
- 球半径 $< R$

## 算法

**std**: 状态压缩 DP。两球 $i,j$ 中心间距 $h_{ij} = \sqrt{(r_i+r_j)^2 - (2R - r_i - r_j)^2}$。dp[mask][last] 表示已放置子集 mask 且末尾为 last 的最小管长。转移 $O(2^N \cdot N^2)$，$N=21$ 时约 $4.4\times 10^7$，可在 1s 内完成。

**brute**: 枚举全排列，适用于 $N \le 8$。

## 改编方向

1. **参数化 N, R**：将固定 21 球改为可变参数。
2. **通用半径输入**：可改为输入任意半径序列（本题采用等差数列）。
3. **优化算法**：对于更大的 N，可用启发式搜索（模拟退火/遗传算法）。
