# 球体打包

## 题目描述

将 $N$ 个半径分别为 $30, 31, \dots, 30+N-1$ 毫米的球完全装入一根内径为 $R$ 毫米的管子，求所需的最短管长。

将你的答案用微米（$10^{-6}$ 米）表示，并四舍五入到最近的整数。

---

## 输入格式

输入一行，两个整数 $N$ 和 $R$。

---

## 输出格式

输出一个整数，表示最短管长（微米）。

---

## 样例

### 输入
```
21 50
```

### 输出
```
1590933
```

---

## 数据范围

- $2 \le N \le 21$
- $40 \le R \le 60$
- 球半径严格小于 $R$
