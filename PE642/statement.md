# 最大质因子和

## 题目描述

对于一个正整数 n > 1，定义 f(n) 为 n 的最大质因子（largest prime factor）。

定义 S(N) = Σ_{n=2}^{N} f(n)，即从 2 到 N 所有整数的最大质因子之和。

已知 S(100) = 853。

求 S(201820182018)。

## 输入格式

一行，字符串 `PE` 或 `verify` 或 `compute`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案。

若输入为 `verify`，输出 S(10)、S(100)、S(1000)、S(5000) 的结果。

若输入为 `compute`，计算 S(100000)。

## 样例

### 输入
```
PE
```

### 输出
```
631499044201325
```

## 数据范围

- 完整问题：N = 201820182018（约 2×10¹¹）
- 需要使用高级算法（分段筛、Lucy DP 等）处理大规模输入
