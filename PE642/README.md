# PE642 — 最大质因子和 (Sum of largest prime factors)

来源：改编自 Project Euler Problem 642

## 原题意

对每个 n ≥ 2，令 f(n) 为 n 的最大质因子。定义 S(N) = Σ_{n=2}^{N} f(n)。

已知 S(100) = 853。求 S(201820182018)。

PE 答案：631499044201325。

## 算法

### 贡献分解

对于每个质数 p ≤ N，它在 S(N) 中的贡献为：

contribution(p) = p × count_{p}(N)

其中 count_{p}(N) 是满足「最大质因子恰好为 p」的 n ≤ N 的个数。

### p-光滑数计数

一个数 n 的最大质因子为 p，当且仅当 n = p × m，且 m 的所有质因子 ≤ p（即 m 是 p-光滑的）。

因此 count_{p}(N) = #{m ≤ N/p : m 是 p-光滑的}

### 高效实现

对于 N ≈ 2×10¹¹，无法使用完整筛法。需要使用：

1. **Lucy DP**（或类似的递归计数方法）：递归计算 ≤X 的 p-光滑数个数
2. **分块处理**：将质数按大小分段，对每段分别计算贡献
3. **大质数特殊处理**：对于 p > √N，每个这样的 p 贡献次数为 ⌊N/p⌋

### 实现步骤

1. 筛出所有质数 p ≤ N
2. 对每个质数 p，计算 N/p 以内的 p-光滑数个数
3. 累加贡献得到 S(N)
