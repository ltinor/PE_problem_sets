# 亚历山大整数

## 题目描述

我们称一个正整数 $A$ 为"亚历山大整数"，如果存在整数 $p$、$q$、$r$ 满足：

$$A = p \cdot q \cdot r \quad \text{且} \quad \frac{1}{A} = \frac{1}{p} + \frac{1}{q} + \frac{1}{r}$$

例如，$630$ 是一个亚历山大整数（$p = 5$，$q = -7$，$r = -18$）。事实上，$630$ 是第 $6$ 个亚历山大整数，前 $6$ 个亚历山大整数分别是 $6$、$42$、$120$、$156$、$420$ 和 $630$。

给定正整数 $K$，求第 $K$ 个亚历山大整数。

---

## 输入格式

输入一行，一个整数 $K$。

---

## 输出格式

输出一个整数，表示第 $K$ 个亚历山大整数。

---

## 样例

### 输入
```
6
```

### 输出
```
630
```

---

## 数据范围

$K \le 150000$
