# 无平方因子的高斯整数（PE 556）

## 原题描述

原题及更多讨论见 [https://projecteuler.net/problem=556](https://projecteuler.net/problem=556)。

<b>高斯整数</b>是指形如z = a + bi的数，其中a, b均为整数，i<sup>2</sup> = -1。
高斯整数是复数的一个子集，而一般意义上的整数又是高斯整数取b = 0的一个子集。

高斯整数的<b>单位</b>满足a<sup>2</sup> + b<sup>2</sup> = 1，这样的数包括1, i, -1, -i。
我们定义<i class=zh>真</i>高斯整数为满足a &gt; 0且b ≥ 0的高斯整数。

如果z<sub>3</sub> = a<sub>3</sub> + b<sub>3</sub>i = z<sub>1</sub>/z<sub>2</sub>仍然是高斯整数，我们就称高斯整数z<sub>1</sub> = a<sub>1</sub> + b<sub>1</sub>i能够被z<sub>2</sub> = a<sub>2</sub> + b<sub>2</sub>i整除。
$$\frac {z_1} {z_2} = \frac {a_1 + b_1 i} {a_2 + b_2 i} = \frac {(a_1 + b_1 i)(a_2 - b_2 i)} {(a_2 + b_2 i)(a_2 - b_2 i)} = \frac {a_1 a_2 + b_1 b_2} {a_2^2 + b_2^2} + \frac  {a_2 b_1 - a_1 b_2}  {a_2^2 + b_2^2}i = a_3 + b_3 i$$
因此，z<sub>1</sub>被z<sub>2</sub>整除当且仅当$\frac {a_1 a_2 + b_1 b_2} {a_2^2 + b_2^2}$和$\frac  {a_2 b_1 - a_1 b_2}  {a_2^2 + b_2^2}$都是整数。
例如，2被1 + i整除，因为2/(1 + i) = 1 - i是高斯整数。

<b>高斯素数</b>是指只能被单位、其本身或其本身乘以单位所整除的高斯整数。
例如，1 + 2i是高斯素数，因为它只能被1, i, -1, -i, 1 + 2i, i(1 + 2i) = i - 2, -(1 + 2i) = -1 - 2i和-i(1 + 2i) = 2 - i整除。
2不是高斯素数，因为它被1 + i整除。

任意高斯整数可以唯一地分解为一个单位和一系列真高斯素数的乘积。
例如，2 = -i(1 + i)<sup>2</sup>，以及1 + 3i = (1 + i)(2 + i)。
如果一个高斯整数的素数分解中不包含重复的真高斯素数，我们称这个高斯整数无平方因子。
因此在高斯整数中，2不是无平方因子的，而1 + 3i是无平方因子的。
根据定义，单位和高斯素数都是无平方因子的。

记f(n)为所有满足a<sup>2</sup> + b<sup>2</sup> ≤ n的无平方因子真高斯整数的数目。
例如，f(10) = 7因为1, 1 + i, 1 + 2i, 1 + 3i = (1 + i)(2 + i), 2 + i, 3和3 + i = -i(1 + i)(1 + 2i)是无平方因子的，而2 = -i(1 + i)<sup>2</sup>和2 + 2i = -i(1 + i)<sup>3</sup>不是。
已知f(10<sup>2</sup>) = 54，f(10<sup>4</sup>) = 5218以及f(10<sup>8</sup>) = 52126906。

求f(10<sup>14</sup>)。
