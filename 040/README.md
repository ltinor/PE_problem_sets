# 钱珀瑙恩常数 (Champernowne's Constant)

来源：改编自 Project Euler Problem 40

## 原题意

将所有正整数拼接成小数：0.123456789101112...，记 d_n 为小数点后第 n 位。求 d_1 × d_10 × d_100 × d_1000 × d_10000 × d_100000 × d_1000000 的值。答案：210。

## 改编方向

参数化。输入 K 和 K 个位置 p_i，输出这些位置上的数字之积。支持多组输入。K≤7，p_i≤10^6。

## 题目

将所有正整数按顺序拼接起来构造一个十进制小数：

0.123456789101112131415161718192021...

记 d_n 为小数点后第 n 位数字。给定 K 个位置，求这些位置上的数字的乘积。

## 数据范围

- K: 1 ≤ K ≤ 7
- p_i: 1 ≤ p_i ≤ 10^6
- 多组测试数据

## 算法

std: 数学分段计算。1位数有9个（占9位），2位数有90个（占180位），3位数有900个（占2700位）... 根据位置定位到具体数字，取对应位。O(K log p)。

brute: 直接拼接字符串到 10^6 位，然后按位置取字符。O(10^6)。
