# 有一个整数角的整数边三角形

## 题目描述

考虑三边长 $a,b,c$ 均为整数的三角形，且**至少有一个角**的度数为整数（$60\degree$、$90\degree$ 或 $120\degree$）。

给定周长上限 $N$，求满足条件的三角形个数（全等三角形仅计一次）。

---

## 输入格式

一行一个整数 $N$。

---

## 输出格式

一行一个整数，表示答案。

---

## 样例

### 输入
```
50
```

### 输出
```
6
```

（满足条件的三角形边长：$(1,1,1)$、$(3,3,4)$、$(3,4,5)$、$(5,5,8)$、$(5,6,7)$、$(7,8,13)$ 等）

---

## 数据范围

- $3 \le N \le 10^8$
