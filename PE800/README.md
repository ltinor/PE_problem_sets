# PE800 — Hybrid Integers（混合整数）

来源：改编自 Project Euler Problem 800

## 原题意

若一个整数可以表示为 $p^q q^p$ 的形式（$p \neq q$ 均为质数），则称其为混合整数（hybrid-integer）。例如 $800 = 2^5 \times 5^2$ 是一个混合整数。

定义 $C(n)$ 为不超过 $n$ 的所有混合整数的个数。已知 $C(800) = 2$，$C(800^{800}) = 10790$。求 $C(800800^{800800})$。

PE 答案：1412403576。

## 算法

1. **对数化处理**：$p^q q^p \le N \iff q \ln p + p \ln q \le \ln N$。使用对数避免大数溢出。
2. **质数筛**：只需筛到约 $1.5 \times 10^7$ 的质数（约 $10^6$ 个），因为 $\ln N = B \ln B \approx 1.09 \times 10^7$，且对 $p=2$ 时 $q \le \ln N / \ln 2 \approx 1.57 \times 10^7$。
3. **二分查找**：对每个质数 $p$，在质数列表中二分查找满足 $q \ln p + p \ln q \le \ln N$ 的最大质数 $q > p$。
4. **复杂度**：$O(\pi(Q_{\max}) \log \pi(Q_{\max})) \approx 10^6 \times 20 \approx 2 \times 10^7$ 次运算，完全可行。
5. **早期终止**：当 $p$ 足够大使得 $f(p, \text{next\_prime}(p)) > \ln N$ 时终止循环。
