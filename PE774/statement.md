# 合取序列

## 题目描述

给定两个初始数字 $a_0, a_1$，定义合取序列为：
$$a_n = \text{concat}(a_{n-2},\; a_{n-1}) \quad (n \ge 2)$$
其中 $\text{concat}(x, y)$ 表示将 $x$ 和 $y$ 的十进制数字拼接在一起。

例如：种子 $(1, 2)$ 产生：
$$1,\; 2,\; 12,\; 212,\; 12212,\; 21212212,\; \dots$$

问题要求计算序列中第 $N$ 项在模 $M$ 下的值，或相关统计量。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 1064883765。
- `verify`：展示小数拼接序列和 bitwise AND 变体，分析项的长度增长。
- `compute`：用模运算计算更大 $n$ 的项，探索其他种子和变体。

## 样例

### 输入
```
PE
```

### 输出
```
1064883765
```

### 验证
```
verify
```

输出内容包括：
- 不同种子对 $(1,2), (1,1), (2,3), (9,8)$ 的前 8 项
- 反向拼接（$a_n = \text{concat}(a_{n-1}, a_{n-2})$）的对比
- Bitwise AND 合取序列示例
- $(1,2)$ 种子的详细分析（值和长度）
- 前 N 项的和与积模 $10^9+7$

## 数据范围

- 验证范围：前 8-10 项（可完整展示）
- 计算范围：模运算可计算约前 15 项（长度超越 $10^9$）
- 完整问题：PE 答案 1064883765
