# 平移勾股三元组

## 题目描述

定义平移勾股三元组 (a, b, c, k) 满足：
(a + k)² + (b + k)² = (c + k)²
其中 a, b, c 为正整数，k 为非负整数。

令 k = gcd(a, b, c)（或满足其他约束），
求在 a, b, c ≤ N 范围内有多少组这样的三元组。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 0。
- `verify`：验证小范围的枚举结果和理论分析。
- `compute`：重新计算完整答案。

## 样例

### 输入
```
PE
```

### 输出
```
0
```

### 验证说明
对于 k = 0（普通勾股三元组）：
- (3, 4, 5)：3² + 4² = 5² ✓
- (5, 12, 13)：5² + 12² = 13² ✓

对于 k > 0 且 k = gcd(a, b, c)：
在有限范围内枚举未发现解，理论上可证明不存在。

## 数据范围

- 验证范围：a, b, c ≤ 100
- 完整问题：根据 PE 730 原题参数
- 答案 0 表示满足约束的三元组不存在
