1. **`_tools/audit/audit_full.py` 语法错误**（字符串字面量内嵌换行）——已修复，
   数据一致性审计史上首次跑通。
2. **"全量数据增强"（2b765392）提交的数据大面积损坏**：306 题 461 个文件
   DATA_BAD。分两类处理：
   - 本会话生成的 423 个文件：写出时误剥离了输出内部空行（与审计的严格规范
     不一致）→ 411 个按实际 stdout 重写、12 个超 10s 删点；

     以 std 为准），19 个删除（输入格式与 std 不符喂出未初始化垃圾、
     非确定性 std、真超时/崩溃）。

   不可靠：同秒双跑会伪装成确定性。已对相关数据点做隔秒复验，21 点全部稳定。

   本次未修该工具（避免触发全量样例清算），已用修正逻辑在收割器中单独实现。
