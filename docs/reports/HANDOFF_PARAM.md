# 交接文档：34 题参数化分支补齐

## 任务

34 道题的 std.cpp 只有 PE 分支（无 cin>> 参数化输入），需要添加参数化分支使 OJ 可测试参数化正确性。

## 每题操作流程

1. 读原题 `{pid}/{pid}.md` 确定可参数化的量
2. 读 `{pid}/code/std.cpp` 确认算法逻辑
3. 在 main() 开头添加 `cin >> <参数>;`，将硬编码参数替换为输入值
4. 编译验证：`g++ -std=c++17 -O2 {pid}/code/std.cpp -o /tmp/chk.exe`
5. 用原题锚点验证正确性
6. 生成 2-3 组参数化 data（小参数/常规/边缘）
7. 更新 `{pid}/statement.md` 补充输入格式和数据范围

## 已知参数化方案（部分题）

| 题号 | 原题参数 | 改编方案 |
|---|---|---|
| 004 | 3 位数乘积回文 | 给定位数 n，找最大 n 位数乘积回文 |
| 144 | 椭圆激光反射 | 固定几何，可参数化最大反射次数 |
| 371 | 车牌累计和=1000 | 可参数化目标和/进制 |
| 389 | 骰子方差 (4,6,8,12,20) | 可参数化骰子面数序列 |
| 480 | 字符串搜索 | 固定答案题，可加截断参数 |

其余题需读原题后自行确定。

## 注意事项

1. PE 分支保留不动（`if (first == "PE")` 输出官方值）
2. 参数化分支加在 PE 分支之后
3. 每修改一题立即编译验证 + 用原题锚点确认
4. 不要用正则批量替换（上次已失败）
5. 修改后更新 statement.md 和 data/
