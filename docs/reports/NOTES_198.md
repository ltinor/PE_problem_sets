# PE198 两可数分析笔记 (2026-09-17)

## 定义
x = p/q (既约) 两可 ⟺ 存在分母上限 d₀, 使得 x 在 F_{d₀} 中的下/上邻居与 x 等距.

## 已推导的特征 (部分)
x = p/q 两可 ⟺ x 是某相邻 Farey 对 (a/b, c/d) (bc−ad=±1) 的中点:
  x = (ad+bc)/(2bd), 既约后 p/q.
给定既约 x = p/q, 2x = m/n (m/n = 2p/q 既约):
  中点条件 => k(m·b' − n·a') = ±1 (k = 未约分倍数) => k = 1
  => m/n 必须是"未约分中点" => m 奇 (t₁t₂ = (m²−1)/4 需整数根).
  => p 奇且 q 偶 (m=2p/g, g=gcd(2p,q); m 奇 ⟺ g ⊇ 2 的全部因子).

## 可行的 q 分裂
q = b·d, d | (p−1)/2, b | (p+1)/2 (p 奇 => (p±1)/2 互素 => (d,b) 与 q 一一对应, 无重复计数).

## 根因: 特征判据漏了 "交换方向" 的拆分

正确的两可特征: x = p/q (p 奇, q 偶) 两可 ⟺ 存在因子拆分
  q = d*b, 满足 (d | (p-1)/2 且 b | (p+1)/2) **或** (d | (p+1)/2 且 b | (p-1)/2)

例: x = 199001/99501000: d = 99501 | (p+1)/2 = 99501 ✓, b = 500 | (p-1)/2 = 99500 ✓
  (旧判据只查了 d | (p-1)/2 = 99500, 99501 不在其中 => 漏)

原推导的 k=1 强制结论错在: 把"中点"(a/b + c/d)/2 = (ad+bc)/(2bd)
  与"和媒介"(a+c)/(b+d) 混淆了. 中点的行列式条件是 bc-ad = ±1 本身,
  没有额外的 k 约束.

## 最终解决 (2026-09-19)

完整推导发现此前所有版本的关键错误: 枚举 q = d*b 少乘了 2, 且 k > 1 的层级
根本不存在 —— 由 gcd(k, p^2*k^2-1) = 1 与整除要求强制 k = 1.

### 正确特征 (充分必要)
x = p/q (既约) 两可 <=> p 奇, q 偶, 且 q/2 | (p-1)/2 * (p+1)/2 (即 p^2 = 1 mod 2q),
等价地存在 d | (p-1)/2, b | (p+1)/2 使 q = 2*d*b, 且自动满足 max(b,d) < q.

推导链:
1. 两可 <=> 存在相邻 Farey 对 (a/b, c/d) (bc-ad=1) 以 x 为中点, 且 max(b,d) < q
   (分母上限 d0 可取 [max(b,d), b+d) 与 [1, q) 的交, 非空).
2. 中点条件 q(ad+bc) = 2pbd. 设 2x = m/n 既约, 则 bd = nk, bc = (mk+1)/2, ad = (mk-1)/2.
3. k | p^2*k^2 - 1 但 gcd(k, p^2*k^2-1) = 1 => k = 1. 层级塌缩.
4. k=1: bd = q/2, b | (p+1)/2, d | (p-1)/2. "双向并集"是多余的:
   方向选择已被 (d,b) 因子拆分的枚举自然涵盖 (A,B 互素, 拆分一一对应).

### 计数实现 (198/code/std.cpp)
- p = 1: A = 0, 任意偶 q ∈ (100, Q], 贡献 Q/2 - 50 = 49,999,950 @ Q=1e8.
- 3 <= p < Q/100: 枚举 A/B 因子对, 统计乘积 ∈ (50p, Q/2].
  A,B 互素 => 因子对乘积两两不同, 无需按 q 去重 (此前 52,978,634 的多计
  正是没有乘 2 导致错误过滤 + 双向重复的混合症状).
