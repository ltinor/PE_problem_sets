# PE198 两可数分析笔记 (2026-09-17)

## 定义
x = p/q (既约) 两可 ⟺ 存在分母上限 d₀, 使得 x 在 F_{d₀} 中的下/上邻居与 x 等距.

## 已推导的特征 (部分)
x = p/q 两可 ⟺ x 是某相邻 Farey 对 (a/b, c/d) (bc−ad=±1) 的中点:
  x = (ad+bc)/(2bd), 既约后 p/q.
给定既约 x = p/q, 2x = m/n (m/n = 2p/q 既约):
  中点条件 => k(m·b' − n·a') = ±1 (k = 未约分倍数) => k = 1
  => m/n 必须是"未约分中点" => m 奇 (t₁t₂ = (m²−1)/4 需整数根).
  => p 奇且 q 偶 (m=2p/g, g=gcd(2p,q); m 奇 ⟺ g ⊇ 2 的全部因子).

## 可行的 q 分裂
q = b·d, d | (p−1)/2, b | (p+1)/2 (p 奇 => (p±1)/2 互素 => (d,b) 与 q 一一对应, 无重复计数).
