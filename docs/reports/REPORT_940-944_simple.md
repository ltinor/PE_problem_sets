# PE 940–944 简单版本改造报告

将 5 道 Project Euler 题（940–944）改为“简单版本”：缩数据 + 可验证算法，
`main` 参数化（从 stdin 读参数、输出答案），并与给定验证点逐一核对。

验证方式：每题分别编译 `code/std.cpp`，喂入验证点输入，比对输出；同时用

## 940 二维递归 Two-Dimensional Recurrence

- **缩数据范围**：原题求 `S(50) mod 1123581313`（f₅₀≈1.25×10¹⁰，需 O(log) 闭式解）；
  简单版本缩到 `k ≤ 20`（f₂₀=6765），输入 `k`，输出 `S(k) mod 1123581313`。
- **算法**：由原始两条递推消元得单向递推
  `A(m+2,n)=3A(m+1,n)+A(m,n)`、`A(m,n+2)=A(m,n+1)+3A(m,n)`；
  先沿 n 方向递推出 `A(0,*)`、`A(1,*)`（初值 A(0,0)=0,A(0,1)=1,A(1,0)=1,A(1,1)=2），
  再对每个需要的列 `n=f_j` 沿 m 方向填满，累加 `A(f_i,f_j)`。时间 O(k·f_k)，几秒内完成。
- **验证结果**：`S(3)=30 ✓`、`S(5)=10396 ✓`；brute（全表 DP）对拍一致。

## 941 de Bruijn 组合锁 de Bruijn's Combination Lock

- **缩数据范围**：原题 `C(10,12)`（长度 10¹²）且要算 Lyndon 排名求和，难度极大；
  简单版本缩到 `k,n` 很小（`k^n ≤ 1e6`），输入 `k n`，输出字典序最小的 de Bruijn 序列 `C(k,n)`。
- **算法**：FKM（Fredricksen–Kessler–Maiorana）——字典序最小的 de Bruijn 序列 =
  所有「长度整除 n 的 Lyndon 词」按字典序拼接，再取周期串的前 `k^n+n-1` 个字符；
  Lyndon 词用 Duval 算法按字典序生成（O(数量)）。
- **验证结果**：`C(3,2)=0010211220 ✓`；brute（枚举所有串 + 显式判 Lyndon 词）对拍一致。

## 942 梅森平方根 Mersenne's Square Root

- **缩数据范围**：原题 `q=74207281`（p=2^q−1 天文数字，需 O(q) 次 Mersenne 归约平方）；
  简单版本缩到 `q ≤ 62`（p 可装入 128 位），输入 `q`，输出最小平方根 `R(q)`（无解输出 -1）。
- **算法**：`p=2^q−1` 对 q≥2 恒有 p≡3 (mod 4)，故 `x=q^((p+1)/4) mod p`（即对 q 连续平方 q−2 次）；
  若 `x²≡q` 则 `R=min(x,p−x)`，否则（非二次剩余/合数）退回线性搜索。
- **验证结果**：`R(5)=6 ✓`、`R(17)=47569 ✓`；brute（线性枚举）对拍一致。

## 943 自描述数列 Self Describing Sequences

- **缩数据范围**：原题 N=22332223332233 且要 ~5 万组 (a,b) 求和，需 O(log N) 分形加速；
  简单版本缩到 `N ≤ 1e6`，输入 `a b N`，输出 `T(a,b,N)`。
- **算法**：直接按定义逐段生成：`seq[0..a-1]=a`（第 0 段是 a 个 a），
  第 j 段长度为 `seq[j]`、符号「j 偶?a:b」，逐段追加直到 ≥N，累加前 N 项。时间 O(N)，秒出。
- **验证结果**：`T(2,3,10)=25 ✓`、`T(4,2,10^4)=30004 ✓`、`T(5,8,10^6)=6499871 ✓`；
  brute（独立重写直接生成）对拍一致。

## 944 元素因数之和 Sum of Elevisors

- **缩数据范围**：原题 `S(10^14) mod 1234567891`（需 O(√n) 整除分块）；
  简单版本缩到 `n ≤ 1e7`，输入 `n`，输出 `S(n) mod 1234567891`。
- **算法**：线性性 + 计数得闭式
  `S(n) = 2^{n-1}·n(n+1)/2 − Σ_{x=1..n} x·2^{n−⌊n/x⌋}`；
  第二项用整除分块（⌊n/x⌋ 只有 O(√n) 段），指数经费马小定理约化。
- **验证结果**：`S(10)=4927 ✓`；brute（枚举全部 2ⁿ 子集按定义统计）在 n≤16 对拍一致。
