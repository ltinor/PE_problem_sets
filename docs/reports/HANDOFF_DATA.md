## P1：为 528 个单点题追加参数化测试

每题的 std.cpp 通过 `cin >>` 读参数。步骤：
1. 读 std.cpp 确定变量数 nvars 和含义
2. 生成 3 组输入：
   - 最小值（如 1, 2）
   - 常规值（如 10, 100, 1000）
   - 边缘值（接近 MAX 常量）
3. 运行 std 捕获输出
4. 跳过输出为 0/空/TIMEOUT 的
5. 保存为 02.in/out, 03.in/out, 04.in/out（01 留给 PE 探针）

去重：相同输出只存一次。

## P2：37 题无 data 的处理

这些题原参数太大导致 TIMEOUT。方案：
1. 读 std.cpp 确定参数含义
2. 使用缩小版参数（如原题 10^8 改为 10^4）
3. 确保 std 能在 15s 内完成
4. 生成 data 并标注"缩小参数版"

## 注意事项

1. 五道缩规模题的 data 优先恢复（这些验证数据是算法正确性的证据）
2. data 的 .out 由 std 自身生成——只验证一致性，不验证正确性
3. 独立正确性验证依赖：原题锚点 + 暴力对拍 + 官方答案
4. 格点吸附模拟（935）对非格点分数会产生伪回归——仅用于格点分数
5. 修改 data 后运行 `python _tools/audit/statement_audit.py` 确认无回归
