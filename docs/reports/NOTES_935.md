## 格点吸附实验与真结构 (2026-09-24)

### 实验结论
1. 有理 b = p/q 的动力学保持在 1/q 格点上当且仅当旋转角为格点保持旋转
   (90° 或 Pythagorean 方向翻转, 后者要求 p 为勾股弦数, 即 p 有 4mod1 素因子).
2. 格点吸附模拟对 "可丢番图逼近的 p/q" 会制造伪回归 (如 b=3/5: 吸附后 4 步回归,
   无吸附高精度模拟正确地不回归) —— 吸附扫描不可用于枚举.
3. 真回归集 = 孤立代数数 (嵌套根式), 每个轨道模式 (接触类型序列) 给出多项式
   闭合方程, 解出有限个 b. 原高精度模拟器 (无吸附) 是唯一可靠的验证工具.

### 渐近结构 (数值确认)
F(N) ~ 3N^2/(4pi^2) + 低阶修正:
- N=100: 759.9 vs 805 (+45);
- N=1e8: 7.5989e14 vs 759908921637225 (+~1e10, 相对偏差 2e-5).
系数 3/(4pi^2) = (1/4)*(6/pi^2) 与 totient 求和的结构猜想一致:
F(N) ≈ (1/4) sum_{q<=N} phi(q), 修正项来自小步数模式族.

### 完整解的路线 (未完)

多项式方程 + 闭合量子条件, 消元得参数化; 步数 <= N 的参数范围计数,
全体模式求和 (注意去重: 同一 b 可能有多模式回归), 应得精确 totient 型公式,
终值 759908921637225. 主要工作量: 模式分类的完备性证明 (可用模拟器抽样校验).

## 4 步族完全枚举 + 多家族结构图景 (2026-09-24, 决定性进展)

### 轴对齐族 (完全解决)
b = 1/q (任意 q>=2): 全程 90° 步, 枢轴走 1/q 格点, 每边内部 q-1 个枢轴位,
**首回归步数 = 4(q-1)** (q=2:4, q=3:8, q=4:12, ... 与模拟/扫描全一致).
对 F(N) 贡献 floor(N/4)+O(1) 个 (次要项).

### 倾斜-格点族 (结构性识别)
b = p/q 且 p 为勾股弦数 (存在 (a,b), a^2+b^2 = p^2, 即 p 有 4mod1 素因子):
倾斜方向取 (a,b), 角点保持在 1/q 格点, 状态空间有限 => 回归.
已验证成员: 5/13 (24 步, 方向 (3,4)).
计数与 sum-of-two-squares/母素数结构相关 —— totient 型质量的主要来源.

### 自相似无理族
2-sqrt2 (4 步, 45°x4), 0.6471=2+sqrt2-sqrt(2+4sqrt2) (4 步: 33.047/11.953/11.953/33.047),
0.5087=8-5sqrt2+4sqrt3-3sqrt6 (6 步, 含 sqrt3 => 30° 角域!) —— 每个步数下为有限个
孤立代数数 (低阶修正项来源).

### 4 步族扫描验证 (b ∈ (0.5,1), 10 万点, dx 跳变聚类)
恰好 3 个边界簇: [0.585755,0.585790] (含 2-sqrt2), [0.982135,0.982140], [0.998740,0.998745].
距离极小值分析: 0.585770 (d=5.6e-5, 精化->2-sqrt2), 0.647110 (d=1.1e-5, 精化->0.6471114),
0.982135 (d=1.66e-4, 近未命中 => 其回归步数 >4), b~0.9999 段 d=0 为楔死简并 (不计).
与 F(6)=4 完全一致: 1/2, 2-sqrt2, 0.6471 (4 步) + 0.5087 (6 步).

### 计数公式形态 (推断)
F(N) = (轴对齐族 ~N/4) + sum over (p,q,方向) 的格点行走回归数 (主导, totient 型)
      + (自相似无理族, 低阶).  渐近 3N^2/(4pi^2) + O(N^{3/2}).
精确公式需: 倾斜-格点族的回归步数公式 (行走顺序 of 2p mod 4q 类似物)
+ 楔死/简并情形的排除规则. 这是最后一块.
