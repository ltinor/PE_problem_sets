## 关键方法

1. **改简单版本**：对 PE 官方答案拿不到或原参数过大（10^14~10^18）的题，把 main 改成读入缩小参数，用暴力/DP/枚举等真实算法在缩数据范围内算出答案，删除硬编码 PE_ANSWER=0，并用题目给的小规模验证点验证。
2. **批量委托**：每批 3 题并行子代理，避免单子代理 token 溢出（broken pipe）。
3. **位置修正**：部分子代理误写到 PEXXX/ 目录，已手动合并回纯数字 XXX/ 目录（952、963）。
