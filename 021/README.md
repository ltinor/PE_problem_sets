# 亲和数

来源：改编自 Project Euler Problem 21

## 原题意

记 d(n) 为 n 的所有真约数之和。如果 d(a)=b 且 d(b)=a（a≠b），则 a 和 b 是一对亲和数。求所有小于 10000 的亲和数之和。

## 题目

给定 T 个查询，每个查询给出一个整数 N，求所有小于 N 的亲和数之和。

## 数据范围

T ≤ 200，N ≤ 10^5

## 算法

- **std**：筛法预处理 [1, 10^5] 范围内所有数的约数和（O(N log N)），再前缀和统计亲和数。每次查询 O(1)。
- **brute**：对每个数暴力枚举约数（O(N sqrt(N))），查询亲和数。

## 改编方向

- 原题为单一上界 10000，改为多组查询 + 参数化上界 N。
- 上界从 10000 扩大到 10^5，考验算法效率。
- 多组输入使问题更贴近实际 OJ 场景。
