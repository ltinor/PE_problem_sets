# 约数平方和

## 题目描述

对于正整数 n，记 σ₂(n) 为 n 的所有正约数的平方和。例如：

σ₂(10) = 1² + 2² + 5² + 10² = 1 + 4 + 25 + 100 = 130

给定 N，求所有满足 n ≤ N 且 σ₂(n) 为完全平方数的 n 之和。

---

## 输入格式

一行，一个整数 N（1 ≤ N ≤ 10⁷）。

---

## 输出格式

一个整数，表示满足条件的 n 之和。

---

## 样例

### 输入
```
100
```

### 输出
```
287
```

### 解释
n ≤ 100 中满足 σ₂(n) 为完全平方数的有：
- n=1: σ₂=1²=1 ✓
- n=42: σ₂=1²+2²+3²+6²+7²+14²+21²+42²=2500=50² ✓
- n=44: σ₂(n)=2500=50² ✓ (还有其他)
和为 287。

---

## 数据范围

- 1 ≤ N ≤ 10⁷
- PE 答案: N = 64,000,000 → 1922364685
