# Divisor Square Sum

来源：改编自 Project Euler Problem 211

## 原题意

对于正整数 n，σ₂(n) 定义为 n 的所有约数的平方和。在 n < 64,000,000 中，求所有满足 σ₂(n) 为完全平方数的 n 之和。

## 题目

给定 N（1 ≤ N ≤ 10⁷），求所有满足 n ≤ N 且 σ₂(n) 为完全平方数的 n 之和。

## 数据范围

- 1 ≤ N ≤ 10⁷
- PE 答案: N = 64,000,000 → 1922364685

## 算法

筛法预处理 σ₂(n)：对于每个 i，将 i² 加到 i 的所有倍数上。复杂度 O(N log N)。然后检查每个 σ₂(n) 是否为完全平方数。

## 改编方向

1. **参数化 N**（采用）：将固定上限 64M 改为可变输入 N ≤ 10⁷
2. **多组测试数据**（未采用）：每题一个 N，单次查询即可
3. **参数化指数**（未采用）：可推广到 σ_k(n)，但偏离原题难度
