# 连续数字最大乘积

## 题目描述

给定一个 $L$ 位数 $S$ 和一个整数 $K$（$1 \le K \le \min(L, 100)$），请你求出 $S$ 中连续 $K$ 个数字的最大乘积。

例如，对于$10$位数

$1234567890$

若 $K = 2$，则连续两位数字的最大乘积是 $9×8 = 72$。


---

## 输入格式

第一行一个整数 $T(1 ≤ T ≤ 10^4)$，表示测试数据组数。  
接下来 $T$ 组数据，每组两行：  
第一行两个整数 $L$ 和 $K(1 ≤ L ≤ 1000，1 ≤ K ≤ min(L, 100))$  
第二行一个 $L$ 位数字 $S$  

---

## 输出格式

对于每组测试数据，输出一行一个整数，表示连续 $K$ 位数字的最大乘积。

---

## 样例

### 输入
```
2
10 2
1234567890
5 3
36791
```
### 输出
```
72
126
```
---

## 数据范围

$1 ≤ T ≤ 10^4$  
$1 ≤ L ≤ 1000  $
$1 ≤ K ≤ min(L, 15)$
