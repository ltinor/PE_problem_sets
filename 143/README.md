# 托里拆利点 (Torricelli Point)

来源：改编自 Project Euler Problem 143

## 原题意

三角形 ABC 所有内角 < 120°。点 X 在三角形内，XA=p, XB=q, XC=r。
当 p+q+r 最小时，若 a,b,c,p,q,r 均为整数，称 ABC 为托里拆利三角形。
求所有满足 p+q+r ≤ 120000 的不同 p+q+r 值之和。

原题答案：30758397

## 题目

给定 M（≤120000），求所有满足 p+q+r ≤ M 的不同 p+q+r 值之和。

## 数据范围

- 1 ≤ M ≤ 120000

## 算法

托里拆利三角形的必要条件是（余弦定理，120°）：
- p² + q² + pq = a²（完全平方数）
- q² + r² + qr = b²
- r² + p² + rp = c²

枚举 p ≤ q ≤ r 满足上述条件，用 set 收集 p+q+r。

可以优化：预计算满足 u²+v²+uv = w² 的所有数对，加速查询。
