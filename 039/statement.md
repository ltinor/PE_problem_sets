# 整数边长直角三角形

## 题目描述

考虑三边长 {a,b,c} 均为整数的直角三角形，并记其周长为 p = a + b + c。当 p=120 时，恰好存在三个不同的解：

{20,48,52}, {24,45,51}, {30,40,50}

在所有的 p ≤ 1000 中，p 取何值时有最多个解？答案是 p=840（共有 8 组解）。

现在将问题一般化：给定 P，求在 p ≤ P 中，哪个周长 p 拥有最多的整数边长直角三角形解。如果有多个 p 的解数相同，输出最小的 p。

---

## 输入格式

多组测试数据，每行一个整数 P（1 ≤ P ≤ 5000）。读取到文件末尾结束。

---

## 输出格式

对于每组数据，输出一行一个整数，表示解最多的最小周长 p。

---

## 样例

### 输入

```
120
1000
```

### 输出

```
120
840
```

---

## 数据范围

- 1 ≤ P ≤ 5000
- 测试数据组数不超过 10 组
