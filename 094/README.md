# 几乎等边的三角形

来源：改编自 Project Euler Problem 94

## 原题意

求所有周长不超过 $10^9$ 的、边长和面积均为整数、且有两边相等第三边与这两边相差不超过 $1$ 的三角形的周长之和。答案：518408346。

## 题目

给定整数 $M$，求所有满足以下条件的三角形的周长之和：
- 三角形有两边相等，第三边与这两边相差恰好为 $1$；
- 三边长均为正整数；
- 面积为整数；
- 周长不超过 $M$。

## 数据范围

$1 \le M \le 10^9$。

## 算法

本题可以转化为 Pell 方程求解。设三角形三边为 $(a, a, b)$，其中 $|a-b|=1$。

- 情形 1：$b = a+1$。由海伦公式，面积为整数等价于 $3a^2-2a-1$ 为完全平方数。
- 情形 2：$b = a-1$。同理，等价于 $3a^2+2a-1$ 为完全平方数。

令 $x = 3a \mp 1$（情形 1 取减号，情形 2 取加号），$y = k$（其中 $k^2 = 3a^2 \mp 2a - 1$），则有：
$$x^2 - 3y^2 = 4$$

这是一个 Pell 型方程。其所有解可由递推生成：
$$(x_{n+1}, y_{n+1}) = (2x_n + 3y_n, x_n + 2y_n)$$

从 $(x_0, y_0) = (4, 2)$ 出发，生成的所有解交替对应情形 1 和情形 2。对于每个解：
- 若 $x \equiv 2 \pmod 3$（情形 1），周长 $P = x + 2$；
- 若 $x \equiv 1 \pmod 3$（情形 2），周长 $P = x - 2$。

累加所有 $P \le M$ 的值即可。

暴力解法直接枚举 $a$，对每个 $a$ 检查两种情形。
