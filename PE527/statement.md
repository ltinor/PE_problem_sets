# 随机二分搜索

## 题目描述

在 1 到 n 中随机选择一个整数 t 作为秘密整数。通过不断猜测整数 g 来确定 t 的值。

标准二分搜索：g = ⌊(L+H)/2⌋（L、H 为当前上下界）。
随机二分搜索：g 为 L 到 H 之间的均匀随机整数。

记 B(n) 为标准二分搜索找到 t 所需猜测的期望次数，R(n) 为随机二分搜索的期望次数。

已知：B(6) = 2.33333333，R(6) = 2.71666667（保留 8 位小数）。

给定 n，求 R(n) − B(n)，结果保留 8 位小数。

## 输入格式

一行，一个整数 n，或字符串 `PE`。

## 输出格式

一个浮点数，保留 8 位小数。

## 样例

### 输入
```
6
```

### 输出
```
0.38333333
```

## 数据范围

- 对于 30% 数据：n ≤ 100
- 对于 60% 数据：n ≤ 5000
- 对于 100% 数据：n ≤ 10¹⁰
