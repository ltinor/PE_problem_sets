# PE527 - 随机二分搜索

来源：改编自 Project Euler Problem 527

## 原题意

秘密整数 t 随机选自 [1, n]。标准二分搜索每次猜测 g = ⌊(L+H)/2⌋，随机二分搜索则均匀随机选择 g ∈ [L, H]。

记 B(n) 为标准二分搜索的期望猜测次数，R(n) 为随机二分搜索的期望猜测次数。
已知：B(6) = 2.33333333, R(6) = 2.71666667。

求 R(10¹⁰) − B(10¹⁰)，保留 8 位小数。

PE 答案：11.49284729。

## 题目

给定 n，计算 R(n) − B(n)，保留 8 位小数。

## 算法

- B(n) 通过二叉树深度和的递推公式 O(log n) 精确计算。
- R(n) 有闭式解：R(n) = 2×(n+1)/n × H_n − 3，其中 H_n 为调和数。
- 调和数 H_n 使用欧拉-麦克劳林渐近展开计算，对 n=10¹⁰ 精度足以满足 8 位小数。
- 小规模 n 使用 DP 验证闭式解。

## 改编方向

1. **非均匀随机**：猜测值不再均匀，而是倾向中点。
2. **三维/高维搜索**：多个秘密整数同时猜测。
3. **有噪声反馈**：回答有时出错。
4. **最小化最坏情况而非期望**。
