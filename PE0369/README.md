# 百得之

来源：改编自 Project Euler Problem 369

## 原题意

从 52 张扑克牌中选 n 张，含 4 张"百得之"（无对子、无同花色）的组合数 f(n)。求 Σf(n), n=4..13。PE 答案：8624002。

## 题目

给定标准扑克牌参数（花色数 S，每花色点数 R），求含特定模式子集的组合数之和。

## 数据范围

S ≤ 4, R ≤ 13

## 算法

### 方向一：组合计数 + 容斥

"百得之"即 4 张牌点数互异且花色互异。用组合数学直接计算：从 R 个点数中选 4 个，从 S 个花色中选 4 个并分配。对于含 k 张牌的集合，容斥计算至少含一个百得之的方案数。

### 方向二：DP 按点数/花色枚举

按点数维度 DP：dp[i][j][mask] 表示前 i 个点数选了 j 张牌的花色分布。最终统计含 4 个不同花色的方案。

### 方向三：生成函数

用生成函数编码每张牌的选择，多项式乘法统计含特定模式的项数。

### 时间复杂度

O(S × R × 2^S)，可快速计算。
