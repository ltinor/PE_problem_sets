# 218 — 完美直角三角形

来源：改编自 Project Euler Problem 218

## 原题意

定义"完美直角三角形"：原始直角三角形（三边互质）且斜边为完全平方数。
定义"超级完美直角三角形"：完美直角三角形的面积是 6 和 28 的倍数（即 84 的倍数）。
求 c ≤ 10^16 的完美直角三角形中有多少个不是超级完美的。原题答案：0。

## 题目

参数化 C：输入 C（≤ 10^16），求 c ≤ C 的完美直角三角形中非超级完美的个数。

## 数据范围

- 1 ≤ C ≤ 10^16

## 算法

**std**: 数学定理：所有完美直角三角形都是超级完美的（答案恒为 0）。枚举验证：
- 原始勾股数：a = m²−n², b = 2mn, c = m²+n²
- 完美条件：c = k² → m = u²−v², n = 2uv, k = u²+v²
- 面积 = ab/2 = (m²−n²)mn，可证明始终被 84 整除
- 枚举 (u,v) 计数并验证面积条件。

**brute**: 对于 C ≤ 10^8，直接枚举 c=k²，寻找原始勾股数 a²+b²=c²。

## 改编方向

1. **参数化 C**：将固定上界 10^16 改为可变输入。
2. **数学验证**：实现枚举算法同时验证"答案恒为 0"的数学结论。
3. **PE 答案**：C=10^16 时答案为 0。
