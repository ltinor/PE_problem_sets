# 数字阶乘链

## 题目描述

对一个正整数，定义操作 $f(x)$ 为：将 $x$ 的每一位数字分别取阶乘然后求和。例如 $f(145) = 1! + 4! + 5! = 145$。

不断重复此操作会形成一条链：$x \to f(x) \to f(f(x)) \to \dots$。可以证明，从任意正整数出发，最终都会进入一个循环。

定义链的长度为从起始数到第一次出现重复之前所经过的不同数字的个数。

---

## 输入格式

一行，两个整数 $N$ 和 $K$，以空格分隔。

---

## 输出格式

一个整数，表示所有小于 $N$ 的正整数中，有多少个数产生的链长恰好为 $K$。

---

## 样例

### 输入
```
1000000 60
```

### 输出
```
402
```

**解释**：从 69 开始可得 5 个不同项。原题中，小于一百万的数最多可得 60 个不同项，恰好有 402 个数满足此条件。

---

## 数据范围

- $1 \le N \le 10^6$
- $1 \le K \le 60$
