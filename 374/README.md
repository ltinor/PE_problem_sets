# 374 — 整数分拆最大乘积

来源：改编自 Project Euler Problem 374

## 原题意

f(n) = n 的不等分拆中部分乘积最大值，m(n) = 相应部分数。求 ∑f(n)·m(n)，n ≤ 10¹⁴，模 982451653。

## 题目

给定 N，求 ∑_{n=1}^N f(n)·m(n) mod 982451653。

## 数据范围

N ≤ 10⁷。

## 算法

1. **贪心+解析公式**：最优分拆由连续整数 {2,3,...,k+1} 加调整组成。对每个 k 批量计算 O(√N)。
2. **DP（小数据验证）**：0/1 背包，O(N√N)。
3. **生成函数**：利用分拆生成函数和模运算优化。
