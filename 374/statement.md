# 整数分拆最大乘积

## 题目描述

整数 n 的不等分拆（distinct parts partition）是将 n 写成不同正整数的和。记 f(n) 为所有不等分拆中各数乘积的最大值，m(n) 为达到该乘积的分拆中正整数的个数。

已知：对于 1 ≤ n ≤ 100，∑f(n)·m(n) = 1683550844462。

给定 N，求 ∑_{n=1}^N f(n)·m(n) 对 982451653 取模的值。

---

## 输入格式

一行一个整数 N (1 ≤ N ≤ 10⁷)。

---

## 输出格式

一行一个整数，表示答案模 982451653。

---

## 样例

### 输入
```
100
```

### 输出
```
611162873
```

---

## 数据范围

1 ≤ N ≤ 10⁷。
