# 071 - 有序分数的左邻

来源：改编自 Project Euler Problem 71

## 原题意

将 d≤1,000,000 的所有最简真分数按大小升序排列，求 3/7 直接左邻的分数的分子。
答案：428570。

## 题目

输入 N, a, b，求 d≤N 的所有最简真分数中，a/b 直接左邻的分数的分子。

## 数据范围

- N ≤ 10^6
- a < b，gcd(a,b) = 1
- 多组测试数据（T ≤ 10）

## 算法

对于每个分母 d，最大的满足 n/d < a/b 的分子 n = floor((a*d-1)/b)。
在所有 gcd(n,d)=1 的 (n,d) 对中，找到使 n/d 最大的那个，输出其分子 n。
