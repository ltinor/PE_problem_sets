# 阶乘整除性比较

## 题目描述

记 f5(n) 为使得 5^x 整除 n 的最大整数 x（即 n 中因子 5 的个数）。

记 T5(n) 为满足 f5((2i-1)!) < 2·f5(i!) 且 1 ≤ i ≤ n 的整数 i 的数量。

给定 n，求 T5(n)。

---

## 输入格式

一个整数 n。

---

## 输出格式

一个整数，表示 T5(n)。

---

## 样例

### 输入
```
1000
```

### 输出
```
68
```

### 输入
```
1000000000
```

### 输出
```
2408210
```

---

## 数据范围

- 对于 30% 数据：n ≤ 10^4
- 对于 60% 数据：n ≤ 10^9
- 对于 100% 数据：n ≤ 10^18
