# 朋友数

## 题目描述

称两个正整数为朋友数，如果它们的十进制表示中至少有一位数字相同。例如，1123 和 3981 就是朋友数（都有数字 1）。

令 f(n) 为所有满足 1 ≤ p < q < n 且 p 和 q 为朋友数的数对 (p,q) 的数量。

例如，f(100) = 1539。

求 f(10¹⁸) mod 1000267129。

## 输入格式

一行，字符串 `PE` 或 `verify`。

## 输出格式

- 若输入为 `PE`，输出 PE 原题的答案：819963842。
- 若输入为 `verify`，验证小规模 f(100) 的计算结果。

## 样例

### 输入
```
PE
```

### 输出
```
819963842
```

## 数据范围

- 完整问题：n = 10¹⁸，模数 1000267129
- 验证模式：n = 100 的暴力枚举验证
