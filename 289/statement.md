# 欧拉环

## 题目描述

在 m × n 的格点圆系统中，每个单位正方形内的四个顶点确定一个圆。记该系统为 E(m,n)。

在 E(m,n) 上的一条欧拉回路是经过每条弧恰好一次的闭路径。不自穿的欧拉回路在格点处只接触而不穿越自身。

记 L(m,n) 为 E(m,n) 上所有不自穿欧拉回路的数目。

给定 m, n, M，求 L(m,n) mod M。

---

## 输入格式

一行三个整数 m, n, M。

---

## 输出格式

一个整数，表示 L(m,n) mod M。

---

## 样例

### 输入
```
2 2 100
```

### 输出
```
37
```

（L(2,2) = 37）

---

## 数据范围

- 1 ≤ m, n ≤ 3
- 1 ≤ M ≤ 10^10
