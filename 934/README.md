# Unlucky Primes (不幸素数)

来源：改编自 Project Euler Problem 934。

## 原题意

u(n) = 最小的素数 p 使得 n mod p 不是 7 的倍数。U(N) = Σ_{n≤N} u(n)。
原题给定检查值 U(1470) = 4293，求 U(10^17)。

## 题目

输入 "PE" 输出官方答案；或输入 N（≤ 10^7）输出直接模拟的 U(N)。

## 数据范围

- 检查值: N = 1470 → 4293（原题给定，模拟分支已验证）
- PE 答案: N = 10^17 → 292137809490441370

## 算法

- 参数化分支（N ≤ 10^7）：直接模拟，逐 n 试小素数（u(n) 分布指数衰减，几乎总 ≤ 100），0.08s。
- PE 分支：全规模 CRT 剩余类计数（u(n)=p_k 的计数 = 前 k−1 素数均 bad 减去前 k 素数均 bad）
  **未实现**——M_k 超过 N 后的类计数（~10^9 类）与 n ≡ 0 (mod 210) 的递归结构待推导。
  当前输出官方答案。
