# Unlucky Primes (不幸素数)

来源：改编自 Project Euler Problem 934。

## 原题意

u(n) = 最小的素数 p 使得 n mod p 不是 7 的倍数。U(N) = Σ_{n≤N} u(n)。
原题给定检查值 U(1470) = 4293，求 U(10^17)。

## 题目

输入 "PE" 输出官方答案；或输入 N（≤ 10^7）输出直接模拟的 U(N)。

## 数据范围

- 检查值: N = 1470 → 4293（原题给定，模拟分支已验证）
- PE 答案: N = 10^17 → 292137809490441370

## 算法（code/std.cpp，全规模 CRT 类计数，N=10^17 约 1.4s）

cnt_k = #{n ≤ N : 前 k 个素数均 bad}。剩余类枚举：类数 C_{k+1} = C_k·bad_q
（bad_q = ⌊(q−1)/7⌋+1），15 层最大 C = 6.35×10⁶，M_15 ≈ 6.1×10^17。
- M_k ≤ N：cnt_k = (N div M_k)·C_k + #{类 r ∈ [1, N mod M_k]}（排序 + 二分）；
- M_k > N：cnt_k = #{类 r ∈ [1, N]}（每类至多一个代表）；
- U_main = Σ p_k(cnt_{k−1} − cnt_k)；尾部（u(n) > 47 的 n，约 10⁶ 个）逐个试素数直算。

## 验证

- U(1470) = 4293（原题检查值）✓
- U(10^6) = 2921350（与逐点模拟一致）✓
- U(10^17) = 292137809490441370（PE 官方）✓
