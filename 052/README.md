# 重排的倍数 (Permuted Multiples)

来源：改编自 Project Euler Problem 52

## 原题意

$125874$ 和它的两倍 $251748$ 拥有同样的数字，只是排列顺序不同。求最小的正整数 $x$，使得 $2x, 3x, 4x, 5x, 6x$ 都拥有与 $x$ 相同的数字。

## 题目

给定整数 $M$（$2 \le M \le 6$），求最小的正整数 $x$，使得 $2x, 3x, \ldots, Mx$ 都是 $x$ 的数字重排（即包含完全相同的数字，只是顺序不同）。

## 数据范围

- $2 \le M \le 6$

## 算法

- **std**: 从 $x=1$ 开始枚举，检查 $2x$ 到 $Mx$ 是否都是 $x$ 的重排。重排检查通过将数字转为字符串并排序后比较实现。
- **brute**: 相同的枚举逻辑，重排检查通过统计各位数字出现次数实现（独立实现）。
