# 重排的倍数

## 题目描述

给定整数 $M$，求最小的正整数 $x$，使得 $2x, 3x, \ldots, Mx$ 都是 $x$ 的数字重排（即包含完全相同的数字，只是排列顺序不同）。

例如，$M=2$ 时，$x=125874$，$2x=251748$，两者包含相同的数字。

---

## 输入格式

一行一个整数 $M$。

---

## 输出格式

一行一个整数 $x$。

---

## 样例

### 输入

```
2
```

### 输出

```
125874
```

### 输入

```
6
```

### 输出

```
142857
```

---

## 数据范围

- $2 \le M \le 6$
