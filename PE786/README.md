# PE786 — Billiard（台球）

来源：改编自 Project Euler Problem 786

## 原题意

一个台球从 $a \times b$ 矩形球桌的左下角以 45° 角击出，球在桌边弹性反弹。问题可能要求计算球回到起始角之前撞击桌边的次数，或计算满足特定轨迹条件的球桌尺寸个数。

PE 答案：18999616（约 $1.90 \times 10^7$）。

## 算法

1. **台球轨迹展开**：将反射路径展开为直线，球在一个由 $a/\gcd(a,b)$ 行、$b/\gcd(a,b)$ 列组成的网格中运动。
2. **撞击次数**：球回到角落前，竖直边撞击 $m-1$ 次、水平边撞击 $n-1$ 次（$m=a/g, n=b/g$），共 $m+n-2$ 次。
3. **经过的单位方格数**：球经过 $a+b-\gcd(a,b)$ 个单位方格。
4. **角落访问**：球在展开的 $m \times n$ 网格对角线上经过 $\gcd(m,n)+1$ 个角落。

## 改编方向

1. 推广到非 45° 角击球（斜率 $p/q$）
2. 考虑非矩形的多边形球桌
3. 计算球在回到角落前经过特定点的次数
4. 带摩擦或非弹性碰撞的变体
5. 统计所有尺寸球桌中满足撞击次数 $=k$ 的个数
