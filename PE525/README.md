# PE525 - 滚动椭圆

来源：改编自 Project Euler Problem 525

## 原题意

椭圆 E(a, b) 初始位置：x²/a² + (y-b)²/b² = 1。
椭圆沿 x 轴无滑动滚动一周。焦点轨迹长度与短轴无关：F(a,b)=2π·max(a,b)。
记 C(a,b) 为椭圆中心轨迹的长度。已知 C(2,4) ≈ 21.38816906。
求 C(1,4) + C(3,4)，四舍五入保留 8 位小数。

PE 答案：30.22902550。

## 题目

给定 a, b，计算 C(a,b)；或计算 C(a₁,b) + C(a₂,b)。

## 算法

- 数值积分（Simpson 法）计算弧长。
- 利用椭圆滚动几何关系推导出参数化公式。
- 核心被积函数：√(D² + (a²-b²)²·sin²φ·cos²φ / D²)，其中 D = a²sin²φ + b²cos²φ。
- 积分区间 [0, 2π]，对应于椭圆旋转一周。

## 改编方向

1. **不同曲线**：圆、抛物线、双曲线的滚动。
2. **空间曲线**：三维滚动的轨迹长度。
3. **非完整周期**：滚动角度不是 2π。
4. **曲面上的滚动**：椭圆在曲面上的滚动。
