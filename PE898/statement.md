# 时钟序列 II（Clock Sequence II）

## 题目描述

时钟序列是由递推关系 $a_{n+1} = f(a_n)$ 定义的序列。因为状态空间有限，序列最终必然进入循环。

考虑递推关系：$a_{n+1} = a_n + S(a_n)$，其中 $S(x)$ 表示 $x$ 的十进制各位数字之和。

对所有起始值 $a_0 = 1, 2, \ldots, M$，计算序列在进入循环前访问的不同值的数量的期望，然后令 $M \to \infty$ 求极限比例。

## 输入格式

无输入（固定参数问题）。

## 输出格式

输出一个浮点数，表示极限期望比例，保留 8 位小数。

## 样例

（无样例输入输出，直接计算并输出最终答案。）
