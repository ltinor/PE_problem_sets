# 因数的尾数

## 题目描述

对于一个正整数 $n$ 和数字串 $d$，记 $F(n, d)$ 为 $n$ 的因数中，十进制表示以 $d$ 结尾的个数。

例如 $F(84, 4) = 3$，因为 $84$ 的因数有 $1, 2, 3, 4, 6, 7, 12, 14, 21, 28, 42, 84$，其中以 $4$ 结尾的有 $4, 14, 84$ 共 $3$ 个。

可以验证：
- $F(12!, 12) = 11$
- $F(50!, 123) = 17888$

---

## 输入格式

两个整数 $n$ 和 $d$，用空格分隔。

---

## 输出格式

一个整数，表示 $F(n!, d) \bmod (10^{16} + 61)$（对于大 $n$）或 $F(n!, d)$（对于小 $n$）。

---

## 样例

### 输入
```
84 4
```

### 输出
```
3
```

### 输入
```
12 12
```

### 输出
```
11
```

---

## 数据范围

- 对于 30% 数据：$n \leq 8$，$d \leq 99$
- 对于 60% 数据：$n \leq 12$，$d \leq 999$
- 对于 100% 数据：$n \leq 8$ 或 $(n, d) = (12, 12), (50, 123), (10^6, 65432)$
