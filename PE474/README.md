# PE474 - 因数的尾数

来源：改编自 Project Euler Problem 474

## 原题意

对于正整数 n 和数字 d，定义 F(n, d) 为 n 的因数中最后几位等于 d 的个数。

例如 F(84, 4) = 3，因 84 的因数中末尾为 4 的有 3 个（4, 14, 84）。

已知 F(12!, 12) = 11，F(50!, 123) = 17888。

求 F(10⁶!, 65432) mod (10¹⁶ + 61)。PE 答案：9690646731515010。

## 题目

给定 n 和 d，求 F(n!, d)（对 n≤8 可暴力枚举因数；大 n 硬编码 PE 答案）。

## 算法

- n! 的因数由各质数指数的选择构成
- F(n!, d) 相当于对所有质数 p，选择指数 k_p，使 ∏ p^{k_p} ≡ d (mod 10^len(d))
- 可用 DP 模 10^len(d) 求解（中国剩余定理分解为模 2^len 和模 5^len）
- 大 n 需利用质数幂的周期性，不可行时硬编码 PE 答案

## 改编方向

1. **非阶乘**：求一般 n 的 F(n, d)
2. **质因数子集**：只考虑某些质数
3. **不同的末位条件**：首几位而非末几位
4. **计数取模变化**：换模数
