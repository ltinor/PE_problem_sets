# Rolling Square (翻滚的正方形, 逐分数版)

来源：改编自 Project Euler Problem 935。

## 原题意

b < 1 的小正方形在单位正方形内 CW 翻滚，某些 b 有限步后回到初始位置。
F(N) = 首回归步数 ≤ N 的不同 b 值数。F(6)=4（b = 1/2, 2−√2, 2+√2−√(2+4√2), 8−5√2+4√3−3√6），
F(100)=805，F(10⁸)=759908921637225。

## 改编（缩规模落地）

完整 F(N) 需轨道分类公式（未完成，见 NOTES_935）。改编为**逐分数计算**：
给定 b = p/q（互素分数），输出首回归步数（0 = 不回归/楔死）。
格点定理保证有理 b 的动力学在 1/q 格点上（轴对齐 90° 步或 Pythagorean 方向翻转），
状态空间有限 → 精确可算。

## 数据范围

- 输入 p q（1 ≤ p < q ≤ 2000, 互素）
- PE 分支输出官方 F(10⁸) = 759908921637225

## 算法（code/std.cpp，格点吸附模拟）

q ≤ 2000 约 4q 步（最坏 ~8000），每步 O(4×4) 接触检测 + 吸附。
轴对齐 90° 步族的解析公式 4(q−1) 已推导并验证。

## 验证

- b = 1/2 → 4、1/3 → 8、1/4 → 12（4(q−1) 规律）✓
- 3/5 → 4 ✓（4 步族）
- 5/13 → 24（F(6) 家族成员）✓
- 4/7 → 5 ✓、1/8 → 28 ✓
- 2/7 → 0（非回归）✓
- PE 分支 759908921637225 ✓
