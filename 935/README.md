# 翻滚的正方形（PE 935）

来源：改编自 Project Euler Problem 935。

## 原题意

边长 b<1 的小正方形在单位大正方形内绕接触角逐步顺时针翻滚（不滑动）。
对某些 b 值小正方形会在有限步后回到初始位置。F(N) = 在 ≤N 步内首次回到初始位置的
不同 b 值数目。

## 题目

给定 N，求 F(N)。已知 F(6)=4、F(100)=805，求 F(10^8)。
