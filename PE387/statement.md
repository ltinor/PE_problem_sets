# 可右截强哈沙德素数

## 题目描述

哈沙德数（Harshad Number）是能被其各位数字之和整除的正整数。

可右截哈沙德数：不断截去最后一位数字后，始终是哈沙德数。

强哈沙德数：哈沙德数除以其各位数字之和得到的商是素数。

可右截强哈沙德素数：本身是素数，且截去最后一位数字后得到一个可右截的强哈沙德数。

给定上限 N，求所有小于 N 的可右截强哈沙德素数之和。

---

## 输入格式

一个整数 N。

---

## 输出格式

一个整数，表示答案。

---

## 样例

### 输入
```
10000
```

### 输出
```
90619
```

---

## 数据范围

- 对于 30% 数据：N ≤ 10^6
- 对于 60% 数据：N ≤ 10^10
- 对于 100% 数据：N ≤ 10^14
