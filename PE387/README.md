# PE387 - 可右截强哈沙德素数

来源：改编自 Project Euler Problem 387

## 原题意

求所有小于 10^14 的可右截强哈沙德素数之和。

## 题目

给定上限 N，求和。使用 BFS/DFS 生成所有满足条件的数。

## 算法

- BFS 生成所有右截哈沙德数（数量有限，≤10^14 时仅约 10^5 个）
- 判断强哈沙德性（素数判定）
- 在末尾追加数字形成素数

## 改编方向

1. **多进制扩展**：在 k 进制下定义类似概念，k 作为输入
2. **左截版本**：改为左截哈沙德数（去掉首位）
3. **恰好 k 位**：求恰好 k 位的可右截强哈沙德素数个数
4. **最值版本**：求最大/最小的可右截强哈沙德素数
