# 交叠洗牌

## 题目描述

完美交叠洗牌（riffle shuffle）的操作流程如下：将偶数张牌的牌堆分成相同数量的两半，上半置于左手，下半置于右手。接着将牌准确地交叉叠合：右手第一张牌放在左手第一张牌下方，右手第二张牌放在左手第二张牌下方，依此类推。（注意此操作不改变牌堆最上和最下两张牌的位置。）

记 s(n) 为将 n 张牌（n 为正偶数）恢复原序所需的最少连续交叠洗牌次数。

令人惊奇的是，52 张牌的标准牌堆仅需 8 次完美洗牌即可恢复原序，故 s(52) = 8。可以验证 86 张牌的牌堆同样在 8 次洗牌后恢复，且所有满足 s(n) = 8 的 n 之和为 412。

求所有满足 s(n) = 60 的 n 之和。

## 输入格式

一行，字符串 `PE` 或 `verify` 或 `compute`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案：3010983666182123972。

若输入为 `verify`，验证 s(52) 和 s(86) 均为 8。

若输入为 `compute`，实际计算并输出结果。

## 样例

### 输入
```
PE
```

### 输出
```
3010983666182123972
```

## 数据范围

- 完整问题：枚举 2⁶⁰ - 1 的所有因子（约 3000 个）
- 验证模式：n = 52, 86
