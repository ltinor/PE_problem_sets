# PE577 - 数六边形 (Counting Hexagons)

来源：改编自 Project Euler Problem 577

## 原题意

将边长为 n 的等边三角形细分为 n² 个单位等边三角形。顶点构成三角形网格。统计所有顶点在格点上且完全位于大三角形内的正六边形数量 H(n)。

已知（暴力枚举）：
H(3)=1, H(4)=3, H(5)=6, H(6)=12, H(7)=21, H(8)=33,
H(9)=51, H(10)=75, H(20)=966。

求 Σ H(n)。

PE 答案：265695031399260211。

## 算法

正六边形的边向量在三角形网格中取形式：
(a,b), (-b,a+b), (-a-b,a), (-a,-b), (b,-a-b), (a+b,-a)

其中 (a,b) 为整数格向量。对齐类型 (1,0) 的六边形计数为 Σ C(n-3k+2, 2)。倾斜类型（如 (1,1) 边）从 n≥6 开始出现，产生额外贡献。完整公式需对所有互质的 (a,b) 求和。

## 改编方向

1. 推导完整闭合公式（含所有边类型的贡献）
2. 统计其他正多边形（如正三角形、正十二边形）
3. 在三维四面体网格中计数正多面体
