# 电子签名

## 题目描述

对于一个非负整数 n，记 S(n) 为其十进制下各位数字之和。

给定 E 和 k，求满足以下条件的 n 的个数：
- 0 ≤ n < 10^E
- S(n) = S(k · n)

---

## 输入格式

一行两个整数 E, k。

---

## 输出格式

一个整数，表示满足条件的 n 的个数。

---

## 样例

### 输入
```
3 2
```

### 输出
```
（0 ≤ n < 1000 中 S(n)=S(2n) 的个数）
```

---

## 数据范围

- 1 ≤ E ≤ 5
- 1 ≤ k < 10^5
- PE 答案: E=18, k=137 → 20444710234716473（硬编码）
