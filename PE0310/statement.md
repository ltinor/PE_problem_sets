# 平方取石子

## 题目描述

Alice 和 Bob 在玩 Nim Square 游戏：三堆石子，每次可以从任意一堆取走平方数（1, 4, 9, 16, ...）个石子。不能取的一方输。

三堆石子数用有序三元组 (a, b, c) 表示（0 ≤ a ≤ b ≤ c ≤ N）。求必败态（无论怎么走都会输的状态）的个数。

---

## 输入格式

一行一个整数 N。

---

## 输出格式

一行一个整数，表示必败态个数。

---

## 样例

### 输入
```
29
```

### 输出
```
1160
```

---

## 数据范围

- $1 \\le N \\le 10^5$
