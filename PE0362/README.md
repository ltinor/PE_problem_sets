# 无平方因子的因数

来源：改编自 Project Euler Problem 362

## 原题意

Fsf(n) 是将 n 分解为一个或多个大于 1 的无平方因子因数乘积的方式数。求 S(10^10) = ∑Fsf(k), k=2..10^10。PE 答案：457895481。

## 题目

给定 N，求 S(N) = ∑_{k=2}^{N} Fsf(k)。

## 数据范围

N ≤ 10^7

## 算法

### 方向一：素数幂分解 + 组合计数

无平方因子数即每个质因子指数 ≤ 1 的数。将 n 分解为质因数幂次，Fsf(n) 取决于各质因子在因数间的分配方式。使用 DP 计算每种质因子分配的方案数。

### 方向二：Dirichlet 卷积 / 积性函数

Fsf(n) 可表示为积性函数的 Dirichlet 卷积。预处理素数后，利用积性函数的性质 O(N log log N) 计算前缀和。

### 方向三：容斥原理 + 莫比乌斯反演

对平方因子进行容斥。使用莫比乌斯函数 μ(d)，将含平方因子的情况排除。转化为对每个 d 计算贡献。

### 时间复杂度

预处理 O(N log log N)，查询 O(1)。
