# PE865 — Trillion Zeckendorf Representation（万亿Zeckendorf表示）

来源：改编自 Project Euler Problem 865

## 原题意

Zeckendorf 定理：每个正整数可以唯一地表示为若干个不相邻的斐波那契数之和（从 F₂ = 1, F₃ = 2 开始）。

本题计算从 1 到 10¹²（一万亿）范围内所有整数的 Zeckendorf 表示中，项数的期望值（平均值）。

## 算法

1. **生成斐波那契数**：生成所有 ≤ 10¹² 的斐波那契数（约 70 个）。
2. **Zeckendorf 表示**：使用贪心算法，每次取最大的不超过剩余数的斐波那契数，并跳过相邻项。
3. **项数统计**：对每个数计算表示中的项数。
4. **期望值计算**：总和 / 总数。

## 改编方向

1. 研究项数的分布规律（渐近正态性）
2. 推广到广义斐波那契数列
3. Zeckendorf 表示的编码长度分析
4. 与其他进制表示的比较
