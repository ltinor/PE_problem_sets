# 透镜孔洞

## 题目描述

若两圆重叠而成的凸区域满足以下条件，我们称之为**透镜孔洞（lenticular hole）**：

- 两圆的圆心都是格点（坐标为整数的点）
- 两圆在两个格点处相交
- 两圆重叠而成的凸区域内部不包含任何格点

例如，圆 $x^2+y^2=25$ 和圆 $(x+4)^2+(y-4)^2=1$ 的圆心都在格点上，它们在点 $(-3,4)$ 和 $(-4,3)$ 处相交（均为格点），且重叠区域内无格点，因此它们形成了一个透镜孔洞。

如果存在两个半径分别为 $r_1$ 和 $r_2$ 的圆能够生成透镜孔洞，我们就称有序正实数对 $(r_1, r_2)$ 为**透镜数对**。

记 $L(N)$ 是所有满足 $0 < r_1 \le r_2 \le N$ 的**不同**透镜数对的个数。

现在给定正整数 $N$，请计算 $L(N)$。

---

## 输入格式

一行一个正整数 $N$。

---

## 输出格式

一行一个整数，表示 $L(N)$。

---

## 样例

### 样例输入 1

```
10
```

### 样例输出 1

```
30
```

### 样例输入 2

```
100
```

### 样例输出 2

```
3442
```

---

## 数据范围

- $1 \le N \le 200$
