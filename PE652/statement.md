# 原型对数函数的不同取值

## 题目描述

考虑定义在整数 m,n ≥ 2 上的函数 f(m,n) = log_m(n)，它具有如下性质：f(m₁,n₁)=f(m₂,n₂) 当且仅当满足以下两个条件之一：

1. m₁=aᵉ, n₁=aᶠ, m₂=bᵉ, n₂=bᶠ
2. m₁=aᵉ, n₁=bᵉ, m₂=aᶠ, n₂=bᶠ

其中 a,b,e,f 均为整数。

我们称满足上述等价关系的函数 g(m,n) 为**原型对数函数**。记 D(N) 为任意原型对数函数在 2 ≤ m,n ≤ N 上的不同取值数目。

已知：
- D(5) = 13
- D(10) = 69
- D(100) = 9607
- D(10000) = 99959605

求 D(10¹⁸)，输出最后 9 位数字。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 983358497。
- `verify`：验证已知小样例。
- `compute`：重新计算 D(10¹⁸)。

## 样例

### 输入
```
PE
```

### 输出
```
983358497
```

## 数据范围

- 完整问题：N = 10¹⁸
- 模数：10⁹（取最后 9 位）
