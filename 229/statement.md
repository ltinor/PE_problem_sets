# 四种平方数表示

## 题目描述

考虑能同时用以下四种形式表示的正整数 $n$：

$$\\begin{aligned} n &= a_1^2 + b_1^2 \\\\ n &= a_2^2 + 2b_2^2 \\\\ n &= a_3^2 + 3b_3^2 \\\\ n &= a_4^2 + 7b_4^2 \\end{aligned}$$

其中 $a_i, b_i$ 均为正整数。

例如，$3600$ 可以这样表示：

$$3600 = 48^2 + 36^2 = 20^2 + 2 \\times 40^2 = 30^2 + 3 \\times 30^2 = 45^2 + 7 \\times 15^2$$

给定 $N$，求所有 $n \\le N$ 中，可以同时用上述四种形式表示的正整数有多少个。

---

## 输入格式

输入一行，一个整数 $N$。

---

## 输出格式

输出一个整数，表示满足条件的正整数个数。

---

## 样例

### 输入
```
10000000
```

### 输出
```
75373
```

---

## 数据范围

$1 \\le N \\le 10^7$
