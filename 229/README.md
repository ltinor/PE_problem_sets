# 229 — Four Representations using Squares

来源：改编自 Project Euler Problem 229

## 原题意

求 $n \\le 2 \\times 10^9$ 中能同时表示为以下四种形式的数的个数：
- $n = a_1^2 + b_1^2$
- $n = a_2^2 + 2b_2^2$
- $n = a_3^2 + 3b_3^2$
- $n = a_4^2 + 7b_4^2$
其中 $a_i, b_i > 0$。原题答案：11325263。

## 题目

参数化 N：输入 N，求 $n \\le N$ 中满足上述四种表示的数有多少个。

## 数据范围

$1 \\le N \\le 10^7$

## 算法

**std**: 枚举 $n \\le N$，对每个 $n$ 检查四种二次型表示。对第 $d$ 型：枚举 $a \\le \\sqrt{n-d}$，检查 $n-a^2$ 是否为 $d$ 的倍数且商为完全平方数。

时间复杂度：$O(N \\cdot \\sqrt{N})$。对 $N=10^7$ 约需数分钟（实际取决于 $\\sqrt{n}$ 的平均值）。可进一步用筛法优化。

**brute**: 同 std，用于较小 N 的验证。

## 改编方向

1. **参数化 N**：将原题固定 $N=2 \\times 10^9$ 改为可输入的上限。
2. **参数化系数**：可改变四种表示的系数 $(1, 2, 3, 7)$ 为其他组合。
3. **只求部分表示**：可求满足其中 k 种表示的数（如 k=2, 3）。
