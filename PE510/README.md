# PE510 - 相切的圆

来源：改编自 Project Euler Problem 510

## 原题意

圆 A 和圆 B 彼此相切并分别与直线 L 相切（三个切点不同）。
圆 C 在 A、B、L 之间，与三者都相切。
S(n) = Σ (rA + rB + rC)，其中 0 < rA ≤ rB ≤ n，且三个半径均为整数。
求 S(10^9)。

PE 答案：315306518862563689。

## 题目

给定 n，求所有满足条件的整数半径三元组 (rA, rB, rC) 的和。

## 算法

- 由 Descartes 圆定理（含直线，曲率 0）得：1/√rC = 1/√rA + 1/√rB
- 参数化：rA = t²a²(a+b)², rB = t²b²(a+b)², rC = t²a²b²
  其中 gcd(a,b)=1, a ≤ b
- 枚举 (a,b,t) 使得 rB ≤ n
- a 的范围：4a⁴ ≤ n；b ≥ a
- t 的范围：t ≤ √n / (b·(a+b))

## 改编方向

1. **不同约束**：rA < rB < rC 等
2. **外切圆**：圆 C 在 A、B 外侧
3. **四个圆**：再加一个圆 D
4. **三维球**：推广到球与平面
