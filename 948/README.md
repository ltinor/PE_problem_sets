# PE 948 — Left vs Right（小左对小右）

来源：改编自 Project Euler Problem 948

## 原题意

小左和小右在用一个由字母 L 和 R 组成的单词玩游戏，两人轮流行动。在小左的回合中，小左可以从单词的左侧移除任意正数个（但不能全部）字母；小右则类似地从单词的右侧移除字母。游戏持续到只剩下一个字母：L 则小左胜，R 则小右胜。

记 $F(n)$ 为长度为 $n$ 且在双方均采取最优策略时，先手玩家（无论是小左还是小右）必胜的单词数量。

原题求 $F(60)$。

验证点：$F(3)=4$，$F(8)=181$。

## 题目

给定 $n$，求 $F(n)$。

## 数据范围

$1 \le n \le 24$（原题 $n=60$，此处缩小数据规模）。

## 算法

记 winL[w] = 小左先手时小左是否必胜，winR[w] = 小右先手时小右是否必胜。

- 递推（单词长 $L$）：
  - winL[w] = 存在 $k \in [1, L-1]$ 使后缀 $w[k:]$（长 $L-k$）上 winR 为假；
  - winR[w] = 存在 $k \in [1, L-1]$ 使前缀 $w[:L-k]$（长 $L-k$）上 winL 为假。
- 基（$L=1$）：winL =（字母为 L），winR =（字母为 R）。
- $F(n)=\#\{w : \text{winL}[w] \wedge \text{winR}[w]\}$。

用二进制编码单词（bit0 为最左字母，1 表示 'R'，0 表示 'L'），按长度从小到大做 DP。
复杂度 $O(n \cdot 2^n)$（时间与空间），$n=24$ 时约 0.5s / 约 67MB，可接受。

> 原题（$n=60$）单词数量 $2^{60}$，无法直接枚举，需借助该组合博弈的深层结构
> 做进一步分析，属研究级难题；此处通过缩小数据规模，用 DP 枚举全部单词即可求解。
