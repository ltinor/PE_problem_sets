# 唯一子集和

## 题目描述

对于集合 S = {1², 2², ..., N²}，考虑所有恰好包含 K 个元素的子集，计算这些子集的元素和。有些和可能出现多次，有些和只出现恰好一次。

记 U(N, K) 为所有"恰好由唯一一个 K-子集得到的和"的集合，求这些唯一和的总和。

例如：N=6, K=3。集合 B = {1,3,6,8,10,11} 的 3-子集和中，唯一出现的和为 {10,12,14,18,21,25,27,29}，总和为 156。

给定 N 和 K，求 U(N, K) 的总和。

---

## 输入格式

一行两个整数 N K (1 ≤ N ≤ 100, 1 ≤ K ≤ N/2)，空格分隔。

---

## 输出格式

一行一个整数，表示唯一子集和的总和。

---

## 样例

### 输入

```
6 3
```

### 输出

```
156
```

### 输入

```
100 50
```

### 输出

```
115039000
```

---

## 数据范围

- 1 ≤ N ≤ 100
- 1 ≤ K ≤ N/2
