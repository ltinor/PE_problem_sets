# 201 — Subsets with a Unique Sum

来源：改编自 Project Euler Problem 201

## 原题意

S = {1², 2², ..., 100²}，取 50 个元素的子集。求所有"唯一和"（恰好只有一种子集能达到的和）的总和。原题答案：115039000。

## 题目

参数化 N, K：输入 N (≤100), K (≤N/2)，S = {1², ..., N²}，求 U(S,K) 的和。

## 数据范围

- N ≤ 100, K ≤ N/2

## 算法

**std**: DP 计数。dp[j][s] = 用前 i 个元素的平方中得到和 s、使用 j 个元素的方法数（上限截断为 2，只关心 0/1/>1）。滚动数组优化。

**brute**: DFS 枚举所有 K-子集，map 计数频率。适用于 N ≤ 20。

## 改编方向

1. **参数化 N, K**：将原题固定 N=100, K=50 改为输入参数。
2. **简化数据范围**：N ≤ 50 时 DP 可在 1s 内完成（状态数 K × maxSum ≈ 25 × 40000）。
3. **增加小数据对拍**：N ≤ 20 可用 brute DFS 验证。
