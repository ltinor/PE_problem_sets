# 235 — Arithmetic Geometric Sequence

来源：改编自 Project Euler Problem 235

## 原题意

给定序列 $u(k) = (900 - 3k) r^{k-1}$。设 $s(n) = \sum_{k=1}^{n} u(k)$。求 $r$ 使得 $s(5000) = -600000000000$。原题答案：1.002322108633。

## 题目

参数化 $n$ 和 $S$：输入 $n$ 和目标值 $S$，求 $r$ 使得 $s(n) = S$。

## 数据范围

$1 \le n \le 5000$，$S$ 在合理范围内（确保 $r \in (0.5, 2)$ 附近有解）。

## 算法

**std**: 使用等差-等比级数闭式：
$$s(r) = A \cdot \frac{1-r^n}{1-r} + D \cdot r \cdot \frac{1 - n r^{n-1} + (n-1) r^n}{(1-r)^2}$$
其中 $A=897, D=-3$（$900-3k = 897 + (-3)(k-1)$）。

$s(r)$ 在 $r > 1$ 时单调递减（因为后期负项被放大）。对 $r$ 二分搜索求解。

**brute**: 同样二分搜索，但用直接求和代替闭式。

## 改编方向

1. **参数化 n, S**：将固定值改为输入参数。
2. **参数化系数**：可改为 $u(k) = (a - bk) r^{k-1}$。
3. **多组测试**：T 组查询。
