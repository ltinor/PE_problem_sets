# 等差-等比级数

## 题目描述

给定等差-等比级数：

$$s(n) = \sum_{k=1}^{n} (900 - 3k) \cdot r^{k-1}$$

其中 $r$ 是实数。给定整数 $n$ 和目标值 $S$，求满足 $s(n) = S$ 的 $r$。

保证解 $r$ 唯一且在 $(0.5, 2)$ 范围内。

---

## 输入格式

输入一行，一个整数 $n$ 和一个实数 $S$，以空格分隔。

---

## 输出格式

输出一个浮点数 $r$，保留 12 位小数。

---

## 样例

### 输入
```
5000 -600000000000
```

### 输出
```
1.002322108633
```

---

## 数据范围

- $1 \le n \le 5000$
- $S$ 为合理范围内的实数，保证有唯一解 $r \in (0.5, 2)$。
