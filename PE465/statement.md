# 极点多边形

## 题目描述

多边形的核心（kernel）定义为能够看到整个多边形边界的点集。如果一个多边形的核心严格包含原点 (0,0)，则称这个多边形为极点多边形。

在这个问题中，顶点坐标为整数 (x, y)，且 |x|, |y| ≤ n。允许存在连续的共线顶点，但不允许自交，面积不能为零。

注意：即使两个多边形围住的区域相同，如果它们的边集不同（顶点序列不同），也被认为是不同的多边形。

定义 P(n) 为满足条件的极点多边形个数。

已知：
- P(1) = 131
- P(2) = 1648531
- P(3) = 1099461296175
- P(343) mod 1000000007 = 937293740

求 P(N) mod 1000000007。

---

## 输入格式

一个整数 N (1 ≤ N ≤ 2)。

---

## 输出格式

一个整数，表示 P(N) mod 1,000,000,007。

---

## 样例

### 输入
```
1
```

### 输出
```
131
```

---

## 数据范围

- 对于 100% 数据：N ≤ 2
