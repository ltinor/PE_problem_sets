# 奢侈礼篮

## 题目描述

供应商 A 和 B 为奢侈礼篮市场提供 $5$ 种商品，第 $i$ 种商品的供应量分别为 $a_i$ 和 $b_i$。

存在不可避免的损耗（变质）。定义：
- 商品 $i$ 的单项损耗率：供应商 A 为 $x_i/a_i$，供应商 B 为 $y_i/b_i$（$0 \le x_i \le a_i$，$0 \le y_i \le b_i$）。
- 总损耗率：供应商 A 为 $\sum x_i / \sum a_i$，供应商 B 为 $\sum y_i / \sum b_i$。

两个供应商惊讶地发现：对于每种商品，B 的损耗率都恰好是 A 的 $m$ 倍（$m>1$）；但总损耗率 A 却是 B 的 $m$ 倍。

求可能的最大 $m$ 值（以最简分数 $u/v$ 的形式输出）。

---

## 输入格式

共 $5$ 行，每行两个整数 $a_i\ b_i$，表示第 $i$ 种商品的两个供应商的供应量。

---

## 输出格式

输出一行，格式为 `u/v`，其中 $u/v$ 是满足条件的最大 $m$ 的最简分数。

---

## 样例

### 输入
```
5248 640
1312 1888
2624 3776
5760 3776
3936 5664
```

### 输出
```
123/59
```

---

## 数据范围

$1 \le a_i, b_i \le 6000$，共 $5$ 种商品。
