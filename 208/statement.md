# 机器人走路

## 题目描述

一个机器人每步沿 72° 圆弧移动。每步可以自由选择顺时针或逆时针方向，但不能原地转向。

机器人从面向正北方向开始，在执行完所有步数后，如果回到出发位置，则称此路径为闭合路径。

例如，走 25 步的闭合路径共有 70932 条。

给定步数 n（n 为 5 的倍数），求走 n 步后能回到出发位置的闭合路径总数。

---

## 输入格式

一行，一个整数 n（5 ≤ n ≤ 200，且 n 是 5 的倍数）。

---

## 输出格式

一行，一个整数，表示闭合路径数。

---

## 样例

### 输入 1

```
5
```

### 输出 1

```
2
```

### 输入 2

```
25
```

### 输出 2

```
70932
```

---

## 数据范围

- 5 ≤ n ≤ 200
- n 为 5 的倍数
- PE 答案：n=70 时输出 331951449665644800
