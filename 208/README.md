# 208 — 机器人走路 (Robot Walks)

来源：改编自 Project Euler Problem 208

## 原题意

机器人每步走 72° 圆弧（可顺时针或逆时针），从面向正北开始。求走 70 步后回到出发位置的路径数。

原题答案：331951449665644800（已通过题目验证点 n=25→70932 及暴力/DP 双重验证）

## 题目

参数化步数 n（n 必须为 5 的倍数）。求走 n 步后回到出发位置的闭合路径数。

## 数据范围

- n ≤ 200，n 为 5 的倍数（OJ 测试数据 ≤ 70）

## 算法

**std**: DP 跟踪和弦方向计数。回到原点的充要条件是 5 个和弦方向的步数相等（各 n/5）。使用哈希表进行 DP，状态 = (当前朝向, 4 个和弦方向的计数)。时间复杂度 O(n × 状态数)，使用 `__int128` 存储大数。

**brute**: 枚举所有 2^n 种转向序列（n ≤ 25），对每个序列计算和弦方向计数并检查。

## 改编方向

1. **参数化步数 n**：将固定步数 70 改为可变输入。
2. **和弦方向计数**：利用 5 个和弦方向步数必须相等这一关键性质。
3. **DP 优化**：使用哈希表压缩状态，避免 5 维数组爆炸。
4. **PE 答案验证**：n=70 时输出原题答案。
