# 平方余数

## 题目描述

对于整数 a ≥ 3，定义 r 为 (a−1)^n + (a+1)^n 除以 a² 的余数。

随着 n 的变化，r 也会变化。对于给定的 a，记 r_max 为所有可能的 n（n ≥ 1）对应的 r 中的最大值。

例如 a = 7 时：
- n = 1：6¹ + 8¹ = 14，14 mod 49 = 14
- n = 2：6² + 8² = 100，100 mod 49 = 2
- n = 3：6³ + 8³ = 728，728 mod 49 = 42
- r_max = 42

给定 M，求所有 a = 3, 4, ..., M 的 r_max 之和。

---

## 输入格式

一行，一个整数 M。

---

## 输出格式

一行，一个整数，表示答案。

---

## 样例

### 输入
```
7
```

### 输出
```
100
```

### 输入
```
1000
```

### 输出
```
333082500
```

### 说明
- M=7：a=3→6, a=4→8, a=5→20, a=6→24, a=7→42，总和 100

---

## 数据范围

- 3 ≤ M ≤ 1000
