# 约束最小最大和最大最小

## 题目描述

一个长度为 N 的正整数序列 (a_1, a_2, ..., a_N) 的：
- **最大公约数**（gcd）是能整除所有元素的最大自然数。
- **最小公倍数**（lcm）是所有元素的公倍数中最小的自然数。

定义 f(G, L, N) 为满足以下两个条件的长度为 N 的正整数序列的个数：
- gcd(a_1, ..., a_N) ≥ G
- lcm(a_1, ..., a_N) ≤ L

例如：
- f(10, 100, 1) = 91
- f(10, 100, 2) = 327
- f(10, 100, 3) = 1135
- f(10, 100, 1000) mod 101^4 = 3286053

给定 G, L, N 和模数 M，求 f(G, L, N) mod M。

---

## 输入格式

一行四个整数 G, L, N, M，用空格分隔。

---

## 输出格式

一个整数，表示 f(G, L, N) mod M。

---

## 样例

### 输入
```
10 100 1 1000000007
```

### 输出
```
91
```

### 输入
```
10 100 1000 104060401
```

### 输出
```
3286053
```

---

## 数据范围

- 对于 30% 数据：N ≤ 3，L ≤ 30
- 对于 60% 数据：N ≤ 10，L ≤ 10^4
- 对于 100% 数据：1 ≤ G ≤ L ≤ 10^12，1 ≤ N ≤ 10^18，1 < M ≤ 10^9+7
