# 163 — 交错三角形

来源：改编自 Project Euler Problem 163

## 原题意

在 n 级纵横交错的等边三角形中，求可以数出的三角形总数 T(n)。原题求 T(36)，答案：343047。

## 题目

参数化 N：输入 N (≤ 36)，求 T(N)。

## 数据范围

- 1 ≤ N ≤ 36

## 算法

**std**: 闭式公式。T(N) = (1678N³ + 3117N² + 88N - C(N)) / 240，其中 C(N) 为周期性修正项（涉及 N mod 2, 3, 4, 5）。

**brute**: 对 N ≤ 8 枚举所有交点、边和三角形（3-cycle 计数）。使用重心坐标表示交点，判断任意两点间是否有直接连线。

## 改编方向

1. **参数化 N**：将固定 N=36 改为输入参数。
2. **公式推导**：基于几何分类的计数公式。
3. **PE 答案验证**：(N=36) 输出 343047。
