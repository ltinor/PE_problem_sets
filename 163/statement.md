# 纵横交错的三角形

## 题目描述

考虑一个 n 级等边三角形：它由 n² 个 1 级三角形组成，并且从大三角形的每个顶点向对边中点引一条线段。在这个图形中可以数出许多不同形状、大小、方向和位置的三角形。记 T(n) 为 n 级三角形中可以数出的三角形总数。

已知 T(1) = 16，T(2) = 104。求 T(N)。

## 输入格式

一行一个整数 N。

## 输出格式

一行一个整数，表示 T(N)。

---

## 样例

### 输入
```
1
```

### 输出
```
16
```

### 输入
```
2
```

### 输出
```
104
```

---

## 数据范围

- 1 ≤ N ≤ 36

---

## 提示

PE 原题 N=36 时答案为 343047。
