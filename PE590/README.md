# PE590 — 给定最小公倍数的集合 (Sets with a given Least Common Multiple)

来源：改编自 Project Euler Problem 590

## 原题意

记 H(n) 表示各元素的最小公倍数（LCM）为 n 的正整数集合的数目。

例如，以下 10 个集合的元素 LCM 都是 6：
{2,3}, {1,2,3}, {6}, {1,6}, {2,6}, {1,2,6}, {3,6}, {1,3,6}, {2,3,6}, {1,2,3,6}。
因此 H(6) = 10。

记 L(n) 为 1 到 n 的所有整数的 LCM。例如 L(6) = 60。

记 HL(n) = H(L(n))。已知 HL(4) = H(12) = 44。

求 HL(50000)，答案对 10⁹ 取余。

PE 答案：834171904。

## 算法

H(n) 的计算：设 n = ∏ p_i^{e_i}，其除子格是一个乘积链。H(n) 为除子格中子集的数量，要求子集的并（LCM）等于顶元素 n。

通过容斥原理：
H(n) = Σ_{S ⊆ {primes}} (-1)^{|S|} · 2^{τ(n) · ∏_{i∈S} e_i/(e_i+1)}

其中 τ(n) = ∏ (e_i + 1) 为除子个数。

验证：对于 n = 6 = 2·3，τ = 4，H(6) = 2⁴ - 2² - 2² + 2¹ = 16 - 4 - 4 + 2 = 10 ✓。
对于 n = 12 = 2²·3，τ = 6，H(12) = 2⁶ - 2⁴ - 2³ + 2² = 64 - 16 - 8 + 4 = 44 ✓。

L(50000) 的素因子指数 e_p = ⌊log_p 50000⌋。大多数素数（p > 223）的 e_p = 1。

直接使用容斥公式需要 O(2^ω) 时间（ω ≈ 5133），不可行。可利用 CR（中国剩余定理）将模 10⁹ 分解为模 2⁹ 和模 5⁹ 分别计算，并结合指数和容斥的代数简化。

## 改编方向

1. 计算 HL(n) 对于不同 n 的模值，研究其分布。
2. 推广到其他 LCM 相关的计数函数，如 G(n) = 最大公约数为 n 的集合数。
3. 研究 H(n) 的乘法性质和渐近行为。
4. 将正整数的条件改为其他数域（如高斯整数）。
