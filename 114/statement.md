# 方格组合计数 I

## 题目描述

用长度为 1 的黑色方块和**最短长度为 M** 的红色方块摆成长度为 N 的一行，要求任意两个红色方块（长度可以不同）之间至少有一个黑色方块。求有多少种不同的摆法。

例如，N=7、M=3 时，有 17 种不同的摆法。

---

## 输入格式

一行两个整数 N M，空格分隔。

---

## 输出格式

一行一个整数，表示摆法总数。

---

## 样例

### 输入
```
7 3
```

### 输出
```
17
```

### 输入
```
50 3
```

### 输出
```
16475640049
```

---

## 数据范围

- 3 ≤ M ≤ N ≤ 50
