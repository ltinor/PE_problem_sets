# 异或问题（XOR Problem）

## 题目描述

定义**异或积**（XOR-product）$x \otimes y$：模仿二进制长乘法，但将中间结果的相加替换为按位异或。

例如 $7 \otimes 3 = 9$，即 $111_2 \otimes 11_2 = 1001_2$。

考虑方程：
$$(a \otimes a) \oplus (2 \otimes a \otimes b) \oplus (b \otimes b) = 5$$

定义 $X(N)$ 为所有满足 $0 \le a \le b \le N$ 的方程解中，所有 $b$ 取值的按位异或结果。

已知 $X(10) = 5$。求 $X(10^{18})$。

## 输入格式

无输入（固定参数问题）。

## 输出格式

输出一个整数，表示 $X(10^{18})$ 的值。

（无样例输入输出，直接计算并输出最终答案。）
