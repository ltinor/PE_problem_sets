# 127 — abc-hits

来源：改编自 Project Euler Problem 127

## 原题意

求 c < 120000 的所有 abc-hit 的 ∑c。

原题答案：18407904。

## 题目

参数化 M：输入 M (≤ 120000)，求所有 c < M 的 abc-hit 的 ∑c。

## 数据范围

- M ≤ 120000

## 算法

筛法计算 rad[1..M]（每个数的不同质因数之积）。枚举 a, b (a < b, a+b < M)，检查 gcd(a,b)=1 且 rad[a]*rad[b]*rad[a+b] < a+b。满足条件则累加 c = a+b。

时间复杂度 O(M² log M)，可接受因为 M ≤ 120000 且 abc-hit 很稀疏。

## 改编方向

1. **参数化 M**：将原题固定 M=120000 改为输入参数。
2. **小范围版本**：M ≤ 1000 可用于对拍验证（答案 12523）。
3. **固定答案验证**：M=120000 作为测试点，输出 18407904。
