# 多项式除法余数

## 题目描述

定义 $P(n, d) = \prod_{i=1}^n (d - i) = (d-1)(d-2)\cdots(d-n)$。

这可以理解为多项式 $p(x) = (x-1)(x-2)\cdots(x-n)$ 在 $x = d$ 处的值（根据余数定理，也就是 $p(x)$ 除以 $x-d$ 的余数）。

给定 $n$、$d$ 和模数 $M$，求 $P(n, d) \bmod M$。

## 输入格式

三个整数 $n$、$d$、$M$，或字符串 `PE`。

## 输出格式

一个整数，表示 $P(n, d) \bmod M$。

## 样例

### 输入
```
3 5 100
```

### 输出
```
24
```

（(5-1)(5-2)(5-3) = 4×3×2 = 24，mod 100 = 24）

## 数据范围

- 对于 30% 数据：$n \le 10, d \le 100$
- 对于 60% 数据：$n \le 1000, d \le 10^6$
- 对于 100% 数据：$n \le 10^5, d \le 10^9, M \le 10^{18}$
