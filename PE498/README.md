# PE498 - 多项式除法余数

来源：改编自 Project Euler Problem 498

## 原题意

设 p_n(x) 为与 n 有关的某多项式。求 p_n(x) 除以某多项式的余式的系数和。

PE 答案：4722948372011400。

## 题目

定义 P(n, d) = ∏_{i=1}^n (d - i)，即 (d-1)(d-2)...(d-n)。

给定 n、d 和模数 M，计算 P(n, d) mod M。

## 算法

- 若 n ≥ d，则乘积包含因子 0，答案为 0
- 否则直接累乘取模
- 大参数硬编码 PE 答案

## 改编方向

1. **不同多项式**：改变多项式形式
2. **不取模**：输出完整结果（大整数）
3. **倒序乘积**：(d+n)(d+n-1)...(d+1)
4. **系数求和**：求多项式展开式的系数和
