# 整除序列计数

## 题目描述

记 Seq(n, k) 为满足以下条件的长为 n 的正整数序列 {a_i}_{1≤i≤n} 的数目：

1. 对于所有 1 ≤ i ≤ n，n 能被 a_i 整除；
2. n + a_1 + a_2 + ... + a_n 能被 k 整除。

求 Seq(n, k) 的最后九位数字（即对 10^9 取模的结果）。

## 输入格式

一行，两个整数 n 和 k（以空格分隔），或字符串 `PE`。

## 输出格式

一个整数，表示 Seq(n, k) mod 10^9。

## 样例

### 输入
```
3 4
```

### 输出
```
4
```

### 输入
```
4 11
```

### 输出
```
8
```

### 输入
```
1111 24
```

### 输出
```
840643584
```

## 数据范围

- 对于 30% 数据：n ≤ 100, k ≤ 10
- 对于 60% 数据：n ≤ 10^6, k ≤ 100
- 对于 100% 数据：n ≤ 10^13, k ≤ 10^4
