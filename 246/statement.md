# 椭圆的切线

## 题目描述

已知：点 M(-2000, 1500)、G(8000, 1500)，以及以 M 为圆心、半径 r = 15000 的圆 c。

到圆 c 和到点 G 距离相等的点的轨迹构成椭圆 e。

对于椭圆 e 外的一点 P，引椭圆的两条切线 t₁ 和 t₂，分别切椭圆于 R 和 S。

给定角度 D（度数），求有多少个格点 P，使得角 RPS 严格大于 D 度。

---

## 输入格式

一行一个整数 D，表示角度（度数）。

---

## 输出格式

一行一个整数，表示满足条件的格点 P 的数量。

---

## 样例

### 输入
```
80
```

### 输出
```
46342844
```

### 输入
```
45
```

### 输出
```
810834388
```

---

## 数据范围

- 对于 20% 的数据：D ≥ 80
- 对于 50% 的数据：D ≥ 60
- 对于 80% 的数据：D ≥ 50
- 对于 100% 的数据：30 ≤ D ≤ 89
