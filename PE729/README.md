# PE729 — Range of continued fractions (连分数范围)

来源：改编自 Project Euler Problem 729

## 原题意

考虑所有满足一定条件的周期连分数。
例如，对于周期为 2 的连分数 [a; b, a, b, ...]，
求值域的范围（最大值减最小值）。

或更一般地：给定参数 N 和 k，考虑所有满足 1 ≤ a₁ ≤ a₂ ≤ ... ≤ a_k ≤ N 的
k 元组，求纯周期连分数 [a₁; a₂, ..., a_k, a₁, ...] 的值域范围。

## 算法

1. **连分数求值**：纯周期连分数满足二次方程。
   设 x = [a₀; a₁, ..., a_{m-1}, ...]（周期 m），
   则 x = (p_{m-1}x + p_{m-2})/(q_{m-1}x + q_{m-2})，
   解二次方程得 x。
2. **单调性分析**：对于周期为 2 的连分数，
   F(a,b) 对 a 单调递增，对 b 单调递减。
   因此范围 R(N) = F(N,N) - F(1,N)。
3. **一般周期**：对于周期 k > 2，单调性更复杂，
   但极值通常出现在边界（全取最小或全取最大）。
4. **收敛项计算**：使用连分数的递推关系快速计算 p_i, q_i。
5. **高精度**：需要使用高精度浮点数（long double）或分数表示。

## 改编方向

1. 不同的参数序关系（严格递增、任意序等）
2. 非纯周期连分数（带前导项）
3. 求连分数值的分布而非范围
4. 连分数的统计特性
5. 多维连分数的推广
