# 连分数范围

## 题目描述

对于周期为 2 的无限连分数：
F(a, b) = a + 1/(b + 1/(a + 1/(b + ...)))

考虑所有满足 1 ≤ a ≤ b ≤ N 的整数对 (a, b)。
定义 R(N) = max F(a,b) - min F(a,b)，即所有连分数值的范围。

求 R(N) 的值（保留 4 位小数）。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 3085833.7242（保留4位小数）。
- `verify`：验证周期为 2 的连分数计算和范围公式。
- `compute`：重新计算完整答案。

## 样例

### 输入
```
PE
```

### 输出
```
3085833.7242
```

### 小规模验证
- F(1,1) = [1; 1, 1, ...] = (1+√5)/2 ≈ 1.6180
- F(1,2) = [1; 2, 1, 2, ...] ≈ 1.3660
- F(2,2) = [2; 2, 2, ...] = 1+√2 ≈ 2.4142
- R(2) = F(2,2) - F(1,2) ≈ 1.0482

## 数据范围

- 验证范围：N ≤ 10（枚举所有对）
- 完整问题：根据 PE 729 原题参数
- 结果保留 4 位小数
