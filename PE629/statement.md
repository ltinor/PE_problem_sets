# 分堆取石子游戏

## 题目描述

Alice 和 Bob 在玩一个名为「分堆取石子」的变种 Nim 游戏。Alice 先手，双方轮流行动。

游戏开始时，将 n 枚石子分成若干堆，每堆石子数任意。

轮到任一玩家时，该玩家先选择一堆至少含 2 枚石子的堆，然后将其分成 p 个非空堆，满足 2 ≤ p ≤ k（k 为约定常数）。例如，一堆 4 枚石子，当 k=3 时可分成 {1,3}、{2,2} 或 {1,1,2}。

若轮到某玩家时无法行动，则对手获胜。

对于给定的 n 和 k，记 f(n,k) 为 Alice 作为先手时必胜态（石子分区方案）的数目。

例如：f(5,2)=3（必胜态：{1,1,1,2}、{1,4}、{2,3}），f(5,3)=5（增加 {1,1,3}、{5}）。

记 g(n) 为 k 从 2 到 n 的 f(n,k) 之和。例如 g(7)=66，g(10)=291。

求 g(200)，并将答案对 1,000,000,007 取模。

## 输入格式

一行，字符串 `PE` 或 `verify` 或 `compute`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案。

若输入为 `verify`，输出 f(5,2)、f(5,3)、g(7) 的验证结果。

若输入为 `compute`，计算 g(10)。

## 样例

### 输入
```
PE
```

### 输出
```
626616617
```

## 数据范围

- 完整问题：n = 200
- 验证模式：n ≤ 7
- 取模：1,000,000,007
