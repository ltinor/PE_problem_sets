# B-三除数

## 题目描述

如果正整数 $n$ 所有不大于 $B$ 的不同质因数之和能被 $3$ 整除，则称 $n$ 为 $B$-三除数。

例如，$175 = 5^2 \cdot 7$ 是 $10$-三除数，因为 $5+7=12$ 能被 $3$ 整除。$175$ 也是 $4$-三除数，因为 $175$ 所有不大于 $4$ 的质因数（没有）之和为 $0$，能被 $3$ 整除。而 $175$ 不是 $6$-三除数，因为满足条件的质数之和为 $5$，不能被 $3$ 整除。

设 $F(N,B)$ 为不大于 $N$ 的 $B$-三除数的个数。例如 $F(10,4)=5$，这些数分别是 $1,3,5,7,9$。

给定 $N$ 和 $B$，求 $F(N,B)$。

---

## 输入格式

输入一行，两个整数 $N$ 和 $B$，以空格分隔。

---

## 输出格式

输出一个整数，表示 $F(N,B)$。

---

## 样例

### 输入

```
10 4
```

### 输出

```
5
```

### 输入

```
10 10
```

### 输出

```
3
```

### 输入

```
100 10
```

### 输出

```
41
```

---

## 数据范围

$1 \le N \le 10^{18}$

$1 \le B \le 40$
