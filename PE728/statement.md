# 硬币圆

## 题目描述

N 枚硬币排成圆圈。每次操作可以选择一个位置，将
该位置及其两个相邻位置的硬币全部翻转（H↔T）。

从全正面状态出发，问能否到达全反面状态？
如果可以，最少需要多少次操作？

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 709537650。
- `verify`：验证小规模的可达性和最小操作数。
- `compute`：重新计算完整答案。

## 样例

### 输入
```
PE
```

### 输出
```
709537650
```

### 小规模验证
- N=1：操作翻转位置 1 三次（循环）→ 不可达
- N=2：操作翻转所有硬币 → 2 步可达
- N=3：不可达（3|N）
- N=4：可达，最少 2 步
- N=5：可达，最少 3 步

## 数据范围

- 验证范围：N ≤ 30
- 完整问题：根据 PE 728 原题参数
- 操作在 GF(2) 上分析
