# 最大互质子集

## 题目描述

取集合 {1, 2, ..., N} 的一个子集，要求子集中任意两个元素互质（最大公约数为 1）。记所有满足条件的子集中元素之和的最大值为 Co(N)。

例如：Co(10)=30，达到最大值的子集为 {1, 5, 7, 8, 9}（和为 30）。
已知 Co(30)=193，Co(100)=1356。

给定整数 N，求 Co(N)。

---

## 输入格式

一个整数 N。

---

## 输出格式

一个整数，表示 Co(N)。

---

## 样例

### 输入
```
10
```

### 输出
```
30
```

### 输入
```
30
```

### 输出
```
193
```

### 输入
```
100
```

### 输出
```
1356
```

---

## 数据范围

- 对于 30% 数据：N ≤ 20
- 对于 60% 数据：N ≤ 100
- 对于 100% 数据：N ≤ 200000
