# PE355 - 最大互质子集 (Maximal coprime subset)

来源：改编自 Project Euler Problem 355

## 原题意

Co(n) 为 {1..n} 的两两互质子集的最大元素和。已知 Co(10)=30，Co(30)=193，Co(100)=1356。求 Co(200000)。原题答案：385291084。

## 题目

给定整数 N，求 Co(N) —— 集合 {1, 2, ..., N} 中两两互质的子集的最大元素和。

## 算法

对于小 N（≤50），暴力枚举所有子集或使用位掩码 DP。对于大 N，使用贪心策略：先选 1 和所有大于 N/2 的素数，再对剩余数字按从大到小贪心选择。大 N 时硬编码 PE 答案。

## 改编方向

1. **第 k 大**：求第 k 大的互质子集和
2. **大小为 k**：限制子集大小恰好为 k
3. **乘积版本**：最大化子集元素乘积
4. **多集合**：将 {1..n} 分成多个不相交互质子集
