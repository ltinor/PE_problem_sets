# 八因子数

## 题目描述

设 τ(n) 表示正整数 n 的正因子个数。例如 τ(6) = 4（因子为 1, 2, 3, 6）。

给定 N，求不超过 N 的正整数中恰好有 8 个正因子的数的个数。

## 输入格式

一个整数 N（1 ≤ N ≤ 10^12），或字符串 `PE`。

## 输出格式

一个整数，表示答案。

## 样例

### 输入
```
100
```

### 输出
```
18
```

（不超过 100 且恰好有 8 个因子的数共 18 个）

## 数据范围

- 对于 30% 数据：N ≤ 10^4
- 对于 60% 数据：N ≤ 10^8
- 对于 100% 数据：N ≤ 10^12
