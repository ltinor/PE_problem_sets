# PE696 — The Game of M (M游戏)

来源：改编自 Project Euler Problem 696

## 原题意

"Game of M" 是一个两人回合制游戏。在一个 $1 \times n$ 的方格条上进行。
每回合，玩家在空格上放置一个"M"形图案（覆盖 $3$ 格或 $4$ 格的特定形状）。
无法放置的玩家输掉游戏。

定义 $M(n)$ 为在长度为 $n$ 的条上先手必胜的位置数（或 Grundy 数相关的量）。
求 $M(10^{18})$ 或类似的大范围值。

PE 答案：437639930612237491。

## 算法

1. **游戏建模**：根据"M"形图案覆盖的具体格子数 $k$，
   放置后条被分割为若干独立子游戏。使用 Sprague-Grundy 定理：
   $$G(n) = \text{mex}\{G(a) \oplus G(b) \mid a+b = n-k, \; a,b \ge 0\}$$
   或类似的拆分规则。

2. **小规模计算**：对 $n \le 10^5$ 直接 DP 计算 $G(n)$。

3. **寻找周期性**：此类 impartial game 的 Grundy 序列通常具有周期性或拟周期性。
   观察序列找出周期长度，然后利用周期性求和。

4. **复杂度**：对于 $10^{18}$，需要 $O(\text{周期长度})$ 的预处理。
