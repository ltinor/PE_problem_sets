# 不同的质因数 (Distinct Primes Factors)

来源：改编自 Project Euler Problem 47

## 原题意

找出首个连续四个数各自都有四个不同质因数的第一个数。答案：134043。

## 改编方向

参数化 K（1≤K≤4）。输入 K，求首个连续 K 个数各有 K 个不同质因数的第一个数。

## 题目

给定整数 K，求最小的正整数 N，使得 N, N+1, ..., N+K-1 这 K 个连续整数中，每个数恰好有 K 个不同的质因数。

## 数据范围

- K: 1 ≤ K ≤ 4

## 算法

std: 埃氏筛变体计算每个数的不同质因数个数，然后扫描找连续 K 个。O(L log log L)，L≈2×10^5。

brute: 对每个数逐个质因数分解。O(L√L)。
