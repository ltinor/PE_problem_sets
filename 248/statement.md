# 欧拉函数定值

## 题目描述

欧拉函数 φ(n) 表示不超过 n 且与 n 互质的正整数个数。

例如：φ(1)=1, φ(2)=1, φ(6)=2, φ(12)=4。

给定两个整数 K 和 T，求第 T 小的正整数 n，使得 φ(n) = K。

如果不存在 T 个这样的 n，输出 -1。

---

## 输入格式

一行两个整数 K, T。

---

## 输出格式

一行一个整数，表示第 T 小的满足 φ(n)=K 的 n；若不足 T 个，输出 -1。

---

## 样例

### 输入
```
2 2
```

### 输出
```
4
```

（φ(3)=2, φ(4)=2, φ(6)=2。第 2 小的是 4。）

### 输入
```
6227020800 150000
```

### 输出
```
23507044290
```

---

## 数据范围

- 对于 30% 的数据：K ≤ 100
- 对于 60% 的数据：K ≤ 10⁶
- 对于 100% 的数据：K ≤ 10¹⁰, T ≤ 150000
