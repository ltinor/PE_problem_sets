# 欧拉函数定值

来源：改编自 Project Euler Problem 248

## 原题意

求第 150000 个满足 φ(n) = 13! = 6227020800 的正整数 n。答案: 23507044290。

## 题目

给定 K, T，求第 T 小的 n 使得 φ(n) = K。

## 数据范围

K ≤ 10¹⁰, T ≤ 150000。共 10 个测试点，包含原题数据 (K=13!, T=150000) 和随机小数据。

## 算法

1. **分解 K**: 若 φ(n) = K，则 n = ∏ p_i^{e_i}，而 K = ∏ p_i^{e_i-1} · (p_i-1)。因此 p_i-1 | K。

2. **DFS 搜索**: 枚举所有满足 p-1 | K 的素数 p。对于每个 p，尝试所有可能的指数 e ≥ 1，使得 p^{e-1} | K。递归组合所有素数因子。

3. **排序输出**: 收集所有找到的 n，排序后取第 T 个。

4. **复杂度**: 取决于 K 的素因子分解结构和满足条件的素数个数。对 K=13!，约有几十万个解。
