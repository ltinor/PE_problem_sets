# 石子纸牌游戏（简单版）

来源：改编自 Project Euler Problem 960（Stone Game Solitaire）。

## 原题意

有 $n$ 个不同的石堆，每堆 $n-1$ 枚石子。每次选两堆共移除 $n$ 枚（分别移除 $a,b$，$a+b=n$），分数加 $\min(a,b)$。能清空所有石堆则分数为最终分数，卡住则最终分数为 $0$。$F(n)$ 为所有成功清空序列的最终分数之和。已知 $F(3)=12$，$F(4)=360$，$F(8)=16785941760$，求 $F(100) \bmod (10^9+7)$。

## 题目

本题为缩数据简单版：给定 $n$，求 $F(n)$ 的精确值。

## 数据范围

$1 \le n \le 12$。

## 算法

记忆化搜索（动态规划）＋ 状态排序（规范化）。

- 一个成功序列与一个 $(n-1)\times n$ 矩阵一一对应：每行恰有两个正整数且和为 $n$，每列和为 $n-1$；分数为每行两数之 $\min$ 的和。
- 游戏对石堆标号的置换对称，答案只取决于石堆大小的多重集，因此可将状态排序后作为记忆化搜索的键。
- 记 $\mathit{cnt}(s)$ 为从状态 $s$ 出发能清空全部石堆的带标号序列数，$\mathit{sum}(s)$ 为这些序列的分数总和，则对空状态 $\mathit{cnt}=1,\mathit{sum}=0$，否则

  $$\mathit{cnt}(s)=\sum_m \mathit{cnt}(\text{next}_m),\qquad
  \mathit{sum}(s)=\sum_m \big(\mathit{score}_m\cdot \mathit{cnt}(\text{next}_m)+\mathit{sum}(\text{next}_m)\big).$$

- 由于石堆带标号，枚举每对位置 $(i<j)$ 及拆分 $a$（$b=n-a$）恰好计数每个带标号移动一次。

验证点：$F(3)=12$，$F(4)=360$，$F(8)=16785941760$ 均已通过。
