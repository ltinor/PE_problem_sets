# 石子纸牌游戏（简单版）

来源：改编自 Project Euler Problem 960（Stone Game Solitaire）。

## 题目描述

有 $n$ 个**互不相同**的石堆，每堆有 $n-1$ 枚石子。从初始分数 $0$ 开始，重复执行以下操作：

1. 选择任意两个石堆，从这两个石堆中**总共移除恰好 $n$ 枚石子**；
2. 若从这两个石堆中移除的石子数分别为 $a$ 和 $b$（$a+b=n$），则将 $\min(a,b)$ 加入分数。

如果最终所有石堆都被清空，则当前分数即为最终分数；如果中途被"卡住"无法清空所有石堆，则最终分数计为 $0$。

定义 $F(n)$ 为所有能够成功清空所有石堆的操作序列所得到的最终分数之和。给定 $n$，求 $F(n)$。

（原题要求 $F(100) \bmod (10^9+7)$；本题为缩数据简单版，$n$ 很小，直接输出 $F(n)$ 的精确值。）

---

## 输入格式

一行一个整数 $n$。

---

## 输出格式

一行一个整数，表示 $F(n)$。

---

## 样例

### 样例输入 1

```
3
```

### 样例输出 1

```
12
```

### 样例输入 2

```
4
```

### 样例输出 2

```
360
```

---

## 数据范围

- $1 \le n \le 12$
- 答案保证在 $128$ 位整数范围内。
