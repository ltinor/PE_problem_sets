# 超级无敌和（Super Duper Sum）

## 题目描述

记 $\Omega(n)$ 为 $n$ 的质因数个数（包含重复的质因数）。例如 $\Omega(12)=3$，因为 $12=2\times2\times3$，包含两个质因数 $2$ 和一个质因数 $3$。

定义 $D(n,m)$ 为 $n$ 的所有满足「$\Omega(d)$ 能被 $m$ 整除」的因数 $d$ 之和。

例如 $24$ 的因数为 $1,2,3,4,6,8,12,24$，对应的 $\Omega$ 分别为 $0,1,1,2,2,3,3,4$，其中能被 $3$ 整除的是 $0,3,3$，对应因数 $1,8,12$，所以 $D(24,3)=1+8+12=21$。

给定 $n$ 和 $m$，求 $D(n,m)$。

## 输入格式

一行两个整数 $n$ 和 $m$。

## 输出格式

一行一个整数，表示 $D(n,m)$。

## 样例

### 输入

```
24 3
```

### 输出

```
21
```

## 数据范围

$1 \le n \le 10^6$，$1 \le m \le 100$。
