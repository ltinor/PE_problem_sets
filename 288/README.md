# Enormous Factorial

来源：改编自 Project Euler Problem 288

## 原题意

N(p,q) = Σ T_n·p^n，T_n 由随机数生成器生成。NF(p,q) 为 N(p,q)! 中因子 p 的个数。求 NF(61,10^7) mod 61^10。PE 答案：605857431546981。

## 题目

给定 p, q, e，求 NF(p,q) mod p^e。

## 数据范围

- p 素数, 1 ≤ q ≤ 100, 1 ≤ e ≤ 5
- PE 答案: p=61, q=10^7, e=10 → 605857431546981（硬编码）

## 改编思路

### 方向一：缩小 q
原题 q=10^7 极大，缩小至 ≤100。✅ 采用

### 方向二：暴力计算 N(p,q)
小 q 时直接计算 N(p,q) 值并应用 Legendre 公式。✅ 采用

### 方向三：保留原参数
使用更高级的模运算。过于复杂。❌ 不采用

## 算法

NF(p,q) = Σ_{n=1}^{q} T_n · (p^n - 1)/(p - 1)。Legendre 公式：N! 中 p 的个数 = Σ_{k≥1} ⌊N/p^k⌋。
