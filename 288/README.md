# Enormous Factorial (巨大的阶乘)

来源：改编自 Project Euler Problem 288。

## 原题意

N(p,q) = Σ_{n=0..q} T_n·p^n（T_n 由 S 递推生成，S₀=290797，S_{n+1} = S_n² mod 50515093，T_n = S_n mod p）。
NF(p,q) = N(p,q)! 中因子 p 的个数（即 v_p(N!)）。原题给定 NF(3,10000) mod 3²⁰ = 624955285，
求 NF(61,10⁷) mod 61¹⁰。

## 题目

给定 p, q, e（p 素数，1 ≤ q ≤ 10⁷，p^e 在 64 位内），输出 NF(p,q) mod p^e。

## 数据范围

- 检查值: p=3, q=10000, e=20 → 624955285（原题给定）
- PE 答案: p=61, q=10⁷, e=10 → **605857431263981935**

## 算法（code/std.cpp，q=10⁷ 约 0.4s）

Legendre 公式 NF = Σ_{j≥1} ⌊N/p^j⌋。N 是 base-p 数（数位恰为 T_n），
故 ⌊N/p^j⌋ mod p^e = 数位窗口 Σ_{d=0..e-1} T[j+d]·p^d。窗口滑动：
w_{j+1} = (w_j − T[j])/p + p^{e−1}·T[j+e]（差值必为 p 的倍数，精确整除，无需逆元）。
总计 O(q + e)。

## 验证

- NF(3,10000) mod 3²⁰ = 624955285（原题检查值）✓
- NF(61,10⁷) mod 61¹⁰ = 605857431263981935（PE 官方）✓
- (5,100,3)、(7,1000,5) 与 Python 大整数直接 Legendre 对拍一致 ✓
