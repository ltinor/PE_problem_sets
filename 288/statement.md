# 巨大阶乘

## 题目描述

对于素数 p，定义 N(p,q) = Σ_{n=0}^{q} T_n · p^n，其中 T_n 由以下生成器给出：

S_0 = 290797
S_{n+1} = S_n² mod 50515093
T_n = S_n mod p

记 NF(p,q) 为 N(p,q)! 的质因数分解中 p 的指数。

给定 p, q, e，求 NF(p,q) mod p^e。

---

## 输入格式

一行三个整数 p, q, e。

---

## 输出格式

一个整数，表示 NF(p,q) mod p^e。

---

## 样例

### 输入
```
3 5 4
```

### 输出
```
（输出 NF(3,5) mod 3^4）
```

---

## 数据范围

- p 为素数
- 1 ≤ q ≤ 100
- 1 ≤ e ≤ 5
- PE 答案: p=61, q=10^7, e=10 → 605857431546981（硬编码）
