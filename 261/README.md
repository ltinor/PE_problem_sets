# 261 — Pivotal Square（平方支点）

来源：改编自 Project Euler Problem 261

## 原题意

称正整数 k 为"平方支点"，若存在 m>0 和 n≥k 使得 (k-m)²+...+k² = (n+1)²+...+(n+m)²。求所有 ≤10¹⁰ 的平方支点之和。答案：238890850232021。

## 题目

输入正整数 N，求所有满足条件的平方支点 k ≤ N 的**不同**值之和。

## 数据范围

- 1 ≤ N ≤ 10¹⁰

## 算法

核心变换：由平方和等式推导出 Pell 型方程。令 X=2k-m, Y=2n+m+1，化简得 (m+1)X²-mY²=-m(m+1)，即 mY²-(m+1)X²=m(m+1)。令 X=mt，得 Y²=(m+1)(mt²+1)。从基本解 (Y₀,t₀)=(m+1,1) 出发，利用 Pell 方程 Y²-m(m+1)t²=m+1 的单位元 (2m+1,2) 迭代生成所有解。对每个解计算 k=m(t+1)/2，若 n=(Y-m-1)/2 ≥ k 则计入。m 只需枚举至 O(√N)。时间复杂度 O(√N·log N)，空间 O(√N)。

## 改编方向与取舍

### 改编方向
1. **参数化上限 N** → 支持 N≤10¹⁰（本题采用），原题固定 N=10¹⁰
2. **求第 K 个支点** → 输入 K，输出第 K 个平方支点
3. **输出所有支点** → 按升序输出所有平方支点
4. **立方支点** → 推广到立方和，需求解更高次 Diophantine 方程

### 取舍理由
- 选择参数化 N：最自然的 OJ 参数化方式，保持原题核心 Pell 方程算法不变
- 不选求第 K 个：需要证明支点序列的稠密性，且 K 的合理范围难以界定
- 不选立方推广：Diophantine 方程次数提高后 Pell 方法不适用
- N 限制在 10¹⁰：与 PE 原题范围一致，int64 足以处理中间量
