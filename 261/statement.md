# 平方支点

## 题目描述

称正整数 $k$ 为"平方支点"（square-pivot），若存在整数 $m > 0$ 和 $n \ge k$，使得从 $k-m$ 到 $k$ 的 $(m+1)$ 个连续整数的平方和等于从 $n+1$ 到 $n+m$ 的 $m$ 个连续整数的平方和：

$$(k-m)^2 + (k-m+1)^2 + \cdots + k^2 = (n+1)^2 + (n+2)^2 + \cdots + (n+m)^2$$

例如：
- $k=4$（$m=1$, $n=4$）：$3^2+4^2=5^2$
- $k=21$（$m=1$, $n=28$）：$20^2+21^2=29^2$
- $k=24$（$m=3$, $n=24$）：$21^2+22^2+23^2+24^2=25^2+26^2+27^2$

给定正整数 $N$，求所有 $k \le N$ 的**不同**平方支点之和。

---

## 输入格式

一行，一个整数 $N$。

---

## 输出格式

一行，一个整数，表示所有满足 $k \le N$ 的不同平方支点之和。

---

## 样例

### 输入
```
25
```

### 输出
```
49
```

**解释**：≤25 的平方支点有 4, 21, 24，和为 4+21+24=49。

### 输入
```
120
```

### 输出
```
159
```

**解释**：≤120 的平方支点有 4, 21, 24, 110，和为 4+21+24+110=159。

---

## 数据范围

- $1 \le N \le 10^{10}$
