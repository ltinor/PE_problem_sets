# 无摩擦管道

## 题目描述

有一根长为 L 毫米、直径为 20 毫米的水平无摩擦管道，东侧末端开口，西侧末端封闭。管道中放有 N 颗直径为 20 毫米的弹珠，每颗弹珠以相同的速率 v 向东或向西运动。假设碰撞是完全弹性的：碰撞后两弹珠立即向反方向运动且保持速率不变；若弹珠撞到西侧封闭末端，也会立即反弹。

弹珠的起始位置和初始方向由如下伪随机数列确定：
- r₁ = 6563116
- r_{j+1} = rⱼ² mod 32745673

最西端弹珠表面距西端 (r₁ mod 1000) + 1 毫米。相邻弹珠表面间距为 (r_j mod 1000) + 1 毫米。若 r_j ≤ 10000000 则向东运动，否则向西运动。

定义 d(L,N,j) 为第 j 颗弹珠（从西数起）在球心到达东侧末端前所运动的距离（单位：毫米）。

已知：
- d(5000, 3, 2) = 5519
- d(10000, 11, 6) = 11780
- d(100000, 101, 51) = 114101

求 d(1000000000, 1000001, 500001)。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 1130671207。
- `verify`：验证已知小样例。
- `compute`：模拟计算（仅适用于小规模）。

## 样例

### 输入
```
PE
```

### 输出
```
1130671207
```

## 数据范围

- 完整问题：L = 10⁹, N = 1000001, j = 500001
- 弹珠直径：20mm
