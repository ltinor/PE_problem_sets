# PE653 — 无摩擦管道 (Frictionless Tube)

来源：改编自 Project Euler Problem 653

## 原题意

长度为 L 毫米的水平无摩擦管道，东端开口，西端封闭。管道内有 N 颗直径为 20mm 的弹珠，以相同速率 v 向东或向西运动。碰撞为完全弹性碰撞。

弹珠初始位置和方向由伪随机序列 r_j 确定：
- r₁ = 6563116
- r_{j+1} = rⱼ² mod 32745673
- 间距 = (r_j mod 1000) + 1 毫米
- 方向：r_j ≤ 10000000 时向东，否则向西

d(L,N,j) = 第 j 颗弹珠（从西数起）球心到达东端前运动的距离。

已知 d(5000,3,2)=5519, d(10000,11,6)=11780, d(100000,101,51)=114101。

求 d(10⁹, 1000001, 500001)。

PE 答案：1130671207。

## 算法

对于完全相同的弹珠，弹性碰撞等价于弹珠互相穿过但交换身份标签。利用事件驱动的模拟方法：
1. 维护每颗弹珠当前的位置和方向
2. 每次寻找下一个事件（碰撞、壁面反弹、离开管道）
3. 更新弹珠状态和累计距离

对于小规模测试用例可使用此方法直接模拟。对于大规模问题，可利用"自由轨迹"方法和排列不变性高效计算。

## 改编方向

1. 改变碰撞规则（非弹性碰撞、有摩擦）
2. 多个开口端
3. 不同质量的弹珠
4. 二维或三维管道
