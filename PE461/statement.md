# 几乎是π

## 题目描述

对于正整数 n，定义函数 f_n(k) = e^{k/n} - 1（k 为非负整数）。

求四个非负整数 a, b, c, d，使得 |f_n(a) + f_n(b) + f_n(c) + f_n(d) - π| 达到最小值。

定义 g(n) = a² + b² + c² + d²，其中 a, b, c, d 是使上述误差最小的参数。

例如，g(200) = 6² + 75² + 89² + 226² = 64658。

求 g(n)。

---

## 输入格式

一个整数 n (2 ≤ n ≤ 10000)。

---

## 输出格式

一个整数，表示 g(n)。

---

## 样例

### 输入
```
200
```

### 输出
```
64658
```

---

## 数据范围

- 对于 30% 数据：n ≤ 50
- 对于 60% 数据：n ≤ 500
- 对于 100% 数据：n ≤ 10000
