# 高斯整数除数和

## 题目描述

在复数域中，高斯整数是形如 a + bi（其中 a, b 为整数）的复数。

对于正整数 n，它的高斯整数因子是所有满足 a > 0, b ≥ 0 且 a + bi 整除 n 的高斯整数。

定义 s(n) 为 n 的所有高斯整数因子的实部之和。

给定 N，求：

$$\sum_{n=1}^{N} s(n)$$

---

## 输入格式

一行一个整数 N (1 ≤ N ≤ 10⁸)。

---

## 输出格式

一行一个整数，表示所求的和。

---

## 样例

### 输入 1

```
5
```

### 输出 1

```
35
```

### 输入 2

```
100000000
```

### 输出 2

```
17971254122360698165
```

---

## 数据范围

- 1 ≤ N ≤ 10⁸
