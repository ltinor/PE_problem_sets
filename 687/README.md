# 洗牌完美点数概率（PE 687）

来源：改编自 Project Euler Problem 687。

## 原题意

52 张牌洗牌后, 某点数 4 张互不相邻称完美。求完美点数恰好为质数个的概率, 保留 10 位小数。

## 题目

见 statement.md。参数与输入输出约定以 code/std.cpp 为准。

## 算法

容斥生成函数: 单点数贡献多项式系数 c=(12,36,24) (配交错符号), a_m = P(m 个指定点数全完美), 再二项式反演出精确分布。

## 验证

a_1 = 4324/5525, E = 4324/425 (题面), P = 0.3285320869 (官方)
