# 幂和之和

## 题目描述

定义 $f_p(n) = \sum_{k=1}^n k^p$（前 $n$ 个正整数的 $p$ 次幂之和）。

给定 $N$ 和 $K$，求：

$$\sum_{i=1}^N \sum_{j=1}^K f_i(j) \pmod{1\,000\,000\,007}$$

---

## 输入格式

两个整数 $N$ 和 $K$。

---

## 输出格式

一个整数，表示上述和模 $1\,000\,000\,007$ 的值。

---

## 样例

### 输入
```
3 2
```

### 输出
```
...
```

---

## 数据范围

- 对于 30% 数据：$N, K \le 10$
- 对于 60% 数据：$N, K \le 100$
- 对于 100% 数据：$N, K \le 10^6$
