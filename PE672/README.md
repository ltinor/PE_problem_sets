# PE672 — 多一个1 (One more one)

来源：改编自 Project Euler Problem 672

## 原题意

定义一种数字变换，使得变换后的表示中恰好比原数多一个数字'1'。求在特定范围内满足该性质的数的计数或求和。

该问题涉及不同进制表示中的数字统计，以及组合数学中的计数技巧。

PE 答案：91627537。

## 算法

1. 使用位运算/数字 DP 统计满足特定数字模式的数的个数
2. 组合数 C(n, k) 用于计算在 n 个位置中选 k 个放置数字'1'的方案数
3. 对于每个可能的1的个数，计算对应范围内的数字计数
4. 高效实现通过逐位处理（digit DP）或组合公式计算

## 改编方向

1. 推广到不同进制
2. 考虑多个数字的统计（如恰好多两个1）
3. 限制数字总位数范围
4. 考虑其他数字的统计约束
