# 硬币求和

## 题目描述

英国的货币单位分为英镑（£）和便士（p）。目前流通的硬币一共有八种面值：

$$1p,\ 2p,\ 5p,\ 10p,\ 20p,\ 50p,\ £1(100p),\ £2(200p)$$

每种硬币数量不限。给定一个正整数 $N$，求用这些硬币凑出恰好 $N$ 便士有多少种不同的方法。

例如，凑出 $200p$（即 £2）共有 $73682$ 种方法。

---

## 输入格式

一行一个正整数 $N$。

---

## 输出格式

一行一个整数，表示凑出 $N$ 便士的方法数。

---

## 样例

### 输入

```
200
```

### 输出

```
73682
```

---

## 数据范围

- $1 \leq N \leq 10^5$
- 答案可能超过 $2^{63}-1$，需使用 128 位整数或高精度
