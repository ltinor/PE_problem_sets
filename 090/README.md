# Cube Digit Pairs

来源：改编自 Project Euler Problem 90

## 原题意

两个立方体，每个面上标一个 $0$ 到 $9$ 的数字（六个面各不相同）。允许 $6$ 和 $9$ 颠倒互用。求有多少种不同的标法，使得两个立方体能摆出所有小于 $100$ 的平方数：$01, 04, 09, 16, 25, 36, 49, 64, 81$。

## 题目

固定答案题。输出满足条件的标法数目。

## 数据范围

无输入（或输入任意整数）。

## 算法

枚举 $C(10,6) = 210$ 种立方体组合。对每对组合 $(a, b)$（无序），检查能否摆出全部 $9$ 个平方数。检查时考虑 $6/9$ 互换。

时间复杂度：$O(210^2 \times 9) \approx O(4 \times 10^5)$。
