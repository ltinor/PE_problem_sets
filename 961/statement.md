# 删除数字

## 题目描述

两位玩家轮流从一个正整数中删除一个数字；每次删除之后产生的前导零也会一并被删除。

例如，从 $105$ 中删除一个数字会得到 $5$、$10$ 或 $15$。

删除最后一个非零数字（即把数变成 $0$）的玩家获胜。

定义 $W(N)$ 为小于 $N$、且双方均采用最优策略时先手必胜的正整数数量。请你计算 $W(N)$。

---

## 输入格式

一行一个整数 $N$。

---

## 输出格式

一行一个整数，表示 $W(N)$。

---

## 样例

### 输入
```
100
```

### 输出
```
18
```

### 输入
```
10000
```

### 输出
```
1656
```

---

## 数据范围

- 对于 $30\%$ 的数据：$N \le 1000$；
- 对于 $60\%$ 的数据：$N \le 10^5$；
- 对于 $100\%$ 的数据：$1 \le N \le 10^6$。

---

## 提示

本题改编自 Project Euler Problem 961（原题要求 $N = 10^{18}$）。

设 $g(n)$ 为数字 $n$ 的 Sprague–Grundy 值，则 $g(0)=0$，且

$$g(n)=\operatorname{mex}\{g(m):m\text{ 为删除 }n\text{ 中某一位并去掉前导零后的结果}\}.$$

先手必胜当且仅当 $g(n)\neq 0$。
