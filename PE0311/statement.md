# 双斜整数四边形

## 题目描述

ABCD 是一个各边长为整数的凸四边形，满足 1 ≤ AB < BC < CD < AD。BD 的长为整数，O 是 BD 的中点，且 AO 的长也是整数。

如果 AO = CO ≤ BO = DO，我们称 ABCD 为双斜整数四边形。

记 B(N) 是所有满足 AB² + BC² + CD² + AD² ≤ N 的双斜整数四边形的数目。

---

## 输入格式

一行一个整数 N。

---

## 输出格式

一行一个整数，表示 B(N)。

---

## 样例

### 输入
```
10000
```

### 输出
```
49
```

---

## 数据范围

- $1 \\le N \\le 10^6$
