# Steady Squares (稳平方数, base 14)

来源：改编自 Project Euler Problem 284。

## 原题意

x² 以 B 为基的末 n 位等于 x（如 376² = 141376）称为稳平方数。原题求 base 14 下
n = 1..10^4 所有 n 位稳平方数的 digit sum 之和，答案以 base-14 表示。

## 题目

输入 "PE" 输出官方答案 `5a411d7b`；或输入 N B（默认 B=14，N ≤ 10^4），
输出 digit sum 总和的 base-14 表示。

## 数据范围

- 检查值: N=9, B=14 → 2d8（十进制 582，含 1 位稳平方数 1）
- PE 答案: n=10^4, B=14 → 5a411d7b（十进制 604557993）

## 算法（code/std.cpp，O(N²) 数位 Hensel 提升，N=10^4 约 3.3s）

x² ≡ x (mod B^n) 有 4 个解（CRT of {0,1}×{0,1}），每个解 x ≡ 0/1 (mod 2 与 mod 7)
⟹ 2x−1 与 B=14 互素，单数字 Hensel 提升合法。维护解的数字数组与 D = x²−x 的数字数组
（不变式 D[i]=0, i<n），提升数字 t = −D[n]·(2x₀−1)⁻¹ (mod B)：
D' = D + 2t·x·B^n − t·B^n + t²·B^{2n}。数位和随提升累加。

## 验证

- N=9 → 2d8（十进制 582；与独立大整数 CRT 枚举一致）✓
- N=10000 → 5a411d7b（PE 官方）✓
