# Steady Squares

来源：改编自 Project Euler Problem 284

## 原题意

在 14 进制下，求 n=1..10000 所有 n 位自守数的各位数字之和（以 14 进制输出）。PE 答案：5a411d7b（14 进制）。

## 题目

给定 N 和基数 B（B=14），求所有 n 位（1 ≤ n ≤ N）非平凡自守数（x² 的末 N 位等于 x）的各位数字之和（以 B 进制输出）。

## 数据范围

- 1 ≤ N ≤ 10, B = 14
- PE 答案: N=9 → 2d8（582 十进制），N=10000 → 5a411d7b

## 改编思路

### 方向一：缩小 N
原题 N=10000 极其困难，缩小至 N ≤ 10 使计算可行。✅ 采用

### 方向二：泛化基数
允许不同的基数 B，但 14 进制是原题核心。❌ 不采用

### 方向三：只输出十进制结果
原题要求 14 进制输出增加趣味性。✅ 保留

## 算法

自守数满足 x² ≡ x (mod B^n)。对 B=14=2×7，使用 CRT：x ≡ 0/1 (mod 2^n) 且 x ≡ 0/1 (mod 7^n)。Hensel 升位法逐位构造。
