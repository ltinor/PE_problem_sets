# 稳态平方数

## 题目描述

在 B 进制下，一个 n 位数 x 若满足 x² 的末 n 位恰好等于 x，则称 x 为自守数（不允许前导零）。

例如，14 进制下，c37² = aa0c37，末 3 位为 c37，因此 c37 是 14 进制下的自守数。它的各位数字和为 c+3+7=18（14 进制）。

给定 N 和基数 B（B=14），求所有 n 位（1 ≤ n ≤ N）非平凡自守数（不含 0 和 1）的各位数字之和，以 B 进制输出。

---

## 输入格式

一行两个整数 N, B。

---

## 输出格式

一个 B 进制数（使用 0-9 和 a-d 表示 10-13），表示各位数字之和。

---

## 样例

### 输入
```
3 14
```

### 输出
```
18
```

（n=1,2,3 的非平凡自守数在 14 进制下的各位数字和为 18）

---

## 数据范围

- 1 ≤ N ≤ 10
- B = 14
- PE 答案: N=9 → 2d8（十进制 582）
