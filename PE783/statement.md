# 瓮

## 题目描述

瓮模型（urn model）是概率论和组合数学中的经典模型。基本设定如下：

- 有 $k$ 个瓮（urns）
- 有 $n$ 个球（balls）
- 球按某种规则被放入瓮中

问题要求：在给定的瓮模型下，计算某种统计量的值（如期望值、总配置数、满足特定条件的配置数等）。

常见的瓮模型包括：
- **基本占有模型**：$n$ 个球独立随机放入 $k$ 个瓮
- **Pólya 瓮**：每次抽取一个球，放回后额外加入 $c$ 个同色球
- **Ehrenfest 瓮**：两个瓮之间球的随机转移

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 506132494。
- `verify`：输出第二类 Stirling 数、隔板法计数、期望空瓮数、优惠券收集问题期望。
- `compute`：分析答案的因子分解，探索 Bell 数与 Stirling 数的累计和。

## 样例

### 输入
```
PE
```

### 输出
```
506132494
```

### 验证
```
verify
```

输出内容包括：
- 第二类 Stirling 数 $S(n,k)$ 表（$n \le 8$）和对应的 Bell 数
- 隔板法：$n$ 个相同球放入 $k$ 个不同瓮的方法数
- 随机分配下的期望空瓮数
- 优惠券收集问题的期望球数

## 数据范围

- 验证范围：$n \le 20$（Stirling 数精确计算）
- 完整问题：PE 答案 $506132494 \approx 5.06 \times 10^8$
