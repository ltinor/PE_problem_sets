# 披萨馅料

## 题目描述

将一张圆形披萨均分为 m·n 片。现有 m 种不同的馅料（m ≥ 2），每种馅料恰好放在 n 片披萨上（n ≥ 1）。

旋转后相同的方案视为同一种；翻转后相同的方案视为不同。

记 f(m,n) 为所有可行的分配方案数。给定阈值 T，求所有满足 f(m,n) ≤ T 的 f(m,n) 之和。

---

## 输入格式

一行，一个整数 T（1 ≤ T ≤ 10^15）。

---

## 输出格式

一个整数，表示答案。

---

## 样例

### 输入
```
2
```

### 输出
```
5
```

（f(2,1)=1, f(2,2)=2, f(3,1)=2）

---

## 数据范围

- 1 ≤ T ≤ 10^15
- PE 答案: T = 10^15 → 1485776387445623
