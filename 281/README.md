# Pizza Toppings

来源：改编自 Project Euler Problem 281

## 原题意

将披萨均分为 m·n 片。有 m 种不同馅料（m≥2），每种恰好放在 n 片（n≥1）上。旋转视为相同，翻转视为不同。记 f(m,n) 为方案数。求所有满足 f(m,n) ≤ 10^15 的 f(m,n) 之和。PE 答案：1485776387445626。

## 题目

给定阈值 T，求所有满足 f(m,n) ≤ T（m ≥ 2, n ≥ 1）的 f(m,n) 之和。

## 数据范围

- 1 ≤ T ≤ 10^15
- PE 答案: T = 10^15 → 1485776387445626

## 改编思路

### 方向一：参数化阈值
将固定的 10^15 改为可变输入 T。保留原题核心（枚举所有满足的 f(m,n) 求和）。✅ 采用

### 方向二：求第 K 大
改为求所有 f(m,n) 中的第 K 大值。需要维护候选集合并排序。❌ 不采用

### 方向三：单独计算 f(m,n)
给定 m,n 直接输出 f(m,n)。过于简单，失去求和趣味。❌ 不采用

## 算法

Burnside 引理：f(m,n) = (1/(mn))·Σ_{d|n} φ(n/d) · (md)!/(d!^m)。搜索范围 m≤18，使用 __int128 计算。
