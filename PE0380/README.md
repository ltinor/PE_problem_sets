# 神奇的迷宫！

来源：改编自 Project Euler Problem 380

## 原题意

m×n 网格迷宫（生成树计数），求 C(100,500)。PE 答案：6.3202e25093。

## 题目

给定 m, n，求 m×n 网格的生成树数量（迷宫数）。

## 数据范围

m, n ≤ 100

## 算法

### 方向一：Matrix-Tree 定理

网格图生成树数 = Laplacian 矩阵任一余子式的行列式。m×n 网格的 Laplacian 有特殊结构，可用特征值公式。

### 方向二：特征值公式

m×n 网格生成树数 = Π_{i=1}^{m-1} Π_{j=1}^{n-1} (4 - 2cos(πi/m) - 2cos(πj/n))。用高精度浮点或对数计算。

### 方向三：Kirchhoff 定理 + LU 分解

直接构建 Laplacian 矩阵，用高精度有理数或模大素数计算行列式。对多个素数取模后用 CRT 合并。

### 时间复杂度

O((mn)³) 直接法，O(mn log(mn)) 特征值法。
