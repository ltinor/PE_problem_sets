# 神奇的迷宫！

## 题目描述

m×n 迷宫是 m×n 网格中放置墙壁，使从左上角到任意其他方格恰好只有一条路径。

C(m,n) 表示不同 m×n 迷宫的数目。旋转/翻转变换视为不同。

给定 m, n，求 C(m,n)，用科学计数法表示（5 位有效数字，格式如 1.2346e12）。

---

## 输入格式

一行两个整数 m, n。

---

## 输出格式

科学计数法表示的 C(m,n)，5 位有效数字。

---

## 样例

### 输入
```
9 12
```

### 输出
```
2.5720e46
```

---

## 数据范围

1 ≤ m, n ≤ 100
