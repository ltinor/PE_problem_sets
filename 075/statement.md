# 唯一的整数边直角三角形

## 题目描述

给定一段长度为 $L$ 的电线，问有多少种不同的整数边直角三角形可以用这段电线弯折而成。不同的三角形指三边长的有序三元组 $(a, b, c)$ 不同（不考虑顺序），且满足 $a^2 + b^2 = c^2$ 及 $a + b + c = L$。

例如：
- $L = 12$ 仅可形成 $(3,4,5)$，共 $1$ 种；
- $L = 120$ 可形成 $(30,40,50), (20,48,52), (24,45,51)$，共 $3$ 种。

求对于所有 $L \le M$，有多少个 $L$ 恰好只有 $1$ 种弯折方式。

---

## 输入格式

一行，一个整数 $M$。

---

## 输出格式

一个整数，表示满足条件的 $L$ 的个数。

---

## 样例

### 输入
```
1500000
```

### 输出
```
161667
```

**解释**：$L = 12$ 仅有 $(3,4,5)$ 一种方式（注意 $(6,8,10)$ 周长为 $24$，是另一个 $L$）。原题中 $M = 1500000$ 时共有 $161667$ 个 $L$ 恰好只有一种方式。

---

## 数据范围

- $12 \le M \le 1\,500\,000$
