# 无平方因子二项式系数

## 题目描述

二项式系数 C(n,k) 可以排列成帕斯卡三角形。如果一个正整数不被任何素数的平方整除，则称其为"无平方因子数"。

在帕斯卡三角形的前 8 行中，所有出现的不同的数有 12 个：1, 2, 3, 4, 5, 6, 7, 10, 15, 20, 21, 35。其中除了 4 和 20 外都是无平方因子数，它们的和为 105。

给定整数 N，求帕斯卡三角形前 N 行（第 0 行到第 N 行）中所有不同的无平方因子数之和。

---

## 输入格式

一行一个整数 N (1 ≤ N ≤ 51)。

---

## 输出格式

一行一个整数，表示无平方因子二项式系数之和。

---

## 样例

### 输入

```
8
```

### 输出

```
105
```

### 输入

```
51
```

### 输出

```
34029210557338
```

---

## 数据范围

- 1 ≤ N ≤ 51
