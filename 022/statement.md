# 英文名得分

## 题目描述

在 Project Euler 的第 22 题中，我们需要计算一个包含五千多个英文名的文本文件中所有名字的得分。

首先将所有英文名按照字母序排序，然后计算每个名字的字母价值。字母价值定义为名字中每个字母在字母表中的位置之和（A=1, B=2, ..., Z=26）。

每个名字的**得分** = 它在排序后的位置（1-indexed）× 它的字母价值。

例如，按字母序排序后，第 938 个名字是 COLIN，其字母价值为 3+15+12+9+14=53，因此得分为 938×53=49714。

你的任务是：给定 N 个英文名，计算所有名字的得分之和。

---

## 输入格式

第一行一个整数 N，表示名字的数量。

接下来 N 行，每行一个只包含大写英文字母的字符串，表示一个名字。

---

## 输出格式

输出一个整数，表示所有名字的得分之和。

---

## 样例

### 输入
```
5
JOHN
COLIN
ADAM
DAVID
MARY
```

### 输出
```
718
```

（排序后：ADAM(1×19=19)、COLIN(2×53=106)、DAVID(3×40=120)、JOHN(4×47=188)、MARY(5×57=285)；总计 19+106+120+188+285=718。）

---

## 数据范围

- $1 \le N \le 5000$
- 每个名字长度在 $1$ 到 $20$ 之间
- 名字仅包含大写字母 A-Z
