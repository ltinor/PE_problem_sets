# 数字和除法

## 题目描述

对于正整数 $n$，记 $s(n)$ 为 $n$ 的十进制各位数字之和。若 $s(n)$ 整除 $n$，则称 $n$ 满足"数字和除法"性质。

问题要求：对于给定的上界 $N$，计算所有满足条件的 $n$ 的总和。

例如：
- $n=12$，$s(12)=1+2=3$，$12 \div 3 = 4$，满足条件。
- $n=11$，$s(11)=2$，$11 \bmod 2 = 1 \neq 0$，不满足条件。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 201773590。
- `verify`：输出前 30 个 Harshad 数、不同上界的统计信息、密度分析。
- `compute`：使用数位 DP 探索更大范围，分析答案的因子分解。

## 样例

### 输入
```
PE
```

### 输出
```
201773590
```

### 验证
```
verify
```

输出内容包括：
- 前 30 个 Harshad 数
- $N=10^2, 10^3, \dots, 10^6$ 的计数与总和
- Harshad 数密度随 $n$ 增大的衰减趋势

## 数据范围

- 验证范围：$N \le 10^6$（朴素枚举可行）
- 数位 DP 范围：$N \le 10^{12}$（取决于数字和上界）
- 完整问题：PE 答案 $201773590 \approx 2.02 \times 10^8$
