# PE776 — Digit Sum Division（数字和除法）

来源：改编自 Project Euler Problem 776

## 原题意

对于一个正整数 $n$，定义 $s(n)$ 为其十进制各位数字之和。若 $s(n)$ 整除 $n$（即 $n \bmod s(n) = 0$），则称 $n$ 为"数字和可除数"（Harshad 数）。

问题要求计算在某个上界 $N$ 以内所有数字和可除数的总和或计数。

PE 答案：201773590（约 $2.02 \times 10^8$）。

## 算法

1. **朴素枚举**：对每个 $n \le N$，计算各位和并判断整除性，时间复杂度 $O(N \log N)$。
2. **数位 DP**：利用数位 DP 在 $O(\text{digits} \times \text{sum}^2)$ 复杂度内计算满足条件的数的个数或总和。
3. **Harshad 数性质**：Harshad 数的密度随 $n$ 增大而趋于 0（因为 $s(n) \approx 4.5 \log_{10} n$，而 $n$ 线性增长）。
4. **分段优化**：对较大的 $N$，可利用递推关系或分块加速。

## 改编方向

1. 推广到其他进制（如二进制数字和除法）
2. 求连续一段区间内的数字和可除数之和
3. 限制数字和的值在一个区间内
4. 推广到多重数字和（各位平方和、乘积等）
5. 计算满足 $s(n)^k \mid n$ 的数的分布
