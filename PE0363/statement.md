# 贝塞尔曲线逼近

## 题目描述

三次贝塞尔曲线由控制点 P_0=(1,0), P_1=(1,v), P_2=(v,1), P_3=(0,1) 定义。

选择 v>0 使得曲线与坐标轴围成的面积 = π/4（四分之一圆面积）。

求该曲线长度 L 与四分之一圆弧长 π/2 的百分比误差：
100 × (L - π/2) / (π/2)。

---

## 输入格式

无输入（或输入任意值）。

---

## 输出格式

一个浮点数，保留小数点后 10 位。

---

## 样例

### 输入
```
0
```

### 输出
```
0.0000372091
```

---

## 数据范围

精度要求 10^{-10}。
