# 海韦龙形曲线

## 题目描述

记 D₀ 为包含两个字符的字符串 "Fa"。对于 n ≥ 1，我们通过如下的字符串重写规则，由 D_{n-1} 推出 D_n：

- "a" → "aRbFR"
- "b" → "LFaLb"

因此，D₀ = "Fa"，D₁ = "FaRbFR"，D₂ = "FaRbFRRLFaLbFR"，依此类推。

这些字符串可以作为一个计算机绘图程序的指令加以解读：
- "F" 表示"向前画一单位"
- "L" 表示"左转 90 度"
- "R" 表示"右转 90 度"
- "a" 和 "b" 可以忽略

初始状态下，计算机光标的位置是 (0,0)，方向指向 (0,1)（向上）。

根据 D_n 绘制的奇异图像被称为 n 阶**海韦龙形曲线**。例如，D₁₀ 中，经过 500 步时所到达的位置是高亮的点 (18,16)。

给定 n 和 K，求根据 D_n 绘制图像，经过 K 步之后光标的位置。将答案写作 "x,y" 的形式，中间没有空格。

## 输入格式

一行两个整数 n 和 K，以空格分隔。

## 输出格式

一行，格式为 "x,y"（不含空格），表示经过 K 步后的坐标。

---

## 样例

### 输入
```
0 1
```

### 输出
```
0,1
```

### 输入
```
10 500
```

### 输出
```
18,16
```

### 输入
```
50 1000000000000
```

### 输出
```
139776,963904
```

---

## 数据范围

- 0 ≤ n ≤ 50
- 0 ≤ K ≤ 2^n
- 标准时限：1 秒

---

## 提示

D_n 中 'F' 的总数为 2^n。可通过预计算每个递归层级上 'a' 和 'b' 展开的净位移和方向变化，在递归遍历时批量跳过完整展开。PE 原题 (n=50, K=10^12) 答案为 (139776,963904)。
