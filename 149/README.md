# 149 — 最大子段和

来源：改编自 Project Euler Problem 149

## 原题意

在 2000×2000 的延迟斐波那契矩阵中，求任意方向（水平、垂直、对角线、反对角线）的最大子段和。

原题答案：52852124。

## 题目

参数化 N：输入 N (≤ 2000)，求 N×N 矩阵中任意直线方向的最大子段和。

## 数据范围

- N ≤ 2000

## 算法

**std**: 使用延迟斐波那契生成器生成矩阵。对水平、垂直、两条对角线四个方向分别使用 Kadane 算法 O(N²)。总复杂度 O(N²)。

**brute**: 对每条直线的所有子段暴力求和 O(N³)，适用于小 N（≤200）。

## 改编方向

1. **参数化 N**：将固定 N=2000 改为输入参数。
2. **Kadane 算法**：使用 O(n) 最大子段和算法处理每条线。
3. **四方向遍历**：水平、垂直、主对角线、反对角线。
4. **PE 答案验证**：(N=2000) 作为测试点，输出 52852124。
