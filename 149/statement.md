# 最大子段和

## 题目描述

使用以下"延迟斐波那契"生成器定义序列 sₖ：

- 当 1 ≤ k ≤ 55 时：sₖ = [100003 − 200003k + 300007k³] (mod 1000000) − 500000
- 当 56 ≤ k 时：sₖ = [sₖ₋₂₄ + sₖ₋₅₅] (mod 1000000) − 500000

将 s₁ 到 s_{N²} 按行优先顺序填入 N×N 的矩阵。

在矩阵中，沿水平、垂直、对角线或反对角线方向取连续的一段，求所有可能子段的和的最大值。

---

## 输入格式

一行一个整数 N (1 ≤ N ≤ 2000)。

---

## 输出格式

一行一个整数，表示最大子段和。
