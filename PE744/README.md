# PE744 — "What? Where? When?" (什么？哪里？何时？)

来源：改编自 Project Euler Problem 744

## 原题意

"什么？哪里？何时？"是一款专家与观众对抗的问答类真人秀电视节目。

节目开始时有 $2n+1$ 个信封，其中 $2n$ 个信封中装有问题，剩下的信封中装有一张**红牌**。

每一轮随机抽取一个未拆封的信封：
- 如果信封里装有红牌，则**游戏非正常结束**
- 若装有问题，则专家必须回答。答对（概率 $p$）则专家加一分，答错则观众加一分

如果一直没有抽到红牌，则当专家或观众任意一方获得 $n$ 分时，游戏**正常结束**。

记 $f(n,p)$ 为游戏正常结束的概率。

已知（保留小数点后 10 位）：
- $f(6, \frac{1}{2}) = 0.2851562500$
- $f(10, \frac{3}{7}) = 0.2330040743$
- $f(10^4, 0.3) = 0.2857499982$

求 $f(10^{11}, 0.4999)$，保留小数点后 10 位。

PE 答案：8.56605648

## 算法

1. **概率模型**：红牌在 $2n+1$ 个位置中均匀分布。设 $T$ 为有人达到 $n$ 分时已处理的问题数。游戏正常结束当且仅当红牌位置 > $T$：
   $$f(n,p) = \sum_{t=n}^{2n-1} P(T=t) \cdot \frac{2n+1-t}{2n+1}$$

2. **$T$ 的分布**：$T$ 是从 $n$ 到 $2n-1$ 的随机变量，服从截断负二项分布：
   $$P(T=t) = \binom{t-1}{n-1}\left[p^n(1-p)^{t-n} + (1-p)^n p^{t-n}\right]$$

3. **大参数渐近**：当 $n \to \infty$ 且 $p \to 0.5$ 时，可利用正态近似或赌徒破产问题的渐近公式计算。

4. **复杂度**：精确计算 $O(n^2)$；渐近公式 $O(1)$。

## 改编方向

1. 参数化 $n, p$
2. 考虑多个红牌
3. 专家和观众的目标分数不同
4. 改为连续时间模型
5. 加入"跳过"或"求助"等特殊规则
