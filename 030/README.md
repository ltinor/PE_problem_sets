# PE030 — 各位数字的 $K$ 次幂

来源：改编自 Project Euler Problem 30

## 原题意

求所有等于其各位数字的五次幂之和的数的总和。

例如，$1634 = 1^4 + 6^4 + 3^4 + 4^4$，$8208 = 8^4 + 2^4 + 0^4 + 8^4$，$9474 = 9^4 + 4^4 + 7^4 + 4^4$ 都等于各位数字的四次幂之和。这些数的总和为 $19316$。

## 题目

给定整数 $K$，求所有十进制正整数 $n$（$n \ge 2$）中，满足 $n$ 等于其各位数字的 $K$ 次幂之和的所有 $n$ 的总和。

## 数据范围

- $K \le 6$
- 多组测试数据

## 算法

- **std**：预计算 $0^K$ 到 $9^K$。枚举所有可能的数 $n$，上界为 $7 \times 9^K$（当数字位数足够多时，各位数字的 $K$ 次幂之和必然小于该数本身）。对每个 $n$ 计算各位数字的 $K$ 次幂之和，判断是否相等。时间复杂度 $O(7 \cdot 9^K)$。
- **brute**：同样的算法。
