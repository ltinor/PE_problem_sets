# 各位数字的 $K$ 次幂

## 题目描述

给定整数 $K$，考虑所有十进制正整数 $n$（$n \ge 2$），满足 $n$ 等于其各位数字的 $K$ 次幂之和。求所有这些 $n$ 的总和。

例如，当 $K=4$ 时：
- $1634 = 1^4 + 6^4 + 3^4 + 4^4$
- $8208 = 8^4 + 2^4 + 0^4 + 8^4$
- $9474 = 9^4 + 4^4 + 7^4 + 4^4$

这三个数的总和为 $1634 + 8208 + 9474 = 19316$。

---

## 输入格式

第一行一个整数 $T$，表示测试数据组数。  
接下来 $T$ 行，每行一个整数 $K$。

---

## 输出格式

对于每组数据，输出一行一个整数，表示所有满足条件的正整数 $n$ 的总和。

---

## 样例

### 输入
```
1
4
```

### 输出
```
19316
```

---

## 数据范围

- $1 \le T \le 10$
- $2 \le K \le 6$
