# 2011 个 9

## 题目描述

考虑实数 $\sqrt{2}+\sqrt{3}$。计算它的偶数次幂：

$(\sqrt{2}+\sqrt{3})^2 = 9.898979485566356\dots$

$(\sqrt{2}+\sqrt{3})^4 = 97.98979485566356\dots$

$(\sqrt{2}+\sqrt{3})^6 = 969.998969071069263\dots$

可以证明 $(\sqrt{2}+\sqrt{3})^{2n}$ 的小数部分在 $n$ 充分大时趋近于 $1$，且小数部分开头连续 $9$ 的个数非降。

对于所有形如 $\sqrt{p}+\sqrt{q}$（$p,q$ 正整数，$p<q$）且满足 $(\sqrt{p}+\sqrt{q})^{2n}$ 小数部分趋近于 $1$ 的数对，记 $C(p,q,n)$ 为小数部分开头连续 $9$ 的个数。记 $N(p,q)$ 为使得 $C(p,q,n) \ge K$ 的最小 $n$ 值。

给定 $K$，求 $\sum\limits_{p+q\le K} N(p,q)$。

---

## 输入格式

一行一个整数 $K$。

---

## 输出格式

一行一个整数，表示 $\sum N(p,q)$ 的值。

---

## 样例

### 输入

```
1
```

### 输出

```
1
```

### 输入

```
3
```

### 输出

```
8
```

### 输入

```
2011
```

### 输出

```
709313889
```

---

## 数据范围

- $1 \le K \le 2011$
