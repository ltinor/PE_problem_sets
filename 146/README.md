# 146 — 素数模式研究

来源：改编自 Project Euler Problem 146

## 原题意

求小于一亿五千万的所有 n，使得 n²+1, n²+3, n²+7, n²+9, n²+13, n²+27 为连续素数，求这些 n 的和。

原题答案：676333270。

## 题目

参数化 M：输入 M (≤ 150,000,000)，求所有 n < M 满足 n²+1, n²+3, n²+7, n²+9, n²+13, n²+27 为连续素数的 n 之和。

## 数据范围

- M ≤ 150,000,000

## 算法

**std**: 基于模分析进行剪枝。n 必须被 10 整除（n²+1,3,7,9 末位分析），n%3≠0，n%7∈{3,4}。对候选 n 使用 Miller-Rabin 确定性素性测试（12 个基）检查 6 个目标数和 8 个间隔数。时间复杂度约为 O(M/50 × log³M)。

**brute**: 使用试除法检查素性，只适用于小 M（≤10⁵）。

## 改编方向

1. **参数化 M**：将固定 M=150M 改为输入参数。
2. **模剪枝**：利用 n≡10 (mod 10), n%3≠0, n%7∈{3,4} 大幅减少候选数。
3. **素性测试**：使用 Miller-Rabin 替代试除法，支持大范围。
4. **PE 答案验证**：(M=150000000) 作为测试点，输出 676333270。
