# 素数模式研究

## 题目描述

使得 n²+1, n²+3, n²+7, n²+9, n²+13, n²+27 为连续素数的最小正整数 n 是 10。在小于一百万的整数中，所有满足这一条件的 n 之和为 1242490。

给定整数 M，求所有 n < M 中满足上述条件的 n 之和。

---

## 输入格式

一行一个整数 M (1 ≤ M ≤ 150,000,000)。

---

## 输出格式

一行一个整数，表示满足条件的 n 之和。

---

## 样例

### 输入

```
1000000
```

### 输出

```
1242490
```

---

## 数据范围

- 1 ≤ M ≤ 150,000,000
