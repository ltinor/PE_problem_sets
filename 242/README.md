# 奇数三元组 (Odd Triplets)

来源：改编自 Project Euler Problem 242

## 原题意

对集合 {1,2,...,n}，定义 f(n,k) 为元素和为奇数的 k 元子集的个数。
当 n, k, f(n,k) 均为奇数时，称 [n,k,f(n,k)] 为奇数三元组。
求 n ≤ 10^12 时奇数三元组的个数。
原题答案: 9971042。

## 题目

给定 N，求所有满足 n ≤ N 的奇数三元组 [n,k,f(n,k)] 的个数。

## 数据范围

输入一个整数 N (1 ≤ N ≤ 10^12)。

## 算法

1. **必要条件**: n 必须是奇数。当 n 为偶数时，O = E = n/2，f(n,k) 总是偶数。

2. **Lucas 定理**: f(n,k) 为奇数当且仅当满足特定二进制条件。
   记 O = ⌈n/2⌉, E = ⌊n/2⌋。由 Lucas 定理：
   C(a,b) mod 2 = 1 ⇔ b ⊆ a（二进制按位包含）
   f(n,k) = Σ_{o odd} C(O,o)C(E,k-o) mod 2 = 奇数个 o 满足 o⊆O 且 k-o⊆E。

3. **关键结论**:
   - n ≡ 3 (mod 4): 无解
   - n ≡ 1 (mod 4): 解的个数 = 2^{popcount(n)-1}
   其中 k 恰好是所有满足 k ⊆ n（按位）且 k 为奇数的值。

4. **求和**: 答案 = Σ_{m=0}^{⌊(N-1)/4⌋} 2^{popcount(m)}
   使用数位 DP 在 O(log N) 时间内求解。
