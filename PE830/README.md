# PE830 — Shifted Exponentiation（平移指数）

来源：改编自 Project Euler Problem 830

## 原题意

计算移位后的自幂求和：$\sum (n+k)^n$ 或其模某数的结果。"Shifted"（平移）指的是底数或指数被加上一个偏移量，而"Exponentiation"（指数运算）指自幂 $n^n$ 或变幂 $(n+k)^n$。

此类求和没有简单的闭式公式，通常需要：
- 对较小的 $n$ 直接计算
- 对较大的 $n$ 利用周期性质（模意义下）

PE 答案：6822681719333421（约 $6.8 \times 10^{15}$，表明 $N$ 很大）。

## 算法

1. **快速模幂**：使用二分幂算法计算 $a^b \bmod m$。
2. **Faulhaber 公式**：对于固定指数的情况（$\sum k^m$），可用 Bernoulli 数求和。
3. **模周期**：模 $m$ 下自幂序列 $n^n \bmod m$ 具有周期性（周期为 $\operatorname{lcm}(m, \varphi(m))$ 的因子）。
4. **分块处理**：对较大的 $N$，利用周期性质加速求和。

## 改编方向

1. 考虑 $(k \cdot n)^n$ 或 $n^{n \cdot k}$ 等变体
2. 研究平移指数的模周期性质

4. 考察不同模数下的分布规律
5. 与 Carmichael 函数和原根的联系
