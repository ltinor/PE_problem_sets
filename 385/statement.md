# 三角形内椭圆

## 题目描述
对于平面上的任意三角形，其内部存在唯一的最大面积椭圆（称为 Steiner 内切椭圆）。

对于给定的 n，考虑所有满足以下条件的三角形：
- 三个顶点的横纵坐标均为绝对值不超过 n 的整数
- 最大内切椭圆的两个焦点分别为 (√13, 0) 和 (-√13, 0)

记 A(n) 为所有这些三角形的面积之和。

给定 n，求 A(n)。

---
## 输入格式
一个整数 n。

---
## 输出格式
A(n)。

---
## 样例
### 输入
```
8
```
### 输出
```
72
```

### 输入
```
10
```
### 输出
```
252
```

---
## 数据范围
- 对于 30% 的数据：n ≤ 8
- 对于 60% 的数据：n ≤ 100
- 对于 100% 的数据：n ≤ 10^9
