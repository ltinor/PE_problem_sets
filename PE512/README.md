# PE512 - 幂的欧拉函数和

来源：改编自 Project Euler Problem 512

## 原题意

记 φ(n) 为欧拉函数。
f(n) = (Σ_{i=1}^n φ(n^i)) mod (n+1)。
g(n) = Σ_{i=1}^n f(i)。
已知 g(100) = 2007。
求 g(5 × 10^8)。

PE 答案：5066059188205026。

## 题目

给定 N，计算 g(N) = Σ_{n=1}^N f(n)，其中 f(n) = (Σ_{i=1}^n φ(n^i)) mod (n+1)。

## 算法

- φ(n^i) = n^{i-1} · φ(n)（对于 i ≥ 1）。
- 在模 n+1 下，n ≡ -1，所以 n^{i-1} ≡ (-1)^{i-1}。
- Σ_{i=1}^n (-1)^{i-1} = 1（n 为奇数）或 0（n 为偶数）。
- 故 f(n) = 0（n 偶数）或 φ(n) mod (n+1) = φ(n)（n 奇数）。
- g(N) = Σ_{n≤N, n odd} φ(n)。
- 使用杜教筛（Dirichlet hyperbola method）递归计算 φ 前缀和。

## 改编方向

1. **改变底数**：用 φ_k(n)（Jordan 函数）替代 φ(n)。
2. **改模数**：f(n) mod m 而非 mod (n+1)。
3. **求部分和**：g(L, R) 区间求和。
4. **高次幂**：Σ φ(n^i) 上界改为 m 而非 n。
