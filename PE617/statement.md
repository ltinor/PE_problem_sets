# 镜面幂序列

## 题目描述

对于两个整数 $n,e>1$，我们定义满足如下条件的无穷整数序列 $(a_i)_{i\ge 0}$ 为 **$(n,e)$-MPS（镜面幂序列）**：对于所有 $i\ge 0$，都有 $a_{i+1}=\min(a_i^e, n-a_i^e)$ 以及 $a_i>1$。

尽管这样的序列总是被 $n$，$e$ 和 $a_0$ 唯一确定，但对于大多数的取值这样的序列并不存在。例如，不存在任何 $n<6$ 的 $(n,e)$-MPS。

记 $C(n)$ 为 $e$ 可以任意选择时所有 $(n,e)$-MPS 的数量，并记 $D(N)=\sum_{n=2}^N C(n)$。

已知 $D(10)=2$，$D(100)=21$，$D(1000)=69$，$D(10^6)=1303$ 以及 $D(10^{12})=1014800$。

求 $D(10^{18})$。

## 输入格式

一行，字符串 `PE` 或 `verify`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案：1001133757。
若输入为 `verify`，输出已知测试值并验证不动点计数。

## 样例

### 输入
```
PE
```

### 输出
```
1001133757
```

## 数据范围

- 完整问题：$N = 10^{18}$
- 验证模式：检查 $D(10)$、$D(100)$ 等已知值的部分贡献
