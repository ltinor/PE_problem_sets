# 利克瑞尔数

来源：改编自 Project Euler Problem 55

## 原题意

在小于10000的数中，经过50次"反转并相加"迭代后仍不能变成回文数的数的个数。原题答案：249。

## 题目

给定多组 $N, M$，对每组求：在 $1 \\leq i < N$ 中，有多少个数经过至多 $M$ 次迭代后仍不能变成回文数。

迭代操作：将当前数反转并与原数相加。例如 $47 + 74 = 121$（回文）。

## 数据范围

$1 \\leq N \\leq 10000$，$1 \\leq M \\leq 50$

输入含多组测试数据，直到 EOF。

## 算法

大整数加法（最高可达约300位）+ 回文检查 + 迭代计数。

时间复杂度：$O(N \\cdot M \\cdot L)$，其中 $L$ 为大整数长度。
