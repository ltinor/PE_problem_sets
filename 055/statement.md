# 利克瑞尔数

## 题目描述

将 $47$ 反转并相加：$47 + 74 = 121$，得到一个回文数。

不是所有数都能迅速变成回文数。例如 $349$ 需要3次迭代：
- $349 + 943 = 1292$
- $1292 + 2921 = 4213$
- $4213 + 3124 = 7337$

有些数（如 $196$）被认为永远无法通过反转相加变成回文数，这类数称为**利克瑞尔数**。

给定整数 $N$ 和 $M$，对于 $1$ 到 $N-1$ 之间的每个数，执行至多 $M$ 次反转相加操作。如果在 $M$ 次内能得到回文数，则该数不是利克瑞尔数；否则是。统计利克瑞尔数的个数。

---

## 输入格式

一行两个整数 $N$ 和 $M$，以空格分隔。

---

## 输出格式

一行一个整数，表示利克瑞尔数的个数。

---

## 样例

### 输入
```
10 50
```

### 输出
```
0
```

---

## 数据范围

- $1 \\leq N \\leq 10000$
- $1 \\leq M \\leq 50$
- 注意：迭代过程中数字可能很大（可达数百位），需要使用大整数运算
