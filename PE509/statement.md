# 约数取石子游戏

## 题目描述

安东和伯特兰喜欢玩三堆取石子游戏。但他们修改了规则：
每次只能从一堆中取石子，且取出的石子数必须是该堆当前石子数的真约数（即小于自身的约数）。
如果一堆只剩 1 颗石子，则无法取出（因为 1 没有真约数）。

两人都采取最优策略，无法取石子的一方输。

三元组 (a,b,c) 表示三堆石子分别的数量。对于所有 1 ≤ a,b,c ≤ n，记 S(n) 为先手必胜的局面数量。

已知 S(10) = 692，S(100) = 735494。

给定 n，求 S(n) mod 1234567890。

## 输入格式

一个整数 n（1 ≤ n ≤ 123456787654321），或字符串 `PE`。

## 输出格式

一个整数，表示 S(n) mod 1234567890。

## 样例

### 输入
```
10
```

### 输出
```
692
```

## 数据范围

- 对于 30% 数据：n ≤ 20
- 对于 60% 数据：n ≤ 2000
- 对于 100% 数据：n ≤ 123456787654321
