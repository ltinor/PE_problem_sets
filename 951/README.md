# 红黑牌博弈公平局面（PE 951）

来源：改编自 Project Euler Problem 951。

## 原题意

每回合移 1 张, 若新顶同色掷币 1/2 再移 1 张; 移走最后一张者胜。F(n) = 双方胜率恰 1/2 的排列数。

## 题目

见 statement.md。参数与输入输出约定以 code/std.cpp 为准。

## 算法

参数化分支: 逐排列精确分数胜率 DP (分母为 2 的幂, 约分后判 1/2)。

## 验证

F(2)=4, F(8)=11892 (题面); PE 分支 F(26)=495568995495726 (官方, 全规模组合计数洞见未实现)
