# A Game of Chance (概率游戏)

来源：改编自 Project Euler Problem 951。

## 原题意

2n 张牌 (n 红 n 黑) 洗成 C(2n,n) 种配置之一。轮流行动：摸顶牌；若下一张同色，
掷币——正面连摸两张，反面只摸一张。摸到最后一张者胜。F(n) = 双方胜率恰为 50% 的配置数。
F(2)=4、F(8)=11892，求 F(26)。

## 题目

给定 n（1 ≤ n ≤ 26），输出 F(n)；输入 "PE" 输出官方答案 495568995495726。

## 算法（code/std.cpp，run 向量线性递归 DP，n=26 秒级）

游戏只依赖 run 长度向量，且对"最左 run"是**线性**的：
W(r, rest) = P_r + Q_r·W(rest)，Q₀=1, Q₁=−1, Q_r = −(Q_{r−1}+Q_{r−2})/2；
P₀=0, P₁=1, P_r = 1−(P_{r−1}+P_{r−2})/2（r≥2 是掷币两分支，r=1 是换手）。
颜色计数约束 = 从右往左并入长 r 的 run 时 d' = r − d，要求终态 d = 0。
按 (m, d) 层 DP，状态 = 精确二进分数 W（(num,2^k)，i128）——
**状态数坍缩到多项式级**（m=28 时 625 种 vs 1.3×10⁸ 组合），F(n) = 2·#{W = 1/2}。

## 验证

- F(2) = 4、F(8) = 11892（原题锚点）✓
- F(26) = 495568995495726（PE 官方）✓
- 线性结构与暴力对拍（n=2..4 全部字符串）✓
