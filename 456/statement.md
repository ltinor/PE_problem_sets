# 包含原点的三角形 II

## 题目描述

定义序列：
- $x_n = (1248^n \bmod 32323) - 16161$
- $y_n = (8421^n \bmod 30103) - 15051$
- $P_n = \{(x_1, y_1), (x_2, y_2), \dots, (x_n, y_n)\}$

记 $C(n)$ 为以 $P_n$ 中的点为顶点，且严格包含原点在其内部的三角形个数。

例如：
- $C(8) = 20$
- $C(600) = 8950634$
- $C(40000) = 2666610948988$

求 $C(2000000)$。

---

## 输入格式

一行一个整数 $n$。

---

## 输出格式

一行一个整数，表示 $C(n)$。

---

## 样例

### 输入
```
8
```

### 输出
```
20
```

### 输入
```
600
```

### 输出
```
8950634
```

---

## 数据范围

- $3 \le n \le 2 \times 10^6$
- 答案保证在 64 位有符号整数范围内（部分大测试点可能需要使用 `long long`）
