# 采豆子

## 题目描述

有 x 个碗摆成圆形，每个碗中有一颗豆子（初始共 x 颗豆子，每碗一颗）。

操作规则：选择一个碗，将其中的所有豆子取出，按顺时针方向在每个碗中依次放入一颗，直到豆子放完。下一次操作从最后放入豆子的那个碗开始。

不断重复直到回到初始状态（每个碗各有一颗豆子）。

记 M(x) 为从初始状态开始回到初始状态所需的操作次数。已知 M(5)=15，M(100)=10920。

给定 x，求 M(x)。

---

## 输入格式

一个整数 x。

---

## 输出格式

一个整数，表示 M(x)。

---

## 样例

### 输入
```
5
```

### 输出
```
15
```

### 输入
```
100
```

### 输出
```
10920
```

---

## 数据范围

- 对于 30% 数据：x ≤ 100
- 对于 60% 数据：x ≤ 5000
- 对于 100% 数据：x ≤ 100000
