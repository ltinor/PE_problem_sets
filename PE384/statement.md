# 鲁丁-夏皮罗序列

## 题目描述

定义序列 a(n) 为 n 的二进制表示中相邻两个 1 出现的次数（可重叠）。
定义 b(n) = (-1)^a(n)。
定义 s(n) = Σ_{i=0}^n b(i)。

s(n) 有一个性质：所有元素为正，且每个正整数 k 恰好出现 k 次。

记 g(t, c) 为 t 在 s(n) 中第 c 次出现时的下标 n（1 ≤ c ≤ t）。

定义斐波那契数列 F：F(0)=F(1)=1，F(n)=F(n-1)+F(n-2) (n>1)。
定义 GF(t) = g(F(t), F(t-1))。

给定 T，求 Σ_{t=2}^{T} GF(t)。

---

## 输入格式

一个整数 T。

---

## 输出格式

一个整数，表示答案。

---

## 样例

### 输入
```
5
```

### 输出
```
72
```

---

## 数据范围

- 对于 30% 数据：T ≤ 10
- 对于 60% 数据：T ≤ 30
- 对于 100% 数据：T ≤ 45
