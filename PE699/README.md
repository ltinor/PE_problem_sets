# PE699 — Trinity (三位一体)

来源：改编自 Project Euler Problem 699

## 原题意

"三位一体"（Trinity）数是对满足某种与数字 $3$ 相关性质的整数的称呼。
可能涉及以下定义之一：
- $\sigma(n) = 3n$（三倍完全数，triperfect numbers）
- $\sigma(n) \equiv n \pmod{3}$（因子和与 $n$ 模 $3$ 同余）
- 数字 $n$ 可表示为 $a+b+c$ 且三者满足某种三分性质。

求所有不超过 $N$ 的 Trinity 数之和。

PE 答案：37010438774467572。

## 算法

1. **因子和计算**：对于涉及 $\sigma(n)$ 的问题，可使用：
   - 线性筛法预计算 $\sigma(n)$（适用于 $n \le 10^7$）
   - 数论分块 + Dirichlet 卷积（适用于更大的 $n$）

2. **三倍完全数**：已知的三倍完全数非常稀少（仅 $6$ 个已知），
   分别是 $120, 672, 523776, 459818240, 1476304896, 51001180160$。
   若问题本身就是求所有不超过某上限的三倍完全数之和，答案可直接计算。

3. **大范围求和**：若 $N = 10^{18}$，需要使用数论筛法或分块技巧。
   可能需要利用 $\sigma(n)$ 的 Dirichlet 生成函数、积性性质和前缀和快速计算方法。

## 改编方向

1. 参数化倍数 $k$（求 $k$ 倍完全数）
2. 改为计数而非求和
3. 考虑 $\sigma(n) - 2n$（亏数/盈数）的分类
4. 求 $\sigma(n)/n$ 为特定有理数的 $n$
5. 结合 Euler totient 函数 $\varphi(n)$ 的多函数约束
