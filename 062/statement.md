# 立方数重排

## 题目描述

立方数 41063625（即 345³）的数字可以重排成另外两个立方数：56623104（即 384³）和 66430125（即 405³）。事实上，41063625 是满足以下条件的最小立方数：其数字的排列中恰好有三个是立方数。

现在将问题一般化：给定整数 K，求最小的立方数，使得将其十进制表示的数字重排后，恰好可以得到 K 个不同的立方数（包括它本身）。注意，不允许有前导零。

---

## 输入格式

一行一个整数 K（2 ≤ K ≤ 5）。

---

## 输出格式

一行一个整数，表示满足条件的最小立方数。

---

## 样例

### 输入

```
5
```

### 输出

```
127035954683
```

---

## 数据范围

- 2 ≤ K ≤ 5
- 答案不超过 64 位无符号整数范围
