# 立方数重排 (Cubic Permutations)

来源：改编自 Project Euler Problem 62

## 原题意

找出最小的立方数，其数字重排后恰好产生 5 个立方数。答案：127035954683。

## 改编方向

参数化 K（2≤K≤5）。输入 K，找出最小的立方数，其数字重排恰好产生 K 个立方数。

## 题目

给定整数 K，求最小的立方数 n³，使得将 n³ 的数字重排后，恰好可以得到 K 个不同的立方数（包括 n³ 本身）。

## 数据范围

- K: 2 ≤ K ≤ 5
- 答案在 unsigned long long 范围内

## 算法

std: 生成立方数 → 按排序后的数字字符串分组 → 找大小为 K 的组中最小值。

brute: 相同算法独立实现。
