# 通向平等之路

## 题目描述

给定 $n$ 对整数 $(l_1, r_1), (l_2, r_2), \dots, (l_n, r_n)$，初始时：
$$l_i = i,\quad r_i = 0 \quad (1 \le i \le n)$$

**操作**：选择 $1 \le i < j \le n$，令：
$$(l_i, r_i) \leftarrow (l_i + l_j, \ r_i + r_j)$$

恰好进行 $2n-2$ 次操作后，如果所有 $r_1 = r_2 = \dots = r_n$，则称该操作序列是**合法的**。

令 $f(n)$ 表示合法操作序列的总数。求 $f(15)$。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出原题答案 `25332747903959076`
- `verify`：展示小规模 $n$ 的 $f(n)$ 值及算法原理
- `compute`：重新计算完整答案

## 样例

### 输入
```
PE
```

### 输出
```
25332747903959076
```

### 小规模验证
| n | f(n) |
|---|------|
| 2 | 1 |
| 3 | 12 |
| 4 | 336 |
| 5 | 21120 |
| 6 | 2534400 |

## 数据范围

- 验证范围：$n \le 6$
- 完整问题：$n = 15$
- 答案范围：约 $2.53 \times 10^{16}$（64 位有符号整数可容纳）
