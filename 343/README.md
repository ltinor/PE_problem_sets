# 343 — Fractional Sequences

来源：改编自 Project Euler Problem 343

## 原题意

对正整数 k，定义分数序列：a₁ = 1/k，aᵢ = (x_{i-1}+1)/(y_{i-1}-1)（约分到最简）。当 aᵢ 为整数 n 时停止，记 f(k) = n。求 Σ f(k³)（1 ≤ k ≤ 2×10⁶）。答案：821533053。

## 题目

输入 K，求 Σ_{k=1}^{K} f(k³)。

## 数据范围

- 1 ≤ K ≤ 2×10⁵（OJ 版本）
- 原 PE：K = 2×10⁶

## 算法

1. **直接模拟法**：对每个 k 模拟分数序列，O(步骤数)。
2. **数学推导**：f(k) = S-1，其中 S 从 k+1 开始，重复除以最小质因子直至为素数。对于 k³，S = k³+1 = (k+1)(k²-k+1)。
3. **质因数分解**：预处理小素数表，对 k²-k+1 用 Miller-Rabin + Pollard's Rho 分解。

## 改编方向

1. 原题固定 K = 2×10⁶ → 参数化 K（≤ 2×10⁵）
2. 改为求 Σ f(k²) 或 f(k) 本身
3. 增加模数限制

选择方向 1：参数化 K。
