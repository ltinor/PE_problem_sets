# 分数序列

## 题目描述

对于任意正整数 k，由分数 xᵢ/yᵢ 组成的有限序列 aᵢ 按如下方式定义：

- a₁ = 1/k
- 对于 i > 1，aᵢ = (x_{i-1} + 1) / (y_{i-1} - 1)，并将结果约分到最简形式

当 aᵢ 为某个整数 n 时，序列停止。定义 f(k) = n。

例如，当 k = 20 时：

1/20 → 2/19 → 3/18 = 1/6 → 2/5 → 3/4 → 4/3 → 5/2 → 6/1 = 6

所以 f(20) = 6。

给定整数 K，请你计算：

$$\sum_{k=1}^{K} f(k^3)$$

---

## 输入格式

一行一个整数 K。

---

## 输出格式

一行一个整数，表示 Σ f(k³)。

---

## 样例

### 输入

```
100
```

### 输出

```
118937
```

**解释**：已知 Σ_{k=1}^{100} f(k³) = 118937。

---

## 数据范围

- 1 ≤ K ≤ 200000
