# 186 — 网络连通性

来源：改编自 Project Euler Problem 186

## 原题意

一个电话系统有 $10^6$ 个用户，编号 $0$ 到 $999999$。PM（首相）的用户编号是 $524287$。系统记录电话呼叫：第 $k$ 个电话中，呼叫方为 $S_{2k-1}$，被叫方为 $S_{2k}$。序列 $S_k$ 由延迟斐波那契生成器定义：
- $S_k = (100003 - 200003k + 300007k^3) \bmod 10^6$，对于 $1 \le k \le 55$
- $S_k = (S_{k-24} + S_{k-55}) \bmod 10^6$，对于 $k \ge 56$

如果呼叫方和被叫方相同（误拨），呼叫失败但计入呼叫次数。否则，呼叫成功，双方连通（以及它们各自的连通分量）。求使 PM 的连通分量包含至少 $99\%$ 用户（包括 PM）时所需的成功呼叫数。

答案：2325629

## 题目

参数化版本：输入目标百分比 $P$ 和 PM 的编号 $T$，求使 $T$ 所在连通分量大小 $\ge P\% \times 10^6$ 时所需的总呼叫数。

## 数据范围

- $1 \le P \le 100$
- $0 \le T \le 999999$

## 算法

并查集（DSU）。生成延迟斐波那契序列 $S_k$，逐对处理电话记录。每次成功呼叫执行 union 操作，实时检查 PM 所在分量大小。
