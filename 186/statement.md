# 网络连通性

## 题目描述

一个电话系统有 $10^6$ 个用户（编号 $0$ 到 $999999$）。电话记录由延迟斐波那契生成器产生。

第 $k$ 个电话中，呼叫方编号为 $S_{2k-1}$，被叫方编号为 $S_{2k}$。

序列 $S_k$ 定义如下：
- 对于 $1 \le k \le 55$：$S_k = (100003 - 200003k + 300007k^3) \bmod 10^6$
- 对于 $k \ge 56$：$S_k = (S_{k-24} + S_{k-55}) \bmod 10^6$

如果呼叫方和被叫方相同（误拨），该呼叫失败但仍计入呼叫次数。否则，呼叫成功，且双方所在的连通分量合并。

求使得用户 $T$ 所在的连通分量包含至少 $P\%$ 的用户时，所需的呼叫总数。

---

## 输入格式

一行，两个整数 $P$ 和 $T$，用一个空格分隔。

---

## 输出格式

一行，一个整数，表示所需的呼叫总数。

---

## 样例

### 输入
```
99 524287
```

### 输出
```
2325629
```

---

## 数据范围

- $1 \le P \le 100$
- $0 \le T \le 999999$
