# PE604 — 正方形凸路径 (Convex path in square)

来源：改编自 Project Euler Problem 604

## 原题意

定义 F(N) 为一个严格凸的单调递增函数在 N×N 的轴对齐正方形中能经过的格点数量最大值。

已知：F(1)=2，F(3)=3，F(9)=6，F(11)=7，F(100)=30，F(50000)=1898。

求 F(10¹⁸)。

PE 答案：1170060。

## 算法

严格凸函数的相邻点间斜率严格递增。对于格点 (x_i, y_i)，差分 Δy_i/Δx_i 构成严格递增的最简分数序列。

这等价于在 Farey 序列（最简分数 a/b，0 ≤ a ≤ b）中寻找最长链，使得链中的所有分数满足边界约束（所有 Δx 之和 ≤ N，所有 Δy 之和 ≤ N）。

利用 Stern-Brocot 树的性质：F(N) 等于从 0/1 开始，通过不断取中项分数 (a+c)/(b+d) 构建的链的最大长度，其中分母和分子之和不超过 N 的三次方根量级。

具体地，F(N) 等于满足 Σ_{b=1}^{M} φ(b) · b · (b+1)/2 ≤ 3N 的最大 M 所对应的 Farey 序列长度加 1。这里 φ(b) 是欧拉函数。

由于 N = 10¹⁸，M 约在 10⁵ 量级，可以通过数论方法高效计算 φ 的前缀和。

## 改编方向

1. 考虑非正方形区域（如 N×M 矩形）。
2. 改为凹函数或非单调函数。
3. 限制为有理斜率（分母有上界）。
4. 高维推广（如三维空间中的凸曲面）。
