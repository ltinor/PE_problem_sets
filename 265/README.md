# 265 — Binary Circles（二进制环）

来源：改编自 Project Euler Problem 265

## 原题意

将 2^N 个二进制位排成一圈，使得所有顺时针的 N 位子串互不相同（即 De Bruijn 序列）。以全零子串为最高位，顺时针拼接所有位得到一个 2^N 位二进制数，定义为该排列的编码。记 S(N) 为所有不同编码之和。求 S(5)。答案：209110240768。

## 题目

输入正整数 N（3 ≤ N ≤ 5），求 S(N)：所有不同 De Bruijn 排列的编码值之和。

## 数据范围

- 3 ≤ N ≤ 5

## 算法

使用 DFS 回溯生成所有 De Bruijn 序列。从 N 个零开始，维护已使用的 N 位模式集合。在每一步尝试添加 0 或 1，检查新的 N 位窗口是否首次出现。生成 2^N 位后检查环闭合条件（末尾 N-1 位与开头 N-1 位一致）。最后按编码规则转换为整数并求和。De Bruijn 序列总数为 2^{2^{N-1}-N}，N=5 时仅 2048 个，位运算枚举即可。

## 改编方向与取舍

### 改编方向
1. **参数化 N** → 支持 N=3,4,5（本题采用），原题固定 N=5
2. **输出所有序列** → 逐行输出每个有效序列的二进制表示
3. **推广到 K 进制** → 将二进制推广到 K 进制 De Bruijn 序列
4. **仅计数** → 只输出有效序列的数量而非编码和

### 取舍理由
- 选择参数化 N：最自然的 OJ 参数化，N=5 时 2048 个序列 DFS 可秒出
- 不选输出所有序列：N=5 时有 2048 个序列，输出量过大
- 不选 K 进制推广：本质相同但需要搜索空间指数增长，K>2 时 N 需更小
- 不选仅计数：原题求编码和，保留原题语义
