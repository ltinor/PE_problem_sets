# PE784 — Reciprocal Pairs（互反对）

来源：改编自 Project Euler Problem 784

## 原题意

考虑正整数对 $(x, y)$ 满足某种与倒数（reciprocal）相关的条件。常见问题包括：
- 计算满足 $\frac{1}{x} + \frac{1}{y} = \frac{1}{n}$（埃及分数）的整数对数量
- 求 $\frac{1}{x} + \frac{1}{y} < 1$ 的整数对
- 模意义下的互反对：$x \cdot y \equiv 1 \pmod{N}$

PE 答案：5834231041212316（约 $5.83 \times 10^{15}$，16 位整数）。

## 算法

1. **埃及分数拆分**：方程 $\frac{1}{x} + \frac{1}{y} = \frac{1}{n}$ 等价于 $(x-n)(y-n) = n^2$。解数等于 $n^2$ 的正因子个数 $d(n^2)$。
2. **除数函数**：若 $n = \prod p_i^{e_i}$，则 $d(n^2) = \prod (2e_i + 1)$。
3. **双曲求和方法**：$\sum_{n \le N} d(n^2)$ 的渐近行为为 $O(N \log^3 N)$。
4. **逐对枚举**：对于每个 $n$ 的每个 $n^2$ 的因子 $d$，得到解 $(x,y) = (n+d, n + n^2/d)$。
5. **模互反对**：在模 $N$ 意义下，$x$ 的逆元为满足 $x \cdot x^{-1} \equiv 1 \pmod{N}$ 的最小正整数。

## 改编方向

1. 推广到 $\frac{1}{x} + \frac{1}{y} = \frac{p}{q}$（更一般的分数）
2. 求解 $\frac{1}{x} + \frac{1}{y} + \frac{1}{z} = 1$（三项埃及分数）
3. 限制 $x \le y \le N$ 并计数
4. 模互反对的性质（如 Wilson 定理相关）
5. 倒数对的和函数：$\sum_{x,y} f(x,y)$ 满足倒数条件
