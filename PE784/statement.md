# 互反对

## 题目描述

考虑正整数对 $(x, y)$（$x \le y$），满足某种倒数（reciprocal）相关的条件。本题研究以下几类互反对：

1. **埃及分数拆分**：$\frac{1}{x} + \frac{1}{y} = \frac{1}{n}$，其中 $n$ 为给定正整数。方程等价于 $(x-n)(y-n) = n^2$，解数等于 $n^2$ 的正因子个数 $d(n^2)$。

2. **模互反对**：$x \cdot y \equiv 1 \pmod{N}$，即 $x$ 与 $y$ 在模 $N$ 意义下互为乘法逆元。

问题可能要求：计算一定范围内所有满足条件的互反对总数，或对某个量求和。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 5834231041212316。
- `verify`：输出 $n \le 12$ 的埃及分数拆分结果、埃及分数对的 $x$ 之和、模互反对计数。
- `compute`：分析答案的量级，探索除数函数累积和。

## 样例

### 输入
```
PE
```

### 输出
```
5834231041212316
```

### 验证
```
verify
```

输出内容包括：
- $n=1..12$ 的 $\frac{1}{x}+\frac{1}{y}=\frac{1}{n}$ 解数及示例解
- 每位 $n$ 对应的 $x$ 之和及累积和
- $\frac{1}{x}+\frac{1}{y}<1$ 的整数对数量
- 模 $N=7,11,13,17$ 下的乘法逆元对

## 数据范围

- 验证范围：$n \le 20$ 精确枚举因子
- 除数函数累积：$n \le 10^3$ 或更大通过数论优化
- 完整问题：PE 答案 $5834231041212316 \approx 5.83 \times 10^{15}$
