# 排列概率

## 题目描述

一个盒子里装有若干蓝色碟子和红色碟子。设蓝色碟子有 $b$ 个，总碟子数 $t = b + r$（$r$ 为红色碟子数）。从盒子中随机取出两个碟子，两个都是蓝色的概率恰好为 $\frac{1}{2}$。

给定一个整数 $T$，求满足 $t > T$ 这一条件的最小 $b$ 值。

---

## 输入格式

一行一个整数 $T$。

---

## 输出格式

一行一个整数 $b$，表示蓝色碟子的数量。

---

## 样例

### 输入

```
10
```

### 输出

```
15
```

（$t=21, b=15$：$\frac{15}{21} \cdot \frac{14}{20} = \frac{1}{2}$，且 $t > 10$）

### 输入

```
1000000000000
```

### 输出

```
756872327473
```

---

## 数据范围

- $1 \le T \le 10^{12}$
