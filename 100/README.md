# 100 — Arranged Probability

来源：改编自 Project Euler Problem 100

## 原题意

一个盒子中有 $b$ 个蓝色碟子和 $r$ 个红色碟子，总共 $t = b + r$ 个。随机取出两个碟子，两个都是蓝色的概率恰好为 $1/2$。求满足 $t > 10^{12}$ 的最小 $t$ 对应的蓝色碟子数 $b$。

答案：756872327473。

## 题目

输入一个整数 $T$，求在总碟子数 $t > T$ 的条件下，满足随机取两个碟子均为蓝色的概率恰好为 $1/2$ 的最小蓝色碟子数 $b$。

## 数据范围

- $1 \le T \le 10^{12}$

## 算法

问题转化为 Pell 方程 $2b(b-1) = t(t-1)$。递推公式：
- $b_{k+1} = 3b_k + 2t_k - 2$
- $t_{k+1} = 4b_k + 3t_k - 3$

初始值 $b_0=3, t_0=4$。迭代直到 $t > T$，输出 $b$。
