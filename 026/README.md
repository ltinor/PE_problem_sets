# Reciprocal Cycles

来源：改编自 Project Euler Problem 26

## 原题意

对于 d < 1000，$1/d$ 十进制循环节最长的是 d=983，循环节长度为 982。

## 题目

给定 N，求所有 d < N 中，使得 $1/d$ 的十进制表示中循环节最长的 d，输出 d 和循环节长度。

## 数据范围

- $2 \le N \le 10000$

## 算法

std: 模拟长除法，对每个 d 记录余数首次出现位置来确定循环节长度。先去除因子 2 和 5（它们不影响循环节）。  
brute: 相同算法独立实现。

时间复杂度：$O(N^2)$（每个 d 最多 N 步长除法）。
