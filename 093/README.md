# Arithmetic Expressions

来源：改编自 Project Euler Problem 93

## 原题意

使用集合 $\{1, 2, 3, 4\}$ 中每个数字恰好一次，再加上四则运算 $(+, -, \times, /)$ 和括号，可以表示出 $31$ 个不同的数，最大值是 $36$，并且能连续表示 $1$ 至 $28$。

求四个不同数字 $a<b<c<d$ 构成的集合中，可以从 $1$ 开始连续表示最多个正整数的集合，输出 $abcd$。（答案：1258）

## 题目

本题为固定答案题。从 0-9 中选择 4 个不同数字 $a<b<c<d$，用它们各一次以及 $+, -, \times, /$ 和括号，求能连续表示 $1$ 到 $n$ 且 $n$ 最大的那个集合，输出 $abcd$。

## 数据范围

无输入。

## 算法

枚举 $\binom{10}{4}=210$ 种数字组合，每种尝试：
- 24 种数字排列
- 5 种括号结构（Catalan 数 $C_3=5$）
- $4^3=64$ 种运算符组合
使用 RPN（逆波兰表示法）求值，统计可达的正整数目标。

总计算量约 $210 \times 24 \times 5 \times 64 \approx 1.6 \times 10^6$ 次求值。
