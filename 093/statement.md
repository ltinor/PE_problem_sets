# 算术表达式

## 题目描述

使用集合 $\{1, 2, 3, 4\}$ 中每个数字恰好一次，再加上四则运算 $(+, -, \times, /)$ 和括号，可以表示出 $31$ 个不同的数，最大值是 $36$，并且能连续表示 $1$ 至 $28$。

现在考虑所有从 0-9 中选取的 4 个不同数字 $a<b<c<d$ 构成的集合。求出其中可以从 $1$ 开始连续表示最多个正整数的集合，输出 $abcd$。

注意：不允许把数字连起来使用（如 $12+34$）。

---

## 输入格式

无需输入。

---

## 输出格式

输出一个四位数字串 $abcd$，表示最优集合。

---

## 样例

（直接运行即可得到答案）

### 输出

```
1258
```

---

## 数据范围

无输入。答案为固定值。
