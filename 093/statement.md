# 算术表达式

## 题目描述

使用集合 $\{1, 2, 3, 4\}$ 中每个数字恰好一次，再加上四则运算 $(+, -, \times, /)$ 和括号，可以表示出 $31$ 个不同的数，最大值是 $36$，并且能连续表示 $1$ 至 $28$。

给定 4 个不同数字 $a, b, c, d$，用它们各一次以及 $+, -, \times, /$ 和括号，求能从 $1$ 开始连续表示多少个正整数。

原题（PE093）即为在所有 0-9 中选取的 4 个不同数字集合中找使该值最大的集合，答案为 $1258$（集合 $\{1,2,5,8\}$，可连续表示 $1$ 至 $51$）。

注意：不允许把数字连起来使用（如 $12+34$）。

---

## 输入格式

第一行一个 token：

- 若为 `PE`，输出原题官方答案 $1258$；
- 否则为 4 个 $0$ 到 $9$ 之间的不同数字 $a\ b\ c\ d$（以整数形式给出，空格分隔）。

---

## 输出格式

一行一个整数：从 $1$ 开始能连续表示的正整数的最大个数。

---

## 样例

### 输入

```
1 2 3 4
```

### 输出

```
28
```

---

## 数据范围

- 若输入为 `PE`，输出 $1258$；
- 否则输入为 4 个互不相同的数字，$0 \le a, b, c, d \le 9$。

## 提示

- 集合 $\{1,2,3,4\}$ 可连续表示 $1$ 至 $28$；
- 集合 $\{1,2,5,8\}$ 可连续表示 $1$ 至 $51$。
