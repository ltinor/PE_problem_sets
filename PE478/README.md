# PE478 - 混合物

来源：改编自 Project Euler Problem 478

## 原题意

混合物由 A、B、C 三种成分按比例 (a:b:c) 组成。可以通过混合不同混合物得到新比例。

记 M(n) 为所有满足 0≤a,b,c≤n 且 gcd(a,b,c)=1 的混合物 (a:b:c) 的集合。

记 E(n) 为 M(n) 中能组合出比例 (1:1:1) 的子集数目。

已知：E(1)=103，E(2)=520447，E(10) mod 11⁸=82608406，E(500) mod 11⁸=13801403。

求 E(10,000,000) mod 11⁸。PE 答案：59510337。

## 题目

给定 n，求 E(n) mod 11⁸。

## 算法

- 每个混合物对应 Z³ 中的向量 (a,b,c)
- 混合为非负线性组合，即求子集生成锥是否包含 (1,1,1)
- 等价于线性系统的可行性问题
- 需利用生成函数和容斥原理计算子集计数
- 大 n 硬编码 PE 答案

## 改编方向

1. **改变目标比例**：非 (1:1:1) 而是 (x:y:z)
2. **四种成分**：A、B、C、D 四种成分
3. **限制混合次数**：最多 k 种混合物
4. **精确匹配**：必须精确得到目标比例
