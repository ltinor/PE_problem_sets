# PE810 — XOR-Primes（异或素数）

来源：改编自 Project Euler Problem 810

## 原题意

定义非负整数的**异或乘法**（XOR multiplication）$a \otimes b$：将 $a$ 和 $b$ 的二进制表示视为 $\text{GF}(2)$ 上的多项式，按多项式乘法相乘（系数加法为异或），结果即为乘积的二进制值。

一个大于 1 的整数若不能表示为两个大于 1 的整数的异或乘积，则称为**异或素数**（XOR-prime）。这等价于 $\text{GF}(2)$ 上的不可约多项式。

例如：
- $2 = (10)_2 = x$，不可约，是异或素数。
- $3 = (11)_2 = x+1$，不可约，是异或素数。
- $6 = 2 \otimes 3 = x(x+1) = x^2+x = (110)_2 = 6$，可分解，不是异或素数。

求前 $N$ 个异或素数的相关量（如和、数量等）。

PE 答案：12413689438106832。

## 算法

1. **多项式表示**：每个整数对应一个 $\text{GF}(2)$ 上的多项式。
2. **多项式除法**：在 $\text{GF}(2)$ 上进行多项式长除法，检验整除性。
3. **不可约性检验**：只需检验次数不超过 $\deg(n)/2$ 的所有不可约多项式是否能整除 $n$。
4. **计数公式**：$n$ 次不可约多项式的数目为 $I(n) = \frac{1}{n}\sum_{d|n} \mu(d) \cdot 2^{n/d}$。
