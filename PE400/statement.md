# 斐波那契树游戏

## 题目描述

斐波那契树 T(k) 是一棵递归定义的二叉树：
- T(0) 是空树（无节点）
- T(1) 是只有一个节点的二叉树
- T(k) 的根节点有左右两棵子树，分别为 T(k-1) 和 T(k-2)

在这棵树上，两名玩家玩一个取节点游戏。每回合，一名玩家选择一个节点，并取走以该节点为根的整个子树。取走整棵树根节点的玩家输掉游戏。

记 f(k) 为先手玩家在 T(k) 上第一步的必胜走法数目（即保证后手没有必胜策略的走法数）。

给定 k，求 f(k)。

---

## 输入格式

一个整数 k。

---

## 输出格式

一个整数，表示 f(k)。

---

## 样例

### 输入
```
5
```

### 输出
```
1
```

### 输入
```
10
```

### 输出
```
17
```

---

## 数据范围

- 对于 30% 数据：k ≤ 10
- 对于 60% 数据：k ≤ 100
- 对于 100% 数据：k ≤ 10000
