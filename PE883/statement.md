# 显著调和三角形（Remarkable Harmonic Triangles）

## 题目描述

如果一个三角形的三边长 $a, b, c$（均为正整数，$a \le b \le c$）满足：

$$\frac{2}{b} = \frac{1}{a} + \frac{1}{c}$$

则称该三角形为**调和三角形**。此条件等价于 $b$ 等于 $a$ 和 $c$ 的调和平均数，即 $b = \frac{2ac}{a+c}$。

请计算满足周长不超过某个界限的所有调和三角形的相关统计量。

## 输入格式

无输入（固定参数问题）。

## 输出格式

输出一个整数，表示最终答案。

（无样例输入输出，直接计算并输出最终答案。）
