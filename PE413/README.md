# PE413 - 独子数

来源：改编自 Project Euler Problem 413

## 原题意

独子数：d 位正整数，恰好有一个子串能被 d 整除。原题求 F(10^19)，答案为 3079418648040719。

## 题目

给定 N，求所有小于 N 的独子数的个数 F(N)。

## 算法

- 枚举法：对于较小的 d，枚举所有 d 位数，逐一检查每个子串是否被 d 整除
- 子串整除判定：O(d²) 枚举子串，计算数值并取模
- 优化方向：使用数位 DP，以子串模 d 的值作为状态，追踪当前"只有一个子串被整除"的条件

## 改编方向

1. **改为恰好 k 个子串**：求恰好有 k 个子串被 d 整除的 d 位数个数
2. **改变基**：在 b 进制下定义独子数（子串被 d 整除）
3. **改变除数**：子串需被 p 整除（p 为质数），不依赖于位数 d
4. **计数所有位数**：求所有不超过 D 位的独子数总数
