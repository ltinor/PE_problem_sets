# 148 — 帕斯卡三角形

来源：改编自 Project Euler Problem 148

## 原题意

求帕斯卡三角形前 10⁹ 行中不被 7 整除的条目数。

原题答案：2129968654。

## 题目

参数化 R：输入 R (≤ 10⁹)，求帕斯卡三角形前 R 行中不被 7 整除的条目数。

## 数据范围

- R ≤ 1,000,000,000

## 算法

**std**: 使用 Lucas 定理：C(n,k) mod 7 ≠ 0 当且仅当 k 的 base-7 每位 ≤ n 的对应位。第 n 行不被 7 整除的个数 = Π(dᵢ+1)，其中 dᵢ 是 n 的 base-7 各位。累加各行可通过 base-7 分块高效计算：若 g(k)=28ᵏ 为连续 7ᵏ 行的和，则 f(R) = Σ_{i} dᵢ(dᵢ+1)/2 × 28ⁱ × Π_{j>i}(dⱼ+1)。时间复杂度 O(log₇ R)。

**brute**: 逐行生成帕斯卡三角模 7，适用于小 R（≤10³）。

## 改编方向

1. **参数化行数**：将固定 R=10⁹ 改为输入参数。
2. **Lucas 定理**：利用组合数模素数的性质高效计数。
3. **base-7 分块**：利用等比求和公式 O(log R) 求解。
4. **PE 答案验证**：(R=1000000000) 作为测试点，输出 2129968654。
