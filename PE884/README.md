# PE884 — Removing the Joker from the Game（游戏中去除鬼牌）

来源：改编自 Project Euler Problem 884

## 原题意

在 PE 882 的基础上进行扩展：在一场更复杂的牌类游戏中，鬼牌（Joker）被引入。游戏按照特定规则进行，鬼牌可以在某些条件下从游戏中移除。

这涉及到更复杂的概率模型，可能包括：
- 多个玩家轮流抽牌
- 鬼牌在满足特定条件时被移除
- 计算游戏的期望长度或获胜概率
- 最优策略分析

PE 答案：966580193

## 算法

1. **多状态马尔可夫决策过程**：
   - 状态空间包括：剩余牌数、鬼牌位置、各玩家手牌状态
   - 转移概率依赖于当前状态和可选动作

2. **期望值动态规划**：
   - dp[state] = 从当前状态到游戏结束的期望步数
   - 利用吸收马尔可夫链的性质求解

3. **组合计数**：
   - 统计可能的手牌组合数量
   - 考虑鬼牌替代的可能性

4. **优惠券收集问题变体**：
   - 鬼牌作为"通配符"影响收集过程
   - 鬼牌移除后问题退化为标准优惠券收集

2. 多鬼牌场景
