# PE734 — A bit of prime (一点素数)

来源：改编自 Project Euler Problem 734

## 原题意

对于正整数 $n$，定义 $f(n)$ 为所有 $\le n$ 的素数的按位或（bitwise OR）：
$$f(n) = \bigvee_{p \le n,\ p\text{ prime}} p$$

即将所有不超过 $n$ 的素数用二进制表示后，对每一位取逻辑或。
结果中某一位为 $1$ 当且仅当存在至少一个 $\le n$ 的素数在该位为 $1$。

定义 $S(N) = \sum_{n=1}^{N} f(n)$，求 $S(N)$ 的值。

PE 答案：128088830560082。

## 算法

1. **筛法**：使用埃拉托色尼筛法求出 $[1, N]$ 内所有素数。

2. **单调性分析**：$f(n)$ 是 $n$ 的单调不减函数。
   一旦某个比特位被某个素数置为 $1$，该位对后续所有 $n$ 都保持为 $1$。

3. **逐位贡献法**：
   - 对于比特位 $b$，找出最小的素数 $p$ 满足 $p$ 的第 $b$ 位为 $1$
   - 该位对 $S(N)$ 的贡献为 $2^b \times (N - p + 1)$
   - 因为对于所有 $n \ge p$，$f(n)$ 的第 $b$ 位都是 $1$

4. **前缀和优化**：
   - 扫描 $n = 1 \dots N$，维护当前 OR 值
   - 当遇到新的素数时更新 OR 值
   - 累加 $f(n)$ 到前缀和中

5. **复杂度**：$O(N \log \log N)$ 筛法 + $O(N)$ 扫描。

## 改编方向

1. 改为按位与（AND）操作
2. 改为按位异或（XOR）操作
3. 限定素数范围（如区间 $[L, R]$）
4. 改为对合数而非素数进行操作
5. 求使得 $f(n)$ 改变时的 $n$ 值（关键点）
