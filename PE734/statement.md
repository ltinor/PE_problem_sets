# 一点素数

## 题目描述

对于正整数 $n$，定义 $f(n)$ 为所有不超过 $n$ 的素数的按位或：
$$f(n) = \bigvee_{p \le n,\ p\text{ prime}} p$$

即将所有 $\le n$ 的素数用二进制表示后逐位取或运算。
例如：
- $f(5) = 2 \lor 3 \lor 5 = 0010_2 \lor 0011_2 \lor 0101_2 = 0111_2 = 7$
- $f(1) = 0$（没有 $\le 1$ 的素数）

定义 $S(N) = \sum_{n=1}^{N} f(n)$。求 $S(N)$ 的值。

## 输入格式

一行字符串：`PE`、`verify`、`compute` 或 `simple <N>`。

## 输出格式

- `PE`：输出 PE 原题答案 128088830560082。
- `verify`：展示 $n \le 20$ 的 $f(n)$ 值和二进制表示。
- `compute`：计算不同 $N$ 的 $S(N)$ 值。
- `simple <N>`：计算指定 $N$ 的 $S(N)$。

## 样例

### 输入
```
PE
```

### 输出
```
128088830560082
```

### 小规模验证
```
verify
```

展示 $n=1..20$ 的 $f(n)$ 值及其二进制：
| n | f(n) | 二进制 |
|---|------|--------|
| 1 | 0    | 00000000 |
| 2 | 2    | 00000010 |
| 3 | 3    | 00000011 |
| 5 | 7    | 00000111 |
| 11| 15   | 00001111 |
| 17| 31   | 00011111 |

## 数据范围

- 验证范围：$N \le 100$（展示 $f(n)$ 值）
- 完整问题：$N \approx 2 \times 10^6$
- 位数：最多 60 位（$2^{60} \approx 10^{18}$）
