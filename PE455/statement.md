# 尾数幂

## 题目描述

对于正整数 n，记 f(n) 为满足以下条件的最大整数 x（0 ≤ x < 10^9）：
- nˣ 的末 9 位数字恰好等于 x（包括前导零）。
- 若不存在这样的 x，则 f(n) = 0。

例如：
- f(4) = 411728896（因为 4^411728896 = ...490411728896）
- f(10) = 0
- f(157) = 743757（因为 157^743757 = ...567000743757）

验证：Σ_{n=2}^{1000} f(n) = 442530011399。

求 Σ_{n=2}^{N} f(n)。

---

## 输入格式

一个整数 N (2 ≤ N ≤ 10^6)。

---

## 输出格式

一个整数，表示 Σ_{n=2}^{N} f(n)。

---

## 样例

### 输入
```
1000
```

### 输出
```
442530011399
```

---

## 数据范围

- 对于 30% 数据：N ≤ 100
- 对于 60% 数据：N ≤ 5000
- 对于 100% 数据：N ≤ 10^6
