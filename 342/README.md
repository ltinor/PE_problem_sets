# 342 — The Totient of a Square is a Cube

来源：改编自 Project Euler Problem 342

## 原题意

求所有 n（1 < n < 10¹⁰）中，满足 φ(n²) 为立方数的 n 的和。φ 为欧拉总计函数。答案：5943040885644。

## 题目

输入 N，求所有 n（1 < n < N）中，满足 φ(n²) 为完全立方数的 n 的和。

## 数据范围

- 2 ≤ N ≤ 10⁷（OJ 版本）
- 原 PE：N = 10¹⁰

## 算法

1. **线性筛法**：用线性筛 O(N) 计算 φ(n)。对每个 n，验证 n·φ(n) 是否为完全立方数（φ(n²) = n·φ(n)）。
2. **质因数分解法**：对每个 n 分解 n·φ(n) 的质因数，检查所有指数是否为 3 的倍数。
3. **DFS 枚举法**：枚举质因数组合构造候选 n，适合更大范围。

## 改编方向

1. 原题固定 N = 10¹⁰ → 参数化 N（≤ 10⁷）
2. 改为求 φ(n^k) 为 m 次幂
3. 增加模数限制

选择方向 1：参数化 N。原题 10¹⁰ 需要 DFS 枚举，现降为 10⁷ 可用线性筛。
