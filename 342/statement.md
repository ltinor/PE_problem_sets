# 平方数的欧拉函数为立方数

## 题目描述

欧拉总计函数 φ(n) 定义为不超过 n 且与 n 互质的正整数个数。

考虑数 50：
- 50² = 2500 = 2² × 5⁴
- φ(2500) = 2 × 4 × 5³ = 8 × 125 = 1000 = 10³

所以 φ(2500) = φ(50²) 是一个完全立方数。

给定整数 N，求所有满足条件的整数 n（1 < n < N），使得 φ(n²) 是一个完全立方数，并输出这些 n 的总和。

---

## 输入格式

一行一个整数 N。

---

## 输出格式

一行一个整数，表示所有满足条件的 n 的和。

---

## 样例

### 输入

```
100
```

### 输出

```
50
```

**解释**：在 1 < n < 100 范围内，只有 n = 50 满足 φ(50²) = 1000 = 10³。

---

## 数据范围

- 2 ≤ N ≤ 10⁷
