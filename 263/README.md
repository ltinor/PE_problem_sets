# 263 — An Engineers' Dream Come True（工程梦想）

来源：改编自 Project Euler Problem 263

## 原题意

定义"工程师天堂数" n 满足：(n-9,n-3),(n-3,n+3),(n+3,n+9) 是三组连续性感素数对（差为 6 的连续素数），且 n-8,n-4,n,n+4,n+8 均为实用数。求前四个天堂数之和。答案：2039506520。

## 题目

输入正整数 K（1 ≤ K ≤ 4），求前 K 个工程师天堂数之和。

## 数据范围

- 1 ≤ K ≤ 4

## 算法

利用实用数的判定定理（Stewart–Sierpiński）：设 m = 2^a · ∏ p_i^{e_i}（p_i 为奇素数且递增），令 s = 2^{a+1}-1，若对所有 i 有 p_i ≤ s+1 且按序更新 s ← s·(p_i^{e_i+1}-1)/(p_i-1)，则 m 为实用数。

对素数进行线性筛，枚举满足四素数 p-6, p, p+6, p+12 全部为素数且各自之间无中间素数的候选 p，令 n = p+3，验证五个实用数条件。时间复杂度约为 O(B log log B)，其中 B 为搜索上界（~3×10⁹）。

## 改编方向与取舍

### 改编方向
1. **参数化 K** → 求前 K 个天堂数之和（本题采用），K≤4
2. **参数化上界** → 求所有 ≤ N 的天堂数
3. **放宽条件** → 不要求素数对连续，仅要求素性
4. **推广到 M 元组** → 求 M 重性感素数对 + 实用数的组合

### 取舍理由
- 选择参数化 K：原题已固定 K=4，参数化 K 后适合 OJ 评测
- 不选参数化上界：天堂数密度极低，N 的合理范围难以界定
- 保留连续素数条件：这是原题的核心约束，放宽后结果完全不同
- K 限制在 4：第五个天堂数 > 10¹⁰，超出可行搜索范围
