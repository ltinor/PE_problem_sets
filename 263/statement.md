# 工程师的天堂数

## 题目描述

如果正整数 $m$ 满足：从 $1$ 到 $m$ 的每一个整数都可以写成 $m$ 的不同真约数之和，则称 $m$ 为**实用数**（practical number）。例如 $6$ 是实用数，因为 $1=1$, $2=2$, $3=1+2$, $4=1+3$, $5=2+3$, $6=6$。

如果两个连续素数的差为 $6$，则称它们为一对**性感素数**（sexy primes）。例如 $(23, 29)$。

我们称正整数 $n$ 为**工程师的天堂数**，若以下条件同时成立：

1. $(n-9, n-3)$、$(n-3, n+3)$、$(n+3, n+9)$ 是三组**连续**性感素数对（即每组中的两个素数之间没有其他素数）；
2. $n-8$、$n-4$、$n$、$n+4$、$n+8$ 全部是实用数。

给定 $K$，求前 $K$ 个工程师的天堂数之和。

---

## 输入格式

一行，一个整数 $K$。

---

## 输出格式

一行，一个整数，表示前 $K$ 个工程师的天堂数之和。

---

## 样例

### 输入
```
1
```

### 输出
```
254346790
```

### 输入
```
2
```

### 输出
```
1219921790
```

---

## 数据范围

- $1 \le K \le 4$
