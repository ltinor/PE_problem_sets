# Totient Chains

来源：改编自 Project Euler Problem 214

## 原题意

φ 为欧拉函数。迭代 φ 生成递减链直到 1。求所有小于 40,000,000 的素数中，φ 链长度为 25 的素数之和。

## 题目

给定 N（1 ≤ N ≤ 10⁷）和 L（1 ≤ L ≤ 30），求所有小于 N 的素数中，其 φ 链长度为 L 的素数之和。

## 数据范围

- 1 ≤ N ≤ 10⁷
- 1 ≤ L ≤ 30
- PE 答案: N = 40,000,000, L = 25 → 1677366278943

## 算法

欧拉筛预处理 φ(n)，DP 计算链长度：chain[1]=1, chain[n]=1+chain[φ(n)]。最后筛素数，累加满足条件的。

## 改编方向

1. **参数化 N, L**（采用）：将固定 40M/25 改为可变
2. **参数化起点类型**（未采用）：不只素数，任意数范畴更广但偏离原题
3. **参数化函数**（未采用）：改为 σ 链等，本质不同题
