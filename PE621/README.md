# PE621 — 三角形数和 (Expressing an integer as the sum of triangular numbers)

来源：改编自 Project Euler Problem 621

## 原题意

三角形数：t_k = k(k+1)/2（k ≥ 0）。

高斯证明了任意正整数可以表示为三个三角形数之和（包括 t_0 = 0）。

G(n) = 将 n 表示为三个三角形数之和的方式数，不同的排列视为不同的方式。

求 G(17526 × 10⁹)。

PE 答案：11429712。

## 算法

核心变换：n = t_a + t_b + t_c ⇔ 8n + 3 = (2a+1)² + (2b+1)² + (2c+1)²。

因此 G(n) = r₃(8n+3) / 8，其中 r₃(N) 是将 N 表示为三个整数平方和的方式数（考虑符号和顺序）。

对于 N ≡ 3 (mod 8)，所有平方和表示中三个分量必然均为奇数，故上述关系精确成立。

r₃(N) 通过虚二次域的类数（class number）计算。具体公式涉及 Hurwitz 类数 H(4N) 或通过除数和与 Kronecker 符号的 Dirichlet 卷积得到。

由于 n = 17526 × 10⁹ 的数值非常大，实际实现需要高效的除数和计算（可在 O(√N) 内完成）。

## 改编方向

1. 增加模数限制：求 G(n) mod M。
2. 推广到更多个三角形数（如 4 个、5 个）。
3. 求 G(n) 在不同 n 下的分布。
4. 研究限制三角形数非零时的计数。
