# 电容电路

## 题目描述

使用 n 个相同电容值的电容器，通过串联和并联的组合，可以构造出各种不同的总电容值。

构造规则：
- 单个电容的总电容为其自身值（归一化为 1）。
- 将 k 个电容构成的电路（总电容 C₁）与 n−k 个电容构成的电路（总电容 C₂）串联：总电容 C = 1/(1/C₁ + 1/C₂)。
- 将上述两个子电路并联：总电容 C = C₁ + C₂。

定义 D(n) 为使用不超过 n 个电容能获得的不同总电容值的数量。

例如：D(1)=1, D(2)=3, D(3)=7。

给定 N，求 D(N)。

---

## 输入格式

一行一个整数 N (1 ≤ N ≤ 18)。

---

## 输出格式

一行一个整数，表示 D(N)。

---

## 样例

### 输入 1

```
3
```

### 输出 1

```
7
```

### 输入 2

```
18
```

### 输出 2

```
3857447
```

---

## 数据范围

- 1 ≤ N ≤ 18
