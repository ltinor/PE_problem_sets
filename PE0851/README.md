# PE851 — SOP and POS（除数对的积与和）

来源：改编自 Project Euler Problem 851

## 原题意

对于整数 $n > 1$，记 $D(n)$ 为 $n$ 的所有正因子集合（包含 $1$ 和 $n$）。定义：

- $\\text{SOP}(n) = \\sum_{a, b \\in D(n), a < b} a \\times b$ —— 所有无序因子对的乘积之和
- $\\text{POS}(n) = \\prod_{a, b \\in D(n), a < b} (a + b)$ —— 所有无序因子对的和的乘积

利用 $\\sigma_1(n) = \\sum_{d \\mid n} d$（因数和）和 $\\sigma_2(n) = \\sum_{d \\mid n} d^2$（因子平方和），可以直接计算：
$$\\text{SOP}(n) = \\frac{\\sigma_1(n)^2 - \\sigma_2(n)}{2}$$

PE 答案：169796973644。

## 算法

1. **$\\sigma_1(n)$ 和 $\\sigma_2(n)$**：通过 $O(\\sqrt{n})$ 时间遍历因子计算。
2. **SOP 公式**：$\\text{SOP}(n) = (\\sigma_1^2 - \\sigma_2)/2$，无需枚举所有因子对。
3. **POS 取模**：由于 POS 增长极快（超指数），实际计算需要对大质数取模。
4. **累积求和**：计算 $\\sum_{n=2}^{N} \\text{SOP}(n)$ 时需使用数论分块或线筛预处理因子。
