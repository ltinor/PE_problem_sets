# 除数对的积与和（SOP and POS）

## 题目描述

对于正整数 $n > 1$，设 $D(n) = \\{d_1, d_2, \\ldots, d_k\\}$ 为 $n$ 的所有正因子（包括 $1$ 和 $n$）。定义：

$$\\text{SOP}(n) = \\sum_{1 \\leq i < j \\leq k} d_i \\cdot d_j$$

$$\\text{POS}(n) = \\prod_{1 \\leq i < j \\leq k} (d_i + d_j)$$

记 $\\sigma_1(n)$ 为 $n$ 的因子和，$\\sigma_2(n)$ 为 $n$ 的因子平方和。容易证明：

$$\\text{SOP}(n) = \\frac{\\sigma_1(n)^2 - \\sigma_2(n)}{2}$$

该公式可以高效计算 SOP 而不需要枚举所有 $O(k^2)$ 对因子。

你的任务是对于给定的 $N$，计算：

$$S(N) = \\sum_{n=2}^{N} \\text{SOP}(n)$$

## 输入格式

无输入（固定参数问题）。

## 输出格式

输出一个整数，表示 $S(N)$ 的值。

## 样例

（无样例输入输出，直接计算并输出最终答案。）

相关参数在 PE 原题中定义。
