# 幸运三角形（PE 919）

来源：改编自 Project Euler Problem 919。

## 原题意

整数三角形至少一个顶点满足到垂心距离 = 到外心距离的一半 (|cos|=1/4), S(P) 为周长 ≤P 的边长和。

## 题目

见 statement.md。参数与输入输出约定以 code/std.cpp 为准。

## 算法

参数化分支: 暴力枚举 a≤b, 三顶点角色判定 2|邻边²和−对边²| = 邻边积 (含钝角 ± 分支)。

## 验证

S(10)=24, S(100)=3331 (题面); PE 分支 S(10^7)=134222859969633 (官方, 全规模需二次曲面参数化, 未实现)
