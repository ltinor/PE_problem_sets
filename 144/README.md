# 激光反射 (Laser Reflections)

来源：改编自 Project Euler Problem 144

## 原题意

椭圆 4x²+y²=100，顶部有缺口 (-0.01≤x≤0.01)。激光从 (0,10.1) 射出，第一次击中 (1.4,-9.6)。求激光离开前在椭圆内表面反射的次数。

原题答案：354

## 题目

固定答案题。输出反射次数。

## 数据范围

- 固定输出（无参数输入）

## 算法

模拟光线追踪：
1. 入射点 (x,y) 处切线斜率 m = -4x/y
2. 法向量 n = (4x, y)（垂直于切线）
3. 反射向量 v' = v - 2(v·n)/|n|² · n
4. 求 v' 与椭圆的交点：解二次方程 4(x+t·v'ₓ)²+(y+t·v'ᵧ)²=100
5. 一个根 t=0（当前点），另一个根 t=-B/A
6. 检查出口条件：|x|≤0.01 且 y>0
