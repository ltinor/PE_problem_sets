# 一束激光多次反射的研究

## 题目描述

椭圆方程为 4x² + y² = 100，顶部缺口 -0.01 ≤ x ≤ +0.01。

激光从 (0.0, 10.1) 发出，第一次击中镜面于 (1.4, -9.6)。每次击中遵循反射定律。

求激光离开椭圆前，在椭圆内表面上的击中次数。

---

## 输入格式

固定答案题，输入任意内容均可（实际读入一个整数作为占位）。

---

## 输出格式

一行一个整数，表示击中次数。

---

## 样例

### 输入

```
1
```

### 输出

```
354
```

---

## 数据范围

固定答案题（原题答案 354），无需数据范围。
