# PE504 - 内部格点

来源：改编自 Project Euler Problem 504

## 原题意

给定正整数 a,b,c,d，考虑四边形顶点 A(a,0), B(0,b), C(-c,0), D(0,-d)。统计严格位于四边形内部的格点 (x,y) 数量。对所有 1 ≤ a,b,c,d ≤ 100 求和。

PE 答案：694687。

## 题目

给定 N，对所有 1 ≤ a,b,c,d ≤ N 求和四边形内部格点数。

## 算法

- Pick 定理：面积 = I + B/2 - 1
- 面积 = (a+c)(b+d)/2
- 边界格点 B = gcd(a,b) + gcd(b,c) + gcd(c,d) + gcd(d,a)
- I = (面积·2 - B)/2 + 1 = (a+c)(b+d)/2 - (gcd(a,b) + ...)/2 + 1

## 改编方向

1. **不同范围**：改变 N
2. **不同形状**：改变四边形顶点规则
3. **边界格点**：统计边界而非内部格点
