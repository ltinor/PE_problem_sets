# 可截素数

## 题目描述

3797 有着奇特的性质。它本身是一个素数；如果从左往右逐一截去数字，剩下的仍然都是素数：3797、797、97 和 7；如果从右往左逐一截去数字，剩下的也仍然都是素数：3797、379、37 和 3。

如果一个素数满足，无论从左往右还是从右往左逐一截去数字，剩下的仍然都是素数，则称之为可截素数。已知总共有十一个可截素数（注意：2、3、5 和 7 不被视为可截素数），求这些数的和。

---

## 输入格式

一个整数（任意值，忽略）。

---

## 输出格式

一个整数，表示十一个可截素数的和。

---

## 样例

### 输入

```
1
```

### 输出

```
748317
```

---

## 数据范围

固定答案，无数据范围限制。
