# Totient Maximum

来源：改编自 Project Euler Problem 69

## 原题意

对于 n ≤ 1,000,000，求使 n/φ(n) 最大的 n。

答案：510510。

## 题目

给定 N，求 ≤ N 中使 n/φ(n) 最大的 n。多组输入（直到 EOF）。

## 数据范围

N ≤ 10⁶（1,000,000）。

## 算法

n/φ(n) = Π(p/(p-1))，其中 p 是 n 的不同质因子。要最大化这个比值，应取尽量多的不同小质数的乘积。

因此最优解是 ≤ N 的最大连续质数乘积：2×3×5×7×11×13×17×...。

std：O(1) 每组查询，预计算连续质数列表。
brute：O(N log log N) 筛法计算 φ(1..N)，遍历找最大比值。

## 改编说明

原题固定 N = 1,000,000。改编为参数化 N，支持多组输入，使题目更具通用性。std 利用连续质数乘积的数学性质实现 O(1) 查询。
