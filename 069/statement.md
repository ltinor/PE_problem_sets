# 欧拉总计函数与最大值

## 题目描述

欧拉总计函数 φ(n) 表示小于 n 且与 n 互质的正整数个数。例如，φ(9) = 6（1, 2, 4, 5, 7, 8）。

定义比值 r(n) = n / φ(n)。给定 N，求所有 ≤ N 的正整数中，使 r(n) 最大的 n。

---

## 输入格式

一行一个整数 $N$。

---

## 输出格式

一行一个整数，表示 $\le N$ 中使 $n/\varphi(n)$ 最大的 $n$。

---

## 样例

### 输入
```
10
```

### 输出
```
6
```

---

## 数据范围

- $N \\leq 1{,}000{,}000$
