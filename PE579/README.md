# PE579 - 网格 (Grid)

来源：改编自 Project Euler Problem 579

## 原题意

考虑满足 0 ≤ a ≤ b ≤ c ≤ n 且 a² + b² + c² = d²（d 为整数）的整数三元组 (a, b, c)。统计这些毕达哥拉斯四元组的数量 S(n)。

已知（暴力枚举）：
S(1)=2, S(5)=9, S(10)=23, S(50)=308。

PE 答案：380552632087080。

## 算法

问题等价于在三维空间中统计以原点为一端、另一端在正方体内的空间对角线长度为整数的长方体个数。对于小规模 n，可使用三重循环暴力枚举。对于大规模，需利用毕达哥拉斯四元组的参数化生成（如勒贝格参数化）和容斥原理。

## 改编方向

1. 优化到 O(n²) 或 O(n log n) 的计数算法
2. 推广到更高维度（五元组、六元组）
3. 统计 a, b, c 互质的本原四元组数量
