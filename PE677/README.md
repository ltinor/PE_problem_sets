# PE677 — 图染色 (Coloured Graphs)

来源：改编自 Project Euler Problem 677

## 原题意

记 $g(n)$ 为具有 $n$ 个结点并满足以下性质的无向图总数：

- 该图是连通图、无环、无重边（即树）
- 每个结点被染上红色、蓝色或黄色之一
- 每个红色结点至多与 4 条边相连
- 每个蓝色或黄色结点至多与 3 条边相连
- 黄色结点之间不能直接相连

已知：$g(2)=5$，$g(3)=15$，$g(4)=57$，$g(10)=710249$，$g(100) \equiv 919747298 \pmod{10^9+7}$。

求 $g(10000) \bmod 10^9+7$。

PE 答案：984183023。

## 算法

1. **图的计数方法**：
   - 计数对象是**无标号**（unlabeled）的着色树
   - 使用 Pólya 计数理论处理对称性

2. **生成函数方法**：
   - 构建带约束的有根树的指数型生成函数
   - 红色结点度数限制 ≤4，蓝/黄结点度数限制 ≤3
   - 黄色结点之间无边：在生成函数中排除 Y-Y 连接
   - 使用 Otter 公式将有根树计数转换为无根树计数

3. **实现要点**：
   - 对较小的 $n$（≤10），可以枚举所有无标号树并计数着色方案
   - 对大 $n$，使用生成函数的级数展开和递推计算
   - 模运算：所有计算对 $10^9+7$ 取模

4. **复杂度**：
   - 需要计算到 $n=10000$ 的生成函数系数
   - 可以使用 $O(n^2)$ 或 $O(n \log n)$ 的递推

## 改编方向

1. 增加更多颜色种类
2. 修改度数限制参数
3. 允许黄-黄边并添加新的约束条件
4. 计数有根树而非无根树
5. 考虑带标号的图计数（Cayley 公式变体）
