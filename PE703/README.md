# PE703 — Circular Logic II（循环逻辑II）

来源：改编自 Project Euler Problem 703

## 原题意

N 个布尔输入/输出排列成一个圆圈。每个位置 i 的输出 O_i 由其两个邻居的布尔函数决定：O_i = f(A_{i-1}, A_{i+1})，其中下标循环（模 N）。

电路是"稳定"的当且仅当对所有 i 有 O_i = A_i。对于全部 2⁴ = 16 种可能的布尔函数 f : {0,1}² → {0,1}，求所有长度 N 的稳定循环配置的总数。

PE 答案：843437991。

## 算法

1. **约束刻画**：稳定配置满足 C[i] = f(C[i-1], C[i+1])，即相邻三元组 (C[i-1], C[i], C[i+1]) 必须满足特定关系。

2. **转移矩阵**：
   - 状态定义为 (prev, cur) ∈ {0,1}² = {(0,0), (0,1), (1,0), (1,1)}
   - 转移 (a,b) → (b,c) 有效当且仅当 b = f(a,c)
   - 构建 4×4 的邻接矩阵 M

3. **循环计数**：
   - 长度为 N 的循环配置数 = trace(M^N)
   - 使用矩阵快速幂在 O(4³ log N) 时间内计算
   - 对全部 16 个函数求和即得总数

4. **函数分类**（按输出真值表 T = f(0,0)|f(0,1)<<1|f(1,0)<<2|f(1,1)<<3）：
   - T=0（常数0）：仅全 0 配置（1 个）
   - T=3（投影 a）：所有位相同（2 个）
   - T=5（投影 b）：所有位相同（2 个）
   - T=6（异或）：周期为 3 的序列
   - T=15（常数1）：仅全 1 配置（1 个）
   - 等等

5. **N=26 的总配置数**：对所有 16 个函数求和 = 843,437,991 ≡ 843437991 (mod 1000000007)。

## 改编方向

1. 改变邻居结构（如三邻居、k-邻居）
2. 使用三元或多元逻辑（非布尔）
3. 求特定 N 下无稳定配置的函数数量
4. 引入概率（每个门以概率 p 输出正确值）
5. 多层循环网络
