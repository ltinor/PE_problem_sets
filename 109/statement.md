# 飞镖

## 题目描述

在飞镖游戏中，玩家采用"双倍结束"规则：最后一镖必须射中双倍区域（D1-D20 或 D25/靶心内圈）才能获胜。

飞镖的得分区域：
- **单倍区**（S）：S1-S20 分别得 1-20 分；外靶心得 25 分（S25）
- **双倍区**（D）：D1-D20 分别得 2,4,...,40 分；内靶心得 50 分（D25）
- **三倍区**（T）：T1-T20 分别得 3,6,...,60 分

一轮最多投掷 3 镖（脱靶不计数）。求所有分数**严格小于** $S$ 的结分方式总数。

---

## 输入格式

一行一个整数 $S$。

---

## 输出格式

一行一个整数，表示结分方式总数。

---

## 样例

### 输入
```
7
```

### 输出
```
11
```

**解释**：分数 6 有 11 种结分方式，分数 < 7 即只统计分数为 2~6 的结分方式。分数 2 有 1 种（D1），分数 4 有 2 种（D2、D1 D1），等等。总计 11。

### 输入
```
100
```

### 输出
```
38182
```

---

## 数据范围

- $3 \\le S \\le 171$
- 最高可结分分数为 170（T20 T20 D25）
