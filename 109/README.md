# 109 — Darts

来源：改编自 Project Euler Problem 109

## 原题意

飞镖游戏"双倍结束"规则下，最后一镖必须是双倍区。求分数小于 100 的所有结分方式总数。

原题答案：38182（分数 < 100）、42336（所有分数）。

## 题目

输入整数 $S$，求分数严格小于 $S$ 的所有结分方式总数。

## 数据范围

- $3 \\le S \\le 171$（最高结分为 170）

## 算法

枚举所有可能的 1/2/3 镖结分组合：

- **飞镖分值**：S1-S20（1-20）、D1-D20（2-40）、T1-T20（3-60）、S25（25）、D25（50）
- **非结分镖**：以上所有类型（62 种）
- **结分镖（最后一镖）**：必须是双倍 D1-D20 或 D25（21 种）

三种结分方式：
1. 1 镖：直接双倍命中目标分数
2. 2 镖：一镖非结分 + 一镖双倍
3. 3 镖：两镖非结分（不计顺序）+ 一镖双倍

预计算所有分数（2~170）的结分方式数，对分数 < S 求和。

时间复杂度 $O(62^2 \\times 21) \\approx O(8 \\times 10^4)$，常数极小。

## 改编方向与取舍

### 改编方向
1. **参数化 $S$** → 求分数 < S 的结分方式总数（本题采用）
2. **求特定分数的结分方式** → 输入单个分数，输出该分数的结分方式数
3. **扩展规则** → 支持不同的飞镖游戏规则变体（如 301/501 起始分）
4. **输出所有组合** → 对每个分数列出所有结分方式

### 取舍理由
- 选择参数化 $S$：最自然，保留原题枚举核心
- $S \\le 171$：最高结分为 170，$S=171$ 即统计所有结分方式（42336）
- 枚举量极小，std 和 brute 实现相同即可
