# PE911 — Khinchin's Constant（辛钦常数）

来源：改编自 Project Euler Problem 911

## 原题意

对任意实数 \(x\)，定义其连分数展开 \([a_0; a_1, a_2, \dots]\)，其中 \(a_0 = \lfloor x \rfloor\)，其余为正整数。对于几乎所有的实数 \(x\)，其连分数系数的几何均值收敛于辛钦常数：

\[
K_0 = \prod_{r=1}^{\infty} \left(1 + \frac{1}{r(r+2)}\right)^{\log_2 r} \approx 2.685452\ldots
\]

本题对随机选择的正整数对 \((a, b)\) 定义分布 \(Q\)，并计算该分布下连分数系数的某种加权几何均值。具体定义为：

设 \(s_k\) 为连分数系数 \(a_m\) 首次达到至少 \(k\) 的最小下标 \(m\)。对足够大的 \(N\)，考察所有 \(1 \le a, b \le N\) 的连分数，计算加权和的极限。

求该极限值，四舍五入至小数点后 6 位。

PE 答案：**21.303979**。

## 算法

本题是极难的分析数论题，涉及：
1. 连分数展开中系数的概率分布
2. Gauss-Kuzmin 分布的变种
3. 辛钦常数的推广形式
4. 需要高精度浮点运算和对无穷乘积/和的数值估计

## 改编方向

1. 改变分布（如不同的随机变量选取方式）
2. 修改截断条件
3. 改为求连分数系数的其他统计量
