# 943 自描述数列（简单版本）

来源：改编自 Project Euler Problem 943 (Self Describing Sequences)

## 原题意

由 a、b 交替的连续段组成数列，首元素为 a，且「段长序列」等于原数列本身。
T(a,b,N)=前 N 项之和。原题对 2≤a,b≤223, a≠b 求 ΣT(a,b,22332223332233)。

## 题目（简单版本）

输入三个整数 a、b、N，输出 T(a,b,N)。

## 数据范围

- 简单版本：2 ≤ a,b ≤ 223（a≠b），N ≤ 10^6。

## 算法

按定义逐段生成：seq[0..a-1]=a，第 j 段长度为 seq[j]、符号「j 偶?a:b」，逐段追加至 ≥N，
累加前 N 项。O(N)。

验证：T(2,3,10)=25，T(4,2,10^4)=30004，T(5,8,10^6)=6499871。
