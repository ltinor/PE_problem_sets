# 数字平方和为平方数

## 题目描述

对于正整数 n，记 f(n) 为 n 在十进制表示下各位数字的平方和。

例如：
- f(3) = 3² = 9
- f(25) = 2² + 5² = 4 + 25 = 29
- f(442) = 4² + 4² + 2² = 16 + 16 + 4 = 36

求所有满足 0 < n < 10^D 且 f(n) 为完全平方数的 n 的和，输出最后九位数字。

## 输入格式

一行一个整数 D（1 ≤ D ≤ 20），表示数字位数的上限。

## 输出格式

一行一个整数，表示和的最后九位数字。

---

## 样例

### 输入
```
1
```

### 输出
```
45
```

### 输入
```
2
```

### 输出
```
726
```

### 输入
```
3
```

### 输出
```
28083
```

---

## 数据范围

- 1 ≤ D ≤ 20

---

## 提示

PE 原题 D=20 时答案为 142989277。

使用 DP 动态规划：dp[sum] 统计方案数和数字和。最大数字平方和 ≤ 9² × 20 = 1620。枚举所有完全平方数 s² ≤ 1620，DP 计算数字平方和为 s² 的所有 n 的贡献。时间复杂度 O(D × 1620)。
