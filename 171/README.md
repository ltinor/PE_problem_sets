# 171 — 数字平方和为平方数

来源：改编自 Project Euler Problem 171

## 原题意

求所有 n < 10^20 且各位数字平方和为完全平方数的 n 之和的最后九位数字。原题答案：142989277。

## 题目

参数化 D：输入 D（≤ 20），求 n < 10^D 满足条件的和的最后九位数字。

## 数据范围

- D ≤ 20

## 算法

**std**: 动态规划。最大数字平方和 = 9² × D ≤ 1620。对每个完全平方数 s² ≤ 1620，DP 计算数字平方和为 s² 的所有 n 的贡献。DP[pos][sum] 同时记录方案数和数字总和。最后对每个目标平方数，枚举第一个非零数字和剩余数字平方和，累加贡献。时间复杂度 O(D × 1620)。

**brute**: 枚举所有 n < 10^D，验证数字平方和是否为完全平方数。用于小 D（≤ 6）验证。

## 改编方向

1. **参数化 D**：将固定 D=20 改为任意输入。
2. **DP 方法**：同时维护计数和数字和。
3. **PE 答案验证**：(D=20) 输出 142989277。
