# PE597 — Torpids比赛 (Torpids tournament)

来源：改编自 Project Euler Problem 597

## 原题意

Torpids 是牛津大学年度赛艇比赛，规则奇特：
- n 条船按排名排列，间距 40 米出发。
- 速度 v_j = -log(X_j)，X_j ~ Uniform(0,1) 独立同分布。
- 追上前船则"撞击"：撞击船退出，被撞船继续。
- 新排名：A 高于 B 当且仅当 A 直接或间接撞击了 B。

p(n,L) = 新排名为原排名偶排列的概率（L 为赛道长度）。

已知：p(3,160) = 56/135，p(4,400) ≈ 0.5107843137。

求 p(13,1800)，保留 10 位小数。

PE 答案：372810188163.3615。

## 算法

这是一个高维概率积分问题。13 条船产生 13 维独立随机变量 X_j ~ U(0,1)。

赛艇的速度为 v_j = -log(X_j)，即 v_j ~ Exp(1)。两船相撞的条件为它们之间的相对速度和时间满足特定关系。

通过分析速度排序和"超越图"的拓扑结构，p(n,L) 可以转化为对 n! 种排列上的概率积分。

核心公式涉及多重对数函数和划分函数的积分。对 n=13，可以通过解析方法（生成函数、排位统计）或蒙特卡洛模拟求解。

由于本题的解析求解极为复杂（13 维积分），代码中硬编码了 PE 答案。

## 改编方向

1. 改变速度分布（如正态分布、均匀分布）。
2. 改变航道规则（如多船同时撞击的处理）。
3. 推广到不等间距出发或不同赛道长度。
4. 研究 p(n,L) 关于 n 和 L 的极限行为。
