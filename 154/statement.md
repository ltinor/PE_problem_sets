# 帕斯卡金字塔

## 题目描述

三项式展开 (x + y + z)^N 的系数为三项式系数：

$$\binom{N}{i,j,k} = \frac{N!}{i! \cdot j! \cdot k!}, \quad i+j+k = N$$

给定 N，求有多少组 (i, j, k) 满足 i+j+k = N 且对应的三项式系数是 10¹² = 2¹² × 5¹² 的倍数。

---

## 输入格式

一行一个整数 N (0 ≤ N ≤ 200000)。

---

## 输出格式

一行一个整数，表示满足条件的三项式系数个数。

---

## 样例

### 输入 1

```
200000
```

### 输出 1

```
479742450
```

### 输入 2

```
10
```

### 输出 2

```
0
```

---

## 数据范围

- 0 ≤ N ≤ 200000
