# 154 — 帕斯卡金字塔

来源：改编自 Project Euler Problem 154

## 原题意

求 (x+y+z)^200000 展开式中，是 10¹² 倍数的系数个数。

原题答案：479742450。

## 题目

参数化 N（≤ 200000），求 (x+y+z)^N 中系数为 10¹² 倍数的个数。

## 数据范围

- N ≤ 200000

## 算法

**std**: 使用勒让德公式计算阶乘中质因子 2 和 5 的指数。
1. 三项式系数 = N! / (i! × j! × k!)。
2. 系数中 v₂ = v₂(N!) − v₂(i!) − v₂(j!) − v₂(k!)。
3. 系数中 v₅ = v₅(N!) − v₅(i!) − v₅(j!) − v₅(k!)。
4. 当 v₂ ≥ 12 且 v₅ ≥ 12 时，系数是 10¹² 的倍数。
5. 预计算 v₂[n!] 和 v₅[n!] 数组，然后 O(N²) 枚举 (i, j)。

**brute**: 相同的算法（该问题 std 和 brute 算法相同，brute 限制 N ≤ 500）。

## 改编方向

1. **参数化 N**：将固定 N=200000 改为输入参数。
2. **勒让德公式**：使用 v_p(n!) = Σ⌊n/pᵏ⌋ 预计算质因子指数。
3. **PE 答案验证**：N=200000 时输出 479742450。
