# 等比三角形

来源：改编自 Project Euler Problem 370

## 原题意

整数边三角形 a≤b≤c 满足 b²=a·c（等比数列），求周长 ≤ 2.5×10^13 的三角形个数。PE 答案：41791929448408。

## 题目

给定周长上限 P，求等比三角形个数。

## 数据范围

P ≤ 10^12

## 算法

### 方向一：参数化约分

设 a=x²·z, b=x·y·z, c=y²·z，其中 gcd(x,y)=1。三角形不等式 a+b>c 即 x²+xy>y²。周长 = z(x²+xy+y²) ≤ P。枚举互质的 (x,y) 对，计算 z 的上限。

### 方向二：Stern-Brocot 树 / Farey 序列

条件 x²+xy-y²>0 给出 x/y 的范围。用 Farey 序列枚举互质对 (x,y)，累加 floor(P/(x²+xy+y²))。

### 方向三：数论分块

固定 x，y 的范围受三角形不等式约束。按 x 分块处理，每块内直接计算贡献。

### 时间复杂度

O(P^{1/3}) 或 O(P^{1/2})。
