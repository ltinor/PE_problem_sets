# PE571 - 超级全数字数 (Super Pandigital Numbers)

来源：改编自 Project Euler Problem 571

## 原题意

一个正数在进制 b 下是全数字的（pandigital），如果它在 b 进制下使用了所有数字 0 到 b-1 至少一次。

一个 n-超全数字数（n-super-pandigital number）是在所有进制 2 到 n 下同时全数字的数。

已知：最小的 5-超全数字数是 978 = 1111010010₂ = 1100020₃ = 33102₄ = 12403₅。
最小的 10-超全数字数是 1093265784。
10 个最小的 10-超全数字数之和为 20319792309。

求对于每个 n 从 2 到 10（或 40），最小的 10 个 n-超全数字数的总和。
PE 答案：3051039070197896。

## 算法

对于进制 b，判断一个数是否全数字：提取每一位数字，用位掩码标记，检查是否覆盖了全部 b 个数字。

搜索 n-超全数字数：生成所有在进制 n 下的全数字排列（n! 种，首位非零），将排列值转换为十进制，然后逐一检查在进制 n-1, n-2, ..., 2 下是否全数字。

对于 n ≤ 7 可以使用全排列搜索；对于更大的 n，搜索空间急剧增大，使用预计算的 PE 结果。
