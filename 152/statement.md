# 平方倒数和

## 题目描述

给定整数 N，考虑集合 {2, 3, 4, ..., N}。求有多少个不同的子集，使得子集中所有元素的平方倒数之和恰好为 1/2。

即求满足以下条件的子集 S ⊆ {2, 3, ..., N} 的数量：

$$\sum_{k \in S} \frac{1}{k^2} = \frac{1}{2}$$

---

## 输入格式

一行一个整数 N (2 ≤ N ≤ 80)。

---

## 输出格式

一行一个整数，表示满足条件的子集数量。

---

## 样例

### 输入 1

```
80
```

### 输出 1

```
301
```

### 输入 2

```
10
```

### 输出 2

```
0
```

---

## 数据范围

- 2 ≤ N ≤ 80
