# 各位数字和

## 题目描述

对于正整数 $k$，记 $d(k)$ 为 $k$ 的十进制表示下各位数字之和。例如 $d(42) = 4+2 = 6$。

对于正整数 $n$，定义 $S(n)$ 为满足以下两个条件的正整数 $k$ 的个数：

- $k < 10^n$
- $k$ 能被 $23$ 整除
- $d(k) = 23$

现在给定正整数 $n$，请计算 $S(n)$。

---

## 输入格式

一行一个正整数 $n$。

---

## 输出格式

一行一个整数，表示 $S(n)$。

---

## 样例

### 输入

```
9
```

### 输出

```
263626
```

---

## 数据范围

- $1 \le n \le 20$
