# PE660 — 全数字三角形 (Pandigital Triangles)

来源：改编自 Project Euler Problem 660

## 原题意

整数边三角形含有一个 120° 角。由余弦定理：c² = a² + b² + ab（c 为 120° 角的对边，即最长边）。

n-全数字三角形：a, b, c 在 n 进制下的所有数字恰好覆盖 0..n−1 各一次。

已知 (217, 248, 403) 是 9-全数字三角形。

对 9 ≤ n ≤ 18，求所有 n-全数字三角形最长边 c 的和。

PE 答案：400107221768。

## 算法

### 120° 三角形参数化
原始解（本原解）满足：
a = m² − n²,  b = 2mn + n²,  c = m² + mn + n²
其中 m > n > 0，gcd(m,n)=1。非本原解可乘以缩放因子 t。

a, b 可互换。

### 搜索策略
对每个 n (9-18)，生成本原三角形直到 c 超过合理的上界（c ≈ n⁸ 通常足够覆盖 pandigital 条件）。然后对每个三角形检查：
1. 120° 条件：c² = a² + b² + ab
2. n-全数字条件：a, b, c 在 n 进制下数字合起来使用全部 n 个数字

由于 n ≤ 18 且 pandigital 约束极强，实际解的数量很少（每 n 通常 ≤ 2 个）。

## 改编方向

1. 推广到 60° 三角形（c² = a² + b² − ab）
2. 要求三边本身的数字集合完全不同
3. 扩大到更大的 n
4. 考虑边长有额外约束（如均为素数）
