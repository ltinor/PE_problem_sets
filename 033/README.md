# 消去数字的分数 (Digit Cancelling Fractions)

来源：改编自 Project Euler Problem 33

## 原题意

找出所有非平凡"消去数字"分数：分子和分母均为两位数、值小于 1，消去分子和分母中共有的一个数字后分数值不变。共有恰好 4 个这样的分数：

- 16/64 = 1/4
- 19/95 = 1/5
- 26/65 = 2/5
- 49/98 = 4/8 = 1/2

求这 4 个分数的乘积化为最简分数后的分母。

原题答案：100。

## 改编方向

此题答案固定（分母=100）。改编为验证型题目：输入任意值，程序穷举所有满足条件的分数，计算乘积的最简分母并输出。保留原题风味作为验证题。

## 题目

在所有分子和分母均为两位数、值小于 1 的分数中，找出所有满足以下"非平凡消去数字"条件的分数：

- 分子和分母的十进制表示中有一个共同的数字
- 消去这个共同数字后，剩余数字组成的分数值与原分数相等
- 平凡情况（如 30/50 = 3/5）不计入

求所有满足条件的分数的乘积化为最简分数后的分母。

## 数据范围

答案固定为 100。输入参数 T（1 ≤ T ≤ 100）仅用于兼容多测试用例格式，不影响结果。

## 算法

std：枚举分子 11~98，分母 > 分子，检查四种消去情况（十位-十位、十位-个位、个位-十位、个位-个位），排除平凡情况（末位均为 0），用浮点比较验证分数值相等。

brute：独立实现，使用十字相乘（整数比较）而非浮点比较来验证分数值相等。

## 验证

- 共有恰好 4 个非平凡解：16/64, 19/95, 26/65, 49/98
- 乘积最简分母 = 100 ✓
- 10 组随机数据对拍（std vs brute）：全部 AC
- 10 组正式数据对拍（std vs brute）：全部 AC
