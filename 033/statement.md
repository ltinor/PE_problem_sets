# 消去数字的分数

## 题目描述

分数 $49/98$ 是一个有趣的分数：如果错误地在分子和分母中同时"消去"数字 $9$，会得到 $4/8$，而巧合的是 $49/98 = 4/8 = 1/2$。

像 $30/50 = 3/5$ 这样分子和分母末尾都是 $0$ 的情况被视为**平凡解**。

在所有分子和分母均为两位数、值小于 $1$ 的分数中，找出所有满足以下条件的**非平凡**分数：

- 分子和分母的十进制表示中有一个共同的数字（不为 $0$）
- 消去这个共同数字后，剩余数字按原顺序组成的分数值与原分数相等

可以证明，恰好存在 $4$ 个这样的非平凡分数。

将这 $4$ 个分数相乘，并将结果化为最简分数。求此时的分母。

---

## 输入格式

第一行一个整数 $T$（$1 \leq T \leq 100$），表示测试用例数量。本题中 $T$ 的值不影响结果（答案恒为 $100$）。

---

## 输出格式

一行一个整数 $100$，表示这 $4$ 个分数的乘积化为最简分数后的分母。

---

## 样例

### 输入

```
1
```

### 输出

```
100
```

---

## 数据范围

- $1 \leq T \leq 100$

## 提示

四个非平凡解为：$16/64$、$19/95$、$26/65$、$49/98$。
