# 立方取模 I

## 题目描述

对于正整数 n，定义 S(n) 为所有满足以下条件的整数 x 的和：
- 1 < x < n
- x³ ≡ 1 (mod n)

例如，n = 91 时，满足条件的 x 有 8 个：9, 16, 22, 29, 53, 74, 79, 81，S(91) = 363。

---

## 输入格式

一行一个正整数 n (n ≥ 2)。

---

## 输出格式

一行一个整数，表示 S(n)。

---

## 样例

### 输入

```
91
```

### 输出

```
363
```

---

## 数据范围

- 2 ≤ n ≤ 10^10（原题参数范围）
