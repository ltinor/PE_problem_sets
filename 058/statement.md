# 螺旋素数

## 题目描述

从 1 开始按照逆时针方向摆放自然数，可以构造出如下边长为 7 的螺旋数阵。其中红色数字位于两条对角线上。

在对角线的 13 个数字中有 8 个素数（比例 ≈ 62%）。不断在外面添加新的层，对角线上素数比例不断降低。

给定目标百分比 P，求对角线上素数的比例第一次低于 P% 时，螺旋方阵的边长。

---

## 输入格式

多组测试数据。每组数据一行，包含一个整数 P（1 ≤ P ≤ 50）。

---

## 输出格式

对于每组数据，输出一行一个奇数，表示满足条件的螺旋方阵边长。

---

## 样例

### 输入

```
10
```

### 输出

```
26241
```

---

## 数据范围

- 1 ≤ P ≤ 50
- 测试数据组数不超过 10 组
