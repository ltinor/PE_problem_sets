# 螺旋素数 (Spiral Primes)

来源：改编自 Project Euler Problem 58

## 原题意

对角线上素数比例首次低于 10% 的螺旋方阵边长。答案：26241。

## 改编方向

参数化目标比例 P（1≤P≤50）。输入 P，求对角线素数比例 < P% 的最小奇数边长。

## 题目

从 1 开始逆时针螺旋排列，边长为 s（奇数）时对角线有 2s-1 个数。每增加一层，新增 4 个角上的数。求对角线上素数比例第一次低于 P% 的边长 s。

## 数据范围

- P: 1 ≤ P ≤ 50

## 算法

std: 公式生成对角线数 + O(√n) 判素 + 累计。逐层迭代直到比例 < P%。

brute: 相同算法独立实现。
