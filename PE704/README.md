# PE704 — Factors of Two in Binomial Coefficients（二项式系数中2的因子）

来源：改编自 Project Euler Problem 704

## 原题意

设 v₂(x) 为整数 x 的质因数分解中 2 的指数（2-adic valuation）。定义：
- F(n) = Σ_{k=0}^{n} v₂(C(n, k))
- G(N) = Σ_{n=1}^{N} F(n)

计算 G(N) 对于某个特定的 N（如 N = 10⁷）。

PE 答案：501985601188027。

## 算法

1. **核心恒等式**（由 Legendre 公式推导）：
   ```
   v₂(C(n,k)) = s₂(k) + s₂(n-k) - s₂(n)
   ```
   其中 s₂(x) 是 x 的二进制表示中 1 的个数。

2. **F(n) 的化简**：
   ```
   F(n) = Σ_{k=0}^{n} [s₂(k) + s₂(n-k) - s₂(n)]
        = 2 × Σ_{k=0}^{n} s₂(k) - (n+1) × s₂(n)
   ```

3. **S(n) = Σ_{k=0}^{n} s₂(k) 的快速计算**：
   ```
   S(n) = Σ_{j≥0} (⌊(n+1)/2^{j+1}⌋ × 2^j + max(0, (n+1) mod 2^{j+1} - 2^j))
   ```
   在 O(log n) 时间内计算。

4. **G(N) 的计算**：
   ```
   G(N) = Σ_{n=1}^{N} [2S(n) - (n+1)s₂(n)]
   ```
   可使用逐项求和（O(N)），或使用数位 DP 在 O(log N) 时间内完成。

5. **复杂度**：
   - O(N) 方法：对于 N = 10⁷ 可在 ~1 秒内完成
   - O(log N) 方法：可处理 N = 10¹⁸

## 改编方向

1. 推广到质数 p（求 v_p(C(n,k)) 的和）
2. 求 v₂² 的和或更高阶统计量
3. 限制 k 的范围（如只求中心二项式系数 C(2n,n) 的 v₂ 和）
4. 求满足 v₂(C(n,k)) ≥ m 的 (n,k) 对数量
5. 多项式系数中的因子计数
