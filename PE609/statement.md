# π序列

## 题目描述

对于任意 n ≥ 1，**素数计数**函数 π(n) 等于不超过 n 的素数数目。

称序列 u = (u₀, ..., uₘ) 为 **π 序列**，如果满足：
- uₙ ≥ 1（任意 n）
- uₙ₊₁ = π(uₙ)
- u 中至少有两个元素

记 c(u) 为序列 u 中非素数元素的数目。
记 p(n,k) 为满足 u₀ ≤ n 且 c(u) = k 的 π 序列 u 的数目。
记 P(n) 为所有大于 0 的 p(n,k) 的乘积。

已知：P(10) = 3×8×9×3 = 648，P(100) = 31038676032。

求 P(10⁸)，将答案对 1000000007 取模。

## 输入格式

一行，字符串 `PE` 或 `verify`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案：172023848。
若输入为 `verify`，验证 P(10) = 648。

## 样例

### 输入
```
PE
```

### 输出
```
172023848
```

## 数据范围

- 完整问题：n = 10⁸
- 验证模式：n = 10（精确验证 P(10) = 648）
