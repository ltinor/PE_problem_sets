# 素数三元组和等比数列（PE 518）

> ⚠️ 本题面为自动生成的骨架：题目描述取自 PE 原题（中文译文）。
## 原题描述

原题及更多讨论见 [https://projecteuler.net/problem=518](https://projecteuler.net/problem=518)。

对于所有满足下列条件的三元组(a,b,c)，记S(n) = a+b+c之和：
- a、b、c均为素数。
- a &lt; b &lt; c &lt; n。
- a+1、b+1、c+1构成**等比数列**。

例如，由于存在下列三元组，S(100) = 1035：

(2, 5, 11), (2, 11, 47), (5, 11, 23), (5, 17, 53), (7, 11, 17), (7, 23, 71), (11, 23, 47), (17, 23, 31), (17, 41, 97), (31, 47, 71), (71, 83, 97)

求S(10<sup>8</sup>)。
