# 梅花形编码

## 题目描述

四分树编码可将 2^N × 2^N 的黑白图像表示为比特串：
- "0" 表示将当前区域四等分，后续比特依次描述左上、右上、左下、右下子区域
- "10" 表示当前区域全黑
- "11" 表示当前区域全白

定义 D_N 为满足以下条件的 2^N × 2^N 图像（x=0, y=0 为左下角）：
- 若 (x - 2^{N-1})² + (y - 2^{N-1})² ≤ 2^{2N-2}，则该像素为黑色
- 否则为白色

给定 N，求 D_N 的最短四分树编码长度。

---

## 输入格式

一行，一个整数 N。

---

## 输出格式

一个整数，表示最短编码长度。

---

## 样例

### 输入
```
2
```

### 输出
```
16
```

（4×4 图像的最短编码长度）

---

## 数据范围

- 1 ≤ N ≤ 10
- PE 答案: N=24 → 313135496（硬编码）
