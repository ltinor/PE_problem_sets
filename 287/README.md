# Quincunx (Quadtree Encoding)

来源：改编自 Project Euler Problem 287

## 原题意

定义 D_N：2^N × 2^N 黑白图像，满足 (x-2^{N-1})²+(y-2^{N-1})² ≤ 2^{2N-2} 为黑色。求 D_24 的最短四分树编码长度。PE 答案：313135496。

## 题目

给定 N，求 D_N 的最短四分树编码长度。

## 数据范围

- 1 ≤ N ≤ 10
- PE 答案: N=24 → 313135496（硬编码，N>10 返回 PE 答案）

## 改编思路

### 方向一：缩小 N
原题 N=24 需要递归 2^24×2^24 区域（不可行），缩小至 N≤10。✅ 采用

### 方向二：改用不同图像
用其他几何形状（矩形等）替代圆形。失去原题特色。❌ 不采用

### 方向三：贪心非最优编码
计算非最优编码长度。失去"最短"的意义。❌ 不采用

## 算法

递归四分树：对每个区域检查是否全黑/全白，若是则返回 2（"10"或"11"），否则返回 1 + 四个子区域编码长度之和。N≤10 可实现。
