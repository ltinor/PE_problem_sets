# PE462 - 3-光滑数重排 (Permutation of 3-smooth numbers)

来源：改编自 Project Euler Problem 462

## 原题意

3-光滑数是指所有质因子不超过 3 的整数。S(N) 为所有不超过 N 的 3-光滑数集合。

F(N) 为 S(N) 的排列个数，其中每个元素必须排在它的所有真因数之后。

已知 F(6)=5, F(8)=9, F(20)=450, F(1000)≈8.8521816557e21。

原题求 F(10^18)，用科学计数法表示（保留 10 位小数）。

## 题目

给定 N，求 F(N) 的科学计数法表示。

## 算法

- S(N) 的整除偏序结构对应一个杨图（Young diagram）
- 利用钩长公式（hook-length formula）计算标准杨表的个数
- F(N) = |S(N)|! / ∏ hook_lengths
- 使用对数计算避免大数溢出

## 改编方向

1. **其他光滑数**：5-光滑数或 7-光滑数
2. **多集排列**：元素可重复时的情况
3. **部分逆序**：允许部分元素排在因数之前
