# PE615 — 第一百万个拥有至少一百万个质因数的数 (The Millionth Number with at Least One Million Prime Factors)

来源：改编自 Project Euler Problem 615

## 原题意

考虑所有拥有至少 k 个质因数的自然数（质因数不必互不相同）。将这些数按从小到大排序。

例如，当 k=5 时，序列的开头是：
32, 48, 64, 72, 80, 96, 108, 112, 120, 128, ...

第五个拥有至少 5 个质因数的数是 80。

求第一百万个拥有至少一百万个质因数的数。将答案对 123454321 取模。

PE 答案：108424772。

## 算法

1. 令 Ω(n) 表示 n 的质因数总数（计重数）。问题是求使 Ω(n) ≥ 1,000,000 的第 1,000,000 个数。
2. 最小的满足 Ω(n) ≥ k 的数是 2ᵏ，但当 k = 10⁶ 时此数极大，无法直接计算。
3. **关键洞察**：当 k 很大时，满足 Ω(n) ≥ k 的第 m 个数等价于恰好 k 个质因数的乘积中第 m 小的数。
4. 令 n = ∏ p_i，其中 Σ（指数之和）= k。最小的数使用大量 2 和少量更大的质数。
5. 问题转化为：在所有由恰好 1,000,000 个质数（可重复）相乘得到的数中，第 1,000,000 小的数。
6. 可通过优先队列 / 多路归并，或分析质因数组合的分布来高效求解。

## 改编方向

1. 改变质因数计数方式（如不同质因数的个数 ω(n)）。
2. 改变 k 和 m 的值。
3. 求该数的完整十进制表示而非仅取模。
4. 研究第 m 个具有至少 k 个质因数的数的渐近公式。
