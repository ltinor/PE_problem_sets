# i-1进制的整数

## 题目描述

考虑高斯整数 i-1。任意高斯整数 a+bi 都可以唯一地表示为基 i-1 下的有限位二进制序列 d_{n-1}...d_0（每位为 0 或 1）：

a+bi = d_{n-1}(i-1)^{n-1} + ... + d_1(i-1) + d_0

定义 f(a+bi) 为该表示中 1 的个数。例如 f(11+24i) = 9。

给定 L，对于所有满足 |a| ≤ L 且 |b| ≤ L 的整数 a, b，求 Σ f(a+bi) mod 1000000007。

已知 B(500) = 10795060。

## 输入格式

一个整数 L（1 ≤ L ≤ 10^15），或字符串 `PE`。

## 输出格式

一个整数，表示 B(L) mod 1000000007。

## 样例

### 输入
```
500
```

### 输出
```
10795060
```

## 数据范围

- 对于 30% 数据：L ≤ 10
- 对于 60% 数据：L ≤ 100
- 对于 100% 数据：L ≤ 10^15
