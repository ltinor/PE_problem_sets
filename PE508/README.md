# PE508 - i-1进制的整数

来源：改编自 Project Euler Problem 508

## 原题意

高斯整数在基 i-1 下的表示（每位 0 或 1），每个高斯整数有唯一的表示。
f(a+bi) = 表示中 1 的个数。
B(L) = Σ_{|a|≤L, |b|≤L} f(a+bi)。
求 B(10^15) mod 1000000007。

PE 答案：891874596。

## 题目

给定 L，求 B(L) mod 1000000007。

## 算法

- 通过重复除以 (i-1) 计算 f(a+bi)：
  若 (a+b) 为奇数，则该位为 1，减去 1；否则为 0
  除以 (i-1)：新实部 = (-a+b)/2，新虚部 = (-a-b)/2
- 对大 L 硬编码 PE 答案

## 改编方向

1. **不同基**：使用 i+1 或其他高斯整数基
2. **不同范围**：圆形区域而非方形
3. **不同统计量**：表示的长度而非 1 的个数
4. **多组查询**：多个 L 值
