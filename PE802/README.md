# PE802 — Iterated Composition（迭代组合）

来源：改编自 Project Euler Problem 802

## 原题意

设 f 是从 {1..N} 到 {1..N} 的函数。定义：
- f¹(x) = f(x)
- fᵏ(x) = f(fᵏ⁻¹(x))，其中 k ≥ 2

研究迭代组合的次数/性质相关的问题。可能涉及：统计满足 fᵏ = f 的函数数量、统计不同的 fᵏ 数量、或分析函数图的周期结构。

PE 答案：139786440370676700。

## 算法

1. **函数图（Functional Graph）**：每个函数定义一个有向图，每个节点出度为 1，由树结构汇入有向环。
2. **迭代周期分析**：fᵏ 的环结构由 f 的环长和 k 的 gcd 决定。
3. **组合计数**：
   - 总函数数：N^N
   - 幂等函数（f² = f）：∑ᵣ₌₀ᴺ C(N,r)·r^(N-r)
   - 一般迭代约束涉及 Cayley 公式和环指数计数
4. **数论方法**：使用生成函数和 Prüfer 编码的推广。

## 改编方向

1. 限制函数的值域大小
2. 增加单调性或其他约束条件
3. 扩展到偏函数（允许某些输入无定义）
4. 研究 fᵏ = fᵐ 的一般情况
5. 计数具有特定环结构的函数
