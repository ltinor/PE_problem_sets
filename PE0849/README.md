# PE849 — Race to Strength（力量竞赛）

来源：改编自 Project Euler Problem 849

## 原题意

两名选手竞赛达到目标力量值。每轮各选手按概率获得力量。首先达到目标的选手获胜。问题计算获胜概率或期望回合数，汇总所有初始配置。

PE 答案：68321107。

## 算法

1. **赌徒破产模型**：经典随机游走模型，两吸收壁。
2. **获胜概率公式**：P(A赢) = (1-(q/p)^a)/(1-(q/p)^(a+b))（p≠½），或 a/(a+b)（公平游戏）。
3. **期望步数**：E[T] = a·b（公平对称随机游走）。
4. **模运算**：在模素数下用费马小定理计算有理数。

## 改编方向

1. 多人竞赛（超过两名选手）
2. 力量值可以减小（随机游走回退）
3. 不同选手有不同的增益分布
4. 阶段目标（多个里程碑）
5. 团队竞赛（多名选手合作）
