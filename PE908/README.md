# PE908 — Clock Sequence II（钟摆序列二）

来源：改编自 Project Euler Problem 908

## 原题意

钟摆序列是周期正整数序列，可分成连续片段使第 $n$ 段之和等于 $n$。$C(N)$ 为周期 $\leq N$ 的不同钟摆序列的数量。

已知：$C(3)=3$，$C(4)=7$，$C(10)=561$。求 $C(10^4) \bmod 1111211113$。

PE 答案：898438666

## 算法

1. **条件刻画**：
   - 周期 $P$ 的序列 $a[0..P-1]$，前缀和必须覆盖所有三角数 $T_k = k(k+1)/2$
   - 令 $\Sigma = \sum a[i]$，则累积和 $S(mP+r) = m\Sigma + \text{prefix}(r)$

2. **组合解释**：
   - 钟摆序列等价于满足特定整除条件的整数组合
   - 每个周期相当于对三角数序列的一个"匹配"模式

3. **DP/生成函数**：
   - 小规模可枚举周期序列并验证
   - 大规模使用数论和组合递推

4. **模运算**：
   - 模数 $1111211113$ 是素数，可利用模逆元
