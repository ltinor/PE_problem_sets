# 钟摆序列（二）（Clock Sequence II）

## 题目描述

钟摆序列是一种具有周期性的正整数序列。该序列可以被分成连续的片段，使得第 $n$ 个片段之和恰好等于 $n$。

例如，周期为 $6$ 的序列 $1,2,3,4,3,2$（重复）可以分成：
$$1 \mid 2 \mid 3 \mid 4 \mid 3,2 \mid 1,2,3 \mid 4,3 \mid 2,1,2,3 \mid 4,3,2 \mid 1,2,3,4 \mid \cdots$$

定义 $C(N)$ 为周期至多为 $N$ 的不同钟摆序列的个数。已知 $C(3)=3$，$C(4)=7$，$C(10)=561$。

求 $C(10^4) \bmod 1\,111\,211\,113$。

## 输入格式

无输入（固定参数问题）。

## 输出格式

输出一个整数，表示 $C(10^4) \bmod 1\,111\,211\,113$。

## 样例

（无样例输入输出，直接计算并输出最终答案。）
