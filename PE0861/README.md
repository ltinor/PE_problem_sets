# PE861 — Products of Divisors（约数乘积）

来源：改编自 Project Euler Problem 861

## 原题意

定义 d(n) 为正整数 n 的正约数个数。n 的所有正约数的乘积为 n^{d(n)/2}。

本题要求计算在某个范围内所有 n 的约数乘积之和（或乘积），可能涉及大数模运算。

## 算法

1. **约数个数筛法**：使用埃拉托色尼筛法预处理 d(n)。
2. **模幂运算**：n^{d(n)/2} mod M 可通过快速幂计算。
3. **约数乘积**：对于小 n 可直接枚举约数求乘积；对于大 n 使用公式 n^{d/2}。
4. **求和**：累加所有 n 的约数乘积。
