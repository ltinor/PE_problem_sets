# PE852 — Coins in a Box（盒中硬币）

来源：改编自 Project Euler Problem 852

## 原题意

有 $N$ 个盒子和 $C$ 枚硬币。每枚硬币独立地等概率放入任意一个盒子中。定义某个盒子中有"奇数枚硬币"当且仅当该盒子中的硬币数为奇数。

求包含奇数枚硬币的盒子的期望数量。

对于一枚特定的盒子，硬币数服从二项分布 $\\text{Bin}(C, 1/N)$。该盒子含有奇数枚硬币的概率为：
$$P_{\\text{odd}} = \\sum_{k \\text{ odd}} \\binom{C}{k} \\left(\\frac{1}{N}\\right)^k \\left(1-\\frac{1}{N}\\right)^{C-k} = \\frac{1 - (1 - 2/N)^C}{2}$$

期望值为 $E = N \\cdot P_{\\text{odd}}$。

PE 答案：544106376。

## 算法

1. **精确枚举**：对于 $N, C$ 较小的情况，可以用深度优先搜索枚举所有分配。
2. **二项分布公式**：利用概率生成函数得到 $P_{\\text{odd}} = (1-(1-2p)^n)/2$。
3. **泊松近似**：当 $N$ 较大且 $C/N = \\lambda$ 时，每盒硬币数近似服从泊松分布。
4. **大数渐近**：当 $C \\to \\infty$ 时，$E \\to N/2$；当 $N \\to \\infty$ 且 $C = \\alpha N$ 时，$E \\to N(1-e^{-2\\alpha})/2$。
