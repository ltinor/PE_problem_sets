## 题目描述

### PE 751 — Concatenation Coincidence (拼接巧合)
一个实数 θ > 1。取其连分数展开数字 [b₁; b₂, b₃, ...]，将这些数字按小数拼接 b₁.b₂b₃...，使其等于 θ 自身。求这个唯一的 θ，截断到小数点后 8 位。

### PE 752 — Powers of 1+√7 (1+√7的幂)
考虑 (1+√7)ⁿ = aₙ + bₙ√7，其中 aₙ, bₙ 为整数。求满足特定整除条件的 n 的和。

### PE 753 — Cauchy Matrix (柯西矩阵)
柯西矩阵 C_{i,j} = 1/(x_i + y_j)。对特定序列计算柯西矩阵行列式的相关量。

### PE 754 — Product of Gauss Factorials (高斯阶乘积)
G(n) = Π_{1≤k≤n, gcd(k,n)=1} k 为高斯阶乘。求 Σ G(n) 或 Π G(n) 在某个模下的值。

### PE 755 — Direct Zeckendorf Optimization (直接Zeck优化)
Zeckendorf 定理：每个正整数可唯一表示为非连续斐波那契数之和。f(n) = Zeckendorf 表示中的项数。求 Σ_{n=1}^{N} f(n)，其中 N 很大，需用 DP 优化。
