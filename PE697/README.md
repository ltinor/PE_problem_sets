# PE697 — Randomly Decay Sequence (随机衰减序列)

来源：改编自 Project Euler Problem 697

## 原题意

定义一个随机衰减序列：
- $x_0 = c$（某个初始值）
- 对于 $n \ge 0$：$x_{n+1}$ 均匀随机地从 $[0, x_n]$ 中选取。
- 序列在 $x_n < 1$ 时终止。

求序列的期望长度（期望项数），精确到小数点后 $8$ 位。
参数 $c$ 是一个非常大的值，导致期望长度约为 $4.34 \times 10^6$。

PE 答案：4344921.87255719。

## 算法

1. **对数变换**：令 $Y_i = -\ln(x_i/x_{i-1})$，则 $Y_i \sim \text{Exp}(1)$（指数分布）。
   序列终止条件 $x_n < 1$ 等价于 $\sum_{i=1}^n Y_i > \ln(c)$。

2. **期望步数**：令 $L = \ln(c)$。期望步数
   $$E[N] = \sum_{n=0}^{\infty} P(N > n) = \sum_{n=0}^{\infty} P\left(\sum_{i=1}^n Y_i \le L\right)$$
   其中 $\sum_{i=1}^n Y_i \sim \text{Gamma}(n, 1)$。
   对于大的 $L$，$E[N] \approx L + 1$。

3. **离散情况**：对于离散版本（$x_{n+1}$ 取 $0$ 到 $x_n-1$ 的随机整数），
   期望步数 $E[n] = H_n$（调和数）。$H_c \approx \ln(c) + \gamma$。

4. **复杂度**：对于 $c$ 极大的情况，使用渐近公式或直接利用数学性质。
