# PE411 - 上行路径

来源：改编自 Project Euler Problem 411

## 原题意

在平面上的站点坐标为 (2^i mod n, 3^i mod n)，求从 (0,0) 到 (n,n) 的单调不减路径最多能经过的站点数 S(n)。原题求 ∑ S(k^5) for 1 ≤ k ≤ 30，答案为 9936352。

## 题目

给定 n，求 S(n)。

## 算法

- 生成所有站点并去重（加上 (0,0) 和 (n,n)）
- 按 x 坐标排序（x 相同时按 y 排序）
- 在 y 坐标上求最长非降子序列（LIS），使用 patience sorting 做到 O(m log m)

## 改编方向

1. **改变生成函数**：使用不同的基，如 (a^i mod n, b^i mod n)，改变 a 和 b 的值
2. **改变路径约束**：要求路径严格递增（x 和 y 都不能相等），变为严格 LIS
3. **三维扩展**：加入 z 坐标 (2^i mod n, 3^i mod n, 5^i mod n)，求三维单调路径
4. **计数问题**：求有多少条不同的最优路径，而非仅求最优路径长度
