# 168 — 数字轮换

来源：改编自 Project Euler Problem 168

## 原题意

求所有满足"右旋转是自身的倍数"的 10 < n < 10^100 的整数之和的最后 5 位。原题答案：59206。

## 题目

参数化 D：输入 D（≤ 100），求 10 < n < 10^D 范围内满足条件的整数之和的最后 5 位。

## 数据范围

- 1 ≤ D ≤ 100

## 算法

**std**: 推导公式 n = b × (10^k - 1) / (10m - 1)，其中 b 为末位数字（1-9），m 为倍数（2-9），k 为位数（2-D）。枚举 b, m, k，用大整数除法验证整除性并计算 n mod 10^5。时间复杂度 O(9 × 8 × D) = O(D)。

**brute**: 小 D 时直接枚举所有 n 验证；大 D 时使用相同公式但限制 k ≤ 18（64 位整数范围）。

## 改编方向

1. **参数化 D**：将固定上界 10^100 改为 10^D。
2. **大整数处理**：使用逐位除法处理 k ≤ 100 的情况。
3. **PE 答案验证**：(D=100) 输出 59206。
