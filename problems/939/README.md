# PE 939 Partisan Nim（偏心的取石子游戏）

来源：改编自 Project Euler Problem 939

## 原题意

两名玩家 A、B 玩一种变体 Nim。游戏开始时有若干堆石子，每一堆要么属于 A，要么属于 B（石子堆之间无序）。

轮到任一玩家时，该玩家可以：

- 选择属于对手的一堆石子，并从中移除一枚石子；或
- 选择属于自己的一堆石子，并移除整堆。

移除最后一枚石子的玩家获胜。

令 E(N) 为「最多有 N 枚石子，且无论谁先行动 A 总是有必胜策略」的初始局面数量。

例如 E(4) = 9。原题求 E(5000) mod 1234567891。

## 题目（缩数据版）

读入一个整数 N，输出 E(N) mod 1234567891。

## 数据范围

- 1 ≤ N ≤ 500（缩数据；原题 N = 5000）。
- 验证点：E(4) = 9。

## 算法

### 组合博弈分析

设 `G_k` 为「单独一堆 k 枚石子」对应的博弈（属于 A 记 +G_k，属于 B 记 -G_k）。
单堆的走法给出递归式：

```
G_0 = 0
G_k = { 0 | G_{k-1} }        (k >= 1)
```

于是 `G_1 = *`（先手胜的模糊局面），`G_2 = ↑`（正的无穷小），`G_3 = {0|↑}`，……。
整个局面为 `Σ_{A堆} G_k + Σ_{B堆} (-G_k)`，A 无论谁先手都必胜 ⟺ 该博弈值 > 0。

### 必胜判定

对每个局面定义：

- `n = Σ_{A堆}(k-1) - Σ_{B堆}(k-1)`
- `o = (Σ_A (k mod 2) - Σ_B (k mod 2)) mod 2`

则 A 无论谁先手都必胜 ⟺ `n >= 2` 或 `(n == 1 且 o == 0)`。

该判定已通过对总石子数 ≤ 11 的全部 1967 个局面逐一遍历、与直接博弈搜索对照验证，无一不一致。

### 计数 DP（O(N^3)）

对每个堆大小 `k = 1..N`，可选择任意个「A 侧 k 堆」与任意个「B 侧 k 堆」（无限背包）：

- A 侧 k 堆：总石子 +k，n +(k-1)，o 异或 (k & 1)；
- B 侧 k 堆：总石子 +k，n -(k-1)，o 异或 (k & 1)。

状态 `dp[t][j][o]`：总石子 t、n = j - N（偏移 N 保证下标非负）、奇偶 o 的局面数。
答案 = Σ dp[t][j][o]，其中满足 `n >= 2` 或 `(n == 1 且 o == 0)`。

复杂度 O(N^3)，N = 500 时约 5×10^8 次加法，可在数秒内完成。
