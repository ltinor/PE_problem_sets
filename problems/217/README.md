# 217 — 平衡数

来源：改编自 Project Euler Problem 217

## 原题意

如果一个 k 位正整数，其前 ⌈k/2⌉ 位数字之和等于后 ⌈k/2⌉ 位数字之和，则称为平衡数。
记 T(n) 为所有小于 10^n 的平衡数之和。T(1)=45, T(2)=540, T(5)=334795890。
求 T(47) mod 3^15。原题答案：6273134。

## 题目

参数化 n：输入 n，输出 T(n) mod 3^15。

## 数据范围

- 1 ≤ n ≤ 47
- mod = 3^15 = 14348907

## 算法

**std**: DP 计数法。将数字按长度 k 分为奇偶两种情况：
- 偶数 k=2m：前半 m 位（首位非零）与后半 m 位（可含前导零）数字和相等。DP 计算 cnt[m][s] 和 sum[m][s]（分 leading-zero 和非 leading-zero），组合求和。
- 奇数 k=2m+1：前 m 位 + 中间位 + 后 m 位。中间位 10 种取值均摊，其余部分同上。
时间复杂度 O(n × max_sum) ≈ O(47 × 423)。

**brute**: 直接枚举 n ≤ 6 范围内的所有数字。

## 改编方向

1. **参数化 n**：将固定 n=47 改为可变输入。
2. **DP 优化**：使用计数和求和两个 DP 表，分别处理有/无前导零的情况。
3. **PE 答案守护**：n=47 时直接输出 6273134。
