# 二项式系数的质因子和

## 题目描述

二项式系数 $\binom{N}{K} = \dfrac{N!}{K!(N-K)!}$。

求 $\binom{N}{K}$ 的所有质因子的和。例如：

- $\binom{10}{3} = 120 = 2^3 \times 3 \times 5$，质因子和为 $2+2+2+3+5 = 14$。

给定 $N$ 和 $K$，求 $\binom{N}{K}$ 的质因子和。

---

## 输入格式

输入一行，两个整数 $N, K$（$1 \le K < N \le 2 \times 10^7$）。

---

## 输出格式

输出一个整数，表示 $\binom{N}{K}$ 的所有质因子的和。

---

## 样例

### 输入
```
10 3
```

### 输出
```
14
```

---

## 数据范围

$1 \le K < N \le 2 \times 10^7$
