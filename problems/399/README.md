# PE399 - 无平方因子斐波那契数

来源：改编自 Project Euler Problem 399

## 原题意

求第 100,000,000 个无平方因子的斐波那契数。

## 题目

给定 K，求第 K 个无平方因子的斐波那契数。假设 Wall 猜想成立（每个质数 p，第一个被 p 整除的斐波那契数不被 p² 整除）。

## 算法

- 斐波那契数增长极快（指数级），需大数运算
- 无平方因子判定：检查质数平方是否整除
- 利用 Wall 猜想简化判定

## 改编方向

1. **求第 K 个有平方因子的**：相反条件
2. **指定质数集合**：只允许/不允许某些质数作为平方因子
3. **求密度**：前 N 个斐波那契数中无平方因子的比例
4. **卢卡斯数**：对卢卡斯数做同样分析
