# 拥有良好可整除性的数列（PE 511）

## 原题描述

原题及更多讨论见 [https://projecteuler.net/problem=511](https://projecteuler.net/problem=511)。

记Seq(n,k)是所有满足下列条件的长为n的正整数序列{a<sub>i</sub>}<sub>1≤i≤n</sub>的数目：
-  对于所有1&nbsp;≤&nbsp;i&nbsp;≤&nbsp;n，n能够被a<sub>i</sub>整除，且
-  n + a<sub>1</sub> + a<sub>2</sub> + ... + a<sub>n</sub>能被k整除。

举例如下：

Seq(3,4) = 4，这4个数列分别是：
{1, 1, 3}
{1, 3, 1}
{3, 1, 1}
{3, 3, 3}

Seq(4,11) = 8，这8个数列分别是：
{1, 1, 1, 4}
{1, 1, 4, 1}
{1, 4, 1, 1}
{4, 1, 1, 1}
{2, 2, 2, 1}
{2, 2, 1, 2}
{2, 1, 2, 2}
{1, 2, 2, 2}

Seq(1111,24)的最后九位数字是840643584。

求Seq(1234567898765,4321)的最后九位数字。
