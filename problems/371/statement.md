# 汽车牌照期望

## 题目描述

车牌号码为 $0$ 到 $999$ 中的整数，等概率出现。赛斯每次记录一块看到的车牌。

当赛斯看到过的两块车牌号码之和等于给定的目标值 $S$ 时获胜（特别地，若 $S$ 为偶数，号码 $S/2$ 需要被看到两次）。

求赛斯获胜所需看到的车牌数的数学期望，保留 8 位小数。

原题（PE371）即 $S = 1000$ 的情形，期望约为 $40.66368097$。

---

## 输入格式

第一行一个 token：

- 若为 `PE`，输出原题（$S=1000$）官方答案；
- 否则为整数 $S$（$2 \le S \le 1000$），表示目标和。

---

## 输出格式

一行一个实数，表示期望值，保留 8 位小数。

---

## 样例

### 输入

```
1000
```

### 输出

```
40.66368097
```
