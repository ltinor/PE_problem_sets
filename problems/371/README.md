# 371 — 汽车牌照期望

来源：改编自 Project Euler Problem 371

## 原题意

俄勒冈州汽车牌照由三个字母和一个三位数组成。在上班路上，赛斯记录看到的牌照号码，如果两个牌照的三位数之和等于1000则获胜。求获胜所需牌照数的期望值，保留8位小数。

## 题目

给定偶数 S（2 ≤ S ≤ 200），车牌数字范围为 [0, S-1] 均匀分布。当看到两个数字之和为 S 时获胜（S/2 需要出现两次）。求期望看到的牌照数，保留8位小数。

## 数据范围

S 为偶数，2 ≤ S ≤ 200。

## 算法

1. **马尔可夫链期望DP**：状态为 (已见半配对数, 是否见过S/2)，解线性方程组求期望，O(S³)或迭代。
2. **蒙特卡洛模拟**：大量随机模拟取平均，O(T·S)。
3. **组合公式**：利用几何分布和容斥原理推导闭式解。
