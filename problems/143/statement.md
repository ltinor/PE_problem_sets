# 三角形托里拆利点的研究

## 题目描述

三角形 ABC 的每一个内角均小于 120 度。当 p+q+r 最小时，若边 a,b,c 和距离 p,q,r 均为正整数，称 ABC 为托里拆利三角形。

给定 M，求所有满足 p+q+r ≤ M 的不同 p+q+r 值之和。

---

## 输入格式

一行一个整数 M (1 ≤ M ≤ 120000)。

---

## 输出格式

一行一个整数，表示所有不同的 p+q+r 值之和。

---

## 样例

### 输入

```
1000
```

### 输出

```
784
```

（p+q+r = 784 是 a=399, b=455, c=511 对应的托里拆利三角形示例）

---

## 数据范围

- 1 ≤ M ≤ 120000
