# PE 955 · Finding Triangles（寻找三角形数）— 简单版本

来源：改编自 Project Euler Problem 955

## 原题意

数列 $(a_n)_{n\ge 0}$ 从 $a_0=3$ 开始：若 $a_n$ 是三角形数则 $a_{n+1}=a_n+1$，否则 $a_{n+1}=2a_n-a_{n-1}+1$。求数列中第 70 个三角形数的下标 $n$。

## 简单版本改动

原题第 70 个三角形数下标极大，需要 Pell 方程等高阶数论方法。改为：给定 $k$，输出数列中第 $k$ 个三角形数的下标 $n$。

## 缩数据范围

$1 \le k \le 20$（第 20 个下标约 $1.66\times10^7$，直接模拟毫秒级完成）。

## 算法

直接模拟。维护当前值 $a$ 与相邻项差 $d=a_n-a_{n-1}$：

- 若 $a$ 是三角形数，则下一项差重置为 $1$；
- 否则差加 $1$（因 $a_{n+1}-a_n=a_n-a_{n-1}+1$）。

每走一步判断新值是否为三角形数并计数。判断用 $(2m+1)^2=8x+1$，`__int128` 精确开方。复杂度 $O(\text{下标})$。
