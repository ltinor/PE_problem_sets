# 钝角三角形

## 题目描述

定义点集 S(r) 为所有满足 |x| + |y| ≤ r 的整数坐标点 (x, y)。

记 O 为原点 (0, 0)，C 为点 (r/4, r/4)（整数除法）。

在 S(r) 中取一点 B，使得三角形 OBC 有一个钝角（即最大角 α 满足 90° < α < 180°）。记 N(r) 为所有这样的点 B 的数量。

例如：N(4) = 24，N(8) = 100。

给定 r，求 N(r)。

---

## 输入格式

一行，一个整数 r（1 ≤ r ≤ 2×10^5）。

---

## 输出格式

一行，一个整数，表示 N(r)。

---

## 样例

### 输入 1

```
4
```

### 输出 1

```
24
```

### 输入 2

```
8
```

### 输出 2

```
100
```

---

## 数据范围

- 1 ≤ r ≤ 2×10^5
- PE 答案：r = 1,000,000,000 → 1598174770174689458
