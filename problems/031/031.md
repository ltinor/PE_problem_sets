# 硬币求和

改编自 [Project Euler Problem 31](https://projecteuler.net/problem=31)

## 原题

英国货币有 8 种面值硬币：1p, 2p, 5p, 10p, 20p, 50p, £1(100p), £2(200p)。
每种硬币数量不限，求凑出 £2(200p) 有多少种不同的方法。

**原题答案：73682**

## 改编

将固定目标金额 £2 参数化为任意正整数 N（N ≤ 10^5）。输入 N，使用同样的 8 种硬币面值，求凑出 N 便士的方法数。

## 算法

经典完全背包 DP：dp[i] 表示凑出 i 便士的方法数，对每种硬币 c 进行 dp[j] += dp[j-c]。

时间复杂度 O(8×N)，空间复杂度 O(N)。
