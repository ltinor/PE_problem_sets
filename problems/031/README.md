# 硬币求和 (Coin Sums)

来源：改编自 Project Euler Problem 31

## 原题意

英国货币有8种面值硬币：1p, 2p, 5p, 10p, 20p, 50p, £1(100p), £2(200p)。求凑出 £2(200p) 有多少种不同的方法。

原题答案：73682。

## 改编方向

将固定目标金额 £2 参数化为任意正整数 N。输入 N，使用同样的 8 种硬币面值，求凑出 N 便士的方法数。

## 题目

给定 8 种硬币面值 {1, 2, 5, 10, 20, 50, 100, 200}（单位：便士），每种硬币数量不限。输入一个正整数 N，求用这些硬币凑出 N 便士有多少种不同的方式。

## 数据范围

- N ≤ 10^5
- 答案可能超过 64 位整数范围，需使用 128 位整数或大数

## 算法

经典完全背包 DP：`dp[i]` 表示凑出 i 便士的方法数。对每种硬币 c，`dp[j] += dp[j-c]`。由于答案可能超过 2^63-1，使用 `__int128` 存储。时间复杂度 O(8×N)，空间复杂度 O(N)。

brute 使用独立实现的 2D DP（bottom-up），算法相同但实现方式不同以保证正确性验证。

## 验证

- 原题答案：N=200 → 73682 ✓
- 10 组随机小数据对拍（std vs brute）：全部 AC
- 10 组正式数据对拍（std vs brute）：全部 AC
