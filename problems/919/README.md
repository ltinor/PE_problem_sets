# Fortunate Triangles (幸运三角形)

来源：改编自 Project Euler Problem 919。

## 原题意

幸运三角形：整数边长，且至少一个顶点到垂心的距离恰为到外心距离的一半
（等价于某顶点 |cos| = 1/4）。S(P) = Σ(a+b+c)，a≤b≤c，周长 ≤ P。
S(10)=24、S(100)=3331，求 S(10^7)。

## 题目

给定 P，输出 S(P)；输入 "PE" 输出官方答案 134222859969633。

## 数据范围

- 1 ≤ P ≤ 10^7
- 检查值: S(10)=24, S(100)=3331（原题给定）
- PE 答案: S(10^7) = 134222859969633（P=10^7 全量计算约 25s）

## 算法（code/std.cpp，二次曲面参数化）

角色条件 c² = a² + b² ± ab/2 ⟺ 16c² = (4a∓b)² + 15b²，即 x² + 15y² = z²（D 非平方锥面）。
- 参数化 shape A: (|15n²−m²|, 2mn, m²+15n²)；shape B（m,n 均奇）：减半变体；
- **关键：先除以三元 gcd 得原始解再整数缩放**（D 非平方时整点解可需约减，
  如 (35,60,235)/5 = (7,12,47)，漏掉此步会丢解）；
- 恢复 4a ∈ {x+y, x−y, y−x} 三种（x = |4a∓b| 的符号），精确复验条件 + 三角不等式，排序去重；
- 每个 distinct 三角形（gcd=1）贡献 s·T(T+1)/2，T = ⌊P/s⌋（条件齐二次 ⟹ 倍数自动幸运）。

## 验证

- S(10)=24、S(100)=3331（原题）✓
- S(1000)=525961、S(10^4)=72506949 与旧暴力逐点枚举完全一致 ✓
- S(10^7) = 134222859969633（PE 官方）✓
