# 119 — 数字和的幂

来源：改编自 Project Euler Problem 119

## 原题意

定义 a_n 为第 n 个满足"等于其各位数字和的某次幂（指数 ≥ 2）且至少两位数字"的数。已知 a_2 = 512，a_10 = 614656。求 a_30。答案：248155780267521。

## 题目

输入 K，求 a_K（第 K 个这样的数）。

## 数据范围

- 1 ≤ K ≤ 30

## 算法

枚举各位数字和 s（2 到约 200），对每个 s 计算 s 的各次幂 s^p（p ≥ 2），检查 s^p 的各位数字和是否等于 s。收集所有满足条件的数，排序后取第 K 个。

- s 的上界：a_30 ≈ 2.48×10^14，共 15 位数字，最大数字和为 9×15 = 135，留余量取 200
- 幂次上界：p 增长时 s^p 快速增长，当 s^p > 10^18 时停止（64 位溢出前）

时间复杂度取决于枚举规模，s 最多 ~200，p 最多 ~log_s(10^18) ≤ 60，总候选数 < 10000。

## 改编方向与取舍

### 改编方向
1. **参数化 K** → 输入 K 求第 K 个数（本题采用）
2. **参数化位数** → 输入最小位数
3. **参数化指数下界** → 输入最小指数 p_min
4. **只输出所有数** → 列出某范围内的所有数

### 取舍理由
- 选择参数化 K：保持原题核心，K=30 包含原题
- K ≤ 30：枚举范围可控，无需大整数
- 直接枚举数字和：规模小，代码简洁
