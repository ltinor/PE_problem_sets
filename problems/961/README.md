# PE961 - 删除数字

来源：改编自 Project Euler Problem 961（Removing Digits）。

## 原题意

两位玩家轮流从一个正整数中删除一个数字；每次删除之后产生的前导零也会一并被删除。

例如，从 $105$ 中删除一个数字会得到 $5$、$10$ 或 $15$。

删除最后一个非零数字（即把数变成 $0$）的玩家获胜。

定义 $W(N)$ 为小于 $N$ 且双方均采用最优策略时先手必胜的正整数数量。已知 $W(100)=18$，$W(10^4)=1656$，求 $W(10^{18})$。

## 题目

本题为缩数据简单版：给定 $N$，求 $W(N)$。

## 数据范围

$1 \le N \le 10^6$（原题 $N = 10^{18}$，此处为缩数据版）。

## 算法

Sprague–Grundy 定理 + 动态规划。

- 该游戏是普通 play 的无偏博弈，终止态为 $0$（无数字可删，即上一步已获胜）。先手必胜当且仅当 Grundy 值 $g(n)\neq 0$。
- $g(0)=0$，且
  $$g(n)=\operatorname{mex}\{g(m):m\text{ 为删除 }n\text{ 中某一位并去掉前导零后的结果}\}.$$
- 删除一位后数字严格变小，故可按 $n$ 递增顺序 DP，只需一个 `vector<int>` 存 $g$。
- 删除第 $i$ 位（自低位起 $i=0$）的结果用整数运算得到：
  $$m=\left\lfloor\frac{n}{10^{\,i+1}}\right\rfloor\cdot 10^{\,i}+(n\bmod 10^{\,i}),$$
  前导零被整数运算自动去掉。
- 每个 $n$ 的移动数不超过其位数，故 `mex` 值上界约为位数，`mex` 只用一个小布尔数组即可。
- 复杂度 $O(N\log N)$。

## 验证

- `std`（整数运算 DP）与 `brute`（字符串逐位删除 + 递归记忆化）在 $N\le 10^4$ 全量一致；
- 官方验证点 $W(100)=18$、$W(10^4)=1656$ 通过；
- 随机小样本（`gen small`）std 与 brute 一致。

## 改编方向

原题 $N=10^{18}$ 需要刻画数字模式下的 Grundy 规律（数位 DP / 分类计数），无法直接枚举；
