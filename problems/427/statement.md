整数序列S = {s<sub>i</sub>}被称为<em>n-序列</em>，如果它有n个元素，而且每个元素s<sub>i</sub>满足1 ≤ s<sub>i</sub> ≤ n。因此，一共有n<sup>n</sup>个不同的n-序列。例如，序列S = {1, 5, 5, 10, 7, 7, 7, 2, 3, 7}就是一个10-序列。

对于任意序列S，记L(S)是其中相同元素连续出现的最大次数。例如，对于上述序列S，L(S) = 3，因为其中有连续出现的3个7。

对于所有的n-序列S，记f(n) = ∑ L(S)。

例如，f(3) = 45，f(7) = 1403689，f(11) = 481496895121。

求f(7&nbsp;500&nbsp;000) mod 1&nbsp;000&nbsp;000&nbsp;009。
