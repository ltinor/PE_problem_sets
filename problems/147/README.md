# 147 — 交叉线网格中的长方形

来源：改编自 Project Euler Problem 147

## 原题意

求所有 ≤47×43 的交叉线网格中，可以找到的长方形总数。

原题答案：846910284。

## 题目

参数化 W, H：输入 W 和 H，求所有 w×h 网格（1≤w≤W, 1≤h≤H）中长方形总数之和。

## 数据范围

- W ≤ 47, H ≤ 43

## 算法

**std**: 对每个 w×h 网格：普通长方形数为 C(w+1,2)×C(h+1,2)。对角线长方形：对于投影为 a（水平）和 b（垂直）、满足 a+b 为偶数的斜长方形，数量为 2×(w-a+1)×(h-b+1)（两个方向）。对所有 (w,h) 求和。时间复杂度 O(W²H²)。

**brute**: 枚举所有网格点，检查任意四点是否构成矩形。适用于极小网格（≤3×3）。

## 改编方向

1. **参数化网格大小**：将固定 47×43 改为输入 W, H。
2. **公式推导**：分为普通长方形和对角线长方形两类计数。
3. **双方向对角线**：考虑 NW-SE 和 NE-SW 两个方向的对角线长方形。
4. **PE 答案验证**：(W=47, H=43) 作为测试点，输出 846910284。
