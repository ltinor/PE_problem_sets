# 完全平方数收集

## 题目描述

找出最小的 x + y + z，其中正整数 x > y > z > 0，满足 x+y, x-y, x+z, x-z, y+z, y-z 均为完全平方数。

---

## 输入格式

第一行一个 token：

- 若为 `PE`，输出原题（PE142）官方答案；
- 否则为整数 $T$（$1 \le T \le 10^9$），作为占位参数，不影响结果（答案恒为最小 $x+y+z$）。

---

## 输出格式

一行一个整数，表示最小的 x+y+z。

---

## 样例

### 输入

```
1
```

### 输出

```
1006193
```
