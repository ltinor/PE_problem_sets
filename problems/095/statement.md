# 亲和数链

## 题目描述

一个数除了自身之外的因数称为**真因数**。令 $s(n)$ 表示 $n$ 的所有真因数之和。

若存在一系列正整数 $a_1, a_2, \dots, a_k$ 满足：
$$s(a_1) = a_2,\ s(a_2) = a_3,\ \dots,\ s(a_{k-1}) = a_k,\ s(a_k) = a_1$$

则称 $(a_1, a_2, \dots, a_k)$ 为一个**亲和数链**，其长度为 $k$。

例如，$220$ 的真因数之和为 $284$，$284$ 的真因数之和为 $220$，因此 $(220, 284)$ 是一个长度为 $2$ 的亲和数链（也称为亲和数对）。

给定正整数 $N$，求所有元素均不超过 $N$ 的最长亲和数链中最小的元素。若有多个最长链，输出其中最小的元素。

---

## 输入格式

一行一个整数 $N$。

---

## 输出格式

一行一个整数，表示答案。

---

## 样例

### 输入

```
300
```

### 输出

```
220
```

**解释**：在不超过 $300$ 的数中，只有 $(220, 284)$ 这一条亲和数链，其中最小的元素为 $220$。

---

## 数据范围

$2 \le N \le 10^6$。
