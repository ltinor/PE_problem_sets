# 亲和数链

来源：改编自 Project Euler Problem 95

## 原题意

在所有元素不超过 $10^6$ 的亲和数链中，找出最长链中最小的元素。答案：14316。

## 题目

给定正整数 $N$，对于所有满足以下条件的亲和数链：
- 链中所有元素均为不超过 $N$ 的正整数；
- 链长大于 $1$（即排除单元素平凡链）；

求最长链中最小的元素。若有多个最长链，输出其中最小的元素。

## 数据范围

$2 \le N \le 10^6$。

## 算法

首先使用筛法计算 $1 \sim N$ 中每个数的真因数之和（即除自身外所有因数的和）。对于每个数 $i$，令 $s(i)$ 表示其真因数之和。

然后对 $1 \sim N$ 中每个未访问过的数进行 DFS，沿着 $i \to s(i) \to s(s(i)) \to \dots$ 的方向追踪，直到：
- 超出 $N$（无效链）；
- 遇到已访问节点，若形成环（链长 $>1$），记录环长和环中最小元素。

维护全局最优解即可。
