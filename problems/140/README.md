# 140 — Modified Fibonacci Golden Nuggets

来源：改编自 Project Euler Problem 140

## 原题意

求前 30 个 modified Fibonacci golden nuggets 之和。

原题答案：5673835352990。

## 题目

参数化 K：输入 K (≤ 30)，求前 K 个 golden nuggets 之和。

## 数据范围

- K ≤ 30

## 算法

**std**: 考虑修改的斐波那契序列 G₁=1, G₄=4, Gₖ=Gₖ₋₁+Gₖ₋₂。其生成函数 AG(x) = (x+3x²)/(1−x−x²) = N（正整数）。需 x 为有理数，等价于 5N²+14N+1 为平方数。通过 Pell 方程分析得递推关系：N₁=2, N₂=5, N₃=21, N₄=42。对 k≥5：Nₖ = 7·Nₖ₋₂ − Nₖ₋₄ + 7。求和输出。

**brute**: 相同递推公式。

## 改编方向

1. **参数化 K**：将原题固定 K=30 改为输入参数。
2. **递推公式**：利用序列的递推关系高效生成 golden nuggets。
3. **扩展性**：K 可扩展到更大值（如 100），答案可容于 64 位整数。
4. **PE 答案验证**：(K=30) 作为测试点，输出 5673835352990。
