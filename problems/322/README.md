# 322 — Binomial Coefficients Divisible by 10

来源：改编自 Project Euler Problem 322

## 原题意

记 T(m, n) 为满足 n ≤ i < m 且 C(i, n) 能被 10 整除的 i 的个数。

已知 T(10^9, 10^7-10) = 989697000。
求 T(10^18, 10^12-10)。

答案：1998781740。

## 题目

输入 D 和 K，令 m = 10^D，n = 10^K - 10。求 T(m, n)。

## 数据范围

- 1 ≤ D ≤ 18（但 D ≥ K 时仅小参数直接计算）

## 算法

1. **Kummer 定理**：C(i, n) 被 p 整除当且仅当 n + (i-n) 在 p 进制下产生进位。被 10 整除当且仅当同时在 2 进制和 5 进制下产生进位。
2. **数位 DP**：分别统计 2 进制和 5 进制下无进位的 i 个数，用容斥原理求有进位的个数。复杂度 O(log_p(m) · 状态数)。
3. **直接枚举**：仅适用于小 D。

## 改编方向

1. 原题固定 D=18, K=12 → 参数化 D, K
2. 改变除数（如被 100 整除）
3. 改变组合数定义（如排列数）

选择方向 1：参数化 D, K，保留原题核心。
