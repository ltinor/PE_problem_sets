# PE027 — 素数生成二次多项式

来源：改编自 Project Euler Problem 27

## 原题意

欧拉发现了二次多项式 $n^2 + n + 41$ 可以对 $0 \le n \le 39$ 连续生成 40 个素数。之后又发现了 $n^2 - 79n + 1601$ 可以连续生成 80 个素数。

考虑所有形如 $n^2 + an + b$ 的二次多项式，其中 $|a| < 1000$，$|b| \le 1000$，从 $n=0$ 开始计数。找出能连续生成最多素数的多项式，求系数 $a$ 和 $b$ 的乘积。

## 题目

给定两个整数 $A$ 和 $B$，在所有满足 $|a| < A$ 且 $|b| \le B$ 的整数对 $(a, b)$ 中，考虑二次多项式 $n^2 + an + b$。对于每对 $(a, b)$，从 $n=0$ 开始计算该多项式连续生成素数的个数。求能生成最多连续素数的多项式中 $a \times b$ 的值。如果有多组解，输出任意一组对应的乘积。

## 数据范围

- $A, B \le 1000$
- 多组测试数据（每组一行输入 $A$ $B$）

## 算法

- **std**：埃拉托色尼筛法预处理素数表（筛到 $A \cdot B + B$），枚举所有合法的 $a, b$，对每组 $(a,b)$ 直接判素并计数。时间复杂度 $O(A \cdot B \cdot L)$，其中 $L$ 为最长连续素数长度（不超过 $B$）。
- **brute**：同样枚举 $a, b$，但使用朴素 $O(\sqrt{n})$ 判素法。在小范围下与正解一致。
