# 斐波那契数列偶数和

## 题目描述

斐波那契数列定义如下：

$F_1 = 1$, $F_2 = 2$

$F_n = F_{n-1} + F_{n-2}$ （$n \ge 3$）

给定一个整数 $n$，请计算斐波那契数列中 不超过 $n$ 的偶数项之和。

---

## 输入格式

一个整数 $n$ （$1 \le n \le 10^9$）。

---

## 输出格式

输出一个整数，表示不超过 $n$ 的偶数斐波那契数的和。

---

## 样例

### 输入
```
10
```

### 输出
```
10
```


---

## 数据范围

$n ≤ 10^{9}$
