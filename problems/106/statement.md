# 特殊子集和：元检验

## 题目描述

对于一个包含 $n$ 个**严格递增**元素的集合 $A = \\{a_1 < a_2 < \\dots < a_n\\}$，假设它已经满足以下规则2：若子集 $B$ 的元素个数大于子集 $C$，则 $S(B) > S(C)$（$S(X)$ 表示集合 $X$ 的元素之和）。

在所有可能的不相交非空子集对 $(B, C)$ 中，有多少对**仍需要**检验规则1（即 $S(B) \\neq S(C)$，子集和不能相等）？

---

## 输入格式

一行一个整数 $n$。

---

## 输出格式

一行一个整数，表示需要检验规则1的子集对数量。

---

## 样例

### 输入
```
4
```

### 输出
```
1
```

### 输入
```
7
```

### 输出
```
70
```

---

## 数据范围

- $2 \\le n \\le 12$
