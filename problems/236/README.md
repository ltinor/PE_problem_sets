# 236 — Luxury Hampers

来源：改编自 Project Euler Problem 236

## 原题意

供应商 A 和 B 提供 5 种商品，各有不同数量。存在损耗率（变质数/供应数）。对每种商品，B 的损耗率是 A 的 m 倍（m>1）；但总体损耗率 A 是 B 的 m 倍。这种矛盾情况共有 35 个可能的 m，最小为 1476/1475，求最大的 m。

PE 答案：123/59。

## 题目

输入 5 行，每行两个整数 a_i, b_i，分别表示供应商 A 和 B 对商品 i 的供应量。求最大的有理数 m = u/v > 1，使得存在非负整数损耗数 x_i, y_i（0 ≤ x_i ≤ a_i, 0 ≤ y_i ≤ b_i），满足：对所有 i 有 (y_i/b_i) / (x_i/a_i) = m，且 (∑x_i/∑a_i) / (∑y_i/∑b_i) = m。输出最简分数 u/v。

## 数据范围

a_i, b_i ≤ 6000（PE 数据规模）。5 种商品。

## 算法

**std**: 枚举候选 m 值。从范围最小的商品生成所有可能的 m = y·a/(x·b) 作为化简分数，用哈希集去重。对每个候选 m = p/q，检查其余商品的可行性（只需 gcd(a_i·q, b_i·p) ≥ p），再用 meet-in-the-middle 检查总体条件。

时间复杂度：O(R + M·K²)，其中 R 是最小商品的对数枚举量（~3×10⁶），M 是候选 m 数量（~10⁴），K 是 each k_i 搜索上限。

**brute**: 对小数据直接枚举所有 x_i, y_i 组合。

## 改编方向

1. **参数化商品数/供应量**：原题固定 5 种商品，改为输入任意数量。
2. **求所有可能的 m**：改为输出所有 35 个 m 值。
3. **求最小 m**：求满足条件的最小 m（原题已知为 1476/1475）。
4. **多组查询**：支持 T 组数据，预处理加速。
