# 136 — Singleton Difference

来源：改编自 Project Euler Problem 136

## 原题意

求 n < 5×10⁷ 中恰有 1 个不同的等差数列解 (x, y, z) 满足 x² − y² − z² = n 的 n 的个数。

原题答案：2544559。

## 题目

参数化 M：输入 M (≤ 5×10⁷)，求 n < M 中恰有 1 个解的 n 的个数。

## 数据范围

- M ≤ 5×10⁷

## 算法

**std**: 同 PE 135。x = y+d, z = y−d，代入得 n = y(4d−y)。枚举 y 和 d，累加 cnt[n]。遍历 cnt 统计 cnt[n] = 1 的 n 个数。复杂度 O(M log M)。

**brute**: 同思路，枚举 y 和 d，累计计数。复杂度 O(M²)，仅用于小数据对拍。

## 改编方向

1. **参数化 M**：将原题固定 M=5×10⁷ 改为输入参数。
2. **固定 K=1**：原题要求恰好 10 个解（PE 135），本题固定为恰有 1 个解。
3. **小范围版本**：M ≤ 5000 可用于对拍验证。
4. **PE 答案验证**：(M=5×10⁷) 作为测试点，输出 2544559。
