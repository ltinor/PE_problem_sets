# 271 — 立方取模 I

来源：改编自 Project Euler Problem 271

## 原题意

对于正整数 n，求所有满足 1 < x < n 且 x³ ≡ 1 (mod n) 的整数 x 的和 S(n)。

原题：求 S(13082761331670030) = 4617456485273129588。

## 题目

参数化 n：输入一个正整数 n，求 S(n)。

## 数据范围

- n ≥ 2

## 算法

**std**: 对 n 分解质因数，对每个质数幂 p^e 求解 x³ ≡ 1 (mod p^e)（用 Hensel 引理提升），然后用中国剩余定理枚举所有组合，求和。

**brute**: 直接枚举 x 从 2 到 n-1，用快速幂检查 x³ % n == 1。

## 改编方向

1. **参数化 n**：将原题固定的 n = 13082761331670030 改为输入参数。
2. **小数据验证**：n = 91 时答案为 363，可用于对拍。
3. **多组测试点**：构造不同质因数组合的 n，验证 CRT 正确性。
