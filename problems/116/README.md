# 116 — 红色、绿色或蓝色的地砖

来源：改编自 Project Euler Problem 116

## 原题意

将一行黑色方形地砖的一部分替换为彩色长方形地砖：红色（长度2）、绿色（长度3）或蓝色（长度4），颜色不能混合使用，且至少使用一种彩色地砖。原题求长度为 50 时的替换方式总数。答案：20492570929。

## 题目

输入 N，求长度为 N 时，分别使用红/绿/蓝三种颜色（各自单独使用，不混合）的所有替换方式数之和（每种颜色至少使用一块）。

## 数据范围

- 1 ≤ N ≤ 50

## 算法

对每种颜色长度 L（2、3、4）分别 DP：dp[i] = dp[i-1] + dp[i-L]，dp[0] = 1。dp[N] 包含不使用彩色地砖的情况，减去 1 后求和即可。

- dp2[N]：斐波那契数列 F[N+1]
- dp3[N]：三阶递推
- dp4[N]：四阶递推

答案 = (dp2[N] - 1) + (dp3[N] - 1) + (dp4[N] - 1)。

时间复杂度 O(N)，N ≤ 50。

## 改编方向与取舍

### 改编方向
1. **参数化 N** → 输入 N 求方式数（本题采用）
2. **混合使用** → 允许颜色混合（类似 PE 117）
3. **参数化颜色长度** → 输入多个长度
4. **计数模 MOD** → 大 N 取模

### 取舍理由
- 选择参数化 N：保持原题核心 DP 结构，扩展为通用输入
- N ≤ 50：原题范围，答案在 64 位整数范围内
- 不选择混合使用：那是 PE 117 的内容
