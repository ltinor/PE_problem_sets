# 平方数和立方数之和（PE 348）

> ⚠️ 本题面为自动生成的骨架：题目描述取自 PE 原题（中文译文）。
## 原题描述

原题及更多讨论见 [https://projecteuler.net/problem=348](https://projecteuler.net/problem=348)。

许多数可以表示称一个平方数和一个立方数之和，有些数甚至有不止一种表示方式。

考虑能表示成大于1的平方数和立方数之和，且<b>恰好</b>有4种不同的表示方式的回文数。
例如，5229225是一个回文数，而且它恰好可以用4种不同的方式进行表达：

2285<sup>2</sup> + 20<sup>3</sup>
2223<sup>2</sup> + 66<sup>3</sup>
1810<sup>2</sup> + 125<sup>3</sup>
1197<sup>2</sup> + 156<sup>3</sup>
 
求出这类回文数中最小的五个之和。

---

## 输入格式

字符 `PE`：输出原题官方答案（最小五个之和）。
整数 `k`（1 ≤ k ≤ 5）：输出恰好 4 种表示的回文数中最小 k 个之和。

## 输出格式

对应查询的一行整数。

## 样例

### 输入
```
1
```

### 输出
```
5229225
```

（5229225 = 2285² + 20³ = 2223² + 66³ = 1810² + 125³ = 1197² + 156³，题面原例。）

### 输入
```
PE
```

### 输出
```
1004195061
```
