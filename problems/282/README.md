# Ackermann Function

来源：改编自 Project Euler Problem 282

## 原题意

Ackermann 函数 A(m,n) 定义：A(0,n)=n+1；A(m,0)=A(m-1,1)；A(m,n)=A(m-1,A(m,n-1))。求 Σ_{n=0}^{6} A(n,n) mod 14^8。PE 答案：1098988351。

## 题目

给定 m（0 ≤ m ≤ 3）、n（0 ≤ n ≤ 10^9）、M（1 ≤ M ≤ 10^9），求 A(m,n) mod M。

## 数据范围

- 0 ≤ m ≤ 3, 0 ≤ n ≤ 10^9, 1 ≤ M ≤ 10^9
- PE 答案: m=n=6 组合 → 1098988351（mod 14^8）

## 改编思路

### 方向一：限制 m ≤ 3
利用闭式解：A(0,n)=n+1, A(1,n)=n+2, A(2,n)=2n+3, A(3,n)=2^{n+3}-3。✅ 采用

### 方向二：限制 n 较小
Brute-force 递归 A(m,n) 仅限 m≤3,n≤10。失去挑战性。❌ 不采用

### 方向三：原题格式
求 Σ_{n=0}^{K} A(n,n) mod M。对 m≥4 的计算极其困难。❌ 不采用

## 算法

闭式解 + 快速幂取模。A(3,n) = 2^{n+3} - 3 mod M 用快速幂。
