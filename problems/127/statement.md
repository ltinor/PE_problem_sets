# abc 匹配

## 题目描述

数 n 的基 rad(n) 定义为 n 的不同质因数之积。例如 504 = 2³ × 3² × 7，所以 rad(504) = 2 × 3 × 7 = 42。

正整数三元组 (a, b, c) 称为 abc 匹配，当：
1. GCD(a, b) = GCD(a, c) = GCD(b, c) = 1
2. a < b
3. a + b = c
4. rad(abc) < c

给定整数 M，求所有满足 c < M 的 abc 匹配中 ∑c 的值。

---

## 输入格式

一行一个整数 M (1 ≤ M ≤ 120000)。

---

## 输出格式

一行一个整数，表示 ∑c。

---

## 样例

### 输入

```
1000
```

### 输出

```
12523
```

---

## 数据范围

- 1 ≤ M ≤ 120000
