# 变种音乐椅游戏

## 题目描述

一群 $T = k(k-1)/2 + 1$ 个孩子围成一圈坐在椅子上，游戏共进行 $k$ 轮。

游戏开始时，每个孩子坐在自己的椅子上（椅子按顺时针编号 $0,1,\dots,T-1$）。

在第 $i$ 轮（$i=1,2,\dots,k$）中：

1. 随机选出 $i$ 个孩子（所有组合等概率），他们站起来随着音乐跳舞；
2. 音乐停止后，这 $i$ 个孩子随机坐回空出的 $i$ 把椅子（所有排列等概率）。

当 $k$ 轮全部结束后，记 $P(k)$ 为"每个孩子恰好都坐在自己初始座位顺时针方向下一把椅子"的概率。

已知 $P(3) \approx 1.3888888889\times 10^{-2}$。给定 $k$，请计算 $P(k)$。

## 输入格式

一行一个整数 $k$（$1 \le k \le 7$）。

## 输出格式

一行，$P(k)$ 的科学计数法表示：尾数保留 **10 位有效数字**（即小数点后 9 位），并用小写字母 `e` 分隔尾数与指数（指数带正负号，不补前导零）。

## 样例

### 输入

```
3
```

### 输出

```
1.388888889e-2
```

## 数据范围

$1 \le k \le 7$，对应 $1 \le T \le 22$。

## 提示

$P(1)=1$，$P(2)=0.5$。
