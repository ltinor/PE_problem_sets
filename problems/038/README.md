# 全数字的倍数 (Pandigital Multiples)

来源：改编自 Project Euler Problem 38

## 原题意

将 192 分别与 1, 2, 3 相乘得到 192, 384, 576，拼接后得到 1~9 全数字数 192384576。求最大的 1~9 全数字拼接乘积（n>1）。答案：932718654。

## 改编方向

参数化 N。输入 N (1≤N≤9)，求最大的 1~N 全数字拼接乘积。对于 N=9 等价于原题。

## 题目

将一个整数分别乘以 (1, 2, ..., n)，将乘积按顺序拼接成一个数。如果拼接结果恰好包含数字 1 到 N 各一次（N≤9），则称该数为 **1~N 全数字拼接乘积**。

给定 N，求最大的 1~N 全数字拼接乘积。如果不存在，输出 0。

## 数据范围

- N: 1 ≤ N ≤ 9

## 算法

枚举基数 base（1 到 99999），依次乘 1, 2, 3... 并拼接，当拼接长度等于 N 且 n≥2 时检查是否全数字。取最大值。
