# Badugi 扑克计数（PE 369）

来源：改编自 Project Euler Problem 369。

## 原题意

改编自 PE 369。f(n) = 含 4 张百得之(4 点数互异+4 花色互异)的 n 张牌取法数, 求 Σf(n), 4≤n≤13。

## 题目

见 statement.md。参数与输入输出约定以 code/std.cpp 为准。

## 算法

补集转化: 无 Badugi ⟺ 点数-花色二部图最大匹配 ≤3 (Kőnig)。13 轮 DP, 状态 = 16 个花色子集的最大匹配向量, 按张数计数。

## 验证

f(5)=514800 (题面); Σf(4..13) = 862400558448 (官方)
