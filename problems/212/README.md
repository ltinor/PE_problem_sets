# Combined Volume of Cuboids

来源：改编自 Project Euler Problem 212

## 原题意

50000 个与轴平行的立方体，由延迟斐波那契生成器确定参数。求它们的组合体积（并的体积）。

## 题目

给定 K（1 ≤ K ≤ 50000），使用原题描述的延迟斐波那契生成器生成前 K 个立方体，求它们的组合体积。

## 数据范围

- 1 ≤ K ≤ 50000
- PE 答案: K = 50000 → 328968937309

## 算法

三维扫描线：对 x 坐标离散化，每个 x 区间内用 y-z 平面扫描线（y 扫描 + z 线段树）求矩形并面积。线段树维护 z 轴覆盖长度。总复杂度 O(K² log K)（但 dx ≤ 400 限制使实际效率较高）。

## 改编方向

1. **参数化 K**（采用）：将固定 50000 改为可变 K ≤ 50000
2. **参数化生成器**（未采用）：改变生成器参数会破坏与原题的关联
3. **参数化坐标范围**（未采用）：坐标模数固定，改变会影响答案性质
