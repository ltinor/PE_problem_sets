# 153 — 高斯整数除数和

来源：改编自 Project Euler Problem 153

## 原题意

求 n ≤ 10⁸ 的所有高斯整数因子实部之和。

原题答案：17971254122360698165。

## 题目

参数化 N（≤ 10⁸），求 ∑_{n=1}^{N} s(n)，其中 s(n) 为 n 的所有高斯整数因子（a+bi, a>0, b≥0）的实部之和。

## 数据范围

- N ≤ 10⁸

## 算法

**std**: 直接枚举所有 (a, b) 对。
1. 对于 a+bi（a>0, b≥0），其范数 m = a² + b²。
2. a+bi 整除 n 当且仅当 m | n。
3. 对于每个 (a, b)，贡献 a × ⌊N/m⌋ 到答案。
4. 总复杂度：枚举所有 a²+b² ≤ N 的 (a, b) 对，约 πN/4 ≈ 7.85×10⁷ 次迭代。

$$
\text{ans} = \sum_{a=1}^{\lfloor\sqrt{N}\rfloor} a \sum_{b=0}^{\lfloor\sqrt{N-a^2}\rfloor} \left\lfloor\frac{N}{a^2+b^2}\right\rfloor
$$

**brute**: 枚举每个 n ≤ N，再枚举其所有高斯因子，O(N√N)。仅适用于小 N。

## 改编方向

1. **参数化 N**：将固定 N=10⁸ 改为输入参数。
2. **高效枚举**：将 O(N√N) 的朴素方法优化为 O(N) 的直接枚举 (a,b)。
3. **PE 答案验证**：N=10⁸ 时输出 17971254122360698165。
