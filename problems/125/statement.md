# 回文平方和

## 题目描述

回文数是指正读和反读都一样的正整数，如 595、12321。

有些回文数可以表示为连续正整数的平方和。例如：
- 595 = 6² + 7² + 8² + 9² + 10² + 11² + 12²
- 5 = 1² + 2²

给定正整数 N，求所有严格小于 N 且能表示为至少两个连续正整数的平方和的回文数之和。注意每个满足条件的数只计算一次，即使它可以用多种方式表示。

---

## 输入格式

一行一个整数 N。

---

## 输出格式

一行一个整数，表示满足条件的回文数之和。

---

## 样例

### 输入
```
1000
```

### 输出
```
4164
```

**解释**：小于 1000 且满足条件的回文数有：5=1²+2², 55=1²+2²+3²+4²+5², 77=4²+5²+6², 181, 313, 434, 505, 545, 595, 636, 818, 959。它们的和为 4164。

---

## 数据范围

- 1 ≤ N ≤ 10^8
