# 125 — 回文平方和

来源：改编自 Project Euler Problem 125

## 原题意

求小于 10^8 且能表示为至少两个连续正整数的平方和的所有回文数之和（去重）。答案：2906969179。

## 题目

输入 N，求所有小于 N 且能表示为连续平方和（至少两项）的回文数之和（每个数只计一次）。

## 数据范围

- 1 ≤ N ≤ 10^8

## 算法

枚举连续平方和的起始点 i，累加 i² + (i+1)² + ... 直到 ≥ N。对每个和检查是否为回文数，用哈希集合去重。起始点 i 最大为 √N，内层循环在 N=10^8 时总操作数约 10^7 量级，可在 10ms 内完成。

回文判断：转为字符串后双指针比较。

验证：N=10^8 → sum=2906969179。

## 改编方向与取舍

### 改编方向
1. **参数化 N** → 输入 N 求和（本题采用）
2. **区间统计** → 求 [L,R] 内满足条件的回文数和
3. **大范围 N** → N ≤ 10^12，需优化枚举
4. **附加条件** → 要求最多 / 最少项数限制

### 取舍理由
- 选择参数化 N：N=10^8 包含原题
- 双循环枚举：实现简单，N=10^8 时 ~10^7 次检查完全可行
- 哈希集合去重：保证正确性，避免重复计数
