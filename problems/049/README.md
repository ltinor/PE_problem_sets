# 素数重排 (Prime Permutations)

来源：改编自 Project Euler Problem 49

## 原题意

找出除 1487, 4817, 8147 外另一组四位素数等差数列，三项互为其数字重新排列。将三项拼接成的 12 位数作为答案。答案：296962999629。

## 改编方向

参数化位数 D（D=4,5,6）。输入 D，求 D 位素数中满足等差+互为排列的三元组（排除已知例子 1487-4817-8147）。输出拼接后的 3×D 位数。

## 题目

给定位数 D，找出由三个 D 位素数组成的三元组 (a, b, c)，满足：
1. a, b, c 均为 D 位素数
2. b - a = c - b（即构成等差数列，差值 > 0）
3. a, b, c 的三个数字互为排列（即包含相同的数字）
输出将 a, b, c 按升序拼接得到的 3×D 位数。如果有多组解，输出拼接后最小的那组。

注意：对于 D=4，需要排除已知的例子 1487, 4817, 8147。

## 数据范围

- D: 4 ≤ D ≤ 6

## 算法

std: 埃氏筛生成素数 → 按数字签名分组 → 每组内找等差数列。O(10^D log log 10^D)。

brute: 逐个数判断素数 → 分组 → 找等差数列。O(10^D √(10^D))。
