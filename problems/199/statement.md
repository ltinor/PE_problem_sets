# 迭代放圆

## 题目描述

在一个半径为1的大圆内放入三个等大的小圆，使得小圆两两相切且都与大圆相切。此时大圆内有四个未被覆盖的空隙。

在每一轮迭代中，我们在每个空隙中放入尽可能大的圆（与空隙的三条边界相切），新放入的圆又会创造更多空隙。

给定迭代轮数 K（以初始四个空隙为第0轮），求K轮迭代后，大圆内未被任何圆覆盖的面积占大圆面积的比例。

答案保留8位小数（四舍五入）。

---

## 输入格式

一行，一个整数 K（0 ≤ K ≤ 10）。

---

## 输出格式

一个实数，保留8位小数。

---

## 样例

### 输入
```
3
```

### 输出
```
0.06790342
```

---

## 数据范围

- 0 ≤ K ≤ 10
- PE 答案: K=10 → 0.00396087
