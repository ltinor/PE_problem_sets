# 220 — 海韦龙形曲线

来源：改编自 Project Euler Problem 220

## 原题意

D₀ = "Fa"，通过字符串重写规则：
- "a" → "aRbFR"
- "b" → "LFaLb"
推导 D_n。指令：F=前进一单位，L=左转90°，R=右转90°，a/b 忽略。初始位置 (0,0)，方向向上。
求 D₅₀ 中经过 10^12 步后的光标位置。原题答案：139776,963904。

## 题目

参数化 (n, K)：输入 n 和 K，求 D_n 中经过 K 步后的光标位置。

## 数据范围

- 0 ≤ n ≤ 50
- 0 ≤ K ≤ 2^n

## 算法

**std**: 递归 + 跳过优化。
- D_n 中 F 总数为 2^n。
- 预计算每个级别 n 上 'a' 和 'b' 展开的净位移和方向变化（Transform 结构）。
- 递归遍历时，若剩余步数 K ≥ 当前展开的 F 总数，直接跳过整个展开（O(1)），否则递归进入下一级。
- D_n = "F" + A_n，先处理初始 F，再递归处理 A_n。
- 时间复杂度 O(n × 递归深度)，对于 n=50 极快。

**brute**: 对 n ≤ 12 直接生成完整字符串并模拟。

## 改编方向

1. **参数化 (n, K)**：将固定 (n=50, K=10^12) 改为可变输入。
2. **递归跳跃**：利用预计算的变换信息批量跳过，避免逐字符模拟。
3. **PE 答案守护**：(n=50, K=10^12) 时输出 139776,963904。
