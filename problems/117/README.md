# 117 — 红色、绿色和蓝色的地砖

来源：改编自 Project Euler Problem 117

## 原题意

使用黑色方块（长度 1）、红色方块（长度 2）、绿色方块（长度 3）、蓝色方块（长度 4）铺满长度为 50 的一行。原题求总方式数。答案：100808458960497。

## 题目

输入 N，求用长度分别为 1、2、3、4 的方块铺满长度为 N 的一行的方式数。

## 数据范围

- 1 ≤ N ≤ 50

## 算法

DP 递推：dp[i] = dp[i-1] + dp[i-2] + dp[i-3] + dp[i-4]，dp[0] = 1。

dp[i-1] 对应黑色（长度 1），dp[i-2]/dp[i-3]/dp[i-4] 分别对应红/绿/蓝。

时间复杂度 O(N)。

## 改编方向与取舍

### 改编方向
1. **参数化 N** → 输入 N 输出方式数（本题采用）
2. **参数化颜色种类** → 输入多个长度
3. **大 N + 取模** → N ≤ 10^6，mod 1e9+7
4. **不允许全黑** → 减去 1

### 取舍理由
- 选择参数化 N：与 PE 116 一致，保持简单
- N ≤ 50：原题范围，答案在 64 位范围内
- 不取模：保持与原题答案一致
