# 全数字的乘积

改编自 [Project Euler Problem 32](https://projecteuler.net/problem=32)

## 原题

找出所有 a × b = c 的等式，使得 a, b, c 合起来恰好使用数字 1~9 各一次。求所有满足条件的乘积 c 的和（去重）。

**原题答案：45228**

## 改编

将固定使用数字 1~9 参数化为使用数字 1~N（1 ≤ N ≤ 9）。输入 N，求所有满足条件的乘积之和。

## 算法

std：枚举 a 和 b 的位数组合，在每种组合下暴力枚举 a 和 b，验证全数字性，用 set 去重。

brute：生成 1~N 的所有排列，枚举分割点，验证 a × b = c。

两种算法互为验证。
