# Maximum Path Sum II

来源：改编自 Project Euler Problem 67

## 原题意

从一个100行的数字三角形顶端出发，不断移动到下一行与其相邻的数直至到达底部，求所能得到的最大路径和。

这是第18题的强化版，总路径数为 2^99，无法穷举。

## 题目

给定一个 R 行的数字三角形，从顶部出发，每次移动到下一行相邻的数，求到达底部时的最大路径和。

## 数据范围

三角形行数 R ≤ 100，每个数为 0~99 的非负整数。

## 算法

自底向上 DP：dp[i][j] = a[i][j] + max(dp[i+1][j], dp[i+1][j+1])。

时间复杂度：O(R²)，空间复杂度 O(R²)。

## 改编说明

原题依赖 triangle.txt 文件作为输入，改为从标准输入读取，支持参数化 R（行数）。这样题目更灵活，可适配不同规模的三角形。

brute：对较小的 R（≤15），使用递归枚举所有路径来验证 std 正确性。对较大 R 时 brute 和 std 答案一致（因为 DP 是精确解）。
