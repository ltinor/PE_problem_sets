# PE 957 · Point Genesis（点·创世纪）— 简单版本

来源：改编自 Project Euler Problem 957

## 原题意

平面上初始有 3 个红点、2 个蓝点，其余为白点。每天构造所有过红点与蓝点的直线，任意两条不同直线相交处的白点变为蓝点。$g(n)$ 为 $n$ 天后的最大蓝点数。求 $g(16)$。

## 简单版本改动

原题点数呈超指数增长（$g(16)$ 极大）。改为：用精确几何模拟求小 $n$ 的 $g(n)$。

## 缩数据范围

$1 \le n \le 4$（$g(4)=1643$）。

## 算法

齐次坐标精确几何模拟（全整数、无浮点误差）：

- 点与直线都用齐次三元组 $(x:y:z)$ / $(a,b,c)$ 表示；
- 过两点 $P,Q$ 的直线 $=P\times Q$（叉积）；两直线交点 $=\ell_1\times\ell_2$；
- 两点相同 $\Leftrightarrow$ 叉积为零向量；$z=0$ 为无穷远点（平行线交点，不计）。

初始取一般位置（3 红 + 2 蓝五点无三点共线），保证达到最大计数。每天枚举红-蓝直线（去重），再枚举直线对求交点，去掉红点/已有蓝点得到新蓝点。复杂度随天数超指数增长，故仅限 $n\le4$。

## 验证结果

| 验证点 | 期望 | 实际 | 结果 |
|--------|------|------|------|
| $g(1)$ | 8 | 8 | ✓ |
| $g(2)$ | 28 | 28 | ✓ |

继续迭代：$g(3)=183$，$g(4)=1643$。
