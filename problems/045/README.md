# 三、五、六边形数 (Triangular, Pentagonal, and Hexagonal)

来源：改编自 Project Euler Problem 45

## 原题意

三角形数 T_n = n(n+1)/2，五边形数 P_n = n(3n-1)/2，六边形数 H_n = n(2n-1)。已知 T_285 = P_165 = H_143 = 40755。求下一个同时是三角形数、五边形数和六边形数的数。

原题答案：1533776805。

## 改编方向

将问题参数化：输入 K，求第 K 个同时是三角形数、五边形数和六边形数的数。规定 T_1 = P_1 = H_1 = 1 是第 1 个。

## 题目

给定正整数 K，求第 K 个同时是三角形数、五边形数和六边数形的正整数。

## 数据范围

- K ≤ 3
- 答案在 64 位有符号整数范围内

## 算法

所有六边形数也是三角形数（H_n = T_{2n-1}），因此只需检查六边形数是否是五边形数。迭代生成六边形数 H_n = n(2n-1)，对每个 H_n 解方程 x(3x-1)/2 = H_n 判断是否为整数。时间复杂度与答案大小成正比。

brute 使用独立实现：迭代三角形数，用相同的五边形数判定方法。

## 验证

- 原题答案：K=2 → 40755 ✓，K=3 → 1533776805 ✓
