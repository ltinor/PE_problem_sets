# 非传递性骰子集合

## 题目描述

考虑三枚六面骰子，每面的点数均为 1 到 N 之间的整数。

两名玩家进行游戏：先手选一枚骰子，后手选另一枚，各自掷出，点数大者获胜。
若无论先手选哪枚，后手总能选一枚有超过 50% 胜率的骰子，则称这三枚骰子构成**非传递性骰子集合**。

形式化：骰子 A 击败骰子 B 当且仅当等概率随机掷出时 P(A > B) > 1/2。
{A, B, C} 构成非传递性集合当且仅当 A 击败 B、B 击败 C、C 击败 A。

给定 N，求不同非传递性骰子集合的数量（内部排列视为同一集合）。

---
## 输入格式

一个整数 N。

---
## 输出格式

一个整数。

---
## 样例

### 输入
```
7
```

### 输出
```
9780
```

---
## 数据范围

- N ≤ 7：暴力算法
- N = 30：特殊大测试点
