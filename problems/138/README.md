# 138 — Special Isosceles Triangles

来源：改编自 Project Euler Problem 138

## 原题意

求前 12 个满足 h = b ± 1 的等腰三角形的 L 之和（b 为底边长，L 为腰长）。

原题答案：1118049290473932。

## 题目

参数化 K：输入 K (≤ 12)，求前 K 个满足条件的等腰三角形的 L 之和。

## 数据范围

- K ≤ 12

## 算法

**std**: 设 b=2k，h = 2k±1。勾股定理得 L² = 5k²±4k+1。乘以 5 得 (5k±2)² − 5L² = −1。解负 Pell 方程 x²−5y²=−1，基础解 (2,1)，递推 (x',y')=(9x+20y, 4x+9y)。L=y，当 x≡2 或 3 (mod 5) 时三角形有效。取前 K 个 L 求和。

**brute**: 相同 Pell 递推。

## 改编方向

1. **参数化 K**：将原题固定 K=12 改为输入参数。
2. **Pell 方程递推**：利用 x²−5y²=−1 的递推性质生成解。
3. **PE 答案验证**：(K=12) 作为测试点，输出 1118049290473932。
