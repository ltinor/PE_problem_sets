# 特殊等腰三角形

## 题目描述

考虑底边长为 b，腰长为 L 的等腰三角形。其高记为 h。

求满足 h = b ± 1 且 b, L 均为正整数的等腰三角形。

将这些三角形按某种顺序排列，给定整数 K，求前 K 个三角形的 L 之和。

---

## 输入格式

一行一个整数 K (1 ≤ K ≤ 12)。

---

## 输出格式

一行一个整数，表示前 K 个满足条件的等腰三角形的 L 之和。

---

## 样例

### 输入

```
1
```

### 输出

```
17
```

（b=16, L=17, h=15 = b−1）

### 输入

```
2
```

### 输出

```
322
```

（17 + 305 = 322）

---

## 数据范围

- 1 ≤ K ≤ 12
