# PE 950 海盗宝藏（简单 / 缩小版）

来源：改编自 Project Euler Problem 950 "Pirate Treasure"。

## 原题意

`n` 名海盗分 `C` 枚完全相同的不可分割金币，每人嗜血度均为 `p`。分配流程：

1. 资历最深的海盗提出分配方案；
2. 所有海盗（含提案者）投票；
3. 若 **至少一半** 海盗同意，方案生效；
4. 否则提案者走跳板，由次深者重新提案，依此类推。

海盗幸福度：未存活为 `-∞`；存活则为 `c + p·w`，其中 `c` 是所得金币数，
`w` 是全程走跳板的人数。海盗贪婪（最大化幸福度）、无情、完全理性。

定义 `c(n,C,p)` 为最终幸存者中资历最深者的金币数，`w(n,C,p)` 为走跳板总人数，
`T(N,C,p) = Σ_{n=1..N} ( c(n,C,p) + w(n,C,p) )`。

原题求 `Σ_{k=1..6} T(10^16, 10^k+1, 1/√(10^k+1))` 的末 9 位，数据量过大，
需要闭式/周期分析，难度过高。本仓库提供 **缩小版**：直接读取小参数，
用可计算的后向归纳算法算出 `T(N,C,p)`。

## 题目（缩小版）

输入一行 `N C m`（`p = 1/√m`，保证 `m` 非完全平方数），输出 `T(N,C,p)`。

## 数据范围

- 小：`N ≤ 60`，`C ≤ 30`，`m ≤ 300`
- 中：`N ≤ 2000`，`C ≤ 200`，`m ≤ 5000`
- 大：`N ≤ 100000`，`C ≤ 1000`，`m ≤ 10^6`

## 算法

后向归纳（backward induction），复杂度 `O(N·C)`。

- `n = 1`：唯一海盗独占 `C` 枚，`c = C`，`w = 0`。
- 设 `(n-1)` 人局中走跳板者为 `w` 人（`w` 名注定死亡者），幸存者各持若干金币
  （用频率数组 `freq[v]` 记录持 `v` 枚金币的幸存者人数）。
- `n` 人局中提案者需要 `ceil(n/2)` 票：自己 1 票 + `w` 名注定死亡者的免费票
  （`0 > -∞`）+ 再收买若干幸存者。
  - 若免费票已够，提案者独占全部金币，`w = 0`。
  - 否则，被收买者 `j` 的保留幸福度为 `x_j + p·(1+w)`，其中 `x_j` 是其现持金币，
    `1+w` 是若拒绝后的走跳板总数。因 `p = 1/√m` 为无理数，
    需付 `x_j + floor((1+w)/√m) + 1` 枚。
  - 提案者收买持币最少的 `votes` 名幸存者；若总花费 `≤ C` 则幸存并结算新的
    频率数组，否则提案者走跳板（`w += 1`，幸存者状态不变）。

`isqrt128` 用整数开方精确计算 `floor((1+w)/√m)`，全程整数运算，无浮点误差。

## 验证

- `T(30, 3, 1/√3)  = 190`  → 输入 `30 3 3`
- `T(50, 3, 1/√31) = 385`  → 输入 `50 3 31`
- `T(1000, 101, 1/√101) = 142427` → 输入 `1000 101 101`
