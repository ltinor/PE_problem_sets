# 942 梅森平方根（简单版本）

来源：改编自 Project Euler Problem 942 (Mersenne's Square Root)

## 原题意

p=2^q−1（梅森数），R(q) 为满足 x²≡q (mod p) 的最小正整数 x。原题求 R(74207281) mod 10^9+7。

## 题目（简单版本）

输入一个整数 q，输出 R(q)（无解输出 -1）。

## 数据范围

- 简单版本：2 ≤ q ≤ 62（p=2^q−1 可装入 128 位）。

## 算法

p≡3 (mod 4)，故 x=q^((p+1)/4) mod p（对 q 连续平方 q−2 次）；若 x²≡q 则 R=min(x,p−x)，
否则退回线性搜索。

验证：R(5)=6，R(17)=47569。
