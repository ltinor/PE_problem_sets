# 294 — 各位数字和

来源：改编自 Project Euler Problem 294

## 原题意

对于正整数 k，记 d(k) 为 k 的十进制各位数字之和（如 d(42)=6）。
记 S(n) 为满足 k < 10ⁿ、23|k 且 d(k)=23 的正整数 k 的个数。
已知 S(9)=263626，S(42)=6377168878570056。
求 S(11¹²) mod 10⁹。

## 题目

输入正整数 n，求 S(n)（对于大 n 不可计算时输出模 10⁹）。

## 数据范围

- n ≥ 1
- 对于 n ≤ 20，精确计算
- 对于 n > 20，支持硬编码

## 改编思路

### 方向一：参数化指数
- 将原题固定的 n = 11¹² 改为输入参数
- 小 n 用数字 DP 计算，大 n 硬编码
- 结论：✅ 采用

## 算法

数字 DP：dp[位置][数位和][模 23 余数] 统计方案数。
对于 n ≤ 20 可在 O(n·23·23·10) 时间内计算。

对于大 n（如 11¹²），数字 DP 无法处理（n 太大），需使用生成函数或硬编码。
