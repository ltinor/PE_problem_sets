# 三个相似三角形（PE 299 简化版）

来源：改编自 [Project Euler Problem 299](https://projecteuler.net/problem=299)

## 原题意

给定四个整数坐标点 A(a,0)、B(b,0)、C(0,c)、D(0,d)，其中 0 < a < b，0 < c < d。
在直线 AC 上取整数坐标点 P，使得三角形 ABP、CDP、BDP 两两相似。

可证仅当 a=c 时才可能存在这样的 P。于是问题转化为：统计满足 b+d < N 的三元组 (a,b,d)
（a=c，且 a<b，a<d）中，存在整数点 P 使三个三角形两两相似的个数。

原题要求 N = 100 000 000，答案 549 936 643。

## 简化（缩数据）

原题 N 高达 10^8，需要筛法级别的数论算法。本 OJ 版本将 N 缩小到 **≤ 100000**。

- 验证点 1：N = 100 时答案为 **92**（与题目给出的 "b+d < 100 有 92 个" 一致）。
- 验证点 2：N = 100000 时答案为 **320471**（与题目给出的 "b+d < 100000 有 320471 个" 一致）。

## 题目

输入一个整数 N，输出满足条件的三元组 (a,b,d) 的个数。

## 数据范围

- 1 ≤ N ≤ 100000

## 算法

设整数点 P = (u, v)（在直线 AC 上，u+v=a，1≤u<a），并令 α=b-a、β=d-a。

把三个三角形 ABP、CDP、BDP 的边长平方写出来（均为整数）：

- △ABP：`(b-a)^2`、`2v^2`、`(b-u)^2+v^2`
- △CDP：`(d-a)^2`、`2u^2`、`u^2+(d-v)^2`
- △BDP：`b^2+d^2`、`(b-u)^2+v^2`、`u^2+(d-v)^2`

三边平方排序后，两三角形相似当且仅当对应三边平方成比例。代数化简后，三元组 (a,b,d)
合法当且仅当存在 u（v=a-u）满足：

```
α·β = 2uv   且   (u == v 或 α == β)
```

据此分成两个互不相交的族：

1. **u = v**：a 为偶数，α·β = a²/2（即 (b-a)(d-a) = a²/2），且 α+β < N-2a。
   枚举 a（偶数）并枚举 a²/2 的因子 α 统计即可。
2. **α = β**：b = d = a+k，且 k² = 2uv 存在整数解，即 a² - 2k² 是完全平方数 s²，
   且 2(a+k) < N。枚举 a 和 k 判断即可。

时间复杂度 O(N²)（因子枚举与整数开方均可 O(1)/O(√a)），在本数据范围 N ≤ 10^5 下毫秒级通过。

`code/std.cpp` 为上述算法实现；`code/brute.cpp` 为 O(N^4) 的直接几何暴力（只用于小 N 对拍）。
两版在 N=1..300 全量对拍一致，并与题目两个验证点（92、320471）吻合。
