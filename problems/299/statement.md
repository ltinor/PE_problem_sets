# 三个相似三角形

## 题目描述

给定四个坐标为整数的点 A(a,0)、B(b,0)、C(0,c)、D(0,d)，其中 0 < a < b 且 0 < c < d。

在直线 AC 上选择一个坐标为整数的点 P，使得三角形 ABP、CDP、BDP 两两相似。

可以证明，仅当 a = c 时这三个三角形才可能相似。

因此，给定 a = c，统计满足 b + d < N 的三元组 (a,b,d)（其中 a < b 且 a < d）中，
使得 AC 上至少存在一个整数坐标点 P、让三个三角形 ABP、CDP、BDP 两两相似的个数。

例如 (a,b,d) = (2,3,4) 时，点 P(1,1) 满足条件。注意 (2,3,4) 与 (2,4,3) 视为两个不同的三元组。

---

## 输入格式

一行一个整数 N。

---

## 输出格式

一行一个整数，表示满足条件的三元组 (a,b,d) 的个数。

---

## 样例

### 输入

```
100
```

### 输出

```
92
```

### 输入

```
10
```

### 输出

```
2
```

---

## 数据范围

- 1 ≤ N ≤ 100000
