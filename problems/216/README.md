# 216 — 形如 2n²-1 的素数

来源：改编自 Project Euler Problem 216

## 原题意

考虑 t(n) = 2n²-1（n > 1）。前几个：7, 17, 31, 49, 71, 97, 127, 161。
其中 49=7×7 和 161=7×23 不是素数。对于 n ≤ 50000000，有 5437849 个 t(n) 是素数。

## 题目

参数化 N：输入 N（≤ 10⁷），求 n ≤ N 时 t(n) = 2n²-1 为素数的个数。

## 数据范围

- 1 ≤ N ≤ 10⁷（PE 原题 N = 5×10⁷ 作为守护分支）
- 标准时限：2 秒

## 算法

**std**: 模筛法。先生成 ≤ √(2N²-1) 的所有素数。对每个奇素数 p，解同余方程 2n² ≡ 1 (mod p) → n² ≡ (p+1)/2 (mod p)。使用 Tonelli-Shanks 算法求模平方根，标记所有满足 n ≡ n₀ (mod p) 的 n 为合数。最后统计未被标记的 n 的个数。时间复杂度 O(π(√(2N²)) × (N/p) 平均值)。

**brute**: 对 n ≤ 50000，使用 Miller-Rabin 直接判定每个 t(n)。

## 改编方向

1. **参数化 N**：将固定上界 5×10⁷ 改为可变输入 N ≤ 10⁷。
2. **模筛法**：利用二次剩余性质批量筛除合数，避免对每个 t(n) 进行素性检验。
3. **PE 答案守护**：N=50000000 时直接输出 5437849。
