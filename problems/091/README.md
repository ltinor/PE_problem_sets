# Right Triangles with Integer Coordinates

来源：改编自 Project Euler Problem 91

## 原题意

点 $P(x_1, y_1)$ 和 $Q(x_2, y_2)$ 的坐标均为整数，与原点 $O(0,0)$ 构成三角形 $\triangle OPQ$。

当 $0 \le x_1, y_1, x_2, y_2 \le 2$ 时，恰好能构造出 $14$ 个直角三角形。

若 $0 \le x_1, y_1, x_2, y_2 \le 50$，能构造出多少个直角三角形？（答案：14234）

## 题目

给定整数 $N$，求坐标在 $[0, N]$ 范围内的整点 $P(x_1, y_1)$ 和 $Q(x_2, y_2)$ 与原点 $O(0,0)$ 能构成多少个直角三角形。其中直角可能位于 $O$、$P$ 或 $Q$。

## 数据范围

$0 \le N \le 50$

## 算法

枚举 $P$ 和 $Q$，检查三个直角条件（向量点积为零），最后除以 $2$（因为 $P$ 和 $Q$ 的对称性）。

时间复杂度 $O(N^4)$。
