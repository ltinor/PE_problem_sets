# 格点直角三角形

## 题目描述

点 $P(x_1, y_1)$ 和 $Q(x_2, y_2)$ 的坐标均为整数，与原点 $O(0,0)$ 构成三角形 $\triangle OPQ$。

当 $0 \le x_1, y_1, x_2, y_2 \le 2$ 时，恰好能构造出 $14$ 个直角三角形。

现在给定整数 $N$，求坐标在 $[0, N]$ 范围内的整点 $P$ 和 $Q$ 与原点 $O(0,0)$ 能构成多少个直角三角形。

---

## 输入格式

一行一个整数 $N$。

---

## 输出格式

一行一个整数，表示能构成的直角三角形数量。

---

## 样例

### 输入

```
2
```

### 输出

```
14
```

---

## 数据范围

$0 \le N \le 50$
