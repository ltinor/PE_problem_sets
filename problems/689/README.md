# Binary Series (二进制级数, 截断版)

来源：改编自 Project Euler Problem 689。

## 原题意

x 均匀分布于 [0,1)，d_i(x) 为二进制小数第 i 位（独立同分布 Bern(1/2)）。
f(x) = Σ_{i≥1} d_i(x)/i²。求 P(f(x) > 0.5)，8 位小数 = 0.56565454（官方）。

## 改编（缩规模落地）

定义**截断级数** f_D(x) = Σ_{i=1}^{D} d_i(x)/i²，p_D(a) = P(f_D(x) > a)。
给定 D 与 a，精确计算 p_D(a)。原题对应 D→∞ 的极限：
p_D(0.5) 随 D 增大收敛于官方值（D=20: 0.5410，D=42: 0.5536，D→∞: 0.56565454，
偏差 ~1/D 为截断尾项影响，符合理论）。

## 数据范围

- 2 ≤ D ≤ 42（D=42 时 MITM 约 0.5s）
- 0 ≤ a ≤ 2（十进制小数）
- PE 分支输出原题官方答案 0.56565454（D→∞ 参考）

## 算法（code/std.cpp，精确无浮点）

meet-in-the-middle：元素权重 (L/i)²（L = lcm(1..D)，D ≤ 42 时所有子集和
≤ 1.64·L² < i128 上限），两半各 2^(D/2) 个子集和，排序 + 二分计数。
严格不等式阈值 floor(a·L²) 由 a 的十进制**精确解析**（无浮点）。
p = cnt/2^(D−1)，分母为 2 的幂 ⟹ 十进制展开有限，输出 12 位精确（四舍五入）。

## 验证

- D ≤ 18 与 2^(D−1) 直接枚举逐位一致（含 a = 0.5/0.25/0.75/1 多组）✓
- 单调性、补对称（f ↦ Z−f）恒等式抽检 ✓
- p_D(0.5) 收敛于原题官方值 ✓
