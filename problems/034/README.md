# PE034 — 数字阶乘和（Digit Factorials）

来源：改编自 Project Euler Problem 34

## 原题意

$145$ 是一个奇特的数，因为 $1! + 4! + 5! = 1 + 24 + 120 = 145$。求所有等于其各位数字的阶乘之和的数（不包括 $1$ 和 $2$）的总和。

原题答案：$40730$（$145 + 40585$）。

## 改编方向

- **参数化**：原题为固定上界（所有满足条件的数之和），改编为输入参数 $N$，求 $\le N$ 中所有满足条件的数之和。
- **多组输入**：支持 $T$ 组测试数据。
- **数据范围**：$N \le 10^6$。

## 算法

- **std**：预计算 $0! \sim 9!$。由于 $7 \times 9! = 2540160 > 10^6$，直接枚举 $1 \sim \min(N, 10^6)$，判断各位数字阶乘之和是否等于自身。使用前缀和数组 $O(1)$ 回答每个查询。总复杂度 $O(\max N + T)$。
- **brute**：相同算法，独立实现，每查询一次重新枚举。

## PE 原答案验证

输入 $N = 10^6$，输出应为 $40730$。
