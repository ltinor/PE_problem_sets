# 152 — 平方倒数和

来源：改编自 Project Euler Problem 152

## 原题意

求 {2, 3, ..., 80} 的子集中，元素平方倒数之和为 1/2 的子集个数。

原题答案：301。

## 题目

参数化 N（≤ 80），求 {2, 3, ..., N} 中满足条件的子集数。

## 数据范围

- N ≤ 80

## 算法

**std**: 分数通分 + DFS + 剪枝。
1. 计算所有分母 2², 3², ..., N² 的最小公倍数 L。
2. 将所有分数通分为以 L 为分母的整数权重 w_k = L/k²。
3. 目标值 T = L/2。
4. 从大到小 DFS：每个数可选或不选，使用 BigInt 精确表示。
5. 剪枝：当前和 > T 则剪枝；当前和 + 剩余所有和 < T 则剪枝。
6. 使用自定义 256 位大整数（BigInt）支持精确计算。

**brute**: 对于 N ≤ 25，使用位掩码枚举所有子集，分数约分后判断是否等于 1/2。

## 改编方向

1. **参数化 N**：将固定 N=80 改为输入参数。
2. **DFS + 剪枝**：使用从大到小的搜索顺序和上下界剪枝。
3. **BigInt**：实现 256 位大整数以支持精确的 LCM 和权重计算。
4. **PE 答案验证**：N=80 时输出 301。
