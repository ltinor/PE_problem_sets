# 素数平方余数

## 题目描述

设 p_n 为第 n 个素数（p_1=2, p_2=3, p_3=5, ...）。定义 r_n 为 (p_n − 1)^n + (p_n + 1)^n 除以 p_n² 的余数。

例如，当 n=3 时，p_3=5，(5−1)^3+(5+1)^3 = 4^3+6^3 = 64+216 = 280。280 mod 25 = 5。

给定一个整数 T，求最小的 n 使得 r_n > T。

---

## 输入格式

一行一个整数 T。

---

## 输出格式

一行一个整数 n，表示最小的使得余数 r_n > T 的 n。

---

## 样例

### 输入
```
100
```

### 输出
```
5
```

**解释**：n=1 时 r=2, n=2 时 r=6, n=3 时 r=5, n=4 时 r=2, n=5 时 p_5=11, r=2×5×11=110 > 100。

---

## 数据范围

- 1 ≤ T ≤ 10^12
