# 123 — 素数平方余数

来源：改编自 Project Euler Problem 123

## 原题意

设 p_n 为第 n 个素数，r = (p_n−1)^n + (p_n+1)^n mod p_n²。求使 r 首次超过 10^10 的 n。答案：21035。

## 题目

输入阈值 T，求使余数 r 首次超过 T 的最小 n。

## 数据范围

- 1 ≤ T ≤ 10^12

## 算法

数学推导：
- 当 n 为偶数时：(p−1)^n + (p+1)^n ≡ 2 (mod p²)，r=2，不会超过 T（T≥1）
- 当 n 为奇数时：(p−1)^n + (p+1)^n ≡ 2np (mod p²)

因此只需检查奇数 n。对于奇数 n，r = 2·n·p_n mod p_n²。当 2·n·p_n < p_n² 时（即 2n < p_n），r = 2·n·p_n。实际中，对于 n ≤ 30000，p_n ≈ 350000，而 2n ≈ 60000 < p_n，所以直接使用 r = 2·n·p_n。

线性筛素数到 ~400000，遍历奇数 n 直到 2·n·p_n > T。时间复杂度 O(max_n)。

验证：T=10^10 → n=21035，p_21035=237673，r=2×21035×237673=10^10。

## 改编方向与取舍

### 改编方向
1. **参数化 T** → 输入 T 求最小 n（本题采用）
2. **区间查询** → 求 T 在 [L,R] 内时对应的 n
3. **余数求和** → 求前 N 项的余数和
4. **大范围 T** → T ≤ 10^18，需更高精度

### 取舍理由
- 选择参数化 T：T=10^10 包含原题
- 使用公式推导：避免 O(n log p) 的快速幂，直接 O(n) 计算
- 筛素数至 400000：覆盖 T≤10^12 所需的所有 n
