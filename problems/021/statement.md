# 亲和数

## 题目描述

记 $d(n)$ 为 $n$ 的所有真约数（小于 $n$ 且整除 $n$ 的正整数）之和。

如果 $d(a) = b$ 且 $d(b) = a$（其中 $a \neq b$），则称 $a$ 和 $b$ 是一对**亲和数**。

例如，$220$ 的真约数为 $1,2,4,5,10,11,20,22,44,55,110$，所以 $d(220)=284$；
而 $284$ 的真约数为 $1,2,4,71,142$，所以 $d(284)=220$。因此 $220$ 和 $284$ 是一对亲和数。

现在给出 $T$ 个查询，每个查询给定一个整数 $N$，请输出所有小于 $N$ 的亲和数之和。

---

## 输入格式

第一行一个整数 $T$，表示查询数量。

接下来 $T$ 行，每行一个整数 $N$。

---

## 输出格式

输出 $T$ 行，每行一个整数，表示对应查询的答案。

---

## 样例

### 输入
```
1
300
```

### 输出
```
504
```

（小于 300 的亲和数只有 220 和 284，它们的和为 504。）

---

## 数据范围

- $T \le 200$
- $1 \le N \le 10^5$
