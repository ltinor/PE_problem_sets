# 整数边长直角三角形 (Integer Right Triangles)

来源：改编自 Project Euler Problem 39

## 原题意

在 p ≤ 1000 中，求哪个周长 p 有最多的整数边长直角三角形解（(a,b,c) 满足 a²+b²=c²，a+b+c=p）。答案：p=840（8组解）。

## 改编方向

参数化 P。输入 P（P≤5000），输出 p≤P 中解最多的周长（并列取最小 p）。支持多组输入。

## 题目

考虑三边长 {a,b,c} 均为整数的直角三角形，记其周长为 p=a+b+c。对于给定的 P，在 p≤P 中，哪个 p 拥有最多的整数边长直角三角形解？如果有多个 p 的解数相同，输出最小的 p。

## 数据范围

- P: 1 ≤ P ≤ 5000
- 多组测试数据，每行一个 P

## 算法

std: 使用欧几里得公式生成勾股数：a=k(m²-n²), b=k(2mn), c=k(m²+n²)，其中 m>n, gcd(m,n)=1, m-n 为奇数。枚举 m,n,k，统计每个周长 p 的解数。预计算后 O(1) 回答查询。复杂度 O(P log P)。

brute: 枚举 a, b ≤ P/2，判断 a²+b²=c²，O(P²)。用于小范围对拍验证。
