# 幂的数字和

来源：改编自 Project Euler Problem 56

## 原题意

对于 $a, b < 100$，求 $a^b$ 的最大各位数字和。原题答案：972。

## 题目

给定 $A, B$，求 $1 \\leq a < A, 1 \\leq b < B$ 范围内所有 $a^b$ 的各位数字和的最大值。

## 数据范围

$2 \\leq A, B \\leq 100$

## 算法

大整数乘法 + 数字求和。

时间复杂度：$O(A \\cdot B \\cdot L)$，其中 $L$ 为大整数长度（$100^{99} \\approx 10^{198}$，约 200 位）。
