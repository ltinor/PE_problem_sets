# Crack-free Walls

来源：改编自 Project Euler Problem 215

## 原题意

用 2×1 和 3×1 的砖块（宽×高）筑墙，要求相邻层之间的砖缝不能对齐（无"延伸裂纹"）。求 W(32,10) 的不同筑法数。

## 题目

给定 W（2 ≤ W ≤ 40）和 H（1 ≤ H ≤ 20），用 2×1 和 3×1 的砖块筑一面 W×H 的墙，每层砖块水平放置。相邻层之间的砖缝（即砖块结合处）不能垂直对齐。求不同的筑墙方案数。

## 数据范围

- 2 ≤ W ≤ 40
- 1 ≤ H ≤ 20
- PE 答案: W=32, H=10 → 806844323190414
- 样例: W=9, H=3 → 8

## 算法

位掩码 DP。生成所有合法行模式（用 2 和 3 分割宽度 W），用 bitmask 表示砖缝位置。两行兼容当且仅当 bitmask 无交集。dp[h][pattern] 用兼容矩阵转移。复杂度 O(P²·H)，P 为行模式数。

## 改编方向

1. **参数化 W, H**（采用）：将固定 32×10 改为可变输入
2. **参数化砖块尺寸**（未采用）：支持任意砖块组合，但偏离原题
3. **统计而非计数**（未采用）：求带权方案数，本质不同
