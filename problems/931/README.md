# 欧拉函数图总权（PE 931）

来源：改编自 Project Euler Problem 931。

## 原题意

n 的因数为顶点、商为素数连边、边权 φ(a)-φ(b), t(n)=总权; 求 T(10^12) mod 715827883。

## 题目

见 statement.md。参数与输入输出约定以 code/std.cpp 为准。

## 算法

闭式 t(n)=Σ_{p^a||n}(n/p^a)[(p-1)p^(a-1)-1]; T(N)=Σ_p Σ_a c(p,a)·E(⌊N/p^a⌋,p), E 为剔除 p 倍数的等差和; 大素数段用 Lucy 素数计数/素数和按商分组聚合。

## 验证

T(10)=26, T(100)=5282 (题面), T(10^5)/T(10^6) 暴力对拍一致; T(10^12)=128856311 (官方, 3.9s)
