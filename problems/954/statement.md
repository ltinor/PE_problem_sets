# 恐七数

## 题目描述

一个正整数如果本身不能被 $7$ 整除，并且交换它的任意两个数字后得到的数也都不能被 $7$ 整除，则称其为**恐七数**。注意交换前后都不允许出现前导零。

例如，$17$ 和 $1305$ 是恐七数，而 $14$ 和 $132$ 不是：$14$ 本身是 $7$ 的倍数；$132$ 交换第 $1$、$3$ 位得到 $231=7\times 33$。

记 $C(N)$ 为小于 $N$ 的恐七数的个数。已知 $C(100)=74$，$C(10^4)=3737$。

---

## 输入格式

一行一个整数 $N$。

---

## 输出格式

一行一个整数 $C(N)$，表示小于 $N$ 的恐七数的个数。

---

## 样例

### 输入

```
100
```

### 输出

```
74
```

---

## 数据范围

$1 \le N \le 10^6$。
