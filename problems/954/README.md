# PE 954 恐七数（Heptaphobia）—— 缩数据版

来源：改编自 Project Euler Problem 954

## 原题意

一个正整数如果本身不能被 $7$ 整除，并且交换它的任意两个数字后得到的数也都不能被 $7$ 整除，则称其为**恐七数**（heptaphobic）。注意交换前后都不允许出现前导零。

例如 $17$ 和 $1305$ 是恐七数，而 $14$（本身是 $7$ 的倍数）和 $132$（交换后得到 $231=7\times 33$）不是。

记 $C(N)$ 为小于 $N$ 的恐七数的个数。原题给定 $C(100)=74$、$C(10^4)=3737$，求 $C(10^{13})$。

## 题目（缩数据版）

给定整数 $N$，求小于 $N$ 的恐七数的个数 $C(N)$。

## 数据范围

- $1 \le N \le 10^6$

（原题求 $C(10^{13})$ 需要高深的组合计数/数位 DP 技巧；本题作为 OJ 缩数据版，把 $N$ 缩小到 $10^6$，可以直接用暴力判定。）

## 算法

对每个 $n < N$ 用 $O(d^2)$（$d$ 为位数）判定是否为恐七数：

1. 若 $n\bmod 7=0$，不是恐七数。
2. 枚举所有数位对 $(i,j)$（$i<j$），若交换后得到 $7$ 的倍数，则不是恐七数。

利用 $10^k \bmod 7$ 的周期（周期 6），交换第 $i,j$ 位引起的值模 $7$ 的变化为
$\Delta \equiv (a_j-a_i)\cdot 10^{d-1-i} + (a_i-a_j)\cdot 10^{d-1-j} \pmod 7$。
只要存在某对 $(i,j)$ 使 $n+\Delta\equiv 0\pmod 7$（且交换后无前导零），则 $n$ 不是恐七数。

总复杂度 $O(N\log N)$，$N\le 10^6$ 时可在时限内完成。

验证点：$C(100)=74$，$C(10^4)=3737$；$17$、$1305$ 为恐七数，$14$、$132$ 不是。
