# 可截素数 (Truncatable Primes)

来源：改编自 Project Euler Problem 37

## 原题意

求所有双向可截素数的和。已知共有11个这样的素数（不包括2, 3, 5, 7），求和即可。原题答案：748317。

## 改编方向

此题答案固定（只有11个可截素数），无参数化空间。改为直接输出这11个可截素数的和，输入可忽略。

## 题目

如果一个素数满足：无论从左往右还是从右往左逐一截去数字，剩下的数仍然是素数，则称之为**可截素数**。例如 3797 是素数，从右往左截：3797, 379, 37, 3 都是素数；从左往右截：3797, 797, 97, 7 也都是素数。注意：2, 3, 5, 7 不被视为可截素数。

已知总共有十一个可截素数（不包括 2, 3, 5, 7），求这些数的和。

## 数据范围

固定答案，输入任意整数（忽略）。

## 算法

从一位素数 2, 3, 5, 7 开始 BFS 扩展，每次在右侧添加数字 1, 3, 7, 9（素数末位不能是偶数或5），生成所有右可截素数。然后对每个数检查左可截性（逐位截去左侧数字，验证素数）。计数到11个后求和。
