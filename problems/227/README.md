# 227 — The Chase

来源：改编自 Project Euler Problem 227

## 原题意

100 名玩家围坐一圈，两名相对玩家各持一颗骰子。每轮掷骰子：1 向左传，6 向右传，否则保留。当一名玩家同时持有两颗骰子时游戏结束。求期望轮数。原题答案：3780.618622（10 位有效数字）。

## 题目

参数化 N（玩家数量，偶数）：输入 N，计算游戏期望持续轮数，保留 6 位小数。

## 数据范围

$2 \\le N \\le 1000$，$N$ 为偶数

## 算法

**std**: 马尔可夫链 + Gauss-Seidel 迭代。状态定义为两颗骰子之间的（较短弧）距离 $d \\in [1, N/2]$，$d=0$ 为吸收态。对每个距离 $d$，枚举两颗骰子的 9 种移动组合（各 3 种结果），计算转移概率。建立线性方程组 $E[d] = 1 + \\sum P(d \\to d')E[d']$，迭代求解至收敛（$\< 10^{-12}$）。

时间复杂度：$O(k \\cdot N)$，其中 $k$ 为迭代次数（约 50000）。

**brute**: 蒙特卡洛模拟 500000 局取平均，仅适用于小 N。

## 改编方向

1. **参数化 N**：将原题固定 N=100 改为输入参数。
2. **改变骰子面数**：可参数化骰子面数（如改为 d20），改变转移概率。
3. **非对称骰子**：可让两颗骰子有不同的传递规则。
