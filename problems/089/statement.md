# 罗马数字

## 题目描述

要正确地用罗马数字表达一个数，必须遵循一些基本规则。尽管符合规则的写法有时会多于一种，但对每个数来说总是存在一种"最好的"（最简短的）写法。

例如，至少有六种写法可以表达十六这个数：

```
IIIIIIIIIIIIIIII
VIIIIIIIIIII
VVIIIIII
XIIIIII
VVVI
XVI
```

然而，根据规则，只有 `XIIIIII` 和 `XVI` 是合理的写法，而后一种因为使用了最少的数字而被认为是最有效的写法。

给定 $N$ 个用有效罗马数字书写的数字（不一定是极简形式），请计算如果将它们都改写为极简形式，总共能节省的字符个数。

---

## 输入格式

第一行一个整数 $N$，表示罗马数字的个数。

接下来 $N$ 行，每行一个由大写字母 `I`, `V`, `X`, `L`, `C`, `D`, `M` 组成的罗马数字。

---

## 输出格式

输出一个整数，表示总共节省的字符个数。

---

## 样例

### 输入
```
1
XIIIIII
```

### 输出
```
4
```

**解释**：`XIIIIII`（7 个字符）→ `XVI`（3 个字符），节省 4 个字符。

---

## 数据范围

- $1 \leq N \leq 1000$
- 每个罗马数字长度不超过 $30$，对应的数值不超过 $3999$
- 保证输入的所有罗马数字都是有效的
