# 强阿喀琉斯数

来源：改编自 Project Euler Problem 302

## 原题意

统计小于 $10^{18}$ 的强阿喀琉斯数。PE 答案：1170060。

## 题目

输入 $N$，求小于 $N$ 且满足 $n$ 和 $\varphi(n)$ 均为阿喀琉斯数的正整数个数。

## 数据范围

$1 \le N \le 10^{12}$。

## 算法

### 方向一：生成强力数 + 筛选（核心）

利用"每个强力数可表示为 $a^2 b^3$（$b$ 无平方因子）"的定理，枚举 $a \le \sqrt{N}$ 和 $b$，生成所有强力数。

对每个强力数 $n$：
- 判断是否为完全幂（对所有 $k \ge 2$ 二分搜索 $m$ 满足 $m^k = n$）
- 若是阿喀琉斯数（强力且非完全幂），计算 $\varphi(n)$ 并判断其是否也为阿喀琉斯数

时间复杂度：强力数个数约为 $O(\sqrt{N})$，$N=10^{12}$ 时约 $10^6$ 个强力数。

### 方向二：逐数分解（暴力验证）

对每个 $n < N$ 进行质因数分解，依次判断强大、完全幂、阿喀琉斯和强阿喀琉斯条件。复杂度 $O(N \sqrt{N})$，仅适用于 $N \le 10^5$。

### 方向三：质因数指数枚举

枚举所有可能的质因数指数组合（每个指数 $\ge 2$），生成阿喀琉斯数，再计算 $\varphi$ 验证。比方向一更精确但实现更复杂。

### 时间复杂度

标准解法生成强力数 $O(\sqrt{N})$ 个，每个检查 $O(\log N)$，总计约 $10^6$ 次运算，$N=10^{12}$ 可在 1 秒内完成。
