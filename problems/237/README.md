# 237 — Tours on a 4×n playing board

来源：改编自 Project Euler Problem 237

## 原题意

在 4×n 棋盘上，从左上角 (0,0) 到左下角 (3,0) 的哈密顿路径（每格恰好经过一次，只能上下左右移动）。已知 T(10) = 2329，求 T(10¹²) mod 10⁸。

PE 答案：15836928。

## 题目

输入整数 n，求 T(n) mod 10⁸，即 4×n 棋盘上从左上到左下的哈密顿路径数模 10⁸。

## 数据范围

1 ≤ n ≤ 10¹²

## 算法

**std**: 状态压缩 DP + 转移矩阵快速幂。将每列的边界连通性编码为状态（最多 4 个插头，每个插头有 0/1/2 三种标签表示连通性，约 10-14 个有效状态）。枚举每列内部的合法填充，建立转移矩阵。初始状态从第 0 列（含起点/终点）推出。用矩阵快速幂计算 T(n)。

时间复杂度：O(S³ log n)，S 为状态数（~14）。

**brute**: DFS 回溯枚举所有哈密顿路径，适用于 n ≤ 5。

## 改编方向

1. **参数化 n**：原题固定 n=10¹²，改为输入任意 n。
2. **不同棋盘尺寸**：改为 m×n 棋盘，m 可变。
3. **不同起终点**：改变起点/终点位置。
4. **哈密顿回路**：改为求哈密顿回路（回到起点）的数量。
