# 563 - 焊接机器人 (Robot Welders)

来源：改编自 Project Euler Problem 563

## 原题意

机器人从单位正方形（1×1）开始，每次焊接 k（1 ≤ k ≤ 25）个相同矩形，可沿长边或短边焊接。最终可制造的矩形尺寸 (w, h) 需满足：w 和 h 都是 [2,25] 中整数的乘积。

顾客要求：面积 A 精确给定，长边 ≤ 1.1 × 短边。对于给定 A，若存在多种 (w,h) 满足要求，全部生产。

记 M(n) 为恰好有 n 种合格尺寸的最小面积。已知 M(3) = 889200。
求 Σ_{n=2}^{100} M(n)。

PE 答案：27186308211734760。

## 题目

给定 N，求 Σ_{n=2}^{N} M(n)。

## 数据范围

- 2 ≤ N ≤ 100

## 算法

可制造的尺寸 w, h 均为 23-光滑数（所有质因子 ≤ 23）。因为 [2,25] 的生成元包含所有 ≤ 23 的质数，且可通过组合得到该范围内所有合数。

算法：
1. 生成所有 ≤ LIMIT 的 23-光滑数
2. 对每个光滑数 w，找所有光滑数 h 满足 w ≤ h ≤ 1.1w
3. 按面积 A = w×h 分组，统计每个面积的变体数
4. 对每个计数 c，记录最小面积 M[c]
5. 输出 Σ_{c=2}^{N} M[c]

时间复杂度：O(S² log S)，其中 S 为光滑数个数。

## 改编方向

1. **不同 k 限制**：改变最大焊接数 25。
2. **不同比例**：改变长宽比上限。
3. **最小面积**：改为求最大面积。
4. **计数变体**：统计给定范围内每个面积的变体数分布。
