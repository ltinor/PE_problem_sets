# 几乎等边的三角形

## 题目描述

考虑满足以下条件的三角形：
- 有两条边长相等；
- 第三边与这两边相差恰好为 $1$；
- 所有边长均为正整数；
- 面积为整数。

例如，$5-5-6$ 是一个几乎等边的三角形，其面积为 $12$。

给定整数 $M$，求所有周长不超过 $M$ 的几乎等边三角形的周长之和。

---

## 输入格式

一行一个整数 $M$。

---

## 输出格式

一行一个整数，表示所有满足条件的三角形的周长之和。

---

## 样例

### 输入

```
100
```

### 输出

```
66
```

**解释**：满足条件的三角形有 $5-5-6$（周长 $16$）和 $17-17-16$（周长 $50$），周长和为 $66$。

---

## 数据范围

$1 \le M \le 10^9$。
