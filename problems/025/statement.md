# 斐波那契位数

## 题目描述

斐波那契数列定义为 $F_1 = 1$, $F_2 = 1$, $F_n = F_{n-1} + F_{n-2}$。

给定整数 $D$，求斐波那契数列中第一个包含 $D$ 位数字的项的序号。

例如：
- $F_1=1$ 有 $1$ 位数字，所以当 $D=1$ 时答案是 $1$。
- $F_7=13$ 有 $2$ 位数字，所以当 $D=2$ 时答案是 $7$。
- $F_{12}=144$ 有 $3$ 位数字，所以当 $D=3$ 时答案是 $12$。

---

## 输入格式

第一行一个整数 $T$，表示测试数据组数。  
接下来 $T$ 行，每行一个整数 $D$。

---

## 输出格式

对于每组数据，输出一行一个整数，表示第一个包含 $D$ 位数字的斐波那契数的序号。

---

## 样例

### 输入
```
3
1
2
3
```

### 输出
```
1
7
12
```

---

## 数据范围

- $1 \le D \le 5000$
- $1 \le T \le 10$
