# 1000-digit Fibonacci Number

来源：改编自 Project Euler Problem 25

## 原题意

斐波那契数列中，第一个包含1000位数字的是第4782项。

## 题目

给定 D，求斐波那契数列中第一个包含 D 位数字的项的序号（$F_1=1$, $F_2=1$）。

## 数据范围

- $1 \le D \le 5000$

## 算法

std: 大整数加法（`vector<int>` 存储每一位），迭代计数直到位数达到 D。  
brute: 相同算法独立实现。

时间复杂度：$O(D^2)$（斐波那契第 n 项约 n 位，迭代索引约 $4.785D$）。
