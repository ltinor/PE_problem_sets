# 无穷字符串游历

## 题目描述

使用 Blum Blum Shub 伪随机数生成器：

$$s_0 = 14025256$$
$$s_{n+1} = s_n^2 \bmod 20300713$$

将这些数字依次连接形成一个无穷长的字符串 $w$：
$$w = 14025256741014958470038053646\ldots$$

对于正整数 $k$，定义 $p(k)$ 如下：
- 若 $w$ 中不存在各位数字和恰好为 $k$ 的子串，则 $p(k)=0$；
- 否则，$p(k)$ 为最早出现的各位数字和为 $k$ 的子串的起始位置（从 $1$ 开始编号）。

例如：子串 `1`（数字和为 1）起始于位置 1，故 $p(1)=1$；子串 `14`（和为 5）起始于位置 1，故 $p(5)=1$。

给定 $K$，求 $\sum_{k=1}^{K} p(k)$。

---

## 输入格式

一行一个整数 $K$。

---

## 输出格式

输出所求的和。

---

## 样例

### 输入
```
1000
```

### 输出
```
4742
```

---

## 数据范围

$1 \le K \le 2 \times 10^{15}$
