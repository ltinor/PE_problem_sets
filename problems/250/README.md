# 250250

来源：改编自 Project Euler Problem 250

## 原题意

求集合 {1¹, 2², ..., 250250²⁵⁰²⁵⁰} 的非空子集中，元素和能被 250 整除的子集个数。输出最后 16 位。答案: 1425480602091519。

## 题目

给定 N, M，求 {1¹, 2², ..., Nᴺ} 的非空子集中，元素和 ≡ 0 (mod M) 的个数。输出 mod 10¹⁶。

## 数据范围

N ≤ 250250, M ≤ 250。共 10 个测试点，包含原题数据和随机数据。

## 算法

1. **DP 计数**: 经典子集和 DP mod M。dp[r] = 和为 r (mod M) 的子集个数。初始 dp[0]=1（空集）。对每个元素 val = i^i mod M，更新 dp。

2. **快速幂**: 使用快速幂计算 i^i mod M。注意取模以减少运算量。

3. **复杂度**: O(N·M)。N=250250, M=250 时约 6.2×10⁷ 次运算，在 1s 内可通过。
