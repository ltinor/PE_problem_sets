# 139 — Pythagorean Tiles

来源：改编自 Project Euler Problem 139

## 原题意

求周长 < 10⁸ 的直角三角形中，可以用中间正方形孔洞的方砖铺满的三角形数量。

原题答案：10057761。

## 题目

参数化 M：输入 M (≤ 10⁸)，求周长 < M 满足条件的直角三角形数量。

## 数据范围

- M ≤ 10⁸

## 算法

**std**: 生成原始勾股数 (a=m²−n², b=2mn, c=m²+n²) 其中 m>n, gcd(m,n)=1, m−n 为奇数。条件：c % (b−a) == 0。满足条件的原始三角形，其所有相似放大也满足条件。累加 (M−1)/(a+b+c)。

**brute**: 相同算法。

## 改编方向

1. **参数化 M**：将原题固定 M=10⁸ 改为输入参数。
2. **原始勾股数生成**：使用 Euclid 公式生成所有原始勾股三元组。
3. **PE 答案验证**：(M=10⁸) 作为测试点，输出 10057761。
