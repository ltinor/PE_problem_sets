# 228 — Minkowski Sum

来源：改编自 Project Euler Problem 228

## 原题意

记 $S_n$ 为正 n 边形，顶点 $v_k = (\\cos(\\frac{2k-1}{n} \\cdot 180^\\circ), \\sin(\\frac{2k-1}{n} \\cdot 180^\\circ))$。求 $S_{1864} + S_{1865} + \\dots + S_{1909}$（闵可夫斯基和）的边数。原题答案：86226。

## 题目

参数化 $[L, R]$：输入 L 和 R，求 $S_L + S_{L+1} + \\dots + S_R$ 的闵可夫斯基和的边数。

## 数据范围

$3 \\le L \\le R \\le 2000$

## 算法

**std**: 闵可夫斯基和的边数等于所有输入多边形边法向量的不同方向数。$S_n$ 的边外法向量方向角为 $\\frac{(2k-1)\\pi}{n} \\pod{k=1..n}$。标准化为最简分数 $\\frac{2k-1}{2n}$（约分后），用集合去重。集合大小即为边数。

时间复杂度：$O(\\sum_{n=L}^{R} n \\cdot \\log n)$。

**brute**: 直接使用浮点角度 `set<double>` 去重，验证 std 结果。

## 改编方向

1. **参数化范围**：将原题固定范围 [1864, 1909] 改为输入 L, R。
2. **多边形旋转角度参数化**：可改变多边形的起始旋转角度 $\\theta_0$。
3. **非连续求和**：可改为求 $S_{n_1} + S_{n_2} + \\dots + S_{n_k}$ 其中 $n_i$ 为任意序列。
