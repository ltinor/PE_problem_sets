# PE 966 三角形与圆的交集（简单/缩数据版）

来源：改编自 Project Euler Problem 966（Triangle Circle Intersection）

## 原题意

记 $I(a,b,c)$ 为边长 $a,b,c$ 的三角形与一个面积与之相等的圆之间的**最大**交集面积（圆可放在平面任意位置）。

例如 $I(3,4,5)\approx 4.593049$，$I(3,4,6)\approx 3.552564$。

原题要求对所有满足 $1\le a\le b\le c < a+b$ 且 $a+b+c\le 200$ 的整数三角形，求 $\sum I(a,b,c)$ 并四舍五入到两位小数。

## 题目（简单版）

给定一个三角形的三边 $a,b,c$（整数，满足三角形不等式 $1\le a\le b\le c<a+b$），
输出 $I(a,b,c)$，四舍五入保留 6 位小数。

### 输入格式

一行三个整数 `a b c`。

### 输出格式

一个实数，`I(a,b,c)` 保留 6 位小数。

### 样例

```
输入:  3 4 5
输出:  4.593049
```

```
输入:  3 4 6
输出:  3.552564
```

## 数据范围

- $1\le a\le b\le c<a+b$（构成合法三角形）。
- 边长为整数（本题算法对任意正实数边长同样适用）。

## 算法

1. 海伦公式求三角形面积 $A$，圆半径 $R=\sqrt{A/\pi}$（圆与三角形等面积）。
2. 将三角形置于坐标平面（$A=(0,0),\,B=(c,0),\,C=(x,y)$，逆时针）。
3. 求圆盘（圆心 $O$，半径 $R$）与三角形的交集面积 $f(O)$：
   - 最优圆心必在三角形**内部**（否则白白浪费圆面积），故用 $O$ 到三个顶点的
     扇形剖分，交面积 $=\sum_i$ 三角形 $(O,V_i,V_{i+1})\cap$ 圆盘的面积。
   - 单个扇形三角形与圆盘的交用径向积分闭式：
     $f=\tfrac12\int_{\theta_p}^{\theta_q}\min\big(R^2,\,(h/\cos(\phi-\phi_n))^2\big)\,d\phi$，
     其中 $h$ 是 $O$ 到边的距离、$\phi_n$ 是指向边的法向角。
     $h\ge R$ 时积分为 $R^2\cdot\Delta\theta$；否则在 $|\phi-\phi_n|<\arccos(h/R)$
     区间积 $h^2/\cos^2$（原函数 $h^2\tan$），其余区间积 $R^2$。
4. $f(O)$ 是两个凸集指示函数（三角形、圆盘）的卷积，由 Prékopa–Leindler 不等式
   可知为 log-concave，故单峰。对 $x$ 外层三分、$y$ 内层三分（$y$ 限制在三角形
   在该 $x$ 处的竖直截面 $[y_{lo}(x),y_{hi}(x)]$ 内），求得全局最大即 $I(a,b,c)$。

单次查询复杂度 $O(T_x\cdot T_y)$（约几千次交面积计算），常数极小。

## 验证

```
$ echo "3 4 5" | ./std
4.593049
$ echo "3 4 6" | ./std
3.552564
```

与题目给出的 $I(3,4,5)\approx4.593049$、$I(3,4,6)\approx3.552564$ 一致。
