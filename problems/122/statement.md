# 高效幂运算

## 题目描述

计算 n^k 最朴素的方法需要 k−1 次乘法，但我们可以用更少的乘法。例如计算 n^15：可以先算 n^2，再算 n^3=n^2×n，n^6=n^3×n^3，n^12=n^6×n^6，n^15=n^12×n^3，共 5 次乘法。

定义 m(k) 为计算 n^k（n 为任意正整数）所需的最少乘法次数。

给定整数 K，求 m(1)+m(2)+...+m(K) 的值。

---

## 输入格式

一行一个整数 K。

---

## 输出格式

一行一个整数，表示 m(1)+m(2)+...+m(K) 的和。

---

## 样例

### 输入
```
15
```

### 输出
```
50
```

**解释**：m(1)=0, m(2)=1, m(3)=2, m(4)=2, m(5)=3, m(6)=3, m(7)=4, m(8)=3, m(9)=4, m(10)=4, m(11)=5, m(12)=4, m(13)=5, m(14)=5, m(15)=5。和为 50。

---

## 数据范围

- 1 ≤ K ≤ 200
