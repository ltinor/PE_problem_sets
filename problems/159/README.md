# 159 — 分解约数数字根之和

来源：改编自 Project Euler Problem 159

## 原题意

求 ∑_{n=2}^{999999} mdrs(n)，其中 mdrs(n) 是 n 的所有分解中数字根和的最大值。

原题答案：14489159。

## 题目

参数化 N：输入 N (< 10^6)，求 ∑_{n=2}^{N} mdrs(n)。

## 数据范围

- N < 10^6

## 算法

**std**: DP 递推。mdrs(n) = max(dr(n), max_{d|n, 1<d<n}(dr(d) + mdrs(n/d)))。其中 dr(n) = 1 + (n-1) % 9。对每个 i，枚举其所有约数 d（到 sqrt(i)），O(N√N)。对于 N=10^6 约 10^9 次操作，在 O2 优化下可接受。

**brute**: 相同算法，用于验证。

## 改编方向

1. **参数化 N**：将固定 N=999999 改为输入参数。
2. **DP 递推**：利用数字根和分解的递推性质。
3. **PE 答案验证**：(N=999999) 输出 14489159。
