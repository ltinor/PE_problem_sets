# 网格路径

## 题目描述

给定一个 $n \times m$ 的网格。从左上角 $(0,0)$ 出发，每次只能向右或向下移动一格，求抵达右下角 $(n,m)$ 的不同路径总数。

例如，在一个 $2 \times 2$ 的网格中，恰好有 $6$ 条不同路径。

由于答案可能很大，请输出结果对 $10^9 + 7$ 取模的值。

---

## 输入格式

第一行一个整数 $T$，表示测试数据组数。

接下来 $T$ 行，每行两个整数 $n$ 和 $m$，空格分隔。

---

## 输出格式

对于每组数据，输出一行一个整数表示从左上角到右下角的不同路径数，对 $10^9+7$ 取模。

---

## 样例

### 输入
```
3
2 2
3 3
1 1
```

### 输出
```
6
20
2
```

---

## 数据范围

- $1 \le T \le 10$
- $1 \le n, m \le 500$
