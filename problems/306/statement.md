# 纸条游戏

## 题目描述

两名玩家在一张划成 $n$ 个白格的纸条上轮流操作。每一轮，玩家必须选择两个**相邻**的白格，并将它们涂成黑色。先手无法进行合法操作的玩家输掉游戏。

例如：
- $n = 1$：没有相邻白格，先手输。
- $n = 2$：只有一种操作，先手操作后后手输，故先手赢。
- $n = 3$：有两种操作，但无论哪种后手都输，故先手赢。
- $n = 4$：有三种操作，先手将中间两格涂黑即可赢。
- $n = 5$：有四种操作，但后手总能赢。

因此，$1 \le n \le 5$ 中有 $3$ 个 $n$ 使得先手必胜。

现在给定一个正整数 $N$，请计算 $1 \le n \le N$ 中有多少个 $n$ 使得先手必胜。

---

## 输入格式

一行一个正整数 $N$。

---

## 输出格式

一行一个整数，表示必胜的 $n$ 的数量。

---

## 样例

### 输入

```
5
```

### 输出

```
3
```

### 输入

```
50
```

### 输出

```
40
```

---

## 数据范围

- $1 \le N \le 10^7$
