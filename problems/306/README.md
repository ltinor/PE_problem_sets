# 306 — 纸条游戏

来源：改编自 Project Euler Problem 306

## 原题意

两名玩家在一张划成 n 个白格的纸条上轮流操作。每轮选择相邻的两个白格涂黑。先无法操作者输。求 1 ≤ n ≤ 1,000,000 中先手必胜的 n 的数量。

原题答案：852938。

## 题目

输入一个正整数 N，求 1 ≤ n ≤ N 中先手必胜的 n 的数量。

## 数据范围

- N ≥ 1
- N ≤ 10⁷

## 改编思路

### 方向一：参数化上界
- 将原题固定的 N = 10⁶ 改为输入参数
- 原题核心算法不变：计算 Grundy 数（Dawson's Kayles），检测周期 34，统计非零值
- 结论：✅ 采用

### 方向二：输出必胜 n 的列表
- 输出所有先手必胜的 n 值
- 结论：❌ 输出量大，不实用

### 方向三：多组询问
- 支持多组 N 的查询
- 结论：❌ 当前版本简化处理

## 算法

计算 Dawson's Kayles 的 Grundy 数序列。该序列从 n=52 开始呈现周期 34，每个周期内有 28 个必胜态。对于 N ≤ 10⁷，先计算前几百项的 Grundy 数并检测周期，然后利用周期性 O(1) 统计。
