# 114 — Counting Block Combinations I

来源：改编自 Project Euler Problem 114

## 原题意

用黑色方块（长度 1）和红色方块（最短长度 3）填充长度为 50 的一行，要求任意两个红色方块之间至少有一个黑色方块。求摆法总数。答案：16475640049。

## 题目

输入两个整数 N 和 M，求用黑色方块（长度 1）和红色方块（最短长度 M）填充长度为 N 的一行的摆法总数。

## 数据范围

- 3 ≤ M ≤ N ≤ 50

## 算法

动态规划：dp[i] 表示长度为 i 的行的摆法数。
- dp[0] = 1（空行）
- dp[i] = dp[i-1]（末尾放黑色方块）+ Σ_{j=M}^{i} dp[i-j-1]（末尾放长度为 j 的红色方块，前面必须有黑色方块或行首）

其中 dp[-1] = 1（红色方块直接从位置 1 开始的情况）。

时间复杂度 O(N²)，N≤50 时瞬间完成。答案最大约 1.6×10^10，用 unsigned long long 足够。

## 改编方向与取舍

### 改编方向
1. **参数化 N 和 M** → 支持 N ≤ 50, M ≥ 3（本题采用）
2. **大范围 N** → N ≤ 1000，需大整数/取模
3. **多组查询** → T 组输入，每组输出摆法数
4. **输出所有 N 的结果** → 给定 M，输出 N=M..Nmax 的摆法数

### 取舍理由
- 选择参数化 N 和 M：保留原题核心 DP，同时增强灵活性
- N 限制在 50：原题范围，不需要大整数
- 不选择大范围：用取模会改变题意，不用取模需要大整数库
