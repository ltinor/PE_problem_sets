# 小左对小右（二）（Left vs Right II）

来源：改编自 Project Euler Problem 949

## 原题意

小左和小右用若干个由 `L`/`R` 组成的单词玩游戏，轮流行动。小左从每个单词左侧移除字母，小右从每个单词右侧移除字母（可移除 0 个但不能移除全部，整回合至少移除一个）。直到每个单词只剩一个字母，剩余 `L` 多则小左胜，`R` 多则小右胜。单词数为奇数，无平局。

记 $G(n,k)$ 为「$k$ 个长度为 $n$ 的单词、小左先手时小右有必胜策略」的局面数（有序计数）。

原题：已知 $G(2,3)=14$、$G(4,3)=496$、$G(8,5)=26359197010$，求 $G(20,7) \bmod 1001001011$。

## 题目（缩数据版）

读入 $n, k$（$k$ 为奇数），输出 $G(n,k)$。

## 数据范围

- $1 \le n \le 4$
- $1 \le k \le 5$，$k$ 为奇数。

## 算法

本题是多个独立单词游戏的不相交和（partizan 组合博弈），完整求解 $G(20,7)$ 需要较深的组合博弈论（超现实数 / switch 值）分析，并配合生成函数计数，难度很高。

缩数据版采用**直接枚举 + 记忆化极小极大博弈搜索**：

1. 生成全部 $2^n$ 个长度为 $n$ 的单词；
2. 枚举 $k$ 个单词的多重集（可重复、不计顺序），对每个多重集用极小极大博弈树判定小右是否必胜；
3. 对每个「小右必胜」的多重集，用多项式系数 $k! / \prod c_i!$ 累计其有序排列数。

博弈判定：

- 状态为「当前各单词 + 轮到谁」，按「排序后的单词列表 + 回合」做记忆化；
- 终局：所有单词均为单字母，比较 `L`/`R` 个数；
- 小左（回合 0）枚举各单词的左移除（后缀）+「不动」，寻找能到达「小左胜」状态的走法；小右（回合 1）对称地枚举右移除（前缀），寻找能到达「小右胜」状态的走法；需排除「全部单词均不动」的非法走法。

验证点：`G(2,3)=14`、`G(3,3)=80`、`G(4,3)=496` 均已通过。
