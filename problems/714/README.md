# Duodigits (双字数)

来源：改编自 Project Euler Problem 714

## 原题意

双字数是十进制表示至多使用两种不同数字的自然数。d(n) 为 n 的最小双字数倍数，
D(k) = Σ_{n≤k} d(n)。已知 D(110)=11047、D(150)=53312、D(500)=29570988，
求 D(50000)，以 13 位有效数字科学计数法表示。

## 题目

给定 K（1 ≤ K ≤ 5×10^4），输出 D(K) 的精确十进制值；输入 `PE` 输出官方答案
`2.452767775565e20`。

## 数据范围

- 1 ≤ K ≤ 5×10^4
- PE 答案: D(50000) = 245276777556527592946 = 2.452767775565e20

## 算法（code/std.cpp，K=5×10^4 约 7s @12 线程）

对 45 个无序数字集 {d1<d2}，在模 n 的残余图上做 **(长度,字典序) 序 BFS**：

- FIFO 队列 + 每状态按数字升序扩展 + 按余数去重（首次到达某余数的串即该余数的
  (长度,字典序) 最小串；正确性由"同长度下前缀支配字典序"保证）；
- 首个到达余数 0 的串 = 该数字集的最小双字数倍数；d(n) 取 45 个集合的最小值
  （单数字串自动被含该数字的集合覆盖）；
- 剪枝：深度上限 = 当前最优串长度（更长的十进制数必更大）；
- 各 n 完全独立，按原子计数器动态并行（大 n 显著更难，连续分块会失衡）。

数据点：PE 锚点 110/150/500 + 梯度 1000/5000/10000/20000/50000。

## 验证

- `code/brute.cpp`（按值升序扫描全部双字数、定义直译）与 std 在 K = 110/150/300 完全一致；
- D(110)/D(150)/D(500) 三个官方锚点精确命中；
- D(50000) = 245276777556527592946，四舍五入 13 位有效数字 = 2.452767775565e20，
  与 PE 官方答案一致。
