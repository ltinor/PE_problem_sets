# 372 — Pencil of Rays

来源：改编自 Project Euler Problem 372

## 原题意

R(M,N) = 满足 M<x≤N, M<y≤N 且 ⌊y²/x²⌋ 为奇数的格点数。求 R(2·10⁶, 10⁹)。

## 题目

给定 M, N，计算满足条件的格点 (x, y) 数目，其中 ⌊y²/x²⌋ 为奇数。

## 数据范围

0 ≤ M < N ≤ 10⁶，N - M ≤ 10⁵。

## 算法

1. **枚举x+整数平方根**：对每个x，枚举奇数k，用整数平方根计算y的范围，O(N√N)。
2. **数论分块优化**：利用 ⌊y²/x²⌋ 的分段性质减少枚举，O(N^{2/3})。
3. **前缀和预处理**：预处理平方数，二分查找边界加速。
