# 弱古德斯坦序列

## 题目描述

对正整数 n，第 n 个弱古德斯坦序列定义如下：
- g1 = n
- gk：将 g_{k-1} 写成 k 进制，然后视为 k+1 进制数，最后减 1
- 序列在 gk = 0 时终止

记 G(n) 为序列中非零元素个数。

给定 N，求 Σ_{n=1}^{N-1} G(n)。

---

## 输入格式

一个整数 N。

---

## 输出格式

一个整数，表示 ΣG(n)。

---

## 样例

### 输入
```
8
```

### 输出
```
2517
```

---

## 数据范围

- 对于所有数据：2 ≤ N ≤ 8

> 注：原 Project Euler 396 要求 1 ≤ n < 16（G(n) 呈 Ackermann 级增长，需特殊算法）。
> 本题为缩数据简单版，限制 N ≤ 8，直接模拟即可。
