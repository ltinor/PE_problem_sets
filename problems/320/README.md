# 320 — Factored Integers Divisible by $K$

来源：改编自 Project Euler Problem 320

## 原题意

记 $N(i)$ 为使 $n!$ 被 $(i!)^{1234567890}$ 整除的最小整数 $n$。
记 $S(u) = \sum_{i=10}^{u} N(i)$。

已知 $S(1000) = 614538266565663$。
求 $S(10^6) \bmod 10^{18}$。

答案：$2781579195314827256$。

## 题目

输入 $U$ 和 $K$，记 $N(i)$ 为使 $n!$ 被 $(i!)^K$ 整除的最小整数 $n$。求 $S(U) = \sum_{i=10}^{U} N(i) \bmod 10^{18}$。

## 数据范围

- $10 \le U \le 10^6$
- $1 \le K \le 10^9$

## 算法

1. **质因数分解法**：对每个 $i$，计算所有质数 $p \le i$ 的 $v_p(i!)$，然后对每个质数二分查找最小的 $n$ 使 $v_p(n!) \ge K \cdot v_p(i!)$。取所有质数中的最大值作为 $N(i)$。
2. **直接公式法**：利用 $v_p(n!) = \sum_{k\ge 1} \lfloor n/p^k \rfloor$ 和单调性，通过数学推导直接计算 $N(i)$ 的主导质数。
3. **预处理优化**：预计算所有质数的 $v_p(i!)$ 前缀信息，加速批量查询。

## 改编方向

1. 原题固定 $K=1234567890$ → 参数化 $K$
2. 改变求和范围（如 $i$ 从 $1$ 开始）
3. 使用 $(i!)^K$ 以外的指数形式

选择方向 1：参数化 $K$，保留原题阶乘整除的核心。
