# Ambiguous Numbers

来源：改编自 Project Euler Problem 198

## 原题意

对于实数x，分母上限为d的最佳逼近是最简分数r/s (s≤d)，使得任何更接近x的有理数分母都>d。如果存在某个d使x有两个最佳逼近，则x是两可数。求0<x<1/100, q≤10^8的两可数个数。

## 题目

给定分母上限Q，求满足 0 < x < 1/100 且分母不超过 Q 的两可数个数。

## 数据范围

- Q ≤ 10^8
- PE 答案: Q=10^8 → 52374425

## 算法

**判定特征（已推导并双重验证）**：x = p/q（既约）是两可数 ⟺ p 奇、q 偶，且存在
d | (p−1)/2, b | (p+1)/2 使 q = 2·d·b，即 (q/2) | ((p−1)/2)·((p+1)/2)（等价于 p² ≡ 1 mod 2q）。

推导：两可 ⟺ x 是某对相邻 Farey 分数 (a/b, c/d)（bc−ad=1）的中点且 max(b,d) < q。
设 2x = m/n 既约，中点条件给出 bd = nk、bc = (mk+1)/2、ad = (mk−1)/2；
由 gcd(k, p²k²−1) = 1 强制 k = 1，条件塌缩为上述单一形式。

**计数**（`code/std.cpp`，O(Σ τ) ≈ 0.4s @ Q=10^8）：
- p = 1：任意偶 q ∈ (100, Q]，贡献 Q/2 − 50；
- 3 ≤ p < Q/100：枚举 A=(p−1)/2 与 B=(p+1)/2 的因子对 (d, b)，
  统计乘积 d·b ∈ (50p, Q/2]（A、B 互素 ⟹ 乘积两两不同，无需去重）。

**验证**：
- `code/brute.cpp`：定义忠实的 Stern-Brocot 祖先对走查暴力，
  与 std 在 Q = 2000 / 10^4 / 10^5 完全一致（950 / 4950 / 50271）；
- Q = 10^8 输出 52374425，与 PE 官方答案精确一致。
