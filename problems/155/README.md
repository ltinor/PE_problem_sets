# 155 — 电容电路

来源：改编自 Project Euler Problem 155

## 原题意

求使用不超过 18 个相同电容，通过串并联组合能获得的不同总电容值数量。

原题答案：3857447。

## 题目

参数化 N（≤ 18），求 D(N) = 使用不超过 N 个电容可获得的不同总电容值数量。

## 数据范围

- N ≤ 18

## 算法

**std**: DP + 分数 + set 去重。
1. 用分数（分子/分母）表示电容值，1 个电容值为 1/1。
2. DP：exact[n] 表示恰好使用 n 个电容可获得的所有电容值。
3. 递推：exact[n] = 对所有 1 ≤ k < n，exact[k] 与 exact[n−k] 的所有组合：
   - 并联：C = C₁ + C₂ = (n₁d₂ + n₂d₁)/(d₁d₂)
   - 串联：C = 1/(1/C₁ + 1/C₂) = (n₁n₂)/(d₁n₂ + d₂n₁)
4. D(N) = ∪_{n=1}^{N} exact[n] 的大小。

**brute**: 相同的 DP 算法，限 N ≤ 8 用于快速验证。

## 改编方向

1. **参数化 N**：将固定 N=18 改为输入参数。
2. **分数表示**：使用最简分数避免精度问题。
3. **DP 递推**：从小 n 到大 n 递推，每次枚举分组 (k, n−k)。
4. **PE 答案验证**：N=18 时输出 3857447。
