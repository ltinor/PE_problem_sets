# 169 — 2 的幂之和

来源：改编自 Project Euler Problem 169

## 原题意

求 f(10^25)，其中 f(n) 表示将 n 表示为 2 的幂之和且每个幂至多使用两次的不同方式数。原题答案：178653872807。

## 题目

参数化 N：输入 N（≤ 10^25，用字符串表示），求 f(N)。

## 数据范围

- N ≤ 10^25

## 算法

**std**: 使用递推公式：
- f(0) = 1
- N 为偶数：f(N) = f(N/2) + f(N/2 - 1)
- N 为奇数：f(N) = f(N/2)
使用 `__int128` 存储 N 和结果，`map` 记忆化。N ≤ 10^25 < 2^84，递归深度不超过 84 层。

**brute**: 对小的 N（≤ 10^6）使用 DP 数组直接计算 f(N)，用于验证递推公式。

## 改编方向

1. **参数化 N**：将固定 N=10^25 改为任意输入。
2. **大整数记忆化**：使用 `__int128` 处理大数。
3. **PE 答案验证**：(N=10^25) 输出 178653872807。
