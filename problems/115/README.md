# 115 — Counting Block Combinations II

来源：改编自 Project Euler Problem 115

## 原题意

F(M,n) 表示用黑色方块和最短长度为 M 的红色方块填充长度为 n 的行的方法数。原题求 M=50 时使 F(M,n) > 10^6 的最小 n。答案：168。

## 题目

输入整数 M 和 K，求使 F(M,n) > K 的最小 n。

## 数据范围

- 2 ≤ M ≤ 50
- 1 ≤ K ≤ 10^6

## 算法

使用与 PE 114 相同的 DP 公式计算 F(M,n)：
- dp[0] = 1
- dp[i] = dp[i-1] + Σ_{j=M}^{i} dp[i-j-1]（dp[-1]=1）

从 n=M 开始递增，每次计算 F(M,n) 并检查是否超过 K。由于 K ≤ 10^6 且 M ≥ 2，n 的增长速度很快（F 随 n 指数增长），n 不会超过 200。

时间复杂度 O(n²)，其中 n ≤ 200。

## 改编方向与取舍

### 改编方向
1. **参数化 M 和 K** → 支持 M ≤ 50, K ≤ 10^6（本题采用）
2. **大范围 K** → K ≤ 10^18，需要大整数
3. **输出 F(M,n) 值** → 给定 M 和 n，直接输出 F(M,n)
4. **固定 K 变化 M** → 输入 K，输出使 F(M,n)>K 的最小 n 关于 M 的表格

### 取舍理由
- 选择参数化 M 和 K：在 PE 114 基础上扩展，保留原题核心
- K 限制在 10^6：原题范围，计算量可控
- 不选择大范围：答案增长快，大 K 需要大整数，改变难度
