# 二维格阵中的阿米巴原虫（PE 762 缩数据版）

来源：改编自 [Project Euler Problem 762](https://projecteuler.net/problem=762)

## 原题意

4 行无穷列的格阵，阿米巴原虫从 $(x,y)$ 分裂为 $(x+1,y)$ 与 $(x+1,(y+1)\bmod 4)$（目标需为空）。
求经过 $N$ 次分裂后不同分布的个数 $C(N)$，原题求 $C(100000)$ 的最后九位数字。

已知：$C(2)=2$，$C(10)=1301$，$C(20)=5895236$，$C(100)$ 最后九位为 $125923036$。

## 题目（缩数据）

给定 $N$（$0 \le N \le 20$），直接输出精确值 $C(N)$（无需取模）。

## 数据范围

- $0 \le N \le 20$
- $C(20) = 5895236$，答案在 64 位整数范围内。

## 算法

**BFS 逐层枚举 + bitset 状态编码 + sort/unique 去重。**

- 把「当前占据的方格集合」作为一个状态。方格 $(x,y)$ 编码为一位 `bit = x*4+y`，
  整个状态用一个 128 位无符号整数表示（$N\le20$ 时最多用到 84 位）。
- 初始状态只有 $(0,0)$。每一层对每个状态、每只变形虫尝试分裂：
  若 $(x+1,y)$ 与 $(x+1,(y+1)\bmod4)$ 都为空，则删除自身、加入两个子方格，得到后继状态。
- 收集本层全部后继状态后 `sort + unique` 去重，得到下一层状态集合。
- 迭代 $N$ 次后，集合大小即为 $C(N)$。

复杂度约为状态总数 $\sum_{k=0}^{N} C(k)$ 级别，$C(20)\approx 5.9\times10^6$，可秒级完成。

`code/std.cpp` 为标准解（bitset 编码），`code/brute.cpp` 为独立朴素实现（`std::set` 存有序列表），
两者在 `scripts/check.sh` 中对拍验证一致。

> 注：原题 $C(100000)$ 需要借助线性递推/矩阵快速幂等进阶方法；本缩数据版仅需在 $N\le20$
> 的小范围内给出精确值，故采用直接枚举的确定性算法，未硬编码任何答案。
