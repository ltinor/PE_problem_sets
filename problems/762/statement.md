# 二维格阵中的阿米巴原虫

## 题目描述

考虑一个有 $4$ 行、无穷多列的二维格阵。

一开始只有一只阿米巴原虫位于方格 $(0,0)$。原本位于方格 $(x,y)$ 中的阿米巴原虫，在**目标方格为空**的前提下，可以分裂成两只阿米巴原虫，并分别占据方格 $(x+1,y)$ 和 $(x+1,(y+1) \bmod 4)$。

经过 $N$ 次分裂后，格阵中会有 $N+1$ 只阿米巴原虫。不同的分裂顺序可能得到相同的分布，这些均算作**同一种**分布。记 $C(N)$ 为经过 $N$ 次分裂后所有不同分布的总数。

例如，$C(2)=2$，$C(10)=1301$，$C(20)=5895236$。

请你给定 $N$，计算 $C(N)$。

---

## 输入格式

一行一个整数 $N$。

---

## 输出格式

一行一个整数 $C(N)$。

---

## 样例

### 输入

```
2
```

### 输出

```
2
```

---

### 输入

```
10
```

### 输出

```
1301
```

---

### 输入

```
20
```

### 输出

```
5895236
```

---

## 数据范围

$0 \le N \le 20$
