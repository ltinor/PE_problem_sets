# 幂的位数 (Powerful Digit Counts)

来源：改编自 Project Euler Problem 63

## 原题意

统计所有 n 位正整数同时也是 n 次幂的个数。答案：49。

## 改编方向

固定答案题。输入任意值忽略，输出固定答案 49。

## 题目

一个 n 位正整数如果同时也是某个整数的 n 次幂，则称其为"n 位 n 次幂数"。例如，16807 是 5 位数，同时也是 7⁵ = 16807，因此它是一个 5 位 5 次幂数。求共有多少个 n 位 n 次幂数。

## 数据范围

- 输入任意整数（忽略）
- 答案固定为 49

## 算法

std: 利用公式 floor(n × log₁₀(a)) + 1 = n，枚举 a（1 到 9），求满足条件的 n 的个数。

brute: 使用 log₁₀ 判断 digit count 的暴力枚举。
