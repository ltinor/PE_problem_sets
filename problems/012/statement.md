# Highly Divisible Triangular Number

来源：改编自 Project Euler Problem 12

## 原题意

三角形数是通过累加自然数所得到的数。例如，第$7$个三角形数是$1 + 2 + 3 + 4 + 5 + 6 + 7 = 28$。前十个三角形数分别是：

$$1, 3, 6, 10, 15, 21, 28, 36, 45, 55, \ldots $$

$28$是第一个约数数量超过五的三角形数。

求第一个约数数量超过五百的三角形数。

## 题目

给定一个正整数 $K$，请你求出第一个约数数量超过 $K$ 的三角形数。

## 输入格式

一行，一个整数 $K$。

## 输出格式

一行，一个整数，表示第一个约数数量超过 $K$ 的三角形数。

## 样例

### 输入
```
5
```
### 输出
```
28
```

（说明：$28$ 是第一个约数数量超过 $5$ 的三角形数。）

## 数据范围

$1 \le K \le 10^3$

## 算法

约数个数定理 + 质因数分解

对于三角形数 $T_n = n(n+1)/2$，需要高效计算其约数个数。

时间复杂度：$O(\sqrt{n})$ 或更优
