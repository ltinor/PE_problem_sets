# 170 — 全数字乘积拼接

来源：改编自 Project Euler Problem 170

## 原题意

求最大的 0~9 全数字数，它可由一个整数与至少两个其他整数乘积连接而成，且所有输入数字的连接也是 0~9 全数字。原题答案：9857164023。

## 题目

固定答案题。输入任意标志（如 1），输出最大全数字拼接积 9857164023。

## 数据范围

- 输入恒为 1

## 算法

**std**: 枚举基数 a（1-99），然后 DFS 搜索乘数组合。对于每个基数，预计算所有可能的乘数及其对应积，要求积和乘数各自无重复数字。DFS 过程中维护已用积数字掩码和已用输入数字掩码，剪枝重叠。找到的最大全数字串即为答案。

**brute**: 同算法验证。

## 改编方向

1. **固定答案题**：输入为占位符，输出固定答案 9857164023。
2. **DFS + 剪枝**：通过位掩码快速判重。
3. **PE 答案验证**：输出 9857164023。
