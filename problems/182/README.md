# RSA 加密

来源：改编自 Project Euler Problem 182

## 原题意

给定 p=1009, q=3643，φ = (p-1)(q-1)。找出所有满足 1<e<φ 且 gcd(e,φ)=1 的 e，使得未加密消息数最少，求这些 e 的和。答案为 399788195976。

## 题目

给定两个不同的素数 p 和 q，计算所有满足条件的 e 之和。

## 数据范围

- 3 ≤ p, q ≤ 5000（p ≠ q）
- 枚举 e 范围可能较大

## 算法

未加密消息数公式：U(e) = (1 + gcd(e-1, p-1)) · (1 + gcd(e-1, q-1))

枚举所有满足 gcd(e, φ)=1 的 e（1<e<φ），计算 U(e)，记录最小值，对达到最小值的 e 求和。

## 改编方向

1. **参数化 p, q**：原题固定 p=1009, q=3643，改编后输入任意两个素数。
2. **答案范围**：对于较小素数，枚举量可控；原 PE 答案作为第一个测试点。
3. **可替代算法**：也可通过分析 gcd(e-1, p-1) 的可能值来优化，但直接枚举在小范围内足够。
