# 唯一的整数边直角三角形

来源：改编自 Project Euler Problem 75

## 原题意

给定电线长度 L，求有多少种方式可以弯折成整数边直角三角形。原题求：对于 L ≤ 1,500,000，有多少个 L 恰好只有一种弯折方式？答案为 161667。

## 题目

给定 M，求所有 L ≤ M 中，有多少个 L 恰好只有一种方式可以弯折成整数边直角三角形（忽略缩放产生的重复，即 (3,4,5) 和 (6,8,10) 视为不同方式）。

## 数据范围

- 12 ≤ M ≤ 1,500,000

## 算法

使用欧几里得公式生成所有原始勾股数：(a, b, c) = (m²-n², 2mn, m²+n²)，其中 m > n > 0，gcd(m,n) = 1，m-n 为奇数。对每个原始勾股数，周长为 p = 2m(m+n)，将其所有倍数 k·p ≤ M 计入统计。最后统计周长的解数为 1 的个数。
