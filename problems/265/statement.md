# 二进制环

## 题目描述

$2^N$ 个二进制位可以排成一圈，使得按顺时针顺序得到的所有 $N$ 位二进制子串**互不相同**（即每一个可能的 $N$ 位二进制子串恰好出现一次）。

例如 $N=3$ 时，共有两种不同的排列（不考虑旋转）：

- `00010111`：子串依次为 000, 001, 010, 101, 011, 111, 110, 100
- `00011101`：子串依次为 000, 001, 011, 111, 110, 101, 010, 100

每一种排列按如下方式**编码**为一个整数：以全为 $0$ 的 $N$ 位子串作为最高位，沿顺时针将所有 $2^N$ 个二进制位拼接成一个 $2^N$ 位二进制数。

$N=3$ 时：
- `00010111₂ = 23`
- `00011101₂ = 29`

记 $S(N)$ 为所有不同排列的编码之和。已知 $S(3) = 23 + 29 = 52$。

给定 $N$，求 $S(N)$。

---

## 输入格式

一行，一个整数 $N$。

---

## 输出格式

一行，一个整数，表示 $S(N)$。

---

## 样例

### 输入
```
3
```

### 输出
```
52
```

### 输入
```
4
```

### 输出
```
51504
```

---

## 数据范围

- $3 \le N \le 5$
