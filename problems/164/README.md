# 164 — 连续三位和

来源：改编自 Project Euler Problem 164

## 原题意

求有多少个 20 位数满足任意连续三位的和不超过 9。原题答案：378158756814587。

## 题目

参数化 N：输入 N (≤ 20)，求有多少个 N 位数满足任意连续三位的和 ≤ 9。

## 数据范围

- 1 ≤ N ≤ 20

## 算法

**std**: DP。dp[a][b] 表示末两位为 ab 的方案数。转移：枚举下一位 c (0~9)，若 a+b+c ≤ 9 则 dp_new[b][c] += dp[a][b]。初始化：前两位满足 a+b ≤ 9 且 a ≠ 0。时间复杂度 O(N·10²·10) = O(1000N)。

**brute**: 对 N ≤ 6 直接枚举所有 N 位数验证；更大 N 使用同 std 的 DP。

## 改编方向

1. **参数化 N**：将固定 N=20 改为输入参数。
2. **DP 状态设计**：仅需保存末两位。
3. **PE 答案验证**：(N=20) 输出 378158756814587。
