# 207 — 整数分拆等式 (Integer Partition Equations)

来源：改编自 Project Euler Problem 207

## 原题意

对于某些正整数 k，存在形如 4^t = 2^t + k 的整数分拆。若 t 为整数，则为完美分拆。
对 m ≥ 1，P(m) 为 k ≤ m 的分拆中完美分拆的比例。
求使 P(m) < 1/12345 的最小 m。

原题答案：44043947822（待验证）

## 题目

参数化比例。输入 a 和 b，求使 P(m) < a/b 的最小正整数 m。

## 数据范围

- 1 ≤ a < b ≤ 20000
- 答案 ≤ 10^12

## 算法

**std**: 总的分拆数 = 满足 n(n-1) ≤ m 的 n 的个数（n ≥ 2）。完美分拆数 = 满足 2^t(2^t-1) ≤ m 的 t 的个数（t ≥ 1）。从小到大枚举 pronic 数 n(n-1) 作为 m，在每个 m 处计算完美分拆数，检查比例是否满足条件。

**brute**: 相同的迭代逻辑，限小范围用于验证。

## 改编方向

1. **参数化比例**：将固定比例 1/12345 改为可输入的 a/b。
2. **枚举优化**：仅在 pronic 数处检查（P(m) 仅在完美分拆数或总计数变化时改变）。
3. **数学公式**：完美分拆数为 O(log m)，总分拆数为 O(√m)，比例递减。
4. **PE 答案验证**：输入 a=1, b=12345 时输出原题答案。
