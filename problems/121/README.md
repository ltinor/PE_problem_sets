# 121 — 碟子游戏奖金

来源：改编自 Project Euler Problem 121

## 原题意

袋中初始有 1 红 1 蓝碟子，每轮随机抽取后放回，并多放 1 个红碟子。玩家付 £1，结束时蓝碟多于红碟则获胜。15 轮游戏，求最高奖金（整数），答案：2269。

## 题目

输入回合数 N，求 N 轮游戏的最高奖金（floor(1/P)，其中 P 为获胜概率）。

## 数据范围

- 1 ≤ N ≤ 15

## 算法

使用分数精确计算概率。第 i 轮（1-indexed）蓝碟概率 1/(i+1)，红碟概率 i/(i+1)。获胜条件为蓝碟数 > N/2。枚举所有 2^N 种结果组合，用公分母 ∏(i+1) 通分，分子为所有获胜组合的红碟因子乘积之和。时间复杂度 O(2^N)，N≤15 可行。

验证：N=4 时概率 11/120，奖金=floor(120/11)=10；N=15 时奖金=2269。

## 改编方向与取舍

### 改编方向
1. **参数化 N** → 输入 N 求奖金（本题采用）
2. **大 N 近似** → N ≤ 100，用高精度或动态规划
3. **变种规则** → 初始碟数可变
4. **期望值版本** → 求期望净收益

### 取舍理由
- 选择参数化 N：N=15 包含原题，N≤15 保证暴力枚举可行
- 分数精确计算：用 __int128 避免浮点误差
- 枚举法简单直接，N≤15 时 2^15=32768 次计算瞬时完成
