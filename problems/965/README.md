# 最小分数期望值

来源：改编自 Project Euler Problem 965

## 原题意

记 $\{x\}$ 为实数 $x$ 的小数部分（$0 \le \{x\} < 1$）。

定义 $f_N(x)$ 为所有满足 $0 < n \le N$ 的整数 $n$ 中 $\{n x\}$ 的**最小**值，
$F(N)$ 为当 $x$ 在 $[0,1]$ 上均匀随机选取时 $f_N(x)$ 的期望值。

已知 $F(1)=\frac12$，$F(4)=\frac14$，$F(10)\approx 0.1319444444444$。

求 $F(10^4)$，四舍五入到小数点后 13 位。

## 题目（简单版 / 缩数据）

给定整数 $N$，求 $F(N)$，四舍五入到小数点后 13 位作为输出。

## 数据范围

$1 \le N \le 10^4$

## 算法

三间隙定理（three-gap theorem）：对 $x$ 落在相邻的 $N$ 阶 Farey 分数
$a/b < c/d$（$bc-ad=1$，$b,d\le N$，$b+d>N$）之间时，
$f_N(x)=bx-a$，在区间 $[a/b, c/d]$ 上为一段底长 $1/(bd)$、高 $1/d$ 的三角形，面积
$1/(2bd^2)$。枚举所有相邻 Farey 对：

$$F(N)=\frac12\sum_{b=1}^{N}\sum_{d=1}^{N}\frac{[\,\gcd(b,d)=1\,][\,b+d>N\,]}{b\,d^2}$$

$O(N^2)$，用 long double + Kahan 求和保证 13 位小数精度。

验证点：$F(1)=0.5$，$F(2)=0.375$，$F(4)=0.25$，$F(10)\approx 0.1319444444444$。
