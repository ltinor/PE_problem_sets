# PE392 - 单位圆网格覆盖

来源：改编自 Project Euler Problem 392

## 原题意

N×N 的非等距网格覆盖单位圆，求最小红色面积。N=400 时的答案。

## 题目

给定 N，求最优网格线位置使与单位圆有交的网格总面积最小。

## 算法

- 优化问题：每条网格线的位置是连续变量
- 红色面积 = 对称性 → 只需优化第一象限
- 可用二分/牛顿法优化每条网格线位置

## 改编方向

1. **非单位圆**：圆的半径为 R，R 作为输入参数
2. **矩形区域**：网格范围改为 [-a, a] × [-b, b]
3. **三维版本**：求最小红色体积（单位球）
4. **非对称网格**：允许水平线和竖直线数量不同
