# Monopoly Odds

来源：改编自 Project Euler Problem 84

## 原题意

在大富翁游戏中，使用两个4面骰子，求三个最有可能停下的方格所构成的六位数字串（按概率从高到低排列）。答案：101524。

## 题目

给定骰子面数 $S$（$4 \le S \le 6$），使用两个 $S$ 面骰子进行大富翁游戏模拟。求三个最有可能停下的方格编号（00-39）按概率从高到低排列后拼接成的六位数字串。

游戏规则：
- 40个方格，从GO(00)出发
- 掷两个S面骰子，点数相加前进
- 连续三次掷出对子则直接入狱(JAIL=10)
- 落在G2J(30)直接入狱
- 落在CC(2,17,33)：16张卡中2张会移动（1张去GO，1张去JAIL），其余不动
- 落在CH(7,22,36)：16张卡中10张会移动（GO/JAIL/C1/E3/H2/R1/next R×2/next U/back 3），其余不动
- CH卡"后退三步"若落在CC格上需要再抽CC卡

## 数据范围

$4 \le S \le 6$

## 改编思路

### 方向一：参数化骰子面数（✅ 采用）
- 做法：将骰子面数 $S$ 作为输入参数，$4 \le S \le 6$
- 优点：保留原题核心模拟逻辑，数据范围合理
- 缺点：无
- 结论：✅ 采用

### 方向二：参数化更多棋盘参数
- 做法：允许修改棋盘布局、卡牌数量等
- 优点：灵活性更高
- 缺点：大幅增加复杂度，脱离原题核心
- 结论：❌ 不采用

## 算法

蒙特卡洛模拟。
- 模拟 $2 \times 10^7$ 次掷骰子
- 维护CC和CH卡牌堆（循环抽取）
- 处理连续对子入狱、G2J、CC卡、CH卡以及CH→CC的连锁
- 统计每个方格被访问次数，排序取前三

时间复杂度：$O(\text{ITER})$，其中 $\text{ITER} = 2 \times 10^7$
