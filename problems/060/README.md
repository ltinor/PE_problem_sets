# 素数对集合 (Prime Pair Sets)

来源：改编自 Project Euler Problem 60

## 原题意

找出 5 个素数，任意两个按任意顺序拼接后仍是素数，求最小和。答案：26033。

## 改编方向

参数化 K（2≤K≤5）。输入 K，求 K 个素数满足条件的集合的最小和。

## 题目

给定整数 K，找出 K 个素数，使得任意两个素数以任意顺序拼接后仍然是素数。求满足条件的 K 个素数的最小和。

## 数据范围

- K: 2 ≤ K ≤ 5
- 素数上限约 10000

## 算法

std: 埃氏筛生成素数 → 预计算两两拼接的素性 → DFS 搜索 K 个两两兼容的素数 → 求最小和。K=5 时搜索量较大，但可在合理时间内完成。

brute: 相同算法独立实现。
