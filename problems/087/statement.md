# 素数幂三元组

## 题目描述

最小的、可以表示为一个素数的平方、一个素数的立方和一个素数的四次方之和的数是 $28 = 2^2 + 2^3 + 2^4$。实际上，在小于 $50$ 的数中，一共有 $4$ 个数满足这一性质：

$$28 = 2^2+2^3+2^4$$
$$33 = 3^2+2^3+2^4$$
$$49 = 5^2+2^3+2^4$$
$$47 = 2^2+3^3+2^4$$

给定正整数 $N$，求所有满足 $p^2 + q^3 + r^4 < N$（$p,q,r$ 均为素数）的**不同值**的个数。

---

## 输入格式

输入一行，一个整数 $N$。

---

## 输出格式

输出一个整数，表示满足条件的不同的值的个数。

---

## 样例

### 输入
```
50
```

### 输出
```
4
```

---

## 数据范围

$1 \leq N \leq 5 \times 10^7$
