# 最大回文乘积

## 题目描述

回文数是指从前往后读和从后往前读都一样的数。由两个 $2$ 位数相乘得到的回文数中，最大的是 $9009 = 91 \times 99$。

给定因子的位数 $n$，求能表示为**两个 $n$ 位数乘积**的最大回文数。

特别地，当 $n=3$ 时即原题（PE004），答案为 $906609 = 913 \times 993$。

---

## 输入格式

第一行一个 token：

- 若为 `PE`，输出原题（$n=3$）的官方答案；
- 否则为整数 $n$，表示因子的位数。

---

## 输出格式

一行一个整数：两个 $n$ 位数乘积能得到的最大回文数。

---

## 样例

### 输入

```
2
```

### 输出

```
9009
```

# 最大回文乘积

回文数是指从前往后读和从后往前读都一样的数。由两个 $2$ 位数相乘得到的回文数中，最大的是 $9009 = 91 \times 99$。

给定因子的位数 $n$，求能表示为**两个 $n$ 位数乘积**的最大回文数。

特别地，当 $n=3$ 时即原题（PE004），答案为 $（见 data/） = 913 \times 993$。

---

## 输入格式

第一行一个 token：

- 若为 `PE`，输出原题（$n=3$）的官方答案；
- 否则为整数 $n$，表示因子的位数。

---

## 输出格式

一行一个整数：两个 $n$ 位数乘积能得到的最大回文数。

---

## 样例

### 输入

```
2
```

### 输出

```
9009
```

---

## 数据范围

- 若输入为 `PE`，输出 $906609$；
- 否则 $2 \le n \le 7$。

## 提示

- $n=2$：$9009 = 91 \times 99$
- $n=3$：$906609 = 913 \times 993$
- $n=4$：$99000099 = 9999 \times 9901$
