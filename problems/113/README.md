# 113 — Non-bouncy Numbers

来源：改编自 Project Euler Problem 113

## 原题意

统计小于 10^100 的非弹跳数（即上升数或下降数）的个数。答案：51161058134250。

## 题目

输入整数 D（1 ≤ D ≤ 100），求小于 10^D 的非弹跳数个数。

## 数据范围

- 1 ≤ D ≤ 100

## 算法

使用组合数学公式：
- 上升数个数 = C(D+9, 9) - 1
- 下降数个数 = C(D+10, 10) - D - 1
- 重叠数（所有数位相同，既是上升又是下降）= 9 × D
- 答案 = 上升数 + 下降数 - 重叠数

使用 `__int128` 处理大整数（D=100 时答案约 5×10^13）。组合数通过递推计算，复杂度 O(D²) 或 O(D)。

## 改编方向与取舍

### 改编方向
1. **参数化 D** → 支持 D ≤ 100（本题采用）
2. **输出上升数和下降数分别** → 输出两个分项值
3. **mod M 版本** → 输出答案对 M 取模的结果
4. **统计 bouncy 数** → 改为统计弹跳数个数（总数-非弹跳数）

### 取舍理由
- 选择参数化 D：保留原题核心组合数学推导
- D 限制在 100：原题范围，`__int128` 足够
- 不选择 mod 版本：不改变原题难度，避免引入无关的模运算
