# PE036 — 双进制回文数（Double-base Palindromes）

来源：改编自 Project Euler Problem 36

## 原题意

十进制数 $585 = 1001001001_2$（二进制表示），因此它在十进制和二进制下都是回文数。求所有小于一百万，且在十进制和二进制下均回文的数之和。

原题答案：$872187$。

## 改编方向

- **参数化**：原题为固定上界 $10^6$，改编为输入参数 $N$，求 $< N$ 且在十进制和二进制下均回文的数之和。
- **多组输入**：支持 $T$ 组测试数据。
- **数据范围**：$N \le 10^6$。

## 算法

- **std**：枚举 $1 \sim \min(N, 10^6)$，检查十进制回文（字符串反转比较）和二进制回文（构建二进制字符串后检查）。使用前缀和数组 $O(1)$ 回答查询。总复杂度 $O(\max N + T)$。
- **brute**：相同算法，独立实现（十进制回文用数字反转判断，二进制回文用位数组判断），每查询一次重新枚举。

## PE 原答案验证

输入 $N = 10^6$，输出应为 $872187$。
