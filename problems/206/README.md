# 206 — 被遮挡的平方数 (Concealed Square)

来源：改编自 Project Euler Problem 206

## 原题意

找出唯一一个正整数 n，使得 n² 的形式为 1_2_3_4_5_6_7_8_9_0，其中每个 "_" 代表一位数字。

原题答案：1389019170。

## 题目

参数化模式串。输入一个包含数字和下划线的模式串（如 "1_2_3_4_5_6_7_8_9_0"），输出满足 n² 匹配该模式的最小正整数 n。

## 数据范围

- 模式串长度 L ≤ 19
- 保证答案存在且在 64 位整数范围内

## 算法

**std**: 从下界开始枚举 n，步长为 10（因为模式串末位为 0 时 n 必以 0 结尾）。对每个 n 计算 n² 并与模式串匹配。使用 `__int128` 处理大数平方。

**brute**: 相同的枚举算法，限制在较小范围内用于对拍验证。

## 改编方向

1. **参数化模式串**：将固定的 "1_2_3_4_5_6_7_8_9_0" 改为可输入的模式串。
2. **步长优化**：根据模式串末位数字确定 n 的可行末位，减少搜索空间。
3. **多组测试**：支持多个不同的模式串作为测试数据。
4. **PE 答案验证**：输入原题模式串时输出 1389019170。
