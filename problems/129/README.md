# 129 — Repunit Divisibility

来源：改编自 Project Euler Problem 129

## 原题意

求 A(n) > 1,000,000 的最小 n（gcd(n,10)=1）。

原题答案：1000023。

## 题目

参数化 T：输入 T (≤ 10⁶)，求 A(n) > T 的最小 n。

## 数据范围

- T ≤ 1,000,000

## 算法

从 n=T 开始枚举（跳过偶数和 5 的倍数），对每个 n 计算 A(n)：使用余数递推 r_{i+1} = (r_i × 10 + 1) mod n，统计步数直到 r=0。找到第一个 A(n) > T 的 n 即停止。

## 改编方向

1. **参数化 T**：将原题固定 T=10⁶ 改为输入参数。
2. **小范围版本**：T ≤ 100 可用于对拍验证。
3. **固定答案验证**：T=1000000 作为测试点，输出 1000023。
