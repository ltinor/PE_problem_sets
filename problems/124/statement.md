# 有序根积

## 题目描述

对于正整数 n，定义 rad(n) 为 n 的所有不同质因子的乘积。例如：
- rad(1) = 1
- rad(8) = rad(2³) = 2
- rad(12) = rad(2²×3) = 2×3 = 6
- rad(504) = rad(2³×3²×7) = 2×3×7 = 42

将所有 1 ≤ n ≤ N 按 rad(n) 升序排列，若 rad 相同则按 n 升序排列。给定 N 和 K，求排序后第 K 个 n。

---

## 输入格式

一行，两个整数 N 和 K，空格分隔。

---

## 输出格式

一行，一个整数，表示排序后第 K 个 n。

---

## 样例

### 输入
```
10 4
```

### 输出
```
8
```

**解释**：N=10 时排序为：
rad(1)=1, rad(2)=2, rad(4)=2, rad(8)=2, rad(3)=3, rad(9)=3, rad(5)=5, rad(10)=10, rad(7)=7, rad(6)=6
排序后：1, 2, 4, 8, 3, 9, 5, 10, 7, 6。第 4 个是 8。

---

## 数据范围

- 1 ≤ K ≤ N ≤ 100000
