# 564 - 最大多边形 (Maximal polygons)

来源：改编自 Project Euler Problem 564

## 原题意

将长度为 2n-3 的线段随机分割成 n 段（整数长度，n ≥ 3）。按照分割顺序连接这些边，构成面积最大的凸 n 边形。所有 C(2n-4, n-1) 种分割等概率。

E(n) 为期望面积。已知 E(3) = 0.433013，E(4) = 1.299038。
记 S(k) = Σ_{n=3}^{k} E(n)。
已知 S(3) = 0.433013，S(4) = 1.732051，S(10) = 66.955511。

求 S(50)，保留 6 位小数。

PE 答案：12363.698750。

## 题目

给定 K，求 S(K) = Σ_{n=3}^{K} E(n)，保留 6 位小数。

## 数据范围

- 3 ≤ K ≤ 50

## 算法

最大面积的凸 n 边形必然是圆内接多边形（所有顶点共圆）。给定边长 a_i，面积通过解方程 Σ arcsin(a_i/(2R)) = π 求外接圆半径 R，再算面积。

由于只需考虑边长的多重集（顺序无关），可枚举整数分拆。n 条边之和为 2n-3，每边 ≥ 1。令 x_i = a_i - 1 ≥ 0，Σ x_i = n-3。不同多重集的个数为分拆数 p(n-3)（对 n=50 为 p(47)=124754）。

对每个多重集：
1. 计算排列数（多项式系数）
2. 数值求解 R，计算面积
3. 加权平均得 E(n)

时间复杂度：O(p(n-3) · n · iters)。

## 改编方向

1. **最大面积**：求最大可能面积（而非期望值）。
2. **固定外接圆**：给定半径 R，求内接多边形期望面积。
3. **非整数边**：放宽为实数边长。
4. **三维推广**：球面上的测地多边形。
