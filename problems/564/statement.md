# 最大多边形

## 题目描述

将长度为 2n-3 的线段随机分割成 n 段（整数长度，n ≥ 3）。按照分割顺序连接这些边，构成面积最大的凸 n 边形。所有 C(2n-4, n-1) 种分割等概率。

记 E(n) 为期望面积。已知 E(3) = 0.433013。
记 S(k) = Σ_{n=3}^{k} E(n)。已知 S(3) = 0.433013。

给定 K，求 S(K)，保留 6 位小数。

---

## 输入格式

一行，一个整数 K。

---

## 输出格式

一行，一个实数，保留 6 位小数，表示 S(K)。

---

## 样例

### 输入
```
4
```

### 输出
```
1.732051
```

---

## 数据范围

- 3 ≤ K ≤ 50
