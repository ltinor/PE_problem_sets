# Flea Circus

来源：改编自 Project Euler Problem 213

## 原题意

30×30 网格，每个格子一只跳蚤。每次钟声，每只跳蚤等概率跳向相邻格子。求 50 次钟声后空白格子的期望数（保留 6 位小数）。

## 题目

给定 N（1 ≤ N ≤ 30）和 R（1 ≤ R ≤ 50），在 N×N 网格上，每个格子初始一只跳蚤。每次跳蚤等概率跳向四邻之一（边界/角落选择更少）。求 R 次跳跃后空白格子的期望数，保留 6 位小数。

## 数据范围

- 1 ≤ N ≤ 30
- 1 ≤ R ≤ 50
- PE 答案: N=30, R=50 → 330.721154

## 算法

利用跳蚤移动独立性：对每个起始位置 i，DP 计算 R 步后到达位置 j 的概率 p_{i,j}。空白格子期望 = Σ_j Π_i (1 - p_{i,j})。复杂度 O(N⁴·R)。

## 改编方向

1. **参数化 N, R**（采用）：将固定 30×30, 50 改为可变
2. **参数化跳蚤分布**（未采用）：改变初始分布偏离原题
3. **更改移动规则**（未采用）：例如允许停留，偏离原题
