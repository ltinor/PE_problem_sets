# 5D Summation（五维求和）

来源：改编自 Project Euler Problem 968

## 原题意

定义

$$P(X_{a,b},X_{a,c},X_{a,d},X_{a,e},X_{b,c},X_{b,d},X_{b,e},X_{c,d},X_{c,e},X_{d,e})$$

为所有满足「任意两个变量之和不超过对应上界」的非负整数五元组 $(a,b,c,d,e)$ 对应的 $2^a3^b5^c7^d11^e$ 之和。例如 $P(2,2,\dots,2)=7120$，$P(1,2,\dots,10)\equiv799809376\pmod{10^9+7}$。

再定义数列 $A$：$A_0=1,A_1=7$，$A_n=(7A_{n-1}+A_{n-2}^2)\bmod(10^9+7)$；令 $Q(n)=P(A_{10n},\dots,A_{10n+9})$，求 $\sum_{0\le n<100}Q(n)\bmod(10^9+7)$。原题的难点在于 $X$ 值高达 $10^9$ 量级，需要处理 100 组、每组的 5 维带两两约束的求和，无法朴素枚举。

## 题目

给定 10 个非负整数作为 5 个变量两两和的上界，计算 $P$ 的值对 $10^9+7$ 取模。本简化版将每个上界缩到 $[0,15]$。

## 数据范围

$0 \le X \le 15$

## 算法

枚举 + 等比数列闭合式。

- 变量记为 $x_0=a,x_1=b,x_2=c,x_3=d,x_4=e$，两两约束 $x_i+x_j\le X_{i,j}$。
- 由于 $x_i+x_j\le X_{i,j}$ 且 $x_j\ge0$，故 $x_i\le\min_j X_{i,j}$，每个变量的枚举上界即其与其余变量上界的最小值。
- 枚举前 4 个变量 $a,b,c,d$（并剪枝两两约束），最后一个变量 $e$ 的上界为 $E=\min(X_{a,e}-a,X_{b,e}-b,X_{c,e}-c,X_{d,e}-d)$，其贡献为 $\sum_{e=0}^{E}11^e=\frac{11^{E+1}-1}{10}$，可用快速幂 + 逆元在 $O(\log E)$ 内求出。
- 总复杂度 $O(B^4\log B)$，其中 $B=\max X\le15$，可轻松通过。

验证：`P(2,...,2)=7120`、`P(1,2,...,10)=799809376` 均通过。
