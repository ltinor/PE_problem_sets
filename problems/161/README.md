# 161 — 三联骨牌

来源：改编自 Project Euler Problem 161

## 原题意

用六种三联骨牌（triominoes）拼满 9×12 网格，求拼法数。原题答案：20574308184277971。

## 题目

参数化 W, H：输入网格宽度 W 和高度 H（W×H 可被 3 整除），求用六种三联骨牌拼满网格的方案数。

## 数据范围

- 2 ≤ W, H ≤ 12
- W×H 是 3 的倍数

## 算法

**std**: 轮廓线 DP + 位压缩。逐格扫描，用 W 位（或 2W 位）mask 表示前方格子的填充状态。对每个空格尝试 6 种骨牌放置。使用 `map<ll,ll>` 存储 DP 状态。时间复杂度 O(W·H·S·6)，其中 S 为可达状态数（通常远小于 2^(2W)）。

**brute**: 对 W×H ≤ 24 的小网格使用 DFS 回溯暴力枚举；对更大网格回退到与 std 相同的 DP 算法验证。

## 改编方向

1. **参数化 W, H**：将固定 9×12 改为输入两个参数。
2. **轮廓线 DP**：逐格推进，状态压缩。
3. **PE 答案验证**：(W=9, H=12) 输出 20574308184277971。
