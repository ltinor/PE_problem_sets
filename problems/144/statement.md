# 一束激光多次反射的研究

## 题目描述

椭圆方程为 4x² + y² = 100，顶部缺口 -0.01 ≤ x ≤ +0.01。

激光从 (0.0, 10.1) 发出，第一次击中镜面于 (1.4, -9.6)。每次击中遵循反射定律。

给定允许的最大击中次数 $N$：若激光在此轨迹上于前 $N$ 次击中内离开椭圆，输出它离开前的击中次数；否则输出 $-1$。

原题（PE144）即求激光离开椭圆前的实际击中次数，答案为 $354$。

---

## 输入格式

第一行一个 token：

- 若为 `PE`，输出原题官方答案 $354$；
- 否则为整数 $N$（$1 \le N \le 10^7$），表示允许的最大击中次数。

---

## 输出格式

一行一个整数：若激光在前 $N$ 次击中内离开椭圆，输出击中次数；否则输出 $-1$。

---

## 样例

### 输入

```
354
```

### 输出

```
354
```
