# 166 — 纵横交错

来源：改编自 Project Euler Problem 166

## 原题意

在 4×4 方阵中填入 0-9 的数字，使得每一行、每一列和两条对角线上的数字之和均相等。求总填法数。原题答案：7130034。

## 题目

固定答案题。输入任意标志（如 1），输出总方案数 7130034。

## 数据范围

- 输入恒为 1

## 算法

**std**: 枚举左上角 3×3 的 9 个变量（每个 0-9），其余 7 格由行列对角线方程确定。对每个可能的和 S（0-36），验证所有变量均在 0-9 范围内且满足对角线约束。时间复杂度 O(37 × 10^9)，约 3.7 × 10^10 次循环，需数分钟。

**brute**: 同算法验证。

## 改编方向

1. **固定答案题**：输入为占位符，输出固定答案 7130034。
2. **等式约束优化**：利用行列对角线方程减少枚举变量数。
3. **PE 答案验证**：输出 7130034。
