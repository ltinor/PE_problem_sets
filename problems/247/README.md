# 双曲线下的正方形

来源：改编自 Project Euler Problem 247

## 原题意

在 y=1/x (x≥1) 下放置最大正方形。求使得 S_n 索引为 (3,3) 的最大 n。答案: 782252。

## 题目

给定 K，求使得 S_n 索引为 (K, K) 的最大 n。

## 数据范围

K ≤ 3。共 10 个测试点，包含原题数据 (K=3)。

## 算法

1. **优先队列模拟**: 使用最大堆维护候选正方形。每个候选由其左下角坐标 (x, y_base) 和索引 (left, below) 描述。

2. **正方形大小**: 在位置 (x, y_base) 处，最大正方形的边长 s 满足 s + y_base = 1/(x + s)，解二次方程得到 s。

3. **分裂**: 放置正方形后产生两个新候选：上方 (x, y_base+s) 和右侧 (x+s, y_base)，索引分别增加 below 和 left 计数。

4. **复杂度**: 需要模拟到目标索引 (K, K)。对 K=3，约需 10⁶ 个正方形。优先队列保证按大小顺序处理。
