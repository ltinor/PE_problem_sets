# 193 — Squarefree Numbers

来源：改编自 Project Euler Problem 193

## 原题意

求小于 2^50 的无平方因子数的个数。原题答案：684465067343069。

## 题目

参数化 K：输入 K（≤ 50），求小于 2^K 的无平方因子数的个数。

## 数据范围

- K ≤ 50

## 算法

**std**: 莫比乌斯函数 + 容斥原理：squarefree(N) = Σ_{i=1}^{√N} μ(i)·⌊N/i²⌋。使用线性筛计算 μ 至 √(2^K)，然后累加。√(2^50) ≈ 3.3×10^7，可在数秒内完成。

**brute**: 直接枚举 < 2^K 的数检查 squarefree，仅适用于 K ≤ 12。

## 改编方向

1. **参数化 K**：将原题固定 K=50 改为输入参数。
2. **小范围验证**：K ≤ 12 可用 brute 对拍。
3. **固定答案验证**：K=50 输出 684465067343069。
