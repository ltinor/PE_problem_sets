**莫比乌斯函数**μ(n)按照如下方式定义：
- μ(n) = (-1)<sup>ω(n)</sup>，如果n是无平方因子的（其中ω(n)是n的不同质因数的个数）
- μ(n) = 0 如果n不是无平方因子的。

记P(a,b)是在区间[a,b]中使得μ(n) = 1的整数n的个数。
记N(a,b)是在区间[a,b]中使得μ(n) = -1的整数n的个数。
举例而言，P(2,10) = 2，N(2,10) = 4.

记C(n)是满足如下条件的整数对(a,b)的数目：
-  1&nbsp;≤&nbsp;a&nbsp;≤&nbsp;b&nbsp;≤&nbsp;n,
-  99·N(a,b)&nbsp;≤&nbsp;100·P(a,b),
-  99·P(a,b)&nbsp;≤&nbsp;100·N(a,b).

例如，C(10)&nbsp;=&nbsp;13，C(500)&nbsp;=&nbsp;16676，而C(10&nbsp;000)&nbsp;=&nbsp;20155319.

求C(20&nbsp;000&nbsp;000)。
