# 323 — Bitwise-OR Operations on Random Integers

来源：改编自 Project Euler Problem 323

## 原题意

y_0, y_1, y_2, ... 是 32 位无符号随机整数序列（0 ≤ y_i < 2^32，均匀分布）。
定义 x_0 = 0，x_i = x_{i-1} | y_{i-1}（按位或）。
求最小的 N 使得对所有 i ≥ N 有 x_i = 2^32 - 1 的期望值，保留 10 位小数。

答案：6.3551758451。

## 题目

输入 K，求 32 位改为 K 位时的期望值，保留 10 位小数。

## 数据范围

- 1 ≤ K ≤ 32

## 算法

1. **概率期望公式**：每一位独立。设 p_j 为第 j 位已被置 1 的概率。E[N] = Σ_{j=0}^{K-1} 2^K / (2^K - 2^j)。复杂度 O(K)。
2. **蒙特卡洛模拟**：随机模拟多次取平均。

## 改编方向

1. 原题固定 K=32 → 参数化 K
2. 改为其他位运算（如 AND、XOR）
3. 考虑非均匀分布

选择方向 1：参数化 K，保留原题概率核心。
