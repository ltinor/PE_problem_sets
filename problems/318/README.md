# 318 — 2011 Nines

来源：改编自 Project Euler Problem 318

## 原题意

考虑形如 $\sqrt{p}+\sqrt{q}$ 的实数，其中 $p,q$ 为正整数且 $p<q$。对于满足 $(\sqrt{p}+\sqrt{q})^{2n}$ 小数部分趋近于 $1$（即 $\sqrt{q}-\sqrt{p}<1$）的 $(p,q)$ 对，定义 $C(p,q,n)$ 为 $(\sqrt{p}+\sqrt{q})^{2n}$ 小数部分开头连续 $9$ 的个数。$N(p,q)$ 是使 $C(p,q,n) \ge K$ 的最小 $n$。

原题 $K=2011$，求 $\sum_{p+q\le 2011} N(p,q)$。

答案：$709313889$。

## 题目

输入 $K$，求 $\sum_{p<q, p+q\le K} N(p,q)$，其中 $N(p,q)$ 是使小数部分至少有 $K$ 个连续前导 $9$ 的最小指数 $n$。

## 数据范围

- $1 \le K \le 2011$

## 算法

1. **数学公式法**：$(\sqrt{p}+\sqrt{q})^{2n}$ 的小数部分 $= 1 - (\sqrt{q}-\sqrt{p})^{2n}$。$C(p,q,n) = \lfloor -2n \cdot \log_{10}(\sqrt{q}-\sqrt{p}) \rfloor$。$N(p,q) = \lceil \frac{K}{-2\log_{10}(\sqrt{q}-\sqrt{p})} \rceil$。复杂度 $O(K^2)$。
2. **高精度计算**：直接用高精度浮点数计算所需的指数值。
3. **近似+验证**：用双精度近似计算 $N(p,q)$，再逐对验证。

## 改编方向

1. 原题固定 $K=2011$ → 参数化 $K$
2. 改变基数（如二进制下连续 $1$ 的个数）
3. 仅考虑 $p,q$ 互质等附加条件

选择方向 1：参数化 $K$，保留原题数学核心。
