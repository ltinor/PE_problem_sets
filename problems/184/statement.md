# 包含原点的三角形

## 题目描述

集合 $I_r$ 包含了以原点为圆心、半径为 $r$ 的圆内的所有格点 $(x,y)$，即满足 $x^2 + y^2 < r^2$ 的点（不包括原点 $(0,0)$）。

从 $I_r$ 中选取三个不同的点构成三角形，问有多少个三角形满足原点在其**内部**（不在边上）？

- 对于 $r=2$，有 8 个三角形满足条件。
- 对于 $r=3$，有 360 个三角形。
- 对于 $r=5$，有 10600 个三角形。

---

## 输入格式

第一行一个整数 $T$，表示测试数据组数。
接下来 $T$ 行，每行一个整数 $R$。

---

## 输出格式

对于每组数据，输出一行一个整数，表示答案。

---

## 样例

### 输入
```
1
2
```

### 输出
```
8
```

---

## 数据范围

- $1 \le T \le 10$
- $2 \le R \le 105$
