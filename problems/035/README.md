# PE035 — 圆周素数（Circular Primes）

来源：改编自 Project Euler Problem 35

## 原题意

$197$ 被称为圆周素数，因为将其逐位轮转所得到的数（$197$、$971$、$719$）都是素数。求小于一百万的圆周素数有多少个。

原题答案：$55$。

## 改编方向

- **参数化**：原题为固定上界 $10^6$，改编为输入参数 $N$，求 $< N$ 的圆周素数个数。
- **多组输入**：支持 $T$ 组测试数据。
- **数据范围**：$N \le 10^6$。

## 算法

- **std**：埃氏筛预处理 $10^6$ 以内的素数。对每个素数，生成其所有轮转（使用字符串旋转），检查是否均为素数。使用前缀计数数组 $O(1)$ 回答查询。总复杂度 $O(\max N \log \log \max N + T)$。
- **brute**：对每个数逐个判素（试除法 $O(\sqrt{n})$）+ 轮转检查，每查询一次重新计算。

## PE 原答案验证

输入 $N = 10^6$，输出应为 $55$。
