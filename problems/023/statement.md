# 非盈数和

## 题目描述

如果一个数的真约数（小于该数的正约数）之和恰好等于该数，则称该数为**完全数**。例如，28 的真约数为 1, 2, 4, 7, 14，其和为 28。

如果一个数的真约数之和小于该数，则称该数为**亏数**；如果大于该数，则称该数为**盈数**。

12 是最小的盈数（1+2+3+4+6=16>12），因此能表示为两个盈数之和的最小数是 24。

已知所有大于 28123 的整数都可以表示为两个盈数之和。

现在给出 T 个查询，每个查询给定一个整数 N，请计算 ≤N 中所有**不能**表示为两个盈数之和的正整数之和。

---

## 输入格式

第一行一个整数 T，表示查询数量。

接下来 T 行，每行一个整数 N。

---

## 输出格式

输出 T 行，每行一个整数，表示对应查询的答案。

---

## 样例

### 输入
```
2
23
24
```

### 输出
```
276
276
```

（1 到 23 都不能表示为两个盈数之和，其和为 1+2+...+23=276；24=12+12 可以，所以 ≤24 的答案仍是 276。）

---

## 数据范围

- $T \le 100$
- $1 \le N \le 28123$
