# 非盈数和

来源：改编自 Project Euler Problem 23

## 原题意

完全数：真约数之和等于自身。盈数：真约数之和大于自身。亏数：真约数之和小于自身。已知 >28123 的所有整数都可以表示为两个盈数之和。求所有不能表示为两个盈数之和的正整数之和。

## 题目

给定 T 个查询，每个查询给出整数 N，求 ≤N 中所有不能表示为两个盈数之和的正整数之和。

## 数据范围

T ≤ 100，N ≤ 28123

## 算法

- **std**：筛法求 [1, 28123] 所有数的约数和 → 标记盈数 → 两重循环标记可表示为两盈数之和的数 → 前缀和查询 O(1)。
- **brute**：对每个查询单独计算约数和并标记，O(N sqrt(N) + N²)。

## 改编方向

- 原题为求全局答案（≤28123），改为多组查询 + 参数化上界 N。
- 鼓励用筛法预处理 + 前缀和的思路，避免每次查询重新计算。
- 多组输入更符合竞赛题目风格。
