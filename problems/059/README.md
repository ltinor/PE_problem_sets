# 异或解密 (XOR Decryption)

来源：改编自 Project Euler Problem 59

## 原题意

用 3 个小写字母密钥解密 cipher.txt，求原文 ASCII 码之和。答案：129448。

## 改编方向

原题依赖外部 cipher.txt，改为标准输入。输入 N（密文长度）和 N 个整数（加密的 ASCII 码）。已知密钥由 3 个小写字母组成。输出原文 ASCII 码之和。

## 题目

给定一段密文（由 N 个加密后的 ASCII 码组成），已知加密方式是：明文每个字节与一个 3 字符小写字母密钥的对应位置进行 XOR 操作，密钥循环使用。破解密文并输出原文 ASCII 码之和。

## 数据范围

- N: 1 ≤ N ≤ 3000
- 密钥为 3 个小写字母
- 解密后的明文只包含可打印 ASCII 字符（32-126）

## 算法

std: 枚举 26³ = 17576 种密钥 → 解密 → 检查明文是否由可打印字符和常见英文单词构成 → 输出 ASCII 和。O(26³ · N)。

brute: 相同算法。
