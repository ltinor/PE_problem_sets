# 293 — 伪幸运数

来源：改编自 Project Euler Problem 293

## 原题意

如果正偶数 N 是 2 的幂，或者其所有不同的质因数恰好是连续的质数（从 2 开始），则称 N 为可接受的（admissible）。

若 N 是可接受的，使得 N+M 为质数的最小整数 M > 1 称为 N 的伪幸运数。

求所有小于 10⁹ 的可接受数 N 的所有不同伪幸运数之和。

原题答案：2209。

## 题目

输入一个正整数 U，求所有小于 U 的可接受数 N 的所有不同伪幸运数之和。

## 数据范围

- U ≥ 2
- U ≤ 10⁹

## 改编思路

### 方向一：参数化上界
- 将原题固定的 U = 10⁹ 改为输入参数
- 原题核心算法不变：DFS 生成可接受数，对每个数计算伪幸运数
- 结论：✅ 采用

## 算法

DFS 枚举所有可接受数 N < U（形如 2ᵃ·3ᵇ·5ᶜ·...，所有指数 ≥ 1 且质数连续）。
对每个 N，从 M=2 开始递增直到 N+M 为素数，记录 M 到集合中。
最后输出集合中所有元素之和。

时间复杂度：O(K · √U) 其中 K 为可接受数个数。
