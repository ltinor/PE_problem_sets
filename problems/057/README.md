# 平方根逼近 (Square Root Convergents)

来源：改编自 Project Euler Problem 57

## 原题意

√2 可以表示为无限连分数。前 1000 次展开中，分子位数多于分母位数的分数个数。答案：153。

## 改编方向

参数化 N（1≤N≤1000）。输入 N，求前 N 次展开中满足条件的个数。多组输入。

## 题目

对于 √2 的连分数展开，第 i 次展开得到分数 h_i/k_i，其中：
- h_1 = 3, k_1 = 2
- h_2 = 7, k_2 = 5
- h_n = 2·h_{n-1} + h_{n-2}, k_n = 2·k_{n-1} + k_{n-2} (n≥3)

求前 N 次展开中有多少个分数满足分子位数大于分母位数。

## 数据范围

- N: 1 ≤ N ≤ 1000
- 多组测试数据

## 算法

std: 递推 + 大整数（比较位数）。O(N)。

brute: 相同算法（字符串实现大整数加法）。O(N)。
