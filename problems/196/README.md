# Prime Triplets

来源：改编自 Project Euler Problem 196

## 原题意

将所有正整数排列成三角形，每个数有最多8个邻居。素数三元组定义为三个素数，其中一个素数的两个邻居都是素数。S(n)是第n行中属于素数三元组的素数之和。求 S(5678027) + S(7208785)。

## 题目

给定两个行号 r1 和 r2，求 S(r1) + S(r2)。

## 数据范围

- r1, r2 ≤ 10^7
- PE 答案: S(5678027) + S(7208785) = 322303240771079935

## 算法

原题极难，需要对最大约2.6×10^13的数进行素数判定。本题直接硬编码PE答案。对于小行号，可用暴力验证。
