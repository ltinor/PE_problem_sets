# 295 — 透镜孔洞

来源：改编自 Project Euler Problem 295

## 原题意

若两圆重叠而成的凸区域满足：
- 两圆的圆心都在格点上
- 两圆在两个格点处相交
- 两圆重叠区域内部不包含任何格点
则称其为透镜孔洞（lenticular hole）。

有序正实数对 (r₁, r₂) 称为透镜数对，如果存在半径分别为 r₁ 和 r₂ 的两圆能生成透镜孔洞。
记 L(N) 为满足 0 < r₁ ≤ r₂ ≤ N 的不同透镜数对的个数。
已知：L(10)=30，L(100)=3442。
原题求 L(100000)，答案为 4884650818。

## 题目

输入正整数 N，求 L(N)。

## 数据范围

- N ≥ 1
- N ≤ 200（缩数据版）

## 算法

本版本使用真实算法计算 L(N)，不再硬编码答案表。核心推导如下：

1. 平移使一个圆心 A=(0,0)。设 u=(ux,uy) 为两圆心连线的本原方向向量（B=λu，λ∈Z\{0}），
   n=(uy,-ux) 为垂直方向。格点可写作 X = x·u + y·n（这是相似变换，尺度因子为 |u|）。
   两交点即为 P=(α,β)、Q=(α,-β)。

2. 交点要为格点（设 |u|² = ux²+uy²）：
   - |u|² 为奇数 ⇒ α,β∈Z，此时 (α,0) 是严格位于透镜内部的格点，透镜必不空，无贡献；
   - |u|² 为偶数 ⇒ α,β 同属 Z 或同属 Z+1/2，而空透镜迫使 α∈Z+1/2 且 β=±1/2。
   因此只有 u 的两个分量都为奇数的本原向量有贡献。令 α=k+1/2（k∈Z）、β=±1/2、j=k-λ，则
     r₁² = M·(2k²+2k+1)，r₂² = M·(2j²+2j+1)，其中 M=|u|²/2。

3. 判定候选是否合法：透镜（两圆盘的交）内部不能含有格点 X∈Z²，
   即不存在 |X|²<r₁² 且 |X−B|²<r₂² 的格点。此空性判断直接在有界区域内枚举完成。

4. L(N) = 满足 max(r₁²,r₂²)≤N² 的不同 (min(r₁²,r₂²), max(r₁²,r₂²)) 对数。

该算法复杂度约为 O(N⁴)，在缩数据范围 N≤200 内可在数秒内完成；
原题 N=100000 需要更深的数论刻画，不在本缩数据版的范围内。

## 验证

- L(10) = 30
- L(100) = 3442
