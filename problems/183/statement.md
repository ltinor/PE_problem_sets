# 最大拆分乘积

## 题目描述

$N$ 是一个正整数，将 $N$ 拆分成 $k$ 个相等的部分，记 $r = N/k$，也即 $N = r + r + \dots + r$（$k$ 个 $r$）。

记 $P = r^k = (N/k)^k$ 是这些拆分的乘积。对于给定的 $N$，记 $M(N) = \max_{1 \le k \le N} (N/k)^k$。

若 $M(N)$ 是有限小数，记 $D(N) = -N$；否则记 $D(N) = N$。

给定 $N$，求 $\sum_{i=5}^{N} D(i)$。

---

## 输入格式

第一行一个整数 $T$，表示测试数据组数。
接下来 $T$ 行，每行一个整数 $N$。

---

## 输出格式

对于每组数据，输出一行一个整数，表示答案。

---

## 样例

### 输入
```
1
100
```

### 输出
```
2438
```

---

## 数据范围

- $1 \le T \le 10$
- $5 \le N \le 10000$
