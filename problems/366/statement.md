# 取石子游戏 III

## 题目描述

两名玩家安东和伯恩哈德在玩取石子游戏。有一堆共 $n$ 枚石子。

先手玩家可以从堆中取走任意正数枚石子，但不能全部拿走。此后，每名玩家可以从堆中取走的石子数目最多是其对手上一轮取走石子数目的两倍。取走最后一枚石子的玩家获胜。

对于先手玩家的必胜态，记 $M(n)$ 为先手玩家第一轮最多能取走的石子数目；对于必败态，记 $M(n)=0$。

## 输入格式

一行一个整数 $n$。

## 输出格式

输出 $\sum_{i=1}^{n} M(i) \bmod 10^8$。

## 样例

### 输入
```
100
```

### 输出
```
728
```

## 数据范围

- 对于 30% 数据：$n \le 10^3$
- 对于 60% 数据：$n \le 10^5$
- 对于 100% 数据：$n \le 10^{18}$
