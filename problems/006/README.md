# Sum Square Difference

来源：改编自 Project Euler Problem 6

## 原题意

前十个自然数的平方和是

$$1^2+2^2+\ldots +10^2=385$$

前十个自然数的和平方是

$$(1+2+\ldots+10)^2 = 55^2 = 3025$$

因此，前十个自然数的平方和与和平方之差是$3025 − 385 = 2640$。

求前一百个自然数的平方和与和平方之差。

## 题目

前十个正整数的平方和是

$$1^2+2^2+\ldots +10^2=385$$

前十个正整数的和平方是

$$(1+2+\ldots+10)^2 = 55^2 = 3025$$

因此，前十个正整数的平方和与和平方之差是$3025 − 385 = 2640$。

求前K个正整数的平方和与和平方之差。

## 数据范围

$1 \le T \le 10^4$
$1 \le K \le 10^5$

## 算法

简单数学, 较弱的数据，规避除法逆元的使用。
