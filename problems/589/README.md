# PE 589: Poohsticks Marathon / 维尼木棍马拉松

来源：改编自 Project Euler Problem 589

## 原题意

两人在桥上游同时投下木棍，木棍浮出后捞起再投。游戏只在**一根木棍浮出时领先另一根整整一趟（套圈）**时结束。
- 每趟旅程耗时：整数秒，在 `[n, m]` 上等概率均匀分布
- 捞起并重投耗时：5 秒
- `E(m,n)` = 单局期望耗时
- `S(k) = Σ_{m=2..k} Σ_{n=1..m-1} E(m,n)`
- 已知：`E(60,30) = 1036.15…`，`S(5) = 7722.82`
- 求：`S(100)`（保留 2 位小数）

## 题目（缩数据版）

读入整数 `k`，输出 `S(k)` 保留 2 位小数。数据范围 `k ≤ 100`。

## 算法

**关键洞察**：A、B 两根木棍同分布，故"下一次浮出属于谁"等概率 ⇒ 趟数差
`d = cA − cB` 是**简单对称随机游走** `{-1, 0, 1}`，在 `|d| = 2`（套圈）时吸收。
"面积"体现在每次事件间的时间不均匀（取决于哪根浮出及其旅程），故状态需记录：

```
状态 = (d, ra, rb)
  d  : 趟数差 (cA - cB)，取值 {-1, 0, 1}
  ra : A 距下一次浮出的剩余整数秒
  rb : B 距下一次浮出的剩余整数秒
```

转移（事件跳跃，`dt = min(ra, rb)`）：

| 情形 | 转移 |
|------|------|
| `ra < rb` | A 先浮出，`d+1`；若 `|d|=2` 结束（耗时 `dt`），否则 A 重投（新 `ra = 5+U`），B 剩余 `rb−dt` |
| `ra > rb` | B 先浮出，`d−1`；对称 |
| `ra = rb` | 同时浮出，`d` 不变，两者都重投 |

其中 `U ~ Uniform{n..m}` 等概率，重投耗时 5s。

- `E(m,n) = Σ_{u,v} (1/K²) · E_0((0, u, v))`，`K = m−n+1`
- 用**值迭代**求解（状态空间 `3(m+6)²`，小规模秒出）

**优化**：`ra = rb` 分支朴素是 `O(K²)`。预计算聚合量
`T1[d][r] = Σ_u E[d][5+u][r]`、`T2[d][r] = Σ_u E[d][r][5+u]`、`S2[d] = ΣΣ E[d][5+u][5+v]`
后降为 `O(1)`，整体提速数个数量级。

## 性能

- 优化后：`S(20)` 约 1.9 秒
- `S(100)` 约 1 小时 50 分（4950 组 (m,n)，大 m 组状态数 `3(m+6)²` 增长）
- 若需加速可多线程并行各组，或对每个 (m,n) 用高斯-赛德尔替代 Jacobi 迭代
