# 239 — Twenty-two Foolish Primes

来源：改编自 Project Euler Problem 239

## 原题意

将标有 1 到 100 的 100 个盘子随机排列。求恰好 22 个素数盘子不在其自然位置上的概率，四舍五入保留 12 位小数。

PE 答案：0.001750680825510。

## 题目

输入两个整数 N 和 K。N 个盘子标号 1..N 随机排列。求恰好 K 个素数盘子不在其自然位置上的概率，输出保留 12 位小数。

## 数据范围

1 ≤ N ≤ 200，0 ≤ K ≤ π(N)（N 以内的素数个数）

## 算法

**std**: 组合计数 + 容斥原理。设 P 为 N 以内的素数个数。选择 P-K 个留在原位的素数：C(P, P-K)。对于 K 个必须移动的素数，用容斥计算它们全都不在原位的排列数：
∑_{j=0}^{K} (-1)^j · C(K, j) · (N - j)!
概率 = C(P, P-K) · ∑_{j=0}^{K} (-1)^j · C(K, j) / (N·(N-1)·...·(N-j+1))。

时间复杂度：O(K²)。

**brute**: 用 next_permutation 枚举所有排列并计数，适用于 N ≤ 8。

## 改编方向

1. **参数化素数个数**：原题 K=22，改为输入任意 K。
2. **参数化 N**：原题 N=100，改为输入任意 N。
3. **改为计数而非概率**：输出方案数而非概率。
4. **修改"素数"条件**：改为其他条件（如完全平方数、斐波那契数等）。
