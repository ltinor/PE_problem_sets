# 132 — Large Repunit Factors

来源：改编自 Project Euler Problem 132

## 原题意

求 R(10⁹) 的前 40 个质因数的和。

原题答案：843296。

## 题目

参数化 K 和 N：输入 K (≤ 40) 和 N (≤ 9)，求 R(10ᴺ) 的前 K 个质因数的和。

## 数据范围

- K ≤ 40, N ≤ 9

## 算法

**std**: R(m) % p = 0 ⟺ A(p) | m，其中 A(p) = 最小的 k 使得 R(k) % p = 0。计算 A(p) 通过余数递推 r = (r * 10 + 1) % p。筛选满足 A(p) | 10ᴺ 的质数（即 A(p) 的质因子只含 2 和 5），取前 K 个求和。

**brute**: 同上。

## 改编方向

1. **参数化 K, N**：将原题固定 K=40, N=9 改为输入参数。
2. **小范围版本**：K ≤ 10, N ≤ 5 可用于对拍验证。
3. **固定答案验证**：(K=40, N=9) 作为测试点，输出 843296。
