# 大循环单位数的因数

## 题目描述

只包含数字 1 的数称为循环单位数。定义 R(k) 为长度为 k 的循环单位数。

给定整数 K 和 N，求 R(10ᴺ) 的前 K 个质因数的和。

---

## 输入格式

一行两个整数 K N，空格分隔 (1 ≤ K ≤ 40, 1 ≤ N ≤ 9)。

---

## 输出格式

一行一个整数，表示前 K 个质因数的和。

---

## 样例

### 输入

```
4 1
```

### 输出

```
9414
```

（R(10) = 1111111111 = 11×41×271×9091，sum = 9414）

---

## 时间限制

2 秒

## 数据范围

- 1 ≤ K ≤ 40
- 1 ≤ N ≤ 9
