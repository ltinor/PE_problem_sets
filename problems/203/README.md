# 203 — Squarefree Binomial Coefficients

来源：改编自 Project Euler Problem 203

## 原题意

帕斯卡三角形前 51 行中所有不同的无平方因子二项式系数之和。原题答案：34029210557338。

## 题目

参数化 N：输入 N (≤51)，求帕斯卡三角形前 N 行中所有不同的无平方因子数之和。

## 数据范围

- N ≤ 51

## 算法

**std**: 逐行计算 C(n,k) = C(n,k-1) × (n-k+1) / k，收集到 set 去重。利用关键性质：C(n,k) 的所有质因子 ≤ N，只需用 ≤N 的素数检查平方整除。

**brute**: 相同逻辑，但平方因子检查用试除法至 √v。用于小 N 验证。

## 改编方向

1. **参数化 N**：将原题固定 N=51 改为输入参数。
2. **保留原数据范围**：N ≤ 51 时 C(n,k) ≤ 1.26×10¹⁴ 在 64 位范围内。
3. **优化平方因子检查**：利用 C(n,k) 质因子 ≤ N 的性质，只需检查 O(π(N)) 个素数。
