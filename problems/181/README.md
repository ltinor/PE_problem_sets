# 物体分组

来源：改编自 Project Euler Problem 181

## 原题意

有60个黑色物体B和40个白色物体W，问有多少种不同的分组方式？同一组内的物体顺序和组的顺序都不重要，相同颜色的物体不可区分。答案为 83735848679360680。

## 题目

多组测试数据。每组给定 B 和 W，求将 B 个黑色物体和 W 个白色物体分组的不同方式数。

## 数据范围

- 测试组数 T（每组 B, W）
- 0 ≤ B, W ≤ 60
- 答案可能超过 2^63，需使用 128 位整数。

## 算法

二维整数划分 DP（无界背包）。将所有可能的组类型 (i, j)（i 黑 j 白，非 (0,0)）按字典序排列，使用无界背包 DP：
- dp[0][0] = 1
- 对每种组类型 (i, j)：dp[b][w] += dp[b-i][w-j]（b ≥ i, w ≥ j）

使用 __int128 存储结果。总状态数 O(B²W²) ≈ 13M，可接受。

## 改编方向

1. **参数化 B, W**：原题固定 60B+40W，改编后输入任意 B,W。
2. **答案类型**：使用 __int128 避免大数库依赖。
3. **数据范围**：B,W 最大 60，原 PE 答案作为第一个测试点。
