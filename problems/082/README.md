# 路径和：三个方向

来源：改编自 Project Euler Problem 82

## 原题意

在一个 80×80 的矩阵中，从最左列任意位置出发，到达最右列任意位置，每次可以向右、向上或向下移动。求路径上数字之和的最小值。答案：260324。

## 题目

给定一个 N×N 的矩阵，从最左列的任意一格出发，到达最右列的任意一格，每次可以向右、向上或向下移动。求经过路径上数字之和的最小值。

## 数据范围

N ≤ 80，矩阵元素为 ≤ 9999 的正整数。

## 算法

std: 按列 DP，每一列先继承左边路径和，再从上到下扫描取 min，再从下到上扫描取 min。时间复杂度 O(N²)。
brute: 同样的按列 DP 算法，用于交叉验证。
