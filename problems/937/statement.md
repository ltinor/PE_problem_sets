# 等积划分

## 题目描述

令 $\theta=\sqrt{-2}$。定义 $T$ 为形如 $a+b\theta$ 的数构成的集合，其中 $a,b$ 为整数，且满足 $a>0$，或 $a=0$ 且 $b>0$。

对集合 $S\subseteq T$ 和元素 $z\in T$，定义 $p(S,z)$ 为「从 $S$ 中选取两个**不同**元素，且它们的乘积等于 $z$ 或 $-z$」的方案数。

例如，若 $S=\{1,2,4\}$ 且 $z=4$，则只有一对元素 $1$ 与 $4$ 的乘积为 $\pm 4$，故 $p(S,z)=1$。

记 $A$ 和 $B$ 是满足以下条件的两个集合：

- $1\in A$；
- $A\cap B=\varnothing$；
- $A\cup B=T$；
- 对任意 $z\in T$，有 $p(A,z)=p(B,z)$。

这四个条件唯一确定了集合 $A$ 和 $B$。

令 $F_n=\{1!,2!,\dots,n!\}$，定义 $G(n)$ 为 $F_n\cap A$ 中所有元素之和。

已知 $G(4)=25$，$G(7)=745$，$G(100)\equiv 709772949\pmod{10^9+7}$。

给定整数 $n$，请计算 $G(n)$ 对 $10^9+7$ 取模的结果。

---

## 输入格式

一行一个整数 $n$。

---

## 输出格式

一行一个整数，表示 $G(n)\bmod(10^9+7)$。

---

## 样例

### 输入

```
4
```

### 输出

```
25
```

### 输入

```
7
```

### 输出

```
745
```

---

## 数据范围

$1\le n\le 10^6$。
