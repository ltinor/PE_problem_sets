# PE028 — 螺旋数阵对角线

来源：改编自 Project Euler Problem 28

## 原题意

从数字 1 开始，按顺时针方向向右旋转，构成一个 $1001 \times 1001$ 的螺旋数阵。求该数阵两条对角线上的数字之和。

## 题目

给定一个奇数 $N$，求 $N \times N$ 螺旋数阵的两条对角线上的数字之和。

螺旋数阵的构造方式：从中心位置（数字 1）开始，先向右走一步写下 2，然后逆时针旋转依次填写数字。

## 数据范围

- $N$ 为奇数，$1 \le N \le 10^9$
- 多组测试数据

## 算法

- **std**：数学公式推导，$O(1)$ 计算。对于奇数 $N$，第 $k$ 层（$k \ge 3$ 且为奇数）的四个角分别为 $k^2$、$k^2-(k-1)$、$k^2-2(k-1)$、$k^2-3(k-1)$。求和得：
  $$S(N) = 1 + \sum_{\text{odd } k \ge 3}^{N} [4k^2 - 6k + 6] = \frac{4N^3 + 3N^2 + 8N - 9}{6}$$
  使用 `__int128` 避免溢出。
- **brute**：按层模拟，累加四个角的值，仅适用于较小的 $N$。
