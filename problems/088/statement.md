# 积和数

## 题目描述

若自然数 $N$ 能够同时表示成一组至少两个自然数 $\{a_1,a_2,\ldots,a_k\}$ 的积与和，也即 $N = a_1 + a_2 + \ldots + a_k = a_1 \times a_2 \times \ldots \times a_k$，则称之为**积和数**。

例如，$6 = 1 + 2 + 3 = 1 \times 2 \times 3$。

给定这一组自然数的数目 $k$，满足上述性质的**最小** $N$ 值被称为**最小积和数**。当 $k = 2, 3, 4, 5, 6$ 时，最小积和数如下：

- $k=2$：$4 = 2 \times 2 = 2 + 2$
- $k=3$：$6 = 1 \times 2 \times 3 = 1 + 2 + 3$
- $k=4$：$8 = 1 \times 1 \times 2 \times 4 = 1 + 1 + 2 + 4$
- $k=5$：$8 = 1 \times 1 \times 2 \times 2 \times 2 = 1 + 1 + 2 + 2 + 2$
- $k=6$：$12 = 1 \times 1 \times 1 \times 1 \times 2 \times 6$

因此对于 $2 \leq k \leq 6$，所有最小积和数（去重）之和为 $4 + 6 + 8 + 12 = 30$。注意 $8$ 只计算一次。

已知对于 $2 \leq k \leq 12$，所有最小积和数（去重）之和为 $61$。

给定 $K_{\max}$，求对于 $2 \leq k \leq K_{\max}$，所有最小积和数（去重）之和。

---

## 输入格式

输入一行，一个整数 $K_{\max}$。

---

## 输出格式

输出一个整数，表示最小积和数（去重）之和。

---

## 样例

### 输入
```
6
```

### 输出
```
30
```

### 输入
```
12
```

### 输出
```
61
```

---

## 数据范围

$2 \leq K_{\max} \leq 12000$
