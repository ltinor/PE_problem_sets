# Product-sum Numbers

来源：改编自 Project Euler Problem 88

## 原题意

对于 $2 \leq k \leq 12000$，求所有最小积和数之和（去重）。最小积和数是指能够写成恰好 $k$ 个自然数的积与和的最小自然数。

## 题目

给定正整数 $K_{\max}$，求对于 $2 \leq k \leq K_{\max}$，所有最小积和数（去重）之和。

## 数据范围

$2 \leq K_{\max} \leq 12000$

## 算法

DFS 枚举因数分解（每个因数 $\geq 2$）。对于乘积 $P$、因数之和 $S$、因数个数 $m$，对应 $k = P - S + m$（不足的用 $1$ 补齐）。记录每个 $k$ 的最小 $P$，最后用 `set` 去重求和。

时间复杂度：DFS 搜索空间较小，$O(K_{\max} \log K_{\max})$ 实际运行远小于此。
