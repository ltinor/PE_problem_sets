# Number Letter Counts

来源：改编自 Project Euler Problem 17

## 原题意

把 $1$ 到 $1000$ 写成英文单词，不计空格和连字符，一共要用多少个字母？例如 $342$（three hundred and forty-two）包含 $23$ 个字母。

原题答案：$21124$。

## 题目

给定 $T$ 组测试数据，每组给出一个整数 $n$。求将 $1$ 到 $n$ 的所有整数写成英文单词时，所用字母的总数（不计空格和连字符）。使用英式英语规则（百位和十位之间加 "and"）。

## 数据范围

- $1 \le T \le 10$
- $1 \le n \le 10^6$

## 改编思路

### 方向一：参数化上界 ✅ 采用

- 做法：将固定的 $1000$ 改为可变上界 $n$（$1 \le n \le 10^6$）。需要处理更大的数字：千位（thousand）、万位等。
- 优点：自然参数化，扩大了题目的适用范围。$n$ 增大后仍然可以 $O(n)$ 逐数计算，因为每个数转英文是 $O(1)$。
- 结论：✅ 采用

### 方向二：多组输入 ✅ 采用

- 做法：支持 $T$ 组查询，每组给出不同的 $n$。
- 结论：✅ 采用

### 方向三：任意大整数（亿、兆等）❌ 不采用

- 做法：$n$ 可达 $10^9$ 或更大，涉及 million、billion 等。
- 缺点/风险：英文数字规则在 million 以上变得复杂（英式用 "thousand million" 还是 "billion" 有争议）。且 $O(n)$ 算法在 $10^9$ 时会超时，需要数学推导，改变了难度。
- 结论：❌ 不采用——超出合理难度范围。

### 方向四：统计某个特定字母的出现次数 ❌ 不采用

- 做法：求数字 $1$ 到 $n$ 的英文单词中，字母 'e' 出现了多少次。
- 缺点/风险：偏离原题核心（原题是"总字母数"），且引入了一个不太自然的统计维度。
- 结论：❌ 不采用——偏离原题意图。

### 方向五：允许自定义语言 ❌ 不采用

- 做法：不仅支持英文，还支持其他语言的数字拼写规则。
- 缺点/风险：多语言映射规则复杂且易出错，不适合作为算法竞赛题。
- 结论：❌ 不采用——过于复杂且非算法挑战。

### 方向六：前缀和优化到 $O(1)$ 查询 ❌ 不采用

- 做法：预处理前缀和数组，使每组查询 $O(1)$。
- 备注：方向一的对每组数据逐数计算是 $O(n)$ 每组，$T$ 组可达 $O(Tn)$。但 $n\le 10^6$、$T\le 10$ 时 $10^7$ 次操作仍然可行。不引入前缀和保持了代码简洁性。
- 结论：❌ 不采用——当前数据范围不需要优化。

## 算法

模拟 + 逐数转换。预处理英文数字 1-19、20-90 的字母长度，定义递归函数 `count_letters(n)` 计算单个数字的英文单词字母数，然后对 $1$ 到 $n$ 求和。时间复杂度 $O(n)$ 每组查询。

## 验证

- brute.cpp 使用相同的算法（独立实现）在小数据上验证
- 原题答案 $n=1000$ 时输出 $21124$ 可验证
