# 圆上的格点

## 题目描述

考虑经过 $(0, 0), (N, 0), (0, N), (N, N)$ 四个点的圆。设 $f(N)$ 为这个圆上整点（坐标为整数的点）的个数。

例如，$f(1) = 4$（四个顶点就是全部整点）；$f(5) = 12$。

给定 $N$，求 $f(N)$。

---

## 输入格式

输入一行，一个整数 $N$（$1 \le N \le 10^{12}$）。

---

## 输出格式

输出一个整数，表示 $f(N)$。

---

## 样例

### 输入
```
1
```

### 输出
```
4
```

### 输入
```
5
```

### 输出
```
12
```

---

## 数据范围

$1 \le N \le 10^{12}$
