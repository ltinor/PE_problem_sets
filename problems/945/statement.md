# 异或方程（三）

## 题目描述

用 $x\oplus y$ 表示 $x$ 和 $y$ 按位异或的结果。考虑 $x$ 和 $y$ 的二进制长乘法，但将中间结果的相加替换为按位异或，定义其结果为 $x$ 和 $y$ 的**异或积**，记作 $x\otimes y$。

例如，$7\otimes 3 = 9$，即在二进制下 $111_2 \otimes 11_2 = 1001_2$。

考虑方程：
$$(a\otimes a)\oplus(2\otimes a\otimes b)\oplus(b\otimes b)=c\otimes c.$$

例如，$(a,b,c)=(1,2,1)$ 是该方程的一个解，$(1,8,13)$ 是另一个解。

记 $F(N)$ 为满足 $0\le a\le b\le N$ 的该方程解的数量。已知 $F(10)=21$。

给定 $N$，求 $F(N)$。

---

## 输入格式

一行一个整数 $N$。

---

## 输出格式

一行一个整数，表示 $F(N)$。

---

## 样例

### 输入

```
10
```

### 输出

```
21
```

---

## 数据范围

$0 \le N \le 5000$。
