# Digital Signature

来源：改编自 Project Euler Problem 290

## 原题意

求 0 ≤ n < 10^18 中各位数字和等于 137n 的各位数字和的 n 的个数。PE 答案：20444710234716473。

## 题目

给定 E 和 k，求 0 ≤ n < 10^E 且 digit_sum(n) = digit_sum(k·n) 的 n 的个数。

## 数据范围

- 1 ≤ E ≤ 5, 1 ≤ k < 10^5
- PE 答案: E=18, k=137 → 20444710234716473（硬编码）

## 改编思路

### 方向一：缩小指数
原题 10^18 太大（DP 状态过多），缩小至 E≤5。✅ 采用

### 方向二：改变乘数 k
保持 10^18 但改 k。k=137 特殊但原理相同。❌ 不采用

### 方向三：计数+求和
除计数外还要求和。增加复杂度。❌ 不采用

## 算法

数位 DP：dp[pos][carry][diff] 记录位置、进位、数字和差值。状态转移 O(E·10·C·D)，其中 C 和 D 为进位和差值上限。
