# 柏拉图多面体骰子（PE 389）

## 题目描述

给定骰子面数序列 $f_1, f_2, \dots, f_k$。

先掷一枚 $f_1$ 面骰子，记点数为 $T_1$；再掷 $T_1$ 枚 $f_2$ 面骰子，记点数和为 $T_2$；以此类推，$T_i$ 为掷 $T_{i-1}$ 枚 $f_i$ 面骰子的点数和。

求 $T_k$ 的方差，四舍五入到 4 位小数。

原题（PE389）即序列 $4, 6, 8, 12, 20$ 的情形，$\mathrm{Var}(I) = 2406376.3623$。

---

## 输入格式

第一行一个 token：

- 若为 `PE`，输出原题官方答案 $2406376.3623$；
- 否则第一个整数为 $k$（$1 \le k \le 8$），后跟 $k$ 个整数 $f_1, \dots, f_k$（$2 \le f_i \le 1000$）。

---

## 输出格式

一行一个实数：$T_k$ 的方差，保留 4 位小数。

---

## 样例

### 输入

```
1 4
```

### 输出

```
1.2500
```

## 题目描述

给定骰子面数序列 $f_1, f_2, \dots, f_k$。

先掷一枚 $f_1$ 面骰子，记点数为 $T_1$；再掷 $T_1$ 枚 $f_2$ 面骰子，记点数和为 $T_2$；以此类推，$T_i$ 为掷 $T_{i-1}$ 枚 $f_i$ 面骰子的点数和。

求 $T_k$ 的方差，四舍五入到 4 位小数。

原题（PE389）即序列 $4, 6, 8, 12, 20$ 的情形，$\mathrm{Var}(I) = （见 data/）$。

---

## 输入格式

第一行一个 token：

- 若为 `PE`，输出原题官方答案 $（见 data/）$；
- 否则第一个整数为 $k$（$1 \le k \le 8$），后跟 $k$ 个整数 $f_1, \dots, f_k$（$2 \le f_i \le 1000$）。

---

## 输出格式

一行一个实数：$T_k$ 的方差，保留 4 位小数。

---

## 样例

### 输入

```

```

### 输出

```

```

---

## 数据范围

- 若输入为 `PE`，输出 $2406376.3623$；
- 否则 $1 \le k \le 8$，$2 \le f_i \le 1000$。

## 提示

单枚 $f$ 面骰子：$E = \frac{f+1}{2}$，$\mathrm{Var} = \frac{f^2-1}{12}$。

由全期望/全方差公式：$\mathrm{Var}(T_i) = E[T_{i-1}]\cdot\frac{f_i^2-1}{12} + \left(\frac{f_i+1}{2}\right)^2 \mathrm{Var}(T_{i-1})$。
