# 重排平方数

## 题目描述

给定 $N$ 个由大写字母组成的单词，找出所有字母重排单词对（即两个单词包含完全相同的字母，只是顺序不同）。对于每一对单词，尝试将每个字母映射为一个数字（不同字母映射不同数字，且不能有前导零），使得两个单词对应的数字均为完全平方数。求所有满足条件的平方数中的最大值。如果不存在这样的平方数，输出 $0$。

---

## 输入格式

第一行一个整数 $N$。

接下来 $N$ 行，每行一个由大写字母 A-Z 组成的单词。

---

## 输出格式

一行一个整数，表示最大的满足条件的平方数。若不存在，输出 $0$。

---

## 样例

### 输入

```
4
CARE
RACE
HELLO
WORLD
```

### 输出

```
9216
```

（CARE=1296=36², RACE=9216=96²，其中最大为 9216）

---

## 数据范围

- $1 \le N \le 2000$
- 单词长度不超过 $10$
- 单词只包含大写字母 A-Z
