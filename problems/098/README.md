# 098 — Anagramic Squares

来源：改编自 Project Euler Problem 98

## 原题意

给定 `words.txt` 中的单词列表，找出所有由相同字母重排构成的单词对（如 CARE 和 RACE）。对于每一对，将字母映射为数字，使得两个单词都对应完全平方数，求所有这样的平方数中的最大值。

答案：18769。

## 题目

输入 $N$ 和 $N$ 个由大写字母组成的单词。找出最大的整数 $M$，满足存在一对重排单词和一种字母到数字的映射，使得两个单词对应的数字均为完全平方数，且 $M$ 是其中之一。

## 数据范围

- $1 \le N \le 2000$
- 单词长度 $\le 10$
- 单词只包含大写字母 A-Z

## 算法

按字母模式（排序后字符串）分组 → 对每组内的单词对枚举同长度平方数进行字母-数字映射验证。时间复杂度 $O(N \log N + G \cdot \sqrt{10^L} \cdot L)$，其中 $G$ 为单词对数量，$L$ 为单词长度。
