# 数字阶乘链

来源：改编自 Project Euler Problem 74

## 原题意

对一个数，定义"各位数字的阶乘之和"操作：将该数每一位的数字分别取阶乘然后求和。不断重复此操作会形成一条链，最终必定进入循环。原题求：在小于 1,000,000 的数中，有多少个起始数产生的链恰好包含 60 个不重复的项？答案为 402。

## 题目

给定 N 和 K，求所有小于 N 的正整数中，有多少个数从它出发执行"各位数字的阶乘之和"操作，产生的链恰好包含 K 个不重复的项。

## 数据范围

- 1 ≤ N ≤ 1,000,000
- 1 ≤ K ≤ 60

## 算法

预计算 0! 到 9!。对每个起始数，使用记忆化搜索 / DFS 计算链长（不重复项的数量），直到遇到已经计算过的数或检测到循环。统计链长恰好为 K 的起始数个数。
