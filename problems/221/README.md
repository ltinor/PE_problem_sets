# 221 — Alexandrian Integers

来源：改编自 Project Euler Problem 221

## 原题意

求第 150000 个亚历山大整数。原题答案：1884161251122450。

## 题目

参数化 K：输入 K (≤150000)，求第 K 个亚历山大整数。

## 数据范围

$K \le 150000$

## 算法

**std**: 利用恒等式 $(p+k)(q+k) = k^2+1$（其中 $k=p$），枚举 $k$，分解 $k^2+1$ 得到所有因子，对每个负因子 $d$ 计算 $A = k(d-k)((k^2+1)/d - k)$（正值即为亚历山大整数）。使用 SPF 筛法加速因数分解，排序去重后取第 $K$ 个。

时间复杂度：$O(M \cdot \tau(M^2))$，$M \approx 50000$。

**brute**: 在三重循环中直接枚举 $p,q,r$ 满足 $pq+pr+qr=1$，适用于 $|p|,|q|,|r| \le 100$。

## 改编方向

1. **参数化 K**：将原题固定 K=150000 改为输入参数。
2. **多组输入**：可改为 T 组测试数据。
3. **范围扩展**：可增大 K 上限，但需扩展 k 枚举范围和优化因数分解。
