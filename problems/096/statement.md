# 数独

## 题目描述

数独是一种经典的逻辑谜题。在一个 $9 \times 9$ 的网格中，部分格子已填入数字 $1 \sim 9$，其余格子为空白（用 $0$ 表示）。目标是将所有空白格子填上数字，使得：
- 每行包含数字 $1 \sim 9$ 各一次；
- 每列包含数字 $1 \sim 9$ 各一次；
- 每个 $3 \times 3$ 的九宫格包含数字 $1 \sim 9$ 各一次。

给定 $N$ 个待求解的数独谜题（保证每个有唯一解），对于每个谜题，求解后将左上角的三个数字组成的三位数求和输出。

---

## 输入格式

第一行一个整数 $N$，表示数独谜题数量。

接下来对于每个谜题，输入 $9$ 行，每行是一个长度恰好为 $9$ 的字符串（不含空格），由数字 `0`-`9` 组成，`0` 表示空格。

---

## 输出格式

一行一个整数，表示所有谜题解答左上角三位数之和。

---

## 样例

### 输入

```
1
003020600
900305001
001806400
008102900
700000008
006708200
002609500
800203009
005010300
```

### 输出

```
483
```

**解释**：这个谜题源自 Project Euler Problem 96 的样例。解答后左上角三个数字组成的数为 $483$。

---

## 数据范围

$1 \le N \le 50$。每个谜题保证有唯一解。
