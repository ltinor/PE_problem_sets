# 135 — Same Differences

来源：改编自 Project Euler Problem 135

## 原题意

求 n < 10⁶ 中恰有 10 个不同的等差数列解 (x, y, z) 满足 x² − y² − z² = n 的 n 的个数。

原题答案：4989。

## 题目

参数化 M 和 K：输入 M (≤ 10⁶) 和 K (≤ 20)，求 n < M 中恰有 K 个解的 n 的个数。

## 数据范围

- M ≤ 10⁶, K ≤ 20

## 算法

**std**: x = y + d, z = y − d。代入得 n = y(4d − y)。枚举 y 和 d，累加 cnt[n]。遍历 cnt 统计 cnt[n] = K 的 n 个数。

**brute**: 同思路，枚举 y 和 d，累计计数。

## 改编方向

1. **参数化 M, K**：将原题固定 M=10⁶, K=10 改为输入参数。
2. **小范围版本**：M ≤ 10000 可用于对拍验证。
3. **固定答案验证**：(M=10⁶, K=10) 作为测试点，输出 4989。
