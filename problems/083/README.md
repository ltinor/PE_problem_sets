# 路径和：四个方向

来源：改编自 Project Euler Problem 83

## 原题意

在一个 80×80 的矩阵中，从左上角到右下角，可以向上、下、左、右任意方向移动。求路径上数字之和的最小值。答案：425185。

## 题目

给定一个 N×N 的矩阵，从左上角 (1,1) 走到右下角 (N,N)，可以向上、下、左、右任意方向移动。求经过路径上数字之和的最小值。

## 数据范围

N ≤ 80，矩阵元素为 ≤ 9999 的正整数。

## 算法

std: Dijkstra 最短路径算法，使用优先队列。时间复杂度 O(N² log N)。
brute: 同样的 Dijkstra 算法，用于交叉验证。
