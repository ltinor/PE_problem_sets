# 240 — Top Dice

来源：改编自 Project Euler Problem 240

## 原题意

扔 N 个 S 面骰子（面值 1..S），点数最大的 K 个之和为 T 的方式数。已知 N=5, S=6, K=3, T=15 时有 1111 种方式。求 N=20, S=12, K=10, T=70 时的方式数。

PE 答案：7448717393364181966。

## 题目

输入四个整数 N, S, K, T，求扔 N 个 S 面骰子（可区分），点数最大的 K 个之和恰好为 T 的方式数。

## 数据范围

1 ≤ N ≤ 20，1 ≤ S ≤ 12，1 ≤ K ≤ N，K ≤ T ≤ K·S

## 算法

**std**: DP 计数。从大到小处理面值 v（S..1）。状态 dp[total][top][sum] 表示已分配面值 ≥v 的骰子数、其中在 Top-K 中的数量、Top-K 的和。转移时选择 x 个骰子取面值 v，其中 t=min(x, K-top) 个进入 Top-K。组合数 C(剩余骰子数, x) 计入方案。

状态数：N×K×(K·S) ≈ 20×10×120 = 24000，每个状态枚举 x（≤N），总复杂度 O(N²·K²·S)。

**brute**: 枚举所有 S^N 种可能并统计，适用于 N≤6, S≤8。

## 改编方向

1. **参数化骰子数/面数/取几个**：原题固定 (20,12,10,70)，改为四个可变参数。
2. **求概率而非计数**：输出概率（除以 S^N）。
3. **Bottom K**：改为求最小的 K 个之和。
4. **加权骰子**：骰子面值非均匀（如 1,2,3,5,8,13）。
