# 自幂 (Self Powers)

来源：改编自 Project Euler Problem 48

## 原题意

求 1¹ + 2² + 3³ + ... + 1000¹⁰⁰⁰ 的最后 10 位数字。答案：9110846700。

## 改编方向

参数化 N（1≤N≤10⁶）。输入 N，求 1¹+2²+...+N^N 的最后 10 位数字（含前导零）。支持多组输入。

## 题目

给定正整数 N，求 S(N) = Σ_{i=1}^{N} i^i 的十进制表示的最后 10 位数字。如果不足 10 位需要用前导零补齐到恰好 10 位。

## 数据范围

- N: 1 ≤ N ≤ 10⁶
- 多组测试数据

## 算法

std: 快速幂取模 10¹⁰，累加。O(N log N)。

brute: 朴素幂取模（循环乘）。O(N²)，仅适用于小 N。
