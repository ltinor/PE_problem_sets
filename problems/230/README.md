# 230 — Fibonacci Words

来源：改编自 Project Euler Problem 230

## 原题意

给定 A = π 小数点后 100 位，B = 再 100 位。对 $k=0..17$，求 $10^k \\cdot D_{A,B}((127+19k) \\cdot 7^k)$ 之和（$n$ 最大约 $1.7 \\times 10^{16}$）。原题答案：850481152593119296。

## 题目

参数化 A, B, n：输入两行数字串 A、B 和一行整数 n，求 $D_{A,B}(n)$——即斐波那契字序列 $F_{A,B} = (A, B, AB, BAB, \\dots)$ 中首个包含至少 $n$ 个数字的项的第 $n$ 位数字。

## 数据范围

$|A|, |B| \\le 100$，$1 \\le n \\le 10^{16}$

## 算法

**std**: 递归回溯法。预计算斐波那契长度序列 $L_k = L_{k-2} + L_{k-1}$（$L_1=|A|, L_2=|B|$）直到 $L_k \\ge n$。然后从最大 k 回溯：若 $n \\le L_{k-2}$ 则在左半 $F_{k-2}$ 中；否则 $n \\leftarrow n-L_{k-2}$ 在右半 $F_{k-1}$ 中。最终定位到 A 或 B 中的位置。

时间复杂度：$O(\\log n)$ 每次查询。

**brute**: 直接生成斐波那契字串直到长度足够，适用于小 n。

## 改编方向

1. **参数化 A, B, n**：原题固定 π 的 200 位数字，改为可输入任意串。
2. **多组查询**：可改为 T 组查询，加速需预处理长度数组。
3. **变体序列**：将 Fibonacci 递推改为 Tribonacci（三项相加）。
