# 阶乘的尾数

## 题目描述

对于任意 N，记 f(N) 为 N! 除去末尾零后的最后五位数字。

例如：
- 9! = 362880，所以 f(9) = 36288
- 10! = 3628800，所以 f(10) = 36288
- 20! = 2432902008176640000，所以 f(20) = 17664

给定 N，求 f(N)。

---

## 输入格式

一行一个整数 N (1 ≤ N ≤ 10^12)。

---

## 输出格式

一行一个五位整数（含前导零），表示 f(N)。

---

## 样例

### 输入

```
9
```

### 输出

```
36288
```

### 输入

```
20
```

### 输出

```
17664
```

---

## 数据范围

- 1 ≤ N ≤ 10^12

---

## 提示

PE 原题 N = 10^12 时答案为 16576。
