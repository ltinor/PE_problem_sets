# 大和

## 题目描述

给定100个50位的正整数，请你计算它们的和，并输出该和的前10位数字。

---
## 输入格式

输入共100行，每行一个50位的正整数。

---
## 输出格式

输出一个10位整数，表示所有输入数字之和的前10位数字。

---
## 样例

### 输入
```
12345678901234567890123456789012345678901234567890
98765432109876543210987654321098765432109876543210
...（共100行）
```
### 输出
```
1111111110
```

---
## 数据范围

所有输入数字都是50位的正整数，总共100个数字。

**提示：** 需要使用高精度整数运算或字符串处理来避免溢出问题。
