# 包含原点的三角形 II

来源：改编自 Project Euler Problem 456

## 原题意

定义 $x_n = (1248^n \bmod 32323) - 16161$，$y_n = (8421^n \bmod 30103) - 15051$，$P_n = \{(x_i,y_i)\}_{i=1}^n$。求以 $P_n$ 中点为顶点且严格包含原点在内部的三角形个数 $C(2000000)$。

## 题目

给定 $n$，求 $C(n)$。

## 数据范围

$3 \le n \le 2 \times 10^6$

## 算法

1. 生成所有点，按极角排序。
2. 使用双指针统计所有不被包含原点的三角形（三点均位于某个不包含原点的开半平面内），从总数 $\binom{n}{3}$ 中减去。
3. 需额外减去原点在三角形边界上的情况（恰有一对点关于原点对称，即角度差恰为 $\pi$）。
4. 时间复杂度 $O(n \log n)$，空间复杂度 $O(n)$。
