# 120 — 平方余数

来源：改编自 Project Euler Problem 120

## 原题意

对于 a ≥ 3，定义 r 为 (a-1)^n + (a+1)^n 除以 a² 的余数。随 n 变化，r 也在变化，记 r_max 为所有可能的 r 中的最大值。求 a = 3..1000 的 r_max 之和。答案：333082500。

## 题目

输入 M，求 a = 3..M 的 r_max 之和。

## 数据范围

- 3 ≤ M ≤ 1000

## 算法

数学推导：
- 当 n 为偶数时：(a-1)^n + (a+1)^n ≡ 2 (mod a²)
- 当 n 为奇数时：(a-1)^n + (a+1)^n ≡ 2na (mod a²)

r_max 取 2na mod a² 的最大值（n 为奇数），即 r_max = 2a × ⌊(a-1)/2⌋。

枚举 a = 3..M，累加即可。时间复杂度 O(M)。

验证：a = 7 时，r_max = 2×7×⌊6/2⌋ = 42，与原题一致。

## 改编方向与取舍

### 改编方向
1. **参数化 M** → 输入 M 求 ∑r_max（本题采用）
2. **单点查询** → 输入 a 求 r_max
3. **大范围 M** → M ≤ 10^6，需要公式推导 O(1) 或 O(√M)
4. **暴力验证** → 枚举 n 验证 r_max

### 取舍理由
- 选择参数化 M：保持原题核心，M=1000 包含原题
- M ≤ 1000：直接枚举，答案在 64 位范围内
- 使用公式：O(M) 足够快，且结果精确
