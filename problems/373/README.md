# 373 — 外接圆半径和

来源：改编自 Project Euler Problem 373

## 原题意

S(n) = 所有边长整数、外接圆半径也为整数的三角形中，外接圆半径不超过n的半径之和。求 S(10⁷)。

## 题目

给定 n，求所有满足条件的三角形的外接圆半径之和 S(n)。

## 数据范围

n ≤ 2000。

## 算法

1. **枚举三角形+整数判别**：枚举 a≤b≤c≤2n，检查 16K² 是否为完全平方数及 R=abc/(4K) 是否整除，O(n³)。
2. **p,q,r参数化**：令 p=-a+b+c 等，利用对称性减少枚举，O(n²)。
3. **枚举R反推**：对每个 R，枚举整数弦长 a=2R sin θ，利用有理正弦参数化。
