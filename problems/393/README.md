# PE393 - 蚂蚁迁徙

来源：改编自 Project Euler Problem 393

## 原题意

n×n 网格上蚂蚁同时移动到相邻格，求无碰撞且无边交叉的方案数 f(n)。求 f(10)。

## 题目

给定 n，求 f(n)。这是网格上的错排/匹配计数问题。

## 算法

- 转化为网格上边不相交的完美匹配
- 可用状态压缩 DP（按格转移）或回溯搜索
- 利用对称性减少状态

## 改编方向

1. **矩形网格**：改为 n×m 矩形，两个维度均可变
2. **允许原地不动**：蚂蚁可以选择不移动
3. **k 步移动**：每只蚂蚁必须移动恰好 k 步
4. **六边形网格**：在六边形网格上进行类似操作
