# 椭圆的切线

来源：改编自 Project Euler Problem 246

## 原题意

M(-2000,1500), G(8000,1500), r=15000。椭圆 e 由到 G 和到圆 c 距离相等的点构成。求格点 P 的数量使得从 P 引椭圆两切线夹角 > 45°。答案: 810834388。

## 题目

给定角度 D（度），求使得从椭圆 e 外格点 P 引两切线夹角 > D° 的 P 的个数。

## 数据范围

30 ≤ D ≤ 89。共 10 个测试点，包含原题数据 (D=45)。

## 算法

1. **椭圆参数化**: 椭圆中心 (3000, 1500)，a=7500，b=2500√5。

2. **角度条件**: 从点 (x₀, y₀) 到椭圆 x²/a² + y²/b² = 1 的两条切线夹角 θ 满足 tan²(θ/2) = a²b²/(a²y₀² + b²x₀² - a²b²)。角 > D° 等价于 a²y₀² + b²x₀² < a²b²(1 + 1/tan²(D/2))。

3. **椭圆环计数**: 满足条件的点位于两个同心椭圆之间：内椭圆半轴 (a, b)，外椭圆半轴 (a·√(1+1/tan²(D/2)), b·√(1+1/tan²(D/2)))。按行扫描，每行用解析公式确定 x 范围后再数格点。

4. **复杂度**: O(Y_range)，对 D=45° 约扫描 30000 行，每行 O(1)，可在 1s 内完成。
