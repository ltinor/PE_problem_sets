# 179 — 连续拥有同样数目正约数的数

来源：改编自 Project Euler Problem 179

## 原题意

求 n < 10^7 中 n 和 n+1 约数个数相等的 n 的个数。原题答案：986262。

## 题目

参数化 N：输入 N（≤ 10^7），求满足条件的 n 个数。

## 数据范围

- N ≤ 10^7

## 算法

**std**: 筛法计算 d(n)（约数个数）。对每个 i 将其倍数 j 的 d[j] 加 1。然后遍历检查 d[n] == d[n+1]。时间复杂度 O(N log N)。

**brute**: 相同算法，直接计算。

## 改编方向

1. **参数化 N**：将固定 N=10^7 改为任意输入。
2. **筛法求约数个数**：标准调和级数筛。
3. **PE 答案验证**：(N=10^7) 输出 986262。
