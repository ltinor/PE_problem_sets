# 137 — Fibonacci Golden Nuggets

来源：改编自 Project Euler Problem 137

## 原题意

求第 15 个 golden nugget（斐波那契生成函数的正整数取值）。

原题答案：1120149658760。

## 题目

参数化 K：输入 K (≤ 15)，求第 K 个 golden nugget。

## 数据范围

- K ≤ 15

## 算法

**std**: 设 AF(x) = x/(1−x−x²) = N（正整数）。需 x 为有理数，等价于 5N²+2N+1 为平方数。通过 Pell 方程分析得递推关系：N₁=2, N₂=15, Nₖ=7·Nₖ₋₁−Nₖ₋₂+1 (k≥3)。直接递推计算第 K 项。

**brute**: 相同递推公式。

## 改编方向

1. **参数化 K**：将原题固定 K=15 改为输入参数。
2. **递推验证**：小 K 值可手工验证，大 K 值验证递推正确性。
3. **PE 答案验证**：(K=15) 作为测试点，输出 1120149658760。
