# 斐波那契金块

## 题目描述

考虑无穷多项式 A_F(x) = xF₁ + x²F₂ + x³F₃ + ...，其中 Fₖ 是第 k 个斐波那契数（F₁=1, F₂=1）。

可以证明 A_F(x) = x / (1 − x − x²)。

当 x 为有理数时，A_F(x) 为整数。这些整数值被称为 golden nuggets。

给定整数 K，求第 K 个 golden nugget。

---

## 输入格式

一行一个整数 K (1 ≤ K ≤ 15)。

---

## 输出格式

一行一个整数，表示第 K 个 golden nugget。

---

## 样例

### 输入

```
1
```

### 输出

```
2
```

### 输入

```
2
```

### 输出

```
15
```

---

## 数据范围

- 1 ≤ K ≤ 15
