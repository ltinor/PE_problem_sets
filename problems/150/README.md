# 150 — 最小子三角形和

来源：改编自 Project Euler Problem 150

## 原题意

在 1000 行的三角形数组中，求最小子三角形和。

原题答案：-271248680。

## 题目

参数化 R：输入 R (≤ 1000)，求 R 行三角形数组中的最小子三角形和。

## 数据范围

- R ≤ 1000

## 算法

**std**: 使用线性同余生成器 tₖ = (615949·tₖ₋₁ + 797807) mod 2²⁰，sₖ = tₖ − 2¹⁹。填充三角形数组。对每行计算前缀和。枚举每个起点 (i,j)，向下扩展计算子三角形和，利用前缀和 O(1) 得到每行的部分和。总复杂度 O(R³)。

**brute**: O(R⁴) 的四层循环枚举所有子三角形，适用于小 R（≤20）。

## 改编方向

1. **参数化 R**：将固定 R=1000 改为输入参数。
2. **前缀和优化**：使用行前缀和将子三角形求和从 O(R⁴) 优化到 O(R³)。
3. **线性同余生成器**：按 PE 原题规范生成三角形数据。
4. **PE 答案验证**：(R=1000) 作为测试点，输出 -271248680。
