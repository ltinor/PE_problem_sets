# 因数分解取石子游戏（Factorisation Nim）

## 题目描述

在经典取石子游戏中，两位玩家轮流从一堆石子中移除任意正数枚石子，无法移动者输。

在因数分解取石子游戏中，初始局面由自然数 n 的质因数分解决定：每个质因数（含重数）对应一堆石子。例如 n=12=2×2×3，初始有三堆：两堆 2 枚、一堆 3 枚。

已知若双方均采取最优策略，n=1 与 n=70 时先手必败。

定义 S(N) 为 1≤n≤N 中先手必败的 n 之和。给定 N，求 S(N)。

---

## 输入格式

一行一个整数 N。

---

## 输出格式

一行一个整数，表示 S(N)。

---

## 样例

### 输入

```
10
```

### 输出

```
14
```

### 输入

```
100
```

### 输出

```
455
```

---

## 数据范围

1 ≤ N ≤ 10^7
