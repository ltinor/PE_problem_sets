# 欧拉总计函数与重排

## 题目描述

欧拉总计函数 φ(n) 表示小于 n 且与 n 互质的正整数个数。例如，φ(9) = 6。

如果 φ(n) 的数字组成与 n 完全相同（只是顺序可能不同），我们称 φ(n) 是 n 的一个重排。例如，φ(87109) = 79180，79180 是 87109 的一个重排。

定义比值 r(n) = n / φ(n)。给定整数 N，在所有满足 1 < n < N 且 φ(n) 是 n 的重排的正整数中，求使 r(n) 最小的 n。

---

## 输入格式

一行一个整数 N。

---

## 输出格式

一行一个整数，表示满足条件且 n/φ(n) 最小的 n。

---

## 样例

### 输入
```
100
```

### 输出
```
21
```

---

## 数据范围

- N ≤ 10,000,000
