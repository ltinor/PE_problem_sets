# 循环多边形数 (Cyclical Figurate Numbers)

来源：改编自 Project Euler Problem 61

## 原题意

找出6个4位循环多边形数（三角形数、正方形数、五边形数、六边形数、七边形数、八边形数各一个），求最小和。答案：28684。

## 改编方向

参数化 K（3≤K≤6）。输入 K，求 K 个4位循环多边形数（前 K 种多边形数各一个）的集合的最小和。

## 题目

给定整数 K，找出 K 个四位数的多边形数，分别来自前 K 种多边形数类型（三角形数、正方形数、五边形数、六边形数、七边形数、八边形数），使得这些数可以排成一个循环：每个数的后两位数字等于下一个数的前两位数字，最后一个数的后两位等于第一个数的前两位。求满足条件的 K 个数的最小和。

## 数据范围

- K: 3 ≤ K ≤ 6
- 多边形数均为 4 位数（1000 到 9999）

## 算法

std: 预生成4位多边形数 → DFS回溯搜索循环 → 求最小和。枚举所有类型排列组合。

brute: 相同算法独立实现。
