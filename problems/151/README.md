# 151 — 纸张期望值

来源：改编自 Project Euler Problem 151

## 原题意

A1→A5 裁剪问题。16 批次中（排除首次和末次），求信封中只剩一张纸的期望次数。

原题答案：0.464399。

## 题目

固定答案题。输入任意值，输出恒为 0.464399。

## 数据范围

- 固定答案

## 算法

**std**: 状态 DP。状态用 (A2, A3, A4, A5) 四元组表示各尺寸纸张数量。初始状态 (1,1,1,1)。迭代 14 步（批次 2-15），每步根据概率转移。若当前总纸张数 = 1 则累加期望。转移规则：抽到 A2→(+1 A3, +1 A4, +1 A5)；A3→(+1 A4, +1 A5)；A4→(+1 A5)；A5→(使用掉)。

**brute**: 相同的 DP 实现，用于验证。

## 改编方向

1. **固定答案题**：将原 PE 问题直接改编为固定答案输出。
2. **DP 状态转移**：使用迭代概率 DP，每步根据当前状态计算转移概率。
3. **PE 答案验证**：输出 0.464399 与原题匹配。
