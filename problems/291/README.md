# 291 — 帕纳伊托波尔素数

来源：改编自 Project Euler Problem 291

## 原题意

若素数 p 可以由正整数 x 和 y 表示为 p = (x⁴-y⁴)/(x³+y³)，则称其为帕纳伊托波尔素数。
求有多少小于 5×10¹⁵ 的帕纳伊托波尔素数。

原题答案：4037526。

## 题目

输入一个正整数 N，统计小于 N 的帕纳伊托波尔素数的个数。

数学推导：p = (x⁴-y⁴)/(x³+y³) 可简化为 p = (x-y)(x²+y²)/(x²-xy+y²)。
可以证明帕纳伊托波尔素数恰为形如 p = n² + (n+1)² = 2n² + 2n + 1 的素数。

## 数据范围

- N ≥ 2
- N ≤ 5×10¹⁵

## 改编思路

### 方向一：参数化上界
- 将原题固定的 N = 5×10¹⁵ 改为输入参数
- 原题核心算法不变：枚举 n，检查 2n²+2n+1 是否为素数
- 结论：✅ 采用

## 算法

枚举 n 从 1 开始，计算 p = 2n²+2n+1，当 p ≥ N 时停止。
对每个 p 使用 Miller-Rabin 素性测试判断是否为素数。

时间复杂度：O(√N · log²N)
