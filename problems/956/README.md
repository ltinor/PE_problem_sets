# PE 956 · Super Duper Sum（超级无敌和）— 简单版本

来源：改编自 Project Euler Problem 956

## 原题意

$\Omega(n)$ 为 $n$ 的质因数个数（含重复）。$D(n,m)$ 为 $n$ 的所有满足 $\Omega(d)$ 能被 $m$ 整除的因数 $d$ 之和。求 $D(1000\bigstar,1000)\bmod 999999001$（涉及超级无敌阶乘与单位根过滤）。

## 简单版本改动

原题需对超大阶乘结构做单位根过滤。改为：直接给定 $n,m$，求 $D(n,m)$。

## 缩数据范围

$1 \le n \le 10^6$，$1 \le m \le 100$。

## 算法

因数枚举：

1. 对 $n$ 试除法质因数分解，得到 $(p_i,e_i)$；
2. DFS 枚举所有因数 $d=\prod p_i^{f_i}$（$0\le f_i\le e_i$），同时累加 $\Omega(d)=\sum f_i$；
3. 若 $\Omega(d)\bmod m=0$ 则累加 $d$。

复杂度 $O(\sqrt n + \tau(n))$，其中 $\tau(n)$ 为因数个数。

## 验证结果

| 验证点 | 期望 | 实际 | 结果 |
|--------|------|------|------|
| $D(24,3)$ | 21 | 21 | ✓ |

（$24$ 的因数为 $1,2,3,4,6,8,12,24$，$\Omega$ 分别为 $0,1,1,2,2,3,3,4$，能被 $3$ 整除的是 $1,8,12$，和为 $21$。）

额外对照：$D(24,1)=60=\sigma(24)$，$D(24,2)=35=1+4+6+24$，$D(24,4)=25=1+24$。
