# 232 — The Race

来源：改编自 Project Euler Problem 232

## 原题意

两个玩家进行比赛，目标分为 100。玩家 1 每次投掷一枚公平硬币：正面得 1 分，反面 0 分。玩家 2 每次选择一个正整数 $T$，投掷 $T$ 枚硬币：若全部正面则得 $2^{T-1}$ 分，否则 0 分。两人交替进行，求玩家 2 的最优胜率。原题答案：0.83648566。

## 题目

参数化目标分 $S$：输入 $S$，求玩家 2（采用最优策略）的胜率。

## 数据范围

$1 \le S \le 100$

## 算法

**std**: DP，状态 $(a, b, turn)$ 表示玩家 1 还需 $a$ 分，玩家 2 还需 $b$ 分，当前轮到 turn。从最终状态倒推：
- 玩家 2 的回合：枚举所有可行 $T$（$2^{T-1} \le$ 剩余分数），选最优。
- 玩家 1 的回合：正面（概率 0.5）扣 1 分，反面保持不变。

时间复杂度 $O(S^2 \log S)$。

**brute**: 递归搜索所有可能路径，适用于 $S \le 6$。

## 改编方向

1. **参数化目标分**：将固定 100 改为输入参数。
2. **不对称目标分**：可改为不同目标分。
3. **可变概率**：参数化硬币正面概率。
