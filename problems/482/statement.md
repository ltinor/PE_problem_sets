# 三角形的内心（PE 482）

## 原题描述

原题及更多讨论见 [https://projecteuler.net/problem=482](https://projecteuler.net/problem=482)。

三角形ABC的三边长都是整数，其内心记为I，周长记为p.
连接内心和顶点的线段IA，IB和IC的长度恰好也都是整数。 

记L = p + |IA| + |IB| + |IC|。 

对于所有满足p ≤ P的三角形，记S(P) = ∑L。例如，S(10<sup>3</sup>) = 3619。

求S(10<sup>7</sup>)。
