# Counting Sundays

来源：改编自 Project Euler Problem 19

## 原题意

在二十世纪（1901年1月1日到2000年12月31日）中，有多少个月的1号是周日？

已知信息：
- 1900年1月1日是周一。
- 月份天数规律（30/31/28或29）。
- 闰年规则：被4整除但不能被100整除，或能被400整除。

## 题目

统计指定日期范围内，每月1号是星期几的个数。

## 数据范围

起始年份 y1, 结束年份 y2，1 ≤ y1 ≤ y2 ≤ 10^9。

## 改编思路

### 方向一：参数化日期范围 + 大年份
- 做法：将固定区间（1901-2000）改为任意输入的起始/结束日期 [y1-m1-d1, y2-m2-d2]，年份可达 10^9，必须用公式计算而非逐月枚举。
- 优点：从固定答案变成真正的算法题，考察闰年周期公式（400年一周期共 146097 天）和模运算。
- 缺点/风险：闰年规则、月份天数、日期边界处理繁琐，容易出 corner case bug。
- 结论：✅ 采用

### 方向二：多组查询
- 做法：T 组查询，每组给出不同的日期范围，要求快速回答。
- 优点：与方向一结合后，加入前缀和/离线查询思想，考察预处理能力。
- 缺点/风险：若每组都 O(N) 会超时，需要 O(1) 回答 → 必须预处理前缀信息（如每月1号的星期），本质上是日期公式题。
- 结论：✅ 采用（提升题目层次）

### 方向三：统计任意星期而非仅周日
- 做法：输入额外参数 w（0=周日,…,6=周六），统计每月1号是星期 w 的个数。
- 优点：增加一个维度的参数，使公式稍复杂但本质不变。
- 缺点/风险：变化太小，本质上只是多一个查表参数。
- 结论：✅ 采用（简单有效的泛化，可作为子任务）

### 方向四：逆向问题——给定个数求最短区间
- 做法：给定 K，求使得每月1号是周日的个数 ≥ K 的最短连续月份区间（或最早达到的日期）。
- 优点：逆向思维，有趣。
- 缺点/风险：答案与日期单调性相关但查询复杂，出题难度大；若 K 很大需要二分+前缀和配合，属于另一种题型。
- 结论：❌ 不采用（与统计题型差异过大）

### 方向五：输出取模
- 做法：答案对 M 取模。
- 优点：答案可能很大时（比如年份到 10^18）可用。
- 缺点/风险：对于计数问题取模自然成立，但本题答案本身不会爆炸（最大约 4800×年份差），取模意义不大。
- 结论：❌ 不采用（无实际必要性）

### 方向六：统计某日是星期几的频率分布
- 做法：给定年份范围，输出每月1号分别是周日~周六各有多少个（7个数的数组）。
- 优点：一次性输出完整分布，比单个统计更有信息量。
- 缺点/风险：和原题本质相同，只是输出更丰富。
- 结论：✅ 采用（丰富输出，可作为方向三的自然延伸）

## 算法

利用 Zeller 公式或基姆拉尔森公式直接计算任意日期的星期。或利用 400 年周期（400 年恰好 146097 天 = 20871 周，星期分布完全循环），预处理 400 年内每月 1 号的星期分布，再通过周期公式 O(1) 回答。

时间复杂度：O(1) 每次查询（预处理 O(1)）。
