# 累进平方数

## 题目描述

正整数 n 除以 d 的商和余数分别是 q 和 r。除此之外，d, q, r 恰好是一个等比数列中的连续三个正整数项，但其对应顺序不一定一致。我们称这样的 n 为*累进数*。

有些累进数恰好也是完全平方数（累进平方数）。例如，9 和 10404 = 102² 都是累进平方数。

给定 M，求所有小于 M 的累进平方数之和。

---

## 输入格式

一行一个整数 M (1 ≤ M ≤ 10¹²)。

---

## 输出格式

一行一个整数，表示所有小于 M 的累进平方数之和。

---

## 样例

### 输入

```
100000
```

### 输出

```
124657
```

---

## 数据范围

- 1 ≤ M ≤ 10¹²
