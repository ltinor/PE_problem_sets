# Pseudo Square Root

来源：改编自 Project Euler Problem 266

## 原题意

12的约数是：1、2、3、4、6和12。不超过其平方根的最大约数是3。称一个整数n的不超过其平方根的最大约数为n的伪平方根（PSR）。

记p是所有小于190的素数的乘积。求PSR(p) mod 10^16。

## 题目

给定整数N，设p为所有小于N的素数的乘积。求PSR(p) mod 10^16。

## 数据范围

$2 ≤ N ≤ 190$

## 算法

Meet-in-the-middle（折半搜索）+ 二分查找

将素数集合分为两半，分别枚举所有子集乘积（使用对数比较，避免大整数溢出），
对左半部分排序后，对右半部分的每个子集乘积二分查找最优搭配。

时间复杂度：$O(2^{m/2} \log 2^{m/2})$，其中m为小于N的素数个数。

## 扩展方向

1. **更大范围N**：使用双精度对数 + 高精度验证（如多模数中国剩余定理验证）
2. **近似算法**：量子退火 / 模拟退火求解子集和问题
3. **变体问题**：求恰好等于平方根的除数（若存在），或求第k大的"伪平方根"
