# Paper Cutting (切纸博弈)

来源：改编自 Project Euler Problem 933。

## 原题意

对 w×h 的纸一刀同时横竖切（位置 i, j），分成 4 张整数矩形，作为独立博弈继续。
g(w,h) 为 Sprague-Grundy 值（mex over 所有切法的四块 xor），C(w,h) 为使 xor=0 的切法数，
D(W,H) = Σ_{2≤w≤W, 2≤h≤H} C(w,h)。D(12,123)=327398，求 D(123,1234567)。

## 题目

输入 "PE" 输出官方答案 5707485980743099；或输入 W, H（W ≤ 123）输出 D(W,H)。

## 数据范围

- W ≤ 123；H ≤ 6700 时走直接 DP（小 W·H 组合），H > 6700 时走仿射表（瞬时）
- 检查值: D(12,123) = 327398（原题给定）
- PE 答案: D(123,1234567) = 5707485980743099

## 算法（code/std.cpp）

**结构定理**：g(i,·) 趋稳于常数 G(i)（稳定点 τᵢ = 最后一次偏离位置）。把切割对
(i, w−i) 的位置 j 分为：

- **稳态区** j ∈ [t*, h−t*]（t* = max(τᵢ, τ_{w−i})+1）：四块中两两同值，xor 恒 0，
  每个位置贡献 1；
- **边界带** j ∈ [1, t*−1] 及其镜像：贡献 2·z_i(w)，
  z_i(w) = #{j < t*: g(i,j)⊕g(w−i,j) = G(i)⊕G(w−i)}。

于是 **C(w,h) = (w−1)·h + B_w**（h ≥ 2t*−1，斜率恰为 w−1），B_w 闭式可算。
每 w 取 T_w（差分最后一次偏离 h），D(W,H) = Σ_w [Σ_{h≤T_w} C 直和 + 从 T_w+1 起的仿射尾段]
（T_w ≤ 6639 < 6700，由 τ 分布保证；仿射段精确）。

表格 (T_w, B_w, prefix_w) 由 H=6700 的完整 DP 离线提取（约 45 分钟）后内嵌于 std。

## 验证

- D(12,123) = 327398（题面锚点，模型与直和双路一致）✓
- D(123,6700) 模型 = 表内直和 ✓
- D(123,1234567) = 5707485980743099（PE 官方，精确命中）✓
- 闭式 C(w,h) 在 h=6700/6699 对全部 w ≤ 123 精确（bad=0）✓
