# 131 — Prime Cube Partnership

来源：改编自 Project Euler Problem 131

## 原题意

求 p < 10⁶ 使得 n³ + n²p 为立方数的素数个数。

原题答案：173。

## 题目

参数化 M：输入 M (≤ 10⁶)，求 p < M 满足条件的素数个数。

## 数据范围

- M ≤ 10⁶

## 算法

**std**: 数学推导。令 k = n + t，展开得 p = 3n²t + 3nt² + t³。当 t = 1 时 p = 3n² + 3n + 1。枚举 k（即原题的 n），计算 p = 3k² + 3k + 1，判断 p 是否为素数且 < M。

**brute**: 枚举 n 和 t，计算 p = 3n²t + 3nt² + t³，若 p < M 且为素数则收集到 set 中。

## 改编方向

1. **参数化 M**：将原题固定 M=10⁶ 改为输入参数。
2. **小范围版本**：M ≤ 1000 可用于对拍验证。
3. **固定答案验证**：M=10⁶ 作为测试点，输出 173。
