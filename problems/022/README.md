# 英文名得分

来源：改编自 Project Euler Problem 22

## 原题意

从一个包含 5000+ 个英文名的文本文件 names.txt 中读取所有名字，按字母序排序后，计算每个名字的得分（位置 × 字母价值），求所有名字得分之和。

## 题目

输入 N 个名字（每行一个，只含大写字母），按字母序排序后，计算总得分。每个名字的得分 = 排序后的位置 × 名字的字母价值之和（A=1, B=2, ..., Z=26）。

## 数据范围

N ≤ 5000，每个名字长度 ≤ 20

## 算法

- 读入 → 排序 → 遍历计算得分。std 与 brute 算法相同。

## 改编方向

- 原题需读取外部文件 names.txt，改为从标准输入流读取所有名字。
- 先输入 N 再输入 N 个名字，比原题更规范。
- 添加多组测试数据支持。
