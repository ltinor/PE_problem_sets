# 斐波那契余数

## 题目描述

对于 $0 \le a, b < m$，定义 $(a,b,m)$-数列：

$$g(0)=a,\quad g(1)=b,\quad g(n)=\big(g(n-1)+g(n-2)\big)\bmod m$$

所有 $(a,b,m)$-数列都是周期数列，其周期记为 $p(a,b,m)$。

记

$$s(m)=\sum_{a=0}^{m-1}\sum_{b=0}^{m-1} p(a,b,m)^2,\qquad S(M)=\sum_{m=1}^{M} s(m)$$

给定正整数 $M$，求 $S(M)$ 对 $999999893$ 取模的结果。

## 输入格式

一行一个整数 $M$。

## 输出格式

一个整数，表示 $S(M) \bmod 999999893$。

## 样例

### 输入

```
10
```

### 输出

```
310897
```

## 数据范围

$1 \le M \le 1000$

> 原题求 $S(10^6)$，此处缩小数据规模。
