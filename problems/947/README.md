# PE 947 — Fibonacci Residues（斐波那契余数）

来源：改编自 Project Euler Problem 947

## 原题意

对于 $0 \le a, b < m$，定义 $(a,b,m)$-数列：$g(0)=a$，$g(1)=b$，$g(n)=(g(n-1)+g(n-2)) \bmod m$。
所有这样的数列都是周期数列，周期记为 $p(a,b,m)$。

定义 $s(m)=\sum_{a=0}^{m-1}\sum_{b=0}^{m-1} p(a,b,m)^2$，$S(M)=\sum_{m=1}^{M} s(m)$。

原题求 $S(10^6)$ 对 $999999893$ 取模的结果。

验证点：$s(3)=513$，$s(10)=225820$，$S(3)=542$，$S(10)=310897$。

## 题目

给定 $M$，求 $S(M) \bmod 999999893$。

## 数据范围

$1 \le M \le 1000$（原题 $M=10^6$，此处缩小数据规模）。

## 算法

状态转移 $T(a,b)=(b,\ (a+b)\bmod m)$ 是 $(\mathbb{Z}/m\mathbb{Z})^2$ 上的双射
（对应矩阵 $\begin{bmatrix}0&1\\1&1\end{bmatrix}$，行列式 $-1$，在模 $m$ 下可逆）。
因此每个 $(a,b)$ 恰好落在唯一一个环上，$p(a,b,m)$ 就是该环长度。

- 对每个 $m$，枚举所有环，记录环长；$s(m)=\sum_{\text{环}}(\text{环长})^3$。
- 复杂度 $O(m^2)$ per $m$，总复杂度 $O(M^3)$，$M=1000$ 约 1.5s。

> 原题（$M=10^6$）需要 Pisano 周期 + CRT + 核空间计数等数论方法，
> 属研究级难题；此处通过缩小数据规模，用直接枚举环即可求解。
