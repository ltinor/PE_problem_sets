# Eulerian Cycles

来源：改编自 Project Euler Problem 289

## 原题意

在 m×n 的格点圆系统中，求不自穿欧拉回路数 L(m,n)。求 L(6,10) mod 10^10。PE 答案：6567944538。

## 题目

给定 m, n, M，求 L(m,n) mod M。

## 数据范围

- 1 ≤ m, n ≤ 3, 1 ≤ M ≤ 10^10

## 改编思路

原题 6×10 规模巨大，无法在 OJ 上直接求解（PE 需要转移矩阵 + 六顶角模型等高级方法）。此处缩小为 1 ≤ m,n ≤ 3，用朴素枚举算法即可在时限内求解，同时保留原题的组合结构。

## 算法

关键观察：不同圆之间的弧只在格点处相遇，平面内不会相交。因此"不自穿"等价于：在每个格点处，把入射的弧（半边）以**不相交的方式**两两配对（即过格点的"转向"不交叉）。

于是 L(m,n) = 满足以下条件的方案数：

1. 每个格点 v 处，对 v 的入射半边做一个**不相交的完美匹配**（圆周上 2k 个点的不相交匹配，共 Catalan(k) 种）；
2. 由这些配对构成的"转移图"（每条弧通过端点配对连向另外两条弧）恰好是一个环（所有弧连通，即单环欧拉回路）。

算法用回溯枚举所有格点的不相交匹配组合（并查集维护弧的连通性），统计单环方案数。

- 验证点：L(1,2)=2，L(2,2)=37，L(3,3)=104290（与 PE 原文一致）。
- 1 ≤ m,n ≤ 3 时最坏情况 (3,3) 约 9.8×10^6 种组合，O(2) 编译下 < 1s。
- 其它小值：L(1,1)=1，L(1,3)=L(3,1)=4，L(2,3)=L(3,2)=672。
