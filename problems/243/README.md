# 不可约度 (Resilience)

来源：改编自 Project Euler Problem 243

## 原题意

定义分母 d 的不可约度 R(d) = φ(d)/(d-1)，即真分数中不可约分数的比例。
求满足 R(d) < 15499/94744 的最小 d。
原题答案: 892371480。

## 题目

给定 a, b，求满足 R(d) = φ(d)/(d-1) < a/b 的最小分母 d。

## 数据范围

输入两个正整数 a, b (1 ≤ a < b ≤ 10^5)。

## 算法

1. **欧拉函数**: φ(d) = d · ∏_{p|d} (1 - 1/p)，故 R(d) = (d/(d-1)) · ∏_{p|d} (1 - 1/p)。

2. **贪心构造**: 为使 R(d) 小，d 应包含尽可能多的小质因数。
   从质数乘积连乘开始 (d = 2·3·5·7·...)，然后倍增调整达到阈值以下。

3. **搜索**: 对不同的初始质数集合，构造候选 d，通过乘 2、3 等小质数微调，
   直到 R(d) < a/b。取最小值。

4. **优化**: d 一定形如 d = 2^{e_2} · 3^{e_3} · 5^{e_5} · ...（小质数的高次幂）。
   可以通过优先队列搜索所有可能的 d。
