# 帕斯卡三角形

## 题目描述

帕斯卡三角形的前几行如下：

```
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
...
```

可以验证，帕斯卡三角形前 7 行中不被 7 整除的条目共有 28 个。

给定整数 R，求帕斯卡三角形前 R 行中不被 7 整除的条目总数。

---

## 输入格式

一行一个整数 R (1 ≤ R ≤ 1,000,000,000)。

---

## 输出格式

一行一个整数，表示前 R 行中不被 7 整除的条目数。

---

## 样例

### 输入

```
7
```

### 输出

```
28
```

### 输入

```
100
```

### 输出

```
2361
```

---

## 数据范围

- 1 ≤ R ≤ 1,000,000,000
