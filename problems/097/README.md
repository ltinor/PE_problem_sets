# 097 — Large Non-Mersenne Prime

来源：改编自 Project Euler Problem 97

## 原题意

计算 $28433 \times 2^{7830457} + 1$ 的最后 10 位数字。

答案：8739992577。

## 题目

给定三个正整数 $A, B, C$，计算 $A \times 2^B + C$ 的最后 10 位数字。输出需要带前导零补足 10 位。

## 数据范围

- $1 \le A \le 10^5$
- $1 \le B \le 10^7$
- $0 \le C \le 10^5$

## 算法

快速幂取模 $10^{10}$。时间复杂度 $O(\log B)$。
