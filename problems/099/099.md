## **Largest Exponential**

Comparing two numbers written in index form like $2^{11}$ and $3^7$ is not difficult, as any calculator would confirm that $2^{11} = 2048 \lt 3^7 = 2187$.

However, confirming that $632382^{518061} \gt 519432^{525806}$ would be much more difficult, as both numbers contain over three million digits.

Using [base_exp.txt](https://projecteuler.net/project/resources/p099_base_exp.txt) (right click and 'Save Link/Target As...'), a 22K text file containing one thousand lines with a base/exponent pair on each line, determine which line number has the greatest numerical value.

NOTE: The first two lines in the file represent the numbers in the example given above.

***
## **最大指数**

比较两个用指数形式表示的数，如 $2^{11}$ 和 $3^7$ 并不困难，任何计算器都可以验证 $2^{11} = 2048 \lt 3^7 = 2187$。

但是，要确认 $632382^{518061} \gt 519432^{525806}$ 则困难得多，因为这两个数都有超过三百万位。

使用 [base_exp.txt](https://projecteuler.net/project/resources/p099_base_exp.txt)（右键点击并选择"链接存储为…"），一个包含一千行底数/指数对的 22K 文本文件，找出哪一行的数值最大。

注意：文件的前两行即上述例子中的两个数。
