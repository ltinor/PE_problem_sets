# 187 — 半素数

来源：改编自 Project Euler Problem 187

## 原题意

求 $n < 10^8$ 且恰有 $2$ 个质因数（计数重复，即半素数，$n = p \times q$，$p,q$ 为质数，允许 $p = q$）的 $n$ 的个数。

例如，$n < 30$ 的半素数有：$4, 6, 9, 10, 14, 15, 21, 22, 25, 26$，共 $10$ 个。

答案：17427258

## 题目

参数化版本：输入 $N$（$N \le 10^8$），求 $n < N$ 且恰有 $2$ 个质因数的个数。

## 数据范围

- $4 \le N \le 10^8$

## 算法

埃氏筛获取所有质数，然后对每个质数 $p$，枚举 $q \ge p$ 使得 $p \times q < N$。时间复杂度 $O(N \log N)$。
