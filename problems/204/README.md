# 204 — Generalised Hamming Numbers

来源：改编自 Project Euler Problem 204

## 原题意

n 型广义汉明数：所有质因子 ≤ n 的正整数。求 ≤ 10⁹ 的 100 型广义汉明数个数。原题答案：2944730。

## 题目

参数化 n, m：输入 n (≤100), m (≤10¹²)，求不超过 m 的 n 型广义汉明数个数。

## 数据范围

- n ≤ 100, m ≤ 10¹²

## 算法

**std**: DFS 枚举。生成 ≤n 的所有素数，递归乘入质因子。每次可选"不乘当前质数"或"乘 1/2/3...次"。剪枝：乘积超过 m 时停止。

**brute**: 同样算法，用于验证小数据。

## 改编方向

1. **参数化 n, m**：将原题固定 n=100, m=10⁹ 改为输入参数。
2. **扩展 m 范围**：m 放宽至 10¹²。
3. **DFS 剪枝**：递归枚举保证不重不漏。
