# 341 — Golomb's Self-Describing Sequence

来源：改编自 Project Euler Problem 341

## 原题意

戈洛姆自描述序列 {G(n)} 是唯一的单调不降自然数序列，满足 n 在序列中出现恰好 G(n) 次。求 ΣG(n³)（1 ≤ n < 10⁶）。答案：5609861067637700。

## 题目

输入 N，求 Σ_{n=1}^{N-1} G(n³)。

## 数据范围

- 2 ≤ N ≤ 3000（OJ 版本）
- 原 PE：N = 10⁶

## 算法

1. **递推生成法**：G(1) = 1；对 i ≥ 2，维护当前值 cur 和剩余次数 rem。若 rem = 0，则 cur++ 并从 G[cur] 获取新的 rem。复杂度 O(M)，M 为所需最大位置。
2. **前缀和二分查找**：预计算 G 和前缀和 P[M]，对查询 n³ 在 P 中二分查找。
3. **分块法**：利用 G 的缓慢增长特性，按块计算贡献。复杂度 O(N^(2/3))。

## 改编方向

1. 原题固定 N = 10⁶ → 参数化 N（2 ≤ N ≤ 3000）
2. 改为求 ΣG(n²) 或 ΣG(kn) 等变体
3. 增加模数限制

选择方向 1：参数化 N。因原题 N=10⁶ 需要 O(N^(2/3)) 算法，现降为 N≤3000，O(N·M) 可行。
