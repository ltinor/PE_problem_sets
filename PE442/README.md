# PE442 - 无11整数

来源：改编自 Project Euler Problem 442

## 原题意

无11整数：十进制表示中不包含任何 11 的幂（除 1 外）作为子串的整数。11 的幂包括：11, 121, 1331, 14641, 161051, ...。E(n) 是第 n 个无11正整数。原题求 E(10^18)，答案为 1295552661530920149。

## 题目

给定 n，求第 n 个无11正整数 E(n)。

## 算法

- 构建 Aho-Corasick 自动机，将所有 11 的幂的十进制表示作为模式串
- 使用数位 DP 在自动机上统计不超过某上限的无11整数数量
- 二分查找第 n 个无11整数
- 时间复杂度 O(log(answer) × log(answer) × states)

## 改编方向

1. **改变进制**：改为 k 进制下的无 11 的幂整数
2. **改变禁止子串**：禁止其他数的幂（如 2 的幂、3 的幂）
3. **统计类问题**：求 [L, R] 范围内无11整数的个数
4. **求和变化**：求前 n 个无11整数的和
