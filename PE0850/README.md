# PE850 — Fractions of Powers（幂的分数）

来源：改编自 Project Euler Problem 850

## 原题意

研究形如 a^m / b^n 的分数，分子分母均为整数幂。问题要求计数或求和这些分数在特定条件下的值。

PE 答案：21469108。

## 算法

1. **生成幂**：对底数范围 [2, B] 和指数范围 [1, E] 生成所有 a^m。
2. **最简分数**：用 gcd 约分得到最简形式。
3. **去重计数**：用集合去重，统计不同的最简分数。
4. **取整求和**：Σ floor(a^k / b) 类型求和需防溢出。
5. **优化**：利用幂的性质，跳过重复计算。

## 改编方向

1. 分子分母使用不同的底数集合
2. 限制分数在特定区间内
3. 分数排序后求中位数或分位数
4. 连分数表示的研究
5. 同时考虑加法和乘法组合（如 a^m + b^n / c^k）
