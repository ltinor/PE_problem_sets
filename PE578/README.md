# PE578 - 递减素数幂整数 (Integers with Decreasing Prime Powers)

来源：改编自 Project Euler Problem 578

## 原题意

若整数 n > 1 的质因子分解 n = ∏ p_i^{a_i}（其中 p_1 < p_2 < ... < p_k）满足指数严格递减，即 a_1 > a_2 > ... > a_k，则称 n 具有"递减素数幂"。

令 S(N) 表示不超过 N 的递减素数幂整数个数。

已知：S(10)=7（数字 2,3,4,5,7,8,9）, S(100)=54。

求 S(10^13)。

PE 答案：345972989065552。

## 算法

使用 DFS 递归构造：对每个质数 p_i，选取指数 e_i < e_{i-1}（其中 e_0 为极大值，如 ⌊log₂ N⌋+1）。通过跳过质数（即令 e_i = 0）来处理质数间隙。剪枝条件：当前乘积 > N。

对于 N=10^13，需高效计数，可使用质数幂次的分块统计或生成函数方法。

## 改编方向

1. 分析递减指数整数的密度和渐近分布
2. 推广到非严格递减（即 a_i ≥ a_{i+1}）的情况
3. 研究具有递增、单峰或其他指数模式的整数
