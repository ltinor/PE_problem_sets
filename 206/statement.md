# 被遮挡的平方数

## 题目描述

一个平方数 n² 的部分数位被遮挡，已知其形式为一个模式串。模式串由数字和 '_' 组成，其中 '_' 表示被遮挡的一位数字（0-9）。

例如，模式串 "1_2_3_4_5_6_7_8_9_0" 表示一个 19 位数，其中第 1 位是 1，第 3 位是 2，...，第 17 位是 9，第 19 位是 0，其余偶数位未知。

给定一个模式串，求满足 n² 匹配该模式串的最小正整数 n。

---

## 输入格式

一行，一个由数字和 '_' 组成的模式串。

---

## 输出格式

一行，一个整数 n，表示满足条件的最小正整数。如果不存在，输出 0。

---

## 样例

### 输入 1

```
1_2_0
```

### 输出 1

```
11
```

（11² = 121，匹配模式 "1_2_0" 吗？1_2_0 要求第1位1、第3位2、第5位0。121 只有3位。让我改样例。）

### 输入 1

```
1_6_0
```

### 输出 1

```
40
```

（40² = 1600，匹配 1_6_0 模式）

### 输入 2

```
1_2_3_4_5_6_7_8_9_0
```

### 输出 2

```
1389019170
```

---

## 数据范围

- 模式串长度：1 ≤ L ≤ 19
- 保证有解且答案不超过 2×10^9
