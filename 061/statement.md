# 循环多边形数

## 题目描述

三角形数、正方形数、五边形数、六边形数、七边形数和八边形数都是多边形数。例如：

- 三角形数：1, 3, 6, 10, 15, ...
- 正方形数：1, 4, 9, 16, 25, ...
- 五边形数：1, 5, 12, 22, 35, ...
- 六边形数：1, 6, 15, 28, 45, ...
- 七边形数：1, 7, 18, 34, 55, ...
- 八边形数：1, 8, 21, 40, 65, ...

一个四位数的有序集合 (n₁, n₂, ..., nₖ) 被称为"循环多边形数集合"，如果满足：

1. 每个数分别来自前 K 种不同的多边形数类型
2. 每个数的后两位数字等于下一个数的前两位数字（循环）
3. 所有数都是四位数（1000 到 9999）

给定 K，求所有满足条件的循环多边形数集合的最小和。

---

## 输入格式

一行一个整数 K（3 ≤ K ≤ 6）。

---

## 输出格式

一行一个整数，表示最小和。

---

## 样例

### 输入

```
6
```

### 输出

```
28684
```

---

## 数据范围

- 3 ≤ K ≤ 6
- 所有多边形数均为 4 位数
