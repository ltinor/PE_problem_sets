# 创意数

## 题目描述

Alice 正在玩这样一个游戏：她从整数列表 $L$ 开始，每一步她可以：
- 从 $L$ 中去除两个元素 $a$ 和 $b$，并将 $a^b$ 加入 $L$
- 或者相反地，从 $L$ 中去除一个可以写成 $a^b$ 形式的元素 $c$，其中 $a$ 和 $b$ 均为整数且 $a, b > 1$，然后将 $a$ 和 $b$ 加入 $L$

注意在列表中同一整数允许重复出现多次。

称整数 $n>1$ 为**创意数**，如果对于任意整数 $m>1$，Alice 都能从 $L=\{n\}$ 开始得到一个包含有 $m$ 的整数列表。

求所有小于或等于 $10^{12}$ 的创意数之和。

## 输入格式

一行，字符串 `PE` 或 `verify`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案：310884668312456458。
若输入为 `verify`，验证小规模创意数的判断逻辑。

## 样例

### 输入
```
PE
```

### 输出
```
310884668312456458
```

## 数据范围

- 完整问题：$n \le 10^{12}$
- 验证模式：$n \le 100$
