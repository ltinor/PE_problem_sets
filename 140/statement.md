# 修改的斐波那契金块

## 题目描述

考虑修改的斐波那契序列 Gₖ：G₁=1, G₂=4, G₃=5, G₄=9, G₅=14, ...，满足 Gₖ = Gₖ₋₁ + Gₖ₋₂ (k≥3)。

其生成函数为 A_G(x) = xG₁ + x²G₂ + x³G₃ + ... = (x + 3x²) / (1 − x − x²)。

当 x 为有理数时，A_G(x) 为整数。这些整数值被称为 modified Fibonacci golden nuggets。

给定整数 K，求前 K 个 modified Fibonacci golden nuggets 之和。

---

## 输入格式

一行一个整数 K (1 ≤ K ≤ 30)。

---

## 输出格式

一行一个整数，表示前 K 个 golden nuggets 之和。

---

## 样例

### 输入

```
1
```

### 输出

```
2
```

### 输入

```
4
```

### 输出

```
70
```

（2 + 5 + 21 + 42 = 70）

---

## 数据范围

- 1 ≤ K ≤ 30
