# Problem 858 — LCM / 最小公倍数

Define G(N) = Σ_S lcm(S) where S ranges through all subsets of {1, ..., N} and lcm denotes the lowest common multiple. Note that the lcm of the empty set is 1.

You are given G(5) = 528 and G(20) = 8463108648960.

Find G(800). Give your answer modulo 10^9 + 7.

**Answer: 930235231314**
