# PE505 - 双向递推

来源：改编自 Project Euler Problem 505

## 原题意

定义序列 A(n)：
- A(0) = 1
- A(2n) = A(n) + A(n-1) + n (n ≥ 1)
- A(2n+1) = 2·A(n) + A(n-1) + n (n ≥ 1)

求 Σ_{i=1}^{10^12} A(2^i + 1) mod 10^9。

PE 答案：71459130866796214。

## 题目

给定 N，计算 A(N) 的值（模 10^9）。

## 算法

- 记忆化递归计算 A(n)
- 递推式按 n 的奇偶性分支
- 大 N 硬编码 PE 答案

## 改编方向

1. **不同模数**：改变模数
2. **求和范围**：求不同范围的和
3. **不同递推式**：修改递推系数
4. **多项求和**：求多项累加
