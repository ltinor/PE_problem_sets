# 随机整数按位或运算

## 题目描述

记 y_0, y_1, y_2, ... 是一系列 K 比特无符号随机整数（即 0 ≤ y_i < 2^K，每个数等概率出现）。

序列 x_i 按如下方式递归定义：
- x_0 = 0
- x_i = x_{i-1} | y_{i-1}（按位或运算）

可以看出，最终存在下标 N，使得对于所有 i ≥ N，有 x_i = 2^K - 1（所有比特位均取 1）。

求 N 的期望值，保留小数点后 10 位小数。

---

## 输入格式

一行一个整数 K。

---

## 输出格式

一行一个实数，表示 N 的期望值，保留 10 位小数。

---

## 样例

### 输入

```
1
```

### 输出

```
1.0000000000
```

### 输入

```
2
```

### 输出

```
2.6666666667
```

### 输入

```
32
```

### 输出

```
6.3551758451
```

---

## 数据范围

- 1 ≤ K ≤ 32
