# 反链的最大长度

## 题目描述

记 S(n) 为 n 的所有正约数构成的集合。若 S(n) 的子集 A 满足：A 中任意一个元素均不能整除 A 中另一个元素，则称 A 为 S(n) 的反链。

记 N(n) 为 S(n) 的反链的最大可能长度。

给定 n，求 Σ_{i=1}^{n} N(i)。

---

## 输入格式

一个整数 n。

---

## 输出格式

一个整数，表示ΣN(i)。

---

## 样例

### 输入
```
30
```

### 输出
```
44
```

---

## 数据范围

- 对于 30% 数据：n ≤ 10^4
- 对于 60% 数据：n ≤ 10^6
- 对于 100% 数据：n ≤ 10^8
