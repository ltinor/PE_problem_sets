# PE386 - 反链的最大长度

来源：改编自 Project Euler Problem 386

## 原题意

约数集合 S(n) 中反链的最大长度 N(n)。求 ΣN(n) for 1≤n≤10^8。

## 题目

N(n) 等于 n 的不同质因子个数 ω(n)。求前缀和。

## 算法

- 线性筛同时计算 ω(n)，然后前缀和
- O(n) 时间，O(n) 空间

## 改编方向

1. **推广约数链**：改求最长整除链（chain）而非反链
2. **区间最大**：求区间 [L,R] 内最大的 N(n) 值及对应 n
3. **带权版本**：每个质因子有不同的权重，反链按权重求和
4. **子集反链**：限定子集大小恰好为 k，求最大可能的 k
