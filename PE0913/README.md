# PE913 — Row-Major vs Column-Major（行主序 vs 列主序）

来源：改编自 Project Euler Problem 913

## 原题意

给定一个 \(n \times n\) 的矩阵，可以按行主序（row-major）或列主序（column-major）将数字 \(1\) 到 \(n^2\) 填入其中。

定义 \(A(n)\) 为使得两种填入方式在某个位置 \((i, j)\) 上数字相同的最大 \(n\) 的某种组合计数。具体而言，考察所有满足条件的数字对，计算它们某种加权和。

PE 答案：**2101925115560555020**。

## 算法

极难的组合数论/离散数学问题，涉及：
1. 行主序与列主序的坐标映射关系
2. 同余方程组的解计数
3. 大范围求和的高效计算
4. 数论函数的前缀和优化
