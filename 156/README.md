# 156 — 数字计数

来源：改编自 Project Euler Problem 156

## 原题意

对于 d = 1..9，统计所有满足 f(n, d) = n 的 n 之和 ∑ s(d)。其中 f(n, d) 表示从 0 写到 n 时数字 d 出现的总次数。

原题答案：21295121502550。

## 题目

固定答案题。输入 dummy 值，输出总答案 ∑_{d=1}^{9} s(d) = 21295121502550。

## 数据范围

- 答案固定

## 算法

**std**: 使用数位计数公式 O(log n) 计算任意 n 的 f(n, d)。对每个 d=1..9，从 n=0 开始搜索，当 f(n,d) > n 时跳跃到 n = f(n,d)，当 f(n,d) < n 时按位数步进。搜索上界约为 10^11。f(n,d) 使用按位公式计算：对于十进制每一位，分别统计该位为 d 时的贡献。

**brute**: 对于小范围 n（≤ 10^6），直接遍历 0..n 计数每个数字的出现次数，验证快速计数公式的正确性。

## 改编方向

1. **固定答案**：原题答案固定为 21295121502550，直接输出。
2. **搜索算法**：std 使用跳跃式搜索，利用 f(n,d) 的单调性加速。
3. **数位统计**：f(n,d) 使用 O(log n) 按位公式计算，避免 O(n) 遍历。
4. **PE 答案验证**：搜索至 10^11 确保找到所有解，验证总答案。
