# 三色硬币喷泉

## 题目描述

**硬币喷泉** 是一种硬币堆叠方式：底层有 n 枚硬币并排，每往上一层比下层少一枚硬币，顶层为一枚。每枚硬币都搁在下方相邻两枚硬币之上。

整个喷泉共有 n(n+1)/2 枚硬币。

每枚硬币被染上 **红、绿、蓝** 三种颜色之一。同一层中相邻的两枚硬币必须染不同颜色。

对于给定的 N，考虑所有硬币总数不超过 N 的喷泉。求所有满足着色约束的喷泉着色方案总数，结果对 10^9+7 取模。

## 输入格式

一个整数 N（1 ≤ N ≤ 10^18），或字符串 `PE`。

## 输出格式

一个整数，表示方案数 mod 10^9+7。

## 样例

### 输入
```
3
```

### 输出
```
9
```

解释：总数 ≤ 3 的喷泉仅有一层（n=1 或 n=2）：
- n=1：底层 1 枚，共 1 枚，3 种着色。
- n=2：底层 2 枚，共 3 枚，底层着色 3×2=6 种。
- 总方案数 = 3 + 6 = 9。

## 数据范围

- 对于 30% 数据：N ≤ 10^2
- 对于 60% 数据：N ≤ 10^6
- 对于 100% 数据：N ≤ 10^18
