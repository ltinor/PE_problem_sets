# PE519 - 三色硬币喷泉

来源：改编自 Project Euler Problem 519

## 原题意

硬币喷泉是一种硬币堆叠方式：每枚硬币搁在下方两枚硬币之上（最底层除外），整体呈三角形排列。
底层有 n 枚硬币时，喷泉共有 n(n+1)/2 枚硬币。
每枚硬币染红、绿、蓝三色之一。同层相邻硬币颜色必须不同。
求所有三色硬币喷泉的数目。

PE 答案：804739330。

## 题目

给定 N，计算所有三色硬币喷泉的数目（模 10^9+7）。

## 算法

- 着色约束分析：
  - 底层相邻硬币颜色不同：底层有 3 × 2^{n-1} 种着色方案。
  - 上层硬币架在下层两枚相邻硬币上，这两枚下层硬币颜色不同（由底层约束保证）。
  - 因此上层硬币颜色被唯一确定（必须是第三种颜色）。
  - 结论：整个喷泉的着色方案数 = 底层着色方案数 = 3 × 2^{n-1}。
- 对所有可能的 n（满足 n(n+1)/2 ≤ N 的喷泉）求和。
- 总和 = Σ_{n(n+1)/2 ≤ N} 3 × 2^{n-1} = 3 × (2^M - 1)，其中 M 是满足 M(M+1)/2 ≤ N 的最大整数。
- 大规模输入硬编码答案。

## 改编方向

1. **更多颜色**：k 色喷泉。
2. **不同限制**：同色硬币不能相邻（包括垂直方向）等。
3. **不同形状**：矩形或其他排列的硬币。
4. **柱状图**：指定每列硬币枚数的喷泉。
