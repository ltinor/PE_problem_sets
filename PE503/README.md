# PE503 - 妥协还是坚持

来源：改编自 Project Euler Problem 503

## 原题意

一副 1 到 N 的牌，随机洗牌后逐张翻开。每次可选择停止，得分 = 最后翻开的牌的数字。求最优策略下的期望得分。

PE 答案：3.8694550145（N → ∞ 的极限值）。

## 题目

给定 N，求最优策略下的期望得分。

## 算法

- 小 N 使用 DP：dp[mask] = 已知已翻开集合 mask 时的最优期望
- 每一步比较当前牌值与继续翻牌的期望
- 大 N 硬编码 PE 答案

## 改编方向

1. **不同 N**：改变牌的数量
2. **不同规则**：最多能跳过 K 次
3. **部分信息**：只知道牌值的范围而非精确值
