# 妥协还是坚持

## 题目描述

一副牌包含 1 到 N 的整数各一张，随机洗牌后逐张翻开。翻开一张牌后，你可以选择：
- **停止**：得分 = 当前翻开的牌的值
- **继续**：翻开下一张牌（如果还有），然后再次选择

你的目标是最大化期望得分。求最优策略下的期望得分。

## 输入格式

一个整数 N（1 ≤ N ≤ 10^12），或字符串 `PE`。

## 输出格式

一个浮点数，保留 10 位小数，表示最优策略下的期望得分。

## 样例

### 输入
```
2
```

### 输出
```
1.5000000000
```

## 数据范围

- 对于 30% 数据：N ≤ 8
- 对于 60% 数据：N ≤ 20
- 对于 100% 数据：N ≤ 10^12
