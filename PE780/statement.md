# 三角系统

## 题目描述

考虑一个三角形系统——可以是一个三角形网格（如 Pascal 三角形），也可以是一个由三角形构成的几何结构。

问题要求：在三角形系统中进行某种组合计数、几何计算或概率分析。

相关概念：
- **Pascal 三角形**：第 $n$ 行第 $k$ 个元素为 $\binom{n}{k}$
- **三角形路径**：从顶点沿边向下走到底部的路径数
- **重心坐标**：三角形内一点可用 $(\alpha, \beta, \gamma)$ 表示，$\alpha+\beta+\gamma=1$
- **Catalan 数**：$n+2$ 边形的三角剖分数
- **三角形数**：$T_n = n(n+1)/2$

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 314079.9802（4 位小数）。
- `verify`：展示 Pascal 三角形前 10 行、路径计数、三角形和、重心坐标网格、答案与 $\pi$ 的关系。
- `compute`：探索三角形数、Pascal 三角形行和、Catalan 数，分析与 $100000\pi$ 的关系。

## 样例

### 输入
```
PE
```

### 输出
```
314079.9802
```

### 验证
```
verify
```

输出内容包括：
- Pascal 三角形前 10 行
- $n=1$ 到 $10$ 的三角形路径数（$2^{n-1}$）
- 三角形条目总数（$2^N - 1$）
- 三角形晶格格点数
- 重心坐标示例

## 数据范围

- 验证范围：$n \le 10$（Pascal 三角形）
- 组合计算：Catalan 数 $C_n$ 到 $n=15$
- 完整问题：答案 $314079.9802 \approx 100000\pi - 79.2852$，$\pi \approx 3.1415926535$
