# 最小子三角形和

## 题目描述

在一个由正整数和负整数构成的三角形数组中，我们希望找到和最小的子三角形。

三角形数组使用以下线性同余生成器生成：

- t₀ = 0
- tₖ = (615949 × tₖ₋₁ + 797807) mod 2²⁰
- sₖ = tₖ − 2¹⁹

将 s₁, s₂, ... 按行优先顺序填入 R 行的三角形数组。

"子三角形"从数组中的某个元素开始，可以向下扩展任意多行，每行比上一行多包含一个元素（与整体三角形形状相同）。

给定 R，求 R 行三角形数组中的最小子三角形和。

---

## 输入格式

一行一个整数 R (1 ≤ R ≤ 1000)。

---

## 输出格式

一行一个整数，表示最小子三角形和。

---

```
3
```
