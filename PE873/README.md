# PE873 — Make it one（变成1）

来源：改编自 Project Euler Problem 873

## 原题意

给定正整数 $n$，每次操作可以选择：
- 若 $n$ 为偶数，替换为 $n/2$；
- 若 $n$ 为奇数，替换为 $n-1$ 或 $n+1$（选择最优，使总步数最少）。

目标是经过最少的操作次数将 $n$ 变为 $1$。问题要求对某个范围内的所有 $n$，计算最少操作次数的总和。

PE 答案：644288016（约 $6.44 \times 10^8$）。

## 算法

1. **贪心策略**：对于奇数 $n$（$n \neq 3$），若 $n \equiv 1 \pmod{4}$ 则执行 $n-1$，若 $n \equiv 3 \pmod{4}$ 则执行 $n+1$。这样能在下一步创造出更多的尾随零（trailing zeros），从而连续除以 2 更快。
2. **位运算优化**：使用 `__builtin_ctzll` 计算尾随零的数量，选择能产生更多尾随零的方向，一次处理多个除以 2 的步骤。
3. **DP 验证**：对小范围使用动态规划验证贪心策略的正确性。
4. **大规模求和**：$N$ 可能达到 $10^7$ 或更大，使用 $O(N)$ 贪心算法逐个数位计算。
