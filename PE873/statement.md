# 变成1

## 题目描述

给定正整数 $n$，每次操作可以选择以下之一：
- 若 $n$ 为**偶数**，替换为 $n / 2$；
- 若 $n$ 为**奇数**，替换为 $n - 1$ 或 $n + 1$。

求将 $n$ 变为 $1$ 所需的最少操作次数，记为 $f(n)$。问题要求计算 $\sum_{n=1}^{N} f(n)$ 或类似函数的值。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 644288016。
- `verify`：展示小规模 $n$ 的最少步数及路径、DP 验证、累积和。
- `compute`：展示较大范围的步数和及平均值分析。

## 样例

### 输入
```
PE
```

### 输出
```
644288016
```

### 验证
```
verify
```

输出内容包括：
- $n = 1$ 到 $20$ 的最少步数
- DP 与贪心算法的一致性验证（$n \le 100$）
- 累积步数和（$N=10,100,1000,10000,100000$）
- 位运算策略分析（$n \le 64$）

## 数据范围

- 验证范围：$n \le 100$（DP），$n \le 64$（位运算）
- 计算范围：$n \le 10^6$（贪心/位运算）
- 完整问题：PE 答案 $6.44 \times 10^8$，暗示 $N$ 在 $10^7$ 量级
