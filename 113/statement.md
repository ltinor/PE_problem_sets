# 非弹跳数

## 题目描述

从左往右，如果每一位数字都大于等于其左边的数字，称为**上升数**（如 134468）。
如果每一位数字都大于等于其右边的数字，称为**下降数**（如 66420）。
既不是上升数也不是下降数的正整数称为**弹跳数**（如 155349）。

给定 D，求小于 10^D 的正整数中有多少个**非弹跳数**（即上升数或下降数）。

---

## 输入格式

一行一个整数 D（1 ≤ D ≤ 100）。

---

## 输出格式

一行一个整数，表示小于 10^D 的非弹跳数个数。

---

## 样例

### 输入
```
6
```

### 输出
```
12951
```

### 输入
```
10
```

### 输出
```
277032
```

### 输入
```
1
```

### 输出
```
9
```

---

## 数据范围

- 1 ≤ D ≤ 100
