# 103 — Special Subset Sums: Optimum（特殊子集和：最优解）

来源：改编自 Project Euler Problem 103

## 原题意

求 $n=7$ 的最优特殊和集的数字字符串。答案：20313839404245。

## 题目

输入 $n$（$1 \le n \le 7$），求 $n$ 个元素的最优特殊和集的数字字符串（元素升序连接）。

特殊和集定义：集合 $A$ 满足：
1. 任意两个非空不相交子集的和不同
2. 若 $|B| > |C|$ 则 $S(B) > S(C)$

最优特殊和集：在所有 $n$ 元特殊和集中 $S(A)$ 最小的那个。

## 数据范围

- $1 \le n \le 7$

## 算法

使用启发式规则（取前一个最优集的中间元素 $b$，构造 $\{b, a_1+b, ..., a_{n-1}+b\}$）获得近似最优解的上界，然后通过带剪枝的 DFS 搜索更优解。条件 2 提供强剪枝（最小 $k+1$ 项之和 > 最大 $k$ 项之和），条件 1 使用位掩码枚举所有子集和并去重检验。$n=7$ 时搜索空间约 $C(40,7) \approx 1.5 \times 10^7$，剪枝后可在秒级完成。

## 改编方向与取舍

### 改编方向
1. **参数化 $n$** → 输入 $n$ 求不同规模的最优集（本题采用，$n \le 7$）
2. **扩展 $n$ 范围** → $n \le 12$，但需要更复杂的搜索（如 A* + 剪枝），指数级复杂度
3. **验证问题** → 给定集合判断是否为特殊和集（与 PE 105 合并）
4. **近似比分析** → 输出启发式规则得到的结果与理论最优的差距

### 取舍理由
- 选择参数化 $n$：最自然的改编，覆盖 $1 \le n \le 7$ 的所有已知最优解
- $n$ 限制在 7：$n=8$ 时最优解的搜索空间激增，需要专门的搜索技巧，与题目设置的 "改编" 而非 "扩展" 定位不符
- 保留最优搜索而非仅用启发式：确保答案的严格正确性
