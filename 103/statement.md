# 特殊的子集和：最优解

## 题目描述

记 $S(A)$ 是大小为 $n$ 的集合 $A$ 中所有元素的和。若从 $A$ 中任取两个非空且不相交的子集 $B$ 和 $C$ 始终满足下列条件，则称 $A$ 是一个**特殊和集**：

1. $S(B) \neq S(C)$（任意子集的和都不相同）
2. 如果 $B$ 中的元素比 $C$ 多，则 $S(B) > S(C)$

对于给定的 $n$，称使得 $S(A)$ 最小的集合 $A$ 为**最优特殊和集**。

给定 $n$，求其最优特殊和集的**数字字符串表示**（将集合中元素按升序直接拼接）。

---

## 输入格式

一行，一个整数 $n$。

---

## 输出格式

一行，一个数字字符串，表示 $n$ 的最优特殊和集。

---

## 样例

### 输入
```
1
```

### 输出
```
1
```

### 输入
```
6
```

### 输出
```
111819202225
```

### 输入
```
7
```

### 输出
```
20313839404245
```

---

## 数据范围

- $1 \le n \le 7$
