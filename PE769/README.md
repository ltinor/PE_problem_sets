# PE769 — Binary Guessing Game（二进制猜数游戏）

来源：改编自 Project Euler Problem 769

## 原题意

在一个二进制猜数游戏中，秘密数字是一个长度为 $N$ 的二进制串。每轮你可以猜测一个二进制串，系统会反馈有多少位与你猜的串匹配（即 Hamming 距离的补集——正确位置的个数）。

游戏的目标是以最少的期望猜测次数确定秘密串。你可以在每轮之后根据反馈调整策略。

问题要求计算最优策略下的期望猜测次数（或该期望的某个归一化值）。

PE 答案：0.53568305（8 位小数）。

## 算法

1. **状态空间**：$2^N$ 个可能的秘密串。
2. **DP / 决策树**：每个状态是当前可能的秘密串集合。每一步选择一个猜测，根据反馈将剩余可能串集合分成 $N+1$ 个组（匹配 0 到 N 位）。
3. **最优策略**：在每个状态下，选择最小化期望剩余步数的猜测。这等价于构造最优决策树。
4. **信息论下界**：每轮最多获得 $\log_2(N+1)$ bits 信息，需要猜测的总 bits 数为 $N$，故下界为 $N / \log_2(N+1)$ 轮。
5. **小规模暴力**：$N \le 4$ 时可以用 DP 精确计算最优策略的期望步数。

## 改编方向

1. 推广到 $M$ 元字母表
2. 允许部分匹配反馈（Mastermind 风格：黑钉/白钉）
3. 噪声反馈（一定概率反馈错误）
4. 多个秘密同时猜
5. 对手选择秘密的博弈论版本
