# 二进制猜数游戏

## 题目描述

秘密数字是一个长度为 $N$ 的二进制串。每轮你猜测一个二进制串，系统反馈正确匹配的位数（即你的猜测串与秘密串有多少位相同）。

你可以根据历史反馈调整后续猜测。目标是使用最优策略，使期望猜测次数最小化。

问题要求输出最优策略下的期望猜测次数（对大量实验的归一化结果），精确到 8 位小数。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 0.53568305（精确到 8 位小数）。
- `verify`：对 $N \le 4$ 使用 DP 精确计算最优期望步数，并展示信息论下界。
- `compute`：对 $N \le 8$ 使用熵近似计算期望步数下界，并分析候选闭式公式。

## 样例

### 输入
```
PE
```

### 输出
```
0.53568305
```

### 验证
```
verify
```

输出内容包括：
- $N=1,2,3,4$ 的最优期望猜测次数（$N=4$ 有 16 个候选串，用 DP 精确计算）
- 随机猜测的期望步数和穷举搜索的期望步数
- $N=1 \dots 10$ 的信息论下界 $N / \log_2(N+1)$
- 答案的数学解释分析

## 数据范围

- 验证范围：$N \le 4$（状态空间 $2^4 = 16$，完全 DP）
- 近似范围：$N \le 8$（信息论边界）
- 完整问题：PE 答案 0.53568305
