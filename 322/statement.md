# 能被 10 整除的二项式系数

## 题目描述

记 T(m, n) 为满足 n ≤ i < m 且二项式系数 C(i, n) 能被 10 整除的整数 i 的个数（i, m, n 均为正整数）。

已知 T(10^9, 10^7-10) = 989697000。

给定 D 和 K，令 m = 10^D，n = 10^K - 10。求 T(m, n)。

---

## 输入格式

一行两个整数 D 和 K。

---

## 输出格式

一行一个整数，表示 T(10^D, 10^K-10)。

---

## 样例

### 输入

```
9 7
```

### 输出

```
989697000
```

### 输入

```
18 12
```

### 输出

```
1998781740
```

---

## 数据范围

- 1 ≤ D ≤ 18
- 1 ≤ K ≤ D
