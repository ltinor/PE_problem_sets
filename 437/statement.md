# 斐波那契原根（PE 437）

## 题目描述

若素数 $p$ 的某个原根 $g$ 满足 $g^n + g^{n+1} \equiv g^{n+2} \pmod p$ 对所有 $n$ 成立，则称 $g$ 为 $p$ 的一个**斐波那契原根**。

给定 $N$，求所有不超过 $N$ 且至少有一个斐波那契原根的素数 $p$ 之和 $S(N)$。

由 $g^2 \equiv g+1$ 可知候选根为 $g \equiv \frac{1\pm\sqrt 5}{2} \pmod p$，故 $5$ 必须是 $p$ 的二次剩余。

原题（PE437）即 $N = 10^8$，答案为 $74204709657207$。

---

## 输入格式

第一行一个 token：

- 若为 `PE`，输出原题（$N=10^8$）官方答案；
- 否则为整数 $N$（$2 \le N \le 10^6$）。

---

## 输出格式

一行一个整数 $S(N)$。

---

## 样例

### 输入

```
10000
```

### 输出

```
1480491
```

（与原题陈述中给出的校验值一致：小于 10000 的数中有 323 个这样的素数，和为 1480491。）

---

## 数据范围

- 若输入为 `PE`，输出 $74204709657207$；
- 否则 $2 \le N \le 10^6$。

## 提示

- $S(20) = 35$：满足条件的素数为 $5, 11, 19$（$11$ 的斐波那契原根是 $8$）。
