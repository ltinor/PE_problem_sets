# 约数和的整除性

## 题目描述

记 σ(n) 为 n 的所有正约数之和。例如 σ(4) = 1+2+4 = 7。

记 S(N, 2017) 为所有不超过 N 且 σ(i) 能被 2017 整除的 i 之和。

已知 S(10^6, 2017) = 150850429。

给定 N，求 S(N, 2017)。

---

## 输入格式

第一行一个 token：

- 若为 `PE`，输出原题（$N = 10^{11}$）官方答案；
- 否则为整数 $N$（$1 \le N \le 10^6$）。

## 输出格式

一行一个整数：$\sum_{n \le N,\ 2017 \mid \sigma(n)} n$。

## 样例

### 输入

```
12101
```

### 输出

```
12101
```

（最小的好例：$\sigma(12101) = 12102 = 6 	imes 2017$；$N = 24202$ 时和为 $12101 + 24202 = 36303$。）

---

## 数据范围

- 若输入为 `PE`，输出 $2992480851924313898$；
- 否则 $1 \le N \le 10^6$。

## 提示

$\sigma(n) = \prod \sigma(p_i^{a_i})$，$2017$ 为素数，故 $2017 \mid \sigma(n)$ 当且仅当 $n$ 的某个素数幂 $p^a$ 满足 $\sigma(p^a) \equiv 0 \pmod{2017}$。对每个素数取最小这样的 $a$；在 $N \le 10^6$ 内各"最小坏素数幂"两两乘积超过 $N$，直接求和即可。
