# 约数和的整除性

## 题目描述

记 σ(n) 为 n 的所有正约数之和。例如 σ(4) = 1+2+4 = 7。

记 S(N, 2017) 为所有不超过 N 且 σ(i) 能被 2017 整除的 i 之和。

已知 S(10^6, 2017) = 150850429。

给定 N，求 S(N, 2017)。

---

## 输入格式

一行，一个整数 N。

---

## 输出格式

一行，一个整数，表示 S(N, 2017)。

---

## 样例

### 输入
```
1000000
```

### 输出
```
150850429
```

---

## 数据范围

- 1 ≤ N ≤ 10^11
