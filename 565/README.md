# 565 - 约数和的整除性 (Divisibility of sum of divisors)

来源：改编自 Project Euler Problem 565

## 原题意

记 σ(n) 为 n 的约数之和。记 S(N, d) 为所有不超过 N 且 σ(i) 被 d 整除的 i 之和。
已知 S(20, 7) = 49，S(10^6, 2017) = 150850429，S(10^9, 2017) = 249652238344557。
求 S(10^11, 2017)。

PE 答案：29924808519531668。

## 题目

给定 N，求 S(N, 2017)。

## 数据范围

- 1 ≤ N ≤ 10^11

## 算法

2017 为质数。σ 为积性函数。σ(n) ≡ 0 (mod 2017) 当且仅当存在质数幂 p^e || n 使 σ(p^e) ≡ 0 (mod 2017)。

对于 p ≠ 2017：σ(p^e) ≡ 0 ⟺ p^{e+1} ≡ 1 (mod 2017)。设 d = ord_{2017}(p)，则需 e+1 为 d 的倍数。最小 "坏" 指数为 d-1。

对于 p = 2017：σ(2017^e) ≡ 1 (mod 2017) 恒成立，永不 "坏"。

算法：
1. 对小质数 p ≤ √N，枚举所有坏质数幂 p^e ≤ N
2. 对大质数 p > √N，只有 e=1 可能：σ(p) = p+1 ≡ 0 ⟺ p ≡ 2016 (mod 2017)
3. 使用容斥原理求和：所有被至少一个坏质数幂整除的数
4. 由于坏质数幂的 LCM 增长极快，DFS 深度有限

时间复杂度：O(√N log N)。

## 改编方向

1. **不同除数 d**：更换 d 为其他质数或合数。
2. **约数个数**：改为研究 σ₀(n)（约数个数）的整除性。
3. **区间查询**：求 S(L, R, d)。
4. **乘积计数**：求满足条件的 n 的乘积而非和。
