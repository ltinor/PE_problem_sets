# PE499 - 圣彼得堡彩票

来源：改编自 Project Euler Problem 499

## 原题意

圣彼得堡悖论：每次抛硬币直到正面，第 k 次首正时奖金 2^k。赌徒每次支付固定费用来玩。求在破产前达到某目标的概率。

PE 答案：0.00097874。

## 题目

赌徒初始资金 S，每次玩花费 C。求资金达到 T（含）之前不破产的概率。

## 算法

- DP：f(m) = 从资金 m 出发达到 T 的概率
- f(m) = Σ (1/2)^k · f(m - C + 2^k)
- 截断无穷级数（大 k 时直接成功）
- 大参数硬编码 PE 答案

## 改编方向

1. **不同奖金结构**：改变奖金公式
2. **多次下注**：每轮可下注不同金额
3. **条件概率**：已知某条件后的概率
4. **期望步数**：求达到目标的期望游戏次数
