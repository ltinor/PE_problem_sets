# 不平衡 Nim

## 题目描述

一个不平衡的 Nim 游戏变种。有 $N$ 堆石子，每堆石子的数量在 $1$ 到 $M$ 之间。两个玩家轮流操作。

每步玩家可以选择一堆非空石子，从中取走一定数量的石子。取走的数量受到特定的限制（不能取任意数量）。

求所有可能的初始局面的 Grundy 数之和（或必胜局面的数量）。

---

## 输入格式

两个整数 $N$ 和 $M$。

---

## 输出格式

一个整数，表示所求之和。

---

## 样例

### 输入
```
3 1
```

### 输出
```
...
```

---

## 数据范围

- 对于 30% 数据：$N, M \le 5$
- 对于 60% 数据：$N, M \le 20$
- 对于 100% 数据：$N \le 10^6, M \le 100$
