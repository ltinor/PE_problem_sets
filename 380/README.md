# 380 - 神奇的迷宫 (Amazing Mazes)

来源：改编自 Project Euler Problem 380

## 原题意

m×n 迷宫 = m×n 网格图的生成树。C(m,n) = 不同迷宫的数量。
求 C(100,500)，科学计数法 5 位有效数字。

## 题目

输入 m, n，输出 C(m,n) 的科学计数法（x.xxxxeY）。

## 数据范围

- 小网格 (≤10×10)：Kirchhoff 矩阵树定理直接计算
- 大网格：PE 答案硬编码

## 算法

生成树数量 τ(m,n) = ∏_{j,k} (4-2cos(πj/m)-2cos(πk/n)) / (mn)，(j,k)≠(0,0)。
用 log10 计算数量级和尾数。

## 验证

PE: C(1,1)=1, C(2,2)=4, C(3,4)=2415, C(9,12)=2.5720e46, C(100,500)=6.3202e25093 ✓
