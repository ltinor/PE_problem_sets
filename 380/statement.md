# 神奇的迷宫

## 题目描述

m×n 迷宫是将 m×n 矩形网格的部分方格之间用墙隔开，使得从左上角出发恰好只有一条路到达其他任意方格。

记 C(m,n) 为不同 m×n 迷宫的数量（旋转和翻转视为不同）。

给定 m 和 n，输出 C(m,n) 的科学计数法表示，保留 5 位有效数字，格式 x.xxxxeY。

---
## 输入格式

两个整数 m 和 n。

---
## 输出格式

科学计数法表示的 C(m,n)，格式 x.xxxxeY。

---
## 样例

### 输入
```
1 1
```

### 输出
```
1.0000e0
```

### 输入
```
3 4
```

### 输出
```
2.4150e3
```

---
## 数据范围

- m, n ≤ 500
