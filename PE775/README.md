# PE775 — Saving paper（节约用纸）

来源：改编自 Project Euler Problem 775

## 原题意

"Saving paper" 是关于纸张折叠或切割优化的组合问题。一张矩形纸可以多次对折（水平或垂直对折），每次折叠将纸的尺寸减半（需要边长为偶数）。

主要变体：
1. **纸张折叠**：从 $W \times H$ 开始，每次沿水平或垂直中线对折。求折叠到目标尺寸 $w \times h$ 的方案数。
2. **矩形切割（裁纸）**：给定一组需要的矩形尺寸，求从标准纸张中切出所有矩形所需的最少纸张数（或最小浪费面积）。
3. **组合打包**：将多个小矩形贪心或最优地排列在大纸张上。

PE 答案：946791106（约 $9.47 \times 10^8$）。

## 算法

1. **折叠 BFS**：状态 $(w, h, \text{folds})$ 表示当前纸张尺寸和已折叠次数。从初始状态出发，枚举水平或垂直对折。
2. **合法性判定**：折叠仅当对应边长为偶数且 $\ge 2$。
3. **路径计数**：使用 BFS 或 DP 统计从初始尺寸到目标尺寸的不同折叠序列数。
4. **切割贪心**：对于矩形切割问题，使用面积下界 $\lceil \sum (w_i h_i) / (WH) \rceil$ 作为最少纸张数估计。
5. **旋转处理**：矩形可以旋转 90° 放置（$w \times h$ 或 $h \times w$）。

## 改编方向

1. 推广到 $k$ 折（一次折叠产生 $k$ 层）而非 2 折
2. 非均匀折叠（不沿中线，折叠位置可变）
3. 三维纸张折叠
4. 带纹理/图案的纸张（折叠后图案对齐）
5. 多种纸张尺寸混合的最优切割
