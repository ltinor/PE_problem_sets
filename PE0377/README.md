# 数字和，邂逅13

来源：改编自 Project Euler Problem 377

## 原题意

不含零的数字且各位和 = n 的所有正整数之和为 f(n)。求 Σ_{i=1}^{17} f(13^i) 的最后 9 位数字。PE 答案：732385277。

## 题目

给定 n，求 f(n) mod M。

## 数据范围

n ≤ 10^5, M = 10^9

## 算法

### 方向一：DP + 组合数学

f(n) = Σ_{k=1}^n (各位和为 n-k 且不含零的 k 位数数量) × (由这些数构成的值的贡献)。使用 DP 计算：dp[i][j] = i 位不含零且和 = j 的数的个数 + 数值贡献。

### 方向二：生成函数

不含零的数字集合为 {1,2,...,9}。生成函数 G(x,y) = Π_{i≥0} (1 + y·10^i·(x+x²+...+x⁹))。f(n) 为 y 的一次项在 x^n 的系数 × 对应权重。

### 方向三：递推 + 快速幂

f(n) 满足线性递推。用矩阵快速幂或多项式快速幂加速计算大 n。

### 时间复杂度

O(n²) 或 O(n log n)。
