# 解不定方程

## 题目描述

考虑不定方程 1/a + 1/b = p/10^n，其中 a、b、p、n 均为正整数，且 a ≤ b。

对于 n=1，该方程有 20 个解。

给定 N，求对于所有 1 ≤ n ≤ N，方程共有多少个解。

---

## 输入格式

一行一个整数 N (1 ≤ N ≤ 9)。

---

## 输出格式

一行一个整数，表示总解数。

---

## 样例

### 输入

```
1
```

### 输出

```
20
```

### 输入

```
2
```

### 输出

```
（对应 n=1,2 的总解数）
```

---

## 数据范围

- 1 ≤ N ≤ 9
