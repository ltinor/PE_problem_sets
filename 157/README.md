# 157 — 解不定方程

来源：改编自 Project Euler Problem 157

## 原题意

求不定方程 1/a + 1/b = p/10^n（a ≤ b）在 n=1..9 时的总解数。

原题答案：53490。

## 题目

参数化 N：输入 N (≤ 9)，求 n=1..N 的总解数。

## 数据范围

- N ≤ 9

## 算法

**std**: 方程化为 (a-D)(b-D) = D²，其中 D = 10^n/p。枚举 10^n 的所有约数 d = 2^a2·5^a5，则 D = 10^n/d = 2^(n-a2)·5^(n-a5)。D² 的约数个数为 (2n-2a2+1)(2n-2a5+1)。对于每个 u|D² 且 u ≤ D，得到解 a = D+u, b = D+D²/u。约数对数为 ceil(cnt/2) = (cnt+1)/2。复杂度 O(n²)。

**brute**: 直接枚举 a, b 上限到 10·10^n，验证 10^n(a+b) 能否被 ab 整除。仅适用于小 n（≤ 2-3）。

## 改编方向

1. **参数化 N**：将固定 n=1..9 改为输入 N。
2. **数论推导**：利用变换 (a-D)(b-D) = D²，将问题转化为枚举约数。
3. **PE 答案验证**：(N=9) 输出 53490。
