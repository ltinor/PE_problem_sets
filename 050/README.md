# 连续素数的和 (Consecutive Prime Sum)

来源：改编自 Project Euler Problem 50

## 原题意

找到小于一百万的素数中，能被写成最多连续素数之和的素数。答案：997651（共 543 项）。

## 改编方向

参数化 N（2≤N≤10⁶）。输入 N，求 <N 的素数中能被最多连续素数之和表示的素数，输出该素数和项数。多组输入。

## 题目

给定正整数 N，在所有小于 N 的素数中，找出可以被写成最多连续素数之和的素数。输出这个素数和使用的连续素数项数。

## 数据范围

- N: 2 ≤ N ≤ 10⁶
- 多组测试数据

## 算法

std: 埃氏筛生成素数 → 前缀和 → 双指针/滑动窗口找最大长度。O(N log log N + √N × π(N))。

brute: 筛素数 → 双重循环枚举起点和终点 → 检查累加和是否为素数。O(π(N)²)。
