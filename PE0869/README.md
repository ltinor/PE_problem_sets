# PE869 — Prime Guessing（素数猜数）

来源：改编自 Project Euler Problem 869

## 原题意

一个猜数游戏：在一个范围 [1, N] 内隐藏了一个素数。你可以通过提问来找出这个素数。

问题求解最优策略下的期望猜测次数。这与信息论有关：如果已知有 π(N) 个素数，通过二分查找确定具体是哪一个素数，期望步数约为 log₂(π(N))。

## 算法

1. **素数计数**：使用筛法统计 ≤ N 的素数个数 π(N)。
2. **期望计算**：在 π(N) 个候选中进行二分查找的期望步数。
3. **信息论下界**：最优策略的期望步数 ≥ H(均匀分布) / log₂(分支因子)。
4. **最优策略**：对素数索引进行二分查找。

## 改编方向

1. 非均匀先验分布下的最优猜测
2. 允许范围查询（"是否 ≤ x?"）vs 直接猜测
3. 多次猜测的批量策略
4. 与素数密度的关系分析
