# 维尼木棍马拉松

## 题目描述

克里斯托佛·罗宾和小熊维尼发明了新版本的维尼木棍游戏。两人同时在桥的上游扔下木棍。当一根木棍从下游出现时，捞起来重新扔到上游。游戏只在当一根木棍从下游出现并套了另一根木棍整整一圈时结束。

每根木棍从上游到下游的用时均匀分布在 [n, m] 的所有整数秒上。捞起并重新扔下木棍需 5 秒。

记 E(m, n) 为期望游戏时间（秒）。已知 E(60, 30) = 1036.15...。

令 S(k) = Σ_{m=2}^k Σ_{n=1}^{m-1} E(m, n)。

已知：
- S(5) = 7722.82（保留 2 位小数）

求 S(100)，答案保留 2 位小数。

## 输入格式

一行，一个整数 k（或字符串 `PE`）。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案：131776959.88725。
若输入为整数 k（k < 100），输出 S(k) 保留 2 位小数。

## 样例

### 输入
```
5
```

### 输出
```
7722.82
```

### 输入
```
PE
```

### 输出
```
131776959.88725
```

## 数据范围

- k ≤ 100 或输入为 PE
