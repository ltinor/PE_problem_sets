# PE589 — 泊松分布 / 维尼木棍马拉松 (Poohsticks Marathon)

来源：改编自 Project Euler Problem 589

## 原题意

克里斯托佛·罗宾和小熊维尼发明了新版本的维尼木棍游戏。两人同时在桥的上游扔下木棍。当一根木棍从下游出现时，捞起来重新扔到上游。游戏只在当一根木棍从下游出现并套了另一根木棍整整一圈时结束。

每根木棍从上游到下游的用时均匀分布在 [n, m] 的所有整数秒上。捞起并重新扔下木棍需 5 秒。

记 E(m, n) 为期望游戏时间（秒）。已知 E(60, 30) = 1036.15...。

令 S(k) = Σ_{m=2}^k Σ_{n=1}^{m-1} E(m, n)。

例如 S(5) = 7722.82（保留 2 位小数）。

求 S(100)，答案保留 2 位小数。

PE 答案：131776959.88725。

## 算法

该问题可以建模为两个独立的更新过程（renewal process）。每根木棍的每次旅程时间 T_i ~ Uniform{n, m} + 5。

游戏结束时，两根木棍的完成次数差为 1，且领先的木棍先完成其最后一趟旅程。

这等价于一个在整数 Z 上的随机游走问题：每次事件（某根木棍完成旅程）对应一步 ±1，步长不确定。期望时间可通过马氏链的线性方程组或更新理论公式计算。

对于 n, m ≤ 100，S(100) 包含约 4950 个 E(m, n) 值。可使用动态规划在每个 (m, n) 对的状态空间上进行期望值计算，状态为两根木棍的剩余时间和当前阶段（旅行/打捞）。

## 改编方向

1. 改变打捞时间（如变成随机时间）。
2. 旅行时间改为其他分布（如指数分布、正态分布）。
3. 增加更多玩家（3 人或更多）。
4. 研究 E(m, n) 关于 m, n 的渐近表达式。
5. 改变获胜条件（如需要领先 2 圈）。
