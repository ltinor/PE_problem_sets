# 素数子集和

来源：改编自 Project Euler Problem 249

## 原题意

S = {2, 3, 5, ..., 4999}（小于 5000 的素数）。求 S 的子集中，元素和为素数的子集个数。输出最后 16 位。答案: 9275262564250418。

## 题目

给定 N，S = {素数 < N}。求元素和为素数的子集个数 mod 10¹⁶。

## 数据范围

N ≤ 5000。共 10 个测试点，包含原题数据和随机数据。

## 算法

1. **DP 子集和计数**: dp[s] = 和为 s 的子集个数。对每个素数 p，倒序更新 dp。总状态数为所有素数的和，对 N=5000 约为 1.5×10⁶。

2. **素数判定**: 使用埃氏筛预计算所有 ≤ sum_all 的素数。

3. **复杂度**: O(π(N) · sum)，其中 sum ≈ N²/(2 ln N)。对 N=5000，约 6.7×10⁸ 次操作，在 1s 内可通过（常数小）。
