# 素数子集和

## 题目描述

记 S(N) = {p | p < N, p 是素数}，即所有小于 N 的素数组成的集合。

求 S(N) 有多少个子集，其元素之和是一个素数。

输出答案的最后 16 位数字（即 mod 10¹⁶）。

---

## 输入格式

一行一个整数 N。

---

## 输出格式

一行一个整数，表示答案 mod 10¹⁶。

---

## 样例

### 输入
```
5
```

### 输出
```
3
```

（S(5) = {2, 3}。子集有：∅(和0，非素数), {2}(和2，素数), {3}(和3，素数), {2,3}(和5，素数)。共 3 个素数子集。）

### 输入
```
5000
```

### 输出
```
9275262564250418
```

---

## 数据范围

- 对于 20% 的数据：N ≤ 30
- 对于 50% 的数据：N ≤ 200
- 对于 80% 的数据：N ≤ 1000
- 对于 100% 的数据：N ≤ 5000
