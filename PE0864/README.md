# PE864 — Square + 1（平方+1）

来源：改编自 Project Euler Problem 864

## 原题意

研究形如 n² + 1 的数的性质。素数 p 整除某个 n² + 1 当且仅当 p ≡ 1 (mod 4) 或 p = 2。

本题可能要求：统计 n ≤ N 中使得 n² + 1 为素数的 n 的个数，或求和 n² + 1 的素因子之和，或统计 n² + 1 具有特定约数个数的 n 的数量。

## 算法

1. **素数检测**：对每个 n² + 1 进行素数测试（Miller-Rabin 或试除法）。
2. **素因子分解**：对于小范围，可对每个 n² + 1 做因子分解。
3. **筛法加速**：利用 p ≡ 1 (mod 4) 的性质筛选。
4. **统计分析**：计算素因子个数/种类的分布。

## 改编方向

1. 推广到 an² + bn + c 形式的素数生成
2. n² + 1 的无平方因子性质
3. 与 Bunyakovsky 猜想的数值验证
4. n² + 1 的素因子大小分布
