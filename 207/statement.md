# 整数分拆等式

## 题目描述

对于某些正整数 k，存在实数 t 使得 4^t = 2^t + k 且 4^t, 2^t, k 均为正整数。若 t 也是整数，则称该分拆为完美的。

例如：4^1 = 2^1 + 2 是一个完美分拆（t=1），而 4^{1.5849625...} = 2^{1.5849625...} + 6 不是完美分拆。

对任意 m ≥ 1，定义 P(m) 为所有 k ≤ m 的分拆中完美分拆所占的比例。

给定分数 a/b，求使 P(m) < a/b 的最小正整数 m。

---

## 输入格式

一行，两个整数 a 和 b（1 ≤ a < b ≤ 20000）。

---

## 输出格式

一行，一个整数 m，表示满足条件的最小值。

---

## 样例

### 输入 1

```
1 2
```

### 输出 1

```
6
```

（P(6) = 1/2，不小于 1/2；P(12) = 2/3... 实际要找到第一个 < 1/2 的 m）

### 输入 2

```
1 12345
```

### 输出 2

```
44043947822
```

---

## 数据范围

- 1 ≤ a < b ≤ 20000
- 答案 ≤ 10^12
