# 连续拥有同样数目正约数的数

## 题目描述

求满足 1 < n < N 且 n 和 n + 1 拥有同样数目正约数的整数 n 的数目。

例如，14 有 4 个正约数（1, 2, 7, 14），而 15 也有 4 个正约数（1, 3, 5, 15），因此 14 满足条件。

## 输入格式

一行一个整数 N（2 ≤ N ≤ 10^7）。

## 输出格式

一行一个整数，表示满足条件的 n 的个数。

---

## 样例

### 输入
```
10
```

### 输出
```
1
```

（只有 n=2：d(2)=2, d(3)=2）

### 输入
```
100
```

### 输出
```
15
```

### 输入
```
10000000
```

### 输出
```
986262
```

---

## 数据范围

- 2 ≤ N ≤ 10^7
- PE 原题 N=10^7 时答案为 986262。

---

## 提示

使用筛法计算每个数的约数个数 d(n)。对于 i 从 1 到 N+1，将 i 的所有倍数 j 的 d[j] 加 1。时间复杂度 O(N log N)。
