# 海伦信封

## 题目描述

一个标准信封是由一个在上的等腰三角形（翻折面 BCD）和一个在下的长方形 ABDE 组成的凸多边形。一个合理的信封要求翻折面 BCD 的高小于长方形 ABDE 的高。

若一个信封的所有边长均为整数，且所有对角线（AC, AD, BD, BE, CE）的长度也都是整数，则称之为海伦信封。

令 S(p) 表示所有周长 ≤ p 的海伦信封的周长之和。

已知：S(10⁴) = 884680。

给定 p，求 S(p)。

## 输入格式

一行，一个整数 p（或字符串 `PE`，或 `test`）。

## 输出格式

一个整数，表示 S(p)。

若输入为 `PE`，输出 PE 原题的答案：S(10⁷)。
若输入为 `test`，输出已知测试值。

## 样例

### 输入
```
10000
```

### 输出
```
884680
```

### 输入
```
PE
```

### 输出
```
11741372990012608
```

## 数据范围

- 对于 30% 数据：p ≤ 10³
- 对于 60% 数据：p ≤ 10⁵
- 对于 100% 数据：p ≤ 10⁷ 或输入为 PE
