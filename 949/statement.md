# 小左对小右（二）（Left vs Right II）

## 题目描述

小左和小右在玩一个游戏。桌上有 $k$ 个由字母 `L` 和 `R` 组成的单词，每个单词的长度均为 $n$。两人轮流行动。

- 在小左的回合，小左可以**对每一个单词**从其左侧移除任意个字母（可以为 $0$ 个），但不能把某个单词的字母全部移除；并且整回合至少要从某个单词移除一个字母。
- 在小右的回合，小右可以**对每一个单词**从其右侧移除任意个字母（可以为 $0$ 个），但不能把某个单词的字母全部移除；并且整回合至少要从某个单词移除一个字母。

游戏一直进行，直到每个单词都只剩下一个字母。此时：

- 若剩余的字母中 `L` 比 `R` 多，则小左获胜；
- 若剩余的字母中 `R` 比 `L` 多，则小右获胜。

本题保证 $k$ 为奇数，因此不会出现平局。

记 $G(n,k)$ 为「由 $k$ 个长度为 $n$ 的单词组成、且小左先手时小右有必胜策略」的局面数。由相同单词构成的不同排列分别计数（即统计有序的 $k$ 元组）。

已知 $G(2,3)=14$，$G(4,3)=496$。

---

## 输入格式

一行两个整数 $n, k$（保证 $k$ 为奇数）。

---

## 输出格式

一个整数，表示 $G(n,k)$。

---

## 样例

### 输入

```
2 3
```

### 输出

```
14
```

### 输入

```
4 3
```

### 输出

```
496
```

---

## 数据范围

- $1 \le n \le 4$
- $1 \le k \le 5$，且 $k$ 为奇数。
