# 置换的幂的秩和（PE 902）

来源：改编自 Project Euler Problem 902。

## 原题意

π=τ⁻¹στ (σ=三角块循环移位, τ=模乘置换), P(m)=Σ_{k=1}^{m!}rank(π^k) mod 1e9+7。

## 题目

见 statement.md。参数与输入输出约定以 code/std.cpp 为准。

## 算法

参数化分支: 小 m 直接枚举各次幂, Lehmer 编码 O(n²) 求 rank, 枚举到回到单位置换 (即一个周期)。

## 验证

P(2)=4, P(3)=780, P(4)=38810300 (题面); PE 分支 P(100)=343557869 (官方, 全规模算法未实现)
