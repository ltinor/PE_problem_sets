# 置换的幂的秩和（PE 902）

来源：改编自 Project Euler Problem 902。

## 原题意

π = τ⁻¹στ（σ = 三角块循环移位，τ = 模乘置换），P(m) = Σ_{k=1}^{m!} rank(π^k) mod 1e9+7。
已知 P(2)=4、P(3)=780、P(4)=38810300，求 P(100)。

## 题目

给定 m（1 ≤ m ≤ 100），输出 P(m) mod 1e9+7；输入 `PE` 输出官方答案 343557869。

## 数据范围

- 1 ≤ m ≤ 100（n = m(m+1)/2 ≤ 5050）
- PE 答案: P(100) = 343557869

## 算法（code/std.cpp，全规模闭式，m=100 瞬时）

π 与 σ 共轭 ⟹ 循环长度恰为 1..m，ord(π) = lcm(1..m) 整除 m! ⟹ P = (m!/ord)·Σ_{k=1}^{ord} rank(π^k)（无余项）。

Lehmer 秩交换求和序后，S_i = Σ_{j>i} G(i,j) 逐对闭式：
- **异循环** (A 长 p, B 长 q)：k 的像只有 lcm(p,q) 个，受约束 u − v ≡ t_i − t_j (mod gcd(p,q))
  （gcd>1 时并非全空间！），G(i,j) = (ord/lcm)·D_AB[(t_i−t_j) mod g]，
  D_AB[σ] = #{s < lcm: xB[s mod q] < xA[(σ+s) mod p]}，O(n²) 总量；
- **同循环**：G(i,j) = (ord/p)·C[(t_j−t_i) mod p]，C[d] = #{s: x[(s+d) mod p] < x[s]}。

(ord/D) mod p 用 ord 的素数幂指数差计算；(m!/ord) mod p = (m!)·inv(ord)（素因子全 < p）。

## 验证

- P(1)=1、P(2)=4、P(3)=780、P(4)=38810300（题面锚点）全中；
- P(5) 与逐幂枚举暴力（code/brute.cpp，定义直译）一致（736065216）；
- P(100) = 343557869 = PE 官方答案。
