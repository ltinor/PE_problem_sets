# 平方子集

## 题目描述

对于正整数集 $\{a,a+1,a+2,\ldots,b\}$，记 $C(a,b)$ 为其非空子集中满足所有元素之积为完全平方数的子集的数目。

例如，$C(5,10)=3$，因为除了 $\{5,8,10\}$，$\{5,8,9,10\}$ 和 $\{9\}$ 中所有元素之积为完全平方数外，不存在其它 $\{5,6,7,8,9,10\}$ 的子集满足这一性质。

已知 $C(40,55)=15$，以及 $C(1000,1234) \bmod 1000000007 = 975523611$。

求 $C(1000000,1234567) \bmod 1000000007$。

## 输入格式

一行，字符串 `PE` 或 `verify`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案：3268573801。
若输入为 `verify`，验证 $C(5,10)=3$、$C(40,55)=15$、$C(1000,1234) \bmod 10^9+7 = 975523611$。

## 样例

### 输入
```
PE
```

### 输出
```
3268573801
```

## 数据范围

- 完整问题：$a=10^6$，$b=1234567$，$N=234568$，$|P| \approx 95000$
- 验证模式：$(5,10)$、$(40,55)$、$(1000,1234)$
- 模数：$1000000007$
