# 最后一问

## 题目描述

考虑所有从下面这个词组中选取字母并任意排列所能构成的单词：

> **thereisasyetinsufficientdataforameaningfulanswer**

将其中包括**不超过 15 个字母**的单词按照**字典序**排列，并且从 1 开始逐个编号。

记 $P(w)$ 是单词 $w$ 在列表中的位置。
记 $W(p)$ 是列表中位置 $p$ 上的单词。

$P(w)$ 和 $W(p)$ 互为反函数：$P(W(p)) = p$ 且 $W(P(w)) = w$。

已知：
- $W(10)$ = aaaaaacdee
- $P(\text{euler}) = 115246685191495243$

---

## 输入格式

一个由小写字母组成的单词 $w$（长度 $\le 15$）。

---

## 输出格式

一个整数，表示 $P(w)$（该单词在列表中的位置）。

---

## 样例

### 输入
```
aaaaaacdee
```

### 输出
```
10
```

---

## 数据范围

- 对于 30% 数据：单词长度 $\le 3$
- 对于 60% 数据：单词长度 $\le 8$
- 对于 100% 数据：单词长度 $\le 15$
