# 292 — 毕达哥拉斯多边形

来源：改编自 Project Euler Problem 292（缩数据版）

## 原题意

定义毕达哥拉斯多边形为满足以下条件的凸多边形：
- 至少三个顶点
- 不存在三个顶点共线
- 每个顶点坐标为整数
- 每条边长度为整数

记 P(n) 为周长 ≤ n 的不同毕达哥拉斯多边形个数（平移后相同视为同一个）。
已知：P(4)=1，P(30)=3655，P(60)=891045。
原题求 P(120)。

## 题目（缩数据）

输入一个正整数 N（1 ≤ N ≤ 60），输出 P(N)。

## 数据范围

- N ≥ 1
- N ≤ 60（原题固定 N=120，此处缩小参数）

## 改编思路

### 方向一：参数化周长上界
- 将原题固定的 N=120 改为输入参数 N
- 结论：✅ 采用，且数据上限缩小到 60

### 方向二：纯暴力枚举凸多边形
- 直接枚举所有整数坐标凸多边形不可行（状态空间爆炸）
- 结论：❌ 不采用

### 方向三：组合 DP + 生成函数
- 利用"每条边向量可分解为原始勾股向量 × 倍数"的结构做无界背包 DP
- 结论：✅ 采用（真正的算法，无硬编码）

## 算法

**核心化简**：每条边是一个整数向量 (dx,dy)，且 dx²+dy² 为完全平方数。
把该向量写成 k·(a,b)，其中 (a,b) 为原始（本原）勾股向量，即
gcd(a,b)=1 且 a²+b²=c²（c 为整数边长，包括坐标轴方向 (1,0),(0,1),(-1,0),(0,-1) 对应 c=1）。

一个凸多边形（平移意义下）与"每个原始方向 d 取重数 k_d ≥ 0"的赋值一一对应：
- 各方向边向量之和为零：Σ k_d·(a_d,b_d) = (0,0)（闭合成多边形）
- 使用 ≥3 个不同方向（否则退化成一条线段/两点）
- 按角度排序即得到唯一凸多边形，反之亦然

因此：
```
C(N) = Σ_{p=1..N} [x^0 y^0 z^p] ∏_d 1/(1 - x^{a_d} y^{b_d} z^{c_d})
```
用三维无界背包 DP 计算（方向 (a,b,c) 对应沿射线 (a,b,c) 的背包递推，
因为 c≥1，依赖图按周长 p 拓扑有序，一趟扫描即可）。

再减去退化的"两点线段"（互为反向的一对方向 {d,-d}，每条长度 c 贡献 ⌊N/(2c)⌋ 个）：
```
S(N) = 2·⌊N/2⌋ + Σ_{本原三元组 c≤N} 4·⌊N/(2c)⌋
P(N) = C(N) - S(N)
```

复杂度 O(D · N³)，其中 D 为本原方向数（≤60 时约 70 个），N=60 秒出结果。

算法（std.cpp）对验证点均精确命中：

| N | P(N) |
|---|------|
| 4 | 1 |
| 30 | 3655 |
| 60 | 891045 |
