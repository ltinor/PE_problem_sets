# 毕达哥拉斯多边形

## 题目描述

定义**毕达哥拉斯多边形**为满足以下条件的凸多边形：

- 至少有 3 个顶点
- 不存在 3 个顶点共线
- 每个顶点的坐标均为整数
- 每条边的长度均为整数

记 $P(n)$ 为周长不超过 $n$ 的不同的毕达哥拉斯多边形的个数。若一个多边形可以通过平移得到另一个，则认为它们是相同的。

例如：$P(4)=1$（唯一的毕达哥拉斯多边形是 $1 \times 1$ 的单位正方形）。

现在给定一个正整数 $n$，请计算 $P(n)$。

---

## 输入格式

一行一个正整数 $n$。

---

## 输出格式

一行一个整数，表示 $P(n)$。

---

## 样例

### 输入

```
4
```

### 输出

```
1
```

---

## 数据范围

- $1 \le n \le 60$
