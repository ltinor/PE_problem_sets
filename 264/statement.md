# 三角形中心

## 题目描述

考虑满足以下所有条件的三角形：

1. 三个顶点全部在**格点**（坐标为整数的点）上；
2. **外心**（外接圆圆心）在原点 $O(0, 0)$；
3. **垂心**（三条高的交点）在点 $H(H_x, 0)$，其中 $H_x$ 为给定的正奇数。

求所有周长 $\le P$ 的此类三角形的周长之和，四舍五入保留四位小数。

---

## 输入格式

一行，两个整数 $P$ 和 $H_x$，空格分隔。

---

## 输出格式

一行，一个实数，表示所有符合条件的三角形周长之和，四舍五入保留四位小数。

---

## 样例

### 输入
```
50 5
```

### 输出
```
291.0089
```

**解释**：周长 ≤50、外心在原点、垂心在 (5,0) 的三角形共 9 个，周长之和为 291.0089。

### 输入
```
200 5
```

### 输出
```
1563.0658
```

---

## 数据范围

- $1 \le P \le 10^5$
- $1 \le H_x \le 20$，$H_x$ 为奇数
