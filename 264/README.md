# 264 — Triangle Centers（三角形中心）

来源：改编自 Project Euler Problem 264

## 原题意

求所有顶点在格点、外心在原点 O(0,0)、垂心在 H(5,0) 且周长 ≤ 10⁵ 的三角形的周长之和（四位小数）。答案：2816417.0000。

## 题目

输入两个参数 $P$ 和 $H_x$：求所有顶点在格点、外心在原点、垂心在 $(H_x, 0)$ 且周长 ≤ P 的三角形周长之和（四位小数）。当 $H_x=5$, $P=10^5$ 时对应原题。

## 数据范围

- $1 \le P \le 10^5$
- $1 \le H_x \le 20$，$H_x$ 为奇数

## 算法

由外心在原点得三顶点共圆：$x_i^2+y_i^2=R^2$。由垂心坐标得顶点向量和：$A+B+C=(H_x,0)$。枚举所有可表示为两平方和的 $R^2$，在对应圆上枚举格点，然后在三元组中搜索满足向量和为 $(H_x, 0)$ 且非退化的组合，计算周长并累加。时间复杂度约为 $O(P \cdot \tau(R^2))$，其中 $\tau$ 为除数函数。

## 改编方向与取舍

### 改编方向
1. **参数化 P 和 H_x** → 可调周长上界和垂心位置（本题采用）
2. **参数化外心位置** → 外心不在原点，增加坐标平移
3. **输出所有三角形坐标** → 除周长外还输出顶点坐标
4. **推广到三维** → 四面体的外心和垂心条件

### 取舍理由
- 选择参数化 P 和 H_x：最自然的 OJ 参数化，H_x 必须为奇数才有整数解
- 外心固定在原点：简化计算，平移外心仅增加坐标偏移
- 限制 H_x ≤ 20：确保搜索空间可控（R ≤ P/3 ≈ 33333）
- 限制 P ≤ 10⁵：与 PE 原题范围一致
