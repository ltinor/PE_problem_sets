# 有三个自变量的函数的有理零点

## 题目描述

对于任意整数 n，考虑三个函数：

$$f_{1,n}(x,y,z)=x^{n+1}+y^{n+1}-z^{n+1}$$
$$f_{2,n}(x,y,z)=(xy+yz+zx)(x^{n-1}+y^{n-1}-z^{n-1})$$
$$f_{3,n}(x,y,z)=xyz(x^{n-2}+y^{n-2}-z^{n-2})$$

以及它们的组合：

$$f_n(x,y,z)=f_{1,n}(x,y,z)+f_{2,n}(x,y,z)-f_{3,n}(x,y,z)$$

考虑三元组 (x, y, z)，若 x、y 和 z 都可以表示为满足 0 < a < b ≤ K 的有理数 a/b，且（至少）存在一个整数 n 使得 f_n(x,y,z) = 0，则称其为 K 阶黄金三元组。

记 s(x,y,z) = x + y + z。

考虑所有 K 阶黄金三元组 (x,y,z) 所对应的 s(x,y,z)，记其中所有不同的取值之和为 t = u / v。

所有的 s(x,y,z) 以及 t 都表示为最简分数。求 u + v。

## 输入格式

一行一个整数 K（1 ≤ K ≤ 35）。

## 输出格式

一行一个整数，表示 u + v。

---

## 样例

### 输入
```
35
```

### 输出
```
285196020571078987
```

---

## 数据范围

- 1 ≤ K ≤ 35
- 此题计算量极大，需结合数学化简和程序枚举。

---

## 提示

f_n(x,y,z) = 0 可以化简为 (x + y - z)(x^n + y^n - z^n) = 0。

因此黄金三元组满足：
1. x + y = z，或
2. x^n + y^n = z^n

枚举所有可能的有理数 a/b（0 < a < b ≤ K），验证上述条件。注意去重和约分。
