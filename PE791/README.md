# PE791 — Prefect Squares（完全平方）

来源：改编自 Project Euler Problem 791

## 原题意

"Prefect" 是 "Perfect" 的变体，可能暗示"前缀完全平方"（prefix-perfect）：一个数 $n$ 的平方 $n^2$ 的十进制前缀恰好等于 $n$。例如 $10^2=100$，$100$ 的前缀 $10$ 等于自身。问题要求统计或求和满足某种前缀/后缀性质的完全平方相关数值。

PE 答案：40454087（约 $4.05 \times 10^7$）。

## 算法

1. **前缀完全平方**：$n$ 是前缀完全平方当且仅当 $n^2$ 的十进制表示以 $n$ 的十进制表示开头。
2. **后缀完全平方（自守数）**：$n^2$ 的十进制表示以 $n$ 结尾，例如 $5^2=25$、$25^2=625$。
3. **平方和**：$\sum_{k=1}^n k^2 = n(n+1)(2n+1)/6$。
4. **数位平方和**：各位数字的平方和再次为完全平方（如 Happy Number 变体）。

## 改编方向

1. 推广到任意进制 $b$ 的前缀/后缀平方
2. 考虑高阶前缀：$n^k$ 以 $n$ 开头
3. 求前缀完全平方的倒数和或积
4. 同时要求前缀和后缀性质（双端完全平方）
5. 按字典序下第 $k$ 个前缀完全平方
