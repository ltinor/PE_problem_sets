# （素数-k）阶乘和

## 题目描述

对于素数 p，定义 S(p) = ((p-1)! + (p-2)! + (p-3)! + (p-4)! + (p-5)!) mod p。

例如，p=7 时：
6! + 5! + 4! + 3! + 2! = 720 + 120 + 24 + 6 + 2 = 872，872 mod 7 = 4，故 S(7) = 4。

给定正整数 n，求所有满足 5 ≤ p < n 的素数 p 的 S(p) 之和。

---

## 输入格式

一个整数 n。

---

## 输出格式

一个整数，表示答案。

---

## 样例

### 输入
```
100
```

### 输出
```
480
```

---

## 数据范围

- 对于 30% 数据：n ≤ 1000
- 对于 60% 数据：n ≤ 10^6
- 对于 100% 数据：n ≤ 10^8
