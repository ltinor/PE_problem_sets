# 01矩阵计数

## 题目描述

对于 n×n 的 01 矩阵（元素仅为 0 或 1），可以进行以下四种变形：

1. 交换任意两行
2. 交换任意两列
3. 翻转一行中所有元素（1 变成 0，0 变成 1）
4. 翻转一列中所有元素

若矩阵 A 能够通过一系列上述变形变为矩阵 B，则称 A 和 B **等价**。

记 c(n) 为所有 n×n 01 矩阵中，两两互不等价的最大数目。

已知 c(3) = 3，c(5) = 39，c(8) = 656108。

求 c(20)，并将答案对 1,001,001,011 取模。

## 输入格式

一行，字符串 `PE` 或 `verify` 或 `compute`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案（对 MOD 取模后的值）。

若输入为 `verify`，输出 c(1) 到 c(5) 的计算验证结果。

若输入为 `compute`，计算并输出 c(8)。

## 样例

### 输入
```
PE
```

### 输出
```
6955777866634773
```

## 数据范围

- 完整问题：n = 20
- 验证模式：n ∈ {1, 2, 3, 4, 5}
- 计算模式：n = 8
