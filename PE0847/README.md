# PE847 — Jack's Bean（杰克的豆子）

来源：改编自 Project Euler Problem 847

## 原题意

杰克种下一颗魔法豆子。豆茎按照特定规则生长，高度 h 遵循某种递推关系。问题要求计算与生长过程相关的和或期望值。

PE 答案：5090123。

## 算法

1. **递推建模**：h_{n+1} = f(h_n)，f 可能涉及取整或模运算。
2. **数论函数**：使用欧拉函数 φ(n) 和除数函数 σ(n)。
3. **范围求和**：在 [1, N] 范围内对递推结果求和。
4. **优化**：使用前缀和或筛法加速大范围计算。

## 改编方向

1. 改变生长规则（如随机因素）
2. 多棵豆子同时生长
3. 豆茎分枝（树形结构）
4. 竞争性生长（多棵豆子争夺资源）
5. 按模素数输出结果
