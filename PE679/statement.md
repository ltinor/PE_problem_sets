# FREEFAREA

## 题目描述

记 $S$ 为包含四个字母的集合 $\{\texttt{'A'},\texttt{'E'},\texttt{'F'},\texttt{'R'}\}$。

对于 $n \ge 0$，记 $S^*(n)$ 为仅包含 $S$ 中的字母且长度为 $n$ 的字符串所组成的集合。

我们选择 $\texttt{FREE}$、$\texttt{FARE}$、$\texttt{AREA}$、$\texttt{REEF}$ 作为关键词。

记 $f(n)$ 为 $S^*(n)$ 中**恰好包含**四个关键词各**一次**的字符串数目。

在 $n=9$ 时首次出现满足要求的字符串，且唯一的拥有 9 个字母的此类字符串是 $\texttt{FREEFAREA}$。因此 $f(9)=1$。

已知 $f(15)=72863$。

求 $f(30)$。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 644997092988678。
- `verify`：验证小样例（含 $f(9)$ 到 $f(15)$ 的计算值）。
- `compute`：重新计算完整答案。

## 样例

### 输入
```
PE
```

### 输出
```
644997092988678
```

## 数据范围

- 完整问题：$n = 30$
- 字母表大小：4（A, E, F, R）
- 关键词数量：4（FREE, FARE, AREA, REEF）
- 验证范围：$n \le 15$ 可用暴力枚举或 DP 验证
