# 蚂蚁和种子

## 题目描述

一只蚂蚁在一个 $G \times G$ 的网格上随机行走。行走从网格中心（$(\lfloor G/2 \rfloor, \lfloor G/2 \rfloor)$）开始。每一步，蚂蚁等概率地移动到相邻的上下左右格子，不会离开网格。

初始时，网格最下一行的每个格子上都有一粒种子。当蚂蚁到达最下一行且有种子的格子时，如果它没有携带种子，就会拿起种子。蚂蚁会在之后第一次到达最上一行的空格子时放下种子。

求所有种子都被放到最上一行所需的期望步数。结果四舍五入保留 **6 位小数**。

---

## 输入格式

一行一个整数 $G$，表示网格大小。

---

## 输出格式

一行一个实数，表示期望步数，保留 6 位小数。

---

## 样例

### 输入
```
1
```

### 输出
```
0.000000
```

（$1 \times 1$ 网格：蚂蚁一开始在唯一格子上，既是顶行也是底行，种子立刻放下。）

### 输入
```
2
```

### 输出
```
5.500000
```

---

## 数据范围

- $1 \le G \le 5$
