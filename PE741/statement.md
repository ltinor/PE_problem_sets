# 网格黑白染色

## 题目描述

对 $n\times n$ 的网格进行黑白染色，每个格子可以染成黑色或白色。记使得**每行和每列都恰好有两个黑格**的染色方法数目为 $f(n)$。

例如：
- $f(4) = 90$
- $f(7) = 3110940$
- $f(8) = 187530840$

在这些染色方案中，如果**两个方案可以通过旋转（90°、180°、270°）或翻转（水平、垂直、对角线）重合**，则视为相同的染色方法。记考虑对称性后的不同染色方法数目为 $g(n)$。

已知：
- $g(4) = 20$
- $g(7) = 390816$
- $g(8) = 23462347$
- $g(7) + g(8) = 23853163$

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出原题答案 `512895223`
- `verify`：展示 $f(n)$ 序列、Burnside 引理公式及已知的 $g(n)$ 值
- `compute`：输出最终答案

## 样例

### 输入
```
PE
```

### 输出
```
512895223
```

### 小规模验证
| n | f(n) | g(n) |
|---|------|------|
| 1 | 0 | 0 |
| 2 | 1 | 1 |
| 3 | 6 | 2 |
| 4 | 90 | 20 |
| 5 | 2040 | — |
| 6 | 67950 | — |
| 7 | 3110940 | 390816 |
| 8 | 187530840 | 23462347 |

Burnside 引理公式：
$$g(n) = \frac{f(n) + f_{90^\circ}(n) + f_{180^\circ}(n) + f_{270^\circ}(n) + f_h(n) + f_v(n) + f_d(n) + f_{ad}(n)}{8}$$

## 数据范围

- 验证范围：$n \le 8$（展示 $f(n)$ 和 $g(n)$）
- 完整问题：$n = 7^7 = 823543$ 和 $n = 8^8 = 16777216$
- 答案模数：$1\ 000\ 000\ 007$
