# 加和计数

来源：改编自 Project Euler Problem 76

## 原题意

将 100 写成至少两个正整数的和，有多少种不同的方式（顺序无关）？答案为 190569291。

## 题目

多组测试数据。每组给定 N，求将 N 写成至少两个正整数的和的方式数。即整数划分数 p(N) 减去 1（减去 N = N 这一种方式）。

## 数据范围

- 测试组数 T（每组一个 N）
- 2 ≤ N ≤ 100
- 答案可能超过 2^63，需要使用大整数。

## 算法

整数划分 DP：dp[i][j] 表示将 i 划分为不超过 j 的正整数之和的方式数。
- dp[0][j] = 1
- dp[i][0] = 0 (i > 0)
- dp[i][j] = dp[i][j-1] + dp[i-j][j] (当 i ≥ j)

使用 __int128（128 位整数）存储结果。
