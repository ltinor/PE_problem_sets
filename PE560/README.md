# PE560 — 互反游戏 (Reciprocal Game)

来源：改编自 Project Euler Problem 560

## 原题意

两个玩家进行一个取石子游戏。初始有 n 个石子。每回合，当前玩家可以取走 1 到 ⌊剩余石子数/k⌋ 个石子。取走最后一个石子的玩家获胜。

令 P(k, n) = 1 若先手有必胜策略，否则为 0。
令 G(k, N) = Σ_{n=1}^{N} P(k, n)。

求 G(5, 10¹⁰) + G(7, 10¹⁰) + G(11, 10¹⁰) + G(13, 10¹⁰)。
（k 取前 4 个奇素数）

PE 答案：994345168。

## 题目

给定 k 和 N，求 G(k, N) — 在 1 ≤ n ≤ N 范围内先手必胜的初始石子数个数。

## 算法

- 这是带参数的减法游戏。状态转移：
  - n < k：必败（先手无法取石子）
  - n ≥ k：必胜当且仅当存在 x ∈ [1, ⌊n/k⌋] 使得 n−x 为必败态
- 必败态（冷位置）是稀疏的。分析规律：
  - 令 L_i 为第 i 个必败态
  - 所有 n ∈ (L_i, L_i + ⌊L_i/k⌋] 都是必胜态（可一步跳到 L_i）
  - L_{i+1} 是大于 L_i + ⌊L_i/k⌋ 的最小必败态
- 使用递推公式直接生成必败态序列，直到超过 N。
- 对于 N = 10¹⁰，必败态个数约为 O(log N) 级别，非常高效。
- 答案 = N − 必败态个数。

## 改编方向

1. **不同 k 值**：计算其他 k 值的 G(k, N)，研究 k 对结果的影响。
2. **多个 k 求和**：Σ_{k=p}^{q} G(k, N)。
3. **后手必胜**：改为后手必胜的计数。
4. **两人多堆游戏**：推广到 Nim 类型多堆游戏。
5. **限制取子范围**：取子数不限于 1 到 ⌊n/k⌋，改为其他函数 f(n)。
