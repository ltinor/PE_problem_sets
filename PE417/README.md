# PE417 - 倒数循环节 II

来源：改编自 Project Euler Problem 417

## 原题意

单位分数 1/n 的十进制循环节长度记为 L(n)（若分母仅含质因数 2 和/或 5 则为 0）。原题求 3 ≤ n ≤ 10^8 的 ∑L(n)，答案为 446572970925740。

## 题目

给定 N，求 3 ≤ n ≤ N 的 ∑L(n)。

## 算法

- 去除 n 中的因子 2 和 5
- 若剩余为 1，L(n)=0；否则 L(n) = 10 模剩余数的乘法阶
- 乘法阶通过 φ(m) 的因数测试求得
- 小 N 可用长除法模拟；大 N 需高效求乘法阶

## 改编方向

1. **改变进制**：在 b 进制下求循环节长度
2. **求最大循环节**：在给定范围内找最大 L(n) 的 n
3. **累加平方**：求 ∑L(n)²
4. **区间查询**：支持任意区间 [l,r] 的查询
