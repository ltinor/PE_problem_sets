# 多项式方程式解的整数部分（PE 438）

## 题目描述

对于整数 n 元组 $t = (a_1, \dots, a_n)$，考虑多项式方程

$$x^n + a_1 x^{n-1} + a_2 x^{n-2} + \dots + a_n = 0.$$

若它的 $n$ 个根全为实数，且从小到大排序后满足 $\lfloor x_i \rfloor = i$（对 $1 \le i \le n$），则称 $t$ 为**有效元组**。记 $S(t)$ 为 $t$ 中各整数绝对值之和。

给定 $n$，求所有有效元组的 $\sum S(t)$。

原题（PE438）即 $n = 7$，答案为 $204640961680759493$。

---

## 输入格式

第一行一个 token：

- 若为 `PE`，输出原题（$n=7$）官方答案；
- 否则为整数 $n$（$2 \le n \le 4$）。

---

## 输出格式

一行一个整数：所有有效元组的 $\sum S(t)$。

---

## 样例

### 输入

```
4
```

### 输出

```
2087
```

（与原题陈述一致：$n=4$ 时恰有 12 个有效元组，$\sum S(t) = 2087$。）

---

## 数据范围

- 若输入为 `PE`，输出 $204640961680759493$；
- 否则 $2 \le n \le 4$。

## 提示

- $n=2$：唯一有效元组为 $(-3, 2)$，即 $x^2-3x+2=(x-1)(x-2)$，$\sum S(t) = 5$。
- 判定可用整数系数的 Sturm 定理精确统计每个区间 $[i, i+1)$ 中的根数；系数范围由初等对称多项式在根箱 $[1,2]\times[2,3]\times\cdots\times[n,n+1]$ 顶点处的值界定（$e_k$ 为多重线性函数）。
