# 类肯普纳级数

来源：改编自 Project Euler Problem 368

## 原题意

调和级数中忽略分母含有 ≥3 个连续相同数字的项，求级数收敛值。PE 答案：253.6135092068。

## 题目

给定规则（忽略分母含特定模式的项），求修正调和级数的收敛值。

## 数据范围

求和到精度 10^-10。

## 算法

### 方向一：数位 DP + 级数加速

将分母按位数分段，用数位 DP 计算每段中"合法"分母的贡献。对每段用 Euler-Maclaurin 或积分近似加速。

### 方向二：生成函数 + 递推

定义 A_k 为 k 位合法分母的倒数和。通过递推关系从 A_{k-1} 推出 A_k，累加至收敛。

### 方向三：容斥 + 分组

总调和级数减去含违禁模式的分母。违禁模式（3 个连续相同数字）可用容斥原理分类。每组贡献用积分近似。

### 时间复杂度

O(D × 10^D) 其中 D 为考虑的位数（约 10 位足够）。
