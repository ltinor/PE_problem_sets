# 内心和外心

## 题目描述

对于一个边长为整数的三角形，设其内切圆半径为 $r$，外接圆半径为 $R$。

给定 $N$，求所有满足以下条件的三角形的周长之和：
- 三边 $a, b, c$ 均为正整数，且 $a \le b \le c \le N$
- 满足三角形不等式 $a + b > c$
- 内切圆半径 $r$ 为整数
- 外接圆半径 $R$ 为整数

## 输入格式

一个整数 $N$，或字符串 `PE`。

## 输出格式

一个整数，表示周长之和。

## 样例

### 输入
```
30
```

### 输出
```
168
```

（仅包含 (13,14,15) 等少数三角形）

## 数据范围

- 对于 30% 数据：$N \le 30$
- 对于 60% 数据：$N \le 100$
- 对于 100% 数据：$N \le 200$
