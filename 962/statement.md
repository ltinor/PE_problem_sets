# 角平分线与切线（二）

## 题目描述

给定一个各边长均为整数的三角形 $ABC$，且边长满足 $BC \le AC \le AB$。

记：
- $k$ 是 $\angle ACB$ 的角平分线；
- $m$ 是三角形 $ABC$ 外接圆在点 $C$ 处的切线；
- $n$ 是过点 $B$ 且平行于 $m$ 的直线；
- $E$ 是直线 $n$ 与角平分线 $k$ 的交点。

请你计算：周长 $a+b+c$ 不超过 $N$、且线段 $CE$ 的长度为**整数**的三角形 $ABC$ 的个数。

---

## 输入格式

一行一个整数 $N$。

---

## 输出格式

一行一个整数，表示满足条件的三角形个数。

---

## 样例

### 输入
```
20
```

### 输出
```
2
```

**说明**：周长不超过 $20$ 时，满足 $CE$ 为整数的三角形为 $(5,5,6)$（$CE=4$）与 $(5,5,8)$（$CE=3$）。

### 输入
```
100
```

### 输出
```
26
```

---

## 数据范围

- 对于 $30\%$ 的数据：$N \le 100$；
- 对于 $60\%$ 的数据：$N \le 500$；
- 对于 $100\%$ 的数据：$1 \le N \le 1000$。

---

## 提示

本题改编自 Project Euler Problem 962（原题要求周长不超过 $10^6$）。设边长 $a=BC$、$b=AC$、$c=AB$（$a\le b\le c$），由几何推导可得

$$CE^2=\dfrac{a^3\,(a+b-c)(a+b+c)}{b\,(a+b)^2}.$$

$CE$ 为整数当且仅当上式约分后分母为 $1$ 且分子为完全平方数。
