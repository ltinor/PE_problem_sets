# PE655 — 可除尽的回文数 (Divisible Palindromes)

来源：改编自 Project Euler Problem 655

## 原题意

统计所有小于 10³² 的回文数中，能被 10000019 整除的个数。

小例子：小于 10⁵ 的回文数中，有 9 个能被 109 整除（最小的三个是 545、5995 和 15151）。

PE 答案：2000008332。

## 算法

对于每个长度 L（1 到 32），回文数由其前半部分（ceil(L/2) 位）唯一确定。

回文数 P 被 M 整除等价于 Σ c_i × d_i ≡ 0 (mod M)，其中 c_i 是 10 的幂次的组合。

使用 meet-in-the-middle 方法：
1. 将半长 h = ceil(L/2) 位分成两组
2. 枚举第一组的所有可能取值，计算余数并存入哈希表
3. 枚举第二组的所有可能取值，在哈希表中查找互补余数

对于较大半长（h=16），使用均衡分组使得枚举量可接受。
最终将所有长度的结果求和。
