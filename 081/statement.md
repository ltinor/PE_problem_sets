# 路径和：两个方向

## 题目描述

给定一个 N×N 的矩阵，从左上角 (1,1) 走到右下角 (N,N)，每次只能向右或向下移动。求经过路径上所有数字之和的最小值。

---

## 输入格式

第一行一个整数 N，表示矩阵大小。
接下来 N 行，每行 N 个整数，表示矩阵元素。

---

## 输出格式

一行一个整数，表示最小路径和。

---

## 样例

### 输入
```
3
131 673 234
103 18 96
342 965 150
```

### 输出
```
580
```

---

## 数据范围

2 ≤ N ≤ 80，1 ≤ 矩阵元素 ≤ 9999
