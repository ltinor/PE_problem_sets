# 路径和：两个方向

来源：改编自 Project Euler Problem 81

## 原题意

在一个 80×80 的矩阵中，从左上角到右下角，每次只能向右或向下移动，求路径上数字之和的最小值。答案：427337。

## 题目

给定一个 N×N 的矩阵，从左上角 (1,1) 走到右下角 (N,N)，每次只能向右或向下移动。求经过路径上数字之和的最小值。

## 数据范围

N ≤ 80，矩阵元素为 ≤ 9999 的正整数。

## 算法

std: 二维 DP，dp[i][j] = a[i][j] + min(dp[i-1][j], dp[i][j-1])。时间复杂度 O(N²)。
brute: 同样使用二维 DP（与 std 相同算法），用于交叉验证。
