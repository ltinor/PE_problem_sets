# 122 — 高效幂运算

来源：改编自 Project Euler Problem 122

## 原题意

求 k=1..200 的 m(k) 之和，其中 m(k) 为计算 n^k 所需的最少乘法次数（即 k 的最短加法链长度）。答案：1582。

## 题目

输入 K，求 k=1..K 的 m(k) 之和。

## 数据范围

- 1 ≤ K ≤ 200

## 算法

使用 DFS 搜索最短加法链。从链 {1} 出发，每次从链中选两个元素（可相同）相加得到新元素，记录每个 k 首次被达到的深度。关键剪枝：当 `depth+1 > best[nxt]` 时跳过（更差路径），但允许相同深度的不同路径继续探索（`depth+1 == best[nxt]` 时仍需深入），因为不同路径可能导出更优的后续链。时间复杂度：对 K=200 可在毫秒内完成。

验证：m(15)=5（链 [1,2,3,6,12,15]），sum(1..200)=1582。

## 改编方向与取舍

### 改编方向
1. **参数化 K** → 输入 K 求 ∑m(k)（本题采用）
2. **单点查询** → 输入 k 求 m(k)
3. **大范围 K** → K ≤ 5000，需 BFS + 位掩码优化
4. **最小链输出** → 输出具体的最短加法链

### 取舍理由
- 选择参数化 K：K=200 包含原题
- DFS 搜索：K≤200 时搜索空间可控，无需复杂剪枝
- 允许同深度探索：确保找到全局最优解
