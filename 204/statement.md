# 广义汉明数

## 题目描述

若一个正整数的所有质因数均不超过 5，则被称为汉明数。前几个汉明数是 1, 2, 3, 4, 5, 6, 8, 9, 10, 12, 15。不超过 10⁸ 的汉明数有 1105 个。

若一个正整数的所有质因数均不超过 n，则被称为 n 型广义汉明数。因此原本的汉明数就是 5 型广义汉明数。

给定整数 n 和 m，求不超过 m 的 n 型广义汉明数的个数。

---

## 输入格式

一行两个整数 n m (2 ≤ n ≤ 100, 1 ≤ m ≤ 10¹²)，空格分隔。

---

## 输出格式

一行一个整数，表示不超过 m 的 n 型广义汉明数个数。

---

## 样例

### 输入

```
5 100000000
```

### 输出

```
1105
```

### 输入

```
100 1000000000
```

### 输出

```
2944730
```

---

## 数据范围

- 2 ≤ n ≤ 100
- 1 ≤ m ≤ 10¹²
