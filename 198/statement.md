# 两可数

## 题目描述

对于实数x，分母上限为d的最佳逼近，是一个最简分数形式的 rational 数 r/s (s ≤ d)，使得任何比 r/s 更接近 x 的有理数 p/q 满足 q > d。

如果对于实数x存在某个分母上限d使得它有两个最佳逼近，则称x为两可数。两可数必然是有理数。

给定分母上限 Q，求满足 0 < x < 1/100 且分母不超过 Q 的两可数个数。

---

## 输入格式

一行，一个整数 Q。

---

## 输出格式

一个整数，表示两可数的个数。

---

## 数据范围

- 1 ≤ Q ≤ 10^8
- PE 答案: Q=10^8 → 52374425
