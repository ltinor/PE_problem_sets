# 分解约数数字根之和

## 题目描述

一个合数有多种分解方式。例如 24 有 7 种不同的分解：

24 = 2×2×2×3, 2×3×4, 2×2×6, 4×6, 3×8, 2×12, 24

数字根（digital root）是将一个数的各位数字不断相加，直到得到一位数。例如 467 → 4+6+7=17 → 1+7=8。

数字根和（DRS）是分解中所有因子数字根之和。例如 24 = 2×12 → dr(2)+dr(12)=2+3=5。

记 mdrs(n) 为 n 的所有分解方式中 DRS 的最大值。例如 mdrs(24) = 11。

给定 N，求 ∑_{n=2}^{N} mdrs(n)。

---

## 输入格式

一行一个整数 N (2 ≤ N < 10^6)。

---

## 输出格式

一行一个整数，表示 ∑ mdrs(n)。

---

## 样例

### 输入

```
10
```

### 输出

```
（2..10 的 mdrs 之和）
```

---

## 数据范围

- 2 ≤ N < 10^6

---

## 提示

PE 原题 N=999999 时答案为 14489159。
