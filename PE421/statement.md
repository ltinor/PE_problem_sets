# n<sup>15</sup>+1的质因数

## 题目描述

对于正整数 n 和 m，定义 s(n, m) 为 n<sup>15</sup>+1 的所有不超过 m 的**不同**质因数之和。

例如：
- 2<sup>15</sup>+1 = 3×3×11×331，所以 s(2, 10) = 3，s(2, 1000) = 3+11+331 = 345。
- 10<sup>15</sup>+1 = 7×11×13×211×241×2161×9091，所以 s(10, 100) = 31，s(10, 1000) = 483。

给定 N 和 M，求 ∑<sub>n=1</sub><sup>N</sup> s(n, M)。

---

## 输入格式

一行两个整数 N M。

---

## 输出格式

一个整数，表示答案。

---

## 样例

### 输入
```
10 1000
```

### 输出
```
2100
```

---

## 数据范围

- 对于 30% 数据：N ≤ 10, M ≤ 100
- 对于 60% 数据：N ≤ 100, M ≤ 1000
- 对于 100% 数据：N ≤ 10<sup>11</sup>, M ≤ 10<sup>8</sup>
