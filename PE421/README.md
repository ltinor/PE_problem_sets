# PE421 - n^15+1的质因数

来源：改编自 Project Euler Problem 421

## 原题意

对于正整数 n,m，s(n,m) 为 n^15+1 不超过 m 的不同质因数之和。原题求 n≤10^11, m=10^8 时 ∑s(n,m)，答案为 2304215802083466198。

## 题目

给定 N, M，求 ∑_{n=1}^N s(n, M)。

## 算法

- n^15+1 = (n+1)(n^4-n^3+n^2-n+1)(n^10-n^5+1)
- 对于小范围，可分别分解三个因子
- 大范围需使用数论：素数 p 整除 n^15+1 当且仅当 x^15 ≡ -1 (mod p) 有解
- 通过筛选素数并计算解的个数来求和

## 改编方向

1. **不同指数**：改为 n^k+1 的质因数
2. **素因子个数**：统计不同质因数的个数而非求和
3. **最大质因子**：求所有 n^15+1 的最大质因子之和
