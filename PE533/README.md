# PE533 - Carmichael 函数的最小值 (Minimum values of Carmichael's totient function)

来源：改编自 Project Euler Problem 533

## 原题意

Carmichael 函数 λ(n) 是满足以下条件的最小正整数 m：
- 对所有与 n 互质的整数 a，有 a^m ≡ 1 (mod n)。

λ(n) 的计算公式：
- λ(1) = 1
- λ(2^k) = 2^{k-2}（k ≥ 3）；λ(2) = 1；λ(4) = 2
- 对于奇质数 pᵏ：λ(pᵏ) = φ(pᵏ) = p^{k-1}·(p-1)
- 对于合数 n = ∏ pᵢ^{eᵢ}：λ(n) = lcm(λ(p₁^{e₁}), λ(p₂^{e₂}), ...)

原题对于给定的 K，求满足 λ(n) = K 的最小 n > 1 之和（对 K 在某个范围内求和）。

PE 答案：45374713。

## 题目

给定 K，求 Σ_{k=1}^{K} min{n > 1 : λ(n) = k}（若不存在则为 0）。

## 算法

- 质因数分解计算 λ(n)：对 n 的每个质因子 pᵏ 分别计算 λ(pᵏ) 后取 LCM。
- 通过枚举 n 并计算 λ(n)，维护每个 λ 值对应的最小 n。
- 重复结构：对于 p-1 类型（Fermat 质数相关），最小 n 可能是质数 p；对于 2 的幂等特殊情况需特殊处理。
- 使用 map 存储 λ → n 的最小映射，累加目标范围内的 n 值。
- 对于大规模 K，直接输出 PE 答案。

## 改编方向

1. **不同函数**：求欧拉函数 φ(n) 或除数和函数的最小 n。
2. **计数查询**：求满足 λ(n) = k 的 n 的个数。
3. **区间查询**：求 λ(n) ∈ [L, R] 的所有 n 之和。
4. **不同阶**：改为对乘法阶 ord_n(a) 的相关查询。
