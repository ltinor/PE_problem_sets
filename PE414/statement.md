# 卡布列克常数

## 题目描述

6174 是著名的卡布列克常数。对一个 4 位数，将其数字降序排列和升序排列后相减，重复此过程最终会收敛到 6174（或 0，如果所有数字相同）。

对于 5 位数和进制 b = 6t+3 ≠ 9，可以证明存在一个卡布列克常数 C_b。定义 sb(i) 为：从数 i 出发（不足 5 位补前导零），经过卡布列克路径到达 C_b 所需的迭代次数（若 i = C_b 或 i 的 5 个数字全相同则为 0）。

定义 S(b) = Σ_{0<i<b^5} sb(i)。例如 S(15) = 5274369, S(111) = 400668930299。

给定一个进制 b（b = 6t+3 的形式），求 S(b)。

---

## 输入格式

一个整数 b，表示进制。

---

## 输出格式

一个整数，表示 S(b)。

---

## 样例

### 输入
```
15
```

### 输出
```
5274369
```

---

## 数据范围

- 对于 30% 数据：b ≤ 15
- 对于 60% 数据：b ≤ 21
- 对于 100% 数据：b ≤ 30
