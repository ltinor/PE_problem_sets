# PE414 - 卡布列克常数

来源：改编自 Project Euler Problem 414

## 原题意

对于 5 位数和进制 b = 6t+3 ≠ 9，存在唯一的卡布列克常数 C_b。S(b) 是所有 0 < i < b^5 经过卡布列克路径到达 C_b 的步数之和。原题求 Σ_{k=2..300} S(6k+3) 的最后 18 位，答案为 552506775824935461。

## 题目

给定进制 b，求 S(b)。

## 算法

- 卡布列克路径：数字降序排列的值减去升序排列的值
- 对于给定的进制 b，找到常数 C_b（从任意数出发迭代直到不动点）
- 遍历所有 b^5 个数（或所有 5 位数字的多重集），累计到 C_b 的步数
- 优化：利用多集合同构性，同一多集下的所有数路径相同，只需计算 C(b+4, 5) 个状态

## 改编方向

1. **改变位数**：求 k 位数（k=3, 4, 6）的卡布列克常数和 S(b)
2. **改变进制约束**：研究任意进制 b 的卡布列克行为，寻找常数存在的条件
3. **求最长路径**：对于给定的 b，求到达 C_b 所需的最大步数
4. **统计循环**：求陷入循环（而非到达常数）的数有多少个
