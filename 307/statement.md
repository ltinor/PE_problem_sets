# 芯片缺陷

## 题目描述

在一个工厂生产的 $n$ 块集成电路上随机分布有 $k$ 个缺陷（一块集成电路上可能有任意数量的缺陷，每个缺陷独立地等可能落到任意一块芯片上）。

记 $p(k, n)$ 为存在**至少一块**集成电路上面有**至少 $3$ 个**缺陷的概率。

例如，$p(3, 7) \approx 0.0204081633$。

现在给定 $k$ 和 $n$，请计算 $p(k, n)$ 并四舍五入保留 $10$ 位小数（格式 `0.abcdefghij`）。

---

## 输入格式

一行两个正整数 $k$ 和 $n$，用空格分隔。

---

## 输出格式

一行，格式为 `0.abcdefghij`，即保留 $10$ 位小数的概率值。

---

## 样例

### 输入

```
3 7
```

### 输出

```
0.0204081633
```

### 输入

```
20 100
```

### 输出

```
0.0008590669
```

---

## 数据范围

- $1 \le k \le 20000$
- $1 \le n \le 10^6$
