# 307 — 芯片缺陷

来源：改编自 Project Euler Problem 307

## 原题意

k 个缺陷随机分布在 n 块芯片上。求至少有一块芯片上有 ≥3 个缺陷的概率 p(k,n)。求 p(20000, 1000000)，保留 10 位小数。

原题答案：0.7311720251。

## 题目

输入两个正整数 k 和 n，求至少有一块芯片上有 ≥3 个缺陷的概率，保留 10 位小数。

## 数据范围

- 1 ≤ k ≤ 20000
- 1 ≤ n ≤ 10⁶
- k ≤ n（当 k > n 时概率接近 1）

## 改编思路

### 方向一：参数化 k, n
- 将原题固定的 (k, n) = (20000, 10⁶) 改为输入参数
- 结论：✅ 采用

### 方向二：输出精确分数
- 输出分子/分母形式
- 结论：❌ 数值太大

### 方向三：累计分布
- 求恰好有 m 个芯片有 ≥3 个缺陷的概率分布
- 结论：❌ 计算量大

## 算法

P(至少一块芯片有 ≥3 个缺陷) = 1 - P(所有芯片有 ≤2 个缺陷)。

P(所有 ≤2) = Σ_{b=0}^{⌊k/2⌋} C(n, j) * C(j, 2j-k) * k! / (2^{k-j} * n^k)，其中 j = k - b。

在 log 空间中计算每一项，避免数值溢出。使用 long double 保证 10 位小数精度。
