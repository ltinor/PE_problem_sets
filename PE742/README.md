# PE742 — Minimum area of a convex lattice polygon (格点凸多边形的最小面积)

来源：改编自 Project Euler Problem 742

## 原题意

**对称格点凸多边形**满足：
- 所有顶点坐标为整数
- 所有内角严格小于 $180^\circ$
- 同时具有水平对称性和竖直对称性

记 $A(N)$ 为所有 $N$ 个顶点的对称格点凸多边形的最小面积。

已知：
- $A(4) = 1$
- $A(8) = 7$
- $A(40) = 1039$
- $A(100) = 17473$

求 $A(1000)$。

PE 答案：18397727

## 算法

1. **对称性简化**：水平和竖直对称意味着只需要考虑第一象限的 $\lfloor N/4\rfloor$ 个顶点（加上可能的坐标轴交点）。多边形是中心对称的。

2. **Shoelace 公式**：利用对称性，面积 = $4 \times$ 第一象限下的面积（减去坐标轴上的重合部分）。

3. **最小化问题**：在 Q1 中寻找从 $(0, y_{\max})$ 到 $(x_{\max}, 0)$ 的凸格点路径，使得多边形面积最小。这等价于用最少的格点包裹一个尽可能"小"的椭圆。

4. **最优构造**：利用 Stern-Brocot 树/Farey 序列：最优顶点对应的分数 $x_i/y_i$ 形成特定序列。对于给定 $N$，最小面积对应连续分数的最佳逼近。

5. **复杂度**：$O(N)$（生成最优顶点序列）。

## 改编方向

1. 参数化 $N$（不同顶点数）
2. 仅要求水平对称（或仅竖直对称）
3. 要求严格凸（不允许相邻顶点共线）
4. 改为最大化面积
5. 考虑三维格点多面体
