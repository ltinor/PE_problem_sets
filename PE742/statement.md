# 格点凸多边形的最小面积

## 题目描述

**对称格点凸多边形**是指满足以下三个条件的多边形：

1. 所有顶点的坐标均为整数
2. 所有内角严格小于 $180^\circ$（严格凸）
3. 同时关于水平轴和竖直轴对称

记 $A(N)$ 为：在具有恰好 $N$ 个顶点的对称格点凸多边形中，面积的最小值。

已知：
- $A(4) = 1$（边长为 1 的正方形）
- $A(8) = 7$
- $A(40) = 1039$
- $A(100) = 17473$

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出原题答案 `18397727`
- `verify`：展示已知的 $A(N)$ 值及几何解释
- `compute`：输出最终答案

## 样例

### 输入
```
PE
```

### 输出
```
18397727
```

### 已知数据
| N | A(N) | 说明 |
|---|------|------|
| 4 | 1 | 边长为 1 的正方形 |
| 8 | 7 | 对称八边形 |
| 40 | 1039 | — |
| 100 | 17473 | — |
| 1000 | 18397727 | 目标答案 |

## 数据范围

- 验证范围：$N \in \{4, 8, 40, 100\}$
- 完整问题：$N = 1000$
- 所有坐标和面积均为整数
