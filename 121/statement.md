# 碟子游戏奖金

## 题目描述

一个袋子里最初有 1 个红色碟子和 1 个蓝色碟子。在一场游戏中，每一轮玩家从袋中随机抽取一个碟子，记录颜色后放回，然后往袋中加入 1 个红色碟子，再进行下一轮。

玩家需要支付 £1 来参加游戏。如果游戏结束时，玩家抽到的蓝色碟子数多于红色碟子数，则获胜并获得奖金。奖金必须是整数，且已包含玩家支付的 £1。

给定游戏回合数 N，求庄家应设定的最高奖金（即 `floor(1/P)`，其中 P 为玩家获胜的确切概率）。

---

## 输入格式

一行一个整数 N，表示游戏回合数。

---

## 输出格式

一行一个整数，表示最高奖金。

---

## 样例

### 输入
```
4
```

### 输出
```
10
```

**解释**：4 轮游戏获胜概率为 11/120，最高奖金 = floor(120/11) = 10。

---

## 数据范围

- 1 ≤ N ≤ 15
