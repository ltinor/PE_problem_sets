# PE331 - 十字翻转游戏 (Cross Flips)

来源：改编自 Project Euler Problem 331
PE 答案：4671782350

## 原题意

N×N 棋盘，每个格子有一个双面碟子（黑/白）。每轮选择一个碟子，翻转同行和同列的所有碟子（共 2N−1 个）。初始配置 C(N)：碟子在 (x,y)，若 N−1 ≤ √(x²+y²) < N 则为黑色。求从 C(N) 开始的最少翻转次数 T(N)，若无法完成则 T(N)=0。

求 Σ_{i=3}^{31} T(2^i−1)。

## 题目（改编）

给定 N（≤ 20），求 T(N)。

## 算法

- **GF(2) 线性代数**：翻转操作的效果可分解为 R[r] ⊕ C[c]（行的奇偶性 ⊕ 列的奇偶性）
- 检查初始配置是否满足 2×2 子矩阵 XOR 条件（可解性）
- 若可解，在两种行/列奇偶性赋值中取最小的操作次数
- 最少操作次数 = min(行 1 的个数)（需满足行列 1 的个数相等）

## 复杂度

- 时间：O(N²) 构建矩阵 + O(N⁴) 验证可解性（可优化到 O(N²)）
- 空间：O(N²)

## 改编方向

1. **一般初始配置**：给定任意初始配置矩阵，求最小翻转次数
2. **不同形状的翻转**：翻转十字形、L 形等
3. **模 k 翻转**：每次翻转改变颜色模 k 而非 GF(2)
