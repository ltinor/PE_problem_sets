# PE515 - 不和谐数

来源：改编自 Project Euler Problem 515

## 原题意

记 d(p, n, 0) 为 n 在模素数 p 下的乘法逆元。
d(p, n, k) = Σ_{i=1}^n d(p, i, k-1)，k ≥ 1。
D(a, b, k) = Σ_{a ≤ p < a+b} (d(p, p-1, k) mod p)，p 为素数。
已知 D(10³, 10², 10²) = 8334，D(10⁶, 10³, 10³) = 38162302。
求 D(10⁹, 10⁵, 10⁵)。

PE 答案：448552909。

## 题目

给定 a, b, k，计算 D(a, b, k)。

## 算法

- 数学推导：d(p, p-1, k) ≡ (k-1)^{-1} mod p（k ≥ 2）。
- k = 1 时结果为 0（p > 3）。
- 使用分段筛生成 [a, a+b) 内所有素数。
- 对每个素数 p，用扩展欧几里得算法求 (k-1) 在模 p 下的逆元并求和。

## 改编方向

1. **改变底函数**：用其他数论函数替代逆元。
2. **不同求和上界**：d(p, m, k) 其中 m ≠ p-1。
3. **合数模**：模不是素数的情形。
4. **多轮递推**：用矩阵快速幂加速多层求和。
