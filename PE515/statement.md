# 不和谐数

## 题目描述

对于素数 p 和正整数 n，定义 d(p, n, 0) 为 n 在模 p 下的乘法逆元，即满足 n × d(p, n, 0) ≡ 1 (mod p) 的唯一整数（1 ≤ d(p, n, 0) < p）。

对于 k ≥ 1，递归定义：
d(p, n, k) = Σ_{i=1}^n d(p, i, k-1) mod p。

定义 D(a, b, k) = Σ (d(p, p-1, k) mod p)，其中 p 取遍所有满足 a ≤ p < a+b 的素数。

给定 a, b, k，求 D(a, b, k)。

## 输入格式

一行，三个整数 a, b, k（以空格分隔），或字符串 `PE`。

## 输出格式

一个整数，表示 D(a, b, k)。

## 样例

### 输入
```
101 1 10
```

### 输出
```
45
```

### 输入
```
1000 100 100
```

### 输出
```
8334
```

### 输入
```
1000000 1000 1000
```

### 输出
```
38162302
```

## 数据范围

- 对于 30% 数据：a ≤ 10⁴, b ≤ 100, k ≤ 100
- 对于 60% 数据：a ≤ 10⁶, b ≤ 10³, k ≤ 10³
- 对于 100% 数据：a ≤ 10⁹, b ≤ 10⁵, k ≤ 10⁵
