# 无同树

## 题目描述

一棵树，如果不存在连接两个度数相同顶点的边，就称为一棵**无同树**（peerless tree）。

记 $P(n)$ 为包含 $n$ 个无标记顶点的无同树的数量（两棵同构的树视为同一棵）。

已知 $P(7) = 6$，定义 $\displaystyle S(N) = \sum_{n=3}^{N} P(n)$，已知 $S(10) = 74$。

给定整数 $N$，请计算 $S(N)$。

---

## 输入格式

一行一个整数 $N$。

---

## 输出格式

一行一个整数，表示 $S(N)$ 的值。

---

## 样例

### 输入

```
10
```

### 输出

```
74
```

---

## 数据范围

$3 \le N \le 15$。
