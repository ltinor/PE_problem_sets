# 收缩函数

## 题目描述

对于整数 n > 1，定义函数族 f_{n,a,b}(x) ≡ ax+b (mod n)，其中 a, b, x 是整数且满足 0 < a < n，0 ≤ b < n，0 ≤ x < n。

我们称 f_{n,a,b} 是一个**收缩函数**（Retraction），当且仅当对于所有 0 ≤ x < n 均有：
f_{n,a,b}(f_{n,a,b}(x)) ≡ f_{n,a,b}(x) (mod n)

定义 R(n) 为对于给定的 n，收缩函数的总数。

例如：
- R(2) = 1（仅有 a=1, b=0：f(x)=x，f(f(x))=f(x)）
- R(6) = 6

已知：对于 c = C(100000, k)（1 ≤ k ≤ 99999），有 ΣR(c) ≡ 628701600 (mod 1000000007)。

给定 n，求 R(n)。

---

## 输入格式

一个整数 n (2 ≤ n ≤ 10^12)。

---

## 输出格式

一个整数，表示 R(n)。

---

## 样例

### 输入
```
6
```

### 输出
```
6
```

---

## 数据范围

- 对于 30% 数据：n ≤ 100
- 对于 60% 数据：n ≤ 10^5
- 对于 100% 数据：n ≤ 10^12
