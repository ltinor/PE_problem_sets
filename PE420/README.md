# PE420 - 2x2 正整数矩阵

来源：改编自 Project Euler Problem 420

## 原题意

正整数矩阵：所有元素为正整数的矩阵。F(N) 统计迹 < N 且能表示为两个不同正整数矩阵平方的 2×2 正整数矩阵数目。原题求 F(10^7)，答案为 145159332。

## 题目

给定 N，求 F(N)。

## 算法

- 对 2×2 矩阵 A = [[a,b],[c,d]]，A² = [[a²+bc, b(a+d)], [c(a+d), d²+bc]]
- 迹 = a²+d²+2bc
- 枚举所有满足迹 < N 的正整数矩阵 A
- 计算 A² 并按平方结果分组
- 统计出现至少 2 次的平方矩阵数目
- 小 N（≤1000）可枚举；大 N 需数学分析

## 改编方向

1. **3×3 矩阵**：扩展到 3×3 正整数矩阵
2. **k 种表示**：统计至少 k 种不同平方表示
3. **逆问题**：统计恰有 2 种平方根的正整数矩阵
4. **对称约束**：限定矩阵为对称矩阵
