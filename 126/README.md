# 126 — Cuboid Layers

来源：改编自 Project Euler Problem 126

## 原题意

求使得 C(n)=1000 的最小 n。C(n) 表示在某一层中恰好需要 n 个立方体的长方体数目。

原题答案：18522。

## 题目

参数化 K：输入 K (1 ≤ K ≤ 1000)，求使得 C(n)=K 的最小 n。

## 数据范围

- K ≤ 1000
- 保证答案在合理范围内

## 算法

枚举长宽高 a≤b≤c 和层数 k≥1。第 k 层需要的立方体数公式：
L(a,b,c,k) = 2(ab+bc+ca) + 4(k-1)(a+b+c) + 4(k-1)(k-2)

枚举 a,b,c (上限约 70)，k 递增直到超过 MAX_VAL=50000。用 map 计数每种立方体数出现的次数，然后找次数等于 K 的最小立方体数。

## 改编方向

1. **参数化 K**：将原题固定 K=1000 改为输入参数，保持核心算法不变。
2. **小范围版本**：K ≤ 20 可用于小数据对拍。
3. **固定答案验证**：K=1000 作为测试点，验证输出 n=18522。
