# 投篮概率

## 题目描述

在距离 x 处投篮，得分的概率为 1 - x/q，其中 q > 50 是一个实数常数。

在距离 x = 1, 2, ..., N 处各投篮一次，恰好命中 S 次的精确概率为 p。

给定 N, S, p，求满足条件的 q，结果保留 10 位小数。

---

## 输入格式

一行三个整数/浮点数：N, S, p。

---

## 输出格式

一个浮点数，保留 10 位小数，表示 q 的值。

---

## 样例

### 输入
```
50 20 0.02
```

### 输出
```
52.6494571953
```

---

## 数据范围

- 1 ≤ N ≤ 50
- 0 ≤ S ≤ N
- 0 < p < 1
- PE 答案: N=50, S=20, p=0.02 → 52.6494571953
