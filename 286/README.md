# Scoring Probability

来源：改编自 Project Euler Problem 286

## 原题意

投篮距离 x 得分的概率为 1-x/q（q>50）。距离 1..50 各投一次，恰好得 20 分的概率恰好为 2%。求 q（10 位小数）。PE 答案：52.6494571953。

## 题目

给定 N 个距离、目标得分 S、目标概率 p，求满足条件的 q（10 位小数）。

## 数据范围

- 1 ≤ N ≤ 50, 0 ≤ S ≤ N, 0 < p < 1
- PE 答案: N=50, S=20, p=0.02 → 52.6494571953

## 改编思路

### 方向一：参数化 N, S, p
将固定的 (50, 20, 0.02) 改为可变输入。✅ 采用

### 方向二：求概率而非 q
给定 q 求恰好 S 分的概率。方向相反，失去求根趣味。❌ 不采用

### 方向三：多组查询
T 组测试，每组不同参数。增加代码复用性。❌ 不采用（本题规模小）

## 算法

二分搜索 q，每次用 DP 计算恰好 S 次成功的概率。DP[i][j] = 前 i 次投篮恰好 j 次命中的概率。
