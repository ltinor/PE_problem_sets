# PE585 — 嵌套平方根 (Nested square roots)

来源：改编自 Project Euler Problem 585

## 原题意

考虑形如 √(x + √y + √z) 的嵌套平方根，其中 x, y, z 为正整数，且 y 和 z 不是完全平方数。如果该表达式可以化简为有限个整数平方根的和或差（即解套），则称其可解套。

记 F(n) 为满足 x ≤ n 的可解套表达式的不同值的数目。值相同的表达式只计一次。

已知：
- F(10) = 17
- F(15) = 46
- F(20) = 86
- F(30) = 213
- F(100) = 2918
- F(5000) = 11134074

求 F(5000000)。

PE 答案：177144240686192069。

## 算法

解套条件：(√a + √b + √c)² = a+b+c + 2(√(ab) + √(ac) + √(bc))。

因此 √(x + √y + √z) = √a + √b + √c（或带正负号的类似形式）当且仅当：
- x = a + b + c
- {2√(ab), 2√(ac), 2√(bc)} 可以划分为 {√y, √z, 剩余项}

换言之，需要 y 和 z 的平方根可以表示为 ab, ac, bc 的平方根的两倍（以某种配对方式）。

F(n) 等价于：计数满足 a+b+c ≤ n 的正整数三元组 (a,b,c) 所产生的不同值 √a+√b+√c 的个数。由于 √a+√b+√c 的值完全由 (a,b,c) 的无平方因子部分决定，问题转化为计数不同的无平方因子三元组。

可以利用数论方法（莫比乌斯函数、无平方因子数的分布）来高效计算大规模 F(n)。

## 改编方向

1. 研究更多层嵌套（如 √(x + √(y + √z))）的解套条件。
2. 分析 F(n) 的渐近增长率。
3. 限制 y 和 z 的范围（如 y,z ≤ m），研究解套表达式的分布。
4. 研究带负号的情况（√a - √b + √c 等形式）。
