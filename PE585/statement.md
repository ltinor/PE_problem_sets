# 嵌套平方根

## 题目描述

考虑形如 √(x + √y + √z) 的嵌套平方根，其中 x, y, z 为正整数，且 y 和 z 不是完全平方数。

若该表达式可以化简为有限个整数平方根的和或差，即：
$$\sqrt{x+\sqrt{y}+\sqrt{z}} = \sum_{i=1}^k s_i\sqrt{a_i}$$
其中 k, a_i 为正整数，s_i = ±1，则称该表达式可解套。

值相同的嵌套平方根视为同一个表达式。例如：
√(7+√3+√27)、√(7+√12+√12) 和 √(7+√27+√3) 都可以解套为 2+√3，因此只算一次。

记 F(n) 为满足 x ≤ n 的可解套表达式的不同值的数目。

已知：
- F(10) = 17
- F(15) = 46
- F(20) = 86
- F(30) = 213
- F(100) = 2918
- F(5000) = 11134074

给定 n，求 F(n)。

## 输入格式

一行，一个整数 n（或字符串 `PE`，或 `test`）。

## 输出格式

一个整数，表示 F(n)。

若输入为 `PE`，输出 PE 原题的答案：F(5000000)。
若输入为 `test`，输出所有已知测试值。

## 样例

### 输入
```
10
```

### 输出
```
17
```

### 输入
```
100
```

### 输出
```
2918
```

### 输入
```
PE
```

### 输出
```
177144240686192069
```

## 数据范围

- 对于 30% 数据：n ≤ 100
- 对于 60% 数据：n ≤ 5000
- 对于 100% 数据：n ≤ 5×10⁶ 或输入为 PE
