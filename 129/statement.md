# 循环单位数整除性

## 题目描述

只包含数字 1 的数称为循环单位数。定义 R(k) 为长度为 k 的循环单位数（例如 R(6)=111111）。

对于整数 n（满足 gcd(n,10)=1），定义 A(n) 为最小的 k 使得 R(k) 能被 n 整除。

给定整数 T，求满足 A(n) > T 的最小 n（gcd(n,10)=1）。

---

## 输入格式

一行一个整数 T (1 ≤ T ≤ 10⁶)。

---

## 输出格式

一行一个整数 n，表示满足 A(n) > T 的最小 n。

---

## 样例

### 输入

```
10
```

### 输出

```
17
```

---

## 数据范围

- 1 ≤ T ≤ 1,000,000
