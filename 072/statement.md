# 分数计数

## 题目描述

考虑形如 n/d 的分数，其中 n 和 d 均为正整数。如果 n<d 且 gcd(n,d)=1，则称该分数为最简真分数。

给定 N，求所有分母 d≤N 的最简真分数的总数。

例如 d≤8 时，有如下 21 个最简真分数：
1/8, 1/7, 1/6, 1/5, 1/4, 2/7, 1/3, 3/8, 2/5, 3/7, 1/2, 4/7, 3/5, 5/8, 2/3, 5/7, 3/4, 4/5, 5/6, 6/7, 7/8

---

## 输入格式

第一行一个整数 T，表示测试数据组数。
接下来 T 行，每行一个整数 N。

---

## 输出格式

对于每组数据，输出一行一个整数，表示答案。

---

## 样例

### 输入
```
1
8
```

### 输出
```
21
```

---

## 数据范围

- 1 ≤ T ≤ 10
- 2 ≤ N ≤ 10^6
