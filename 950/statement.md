# 海盗宝藏

## 题目描述

`n` 名海盗分 `C` 枚完全相同的不可分割金币，每人嗜血度均为 `p = 1/√m`。

分配流程：

1. 资历最深的海盗提出一个分配方案；
2. 所有海盗（含提案者）投票；
3. 若至少一半海盗同意，方案生效；
4. 否则提案者走跳板，由资历次深者重新提案。

海盗的幸福度：若未存活为 `-∞`；存活则为 `c + p·w`，其中 `c` 是所得金币数，
`w` 是全程走跳板总人数。海盗贪婪（最大化幸福度）、无情、完全理性。

设 `c(n,C,p)` 为最终幸存者中资历最深者的金币数，`w(n,C,p)` 为走跳板总人数。
求 `T(N,C,p) = Σ_{n=1..N} ( c(n,C,p) + w(n,C,p) )`。

---

## 输入格式

一行三个整数 `N C m`，保证 `m` 不是完全平方数（使 `p = 1/√m` 为无理数）。

---

## 输出格式

一个整数 `T(N,C,p)`。

---

## 样例

### 输入

```
30 3 3
```

### 输出

```
190
```

---

## 数据范围

- 小：`N ≤ 60`，`C ≤ 30`，`m ≤ 300`
- 中：`N ≤ 2000`，`C ≤ 200`，`m ≤ 5000`
- 大：`N ≤ 100000`，`C ≤ 1000`，`m ≤ 10^6`
