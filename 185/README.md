# 数字头脑

来源：改编自 Project Euler Problem 185

## 原题意

给定 22 组猜测及其正确位数，求唯一的 16 位秘密序列。答案：4640261571849533。

## 题目

固定答案题。程序已内置 22 组猜测约束，输出唯一的 16 位秘密序列。

## 算法

约束满足 + 回溯搜索：
- 使用 22 组猜测作为约束条件
- 每步选择约束最紧的位置（可能取值最少的）
- 使用一致性检查剪枝：对于每个猜测，已匹配数 ≤ 正确数 ≤ 已匹配数 + 未确定数

## 改编方向

1. **固定答案**：原题已固定 22 组猜测，直接输出 PE 答案。
2. **搜索算法**：std 使用智能回溯（MRV 启发式），brute 使用简单回溯。
3. **验证**：两个独立实现输出必须一致。
