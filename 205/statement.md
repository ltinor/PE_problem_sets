# 骰子游戏

## 题目描述

彼得有 a 个 b 面骰子，每个骰子的面上分别标有 1, 2, ..., b。
科林有 c 个 d 面骰子，每个骰子的面上分别标有 1, 2, ..., d。

两人分别掷出他们的所有骰子，比较点数和：点数和更大者获胜。如果点数和相同，双方打成平手。

求彼得获胜的概率。答案四舍五入保留七位小数，格式为 0.abcdefg。

---

## 输入格式

一行四个整数 a b c d (1 ≤ a,c ≤ 10, 2 ≤ b,d ≤ 20)，空格分隔。

---

## 输出格式

一行一个浮点数，保留 7 位小数，表示彼得获胜的概率。

---

## 样例

### 输入

```
9 4 6 6
```

### 输出

```
0.5731441
```

### 输入

```
1 6 1 6
```

### 输出

```
0.4166667
```

---

## 数据范围

- 1 ≤ a, c ≤ 10
- 2 ≤ b, d ≤ 20
