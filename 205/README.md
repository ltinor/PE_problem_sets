# 205 — Dice Game

来源：改编自 Project Euler Problem 205

## 原题意

彼得有 9 个四面骰子（1-4），科林有 6 个六面骰子（1-6）。求彼得获胜的概率，保留 7 位小数。原题答案：0.5731441。

## 题目

参数化骰子配置：输入 a, b, c, d，分别表示彼得有 a 个 b 面骰子，科林有 c 个 d 面骰子。求彼得获胜概率。

## 数据范围

- a, c ≤ 10, b, d ≤ 20

## 算法

**std**: DP 计算两个玩家各自点数和分布。dp[s] = 掷出和为 s 的方法数。然后用前缀和计算彼得大于科林的概率。

**brute**: DFS 枚举所有骰子结果组合。适用于小数据（总组合数 ≤ 10⁶）。

## 改编方向

1. **参数化骰子配置**：将原题固定 9d4 vs 6d6 改为四参数输入。
2. **限制数据规模**：a, c ≤ 10; b, d ≤ 20，DP 可 O(a²·b + c²·d)。
3. **精确概率**：使用 64 位整数计数再转浮点，保证 7 位精度。
