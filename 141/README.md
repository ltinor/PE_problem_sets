# 累进平方数 (Progressive Perfect Squares)

来源：改编自 Project Euler Problem 141

## 原题意

正整数 n 除以 d 的商和余数分别是 q 和 r，且 d, q, r 恰好是某个等比数列中的连续三项（顺序任意）。称这样的 n 为"累进数"。求所有小于一万亿（10^12）的累进平方数（既是累进数又是完全平方数）之和。

原题答案：878454337159

## 题目

给定 M（≤10^12），求所有小于 M 的累进平方数之和。

## 数据范围

- 1 ≤ M ≤ 10^12
- 输入单个整数 M

## 算法

### 方法1：直接枚举几何序列参数

设等比数列的三项为 t₁ = k·b², t₂ = k·ab, t₃ = k·a²（公比 a/b, gcd(a,b)=1, a>b）。

由于 r < d（余数小于除数），{d,q,r} 中只有以下分配可行：
- r = t₁, d = t₂, q = t₃（或 r=t₁, d=t₃, q=t₂）：n = k·b·(k·a³ + b)

计算 n = k·b·(k·a³ + b)，检查是否为完全平方数。使用 set 去重。

时间复杂度：O(a_max·Σ 1/√a) ≈ O(√M · √M^{1/3})，在 M=10^12 时可行。

### 方法2：参数化 (进阶)

由 n = m² = k·b·(k·a³ + b)，设 gcd(k,b) = g。可推导：
- k = f²·c², b = f²·d²
- c²·a³ + d² = e²（需为完全平方数）
- n = (f³·c·d·e)²

### 方法3：暴力验证（brute）

对较小的 M，直接枚举 a, b, k 三重循环，无需复杂优化。
