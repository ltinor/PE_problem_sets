# 谢尔宾斯基图的回路

## 题目描述

n 阶谢尔宾斯基图 S_n 的递归定义为：S_1 是一个等边三角形；将三个 S_n 摆在一起，使得任意两个 S_n 都共用一个角，就得到 S_{n+1}。

记 C(n) 为经过 S_n 中所有顶点恰好一次的回路的数目。已知：
- C(1) = C(2) = 1
- C(3) = 8
- C(5) = 71328803586048

给定 n 和模数 M，求 C(n) mod M。

---

## 输入格式

一行两个整数 n M。

---

## 输出格式

一行一个整数，表示 C(n) mod M。

---

## 样例

### 输入
```
3 1000
```

### 输出
```
8
```

---

## 数据范围

- $1 \\le n \\le 18$
- $2 \\le M \\le 10^9$
