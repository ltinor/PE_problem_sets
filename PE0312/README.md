# 谢尔宾斯基图的回路 (Cyclic Paths on Sierpiński Graphs)

来源：改编自 Project Euler Problem 312

## 原题意

n 阶谢尔宾斯基图 S_n 由三个 S_{n-1} 拼接而成。C(n) 为经过所有顶点的哈密顿回路数。已知 C(1)=C(2)=1, C(3)=8, C(5)=71328803586048。求 C(C(C(10000))) mod 13^8 = 324681947。

## 题目

输入 n 和 M，求 C(n) mod M。

## 数据范围

$1 \\le n \\le 18$, $2 \\le M \\le 10^9$。

## 算法

### 方向一：通项公式

C(n) = 2^(3^(n-2)) × 3^((3^(n-2)-3)/2) 对 n ≥ 3，C(1)=C(2)=1。

推导：设 C(n) = 2^a_n × 3^b_n。则 a_3=3, a_{n+1}=3a_n；b_3=0, b_{n+1}=3b_n+3。

### 方向二：快速幂取模

用二分幂计算 2^a mod M 和 3^b mod M，复杂度 O(log a + log b)。

### 时间复杂度

n=18 时 a=3^16≈4.3×10^7，取模 O(log a) ≈ 26 次乘法，极快。
