# PE866 — Tidying Up B（整理B）

来源：改编自 Project Euler Problem 866

## 原题意

"整理B"可能指的是对包含 A 和 B 的二进制串进行操作，将所有 B 移到一侧或整理成连续块。

可能的问题形式：
- 给定一个 A/B 串，求将所有 B 整理到一起的最小操作次数。
- 统计所有长度为 n 的 A/B 串的总整理成本。
- 计算期望整理成本。

## 算法

1. **滑动窗口**：找到包含最多 B 的长度为 total_B 的窗口，需要移动的 B 的数量 = total_B - 窗内 B 的数量。
2. **枚举**：对小规模 n 枚举所有 2^n 种串，计算整理成本。
3. **组合分析**：利用组合数学推导总成本的闭合公式。

## 改编方向

1. 推广到多字符（A, B, C, ...）的整理
2. 带权重的整理成本
3. 最优整理策略的动态规划
4. 双向整理（同时从两端整理）
