# PE788 — Dominating numbers（支配数）

来源：改编自 Project Euler Problem 788

## 原题意

定义一个正整数为"支配数"，当且仅当存在某个数字在该数的十进制表示中出现次数超过总位数的一半（严格多数）。例如 $11123$ 被数字 $1$ 支配（5 位中出现 3 次）。问题要求统计不超过 $N$ 的支配数个数或总和。

PE 答案：471745499（约 $4.72 \times 10^8$）。

## 算法

1. **暴力判定**：对每个数统计 0-9 各数字出现次数，判断是否有严格多数的数字。
2. **组合计数**：对 $D$ 位数，固定支配数字 $d$ 在至少 $\lfloor D/2 \rfloor + 1$ 个位置上，其余位置可任意填。
3. **前导零约束**：当支配数字为 0 时需特殊处理首位。
4. **前缀支配**：若定义"支配"为数字出现次数 $\ge$ 其他数字之和，则门槛为 $D/2$。

## 改编方向

1. 推广到任意进制 $b$
2. 要求支配数字同时是最高位（most significant digit）
3. 求支配数的平方和或 $k$ 次方和
4. 考虑"双支配"或"反支配"（任意数字都不占多数）
5. 按字典序排列支配数并求第 $k$ 个
