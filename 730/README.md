# Shifted Pythagorean Triples (移位勾股数)

来源：改编自 Project Euler Problem 730。

## 原题意

(p,q,r) 为 k-移位勾股三元组：p²+q²+k = r²，本原 (gcd=1)，1≤p≤q≤r，p+q+r≤n。
P_k(n) 为其数目，S(m,n) = Σ_{k=0}^m P_k(n)。S(10,10⁴)=10956，求 S(100,10⁸)。

## 题目

输入 "PE" 输出官方答案 1315965924；或输入 m, n 输出 S(m,n)（n ≤ 3×10⁵，m ≤ 10²）。

## 数据范围

- 检查值: P₀(10⁴)=703、P₂₀(10⁴)=1979、S(10,10⁴)=10956（原题给定）
- PE 答案: S(100,10⁸) = 1315965924

## 算法（code/std.cpp，(a,e,w) 参数化 + Möbius，n=10⁵ 约 0.3s）

换元 (p,q,r) = (a+w, a+e, a+w+e)（w=r−q≥1, e=r−p≥w, a=p+q−r 可为负）：
k = 2ew − a²，周长 = 3a+2w+2e，且 **gcd(p,q,r)=g ⟺ g | a,e,w**。
- S(m,n) = Σ_{g≥1} μ(g)·count_all(⌊m/g²⌋, ⌊n/g⌋)，g 到 n/4
  （**k=0 子族使求和延伸到 ∞**：g²·0 ≤ m 恒成立，g>√m 项非零，μ 筛累计）；
- count_all：主族 a ≥ 0（a ≤ 0.0858n 由周长二次型判别式给出）+ needle 族 a<0
  （c ≤ √m，极小）；枚举 (a,w) 后 e-窗口先经残差 j = (−a²) mod 2w ≤ m 预筛再精确计数；
- m=0（纯勾股）同样走 Möbius 路径。

## 验证

- S(10,10⁴) = 10956、P₀(10⁴) = 703、P₂₀(10⁴) = P₂₀−P₁₉ = 1979（原题锚点全中）✓
- S(10,1000) = 1101、S(0,1000) = 70 与逐元组暴力一致（n=200 亦全元组一致）✓
- S(100,10⁶) = 13159559 ≈ 官方 S(100,10⁸)/100（二次标度交叉印证）✓
