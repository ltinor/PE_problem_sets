# 形如 2n²-1 的素数

## 题目描述

考虑形如 t(n) = 2n² − 1 的数，其中 n > 1。前几个这样的数分别是 7, 17, 31, 49, 71, 97, 127 和 161。可见只有 49 = 7×7 和 161 = 7×23 不是素数。

对于 n ≤ 10000，一共有 2202 个 t(n) 是素数。

给定一个整数 N，求对于 n ≤ N，一共有多少个 t(n) 是素数。

## 输入格式

一行一个整数 N。

## 输出格式

一行一个整数，表示 n ≤ N 时 t(n) 为素数的个数。

---

## 样例

### 输入
```
10
```

### 输出
```
4
```

### 输入
```
10000
```

### 输出
```
2202
```

### 输入
```
50000000
```

### 输出
```
5437849
```

---

## 数据范围

- 1 ≤ N ≤ 10⁷
- 标准时限：2 秒

---

## 提示

t(n) = 2n² − 1 的素性判定不能直接使用朴素试除法。利用二次剩余性质：若素数 p | 2n²−1，则 n² ≡ (p+1)/2 (mod p)。可通过模筛法批量标记合数。PE 原题 N=5×10⁷ 时答案为 5437849。
