# PE559 — 排列矩阵 (Permuted Matrices)

来源：改编自 Project Euler Problem 559

## 原题意

令 P(r, n) 为满足以下条件的 r×n (0,1)-矩阵的数量：
- 对列的任意排列，所有行的和保持不变；
- 对行的任意排列，所有列的和保持不变。

换言之，所有行的和相等且所有列的和相等（即矩阵是「正则」的二元矩阵）。

求 Σ_{r=1}^{n} P(r, n)，其中 n = 10⁴，结果对 10⁹+7 取模。

PE 答案：684463067。

## 题目

给定 n，求 Σ_{r=1}^{n} P(r, n) mod (10⁹+7)。

## 算法

- P(r, n) 等价于：二元矩阵的等价类，在行置换和列置换下不变。
- 利用 Stirling 数展开公式：
  P(r, n) = Σ_{k=0}^{min(r,n)} S(r,k) · S(n,k) · k!
  其中 S(n,k) 为第二类 Stirling 数。
- 这个公式来源于：将行和列分别划分为 k 个等价类，然后匹配这些等价类。
- 计算 Stirling 数可使用容斥公式：
  S(n,k) = 1/k! · Σ_{i=0}^{k} (-1)^{k-i} · C(k,i) · iⁿ
- 对于 n = 10⁴，需要对每个 r 计算 O(min(r,n)·r) 项，总计 O(n³)。
  可以通过预计算多项式或使用卷积优化到 O(n² log n)。
- 模数 10⁹+7 是质数，可以用费马小定理求逆元。

## 改编方向

1. **更大 n**：计算 n = 10⁵ 或更大。
2. **三元矩阵**：推广到取值 {0,1,2} 的矩阵。
3. **部分和**：Σ_{r=a}^{b} P(r, n) 或 Σ_{n≤N} Σ_{r} P(r, n)。
4. **限制条件**：限制每行/每列恰好有 m 个 1。
5. **渐进行为**：研究 P(r, n) 在 r ≈ n/2 附近的分布。
