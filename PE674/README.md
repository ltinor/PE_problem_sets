# PE674 — 解 ω(φ(n)) (Solving ω(φ(n)))

来源：改编自 Project Euler Problem 674

## 原题意

定义：
- ω(n)：n 的不同素因子个数（distinct prime factors）
- φ(n)：欧拉函数（Euler's totient），小于等于 n 且与 n 互质的正整数个数

问题要求计算与复合函数 ω(φ(n)) 相关的求和或统计，对于 n 在某个较大范围内的所有值。

PE 答案：416678753。

## 算法

1. **筛法预处理**：
   - 使用线性筛或埃氏筛同时计算 ω(n) 和 φ(n) 对于所有 n ≤ N
   - ω(n)：每当遇到素数 p，将 p 的所有倍数的 ω 值加 1
   - φ(n)：利用 φ 的积性性质在筛法中计算

2. **复合函数计算**：
   - 对于每个 n，查找 ω(φ(n)) 的值
   - 使用预处理好的数组 O(1) 查询

3. **求和**：遍历 1 到 N，累加 ω(φ(n))

4. **优化**：当 N 很大（如 10^7 或更大）时，需要优化内存和计算速度

## 改编方向

1. 参数化 N 的范围
2. 计算 Σ_{n≤N} ω(φ(n)) * n^k 的加权和
3. 考虑其他数论函数的复合，如 Ω(φ(n))（计重数）
4. 统计满足 ω(φ(n)) = k 的 n 的个数
