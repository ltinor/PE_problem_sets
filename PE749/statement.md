# 近幂和

## 题目描述

"自幂数"（水仙花数）是指其各位数字的 $k$ 次幂之和等于该数本身的数：
$$n = \sum_{d \in \text{digits}(n)} d^k$$

"近幂和"数是幂和与自身相差很小的数：
$$|n - \sum_{d \in \text{digits}(n)} d^k| \le \delta$$

其中 $\delta$ 是一个小阈值。求某个范围内所有近幂和数的和。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 13459471903176422。
- `verify`：验证小范围的自幂数和近幂和数。
- `compute`：对不同 $k$ 和阈值搜索近幂和数。

## 样例

### 输入
```
PE
```

### 输出
```
13459471903176422
```

### 验证
```
verify
```

输出 $n \le 10^6$ 范围内的自幂数（如 153, 370, 371, 407, 1634, 8208, 9474 等）。

## 数据范围

- 验证范围：$n \le 10^6$
- 完整问题：$n$ 很大，答数约为 $1.35 \times 10^{16}$
- 搜索范围受限于 $d \cdot 9^k$ 与 $n$ 的位数关系
