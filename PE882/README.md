# PE882 — Removing the Joker（去掉鬼牌）

来源：改编自 Project Euler Problem 882

## 原题意

一副标准扑克牌有 52 张普通牌加一张鬼牌（Joker），共 53 张牌。鬼牌可以作为任意一张牌的替代（万能牌）。

问题涉及在抽牌过程中，计算与鬼牌相关的概率或期望值。具体场景可能包括：达到特定手牌所需抽牌数的期望、鬼牌被使用/移除后的概率变化等。

PE 答案：245143924

## 算法

1. **超几何分布扩展**：
   - 标准超几何分布描述不放回抽样中成功次数的概率
   - 加入鬼牌后，成功集合大小增加 1（鬼牌可替代任何需要的牌）

2. **马尔可夫链**：
   - 状态由（已抽牌数，已收集目标牌数，鬼牌状态）定义
   - 鬼牌状态：在牌堆中 / 已被抽出并使用 / 已从游戏中移除

3. **期望值计算**：
   - 利用优惠券收集问题（Coupon Collector）的变体
   - 考虑鬼牌作为"万能优惠券"的影响

4. **动态规划**：
   - dp[目标][鬼牌状态] = 期望额外抽牌数
