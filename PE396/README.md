# PE396 - 弱古德斯坦序列

来源：改编自 Project Euler Problem 396

## 原题意

弱古德斯坦序列：每次将数用 k 进制写出，解释为 k+1 进制再减 1。求 ΣG(n) for n=1..15。

## 题目

给定 N，求 Σ_{n=1}^{N-1} G(n)。Goodstein 定理保证序列总会终止。

## 算法

- 模拟进制转换过程
- 每个 n 最多迭代有限次
- 直接模拟即可

## 改编方向

1. **标准古德斯坦序列**：使用遗传进制表示（hereditary base representation）
2. **输出序列本身**：要求输出每个 gk 的值
3. **求最大 gk**：求序列中的最大值
4. **并行计算**：同时计算多个 n，求它们的交汇点
