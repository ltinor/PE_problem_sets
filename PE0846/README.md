# PE846 — Magic Bracelets（魔法手环）

来源：改编自 Project Euler Problem 846

## 原题意

手镯由至少三颗珠子组成一个环。每颗珠子的编号只能是 1、2 或形如 p^k 或 2p^k 的数（p 为奇素数）。

魔法手镯额外要求：
1. 所有珠子编号互不相同
2. 相邻珠子编号的乘积可表示为 x²+1

效力 = 珠子编号之和。F(N) = 所有由 ≤N 的珠子组成的魔法手镯的效力之和（旋转/翻折等价视为同一方案）。

给定 F(20)=258, F(100)=538768，求 F(10⁶)。

PE 答案：159410499132。

## 算法

1. **生成允许的珠子编号**：1、2 和所有形如 p^k 或 2p^k 的数（p 为奇素数）。
2. **构建图模型**：边 (a,b) 当且仅当 a×b = x²+1，其中 a,b 为允许的编号。
3. **寻找所有简单环**：在图中搜索所有长度 ≥3 的环，即为手镯。
4. **去重**：通过旋转和翻折等价类去重。
5. **求和**：对每个不同的手镯，累加其效力。

## 改编方向

1. 修改珠子编号的允许规则（如加入更多合数形式）
2. 改变相邻乘积的条件（如 x²+k）
3. 统计手镯的数量而非效力和
4. 限制手镯的最大长度
5. 考虑线性排列（项链而非手镯）的计数
