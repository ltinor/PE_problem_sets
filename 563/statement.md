# 焊接机器人

## 题目描述

机器人从单位正方形（1×1）开始焊接。每次可焊接 k（1 ≤ k ≤ 25）个相同矩形，沿长边或短边焊接，得到更大的矩形。

顾客要求最终产品满足：
- 面积为指定值 A
- 长边 ≤ 1.1 × 短边
- 若存在多种合格尺寸 (w,h)，全部生产

记 M(n) 为恰好有 n 种合格尺寸的最小面积。已知 M(3) = 889200。

给定 N，求 Σ_{n=2}^{N} M(n)。

---

## 输入格式

一行，一个整数 N。

---

## 输出格式

一行，一个整数，表示 Σ_{n=2}^{N} M(n)。

---

## 样例

### 输入
```
3
```

### 输出
```
889200
```

---

## 数据范围

- 2 ≤ N ≤ 100
