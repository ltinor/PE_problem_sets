# 莫比乌斯函数和区间

## 题目描述

莫比乌斯函数 μ(n) 定义如下：
- μ(n) = (-1)^k 如果 n 是 k 个不同质因数的乘积（无平方因子）
- μ(n) = 0 如果 n 含有平方因子

记 P(a,b) 为区间 [a,b] 中 μ(n) = 1 的整数个数。
记 N(a,b) 为区间 [a,b] 中 μ(n) = -1 的整数个数。

定义 C(n) 为满足以下所有条件的整数对 (a,b) 的数目：
- 1 ≤ a ≤ b ≤ n
- 99·N(a,b) ≤ 100·P(a,b)
- 99·P(a,b) ≤ 100·N(a,b)

例如：C(10) = 13，C(500) = 16676，C(10000) = 20155319。

求 C(N)。

---

## 输入格式

一个整数 N (1 ≤ N ≤ 20000)。

---

## 输出格式

一个整数，表示 C(N)。

---

## 样例

### 输入
```
10
```

### 输出
```
13
```

---

## 数据范围

- 对于 30% 数据：N ≤ 100
- 对于 60% 数据：N ≤ 5000
- 对于 100% 数据：N ≤ 20000
