# 丢番图倒数 I

## 题目描述

考虑方程：

$$\\frac{1}{x}+\\frac{1}{y}=\\frac{1}{n}$$

其中 $x, y, n$ 均为正整数。对于给定的 $n$，该方程有若干不同的正整数解 $(x, y)$（$x \\le y$）。

求最小的正整数 $n$，使得不同解的个数**严格大于** $K$。

---

## 输入格式

一行一个整数 $K$。

---

## 输出格式

一行一个整数，表示最小的满足条件的 $n$。

---

## 样例

### 输入
```
2
```

### 输出
```
4
```

**解释**：$n=4$ 时有 3 个解：$(5,20), (6,12), (8,8)$，超过 $K=2$。

### 输入
```
1000
```

### 输出
```
180180
```

---

## 数据范围

- $1 \\le K \\le 1000$
