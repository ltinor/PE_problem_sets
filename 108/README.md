# 108 — Diophantine Reciprocals I

来源：改编自 Project Euler Problem 108

## 原题意

求最小的 $n$ 使得丢番图方程 $\\frac{1}{x}+\\frac{1}{y}=\\frac{1}{n}$ 的不同正整数解个数超过 1000。

答案：180180。

## 题目

输入整数 $K$，求最小的正整数 $n$ 使得 $\\frac{1}{x}+\\frac{1}{y}=\\frac{1}{n}$ 的不同正整数解个数超过 $K$。

## 数据范围

- $1 \\le K \\le 1000$

## 算法

方程变形为 $(x-n)(y-n)=n^2$，解数等于 $n^2$ 的因子对个数（除以 2 后加回对角线），即 $\\text{sols}(n) = (d(n^2)+1)/2$，其中 $d(n^2)$ 是 $n^2$ 的因子个数。

若 $n = \\prod p_i^{e_i}$，则 $d(n^2) = \\prod (2e_i+1)$。

从小到大枚举 $n$，用 SPF 线性筛快速分解质因数，计算解数直到超过 $K$。$n$ 最大约 $2 \\times 10^5$（$K=1000$ 时 $n=180180$）。

时间复杂度 $O(N \\log \\log N)$（筛法）+ $O(N \\log N)$（枚举分解）。

## 改编方向与取舍

### 改编方向
1. **参数化 $K$** → 求超过 $K$ 个解的最小 $n$（本题采用）
2. **求恰好 $K$ 个解的 $n$** → 可能无解，需要特殊处理
3. **DFS 质因子搜索** → 同 PE 110 的优化方法，直接构造最优 $n$
4. **输出所有解** → 给定 $n$ 输出所有 $(x,y)$ 解

### 取舍理由
- 选择参数化 $K$：最直接，保留原题核心
- 使用筛法枚举：$K \\le 1000$ 时枚举范围可控，比 DFS 实现更简单
- 不选 DFS：DFS 适合 PE 110 大范围，对本题 $K \\le 1000$ 杀鸡用牛刀
