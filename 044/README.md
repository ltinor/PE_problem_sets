# 五边形数 (Pentagon Numbers)

来源：改编自 Project Euler Problem 44

## 原题意

五边形数由公式 P_n = n(3n-1)/2 生成。求一对五边形数 P_j 和 P_k，使得它们的和与差都是五边形数，且 D = |P_k - P_j| 最小。求 D 的值。

原题答案：5482660。

## 改编方向

将问题参数化：给定搜索上限 M，在 P_1 ~ P_M 范围内寻找满足条件的五边形数对，输出最小差值。

## 题目

给定正整数 M，在五边形数序列 P_1, P_2, ..., P_M 中找一对 P_j 和 P_k (j ≠ k)，使得 P_j + P_k 和 |P_j - P_k| 都是五边形数。输出所有满足条件的数对中 |P_j - P_k| 的最小值。

## 数据范围

- M ≤ 3000
- 答案保证在 64 位有符号整数范围内
- 输入保证存在至少一对满足条件的五边形数

## 算法

预计算五边形数 P_1 ~ P_M，用 unordered_set 存储用于 O(1) 查询。双重循环枚举 j, k，检查 P_j+P_k 和 P_j-P_k 是否在集合中，维护最小差值。时间复杂度 O(M^2)，空间复杂度 O(M)。

brute 使用独立实现的数学判断（解二次方程验证是否是五边形数），算法相同但实现方式不同。

## 验证

- 原题答案：M=3000 → 5482660 ✓
