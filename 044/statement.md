# 五边形数

## 题目描述

五边形数由公式 $P_n = \\dfrac{n(3n-1)}{2}$ 给出。前几个五边形数是：

$$1, 5, 12, 22, 35, 51, 70, 92, 117, 145, \\ldots$$

可以看出 $P_4 + P_7 = 22 + 70 = 92 = P_8$。然而，它们的差 $70 - 22 = 48$ 并不是五边形数。

给定正整数 $M$，在五边形数序列 $P_1, P_2, \\ldots, P_M$ 中找一对 $P_j$ 和 $P_k$（$j \\neq k$），使得 $P_j + P_k$ 也是五边形数、且 $|P_j - P_k|$ 也是五边形数。输出所有满足条件的数对中 $|P_j - P_k|$ 的最小值。

---

## 输入格式

一行一个正整数 $M$。

---

## 输出格式

一行一个整数，表示满足条件的五边形数对的最小差值。

---

## 样例

### 输入

```
3000
```

### 输出

```
5482660
```

---

## 数据范围

- $2500 \\leq M \\leq 3000$
- 输入保证存在至少一对满足条件的五边形数
- 答案在 64 位有符号整数范围内
