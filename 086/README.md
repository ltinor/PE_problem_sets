# Cuboid Route

来源：改编自 Project Euler Problem 86

## 原题意

对于一个 $a \times b \times c$ 的长方体（$1 \le a \le b \le c$），从一角到对角沿表面的最短路径长度为 $\sqrt{(a+b)^2 + c^2}$。求使得最短路径为整数的长方体数量首次超过一百万的最小 $M$（其中 $a, b, c \le M$）。答案：$1818$。

## 题目

给定整数 $K$，求最小的 $M$，使得在所有满足 $1 \le a \le b \le c \le M$ 的长方体中，对角最短路径长度为整数的长方体数量严格大于 $K$。

## 数据范围

$1 \le K \le 10^6$

## 改编思路

### 方向一：参数化阈值 K（✅ 采用）
- 做法：将原题固定的 $K = 10^6$ 改为输入参数 $K \le 10^6$
- 优点：保留原题核心算法，直接参数化
- 缺点：无
- 结论：✅ 采用

### 方向二：求第 K 个满足条件的长方体
- 做法：给定 $K$，求体积第 $K$ 小的满足条件的长方体
- 优点：增加了排序维度的考察
- 缺点：改变了原题核心（从计数阈值变为排序），复杂度差异大
- 结论：❌ 不采用

### 方向三：多组询问 K 求对应 M
- 做法：$Q$ 组询问，每组给出 $K$ 求 $M$
- 优点：可以考察预处理和二分
- 缺点：增加复杂度，单组询问已经足够
- 结论：❌ 不采用

## 算法

从小到大枚举 $M$，累计满足条件的长方体数量。
- 对于固定的 $M$，新增的长方体满足 $c = M$
- 枚举 $s = a + b$（$2 \le s \le 2M$），检查 $s^2 + M^2$ 是否为完全平方数
- 若是，则满足 $a + b = s$ 且 $1 \le a \le b \le M$ 的 $(a,b)$ 对数为 $\max(0, \lfloor s/2 \rfloor - \max(1, s-M) + 1)$
- 当累计数量 $> K$ 时输出 $M$

时间复杂度：$O(M_{\text{max}}^2)$，其中 $M_{\text{max}} \approx 2000$（$K = 10^6$ 时）
