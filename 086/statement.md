# 长方体路径

## 题目描述

一只蜘蛛位于一个尺寸为 $a \times b \times c$（$1 \le a \le b \le c$）的长方体房间的一角，一只苍蝇位于其对角。蜘蛛只能沿房间的内表面爬行。

可以证明，从一角到对角沿表面的最短路径长度为：

$$\sqrt{(a+b)^2 + c^2}$$

例如，在 $6 \times 5 \times 3$ 的长方体中，$(a,b,c) = (3,5,6)$（按从小到大排序），最短路径长度为 $\sqrt{(3+5)^2 + 6^2} = \sqrt{64 + 36} = 10$，恰好为整数。

现在给定一个整数 $K$，请你求出最小的 $M$，使得在所有满足 $1 \le a \le b \le c \le M$ 的长方体中，对角最短路径长度为整数的长方体数量**严格大于** $K$。

---

## 输入格式

一行一个整数 $K$。

---

## 输出格式

一行一个整数 $M$。

---

## 样例

### 输入
```
2000
```

### 输出
```
100
```

**解释**：当 $M = 99$ 时，满足条件的长方体有 $1975$ 个；当 $M = 100$ 时，有 $2060$ 个，首次超过 $2000$。

---

## 数据范围

$1 \le K \le 10^6$
