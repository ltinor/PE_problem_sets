# 944 元素因数之和（简单版本）

来源：改编自 Project Euler Problem 944 (Sum of Elevisors)

## 原题意

x∈E 是 elevisor 若 x 整除 E 中另一个元素；sev(E)=所有 elevisor 之和。
S(n)=Σ_{E⊆{1..n}} sev(E)。原题求 S(10^14) mod 1234567891。

## 题目（简单版本）

输入一个整数 n，输出 S(n) mod 1234567891。

## 数据范围

- 简单版本：1 ≤ n ≤ 10^7。

## 算法

线性性 + 计数得闭式 S(n)=2^{n-1}·n(n+1)/2 − Σ_{x=1..n} x·2^{n−⌊n/x⌋}；
第二项用整除分块 O(√n)，指数经费马小定理约化。

验证：S(10)=4927。
