# 亿万富翁

## 题目描述

你有一个独特的投资机会：初始资本为 £1，可以进行 N 轮投注。每轮你可以选择一个固定的下注比例 f（0 < f < 1），投入当前资本的 f 比例，然后抛掷一枚公平硬币：

- 若正面朝上，赢取投入金额的两倍（净赚投入金额）；
- 若反面朝上，损失全部投入金额。

你的目标是经过 N 轮后总资本达到或超过 £1,000,000,000。

请计算：选择最优的 f 时，达成目标的**最大概率**（保留 12 位小数）。

---

## 输入格式

输入一行，一个整数 N。

---

## 输出格式

输出一个浮点数，保留 12 位小数，格式为 0.abcdefghijkl。

---

## 样例

### 输入
```
4
```

### 输出
```
0.000000000000
```

---

## 数据范围

$1 \le N \le 1000$
