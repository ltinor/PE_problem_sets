# Billionaire

来源：改编自 Project Euler Problem 267

## 原题意

初始资金 £1，每次以固定比例 f 下注，抛掷公平硬币 1000 次。正面赢双倍下注，反面输掉下注。选择最优 f 最大化最终资金 ≥ £1,000,000,000 的概率，求该最大概率（保留12位小数）。

## 题目

给定抛掷次数 N，求选择最优下注比例 f 时，最终资金达到 £1,000,000,000 的最大概率。

## 数据范围

$1 \le N \le 1000$

## 算法

二项分布 + 期望最大化

对于固定的 f，最少需要的正面次数 H_min = ceil((ln(1e9) - N·ln(1-f)) / (ln(1+2f) - ln(1-f)))。

概率 = Σ_{h=H_min}^{N} C(N,h) / 2^N。

使用网格搜索 + 三分搜索优化 f。对数阶乘预处理避免溢出。

时间复杂度：$O(N^2)$（对每个候选 f 计算概率）

## 扩展方向

1. **非对称硬币**：推广到硬币正面概率 p ≠ 0.5
2. **动态调整 f**：允许每轮改变下注比例（Kelly criterion）
3. **多个资产**：多臂老虎机模型，同时投资多个独立资产
