# PE347 - 能被两个素数整除的最大整数 (Largest integer divisible by two primes)

来源：改编自 Project Euler Problem 347

## 原题意

对于两个不同的素数 p 和 q，记 M(p,q,N) 为 ≤ N 的正整数中，能整除该数的素数恰好只有 p 和 q 的最大整数（若不存在则记 0）。记 S(N) 为所有不同的 M(p,q,N) 之和。求 S(10^7)。原题答案：11109800204052。

## 题目

输入 N，求 S(N)，即所有不同素数对 (p,q) 对应的 M(p,q,N) 的集合的元素之和。

## 算法

- 筛出 ≤ N/2 的所有素数。
- 枚举所有素数对 (p, q) 其中 p < q 且 p·q ≤ N。
- 对每对 (p,q)，枚举 p^i · q^j ≤ N 的所有组合，取最大值。
- 将所有最大值去重后求和。

复杂度：设 π(x) 为不超过 x 的素数个数，则需枚举约 π(N/2)^2 / 2 对。对于 N=10^7，素数约 3.3×10^5，对数较多但实际 p·q ≤ N 限制使得有效对较少。

## 改编方向

1. **三个素数**：扩展到能被恰好三个不同素数整除的最大数。
2. **多组输入**：支持多组 N。
3. **求最大值本身**：改为求最大值的乘积或其它聚合函数。
4. **允许重复**：不进行去重，直接对每个素数对的最大值求和。
