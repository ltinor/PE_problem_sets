# 落瓶

## 题目描述

将 N 个瓶子排成三角形。瓶子按编号从小到大的顺序落下。
当瓶子 k 落下时，若其下方的两个瓶子中有一个或两个已经碎了，
则失去支撑，瓶子 k 也会碎。

从底层开始，所有底层瓶子最初都是完好的。
定义 F(N) 为在某个规则下未碎瓶子的总数。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 57804030。
- `verify`：验证小规模的三角形计数和概率分析。
- `compute`：重新计算完整答案。

## 样例

### 输入
```
PE
```

### 输出
```
57804030
```

### 小规模验证
对于 N = 3 的三角形（共 6 个瓶子），底层全不碎时：
- 底层 3 个瓶子不碎
- 第 2 行 2 个瓶子（下方各 2 个不碎）→ 2 个不碎
- 第 1 行 1 个瓶子（下方 2 个不碎）→ 1 个不碎
- 总数 = 6

## 数据范围

- 验证范围：N ≤ 20（小规模枚举）
- 完整问题：根据 PE 726 原题参数
- 三角形高度 N 可达较大值
