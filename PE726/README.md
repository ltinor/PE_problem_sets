# PE726 — Falling Bottles (落瓶)

来源：改编自 Project Euler Problem 726

## 原题意

有 N 个瓶子按三角形排列（类似保龄球）。瓶子按编号从小到大落下。
瓶子落到其位置后，若下方两个瓶子都已碎，则该瓶子也会碎。
求某种条件下未碎瓶子的总数或期望值。

## 算法

1. **三角形结构**：第 r 行有 r 个瓶子，共 N(N+1)/2 个位置。
2. **碎瓶传导**：瓶子 (r,c) 不碎当且仅当 (r+1,c) 和 (r+1,c+1) 都不碎。
   从底层向上，这形成 AND 运算的传导。
3. **组合计数**：对于所有可能的底层状态 (2^N 种)，计算未碎瓶子总数。
   瓶子 (r,c) 在所有状态中不碎的次数为 2^{r-1}。
4. **期望分析**：若底层每个瓶子以概率 p 独立地不碎，
   则第 r 行期望未碎瓶数 = r * p^{N-r+1}。
5. **复杂度**：取决于具体参数范围，可使用递推或闭式公式。

## 改编方向

1. 参数化 N 的范围和底部状态的概率分布
2. 考虑不同的碎瓶传导规则
3. 改为按随机顺序落下瓶子
4. 求最大可能未碎瓶子数的最优落下顺序
5. 引入瓶子的重量或编号约束
