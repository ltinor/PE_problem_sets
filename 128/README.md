# 128 — Hexagonal Tile Differences

来源：改编自 Project Euler Problem 128

## 原题意

求第 2000 个 PD(n)=3 的六边形地砖编号。

原题答案：14516824220。

## 题目

参数化 K：输入 K (≤ 2000)，求第 K 个 PD(n)=3 的地砖编号。

## 数据范围

- K ≤ 2000

## 算法

六边形环结构：第 r 环有 6r 个地砖。只有环的起始位置 S_r = 3r(r-1)+2 和结束位置 E_r = 3r(r+1)+1 可能满足 PD=3。

- 对于 S_r (r ≥ 2)，检查 {6r-1, 6r+1, 12r+5} 是否均为素数。
- 对于 E_r (r ≥ 1)，检查 {6r-1, 6r+5, 12r-7} 是否均为素数。
- 地砖 1 特殊处理（PD=3）。

枚举 r 直到收集到 K 个满足条件的候选，排序后取第 K 个。

## 改编方向

1. **参数化 K**：将原题固定 K=2000 改为输入参数。
2. **小范围版本**：K ≤ 20 用于对拍验证。
3. **固定答案验证**：K=2000 作为测试点，输出 14516824220。
