# 不可达数

## 题目描述

从一个指定的初始集合出发，通过可重复应用的一系列操作来生成整数。

如果一个整数不能通过任何有限的操作序列从初始集合中生成，
则称该整数为**不可达数**（Unreachable Number）。

具体参数（初始集合、允许的操作、目标范围）遵循 PE 718 原题定义。

求在给定范围内的所有不可达数的数量（或总和）。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 228490116。
- `verify`：验证小规模数据（展示不可达数的判定过程）。
- `compute`：重新计算完整答案。

## 样例

### 输入
```
PE
```

### 输出
```
228490116
```

## 数据范围

- 验证范围：小参数（如 $N \le 1000$，操作集合最多 5 个元素）
- 完整问题：根据 PE 718 原题参数
- 可达数的数量随 $N$ 增长，通常使用筛法或 BFS
