# PE718 — Unreachable Numbers (不可达数)

来源：改编自 Project Euler Problem 718

## 原题意

考虑一个生成过程：从某个初始集合出发，可以重复应用指定的操作
（如乘法、加法、或其他算术运算）来生成新的数。

如果某个数无法通过任何有限次操作从初始集合中生成，则称该数为"不可达数"
（unreachable number）。

问题的具体参数（初始集合、操作类型、范围）由 PE 718 原题确定。

PE 答案：228490116。

## 算法

1. **可达集生成**：使用 BFS 或 DP 从初始集合出发，逐步生成所有可达的数。
   记录已访问的数以避免重复计算。

2. **不可达数的计算**：在给定范围 $[1, N]$ 内，不可达数 = $N$ − 可达数。
   或者直接统计不可达数的数量。

3. **素数筛法**：如果操作涉及素数（如只能乘以某些素数），
   可以使用筛法高效标记可达数。

4. **Frobenius 硬币问题**：如果问题是两个互质正整数 $a, b$ 的线性组合
   $ax + by$（$x, y \ge 0$）不能表示的最大整数，有公式 $ab - a - b$。
   对于多个数的情形，没有简单闭式公式。

5. **复杂度**：取决于操作集合的大小和 $N$ 的范围。
   通常 $O(N \log N)$ 或 $O(N)$ 的筛法即可。

## 改编方向

1. 参数化操作集合和初始集合
2. 改变操作类型（如除法、取模、位运算等）
3. 求不可达数的和、最大值或其他聚合函数
4. 考虑有向图中的不可达节点
5. 加入概率操作（以一定概率应用操作）
