# PE915 — Sudoku Variant（数独变种）

来源：改编自 Project Euler Problem 915

## 原题意

在标准数独规则的基础上引入额外的约束条件，要求在传统 \(9 \times 9\) 数独或变种大小的网格中填入数字，满足行、列、宫以及额外的自定义约束。

具体而言，本题可能要求计算满足所有约束条件的合法填数方案总数，或针对特定预设局面求解并输出某种编码后的结果。

PE 答案：**60112743**。

## 算法

极难的组合约束满足问题，涉及：
1. 精确覆盖问题的 DLX (Dancing Links) 算法
2. SAT 求解器或 CSP 回溯搜索
3. 数独变种的约束编码
4. 大规模方案计数（可能需要 Burnside 引理或对称性约简）

## 改编方向

1. 改变宫的大小（如 \(4 \times 4\) 小九宫改为不规则区域）
2. 加入新的约束类型（对角线、不等式、杀手数独规则）
3. 统计方案数而非单个解
