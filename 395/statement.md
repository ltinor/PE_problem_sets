# 毕达哥拉斯树

## 题目描述

毕达哥拉斯树是按以下步骤从单位正方形生成的分形：

1. 以正方形一条边为基底，在对边粘连一个 3-4-5 比例的直角三角形（斜边与对边重合，短直角边在右侧）。
2. 在两条直角边上各粘连一个正方形。
3. 对两个新正方形重复步骤 1-2（以与三角形粘连的边为基底）。

无限迭代后得到毕达哥拉斯树。存在一个各边平行于初始正方形的最小外接矩形。

求该最小外接矩形的面积，保留 10 位小数。

---

## 输入格式

一行一个整数 depth，为毕达哥拉斯树的迭代深度。

---

## 输出格式

一个浮点数（保留 10 位小数）：迭代 depth 次后的树的最小外接矩形面积。

---

## 样例

### 输入
```
1
```
### 输出
```
4.1552000000
```

### 输入
```
2
```
### 输出
```
8.2020761600
```

---

## 数据范围

- 1 ≤ depth ≤ 20（改编约定；原题为无限迭代的极限面积 28.2453753155）。
