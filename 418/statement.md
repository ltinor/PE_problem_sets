记n是一个正整数。一个整数三元组(a, b, c)被称为n的因数三元组，当满足一下条件：
-  1 ≤ a ≤ b ≤ c
-  a·b·c = n.

在n因数三元组(a, b, c)中，取使得c / a最小化的一组，记f(n)是这三个数的和a + b + c。可以验证这样的三元组总是唯一的。

例如f(165) = 19，f(100100) = 142，而f(20!) = 4034872。

求f(43!)。
