# 素数重排

## 题目描述

公差为 3330 的三项等差数列 1487, 4817, 8147 在两个方面非常特殊：其一，每一项都是素数；其二，每一项都是其他项的数字重新排列。

在这个三位数的等差数列之外，还有另一个由四位素数构成的此类等差数列。将 2969, 6299, 9629 三项连接起来得到 12 位数 296962999629。

现在将问题一般化：给定位数 D，找出除已知例子外，由三个 D 位素数组成的等差数列，使得三项互为其数字的重新排列。将这三项按升序拼接成一个 3×D 位数字输出。

---

## 输入格式

一行一个整数 D，表示位数。

---

## 输出格式

一行一个整数，为三个素数的升序拼接结果，共 3×D 位。

---

## 样例

### 输入

```
4
```

### 输出

```
296962999629
```

---

## 数据范围

- 4 ≤ D ≤ 6
