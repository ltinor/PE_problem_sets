# PE666 — 多形态细菌 (Polymorphic Bacteria)

来源：改编自 Project Euler Problem 666

## 原题意

一个细菌可以有两种形态：A 型（正常）和 B 型（突变）。一个菌落起始于一个 A 型细菌。在每一代中，每个细菌分裂成两个后代：
- A 型细菌：每个后代独立地以概率 1/2 为 A 型，以概率 1/2 为 B 型
- B 型细菌：后代始终为 B 型（突变不可逆）

问题要求统计经过若干代后，所有可能的基因型序列（菌落家族树）的数目，并对 10⁹+7 取模。

PE 答案：480641715。

## 算法

将细菌菌落建模为带标签的二叉树：
- 根节点总是 A 型
- 对于每个 A 型节点，子节点有 4 种可能的类型组合：(AA, AB, BA, BB)
- 对于每个 B 型节点，子节点总是 (BB)

使用动态规划：
- dp[i][j] = 深度为 i 的树中恰好有 j 个 A 型叶节点的方案数
- 转移：每个 A 型叶节点独立产生 0、1 或 2 个 A 型后代
  - 生成函数为 (1 + 2x + x²)ʲ = (1 + x)²ʲ
  - 系数为 C(2j, k)（二项式系数）

对于大规模 N，可利用生成函数和组合数学进行高效计算。

## 改编方向

1. 推广到多种形态（多种突变类型）
2. 考虑回复突变（B 型可突变回 A 型）
3. 引入死亡/选择压力
4. 统计特定表型出现的概率或期望数目
