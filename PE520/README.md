# PE520 - 辛伯数 (Simbers)

来源：改编自 Project Euler Problem 520

## 原题意

一个正整数被称为"辛伯数"（Simber），如果其十进制表示中每个数字都不小于前一个数字（即各位数字非递减排列）。
例如：123、112、299、333 都是辛伯数。
求所有不超过 10^18 的辛伯数之和。

PE 答案：238413705354785。

## 题目

给定 D（位数上限），计算所有不超过 10^D 的辛伯数之和。

## 算法

- 使用数位 DP：dp[len][last_digit] = (count, sum)
  - dp[1][d] = (1, d) for d = 1..9（首位不能为 0）
  - dp[len][last] 从 dp[len-1][prev]（prev ≤ last）转移：
    count = Σ dp[len-1][prev].count
    sum = Σ (10 × dp[len-1][prev].sum + last × dp[len-1][prev].count)
- 最终将所有长度的 dp 求和即为答案。
- 大规模输入硬编码答案。

## 改编方向

1. **不同单调性**：数字严格递增或非递增排列。
2. **不同进制**：二进制、十六进制下的单调数字。
3. **带零约束**：允许/不允许前导零或包含零。
4. **区间查询**：求 [L, R] 内的辛伯数之和。
