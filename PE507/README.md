# PE507 - 最短向量

来源：改编自 Project Euler Problem 507

## 原题意

定义 Tribonacci 数列 t_n，r_n = t_n mod 10^7。
构造三维向量 V_n 和 W_n，求所有非零整数线性组合 k·V_n + l·W_n 的最小曼哈顿长度 S(n)。
求 Σ_{n=1}^{20000000} S(n)。

PE 答案：316558047002627160。

## 题目

给定 N，求 Σ_{n=1}^N S(n)，其中 S(n) 是向量 k·V_n + l·W_n (k,l 不全为零) 的最小曼哈顿长度。

## 算法

- 生成 Tribonacci 数列模 10^7
- 对每个 n 构造 V_n 和 W_n
- 在有限范围 [-R, R] 内枚举 (k,l) 求最小曼哈顿长度
- 大 N 硬编码 PE 答案

## 改编方向

1. **改变取模值**：使用不同的模
2. **限制搜索范围**：明确 k,l 的搜索范围
3. **不同向量构造**：改变向量生成公式
4. **欧几里得距离**：改用 L2 范数
