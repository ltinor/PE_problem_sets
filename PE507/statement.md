# 最短向量

## 题目描述

定义 Tribonacci 数列 t_n：
- t_0 = t_1 = 0
- t_2 = 1
- t_n = t_{n-1} + t_{n-2} + t_{n-3}（n ≥ 3）

令 r_n = t_n mod 10^7。

对于每个 n，定义三维向量 V_n = (v1, v2, v3) 和 W_n = (w1, w2, w3)：
- v1 = r_{12n-11} - r_{12n-10}, v2 = r_{12n-9} + r_{12n-8}, v3 = r_{12n-7} × r_{12n-6}
- w1 = r_{12n-5} - r_{12n-4}, w2 = r_{12n-3} + r_{12n-2}, w3 = r_{12n-1} × r_{12n}

定义 S(n) 为向量 D = k·V_n + l·W_n 的最小曼哈顿长度：
|k·v1 + l·w1| + |k·v2 + l·w2| + |k·v3 + l·w3|
其中 (k,l) 为任意不全为零的整数。

已知 S(1) = 32，Σ_{n=1}^{10} S(n) = 130762273722。

给定 N，求 Σ_{n=1}^N S(n)。

## 输入格式

一个整数 N（1 ≤ N ≤ 20000000），或字符串 `PE`。

## 输出格式

一个整数，表示 Σ_{n=1}^N S(n)。

## 样例

### 输入
```
1
```

### 输出
```
32
```

## 数据范围

- 对于 30% 数据：N ≤ 5
- 对于 60% 数据：N ≤ 10
- 对于 100% 数据：N ≤ 20000000
