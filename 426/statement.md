## 原题描述

原题及更多讨论见 [https://projecteuler.net/problem=426](https://projecteuler.net/problem=426)。

考虑一行无限多个盒子，其中一些盒子放了球。其中一种放置方法是，前两个放球，然后紧跟着两个空箱子，然后再两个放球，再一个空箱子，再两个放球，这样的放置方法可以表示为序列(2, 2, 2, 1, 2)，连续的数轮流表示放球和不放球。

每一轮，按照下面所述的规则，移动每一个球恰好一次：将最左侧的没有移动过的球移动到右边最近的空格。

经过一轮后，序列(2, 2, 2, 1, 2)将会变成(2, 2, 1, 2, 3)，如下图所示。注意新序列将从第一个放了球的盒子开始计数。

<center><img src="/resources/images/0426_baxball1.gif"></center>

一个这样的系统被称为**盒子与球系统**或者简称**BBS**。

可以看出，经过足够多轮之后，这个系统将会进化到一个不变的状态。在下面的例子中，所有**放球的盒子**的序列最终将会进化成[1, 2, 3]；我们称之为最终状态。

<center><img src="/resources/images/0426_baxball2.gif"></center>

我们按如下方式定义序列{t<sub>i</sub>}：
- s<sub>0</sub> = 290797
- s<sub>k+1</sub> = s<sub>k</sub><sup>2</sup> mod 50515093
- t<sub>k</sub> = (s<sub>k</sub> mod 64) + 1

从初始状态(t<sub>0</sub>, t<sub>1</sub>, …, t<sub>10</sub>)开始，最终状态将是[1, 3, 10, 24, 51, 75]。
从初始状态(t<sub>0</sub>, t<sub>1</sub>, …, t<sub>10 000 000</sub>)开始，求最终状态。
你的答案将以最终状态各元素的平方和的形式给出，例如，如果最终状态是[1, 2, 3]，那么你的答案应当是14 ( = 1<sup>2</sup> + 2<sup>2</sup> + 3<sup>2</sup>)。
