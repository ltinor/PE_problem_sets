# PE620 — 行星齿轮 (Planetary Gears)

来源：改编自 Project Euler Problem 620

## 原题意

周长为 $c$ 的圆 $C$ 内含不同心周长为 $s$ 的小圆 $S$。四个"行星"圆（周长 $p,p,q,q$，$p<q$）内切于 $C$ 且外切于 $S$。这些圆是节距 1cm 且完美咬合的齿轮，$C$ 为内齿轮。所有周长（齿数）均为 $\ge 5$ 的整数。

记 $g(c,s,p,q)$ 为有效齿轮设计方式的数量。$G(n) = \sum_{s+p+q \le n} g(s+p+q,s,p,q)$，其中 $p<q$，$p \ge 5$，$s \ge 5$。

已知：$G(16)=9$，$G(20)=205$。求 $G(500)$。

PE 答案：1470339999。

## 算法

这是一个几何组合问题，结合了相切圆几何与整数齿轮啮合约束。

关键约束条件：

1. **相切几何**：四个行星必须同时与 $C$（内切）和 $S$（外切）相切。由笛卡儿圆定理及推广，四个与两圆相切的圆的配置是离散的。

2. **齿轮啮合**：完美啮合要求齿轮半径与齿数成正比。对于外切的两齿轮，中心距 $d = (r_1 + r_2)$；对于内切，$d = (r_C - r_p)$ 对于行星与 $C$。

3. **整数约束**：所有齿数（周长）为整数 $\ge 5$，且需满足啮合方程组。

4. **间距约束**：$S$ 与 $C$ 边界最近处 $\ge 1$ 齿。

该问题可转化为：枚举所有满足 $s+p+q \le 500$ 且各约束的 $(s,p,q)$ 三元组，对每个有效三元组计算行星的合法排列数。由于行星中有两对相同尺寸，计数需考虑对称性。

主要计算量在于用笛卡儿定理和整数啮合条件枚举所有合法的几何配置。

## 改编方向

1. 改变行星数量（如 6 个行星：$p,p,p,q,q,q$ 或更多）
2. 允许行星有不同的尺寸组合
3. 改变最小齿数约束
4. 研究 $G(n)$ 的渐近增长
5. 引入非均匀节距的齿轮
