# PE893 — Möbius Matchsticks（莫比乌斯火柴）

来源：改编自 Project Euler Problem 893

## 原题意

用火柴棍在数字显示器（7 段数码管）上显示数字。每个数字 0-9 需要的火柴棍数分别为：6, 2, 5, 5, 4, 5, 6, 3, 7, 6。

莫比乌斯函数 $\mu(n)$ 定义为：
- $\mu(1) = 1$
- $\mu(n) = 0$，若 $n$ 有平方质因子
- $\mu(n) = (-1)^k$，若 $n$ 是 $k$ 个不同质数的乘积

问题结合二者：计算由火柴棍数约束生成的数字的莫比乌斯函数期望值，或 $\sum \mu(n) \cdot f(n)$ 其中 $f(n)$ 是 $n$ 的火柴棍数。

## 算法

1. **莫比乌斯筛法**：
   - 线性筛 $\mu(n)$ 到 $N$

2. **火柴棍数**：
   - $\text{sticks}(n) = \sum_{d \in \text{digits}(n)} \text{sticks}[d]$

3. **约束生成**：
   - 用不超过 $S$ 根火柴棍能表示的所有数字
   - 使用 DFS 按位生成

4. **期望值**：
   - $E[\mu] = \frac{1}{|\mathcal{N}|} \sum_{n \in \mathcal{N}} \mu(n)$
   - 其中 $\mathcal{N}$ 是火柴棍约束下的数字集合

## 改编方向

1. 不同数字显示编码（如 14 段）
2. 其他数论函数（欧拉函数 $\varphi(n)$ 等）
3. 权重期望：$E[\mu(n) \cdot w(n)]$
4. 条件分布：限制数字位数
