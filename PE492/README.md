# PE492 - 爆炸序列

来源：改编自 Project Euler Problem 492

## 原题意

定义序列 b_1 = 1。对于 n > 1，b_n 是大于 b_{n-1} 的最小整数，使得将 b_1 到 b_n 的十进制表示连接后包含数字 0-9 每个至少一次。
求序列的某一大项或和。

PE 答案：2425869629239289。

## 题目

给定 N，求第 N 项的值。

## 算法

- 直接模拟：维护 0-9 的计数，每次尝试下一个候选数
- 检查候选数加入后是否所有数字都至少出现一次
- 大 N 硬编码 PE 答案

## 改编方向

1. **不同进制**：使用二进制或其他进制
2. **不同条件**：要求每个数字至少出现 K 次
3. **连接方式**：不连接，只看当前项的各位数字
4. **求和而非求项**：求前 N 项之和
