# 幂等元

## 题目描述

对于正整数 n，称整数 a (0 < a < n) 为 n 的幂等元，若 a² ≡ a (mod n)。

定义 M(n) 为 n 的最大幂等元（若不存在则 M(n)=0）。

给定 N，求 sum_{n=1}^{N} M(n)。

---

## 输入格式

一行一个整数 N。

---

## 输出格式

一行一个整数，表示 sum_{n=1}^{N} M(n)。

---

## 样例

### 输入
```
10
```

### 输出
```
17
```
解释：M(1)=0, M(2)=1, M(3)=1, M(4)=1, M(5)=1, M(6)=4, M(7)=1, M(8)=1, M(9)=1, M(10)=6。总和 = 17。

### 输入
```
15
```

### 输出
```
40
```

---

## 数据范围

- 对于 30% 数据：N ≤ 10³
- 对于 60% 数据：N ≤ 10⁵
- 对于 100% 数据：N ≤ 10⁶
