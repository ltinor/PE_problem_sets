# Totient Permutation

来源：改编自 Project Euler Problem 70

## 原题意

在 1 < n < 10⁷ 中，找到满足 φ(n) 是 n 的重排（即数字组成相同，只是顺序不同）且 n/φ(n) 最小的 n。

答案：8319823。

## 题目

给定 N，求所有 < N 的正整数中，满足 φ(n) 是 n 的一个重排且 n/φ(n) 最小的 n。

## 数据范围

N ≤ 10⁷（10,000,000）。

## 算法

1. 使用欧拉筛法（O(N)）或埃氏筛法（O(N log log N)）计算 1~N-1 的 φ 值。
2. 遍历 n = 2..N-1，检查 φ(n) 是否为 n 的重排。
3. 对满足条件的 n，找最小 n/φ(n) 比值。

std 和 brute 采用相同的筛法思路，但以不同方式实现重排判断（std 用字符串排序，brute 用计数数组）。

## 改编说明

原题固定 N = 10⁷。改编为参数化 N，扩大适用范围。当 N 较小时可用于快速验证；当 N 较大时（接近 10⁷）需要使用高效筛法。
