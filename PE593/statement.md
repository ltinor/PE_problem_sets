# 快速中位数

## 题目描述

定义序列 S 和 S₂：
- S(k) = (p_k)^k mod 10007，其中 p_k 是第 k 个素数
- S₂(k) = S(k) + S(⌊k/10000⌋ + 1)

M(i, j) 为 S₂ 数组从 i 到 j 的中位数。

F(n, k) = Σ_{i=1}^{n-k+1} M(i, i+k-1) 为所有长度为 k 的滑动窗口中位数的和。

已知：F(100, 10) = 463628.5，F(10^5, 10^4) = 675348207.5。

求 F(10^7, 10^5)。若和不是整数，用 .5 表示。

## 输入格式

一行，字符串 `PE` 或 `verify`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案：96632320042.5。
若输入为 `verify`，验证样例 M(1,10) 和 M(100,1000)。

## 样例

### 输入
```
PE
```

### 输出
```
96632320042.5
```

## 数据范围

- 完整问题：n = 10^7, k = 10^5
- 验证模式：n ≤ 1000
