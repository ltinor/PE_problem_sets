# PE 648 — Skipping Squares（平方跳跃）

## 原题

[Project Euler #648](https://projecteuler.net/problem=648)

对变量 s 从 0 开始：以概率 ρ 加 1，否则加 2。重复直到 s 为完全平方数或超过 10¹⁸。

f(ρ) = 期望跳过的完全平方数个数。

f(ρ) 的幂级数展开为 Σ_{k=0}^∞ a_k ρ^k。已知：a₀ = 1，a₁ = 0，a₅ = -18，a₁₀ = 45176。

F(n) = Σ_{k=0}^n a_k。已知 F(10) = 53964，F(50) ≡ 842418857 (mod 10⁹)。

求 F(1000) mod 10⁹。

**答案：30148308**

## 算法

- 动态规划 / 期望递推：从 M = 100000 向 0 反向递推 E_x(ρ)（从位置 x 出发的期望跳过的平方数）。
- 递推公式：对非平方数 x，E_x = ρ·E_{x+1} + (1-ρ)·(E_{x+2} + [x+1 为平方数])。
- 系数提取：将递推展开为 ρ 的幂级数，dp[x][k] 表示 E_x 中 ρ^k 的系数。
- 利用滑动窗口（只需 3 个位置）在 O(M·K) 时间内计算所有系数，K = 1000。
- 边界效应：M 足够大（10⁵），对低阶系数的边界影响可忽略。
