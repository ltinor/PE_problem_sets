# PE 648 — Skipping Squares（平方跳跃）

## 题目描述

变量 s 初始为 0。反复进行以下操作：以概率 ρ 将 s 加 1，以概率 1−ρ 将 s 加 2。重复操作直到 s 是完全平方数，或 s 超过 10¹⁸，以先发生者为准。

f(ρ) 为操作过程中被跳过的完全平方数的期望个数。（"跳过"指 s 从该平方数以下跳到该平方数以上，而没有恰好等于该平方数。）

f(ρ) 可展开为幂级数：f(ρ) = Σ_{k=0}^∞ a_k ρ^k。前几项系数为：
- a₀ = 1
- a₁ = 0
- a₅ = −18
- a₁₀ = 45176

F(n) = Σ_{k=0}^n a_k。

## 已知数据

- F(10) = 53964
- F(50) ≡ 842418857 (mod 10⁹)

## 求解

求 F(1000) mod 10⁹。

## 数据范围

- 0 ≤ ρ ≤ 1
- s 上限 10¹⁸
- n = 1000，模数 10⁹
