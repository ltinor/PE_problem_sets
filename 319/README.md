# 319 — Bounded Sequences

来源：改编自 Project Euler Problem 319

## 原题意

设 $x_1, x_2, \dots, x_n$ 是长度为 $n$ 的整数序列，满足：
- $x_1 = 2$
- 对所有 $1 < i \le n$：$x_{i-1} < x_i$
- 对所有 $1 \le i, j \le n$：$(x_i)^j < (x_j + 1)^i$

记 $t(n)$ 为这样的序列的个数。已知 $t(10) = 86195$，$t(20) = 5227991891$。

求 $t(10^{10}) \bmod 10^9$。答案：$268457129$。

## 题目

输入 $n$，求 $t(n) \bmod 10^9$。

## 数据范围

- $1 \le n \le 10^{10}$（但只有 $n=10^{10}$ 需要预计算答案）

## 算法

1. **DFS 回溯**：暴力枚举所有可能的序列。仅适用于 $n \le 8$。
2. **DP + 区间合并**：利用约束条件计算每步 $x_i$ 的取值范围，DP 合并区间计数。适用于 $n \le 20$。
3. **数学公式**：序列等价于存在 $\alpha \in [2,3)$ 使得 $x_i = \lfloor \alpha^i \rfloor$。通过分析 $\alpha$ 的临界点（$k^{1/i}$）计数。数据范围大时需要组合数学方法。

## 改编方向

1. 原题固定 $n=10^{10}$ → 参数化 $n$
2. 改变 $x_1$ 的初始值
3. 计数模不同模数

选择方向 1：参数化 $n$，保留原题数学核心。
