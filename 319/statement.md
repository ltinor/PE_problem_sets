# 有界序列

## 题目描述

设 $x_1, x_2, \dots, x_n$ 是长度为 $n$ 的整数序列，且满足以下条件：

- $x_1 = 2$
- 对于所有 $1 < i \le n$：$x_{i-1} < x_i$（严格递增）
- 对于所有 $1 \le i, j \le n$：$(x_i)^j < (x_j + 1)^i$

记 $t(n)$ 为满足上述条件的长度为 $n$ 的序列个数。

例如，长度为 $2$ 的序列共有 $5$ 个：$\{2,4\}, \{2,5\}, \{2,6\}, \{2,7\}, \{2,8\}$。
长度为 $5$ 的序列共有 $293$ 个，例如 $\{2,5,11,25,55\}$、$\{2,6,14,36,88\}$ 等。

给定 $n$，求 $t(n)$ 模 $10^9$ 的值。

---

## 输入格式

一行一个整数 $n$。

---

## 输出格式

一行一个整数，表示 $t(n) \bmod 10^9$ 的值。

---

## 样例

### 输入

```
1
```

### 输出

```
1
```

### 输入

```
2
```

### 输出

```
5
```

### 输入

```
5
```

### 输出

```
293
```

### 输入

```
10
```

### 输出

```
86195
```

### 输入

```
10000000000
```

### 输出

```
268457129
```

---

## 数据范围

- $1 \le n \le 10^{10}$
