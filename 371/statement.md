# 汽车牌照期望

## 题目描述

给定一个偶数 S，车牌号码从 0 到 S-1 等概率出现。当赛斯看到的两块车牌号码之和等于 S 时获胜（特别地，号码 S/2 需要出现两次）。求赛斯获胜所需看到的车牌数的数学期望，结果四舍五入保留 8 位小数。

---

## 输入格式

一行一个偶数 S (2 ≤ S ≤ 200)。

---

## 输出格式

一行一个实数，表示期望值，保留 8 位小数。

---

## 样例

### 输入
```
10
```

### 输出
```
5.92603501
```

---

## 数据范围

S 为偶数，2 ≤ S ≤ 200，共 5~10 组测试数据。
