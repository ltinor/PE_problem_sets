# 纸张切割博弈（PE 933）

来源：改编自 Project Euler Problem 933。

## 原题意

一刀同时横竖切矩形成 4 张整数矩形, 无法切者负; C(w,h)=先手必胜切法数, D(W,H)=ΣC。

## 题目

见 statement.md。参数与输入输出约定以 code/std.cpp 为准。

## 算法

参数化分支: Sprague-Grundy DP, g(w,h)=mex(四子矩形 XOR), C = 异或为 0 的切法数。

## 验证

C(5,3)=4, D(12,123)=327398 (题面); PE 分支 D(123,1234567)=5707485980743099 (官方, 全规模周期性规律未实现)
