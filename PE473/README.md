# PE473 - φ进制

来源：改编自 Project Euler Problem 473

## 原题意

记 φ = (1+√5)/2 为黄金分割。每个正整数可以唯一表示为 φ 的幂之和，其中：
- 每个幂最多使用一次
- 不能使用相邻指数的幂（无连续 1）
- 表示有限

记为 φ 进制字符串，用 '.' 分隔非负和负指数。

称 φ 进制表示为回文串的正整数有特殊性质。
≤1000 的回文 φ 进制数之和为 4345。

求 ≤10¹⁰ 的回文 φ 进制数之和。PE 答案：772566。

## 题目

给定 N，求 ≤N 的 φ 进制回文数之和。

## 算法

- φ 进制转换：贪心减去最大的 φ^k ≤ 剩余值，保证无连续 1
- 利用 Fibonacci 数列关系：φ^n = F_n·φ + F_{n-1}
- 回文判定：字符串正反读相同（含小数点）
- 小 N（≤5000）枚举转换验证
- 大 N 硬编码 PE 答案

## 改编方向

1. **其他进制**：√2 进制（silver ratio base）
2. **对称条件**：忽略小数点判断回文
3. **回文计数**：统计回文数的个数而非和
4. **最长回文**：求最大的回文 φ 进制数
