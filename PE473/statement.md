# φ进制

## 题目描述

记 $\varphi = \frac{1+\sqrt{5}}{2}$ 为黄金分割。每个正整数可以唯一表示为：

$$n = \sum_{k} d_k \varphi^k$$

其中 $d_k \in \{0,1\}$，且不能出现连续的 1（即 $d_k \cdot d_{k+1} = 0$），且只用有限项。

用由 0、1 和小数点组成的字符串表示该数，小数点前为非负指数项，小数点后为负指数项。称此表示为**φ进制**。

例如：
- $1 = 1_{\varphi}$
- $2 = 10.01_{\varphi}$（回文）
- $3 = 100.01_{\varphi}$（非回文）
- $14 = 100100.001001_{\varphi}$（回文）

记 $\varphi$ 进制表示为回文串（含小数点）的正整数具有特殊性质。所有不超过 1000 的回文 $\varphi$ 进制数之和为 4345。求不超过 $10^{10}$ 的回文 $\varphi$ 进制数之和。

---

## 输入格式

一个整数 $N$（$1 \leq N \leq 5000$ 或 $N = 10^{10}$）。

---

## 输出格式

一个整数，表示 $\sum \{x \leq N \mid x \text{ 的 } \varphi \text{ 进制表示为回文}\}$。

---

## 样例

### 输入
```
1000
```

### 输出
```
4345
```

---

## 数据范围

- 对于 30% 数据：$N \leq 100$
- 对于 60% 数据：$N \leq 1000$
- 对于 100% 数据：$N \leq 5000$ 或 $N = 10^{10}$
