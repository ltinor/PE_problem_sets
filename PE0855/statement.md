# 德尔斐纸（Delphi Paper）

## 题目描述

取一条长纸带，从右向左反复对折 $N$ 次。每次对折都会在纸上留下一条折痕。展开纸带后，可以看到所有折痕的方向：有些是"山折"（向上凸起），有些是"谷折"（向下凹陷）。

折痕方向构成的序列称为**正则折纸序列**（regular paperfolding sequence）。该序列具有以下递归性质：

- $a(2k) = a(k)$（偶数位置）
- $a(4k+1) = 1$（山折，位置 1, 5, 9, 13, ...）
- $a(4k+3) = 0$（谷折，位置 3, 7, 11, 15, ...）

如果按折痕方向将纸带弯折 $90°$（山折右转、谷折左转），折痕形成的图形便是著名的 **Heighway 龙曲线**（dragon curve），一条优美的分形曲线。

你的任务是计算与折纸序列相关的某个统计量（如特定范围内山折的数量、龙曲线的某种度量等）。

## 输入格式

无输入（固定参数问题）。

## 输出格式

输出一个整数，表示计算结果。
