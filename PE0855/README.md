# PE855 — Delphi Paper（德尔斐纸）

来源：改编自 Project Euler Problem 855

## 原题意

"德尔斐纸"涉及折纸（origami）问题。将一条纸带反复对折，形成一系列折痕。展开后，折痕的方向序列构成著名的"正则折纸序列"（regular paperfolding sequence）。

折叠 $n$ 次后，共有 $2^n - 1$ 条折痕。折痕方向序列可以递归定义：
- $a(2n) = a(n)$（偶数位置复制前面）
- $a(4n+1) = 1$（山折/右折）
- $a(4n+3) = 0$（谷折/左折）

其中 $1$ 表示山折（mountain / right turn），$0$ 表示谷折（valley / left turn）。

该序列与 Heighway 龙曲线（dragon curve）有密切关系：折痕方向对应龙曲线的转向（右转/左转），最终形成的图形是一条自相似的分形曲线。

PE 答案：999998093600。

## 算法

1. **单点查询**：利用二进制位运算在 $O(1)$ 时间内计算任意位置 $k$ 的折痕方向。
2. **区间统计**：利用自相似分块结构，递归计算 $[1, N]$ 区间内山折数量。
3. **完全块公式**：$M$ 次折叠后，$2^M-1$ 条折痕中恰好有 $2^{M-1}$ 条山折和 $2^{M-1}-1$ 条谷折。
4. **龙曲线生成**：根据折纸序列生成 Heighway 龙曲线的转向序列。
