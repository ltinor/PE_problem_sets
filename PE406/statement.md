# 猜数字游戏

## 题目描述

有一个隐藏的整数 t，满足 1 ≤ t ≤ n，t 均匀随机。你每次猜测一个整数 x：
- 若 x = t，游戏结束（代价为 0）
- 若 x < t，支付代价 c_lo 并继续
- 若 x > t，支付代价 c_hi 并继续

你可以采取最优策略使期望总代价最小。记 E(n) 为这个最小值。给定 N，求 sum_{n=1}^{N} E(n)，保留 6 位小数。

---

## 输入格式

一行三个整数 N, c_lo, c_hi。

---

## 输出格式

一个实数，保留 6 位小数，表示 sum_{n=1}^{N} E(n)。

---

## 样例

### 输入
```
3 1 1
```

### 输出
```
0.833333
```

### 输入
```
10 1 1
```

### 输出
```
6.450000
```

---

## 数据范围

- 对于 30% 数据：N ≤ 30
- 对于 60% 数据：N ≤ 200
- 对于 100% 数据：N ≤ 5000, c_lo, c_hi ≤ 10
