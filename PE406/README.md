# PE406 - 猜数字游戏

来源：改编自 Project Euler Problem 406

## 原题意

有一个隐藏整数 t ∈ [1, n]。每轮你可以猜测一个整数 x：
- 若 x = t，游戏结束
- 若 x < t，支付代价 c_lo 并继续
- 若 x > t，支付代价 c_hi 并继续
求最优策略下的最小期望总代价（t 均匀随机）。对 n=1..N 求和，保留 6 位小数。原 PE 参数：N=10000, c_lo=c_hi=1，答案 36813.982586。

## 题目

给定 N、代价 c_lo、c_hi，求 sum_{n=1..N} E_opt(n)，保留 6 位小数。

## 算法

- DP: E[l] = 区间长度为 l 的最优期望代价，O(N²) 转移
- 决策单调性优化可将转移优化至 O(N log N)

## 改编方向

1. **非均匀分布**：t 的分布不再是均匀分布，而是给定概率数组
2. **限制猜测次数**：最多允许 K 次猜测，求最大成功概率
3. **多目标同时猜测**：有 m 个独立的隐藏数字，每次猜测对每个数字都有效
4. **放大 N**：N 达 10⁶，需 O(N √N) 或更优算法
