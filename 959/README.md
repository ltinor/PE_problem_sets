# PE 959 · Asymmetric Random Walk（非对称随机游走）— 简单版本

来源：改编自 Project Euler Problem 959

## 原题意

青蛙在数轴上，每步向左跳 $a$（概率 $\tfrac12$）或向右跳 $b$（概率 $\tfrac12$）。$f(a,b)=\lim c_n/n$，$c_n$ 为前 $n$ 步落过的不同整数个数。求 $f(89,97)$ 并四舍五入到 9 位小数。

## 简单版本改动

原题 $a,b$ 较大（89,97）。改为：给定较小 $a,b$，用精确公式求 $f(a,b)$。

## 缩数据范围

$1 \le a, b \le 50$。

## 算法

解析推导（精确、确定性）：

1. $f(a,b)=P(\text{永不回到 }0)$。因 $E[R_n]=\sum_{k}P(S_k\text{ 是新位置})=\sum_k P(\text{前 }k\text{ 步未回到 }0)$，取极限得 $f=P(\text{永不回到 }0)$。
2. 由更新论，$E[\text{访问 }0\text{ 次数}]=\dfrac{1}{P(\text{永不回到 }0)}$，而 $E[\text{访问 }0\text{ 次数}]=\sum_{n\ge0}P(S_n=0)=:G$。
3. 记 $d=\gcd(a,b)$，$a'=a/d,b'=b/d$。$S_n=0$ 当且仅当 $n=(a'+b')m$，且 $P(S_{(a'+b')m}=0)=\binom{(a'+b')m}{a'm}/2^{(a'+b')m}$。
4. 故 $G=\sum_{m\ge0}\binom{(a'+b')m}{a'm}/2^{(a'+b')m}$，$f(a,b)=1/G$。若 $a'=b'$（对称游走，常返）则 $G$ 发散，$f=0$。

用 `lgamma` 稳定计算组合数对数，逐项求和至收敛。

## 验证结果

| 验证点 | 期望 | 实际 | 结果 |
|--------|------|------|------|
| $f(1,1)$ | 0 | 0.000000000 | ✓ |
| $f(1,2)$ | ≈0.427050983 | 0.427050983 | ✓ |

额外对照：$f(2,1)=f(2,4)=0.427050983$（对称性与约去 $\gcd$），$f(1,3)=0.678573510$，原题目标 $f(89,97)=0.857162085$。
