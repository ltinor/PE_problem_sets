# PE839 — Beans in Bowls（碗中豆）

来源：改编自 Project Euler Problem 839

## 原题意

有 B 个碗排成一圈，每个碗中有若干豆子。每次可以从碗 i（有豆子）取出一颗豆子放入碗 i+1（模 B）。游戏按某种规则进行直到终止。

这是一道组合博弈 / 马尔可夫过程问题。类似经典问题：
- **Chip-Firing Game（筹码点火游戏）**：在一个图上，节点上的筹码通过局部规则重新分配。
- **Bulgarian Solitaire**：一种特殊的拆分-聚合过程。
- **Abelian Sandpile Model**：自组织临界性模型。

PE 答案：229260851949018（≈ 2.3 × 10^14，很大的整数）。

## 算法

1. **Chip-Firing 过程模拟**：
   - 使用优先队列或队列模拟豆子的移动。
   - 对于大规模模拟，需要寻找周期性规律避免重复模拟。

2. **不变量与守恒量**：
   - 总豆子数不变。
   - 豆子的"总势能"（加权位置和）在转移下如何变化？

3. **稳定构型**：
   - 在 Chip-Firing Game 中，给定一个图和一个汇聚点（sink），系统的最终状态（稳定构型）是唯一的。
   - 可通过 Laplacian 矩阵和约化 Laplacian 来计算。

4. **Sandpile 群（临界群）**：
   - Abelian Sandpile Model 的稳定构型构成一个有限阿贝尔群（也称为 Jacobian 或 Picard 群）。
   - 群的大小 = 图的生成树数量（Matrix-Tree Theorem）。

5. **循环检测**：对于确定性转移，使用 Floyd's cycle detection 或状态哈希找周期。

## 改编方向

1. 考虑不同的图结构（完全图、网格、树）
2. 加入随机性（随机选择碗）
3. 改变转移规则（同时移动多颗豆子）
4. 研究达到稳定所需的步数分布
5. 与 Potts 模型 / Tutte 多项式的联系
