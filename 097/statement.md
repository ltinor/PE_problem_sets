# 大非梅森素数

## 题目描述

给定三个正整数 $A, B, C$，求 $A \times 2^B + C$ 的最后 $10$ 位数字。

---

## 输入格式

一行，三个整数 $A, B, C$，以空格分隔。

---

## 输出格式

一行，一个 $10$ 位数字（不足 $10$ 位前面补 $0$），表示 $A \times 2^B + C$ 的最后 $10$ 位。

---

## 样例

### 输入

```
3 10 0
```

### 输出

```
0000003072
```

### 输入

```
28433 7830457 1
```

### 输出

```
8739992577
```

---

## 数据范围

- $1 \le A \le 10^5$
- $1 \le B \le 10^7$
- $0 \le C \le 10^5$
