# 青蛙的旅途

## 题目描述

在一行 n 个方块的最左边一只青蛙。青蛙通过连续跳跃，先跳到最右边再跳回最左边。向右跳每次 1、2 或 3 格，向左同理。这样的往返进行 m 次。

记 F(m,n) 为至多有一个方块从未被访问过的走法总数。

已知：F(1,3)=4, F(1,4)=15, F(1,5)=46, F(2,3)=16, F(2,100) mod 10^9 = 429619151。

给定 m 和 n，求 F(m,n) mod 10^9。

---

## 输入格式

一行两个整数 m 和 n。

---

## 输出格式

一个整数，表示 F(m,n) mod 10^9。

---

## 样例

### 输入
```
1 3
```

### 输出
```
4
```

### 输入
```
1 4
```

### 输出
```
15
```

### 输入
```
2 3
```

### 输出
```
16
```

---

## 数据范围

- 对于 30% 数据：m=1, n ≤ 5
- 对于 60% 数据：m ≤ 2, n ≤ 6
- 对于 100% 数据：m ≤ 10, n ≤ 10^12
