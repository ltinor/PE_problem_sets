# 167 — 乌拉姆序列

来源：改编自 Project Euler Problem 167

## 原题意

对于 n=2..10，求 U(2, 2n+1) 在第 K=10^11 项的和。原题答案：3916160068885。

## 题目

参数化 K：输入 K（≤ 10^11），求 Σ_{n=2}^{10} U(2, 2n+1)_K。

## 数据范围

- K ≤ 10^11

## 算法

**std**: 乌拉姆序列 U(2, 2n+1) 在初始若干项后呈现周期性模式 —— 序列由两个交替的等差数列组成，公差为 d=2n+5。先直接生成前 2000 项检测周期稳定性，之后用公式直接计算第 K 项。

**brute**: 直接生成序列（仅适用于小 K，用于验证）。

## 改编方向

1. **参数化 K**：将固定 K=10^11 改为输入参数。
2. **数学推导**：利用周期性模式避免直接生成到 10^11。
3. **PE 答案验证**：(K=10^11) 输出 3916160068885。
