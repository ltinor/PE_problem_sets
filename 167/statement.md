# 乌拉姆序列

## 题目描述

任取两个正整数 a 和 b，乌拉姆序列 U(a,b) 定义如下：
- U(a,b)₁ = a，U(a,b)₂ = b
- 对于 k > 2，U(a,b)_k 是比 U(a,b)_{k-1} 更大，且存在用序列中之前的不同两项之和唯一表示的最小整数。

例如，序列 U(1,2) 的开头部分为：1, 2, 3, 4, 6, 8, 11, ...

对于 n = 2 到 10，求 Σ U(2, 2n+1)_K，即 9 个序列第 K 项之和。

## 输入格式

一行一个整数 K。

## 输出格式

一行一个整数，表示所求之和。

---

## 样例

### 输入
```
10
```

### 输出
```
731
```

### 输入
```
100000000000
```

### 输出
```
3916160068885
```

---

## 数据范围

- K ≤ 10¹¹

---

## 提示

U(2, 2n+1) 序列在初始若干项后呈现周期性模式，可利用数学公式直接计算大 K 值。PE 原题 K=10¹¹ 时答案为 3916160068885。
