# 素斐波那契数

## 题目描述

定义函数 $\text{next\_prime}(n)$ 为大于 $n$ 的最小素数。

定义序列 $a(n)$：
- $a(1) = \text{next\_prime}(S)$
- $a(n) = \text{next\_prime}(a(n-1))$（$n > 1$）

其中 $S$ 为给定的起始值。即 $\{a(n)\}$ 是从 $S$ 开始的连续素数序列。

定义 $b(n) = F_{a(n)}$，其中 $F$ 为斐波那契数列：$F_0 = 0, F_1 = 1, F_k = F_{k-1} + F_{k-2}$（$k > 1$）。

给定 $N$、模数 $M$ 和起始值 $S$，求 $\sum_{n=1}^N b(n) \bmod M$。

---

## 输入格式

一行三个整数 $N$、$M$、$S$。

---

## 输出格式

一行一个整数，表示结果。

---

## 样例

### 输入
```
3 1000 10
```

### 输出
```
（起始值 S=10，连续素数 11, 13, 17，对应斐波那契数之和）
```

---

## 数据范围

- $1 \le N \le 100000$
- $10^9 \le M \le 10^{13}$
- $1 \le S \le 10^{14}$
