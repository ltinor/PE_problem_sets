# PE601 — 整除连续串 (Divisibility streaks)

来源：改编自 Project Euler Problem 601

## 原题意

对于任意正整数 n，定义 streak(n) = k，其中 k 是满足 n+k 不能被 k+1 整除的最小正整数。

例如：streak(13) = 4（13÷1=13 ✓, 14÷2=7 ✓, 15÷3=5 ✓, 16÷4=4 ✓, 17÷5 不能整除 ✗）。
streak(120) = 1（120÷1=120 ✓, 121÷2 不能整除 ✗）。

定义 P(s, N) 为 1 < n < N 中满足 streak(n) = s 的整数 n 的个数。
已知：P(3, 14) = 1，P(6, 10⁶) = 14286。

求 Σ_{i=1}^{31} P(i, 4ⁱ)。

PE 答案：1617243。

## 算法

关键观察：streak(n) ≥ s 当且仅当 n ≡ 1 (mod LCM(2,3,...,s))。

证明：对 k = 0,1,...,s-1，n+k 被 k+1 整除等价于 n ≡ 1 (mod k+1)。由中国剩余定理，所有条件等价于 n ≡ 1 (mod LCM(2,3,...,s+1))。

因此：
- streak(n) = s ⇔ n ≡ 1 (mod L_s) 且 n ≢ 1 (mod L_{s+1})
- 其中 L_s = lcm(2,3,...,s)，L_1 = 1。

P(s, N) = ⌊(N-2)/L_s⌋ - ⌊(N-2)/L_{s+1}⌋

这是因为 n = 1 + t·L_s，约束 1 < n < N 即 2 ≤ n ≤ N-1，所以 t ∈ [1, ⌊(N-2)/L_s⌋]。

时间复杂度：O(31 · 32) = O(1)。L_s 最大至 L_32 ≈ 2.3×10¹²，仍在 64 位整数范围内。

## 改编方向

1. 推广 streak 定义：使用不同的模数序列（如平方数、斐波那契数）。
2. 求 P(s, N) 的渐进公式。
3. 多维度推广：同时满足多个线性同余条件。
4. 将和式推广到更大的 i 范围或不同的底数（如 5ⁱ 代替 4ⁱ）。
