# Square Digit Chains

来源：改编自 Project Euler Problem 92

## 原题意

从任意一个数开始，不断取其各位数字的平方和，直到出现重复。任意起始数最终都会到达 $1$ 或 $89$。

求小于一千万的数中，最终到达 $89$ 的有多少个。（答案：8581146）

## 题目

给定一个正整数 $N$，求所有小于 $N$ 的正整数中，各位数字平方和迭代最终到达 $89$ 的数的个数。

## 数据范围

$1 \le N \le 10^7$

## 算法

记忆化搜索。注意到对于 $N \le 10^7$，第一次平方和后结果 $\le 7 \times 9^2 = 567$，因此只需记忆化处理 1~567 的状态即可。

时间复杂度 $O(N)$。
