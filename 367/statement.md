# Bozo 排序变种

## 题目描述

Bozo 排序的一种变种：如果序列不是有序的，随机选择三个元素并随机重排它们（所有 $3!=6$ 种排列等概率）。已经有序的序列需要 0 次操作。

考虑前 $n$ 个自然数的所有 $n!$ 种排列作为输入，求所需重排次数的期望值的平均值，四舍五入到整数。

## 输入格式

一行一个整数 $n$。

## 输出格式

输出期望值四舍五入到最近的整数。

## 样例

### 输入
```
4
```

### 输出
```
28
```

（期望值为 27.5，四舍五入为 28）

## 数据范围

- 对于 20% 数据：$n \le 6$
- 对于 50% 数据：$n \le 8$
- 对于 100% 数据：$n = 11$
