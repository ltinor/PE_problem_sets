# 三、五、六边形数

## 题目描述

三角形数、五边形数和六边形数分别由以下公式给出：

$$
\\begin{aligned}
\\text{三角形数}\\ T_n &= \\dfrac{n(n+1)}{2} \\\\\\\\
\\text{五边形数}\\ P_n &= \\dfrac{n(3n-1)}{2} \\\\\\\\
\\text{六边形数}\\ H_n &= n(2n-1)
\\end{aligned}
$$

可以验证，$T_{285} = P_{165} = H_{143} = 40755$。

同时是三角形数、五边形数和六边形数的数从小到大依次为 $1, 40755, 1533776805, \\ldots$。

给定正整数 $K$，求第 $K$ 个同时是三角形数、五边形数和六边形数的数。

---

## 输入格式

一行一个正整数 $K$。

---

## 输出格式

一行一个整数，表示第 $K$ 个同时是三角形数、五边形数和六边形数的数。

---

## 样例

### 输入 #1

```
1
```

### 输出 #1

```
1
```

### 输入 #2

```
2
```

### 输出 #2

```
40755
```

---

## 数据范围

- $1 \\leq K \\leq 3$
- 答案在 64 位有符号整数范围内
