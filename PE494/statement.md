# Collatz前缀族

## 题目描述

Collatz 函数 $f(n)$ 定义为：
- 若 $n$ 为偶数：$f(n) = n/2$
- 若 $n$ 为奇数：$f(n) = 3n + 1$

对于正整数 $n$，连续应用 $f$ 可得到 Collatz 序列。例如 $n=5$：5 → 16 → 8 → 4 → 2 → 1 → ...

用 E 表示偶数步（除以 2），O 表示奇数步（乘 3 加 1）。则 $n=5$ 的前几步为：O, E, E, E, E, ...

给定 $K$ 和 $N$，考虑所有长度为 $K$ 的 E/O 模式（共 $2^K$ 种）。对每种模式，统计有多少 $n \le N$ 的 Collatz 序列前 $K$ 步与该模式一致。求所有模式的总计数。

## 输入格式

两个整数 $K$ 和 $N$，或字符串 `PE`。

## 输出格式

一个整数，表示总计数。

## 样例

### 输入
```
1 20
```

### 输出
```
20
```

## 数据范围

- 对于 30% 数据：$K \le 3, N \le 100$
- 对于 60% 数据：$K \le 6, N \le 10000$
- 对于 100% 数据：$K \le 10, N \le 10^6$
