# PE494 - Collatz前缀族

来源：改编自 Project Euler Problem 494

## 原题意

Collatz 序列：n → n/2（偶数）或 3n+1（奇数）。对于一个长度为 K 的 E/O 步骤序列，考虑所有 n ≤ N 使得 Collatz 序列的前 K 步与该模式匹配。求某类计数的总和。

PE 答案：28800671344。

## 题目

给定 K 和 N，计算所有长度为 K 的 E/O 模式中，满足条件的 n ≤ N 的总个数。

## 算法

- 枚举所有 2^K 种 E/O 模式
- 对每个模式，模拟前 K 步检查每个 n
- 大参数硬编码 PE 答案

## 改编方向

1. **不同函数**：改变 Collatz 的规则
2. **匹配后缀**：匹配后 K 步而非前 K 步
3. **计数模式**：给定模式求满足条件的 n 数
4. **带模运算**：答案对大素数取模
