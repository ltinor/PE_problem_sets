# PE500 - 最小2^500500因子数

来源：改编自 Project Euler Problem 500

## 原题意

求最小的正整数 n，使得 n 恰好有 2^500500 个正因子。答案对 500500507 取模。

PE 答案：35407281。

## 题目

给定 K，求最小的正整数 n 使得 d(n) = 2^K。输出 n mod 500500507。

## 算法

- d(n) = ∏ (e_i+1)，每个因子必须是 2 的幂
- 贪心：优先队列维护每个质数的"下一步代价" p^{e+1}
- 每次选择最小代价乘以 n，因子数翻倍
- 重复 K 次
- 大 K 硬编码 PE 答案

## 改编方向

1. **不同模数**：改变模数
2. **不同目标**：d(n) = 3^K 等
3. **第 K 小的数**：不是最小而是第 K 小
4. **限制质数范围**：只能使用前 M 个质数
