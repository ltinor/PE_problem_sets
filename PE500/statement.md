# 最小2^K因子数

## 题目描述

设 $d(n)$ 表示正整数 $n$ 的正因子个数。例如 $d(6) = 4$（因子为 1, 2, 3, 6）。

给定 $K$，求最小的正整数 $n$ 满足 $d(n) = 2^K$。输出 $n \bmod 500500507$。

## 输入格式

一个整数 $K$（$1 \le K \le 500500$），或字符串 `PE`。

## 输出格式

一个整数，表示 $n \bmod 500500507$。

## 样例

### 输入
```
3
```

### 输出
```
24
```

（24 = 2^3 × 3^1，因子数 = (3+1)(1+1) = 8 = 2^3，24 mod 500500507 = 24）

## 数据范围

- 对于 30% 数据：$K \le 10$
- 对于 60% 数据：$K \le 1000$
- 对于 100% 数据：$K \le 500500$
