# 牛奶冻曲线与圆

## 题目描述

牛奶冻曲线由满足 $0 \\le x \\le 1$ 且

$$y = \\sum_{n=0}^{\\infty} \\frac{s(2^n x)}{2^n}$$

的点 $(x, y)$ 构成，其中 $s(x)$ 是 $x$ 到最近整数的距离。

现在考虑使用前 $N$ 项的截断和来近似该曲线：

$$y_N(x) = \\sum_{n=0}^{N-1} \\frac{s(2^n x)}{2^n}$$

令 $C$ 是以 $(\\frac{1}{4}, \\frac{1}{2})$ 为圆心、半径为 $\\frac{1}{4}$ 的圆。

求曲线 $y_N(x)$ 的下方被圆 $C$ 包围的区域面积，四舍五入保留 8 位小数。

---

## 输入格式

输入一行，一个整数 $N$。

---

## 输出格式

输出一个实数，保留 8 位小数，表示面积。

---

## 样例

### 输入
```
30
```

### 输出
```
0.11316017
```

---

## 数据范围

$1 \\le N \\le 25$
