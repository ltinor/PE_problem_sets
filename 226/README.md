# 226 — Scoop of Blancmange

来源：改编自 Project Euler Problem 226

## 原题意

求牛奶冻曲线下被圆 C（圆心(1/4, 1/2)，半径 1/4）包围的面积。原题答案：0.11316017。

## 题目

参数化 N（迭代次数）：输入 N，计算使用前 N 项近似的牛奶冻曲线 y = Σ_{n=0}^{N-1} s(2^n·x)/2^n 在被圆 C 包围区域下的面积，四舍五入保留 8 位小数。

## 数据范围

$1 \\le N \\le 25$

## 算法

**std**: 数值积分（矩形法/梯形法），使用 200000 个采样点。对每个采样点 x ∈ [0, 1]，计算截断级数 y(x)，判断 (x, y(x)) 是否在圆 C 内，累积面积。

时间复杂度：$O(N \\cdot STEPS)$，收敛后与 N 无关。

**brute**: 同 std 但使用更少采样点（50000），适用于小数据验证。

## 改编方向

1. **参数化 N**：将原题无穷级数改为截断到 N 项，N 越小面积越接近圆内曲线面积（收敛快）。
2. **改变圆参数**：可参数化圆心和半径，计算不同圆内的面积。
3. **精度要求**：可调整输出精度要求（如 6 位小数），适应不同评测需求。
