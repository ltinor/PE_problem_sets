# 圆圈覆盖 II

## 题目描述

记 $R(a, b, c)$ 是三边长分别为 $a$、$b$、$c$ 的三角形内部**三个互不重叠的圆**能覆盖的**最大面积**。

对于所有满足 $1 \le a \le b \le c < a + b \le n$ 的整数三元组 $(a, b, c)$，记 $S(n)$ 为所有 $R(a, b, c)$ 的**平均值**。

已知：
- $S(2) = R(1, 1, 1) \approx 0.31998$
- $S(5) \approx 1.25899$

---

## 输入格式

一个整数 $n$。

---

## 输出格式

一个实数，表示 $S(n)$，保留 **5 位小数**。

---

## 样例

### 输入
```
2
```

### 输出
```
0.31998
```

---

## 数据范围

- 对于 30% 数据：$n \le 5$
- 对于 60% 数据：$n \le 10$
- 对于 100% 数据：$n \le 1803$
