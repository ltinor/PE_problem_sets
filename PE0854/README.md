# PE854 — Pisano Periods 2（Pisano周期2）

来源：改编自 Project Euler Problem 854

## 原题意

Pisano 周期 $\\pi(m)$ 的进一步研究。除了基本性质外，还包括：

- $\\pi(m)$ 对于所有 $m \\geq 3$ 恒为偶数
- $\\pi(m) = m$ 的 $m$ 仅有 $m = 24 \\cdot 5^k$（Wall 猜想，已证明）
- Pisano 周期的取值范围：$\\{1, 3, 6, 8, 12, 20, 24, \\ldots\\}$
- $\\pi(m)$ 与 $m$ 的比值 $\\pi(m)/m$ 在 $(0, 6]$ 范围内

可能的问题方向：
- 计算具有特定 Pisano 周期值的 $m$ 的个数
- 求满足 $\\pi(m) = K$ 的最小/最大 $m$
- 对给定 $N$，统计 $\\pi(m) \\leq N$ 的 $m$ 的个数
- 研究两个不同模数具有相同 Pisano 周期的条件

PE 答案：566225932。

## 算法

1. **暴力枚举**：对于小范围 $m$，直接模拟计算 $\\pi(m)$。
2. **质因数分解 + LCM**：利用 $\\pi$ 的乘性，将 $m$ 分解为质数幂，分别计算并取 LCM。
3. **周期分布分析**：统计不同 Pisano 周期值的频次，研究 $\\pi^{-1}(K)$ 的结构。
4. **快速加倍验证**：用矩阵快速幂在 $O(\\log \\pi(m))$ 时间内验证周期是否正确。

## 改编方向

1. 实现高效的 $\\pi(m)$ 批量计算方法（筛法）
2. 研究 $\\pi(m)$ 的偶性证明与推广
3. 寻找 $\\pi(m) = \\pi(n)$ 但 $m \\neq n$ 的"碰撞"
4. 分析 $\\pi(m)$ 的渐近均值
5. 将问题推广到 Tribonacci、Tetranacci 等广义数列
