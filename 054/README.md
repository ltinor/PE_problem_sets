# 扑克手牌

来源：改编自 Project Euler Problem 54

## 原题意

在 [poker.txt](https://projecteuler.net/project/resources/p054_poker.txt) 中，包含1000局两名玩家的扑克手牌。统计玩家1获胜的局数。原题答案：376。

## 题目

给定 $N$ 局扑克游戏，每局包含10张牌（两个字符表示一张牌：牌面 + 花色），前5张属于玩家1，后5张属于玩家2。计算玩家1获胜的局数。

牌面：2,3,4,5,6,7,8,9,T,J,Q,K,A（由小到大）

花色：S(黑桃), H(红桃), D(方片), C(草花)

手牌等级（由低到高）：
1. **高牌**：无特殊组合，比较最大单牌
2. **一对**：两张同面值
3. **两对**：两个不同对子
4. **三条**：三张同面值
5. **顺子**：五张连续面值（A可作为1: A-2-3-4-5）
6. **同花**：五张同花色
7. **葫芦**：三条 + 一对
8. **四条**：四张同面值
9. **同花顺**：顺子且同花色
10. **皇家同花顺**：10-J-Q-K-A 同花色

## 数据范围

$1 \\leq N \\leq 1000$

所有手牌合法，每局必有唯一胜者。

## 算法

牌型判定 + 比较逻辑。时间复杂度：$O(N)$。
