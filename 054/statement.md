# 扑克手牌

## 题目描述

在扑克牌游戏中，一手牌由五张牌组成。根据牌面组合，手牌分为以下等级（从低到高）：

- **高牌**：牌面最大的一张牌。
- **一对**：两张牌面相同的牌。
- **两对**：两个不同的对子。
- **三条**：三张牌面相同的牌。
- **顺子**：五张牌面连续。
- **同花**：五张牌同一花色。
- **葫芦**：三条加一对。
- **四条**：四张相同的牌。
- **同花顺**：顺子且同一花色。
- **皇家同花顺**：10、J、Q、K、A 同一花色。

牌面顺序（从小到大）：2, 3, 4, 5, 6, 7, 8, 9, T, J, Q, K, A。

花色：S(黑桃), H(红桃), D(方片), C(草花)。

当两名玩家手牌等级相同时，按以下规则比较：先比较组成该等级的关键牌面值，若相同则依次比较其余牌的牌面值（从大到小）。

给定 $N$ 局游戏，每局给出10张牌，前5张属于玩家1，后5张属于玩家2。判断每一局中玩家1是否获胜，并输出玩家1获胜的总局数。

---

## 输入格式

第一行一个整数 $N$，表示游戏局数。

接下来 $N$ 行，每行 10 个字符串，每个字符串由两个字符组成（牌面+花色）。前5张是玩家1，后5张是玩家2。

---

## 输出格式

输出一个整数，表示玩家1获胜的局数。

---

## 样例

### 输入
```
5
5H 5C 6S 7S KD 2C 3S 8S 8D TD
5D 8C 9S JS AC 2C 5C 7D 8S QH
2D 9C AS AH AC 3D 6D 7D TD QD
4D 6S 9H QH QC 3D 6D 7H QD QS
2H 2D 4C 4D 4S 3C 3D 3S 9S 9D
```

### 输出
```
3
```

---

## 数据范围

- $1 \leq N \leq 1000$
- 所有手牌合法，每局必有唯一胜者
- 牌面字符：2-9, T, J, Q, K, A
- 花色字符：S, H, D, C
