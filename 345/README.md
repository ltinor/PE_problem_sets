# 345 — Matrix Sum

来源：改编自 Project Euler Problem 345

## 原题意

定义矩阵的“矩阵和”为：从矩阵中选取元素，使得每行每列恰选一个，并使所选元素之和最大。
例如 5×5 示例矩阵的矩阵和为 3315。
原题为 15×15 矩阵，答案 13938。

## 题目

输入一个 N×N 矩阵，每行 N 个整数。求该矩阵的矩阵和（每行每列恰选一个元素的最大总和）。

## 数据范围

- 1 ≤ N ≤ 15
- 每个元素的绝对值 ≤ 1000

## 算法

**匈牙利算法（Hungarian Algorithm）**：将最大权匹配转化为最小费用匹配（取负），使用 O(N³) 的匈牙利算法求解。N ≤ 15 非常小，也可用 O(N!) 枚举验证。

## 改编方向

1. 原题固定 15×15 → 参数化 N（1 ≤ N ≤ 15）
2. 支持多组测试数据
3. 改为最小矩阵和（无改动难度）

选择方向 1：参数化 N，保留原题数学核心。
