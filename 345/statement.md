# 矩阵和

## 题目描述

给定一个 N×N 的整数矩阵，从中选取恰好 N 个元素，使得每行、每列各有一个元素被选中。求这些元素之和的最大值。

---

## 输入格式

第一行一个整数 N。
接下来 N 行，每行 N 个整数，表示矩阵中的元素。

---

## 输出格式

一行一个整数，表示最大矩阵和。

---

## 样例

### 输入

```
5
  7  53 183 439 863
497 383 563  79 973
287  63 343 169 583
627 343 773 959 943
767 473 103 699 303
```

### 输出

```
3315
```

### 输入

```
3
1 2 3
4 5 6
7 8 9
```

### 输出

```
15
```

---

## 数据范围

- 1 ≤ N ≤ 15
- |a_ij| ≤ 1000
