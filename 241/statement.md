# 完全度商数

## 题目描述

对于正整数 n，记 σ(n) 为 n 的所有正约数之和。例如 σ(6) = 1 + 2 + 3 + 6 = 12。

定义 **完全度商数** 为 p(n) = σ(n) / n。

例如：
- p(6) = 12/6 = 2
- p(28) = 56/28 = 2
- p(12) = 28/12 = 7/3

如果一个正整数的完全度商数可以写成 k + 1/2 的形式（其中 k 是整数），即化简后分母为 2，则称这个数为「半整完全度商数」。

例如：p(2) = 3/2 = 1 + 1/2，所以 2 是半整完全度商数。

给定 N，求所有不超过 N 的半整完全度商数之和。

---

## 输入格式

一行一个整数 N。

---

## 输出格式

一行一个整数，表示答案。

---

## 样例

### 输入
```
100
```

### 输出
```
246
```

（满足条件的 n：2, 24, ...；它们的和为 246）

---

## 数据范围

- 对于 20% 的数据：N ≤ 10^6
- 对于 50% 的数据：N ≤ 10^8
- 对于 80% 的数据：N ≤ 10^10
- 对于 100% 的数据：N ≤ 10^12
