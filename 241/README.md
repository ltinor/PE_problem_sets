# 完全度商数 (Perfection Quotients)

来源：改编自 Project Euler Problem 241

## 原题意

对正整数 n，定义 σ(n) 为 n 的所有约数之和。定义完全度商数 p(n) = σ(n)/n。
求所有满足 p(n) 可写成 k + 1/2（k 为整数）的正整数 n ≤ 10^18 的和。
原题答案: 482316491800239154。

## 题目

给定 N，求所有正整数 n ≤ N 的和，使得 σ(n)/n 为半整数（即分母为 2 的最简分数，形如 k + 1/2）。

## 数据范围

输入一个整数 N (1 ≤ N ≤ 10^12)，输出满足条件的 n 的和。

| 测试点 | N 范围 | 说明 |
|--------|--------|------|
| 1-2 | N ≤ 10^6 | 样例/小数据 |
| 3-5 | N ≤ 10^9 | 中等数据 |
| 6-8 | N ≤ 10^11 | 大数据 |
| 9-10 | N = 10^12 | 接近上界 |

## 算法

1. **数学分析**: σ(n)/n = (2k+1)/2 ⇔ 2σ(n) = n(2k+1)，故 n | 2σ(n) 且商为奇数。
   这等价于 n 的素因子分解满足特定形式：n = 2^a · m，其中 m 是奇完全数的某种推广。
   事实上，条件等价于 σ(n)/n 的分母（化简后）为 2。

2. **参数化枚举**: 满足条件的 n 必然具有形式 n = 2^a · p_1^{2e_1} · p_2^{2e_2} · ... 或特定结构。
   可通过枚举幂次搜索。

3. **剪枝**: 对每个部分积，若当前 σ(n)/n 已超过上限，则剪枝。
   使用递归生成所有可能的 n，维护 σ(n) 和 n 的值。

4. **降数据范围**: 原题 N = 10^18 需要高度优化的搜索。本题降为 N ≤ 10^12，
   可使用 DFS + 剪枝在合理时间内求解。
