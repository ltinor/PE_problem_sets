# 包含原点的三角形

来源：改编自 Project Euler Problem 184

## 原题意

求以原点为圆心、半径为 105 的圆内所有格点（整数坐标点）中，三个顶点构成的三角形包含原点在内部的数量。答案：1725323624056。

## 题目

多组测试数据。每组给定半径 R，求 I_R（圆内格点，不含原点）中顶点构成的三角形包含原点在内部的数量。

## 数据范围

- 2 ≤ R ≤ 105

## 算法

原点在三角形内部的充要条件：三个顶点不都在某个半圆内。

将所有格点按极角排序。总数 = C(N,3) - Σ_i C(c_i,2)，其中 c_i 是从点 i 出发、极角差 < π 范围内的点数。

排序 + 双指针 O(N log N)，N ≈ πR²。

## 改编方向

1. **参数化 R**：原题固定 R=105，改编后输入任意 R。
2. **暴力对拍**：小 R (≤ 6) 用三重循环枚举验证。
3. **大 R 直接计算**：R=105 时 N≈34600，O(N log N) 可行。
