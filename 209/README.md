# 209 — 圆环之理 (Circular Logic)

来源：改编自 Project Euler Problem 209

## 原题意

6 输入二元真值表 τ(a,b,c,d,e,f) 满足：
τ(a,b,c,d,e,f) AND τ(b,c,d,e,f, a XOR (b AND c)) = 0
对所有 6 位输入成立。求满足条件的真值表数量。

原题答案：15964587728784

## 题目

参数化输入位数 k（1 ≤ k ≤ 10）。定义变换：
T(a_0,...,a_{k-1}) = (a_1,...,a_{k-1}, a_0 XOR (a_1 AND a_2))
求满足 τ(s) AND τ(T(s)) = 0（对所有 s ∈ {0,1}^k）的 k 输入真值表 τ 的数量。

## 数据范围

- 1 ≤ k ≤ 7

## 算法

**std**: 变换 T 是 {0,1}^k 上的置换。约束条件等价于真值表中值为 1 的状态构成 T 的独立集。将 T 分解为若干不相交的环。对于长度为 L 的环，分配方案数为 F_{L-1} + F_{L+1}（Fibonacci 数）。答案为所有环的方案数之积。使用 `__int128` 存储大数。

**brute**: 枚举所有 2^(2^k) 种真值表（k ≤ 4），逐一验证。

## 改编方向

1. **参数化 k**：将固定 6 输入改为可变的 k 输入。
2. **置换分解**：利用 T 是置换的性质，分解为循环。
3. **Fibonacci 计数**：环上独立集计数与 Fibonacci 数的关系。
4. **PE 答案验证**：k=6 时输出 15964587728784。
