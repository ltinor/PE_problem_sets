# 圆环之理

## 题目描述

一个 k 输入二元真值表 τ 是从 k 个输入比特到 1 个输出比特的映射。

考虑变换 T，它将输入 (a_0, a_1, ..., a_{k-1}) 映射为：
T(a_0, a_1, ..., a_{k-1}) = (a_1, a_2, ..., a_{k-1}, a_0 XOR (a_1 AND a_2))

其中 XOR 表示异或，AND 表示与。

求有多少个 k 输入真值表 τ，使得以下等式对所有 2^k 个输入 s 都成立：
τ(s) AND τ(T(s)) = 0

---

## 输入格式

一行，一个整数 k（1 ≤ k ≤ 10）。

---

## 输出格式

一行，一个整数，表示满足条件的真值表数量。

---

## 样例

### 输入 1

```
1
```

### 输出 1

```
1
```

### 输入 2

```
2
```

### 输出 2

```
3
```

### 输入 3

```
6
```

### 输出 3

```
15964587728784
```

---

## 数据范围

- 1 ≤ k ≤ 7
- PE 答案：k=6 时输出 15964587728784
- 注：k ≥ 8 时答案超出 128 位整数范围，需使用高精度
