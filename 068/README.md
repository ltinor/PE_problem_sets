# Magic 5-gon Ring

来源：改编自 Project Euler Problem 68

## 原题意

将数字 1 到 10 填入一个五边形环中（外圈 5 个数、内圈 5 个数），每条线（外圈数 + 两个内圈数）之和相等。按规则从外圈最小的数开始顺时针连接数字，求能得到的最大 16 位数字串。

答案：6531031914842725。

## 题目

固定答案题。输入无实际意义（忽略），输出最大 16 位数字串。

## 数据范围

无。题目为固定答案。

## 算法

枚举数字 1~10 的所有排列（10! = 3,628,800），检查是否构成合法的五边形环（5 条线之和相等），找出其中能够形成 16 位数字串的最大值。

五边形环结构：外圈 5 个数 (a, b, c, d, e)，内圈 5 个数 (f, g, h, i, j)。
- 线1: a + f + g
- 线2: b + g + h
- 线3: c + h + i
- 线4: d + i + j
- 线5: e + j + f

要得到 16 位串，10 必须在外圈（否则会产生 17 位串）。

## 改编说明

原题直接输出固定数字串。改编为固定答案题（输入忽略），std 和 brute 使用两种独立方式枚举验证。
