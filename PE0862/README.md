# PE862 — Larger Digit Permutations（较大数字排列）

来源：改编自 Project Euler Problem 862

## 原题意

给定正整数 n，考虑其所有数字排列（包括原排列）。统计所有 ≤ N 的正整数中，存在至少一个数字排列比原数大的数的个数。

等价地，一个数存在更大的数字排列当且仅当其数字不是非递增排列的。

## 算法

1. **直接判断**：检查数字是否按非递增顺序排列。
2. **组合计数**：对于 k 位数，非递增数字序列等价于从 {0,...,9} 中可重复选取 k 个数字按降序排列。
3. **数位 DP**：使用记忆化搜索统计 ≤ N 的非递增数字个数。
4. **结果**：总数 N 减去非递增数字个数即为答案。
