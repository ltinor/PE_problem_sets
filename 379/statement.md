# 最小公倍数计数

## 题目描述

对于正整数 n，记 f(n) 为满足 x ≤ y 且 lcm(x, y) = n 的正整数对 (x, y) 的个数。
记 g(N) = Σ_{n=1}^N f(n)。

给定 N，求 g(N)。

---
## 输入格式

一个整数 N。

---
## 输出格式

g(N)。

---
## 样例

### 输入
```
10
```

### 输出
```
32
```

### 输入
```
1000000
```

### 输出
```
37429395
```

---
## 数据范围

- 对于 60% 的数据：N ≤ 1000
- 对于 100% 的数据：N ≤ 10^7 或特殊值
