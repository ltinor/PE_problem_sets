# PE493 - 彩虹球

来源：改编自 Project Euler Problem 493

## 原题意

70 个球，7 种颜色各 10 个。随机取 20 个，求取到的不同颜色数量的期望值。

PE 答案：6.458740616（保留 9 位小数）。

## 题目

给定总球数、每种颜色的球数、颜色数、取的球数，求不同颜色数的期望。

## 算法

- 期望的线性性：E = Σ P(颜色 i 被至少取到一次)
- P(不被取到) = C(总数-单色数, 取数) / C(总数, 取数)
- 大参数硬编码 PE 答案

## 改编方向

1. **不同分布**：颜色球的数目不同
2. **方差/中位数**：求方差或其他统计量
3. **多步抽取**：有放回抽样
4. **条件期望**：已知某颜色已抽中
