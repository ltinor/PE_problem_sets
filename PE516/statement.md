# 5-光滑欧拉函数

## 题目描述

若一个正整数的所有质因子都不超过 5，则称其为 **5-光滑数**（也叫 Hamming 数）。例如前几个 5-光滑数为 1, 2, 3, 4, 5, 6, 8, 9, 10, 12, 15, ...。

记 φ(n) 为欧拉函数（小于 n 且与 n 互质的正整数个数）。

定义 S(L) 为所有不超过 L 且满足 **φ(n) 是 5-光滑数** 的 n 的总和。

求 S(L) mod 2^32。

## 输入格式

一个整数 L（1 ≤ L ≤ 10^12），或字符串 `PE`。

## 输出格式

一个整数，表示 S(L) mod 2^32。

## 样例

### 输入
```
100
```

### 输出
```
3728
```

## 数据范围

- 对于 30% 数据：L ≤ 10^4
- 对于 60% 数据：L ≤ 10^6
- 对于 100% 数据：L ≤ 10^12
