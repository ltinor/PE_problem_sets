# 最优多项式

## 题目描述

给定一个 $N$ 阶多项式函数 $P(x) = 1 - x + x^2 - x^3 + \dots + (-1)^N x^N$，由其生成数列 $u_n = P(n)$。

对于 $k = 1, 2, \dots, N$，用数列的前 $k$ 项 $(u_1, u_2, \dots, u_k)$ 来拟合一个 $(k-1)$ 阶最优多项式，记该多项式在第 $n$ 项的值为 $\text{OP}(k, n)$。则第一个不正确项（FIT）为 $\text{OP}(k, k+1)$。计算所有坏最优多项式（BOP）的 FIT 之和。

---

## 输入格式

一行，一个整数 $N$。

---

## 输出格式

一行，一个整数，表示所有 $\text{FIT}_k$（$k = 1..N$）之和。

---

## 样例

### 输入
```
3
```

### 输出
```
-55
```

### 输入
```
10
```

### 输出
```
37076114526
```

---

## 数据范围

- $1 \le N \le 10$
