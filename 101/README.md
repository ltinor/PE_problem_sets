# 101 — Optimum Polynomial（最优多项式）

来源：改编自 Project Euler Problem 101

## 原题意

给定一个十阶多项式生成的数列 $u_n = 1-n+n^2-...+n^{10}$，对 $k=1..10$，用前 $k$ 项拟合 $(k-1)$ 阶多项式，计算其在位置 $k+1$ 的值（即第一个不正确项 FIT），求所有 FIT 之和。答案：37076114526。

## 题目

输入正整数 $N$（$1 \le N \le 10$），考虑 $N$ 阶多项式 $P(x) = \sum_{t=0}^{N} (-1)^t x^t$ 生成的数列 $u_n = P(n)$。对 $k=1..N$，用前 $k$ 项拟合 $(k-1)$ 阶最优多项式，计算第一个不正确项 $\text{FIT}_k = \text{OP}(k, k+1)$，求所有 $\text{FIT}_k$ 之和。

## 数据范围

- $1 \le N \le 10$

## 算法

拉格朗日插值公式化简。对于等距点 $x_i = i$ (i=1..k)，在 $x=k+1$ 处的拉格朗日基函数简化为 $l_j(k+1) = (-1)^{k-j} \cdot C(k, j-1)$，因此 $\text{FIT}_k = \sum_{j=1}^{k} (-1)^{k-j} \cdot C(k, j-1) \cdot u_j$。使用 `__int128` 避免中间溢出。时间复杂度 $O(N^2)$。

## 改编方向与取舍

### 改编方向
1. **参数化多项式阶数** → 支持 $N \le 10$（本题采用），可扩展至更大 $N$ 但需要高精度
2. **自定义系数** → 不限于交替符号 $(-1)^t$，允许输入任意系数
3. **多项式类型扩展** → 允许切比雪夫多项式、勒让德多项式等其他正交多项式基
4. **求单个 $\text{FIT}_k$** → 输入 $N$ 和 $k$，仅输出第 $k$ 个 BOP 的 FIT

### 取舍理由
- 选择参数化 $N$：最简单直观，保持原题核心算法（拉格朗日插值）不变
- 不选择自定义系数：会增加输入复杂度，且算法仍需大整数，改动不成比例
- 不选其他多项式基：算法本质相同，仅是 $u_j$ 计算方式不同
- $N$ 限制在 10：因为 $N > 10$ 时 $u_j$ 值超出 64 位，需要完整的大整数库
