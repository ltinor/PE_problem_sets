# 希尔伯特停电

## 题目描述

希尔伯特经营一座 n 层的大型旅馆。每层必须向恰好一个其他楼层供电（不能向自己供电）。发电机可放置在任意一层，电力沿供电方向流动。若发电机在某层时存在楼层无法获得电力，则发生停电。

希尔伯特希望通过最少的重新布线（改变某些楼层的供电目标），使得无论发电机放在哪一层，所有楼层都能获得电力。即：将供电关系图变为一个 n-环。

对于 n 层旅馆，考虑所有可能的初始布线方案（共 (n-1)ⁿ 种），记 F(n) 为所有方案所需最小改线数之和。

已知 F(3) = 6，F(8) = 16276736，F(100) mod 135707531 = 84326147。

给定 n，求 F(n) mod 135707531。

## 输入格式

一行，一个整数 n，或字符串 `PE`。

## 输出格式

一个整数，表示 F(n) mod 135707531。

## 样例

### 输入
```
3
```

### 输出
```
6
```

### 输入
```
8
```

### 输出
```
16276736
```

## 数据范围

- 对于 30% 数据：n ≤ 7
- 对于 60% 数据：n ≤ 100
- 对于 100% 数据：n ≤ 12344321
