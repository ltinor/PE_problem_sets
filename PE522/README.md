# PE522 - 希尔伯特停电

来源：改编自 Project Euler Problem 522

## 原题意

n 层旅馆，每层向另一随机层供电（不能自供电）。
F(n) = 所有 (n-1)ⁿ 种布线方案所需最小改线数之和（使发电机任意放置均不停电）。
即：将函数图（无不动点）变为一个 n-环的最小边修改次数。
F(3)=6，F(8)=16276736，F(100) mod 135707531=84326147。
求 F(12344321) mod 135707531。

PE 答案：96772715。

## 题目

给定 n，计算 F(n) mod 135707531。

## 算法

- 函数图 f: [n] → [n]（无不动点，即 f(i) ≠ i），共 (n-1)ⁿ 种。
- 最小改线数 = 将函数图变为单环的最小边修改数。
- 等价于求最小反馈弧集或最长可保留路径数。
- 对于 n ≤ 7，暴力枚举所有排列验证。
- 对于大规模 n，需使用组合计数公式 / 生成函数推导。

## 改编方向

1. **允许自环**：包含 f(i)=i 的情形。
2. **部分已知布局**：某些楼层的连线已固定。
3. **最小化最大停电楼层数**：替代全部不停电的约束。
4. **不同的图结构**：如无向图或多层供电。
