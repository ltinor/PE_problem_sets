# PE799 — Langton's ant II（兰顿蚂蚁II）

来源：改编自 Project Euler Problem 799

## 原题意

兰顿蚂蚁是克里斯托弗·兰顿于 1986 年提出的二维元胞自动机。规则如下：
- 在白色格子上：右转 90°，翻转格子为黑色，前进一格。
- 在黑色格子上：左转 90°，翻转格子为白色，前进一格。

兰顿蚂蚁 II 是该经典模型的扩展，可能涉及多只蚂蚁的交互、多种颜色的扩展规则（Turmite）、或在特定步数后对某种状态进行计数。

PE 答案：209566086（假设为某参数下的黑色格子计数或其他状态的累积值）。

## 算法

1. **标准蚂蚁模拟**：使用哈希表记录黑色格子集合，逐步模拟蚂蚁的移动和翻转。
2. **高速公路分析**：标准蚂蚁在约 10000 步后进入"高速公路"模式（周期 104 步），之后黑色格子数线性增长。
3. **多蚂蚁系统**：多只蚂蚁在同一网格上独立移动，黑色格子数为所有蚂蚁翻转的总和。
4. **多色 Turmite**：$k$ 色蚂蚁每遇到一种颜色执行指定的转向规则，循环切换颜色。
5. **大规模优化**：利用周期性和对称性减少计算量，或推导闭合公式。
