# 大富翁几率

## 题目描述

大富翁游戏的标准棋盘有 $40$ 个方格，从起点 GO（编号 $00$）出发，按顺时针方向依次编号为 $00$ 到 $39$。

玩家掷两个 $S$ 面骰子（点数范围 $1 \sim S$），将两个点数相加作为本轮前进的步数。但以下规则会改变玩家停留的位置：

- **G2J（直接入狱）**：若落在第 $30$ 格（G2J），直接移动到第 $10$ 格（JAIL）。
- **连续对子入狱**：若连续三次掷出两个相同点数，第三次时直接入狱（移动到 JAIL）。
- **宝箱卡（CC）**：落在 CC 格（编号 $2, 17, 33$）时，从宝箱卡堆顶抽一张卡。$16$ 张卡中仅有 $2$ 张会引起移动：一张去 GO（$00$），一张去 JAIL（$10$）。其余卡无效果，停留在原地。
- **机会卡（CH）**：落在 CH 格（编号 $7, 22, 36$）时，从机会卡堆顶抽一张卡。$16$ 张卡中有 $10$ 张会引起移动：
  - 去 GO（$00$）
  - 去 JAIL（$10$）
  - 去 C1（$11$）
  - 去 E3（$24$）
  - 去 H2（$39$）
  - 去 R1（$5$）
  - 去下一个铁路公司 R（$2$ 张）
  - 去下一个公共事业公司 U（$1$ 张）
  - 后退 $3$ 格

特别地，若机会卡"后退三步"后落在 CC 格上，需要再抽取一张宝箱卡并执行其效果。卡牌使用后放回牌堆底部，牌堆初始为随机打乱状态。

你的任务是：给定骰子面数 $S$，模拟足够多次掷骰子后，找出访问概率最高的三个方格，将它们的两位数编号按概率从高到低拼接成一个六位数字串并输出。若概率相同，则按编号从小到大排序。

---

## 输入格式

一行一个整数 $S$，表示骰子面数。

---

## 输出格式

一行一个六位数字串，表示概率最高的三个方格的编号拼接。

---

## 样例

### 输入
```
4
```

### 输出
```
101524
```

**解释**：使用两个 $4$ 面骰子时，最热门的三个方格依次是 JAIL（$10$）、E3（$24$）、GO（$00$）。

---

## 数据范围

$4 \le S \le 6$
