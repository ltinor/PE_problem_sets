# 能被巨大整数整除的阶乘

## 题目描述

记 $N(i)$ 是使得 $n!$ 能被 $(i!)^K$ 整除的最小正整数 $n$。

记 $S(U) = \sum_{i=10}^{U} N(i)$。

给定 $U$ 和 $K$，求 $S(U) \bmod 10^{18}$。

---

## 输入格式

一行两个整数 $U$ 和 $K$。

---

## 输出格式

一行一个整数，表示 $S(U) \bmod 10^{18}$ 的值。

---

## 样例

### 输入

```
10 1
```

### 输出

```
10
```

### 输入

```
1000 1234567890
```

### 输出

```
614538266565663
```

### 输入

```
1000000 1234567890
```

### 输出

```
2781579195314827256
```

---

## 数据范围

- $10 \le U \le 10^6$
- $1 \le K \le 10^9$
