原题及更多讨论见 [https://projecteuler.net/problem=407](https://projecteuler.net/problem=407)。

对于0 ≤ a ≤ 5，分别计算a<sup>2</sup> mod 6，我们得到： 0,1,4,3,4,1。

使得a<sup>2</sup> ≡ a mod 6的最大a值为4。
我们用M(n)表示使得a<sup>2</sup> ≡ a (mod n)的最大的a &lt; n。
因此M(6) = 4。

对于1 ≤ n ≤ 10<sup>7</sup>，求∑M(n)。
