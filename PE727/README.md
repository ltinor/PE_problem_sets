# PE727 — Triangle of Circular Sectors (圆扇三角形)

来源：改编自 Project Euler Problem 727

## 原题意

给定一个三角形（通常为等边三角形），以各顶点为圆心、以对边为半径画圆弧。
三条弧在三角形内部围成一个曲边区域（Reuleaux 三角形相关）。
求该区域面积的某种度量。

## 算法

1. **扇形面积**：sector = 1/2 * r² * θ，其中 θ 为圆心角。
2. **重叠计算**：三个扇形两两相交，三者的公共区域面积通过
   容斥原理计算：A ∩ B ∩ C = Σ sectors - Σ pairs + triple。
3. **等边三角形**：每个扇形圆心角为 π/3（60 度），
   三扇形交面积 = 3 * sector - 2 * triangle。
4. **一般三角形**：根据三角形的边角关系计算各个扇形的实际重叠。
5. **数值积分**：对于复杂形状，可用 Monte Carlo 方法求面积。

## 改编方向

1. 任意三角形的扇形交面积
2. 扇形半径为可变参数（不一定等于对边）
3. 求恰好落在 k 个扇形内的概率
4. 多个圆心（非三角形顶点）的扇形重叠
5. 三维推广（球扇形）
