# 红色、绿色和蓝色的地砖

## 题目描述

使用以下四种方块铺满长度为 N 的一行：
- **黑色方块**：长度为 1
- **红色方块**：长度为 2
- **绿色方块**：长度为 3
- **蓝色方块**：长度为 4

方块可以以任意顺序排列，求总共有多少种不同的铺法。

例如 N = 5 时有 15 种不同的铺法。

---

## 输入格式

一行，一个整数 N。

---

## 输出格式

一行，一个整数，表示答案。

---

## 样例

### 输入
```
5
```

### 输出
```
15
```

### 输入
```
50
```

### 输出
```
100808458960497
```

---

## 数据范围

- 1 ≤ N ≤ 50
