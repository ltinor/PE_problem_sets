# PE805 — Shifted Multiples（平移倍数）

来源：改编自 Project Euler Problem 805

## 原题意

对于一个正整数 s，将其十进制表示的最后一位数字移到最前面（循环右移），得到新的数字 M。如果 M 是 s 的整数倍（即 M = k·s，k > 1），则称 s 具有"平移倍数"性质。

例如：s = 142857，右移后得 714285 = 5 × 142857。

求所有不超过某个上界的具有此性质的整数 s 之和。

PE 答案：7007143846988468270。

## 算法

1. **数学模型**：设 s 的十进制表示为 dₙ...d₁d₀（d₀ 为末位），右移后为 d₀dₙ...d₁。
   - 等式：k·s = (s - d₀)/10 + d₀·10ⁿ，其中 n 为数字位数
   - 化简得：s = d₀·(10ⁿ⁺¹ - 1) / (10k - 1)
2. **除数条件**：要求 (10k - 1) 整除 d₀·(10ⁿ⁺¹ - 1)。
3. **枚举参数**：d₀ ∈ {1..9}，k ∈ {2..9}，n 从 1 开始增加到 s 超过上界。
4. **模运算**：利用模逆元和阶的计算加速大 n 的判定。

## 改编方向

1. 左移变体（首位数字移到末尾）
2. 多位移位（移 2 位或更多）
3. 基数为非十进制（二进制、十六进制等）
4. 要求移动后的数字是原数的平方或立方
5. 多个不同移位都产生倍数
