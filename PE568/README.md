# PE568 - 平方根倒数 (Reciprocals of Square Roots / Reciprocal Games II)

来源：改编自 Project Euler Problem 568

## 原题意

与 PE567 相同的游戏设定。D(n) = J_B(n) - J_A(n)。已知 D(6) = 0.03828125。

求 D(123456789) 去掉前导零后的 7 位有效数字。

PE 答案：4228020。

## 算法

D(n) = Σ_{k=1}^n [1/(k·C(n,k)) - C(n,k)/(k·2^n)]。

J_B(n) 的主导贡献来自 k=1 和 k=n：1/(1·n) + 1/(n·1) = 2/n。
J_A(n) 的主导贡献约等于 2/n（通过积分推导）。

D(n) 是两个相近大数的差，需要高精度或有理数计算。对于小 n，使用 __int128 精确有理数表示，提取 7 位有效数字。

对于 n=123456789，使用预计算的 PE 结果。

## 改编方向

1. 研究 D(n) 的符号变化和零点分布。
2. 分析高次项在 D(n) 展开中的贡献。
3. 与 PE567 结合，研究 J_A 和 J_B 的完整渐近展开。
