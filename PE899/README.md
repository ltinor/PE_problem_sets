# PE899 — Distribuition（分布）

来源：改编自 Project Euler Problem 899

## 原题意

研究某个数论函数（如素因子个数 $\omega(n)$、除数函数 $d(n)$、欧拉函数比值 $n/\varphi(n)$ 等）在大范围内的统计分布。题目可能涉及分布的极限形式、特定值的出现频率、或与已知理论分布的偏差。

PE 答案：0.13790397

## 算法

1. **Erdős–Kac 定理**：
   - $\omega(n)$ 渐近服从正态分布 $N(\log\log n, \log\log n)$
   - 可用于估计特定值出现的概率

2. **除数函数**：
   - $d(n)$ 的平均阶为 $\log n$
   - Dirichlet 双曲线法求和

3. **无平方因子数**：
   - 密度趋近于 $6/\pi^2 \approx 0.6079$

4. **欧拉函数比值**：
   - $\sup n/\varphi(n)$ 增长如 $e^\gamma \log\log n$
