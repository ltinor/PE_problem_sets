# 分布（Distribuition）

## 题目描述

对于正整数 $n$，定义 $\omega(n)$ 为 $n$ 的不同素因子的个数。例如 $\omega(12) = \omega(2^2 \times 3) = 2$。

对于给定的 $N$，计算满足 $\omega(n) = k$ 的正整数 $n \le N$ 的数量。令 $N \to \infty$，求 $k = \lfloor \log\log N \rfloor$ 时该比例趋近的极限值。

## 输入格式

无输入（固定参数问题）。

## 输出格式

输出一个浮点数，表示极限比例，保留 8 位小数。

## 样例

（无样例输入输出，直接计算并输出最终答案。）
