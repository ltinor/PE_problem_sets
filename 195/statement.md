# 60 度三角形

## 题目描述

我们称恰好有一个角为 60 度的整数边长三角形为 60 度三角形。

记 r 为这个 60 度三角形的内切圆半径。记 T(n) 为满足 r ≤ n 的 60 度三角形的个数。

已知：
- T(100) = 1234
- T(1000) = 22767
- T(10000) = 359912

给定整数 N，求 T(N)。

---

## 输入格式

一行一个整数 N (1 ≤ N ≤ 1053779)。

---

## 输出格式

一行一个整数，表示 T(N)。

---

## 样例

### 输入

```
100
```

### 输出

```
1234
```

### 输入

```
1000
```

### 输出

```
22767
```

### 输入

```
1053779
```

### 输出

```
75085391
```

---

## 数据范围

- 1 ≤ N ≤ 1053779
