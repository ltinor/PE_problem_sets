# 195 — 60-degree Triangles

来源：改编自 Project Euler Problem 195

## 原题意

求 T(1053779)，即内切圆半径 ≤ 1053779 的 60 度三角形个数。原题答案：75085391。

## 题目

参数化 N：输入 N（≤ 1053779），求 T(N)。

## 数据范围

- N ≤ 1053779

## 算法

**std**: 使用 60° 三角形的参数化：
- 边长满足 a² − ab + b² = c²（余弦定理，60° 在 a 和 b 之间）
- 原始解参数化：a = m² − n², b = 2mn − n², c = m² − mn + n² (m > 2n, gcd(m,n)=1, (m−n)%3≠0)
- 内切圆半径 r = √3·ab/(2(a+b+c))
- 对每个原始解，计数 floor(N/r)（使用 __int128 二分搜索避免浮点精度问题）
- 枚举 (m,n) 直到 r > N

**brute**: 直接枚举 a, b ≤ 3.5N，检查 c² = a² + b² − ab 和 r ≤ N。适用于 N ≤ 200。

## 改编方向

1. **参数化 N**：将原题固定 N=1053779 改为输入参数。
2. **小范围验证**：N ≤ 200 可用 brute 对拍。
3. **已知验证点**：T(100)=1234, T(1000)=22767, T(10000)=359912。
