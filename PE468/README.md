# PE468 - 二项式系数的光滑因数 (Smooth divisors of binomial coefficients)

来源：改编自 Project Euler Problem 468

## 原题意

一个正整数是 B-光滑的，当其所有质因数都不大于 B。

记 S_B(n) 为 n 的最大 B-光滑因数。

例如：S_1(10)=1, S_4(2100)=12, S_17(2496144)=5712。

F(n) = Σ_{1≤B≤n} Σ_{0≤r≤n} S_B(C(n,r))，其中 C(n,r) 是二项式系数。

验证：F(11)=3132, F(1111) mod 10^9+993=706036312。

原题求 F(11111111) mod 10^9+993 = 852950321297。

## 题目

给定 n，求 F(n) mod 1,000,000,993。

## 算法

- S_B(C(n,r)) = ∏_{p≤B} p^{v_p(C(n,r))}
- 使用 Legendre 公式计算 v_p(C(n,r))
- 对每个 r 和 B 直接计算贡献（小数据）
- 中等数据：按质数排序，分段累加贡献
- 大数据需要更高级的数论技巧（如生成函数）

## 改编方向

1. **固定 r**：求 Σ_B S_B(C(n,r)) 的通项
2. **光滑数计数**：直接求满足某性质的光滑数个数
3. **模不同质数**：使用不同的模数
