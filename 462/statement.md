## 原题描述

原题及更多讨论见 [https://projecteuler.net/problem=462](https://projecteuler.net/problem=462)。

**3-光滑数**是指所含质因数不大于3的整数。对于整数N，我们定义S(N)是所有小于等于N的3-光滑数所构成的集合，例如，S(20) = { 1, 2, 3, 4, 6, 8, 9, 12, 16, 18 }。

对集合S(N)的元素进行排列使得每个元素都排在其所有真因数之后，记这样的重排数为F(N)。

如下是N = 20时一个有效的重排。
1, 2, 4, 3, 9, 8, 16, 6, 18, 12.
如下不是一个有效的重排，因为12排在其真因数6之前。
1, 2, 4, 3, 9, 8, **12**, 16, **6**, 18.

可以验证F(6) = 5，F(8) = 9，F(20) = 450，以及F(1000) ≈ 8.8521816557e21。
求F(10<sup>18</sup>)，并用保留10位小数的科学计数法表示。
用小写字母e分割尾数和指数，例如，如果答案是112,233,445,566,778,899，则应写成1.1223344557e17。
