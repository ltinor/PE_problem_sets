# 210 — 钝角三角形 (Obtuse Angled Triangles)

来源：改编自 Project Euler Problem 210

## 原题意

点集 S(r) = {(x,y) ∈ Z² : |x|+|y| ≤ r}，O=(0,0)，C=(r/4,r/4)。
N(r) 为 S(r) 中使三角形 OBC 有钝角的点 B 的数目。
求 N(1,000,000,000)。

原题答案：1598174770174689458（待验证）

## 题目

参数化 r。给定 r，求 N(r)。

## 数据范围

- 1 ≤ r ≤ 200000（OJ 测试数据）
- 原题 r = 10^9（PE 验证用）

## 算法

**std**: 扫描 x 坐标，对每个 x 计算合适的 y 范围。钝角条件分三种情况：
1. x + y < 0（O 处钝角）
2. x² + y² - (r/4)(x+y) < 0（B 处钝角）
3. x + y > r/2（C 处钝角）
使用区间算术对每个 x 计算满足条件的 y 数量。时间复杂度 O(r)。

**brute**: 枚举 S(r) 中所有点，用点积判断钝角（r ≤ 100）。

## 改编方向

1. **参数化 r**：将固定 r=10^9 改为可变输入。
2. **扫线法**：逐 x 扫描，用解析公式计算 y 范围。
3. **区域分解**：将菱形 S(r) 分为不同区域分别计数。
4. **PE 答案验证**：r=4 输出 24，r=8 输出 100。
