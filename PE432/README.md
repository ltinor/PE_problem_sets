# PE432 - 欧拉函数和

来源：改编自 Project Euler Problem 432

## 原题意

S(n,m) = Σ_{i=1}^{m} φ(n × i)，其中 φ 为欧拉函数。
已知 S(510510, 10^6) = 45480596821125120。
原题求 S(510510, 10^11) 的最后 9 位数字，答案为 754862080。

## 题目

给定 n 和 m，求 S(n,m) = Σ_{i=1}^{m} φ(n × i)。

## 算法

- 欧拉函数 φ(k) = k · Π_{p|k} (1-1/p)
- 对于小规模数据，使用线性筛计算所有 φ 值
- 对于 n = 510510（前 7 个素数之积），利用 φ(ab) = φ(a)·φ(b)·gcd(a,b)/φ(gcd(a,b))
- 按 gcd(n,i) 分组求和，利用积性函数性质
- 大 m 时使用 Dirichlet 卷积加速

## 改编方向

1. **不同 n**：替换 n 为其他 primorial
2. **加权和**：Σ i^k · φ(n×i)
3. **区间和**：Σ_{i=L}^{R} φ(n×i)
4. **多查询**：Q 组 (n,m) 在线回答
