# 素数对集合

## 题目描述

素数 3、7、109 和 673 是非常特别的一组素数。任取其中的两个素数，以任意顺序拼接起来，其结果仍然是素数。例如，7 和 109 拼接得到 7109 和 1097，均为素数。这四个素数的和是 792，是满足该性质的一组四个素数的最小和。

现在将问题一般化：给定整数 K，找出 K 个素数，使得其中任意两个以任意顺序拼接后仍为素数。求满足条件的 K 个素数的最小和。

---

## 输入格式

一行一个整数 K（2 ≤ K ≤ 5）。

---

## 输出格式

一行一个整数，表示满足条件的 K 个素数的最小和。

---

## 样例

### 输入

```
5
```

### 输出

```
26033
```

---

## 数据范围

- 2 ≤ K ≤ 5
- 素数上限约 10000
