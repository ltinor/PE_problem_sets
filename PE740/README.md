# PE740 — Secret Santa (秘密圣诞老人)

来源：改编自 Project Euler Problem 740

## 原题意

$n$ 个人参加秘密圣诞老人（Secret Santa）游戏。每人从写有所有人名字的帽子中随机抽取一个名字。如果有人抽到自己的名字，所有人将名字放回帽子并重新开始。重复直到得到一个有效的分配（即每个人分给的人不是自己）。

在所有有效的分配（错位排列，derangements）等概率的前提下，求分配恰好形成一个循环（即所有人串成一个环）的概率。特别地，考虑 $n \to \infty$ 时的渐近行为或某个特定 $n$ 下的精确概率。

PE 答案：0.01887408（保留 8 位小数）。

## 算法

1. **错位排列计数**：$n$ 个元素的错位排列数（subfactorial）为：
   $$!n = n! \sum_{k=0}^{n} \frac{(-1)^k}{k!} \approx \frac{n!}{e}$$

2. **单循环计数**：构成一个完整 $n$-循环的排列数为 $(n-1)!$。

3. **概率计算**：
   $$P(\text{单循环} \mid \text{无不动点}) = \frac{(n-1)!}{!n}$$

4. **渐近公式**：对于大 $n$：
   $$P \approx \frac{(n-1)!}{n!/e} = \frac{e}{n}$$
   精确值需考虑 $!n = \lfloor n!/e + 1/2 \rfloor$ 的舍入。

5. **复杂度**：$O(n)$（递推计算错位排列数）。
