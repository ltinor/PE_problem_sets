# 凹三角形

## 题目描述

在一个圆外作外接正方形，称蓝色阴影区域（正方形去掉圆的部分）为 L 型块。从正方形左下角向右上角画一条直线，称橙色阴影区域为凹三角形。

将 n 个圆水平并排摆放，作一个外接长方形，并从左下角向右上角画一条直线。

已知：
- n = 1 时，凹三角形面积恰好是 L 型块的一半（50%）。
- n = 2 时，凹三角形面积约为 L 型块的 36.46%。
- n = 15 时，凹三角形面积少于 L 型块的 10%。

求使得凹三角形面积少于 L 型块的 0.1% 的最小的 n 值。

## 输入格式

一行，一个整数 n（或字符串 `PE`，或 `test`）。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案（最小的 n 值）：2240。
若输入为 `test`，输出已知的比值信息。
若输入为整数 n，输出该 n 对应的凹三角形面积占比。

## 样例

### 输入
```
PE
```

### 输出
```
2240
```

### 输入
```
test
```

### 输出
```
Known ratios:
n=1: 50.000000%
n=2: 36.460000%
n=15: <10.000000%
Answer (n for <0.1%): 2240
```

## 数据范围

- n ≤ 10000（测试模式）或输入为 PE
