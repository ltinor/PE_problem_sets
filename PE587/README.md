# PE587 — 凹三角形 (Concave Triangle)

来源：改编自 Project Euler Problem 587

## 原题意

在一个圆外作外接正方形，称蓝色阴影区域（正方形去掉圆的部分）为 L 型块。从正方形左下角向右上角画一条直线，称橙色阴影区域为凹三角形。

将 n 个圆水平并排摆放，作一个外接长方形，并从左下角向右上角画一条直线。

已知：
- n = 1 时，凹三角形面积恰好是 L 型块的一半（50%）。
- n = 2 时，凹三角形面积约为 L 型块的 36.46%。
- n = 15 时，凹三角形面积少于 L 型块的 10%。

求使得凹三角形面积少于 L 型块的 0.1% 的最小的 n 值。

PE 答案：2240。

## 算法

设圆半径 r = 1，则第 i 个圆心坐标为 (2i+1, 1)，长方形为 [0, 2n] × [0, 2]。

L 型块面积 = 长方形面积 - n × 圆面积 = 4n - nπ。

对角线从 (0,0) 到 (2n, 2)，方程为 y = x/n。

凹三角形是 L 型块中位于对角线下方且与左下角连通的区域。对于 n > 1，该区域由对角线和各圆的下半弧共同界定。

面积比 r(n) = 凹三角形面积 / L 型块面积随 n 增大而递减。对 n = 2240，r(n) < 0.001（0.1%）。可通过二分搜索结合数值积分求解。

## 改编方向

1. 计算不同 n 对应的精确面积比，研究 r(n) 的渐近行为（与 1/n 的关系）。
2. 改为圆形竖直排列或网格排列。
3. 研究对角线不同方向（如从左上到右下）对面积比的影响。
4. 推广到三维（球体 + 立方体）。
