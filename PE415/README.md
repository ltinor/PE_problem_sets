# PE415 - 泰坦尼克集

来源：改编自 Project Euler Problem 415

## 原题意

泰坦尼克集：存在一条直线恰好穿过集合中的两个点。T(N) 统计 [0,N]×[0,N] 范围内的所有泰坦尼克集数量。原题求 T(10^11) mod 10^8，答案为 55859775。

## 题目

给定 N，求 T(N) mod 10^8。

## 算法

- 枚举所有子集：总共有 2^((N+1)²) 个子集
- 对每个子集，检查所有点对：若某对点确定的直线上恰好有 2 个点属于该子集，则为泰坦尼克集
- 小 N（N ≤ 3）可用位掩码枚举；大 N 需要组合数学方法

## 改编方向

1. **改变网格形状**：使用三角形或六边形网格替代正方形网格
2. **改变点集约束**：求"反泰坦尼克集"的数量（不存在恰好穿过 2 点的直线）
3. **求最大泰坦尼克集**：对于给定的 N，求最大可能的泰坦尼克集的大小
4. **改变维度**：在三维格点空间中定义泰坦尼克集
