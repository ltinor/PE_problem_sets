# 124 — 有序根积

来源：改编自 Project Euler Problem 124

## 原题意

对于 n ≤ 100000，按 rad(n)（n 的不同质因子之积）排序后，求第 10000 个 n。答案：21417。

## 题目

多组输入，每组给定 N 和 K，求 n ≤ N 按 rad(n) 升序排列（rad 相同时按 n 升序）后的第 K 个 n。

## 数据范围

- 1 ≤ K ≤ N ≤ 100000
- 多组测试，T ≤ 100

## 算法

使用埃氏筛法预处理 rad(n)：初始 rad[i]=1，对每个质数 i，将 rad[j] 累乘 i（j 为 i 的倍数）。得到 (rad, n) 对后排序取第 K 个。预处理 O(N log log N)，排序 O(N log N)，查询 O(1)。单次 N=100000 在 10ms 内完成。

rad(1)=1（无质因子）。

验证：N=100000, K=10000 → n=21417。

## 改编方向与取舍

### 改编方向
1. **参数化 N,K** → 多组查询（本题采用）
2. **单点 rad 查询** → 输入 n 求 rad(n)
3. **大范围 N** → N ≤ 10^7，需线性筛
4. **区间统计** → 查询 rad 在某范围内的 n 个数

### 取舍理由
- 选择多组查询：增加灵活性，N=100000 包含原题
- 筛法预处理：比逐个数质因数分解快得多
- sort 排序：O(N log N) 在 N=100000 时完全可行
