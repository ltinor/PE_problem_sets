# 无平方因子数

## 题目描述

若正整数 n 不能被任意素数的平方整除，则 n 被称为无平方因子数。

给定整数 K (1 ≤ K ≤ 50)，求小于 2^K 的无平方因子数的个数。

例如：
- K=1: 小于 2 的数只有 1，是 squarefree，答案为 1。
- K=2: 小于 4 的数：1, 2, 3，都是 squarefree，答案为 3。
- K=3: 小于 8 的数：1,2,3,5,6,7（排除 4），答案为 6。

---

## 输入格式

一行一个整数 K (1 ≤ K ≤ 50)。

---

## 输出格式

一行一个整数，表示小于 2^K 的无平方因子数的个数。

---

## 样例

### 输入

```
2
```

### 输出

```
3
```

### 输入

```
50
```

### 输出

```
684465067343069
```

---

## 数据范围

- 1 ≤ K ≤ 50
