# PE890 — Clock II（时钟II）

来源：改编自 Project Euler Problem 890

## 原题意

在基本时钟问题的基础上扩展。标准时钟问题涉及时针和分针之间的角度关系（重合、垂直、反向等）。Clock II 可能引入以下扩展：
- 秒针的加入（三针问题）
- 非标准刻度（如 24 小时制、10 小时制）
- 多个时钟的比较
- 连续时间（非分钟级离散）的处理

## 算法

1. **角度计算**：
   - 时针：$0.5°$/分（$360°$ / 12 小时 / 60 分）
   - 分针：$6°$/分（$360°$ / 60 分）
   - 秒针：$6°$/秒（$360°$ / 60 秒）

2. **相对运动**：
   - 分针相对时针：$5.5°$/分
   - 重合周期：$720/11 \approx 65.4545$ 分钟

3. **计数问题**：
   - 在特定时间段内满足角度条件的时刻计数
   - 可离散化到分钟或秒级精度

## 改编方向

1. 三针共线或对称分布的时刻
2. 连续时间积分（角度函数的定积分）
3. 非均匀刻度时钟
4. 多个时钟同步问题
