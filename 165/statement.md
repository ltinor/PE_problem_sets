# 交点

## 题目描述

一条线段由其两个端点唯一确定。当两条线段恰好有一个交点且该交点不是任一线段的端点时，称该交点为真交点。

使用 BBS 伪随机数生成器：

- s₀ = 290797
- s_{n+1} = s_n² mod 50515093
- t_n = s_n mod 500

用 t_n 的连续四项 (t₁,t₂) 到 (t₃,t₄) 作为第一条线段，依此类推生成 N 条线段。求这些线段中不同真交点的个数。

## 输入格式

一行一个整数 N。

## 输出格式

一行一个整数，表示不同真交点的个数。

---

## 样例

### 输入
```
3
```

### 输出
```
1
```

### 输入
```
10
```

### 输出
```
14
```

---

## 数据范围

- 1 ≤ N ≤ 5000

---

## 提示

PE 原题 N=5000 时答案为 2868868。
