# 165 — 交点

来源：改编自 Project Euler Problem 165

## 原题意

使用 BBS 伪随机数生成器生成 5000 条线段，求其中真交点的个数。原题答案：2868868。

## 题目

参数化 N：输入 N (≤ 5000)，用 BBS 生成 N 条线段，求真交点数。

## 数据范围

- 1 ≤ N ≤ 5000

## 算法

**std**: BBS 生成线段 + O(N²) 交点检测。用叉积判断两线段是否严格内部相交（cross products 异号），用分数精确坐标 + `set` 判重。时间复杂度 O(N² log N)。

**brute**: 同算法验证（小 N 时可快速测试）。

## 改编方向

1. **参数化 N**：将固定 N=5000 改为输入参数。
2. **精确几何**：分数坐标 + 约分避免浮点误差。
3. **PE 答案验证**：(N=5000) 输出 2868868。
