# PE441 - 互质数对的倒数和

来源：改编自 Project Euler Problem 441

## 原题意

对于整数 M，定义 R(M) 为所有满足以下条件的整数对 (p,q) 的 1/(p·q) 之和：
- 1 ≤ p < q ≤ M
- p + q ≥ M
- p 和 q 互质

定义 S(N) 为 R(i) 对 2 ≤ i ≤ N 的和。原题求 S(10^7)，四舍五入保留 4 位小数，答案为 5000088.8395。

## 题目

给定整数 N，求 S(N)，结果保留 4 位小数。

## 算法

- 使用 Möbius 反演消除互质约束：R(M) = Σ μ(d)/d² · G(⌊M/d⌋)
- 其中 G(X) = Σ_{1≤p<q≤X, p+q≥X} 1/(p·q)（无互质限制）
- G(X) 可利用调和数前缀和在 O(X) 时间内计算
- 调和数预计算 + Möbius 函数线性筛

## 改编方向

1. **改变约束条件**：p+q≥M 改为 p+q≤M 或任意不等式
2. **改变互质条件**：改为 gcd(p,q)=k 或 gcd(p,q)>1
3. **三重求和**：扩展到 p<q<r 的三元组求和
4. **模后缀**：要求输出乘以分母 LCM 后的整数结果
