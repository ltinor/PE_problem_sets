# 互质数对的倒数和

## 题目描述

对于整数 M，定义 R(M) 为所有满足以下条件的整数对 (p, q) 的 1/(p·q) 之和：

- 1 ≤ p < q ≤ M
- p + q ≥ M
- p 和 q 互质（即 gcd(p, q) = 1）

定义 S(N) = Σ_{i=2}^{N} R(i)，即 R(2) 到 R(N) 的和。

例如：S(2) = R(2) = 1/2，S(10) ≈ 6.9147，S(100) ≈ 58.2962。

给定 N，计算 S(N)，结果四舍五入保留 4 位小数。

---

## 输入格式

一个整数 N (2 ≤ N ≤ 200)。

---

## 输出格式

一个浮点数，表示 S(N)，精确到小数点后 4 位。

---

## 样例

### 输入
```
10
```

### 输出
```
6.9147
```

---

## 数据范围

- 对于 30% 数据：N ≤ 20
- 对于 60% 数据：N ≤ 100
- 对于 100% 数据：N ≤ 200
