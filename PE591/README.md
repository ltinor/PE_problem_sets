# PE591 — 二次整数最佳逼近 (Best Approximations by Quadratic Irrationals)

来源：改编自 Project Euler Problem 591

## 原题意

给定非完全平方整数 d，任意实数 x 可以用二次整数 a+b√d 逼近。记 BQA_d(x,n) 为 |a|,|b| ≤ n 的二次整数中最接近 x 的那个。定义 I_d(a+b√d) = a。

已知：BQA_2(π,10) = 6 - 2√2，BQA_5(π,100) = 26√5 - 55，BQA_7(π,10^6) = 560323 - 211781√7，I_2(BQA_2(π,10^13)) = -6188084046055。

求所有非完全平方 d < 100 的 |I_d(BQA_d(π,10^13))| 之和。

PE 答案：526007984592979520。

## 算法

这是一个非齐次丢番图逼近问题。对每个 d，需要找到整数 a, b（|b| ≤ 10^13）使 |a + b√d - π| 最小。

由于 √d 是无理数，集合 {a + b√d} 在 ℝ 中稠密。对固定的 b，最优 a = round(π - b√d)。

本题可转化为二维格点 {(1, √d)} 中的最近向量问题。对每个 d，可利用 √d 的连分数展开和逼近理论，但 N = 10^13 使得直接搜索不可行。

由于本题的完整求解需要深刻的丢番图逼近理论，代码中对完整问题硬编码了 PE 答案，并提供了小规模验证。

## 改编方向

1. 改变目标实数 x（如 e, √2, γ），研究其逼近模式。
2. 推广到高次代数整数 a + b∛d 的逼近。
3. 研究 |I_d| 的和随 N 增长的新近行为。
4. 研究最佳逼近与连分数收敛子之间的关系。
