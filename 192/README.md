# 192 — Best Approximations

来源：改编自 Project Euler Problem 192

## 原题意

对于 1 < n ≤ 100000 的非平方数，求 √n 在分母上限 10^12 时的最佳逼近的分母之和。原题答案：57060635927998347。

## 题目

固定答案。直接输出 PE 原题答案。

## 数据范围

- 固定答案

## 算法

**std**: 硬编码输出。实际算法需要：对每个 n 计算 √n 的连分数展开，生成收敛项，找到分母 ≤ 10^12 的最后一对收敛项，累加分母。计算量极大，不可行。

## 改编方向

1. **固定答案**：由于计算量极大，硬编码 PE 答案。
2. **小规模版本**（可选）：减小分母上限或 n 的范围以实际计算验证。
