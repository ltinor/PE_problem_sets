# 最佳逼近分母和

## 题目描述

对于每个满足 1 < n ≤ 100000 的非完全平方数 n，求 √n 在分母上限为 10^12 时的最佳逼近的分母，并求所有这些分母之和。

---

## 输入格式

一行一个整数（占位，无实际意义）。

---

## 输出格式

一行一个整数，表示所有分母之和。

---

## 样例

### 输入

```
0
```

### 输出

```
57060635927998347
```

---

## 数据范围

- 固定答案，无需参数化。

## 说明

本题需要连分数展开和收敛项计算，对每个 n 找到分母 ≤ 10^12 的最后一个收敛项，计算量极大。答案已硬编码为 PE 原题答案。
