# n²+1的约数

## 题目描述

对于正整数 $n$，定义 $f(n)$ 为 $n^2+1$ 的约数中满足 $\equiv 1 \pmod 4$ 的约数个数。

根据数论中的费马平方和定理，若奇素数 $p \mid n^2+1$，则 $p \equiv 1 \pmod 4$。
这意味着 $n^2+1$ 的所有奇质因数都是 $4k+1$ 型素数。

求：
$$S(N) = \sum_{n=1}^{N} f(n)$$

具体地：
- 若 $n$ 为偶数：$n^2+1$ 是奇数，所有约数均 $\equiv 1 \pmod 4$，$f(n)$ = 总约数个数
- 若 $n$ 为奇数：$n^2+1$ 恰好含一个因子 2，$f(n)$ = 奇约数个数

## 输入格式

一行字符串：`PE`、`verify`、`compute` 或 `N=<number>`。

## 输出格式

- `PE`：输出 PE 原题答案 21295121502511。
- `verify`：展示 $n=1..20$ 的因数分解和约数统计。
- `compute`：计算 $N=1000, 2000$ 的结果。
- `N=<number>`：计算指定 $N$ 的累积和。

```
PE
```
