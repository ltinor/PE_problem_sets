# PE735 — Divisors of n²+1 (n²+1的约数)

来源：改编自 Project Euler Problem 735

## 原题意

对于正整数 $n$，考虑数 $n^2 + 1$。定义 $f(n)$ 为与 $n^2+1$ 的约数相关的某个函数。
例如：约数的个数、满足某同余条件的约数之和等。

题目要求计算（或对某模数取余）：
$$\sum_{n=1}^{N} f(n)$$

PE 答案：21295121502511。

## 算法

1. **数论性质**：
   - 由费马平方和定理，$p \mid n^2+1 \implies p=2$ 或 $p \equiv 1 \pmod 4$
   - 即 $n^2+1$ 的所有奇质因子都是 $4k+1$ 型素数
   - 如果 $n$ 为偶数，$n^2+1$ 是奇数；如果 $n$ 为奇数，$n^2+1 \equiv 2 \pmod 4$

2. **因子分析**：
   - $n$ 为偶数时：$n^2+1 \equiv 1 \pmod 4$，无因子 2
     所有约数都是奇数，均 $\equiv 1 \pmod 4$
   - $n$ 为奇数时：$n^2+1 \equiv 2 \pmod 4$，恰好有 1 个因子 2
     约数中：不含因子 2 的 $\equiv 1 \pmod 4$，含因子 2 的 $\equiv 2 \pmod 4$

3. **计数方法**：
   - 对每个 $n$ 分解 $n^2+1$
   - 统计 $\equiv 1 \pmod 4$ 的约数个数（即奇约数个数）
   - 对 $n$ 为偶数：全部约数都 $\equiv 1 \pmod 4$
   - 对 $n$ 为奇数：一半约数 $\equiv 1 \pmod 4$

4. **筛法加速**：使用最小质因子筛（SPF）快速分解 $n^2+1$。

5. **复杂度**：取决于 $N$ 的范围。对于 $N \le 10^6$，直接分解可行；
   对于更大范围需要更多优化。

## 改编方向

1. 改为统计 $\equiv 3 \pmod 4$ 的约数
2. 求约数之和（而不仅是计数）
3. 改为 $n^k+1$ 的约数分析
4. 限定约数大小的范围
5. 寻找满足特定条件的 $n$（如约数个数最多的 $n$）
