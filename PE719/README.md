# PE719 — Number Splitting (数字分裂)

来源：改编自 Project Euler Problem 719

## 原题意

一个正整数 $n$ 被称为 **S-数**（S-number），如果满足以下两个条件：

1. $n$ 是一个完全平方数（即存在整数 $k$ 使得 $n = k^2$）；
2. 将 $n$ 的十进制表示分割成若干连续的数字段，这些数字段代表的整数之和等于 $k$（即 $\sqrt{n}$）。

例如：
- $81$ 是 S-数，因为 $81 = 9^2$，且 $8 + 1 = 9$。
- $6724$ 是 S-数，因为 $6724 = 82^2$，且 $6 + 72 + 4 = 82$。
- $8281$ 是 S-数，因为 $8281 = 91^2$，且 $8 + 2 + 81 = 91$（还有 $82 + 8 + 1 = 91$）。
- $9801$ 是 S-数，因为 $9801 = 99^2$，且 $98 + 0 + 1 = 99$。

已知 $T(10^4) = 41333$（所有 $\le 10^4$ 的 S-数的和）。

求所有 $\le 10^{12}$ 的 S-数的和。

PE 答案：128088830547982。

## 算法

1. **枚举平方数**：由于 $n \le 10^{12}$，只需枚举 $k = 1, 2, \dots, 10^6$，
   检查每个 $n = k^2$ 是否为 S-数。

2. **DFS 分割检查**：对于每个 $n = k^2$，使用深度优先搜索尝试所有可能的分割方式。
   从字符串的最左端开始，依次尝试截取不同长度的前缀作为一段数字，
   递归检查剩余部分是否能分割成和为 $k$ 减去当前段的值。

3. **剪枝**：如果当前累计和已超过 $k$，立即回溯。如果当前值本身已大于 $k$，也立即回溯。

4. **记忆化**：对于同一个位置和相同的剩余目标，可以缓存结果以避免重复计算。

5. **复杂度**：对于 $d$ 位数字，最多有 $2^{d-1}$ 种分割方式。
   但剪枝使得实际搜索空间远小于此。对于 $d \le 12$（$10^{12}$ 为 13 位数），
   剪枝后可行。$10^6$ 次检查需要优化（如使用迭代代替递归）。

## 改编方向

1. 参数化 $N$ 的范围（如 $N \le 10^{14}$ 或更大）
2. 改为其他进制的数字分割（如二进制）
3. 放宽"完全平方数"限制，允许任意正整数 $n$
4. 求满足条件的最大的 S-数或 S-数的个数
5. 改为"乘积分割"：数字段之积等于 $\sqrt{n}$
