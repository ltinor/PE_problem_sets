# 数字分裂

## 题目描述

如果一个正整数 $n$ 满足以下两个条件，则称 $n$ 为 **S-数**（S-number）：

1. $n$ 是一个完全平方数，即存在整数 $k$ 使得 $n = k^2$；
2. 将 $n$ 的十进制表示的数字串任意分割成若干连续的非空子串，
   存在一种分割方式，使得这些子串代表的整数之和等于 $k$（即 $\sqrt{n}$）。

例如：
- $81 = 9^2$，$8 + 1 = 9$，所以 $81$ 是 S-数。
- $6724 = 82^2$，$6 + 72 + 4 = 82$，所以 $6724$ 是 S-数。
- $8281 = 91^2$，$8 + 2 + 81 = 91$（或 $82 + 8 + 1 = 91$），所以 $8281$ 是 S-数。

记 $T(N)$ 为所有不超过 $N$ 的 S-数之和。
已知 $T(10^4) = 41333$。

求 $T(10^{12})$。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 128088830547982。
- `verify`：验证小样例（$N \le 10^4$），列出所有 S-数并验证 $T(10^4) = 41333$。
- `compute`：重新计算完整答案（较耗时，需枚举 $10^6$ 个平方数）。

## 样例

### 输入
```
PE
```

### 输出
```
128088830547982
```

## 数据范围

- 验证范围：$N \le 10^4$（$k \le 100$）
- 完整问题：$N \le 10^{12}$（$k \le 10^6$）
- 数字最多 13 位（$10^{12}$ 为 13 位数字），最多 $2^{12} = 4096$ 种分割方式（剪枝后远小于此）
