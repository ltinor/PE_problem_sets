# 阶乘整除性比较

## 题目描述
记 f_5(n) 为使得 5^x 整除 n 的最大整数 x（即 n 中因子 5 的幂次）。

记 T_5(n) 为满足以下条件的整数 i (1 ≤ i ≤ n) 的个数：
f_5((2i-1)!) < 2·f_5(i!)

给定 n，求 T_5(n)。

---
## 输入格式
一个整数 n。

---
## 输出格式
T_5(n)。

---
## 样例
### 输入
```
1000
```
### 输出
```
68
```

---
## 数据范围
- 对于 50% 的数据：n ≤ 10^5
- 对于 80% 的数据：n ≤ 10^9
- 对于 100% 的数据：n ≤ 10^18
