# PE521 - 最小质因数

来源：改编自 Project Euler Problem 521

## 原题意

记 smpf(n) 为 n 的最小质因数。例如 smpf(91)=7，smpf(45)=3。
S(n) = Σ_{i=2}^n smpf(i)。例如 S(100)=1257。
求 S(10¹²) mod 10⁹。

PE 答案：44389811。

## 题目

给定 n，计算 S(n) mod 10⁹。

## 算法

- 使用最小质因数筛法（类似埃氏筛）直接计算 smpf(i) 并求和。
- 对于 n ≤ 10⁷，使用线性欧拉筛 / 埃氏筛预处理。
- 对于更大规模，需使用递归容斥（Legendre 公式）或 Min_25 筛计算贡献。
- 对每个素数 p，计数 ≤ n 且最小质因子为 p 的数的个数并乘以 p 累加。

## 改编方向

1. **改变函数**：最大质因数、质因数个数等。
2. **带权求和**：smpf(i)² 或 smpf(i)·φ(i) 等。
3. **区间查询**：多个 n 的 S(n) 询问。
4. **不同模数**：改变模数值。
