# 光锥

来源：改编自 Project Euler Problem 372

## 原题意

格点 (x,y) 满足 M<x≤N, M<y≤N 且 ⌊y²/x²⌋ 为奇数。PE 答案：301450082318807027。

## 题目

给定 M, N，求满足条件的格点数。

## 数据范围

M, N ≤ 10^9

## 算法

### 方向一：数论分块

条件 ⌊y²/x²⌋ 为奇数意味着 y/x 落在某个区间 (√(2k+1), √(2k+2))。对 x 分块，每块内 y 的范围连续，可直接计数。

### 方向二：Dirichlet 双曲线法

交换求和顺序，对每个可能的 ⌊y²/x²⌋ = d (奇数)，计数满足 d ≤ y²/x² < d+1 的 (x,y) 对数。

### 方向三：积分近似 + 精确计数

x 较大时用积分近似，x 较小时精确枚举。分界点取 √N 附近。

### 时间复杂度

O(√N) 或 O(N^{1/3})。
