# 106 — Special Subset Sums: Meta-Testing

来源：改编自 Project Euler Problem 106

## 原题意

对于一个包含 $n$ 个严格递增元素的集合，假设其已满足规则2（更大子集的和更大）。在所有可能的不相交非空子集对中，有多少对还需要检验规则1（子集和相等）？

当 $n=4$ 时，25 对中只有 1 对需要检验；$n=7$ 时，966 对中 70 对需要检验；$n=12$ 时，答案 21384。

## 题目

输入整数 $n$（$2 \\le n \\le 12$），求需要检验规则1的子集对数量。

## 数据范围

- $2 \\le n \\le 12$

## 算法

规则1只在两个子集大小相同时才需要检验（大小不同时规则2已保证和不同）。对于等大子集（大小均为 $k$），从 $n$ 个元素中选 $2k$ 个，再将它们分成两个 $k$ 元子集。不需要检验的情况是：排序后一个子集的所有元素都小于另一个子集的对应元素，这恰好对应 Catalan 数 $C_k = \\binom{2k}{k}/(k+1)$ 种分配方式。

因此：
- 对每个 $k$，需要检验的对数 = $\\binom{n}{2k} \\times (\\binom{2k}{k}/2 - C_k)$
- 对 $k=1$，$\\binom{2}{1}/2 - C_1 = 1-1=0$，符合直觉

时间复杂度 $O(n)$。

## 改编方向与取舍

### 改编方向
1. **参数化 $n$** → 支持 $n \\le 12$（本题采用），保持原题核心
2. **参数化 $n$ 大范围** → $n \\le 30$，答案需要用大整数
3. **输出分类统计** → 按子集大小 $k$ 分类输出各 $k$ 需要检验的对数
4. **反向问题** → 给定需检验对数 $M$，求最小 $n$

### 取舍理由
- 选择参数化 $n$：最直接，保留原题核心组合数学推导
- $n$ 限制在 12：原题范围，答案在 64 位整数内，不需要大整数
- 不选择大范围：组合数增长极快，$n=30$ 时答案远超 64 位
