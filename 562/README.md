# 562 - 最大周长 (Maximal perimeter)

来源：改编自 Project Euler Problem 562

## 原题意

构造三角形 ABC 满足：
- 顶点 A, B, C 是在以原点为圆心、半径为 r 的圆内或圆周上的格点
- 三角形内部和边上没有其他格点
- 周长最大

记 R 为三角形 ABC 的外接圆半径，T(r) = R/r。
已知 T(5) ≈ 19.834，T(10) ≈ 97.267，T(100) ≈ 9157.647。
求 T(10^7)，四舍五入到最近的整数。

PE 答案：51208711。

## 题目

给定 r，求最大的 T(r) = R/r，其中 R 为满足条件的最大周长三角形的外接圆半径。输出四舍五入到整数。

## 数据范围

- 1 ≤ r ≤ 10^7

## 算法

空网格三角形（内部无格点）由 Pick 定理知其面积为 1/2，且三边均为本原向量（坐标差互质）。

最大周长三角形顶点趋近于圆周。算法：枚举本原向量，搜索三向量之和为零的向量组，使得所有顶点落入圆内，并最大化周长。计算外接圆半径 R = abc/(4A)，输出 round(R/r)。

对于较大的 r，需要利用数论性质找到最优向量组。

时间复杂度：O(r^2 log r)（小数据），O(1)（大数据使用预计算模式）。

## 改编方向

1. **不同约束**：三角形内部允许 k 个格点。
2. **最大面积**：求最大面积而非最大周长。
3. **n 边形**：推广到 n 边形。
4. **三维推广**：球面格点上的三角形。
