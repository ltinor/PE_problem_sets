# 最大周长

## 题目描述

构造三角形 ABC 满足：
- 顶点 A, B, C 是在以原点为圆心、半径为 r 的圆内或圆周上的格点（坐标均为整数）
- 三角形内部和边上没有其他格点
- 周长最大

记 R 为三角形 ABC 的外接圆半径，T(r) = R/r。

已知 T(5) ≈ 19.834。

给定 r，求 round(T(r))（四舍五入到最近的整数）。

---

## 输入格式

一行，一个整数 r。

---

## 输出格式

一行，一个整数，表示 round(T(r))。

---

## 样例

### 输入
```
5
```

### 输出
```
20
```

---

## 数据范围

- 1 ≤ r ≤ 10^7
