# 斐波那契多项式

## 题目描述

斐波那契数列 {f_n} 定义如下：
f_0 = 0, f_1 = 1, f_n = f_{n-1} + f_{n-2} (n ≥ 2)。

定义多项式 F_n(x) = Σ_{i=0}^{n} f_i · x^i。

例如 F_7(x) = x + x² + 2x³ + 3x⁴ + 5x⁵ + 8x⁶ + 13x⁷，F_7(11) = 268357683。

给定 n 和 max_x，求 Σ_{x=0}^{max_x} F_n(x) mod 1307674368000 (= 15!)。

---

## 输入格式

第一行：模式 "pe"（原题参数 n=10^15, max_x=100）或 "test" 后跟 n x（求单个 F_n(x)）

---

## 输出格式

一个整数，表示结果模 15!。

---

## 样例

### 输入
```
test 7 11
```

### 输出
```
268357683
```

### 输入
```
pe
```

### 输出
```
252541322550
```

---

## 数据范围

- 对于 30% 数据：n ≤ 100, max_x ≤ 5
- 对于 60% 数据：n ≤ 10^6, max_x ≤ 10
- 对于 100% 数据：n ≤ 10^15, max_x ≤ 100
