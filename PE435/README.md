# PE435 - 斐波那契多项式

来源：改编自 Project Euler Problem 435

## 原题意

斐波那契数列 f_n: f_0=0, f_1=1, f_n=f_{n-1}+f_{n-2}。
定义 F_n(x) = Σ_{i=0}^{n} f_i · x^i。
已知 F_7(11) = 268357683。
原题求 [Σ_{x=0}^{100} F_n(x)] mod 15!，其中 n=10^15，答案为 252541322550。

## 题目

给定 n 和 max_x，求 Σ_{x=0}^{max_x} F_n(x) mod 15!。

## 算法

- 生成函数：Σ f_i x^i = x/(1-x-x²)
- F_n(x) 是生成函数的前 n 项部分和
- 闭形式：F_n(x) = (f_{n+2}·x^{n+1} + f_{n+1}·x^{n+2} - x)/(x²+x-1)
- 使用矩阵快速幂计算大 n 的斐波那契数
- 模 15! 的逆元需要扩展欧几里德算法
- 注意分母为零时的特殊处理

## 改编方向

1. **其他递推**：Tribonacci 或一般线性递推
2. **加权和**：Σ i·f_i·x^i 或 Σ f_i²·x^i
3. **不同模数**：mod 16!, 17! 等
4. **区间 x**：L ≤ x ≤ R
