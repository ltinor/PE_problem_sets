# 最大拆分乘积

来源：改编自 Project Euler Problem 183

## 原题意

对 5 ≤ N ≤ 10000，计算 ΣD(N)：
- M(N) = max_{k} (N/k)^k
- D(N) = N（M(N) 不是有限小数）/ -N（M(N) 是有限小数）
答案：48861552。

## 题目

多组测试数据。每组给定 N，求 ΣD(i) for i=5..N。

## 数据范围

- 5 ≤ N ≤ 10000

## 算法

最优 k ≈ N/e，检查 floor 和 ceil 以及邻近值。

有限小数判定：(N/k)^k 是有限小数当且仅当 k 去掉所有 2 和 5 因子后能整除 N。

## 改编方向

1. **参数化 N**：原题固定 N=10000，改编后输入任意 N。
2. **多组测试数据**：支持多次查询。
3. **暴力对拍**：小 N 使用枚举所有 k 验证。
