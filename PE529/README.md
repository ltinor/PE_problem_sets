# PE529 - 10子串友好数

来源：改编自 Project Euler Problem 529

## 原题意

一个数的 10-子串 是各位数字之和恰好为 10 的连续子串。
若一个数的每一位数字都属于某个 10-子串，则称该数为 10-子串友好数。
例如，3523014 是 10-子串友好数，28546 不是。

记 T(n) 为 1 到 10ⁿ 之间（含）所有 10-子串友好数的个数。
已知：T(2) = 9，T(5) = 3492。

求 T(10¹⁸) mod 10⁹+7。

PE 答案：23624465366。

## 题目

给定 n，计算 T(n) mod 10⁹+7。

## 算法

- 构建 DFA（确定有限状态自动机），状态表示当前仍未覆盖的数字位的"剩余需求"。
- 当添加新数字 d 时，新的位需要 10−d 来达到和 10；已有位的需求减去 d。
- 若某位需求降为 0 则该位被覆盖；若降为负则该前缀作废。
- 通过 BFS 枚举所有可达状态，建立状态转移矩阵。
- 使用 DP 或矩阵快速幂计算指定长度内的合法数字个数。
- 小规模 n（≤6）使用暴力枚举验证。

## 改编方向

1. **不同目标和**：将 10 改为其他数字 S。
2. **10-超串**：每个数字属于至少两个不同的 10-子串。
3. **禁止模式**：排除包含特定子串的数字。
4. **多进制**：在二进制或十六进制下定义友好数。
