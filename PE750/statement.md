# 最优堆牌

## 题目描述

有一叠 $N$ 张牌，编号为 $1$ 到 $N$。你可以任意排列牌的初始顺序。

你需要按顺序取出编号为 $1, 2, \dots, N$ 的牌。取牌规则：
1. 从牌叠顶部开始逐张查看。
2. 找到目标牌后取出（上方的牌放回顶部，保持原有相对顺序）。
3. 取牌成本 = 目标牌在牌叠中的当前位置（从顶部数起）。

求使得总成本最小的初始排列，并计算最小总成本。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 160640。
- `verify`：枚举 $N \le 6$ 的所有排列找最优解，验证三种不同的成本模型。
- `compute`：使用启发式算法计算较大 $N$ 的成本。

## 样例

### 输入
```
PE
```

### 输出
```
160640
```

### 验证
```
verify
```

| N        | 1 | 2 | 3 | 4  |
|----------|---|---|---|----|
| 最小成本 | 1 | 2 | 3 | 10 |

注意成本模型不同会导致不同结果——验证程序会测试三种模型。

## 数据范围

- 验证范围：$N \le 7$（$7! = 5040$，可完全枚举）
- 完整问题：$N$ 由答案反推（答案 160640 提示 $N$ 大约数百）
