# 整数长度的中线

## 题目描述

三角形 ABC 的三边长 a ≤ b ≤ c 均为正整数。记 m_c 为连接顶点 C 与对边 AB 中点所得中线的长度。

对于给定的 N，记 F(N) 为满足 c ≤ N 且中线 m_c 的长度也为整数的三角形 (a, b, c) 的个数。

## 输入格式

一行，一个整数 N，或字符串 `PE`。

## 输出格式

一个整数，表示 F(N)。

## 样例

### 输入
```
10
```

### 输出
```
3
```

### 输入
```
50
```

### 输出
```
165
```

## 数据范围

- 对于 30% 数据：N ≤ 100
- 对于 60% 数据：N ≤ 2000
- 对于 100% 数据：N ≤ 10^5
