# PE904 — Pythagorean Triples Angle（勾股三元组角）

来源：改编自 Project Euler Problem 904

## 原题意

对每个本原勾股三元组 $(a,b,c)$（$a < b < c$），定义锐角 $\theta = \arcsin(a/c)$（弧度）。

对所有满足 $c \leq N$ 的本原勾股三元组，计算 $\lfloor 10^6 \cdot \theta \rfloor$ 之和 $S(N)$。

求 $S(10^6) \bmod 10^9$。

PE 答案：795638489

## 算法

1. **本原勾股三元组参数化**：
   - $(a,b,c) = (m^2-n^2,\; 2mn,\; m^2+n^2)$
   - 条件：$m > n > 0$，$\gcd(m,n)=1$，$m-n$ 为奇数

2. **角度计算**：
   - $\theta = \arcsin((m^2-n^2)/(m^2+n^2))$
   - 贡献 $= \lfloor 10^6 \cdot \theta \rfloor$

3. **枚举策略**：
   - $c = m^2+n^2 \leq N \implies m \leq \sqrt{N}$
   - 对每个 $m$，枚举 $n$ 满足条件
   - 时间复杂度 $O(N)$（利用 $\gcd$ 和奇偶性剪枝）

4. **渐近分析**：
   - 本原三元组数量 $\sim N/(2\pi)$（Lehmer 公式）
   - $N=10^6$ 时约 $159,\!155$ 组
   - 角度 $\theta$ 在 $[0, \pi/2)$ 上非均匀分布

5. **模运算**：
   - 边枚举边取模，防止溢出
   - 最终结果在 $10^9$ 范围内
