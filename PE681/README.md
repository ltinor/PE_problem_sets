# PE681 — Maximal Area (最大面积)

来源：改编自 Project Euler Problem 681

## 原题意

给定正整数 $a \le b \le c \le d$，记 $M(a,b,c,d)$ 为以 $a,b,c,d$ 为边长（可以任意顺序排列）的四边形的最大面积。
最大面积由圆内接四边形取得，面积公式为 Brahmagupta 公式：
$A = \sqrt{(s-a)(s-b)(s-c)(s-d)}$，其中 $s = (a+b+c+d)/2$。

记 $SP(n)$ 为所有满足 $a \le b \le c \le d$ 且 $M(a,b,c,d)$ 为不超过 $n$ 的正整数的四元组对应的 $a+b+c+d$ 之和。
已知 $SP(10)=186$，$SP(100)=23238$。
求 $SP(1\\ 000\\ 000)$。

PE 答案：26112239。

## 算法

1. **变量变换**：令 $x=s-a, y=s-b, z=s-c, w=s-d$，则 $x \ge y \ge z \ge w \ge 1$。
   四边形边长 $a=(y+z+w-x)/2$，周长 $p = x+y+z+w$（必须为偶数）。
   面积 $A = \sqrt{xyzw}$，即 $A^2 = xyzw$。

2. **约束条件**：由 $a \ge 1$ 得 $x \le y+z+w-2$。

3. **枚举策略**：枚举 $A$ 从 1 到 $10^6$，对 $A$ 做质因数分解，
   生成 $A^2$ 的所有因数，枚举满足 $w|A^2, z|(A^2/w), y|(A^2/(wz)), x=A^2/(wzy)$ 且
   $w \le z \le y \le x$，$x \le y+z+w-2$，$x+y+z+w$ 为偶数的四元组。

4. **复杂度**：使用线性筛预处理最小质因子，对每个 $A$ 用质因数分解生成 $A^2$ 的所有因数。
   每个 $A$ 的因数个数平均为 $O(\log A)$，总复杂度约 $O(N \log N + \text{枚举因子四元组})$。

## 改编方向

1. 参数化 $N$ 的范围
2. 考虑五边形、六边形等多边形的最大面积问题
3. 限制边长为不同整数或满足其他约束
4. 考虑非圆内接四边形的最大面积近似
