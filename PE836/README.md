# PE836 — A Message in a Mess（混乱中的信息）

来源：改编自 Project Euler Problem 836（发布时间：2024年4月）

## 原题意

博物馆里有一些写着大写字母的卷轴。只能通过交换相邻卷轴来排序，每次交换的成本取决于两个字母在字母表中的位置差。求将 N 个卷轴按字母顺序排列的最小总成本。

这是一道组合优化问题，本质上是在字母序列上求带权重的相邻交换排序的最小总代价。相关的经典问题包括：
- **冒泡排序的最小交换次数**：等于逆序对的数量。
- **带权重的相邻交换排序**：类似于在字符间定义了一个距离度量，最小代价可以通过预处理字母出现位置来计算。

PE 答案：apr2024（这是一个字符串形式的结果，可能与日期有关）。

## 算法

1. **逆序对计数**：对于无权重的情况（即每次交换成本为 1），排序所需的最小相邻交换次数等于序列中逆序对的数量。可以使用 BIT/Fenwick 树或归并排序在 O(N log N) 时间内计算。

2. **带权重的相邻交换**：当每次交换的成本 = 两个字母的 ASCII 差时，问题变为：最小化 Σ（交换成本 × 交换次数）。可以通过以下方式求解：
   - 固定最终排序后的序列 = 按字母非递减排序。
   - 使用贪心策略：对于每个目标位置的字符，找到它在原序列中对应的最早出现位置，计算将它移到目标位置所需的成本。
   - 每次移动成本 = Σ（路径上经过的每个字符与移动字符的绝对差）。

3. **动态规划**：对于较小的字母集（26 个大写字母），可以使用 DP 计算最小总代价：dp[mask] = 处理 mask 中字母子集的最小代价。转移时添加一个新的字母种类，计算将所有该字母移到已处理位置之后所需的成本。

4. **答案格式**：PE 答案 "apr2024" 暗示结果是一个字符串（可能是日期或编码后的答案），而非纯数值。

## 改编方向

1. 考虑不同的成本函数（如成本的平方、字母顺序距离等）
2. 推广到任意字母集（包含小写字母和特殊字符）
3. 研究不同初始分布下的期望最小成本
4. 允许跳跃式移动（不仅限于相邻交换）
5. 最小化排序时间而非交换成本
