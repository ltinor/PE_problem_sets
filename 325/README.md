# 325 — Stone Game II

来源：改编自 Project Euler Problem 325

## 原题意

两名玩家轮流从两堆石子中取石子。每轮可以从较大堆中取走较小堆石子数量的正整数倍。取走一堆中所有石子者获胜。

必败态是指无论先手如何操作，后手都必胜的状态。记 S(N) 为所有满足 0 < x_i < y_i ≤ N 的必败态 (x_i, y_i) 中 (x_i+y_i) 的和。

已知 S(10)=211, S(10^4)=230312207313。求 S(10^16) mod 7^10。

答案：54672965。

## 题目

输入 N，求 S(N) mod 7^10。

## 数据范围

- 1 ≤ N ≤ 10^16

## 算法

1. **博弈 DP**：必败态满足特征：若 y < 2x，只能移动到 (y-x, x)；若 y ≥ 2x，总存在必败态可达 → 必胜。递推计算所有必败态。
2. **Beatty 序列**：必败态 (x, y) 满足 y = ⌊x·φ⌋ 或类似规律，利用无理数逼近批量求和。
3. **分块求和**：对于大 N，利用必败态在数轴上的分布规律分块统计。

## 改编方向

1. 原题固定 N=10^16 → 参数化 N
2. 改变取子规则（如可取任意不超过较小堆的整数倍）
3. 三个堆的扩展

选择方向 1：参数化 N，保留原题博弈核心。
