# 取石子游戏 II

## 题目描述

两名玩家正在用两堆石子玩游戏。

每一轮，玩家可以从较大的堆中取走一定数量的石子，取走的数量必须是较小的堆中石子数量的正整数倍。

从某一堆中取走所有石头的玩家赢得游戏。

所谓**必胜态**指先手玩家必胜的状态。**必败态**指无论先手玩家如何操作，后手玩家都必胜的状态。

例如，(1,5)、(2,6) 和 (3,12) 是必胜态（可立即取走较大堆的所有石子）。
(2,3) 和 (3,4) 是必败态（任何合法操作都会给后手留下必胜态）。

对于所有满足 0 < x_i < y_i ≤ N 的必败态 (x_i, y_i)，记 S(N) 为 Σ(x_i + y_i)。

已知 S(10) = 211，S(10^4) = 230312207313。

给定 N，求 S(N) mod 7^10（7^10 = 282475249）。

---

## 输入格式

一行一个整数 N。

---

## 输出格式

一行一个整数，表示 S(N) mod 282475249。

---

## 样例

### 输入

```
10
```

### 输出

```
211
```

### 输入

```
10000
```

### 输出

```
230312207313
```

### 输入

```
10000000000000000
```

### 输出

```
54672965
```

---

## 数据范围

- 1 ≤ N ≤ 10^16
