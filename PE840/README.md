# PE840 — Sum of Products（乘积和）

来源：改编自 Project Euler Problem 840

## 原题意

给定某个正整数集合（或由某种规则生成的正整数序列），计算所有子集乘积之和，或所有划分方式下各块乘积之和。

这类"乘积和"问题与以下经典问题相关：
- **划分乘积和**：对整数 n 的所有划分（partition）λ ⊢ n，求 Π λ_i 的和。
- **子集乘积和**：对集合 {1, 2, ..., n} 的所有非空子集 T，求 Π_{x∈T} x 的和 = (1+1)(1+2)...(1+n) - 1 = (n+1)! - 1。
- **Bell 多项式**：与集合划分和指数生成函数相关。

PE 答案：0.277319553（小于 1 的浮点数，暗示可能是某种概率或比值）。

## 算法

1. **生成函数方法**：
   - 子集乘积和 = Π_{i=1}^{n} (1 + a_i) - 1。
   - 划分乘积和涉及更复杂的生成函数（如 Euler 的五边形数定理）。

2. **动态规划**：
   - dp[s] = 和为 s 的划分的所有乘积之和。
   - 转移：dp[s + k] += dp[s] × k（在划分中加入部分 k）。

3. **Bell 多项式**：
   - 完全 Bell 多项式 B_n(x_1, ..., x_n) 的变量代入 a_k = (k-1)! 可得到与排列相关的结果。

4. **指数生成函数**：
   - 对于划分乘积和，EGF 为 Σ_{n≥0} P(n)/n! · z^n = exp(Σ_{k≥1} k · z^k/k!) = exp(z·e^z - z)。

5. **数值计算**：对于大参数，可使用高精度浮点数或渐进展开。
