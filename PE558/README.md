# PE558 — 无理底数 (Irrational Base)

来源：改编自 Project Euler Problem 558

## 原题意

每个正整数 n 可以唯一地表示为黄金比例 φ = (1+√5)/2 的非标准进制表示（Zeckendorf 表示），使用数字 0 和 1 且不能出现连续的两个 1。

令 rᵢ(n) 为 n 在 φ 进制表示中第 i 位的数字（最低位为 i=1）。
定义 W(n) = Σ_{i=1}^{∞} rᵢ(n) · 2⁻ⁱ。

令 S(m) = Σ_{k=1}^{m} k · W(k)。

求 S(10¹⁴) 四舍五入到最接近的整数，对 10⁹ 取模。

PE 答案：226754885。

## 题目

给定 m，求 S(m) 的四舍五入值 mod 10⁹。

## 算法

- W(n) 可以解释为 n 在 φ 进制下的「小数部分」的二进制解释。
- Zeckendorf 表示基于斐波那契数列 F₂=1, F₃=2, F₄=3, …。
- 利用数位 DP：逐位（斐波那契位）处理，跟踪当前值和 W 的累积贡献。
- 每一位对 W(n) 的贡献是 2^{-position}，可以按位聚合统计。
- 对于 m = 10¹⁴，斐波那契项数约为 70 个，DP 状态数是可管理的。
- 使用 double 或 __int128 跟踪 W(n) 的精确值，最后四舍五入。

## 改编方向

1. **不同底数**：使用其他无理底数（如 √2、√3、e 等）。
2. **不同权重函数**：改变 W(n) 的定义（如使用不同的权重序列）。
3. **精确有理数**：改用精确有理数计算代替四舍五入。
4. **前缀和**：计算 Σ S(m) 或 Σ W(k)。
5. **不同表示**：使用允许连续 1 的 φ 进制（非标准表示）计数。
