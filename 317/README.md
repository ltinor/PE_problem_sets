# 317 — Firecrackers

来源：改编自 Project Euler Problem 317

## 原题意

一枚爆竹在距离水平地面 $h=100$ 米的高度爆炸，分裂成许多小碎片，向各个方向以相同初速度 $v=20$ m/s 迸射。碎片在无空气阻力、均匀重力场（$g=9.81$ m/s²）中运动。

求碎片在落地前所经过空间的总体积（m³），四舍五入到四位小数。

答案：$1856532.8455$。

## 题目

输入爆炸高度 $h$、初速度 $v$ 和重力加速度 $g$，计算碎片扫过区域的体积，保留四位小数。

## 数据范围

- $1 \le h \le 1000$
- $1 \le v \le 100$
- $1 \le g \le 20$

## 算法

1. **物理推导法**：碎片轨迹的包络线为 $z(r) = h + \frac{v^2}{2g} - \frac{g r^2}{2v^2}$。扫过区域为包络面旋转体，体积公式：$V = \frac{\pi v^2}{g} \left(h + \frac{v^2}{2g}\right)^2$。复杂度 $O(1)$。
2. **蒙特卡洛模拟**：随机模拟大量碎片轨迹，统计扫过空间。仅用于验证。
3. **数值积分**：对包络旋转体进行数值积分验证。

## 改编方向

1. 原题固定 $h=100, v=20, g=9.81$ → 参数化 $h, v, g$
2. 考虑空气阻力（更难）
3. 计算碎片落地时的分布范围面积

选择方向 1：保留原题物理核心，参数化初始条件。
