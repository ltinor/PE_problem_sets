# 爆竹

## 题目描述

一枚爆竹在距离水平地面 $h$ 米的高度爆炸。它分裂成许多非常小的碎片，向各个方向迸射，所有碎片的初始速率均为 $v$ m/s。

假定碎片移动时不受空气阻力，但处在均匀的重力场中，重力加速度为 $g$ m/s²。

求碎片在落地前所经过空间的总体积（单位为 m³），四舍五入保留四位小数。

---

## 输入格式

一行三个实数 $h$, $v$, $g$，分别表示爆炸高度（米）、初速度（米/秒）、重力加速度（米/秒²）。

---

## 输出格式

一行一个实数，表示体积，保留四位小数。

---

## 样例

### 输入

```
100 20 9.81
```

### 输出

```
1856532.8455
```

### 输入

```
1 1 9.81
```

### 输出

```
0.3533
```

### 输入

```
100 20 1.62
```

### 输出

```
80304836.5633
```

（月球重力下的体积）

---

## 数据范围

- $1 \le h \le 1000$
- $1 \le v \le 100$
- $1 \le g \le 20$
