# 蜜蜂蜂巢距离

## 题目描述

蜜蜂蜂巢的每个单元是边长为 1 的正六边形。蜂后占据其中一个单元。B(L) 表示距离蜂后单元恰好为 L 的单元总数（距离指单元中心间的欧氏距离）。

已知：B(√3)=6，B(√21)=12，B(111111111)=54。

给定上限 LIMIT 和目标值 TARGET，求所有满足 L ≤ LIMIT 且 B(L)=TARGET 的 L 的个数。

---

## 输入格式

一行两个整数 LIMIT 和 TARGET，用空格分隔。

---

## 输出格式

一个整数，表示满足条件的 L 的个数。

---

## 样例

### 输入
```
100 6
```

### 输出
```
2
```

（L=√3 和 L=√12 满足 B(L)=6 且 ≤100）

### 输入
```
1000 12
```

### 输出
```
1
```

---

## 数据范围

- 对于 30% 数据：LIMIT ≤ 10^4
- 对于 60% 数据：LIMIT ≤ 10^7
- 对于 100% 数据：LIMIT ≤ 5·10^11，TARGET ≤ 10^4
