# 2 的幂之和

## 题目描述

记 f(0) = 1，f(n) 是将 n 表达为 2 的幂之和且不同的幂至多使用两次的不同方式数目。

例如，f(10) = 5，因为有以下五种不同方式表示 10：

```
1 + 1 + 8
1 + 1 + 4 + 4
1 + 1 + 2 + 2 + 4
2 + 4 + 4
2 + 8
```

## 输入格式

一行一个整数 N（可能很大，以字符串形式给出）。

## 输出格式

一行一个整数 f(N)。

---

## 样例

### 输入
```
10
```

### 输出
```
5
```

### 输入
```
100
```

### 输出
```
788
```

### 输入
```
10000000000000000000000000
```

### 输出
```
178653872807
```

---

## 数据范围

- 0 ≤ N ≤ 10²⁵

---

## 提示

使用递推公式：
- f(0) = 1
- N 为偶数时：f(N) = f(N/2) + f(N/2 - 1)
- N 为奇数时：f(N) = f(N/2)

PE 原题 N=10²⁵ 时答案为 178653872807。
