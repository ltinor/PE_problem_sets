# 三角形网格三染色

## 题目描述

考虑一个由 $64$ 个等边三角形组成的三角形网格，排列如下（共 $8$ 行）：

```
第1行: 1 个三角形
第2行: 3 个三角形
第3行: 5 个三角形
...
第8行: 15 个三角形
```

每个三角形与相邻的三角形共享一条边。要求用红、绿、蓝三种颜色给所有三角形染色，使得任何两个共享一条边的三角形颜色不同。

求不同染色方案的总数。

---

## 输入格式

一行，一个整数（占位符，实际不使用）。

---

## 输出格式

一行，一个整数，表示染色方案数。

---

## 样例

### 输入
```
0
```

### 输出
```
10834893628237824
```

---

## 数据范围

无特殊数据范围。
