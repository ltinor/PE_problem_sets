# PE574 - 验证选举 (Verifying an Election)

来源：改编自 Project Euler Problem 574

## 原题意

一场选举有 n 名候选人和 m 名选民，每名选民投一票。选举结束后，从 m 张选票中随机选择 r 张进行重新计票。

若无论原始投票如何分布，重新计票都能正确确认原始获胜者，则称 r 为"验证充分的"。

Q(n, m) 为验证充分的 r 的数量（0 ≤ r ≤ m）。

已知：Q(2,3) = 1，Q(2,4) = 4，Q(3,2) = 1，Q(3,3) = 3。

求 Q(5,5)。
PE 答案：57804459920512。

## 算法

重新计票需要满足：对于任何可能的原始投票分布，抽样 r 张票中的获胜者与原始获胜者一致。

最坏情况是原始获胜者和第二名之间的票数差距最小。假设获胜者得票 w₁，第二名得票 w₂，差值为 d = w₁ - w₂。要保证重新计票正确，需要在最坏的抽样情况下（即抽样严重偏向第二名的极端情况），抽样结果仍然显示 w₁ > w₂。

对于 n=2（两名候选人），重新计票充分当且仅当 r > m/2（即抽样必须占多数）。

对于 n>2，情况更复杂，涉及组合不等式。

## 改编方向

1. 研究 Q(n,m) 对于固定 n 随 m 增长的渐近行为。
2. 考虑加权投票（每张票权重不同）。
3. 引入"审计风险"：允许以极小概率 ε 出错，研究所需的最小 r。
