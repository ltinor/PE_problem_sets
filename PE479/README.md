# PE479 - 逐渐增长的根

来源：改编自 Project Euler Problem 479

## 原题意

记 a_k, b_k, c_k 是方程 1/x = (k/x)²(k+x²) - kx 在复数域内的三个根。

记 S(n) = Σ (a_k+b_k)^p (b_k+c_k)^p (c_k+a_k)^p，其中 1 ≤ p, k ≤ n。

已知 S(4) = 51160。

求 S(10⁶) mod 1,000,000,007。PE 答案：19154179538。

## 题目

给定 n，求 S(n) mod 1,000,000,007。

## 算法

- 方程整理为三次方程：k·x³ + k²·x² - x + k³ = 0
- 由 Vieta 公式：a_k + b_k + c_k = -k
- 经推导，(a_k+b_k)(b_k+c_k)(c_k+a_k) = 1 + k²
- 故 S(n) = Σ_{k=1}^n Σ_{p=1}^n (1+k²)^p
- 内层为等比数列求和：((1+k²)^{n+1} - (1+k²)) / k²
- O(n log MOD) 可计算，n=10⁶ 可行

## 改编方向

1. **不同方程**：改变方程形式
2. **更高次幂**：求和 (a_k+b_k)^{p+q} 等
3. **仅实数根**：只考虑实数解
4. **不同范围**：p 和 k 不同范围求和
