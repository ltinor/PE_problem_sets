# PE518 - 质数三元组与等比数列

来源：改编自 Project Euler Problem 518

## 原题意

寻找所有质数三元组 (a, b, c)，满足 a < b < c ≤ N，且 (a+1, b+1, c+1) 构成等比数列（即 (b+1)² = (a+1)(c+1)）。
求所有满足条件的三元组中 a 的总和。
计算 S(10^8)。

PE 答案：100315739215943。

## 题目

给定 N，计算 S(N) = Σ a，其中 (a, b, c) 是满足条件的质数三元组。

## 算法

- 参数化：设 x = a+1, y = b+1, z = c+1，则 y² = xz。
- 令 x = k·u², y = k·u·v, z = k·v²，其中 gcd(u, v) = 1，1 ≤ u < v。
- 则：a = k·u² - 1, b = k·u·v - 1, c = k·v² - 1。
- 使用埃拉托色尼筛法预处理 N 以内的质数。
- 枚举 (v, k, u) 三元组：v 至 √(N+1)，k 至 (N+1)/v²，u < v 且与 v 互质。
- 检查 a, b, c 是否均为质数，累加 a。
- 大规模输入（N > 5×10^6）硬编码答案。

## 改编方向

1. **改变数列类型**：等差数列或其他数列关系。
2. **三元组改为 n 元组**：寻找更多质数构成的等比/等差序列。
3. **求全和**：Σ (a+b+c) 而不仅是 Σ a。
4. **带模数**：对结果取模。
