# 质数三元组与等比数列

## 题目描述

考虑三个质数 a < b < c ≤ N，满足 **a+1、b+1、c+1 构成等比数列**，即 (b+1)² = (a+1)(c+1)。

例如，当 N = 100 时，满足条件的三元组有 (2, 5, 11)，因为 3, 6, 12 构成公比为 2 的等比数列。

定义 S(N) 为所有满足条件的三元组中 **a 的总和**。

给定 N，求 S(N)。

## 输入格式

一个整数 N（1 ≤ N ≤ 10^8），或字符串 `PE`。

## 输出格式

一个整数，表示 S(N)。

## 样例

### 输入
```
100
```

### 输出
```
448
```

## 数据范围

- 对于 30% 数据：N ≤ 10^3
- 对于 60% 数据：N ≤ 10^5
- 对于 100% 数据：N ≤ 10^8
