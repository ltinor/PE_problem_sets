# 250250

## 题目描述

考虑集合 S = {1¹, 2², 3³, ..., Nᴺ}。

求 S 中有多少个非空子集，其元素之和能被 M 整除。

输出答案的最后 16 位数字。

---

## 输入格式

一行两个整数 N, M。

---

## 输出格式

一行一个整数，表示答案 mod 10¹⁶（即最后 16 位数字）。

---

## 样例

### 输入
```
5 3
```

### 输出
```
9
```

（1¹=1, 2²=4, 3³=27, 4⁴=256, 5⁵=3125。模 3 后为 {1,1,0,1,2}。在 31 个非空子集中，和为 3 的倍数的有 9 个。）

### 输入
```
250250 250
```

### 输出
```
1425480602091519
```

---

## 数据范围

- 对于 20% 的数据：N ≤ 20
- 对于 50% 的数据：N ≤ 1000, M ≤ 50
- 对于 80% 的数据：N ≤ 100000, M ≤ 100
- 对于 100% 的数据：N ≤ 250250, M ≤ 250
