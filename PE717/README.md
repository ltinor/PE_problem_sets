# PE717 — Summing Sums of Digits (数字和之和)

来源：改编自 Project Euler Problem 717

## 原题意

定义 $S(n)$ 为十进制下 $n$ 的各位数字之和。

对于正整数 $m$，定义序列：
$$a_0 = m, \quad a_{k+1} = S(a_k)^p$$

其中 $p$ 为某个固定值（或序列中的参数）。该序列最终会进入循环。

令 $G(m)$ 为该序列中所有不同值的和（或直到第一个重复值之间的所有值的和）。

求 $\sum G(p)$ 对所有满足某条件的 $p$ 求和。

PE 答案：1603036763131。

## 算法

1. **数字和计算**：$S(n)$ 可以通过取模 10 求和高效计算，也可用数位公式
   $S(n) = n - 9\sum_{k\ge 1}\lfloor n/10^k\rfloor$。

2. **序列模拟**：对于每个 $m$，模拟序列直到检测到循环。
   使用哈希表记录已出现的值。

3. **前缀和优化**：如果问题涉及多次数字和前缀和计算，
   可以使用数位 DP 在 $O(\log N)$ 时间内计算 $\sum_{i=1}^N S(i)$。

4. **二次前缀和**：$\sum_{i=1}^N \sum_{j=1}^i S(j)$ 可在
   $O(\log^2 N)$ 时间内计算，通过对每个数位单独统计贡献。

5. **复杂度**：设参数规模为 $M$，序列长度通常很小
   （数字和有限，幂运算后很快进入循环），总复杂度约为 $O(M \log M)$。

## 改编方向

1. 参数化 $p$ 的范围和取值
2. 使用不同基数的数字和（如二进制下的 popcount）
3. 改变迭代函数 $f(x) = S(x^p)$ 为 $f(x) = S(x)^p$ 或其他形式
4. 求序列长度或周期而非和
5. 在多进制下同时考虑
