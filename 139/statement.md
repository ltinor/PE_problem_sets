# 勾股瓷砖

## 题目描述

设 (a, b, c) 为直角三角形的三边（a < b < c），满足 a² + b² = c²。

用边长为 c 的正方形瓷砖铺地。该瓷砖中心有一个边长为 (b−a) 的正方形孔洞。

如果一个直角三角形能够用这种瓷砖完全铺满（允许旋转），则称其为可铺砖的。

给定整数 M，求周长小于 M 的可铺砖直角三角形的数量。

---

## 输入格式

一行一个整数 M (10 ≤ M ≤ 10⁸)。

---

## 输出格式

一行一个整数，表示满足条件的三角形数量。

---

## 样例

### 输入

```
100
```

### 输出

```
8
```

---

## 数据范围

- 10 ≤ M ≤ 10⁸
