# PE772 — Balanceable numbers（可平衡数）

来源：改编自 Project Euler Problem 772

## 原题意

一个正整数 $n$ 称为"可平衡数"，如果集合 $\{1, 2, \dots, n\}$ 可以被划分成两个和相等的子集。这等价于三角形数 $T_n = n(n+1)/2$ 为偶数，且存在子集和为 $T_n/2$。

问题可能要求：在某个范围内计数可平衡数、求和、或研究与数字平衡（左右半部分数字和相等）相关的变体。

PE 答案：83985379（约 $8.40 \times 10^7$）。

## 算法

1. **子集和可平衡判定**：$T_n$ 为偶数当且仅当 $n \equiv 0$ 或 $3 \pmod{4}$，此时必然存在合法划分（贪心从大到小）。
2. **数字平衡**：将数字串从中间分开，比较左右两部分数字和是否相等。
3. **真因数和平衡**：计算 $\sigma(n) - n$，判断是否为平衡数（完全数、亏数、过剩数）。
4. **大规模计数**：子集和可平衡数密度为 $1/2$，可通过等差数列公式直接计算。
5. **备选解释**：探索其他"可平衡"含义（如回文平衡、数字根平衡等）。

## 改编方向

1. 推广到多路平衡（划分为 $k$ 个等和子集）
2. 限定子集大小相等（等基数划分）
3. 连续整数的平衡（滑动窗口和相等）
4. 权重版本（数字带不同权重）
5. $k$ 进制数字的平衡
