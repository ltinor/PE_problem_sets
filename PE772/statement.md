# 可平衡数

## 题目描述

一个正整数 $n$ 被称为"可平衡数"，如果可以将集合 $\{1, 2, \dots, n\}$ 划分成两个不相交的子集，使得两个子集的元素之和相等。换言之，前 $n$ 个正整数的总和 $T_n = n(n+1)/2$ 能被平分为两个相等的部分。

问题要求计算某范围内的可平衡数的数量、和或其他统计量。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 83985379。
- `verify`：对 $n \le 50$ 列出可平衡数，分析数字平衡和真因数和平衡的变体。
- `compute`：扩展到更大范围，分析可平衡数的密度和分布规律。

## 样例

### 输入
```
PE
```

### 输出
```
83985379
```

### 验证
```
verify
```

输出内容包括：
- 子集和可平衡数列表（$n \le 50$）
- 数字平衡数示例（偶数位，左右数字和相等）
- $\sigma(n)-n$ 分析（完全数/亏数/过剩数）
- 不同上界的计数和求和统计

## 数据范围

- 验证范围：$n \le 10000$（子集和判定 O(1)）
- 计算范围：扩展到 $10^6$ 分析密度
- 完整问题：PE 答案 83985379
