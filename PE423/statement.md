# 连续扔骰子

## 题目描述

连续掷一个六面骰子 n 次，记 c 为连续两次掷出同样点数的次数。

例如 n = 7，点数序列为 (1,1,5,6,6,6,3) 时：
- (1,1,5,6,6,6,3) → c 计数包括位置 (1,2), (4,5), (5,6)，共 3 次

定义 C(n) 为连续掷骰子 n 次时，c **不超过 π(n)** 的结果总数（π 为素数计数函数）。

已知：
- C(3) = 216
- C(4) = 1290
- C(11) = 361912500
- C(24) = 4727547363281250000

定义 S(L) = ∑<sub>n=1</sub><sup>L</sup> C(n) mod 1000000007。

给定 L，求 S(L)。

---

## 输入格式

一个整数 L。

---

## 输出格式

一个整数，表示 S(L) mod 1000000007。

---

## 样例

### 输入
```
50
```

### 输出
```
832833871
```

---

## 数据范围

- 对于 30% 数据：L ≤ 50
- 对于 60% 数据：L ≤ 500
- 对于 100% 数据：L ≤ 5×10<sup>7</sup>
