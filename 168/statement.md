# 数字轮换

## 题目描述

考虑数 142857。将它的末位数字 7 移至最前面，得到 714285。可以验证：714285 = 5 × 142857。这表明 142857 具有特殊性质：它的右旋转是它自身的倍数。

我们称满足此性质的数为"可旋转数"：即将其末位数字移至最前面后，得到的新数是原数的整数倍（倍数在 2 到 9 之间），且原数大于 10。

## 输入格式

一行一个整数 D。

## 输出格式

一行一个整数，表示所有满足 10 < n < 10^D 的可旋转数 n 之和的最后五位数字。

---

## 样例

### 输入
```
4
```

### 输出
```
87491
```

### 输入
```
100
```

### 输出
```
59206
```

---

## 数据范围

- 1 ≤ D ≤ 100

---

## 提示

n = b × (10^k - 1) / (10m - 1)，其中 b 为末位数字（1-9），m 为倍数（2-9），k 为位数。PE 原题 D=100 时答案为 59206。
