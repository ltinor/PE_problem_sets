# Pythagorean Odds

来源：改编自 Project Euler Problem 285

## 原题意

随机选 k 和 a,b ∈ [0,1]，计算 sqrt((ka+1)²+(kb+1)²) 并四舍五入，若等于 k 得 k 分。求 k=1..10^5 的期望总分。PE 答案：52.649457。

## 题目

给定 K，求 k=1..K 时期望总得分的四舍五入值（保留 6 位小数）。

## 数据范围

- 1 ≤ K ≤ 10^5
- PE 答案: K=10^5 → 52.649457

## 改编思路

### 方向一：参数化 K
将固定 10^5 改为可变输入 K。✅ 采用

### 方向二：求单个 k 的期望
给定 k 求期望得分。过于简单。❌ 不采用

### 方向三：蒙特卡洛模拟
用随机采样估计期望。不精确且低速。❌ 不采用

## 算法

几何概率：P(k) = 面积（方形 ∩ 圆环）/ k²。对于大 k，圆环完全在方形内，P(k) ≈ π/(2k)，期望 ≈ π/2。精确计算需考虑边界裁剪。
