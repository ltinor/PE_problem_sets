# 毕达哥拉斯赔率

## 题目描述

随机选择一个正整数 k，再在 [0,1] 区间内均匀随机选择两个实数 a 和 b。

计算 sqrt((k·a+1)² + (k·b+1)²) 并四舍五入到最接近的整数。若结果恰好等于 k，则获得 k 分；否则得 0 分。

对于 k = 1, 2, ..., K，求期望总得分，结果保留 6 位小数。

---

## 输入格式

一行，一个整数 K（1 ≤ K ≤ 10^5）。

---

## 输出格式

一个浮点数，保留 6 位小数，表示期望总得分。

---

## 样例

### 输入
```
10
```

### 输出
```
10.209140
```

---

## 数据范围

- 1 ≤ K ≤ 10^5
- PE 答案: K = 10^5 → 52.649457
