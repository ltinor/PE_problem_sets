# 变种考拉兹序列

## 题目描述

由 $a_1$ 开始根据下列规则生成的整数数列被称为变种考拉兹序列：

- 若 $a_n \equiv 0 \pmod 3$，则 $a_{n+1} = a_n/3$，记作操作 **D**。
- 若 $a_n \equiv 1 \pmod 3$，则 $a_{n+1} = (4a_n+2)/3$，记作操作 **U**。
- 若 $a_n \equiv 2 \pmod 3$，则 $a_{n+1} = (2a_n-1)/3$，记作操作 **d**。

一旦 $a_n = 1$，序列终止。

给定一个操作序列 $S$（由 D、U、d 组成）和一个阈值 $T$，求最小的 $a_1 > T$ 使得其操作序列以 $S$ 开头。

---

## 输入格式

一行，包含一个字符串 $S$ 和一个整数 $T$，空格分隔。

---

## 输出格式

一行一个整数，表示最小的 $a_1 > T$。

---

## 样例

### 输入
```
DdDddUUdDD 1000000
```

### 输出
```
1004064
```

---

## 数据范围

- $1 \le |S| \le 100$
- $0 \le T \le 10^{15}$
