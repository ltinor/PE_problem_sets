# 连续数的最大质因数

## 题目描述

记 f(n) 为 n 的最大质因数。对于从 n 开始的连续 9 个整数，定义 g(n) = f(n) + f(n+1) + ... + f(n+8)。

定义 h(n) 为所有 2 ≤ k ≤ n 中 g(k) 的最大值。

已知：
- f(100) = 5
- f(101) = 101
- g(100) = 409
- h(100) = 417
- h(10⁹) = 4896292593

给定 n，求 h(n)。

## 输入格式

一行，一个整数 n，或字符串 `PE`。

## 输出格式

一个整数，表示 h(n)。

## 样例

### 输入
```
100
```

### 输出
```
417
```

## 数据范围

- 对于 30% 数据：n ≤ 10⁵
- 对于 60% 数据：n ≤ 2×10⁷
- 对于 100% 数据：n ≤ 10¹⁶
