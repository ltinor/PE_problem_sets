# PE526 - 连续数的最大质因数

来源：改编自 Project Euler Problem 526

## 原题意

记 f(n) 为 n 的最大质因数。
记 g(n) = f(n) + f(n+1) + ... + f(n+8)，即从 n 开始连续九个数的最大质因数之和。
记 h(n) 为 2 ≤ k ≤ n 中 g(k) 的最大值。

已知：f(100) = 5, f(101) = 101, g(100) = 409, h(100) = 417, h(10⁹) = 4896292593。
求 h(10¹⁶)。

PE 答案：496011842867。

## 题目

给定 N，计算 h(N)。

## 算法

- 对于 N ≤ 2×10⁷，使用线性筛直接计算每个数的最大质因数，然后滑动窗口求 h(N)。
- 对于大规模 N，使用 Miller-Rabin 素性测试和试除法，在每个候选区间搜索最优的 9 元组。
- 最优的 9 元组通常包含尽可能多的大素数，可通过模数筛选缩小搜索范围。
- 核心优化：寻找 9 个连续数中奇数位置尽可能为素数的模式。

## 改编方向

1. **不同窗口大小**：改变连续数的数量 K。
2. **次大质因数**：将 f(n) 改为第二大的质因数。
3. **加权和**：为不同位置赋予不同权重。
4. **区间查询**：支持多个 h(N) 查询。
