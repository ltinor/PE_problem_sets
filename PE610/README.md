# PE610 — 罗马数字II (Roman Numerals II)

来源：改编自 Project Euler Problem 610

## 原题意

随机生成器从 {I, V, X, L, C, D, M, #} 中生成符号序列。七个字母各 14% 概率，# 为 2% 概率。从左到右记录字母，首次遇到 # 停止（不写 #）。要求已写下的序列（若非空）始终是最简形式的合法罗马数字。若将违反规则，则跳过该字母并尝试下一个。

求停止时表示的数字的期望值（空序列 = 0）。保留 8 位小数。

PE 答案：319.30207833。

## 算法

这是一个吸收马尔可夫链（absorbing Markov chain）问题。

1. 状态：当前已写下的合法罗马数字前缀。
2. 转移：添加一个合法字母（14% 概率 / 7 ≈ 排除无效字母后的归一化概率）或吸收（#，2% 概率）。
3. 每个状态 s 的值 V(s) 满足：
   V(s) = Σ_{合法字母 c} P(c | s) × V(s+c) + P(#) × value(s)

其中 P(c | s) 是给定状态 s 下抽到字母 c 且被接受（不被跳过）的条件概率。

由于字母 # 也有被跳过的概率（不会使序列无效），需要根据有效字母的比例重新归一化转移概率。最终从空状态开始递归求解期望值。

## 改编方向

1. 改变字母和 # 的概率分布。
2. 使用不同的罗马数字规则（如中世纪变体规则）。
3. 计算方差或更高阶矩。
4. 研究期望值随 # 概率变化的函数形态。
