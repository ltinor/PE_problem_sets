# 罗马数字II

## 题目描述

一个随机生成器从集合 {I, V, X, L, C, D, M, #} 中生成符号序列。在每一步中，七个字母以 14% 的等概率被选中，# 符号仅有 2% 的概率被选中。

将生成的符号从左到右写成序列，直到首次碰到 # 号（但不写下 #）。要求写下的字母序列构成一个合法的最简形式罗马数字（除非是空序列）。如果写下一个字母会违反规则，则跳过该字母，继续尝试下一个生成的符号。

求停止时所表示的数字的期望值（空序列视为 0）。四舍五入保留至小数点后 8 位。

## 输入格式

一行，字符串 `PE` 或 `verify`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案：319.30207833。
若输入为 `verify`，验证罗马数字转换和合法性检查函数。

## 样例

### 输入
```
PE
```

### 输出
```
319.30207833
```

## 数据范围

- 完整问题：无限状态马尔可夫链（有限状态空间近似）
- 验证模式：测试罗马数字转换和合法性规则
