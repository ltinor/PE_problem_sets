# 五项式系数

## 题目描述

(x+1)^k 展开的各项系数称为二项式系数。类似地，(x⁴+x³+x²+x+1)^k 展开的各项系数称为五项式系数。

考虑 (x⁴+x³+x²+x+1)³ 的展开：
x¹² + 3x¹¹ + 6x¹⁰ + 10x⁹ + 15x⁸ + 18x⁷ + 19x⁶ + 18x⁵ + 15x⁴ + 10x³ + 6x² + 3x + 1

可见 k=3 时，13 个五项式系数中有 7 个是奇数。

令 Q(k) 表示 (x⁴+x³+x²+x+1)^k 的展开式中奇数系数的数目。因此 Q(3) = 7。

已知：
- Q(10) = 17
- Q(100) = 35

求 Σ_{k=1}^{18} Q(10^k)。

## 输入格式

一行，一个整数 k（或字符串 `PE`，或 `test`）。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案：11651914152793763。
若输入为 `test`，输出 Q(3)、Q(10)、Q(100) 的验证值。
若输入为整数 k（k ≤ 500），输出 Q(k)。

## 样例

### 输入
```
3
```

### 输出
```
Q(3) = 7
```

### 输入
```
PE
```

### 输出
```
11651914152793763
```

### 输入
```
test
```

### 输出
```
Q(3) = 7 (expected 7)
Q(10) = 17 (expected 17)
Q(100) = 35 (expected 35)
```

## 数据范围

- 对于 30% 数据：k ≤ 10
- 对于 60% 数据：k ≤ 100
- 对于 100% 数据：k ≤ 500 或输入为 PE
