# PE588 — 五项式系数 (Quintinomial Coefficients)

来源：改编自 Project Euler Problem 588

## 原题意

(x+1)^k 展开的各项系数称为二项式系数。类似地，(x⁴+x³+x²+x+1)^k 展开的各项系数称为五项式系数（quintus 是拉丁语"第五"）。

考虑 (x⁴+x³+x²+x+1)³ 的展开：
x¹² + 3x¹¹ + 6x¹⁰ + 10x⁹ + 15x⁸ + 18x⁷ + 19x⁶ + 18x⁵ + 15x⁴ + 10x³ + 6x² + 3x + 1

可见 k=3 时，13 个五项式系数中有 7 个是奇数。

令 Q(k) 表示 (x⁴+x³+x²+x+1)^k 的展开式中奇数系数的数目。因此 Q(3) = 7。

已知 Q(10) = 17，Q(100) = 35。

求 Σ_{k=1}^{18} Q(10^k)。

PE 答案：11651914152793763。

## 算法

在特征 2 下，(a+b)² = a² + b²。令 P(x) = 1+x+x²+x³+x⁴。

P(x)² ≡ 1 + x² + x⁴ + x⁶ + x⁸ (mod 2)。更一般地，P(x)^{2^t} ≡ Σ_{j=0}⁴ x^{j·2^t} (mod 2)。

对一般的 k，将其写为二进制展开 k = Σ 2^{e_i}，则：
P(x)^k ≡ ∏ P(x)^{2^{e_i}} ≡ ∏ (Σ_{j=0}⁴ x^{j·2^{e_i}}) (mod 2)。

因此 Q(k) 取决于 k 的二进制表示中各位的卷积。该问题等价于：计算所有可由 {0,1,2,3,4} × {2^{e_i}} 的线性组合（无进位）表示的指数中，系数为奇数的个数。

对于大规模 k（如 k = 10¹⁸），直接 DP 不可行。Q(k) 可以通过 k 的 5 进制表示与二进制表示的相互关系，利用生成函数和数论变换高效计算。

## 改编方向

1. 推广到 m 项式系数（m 为其他素数或合数）。
2. 计算 mod p（p 为其他素数）下非零系数的数量。
3. 研究 Q(k) 的渐近增长率。
4. 统计满足特定性质的 k 值（如 Q(k) 为素数）。
