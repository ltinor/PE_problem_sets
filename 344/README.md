# 344 — Silver Dollar Game

来源：改编自 Project Euler Problem 344

## 原题意

N.G. de Bruijn 的银币游戏：n 个方格上放置 c 枚无价值硬币和 1 枚银币。两玩家轮流操作：常规操作（左移一枚硬币不跳过其他硬币）或特殊操作（将最左硬币放进口袋）。获得银币的玩家获胜。

W(n,c) 表示必胜态的数量。原题求 W(10⁶, 100) mod 1000036000099。答案：65579304332。

## 题目

输入 n 和 c，求 W(n,c)（必胜态数量）。

## 数据范围

- 1 ≤ n ≤ 50，1 ≤ c ≤ 5（OJ 版本）
- 原 PE：n = 10⁶，c = 100

## 算法

1. **Nim 等价**：银币游戏等价于 Nim 游戏，堆大小为从右数奇数位置的硬币间距。必胜态 XOR ≠ 0。
2. **枚举法**：对 n ≤ 50, c ≤ 5，枚举所有 C(n, c+1) 种硬币放置方式，计算 Nim XOR 并计数。
3. **DP + 生成函数**：对大规模数据需使用 DP 按位枚举 XOR 值。

## 改编方向

1. 原题固定 n=10⁶, c=100 → 参数化 n, c（≤ 50, ≤ 5）
2. 改变获胜条件（如改为常规 Nim）
3. 支持多组测试数据

选择方向 1：参数化 n, c。原题规模极大需高级组合技术，OJ 版降为枚举可行。
