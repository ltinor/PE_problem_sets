# 银币游戏

## 题目描述

N.G. 德布鲁因的**银币游戏**的其中一个变种描述如下：

在一长条有 n 个方格的条带上放置有 c+1 枚硬币，最多每个方格放置一枚硬币。其中只有一枚称为**银币**的硬币具有价值，其余 c 枚为无价值硬币。

两名玩家轮流进行操作，每一轮玩家可以选择进行一次**常规**操作或**特殊**操作：

- **常规操作**：选择一枚硬币，将其向左移动一或多格。硬币不能移出方格，也不能跳过或重叠其它硬币。
- **特殊操作**：将最左边的硬币放进口袋。如果不存在可行的常规操作，玩家必须将最左边的硬币放进口袋。

最先获得银币的玩家获胜。

**必胜态**是指无论后手玩家如何操作，先手玩家都能保证获胜的初始硬币放置状态。

记 W(n,c) 为有 n 个方格，c 枚无价值硬币和一枚银币时的必胜态数量。

---

## 输入格式

一行两个整数 n 和 c。

---

## 输出格式

一行一个整数，表示 W(n,c)。

---

## 样例

### 输入

```
10 2
```

### 输出

```
324
```

**解释**：已知 W(10,2) = 324。

---

## 数据范围

- 1 ≤ n ≤ 50
- 1 ≤ c ≤ 5
- c + 1 ≤ n
