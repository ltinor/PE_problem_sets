# 台阶数

## 题目描述

考虑整数 45656。可以看出 45656 的每一对相邻数字之间都差 1。这种任意一对相邻数字之间都差 1 的数称为**台阶数**（Step Number）。

一个**全数字数**（Pandigital Number）包含有 0 到 9 这 10 个数字至少各一次。

求在小于 10^D 的数中，有多少个全数字台阶数？

## 输入格式

一行一个整数 D（1 ≤ D ≤ 40），表示数字位数的上限。

## 输出格式

一行一个整数，表示答案。

---

## 样例

### 输入
```
10
```

### 输出
```
0
```

（因为至少需要 10 位数才能包含所有 0-9 各一次，且同时满足台阶条件的最小长度可能更大。）

### 输入
```
40
```

### 输出
```
126461847755
```

---

## 数据范围

- 1 ≤ D ≤ 40
- PE 原题 D=40 时答案为 126461847755。

---

## 提示

使用动态规划：dp[pos][last_digit][mask] 表示已经放置了 pos 位数字、最后一位数字是 last_digit、已经使用的数字集合为 mask（0-9）的方案数。台阶条件要求相邻数字差 1。时间复杂度 O(D × 10 × 1024)。
