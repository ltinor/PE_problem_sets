# 178 — 台阶数

来源：改编自 Project Euler Problem 178

## 原题意

求 < 10^40 的全数字台阶数个数。原题答案：126461847755。

## 题目

参数化 D：输入 D（≤ 40），求 < 10^D 的全数字台阶数个数。

## 数据范围

- D ≤ 40

## 算法

**std**: DP[pos][last_digit][mask]。台阶条件：相邻数字差 1。mask 记录 0-9 各是否至少出现一次（目标 mask = 1023）。初始化 1 位数（1-9），逐步递推。时间复杂度 O(D × 10 × 1024)。

**brute**: 枚举所有 < 10^D 的数，验证台阶条件和全数字条件。仅适用于 D ≤ 8。

## 改编方向

1. **参数化 D**：将固定 D=40 改为任意输入。
2. **DP 方法**：经典状态压缩 DP。
3. **PE 答案验证**：(D=40) 输出 126461847755。
