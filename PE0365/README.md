# 巨大的二项式系数

来源：改编自 Project Euler Problem 365

## 原题意

对 1000<p<q<r<5000 的素数三元组，求 C(10^18, 10^9) mod (p·q·r) 之和。PE 答案：162619462356610313。

## 题目

给定 n, k 和素数范围 [L,R]，求 Σ C(n,k) mod (p·q·r)，其中 L<p<q<r<R。

## 数据范围

n, k ≤ 10^12, L, R ≤ 10^4

## 算法

### 方向一：Lucas 定理 + CRT

用 Lucas 定理计算 C(n,k) mod p（p 为素数）。对于模数 p·q·r，分别计算三个余数后用中国剩余定理合并。

### 方向二：Kummer 定理

利用 Kummer 定理：C(n,k) 中素数 p 的指数 = k + (n-k) 在 p 进制下相加时的进位数。快速计算 C(n,k) mod p。

### 方向三：分段预处理

对素数范围分段，预处理小素数的阶乘和逆元。使用 Lucas 定理 O(log_p n) 计算每个模数下的结果。

### 时间复杂度

O(π(R)·log n)，π(R) 为素数个数。
