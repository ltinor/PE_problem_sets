# 子串的可整除性

来源：改编自 Project Euler Problem 43

## 原题意

求所有 0~9 全数字数（0-9 各用一次组成的 10 位数）中，满足子串整除性质（d2d3d4%2=0, d3d4d5%3=0, ..., d8d9d10%17=0）的所有数之和。

## 改编方向

此题答案固定（16695334890），作为验证题。输入可忽略（任意整数）。std 和 brute 各自独立实现 next_permutation 枚举 0~9 全排列并验证条件求和。

## 数据范围

输入任意整数（忽略）。

## 算法

std 和 brute 均使用 next_permutation 遍历 0-9 所有排列，跳过 d1=0 的情况，验证 7 个整除条件，满足条件的数累加。

## PE 原答案

16695334890
