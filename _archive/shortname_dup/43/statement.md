# 子串的可整除性

## 题目描述

1406357289 是一个 0 至 9 全数字数，因为它由 0 到 9 这十个数字排列而成；此外它还有一个有趣的性质：子串的可整除性。

记 d1 是它的第 1 个数字，d2 是第 2 个数字，依此类推：

- d2d3d4 = 406 能被 2 整除
- d3d4d5 = 063 能被 3 整除
- d4d5d6 = 635 能被 5 整除
- d5d6d7 = 357 能被 7 整除
- d6d7d8 = 572 能被 11 整除
- d7d8d9 = 728 能被 13 整除
- d8d9d10 = 289 能被 17 整除

找出所有满足同样性质的 0 至 9 全数字数，并求它们的和。

---

## 输入格式

一个整数（输入将被忽略，答案固定）。

---

## 输出格式

一个整数，表示所有满足条件的 0~9 全数字数之和。

---

## 样例

### 输入
```
0
```

### 输出
```
16695334890
```

---

## 数据范围

输入任意整数。
