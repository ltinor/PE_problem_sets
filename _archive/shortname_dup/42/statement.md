# 编码三角形数

## 题目描述

三角形数序列的第 n 项由公式 t_n = n(n+1)/2 给出。前十个三角形数是：1, 3, 6, 10, 15, 21, 28, 36, 45, 55, ...

将一个单词的每个字母分别转化为其在字母表中的顺序（A=1, B=2, ..., Z=26）并相加，所得结果即为这个单词的价值。如果单词价值是三角形数，则称该单词为三角形单词。

给定 N 个单词，统计其中三角形单词的数量。

---

## 输入格式

第一行：整数 N（0 ≤ N ≤ 2000），表示单词数量。
接下来 N 行：每行一个由大写字母 A-Z 组成的单词。

---

## 输出格式

一个整数，表示三角形单词的数量。

---

## 样例

### 输入
```
3
SKY
HELLO
WORLD
```

### 输出
```
1
```

---

## 数据范围

- 0 ≤ N ≤ 2000
- 单词长度 1~20
- 全部由大写字母 A-Z 组成
