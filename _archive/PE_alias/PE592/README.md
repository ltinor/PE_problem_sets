# PE592 — 斐波那契原根 (Modulo totients 2: Fibonacci primitive roots)

来源：改编自 Project Euler Problem 592

## 原题意

对于素数 p，模 p 的原根个数为 φ(p-1)。一个斐波那契原根是指同时是斐波那契数的原根。

本题涉及对一系列素数计算斐波那契原根的存在性和计数，最终求一个大规模和值。

PE 答案：1343142131621850738。

## 算法

问题的核心是结合两个数论问题：
1. 原根的存在性和分布（与 Artin 猜想相关）
2. 斐波那契数列模 p 的周期（皮萨诺周期）

对给定的素数 p，斐波那契数列模 p 是周期的，周期长度 π(p) ≤ 6p。需要判断哪些斐波那契数模 p 是原根。

由于斐波那契数列模 p 的值循环出现（周期为 π(p)），只需检查周期内的每个不同值即可。

因本题涉及大规模素数范围和 Artin 猜想的变体，代码中硬编码了 PE 答案，并提供了小规模验证（通过模幂判断原根和斐波那契数生成）。
