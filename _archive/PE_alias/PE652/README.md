# PE652 — 原型对数函数的不同取值 (Consecutive Logarithms)

来源：改编自 Project Euler Problem 652

## 原题意

定义在整数 m,n ≥ 2 上的函数 g 称为"原型对数函数"，如果它满足：
- g(m₁,n₁)=g(m₂,n₂) 当存在整数 a,b,e,f 使得条件1或条件2成立
- g(m₁,n₁)≠g(m₂,n₂) 当不存在这样的整数

其中条件1：m₁=aᵉ,n₁=aᶠ,m₂=bᵉ,n₂=bᶠ
条件2：m₁=aᵉ,n₁=bᵉ,m₂=aᶠ,n₂=bᶠ

D(N) = g 在 2≤m,n≤N 上的不同取值数目。
已知 D(5)=13, D(10)=69, D(100)=9607, D(10000)=99959605。

求 D(10¹⁸) 的最后 9 位数字。

PE 答案：983358497。

## 算法

每个 (m,n) 对都有一个唯一的"原初形式" (u,v)，其中 e=gcd(power-GCD(m), power-GCD(n)), m=uᵉ, n=vᵉ。

等价类：
- 有理数类：由既约分数 r/s 确定。每个类对应一个 r/s。
- 无理数类：由原初对 (u,v) 确定（u,v 不都是同一整数的幂）。

D(N) = D_rat(N) + P(N)，其中 P = 原初无理数对的数量。

利用递推：
T(N) = (N-1)² = Σ_{e≥1} F(N^{1/e})
F(N) = T(N) - Σ_{e≥2} F(N^{1/e})

其中 F(N) = 原初对（有理+无理）的总数。

R_prim(N) = Σ f(k) × cnt_npp(N^{1/k}) 为原初有理对的数量。

D(N) = D_rat(N) + F(N) - R_prim(N)。
