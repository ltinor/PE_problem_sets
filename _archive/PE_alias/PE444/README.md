# PE444 - 圆桌彩票

来源：改编自 Project Euler Problem 444

## 原题意

p 个人围坐圆桌进行彩票交易游戏。每人有一张未刮开的彩票，价值为 1 到 p 的排列。每轮玩家可选择：
1. 刮开自己的彩票
2. 用未刮开的彩票与前一位玩家已刮开的彩票交换，然后离开游戏

所有人采用最优策略最大化期望收益。E(p) 为游戏结束时留在桌上的期望人数。
S_1(N) = Σ_{p=1}^N E(p)，S_k(N) = Σ_{p=1}^N S_{k-1}(p)。

原题求 S_20(10^14) 的科学记数法（10 位有效数字），答案为 1.200856722e263。

## 题目

给定 k 和 N，求 S_k(N) 的科学记数法表示（保留 10 位有效数字）。

## 算法

- E(p) 随 p 增大收敛至约 5.29，可通过随机模拟或 DP 计算小 p 值
- S_k(N) 对于大 N 可通过组合公式近似
- 本题极难直接计算，主要通过理论分析得出渐近行为

## 改编方向

1. **改变效用函数**：彩票价值分布改为其他分布（均匀、指数等）
2. **改变规则**：允许玩家刮开后决定是否交易
3. **小规模精确解**：求 E(p) 的精确有理数值（小 p）
4. **方差分析**：求剩余人数的方差而非期望
