# 撤销函数 C

## 题目描述

对于任意整数 n>1，定义函数 f(x)≡ax+b (mod n)，其中 a,b,x 均为整数，
满足 0<a<n，0≤b<n，0≤x<n。

若对所有 0≤x<n 均有 f(f(x))≡f(x) (mod n)，则称 f 为**撤销函数**。

记 R(n) 为模 n 意义下撤销函数的个数。

定义 F(N)=∑_{n=2}^{N} R(n)。

已知 F(10⁷)≡638042271 (mod 1000000007)。

---

## 输入格式

一个整数 N (2 ≤ N ≤ 2×10⁷，或 N = 10¹⁴)。

---

## 输出格式

一个整数，表示 F(N) mod 1000000007。

---

## 样例

### 输入
```
100
```

### 输出
```
...
```

---

## 数据范围

- 对于 30% 数据：N ≤ 100
- 对于 60% 数据：N ≤ 5000
- 对于 100% 数据：N ≤ 2×10⁷ 或 N = 10¹⁴（PE 答案硬编码）
