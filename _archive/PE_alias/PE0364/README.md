# 舒适距离

来源：改编自 Project Euler Problem 364

## 原题意

N 个人按规则（优先选两侧无人的座位，其次选一侧有人，否则任意选）坐 N 个座位，求 T(N) 种方案数。PE 答案：44855254 (T(10^6) mod 10^8+7)。

## 题目

给定 N，求 T(N) mod M。

## 数据范围

N ≤ 10^6, M = 10^8+7

## 算法

### 方向一：DP + 组合数学

将规则转化为：第一个人选座位后，问题分裂为左右两个独立子区间。用 DP[n] 表示 n 个连续空座的方案数。利用对称性和组合数合并左右子结果。

### 方向二：递推 + 前缀和优化

推导 DP 递推式：T(n) = Σ C(n-1, k) × T(k) × T(n-1-k) × (某种权重)。用前缀和或卷积优化至 O(n²) 或 O(n log n)。

### 方向三：生成函数 / 指数级数

将座位选择过程建模为指数生成函数。T(N) 的 EGF 满足某种微分方程，可解析求解或快速递推。

### 时间复杂度

O(N) 或 O(N log N)。
