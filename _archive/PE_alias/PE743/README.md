# PE743 — Window into a Matrix (矩阵之窗)

来源：改编自 Project Euler Problem 743

## 原题意

矩阵的**窗口**是指矩阵中一个连续的子矩阵。

考虑一个 $2\times n$ 的矩阵，其中的元素均为 $0$ 或 $1$。
若矩阵中任意一个 $2\times k$ 的窗口中元素之和都为 $k$，记所有这样的矩阵数目为 $A(k,n)$。

已知：
- $A(3,9) = 560$
- $A(4,20) = 1060870$

求 $A(10^8, 10^{16})$ 对 $1\ 000\ 000\ 007$ 取余。

PE 答案：259158998

## 算法

1. **周期性分析**：设 $s_i = a_i + b_i$（第 $i$ 列之和），条件要求所有长度为 $k$ 的窗口和均为 $k$：
   $$\sum_{i=j}^{j+k-1} s_i = k \quad (\forall j)$$
   
   这强制 $s_i$ 以周期 $k$ 重复：$s_{i+k} = s_i$，且一个周期内之和必须等于 $k$。

2. **列配置计数**：在一个周期长度 $k$ 中，设 $c$ 列为 $2$（即 $(1,1)$）、$k-2c$ 列为 $1$（即 $(1,0)$ 或 $(0,1)$）、$c$ 列为 $0$（即 $(0,0)$）：
   $$A(k,n) = \sum_{c=0}^{\lfloor k/2\rfloor} \frac{k!}{c! \cdot (k-2c)! \cdot c!} \cdot 2^{(k-2c) \cdot \lfloor n/k\rfloor}$$

3. **大参数处理**：$k=10^8$，$n=10^{16}$ 时 $n/k = 10^8$。使用模意义的二项式定理或生成函数求和：$$\sum_{c} \binom{k}{c, k-2c, c} \cdot (2^{n/k})^{k-2c}$$

4. **复杂度**：$O(k)$ 不可行，需 $O(\sqrt{k})$ 或 $O(\log k)$ 利用组合恒等式化简。

## 改编方向

1. 参数化 $k, n$
2. 改为非矩形窗口（如 L 形、十字形）
3. 改为每窗口和为 $s \neq k$
4. 推广到 $m \times n$ 矩阵（$m > 2$）
5. 计数不同的矩阵等价类（考虑行列置换）
