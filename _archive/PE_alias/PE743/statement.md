# 矩阵之窗

## 题目描述

矩阵的**窗口**是指矩阵中一个连续的子矩阵。

考虑一个 $2\times n$ 的矩阵，其中的每个元素均为 $0$ 或 $1$。要求矩阵中**任意一个 $2\times k$ 的窗口**（即连续的 $k$ 列构成的 $2\times k$ 子矩阵）中，所有元素之和都恰好等于 $k$。

记所有满足条件的矩阵数目为 $A(k,n)$。

例如：
- $A(3,9) = 560$
- $A(4,20) = 1060870$

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出原题答案 `259158998`
- `verify`：展示小规模验证（周期结构分析及 $A(3,9), A(4,20)$）
- `compute`：输出最终答案

## 样例

### 输入
```
PE
```

### 输出
```
259158998
```

### 核心推导

窗口约束 $\sum_{i=j}^{j+k-1} s_i = k$ 意味着 $s_i$ 必须是以 $k$ 为周期的序列：
$$s_{i+k} = s_i$$

设 $s_i = a_i + b_i \in \{0, 1, 2\}$（第 $i$ 列的和），令周期内：
- $c$ 列的 $s_i = 2$（即 $(1,1)$）
- $k-2c$ 列的 $s_i = 1$（即 $(1,0)$ 或 $(0,1)$，各有 2 种）
- $c$ 列的 $s_i = 0$（即 $(0,0)$）

则：
$$A(k,n) = \sum_{c=0}^{\lfloor k/2\rfloor} \text{Multinomial}(k; c, k-2c, c) \cdot 2^{(k-2c)\lfloor n/k\rfloor}$$

其中 $\text{Multinomial} = \frac{k!}{c!(k-2c)!c!}$。

## 数据范围

- 验证范围：$k \le 4, n \le 20$
- 完整问题：$k = 10^8, n = 10^{16}$
- 答案模数：$1\ 000\ 000\ 007$
