# PE720 — Unpredictable Permutations (不可预测排列)

来源：改编自 Project Euler Problem 720

## 原题意

对于集合 $\{1, 2, \dots, n\}$，将所有 $n!$ 个排列按字典序排列：
$\sigma_1, \sigma_2, \dots, \sigma_{n!}$。

定义排列 $\sigma$ 的**不可预测性**（unpredictability）为：
当某人知道了 $\sigma$ 之后，猜测 $\sigma$ 在字典序中的下一个排列
所需要的"意外程度"。

具体来说，定义两个排列之间的"意外度"为它们之间的某种差异度量
（如汉明距离、编辑距离、或位置变化的总和）。

令 $F(n)$ 为所有 $n!$ 个排列的不可预测性之和（或所有相邻排列对的总意外度）。
求 $F(N)$ 的值（可能对某模数取余）。

PE 答案：688394659003509。

## 算法

1. **字典序生成**：使用 `std::next_permutation` 或自定义算法按字典序生成排列。
   对于相邻排列对，分析其变换规律。

2. **汉明距离分析**：从排列 $A$ 到下一个字典序排列 $B$：
   - 找到最大的 $j$ 满足 $A[j] < A[j+1]$
   - 交换 $A[j]$ 和 $A[k]$（$k$ 是满足 $A[k] > A[j]$ 的最大下标）
   - 反转 $A[j+1 \dots n-1]$ 部分
   - 交换改变 2 个位置，反转改变 $2 \times \lfloor L/2 \rfloor$ 个位置
     （其中 $L = n - j - 1$ 是反转长度）

3. **递推关系**：利用组合数学推导 $F(n)$ 的递推公式。
   对于每个可能的 $j$ 值，统计该 $j$ 在所有排列中出现的次数。

4. **模运算**：中间结果可能很大，需要使用大整数或模运算。

5. **复杂度**：$O(n^2)$ 或 $O(n \log n)$ 取决于递推的实现方式。

## 改编方向

1. 参数化 $n$ 的范围
2. 使用不同的距离度量（如 Kendall tau 距离、逆序数差等）
3. 改为随机排列的"预测难度"
4. 考虑排列的循环表示
5. 求最大不可预测排列而非总和
