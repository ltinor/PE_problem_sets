# PE580 - 无平方因子希尔伯特数 (Squarefree Hilbert Numbers)

来源：改编自 Project Euler Problem 580

## 原题意

希尔伯特数是形如 4k+1 的正整数。希尔伯特素数是大于 1 且不能分解为两个较小希尔伯特数之积的希尔伯特数。
（注意：9 = 3×3 是希尔伯特素数，因为 3 不是希尔伯特数。）

若一个希尔伯特数不能被任何希尔伯特素数的平方整除，则称其为"无平方因子"的。

令 S(N) 为不超过 N 的无平方因子希尔伯特数个数。

已知：S(10)=3, S(100)=23, S(1000)=232, S(10000)=2324, S(100000)=23265。

求 S(10^16)。

PE 答案：2327213148095366。

## 算法

小规模 N：筛法生成希尔伯特素数，标记其平方的倍数。时间复杂度 O(N log log N)。

大规模 N（如 10^16）：需用莫比乌斯反演在希尔伯特整数环上的推广。设希尔伯特 ζ 函数，利用容斥原理：
S(N) = Σ_{d: 希尔伯特数} μ_H(d) · ⌊N/(4d)⌋
其中 μ_H 是希尔伯特整数环上的莫比乌斯函数。
