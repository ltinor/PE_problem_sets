# PE443 - 最大公约数序列

来源：改编自 Project Euler Problem 443

## 原题意

序列 g(n) 定义如下：
- g(4) = 13
- g(n) = g(n-1) + gcd(n, g(n-1))，n > 4

已知 g(1000) = 2524，g(1000000) = 2624152。原题求 g(10^15)，答案为 2744233049300770。

## 题目

给定 n (n ≥ 4)，求 g(n)。

## 算法

- 直接迭代计算：对于每个 n，g(n) = g(n-1) + gcd(n, g(n-1))
- 大多数情况下 gcd = 1，序列每次递增 1
- 跳跃发生在 g(n-1) 与 n 有公因子时
- 对于 n ≤ 2×10^7 可在 1 秒内直接计算
- 更大 n 需要分析跳变模式（涉及质因子和几何级数变化）

## 改编方向

1. **改变初值**：g(1) = a，分析不同初值下序列行为
2. **改变递推**：g(n) = g(n-1) + lcm(n, g(n-1)) 或 g(n-1) + n·gcd(...)
3. **求和问题**：求 Σ g(i) mod M
4. **指定 gcd 值**：统计使得 gcd(n, g(n-1)) = d 的 n 的数量
