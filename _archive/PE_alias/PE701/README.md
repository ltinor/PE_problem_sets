# PE701 — Random connected area（随机连通区域）

来源：改编自 Project Euler Problem 701

## 原题意

考虑一个 7×7 的网格，其中每个格子独立地以 1/2 的概率为黑色，1/2 的概率为白色。求所有黑色格子组成的连通区域中，**最大连通区域的期望面积**（面积 = 包含的格子数）。

连通性定义为 4-邻接（上下左右相邻）。

PE 答案：13.51099836（8 位小数）。

## 算法

1. **暴力枚举**（仅适用于小网格）：
   - 枚举所有 2^{n×n} 种网格配置（n ≤ 4 可行）
   - 对每种配置，使用 BFS/DFS 找出所有连通分量，取最大面积
   - 计算期望值 = 总面积和 / 配置总数

2. **蒙特卡洛模拟**（适用于 7×7）：
   - 随机生成大量网格样本（每格独立以 0.5 概率为黑）
   - 对每个样本找出最大连通分量面积
   - 取平均作为期望值的近似
   - 2M 样本可收敛到 ~0.01 精度

3. **精确计算思路**：
   - 使用 Broken Profile DP（轮廓线 DP）逐格处理
   - 状态 = 前沿格子的连通分量标号
   - 前沿大小 = 8，状态数 ≈ Bell(8) × 2⁸ ≈ 1e6
   - 但需要额外跟踪"当前最大分量大小"

## 改编方向

1. 参数化网格大小 n×n
2. 改为任意概率 p（而非 1/2）
3. 求第二大连通分量的期望面积
4. 8-邻接（对角线也算连通）的情况
5. 求连通分量数量的期望值
