# PE671 — 着色环 (Colouring a Loop)

来源：改编自 Project Euler Problem 671

## 原题意

给定一个由 n 个顶点组成的环（循环图），使用 k 种颜色为顶点着色。相邻顶点不能同色，且考虑旋转对称性（即旋转后相同的着色方案视为同一种）。求所有满足条件的着色方案总数。

PE 答案：946106780。

## 算法

使用 Burnside 引理（Pólya 计数定理）处理旋转对称性：

1. 环的旋转群为循环群 C_n，大小为 n
2. 对于旋转 d 个位置，轨道数由 Burnside 公式给出：
   (1/n) × Σ_{d|n} φ(d) × P(n/d, k)
   其中 φ 为欧拉函数，P(m, k) 为长为 m 的环的正确着色数

3. 长为 m 的环的正确 k-着色数：
   P(m, k) = (k-1)^m + (-1)^m × (k-1)
   - m = 1 时：P(1, k) = k
   - m = 2 时：P(2, k) = k(k-1)

4. 使用模运算快速计算幂和逆元
