# 约数图宽度（Divisor Graph Width）

## 题目描述

对于一个正整数 $N$，定义其**约数图**如下：
- 顶点集合为 $N$ 的所有正约数。
- 若 $a \mid b$ 且 $b/a$ 为素数，则在顶点 $a$ 和 $b$ 之间连一条无向边。

该图的**宽度**定义为最大反链的大小，即最大的顶点子集，使得其中任意两个不同的顶点之间不存在整除关系。

对于 $N = \prod_{i=1}^{k} p_i^{e_i}$，宽度等于多项式 $\prod_{i=1}^{k} (1 + x + x^2 + \cdots + x^{e_i})$ 中系数的最大值。

请计算特定范围内所有数的约数图宽度之和。

## 输入格式

无输入（固定参数问题）。

## 输出格式

输出一个整数，表示最终答案。

（无样例输入输出，直接计算并输出最终答案。）
