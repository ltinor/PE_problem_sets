# 素数青蛙

## 题目描述

青蛙在1到N的方格上跳跃。每次等概率向左或向右跳一格，不能跳出范围（到达两端时下一步只能往唯一可行方向跳）。

叫声规则：
- 在素数方格上：有2/3概率叫'P'，1/3概率叫'N'
- 在非素数方格上：有1/3概率叫'P'，2/3概率叫'N'

青蛙每次叫完后立即跳跃。初始位置在1..N中等概率随机。

给定目标叫声序列S，求听到S的概率，表示为最简分数p/q。

---

## 输入格式

一行，包含整数N和字符串S，空格分隔。
- 1 ≤ N ≤ 500
- 1 ≤ |S| ≤ 20

---

## 输出格式

最简分数 p/q。

---

## 样例

### 样例1
输入：
```
5 PP
```
输出：
```
...（根据具体计算）
```

### 样例2（原PE问题）
输入：
```
500 PPPPNNPPPNPPNPN
```
输出：
```
199740353/29386561536000
```

---

## 数据范围

- 对于30%数据：N ≤ 20, |S| ≤ 5
- 对于60%数据：N ≤ 100, |S| ≤ 10
- 对于100%数据：N ≤ 500, |S| ≤ 20
