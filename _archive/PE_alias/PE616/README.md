# PE616 — 创意数 (Creative numbers)

来源：改编自 Project Euler Problem 616

## 原题意

Alice 从整数列表 $L=\{n\}$ 开始游戏，每一步可以：
- 移除 $a,b$ 并添加 $a^b$（合并）
- 移除可写成 $a^b$ 的 $c$（$a,b>1$）并添加 $a,b$（拆分）

整数 $n>1$ 是**创意数**，若从 $L=\{n\}$ 出发，对任意 $m>1$ 都能得到包含 $m$ 的列表。

求所有不超过 $10^{12}$ 的创意数之和。

PE 答案：310884668312456458。

## 算法

核心思想是将数字视为幂运算表达式树。游戏操作等价于在表达式中上下移动（合并=向上，拆分=向下）。

关键观察：
1. 素数无法被拆分也无法通过合并产生，因此只能作为"叶子"出现
2. 完美幂（如 $8=2^3$）可被拆分，其叶子集合取决于拆分路径
3. 不同的拆分路径可能产生不同的叶子集合
4. 创意数是那些通过选择不同拆分路径能够达到足够"丰富"的叶子集合（涵盖所有素数）的数

完整的数学刻画涉及幂运算图的连通分量分析。创意数正好是那些在幂运算图中与所有整数 $>1$ 处于同一连通分量的数。

实际上，该问题可以转化为分析 "高度"（迭代对数）和幂运算树的组合结构。
