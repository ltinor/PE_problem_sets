# PE354 - 蜜蜂蜂巢距离 (Distances in a bee's honeycomb)

来源：改编自 Project Euler Problem 354

## 原题意

蜂巢中每个单元是边长为 1 的正六边形。B(L) 为距离蜂后单元恰好为 L 的单元数。已知 B(√3)=6，B(√21)=12，B(111111111)=54。求 L ≤ 5·10^11 中满足 B(L)=450 的 L 个数。原题答案：58065134。

## 题目

给定上限 LIMIT 和目标值 TARGET，求满足 L ≤ LIMIT 且 B(L)=TARGET 的 L 的个数。

## 算法

B(L) 与将 M = L²/3 表示为 a²+ab+b² 的方式数有关。r(M) = 6·(d₁(M) - d₂(M))，其中 d₁、d₂ 分别是 M 的 ≡1 mod 3 和 ≡2 mod 3 的因子个数。r(M) 是乘性函数。使用质因子分解和 DFS 枚举满足条件的 M。

## 改编方向

1. **三维蜂巢**：推广到三维蜂巢结构
2. **累积计数**：求 B(L) ≤ K 的 L 个数
3. **多蜂后**：多个蜂后单元的联合距离分布
4. **不同蜂巢形状**：考虑非正六边形蜂巢
