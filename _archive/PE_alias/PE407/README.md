# PE407 - 幂等元

来源：改编自 Project Euler Problem 407

## 原题意

对于正整数 n，定义 M(n) 为满足 0 < a < n 且 a² ≡ a (mod n) 的最大整数 a。
求 sum_{n=1}^{N} M(n)。原 PE 参数：N=10⁷，答案 39782849136421。

## 题目

给定 N，求 sum_{n=1}^{N} M(n)。

## 算法

- a 是幂等元 ⇔ n | a(a-1)
- 对 n 的每个质因子幂 p^e，通过 CRT 构造幂等元：
  a ≡ 1 (mod p^e), a ≡ 0 (mod n/p^e) → a = (n/p^e) * inv(n/p^e mod p^e) mod n
- M(n) 取所有质因子幂对应的最大幂等元
- 主算法：枚举质因子幂 p^e ≤ N，遍历其倍数 n，更新 M[n]
- 复杂度 O(N log log N)

## 改编方向

1. **改变模数**：求 M(n) 在模 M 下的值
2. **最小幂等元**：改为求和最小非平凡幂等元
3. **幂等元个数**：求非平凡幂等元的总个数
4. **高次幂等**：a^k ≡ a (mod n) 的最大 a
