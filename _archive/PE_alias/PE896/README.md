# PE896 — Divisible Ranges（整除区间）

来源：改编自 Project Euler Problem 896

## 原题意

考虑区间 $[L, R]$（$1 \le L \le R \le N$）。如果对于区间内所有 $i, j$，二项式系数 $C(i+j, i)$ 都能被某个模数整除，则称该区间为"整除区间"。问题要求计算满足条件的区间数量或概率。

PE 答案：0.04860463

## 算法

1. **Lucas 定理**：
   - $C(n, k) \bmod p \neq 0$ 当且仅当 $k$ 的 $p$ 进制每位都不超过 $n$ 的对应位
   - 即 $k + (n-k)$ 在 $p$ 进制下无进位

2. **区间分析**：
   - 区间 $[L, R]$ 为整除区间当且仅当对所有 $i, j \in [L, R]$，$C(i+j, i) \equiv 0 \pmod p$
   - 这等价于 $i+j$ 的 $p$ 进制加法始终产生进位

3. **分形结构**：
   - 整除区间形成基于 $p$ 进制数字模式的分形结构
   - $[a \cdot p^k, a \cdot p^k + p^k - 1]$ 形式的块具有特殊性质

## 改编方向

1. 计算大 $N$ 下整除区间的渐近概率
2. 研究不同模数 $p$ 下的行为
3. 推广到多维区间
4. 研究整除区间数量的精确计数公式
