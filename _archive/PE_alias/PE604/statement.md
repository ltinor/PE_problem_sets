# 正方形中的凸路径

## 题目描述

F(N) 为一个严格凸的单调递增函数在 N×N 轴对齐正方形中能经过的格点数量最大值。

已知：
- F(1) = 2
- F(3) = 3
- F(9) = 6
- F(11) = 7
- F(100) = 30
- F(50000) = 1898

求 F(10¹⁸)。

## 输入格式

一行，字符串 `PE` 或 `verify`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案：1170060。
若输入为 `verify`，列出所有已知的 F(N) 值。

## 样例

### 输入
```
PE
```

### 输出
```
1170060
```

## 数据范围

- 完整问题：N = 10¹⁸
- F(N) ≈ O(N^{1/3}) ≈ 10⁶ 量级
- 需使用数论方法（欧拉函数前缀和）高效求解
