# 欧几里德算法步数

## 题目描述

欧几里德算法求 gcd(x₀, y₀) 的过程如下：

x₁ = y₀, y₁ = x₀ mod y₀
xₙ = yₙ₋₁, yₙ = xₙ₋₁ mod yₙ₋₁

E(x₀, y₀) 是使 yₙ = 0 的最小 n。

已知 E(1,1)=1, E(10,6)=3, E(6,10)=4。

定义 S(N) = Σ_{1≤x,y≤N} E(x,y)。已知 S(1)=1, S(10)=221, S(100)=39826。

求 S(N)。

---

## 输入格式

一个整数 N。

---

## 输出格式

一个整数，表示 S(N)。

---

## 样例

### 输入
```
1
```

### 输出
```
1
```

### 输入
```
10
```

### 输出
```
221
```

### 输入
```
100
```

### 输出
```
39826
```

---

## 数据范围

- 对于 30% 数据：N ≤ 100
- 对于 60% 数据：N ≤ 2000
- 对于 100% 数据：N ≤ 5·10^6
