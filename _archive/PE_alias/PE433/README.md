# PE433 - 欧几里德算法步数

来源：改编自 Project Euler Problem 433

## 原题意

E(x,y) 为欧几里德算法求 gcd(x,y) 的步数。S(N) = Σ_{1≤x,y≤N} E(x,y)。
已知 S(1)=1, S(10)=221, S(100)=39826。
原题求 S(5·10^6)，答案为 326624372659664。

## 题目

给定 N，求 S(N) = Σ_{1≤x,y≤N} E(x,y)。

## 算法

- E(x,y) 等于 x/y 连分数展开的项数
- 利用对称性：E(x,y) ≠ E(y,x) 一般情况
- 小 N 直接枚举 O(N²)
- 大 N 使用 Stern-Brocot 树统计
- 利用欧几里德算法的商序列进行计数

## 改编方向

1. **带权步数**：每步带权重（如商的大小）
2. **限定范围**：L ≤ x,y ≤ R
3. **多维扩展**：3 个数的欧几里德算法
4. **二进制欧几里德**：使用 Stein 算法
