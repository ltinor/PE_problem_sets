# 超级全数字数

## 题目描述

一个正数在 b 进制下称为全数字数（pandigital），当且仅当它的 b 进制表示中，数字 0 到 b-1 每个至少出现一次。

一个 n-超全数字数（n-super-pandigital number）是在所有进制 2 到 n 下都全数字的数。

例如，978 是最小的 5-超全数字数：
- 二进制：1111010010（包含 0 和 1）
- 三进制：1100020（包含 0, 1, 2）
- 四进制：33102（包含 0, 1, 2, 3）
- 五进制：12403（包含 0, 1, 2, 3, 4）

已知：
- 最小的 10-超全数字数是 1093265784。
- 10 个最小的 10-超全数字数之和为 20319792309。

## 输入格式

一行，输入 `PE` 返回答案，或输入 `n` 查找第 1 个 n-超全数字数，或输入 `n k` 查找第 k 个。

## 输出格式

一个整数。

## 样例

### 输入
```
5
```

### 输出
```
978
```

### 输入
```
PE
```

### 输出
```
3051039070197896
```

## 数据范围

- 对于小规模测试：n ≤ 7
- 对于 PE 答案：n 可达 40
