# 音乐节

## 题目描述

$12n$ 个音乐家参加了一场音乐节。

第一天，他们组成了 $3n$ 个**四重奏**（每组 4 人），演奏了一整天。

这一天的演奏简直是场灾难。在当天结束的时候，所有的音乐家都决定不再和这一天一同演奏四重奏的其它音乐家合作。

第二天，他们组成了 $4n$ 个**三重奏**（每组 3 人），每位音乐家都避开了第一天的合作者（即同一三重奏中不能有两人在上一天的四重奏中同组）。

记 $f(12n)$ 为这 $12n$ 位音乐家组成三重奏的方案数（假定第一天的四重奏分组已给定）。

已知：
- $f(12) = 576$
- $f(24) \equiv 509089824 \pmod{10^9+7}$

---

## 输入格式

一个整数 $N = 12n$（$n$ 为正整数）。

---

## 输出格式

一个整数，表示 $f(N) \bmod (10^9+7)$。

---

## 样例

### 输入
```
12
```

### 输出
```
576
```

---

## 数据范围

- 对于 30% 数据：$N = 12$
- 对于 60% 数据：$N = 12, 24$
- 对于 100% 数据：$N = 12, 24, 36, 48, 600$
