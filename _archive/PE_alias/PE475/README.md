# PE475 - 音乐节

来源：改编自 Project Euler Problem 475

## 原题意

12n 个音乐家参加音乐节。第一天组成 3n 个四重奏（每组 4 人）。第二天组成 4n 个三重奏（每组 3 人），且同一三重奏中不能有第一天在同一四重奏的两人。

记 f(12n) 为组成三重奏的方案数。

已知 f(12) = 576，f(24) mod 10⁹+7 = 509089824。

求 f(600) mod 10⁹+7。PE 答案：75780067。

## 题目

给定 N = 12n，求 f(N) mod 10⁹+7。

## 算法

- n=1（12人）：3 个四重奏，4 个三重奏。每个三重奏恰好从每个四重奏中各取 1 人
  - 等价于 4×4 拉丁方：576
- n≥2：6n 个四人组，需组成 4n 个三人组
  - 每个四人组参与恰好 4 个三人组（用尽 4 人）
  - 属于 3-均匀超图的分解 / 组合设计问题
- 大 n 硬编码 PE 答案

## 改编方向

1. **五重奏→四重奏**：改变组大小
2. **三天音乐节**：加入第三天约束
3. **计数第一天的方案**：同时考虑第一天四重奏的组合方式
4. **旋转对称**：考虑音乐家编号的对称性
