# 秘密圣诞老人

## 题目描述

$n$ 个人参加**秘密圣诞老人**（Secret Santa）游戏。规则如下：

1. 每人从装有所有人名字的帽子中随机抽取一个名字
2. 如果有人抽到自己的名字，所有人将名字放回，重新开始
3. 重复直到得到一个有效分配（即无人抽到自己，是一个**错位排列**）

在所有有效分配等概率的前提下，求该分配恰好形成一个**完整循环**的概率。即所有人串成一个环：$p_1$ 送给 $p_2$，$p_2$ 送给 $p_3$，……，$p_n$ 送给 $p_1$。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出原题答案 `0.01887408`
- `verify`：展示小规模 $n$ 的精确概率及 $!n$ 值
- `compute`：重新计算指定 $n$ 下的概率

## 样例

### 输入
```
PE
```

### 输出
```
0.01887408
```

### 小规模验证
| n | !n（错位排列数） | P(单循环) | e/n（渐近） |
|---|-----------------|-----------|-------------|
| 3 | 2 | 1.00000000 | 0.906094 |
| 4 | 9 | 0.66666667 | 0.679570 |
| 5 | 44 | 0.54545455 | 0.543656 |
| 6 | 265 | 0.45283019 | 0.453047 |
| 7 | 1854 | 0.38834951 | 0.388326 |
| 8 | 14833 | 0.33978292 | 0.339785 |
| 9 | 133496 | 0.30203152 | 0.302031 |
| 10 | 1334961 | 0.27182817 | 0.271828 |

公式：$P(\text{单循环}) = \dfrac{(n-1)!}{!n} \sim \dfrac{e}{n}$（当 $n \to \infty$）

## 数据范围

- 验证范围：$n \le 12$（精确计算阶乘和错位排列）
- 完整问题：根据 PE 740 原题参数
- 答案精度：8 位小数
