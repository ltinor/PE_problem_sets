# PE416 - 青蛙的旅途

来源：改编自 Project Euler Problem 416

## 原题意

在一行 n 个方块上，青蛙从最左边跳至最右边再跳回。向右每次跳 1/2/3 格，向左同理。进行 m 次往返。F(m,n) 统计至多有一个方块从未被访问的走法数。原题求 F(10, 10^12) mod 10^9，答案为 898082747。

## 题目

给定 m 和 n，求 F(m,n) mod 10^9。

## 算法

- 枚举所有可能的向右/向左路径（跳 1/2/3 步）
- 对每次往返，组合向右和向左路径
- 统计访问覆盖 ≥ n-1 个方块的组合数
- 小参数可用枚举；大参数需组合数学/DP

## 改编方向

1. **改变跳跃步长**：允许跳 1/k 步或任意步
2. **改变约束**：要求恰好 k 个方块未访问
3. **多维网格**：在二维网格上跳跃
4. **改变方向**：允许蛇形往返
