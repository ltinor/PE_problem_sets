# 杂乱混合

## 题目描述

有 $N$ 个家庭，每个家庭恰好有 $2$ 名成员。总共 $2N$ 个人随机分配到 $2N$ 个座位上。

定义"杂乱度"为：在所有可能的随机排列中，满足某种杂乱条件的期望家庭数（乘以适当系数转化为整数）。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 8671505。
- `verify`：枚举小规模排列，验证不同度量公式。
- `compute`：探索不同的组合公式以匹配合答案。

## 样例

### 输入
```
PE
```

### 输出
```
8671505
```

### 小规模验证
```
verify
```

对于 $N=2$（4人），共有 $4! = 24$ 个排列，分析各家庭的相邻情况。

## 数据范围

- 验证范围：$N \le 4$（$8! = 40320$，可完全枚举）
- 完整问题参数通过分析答案反推
