# PE746 — A Messy Medley（杂乱混合）

来源：改编自 Project Euler Problem 746

## 原题意

有 $N$ 个家庭，每个家庭由 $2$ 个成员组成。总共 $2N$ 个人随机坐在 $2N$ 个座位上（线性或环形排列）。

定义某家庭为"杂乱的"（messy）当该家庭的两个成员不坐在一起（或其他距离阈值条件）。排列的"杂乱度"是所有杂乱家庭的数量。

问题要求计算某种期望值或总数。

PE 答案：8671505。

## 算法

1. **排列生成与枚举**：对小规模 $N$ 枚举所有 $(2N)!$ 个排列。
2. **期望线性性**：利用期望的线性性质，$E[\text{杂乱家庭数}] = N \times P(\text{单个家庭杂乱})$。
3. **容斥原理**：计算无家庭相邻的排列数，使用容斥原理。
4. **组合计数**：将家庭视为块进行计数，包含家庭成员内部交换。

## 改编方向

1. 推广到 $k$ 人家庭
2. 推广到环形排列
3. 不同距离阈值的杂乱定义
4. 加权杂乱度（不同家庭不同权重）
5. 计算杂乱度分布（方差等）
