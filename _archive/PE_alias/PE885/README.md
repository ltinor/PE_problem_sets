# PE885 — Sorted Digits（排序数字）

来源：改编自 Project Euler Problem 885

## 原题意

考虑十进制表示中各位数字非严格递增（从左到右不降）的正整数。例如：1、12、113、999、111222 都是"排序数字"。

问题涉及统计或求和某种范围内的排序数字数量或相关属性。

PE 答案：827759707

## 算法

1. **组合计数**：
   - 恰好 d 位的排序数字个数 = C(d+8, 8)
   - 从 10 个数字（0-9）中有重复地选 d 个并排序，但首位不能为 0

2. **生成函数**：
   - 排序数字的计数生成函数为 (1-x)^{-10} 的变体
   - 考虑首位非零约束

3. **数位 DP**：
   - 对于给定上界 N，统计 ≤ N 的排序数字个数
   - 状态：(位置, 前一位数字, 是否已达上界)

4. **求和**：
   - 排序数字的和可通过每位的贡献计算
   - 利用数字计数和位置权重的组合
