# 最小质因数

## 题目描述

对于正整数 n > 1，记 smpf(n) 为 n 的最小质因数。例如 smpf(91)=7（因为 91=7×13），smpf(45)=3（因为 45=3×3×5）。

定义 S(n) = Σ_{i=2}^n smpf(i)，即所有 2 到 n 之间整数的最小质因数之和。

例如 S(100) = 1257。

给定整数 n，求 S(n) mod 10⁹。

## 输入格式

一行，一个整数 n，或字符串 `PE`。

## 输出格式

一个整数，表示 S(n) mod 10⁹。

## 样例

### 输入
```
100
```

### 输出
```
1257
```

## 数据范围

- 对于 30% 数据：n ≤ 10⁵
- 对于 60% 数据：n ≤ 10⁷
- 对于 100% 数据：n ≤ 10¹²
