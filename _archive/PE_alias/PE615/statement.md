# 第一百万个拥有至少一百万个质因数的数

## 题目描述

考虑所有拥有至少 k 个质因数的自然数（质因数不必互不相同）。将这些数按从小到大排序。

例如，拥有至少 5 个质因数的数列开头是：
- 32 = 2·2·2·2·2
- 48 = 2·2·2·2·3
- 64 = 2·2·2·2·2·2
- 72 = 2·2·2·3·3
- 80 = 2·2·2·2·5
- 96 = 2·2·2·2·2·3
- ...

所以，第五个拥有至少 5 个质因数的数是 80。

求第一百万个（即按升序排列的第 1,000,000 个）拥有至少一百万个质因数的数。将答案对 123454321 取模。

## 输入格式

一行，字符串 `PE` 或 `verify`。

## 输出格式

- 若输入为 `PE`，输出 PE 原题的答案：108424772。
- 若输入为 `verify`，验证 k=5 时 a₅(5)=80，并输出前 10 项。

## 样例

### 输入
```
PE
```

### 输出
```
108424772
```

## 数据范围

- 完整问题：k = m = 1,000,000，模数 123454321
- 验证模式：k = 5，枚举验证前 10 项
