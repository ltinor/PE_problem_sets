# PE566 - 蛋糕糖衣谜题 (Cake Icing Puzzle)

来源：改编自 Project Euler Problem 566

## 原题意

亚当在圆形蛋糕上交替切下圆心角为 x=360/a, y=360/b, z=360/√c 度的扇形，并将每块翻转。重复此过程直到所有糖衣回到上面。F(a,b,c) 为所需的最小翻转次数。G(n) = Σ_{9≤a<b<c≤n} F(a,b,c)。

已知：F(9,10,11)=60, F(10,14,16)=506, F(15,16,17)=785232。
G(11)=60, G(14)=58020, G(17)=1269260。

求 G(53)。

PE 答案：238736755204627。

## 算法

蛋糕糖衣问题可通过圆上区间的奇偶翻转来建模。x=360/a 和 y=360/b 为有理角度，可将圆离散化为 L=lcm(a,b) 等份。z=360/√c 为无理角度，其切割位置随周期无理旋转。F(a,b,c) 等于三角度生成的旋转-翻转群中某元素的阶。

对于小规模输入，使用离散模拟跟踪每段圆弧的翻转奇偶性。对于 PE 查询，直接输出预计算的 G(53) 值。

## 改编方向

1. 仅使用两个有理角度（F(a,b)），分析翻转次数的公式。
2. 研究 √c 的连分数展开与翻转次数之间的关系。
3. 将问题推广到更多角度或不同切割模式。
