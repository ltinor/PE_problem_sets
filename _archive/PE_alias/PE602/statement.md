# 抛硬币结果的乘积

## 题目描述

Alice 和 n 个朋友围坐，用一枚 P(反面)=p 的硬币轮流抛掷。每人记录正面次数。Alice 抛出正面时游戏结束，她将所有朋友的正面次数相乘得到随机数。

定义 e(n, p) 为期望值，它是 p 的多项式。c(n, k) 为 pᵏ 的系数。

已知：
- e(3, p) = p³ + 4p² + p
- c(100, 40) ≡ 986699437 (mod 10⁹+7)

求 c(10⁷, 4×10⁶) mod (10⁹+7)。

## 输入格式

一行，字符串 `PE` 或 `verify`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案：269496760（mod 10⁹+7）。
若输入为 `verify`，验证已知的 c(3,1)、c(3,2)、c(3,3) 和 c(100,40)。

## 样例

### 输入
```
PE
```

### 输出
```
269496760
```

## 数据范围

- 完整问题：n = 10⁷，k = 4×10⁶
- 模数：10⁹ + 7
- 计算需 O(n + k·log n) 时间，约 10⁷ 量级操作
