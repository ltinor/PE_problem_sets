# 爆炸序列

## 题目描述

定义一个整数序列 $b_1, b_2, b_3, \dots$ 如下：

- $b_1 = 1$
- 对于 $n > 1$，$b_n$ 是大于 $b_{n-1}$ 的最小整数，满足：将 $b_1, b_2, \dots, b_n$ 的十进制表示按顺序连接后，得到的字符串中包含数字 $0$ 到 $9$ 每个至少一次。

例如：
- $b_1 = 1$，连接字符串为 `1`，不含 0,2-9
- $b_2 = 2$，连接字符串为 `12`，不含 0,3-9
- ...
- 序列继续增长，直到某个 $b_k$ 使得连接字符串涵盖 0-9

求第 $N$ 项 $b_N$ 的值。

## 输入格式

一个整数 $N$（$1 \le N \le 10^6$），或字符串 `PE`。

## 输出格式

一个整数，表示 $b_N$。

## 样例

### 输入
```
5
```

### 输出
```
5
```

## 数据范围

- 对于 30% 数据：$N \le 100$
- 对于 60% 数据：$N \le 1000$
- 对于 100% 数据：$N \le 10^6$
