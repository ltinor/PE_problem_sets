# 球面三角形

## 题目描述

**球面三角形**是在球面上由三条大圆圆弧两两相交所构成的图形。

记 C(r) 为中心在 (0,0,0)，半径为 r 的球。
记 Z(r) 为 C(r) 表面上整数坐标点的集合，即满足 x²+y²+z²=r² 的整数点 (x,y,z)。
记 T(r) 为顶点均在 Z(r) 中的球面三角形构成的集合（不含三个顶点共大圆的退化情况）。
记 A(r) 为 T(r) 中最小球面三角形的面积。

给定 R，求 Σ_{r=1}^{R} A(r)，四舍五入到六位小数。

例如：A(14) = 3.294040。

---

## 输入格式

一个整数 R。

---

## 输出格式

一个小数，四舍五入到六位小数。

---

## 样例

### 输入
```
14
```

### 输出
```
29.463683
```

（这是 r=1..14 的 A(r) 之和的参考值）

---

## 数据范围

- 对于 30% 数据：R ≤ 10
- 对于 60% 数据：R ≤ 25
- 对于 100% 数据：R ≤ 50
