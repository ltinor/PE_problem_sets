# PE886 — Coprime Permutations（互质排列）

来源：改编自 Project Euler Problem 886

## 原题意

统计 {1, 2, ..., n} 的所有排列中，满足相邻元素互质（gcd = 1）的排列数量。

等价于在 n 个顶点的互质图（边 (i,j) 当且仅当 gcd(i,j)=1）中计算哈密顿路径的数量。

## 算法

1. **状态压缩 DP**：
   - dp[mask][last] = 已访问顶点集合为 mask，最后访问 last 的路径数
   - 时间复杂度 O(n²·2^n)，对 n ≤ 15 可行

2. **对称性约简**：
   - 1 与所有数互质，可放在任意位置
   - 奇偶性约束：相邻元素不能同为偶数

3. **生成函数方法**：
   - 对较大 n，使用互质图的特征多项式
   - 利用转移矩阵的谱分解加速

## 改编方向

1. 限制某些元素必须在特定位置
2. 循环排列（首尾也需互质）
3. 推广到其他数列
4. 不互质排列（相邻元素必须有公因子）
