# PE702 — Jumping Flea（跳蚤）

来源：改编自 Project Euler Problem 702

## 原题意

一只跳蚤在非负整数数轴上跳跃。定义函数 G(n) = ⌊n / S(n)⌋，其中 S(n) 是 n 的十进制数字和。跳蚤从某个起点开始，每次可以跳到一个由特定规则确定的位置。求所有 ≤ N 的正整数中无法到达的位置之和，或者是某类统计值。

PE 答案：62230560818495448。

## 算法

1. **数字和函数**：S(n) = Σ digits of n，在 O(log₁₀ n) 时间内计算。

2. **可达性分析**：
   - 若 f(n) = n + S(n)（正向跳跃），则从任意起点可到达无穷多个位置
   - 若考虑双向跳跃（n ± S(n)），可达集合可通过 BFS 确定
   - 从 1 出发，前向跳跃总是严格递增，因此所有正向跳跃产生的数都是唯一的

3. **不可达集合**：
   - 对于前向跳跃 f(n) = n + S(n)，某些数字永远无法到达
   - 这些数字被称为"自我数"（self numbers）或"哥伦比亚数"
   - 不可达数字的密度约为 1/10

4. **高效计算**：
   - 对于大范围 N（如 10¹⁴），需要使用数位 DP 或分段筛法
   - 利用 S(n) 的周期性（模 9）简化计算
   - 分段筛法：将 [1, N] 分成块，每块内生成所有可到达的数
