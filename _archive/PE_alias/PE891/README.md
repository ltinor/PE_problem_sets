# PE891 — Unambiguous Clock（无歧义时钟）

来源：改编自 Project Euler Problem 891

## 原题意

考虑一个时针和分针不可区分的模拟时钟。仅通过两只指针的位置无法唯一确定时间，因为交换时针和分针的位置通常会得到另一个有效时间。

问题要求：在 12 小时周期内，有多少时刻可以仅通过指针位置（不区分哪根是时针）唯一确定时间？

## 算法

1. **指针位置公式**：
   - 时针角度 $\alpha = 30h + m/2$（度）
   - 分针角度 $\beta = 6m$（度）
   - $(h, m) \in \{0, \dots, 11\} \times \{0, \dots, 59\}$

2. **歧义条件**：
   - 交换后 $(\alpha, \beta) \to (\beta, \alpha)$
   - 解方程 $(\beta, \alpha)$ 对应有效时间 $(h', m')$
   - $m' = 5h + m/12$，$h'$ 由方程确定

3. **无歧义条件**：
   - $m \not\equiv 0 \pmod{12}$ 时无歧义
   - $m \equiv 0 \pmod{12}$ 时需要额外判断

## 改编方向

1. 考虑秒针不可区分
2. 非 12 小时制时钟
3. 指针长度信息可用
4. 最小歧义度分析
