# PE897 — Connected Prime Squares（连通素数平方）

来源：改编自 Project Euler Problem 897

## 原题意

考虑 $N \times N$ 的网格，其中格子 $(i, j)$ 被标记当且仅当 $i^2 + j^2$ 是素数。两个被标记的格子若共享一条边（四方向相邻）则称为"连通"。问题要求计算最大连通分量的大小或连通分量的总数。

PE 答案：460088576432531620

## 算法

1. **高斯素数**：
   - $i^2 + j^2$ 为素数与高斯整数环 $\mathbb{Z}[i]$ 中的素元相关
   - 模 4 余 1 的素数可表示为两平方和（费马平方和定理）

2. **连通分量**：
   - 使用并查集（DSU）追踪网格中的连通分量
   - 对每个被标记的格子，检查四个邻居

3. **聚合**：
   - 对所有 $N$ 求和最大连通分量大小
   - 利用对称性和周期性优化
