# PE573 - 不公平骰子 (Unfair Wagers with Dice)

来源：改编自 Project Euler Problem 573

## 原题意

一个 n 面公平骰子，面值为 1 到 n。反复掷骰子，每次掷之前可以选择停止并获得当前累计分数。但如果掷出 1（"爆点"），累计分数清零，游戏结束分数为 0。

目标是最大化期望分数。设 E(n) 为最优策略下的期望分数。

已知 E(6) ≈ 6.425（最优停止阈值约为累计和 ≥ 15）。

求 Σ_{n=3}^{11} E(n)，四舍五入保留 4 位小数。
PE 答案：1252.9809。

## 算法

最优停止问题，可使用动态规划（值迭代）求解。

设 V(s) 为当前累计和为 s 时的最优期望分数：
- 若停止：V(s) = s
- 若继续：V(s) = (1/n) · Σ_{k=2}^{n} V(s+k)
- V(s) = max(s, 继续期望)

当 s 足够大时最优策略是停止。阈值 T(n) 满足：当 s ≥ T(n) 时停止。

对于 PE 范围内的 n（3 到 11），值迭代可以在合理时间内收敛。
