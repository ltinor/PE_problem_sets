# 不公平骰子

## 题目描述

有一个 n 面的公平骰子，面值为 1, 2, ..., n。游戏规则如下：

1. 初始累计分数为 0。
2. 每轮：你可以选择停止，获得当前累计分数作为最终得分。
3. 如果选择继续，掷一次骰子：
   - 若掷出 1，累计分数清零，游戏结束，得分为 0。
   - 若掷出 k（2 ≤ k ≤ n），累计分数增加 k，继续下一轮。

你希望最大化期望得分。设 E(n) 为采用最优策略时的期望得分。

例如，n=6 时，最优策略为当累计和 ≥ 15 时停止，期望得分约为 6.425。

## 输入格式

一行，输入 `PE` 返回 PE 答案，输入 `test` 显示各 n 的详细结果，或输入 `n` 计算单个 E(n)。

## 输出格式

保留适当小数位数。

## 样例

### 输入
```
6
```

### 输出
```
6.425...
```

### 输入
```
PE
```

### 输出
```
1252.9809
```

## 数据范围

- 小规模测试：n ≤ 11
- PE 答案：Σ_{n=3}^{11} E(n)，保留 4 位小数
