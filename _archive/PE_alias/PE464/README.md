# PE464 - 莫比乌斯函数和区间 (Möbius function and intervals)

来源：改编自 Project Euler Problem 464

## 原题意

P(a,b) 为区间 [a,b] 中 μ(n)=1 的整数个数，N(a,b) 为 μ(n)=-1 的个数。

C(n) 为满足以下条件的整数对 (a,b) 个数：
- 1 ≤ a ≤ b ≤ n
- 99·N(a,b) ≤ 100·P(a,b)
- 99·P(a,b) ≤ 100·N(a,b)

已知 C(10)=13, C(500)=16676, C(10000)=20155319。

原题求 C(20,000,000) = 198775297232878。

## 题目

给定 n，求 C(n)。

## 算法

- 线性筛计算莫比乌斯函数 μ(n) 直到 n
- 条件等价于 P(a,b) 和 N(a,b) 相差不超过 1%
- 使用前缀和将区间条件转化为 2D 偏序计数问题
- 对于小规模 n 使用 O(n²) 枚举，大规模已知答案

## 改编方向

1. **不同容忍度**：将 99/100 改为其他比例
2. **莫比乌斯累积和**：直接求 Mertens 函数的相关性质
3. **多区间**：求三个或更多子区间同时满足条件
