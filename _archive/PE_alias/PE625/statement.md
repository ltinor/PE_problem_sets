# 最大公约数和

## 题目描述

定义函数 G(N) 如下：

G(N) = Σ_{j=1}^{N} Σ_{i=1}^{j} gcd(i, j)

已知 G(10) = 122。

求 G(10¹¹)，并将答案对 998244353 取模。

## 输入格式

一行，字符串 `PE` 或 `verify` 或 `compute`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案：551614306。

若输入为 `verify`，输出 G(10) 和 G(100) 的暴力验证结果。

若输入为 `compute`，实际计算 G(10¹¹) mod 998244353。

## 样例

### 输入
```
PE
```

### 输出
```
551614306
```

## 数据范围

- 完整问题：N = 10¹¹
- 验证模式：N ∈ {10, 100}
