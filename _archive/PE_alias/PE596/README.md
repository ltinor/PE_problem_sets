# PE596 — 超球中的格点数目 (Number of lattice points in a hyperball)

来源：改编自 Project Euler Problem 596

## 原题意

T(r) = 满足 x² + y² + z² + t² ≤ r² 的整数四元组 (x,y,z,t) 的个数，即四维超球中的格点数。

已知：T(2)=89，T(5)=3121，T(100)=493490641，T(10⁴)=49348022079085897。

求 T(10⁸) mod 1000000007。

PE 答案：734582049。

## 算法

使用雅可比四平方和定理：
- r₄(n) = 表示 n 为四个平方和的方式数
- r₄(0) = 1
- 对 n ≥ 1：r₄(n) = 8 Σ_{d|n, 4∤d} d

因此：T(r) = 1 + Σ_{n=1}^{r²} r₄(n) = 1 + 8 Σ_{n=1}^{r²} Σ_{d|n, 4∤d} d

交换求和次序：T(r) = 1 + 8 Σ_{d=1}^{r², 4∤d} d · ⌊r²/d⌋

设 N = r² = 10¹⁶。使用下取整除法分块技术：
- ⌊N/d⌋ 只取 O(√N) = O(r) 个不同值
- 对每个块 [l, r_max]（其中 ⌊N/d⌋ 为常数 q），计算 Σ d·q

对每个余数类 d ≡ 1,2,3 (mod 4) 分别处理。

时间复杂度 O(r) = O(10⁸)，在优化 C++ 中可行。

最终结果模 MOD = 1000000007。

## 改编方向

1. 推广到 k 维超球（需 k 平方和定理）。
2. 研究其他区域（如立方体、单纯形）中的格点计数。
3. 研究 T(r) 的渐近展开（主项为 π²r⁴/2）。
4. 计算格点数的精确值（而非模值）用于更小的 r。
