# PE611 — 平方数与走廊 (Hallway of Square Steps)

来源：改编自 Project Euler Problem 611

## 原题意

彼得在有 N+1 扇门的走廊中来回移动，门上依次标有整数 0 至 N。所有门初始关闭。彼得从 0 号门开始，重复执行以下步骤：

1. 移动到距离当前位置为一个正平方数 a² 的门。
2. 移动到距离新位置为另一个更大的平方数 b²（b > a）的门。
3. 改变当前门的状态（开↔关）。
4. 返回 0 号门。

一次行动定义为完整执行上述步骤。彼得不会重复完全相同的行动，并确保所有满足 a² + b² ≤ N 的行动都恰好执行一次。

记 F(N) 为所有行动结束后开着的门数量。已知 F(5)=1，F(100)=27，F(1000)=233，F(10⁶)=112168。求 F(10¹²)。

PE 答案：49283254100。

## 算法

1. 每次行动 (a², b²) 将门 d = a² + b² 切换状态。
2. 令 r(d) = #{(a,b): 0<a<b, a²+b²=d}。门 d 最终打开当且仅当 r(d) 为奇数。
3. 因此 F(N) = #{d ≤ N : r(d) ≡ 1 (mod 2)}。
4. 利用两平方和表示数 r₂(d) 与除数函数的关系：r₂(d) 的奇偶性取决于 d 的素因子分解中形如 p ≡ 1 (mod 4) 的幂次。
5. 对 N = 10¹²，需要高效的数论方法计算满足条件的 d 的数量。

## 改编方向

1. 改变步长规则（如使用立方数、三角数等）。
2. 改变行动次数限制（允许部分行动重复执行）。
3. 推广到三维或多维走廊。
4. 研究 F(N) 的渐近行为或模特定数的周期性。
