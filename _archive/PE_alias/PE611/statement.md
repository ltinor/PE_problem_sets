# 平方数与走廊

## 题目描述

彼得在有 N+1 扇门的走廊中移动，门上依次标有整数 0 至 N。开始时所有门都是关闭的。彼得从 0 号门开始，重复执行以下步骤：

1. 移动到距离当前位置为一个正平方数 a² 的门。
2. 移动到距离新位置为另一个更大的平方数 b²（b > a）的门。
3. 改变当前面对的门的状态（如果是关着的就打开，如果是开着的就关上）。
4. 最后回到 0 号门。

将完整执行上述步骤称为一次行动。彼得不会执行两次完全相同的行动，但同时会执行所有在过程中不会越过最后一扇门的行动。

记 F(N) 为彼得执行完所有可能的行动后仍然开着的门的数量。例如，F(5)=1，F(100)=27，F(1000)=233，F(10⁶)=112168。

求 F(10¹²)。

## 输入格式

一行，字符串 `PE` 或 `verify`。

## 输出格式

- 若输入为 `PE`，输出 PE 原题的答案：49283254100。
- 若输入为 `verify`，对小规模 N 验证 F(N) 的计算结果。

## 样例

### 输入
```
PE
```

### 输出
```
49283254100
```

## 数据范围

- 完整问题：N = 10¹²
- 验证模式：N ≤ 1000 的暴力枚举验证
