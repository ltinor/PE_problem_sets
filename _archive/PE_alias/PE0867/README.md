# PE867 — T-polyominoes（T多联骨牌）

来源：改编自 Project Euler Problem 867

## 原题意

T 多联骨牌是由 4 个正方形组成的 T 形骨牌（一排三个，中间下方一个）。本题涉及 T 形骨牌的计数或铺砖问题：
- 统计 T 形骨牌铺满某个网格的方式数。
- 统计 n 阶 T 形多联骨牌（由 n 个 T 形组合而成）的个数。

## 算法

1. **方向枚举**：T 形骨牌有 4 种旋转方向。
2. **回溯搜索**：对小网格使用 DFS 回溯枚举所有铺砖方式。
3. **状态压缩 DP**：对较大网格使用 DP with bitmask。
4. **多联骨牌枚举**：使用 DFS 从基本 T 形生长更复杂的形状。
