# 蚂蚁迁徙

## 题目描述

在 n×n 的网格上，每个格子有一只蚂蚁。所有蚂蚁同时移动到一个相邻格子（上下左右），移动后不能有多只蚂蚁在同一格子，且不能有两只蚂蚁穿过同一条边。

记 f(n) 为满足条件的移动方案总数。

给定 n，求 f(n)。

---

## 输入格式

一个整数 n。

---

## 输出格式

一个整数，表示 f(n)。

---

## 样例

### 输入
```
4
```

### 输出
```
88
```

---

## 数据范围

- 对于 30% 数据：n ≤ 4
- 对于 60% 数据：n ≤ 6
- 对于 100% 数据：n ≤ 10
