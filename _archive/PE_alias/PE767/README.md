# PE767 — Window into a Matrix II（矩阵之窗 II）

来源：改编自 Project Euler Problem 767

## 原题意

给定一个 $N \times N$ 的矩阵 $A$，其元素通过递推关系（或线性同余生成器）生成。定义一个 $K \times K$ 的"窗口"为矩阵的一个 $K \times K$ 子矩阵。将窗口在矩阵上滑动（每次移动一行或一列），考虑窗口内所有元素的和（或其他统计量）。

问题是 PE 766 "Window into a Matrix I" 的扩展，可能在更大尺寸、不同窗口大小或更复杂的统计量上进行计算。

PE 答案：783976161。

## 算法

1. **矩阵生成**：使用线性同余生成器 $A_{n+1} = (A_n \cdot a + b) \bmod m$ 填充矩阵。
2. **二维前缀和**：构建前缀和数组，实现 $O(1)$ 时间查询任意 $K \times K$ 窗口的元素和。
3. **滑动窗口枚举**：遍历所有可能的窗口位置 $(i, j)$，使用前缀和计算窗口和。
4. **贡献分析**：对于所有窗口大小 $K$ 的总和，可利用每个元素的贡献次数直接计算。
5. **复杂度**：$O(N^2)$ 构建前缀和，$O(N^2)$ 枚举所有 $K$ 的窗口（所有窗口总数为 $O(N^3)$）。

## 改编方向

1. 窗口形状推广（矩形、L 形、圆形等）
2. 统计量改为最大值/最小值/中位数
3. 多个矩阵的联合滑动窗口
4. 三维推广（立体窗口）
5. 在线滑动窗口（流式数据）
