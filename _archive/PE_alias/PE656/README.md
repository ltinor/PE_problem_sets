# PE656 — 回文序列 (Palindromic sequences)

来源：改编自 Project Euler Problem 656

## 原题意

给定无理数 α，S_α(n) = ⌊α·n⌋ − ⌊α·(n−1)⌋。当子序列 {S_α(1), …, S_α(n)} 回文时，称 n 为回文位置。

已知 √31 的前 20 个回文位置为：1, 3, 5, 7, 44, 81, 118, 273, 3158, 9201, 15244, 21287, 133765, 246243, 358721, 829920, 9600319, 27971037, 46341755, 647124734。H_20(√31) = 150243655。

求 Σ_{β∈T} H_100(√β) 的最后 15 位数字，其中 T 是不超过 1000 的非完全平方数。

PE 答案：8888730。

## 算法

S_α 是 Sturmian 词。回文位置由 √β 的连分数展开确定：

设 √β = [a₀; a₁, …, a_p]（周期为 p）。令 q₋₁=0, q₀=1，q_k = a_k·q_{k-1}+q_{k-2}。

回文位置生成：
- n₁ = 1
- 对于每块 t = 1, 2, 3, …：
  - 步长 d = q_{2t}，重数 m = a_{2t+1}（按周期取模）
  - 从当前位置连续加 d，共 m 次，每次得到一个回文位置

对每个 β ∈ T，生成前 100 个回文位置并求和。复杂度 O(|T| × 100)。
