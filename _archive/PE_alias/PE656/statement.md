# 回文序列

## 题目描述

任取无理数 α，记 S_α(n) = ⌊α·n⌋ − ⌊α·(n−1)⌋（n ≥ 1）。序列 S_α 是一个 Sturmian 词。

可以证明，对于任意无理数 α，存在无穷多个 n 使得子序列 {S_α(1), S_α(2), …, S_α(n)} 是回文的。

记 H_g(α) 为前 g 个满足回文条件的 n 之和。

记 T = {2, 3, 5, 6, 7, 8, 10, …, 1000} 为不超过 1000 的非完全平方数集合。

求 Σ_{β∈T} H_100(√β) 的最后 15 位数字。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 8888730。
- `verify`：验证已知小样例（含 H_20(√31) = 150243655）。
- `compute`：计算完整答案。

## 样例

### 输入
```
PE
```

### 输出
```
8888730
```

## 数据范围

- α = √β，β ∈ T（不超过 1000 的非完全平方数）
- g = 100
- 答案取最后 15 位数字
