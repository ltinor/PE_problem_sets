# PE668 — 平方根光滑数 (Square Root Smooth Numbers)

来源：改编自 Project Euler Problem 668

## 原题意

正整数 n 称为"平方根光滑数"，如果它的最大质因子不超过 sqrt(n)。

即：若 n 的所有质因子 p 都满足 p² ≤ n，则 n 是平方根光滑的。

等价表述：令 P(n) 为 n 的最大质因子，则 n 是平方根光滑的当且仅当 P(n)² ≤ n。

定义 S(N) 为不超过 N 的平方根光滑数的个数。

已知：S(10) = 3（4, 8, 9），S(100) 等。

求 S(10¹⁰)。

PE 答案：2811077773。

## 算法

1. 筛出所有 ≤ sqrt(N) 的质数
2. 对于每个质数 p，统计满足最大质因子等于 p 且 p² ≤ n ≤ N 的 n 的数量
3. 设 smooth_p(N) 为所有质因子 ≤ p 且 ≤ N 的数的个数（p-光滑数计数）
4. 最大质因子恰好为 p 的数计数 = smooth_p(N) - smooth_{prev_p}(N)
5. 排除 n < p² 的情况（此时 p > sqrt(n)，不满足条件）

smooth 数计数使用递归/DFS 实现：
- count_smooth(N, p_idx) = count_smooth(N, p_{idx-1}) + count_smooth(N/p, p_idx)
- 基准情况：p_idx < 0 时返回 1（仅含因数 1）

对于 N = 10¹⁰，sqrt(N) ≈ 10⁵，质数数目约 9592 个，DFS 可在合理时间内完成。

## 改编方向

3. 求平方根光滑数的倒数之和
4. 多区间查询 S(L, R)
