# PE680 — 组数转逆 (Yarra Gxree)

来源：改编自 Project Euler Problem 680

## 原题意

任取两个正整数 $N$ 和 $K$。$F_n$ 是第 $n$ 个斐波那契数：$F_1=F_2=1$，$F_n=F_{n-1}+F_{n-2}$（$n \ge 3$）。

令 $s_n = F_{2n-1} \bmod N$，$t_n = F_{2n} \bmod N$。

初始数组 $A[i]=i$，进行 $K$ 次操作，第 $j$ 次操作将下标在 $s_j$ 和 $t_j$ 之间的元素逆序排列。

记 $R(N,K) = \sum_{i=0}^{N-1} i \times A[i]$。

已知：$R(5,4)=27$，$R(10^2,10^2)=246597$，$R(10^4,10^4)=249275481640$。

求 $R(10^{18},10^6) \bmod 10^9$。

PE 答案：563420605084。

## 算法

1. **隐式 Treap（平衡树）**：
   - 使用 Treap（随机化二叉搜索树）维护数组
   - 支持区间反转操作（lazy propagation）
   - 支持求加权和（每个结点维护子树的和）

2. **斐波那契数列模 $N$**：
   - 预计算 $F_1$ 到 $F_{2K+1}$ 模 $N$
   - Pisano 周期可用于加速，但 $K=10^6$ 可直接计算

3. **大规模处理**：
   - $N=10^{18}$ 远大于 $K=10^6$
   - 大部分元素从未被翻转，保持原始位置
   - 只需维护被涉及的区间（稀疏 Treap 或区间合并）

4. **复杂度**：
   - 每次反转操作 $O(\log N)$（Treap 分裂/合并）
   - 总复杂度 $O(K \log N)$
   - 对于 $K=10^6$，总操作量约 $10^6 \times 60 \approx 6 \times 10^7$

## 改编方向

1. 参数化 $N$ 和 $K$ 的范围
2. 使用不同的序列生成 $s_j, t_j$（如卢卡斯数列）
3. 改变操作类型（如循环移位、块交换）
4. 计算不同的聚合函数（如 max、min、xor 和）
