# 组数转逆

## 题目描述

任取两个正整数 $N$ 和 $K$。

$F_n$ 是第 $n$ 个斐波那契数：$F_1 = F_2 = 1$，对于所有 $n \ge 3$，$F_n = F_{n-1} + F_{n-2}$。

令 $s_n = F_{2n-1} \bmod N$，$t_n = F_{2n} \bmod N$。

在初始状态下，整数数组 $A = (A[0], \cdots, A[N-1])$ 中，$A[i] = i$。

现在，对 $A$ 进行连续的 $K$ 次逆转操作，其中第 $j$ 次操作将数组 $A$ 中下标在 $s_j$ 和 $t_j$ 之间（包含两端）的元素逆序排列。

完成 $K$ 次操作后，记 $R(N,K) = \sum_{i=0}^{N-1} i \times A[i]$。

已知：$R(5,4) = 27$，$R(10^2, 10^2) = 246597$，$R(10^4, 10^4) = 249275481640$。

求 $R(10^{18}, 10^6)$ 并将答案对 $10^9$ 取余。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 563420605084。
- `verify`：验证小样例（含 $R(5,4)$ 的逐步演示及 $R(100,100)$ 的计算）。
- `compute`：重新计算完整答案。

## 样例

### 输入
```
PE
```

### 输出
```
563420605084
```

## 数据范围

- 完整问题：$N = 10^{18}$，$K = 10^6$
- 模数 $M = 10^9$（输出答案取模）
- $s_j, t_j$ 由斐波那契数列模 $N$ 生成
- 验证范围：$N \le 10^4$ 可用 Treap 直接模拟操作
