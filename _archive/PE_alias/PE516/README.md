# PE516 - 5-smooth totients

来源：改编自 Project Euler Problem 516

## 原题意

5-光滑数（Hamming 数）是指所有质因子均不超过 5 的正整数。
记 S(L) 为所有满足 φ(n) 是 5-光滑数的 n ≤ L 之和。
求 S(10^12) mod 2^32。

PE 答案：939087315。

## 题目

给定 L，计算 S(L) = Σ_{n≤L, φ(n) 是5-光滑数} n，结果对 2^32 取模。

## 算法

- φ(n) 是 5-光滑数 ⟺ n 的质因子分为两类：
  1. p ≤ 5：可任意次幂出现（φ(p^k) 总是 5-光滑的）。
  2. p > 5：只能出现一次，且 p-1 必须是 5-光滑数。
- 因此 n = 2^a · 3^b · 5^c · ∏ p_i，其中每个 p_i > 5 是满足 p_i - 1 是 5-光滑的质数。
- 算法步骤：
  1. 生成所有 ≤ L 的 5-光滑数（用作基底）。
  2. 筛选出所有 p = s + 1 > 5 为质数的"特殊质数"（s 是 5-光滑数）。
  3. DFS 枚举所有可行的 n 并累加求和。
- 使用 Miller-Rabin 质数测试判断特殊质数。

## 改编方向

1. **改变光滑度**：7-光滑、11-光滑等。
2. **改为计数**：求满足条件的 n 的个数而非求和。
3. **区间查询**：S(L, R) 区间求和。
4. **模数变化**：对其他模数取模。
