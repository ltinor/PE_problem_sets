# 洒豆子

## 题目描述

有无穷多只碗排成一条直线，每只碗中或者有有限颗豆子，或者没有豆子。

游戏只允许一种操作：从任意一只碗中取出两颗豆子，然后在其相邻的两只碗中各放一颗豆子。
当每只碗中要么只有一颗豆子要么没有豆子时，游戏结束。

给定一个初始序列 t₀，按如下规则生成序列：
- 若 t_{i−1} 为偶数，则 t_i = t_{i−1} / 2
- 若 t_{i−1} 为奇数，则 t_i = ⌊t_{i-1}/2⌋ ⊕ C
其中 ⌊x⌋ 为下取整，⊕ 为按位异或。

b_i = (t_i mod 2^k) + 1。

现考虑相邻的 M 个碗中分别装有 b_1, b_2, ..., b_M 颗豆子，其他碗为空。求结束游戏需要多少次操作。

---

## 输入格式

一行三个整数：t₀, C, k, M。

---

## 输出格式

一个整数，表示需要的最少操作次数。

---

## 样例

### 输入
```
123456 926252 11 2
```

### 输出
```
3419100
```

---

## 数据范围

- 对于 30% 数据：M ≤ 10
- 对于 60% 数据：M ≤ 100
- 对于 100% 数据：M ≤ 2000

t₀, C ≤ 10^6，k ≤ 20
