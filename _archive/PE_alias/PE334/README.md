# PE334 - 洒豆子 (Spilling the Beans)

来源：改编自 Project Euler Problem 334
PE 答案：150320021261690835

## 原题意

无穷多只碗排成直线。操作：从任意碗中取出 2 颗豆子，在相邻两碗中各放 1 颗。游戏结束于每碗最多 1 颗豆子。

给定 t₀=123456，按规则生成序列 t_i 和 b_i=(t_i mod 2¹¹)+1。求 1500 个相邻碗分别装有 b₁..b₁₅₀₀ 时需要多少次操作。

## 题目（改编）

给定 t₀, C, k, M，生成序列 b₁..b_M（其中 b_i = (t_i mod 2^k) + 1）。求结束游戏所需的操作次数。

## 算法

- 生成 b 序列
- **贪心模拟**：从左到右扫描，每当 b[i] ≥ 2 时批量执行 b[i]/2 次操作
- 若左邻接碗因此超过阈值，回溯处理
- 利用守恒量（总豆子数、质心不变，Σi²·b_i 每次操作 +2）可推导闭式解

## 复杂度

- 时间：O(M · log S)，其中 S 为豆子总数
- 空间：O(M)

## 改编方向

1. **二维网格**：碗排列成二维网格，相邻为四连通
2. **闭式解**：推导操作次数的闭合公式
3. **不同操作**：每次取出 k 颗，在相邻碗中各放一部分
