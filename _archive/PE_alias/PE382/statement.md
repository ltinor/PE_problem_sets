# 生成多边形

## 题目描述

定义序列 s：s1=1, s2=2, s3=3，sn = sn-1 + sn-3 (n>3)。

记 Un = {s1, s2, ..., sn}。称 Un 的子集能"生成多边形"，当且仅当该子集的大小 ≥3 且其中最大元素小于其余元素之和（多边形不等式）。

给定 n，求 Un 中能生成至少一个多边形的子集数目。

---

## 输入格式

一个整数 n。

---

## 输出格式

一个整数，表示答案。

---

## 样例

### 输入
```
5
```

### 输出
```
7
```

### 输入
```
10
```

### 输出
```
501
```

---

## 数据范围

- 对于 30% 数据：n ≤ 15
- 对于 60% 数据：n ≤ 25
- 对于 100% 数据：n ≤ 10^18，输出答案模 10^9
