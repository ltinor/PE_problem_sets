# PE382 - 生成多边形

来源：改编自 Project Euler Problem 382

## 原题意

序列 s: s1=1,s2=2,s3=3, sn=sn-1+sn-3。Un={s1..sn}，f(n)=能生成多边形的子集数。求 f(10^18) 的最后 9 位。

## 题目

给定 n，求 Un 中满足多边形不等式的子集数目。小数据直接枚举，大数据考察序列单调性和组合推导。

## 数据范围

n ≤ 10^18（取模输出）

## 算法

- 小数据：枚举所有子集，O(2^n)
- 大数据：s 序列增长很快（近似指数），利用单调性，满足条件的子集几乎所有 ≥3 元素的子集
- f(n) = 2^n - 1 - n - n(n-1)/2 - 不满足条件的三元组

## 改编方向

1. **改变递推式**：sn = sn-1 + sn-k，研究 k 对结果的影响
2. **改为三角形生成**：限定子集大小 = 3，求能生成三角形的三元组个数
3. **模任意质数**：输出模 p 的结果，p 作为输入参数
4. **区间查询**：多组查询，求 [l, r] 范围内 f 值
