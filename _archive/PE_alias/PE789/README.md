# PE789 — Minimal pairing modulo p（模p最小配对）

来源：改编自 Project Euler Problem 789

## 原题意

对素数 $p$，考虑集合 $\{1,2,\dots,p-1\}$。将其中的元素两两配对，使得每对 $(a,b)$ 满足某种模 $p$ 约束（如 $ab \equiv 1 \pmod{p}$ 即互逆配对）。求某种代价（如 $\sum |a-b|$ 或 $\sum (a+b)$）的最小值。

PE 答案：174047818579065（约 $1.74 \times 10^{14}$）。

## 算法

1. **模逆配对**：$a$ 的唯一模 $p$ 逆元是 $a^{-1}$，因此配对几乎是被迫的（除自逆元 $1$ 和 $p-1$ 外）。
2. **扩展欧几里得算法**：高效计算模逆元。
3. **代价最小化**：若允许非逆配对，需要全局最优化，可建模为最小权完美匹配。
4. **累积和**：可能需要对大量素数计算代价后求和。

## 改编方向

1. 推广到合数模 $m$（需要考虑与 $m$ 互素的元素）
2. 不同的代价函数（如 $\max(a,b)$、$|a-b|$、$a \oplus b$ 等）
3. 允许三个或更多元素一组（非二元配对）
4. 在线问题：每次添加一个新素数时更新答案
5. 配对方案计数（有多少种达到最小代价的方案）
