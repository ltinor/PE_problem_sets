# 网格图

## 题目描述

对于正整数 $n$，考虑由 $(n+1) \times (n+1)$ 个格点组成的网格图。
格点的坐标为 $(i, j)$，其中 $0 \le i, j \le n$。
两个格点之间有一条无向边当且仅当它们在水平或垂直方向上相邻。

我们称一个顶点 $v$ 为"哈密顿起点"，如果存在一条从 $v$ 出发的哈密顿路
（恰好访问每个顶点一次的路径）。

令 $T(n)$ 为 $n \times n$ 网格图中哈密顿起点的数量。

给出 $T(n)$ 对于特定 $n$ 的值，或求 $\sum_{n=a}^{b} T(n)$ 的值。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 23817519。
- `verify`：验证小规模网格（n ≤ 5）的 T(n) 值。
- `compute`：重新计算完整答案。

## 样例

### 输入
```
PE
```

### 输出
```
23817519
```

## 数据范围

- 小规模验证：$n \le 5$（顶点数 ≤ 36）
- 完整问题：根据 PE 716 原题参数
- 网格图顶点数 $(n+1)^2$，边数 $2n(n+1)$
