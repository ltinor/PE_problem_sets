# PE848 — Guessing with Probability（概率猜数）

来源：改编自 Project Euler Problem 848

## 原题意

猜数游戏：玩家需要通过查询确定隐藏的数字。每次查询后获得概率性反馈。目标是最小化期望查询次数。问题可能对多个游戏实例的期望值求和。

PE 答案：50500744。

## 算法

1. **最优策略 DP**：dp[n] = 在 [1, n] 范围内确定目标的最小期望猜测次数。
2. **二分搜索分析**：对于确定性反馈，最优策略为二分搜索，期望次数 = ⌈log₂(n)⌉。
3. **概率性反馈**：当反馈带有概率时，需要加权期望计算。
4. **求和**：对所有 n ≤ N 的期望值求和。

## 改编方向

1. 引入非均匀先验分布（某些数字更可能是答案）
2. 每次猜测有代价（不同猜测代价不同）
3. 多个隐藏数字同时猜测
4. 对抗性游戏（对手可以选择改变数字）
5. 有限查询次数下的最大化正确概率
