# 整除连续串

## 题目描述

对于任意正整数 n，定义 streak(n) = k，其中 k 是满足 n+k 不能被 k+1 整除的最小正整数。

定义 P(s, N) 为 1 < n < N 中满足 streak(n) = s 的整数 n 的个数。

已知：
- P(3, 14) = 1
- P(6, 10⁶) = 14286

求 Σ_{i=1}^{31} P(i, 4ⁱ)。

## 输入格式

一行，字符串 `PE` 或 `verify`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案：1617243。
若输入为 `verify`，验证已知的 P(3,14) 和 P(6,10⁶)，并展示小规模 streak 值。

## 样例

### 输入
```
PE
```

### 输出
```
1617243
```

## 数据范围

- 完整问题：i = 1..31，N = 4ⁱ（最大约 4.6×10¹⁸）
- 所有计算在 64 位整数范围内完成
