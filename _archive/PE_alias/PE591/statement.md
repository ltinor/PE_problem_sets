# 二次整数最佳逼近

## 题目描述

给定非完全平方整数 d，任意实数 x 可以用二次整数 a+b√d 任意逼近。记 BQA_d(x,n) 为所有满足 |a|,|b| ≤ n 的二次整数中最接近 x 的那个。定义 I_d(a+b√d) = a。

已知：
- BQA_2(π,10) = 6 - 2√2
- BQA_5(π,100) = 26√5 - 55
- BQA_7(π,10^6) = 560323 - 211781√7
- I_2(BQA_2(π,10^13)) = -6188084046055

对于所有小于 100 的非完全平方整数 d，求对应的 |I_d(BQA_d(π,10^13))| 之和。

## 输入格式

一行，字符串 `PE` 或 `verify`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案：526007984592979520。
若输入为 `verify`，验证给定的样例。

## 样例

### 输入
```
PE
```

### 输出
```
526007984592979520
```

## 数据范围

- 对于验证：d ≤ 100, n ≤ 10^6
- 对于完整问题：d < 100, n = 10^13
