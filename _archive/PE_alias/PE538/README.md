# PE538 - 矩形在哪 (Where is the Rectangle?)

来源：改编自 Project Euler Problem 538

## 原题意

将自然数按螺旋形式排列在二维平面上。对于每个坐标 $(x, y)$，定义一个函数值。当存在四个不同的坐标 $(x_1, y_1), (x_2, y_1), (x_1, y_2), (x_2, y_2)$ 具有相同的函数值时，称找到了一个"矩形"。

求第一个出现的矩形的四个角在螺旋中的位置编号之和（使用从 1 开始的编号）。

PE 答案：224728253679477182。

## 题目

在一个二维螺旋网格中搜索由相同值的四个角构成的轴对齐矩形，返回其角点的螺旋索引之和。

## 算法

- 螺旋坐标转换：将二维坐标 $(x, y)$ 映射到螺旋中的线性索引。
  - 层号：$L = \max(|x|, |y|)$
  - 边长：$s = 2L$
  - 起始编号：$\text{start} = (s-1)^2 + 1$
- 搜索矩形：在有限范围内枚举所有坐标，按函数值分组，检测每组中是否存在四个点形成矩形（x 坐标恰有 2 个不同值，y 坐标也恰有 2 个不同值）。
- 时间复杂度：$O(L^2 + V \cdot C^4)$，其中 L 是搜索半径，V 是不同值的个数，C 是每个值的出现次数。

## 改编方向

1. **不同排列**：使用对角排列、蛇形排列等替代螺旋排列。
2. **其他形状**：搜索正方形、菱形等其他几何形状。
3. **不同函数**：改变单元格值的计算函数（如使用曼哈顿距离、质因数个数等）。
4. **多次出现**：求第 k 个矩形而非第一个。
