# 逐渐增长的根

## 题目描述

记 $a_k, b_k, c_k$ 分别是方程

$$\frac{1}{x} = \left(\frac{k}{x}\right)^2 (k + x^2) - kx$$

在复数域内的三个根。

对于所有满足 $1 \le p, k \le n$ 的整数 $p, k$，定义：

$$S(n) = \sum_{p=1}^n \sum_{k=1}^n (a_k + b_k)^p (b_k + c_k)^p (c_k + a_k)^p$$

有趣的是，$S(n)$ 永远是一个整数。

已知：$S(4) = 51160$。

---

## 输入格式

一个整数 $n$。

---

## 输出格式

一个整数，表示 $S(n) \bmod 1\,000\,000\,007$。

---

## 样例

### 输入
```
4
```

### 输出
```
51160
```

---

## 数据范围

- 对于 30% 数据：$n \le 10$
- 对于 60% 数据：$n \le 1000$
- 对于 100% 数据：$n \le 10^6$
