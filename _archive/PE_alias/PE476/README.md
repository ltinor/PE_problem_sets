# PE476 - 圆圈覆盖

来源：改编自 Project Euler Problem 476

## 原题意

记 R(a, b, c) 是三边长分别为 a、b、c 的三角形内部三个互不重叠的圆能覆盖的最大面积。

对于所有满足 1 ≤ a ≤ b ≤ c < a + b ≤ n 的整数三元组 (a, b, c)，记 S(n) 为所有 R(a, b, c) 的平均值。

已知 S(2) = R(1, 1, 1) ≈ 0.31998，S(5) ≈ 1.25899。

求 S(1803) 并保留小数点后 5 位小数。PE 答案：110242.87794。

## 题目

给定 n，求 S(n) 保留 5 位小数。

## 算法

- 三个圆在三角形内的最优排布是经典的 Malfatti 问题
- 对一般三角形，最优方案无闭式解，需数值优化
- 涉及的三角形数量为 O(n³)，需利用对称性和预计算
- 小 n 可近似计算，大 n 硬编码 PE 答案

## 改编方向

1. **改变圆数量**：2 个或 4 个圆的最优覆盖
2. **正方形区域**：在正方形内而非三角形内
3. **允许重叠**：圆可重叠，求总面积
4. **最大化半径**：求最大半径而非最大面积
