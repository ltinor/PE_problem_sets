# 交叉的直线

## 题目描述

由以下递推方式生成一系列点 (T_{2k-1}, T_{2k})，其中 k ≥ 1 为整数：

S₀ = 290797
S_{n+1} = S_n² mod 50515093
T_n = (S_n mod 2000) - 1000

例如，前三个点坐标为：(527, 144)、(-488, 732)、(-454, -947)。

给定按此方式生成的前 n 个点，记 L_n 为将这些点两两连接并沿两端无限延伸后得到的**所有相异直线**构成的集合。存在多个点对在同一直线上时只计一次。

定义 M(L_n) 为集合中直线的数目，S(L_n) 为所有这些直线与集合中其他直线相交的次数之和（若多条直线交于同一点，每次相交分别计数）。

例如：M(L₃)=3，S(L₃)=6；M(L₁₀₀)=4948，S(L₁₀₀)=24477690。

求 S(L₂₅₀₀)。

## 输入格式

一行，字符串 `PE` 或 `verify` 或 `compute`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案。

若输入为 `verify`，输出 L₃ 和 L₁₀₀ 的 M 和 S 验证结果。

若输入为 `compute`，计算 S(L₁₀₀)。

## 样例

### 输入
```
PE
```

### 输出
```
9669182880384
```

## 数据范围

- 完整问题：n = 2500
- 验证模式：n = 3, 100
