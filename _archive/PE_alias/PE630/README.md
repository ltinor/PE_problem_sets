# PE630 — 交叉的直线 (Crossed Lines)

来源：改编自 Project Euler Problem 630

## 原题意

由以下递推生成 n 个点 (T_{2k-1}, T_{2k})（k=1..n）：

S₀ = 290797
S_{n+1} = S_n² mod 50515093
T_n = (S_n mod 2000) - 1000

L_n 为将这些点两两连接并无限延伸得到的所有**相异**直线构成的集合。

M(L_n) = 直线数目，S(L_n) = 每条直线与集合中其他直线相交的次数之和。

已知：M(L₃)=3，S(L₃)=6；M(L₁₀₀)=4948，S(L₁₀₀)=24477690。

求 S(L₂₅₀₀)。

PE 答案：9669182880384。

## 算法

直线无限延伸后，两条直线相交的充要条件是它们不平行。

### 核心公式

S(L) = M² - Σ_{斜率} c_{斜率}²

其中 c_{斜率} 为具有该斜率的直线数量。

### 实现步骤

1. 递推生成 n 个点。
2. 枚举所有点对，计算直线的一般式 ax+by+c=0，并用规范化形式去重。
3. 按斜率分组统计。
4. 代入公式计算 S。
