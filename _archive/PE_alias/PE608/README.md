# PE608 — 约数和 (Divisor Sums)

来源：改编自 Project Euler Problem 608

## 原题意

定义 D(m,n) = Σ_{d|m} Σ_{k=1}^{n} σ₀(kd)，其中 σ₀(n) 是 n 的约数个数。

已知：D(3!, 10²) = 3398，D(4!, 10⁶) = 268882292。

求 D(200!, 10¹²) mod (10⁹ + 7)。

PE 答案：439689828。

## 算法

核心分析：

1. Σ_{d|m} σ₀(kd) = ∏_{p≤200} (e_p+1)(α_p(k) + 1 + e_p/2)，其中 α_p(k) 是 k 中 p 的指数，e_p 是 p 在 200! 中的指数。

2. D(200!, n) = Σ_{k=1}^{n} ∏_{p≤200} (e_p+1)(α_p(k) + 1 + e_p/2)

3. 利用狄利克雷卷积和乘法数论函数加速计算。将求和分解为素数幂贡献，使用分段筛法和模运算。

由于 n = 10¹² 太大，需要使用亚线性算法（如 min_25 筛、杜教筛等）或利用 200! 的因子结构进行组合计数。

## 改编方向

1. 替换 200! 为其他阶乘或大合数。
2. 研究 D(m, n) 在不同 m 增长下的渐近行为。
3. 将 σ₀ 替换为 σₖ（约数 k 次幂和）。
4. 分析 D(m, n) 模不同素数时的周期性。
