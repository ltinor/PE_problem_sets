# 有序因子分解计数

## 题目描述

将正整数 $n$ 分解为 $k$ 个**有序**整数的乘积，每个因子大于 $1$：
$$n = a_1 \times a_2 \times \dots \times a_k, \quad a_i > 1$$

令 $d(n, k)$ 表示长度为 $k$ 的有序因子分解的个数（顺序重要）。
定义 $D(n) = \sum_{k} d(n, k)$，即 $n$ 的所有可能有序因子分解的总数。

例如：
- $D(6) = 3$：分解为 (6), (2,3), (3,2)
- $D(12) = 8$：分解为 (12), (2,6), (6,2), (3,4), (4,3), (2,2,3), (2,3,2), (3,2,2)

问题：求 $\displaystyle S(N) = \sum_{i=1}^{N} D(i!)$ 对素数 $M$ 取模的结果。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出原题答案 `143155974`
- `verify`：展示小规模 $n \le 20$ 的 $D(n)$ 值及验证
- `compute`：重新计算完整答案

## 样例

### 输入
```
PE
```

### 输出
```
143155974
```

### 小规模验证
| n | D(n) | 分解方式 |
|---|------|----------|
| 1 | 1 | () |
| 2 | 1 | (2) |
| 3 | 1 | (3) |
| 4 | 2 | (4), (2,2) |
| 5 | 1 | (5) |
| 6 | 3 | (6), (2,3), (3,2) |
| 8 | 4 | (8), (2,4), (4,2), (2,2,2) |
| 12 | 8 | (12), (2,6), (6,2), (3,4), (4,3), (2,2,3), (2,3,2), (3,2,2) |

递推公式：$D(1) = 1$，$D(n) = \sum_{d \mid n, d < n} D(d)$（$n > 1$）

- 完整问题：根据 PE 738 原题参数
- 答案范围：约 $1.43 \times 10^8$（32 位有符号整数可容纳）
