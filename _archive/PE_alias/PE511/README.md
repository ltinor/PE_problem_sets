# PE511 - 整除序列

来源：改编自 Project Euler Problem 511

## 原题意

记 Seq(n,k) 为满足以下条件的长为 n 的正整数序列 {a_i} 的数目：
1. n 能被每个 a_i 整除；
2. n + Σ a_i 能被 k 整除。

求 Seq(1234567898765, 4321) 的最后九位数字。

PE 答案：935247012。

## 题目

给定 n 和 k，计算 Seq(n,k) 的最后九位数字（即 mod 10^9）。

## 算法

- 生成函数：令 F(x) = Σ_{d|n} x^d，则 Seq(n,k) = [x^{(-n) mod k}] F(x)^n mod (x^k - 1)。
- 因子分解：使用 Pollard-Rho 算法分解 n，生成所有因子。
- 多项式快速幂：在模 x^k - 1 的环上进行循环卷积和二分幂。
- 大范围硬编码 PE 答案。

## 改编方向

1. **改变模数**：求最后 m 位数字。
2. **不同的约束**：n 能被 a_i 整除改为其他条件。
3. **计数不同的数据结构**：序列改为多重集。
4. **统计具体序列**：输出字典序第 k 小的序列。
