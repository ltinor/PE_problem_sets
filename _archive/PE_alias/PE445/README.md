# PE445 - 收缩函数 A

来源：改编自 Project Euler Problem 445

## 原题意

对于 n>1，函数族 f_{n,a,b}(x) ≡ ax+b (mod n)，其中 0<a<n, 0≤b<n, 0≤x<n。若对所有 x 满足 f(f(x)) ≡ f(x)，则称该函数为收缩函数。R(n) 为 n 的收缩函数个数。

条件推导：
- f(f(x)) ≡ a(ax+b)+b ≡ a²x+ab+b ≡ ax+b (mod n)
- 需要 a² ≡ a (mod n) 且 ab ≡ 0 (mod n)
- a 是模 n 的幂等元，对应 n 的每个质因子幂的 CRT 选择
- R(n) = ∏_{p^e||n} (1+p^e) - n

原题求 Σ_{k=1}^{N-1} R(C(N,k)) 模 10^9+7，N=10^7，答案为 659104042。

## 题目

给定 n，求 R(n)。

## 算法

- 对 n 进行质因数分解
- R(n) = ∏(1 + p^e) - n，其中 p^e 为质因子幂
- 时间复杂度 O(√n)

## 改编方向

1. **和式推广**：求 Σ_{i=1}^n R(i)
2. **函数推广**：f(x) ≡ ax²+bx+c (mod n)，二次函数收缩条件
3. **计数问题**：统计满足某些额外约束的收缩函数数量
4. **最大收缩**：在给定 n 的所有收缩函数中，求 gcd(a,n) 的最大值
