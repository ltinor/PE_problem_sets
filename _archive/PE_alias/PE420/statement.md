# 2x2 正整数矩阵

## 题目描述

正整数矩阵是所有元素均为正整数的矩阵。有些正整数矩阵可以有两种不同的方式表示为另一个正整数矩阵的平方。

定义 F(N) 为迹（主对角线元素和）小于 N，且可以表示为两个不同正整数矩阵平方的 2×2 正整数矩阵数目。

已知 F(50)=7, F(1000)=1019。

给定 N，求 F(N)。

---

## 输入格式

一个整数 N。

---

## 输出格式

一个整数，表示 F(N)。

---

## 样例

### 输入
```
50
```

### 输出
```
7
```

### 输入
```
1000
```

### 输出
```
1019
```

---

## 数据范围

- 对于 30% 数据：N ≤ 100
- 对于 60% 数据：N ≤ 1000
- 对于 100% 数据：N ≤ 10^7
