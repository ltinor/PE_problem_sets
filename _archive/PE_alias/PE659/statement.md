# 最大的素数

## 题目描述

考虑序列 n² + k²（n ≥ 1）。记 P(k) 为能够整除该序列相邻两项的最大素数。

例如，对于序列 n²+3：n=6 和 n=7 对应的项 39 和 52 均能被 13 整除，而 13 是所有这样的素数中最大的。

可以证明，P(k) 即为 4k²+1 的最大素因子。

求 Σ_{k=1}^{10,000,000} P(k) 的最后 18 位数字。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 796144972。
- `verify`：验证 P(k) 公式对小 k 的正确性。
- `compute`：完整计算 Σ P(k)（需筛法，约需 10-30 秒）。

## 样例

### 输入
```
PE
```

### 输出
```
796144972
```

## 数据范围

- k 范围：1 到 10,000,000
- 4k²+1 最大值约 4×10^14
- 答案取最后 18 位数字
