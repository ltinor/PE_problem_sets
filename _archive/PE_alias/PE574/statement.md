# 验证选举

## 题目描述

一场选举有 n 名候选人（编号 1 到 n）和 m 名选民。每名选民投票给一名候选人。

选举结束后，从 m 张选票中均匀随机地选择 r 张（0 ≤ r ≤ m）进行重新计票。

如果无论原始 m 张选票如何分布，这 r 张随机抽样选票的计票结果都能正确判断出原始获胜者（即得票最多的候选人），则称 r 是"验证充分的"。

设 Q(n, m) 为验证充分的 r 的个数。

已知：
- Q(2, 3) = 1（必须重新统计全部 3 票）
- Q(2, 4) = 4
- Q(3, 2) = 1
- Q(3, 3) = 3

## 输入格式

一行，输入 `PE` 返回答案，`test` 显示已知值，或输入 `n m` 查询 Q(n, m)。

## 输出格式

一个整数。

## 样例

### 输入
```
2 3
```

### 输出
```
1
```

### 输入
```
PE
```

### 输出
```
57804459920512
```

## 数据范围

- 小规模测试：n ≤ 3, m ≤ 4
- PE 答案：Q(5, 5)
