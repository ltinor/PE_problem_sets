# 相切的圆

## 题目描述

圆 A 和圆 B 彼此相切，同时和直线 L 也分别相切，三个切点互不相同。
圆 C 在 A、B 和 L 之间，且与这三者都相切。

分别记圆 A、B 和 C 的半径为 rA、rB 和 rC。

对于所有满足 0 < rA ≤ rB ≤ n，且 rA、rB、rC 均为整数的可行解，
定义 S(n) = Σ (rA + rB + rC)。

已知 S(5) = 9（唯一解：rA=4, rB=4, rC=1），S(100) = 3072。

给定 n，求 S(n)。

## 输入格式

一个整数 n（1 ≤ n ≤ 10^9），或字符串 `PE`。

## 输出格式

一个整数，表示 S(n)。

## 样例

### 输入
```
5
```

### 输出
```
9
```

## 数据范围

- 对于 30% 数据：n ≤ 10
- 对于 60% 数据：n ≤ 1000
- 对于 100% 数据：n ≤ 10^9
