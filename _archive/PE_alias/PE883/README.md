# PE883 — Remarkable Harmonic Triangles（显著调和三角形）

来源：改编自 Project Euler Problem 883

## 原题意

考虑三边均为正整数的三角形，其边长 a、b、c 满足倒数成等差数列，即：

$$\frac{2}{b} = \frac{1}{a} + \frac{1}{c}$$

等价地，b 等于 a 和 c 的调和平均数：$b = \frac{2ac}{a+c}$。

这种三角形具有特殊的几何性质，与调和分割、反演几何等概念相关。

PE 答案：196246694

## 算法

1. **整数解参数化**：
   - 从调和平均条件 b = 2ac/(a+c) 出发
   - 令 a = g·u, c = g·v，其中 gcd(u,v) = 1
   - 则 b = 2g·u·v/(u+v)，要求 u+v 整除 2g·u·v

2. **生成所有解**：
   - 遍历互素对 (u, v)
   - 对于每个满足整除条件的 g，检查三角不等式

3. **计数与求和**：
   - 统计周长不超过给定界限的三角形数量
   - 计算相关量的和

4. **几何性质**：
   - 调和三角形对应的内切圆、外接圆有特殊关系
   - 与 Apollonius 圆相关

## 改编方向

1. 求周长不超过 N 的调和三角形数量
2. 求调和三角形面积之和
3. 研究调和三角形的内角性质
4. 推广到其他均值（几何平均、算术平均）
