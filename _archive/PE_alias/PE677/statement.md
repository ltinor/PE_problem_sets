# 图染色

## 题目描述

记 $g(n)$ 为有 $n$ 个结点并满足以下性质的**无向图**总数：

- 该图是连通图、无环、无重边（即树）。
- 每个结点被染上红色、蓝色或黄色之一。
- 每个红色结点至多与 4 条边相连。
- 每个蓝色或黄色结点至多与 3 条边相连。
- 黄色结点之间不能直接相连。

例如：$g(2)=5$，$g(3)=15$，$g(4)=57$。

还已知 $g(10)=710249$，$g(100) \equiv 919747298 \pmod{1\,000\,000\,007}$。

求 $g(10\,000) \bmod 1\,000\,000\,007$。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 984183023。
- `verify`：验证小样例（含 $g(2)$ 到 $g(4)$ 以及 $g(10)$、$g(100)$ 的已知值）。
- `compute`：重新计算完整答案。

## 样例

### 输入
```
PE
```

### 输出
```
984183023
```

## 数据范围

- 完整问题：$n = 10\,000$
- 模数 $M = 1\,000\,000\,007$
- 验证范围：$n \le 100$ 可用枚举或 DP 直接计算
