# PE391 - 跳跃游戏

来源：改编自 Project Euler Problem 391

## 原题意

序列 S 为 0~k 二进制中 1 的个数累计。两个玩家轮流在 S 中移动计数器。M(n) 为先手必胜的最大第一步。求 ΣM(n)^3 for n=1..1000。

## 题目

给定 N，求 Σ_{n=1}^N M(n)^3。利用 S 序列的单调性和游戏论分析。

## 算法

- 预计算 S 序列
- 分析游戏：这等价于在 S 序列上的取石子游戏
- M(n) 可以通过递推和胜负态分析得到

## 改编方向

1. **修改计分方式**：求 ΣM(n)^k，k 作为输入参数
2. **改变底层序列**：S 改为其他数论序列（如素数前缀和）
3. **多人游戏**：改为三人游戏，求先手的必胜策略数
4. **限制步数**：每个玩家最多移动 K 步，求胜率
