# 刚性图

## 题目描述

在一个 m×n 的方格图中，每个方格可以选择添加一条对角线（左上-右下或右上-左下，视为同一种）或不添加。添加对角线后，如果整个图变为不可弯折（刚性），则称这个方案有效。

R(m,n) 为将 m×n 方格图变为刚性的方案数。

已知 R(2,3)=19, R(5,5)=23679901。

定义 S(N) = Σ_{1≤i,j≤N} R(i,j)。已知 S(5)=25021721。

求 S(N) mod 1000000033。

---

## 输入格式

一个整数 N。

---

## 输出格式

一个整数，表示 S(N) mod 1000000033。

---

## 样例

### 输入
```
2
```

### 输出
```
27
```

### 输入
```
5
```

### 输出
```
25021721
```

---

## 数据范围

- 对于 30% 数据：N ≤ 3
- 对于 60% 数据：N ≤ 5
- 对于 100% 数据：N ≤ 100
