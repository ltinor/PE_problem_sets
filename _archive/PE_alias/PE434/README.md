# PE434 - 刚性图

来源：改编自 Project Euler Problem 434

## 原题意

在 m×n 方格图中添加对角线（每个方格可选加一条对角线或不加），使图变为不可弯折（刚性）。R(m,n) 为使 m×n 方格图变为刚性的方法数。S(N) = Σ_{1≤i,j≤N} R(i,j)。

已知 R(2,3)=19, R(5,5)=23679901, S(5)=25021721。
原题求 S(100) mod 1000000033 = 863253072。

## 题目

给定 N，求 S(N) mod 1000000033。

## 算法

- 方格图刚性等价于其对应的二分图（行-列）连通
- 每个方格的对角线代表行节点与列节点的一条边
- R(m,n) = 使 m+n 个节点的二分图连通的边选择方案数
- 使用包含-排除原理和连通二分图计数
- 利用转移矩阵和 DP 加速

## 改编方向

1. **三角形网格**：六边形或三角形网格的刚性
2. **3D 网格**：三维立方体网格
3. **加权计数**：不同对角线有不同权重
4. **最少对角线**：求使图刚性的最少对角线数
