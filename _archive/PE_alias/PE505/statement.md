# 双向递推

## 题目描述

定义序列 A(n) 如下：

- A(0) = 1
- 对于 n ≥ 1：
  - 若 n 为偶数：A(n) = A(n/2) + A(n/2 - 1) + n/2
  - 若 n 为奇数：A(n) = 2·A((n-1)/2) + A((n-1)/2 - 1) + (n-1)/2

给定 N，求 A(N) mod 10^9。

## 输入格式

一个整数 N（0 ≤ N ≤ 10^12），或字符串 `PE`。

## 输出格式

一个整数，表示 A(N) mod 10^9。

## 样例

### 输入
```
5
```

### 输出
```
20
```

## 数据范围

- 对于 30% 数据：N ≤ 10^2
- 对于 60% 数据：N ≤ 10^6
- 对于 100% 数据：N ≤ 10^12
