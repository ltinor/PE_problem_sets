# PE383 - 阶乘整除性比较

来源：改编自 Project Euler Problem 383

## 原题意

f5(n) = n 中因子 5 的个数。T5(n) = 满足 f5((2i-1)!) < 2·f5(i!) 的 i 的数量。求 T5(10^18)。

## 题目

给定 n，求 T5(n)。考察 Legendre 公式的推广和数位 DP 思想。

## 算法

- f5(n!) = floor(n/5) + floor(n/25) + floor(n/125) + ...
- T5(n) 等于满足"2i-1 在五进制下某些性质"的 i 的数量
- 可用五进制数位 DP 或直接公式 O(log n)

## 改编方向

1. **推广到任意质数**：将因子 5 改为任意质数 p，p 作为输入参数
2. **推广不等式**：将条件 f5((2i-1)!) < 2·f5(i!) 改为 f5((ki-1)!) < k·f5(i!) 
3. **计数类问题**：改为求满足条件的 i 的集合而非数量
4. **区间版本**：求 [L, R] 范围内满足条件的 i 的数量
