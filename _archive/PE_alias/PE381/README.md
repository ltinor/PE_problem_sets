# PE381 - (素数-k) 阶乘和

来源：改编自 Project Euler Problem 381

## 原题意

对素数 p，S(p) = sum((p-k)! for k=1..5) mod p。求 5 ≤ p < 10^8 的所有素数对应的 S(p) 之和。

## 题目

给定 n，求所有 5 ≤ p < n 的素数 p 的 S(p) 之和。将原题固定边界改为输入参数。

## 数据范围

n ≤ 10^8

## 算法

- Wilson 定理化简：(p-1)! ≡ -1 (mod p)，进而推出五项模值
- 需要素数筛 + 模逆元计算
- S(p) = (p-3)/2 mod p (可由 Wilson 推出)

## 改编方向

1. **扩展 k 的范围**：将 1 ≤ k ≤ 5 扩展为 1 ≤ k ≤ m，其中 m 也是输入参数，增加难度
2. **多次查询**：变为 T 组测试数据，要求每组在 O(√n) 内完成
3. **模数变化**：不模 p 而是模另一个大质数 M，考察数论结合能力
4. **区间求和优化**：要求对任意 [L, R] 区间内的素数快速求和
