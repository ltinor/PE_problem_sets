# Bozo排序

来源：改编自 Project Euler Problem 367

## 原题意

Bozo 排序变种（每次随机选 3 个元素打乱）。求前 11 个自然数所有排列的期望操作次数。PE 答案：48271207（四舍五入）。

## 题目

给定 N，求前 N 个自然数的所有排列在 Bozo 排序变种下的期望操作次数。

## 数据范围

N ≤ 11

## 算法

### 方向一：马尔可夫链 + 状态压缩

将 N! 种排列作为状态，构建转移矩阵。3 元素随机重排有 6 种等概率结果，计算每个状态转移到其他状态的概率。解线性方程组求期望步数。

### 方向二：对称性简化

利用排列的对称性，将状态归类为"无序度"类别（如逆序对数、与目标排列的距离等）。大幅减少状态数。

### 方向三：DP + BFS

从目标排列（已排序）BFS 反向搜索，计算每个排列到目标的期望步数。利用排列的 hash 编码存储 DP 值。

### 时间复杂度

状态数 O(N!)，N ≤ 11 时可行（约 4×10^7 状态，可进一步压缩）。
