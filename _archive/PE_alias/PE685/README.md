# PE685 — Inverse Digit Sum II (数字和的逆函数II)

来源：改编自 Project Euler Problem 685

## 原题意

记 $f(n,m)$ 为第 $m$ 个各位数字之和等于 $n$ 的数（按升序排列）。
例如 $f(10,1)=19$，$f(10,10)=109$，$f(10,100)=1423$。

记 $S(k) = \sum_{n=1}^{k} f(n^3, n^4)$。
已知 $S(3)=7128$，$S(10) \equiv 32287064 \pmod{10^9+7}$。

求 $S(10\\ 000) \bmod 1\\ 000\\ 000\\ 007$。

PE 答案：662878443。

## 算法

1. **赤字表示法**：对于数字和 $S$，最短长度 $L = \lceil S/9 \rceil$。
   定义赤字 $D = 9L - S$（$0 \le D \le 8$）。每位数字 $d_i = 9 - e_i$，其中 $\sum e_i = D$。

2. **枚举长度**：从 $L_0$ 开始，统计每个长度的数字个数。
   对 $D \le 8$，$L$ 位数中数字和为 $S$ 的个数为 $\binom{D+L-1}{D}$（无上界约束时）。

3. **逐位构造**：对于第 $m$ 个数字，逐位确定赤字 $e_i$。
   对每位尝试 $e_i$ 从大到小（对应数字从小到大），统计剩余位数的方案数，
   用组合数 $\binom{\text{剩余赤字} + \text{剩余位数} - 1}{\text{剩余赤字}}$ 计数。

4. **模运算**：最终数字 $f = 10^L - 1 - \sum e_i \cdot 10^{L-1-i}$。
   利用 $10^{\text{大指数}} \bmod M$ 的快速幂计算。

5. **复杂度**：对每个 $n=1..10000$，$n^3 \le 10^{12}$，$n^4 \le 10^{16}$。
   使用 `__int128` 处理大组合数，总计算量可接受。
