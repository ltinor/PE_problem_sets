# 整除链II

## 题目描述

n 的**因子链**（gozinta chain）是一个序列 {1, a, b, ..., n}，其中每个元素都整除后一个元素。
例如，12 有八条因子链：
{1,12}，{1,2,12}，{1,2,4,12}，{1,2,6,12}，{1,3,12}，{1,3,6,12}，{1,4,12} 和 {1,6,12}。

对于任意 n，将所有不超过 n 且恰好有 252 条不同因子链的整数 k 的和记为 S(n)。
已知 S(10⁶) = 8462952，S(10¹²) = 623291998881978。

求 S(10³⁶)，并给出其最后九位数字。

## 输入格式

一行，字符串 `PE` 或 `verify`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案：158452642。
若输入为 `verify`，验证 g(12) = 8 以及已知的 S 值。

## 样例

### 输入
```
PE
```

### 输出
```
158452642
```

## 数据范围

- 完整问题：n = 10³⁶
- 验证模式：n ≤ 1000（部分验证），展示已知的 S(10⁶) 和 S(10¹²)
