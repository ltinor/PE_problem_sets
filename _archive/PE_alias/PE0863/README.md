# PE863 — Digital Digit Factorial（数字数字阶乘）

来源：改编自 Project Euler Problem 863

## 原题意

将 PE 34（数字阶乘和）推广到更大的范围或更复杂的条件。定义 f(n) 为 n 的各位数字的阶乘之和。寻找满足 f(n) = n 的数，或计算在某个范围内 f(n) 的累积和。

已知：145 = 1! + 4! + 5!，40585 = 4! + 0! + 5! + 8! + 5!。

## 算法

1. **预计算阶乘**：0! 到 9! 的值。
2. **数字阶乘和**：对每个 n 计算各位数字阶乘之和。
3. **阶乘链**：类似 PE 74，迭代计算 f(n), f(f(n)), ... 直到循环。
4. **区间求和**：使用数位 DP 高效计算区间内所有 f(n) 的和。

## 改编方向

1. 高阶阶乘链的长度分布
2. 推广到平方和或其他函数
3. 寻找不同进制的数字阶乘数
4. 数字阶乘和的不动点分析
