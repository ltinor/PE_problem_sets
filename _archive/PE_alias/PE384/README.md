# PE384 - 鲁丁-夏皮罗序列

来源：改编自 Project Euler Problem 384

## 原题意

Rudin-Shapiro 序列 b(n)=(-1)^a(n)，其中 a(n) 为 n 二进制中相邻 1 的对数。s(n) 为部分和。g(t,c) 为 t 在 s 中第 c 次出现的下标。求 ΣGF(t) for t=2..45。

## 题目

给定 T，求 Σ_{t=2}^T g(F(t), F(t-1))。将固定范围改为输入参数。

## 算法

- Rudin-Shapiro 序列的递推性质：s(2n)=s(n), s(2n+1)=s(n)+b(n)
- 利用序列的分形结构高效计算 g(t,c)
- 预计算 F(t) 并查询

## 改编方向

1. **改变出现次数规律**：研究其他满足"k 出现 k 次"性质的序列
2. **扩展到任意二重序列**：用类似方法定义双参数查询 g(t,c)，求各种统计量
3. **序列生成器**：要求输出 s(n) 的前 N 项而非求和
4. **修改底层序列**：将 Rudin-Shapiro 替换为 Thue-Morse 或其他自相似序列
