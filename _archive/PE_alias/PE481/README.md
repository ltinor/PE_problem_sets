# PE481 - 厨师对决

来源：改编自 Project Euler Problem 481

## 原题意

两位厨师进行一场 $N$ 局 $M$ 胜制比赛。每局 A 选择 $p$，B 选择 $q$，A 获胜概率为 $p(1-q)+q(1-p)$。A 每局可改变 $p$，B 知道 A 的混合策略。

求 A 的期望总胜场。PE 答案：729.12121547。

## 题目

给定奇数 N，求 A 的最优期望总胜场。

## 算法

- 博弈论最优策略问题
- 动态规划：$V[a][b]$ = A 还需要 $a$ 胜、B 还需要 $b$ 胜时的最优值
- 均衡点处的对称解为 $p = q = 0.5$
- 递推 $V[a][b] = 0.5 \cdot V[a-1][b] + 0.5 \cdot V[a][b-1]$
- 边界：$V[0][b] = 1$（A 已获胜），$V[a][0] = 0$（B 已获胜）
- 最终答案 = $V[M][M] \cdot N$

## 改编方向

1. **不同收益函数**：改变每局的获胜概率公式
2. **不对称信息**：B 不知道 A 的策略
3. **多选手**：三个或更多厨师
4. **连续决策**：p 和 q 可以动态调整
