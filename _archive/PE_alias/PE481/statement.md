# 厨师对决

## 题目描述

两位厨师 A 和 B 进行一场 $N$ 局 $M$ 胜制比赛（$N$ 为奇数，$M = (N+1)/2$）。每局比赛中：

- 厨师 A 选择一个实数 $p \in [0, 1]$ 表示其菜肴的"水平"
- 厨师 B 知道 A 的策略（包括本局的 $p$ 值分布），但不知道具体的 $p$，然后选择 $q \in [0, 1]$
- A 获胜的概率为 $p(1-q) + q(1-p)$

A 可以在每局选择不同的 $p$，目标是最大化期望总胜场。

求当 $N$ 取特定值时，A 的期望总胜场（保留 8 位小数）。

---

## 输入格式

一个奇数 $N$。

---

## 输出格式

一个浮点数，表示 A 的期望总胜场，保留 8 位小数。

---

## 样例

### 输入
```
1
```

### 输出
```
0.50000000
```

---

## 数据范围

- 对于 30% 数据：$N \le 3$
- 对于 60% 数据：$N \le 7$
- 对于 100% 数据：$N \le 11$
