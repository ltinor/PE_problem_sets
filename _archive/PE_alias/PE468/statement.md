# 二项式系数的光滑因数

## 题目描述

当一个正整数的所有质因数都不大于 B 时，这个整数被称为 **B-光滑数**。

记 S_B(n) 为 n 的最大 B-光滑因数（即 n 的所有 ≤B 的质因子的乘积，含重数）。

例如：
- S_1(10) = 1（没有 ≤1 的质因数）
- S_4(2100) = 2² × 3 = 12（2100 = 2²×3×5²×7，仅取质因数 2 和 3）
- S_17(2496144) = 5712

定义 F(n) = Σ_{1≤B≤n} Σ_{0≤r≤n} S_B(C(n,r))，其中 C(n,r) 表示二项式系数。

例如：F(11) = 3132。

给定 n，求 F(n) mod 1,000,000,993。

---

## 输入格式

一个整数 n (1 ≤ n ≤ 200)。

---

## 输出格式

一个整数，表示 F(n) mod 1,000,000,993。

---

## 样例

### 输入
```
11
```

### 输出
```
3132
```

### 输入
```
20
```

### 输出
```
...
```

---

## 数据范围

- 对于 30% 数据：n ≤ 10
- 对于 60% 数据：n ≤ 50
- 对于 100% 数据：n ≤ 200
