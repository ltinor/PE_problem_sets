# 幂的欧拉函数和

## 题目描述

记 φ(n) 为欧拉函数（小于 n 且与 n 互质的正整数个数）。

定义：
- f(n) = (Σ_{i=1}^n φ(n^i)) mod (n+1)
- g(n) = Σ_{i=1}^n f(i)

给定 N，求 g(N)。

## 输入格式

一行，一个整数 N，或字符串 `PE`。

## 输出格式

一个整数，表示 g(N)。

## 样例

### 输入
```
100
```

### 输出
```
2007
```

## 数据范围

- 对于 30% 数据：N ≤ 10^3
- 对于 60% 数据：N ≤ 10^6
- 对于 100% 数据：N ≤ 5 × 10^8
