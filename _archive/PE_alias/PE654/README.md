# PE654 — 相邻约束 (Neighbourly Constraints)

来源：改编自 Project Euler Problem 654

## 原题意

T(m,n) = 任意相邻元素之和 ≤ n 的 m 元正整数组的数目。

已知 T(3,4)=8, T(5,5)=246,
T(10,10²)≡862820094, T(10²,10)≡782136797 (mod 1e9+7)。

求 T(5000, 10¹²) mod 1e9+7。

PE 答案：815868280。

## 算法

动态规划：
dp[i][x] = 以 x 结尾、长度为 i 的有效序列数目。
dp[i][x] = Σ_{y=1}^{n-x} dp[i-1][y]

dp[i][x] 是关于 x 的 i-1 次多项式。
T(m,n) = Σ_{x=1}^{n-1} dp[m][x] 是多项式求值。

对于小规模 n，可直接 DP（O(mn)）。
对于大规模 n（10¹²），可利用多项式性质和拉格朗日插值高效计算。

递推也可写为矩阵形式：T(m,n) = 1ᵀ A^{m-1} 1，
其中 A 是 (n-1)×(n-1) 矩阵，A[x][y] = 1 当 x+y≤n。

## 改编方向

1. 推广环形约束（a₁ + a_m ≤ n 也需满足）
2. 推广到 k-邻近约束（任意 k 个连续元素之和有上界）
3. 元素取值改为有上限的整数
4. 改为求满足约束的序列数目在多个 n 值下的和
