# PE622 — 交叠洗牌 (Riffle Shuffles)

来源：改编自 Project Euler Problem 622

## 原题意

完美交叠洗牌（riffle shuffle）：将偶数张牌分成两半，上半在左手、下半在右手，然后将右手牌逐一交错插入左手牌之后。最上和最下两张牌位置不变。

s(n) = 将 n 张牌（n 为偶数）恢复原序所需的最少连续洗牌次数。

已知 s(52) = 8，且所有满足 s(n) = 8 的 n 的和为 412。

求所有满足 s(n) = 60 的 n 的和。

PE 答案：3010983666182123972。

## 算法

将牌从上到下编号为 0 到 n-1。一次洗牌后，位置 k 的牌移至：
- k → 2k (mod n-1)（k = 0, …, n-2），牌 n-1 位置不变。

因此 s(n) = ord_{n-1}(2)，即 2 在模 n-1 下的乘法阶。

s(n) = 60 意味着 n-1 整除 2⁶⁰ - 1，但不整除任何 2^d - 1（d 为 60 的真因子）。

因此需要枚举 2⁶⁰ - 1 的所有因子，筛选阶恰好为 60 的因子 d，然后对每个 d 将 d+1 累加。

2⁶⁰ - 1 的质因数分解：3² · 5 · 7 · 11 · 13 · 31 · 41 · 61 · 151 · 331 · 1321。因子总数约为 3×2¹⁰ = 3072，可以完全枚举。

## 改编方向

1. 改变洗牌规则（如 out-shuffle vs in-shuffle）。
2. 求满足 s(n) = k 的 n 的个数或和的渐近行为。
3. 增加模数约束。
4. 推广到非均匀分堆（非对半切分）。
