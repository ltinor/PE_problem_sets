# PE482 - 三角形的内心

来源：改编自 Project Euler Problem 482

## 原题意

对于所有整数边三角形（周长 $\le N$），计算与内心相关的某种量的总和。

PE 答案：14008248791472。

## 题目

给定 N，计算所有满足周长 ≤ N 的整数边三角形的内心相关量之和。

## 算法

- 枚举所有满足三角形不等式的整数边三元组 $(a, b, c)$
- 内心重心坐标为 $(a : b : c)$，转换为直角坐标需要顶点坐标
- 对每个三角形计算内心相关量并累加
- 可使用数论优化：按边长分组，利用对称性减少枚举

## 改编方向

1. **不同特殊点**：外心、重心、垂心
2. **不同计数方式**：不同内心数量
3. **限制三角形类型**：直角三角形、等腰三角形
4. **高维扩展**：四面体的内心
