# PE749 — Near Power Sums（近幂和）

来源：改编自 Project Euler Problem 749

## 原题意

"幂和"数（也称自幂数或水仙花数）是满足以下条件的数：其各位数字的 $k$ 次幂之和等于该数本身，即 $n = \sum_{d \in \text{digits}(n)} d^k$。

"近幂和"数是指各位数字的 $k$ 次幂之和与该数本身相差很小的数。形式化定义：
$$|n - \sum_{d \in \text{digits}(n)} d^k| \le \delta$$
其中 $\delta$ 是一个小的阈值（如 1）。

问题要求计算所有近幂和数（在某个范围内）的总和。

PE 答案：13459471903176422。

## 算法

1. **数位分解**：$O(\log n)$ 时间内提取各位数字。
2. **幂和计算**：对给定的 $k$，计算 $\sum d^k$，使用快速幂或预计算。
3. **搜索剪枝**：
   - 对于 $d$ 位数，最大幂和为 $d \times 9^k$
   - 只有当 $10^{d-1} \le d \times 9^k < 10^d$ 时才可能存在解
   - 这极大地限制了 $(d, k)$ 组合
4. **多 $k$ 值搜索**：对 $k = 1, 2, \dots, K_{\max}$ 分别搜索近幂和数。
5. **去重与求和**：收集所有满足条件的数，去重后求和。

## 改编方向

1. 改变阈值 $\delta$（如 $\delta$ 随 $n$ 变化）
2. 推广到负幂或分数幂
3. 考虑不同进制
4. 要求多个不同的 $k$ 同时满足条件
5. 求近幂和数的乘积或其他统计量
