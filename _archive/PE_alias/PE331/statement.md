# 十字翻转游戏

## 题目描述

有一个 N×N 的棋盘，每个格子上有一个碟子，碟子一面黑色一面白色。

在每一轮中，你可以选择一个碟子并翻转**同一行和同一列**的所有碟子（共 2N−1 个碟子被翻转）。当所有碟子白色面朝上时游戏结束。

棋盘左下角坐标为 (0,0)，右下角为 (N−1,0)，左上角为 (0,N−1)。

定义初始配置 C(N)：碟子位于 (x,y)，若 N−1 ≤ √(x²+y²) < N 则为黑色，否则为白色。

记 T(N) 为从 C(N) 开始完成游戏所需的最少翻转次数，若无法完成则 T(N)=0。

已知：T(5)=3，T(10)=29，T(1000)=395253。

给定 N，求 T(N)。

---

## 输入格式

一个整数 N。

---

## 输出格式

一个整数，表示 T(N)。

---

## 样例

### 输入
```
5
```

### 输出
```
3
```

### 输入
```
10
```

### 输出
```
29
```

---

## 数据范围

- 对于 30% 数据：N ≤ 4
- 对于 60% 数据：N ≤ 6
- 对于 100% 数据：N ≤ 8
