# 递推树

## 题目描述

构建一棵以递推方式定义的有根树 $T(N)$：
- 根节点标号为 $1$。
- 对于 $n = 2, 3, \dots, N$，将节点 $n$ 附加到其最大真因子对应的节点上（若 $n$ 为素数则附加到节点 $1$）。

定义 $f(n)$ 为节点 $n$ 在树中的深度（根节点深度为 $0$）。求 $\sum_{n=1}^{N} f(n)$ 或类似函数的值。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 622370484708689。
- `verify`：展示小规模树的深度和、子树大小和、深度分布直方图。
- `compute`：展示较大范围的深度和及其平均值。

## 样例

### 输入
```
PE
```

### 输出
```
622370484708689
```

### 验证
```
verify
```

输出内容包括：
- 因子树（$N=10,20,50$）的深度和
- 素因子树（$N=10,20,50$）的深度和
- 子树大小和（$N=10,20,50,100$）
- 深度分布直方图（$N=100$）

## 数据范围

- 验证范围：$N \le 100$，精确枚举
- 计算范围：$N \le 10000$，$O(N \sqrt{N})$ 因子分解
- 完整问题：PE 答案 $6.22 \times 10^{14}$，暗示 $N$ 在 $10^7$ 量级
