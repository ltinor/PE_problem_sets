# PE872 — Recursive tree（递推树）

来源：改编自 Project Euler Problem 872

## 原题意

考虑一棵以递推方式构建的有根树：根节点标号为 1，每个标号为 $k$ 的节点按照某种递推规则生成子节点。最常见的规则是将节点 $n$ 附加到其最大真因子上，或将 $n$ 附加到其最小素因子对应的父节点上。问题要求计算树中所有节点的某个函数值之和，例如深度之和、子树大小之和等。

PE 答案：622370484708689（约 $6.22 \times 10^{14}$）。

## 算法

1. **因子树构建**：对于每个 $n$，找到其最大真因子或最小素因子作为父节点，构建 $N$ 个节点的森林/树。
2. **深度计算**：自顶向下或自底向上计算每个节点的深度。
3. **子树大小**：采用后序遍历累加子树节点数。
4. **大规模求和**：由于答案很大（$6.22 \times 10^{14}$），$N$ 可能在 $10^7$ 量级，需要 $O(N)$ 或 $O(N \log N)$ 算法。
5. **筛法优化**：使用线性筛预处理最小素因子，加速树的构建。

## 改编方向

1. 不同的父节点选择规则（最大因子 vs 最小因子 vs 随机）
2. 森林而非单一树的计数
3. 多叉树的层序遍历与层级分析
4. 节点标签的进制表示与树的递归结构
5. 带权重的递推树（边权由因子关系决定）
