# PE400 - 斐波那契树游戏

来源：改编自 Project Euler Problem 400

## 原题意

斐波那契树 T(k) 递归定义：T(0) 为空树，T(1) 为单节点，T(k) 的左右子树分别为 T(k-1) 和 T(k-2)。两玩家轮流取走一个节点及其子树，被迫取走根节点者输。求 f(10000) 的最后 18 位，其中 f(k) 为先手在 T(k) 上的必胜第一步数。

## 题目

给定 k，求斐波那契树 T(k) 上的必胜第一步数 f(k)。

## 算法

- 树上的 impartial 游戏，可用 Sprague-Grundy 理论分析
- T(k) 可分解为左右子树的 disjunctive sum
- 取走节点等价于将对应子树替换为更小的斐波那契树森林
- f(k) 可通过 Grundy 值和组合计数递推

## 改编方向

1. **改变树结构**：使用三叉树 T(k)=T(k-1)+T(k-2)+T(k-3)
2. **改变游戏规则**：可以取走 k 个连续节点而非一个
3. **求必败第一步数**：改为求所有第一步中的必败走法数
4. **求 Grundy 值**：改为求 T(k) 的 Grundy 值
