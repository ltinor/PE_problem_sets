# PE728 — Circle of Coins (硬币圆)

来源：改编自 Project Euler Problem 728

## 原题意

N 枚硬币排成一个圆圈，每枚硬币为正面(H)或反面(T)。
每次操作可以选择连续 3 枚硬币全部翻转。
从全正面（或全反面）开始，问可以到达哪些状态，
或求某种加权计数。

## 算法

1. **GF(2) 线性代数**：状态为 N 维 GF(2) 向量，操作为循环三相邻向量。
   可达状态 = 操作向量的生成空间。
2. **特征分析**：操作矩阵的特征多项式为 x² + x + 1（在循环矩阵中）。
   x²+x+1 在 GF(2) 不可约，阶为 3。
3. **可解性**：全 1 向量可达当且仅当 N 不是 3 的倍数。
   因为 x^N - 1 被 x²+x+1 整除当且仅当 3|N。
4. **最小操作数**：当 N%3≠0 时，解唯一，操作数 = 解中 1 的个数 = ⌈N/3⌉ 或类似规律。
5. **状态空间**：操作矩阵的秩 = N - gcd(N,3)×?

## 改编方向

1. 不同的翻转模式（连续 k 枚）
2. 操作次数的限制
3. 从随机状态出发求期望操作数
4. 带权重的硬币翻转
5. 多维硬币阵列
