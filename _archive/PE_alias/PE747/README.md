# PE747 — Triangular Pizza（三角披萨）

来源：改编自 Project Euler Problem 747

## 原题意

在一个圆形披萨的圆周上随机放置 $M$ 个点，连接所有点对之间的弦。这些弦将圆分割成若干区域。

定义"三角形区域"为由三条弦界定的区域（或由弦和弧界定的三角形）。问题要求计算某种三角形区域的期望数量，或求所有可能点配置下的总数。

PE 答案：681813395。

## 算法

1. **组合计数**：对于 $M$ 个点在圆周上一级位置（无三线共点），区域总数 $R = 1 + \binom{M}{2} + \binom{M}{4}$。
2. **三角形分类**：
   - 三个顶点在圆周上：$\binom{M}{3}$ 个
   - 两个顶点在圆周上：$4\binom{M}{4}$ 个
   - 一个顶点在圆周上：$5\binom{M}{5}$ 个
   - 零个顶点在圆周上（全内部）：$\binom{M}{6}$ 个
3. **总数**：$T(M) = \binom{M}{3} + 4\binom{M}{4} + 5\binom{M}{5} + \binom{M}{6}$
4. **期望值**：当 $M$ 个点随机放置时，使用概率方法计算期望三角形数。

## 改编方向

1. 推广到多边形（非圆形）披萨
2. 限制弦的连接方式（如只连接相邻点）
3. 计算其他形状区域（四边形、五边形等）
4. 添加随机放置的约束（如点必须在对径点）
5. 三维推广（球面切割）
