# 彩虹球

## 题目描述

有 $T$ 个球，共 $C$ 种颜色，每种颜色恰好 $P$ 个（$T = C \times P$）。随机从中选取 $K$ 个球（不放回），求取到的不同颜色数量的数学期望。

## 输入格式

四个整数 $T$、$P$、$C$、$K$，或字符串 `PE`。

## 输出格式

一个浮点数，保留 9 位小数，表示期望值。

## 样例

### 输入
```
10 3 2 5
```

### 输出
```
2.000000000
```

（两种颜色各 3 个球，取 5 个，必然取到两种颜色）

## 数据范围

- 对于 30% 数据：$T \le 20$
- 对于 60% 数据：$T \le 100$
- 对于 100% 数据：$T \le 1000$
