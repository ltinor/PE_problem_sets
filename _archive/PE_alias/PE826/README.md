# PE826 — Birds on a Wire（电线上的鸟）

来源：改编自 Project Euler Problem 826

## 原题意

$N$ 只鸟依次随机降落在长度为 $L$ 的电线上，每只鸟均匀随机选择位置。若新鸟与已有鸟的距离小于 $d$，两只鸟都飞走。求最终剩余鸟数的期望值。

这是一个经典的随机顺序吸附（Random Sequential Adsorption, RSA）问题，类似于"停车问题"（car parking problem / Rényi's parking problem）。

PE 答案：23.77311635。

## 算法

1. **随机模拟（Monte Carlo）**：直接模拟鸟的降落过程，统计剩余鸟数。
2. **RSA 理论**：在连续极限下，期望覆盖率趋于 Rényi 常数 $m_1 \approx 0.74759792025\ldots$。
3. **精确计算（小规模）**：对于少量鸟的情形，可通过积分计算精确期望值。
4. **Markov 过程**：将系统状态建模为硬杆气体，使用转移概率矩阵。

## 改编方向

1. 考虑鸟的降落顺序对结果的影响
2. 推广到二维平面上的随机降落问题
3. 研究不同飞走规则（如只飞走新鸟、只飞走老鸟）
4. 考虑有向驱逐（新鸟只驱赶左侧或右侧的鸟）
5. 引入鸟的权重或优先级
