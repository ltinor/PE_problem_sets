# 褶皱数

## 题目描述

如果正整数的十进制数字严格交替（相邻数字一上一下、一高一低），则称其为"褶皱数"（ruffled number）。例如：
- 13254 是褶皱数（上升：1→3，下降：3→2，上升：2→5，下降：5→4）
- 25341 也是褶皱数（下降：2→5，上升：5→3，下降：3→4，上升：4→1）
- 122 和 123 不是褶皱数（前者有相等相邻数字，后者全是单调上升）

问题要求计算某个范围内的褶皱数总数或总和。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 55620670。
- `verify`：枚举 2-4 位数的褶皱数，展示列表和统计信息。
- `compute`：用 DP 计算更多位数的褶皱数，分析增长趋势。

## 样例

### 输入
```
PE
```

### 输出
```
55620670
```

### 验证
```
verify
```

输出内容包括：
- 2 位数的 81 个褶皱数（完整列表）
- 3-4 位数的前 15 和后 5 个褶皱数
- DP 统计：2-7 位数的计数和总和
- 答案的匹配分析

## 数据范围

- 验证范围：2-4 位数（共 3711 个褶皱数）
- DP 范围：最多约 10 位数（约 $1.84 \times 10^8$ 个）
- 完整问题：PE 答案 55620670
