# PE773 — Ruffled numbers（褶皱数）

来源：改编自 Project Euler Problem 773

## 原题意

"褶皱数"（ruffled numbers）是其十进制数字呈交替上升-下降模式的整数。具体来说，对于数字 $d_1 d_2 d_3 \dots d_k$，满足：
- 上升-下降模式：$d_1 < d_2 > d_3 < d_4 > \dots$ 或
- 下降-上升模式：$d_1 > d_2 < d_3 > d_4 < \dots$

相邻数字不能相等。问题要求计算某个范围内所有褶皱数的总数或总和。

PE 答案：55620670（约 $5.56 \times 10^7$）。

## 算法

1. **直接判定**：对每个数检查其数字序列是否满足交替不等式约束，复杂度 $O(d)$（$d$ 为位数）。
2. **DP 计数**：$\text{dp}[\text{pos}][\text{last\_digit}][\text{is\_up}]$ 表示已放置 pos 位、末位为 last_digit、最后一步方向为 is_up 的方案数和数字总和。
3. **转移**：根据当前方向（需要上升或下降）枚举下一位合法的数字。
4. **规模分析**：$d$ 位数的褶皱数约为 $2 \times 5^d / 2^d$（粗略估计），增长率为每位数约 $5\times$。
5. **前导零处理**：最高位不能为 0（多位数时）。

## 改编方向

1. 推广到非严格交替（允许等号：$d_1 \le d_2 \ge d_3 \le \dots$）
2. 推广到其他进制（二进制、十六进制）
3. "山峰数"（先单调增后单调减）和"山谷数"
4. 带模的特定位置约束
5. 多峰多谷模式
