# PE425 - 素数连接

来源：改编自 Project Euler Problem 425

## 原题意

两个数"相连"如果位数相同且仅有一位数字不同，或者通过添加/删除一位前导数字互相转换。从素数 2 出发，通过相连素数链接到的素数称为"2 的亲戚"（链中所有素数不超过目标素数）。原题求 F(10⁷)，即 ≤10⁷ 的非亲戚素数和，答案为 46479497324。

## 题目

给定 N，求所有 ≤N 且不是 2 的亲戚的素数和 F(N)。

## 算法

- 筛出所有 ≤N 的素数
- 生成每个素数的所有相邻数（改一位数字、加前导数字、删前导数字）
- 按素数升序处理：一个素数 p 是 2 的亲戚，当且仅当存在某个相邻素数 q < p 且 q 已是亲戚
- 对所有非亲戚素数求和

## 改编方向

1. **不同起点**：从 3 或 5 开始连接
2. **加权链**：定义连接代价，求最小代价
3. **最长链**：求最长连接到 2 的素数链
