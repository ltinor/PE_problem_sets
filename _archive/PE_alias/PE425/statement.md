# 素数连接

## 题目描述

两个正整数 A 和 B 被称为**相连的**（记作 A ↔ B），如果满足以下条件之一：
1. A 和 B 位数相同，且恰有一位数字不同。例如 123 ↔ 173。
2. 在 A（或 B）的左侧添加一位数字得到 B（或 A）。例如 23 ↔ 223，123 ↔ 23。

称一个素数 P 为**2 的亲戚**，如果存在一条由相连的素数组成的链连接 2 和 P，且链中所有素数都不超过 P。

例如，127 是 2 的亲戚，存在链：2 ↔ 3 ↔ 13 ↔ 113 ↔ 103 ↔ 107 ↔ 127。
而 11 和 103 不是 2 的亲戚。

定义 F(N) 为所有 ≤ N 且不是 2 的亲戚的素数之和。

已知：
- F(10³) = 431
- F(10⁴) = 78728

给定 N，求 F(N)。

---

## 输入格式

一个整数 N。

---

## 输出格式

一个整数，表示 F(N)。

---

## 样例

### 输入
```
1000
```

### 输出
```
431
```

### 输入
```
10000
```

### 输出
```
78728
```

---

## 数据范围

- 对于 30% 数据：N ≤ 10³
- 对于 60% 数据：N ≤ 10⁵
- 对于 100% 数据：N ≤ 10⁷
