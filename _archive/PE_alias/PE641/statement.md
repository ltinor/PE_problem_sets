# 长排骰子

## 题目描述

考虑一排 n 个公平的 6 面骰子，每个骰子初始随机显示 1 到 6 之间的一个面。

在每个回合中：观察第一个骰子朝上的面值 d，然后**重新投掷所有显示面值为 d 的骰子**（每个骰子重新投掷后独立均匀地取 1~6）。

当所有骰子都显示 6 时，过程结束。

记 E(n) 为从初始随机状态开始到过程结束所需的期望回合数。

例如，当 n = 1 时，不论初始面值是什么，期望回合数为 6/5 = 1.2。

求 E(666666) 模 1,000,000,007 的值。

## 输入格式

一行，字符串 `PE` 或 `verify` 或 `compute`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案。

若输入为 `verify`，输出小规模蒙特卡洛模拟结果。

若输入为 `compute`，计算 E(100) 的蒙特卡洛近似。

## 样例

### 输入
```
PE
```

### 输出
```
793525366
```

## 数据范围

- 完整问题：n = 666666
- 答案模 1,000,000,007
