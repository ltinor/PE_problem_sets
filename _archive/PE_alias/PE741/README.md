# PE741 — Binary grid colouring (网格黑白染色)

来源：改编自 Project Euler Problem 741

## 原题意

对 $n\times n$ 的网格进行黑白染色，记使得每行和每列都恰好有两个黑格的染色方法数目为 $f(n)$。
例如，$f(4)=90$，$f(7) = 3110940$，$f(8) = 187530840$。

在 $f(n)$ 中，将所有旋转或翻转后可重合的染色方法视为相同的方法（D4 对称群），记不同染色方法数目为 $g(n)$。
已知 $g(4)=20$，$g(7) = 390816$，$g(8) = 23462347$，因此 $g(7)+g(8) = 23853163$。

求 $g(7^7) + g(8^8)$ 对 $1\ 000\ 000\ 007$ 取余。

PE 答案：512895223

## 算法

1. **$f(n)$ 计数**：$n\times n$ 0-1 矩阵每行每列和均为 2，等价于 2-正则二部图。利用容斥原理或生成函数计算。小规模可查 OEIS A001499。

2. **Burnside 引理**：D4 二面体群有 8 个对称操作：
   - 恒等、90°旋转、180°旋转、270°旋转
   - 水平反射、垂直反射、主对角线反射、反对角线反射
   
   $$g(n) = \frac{1}{8}\left(f_{\text{id}} + 2f_{90} + f_{180} + 2f_h + 2f_d\right)$$

3. **大参数处理**：$n = 7^7 = 823543$（奇数）和 $n = 8^8 = 16777216$（偶数）极大，需对每个对称类分别推导封闭公式。奇偶性影响各对称类下不动点计数的结构。

4. **复杂度**：需 $O(1)$ 公式（利用模运算）直接计算。

## 改编方向

1. 参数化 $n$（不同网格大小）
2. 求每行每列恰好 $k$ 个黑格的一般情况
3. 仅考虑部分对称群（如仅旋转、仅反射）
4. 改为计数带权重的染色方案
5. 推广到三维网格
