# PE651 — 图案圆柱 (Patterned Cylinders)

来源：改编自 Project Euler Problem 651

## 原题意

无限长圆柱体侧面被长方形贴纸完全覆盖，贴纸对齐圆柱体，边缘平行于轴线。沿轴向每 a 张贴纸颜色模式重复，环绕圆周有 b 张贴纸。

f(m,a,b) = 恰好使用 m 种不同颜色的模式数目，经过平移、旋转、翻转后相同的模式只计一次。

已知 f(2,2,3)=11, f(3,2,3)=56, f(2,3,4)=156,
f(8,13,21)≡49718354, f(13,144,233)≡907081451 (mod 1e9+7)。

求 Σ_{i=4}^{40} f(i, F_{i-1}, F_i) mod 1e9+7。

PE 答案：448233151。

## 算法

使用 Burnside 引理 + 容斥原理。对称群为 D_a × D_b（轴向和圆周方向均为二面体群），|G| = 4ab。

群元素分四类：
1. (rot, rot): 两方向均平移，c = gcd(a,t)·gcd(b,s)·gcd(a/gcd(a,t), b/gcd(b,s))
2. (rot, ref): 轴向平移、周向反射
3. (ref, rot): 轴向反射、周向平移
4. (ref, ref): 两方向均反射

每种类型的循环数通过分类讨论偶/奇情况高效计算。

利用除数求和公式分组计算 Burnside 和：Σ_{d|a} φ(a/d) Σ_{d'|b} φ(b/d') k^{c(d,d')}。

最后通过容斥得到恰好使用 m 种颜色的方案数：
f(m) = Σ_{k=0}^{m} (-1)^{m-k} C(m,k) · Colorings(≤k)

对于每个 i=4..40，a=F_{i-1}, b=F_i（Fibonacci 数），分解因数后迭代除数计算。

## 改编方向

1. 推广到其他曲面（环面、Möbius 带等）
2. 限制颜色使用频率（每种颜色至少/至多出现次数）
3. 考虑贴纸方向性（长方形贴纸有方向）
4. 扩展到高维情况（如超环面着色）
