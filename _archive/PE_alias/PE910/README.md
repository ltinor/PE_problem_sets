# PE910 — $L$-expressions II（$L$-表达式二）

来源：改编自 Project Euler Problem 910

## 原题意

在同一 $L$-表达式系统中定义序列：
- $C_0 = Z$，$C_{i+1} = S(C_i)$（Church 数字编码）
- $D_i = C_i(S)(S)$

计算 $F(12, 345678, 9012345, 678, 90)$ 的最后九位数字。

PE 答案：128811200

## 算法

1. **Church 数字**：
   - $C_i$ 是 Church 数字 $i$：$C_i(f)(x) = f^i(x)$
   - $D_i = C_i(S)(S) = S^i(S)$

2. **函数复合**：
   - $F(a,b,c,d,e)$ 编码深度嵌套的函数迭代
   - $C_d(A)(e) = e + d$（基础迭代）
   - $D_c$ 将其放大为超指数级别

3. **模运算**：
   - 仅 $A(x) \to x+1$ 涉及算术
   - 结果 $= e + (\text{总应用次数}) \bmod 10^9$
   - 需要计算 $A$ 被应用的次数模 $10^9$

4. **快速增长层级**：
   - 表达式编码了 Ackermann 级别的函数
   - 总迭代次数远超宇宙原子数
   - 但模运算使其可计算
