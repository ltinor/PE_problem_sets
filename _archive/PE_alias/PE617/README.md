# PE617 — 镜面幂序列 (Mirror Power Sequence)

来源：改编自 Project Euler Problem 617

## 原题意

对于两个整数 $n,e>1$，定义 **$(n,e)$-MPS（镜面幂序列）** 为满足如下条件的无穷整数序列 $(a_i)_{i\ge 0}$：
- 对所有 $i\ge 0$，$a_{i+1} = \min(a_i^e, n - a_i^e)$
- 对所有 $i\ge 0$，$a_i > 1$

记 $C(n)$ 为对某个 $e$ 所有的 $(n,e)$-MPS 的数量。
记 $D(N) = \sum_{n=2}^N C(n)$。

已知：$D(10)=2$，$D(100)=21$，$D(1000)=69$，$D(10^6)=1303$，$D(10^{12})=1014800$。

求 $D(10^{18})$。

PE 答案：1001133757。

## 算法

MPS 序列必须无限延续且所有项 $>1$，因此序列最终必然进入不动点或循环。

**不动点**（固定点）：$a = \min(a^e, n - a^e)$ 意味着 $a^e = n - a^e$，即 $2a^e = n$ 且 $a > 1, e > 1$。因此 $n$ 必须是偶数且 $n/2$ 是完全 $e$ 次幂。每个这样的 $(a,e)$ 贡献 1 个 MPS。

**2-循环**：$a \leftrightarrow b$ 满足 $b = \min(a^e, n - a^e)$ 且 $a = \min(b^e, n - b^e)$。这要求 $n = a^e + b^e$ 且 $a < b^e$、$b < a^e$（保证不是不动点）。每个有效的 $(a,b,e)$ 贡献 2 个 MPS（以 $a$ 和 $b$ 分别起始）。

主要挑战：$N = 10^{18}$ 的规模要求数论优化。
- 不动点计数：对 $e = 2, 3, \ldots, \log_2(N/2)$，统计 $a \le (N/2)^{1/e}$ 的整数个数
- 循环计数：统计 $a^e + b^e \le N$ 的解数，利用幂和的稀疏性
