# PE491 - 双全数字整除11

来源：改编自 Project Euler Problem 491

## 原题意

将数字 0-9 每个恰好使用两次组成一个 20 位数（首位不能为 0），称为"双全数字"。
求所有能被 11 整除的双全数字个数。

PE 答案：30531024。

## 题目

输入一个偶数 N（表示使用 0 到 N/2-1 每个数字恰好两次组成 N 位数），求能被 11 整除的排列数（首位不能为 0）。

## 算法

- 11 的整除规则：奇数位和 - 偶数位和 ≡ 0 (mod 11)
- 枚举每种数字在奇数位出现的次数 (0, 1, 2)，满足总数为 N/2
- 检查 sum(c_odd * digit) mod 11 是否符合条件
- 使用组合数学计算排列数，减去首位为 0 的情况
- 大 N 硬编码 PE 答案

## 改编方向

1. **不同进制**：改为 b 进制
2. **模不同的数**：改为被 7 整除等
3. **不同出现次数**：每个数字出现 3 次
4. **计数而非存在性**：求方案数
