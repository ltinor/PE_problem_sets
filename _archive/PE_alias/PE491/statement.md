# 双全数字整除11

## 题目描述

将数字 $0$ 到 $K-1$（$K = N/2$）每个恰好使用两次，组成一个 $N$ 位数。首位不能为 0。这样的数叫做"双全数字"。

例如，当 $N=4$ 时（$K=2$，数字 $0$ 和 $1$ 各出现两次），所有合法的双全数字为：1001, 1010, 1100。

求其中能被 $11$ 整除的数的个数。

## 输入格式

一个偶数 $N$（$2 \le N \le 20$），或字符串 `PE`。

## 输出格式

一个整数，表示能被 $11$ 整除的双全数字个数。

## 样例

### 输入
```
4
```

### 输出
```
1
```

（只有 1001 能被 11 整除：1-0+0-1=0）

## 数据范围

- 对于 30% 数据：$N \le 8$
- 对于 60% 数据：$N \le 14$
- 对于 100% 数据：$N \le 20$
