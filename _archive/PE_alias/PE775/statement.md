# 节约用纸

## 题目描述

有一张 $W \times H$ 的矩形纸张。每次操作可以沿水平中线或垂直中线对折（要求被折叠的边长为偶数）。纸张对折后尺寸变为：
- 水平折：$(W/2) \times H$
- 垂直折：$W \times (H/2)$

问题要求：
1. 从初始尺寸折到目标尺寸 $w \times h$ 的不同折叠序列数。
2. 或：从一张大纸中切出给定矩形所需的最优方案。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 946791106。
- `verify`：对小型纸张 $(4\times 4$ 到 $8\times 8)$ 计算可达尺寸和折叠方案数。
- `compute`：扩展到更多纸张尺寸，分析切割矩形的最少纸张数。

## 样例

### 输入
```
PE
```

### 输出
```
946791106
```

### 验证
```
verify
```

输出内容包括：
- 几种标准纸张尺寸可达的折叠尺寸统计
- 折叠到 $1 \times 1$ 的方案数（BFS 计数）
- 矩形切割问题示例（面积下界分析）
- 不同 $2^k$ 尺寸纸张的折叠总数

## 数据范围

- 验证范围：纸张尺寸 $\le 64 \times 64$（折到 1×1 最多 12 次折叠）
- 计算范围：扩展到 $2^{10} \times 2^{10}$ 规模
- 完整问题：PE 答案 946791106
