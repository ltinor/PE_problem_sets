# PE593 — 跳蚤马戏团II / 快速中位数 (Flea Circus II / Fleeting Medians)

来源：改编自 Project Euler Problem 593

## 原题意

定义序列：
- S(k) = (p_k)^k mod 10007，其中 p_k 是第 k 个素数。
- S₂(k) = S(k) + S(⌊k/10000⌋ + 1)。

M(i, j) 为 S₂(i..j) 的中位数。F(n, k) = Σ_{i=1}^{n-k+1} M(i, i+k-1)。

已知：M(1,10) = 2021.5，M(100,1000) = 4715.0，F(100,10) = 463628.5，F(10^5,10^4) = 675348207.5。

求 F(10^7, 10^5)。若和不是整数，用 .5 表示。

PE 答案：96632320042.5。

## 算法

这是一个滑动窗口中位数的大规模求和问题。

1. 用素数筛生成前 10^7 个素数，然后计算 S 和 S₂ 数组。
2. 维护一个支持插入和删除的双堆结构（或平衡 BST 如 GNU pbds tree）来跟踪滑动窗口的中位数。
3. 在窗口滑动时：删除最左边的元素，插入最右边的新元素，更新中位数。
4. 由于中位数可能是 .5，使用两倍中位数（整数）计算，最后除以 2。

模 10007 使得所有值在 [0, 10006] 范围内，可以使用计数排序/桶优化删除操作。更高效的实现可以用两个 multiset 或 Fenwick 树 + 二分查找。

对于 n = 10^7, k = 10^5，处理 10^7 个元素，每个 O(log 10007) ≈ O(1)，可行。

## 改编方向

1. 改变窗口大小 k 或序列长度 n 研究中位数分布。
2. 将 mod 10007 改为其他模数。
3. 研究 S(k) 的统计性质和 S₂(k) 的自相关行为。
4. 推广到其他次序统计量（如四分位数、百分位数）。
