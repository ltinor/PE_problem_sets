# 开放棋局

## 题目描述

在 n×n 的棋盘上摆放 n 个兵，满足每行每列恰有一个兵。

左下角的格子保证为空。在该格子放置一个车。如果该车能够只向右或向上移动（如象棋中车的走法），在不经过任何有兵格子的前提下到达右上角的格子，则称该局面为**开放**局面。

记 f(n) 为 n×n 棋盘上开放局面的数目。

例如，在 3×3 棋盘上有 f(3)=2 种开放局面，在 5×5 棋盘上有 f(5)=70 种。

求 f(10⁸)，并将答案对 1,008,691,207 取模。

## 输入格式

一行，字符串 `PE` 或 `verify` 或 `compute`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案。

若输入为 `verify`，输出 f(1) 到 f(6) 的计算验证结果。

若输入为 `compute`，计算 f(5)。

## 样例

### 输入
```
PE
```

### 输出
```
210286684
```

## 数据范围

- 完整问题：n = 10⁸
- 验证模式：n ≤ 7
- 取模：1,008,691,207
