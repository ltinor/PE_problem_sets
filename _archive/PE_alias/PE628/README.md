# PE628 — 开放棋局 (Open Chess Positions)

来源：改编自 Project Euler Problem 628

## 原题意

在 n×n 的棋盘上摆放 n 个兵，每行每列恰有一个兵。

若从（空的）左下角出发的车，只能向右或向上移动，且不经过任何有兵的格子，能到达右上角，则称该局面为**开放**局面。

记 f(n) 为 n×n 棋盘上开放局面的数目。

已知 f(3)=2，f(5)=70。

求 f(10⁸) mod 1,008,691,207。

PE 答案：210286684。

## 算法

每个局面对应一个排列 p，其中 p[i] 表示第 i 行的兵所在的列。

车从 (0,0) 滑动到 (n-1,n-1)，只能向右或向上滑动（象棋中车的走法），且不能在兵所在的格子停留。

### 小规模验证

对 n≤7，枚举所有排列并在 BFS 中模拟车的滑动路径，统计开放局面数。

### 大规模计算

f(n) 满足递推关系（可用生成函数或 Catalan 数表示）。对于 n=10⁸，需要使用数学公式和对大模数的快速计算。

## 改编方向

1. 改变棋盘形状（n×m 矩形）
2. 修改棋子的种类或数量
3. 允许车向四个方向移动（增加向下和向左）
4. 研究 f(n) 的递推关系和生成函数
