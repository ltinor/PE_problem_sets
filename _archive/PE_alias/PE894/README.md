# PE894 — Spiral of Theodorus（泰奥多勒斯螺线）

来源：改编自 Project Euler Problem 894

## 原题意

泰奥多勒斯螺线（Spiral of Theodorus，也称平方根螺线）由一系列直角三角形构成：
- 从直角边长为 (1, 1) 的三角形开始（斜边 $\sqrt{2}$）
- 第 $k$ 个三角形的直角边长为 $(1, \sqrt{k})$，斜边 $\sqrt{k+1}$
- 依次连接，形成螺线

点 $P_n$ 的极坐标为：$r_n = \sqrt{n+1}$，$\varphi_n = \sum_{k=1}^{n} \arctan(1/\sqrt{k})$。

问题可能涉及：螺线内的格点数、螺线的圈数、或几何统计。

## 算法

1. **坐标计算**：
   - 迭代计算每步的旋转和平移
   - $P_n = P_{n-1} + (\cos\varphi_n, \sin\varphi_n) \cdot (\sqrt{n+1} - \sqrt{n})$

2. **渐近行为**：
   - $\varphi_n \approx 2\sqrt{n}$（大 $n$ 下）
   - 螺线近似阿基米德螺线

3. **格点计数**：
   - 使用射线法（Ray casting）判断格点是否在螺线多边形内
   - 边界框限制搜索范围
