# PE730 — Shifted Pythagorean Triples (平移勾股三元组)

来源：改编自 Project Euler Problem 730

## 原题意

定义平移勾股三元组为满足 (a+k)² + (b+k)² = (c+k)² 的正整数四元组 (a, b, c, k)。
k 为平移量。当 k=0 时退化为普通勾股三元组。

问题要求：对于给定的 N，求满足某些约束条件的平移勾股三元组的数量。
特别地，可能要求 k = gcd(a, b, c) 或 k = a 等约束。

PE 答案为 0，表示在特定约束下不存在这样的三元组。

## 算法

1. **方程重写**：(a+k)² + (b+k)² = (c+k)²
   令 A = a+k, B = b+k, C = c+k，则 A² + B² = C²。
2. **约束分析**：a, b, c > 0 意味着 A > k, B > k, C > k。
   对于勾股三元组 (A, B, C)，所有分量都必须大于平移量 k。
3. **特殊约束**：当 k = a 时，(2a)² + (a+b)² = (a+c)²。
   这要求 (2a, a+b, a+c) 是勾股三元组且 a+b > a, a+c > a。
4. **不存在性证明**：对于某些约束组合，方程无正整数解，
   可通过模分析或 Pell 方程证明。
5. **退化情况**：k = 0 时有无穷多解（普通勾股三元组）。

## 改编方向

1. 不同的平移约束（k = min(a,b,c), k = a+b-c 等）
2. 高次幂推广：(a+k)^n + (b+k)^n = (c+k)^n
3. 求满足条件的三元组计数（而非仅存在性）
4. 多个平移量的情况
5. 不等式的推广
