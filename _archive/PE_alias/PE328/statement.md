# 最低成本搜索

## 题目描述

要在 {1, 2, ..., n} 中找出一个隐藏数。每次可以猜一个数 k，花费成本 k。你会得到三种回答之一：
- "你猜的数小于隐藏数"
- "猜对了！"
- "你猜的数大于隐藏数"

记 C(n) 为最优策略下最坏情况的总成本。

例如：C(1)=0, C(2)=1, C(3)=2, C(8)=12。
已知 Σ_{n=1}^{100} C(n) = 17575。

给定 N，求 Σ_{n=1}^{N} C(n)。

---

## 输入格式

一个整数 N (1 ≤ N ≤ 1200)。

---

## 输出格式

一个整数，表示 Σ_{n=1}^{N} C(n)。

---

## 样例

### 输入
```
100
```

### 输出
```
17575
```

---

## 数据范围

- 对于 30% 数据：N ≤ 100
- 对于 60% 数据：N ≤ 500
- 对于 100% 数据：N ≤ 1200
