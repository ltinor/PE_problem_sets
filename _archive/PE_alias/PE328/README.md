# PE328 - 最低成本搜索
来源：改编自 Project Euler Problem 328

## 原题意

在 {1..n} 中猜隐藏数。猜 k 花费 k，得到"更低/正确/更高"回答。C(n) 为最优策略的最坏情况成本。求 ΣC(n)。

## 题目

给定 N，求 Σ_{n=1}^{N} C(n)。

## 算法

- 区间 DP：dp[L][R] = min_{k=L..R} {k + max(dp[L][k-1], dp[k+1][R])}
- 使用 Knuth 优化至 O(N²)
- 对于 OJ，N ≤ 2000

## 改编方向

1. **限制猜测次数**：允许最多 K 次猜测
2. **非均匀代价**：猜 k 花费 f(k)
3. **交互式**：在线回答查询
