# 素数位和（Prime Digit Sum）

## 题目描述

对于给定的正整数 $N$，考虑所有不超过 $N$ 的素数 $p$。定义 $S(p)$ 为 $p$ 的十进制表示中各位数字之和。

例如：
- $S(2) = 2$
- $S(11) = 1+1 = 2$
- $S(23) = 2+3 = 5$
- $S(997) = 9+9+7 = 25$

计算所有素数 $p \leq N$ 的 $S(p)$ 之和。或者，计算所有使得 $S(p)$ 也是素数的 $p$（加性素数）的个数或和。

## 输入格式

无输入（固定参数问题）。

## 输出格式

输出一个整数，表示计算结果。

## 样例

（无样例输入输出，直接计算并输出最终答案。）
