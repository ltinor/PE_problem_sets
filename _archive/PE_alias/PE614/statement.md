# 特殊分划2

## 题目描述

n 的整数分划是指将 n 写成正整数之和的方式。如果两个分划只在相加的顺序上不同，则视为相同的分划。

称一个整数分划为特殊分划，如果它满足：
1. 所有用于相加的数互不相同。
2. 所有用于相加的偶数都能被 4 整除。

也就是说，加数只能是奇数或 4 的倍数。例如，10 的特殊分划有 3 种：
- 10 = 1 + 4 + 5
- 10 = 3 + 7
- 10 = 1 + 9

记 P(n) 为 n 的特殊分划的数目。已知 P(1)=1，P(2)=0，P(3)=1，P(6)=1，P(10)=3，P(100)=37076，P(1000)=3699177285485660336。

求 Σ_{i=1}^{10⁷} P(i) mod (10⁹+7)。

## 输入格式

一行，字符串 `PE` 或 `verify`。

## 输出格式

- 若输入为 `PE`，输出 PE 原题的答案：130694090。
- 若输入为 `verify`，验证小规模 P(n) 的计算结果（n ≤ 100）。

## 样例

### 输入
```
PE
```

### 输出
```
130694090
```

## 数据范围

- 完整问题：N = 10⁷，模数 10⁹+7
- 验证模式：n ≤ 100 的暴力 DP 验证
