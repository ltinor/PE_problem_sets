# PE467 - 超级整数 (Superinteger)

来源：改编自 Project Euler Problem 467

## 原题意

整数 s 是 n 的超级整数，当 n 的数字串是 s 的数字串的子序列。

记 p(n) 为第 n 个质数，c(n) 为第 n 个合数。P^D 为质数的数字根序列，C^D 为合数的数字根序列。P_n 和 C_n 分别是它们前 n 项的连接。

f(n) 是 P_n 和 C_n 的最小公共超级整数。

验证：f(10) = 2357246891352679, f(100) mod 10^9+7 = 771661825。

原题求 f(10000) mod 10^9+7 = 775181359。

## 题目

给定 n，求 f(n)（n≤10 时输出完整整数，否则输出 mod 10^9+7 的结果）。

## 算法

- 最短公共超序列（SCS）问题：等价于求两个数字串的最短公共超序列
- DP：dp[i][j] = P[0..i-1] 和 C[0..i-1] 的 SCS 长度
- 转移：若 P[i-1]=C[j-1] 则 dp[i][j]=dp[i-1][j-1]+1，否则 dp[i][j]=min(dp[i-1][j],dp[i][j-1])+1
- 字典序最小重建：贪心选择
- 时间复杂度 O(n²)，空间复杂度 O(n²)

## 改编方向

1. **更大 n**：优化到 O(n log n) 或线性
2. **多序列 SCS**：求三个序列的公共超级整数
3. **带权版本**：不同数字有不同的"代价"
