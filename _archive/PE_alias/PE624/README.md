# PE624 — 两个头比一个好 (Two heads are better than one)

来源：改编自 Project Euler Problem 624

## 原题意

反复抛掷一枚公平硬币，直到出现连续两次正面。设此时总抛掷次数为 M（即第 M-1 和第 M 次均为正面）。

令 P(n) 为 M 能被 n 整除的概率。

已知 P(2) = 3/5，P(3) = 9/31。可以证明 P(n) 总是有理数。

对于素数 p 和最简分数 a/b，定义 Q(a/b, p) 为满足 a ≡ bq (mod p) 的最小正整数 q。

例如 Q(P(2), 109) = 66，Q(P(3), 109) = 46。

求 Q(P(10¹⁸), 1,000,000,009)。

PE 答案：984568441。

## 算法

将过程建模为马尔可夫链。状态：
- S（初始 / 上次抛反面）
- H（上次抛正面但尚未连续）
- HH（吸收态，连续两次正面）

转移矩阵 M = [[1/2, 1/2], [1/2, 0]] 对应 (S, H) 之间的转移。

吸收时间分布：P(M = k) = F_{k-1} / 2^k（k ≥ 2），其中 F_n 是斐波那契数。

因此 P(n) = Σ_{j≥1} F_{jn-1} / 2^{jn}。

代入 Binet 公式 F_k = (α^k - β^k)/√5（α = (1+√5)/2, β = (1-√5)/2），得到闭式：
P(n) = (1/√5) · [α⁻¹·xⁿ/(1-xⁿ) - β⁻¹·yⁿ/(1-yⁿ)]

其中 x = α/2, y = β/2。

对模 p = 10⁹+9 计算：首先解 √5 mod p（Tonelli-Shanks 算法），然后在模意义下计算 α, β, x, y，代入公式得到 P(10¹⁸) mod p。由于 Q(a/b, p) = a·b⁻¹ mod p，最终答案即为 P(10¹⁸) mod p。

## 改编方向

1. 推广到需要连续 k 次正面（k ≥ 3）的情形。
2. 使用不公平硬币（正反面概率不为 1/2）。
3. 求 P(n) 对多个 n 的联合概率。
4. 改为条件概率问题（如已知 M ≤ N 求 P(n)）。
