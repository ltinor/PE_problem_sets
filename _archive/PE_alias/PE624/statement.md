# 两个头比一个好

## 题目描述

不断抛掷一枚公平硬币，直到连续两次抛出正面。记此时的总抛掷次数为 M（即第 M-1 和第 M 次均为正面）。

令 P(n) 表示 M 能被 n 整除的概率。例如，HH、HTHH 和 THTTHH 的结果均计入 P(2)，而 THH 和 HTTHH 不计入。

已知 P(2) = 3/5，P(3) = 9/31。可以证明 P(n) 总是有理数。

对于素数 p 和最简分数 a/b，定义 Q(a/b, p) 为满足 a ≡ bq (mod p) 的最小正整数 q。

例如，Q(P(2), 109) = Q(3/5, 109) = 66，因为 5×66 = 330 ≡ 3 (mod 109)。

同理可得 Q(P(3), 109) = 46。

求 Q(P(10¹⁸), 1,000,000,009)。

## 输入格式

一行，字符串 `PE` 或 `verify` 或 `compute`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案：984568441。

若输入为 `verify`，输出 P(2) 和 P(3) mod p 的验证。

若输入为 `compute`，实际计算并输出结果。

## 样例

### 输入
```
PE
```

### 输出
```
984568441
```

## 数据范围

- 完整问题：n = 10¹⁸，p = 1,000,000,009
- 验证模式：n ∈ {2, 3}
