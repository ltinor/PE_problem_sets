# PE898 — Clock Sequence II（时钟序列II）

来源：改编自 Project Euler Problem 898

## 原题意

"时钟序列"是指由确定性的递推关系定义的序列，该序列最终会进入循环（就像时钟一样）。这是之前时钟序列问题的延续，研究序列的极限统计性质。

PE 答案：0.69233750

## 算法

1. **周期检测**：
   - 使用 Floyd 或 Brent 算法检测序列的周期
   - 记录前周期长度和周期长度

2. **极限统计**：
   - 在周期内计算满足某条件的元素比例
   - 该比例即为极限概率

3. **递推类型**：
   - $a_{n+1} = a_n + \text{digit\_sum}(a_n)$
   - $a_{n+1} = \text{digital\_root}(a_n^2)$
   - 涉及模运算的变体

3. 推广到基于不同数字操作的变体
4. 分析周期长度的分布
