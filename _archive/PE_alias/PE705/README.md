# PE705 — Division Inversion（除法反转）

来源：改编自 Project Euler Problem 705

## 原题意

"除法反转"（Division Inversion）涉及模 n 下的乘法逆元。对于正整数 n 和 a（满足 1 ≤ a < n，gcd(a,n) = 1），a 在模 n 下的逆元 a⁻¹ mod n 是唯一满足 a × a⁻¹ ≡ 1 (mod n) 的整数（1 ≤ a⁻¹ < n）。

考虑所有这样的 (n, a) 对，求所有模逆元的和：
```
F(N) = Σ_{n=1}^{N} Σ_{a: 1≤a<n, gcd(a,n)=1} (a⁻¹ mod n)
```

PE 答案：480440153。

## 算法

1. **关键观察**：在 (ℤ/nℤ)×（模 n 的可逆元群）中，映射 a → a⁻¹ 是一个对合（involutive permutation）。因此：
   ```
   Σ_{a: gcd(a,n)=1} a⁻¹ = Σ_{a: gcd(a,n)=1} a
   ```

2. **与 n 互质的数之和**：
   ```
   Σ_{a: 1≤a<n, gcd(a,n)=1} a = n × φ(n) / 2
   ```
   其中 φ(n) 是欧拉函数。

3. **化简**：
   ```
   F(N) = Σ_{n=1}^{N} n × φ(n) / 2
   ```

4. **高效计算**：
   - 使用线性筛法在 O(N) 时间内计算 φ(1)..φ(N)
   - 对于 N = 2000 左右（若答案 ~4.8×10⁸），计算非常快速
   - 对于更大的 N，可使用杜教筛（杜教筛/Dirichlet 卷积）在 O(N^{2/3}) 时间内计算前缀和

5. **验证**：
   - n × φ(n) / 2 对于所有 n ≥ 3 都是整数（因为 φ(n) 对 n>2 总是偶数）
   - F(N) 的增长约为 N³ / π²

## 改编方向

1. 求逆元的其他统计量（最大值、中位数等）
2. 只考虑 n 为质数的情况
3. 推广到其他模数（如模 M 下的逆元）
4. 求逆元等于自身的 a（即 a² ≡ 1 mod n）的计数
5. 考虑在多项式环上的"除法反转"
