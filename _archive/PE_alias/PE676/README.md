# PE676 — 相同数字和 (Matching Digit Sums)

来源：改编自 Project Euler Problem 676

## 原题意

记 $d(i,b)$ 为数 $i$ 在 $b$ 进制下的数字和。例如 $d(9,2)=2$（$9=1001_2$）。

不同进制下的数字和通常不同，但有些数 $i$ 在不同进制下会有相同的数字和，如 $d(17,4)=d(17,2)=2$。

记 $M(n,b_1,b_2)$ 为所有满足 $i \le n$ 且 $d(i,b_1)=d(i,b_2)$ 的自然数 $i$ 之和。

已知：$M(10,8,2)=18$，$M(100,8,2)=292$，$M(10^6,8,2)=19173952$。

求 $\sum_{k=3}^6 \sum_{l=1}^{k-2}M(10^{16},2^k,2^l)$，给出最后 16 位数字。

PE 答案：2668608479740672。

## 算法

1. **进制转换与数字和**：
   - 对于 $2^k$ 进制，可以将二进制表示按 $k$ 位分组
   - $d(i,2^k) = \sum_{j} (i \gg (j\cdot k)) \mathbin{\&} (2^k-1)$
   - $d(i,2)$ 即为 popcount（二进制中 1 的个数）

2. **数位 DP**：
   - 对每个 $(k,l)$ 对，使用数位 DP 统计满足 $d(i,2^k)=d(i,2^l)$ 的数
   - DP 状态：当前二进制位、差分值、是否紧贴上限
   - 同时统计符合条件的数的个数与和

3. **优化技巧**：
   - 利用 $M(n,b_1,b_2)$ 的组合结构进行加速
   - $2^k$ 进制下数字和的分布具有规律性
   - 可以使用生成函数或矩阵乘法加速大范围计算

4. **复杂度**：
   - $10^{16} \approx 2^{53.15}$，需要约 54 位的 DP
   - 对于 $(k,l) \in \{(3,1),(4,1),(4,2),(5,1),(5,2),(5,3),(6,1),(6,2),(6,3),(6,4)\}$ 共 10 对

## 改编方向

1. 参数化 $N$ 的范围（代替固定的 $10^{16}$）
2. 推广到任意进制对 $(b_1,b_2)$ 而不仅是 2 的幂
3. 统计数字和相等的数对个数而非求和
4. 扩展到三个或更多进制的数字和匹配问题
