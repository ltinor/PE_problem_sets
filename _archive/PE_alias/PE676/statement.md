# 相同数字和

## 题目描述

记 $d(i,b)$ 为数 $i$ 在 $b$ 进制下的**数字和**。例如 $d(9,2)=2$，因为 $9=1001_2$。不同进制下的数字和通常是不同的，例如 $d(9,4)=3 \ne d(9,2)$。

然而，对于某些数 $i$，在不同进制下的数字和可能会相同，比如 $d(17,4)=d(17,2)=2$。

记 $M(n,b_1,b_2)$ 为所有满足 $i \le n$ 且 $d(i,b_1)=d(i,b_2)$ 的自然数 $i$ 之和。

例如：$M(10,8,2)=18$，$M(100,8,2)=292$，$M(10^6,8,2)=19173952$。

求 $\displaystyle \sum_{k=3}^6 \sum_{l=1}^{k-2}M(10^{16},2^k,2^l)$，给出其最后 16 位数字作为答案。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 2668608479740672。
- `verify`：验证小样例（含 M(10,8,2)、M(100,8,2)、M(10^6,8,2) 等）。
- `compute`：重新计算完整答案。

## 样例

### 输入
```
PE
```

### 输出
```
2668608479740672
```

## 数据范围

- 完整问题：$n = 10^{16}$，$b_1,b_2 \in \{2^1,2^2,2^3,2^4,2^5,2^6\}$
- 共有 10 组 $(k,l)$ 对，每组需求 $M(10^{16},2^k,2^l)$
- 答案取最后 16 位十进制数字
