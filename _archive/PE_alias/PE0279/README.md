# 整数边 & 整数角三角形 (Triangles with integral sides and an integral angle)

来源：改编自 Project Euler Problem 279

## 原题意

统计周长不超过 $10^8$ 且至少有一个整数角（以度为单位）的整数边三角形个数。PE 答案：416577688。

## 题目

输入 $N$，输出周长 $\le N$ 的满足条件的三角形数。

## 数据范围

$3 \le N \le 10^8$。

## 算法

### 方向一：生成三类本原三角形并计数（核心）

利用余弦定理，只可能出现在整数边三角形中的整数角为 $60\degree$、$90\degree$、$120\degree$。三类互相不重叠。

分别用 Eisenstein / 毕达哥拉斯三元组参数化生成本原三角形，再用 $\lfloor N/P \rfloor$ 累加全部倍数。用 `set` 对本原三角形去重。

三类参数化：

| 角 | 方程 | 本原参数化 | 周长 |
|---|---|---|---|
| $90\degree$ | $a^2+b^2=c^2$ | $(m^2-n^2,\;2mn,\;m^2+n^2)$ | $2m(m+n)$ |
| $60\degree$ | $a^2+b^2-ab=c^2$ | $(m^2-n^2,\;2mn-n^2,\;m^2-mn+n^2)$ | $2m^2+mn-n^2$ |
| $120\degree$ | $a^2+b^2+ab=c^2$ | $(m^2-n^2,\;2mn+n^2,\;m^2+mn+n^2)$ | $(2m+n)(m+n)$ |

条件：$m>n>0$，$\gcd(m,n)=1$；$90\degree$ 还需 $m-n$ 为奇数；$60\degree/120\degree$ 还需 $m \not\equiv n \pmod 3$。

### 方向二：暴力枚举（仅小数据）

$O(N^3)$ 枚举所有三角形，用余弦定理检查整数角。适用于 $N \le 200$ 验证。

### 方向三：数论推导（等价）

直接在 Eisenstein 整数环和 Gauss 整数环中生成范数分解，本质上与方向一相同。

### 时间复杂度

$O(\sqrt{N})$ 生成本原三角形，$10^8$ 时约 $10^6$ 个本原，可在 1 秒内完成。
