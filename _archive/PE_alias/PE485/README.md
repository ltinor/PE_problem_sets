# PE485 - 最大约数个数

来源：改编自 Project Euler Problem 485

## 原题意

$d(n)$ 为 $n$ 的约数个数。$S(u,k)$ 为所有长度为 $k$ 的滑动窗口中 $d(n)$ 的最大值之和。

求 $S(10^8, 10^5)$。PE 答案：51281274353247367。

## 题目

给定 u 和 k，求滑动窗口最大约数个数的总和。

## 算法

- 使用线性筛（SPF）预计算每个数的约数个数
- $d(n) = \prod (e_i + 1)$，其中 $e_i$ 是质因数指数
- 滑动窗口最大值：使用单调队列（deque）$O(u)$
- 对 u ≤ 10^8，需要高效内存：使用 short 存储 d(n)（最大约数个数不超过 ~1000）
- 可以分段处理以节省内存

## 改编方向

1. **不同数论函数**：$\sigma(n)$（约数和）、$\phi(n)$（欧拉函数）
2. **最小值窗口**：滑动窗口最小值之和
3. **不同窗口大小**：$k$ 随 $i$ 变化
4. **加权窗口**：窗口中元素带权重
