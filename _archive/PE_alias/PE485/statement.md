# 最大约数个数

## 题目描述

记 $d(n)$ 为 $n$ 的正约数个数。

定义 $S(u, k) = \sum_{i=1}^{u-k+1} \max_{i \le j < i+k} d(j)$。

给定 $u$ 和 $k$，求 $S(u, k)$。

---

## 输入格式

两个整数 $u$ 和 $k$。

---

## 输出格式

一个整数，表示 $S(u, k)$。

---

## 样例

### 输入
```
10 3
```

### 输出
```
...
```

---

## 数据范围

- 对于 30% 数据：$u \le 1000$
- 对于 60% 数据：$u \le 10^5$
- 对于 100% 数据：$u \le 10^8, k \le 10^5$
