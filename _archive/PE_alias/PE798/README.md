# PE798 — Card Stacking Game（堆牌游戏）

来源：改编自 Project Euler Problem 798

## 原题意

两位玩家用一副共 $s$ 个花色、每个花色包含 $1$ 到 $n$ 共 $n$ 张牌的扑克牌进行游戏。游戏开始前，从牌中挑出若干张（可不挑）面朝上放在桌上，称作可见牌。玩家轮流选择牌堆中的一张牌 X 覆盖在可见牌 Y 上，要求 X 和 Y 同花色且点数 X > Y。无法行动的玩家输。

$C(n, s)$ 表示先手必败的初始可见牌布置数目。已知 $C(3, 2) = 26$，$C(13, 4) \equiv 540318329 \pmod{10^9+7}$。求 $C(10^7, 10^7)$。

PE 答案：19.16212503。

## 算法

1. **公平组合游戏**：每个花色独立，游戏等价于 Nim 游戏。
2. **Sprague-Grundy 定理**：总体 Grundy 值为各花色 Grundy 值的异或。先手必败当且仅当异或值为 0。
3. **间隙 Nim 编码**：每个花色的可见牌 $v_1 < \dots < v_k$ 编码为 $(v_1-1), (v_2-v_1-1), \dots, (n-v_k)$ 的 Nim 堆。
4. **组合计数**：$C(n,s)$ 为满足 XOR = 0 的间隙配置数目，可通过生成函数卷积计算。
5. **大规模计算**：$n = s = 10^7$ 需要高级组合恒等式或渐近公式。

## 改编方向

1. 推广到不同花色有不同牌数（$n_i$ 各异）
2. 允许跨花色的放置规则
3. 计算期望游戏长度
4. 引入随机初始可见牌的期望分析
5. 三人和多人扩展
