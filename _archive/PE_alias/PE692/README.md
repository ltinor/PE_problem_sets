# PE692 — Siegbert and Jo (Siegbert与Jo)

来源：改编自 Project Euler Problem 692

## 原题意

Siegbert 和 Jo 玩一个堆石子游戏。初始有若干堆石子。
每回合，玩家选择一个非空的堆，将其替换为 $0$ 个、$1$ 个或 $2$ 个石子数总和比原堆少 $1$ 的堆
（即移除 $1$ 个石子并将剩余的 $n-1$ 个石子任意分成两堆，或保留一堆不分裂，或全部移除）。
无法移动的玩家输掉游戏。Siegbert 先手。

定义 $G(n)$ 为单个大小为 $n$ 的堆的 Grundy 数（nim 值）。
求 $H(10^{18}) = \sum_{n=1}^{10^{18}} G(n)$。

PE 答案：842043391019219959。

## 算法

1. **Grundy 数定义**：
   $$G(0) = 0,\quad G(n) = \text{mex}\big(\{0\} \cup \{G(a) \oplus G(b) \mid a+b = n-1\}\big)$$
   其中 $\{0\}$ 对应移除整堆的操作；$a+b=n-1$ 对应移除 $1$ 个石子并分裂剩余的操作。

2. **小规模计算**：对 $n \le 10^5$ 直接 DP 计算 $G(n)$。

3. **寻找规律**：观察 Grundy 序列的周期性或模式。此游戏的 Grundy 数与斐波那契进制表示相关，
   序列具有可预测的模式，可以利用数位 DP 或周期性求和大范围结果。

4. **复杂度**：对于 $10^{18}$，需要利用 Grundy 序列的数学结构，而非逐项计算。

## 改编方向

1. 参数化堆的数量上限
2. 修改分裂规则（如允许分成 $3$ 堆）
3. 求所有 P-positions（$G(n)=0$）的个数
4. 多堆初始状态的胜负判定
