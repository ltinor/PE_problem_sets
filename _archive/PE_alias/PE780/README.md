# PE780 — Triangle System（三角系统）

来源：改编自 Project Euler Problem 780

## 原题意

考虑一个三角形网格或三角系统。问题可能涉及：
- 在三角形网格（如 Pascal 三角形）中计算路径数、和或乘积。
- 在三角形晶格中进行某种组合计数。
- 三角形系统中的几何配置或不等式系统。

PE 答案：314079.9802（一个带有 4 位小数的值）。

## 算法

1. **Pascal 三角形**：$\binom{n}{k} = \binom{n-1}{k-1} + \binom{n-1}{k}$。
2. **三角形路径计数**：从顶点到底部的路径数为 $2^{n-1}$。
3. **三角形网格点**：边长为 $n$ 的等边三角形晶格共有 $(n+1)(n+2)/2$ 个格点。
4. **Catalan 数**：凸多边形的三角剖分数为 Catalan 数 $C_n = \frac{1}{n+1}\binom{2n}{n}$。
5. **重心坐标**：三角形内点的重心坐标 $(\alpha, \beta, \gamma)$，$\alpha+\beta+\gamma=1$。
