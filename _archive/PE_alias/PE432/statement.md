# 欧拉函数和

## 题目描述

欧拉函数 φ(k) 表示 [1,k] 中与 k 互质的数的个数。

定义 S(n,m) = Σ_{i=1}^{m} φ(n × i)。

例如 S(510510, 10^6) = 45480596821125120。

给定 n 和 m，求 S(n,m)。对于 m ≥ 10^9 的情况，输出答案的最后 9 位数字。

---

## 输入格式

一行两个整数 n 和 m。

---

## 输出格式

一个整数，表示 S(n,m)（或其后 9 位数字）。

---

## 样例

### 输入
```
6 10
```

### 输出
```
160
```

### 输入
```
510510 1000000
```

### 输出
```
45480596821125120
```

### 输入
```
510510 100000000000
```

### 输出
```
754862080
```

---

## 数据范围

- 对于 30% 数据：n·m ≤ 10^6
- 对于 60% 数据：n·m ≤ 10^7
- 对于 100% 数据：n ≤ 510510, m ≤ 10^11
