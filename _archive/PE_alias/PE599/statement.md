# 魔方上色

## 题目描述

2×2×2 魔方有 8 个小立方体，共 24 个可见面。有 n 种不同颜色可选（每种无限量），每个面贴一张贴纸。

两种涂色方案称为"本质上不同的"，如果无法通过合法的魔方旋转操作将一种变为另一种。

已知：有 2 种颜色可选时，共 183 种本质上不同的涂色方案。

求：有 10 种颜色可选时的方案数。

## 输入格式

一行，字符串 `PE` 或 `verify`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案：26032424610。
若输入为 `verify`，验证 n=2 时的结果（应为 183）。

## 样例

### 输入
```
PE
```

### 输出
```
26032424610
```

## 数据范围

- 完整问题：n = 10
- 验证模式：n = 2
