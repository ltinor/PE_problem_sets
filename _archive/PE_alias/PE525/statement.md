# 滚动椭圆

## 题目描述

椭圆 E(a, b) 的初始位置由以下方程给出：

$$\frac{x^2}{a^2} + \frac{(y-b)^2}{b^2} = 1$$

椭圆沿 x 轴无滑动地滚动一周。椭圆中心的运动轨迹是一条曲线，记其长度为 C(a, b)。

已知 C(2, 4) ≈ 21.38816906。

给定参数 a 和 b，求 C(a, b)。将答案四舍五入保留到小数点后 8 位。

（注：在 PE 原题中需求 C(1, 4) + C(3, 4)。）

## 输入格式

一行，两个浮点数 a, b（以空格分隔），或字符串 `PE`。

## 输出格式

一个浮点数，保留 8 位小数，表示 C(a, b)。

若输入仅含两个数 a, b，输出 C(a, b)。
若输入含三个数 a1, a2, b，输出 C(a1, b) + C(a2, b)。

## 样例

### 输入
```
2 4
```

### 输出
```
21.38816906
```

### 输入
```
1 3 4
```

### 输出
```
44.69921807
```

## 数据范围

- a, b 为正实数，且 a, b ∈ [0.1, 100]
- 精度要求：输出与标准答案误差不超过 10⁻⁸
