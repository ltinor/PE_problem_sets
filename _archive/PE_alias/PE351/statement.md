# 六边形果园

## 题目描述

n 阶**六边形果园**是在边长为 n 的正六边形中的三角形网格。站在中心向外看，某些点会被更近的点挡住。

记 H(n) 为 n 阶六边形果园中从中心看去被挡住的点的数量。

例如：H(5) = 30，H(10) = 138，H(1000) = 1177848。

给定整数 N，求 H(N)。

---

## 输入格式

一个整数 N。

---

## 输出格式

一个整数，表示 H(N)。

---

## 样例

### 输入
```
5
```

### 输出
```
30
```

### 输入
```
10
```

### 输出
```
138
```

### 输入
```
1000
```

### 输出
```
1177848
```

---

## 数据范围

- 对于 30% 数据：N ≤ 100
- 对于 60% 数据：N ≤ 10^5
- 对于 100% 数据：N ≤ 10^7
