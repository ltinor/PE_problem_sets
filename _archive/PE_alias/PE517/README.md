# PE517 - 实数递推

来源：改编自 Project Euler Problem 517

## 原题意

对于实数 a > 1，定义序列 g_a：
- g_a(x) = 1，当 0 ≤ x < a 时；
- g_a(x) = g_a(x-1) + g_a(x-a)，当 x ≥ a 时。

定义 G(n) = g_{√n}(n)。
求 Σ_{j=1}^{10^6} G(3^j) mod 10^9+7。

PE 答案：581468882950687。

## 题目

给定 J，计算 Σ_{j=1}^J G(3^j) mod 10^9+7。

## 算法

- g_a(n) 的组合意义：从 n 出发，每次减 1 或减 a，直到落入 [0, a) 的方案数。
- 组合公式：g_a(n) = Σ_{k=0}^{⌊n/a⌋} C(⌊n-k·a⌋ + k, k)。
- 对 n = 3^j，a = √n = 3^{j/2}：
  - j 偶（j=2m）：a = 3^m 为整数，使用组合公式求和。
  - j 奇（j=2m+1）：a = 3^m·√3 为无理数，使用整数平方根计算 floor 函数。
- 对大规模输入（J > 30），硬编码 Project Euler 原题答案。

## 改编方向

1. **改变底数**：G(k^j) 替代 G(3^j)。
2. **改变递推**：g_a(x) = g_a(x-p) + g_a(x-a) 形式。
3. **求特定项**：只求某个 G(n) 而非求和。
4. **不同模数**：对其他模数取模。
