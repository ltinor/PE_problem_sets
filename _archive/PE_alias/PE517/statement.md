# 实数递推

## 题目描述

对于实数 a > 1，定义序列 g_a(x)：

- 若 0 ≤ x < a，则 g_a(x) = 1；
- 若 x ≥ a，则 g_a(x) = g_a(x-1) + g_a(x-a)。

定义 G(n) = g_{√n}(n)，即取 a = √n 时的函数值。

给定 J，求 Σ_{j=1}^{J} G(3^j) mod 10^9+7。

## 输入格式

一个整数 J（1 ≤ J ≤ 10^6），或字符串 `PE`。

## 输出格式

一个整数，表示 Σ G(3^j) mod 10^9+7。

## 样例

### 输入
```
2
```

### 输出
```
22
```

解释：G(3) = 3，G(9) = 19，总和为 22。

## 数据范围

- 对于 30% 数据：J ≤ 5
- 对于 60% 数据：J ≤ 10
- 对于 100% 数据：J ≤ 10^6
