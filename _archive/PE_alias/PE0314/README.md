# 月球上的老鼠 (The Mouse on the Moon)

来源：改编自 Project Euler Problem 314

## 原题意

500m×500m 方形土地，每 1m 有桩。用直线段围成封闭多边形，求最大面积/周长比。PE 答案：132.527... （8 位小数）。

## 题目

输入 N（方形土地半边长），求最大面积/周长比，保留 8 位小数。

## 数据范围

$1 \\le N \\le 500$。

## 算法

### 方向一：八角形近似

在正方形四角各切去一个等腰直角三角形，边长为 t。优化 t 使面积/周长比最大。

面积 = N² - 2t²，周长 = 4N - 8t + 4√2·t。

通过扫描 t ∈ [0, N] 求最优值，进一步细化搜索精度。

### 方向二：多边形优化

使用更多顶点（16 边形、32 边形等）逼近最优解。最优解趋近于沿边界与从中心出发射线交点的连续曲线。

### 时间复杂度

扫描 O(N/ε)，N≤500 时 <0.1s。
