# 倒数循环节 II

## 题目描述

单位分数 1/n 的十进制表示中，循环节长度记为 L(n)。若分母仅含质因数 2 或 5，则视为无循环节，L(n)=0。

已知 ∑L(n) (3 ≤ n ≤ 10^6) = 55535191115。

给定 N，求 ∑L(n) (3 ≤ n ≤ N)。

---

## 输入格式

一个整数 N。

---

## 输出格式

一个整数，表示 ∑L(n) (3 ≤ n ≤ N)。

---

## 样例

### 输入
```
10
```

### 输出
```
12
```

### 输入
```
100
```

### 输出
```
288
```

### 输入
```
1000
```

### 输出
```
72046
```

---

## 数据范围

- 对于 30% 数据：N ≤ 10^4
- 对于 60% 数据：N ≤ 10^6
- 对于 100% 数据：N ≤ 10^8
