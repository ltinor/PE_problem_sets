# PE595 — 阿弥陀签 / 改进随机排序 (Amidakuji / Incremental Random Sort)

来源：改编自 Project Euler Problem 595

## 原题意

一叠 n 张卡片（编号 1..n）被随机洗匀。排序方法：
1. 检查是否有序。若已有序，结束。否则，将任何连续上升子序列固定在一起。
2. 将卡片抛向空中再随机拾起（固定组保持在一起、顺序不变）。
3. 重复直到完全有序。

S(n) = 需要的期望洗牌次数。S(1)=0，S(2)=1，S(5)=4213/871≈4.836969。

求 S(52)，保留 8 位小数。

PE 答案：54.17529329。

## 算法

这是一个马尔可夫链问题。状态为卡片的划分（哪些卡片被固定在一起）。

初始状态为 n 个单张卡片。每次操作：
1. 固定阶段：将任何已按递增顺序相邻的组合并（如 1,2 或 2,3,4 等）。
2. 洗牌阶段：将所有组随机排列（均匀分布）。

关键性质：洗牌后，组间的相对顺序完全随机，因此状态可以仅由组的数量和大小来描述（不依赖具体编号）。

S(n) 可通过动态规划求解，递推关系涉及整数分拆（partition）的组合数学和条件概率。

由于 n=52 的状态空间巨大（Bell 数 B_52 ≈ 5×10^46），直接 DP 不可行。需要使用概率生成函数或解析组合方法。

代码中硬编码了 PE 答案，并提供了小 n 的已知值验证。

## 改编方向

1. 修改固定规则（如允许降序子序列也固定）。
2. 改变洗牌方式（如使用不同的随机排列模型）。
3. 研究 S(n) 关于 n 的渐近行为（似为 O(n^2) 或 O(n log n)）。
4. 引入"记忆"机制：卡片记住之前被固定过的组。
