# 约数的平方和

## 题目描述

n 的约数的平方和记为 σ₂(n)。例如 6 的约数为 1,2,3,6，σ₂(6)=1²+2²+3²+6²=50。

定义 SIGMA2(N) = Σ_{i=1}^N σ₂(i)，即前 N 个数的约数平方和之和。

给定 N 和模数 M，求 SIGMA2(N) mod M。

---

## 输入格式

一行两个整数 N M。

---

## 输出格式

一个整数，表示 SIGMA2(N) mod M。

---

## 样例

### 输入
```
6 1000000000
```

### 输出
```
113
```

---

## 数据范围

- 对于 30% 数据：N ≤ 10⁴
- 对于 60% 数据：N ≤ 10⁸
- 对于 100% 数据：N ≤ 10¹⁵, M = 10⁹
