# PE401 - 约数的平方和

来源：改编自 Project Euler Problem 401

## 原题意

求 SIGMA2(10^15) = Σ_{i=1}^{10^15} σ₂(i)，其中 σ₂(n) 是 n 所有约数的平方和。结果模 10^9。PE 答案：281632621。

## 题目

给定 N 和模数 M，求 SIGMA2(N) mod M。

## 算法

- 核心恒等式：Σ_{i=1}^N σ₂(i) = Σ_{d=1}^N d² × ⌊N/d⌋
- 使用整除分块（harmonic lemma）：⌊N/d⌋ 只有 O(√N) 个不同值
- 两阶段处理：
  1. d = 1..√N：直接累加 d² × ⌊N/d⌋
  2. 按商 q = ⌊N/d⌋ 分组（q 从 ⌊N/(√N+1)⌋ 到 1）：
     对应 d ∈ [⌊N/(q+1)⌋+1, ⌊N/q⌋]，贡献 q × Σ d²
- 平方和公式：1²+2²+…+n² = n(n+1)(2n+1)/6
- 时间复杂度 O(√N)，空间复杂度 O(1)

## 改编方向

1. **求 σ₂(n) 本身**：直接求某个 n 的约数平方和
2. **约数的 k 次幂和**：推广到 σ_k(n) 的和函数
3. **区间查询**：支持多次查询不同 N 范围
4. **约数和 vs 约数平方和**：比较 Σσ(n) 和 Σσ₂(n) 的增长速度
5. **只考虑真约数**：排除 n 本身后求和
