# PE556 — 高斯整数 (Gaussian Integers)

来源：改编自 Project Euler Problem 556

## 原题意

高斯整数是形如 a + bi 的复数，其中 a, b 为整数。定义其范数 N(a+bi) = a² + b²。

对于一个高斯整数 z，称其为「无平方因子」的，当且仅当不存在高斯素数 π（范数大于 1）使得 π² 整除 z。

令 S(M) 表示满足 0 ≤ x, y ≤ M−1 且 x+yi 为无平方因子高斯整数的 (x, y) 对数。

求 S(10⁴)。

PE 答案：52121385。

## 题目

给定 M，求 S(M) — 在 [0, M−1] × [0, M−1] 范围内无平方因子的高斯整数个数。

## 算法

- 高斯整数环 Z[i] 是唯一分解整环。高斯素数有三类：
  1. 1+i（范数 2）
  2. 有理素数 p ≡ 3 (mod 4)（在 Z[i] 中仍是素数）
  3. a ± bi，其中 a²+b² = p 为有理素数且 p ≡ 1 (mod 4)（p 在 Z[i] 中分裂）
- 一个高斯整数无平方因子当且仅当：
  - 不被任何 p²（p ≡ 3 mod 4）整除
  - 不被任何 (a+bi)² 整除
- 使用容斥原理或 Möbius 反演统计被平方因子整除的个数。
- 对于 M = 10⁴，范数上限 ≈ 2M²，需要的高斯素数范数不超过 M√2。

## 改编方向

1. **不同范围**：计算 S(M) 对更大的 M（如 10⁵、10⁶）。
2. **部分和**：求 Σ_{M≤N} S(M) mod m。
3. **k-无平方因子**：推广到不被任何 πᵏ 整除的高斯整数。
4. **范数条件**：限制在高斯整数范数在某个范围内的无平方因子计数。
5. **对称问题**：在所有 |x|,|y| ≤ M 的全平面范围内计数。
