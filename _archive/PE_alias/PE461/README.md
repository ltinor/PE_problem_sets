# PE461 - 几乎是π (Approximating π)

来源：改编自 Project Euler Problem 461

## 原题意

设 f_n(k) = e^{k/n} - 1，对所有非负整数 k。

求非负整数 a, b, c, d，使得 |f_n(a) + f_n(b) + f_n(c) + f_n(d) - π| 最小。

定义 g(n) = a² + b² + c² + d²，其中 a, b, c, d 是使上述误差最小的参数。

已知 g(200) = 6² + 75² + 89² + 226² = 64658。

原题求 g(10000)。

## 题目

给定 n，求 g(n)。

## 算法

- 枚举所有 f_n(k) 值（k 直到 f_n(k) 超过 π）
- 使用 meet-in-the-middle：计算所有两数之和，排序后双指针寻找最接近 π 的四数之和
- 时间复杂度 O(M² log M)，其中 M ≈ n·ln(π+1)

## 改编方向

1. **不同目标值**：逼近其他常数如 e, √2
2. **不同项数**：使用 3 项或 5 项而非 4 项
3. **加权平方和**：最小化 a² + 2b² + 3c² + 4d²
