# PE402 - 整数值多项式

来源：改编自 Project Euler Problem 402

## 原题意

定义 M(a,b,c) 为最大的整数 m 使得多项式 P(n)=n⁴+an³+bn²+cn 对所有整数 n 都是 m 的倍数。
S(N) = Σ_{a=1}^N Σ_{b=1}^N Σ_{c=1}^N M(a,b,c)。
原题涉及斐波那契数的求和，PE 答案（最后 9 位）：356019862。

## 题目

给定 N，求 S(N)。（N ≤ 10000）

## 算法

- **下降阶乘基表示**：将 P(n) 写为下降阶乘 (n)_k = n(n-1)…(n-k+1) 的线性组合
  - n⁴ = (n)₄ + 6(n)₃ + 7(n)₂ + (n)₁
  - n³ = (n)₃ + 3(n)₂ + (n)₁
  - n² = (n)₂ + (n)₁
  - n = (n)₁
  - P(n) = (n)₄ + (6+a)(n)₃ + (7+3a+b)(n)₂ + (1+a+b+c)(n)₁
- **定理**：gcd_{n∈ℤ} P(n) = gcd(A₁, 2A₂, 6A₃, 24A₄)，其中 A_k 是 (n)_k 的系数
  - M(a,b,c) = gcd(1+a+b+c, 2(7+3a+b), 6(6+a), 24)
  - 令 g₀ = gcd(14+6a+2b, 36+6a, 24)，则 M = gcd(1+a+b+c, g₀)
  - 由于 g₀ | 24，g₀ ∈ {1,2,3,4,6,8,12,24}
- **高效求和**：对固定的 (a,b)，利用 gcd(t, g₀) 以 g₀ 为周期的性质，O(1) 计算 Σ_{c=1}^N gcd(1+a+b+c, g₀)
- 时间复杂度 O(N²)，空间复杂度 O(1)

## 改编方向

1. **改变多项式次数**：使用 nᵏ 代替 n⁴
2. **改变系数范围**：允许 a,b,c 取负值
3. **求最大值**：求 max M(a,b,c) 而非求和
4. **区间查询**：支持多次查询不同 N
5. **限制 a+b+c**：加上 a+b+c ≤ K 的约束
