# 最小公倍数计数

来源：改编自 Project Euler Problem 379

## 原题意

f(n) 为满足 LCM(x,y)=n 且 x≤y 的正整数对 (x,y) 数量。求 g(10^12) = Σ_{i=1}^{10^12} f(i)。PE 答案：172023848。

## 题目

给定 N，求 g(N) = Σ_{i=1}^{N} f(i)。

## 数据范围

N ≤ 10^8

## 算法

### 方向一：积性函数 + Dirichlet 卷积

f(n) 与 n 的质因数分解有关。若 n = Π p_i^{e_i}，则 f(n) = Π (2e_i+1)（有序对）/ 2 上取整。g(N) 可通过枚举 x 并计算 y 的范围。

### 方向二：交换求和顺序

g(N) = Σ_{x=1}^N Σ_{y=x}^N [LCM(x,y) ≤ N]。利用 LCM(x,y) = x·y / GCD(x,y)，枚举 g = GCD(x,y)，设 x=ga, y=gb，条件变为 gab ≤ N。

### 方向三：数论分块 + 莫比乌斯反演

用莫比乌斯函数处理互质条件。用分块优化枚举，O(N^{2/3}) 或更优。

### 时间复杂度

O(N^{2/3}) 或 O(√N)。
