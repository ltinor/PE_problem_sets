# PE691 — Long substring with many repetitions (多重复长子串)

来源：改编自 Project Euler Problem 691

## 原题意

将正整数 $1, 2, \dots, n$ 的十进制表示按顺序拼接成一个字符串 $S_n$。
定义 $A(n)$ 为 $S_n$ 的最长子串长度，使得该子串中某个数字至少出现 $7$ 次。
求 $\sum_{n=1}^{10^6} A(n)$。

PE 答案：11570761。

## 算法

1. **字符串构造**：拼接 $1$ 到 $n$ 的数，可使用 `to_string` 实现。
2. **滑动窗口**：对于每个前缀 $S_n$，维护一个滑动窗口，记录窗口内各数字的频率。
   当某个数字频率达到 $7$ 时，窗口是有效的。
3. **增量计算**：由于 $A(n)$ 随 $n$ 非严格递增，可以从之前的结果增量更新。
   对于每个新添加的数字字符，扫描以该字符结尾的所有后缀，找出最长有效后缀。
4. **复杂度**：对于 $n \le 10^6$，总字符数约 $7 \times 10^6$。
   使用暴力 $O(N \cdot L)$ 对每个前缀扫描最大后缀，总体可通过小规模数据。
