# PE907 — Stacking Cups（叠杯子）

来源：改编自 Project Euler Problem 907

## 原题意

$n$ 个大小递增的杯子可以通过嵌套、底对底、顶对顶方式堆叠。每个杯子可以正放或倒放。求将所有杯子堆成单一塔的方案数。

已知：$S(4)=12$，$S(8)=58$，$S(20)=5560$。求 $S(10^7) \bmod 10^9+7$。

PE 答案：31875000

## 算法

1. **状态表示**：
   - 每个杯子有正放/倒放两种朝向
   - 塔是杯子的排列，相邻杯子需满足堆叠规则

2. **位掩码DP（小规模）**：
   - $\text{dp}[\text{mask}][\text{last}][\text{orient}]$ 计数
   - 时间复杂度 $O(2^n \cdot n^2)$，适用于 $n \leq 10$

3. **递推关系（大规模）**：
   - 问题具有线性递推结构
   - 利用生成函数或矩阵快速幂求解
   - 杯子按奇偶性分为两组，每组内部有独立的堆叠规则

4. **模运算**：
   - 最终答案对 $10^9+7$ 取模

## 改编方向

1. 研究不同堆叠规则下的方案数
2. 考虑多维堆叠（金字塔结构）
3. 带颜色/标签的杯子变体
4. 限制塔高的堆叠计数
