# 圣彼得堡彩票

## 题目描述

圣彼得堡游戏规则：反复抛一枚公平硬币，直到第一次出现正面。若在第 $k$ 次抛掷时首次出现正面（即前 $k-1$ 次都是反面），则获得 $2^k$ 元奖金。

一个赌徒初始有 $S$ 元。他每次支付 $C$ 元玩一次游戏（$C < S$）。如果某次游戏后资金达到或超过 $T$ 元，则他获胜并停止。如果资金不足 $C$ 元无法继续游戏，则他破产。

求赌徒最终获胜（在破产前达到目标）的概率。

## 输入格式

三个整数 $S$、$C$、$T$，或字符串 `PE`。

## 输出格式

一个浮点数，保留 8 位小数，表示获胜概率。

## 样例

### 输入
```
3 1 10
```

### 输出
```
0.62500000
```

## 数据范围

- 对于 30% 数据：$T \le 20$
- 对于 60% 数据：$T \le 100$
- 对于 100% 数据：$T \le 500$
