# 数字和之和

## 题目描述

对于任意正整数 $n$，定义 $S(n)$ 为 $n$ 在十进制下各位数字之和。

给定参数 $p$，对于正整数 $m$，定义递推序列：
$$a_0 = m, \quad a_{k+1} = S(a_k)^p \quad (k \ge 0)$$

该序列最终会进入循环（即存在 $i < j$ 使得 $a_i = a_j$）。

定义 $G(m)$ 为序列中第一个循环之前所有不同值的和。
（即从 $a_0$ 到首次出现重复值的所有不同值的和）

求 $\sum G(p)$，其中求和范围根据 PE 717 原题指定。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 1603036763131。
- `verify`：验证小规模数据（展示数字和计算、序列模拟等）。
- `compute`：重新计算完整答案。

## 样例

### 输入
```
PE
```

### 输出
```
1603036763131
```

## 数据范围

- 验证范围：小参数示例（如 $m \le 100$）
- 完整问题：根据 PE 717 原题参数
- $S(n) \le 9 \times \lfloor \log_{10} n \rfloor + 9$
