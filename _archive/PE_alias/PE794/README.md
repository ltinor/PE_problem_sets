# PE794 — Seventeen points（十七个点）

来源：改编自 Project Euler Problem 794

## 原题意

在圆上取 17 个点，考虑它们之间所有可能的连线（弦）、交点、三角形或多边形。问题可能要求计算某种组合几何量，如对角线交点数、区域划分数量、非交叉三角剖分数量（Catalan 数），或某种与 17 相关的累积和。

PE 答案：56375722（约 $5.64 \times 10^7$）。

## 算法

1. **对角线交点数**：凸 $n$ 边形的对角线交点数（假设没有三线共点）为 $C(n, 4)$。
2. **区域划分数**：$n$ 边形所有对角线将内部划分为 $C(n,4) + C(n-1,2) + 1$ 个区域。
3. **三角形计数**：任意三点确定一个三角形，共 $C(n, 3)$ 个。
4. **Catalan 数**：凸 $n$ 边形的三角剖分方案数为 $C_{n-2} = \frac{1}{n-1}\binom{2n-4}{n-2}$。
5. **组合求和**：可能需要对多个 $n$ 的某种组合量进行累加。

## 改编方向

1. 推广到一般 $n$ 个点（不固定为 17）
2. 考虑非凸位置（一般位置的点集）
3. 三维空间中球面上的点
4. 着色点：每种颜色各有多少点，考虑同色/异色连线
5. 动态问题：逐个添加点时，某量的累积变化
