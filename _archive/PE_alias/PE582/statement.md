# 几乎等腰120度三角形

## 题目描述

记有一个角为 120 度的整数边长三角形的三边长为 a, b, c，满足 a ≤ b ≤ c 且 b-a ≤ 100。

记 T(n) 为满足 c ≤ n 的上述三角形的数目。

已知：T(1000) = 235，T(10⁸) = 1245。

给定 n，求 T(n)。

## 输入格式

一行，一个整数 n（或字符串 `PE`，或 `test`）。

## 输出格式

一个整数，表示 T(n)。

若输入为 `PE`，输出 PE 原题的答案：T(10¹⁰⁰)。
若输入为 `test`，输出已知测试值。

## 样例

### 输入
```
1000
```

### 输出
```
235
```

### 输入
```
PE
```

### 输出
```
199029329684864
```

## 数据范围

- 对于 30% 数据：n ≤ 10⁴
- 对于 60% 数据：n ≤ 10⁶
- 对于 100% 数据：n ≤ 10¹⁰⁰ 或输入为 PE
