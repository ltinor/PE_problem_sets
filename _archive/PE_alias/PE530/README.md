# PE530 - 约数的最大公约数

来源：改编自 Project Euler Problem 530

## 原题意

数 n 的每个约数 d 都有一个互补约数 n/d。
记 f(n) = Σ_{d|n} gcd(d, n/d)，即所有约数与其互补约数的最大公约数之和。
记 F(k) = Σ_{n=1}^k f(n)。

已知：F(10) = 32，F(1000) = 12776。
求 F(10¹⁵)。

PE 答案：258416372748。

## 题目

给定 k，计算 F(k)。

## 算法

- 利用数论恒等式：f(n) = Σ_{g²|n} g × 2^{ω(n/g²)}，其中 ω(m) 为 m 的不同质因子数。
- F(N) = Σ_{g=1}^{⌊√N⌋} g × S(⌊N/g²⌋)，其中 S(x) = Σ_{m=1}^x 2^{ω(m)}。
- S(x) = Σ_{d=1}^x |μ(d)| × ⌊x/d⌋，通过莫比乌斯函数计算。
- 小范围 x 通过线性筛预计算 S(x)，大范围通过无平方因子数计数函数 Q(y) 分段计算。
- Q(y) = Σ_{k=1}^{√y} μ(k) × ⌊y/k²⌋，可在 O(√y) 时间内计算。

## 改编方向

1. **最大公约数改为最小公倍数**：f(n) = Σ_{d|n} lcm(d, n/d)。
2. **加权和**：为不同大小的约数赋予权重。
3. **限制约数范围**：仅考虑 [a, b] 范围内的约数。
4. **GCD 的幂**：f(n) = Σ_{d|n} (gcd(d, n/d))²。
