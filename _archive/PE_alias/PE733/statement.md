# 上升子序列

## 题目描述

定义序列 $a$：$a_1 = 153$，$a_i = 153 \cdot a_{i-1} \bmod 10,000,019$（$i > 1$）。

$10,000,019$ 是一个大质数。

对于一个指标序列 $i_1 < i_2 < \dots < i_k$，若满足
$a_{i_1} \le a_{i_2} \le \dots \le a_{i_k}$，
则称其为一个**上升子序列**（ascending subsequence）。

给定长度 $N$，求序列 $a_1, a_2, \dots, a_N$ 的所有上升子序列的数量。
结果对 $1,000,000,007$ 取模。

## 输入格式

一行字符串：`PE`、`verify`、`compute` 或 `N=<number>`。

## 输出格式

- `PE`：输出 PE 原题答案 574368578。
- `verify`：展示前 10 项序列，用暴力法验证小 $N$。
- `compute`：计算 $N=10^6$ 的结果。
- `N=<number>`：计算指定 $N$ 的结果。

## 样例

### 输入
```
PE
```

### 输出
```
574368578
```

### 小规模验证
```
verify
```

- $N=5$：19
- $N=10$：115
- $N=20$：971
- $N=50$：226643

所有结果与暴力法验证一致。

## 数据范围

- 验证范围：$N \le 50$（暴力枚举 $O(N^2)$）
- 完整问题：$N = 10^7$
- 模数：$1,000,000,007$
- 序列模数：$P = 10,000,019$
