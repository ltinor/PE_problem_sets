# PE733 — Ascending subsequences (上升子序列)

来源：改编自 Project Euler Problem 733

## 原题意

给定一个由递推公式生成的序列 $a_1, a_2, \dots, a_N$：
$$a_i = 153^i \bmod 10,000,019$$

其中 $10,000,019$ 是大质数。

定义序列的**上升子序列**（ascending subsequence）为
指标序列 $i_1 < i_2 < \dots < i_k$ 满足 $a_{i_1} \le a_{i_2} \le \dots \le a_{i_k}$。

求所有上升子序列的数量（模 $1,000,000,007$）。

PE 答案：574368578。

## 算法

1. **序列生成**：利用快速幂递推 $a_i = 153 \cdot a_{i-1} \bmod P$。

2. **坐标压缩**：$a_i$ 取值范围为 $[0, P-1]$，但实际出现的值只有 $N$ 个。
   将值离散化到 $[1, N]$ 以便使用树状数组。

3. **Fenwick 树（BIT）优化 DP**：
   - 令 $dp[i]$ 为以位置 $i$ 结尾的上升子序列数量
   - $dp[i] = 1 + \sum_{j < i, a_j \le a_i} dp[j]$
   - 使用 BIT 维护前缀和，支持 $O(\log N)$ 的单点更新和前缀查询
   - 按顺序处理元素，查询 $\le a_i$ 的所有 $dp[j]$ 之和

4. **模运算**：所有操作对 $1,000,000,007$ 取模。

5. **复杂度**：$O(N \log N)$，其中 $N = 10^7$。

## 改编方向

1. 参数化 $N$ 和模数 $P$
2. 使用不同的递推公式生成序列
3. 改为严格上升子序列（$a_{i_1} < a_{i_2} < \dots$）
4. 求最长上升子序列（LIS）
5. 改为下降子序列的计数
