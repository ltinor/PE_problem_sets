# 能被两个素数整除的最大整数

## 题目描述

对于两个**不同**的素数 p 和 q，记 M(p,q,N) 为在不超过 N 的正整数中，能整除该数的素数恰好只有 p 和 q 的最大整数。如果不存在这样的正整数，则 M(p,q,N) = 0。

例如：
- M(2, 3, 100) = 96，因为 96 = 2^5 × 3，且其质因数只有 2 和 3。
- M(3, 5, 100) = 75，不是 90（因为 90 含有质因数 2）。
- M(2, 73, 100) = 0，因为不存在 ≤ 100 且质因数只有 2 和 73 的数。

记 S(N) 为所有不同的 M(p,q,N) 之和（对所有不同素数对 p < q）。已知 S(100) = 2262。

给定 N，求 S(N)。

---

## 输入格式

一个整数 N。

---

## 输出格式

一个整数，表示 S(N)。

---

## 样例

### 输入
```
100
```

### 输出
```
2262
```

---

## 数据范围

- 对于 30% 数据：N ≤ 10^4
- 对于 60% 数据：N ≤ 10^6
- 对于 100% 数据：N ≤ 10^7
