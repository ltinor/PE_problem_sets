# 抛物线下格点

## 题目描述

对于整数 a 和 b，定义区域 D(a,b) 为抛物线 y=x² 和直线 y=ax+b 之间的区域。

定义 L(a,b) 为 D(a,b) 内格点（整点）的个数。例如 L(1,2)=8, L(2,-1)=1。

定义 S(N) 为所有满足 |a|,|b| ≤ N 且 D(a,b) 面积为有理数的 (a,b) 对应的 L(a,b) 之和。

给定 N，求 S(N) mod 10⁸。

---

## 输入格式

一个整数 N。

---

## 输出格式

一个整数，表示 S(N) mod 10⁸。

---

## 样例

### 输入
```
5
```

### 输出
```
344
```

---

## 数据范围

- 对于 20% 数据：N ≤ 5
- 对于 50% 数据：N ≤ 30
- 对于 100% 数据：N ≤ 100
