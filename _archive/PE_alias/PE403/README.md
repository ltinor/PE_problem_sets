# PE403 - 抛物线下格点

来源：改编自 Project Euler Problem 403

## 原题意

对于整数 a,b，定义 D(a,b) = {(x,y) | x² ≤ y ≤ ax+b}。L(a,b) = D(a,b) 内格点数量。
S(N) = Σ_{|a|,|b|≤N, D(a,b)面积是有理数} L(a,b) mod 10⁸。
原题 N=10^12，PE 答案：18224771。

## 题目

给定 N，求 S(N) mod 10⁸。（N ≤ 100）

## 算法

- 有理面积判定：D(a,b) 的面积为有理数 ⇔ 判别式 a²+4b 是完全平方数
  - 这是因为抛物线与直线的交点 x = (a ± √(a²+4b))/2 必须有理数
- 对于每个满足条件的 (a,b)，计算交点范围并枚举整点
- 对每个满足 |a|,|b| ≤ N 且 a²+4b 为平方数的 (a,b)：
  1. 设 k = √(a²+4b)
  2. x 范围：[⌈(a-k)/2⌉, ⌊(a+k)/2⌋]
  3. 对每个整数 x，y 范围：[x², ax+b]
  4. 累加 y 范围内的整数个数
- 时间复杂度 O(N² · √N)（N=100 时约 10⁴ × 200 = 2×10⁶）

## 改编方向

1. **使用不同的曲线**：双曲线、椭圆等代替抛物线
2. **三维推广**：抛物面下的格点计数
3. **改变格点定义**：使用三角形格点或六边形格点
4. **区间边界条件**：改为严格不等号
5. **使用不同的判定条件**：面积有理→面积整数
