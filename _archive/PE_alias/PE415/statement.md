# 泰坦尼克集

## 题目描述

格点集 S 被称为泰坦尼克集，如果存在一条直线恰好只穿过 S 中的两个点。

例如 S = {(0, 0), (0, 1), (0, 2), (1, 1), (2, 0), (1, 0)} 是泰坦尼克集，因为存在直线穿过 (0, 1) 和 (2, 0) 而不穿过 S 中其它点。

{ (0, 0), (1, 1), (2, 2), (4, 4) } 不是泰坦尼克集，因为穿过任意两点的直线也穿过其它点。

记 T(N) 为所有点的坐标 (x, y) 满足 0 ≤ x, y ≤ N 的泰坦尼克集的数目。

已知 T(1) = 11, T(2) = 494。

给定 N，求 T(N) mod 10^8。

---

## 输入格式

一个整数 N。

---

## 输出格式

一个整数，表示 T(N) mod 10^8。

---

## 样例

### 输入
```
1
```

### 输出
```
11
```

### 输入
```
2
```

### 输出
```
494
```

---

## 数据范围

- 对于 30% 数据：N ≤ 1
- 对于 60% 数据：N ≤ 2
- 对于 100% 数据：N ≤ 3
