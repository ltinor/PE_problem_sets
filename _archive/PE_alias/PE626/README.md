# PE626 — 01矩阵计数 (Counting Binary Matrices)

来源：改编自 Project Euler Problem 626

## 原题意

对于 n×n 的 01 矩阵，可以进行以下变形：
- 交换任意两行
- 交换任意两列
- 翻转一行中所有元素（1↔0）
- 翻转一列中所有元素

若矩阵 A 可通过一系列上述变形变为 B，则称 A 与 B 等价。

记 c(n) 为 n×n 01 矩阵中两两互不等价的最大数目。

已知 c(3)=3，c(5)=39，c(8)=656108。

求 c(20) mod 1,001,001,011。

PE 答案：6955777866634773。

## 算法

使用 Burnside 引理。群 G = (S_n × S_n) ⋊ (C_2^n × C_2^n)，|G| = n!² × 2^{2n}。

### 群作用分析

对群元素 (σ, τ, a, b)（σ 为行置换，τ 为列置换，a 为行翻转向量，b 为列翻转向量），矩阵 M 被映射为：
M'[i,j] = M[σ⁻¹(i), τ⁻¹(j)] ⊕ a_i ⊕ b_j

### Burnside 公式

c(n) = Σ_{λ,μ} w(λ) w(μ) 2^{O(λ,μ) - p - q + free(λ,μ)}

其中：
- λ, μ 分别为行和列置换的循环结构（n 的划分）
- w(λ) = 1/Π_i(i^{m_i} × m_i!) 为归一化权重
- p, q 分别为 λ, μ 的循环数
- O(λ,μ) = Σ_{i,j} gcd(|R_i|, |C_j|) 为网格上的轨道数
- free(λ,μ) 为满足一致性条件的翻转奇偶性赋值自由度数

### 一致性条件

对循环 R_i（大小 r_i, 2-进赋值 a_i）和 C_j（大小 c_j, 2-进赋值 b_j）：

- 若 a_i > b_j：行奇偶性 A_i = 0（强制）
- 若 a_i < b_j：列奇偶性 B_j = 0（强制）
- 若 a_i = b_j：A_i = B_j

按 2-进赋值逐层处理，统计自由变量数。

### 计算复杂度

n=20 时有 p(20)=627 个划分，627²≈393,129 对，可在数秒内完成。
