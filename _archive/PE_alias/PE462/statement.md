# 3-光滑数重排

## 题目描述

3-光滑数是指质因子只包含 2 和 3 的整数。定义 S(N) 为所有不超过 N 的 3-光滑数所构成的集合。

对 S(N) 的元素进行排列使得每个元素都排在其所有真因数之后，记这样的排列数为 F(N)。

例如：
- F(6) = 5
- F(8) = 9
- F(20) = 450
- F(1000) ≈ 8.8521816557e21

求 F(N)。

---

## 输入格式

一个整数 N (2 ≤ N ≤ 10^18)。

---

## 输出格式

用保留 10 位小数的科学计数法表示 F(N)，用小写字母 e 分隔尾数和指数。

---

## 样例

### 输入
```
20
```

### 输出
```
4.5000000000e2
```

---

## 数据范围

- 对于 30% 数据：N ≤ 100
- 对于 60% 数据：N ≤ 10^6
- 对于 100% 数据：N ≤ 10^18
