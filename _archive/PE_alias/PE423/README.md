# PE423 - 连续扔骰子

来源：改编自 Project Euler Problem 423

## 原题意

掷 n 次六面骰子，c 为连续相同点数对的个数。C(n) 统计 c ≤ π(n) 的结果数。原题求 S(5×10⁷) mod 1e9+7，答案为 653972374。

## 题目

给定 L，求 S(L) = ∑_{n=1}^{L} C(n) mod 1e9+7。

## 算法

- 定义 f(n, k) = n 次投掷中恰好有 k 对连续相同的结果数
- DP 递推：f(n, k) = 5·f(n-1, k) + f(n-1, k-1)，f(1,0) = 6
- 显式公式：f(n,k) = 6·C(n-1, k)·5^{n-1-k}
- C(n) = 6·∑_{k≤π(n)} C(n-1,k)·5^{n-1-k}
- 通过预计算组合数与幂次求解，大范围使用前缀和优化

## 改编方向

1. **多面骰子**：改为 k 面骰子
2. **马氏链约束**：限制连续相同对在某个区间
3. **加权和**：不同面有不同的权重
