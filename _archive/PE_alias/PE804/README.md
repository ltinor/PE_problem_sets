# PE804 — Count Binary Quadratic Representations（二元二次型表示计数）

来源：改编自 Project Euler Problem 804

## 原题意

统计在某个范围内，正整数能被二元二次型 f(x,y) = ax² + bxy + cy² 表示的方式数或能表示的整数个数。可能的二次型包括：

- x² + y²（二平方和）
- x² + Dy²（特定 D 的二次型）
- Dx² + y⁴（混合幂次）
- 16x² + y⁴（已知 PE 变体）

PE 答案：721014409585053。

## 算法

1. **直接枚举**：x 遍历 0 到 sqrt(N/a)，对于每个 x 求解 y 为整数。
2. **数论方法**：
   - 利用二次型的判别式和类数理论
   - 通过素数分解判断可表示性
   - 除数函数在二次域中的推广
3. **筛法优化**：对于统计可表示数的个数，使用布尔数组标记。
4. **对称性利用**：考虑 (x,y)、(-x,y)、(x,-y)、(-x,-y) 的符号组合。

## 改编方向

1. 改变二次型的系数 a, b, c
2. 使用更高次的多项式（如 x² + y³）
3. 添加线性项变为一般二次型
4. 统计表示数为平方数的情形
5. 限制 x, y 的取值范围（如 x, y 为素数）
