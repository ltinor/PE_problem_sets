# 格点四边形

## 题目描述

简单四边形是指具有四个不同顶点、任意三点不共线且不自交的多边形。

记 Q(m,n) 为所有顶点均为格点（坐标满足 0 ≤ x ≤ m 且 0 ≤ y ≤ n）的简单四边形的数目。

例如：Q(2,2) = 94。

可以验证 Q(3,7) = 39590，Q(12,3) = 309000。

给定 m 和 n，求 Q(m,n) mod 135707531。

---

## 输入格式

两个整数 m, n (1 ≤ m, n ≤ 12345)。

---

## 输出格式

一个整数，表示 Q(m,n) mod 135707531。

---

## 样例

### 输入
```
2 2
```

### 输出
```
94
```

---

## 数据范围

- 对于 30% 数据：m, n ≤ 4
- 对于 60% 数据：m, n ≤ 10
- 对于 100% 数据：m, n ≤ 12345
