# PE453 - 格点四边形 (Lattice Quadrilaterals)

来源：改编自 Project Euler Problem 453

## 原题意

简单四边形：四个不同顶点、任意三点不共线、不自交的多边形。

Q(m,n) = 顶点为格点（坐标满足 0 ≤ x ≤ m, 0 ≤ y ≤ n）的简单四边形的数目。

验证：Q(2,2)=94, Q(3,7)=39590, Q(12,3)=309000, Q(123,45)=70542215894646。

原题求 Q(12345, 6789) mod 135707531 = 104354107。

## 题目

给定 m, n，求 Q(m,n) mod 135707531。

## 算法

- 总四元组：C(P,4) 其中 P = (m+1)(n+1)
- 减去：四点共线、凹四边形
- 凸四边形通过叉积符号判断
- 对于大网格，使用 Pick 定理和组合计数

## 改编方向

1. **简单多边形**：推广到 k 边形
2. **正交四边形**：要求边与坐标轴平行
3. **面积约束**：限制四边形的面积范围
