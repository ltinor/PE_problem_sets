# PE451 - 模逆元和 (Modular inverses)

来源：改编自 Project Euler Problem 451

## 原题意

对于整数 n，考虑所有与 n 互质的正整数 m < n。若 m 的模逆元等于自身（即 m² ≡ 1 (mod n)），记 I(n) 为所有满足 m < n-1 中最大的 m。

例如：I(15)=11，I(100)=51，I(7)=1。

原题求 Σ_{n=3}^{2·10^7} I(n) = 153651073760956。

## 题目

给定 n，求 I(n)；或给定 N，求 Σ_{n=3}^N I(n)。

## 算法

- m² ≡ 1 (mod n) 的解通过中国剩余定理求得
- 对 n 的每个质因子幂，m ≡ ±1；共 2^k 个解
- I(n) = 最大解 < n-1（n-1 本身被排除）
- 若仅有平凡解（1 和 n-1），则 I(n) = 1
- 时间复杂度：单次 O(√n)，批量可用筛法

## 改编方向

1. **区间求和**：求 Σ_{a≤n≤b} I(n)
2. **模逆对**：统计满足 m² ≡ 1 (mod n) 的 m 的总数
3. **最小非平凡解**：求最小的 m > 1 满足 m² ≡ 1 (mod n)
