# 钟摆序列

## 题目描述

考虑下面这个无限重复的数字序列：

1234321234321234321...

神奇的是，你可以将这个序列分解成一个整数的序列，使得第 n 个整数的各位数字之和恰好是 n。

这个整数序列的前几项为：1, 2, 3, 4, 32, 123, 43, 2123, 432, 1234, 32123, ...

记 v_n 为第 n 个整数。已知 S(11) = v_1 + v_2 + ... + v_11 = 36120，
S(1000) mod 123454321 = 18232686。

给定 N，求 S(N) mod 123454321。

## 输入格式

一个整数 N（1 ≤ N ≤ 10^14），或字符串 `PE`。

## 输出格式

一个整数，表示 S(N) mod 123454321。

## 样例

### 输入
```
11
```

### 输出
```
36120
```

## 数据范围

- 对于 30% 数据：N ≤ 20
- 对于 60% 数据：N ≤ 1000
- 对于 100% 数据：N ≤ 10^14
