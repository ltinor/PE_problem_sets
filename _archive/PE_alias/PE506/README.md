# PE506 - 钟摆序列

来源：改编自 Project Euler Problem 506

## 原题意

考虑无限重复的数字序列 1234321234321234321...
将其分解为整数序列 v_n，使得第 n 个整数的各位数字之和恰好为 n。
求 S(10^14) mod 123454321。

PE 答案：18934502。

## 题目

给定 N，求 v_1 + v_2 + ... + v_N，结果对 123454321 取模。

## 算法

- 贪心模拟：从序列位置 0 开始，对于每个 n，不断取数字直到和 ≥ n
- 数字序列周期为 6（"123432"），每 6 个数字和为 15
- 对于 N ≤ 10^6，直接模拟即可
- 对于大 N，数字分组存在周期性规律，可通过周期检测加速

## 改编方向

1. **不同模数**：改变取模值
2. **不同数字序列**：使用不同的重复模式
3. **限制 N 范围**：对于 OJ 环境，N ≤ 10^5
4. **在线查询**：多个查询，每个给定不同的 N
