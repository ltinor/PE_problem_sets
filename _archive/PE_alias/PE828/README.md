# PE828 — Numbers Challenge（数字挑战）

来源：改编自 Project Euler Problem 828

## 原题意

类似于电视节目"Countdown"中的数字游戏：给定一组数字，使用 $+,-,\times,\div$（整除）和括号，每个数字恰好用一次，求能构造出的所有不同整数值的总和（或其他统计量）。

对于数字 $1$ 到 $N$，这是一个组合爆炸问题：可能的表达式数量随 $N$ 急剧增长。已知数列 OEIS A071115 记录了使用 $\{1,\ldots,N\}$ 可构造的不同值的数量。

PE 答案：764545780025915（极大值，表明 $N$ 或范围很大）。

## 算法

1. **子集 DP**：对所有子集计算可达到的值集合。$\text{dp}[\text{mask}]$ 表示使用 mask 中的数字能构造出的值。
2. **操作合并**：对子集的两部分，枚举所有可能的 $+,-,\times,\div$ 操作合并结果。
3. **记忆化**：利用已有结果避免重复计算。
4. **大数处理**：涉及极大的值，需要高精度或 __int128。

## 改编方向

1. 允许数字拼接（如 $1,2 \to 12$）
2. 增加更多运算（幂运算、阶乘等）
3. 考察特定目标值的可构造性
4. 限制运算符使用次数或类型
5. 考虑不同的初始数字集合
