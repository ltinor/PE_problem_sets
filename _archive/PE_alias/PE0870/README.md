# PE870 — Unbreaking（不打破）

来源：改编自 Project Euler Problem 870

## 原题意

"Unbreaking" 可能指：
- 数字的"不可拆分"性质：某些数字不能被拆分成两个有效部分。
- 字符串/序列的"不可打破"性：无法通过某种操作将其拆解。
- 与"破棍子问题"（broken stick）相关的概率计算。

本题可能要求统计在某个范围内"不可拆分"的数字的个数或总和，或计算在不打破某约束条件下的方案数。

## 算法

1. **连接拆分检测**：检查一个数字的所有可能拆分位置，判断是否存在有效拆分。
2. **等和拆分**：检查数字是否能拆分为数字和相等的两部分。
3. **错排计数**：另一种"不打破"的解释——没有不动点的排列。
4. **组合计数**：使用 DP 统计不可拆分的数字数量。

## 改编方向

1. 推广到多段拆分
2. 带约束的拆分（如素数乘积）
3. 不可拆分数字的渐近密度
4. 与 de Bruijn 序列的关系
