# 生日问题重温

## 题目描述

居民一个接一个地走进一间非常大的房间，每个人的生日在一年 D 天中等概率且独立分布。

求第一次出现有 K 个人的生日两两相差不超过 W 天时，房间中人数的期望值。答案保留 8 位小数。

已知测试案例：
- WimWi 星球（D=10, K=3, W=1）：5.78688636
- Joka 星球（D=100, K=3, W=7）：8.48967364

给定 D、K、W，求对应的期望人数。地球的参数为 D=365, K=4, W=7。

## 输入格式

一行，可以包含：
- 三个整数 D K W，表示星球参数
- 字符串 `PE`：输出地球的答案
- 字符串 `WimWi` 或 `Joka`：输出对应星球的已知答案
- 字符串 `test`：等价于 `WimWi`

## 输出格式

一个小数，保留 8 位小数。

## 样例

### 输入
```
PE
```

### 输出
```
32.83822408
```

### 输入
```
WimWi
```

### 输出
```
5.78688636
```

### 输入
```
Joka
```

### 输出
```
8.48967364
```

## 数据范围

- 对于小规模测试：D ≤ 100, K ≤ 5, W ≤ 10
- 对于 100% 数据：任意输入的 D, K, W，或直接输入 PE
