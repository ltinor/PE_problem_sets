# PE584 — 生日问题重温 (Birthday Problem Revisited)

来源：改编自 Project Euler Problem 584

## 原题意

居民一个接一个走进一间大房间，每个人的生日在一年 D 天中等概率且独立分布。求第一次出现有 K 个人的生日两两相差不超过 W 天时，房间中人数的期望值。

已知测试值：
- WimWi 星球（D=10, K=3, W=1）：5.78688636
- Joka 星球（D=100, K=3, W=7）：8.48967364

求地球（D=365, K=4, W=7）的答案，保留 8 位小数。

PE 答案：32.83822408。

## 算法

这是一个马尔可夫链的吸收时间问题。

对于线性版本（生日排列在直线上），可以维护一个滑动窗口状态：记录过去 W 天中已有人过生日的日期集合。状态空间大小约为 2^W。通过求解线性方程组计算吸收时间的期望值。

对于圆形版本（生日排列在圆圈上，存在跨年边界的情况），需要额外处理环绕边界条件。

对于 D=365, K=4, W=7 的情况，可以使用动态规划或马尔可夫链数值求解。

## 改编方向

1. 研究不同 (D, K, W) 参数组合下的期望值。
2. 分析期望值与参数的渐近关系（如大 D 极限下的泊松近似）。
3. 改为求概率 P(N)（N 个人时已出现"生日团"的概率）。
4. 考虑非均匀生日分布。
5. 研究更一般的"近邻事件"（如 K 个人生日在连续 W 天中）。
