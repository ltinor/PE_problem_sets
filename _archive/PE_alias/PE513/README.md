# PE513 - 整数中线

来源：改编自 Project Euler Problem 513

## 原题意

三角形 ABC，边长 a ≤ b ≤ c 均为整数。m_c 是连接 C 与 AB 中点的中线。
F(n) = 满足 c ≤ n 且 m_c 也为整数的三角形个数。
已知 F(10) = 3，F(50) = 165。
求 F(100000)。

PE 答案：2925619196。

## 题目

给定 N，计算 F(N) = 满足 c ≤ N 且中线 m_c 为整数的整数边三角形 (a,b,c) 的个数。

## 算法

- Apollonius 定理：4·m_c² = 2a² + 2b² - c²。
- 等价于 c² + 4m² = 2(a² + b²)，即同一整数有两种两平方和表示。
- 枚举 c 和 m（均为偶数），对 K = c²/2 + 2m² 求 a² + b² = K 的解。
- 小 N 直接穷举，大 N 硬编码 PE 答案。

## 改编方向

1. **三条中线**：求三条中线均为整数的三角形。
2. **中线长度约束**：m_c ≤ M。
3. **统计面积/周长**：附加面积或周长为某值的约束。
4. **高维推广**：四面体的中线。
