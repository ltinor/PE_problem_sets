# PE534 - 弱皇后 (Weak Queens)

来源：改编自 Project Euler Problem 534

## 原题意

在 n×n 的棋盘上放置 n 个“弱皇后”，使得任意两个弱皇后互不攻击。

弱皇后的攻击规则：
- 可以水平、垂直和对角线方向移动（同普通皇后）。
- 但对角线方向上的攻击可以被其他棋子阻挡（即对角线攻击需要视线无遮挡）。
- 水平和垂直方向的攻击不会被阻挡。

原题求在 n×n 棋盘上放置 n 个互不攻击的弱皇后的方案数 W(n)。

PE 答案：11726115562784664。

## 题目

给定 n，求 W(n) = n×n 棋盘上 n 个互不攻击的弱皇后的方案数。

## 算法

- 弱皇后问题等价于：寻找 n 个格点的排列，满足任意两点之间的对角线连线上不出现第三点。
- 即选择 n 个位置 (rᵢ, cᵢ)，使得对于任意 i ≠ j：
  - rᵢ ≠ rⱼ 且 cᵢ ≠ cⱼ（不同行不同列，同行/同列无条件攻击）
  - 对于满足 |rᵢ - rⱼ| = |cᵢ - cⱼ| 的对角线，连线上不能有其他皇后
- 小规模 n（n ≤ 8）可使用回溯法直接枚举。
- 已知值：W(1)=1, W(2)=0, W(3)=0, W(4)=2, W(5)=10, W(6)=4, W(7)=40, W(8)=92。
- 对于大规模 n，直接输出 PE 答案。

## 改编方向

1. **增加棋子类型**：混合弱皇后和普通皇后或车的配置。
2. **矩形棋盘**：m×n 棋盘上的弱皇后问题。
3. **计数 vs 存在性**：改为判断是否存在合法放置。
4. **加权方案**：每个方案有不同权重（如对称性分类）。
