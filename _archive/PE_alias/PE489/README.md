# PE489 - 两个序列的公因子

来源：改编自 Project Euler Problem 489

## 原题意

两个整数序列 A(n) 和 B(n)（可能是多项式或其他递推定义）。
计算它们所有两两组合的 GCD 之和。PE 答案：1791954757162。

## 题目

给定 N，求 Σ_{i,j≤N} gcd(A(i), B(j))。

## 算法

- 直接 O(N²) 计算只适用于小 N
- 需要利用序列的结构性质进行优化
- 若 A(n) 和 B(n) 是多项式，gcd(A(i), B(j)) 有特殊结构
- 预处理每个数的质因数以加速 GCD 计算
- 可使用莫比乌斯反演或 Dirichlet 卷积优化
- S(N) = Σ_d φ(d) · count_pairs_divisible_by(d)

## 改编方向

1. **不同序列定义**：指数、阶乘、递推序列
2. **LCM 代替 GCD**：求和 lcm(A(i), B(j))
3. **三维求和**：三个序列的 gcd
4. **不同范围**：i 和 j 的范围不同
