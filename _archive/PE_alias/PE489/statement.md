# 两个序列的公因子

## 题目描述

定义两个整数序列 $A(n)$ 和 $B(n)$（例如 $A(n) = n^3 + n$，$B(n) = n^2 + 1$）。

求：

$$S(N) = \sum_{i=1}^N \sum_{j=1}^N \gcd(A(i), B(j))$$

---

## 输入格式

一个整数 $N$。

---

## 输出格式

一个整数，表示 $S(N)$。

---

## 样例

### 输入
```
3
```

### 输出
```
...
```

---

## 数据范围

- 对于 30% 数据：$N \le 10$
- 对于 60% 数据：$N \le 100$
- 对于 100% 数据：$N \le 10^5$
