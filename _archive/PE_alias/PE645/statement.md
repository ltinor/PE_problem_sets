# 素数日

## 题目描述

在某个历法系统中，每一天都有一个编号。定义"素数日"（Prime Day）为满足以下条件的日子：

- 该日的编号 n 的二进制表示中，1 的个数（即 popcount 或汉明重量）是一个素数。

例如，n = 7（二进制 111）的 popcount 为 3，而 3 是素数，所以第 7 天是一个素数日。

定义 J(N) 为不大于 N 的正整数中素数日的个数。

求 J(10⁹)。

## 输入格式

一行，字符串 `PE` 或 `verify` 或 `compute`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案。

若输入为 `verify`，输出 N=100 时的素数日列表和计数。

若输入为 `compute`，计算 J(10⁶)。

## 样例

### 输入
```
PE
```

### 输出
```
488895204
```

## 数据范围

- 完整问题：N = 10⁹
- 需要利用组合数学高效计算
