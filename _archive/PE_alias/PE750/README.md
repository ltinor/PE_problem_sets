# PE750 — Optimal Card Stacking（最优堆牌）

来源：改编自 Project Euler Problem 750

## 原题意

有一叠 $N$ 张牌，编号为 $1$ 到 $N$。牌的初始顺序可以任意排列。

我们需要按编号顺序（1, 2, ..., N）依次取出每张牌。取牌时，必须从顶部开始逐张移除，直到找到目标牌。被移除的牌（即目标牌上方的牌）会被放回顶部并保持原有相对顺序（或按某种规则处理）。

每次取牌的成本取决于目标牌在当前位置（从顶部数起的位置），或等于目标牌上方所有牌的编号之和。

问题要求找到最优的初始排列，使得按顺序取出所有牌的总成本最小，并计算该最小成本。

PE 答案：160640。

## 算法

1. **暴力枚举**：对 $N \le 7$ 枚举所有 $N!$ 个排列，模拟取牌过程，找最小成本。
2. **动态规划**：对较大的 $N$，使用 DP 求解最优排列。
   - 状态：当前待处理的牌区间 $[l, r]$
   - 最优排列是将区间中点放在顶部，然后递归处理左右子区间
3. **最优结构**：最优排列类似二分搜索树的中序遍历，形成平衡结构。
4. **成本公式推导**：利用最优子结构性质，可以得到最小成本的闭式或递推公式。
5. **复杂度**：$O(N^3)$ DP 或 $O(N)$ 公式。

## 改编方向

1. 推广到牌上方的牌被丢弃而非放回
2. 成本函数改为加权和（不同牌有不同权重）
3. 取牌顺序不是 1..N 而是任意给定顺序
4. 限制初始排列满足某些约束
5. 三维推广（多叠牌）
