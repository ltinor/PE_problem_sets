# 吃馅饼

## 题目描述

杰夫切圆形馅饼：先沿半径切一刀。只要馅饼剩余比例 ≥ F = 1/x，就进行以下操作：
- 在剩余馅饼边缘均匀随机选两点，从圆心切两刀，将剩余部分分为三份。
- 从初始切口逆时针取前两份吃掉。

当馅饼剩余不足 F 时，将剩余全部吃掉。

记 E(x) 为上述操作（切两刀取两份）的期望执行次数。

给定 x，求 E(x)，保留 10 位小数。

---

## 输入格式

一个实数 x（x ≥ 1）。

---

## 输出格式

一个浮点数，表示 E(x)，四舍五入到 10 位小数。

---

## 样例

### 输入
```
2
```

### 输出
```
1.2676536759
```

### 输入
```
7.5
```

### 输出
```
2.1215732071
```

---

## 数据范围

- x 的范围：1 ≤ x ≤ 100
