# PE783 — Urns（瓮）

来源：改编自 Project Euler Problem 783

## 原题意

考虑一个经典的瓮模型（urn model）：将球按某种规则放入瓮中。问题可能涉及期望值计算（如期望空瓮数、期望首次填满所有瓮的时间等）或对球与瓮的某种配置进行计数。

PE 答案：506132494（约 $5.06 \times 10^8$）。

## 算法

1. **第二类 Stirling 数**：$S(n,k)$ 表示将 $n$ 个不同球放入 $k$ 个相同瓮（不允许空瓮）的方法数。递推：$S(n,k) = S(n-1,k-1) + k \cdot S(n-1,k)$。
2. **Bell 数**：$B(n) = \sum_k S(n,k)$，将 $n$ 个元素划分任意数量的子集的方法数。
3. **隔板法（Stars and bars）**：将 $n$ 个相同球放入 $k$ 个不同瓮的方法数为 $\binom{n+k-1}{k-1}$。
4. **期望空瓮数**：$n$ 个球随机放入 $k$ 个瓮，期望空瓮数为 $k \cdot (1 - 1/k)^n$。
5. **优惠券收集问题（Coupon collector）**：填满 $k$ 个瓮所需的期望球数为 $k \cdot H_k$。

## 改编方向

1. Pólya 瓮模型（强化过程，抽取一个球后放回 $c$ 个同色球）
2. Ehrenfest 瓮模型（两瓮间的 Markov 链）
3. 限制瓮的容量（有限容量瓮的分布问题）
4. 考虑多色球和瓮的区分
5. 计算所有配置中某些统计量（如最大瓮的球数）的期望
