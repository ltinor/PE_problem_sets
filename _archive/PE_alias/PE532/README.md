# PE532 - 测量地球！(Measure the Earth!)

来源：改编自 Project Euler Problem 532

## 原题意

在地球（视为半径为 R 的球体）表面进行测地线测量实验。地球表面有 N 条等间距的经线（子午线）。从赤道与零度经线的交点出发，沿大圆（测地线）依次走到每条经线，测量并累加走过的距离。

原题计算某种几何测量下的总路径长度或相关衍生量。

PE 答案：8130374923。

## 题目

给定经线数量 N 和地球半径 R，计算沿测地线依次访问所有等间距经线的总路径长度。

## 算法

- 使用球面几何的 Haversine 公式计算两点间的大圆距离：
  - d = 2R · atan2(√a, √(1-a))
  - a = sin²(Δlat/2) + cos(lat₁)·cos(lat₂)·sin²(Δlon/2)
- N 条等间距经线：λᵢ = i · 360°/N（i = 0, 1, ..., N-1）
- 从 (lat=0, lon=0) 出发，依次沿赤道走到经度 λ₁, λ₂, ...
- 对每个 i，计算 (0, 0) 到 (0, λᵢ) 的赤道距离并累加。
- 使用双精度浮点数计算，确保足够精度。

## 改编方向

1. **不同路径**：从北极出发或沿不同大圆路径行走。
2. **三维坐标**：输入球面上的坐标点序列，求路径总长。
3. **椭球模型**：使用 WGS84 椭球面代替完美球体。
4. **面积/体积**：求测地线围成的区域面积或球面多边形面积。
