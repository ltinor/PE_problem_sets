# PE557 — 切割三角形 (Cutting Triangles)

来源：改编自 Project Euler Problem 557

## 原题意

将一个边长为 n 的等边三角形用平行于三边的直线划分为 n² 个边长为 1 的小等边三角形。

从大三角形的顶点出发，沿网格线作切割，将大三角形划分成若干大小不一的等边三角形（每条切割线必须沿网格线）。

令 T(n) 为将边长为 n 的等边三角形切割成若干个整数边长的小等边三角形的方案数。

求 Σ_{n=1}^{10⁴} T(n)。

PE 答案：108878932306682434。

## 题目

给定 N，求 Σ_{n=1}^{N} T(n) — 前 N 个等边三角形的切割方案总数之和。

## 算法

- T(n) 等于将 n 划分为三个正整数 (a,b,c) 且满足 a+b > c（三角形不等式）的带权方案数。
- 利用生成函数：每个子三角形对应一个三部分的划分，且子三角形的位置由网格上的重心坐标决定。
- 可通过递推关系计算 T(n)：从小到大枚举所有可能的 (a,b,c) 组合。
- 对 N ≤ 10⁴ 可以使用 O(N²) 或 O(N³ᐟ²) 算法配合前缀和优化。

## 改编方向

1. **不同 N**：计算更大的 N 值（如 10⁵）的求和。
2. **模运算**：求结果对某大质数取模。
3. **T(n) 的分析**：研究 T(n) 的渐近行为或生成函数。
4. **不同形状**：推广到正方形或其他多边形网格的切割。
5. **限制条件**：只计数恰好切为 k 块的方案数。
