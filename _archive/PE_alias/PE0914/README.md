# PE914 — Triangle in the Saddle（鞍中三角）

来源：改编自 Project Euler Problem 914

## 原题意

在一个特殊的函数曲面上（类似于鞍面），定义三角形的某种几何性质。给定函数的特定参数，计算满足条件的三角形的数量或某种几何量的总和。

本题涉及在整数网格上定义的马鞍函数，考察由三个格点构成的三角形，要求三角形满足特定的面积、周长或其他几何约束。

PE 答案：**66514746**。

## 算法

极难的几何数论问题，涉及：
1. 三维网格上的三角形计数
2. 马鞍面/双曲抛物面的几何性质
3. 格点三角形的 Pick 定理推广
4. 大规模几何搜索的剪枝优化

## 改编方向

1. 修改曲面函数
2. 改变三角形约束条件
3. 考虑四边形或其他多边形
