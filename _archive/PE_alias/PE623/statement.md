# Lambda 计数

## 题目描述

Lambda 项（lambda term）由以下符号构成：括号、λ、点号和变量名。闭合 lambda 项（combinator）是指没有自由变量的项。

记 Λ(n) 为可以用至多 n 个符号表示的不同闭合 lambda 项的数目，其中 α-等价的项（仅绑定变量重命名不同的项）只计算一次。

已知：
- Λ(6) = 1
- Λ(9) = 2
- Λ(15) = 20
- Λ(35) = 3166438

求 Λ(2000)，并将答案对 1000000007 取模。

## 输入格式

一行，字符串 `PE` 或 `verify`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案：3999787880。

若输入为 `verify`，输出 Λ(6)、Λ(9)、Λ(15)、Λ(35) 的验证结果。

## 样例

### 输入
```
PE
```

### 输出
```
3999787880
```

## 数据范围

- 完整问题：n = 2000
- 验证模式：n ∈ {6, 9, 15, 35}
