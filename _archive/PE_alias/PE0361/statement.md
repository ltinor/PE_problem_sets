# 图厄-摩尔斯序列的子序列

## 题目描述

图厄-摩尔斯序列 {T_n} 满足 T_0=0, T_{2n}=T_n, T_{2n+1}=1-T_n。

序列 {A_n} 定义为：所有二进制表示为 {T_n} 子序列的整数，从小到大排列。

例如：18（二进制 10010）出现在 T_8~T_{12}，所以 18 ∈ {A_n}。14（二进制 1110）不出现。

给定 n，求 A_n 的值模 10^9。

---

## 输入格式

一个整数 n (1 ≤ n ≤ 10^6)。

---

## 输出格式

一个整数，表示 A_n mod 10^9。

---

## 样例

### 输入
```
5
```

### 输出
```
4
```

---

## 数据范围

1 ≤ n ≤ 10^6
