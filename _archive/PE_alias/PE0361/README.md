# 图厄-摩尔斯序列的子序列

来源：改编自 Project Euler Problem 361

## 原题意

定义 Thue-Morse 序列，求二进制表示为该序列子序列的所有整数中，A_{10^k} (k=1..18) 之和的最后9位数字。PE 答案：178476944。

## 题目

给定一个上限 N，求所有 ≤N 且其二进制表示为 Thue-Morse 序列子序列的整数之和。

## 数据范围

N ≤ 10^9

## 算法

### 方向一：Thue-Morse 前缀自动机 + DFS

构建基于 Thue-Morse 序列的有限状态自动机，在每个状态下枚举添加 0 或 1 的位。递归生成所有"合法"二进制串，转换为十进制后累加。

### 方向二：数位 DP

将问题转化为数位 DP：逐位构建二进制数，维护当前位置在 Thue-Morse 序列中的匹配状态。状态数有限（Thue-Morse 序列的周期性/递归结构），可高效预处理转移。

### 方向三：递归分治

利用 Thue-Morse 序列的定义 T_{2n}=T_n, T_{2n+1}=1-T_n，递归地划分子问题。每个区间 [L,R) 内合法数的计数和求和可通过递归合并子区间结果。

### 时间复杂度

O(log N × 状态数)，状态数约 O(log N)，总复杂度 O(log² N)。
