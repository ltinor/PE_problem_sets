# PE335 - 采豆子 (Gathering Beans)

来源：改编自 Project Euler Problem 335
PE 答案：5032316（模 7⁹）

## 原题意

x 个碗摆成圆形，每碗 1 颗豆子。操作：取空当前碗的所有豆子，顺时针逐个放入后续碗中。下一次从最后放豆的碗开始。M(x) 为回到初始状态（每碗 1 颗）所需的操作数。

已知：M(5)=15，M(100)=10920。
求 Σ_{k=0}^{10¹⁸} M(2^k+1) mod 7⁹。

## 题目（改编）

给定 x（≤ 100000），求 M(x)。

## 算法

- 维护豆子数组和"非 1 计数器"
- 模拟整个过程：每次取当前碗的豆子数 b，将当前碗清零，顺时针分发 b 颗
- 更新计数器，当所有碗均为 1 时停止
- 对于 x=2^k+1 有周期性规律（原题用此求和大范围）

## 复杂度

- 时间：O(M(x) · L)，其中 L 为每次分发豆子的数量（≤ x）
- 空间：O(x)

## 改编方向

1. **不同初始状态**：初始每碗有不同数量的豆子
2. **逆时针分发**：改为逆时针方向
3. **周期性分析**：推导 M(2^k+1) 的递推公式
