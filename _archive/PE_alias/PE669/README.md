# PE669 — 骑士拨号 (The Knight's Dial)

来源：改编自 Project Euler Problem 669

## 原题意

一个国际象棋中的骑士被放置在标准电话键盘上：

```
1 2 3
4 5 6
7 8 9
* 0 #
```

骑士以 L 形移动（一个方向走 2 步，垂直方向走 1 步）。从每个数字出发，骑士可以跳到特定的其他数字。

骑士从数字 1 出发。求经过 N 次跳跃（共 N+1 个数字）可以形成的不同数字序列的数目。

经典的动态规划问题。令 dp[i][d] 为长度为 i 且以数字 d 结尾的序列数目。

转移：从每个数字 d，骑士可以跳到 adj[d] 中的数字。

已知小规模情况：
- N=1（1 次跳跃，2 个数字）：从 1 出发，骑士可到 {6, 8}，共 2 种
- N=2（2 次跳跃）：从 6→{1,7,0}，从 8→{1,3}，共 5 种

PE 答案：197912312715。

## 算法

骑士移动图（电话键盘坐标系统）：

坐标分配：1=(0,0), 2=(0,1), 3=(0,2); 4=(1,0), 5=(1,1), 6=(1,2); 7=(2,0), 8=(2,1), 9=(2,2); 0=(3,1)

骑士移动方向：(±1, ±2) 或 (±2, ±1)

各数字的可达数字：
- 0 → {4, 6}
- 1 → {6, 8}
- 2 → {7, 9}
- 3 → {4, 8}
- 4 → {3, 9, 0}
- 5 → {}（无合法移动）
- 6 → {1, 7, 0}
- 7 → {2, 6}
- 8 → {1, 3}
- 9 → {2, 4}

DP 递推：dp_{i+1}[nxt] += dp_i[d]，对所有 (d → nxt) 边。

对于大规模 N（如 10⁹），可使用矩阵快速幂优化（邻接矩阵的 N 次幂）。

## 改编方向

1. 不同的棋盘/键盘布局
2. 多种棋子（后、象等）
3. 限制访问特定数字的次数
4. 有障碍（某些格子不可访问）
5. 加权计数（某些数字被拨打多次的场景）
