# PE737 — Coin Loops (硬币循环)

来源：改编自 Project Euler Problem 737

## 原题意

$n$ 枚硬币排成一圈，编号 $0$ 到 $n-1$。每枚硬币可以是正面（heads）或反面（tails）。

规则：每一步查看硬币 $0$（当前位置 $0$ 的硬币）。
- 如果是**正面**：翻转它，然后将它移动到位置 $n-1$（所有其他硬币向左移动一位）。
- 如果是**反面**：翻转它，但保持它在位置 $0$。

从所有硬币都是正面的初始状态开始，重复应用上述规则。状态空间的大小为 $n \times 2^n$（硬币 $0$ 有 $n$ 个可能位置，每枚硬币有两种面值）。

定义**硬币循环**（coin loop）为该状态转移图中的一个循环（cycle）。求 $n = 30$ 时的循环总数。

PE 答案：75779467。

## 算法

1. **状态编码**：将状态编码为 `(coin0_position << n) | face_bits`，共 $n \cdot 2^n$ 个状态。

2. **模拟状态转移**：对每个状态计算后继状态，构建置换。

3. **循环计数**：使用 DFS/并查集遍历状态图，统计循环数。

4. **数学公式**（用于大 $n$）：
   - 问题等价于某个特定置换的循环分解
   - 循环数与项链计数（necklace counting）有关
   - 使用数论函数（欧拉函数）简化计算

5. **复杂度**：$O(n \cdot 2^n)$ 对于 $n=30$ 不可直接模拟，需使用组合公式。

## 改编方向

1. 参数化 $n$（更大的硬币数）
2. 改变硬币规则（如同时移动多枚硬币）
3. 考虑不同的初始状态
4. 求最长循环的长度而非循环总数
5. 改为概率问题：随机初始状态下期望的循环长度
