# PE600 — 整数边长等角六边形 (Equiangular hexagons with integer sides)

来源：改编自 Project Euler Problem 600

## 原题意

H(n) = 周长不超过 n 的不同整数边长等角凸六边形的个数（不全等视为不同）。

已知：H(6)=1，H(12)=10，H(100)=31248。

求 H(55106)。

PE 答案：7105371060687586。

## 算法

等角六边形的内角均为 120°。在三角形网格上，等角六边形的边可以表示为 6 个方向上的步数。

设边长为 a,b,c,d,e,f（顺时针）。等角六边形的封闭条件等价于对边差的关系：
- a - d = e - b
- c - f = e - b（或等价形式）

标准的参数化：用三个非负整数 x, y, z 进行参数化：
- a = x + y
- b = y + z
- c = z + x
- d = x + y
- e = y + z
- f = z + x
但这会得到规则的六边形（对边相等）。

正确的参数化（源自 PE 论坛分析）：
设六边形由"大等边三角形减去三个角"构造。设大三角形边长为 S，三个角切去的三角形边长分别为 p,q,r。则六边形边长为：
- a = S - r, b = p, c = S - q, d = r, e = S - p, f = q

周长 = 3S。约束：p+q+r < S 且各边 > 0。需对 D₆ 对称性去重。

通过枚举 S ≤ 55106/3 ≈ 18368，再枚举每个 S 下的 (p,q,r) 三元组，即可计数。由于对称性，计数可通过数论函数和组合数学加速。

具体实现中，H(n) = Σ_{per ≤ n} [valid (a,b,c,d,e,f)]，可用 O(n^3) 或更优的方法枚举。

## 改编方向

1. 推广到 2k 边形（八边形、十边形等）。
2. 加入面积或对角线的限制条件。
3. 研究 H(n) 的渐近公式（如 H(n) ~ C·n³）。
4. 将整数边长条件改为有理数或有理角度。
