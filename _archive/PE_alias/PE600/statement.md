# 整数边长等角六边形

## 题目描述

H(n) 为周长不超过 n 的不同整数边长等角凸六边形的个数。当且仅当两个六边形不全等时视为不同。

已知：
- H(6) = 1
- H(12) = 10
- H(100) = 31248

求 H(55106)。

## 输入格式

一行，字符串 `PE` 或 `verify`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案：7105371060687586。
若输入为 `verify`，验证已知的 H(6)（H(12) 和 H(100) 因计算量较大，仅列出已知值）。

## 样例

### 输入
```
PE
```

### 输出
```
7105371060687586
```

## 数据范围

- 完整问题：n = 55106
- 验证模式：n ≤ 6（精确验证），更大值仅显示已知结果
