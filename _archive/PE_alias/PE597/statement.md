# 赛艇

## 题目描述

Torpids 赛艇比赛的规则：
- n 条船，以 40 米间隔出发，排名高的靠近上游。
- 各船以固定速度向上游行进，速度 v_j = -log(X_j)，X_j ~ U(0,1)。
- 追上前船则"撞击"：撞击船退出，被撞船继续（可被再撞）。
- 最终排名：A 高于 B 当且仅当 A 直接或间接撞击了 B。

p(n,L) = 新排名为原排名偶排列的概率。已知 p(3,160)=56/135, p(4,400)≈0.5107843137。

求 p(13,1800)，保留 10 位小数。

## 输入格式

一行，字符串 `PE` 或 `verify`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案：372810188163.3615。
若输入为 `verify`，验证已知的 p(3,160) 和 p(4,400)。

## 样例

### 输入
```
PE
```

### 输出
```
372810188163.3615
```

## 数据范围

- 完整问题：n = 13, L = 1800
- 验证模式：n ≤ 4
