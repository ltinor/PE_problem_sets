# PE543 - 素和数 (Prime-Sum Numbers)

来源：改编自 Project Euler Problem 543

## 原题意

定义函数 P(n,k)：若 n 可写成 k 个素数（可重复）的和则为 1，否则为 0。

例如 P(10,2)=1（10=3+7=5+5），P(11,2)=0（不存在两素数之和为 11）。

令 S(n) = Σ_{1≤i,k≤n} P(i,k)。已知 S(10)=20，S(100)=2402，S(1000)=248838。

令 F(k) 为第 k 个斐波那契数（F(0)=0, F(1)=1）。求 Σ_{k=3}^{44} S(F(k))。

PE 答案：1990075970818614370。

## 题目

给定 n，求 S(n) = Σ_{i=1}^n Σ_{k=1}^n P(i,k)，即所有 n×n 表格中 P(i,k) 的总和。

## 算法

- 按 k 分类讨论：
  - **k = 1**：P(n,1) = 1 ⇔ n 是素数。计数 = π(n)。
  - **k = 2**：P(n,2) = 1 对偶数 n≥4（Goldbach，已验证至 4×10^18）和对满足 n−2 为素数的奇数 n。计数 = ⌊n/2⌋ + π(n−2) − 2。
  - **k ≥ 3**：P(n,k) = 1 ⇔ n ≥ 2k（最小和为 k 个 2→2k，且 k≥3 时所有 ≥2k 的整数均可表示）。计数 = Σ_{k=3}^{⌊n/2⌋} (n−2k+1)。
- 化简得闭公式：S(n) = π(n) + π(n−2) + ⌊n/2⌋ + (m−2)(n+1) − m(m+1) + 4，其中 m = ⌊n/2⌋。
- 需要高效素数计数函数（π函数）。由于最大 n = F_44 ≈ 7×10^8，可使用分段筛法。
- 生成斐波那契数列 F_3 至 F_44，对每个计算 S(F_k) 并求和。

## 改编方向

1. **不同区间**：求 S(n) 在更大范围的求和或取模。
2. **加权和**：求 Σ i·P(i,k) 或 Σ k·P(i,k)。
3. **不同表述数**：将素数改为其他特殊数集（如完全平方数、斐波那契素数等）。
4. **概率角度**：计算 P(i,k)=1 的比例或期望值。
