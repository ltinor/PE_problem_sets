# 乘法表中的不同项

## 题目描述

记 P(m,n) 为 m×n 乘法表中**不同**项的个数。

例如，3×4 的乘法表：

| × | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| 1 | 1 | 2 | 3 | 4 |
| 2 | 2 | 4 | 6 | 8 |
| 3 | 3 | 6 | 9 | 12|

其中有 8 个不同的项 {1,2,3,4,6,8,9,12}，因此 P(3,4) = 8。

已知：
- P(64,64) = 1263
- P(12,345) = 1998

给定 m 和 n，求 P(m,n)。

---

## 输入格式

两个整数 m, n (1 ≤ m ≤ 25, 1 ≤ n ≤ 10^9)。

---

## 输出格式

一个整数，表示 P(m,n)。

---

## 样例

### 输入
```
3 4
```

### 输出
```
8
```

### 输入
```
64 64
```

### 输出
```
1263
```

### 输入
```
12 345
```

### 输出
```
1998
```

---

## 数据范围

- 对于 30% 数据：m,n ≤ 8
- 对于 60% 数据：m ≤ 15, n ≤ 10^6
- 对于 100% 数据：m ≤ 25, n ≤ 10^9
