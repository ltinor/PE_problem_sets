# 内部格点

## 题目描述

给定四个正整数 a, b, c, d，考虑以 A(a,0), B(0,b), C(-c,0), D(0,-d) 为顶点的四边形。统计严格位于该四边形内部的格点（坐标为整数的点）数量。

求对所有 1 ≤ a,b,c,d ≤ N 的四边形的内部格点数之和。

## 输入格式

一个整数 N（1 ≤ N ≤ 100），或字符串 `PE`。

## 输出格式

一个整数，表示内部格点总数之和。

## 样例

### 输入
```
2
```

### 输出
```
42
```

## 数据范围

- 对于 30% 数据：N ≤ 2
- 对于 60% 数据：N ≤ 4
- 对于 100% 数据：N ≤ 100
