# 汽车牌照

来源：改编自 Project Euler Problem 371

## 原题意

俄勒冈车牌（三位数字）。求看到两个车牌数字之和为 1000 所需期望数量。PE 答案：7278014883470655（含小数，四舍五入到 8 位）。

## 题目

给定目标和 S，求随机三位数序列首次出现两数之和为 S 的期望步数。

## 数据范围

S = 1000，数字范围 000-999。

## 算法

### 方向一：马尔可夫链 + 期望 DP

状态为已看到的数字集合（不能形成和为 S 的对）。共 1000 个数字，和为 S 的对共 500 对（含 500+500）。DP 计算从空集合到首次出现"配对"的期望步数。

### 方向二：吸收马尔可夫链

构建转移矩阵（状态：已见数字中未配对的"危险"数字数）。利用对称性，状态仅取决于已见数字中与未配对数字互补的那些。解线性方程组。

### 方向三：Coupon Collector 变种

类似 Coupon Collector 问题，但目标是收集到一对互补的 coupon。用概率生成函数分析期望。

### 时间复杂度

状态数 O(S) ≈ 500，矩阵求逆 O(S³)。
