# PE695 — Random Rectangles (随机矩形)

来源：改编自 Project Euler Problem 695

## 原题意

在单位正方形中独立随机地放置三个矩形（每个矩形的 $x$ 和 $y$ 坐标在 $[0,1]$ 上均匀随机）。
求这三个矩形的面积中第二大的期望值，精确到小数点后 $10$ 位。

PE 答案：0.1017786859。

## 算法

1. **随机矩形面积**：一个随机矩形的面积 $A = |x_1-x_2| \cdot |y_1-y_2|$，
   其中 $x_1,x_2,y_1,y_2 \sim U(0,1)$。$E[A] = \frac{1}{3} \cdot \frac{1}{3} = \frac{1}{9}$。

2. **次序统计量**：三个独立同分布的矩形面积，第二大的期望值需要计算
   $$E[A_{(2)}] = \int_0^1 6 \cdot t \cdot F(t) \cdot (1-F(t)) \cdot f(t) \, dt$$
   其中 $F(t)$ 和 $f(t)$ 是单个矩形面积的 CDF 和 PDF。

3. **数值方法**：
   - **蒙特卡洛模拟**：生成大量随机矩形组合，取第二大面积的平均值。
     需要足够的样本量（$10^7$ 以上）以获得 $10$ 位精度。
   - **数值积分**：对 $4$ 维积分使用中点法或 Simpson 法近似。

4. **解析方法**：单个矩形面积的分布是 $|x_1-x_2|$（三角形分布）与 $|y_1-y_2|$ 的乘积分布。
   可通过积分变换求得精确的次序统计量期望。

## 改编方向

1. 参数化矩形数量 $k$（求第 $m$ 大的期望）
2. 使用不同的随机分布生成矩形
3. 在非正方形区域内放置矩形
4. 求面积之和、最小值等其他统计量
5. 考虑矩形之间互不相交的约束
