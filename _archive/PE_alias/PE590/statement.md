# 给定最小公倍数的集合

## 题目描述

记 H(n) 表示各元素的最小公倍数（LCM）为 n 的正整数集合的数目。

例如，以下 10 个集合的元素 LCM 都是 6：
{2,3}, {1,2,3}, {6}, {1,6}, {2,6}, {1,2,6}, {3,6}, {1,3,6}, {2,3,6}, {1,2,3,6}。
因此 H(6) = 10。

记 L(n) 为 1 到 n 的所有整数的 LCM。例如 L(6) = 60。

记 HL(n) = H(L(n))。已知 HL(4) = H(12) = 44。

求 HL(50000)，答案对 10⁹ 取余。

## 输入格式

一行，一个整数 n（或字符串 `PE`）。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案：834171904。
若输入为整数 n（n < 50000），输出 HL(n)（若 n 较小可暴力计算，否则提示使用 PE）。

## 样例

### 输入
```
4
```

### 输出
```
HL(4) = 44
```

### 输入
```
PE
```

### 输出
```
834171904
```

## 数据范围

- 对于 30% 数据：n ≤ 20
- 对于 100% 数据：n = 50000 或输入为 PE
