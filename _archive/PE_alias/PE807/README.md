# PE807 — Rododdle（杆旋转）

来源：改编自 Project Euler Problem 807

## 原题意

给定 $N$ 根长度各不相同的细杆，每根杆可以绕其中心点旋转 $180°$（即翻转方向）。初始所有杆水平放置在同一条直线上，通过旋转若干杆可以改变其朝向。目标是使所有杆端点的凸包（包围所有端点的最小凸多边形）周长最小。

求对所有可能的初始旋转方案，最小凸包周长的期望值。

PE 答案：240.6377473（保留 7 位小数）。

## 算法

1. **凸包计算**：对于给定的杆朝向组合，计算所有端点的凸包周长。
2. **组合优化**：每根杆有两种朝向（水平/垂直），共 $2^N$ 种方案。需要使用 DP 或几何分析来高效求解。
3. **期望计算**：对所有方案取平均，或利用对称性化简。

## 改编方向

1. 允许任意旋转角度（连续优化问题）
2. 考虑杆的宽度（不再视为线段）
3. 最小化凸包面积而非周长
4. 杆之间存在碰撞约束
5. 推广到三维空间
