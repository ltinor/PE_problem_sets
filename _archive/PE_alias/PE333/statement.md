# 特殊分划

## 题目描述

所有正整数都可以划分为若干个形如 2^i×3^j（i,j ≥ 0）的项的和。

我们只考虑满足**任意一项不能整除其他项**的分划方式。
例如，分划 17 = 2 + 6 + 9 不合理，因为 2 整除 6。分划 17 = 16 + 1 不合理，因为 1 整除 16。对 17 唯一合理的分划为 8 + 9。

记 P(n) 为对 n 合理的分划数目。例如 P(11) = 2，分划方式为 2+9 和 8+3。

给定 N，求所有使得 P(q) = 1 的素数 q < N 的和。

已知：所有使 P(q)=1 的素数 q < 100 之和为 233。

---

## 输入格式

一个整数 N。

---

## 输出格式

一个整数，表示所有使 P(q)=1 的素数 q < N 的和。

---

## 样例

### 输入
```
100
```

### 输出
```
233
```

---

## 数据范围

- 对于 30% 数据：N ≤ 200
- 对于 60% 数据：N ≤ 2000
- 对于 100% 数据：N ≤ 200000
