# PE333 - 特殊分划 (Special Partitions)

来源：改编自 Project Euler Problem 333
PE 答案：3053105

## 原题意

正整数可以划分为若干个形如 2^i×3^j 的项的和。只考虑任意一项不能整除其他项的分划。P(n) 为合理分划数。求所有使 P(q)=1 的素数 q<1000000 的和。

已知：q<100 时和为 233。

## 题目（改编）

给定 N（≤ 200000），求所有使 P(q)=1 的素数 q<N 的和。

## 算法

- 生成所有 2^i×3^j ≤ N 的项
- 将项按 i（2 的指数）分组
- **动态规划**：dp[j_bound][sum] = 考虑前若干行、下一项 j 必须 < j_bound 时，和为 sum 的分划数
- 递推：每行可以跳过，或选一个 j < j_bound 的项，然后下界更新为 j
- 筛法求素数，统计 P(q)=1 的素数

## 复杂度

- 时间：O(I · J · N)，其中 I≈log₂N≈18，J≈log₃N≈12（对于 N=200000）
- 空间：O(J · N)

## 改编方向

1. **多参数**：推广到 a^i×b^j×c^k 三项指数
2. **多解计数**：求 P(q)=2 或 P(q)=k 的素数
3. **非素数限制**：求所有 P(n)=1 的正整数 n
