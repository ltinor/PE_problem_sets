# PE895 — Goldbach's Other Comet（哥德巴赫的另一彗星）

来源：改编自 Project Euler Problem 895

## 原题意

哥德巴赫彗星（Goldbach's comet）是将 $G(2n)$（将偶数 $2n$ 表示为两素数之和的方式数）关于 $2n$ 绘制的散点图，形似彗星。

"哥德巴赫的另一彗星"是这一经典主题的变体：
- 加权哥德巴赫：$G_k(n) = \#\{(p,q): p + kq = n, p,q \text{ 为素数}\}$
- 受限素数分区：限制其中一个素数满足同余条件
- 高阶哥德巴赫：三个或更多素数之和

## 算法

1. **标准哥德巴赫计数**：
   - 使用素数筛法
   - 对每个 $n$ 枚举 $p \leq n$，检查 $2n-p$ 是否为素数

2. **变体 $G_k(n)$**：
   - $G_k(n) = \#\{(p,q): p + kq = n\}$
   - 枚举 $q$，检查 $n - kq$ 是否为素数

3. **累积统计**：
   - $\sum_n G(2n)$、$\sum_n G(2n)^2$ 等
   - 研究彗星的结构特征（稠密带、峰值）

## 改编方向

3. 三元哥德巴赫问题
