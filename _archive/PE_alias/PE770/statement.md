# B旅游

## 题目描述

有 $N$ 个地点排列在一条直线上，坐标为 $0, 1, 2, \dots, N-1$。一位旅行者从某个地点出发，需要访问所有地点恰好一次，但每次移动的距离不能超过 $B$（即相邻两次访问的坐标差不超过 $B$）。

问题要求：对于给定的 $N$，计算所有可能的 $B$（或某个特定的 $B$）对应的合法旅行路线的总数。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 1273112231728726740。
- `verify`：对 $N \le 10$ 和不同 $B$ 值计算合法路线数。
- `compute`：扩展到 $N \le 16$，分析增长趋势和与阶乘的对比。

## 样例

### 输入
```
PE
```

### 输出
```
1273112231728726740
```

### 验证
```
verify
```

输出内容包括：
- $N=1 \dots 10$ 的合法路线数（对不同 $B$ 值）
- $B=\infty$ 时的路线数（即 $N!$）
- 所有 $B$ 的路线数之和
- 答案与最近阶乘的对比分析

## 数据范围

- 验证范围：$N \le 10$（状态空间 $2^{10} = 1024$，DP 可行）
- 扩展计算：$N \le 16$（状态空间 $2^{16} = 65536$）
- 完整问题：PE 答案 $1.27 \times 10^{18}$，介于 $19!$ 和 $20!$ 之间
