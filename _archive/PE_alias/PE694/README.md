# PE694 — Cube-full divisors (立方满因子)

来源：改编自 Project Euler Problem 694

## 原题意

一个正整数 $n$ 被称为"立方满"（cube-full）的，如果对于 $n$ 的每个素因子 $p$，
$p^3$ 也整除 $n$。换言之，$n$ 的素数分解中每个指数至少为 $3$。

定义 $S(N)$ 为所有不超过 $N$ 的立方满数的和。
求 $S(10^{18})$。

PE 答案：1339784153569958487。

## 算法

1. **立方满数的表示**：每个立方满数可以写成 $a^3 \cdot b^2$ 的形式，
   其中 $a, b$ 是正整数。这是因为 $3$ 和 $2$ 互素，可以组合出所有 $\ge 2$ 的指数。
   注意 $a^3 b^2$ 会生成所有立方满数但也包含指数仅为 $2$ 的数（非立方满），需要筛选。

2. **枚举策略**：枚举 $a$（$a^3 \le N$），对每个 $a$，枚举 $b$ 使得 $a^3 b^2 \le N$。
   用哈希集合去重后求和。

3. **优化**：立方满数的密度约为 $O(N^{1/3})$，直接枚举 $a \le N^{1/3}$ 和 
   $b \le \sqrt{N/a^3}$，总量可接受。

4. **复杂度**：枚举量 $\approx \sum_{a=1}^{N^{1/3}} \sqrt{N/a^3} \approx N^{1/3} \cdot \sqrt{N} \cdot O(1)$，
   对于 $N=10^{18}$ 需要进一步优化或使用数论筛法。

## 改编方向

1. 参数化 $N$ 的上限
2. 改为计数而非求和
3. 求 $k$-full 数（指数 $\ge k$）的和
4. 限定在特定区间内的立方满数统计
