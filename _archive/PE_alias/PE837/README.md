# PE837 — Minimal Circles（最小圆）

来源：改编自 Project Euler Problem 837

## 原题意

给定平面上 N 个点，用若干个半径相同的圆覆盖所有点。求最小半径 R 和所需的最少圆数量。

这是经典的几何覆盖问题，近似于：
- **最小覆盖圆（Minimum Enclosing Circle）**：Welzl 算法 O(N)。
- **K-中心问题（K-Center Problem）**：在度量空间中找到 K 个中心，使最大距离最小化。NP-hard。
- **单位圆盘覆盖问题**：将问题转化为寻找最小半径以允许用 K 个圆覆盖所有点。

PE 答案：572410.960905（浮点数，约 0.57 × 10^6，说明点数或坐标很大）。

## 算法

1. **Welzl 算法**：在 O(N) 期望时间内找到一个点集的最小包围圆。用于单个圆的情况（K=1）。

2. **二分答案 + 验证**：二分搜索半径 R，然后用贪心或图论方法验证是否能用 ≤K 个半径为 R 的圆覆盖所有点。

3. **覆盖图的构建**：
   - 对每个点对 (i, j)，如果 dist(i, j) ≤ 2R，则它们可能被同一个圆覆盖。
   - 该问题可以规约为集合覆盖问题（Set Cover），但集合覆盖也是 NP-hard。
   - 在几何中，对于单位圆盘覆盖，可以使用 Strips 方法和 DP。

4. **贪心覆盖**：每次选择能覆盖最多未覆盖点的圆心位置，重复直到所有点被覆盖。该贪心算法可达到 O(log n) 近似比。

5. **最小包围圆的增量构造**：通过 Welzl 算法或 Megiddo 的 prune-and-search 算法。

## 改编方向

1. 考虑不同的覆盖形状（正方形、椭圆）而非圆形
2. 允许不同半径的圆（加权覆盖）
3. 加入覆盖约束（某些点必须在同一个圆内）
4. 三维空间中的球覆盖问题
5. 动态覆盖（点可以移动）
