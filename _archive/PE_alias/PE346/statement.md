# 强循环单位数

## 题目描述

一个正整数如果在至少两种不同的进位制（基数 b > 1）下可以写成所有位都是 1 的形式（即循环单位数 repunit），则称其为**强循环单位数**。

例如，7 在二进制下写作 111，在六进制下写作 11，因此 7 是一个强循环单位数。

可以验证，小于 50 的强循环单位数有 8 个：{1, 7, 13, 15, 21, 31, 40, 43}，它们的和为 171。

小于 1000 的强循环单位数之和为 15864。

给定 N，求所有小于 N 的强循环单位数之和。

---

## 输入格式

一个整数 N。

---

## 输出格式

一个整数，表示所有小于 N 的强循环单位数之和。

---

## 样例

### 输入
```
50
```

### 输出
```
171
```

### 输入
```
1000
```

### 输出
```
15864
```

---

## 数据范围

- 对于 30% 数据：N ≤ 10^5
- 对于 60% 数据：N ≤ 10^8
- 对于 100% 数据：N ≤ 10^12
