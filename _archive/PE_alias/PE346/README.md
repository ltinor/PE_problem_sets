# PE346 - 强循环单位数 (Strong Repunits)

来源：改编自 Project Euler Problem 346

## 原题意

一个强循环单位数是指在至少两种 b>1 进制下都是循环单位数（repunit）的正整数。求所有小于 10^12 的强循环单位数之和。原题答案：336108797689833276。

## 题目

输入 N，求所有小于 N 的强循环单位数之和。

循环单位数（repunit）指在某进制 b 下所有位都是 1 的数，即 R(b,n) = (b^n - 1) / (b - 1)，其中 n 为位数。

由于对于任意 X ≥ 2，R(X-1, 2) = X，因此每个 ≥ 2 的数至少在一个进制（基数为 X-1，位数为 2）下是循环单位数。一个强循环单位数等价于存在至少一个 n ≥ 3 的循环单位数表示（此外 1 是特殊情况，它在所有进制下都是循环单位数）。

## 算法

- 枚举基数 b ≥ 2 和位数 n ≥ 3，生成所有 repunit 值 R(b, n) = (b^n - 1) / (b - 1) ≤ N。
- 使用集合（unordered_set）去重，求和。
- 另外加上 1（1 在任意进制下都是强循环单位数）。

复杂度：b 最多枚举到约 √N，对于每个 b，n 最多枚举到 log_b(N)。总体约 O(√N · log N)。

## 改编方向

1. **限定进制范围**：只统计在不超过某最大基数 B 的进制下是强循环单位数的数。
2. **限定位数**：位数 n 需满足某个条件（如 n 为质数）。
3. **多组输入**：支持多组测试数据 N_1, N_2, ...。
4. **模数版本**：答案对 M 取模。
