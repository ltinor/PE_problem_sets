# 外接圆

来源：改编自 Project Euler Problem 373

## 原题意

整数边三角形且外接圆半径为整数。求半径 ≤ 10^7 的所有此类三角形外接圆半径之和。PE 答案：727227472448913。

## 题目

给定 R_max，求所有外接圆半径 ≤ R_max 且为整数的整数边三角形的半径之和。

## 数据范围

R_max ≤ 10^7

## 算法

### 方向一：外接圆半径公式 + 参数化

外接圆半径 R = abc/(4Δ)，其中 Δ 为面积。对于整数边三角形，R 为整数的条件可参数化为勾股数生成。

### 方向二：枚举弦长 + 正弦定理

三角形的外接圆半径 R = a/(2 sin A)。使用正弦定理，将问题转化为寻找满足整数条件的 (a,b,c) 三元组。

### 方向三：生成所有整边三角形

枚举三角形的最长边 c 和外接圆半径 R。由 a = 2R sin A, b = 2R sin B，使用余弦定理约束 c² = a²+b²-2ab cos C。

### 时间复杂度

O(R_max log R_max) 或更好。
