# PE736 — Paths to Equality (通向平等之路)

来源：改编自 Project Euler Problem 736

## 原题意

有 $n$ 对整数 $(l_i, r_i)$，$i = 1, 2, \dots, n$，初始状态为：
- $l_i = i$
- $r_i = 0$

每次操作选择两个下标 $1 \le i < j \le n$，执行：
$(l_i, r_i) \leftarrow (l_i + l_j, r_i + r_j)$

恰好执行 $2n-2$ 次操作后，要求所有 $r_i$ 相等。求满足条件的操作序列总数。

PE 答案：25332747903959076（对应 $n = 15$）。

## 算法

该问题等价于计数所有可能的合并二叉树：
1. 初始 $n$ 个叶节点表示原始的 $n$ 对
2. 每次操作将第 $j$ 对合并到第 $i$ 对，相当于构建一个内部节点
3. 最终保留一个节点，其 $r$ 值是所有 $r$ 的某种组合

核心洞察：
- 操作序列对应一棵完全二叉树（full binary tree），叶子有序标号
- $2n-2$ 次操作意味着 $n-1$ 次内部合并
- 等式约束等价于合并过程中的对称性条件

递推关系：令 $f(n)$ 表示 $n$ 对时的合法操作序列数，满足：
- $f(1) = 0$（无法操作）
- $f(2) = 1$（唯一操作序列）
- 对于 $n > 2$，通过分析第一个合并操作的后效性建立递推

## 改编方向

1. 参数化 $n$ 的范围（更大或更小）
2. 改变初始条件 $(l_i, r_i)$ 的赋值规则
3. 允许不同的合并操作规则（如加权合并）
4. 求模意义下的计数
5. 改为计数最短路径而非所有操作序列
