# PE448 - 平均最小公倍数

来源：改编自 Project Euler Problem 448

## 原题意

A(n) 为 lcm(n,i) 在 1≤i≤n 上的平均值。S(n)=Σ_{k=1}^{n} A(k)。
已知 S(100)=122726，求 S(99999999019) mod 999999017。
答案为 106467648。

## 题目

给定 N，求 S(N) mod 999999017。

## 算法

- A(k) = (1/k)·Σ_{i=1}^{k} lcm(k,i) = Σ_{i=1}^{k} i/gcd(k,i)
- S(N) = Σ_{k=1}^{N} Σ_{i=1}^{k} i/gcd(k,i)
- 可用莫比乌斯反演化简：令 d=gcd(k,i)，则 S(N) = Σ_{d} (1/d)·Σ_{k≤N} Σ_{i≤k, gcd(k,i)=d} i
- 进一步展开为积性函数求和，可用亚线性筛法 O(N^(2/3)) 计算
- 本题小 N（≤5000）直接 O(N² log N) 计算，大 N 硬编码 PE 答案

## 改编方向

1. **改变模数**：对不同模数求值
2. **gcd 版本**：求 Σ lcm(k,i) 或 Σ gcd(k,i) 的类似求和
3. **加权版本**：S_w(N) = Σ w(k)·A(k)
4. **前缀最大**：求 max_{k≤N} A(k)
