# 平均最小公倍数

## 题目描述

函数 lcm(a,b) 表示 a 和 b 的最小公倍数。

对于 1≤i≤n，定义 A(n) 为 lcm(n,i) 的平均值：

$$A(n) = \frac{1}{n}\sum_{i=1}^{n} \text{lcm}(n,i)$$

例如：A(2) = (2+2)/2 = 2，A(10) = (10+10+30+20+10+30+70+40+90+10)/10 = 32。

定义 S(n) = Σ_{k=1}^{n} A(k)。

已知 S(100) = 122726。

---

## 输入格式

一个整数 N（1 ≤ N ≤ 5000，或 N = 99999999019）。

---

## 输出格式

一个整数，表示 S(N) mod 999999017。

---

## 样例

### 输入
```
10
```

### 输出
```
...
```

---

- 对于 30% 数据：N ≤ 10
- 对于 60% 数据：N ≤ 200
- 对于 100% 数据：N ≤ 5000 或 N = 99999999019（PE 答案硬编码）
