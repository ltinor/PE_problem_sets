# PE609 — π序列 (π sequences)

来源：改编自 Project Euler Problem 609

## 原题意

π(n) 为素数计数函数：不超过 n 的素数个数。

若序列 u = (u₀, ..., uₘ) 满足 uₙ ≥ 1，uₙ₊₁ = π(uₙ)，且 m ≥ 1（至少两个元素），则称其为 **π 序列**。

c(u) = u 中非素数元素的个数。
p(n,k) = 满足 u₀ ≤ n 且 c(u) = k 的 π 序列数目。
P(n) = 所有大于 0 的 p(n,k) 的乘积。

已知：P(10) = 3×8×9×3 = 648，P(100) = 31038676032。

求 P(10⁸) mod 1000000007。

PE 答案：172023848。

## 算法

π 序列由 u₀ 完全确定。对于每个 u₀，生成完整的 π 链（u₀ → π(u₀) → π²(u₀) → ... → 1），然后取所有长度 ≥ 2 的前缀作为有效的 π 序列。

关键优化：
1. 使用素数筛预计算 π(n)（线性筛）。
2. 观察到 π(n) 下降很快（π(10⁸) ≈ 5.76×10⁶，π²(10⁸) ≈ 4.0×10⁵，π³(10⁸) ≈ 3.4×10⁴，π⁴(10⁸) ≈ 3.6×10³，π⁵(10⁸) ≈ 504，π⁶(10⁸) ≈ 96，π⁷(10⁸) ≈ 24，π⁸(10⁸) ≈ 9，π⁹(10⁸) = 4，π¹⁰(10⁸) = 2，π¹¹(10⁸) = 1）。
3. 使用 bucket 方法对具有相同 π 链后缀的 u₀ 进行分组计数。

## 改编方向

1. 将 π 函数替换为其他数论函数（如 Ω、ω、φ）。
2. 研究 P(n) 随 n 增长的渐近行为。
3. 计算 P(n) 模不同模数时的结果。
4. 研究 π 序列长度和 c 值的联合分布。
