# PE470 - 超级 Ramvok (Super Ramvok)

来源：改编自 Project Euler Problem 470

## 原题意

**Ramvok 游戏**：玩家选择最大回合数 t，支付 c·t。每回合掷一个 d 面骰子，可选择停止并获得点数，或继续（最后一回合必须接受）。R(d,c) 为最优策略下的期望收益。

**超级 Ramvok**：重复进行 Ramvok，每次游戏后随机翻转变异一个骰子面（可见↔空白，掷出空白则重掷）。当所有面都空白时结束。S(d,c) 为最优策略下的期望收益。

验证：R(4,0.2)=2.65, S(6,1)=208.3。

定义 F(n) = Σ_{4≤d≤n} Σ_{0≤c≤n} S(d,c)，四舍五入到整数。

原题求 F(20) ≈ 147668794。

## 题目

给定 d 和 c，求 S(d,c)（保留 6 位小数）；或给定 n，求 F(n)。

## 算法

- Ramvok 最优策略：保留阈值，当掷出值 ≥ 继续期望时停止
- EV(t) = (1/d)·Σ max(i, EV(t-1))，最优 t 最大化 EV(t)-c·t
- 超级 Ramvok：状态 DP，mask 表示哪些面可见
- S(mask) = R(mask) + (1/|mask|)·Σ S(mask 翻转一面)
- 自底向上 DP 求解

## 改编方向

1. **不同支付模型**：每回合成本不同而非固定
2. **非均匀骰子**：每个面的概率不同
3. **多玩家版本**：博弈论扩展
