# 超级 Ramvok

## 题目描述

**Ramvok 游戏**：

游戏有一个 d 面公平骰子（点数 1 到 d）。玩家在游戏开始前选择一个最大回合数 t，并支付 c·t 的费用（若 c=0 且 t 可任意大，则费用为 0）。

每回合：玩家掷骰子。若当前回合 i < t，玩家可选择**停止**并获得当前掷出的点数，或**放弃**点数进入下一回合。若 i = t（最后一回合），玩家必须接受掷出的点数。

R(d,c) 为玩家选择最优 t 并采用最优停止策略时的**期望净收益**（收益 - 成本）。

例如：R(4, 0.2) = 2.65。

---

**超级 Ramvok 游戏**：

玩家反复进行 Ramvok 游戏，但每次游戏后骰子会被修改：
1. 掷骰子一次（均匀随机选择一个面）
2. 若该面原本**可见**（有点数），则变为**空白**
3. 若该面原本**空白**，则恢复原来的点数
4. 修改后，继续下一局 Ramvok（注意：掷出空白面需重掷直到出现点数面）

当骰子所有面都变为空白时，超级 Ramvok 结束。玩家在任何时候都知道哪些面可见。

S(d,c) 为超级 Ramvok 中玩家采用最优策略的**期望总收益**。

例如：S(6, 1) = 208.3。

---

给定 d 和 c，求 S(d,c)，保留 6 位小数。

---

## 输入格式

两个数：d（整数，4 ≤ d ≤ 15）和 c（实数，0 ≤ c ≤ 10）。

---

## 输出格式

一个小数，保留 6 位小数，表示 S(d,c)。

---

## 样例

### 输入
```
4 0.2
```

### 输出（R 值示意）
```
2.650000
```

### 输入
```
6 1
```

### 输出
```
208.300000
```

---

## 数据范围

- 对于 30% 数据：d ≤ 6, c ≤ 2
- 对于 60% 数据：d ≤ 10, c ≤ 5
- 对于 100% 数据：d ≤ 15, c ≤ 10
