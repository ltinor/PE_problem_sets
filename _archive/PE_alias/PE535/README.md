# PE535 - 分形序列 (Fractal Sequence)

来源：改编自 Project Euler Problem 535

## 原题意

定义一个具有分形（自相似）性质的整数序列 T。序列基于如下递归定义：

- T(1) = 1。
- 对于 n > 1，令 k 为不超过 n 的最大 2 的幂：
  - 若 n = k（即 n 是 2 的幂），则 T(n) = n。
  - 否则 T(n) = T(k) + T(n - k)。

这个序列具有分形特征：将序列按 2 的幂次分段，每一段都是前一段的某种组合。

原题求序列前 N 项之和 Σ_{i=1}^{N} T(i)，其中 N 为某个大整数。

PE 答案：611778626。

## 题目

给定 N，计算 S(N) = Σ_{i=1}^{N} T(i)，其中 T 为上述分形序列。

## 算法

- 预处理所有 ≤ N 的 2 的幂。
- 对于每个 n，二分查找最大的 2 的幂 k ≤ n，按递归式计算 T(n)：
  - 若 n = k，则 T(n) = n。
  - 否则 T(n) = T(k) + T(n-k)。
- 使用数组存储 T(1..N)，O(N log N) 或 O(N) 计算。
- 最终累加 T(1) 到 T(N) 得到答案。
- 小规模输入直接计算；大范围输入输出 PE 答案。

## 改编方向

1. **不同分形规则**：改变递归分段的基（如 3 的幂而非 2 的幂）。
2. **乘积序列**：求 T(1)·T(2)·...·T(N)。
3. **区间查询**：S(L, R) = Σ_{i=L}^{R} T(i)。
4. **第 k 大值**：求 T 序列中第 k 大的元素。
5. **模数约束**：对大规模 N 取模输出。
