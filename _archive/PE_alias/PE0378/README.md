# 三角形三元组

来源：改编自 Project Euler Problem 378

## 原题意

三角形数 T(n)=n(n+1)/2，dT(n) 为 T(n) 的约数个数。求满足 dT(i)>dT(j)>dT(k) (i<j<k) 的三元组数。PE 答案：147534623725724718 (n=6×10^7)。

## 题目

给定 n，求 Tr(n)。

## 数据范围

n ≤ 10^5

## 算法

### 方向一：预处理 + 顺序统计

预处理所有 dT(i) = d(T(i))。问题转化为：求数组中严格递减的长度为 3 的递增下标子序列数量。用两个 BIT：第一个统计 dT 值频数，第二个统计长度为 2 的递减对。

### 方向二：Fenwick 树（BIT）

从左到右扫描，用 BIT1 维护已出现的 dT 值的计数，BIT2 维护以某个值为较大元素的二元递减对数量。ans += BIT2.query(dT[i]-1)。

### 方向三：分治 / CDQ 分治

三维偏序问题：i<j<k 且 dT(i)>dT(j)>dT(k)。使用 CDQ 分治 O(n log² n)。

### 时间复杂度

O(n log n)。
