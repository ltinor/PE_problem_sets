# 数根时钟 (Digital Root Clocks)

来源：改编自 Project Euler Problem 315

## 原题意

两个数字时钟计算 $[A,B]$ 内所有质数的"数根"序列。Sam 的时钟每次完整关屏再显示；Max 的时钟只关闭不需要的数码管。求两者转换次数的差。PE 答案：13625242。

## 题目

输入 $A$ 和 $B$，计算区间内所有质数的 Sam 和 Max 时钟转换次数差。

## 数据范围

$1 \le A \le B \le 2 \times 10^7$，且 $B - A \le 2 \times 10^6$。

## 算法

### 方向一：七段数码管状态压缩 + 预处理

七段数码管共有 7 段（上、中、下、左上、右上、左下、右下），用 7 位掩码表示每个数字 0-9 的亮灭状态。

- 数字 0: 0111111 (0x3F)
- 数字 1: 0000110 (0x06)
- 数字 2: 1011011 (0x5B)
- 数字 3: 1001111 (0x4F)
- 数字 4: 1100110 (0x66)
- 数字 5: 1101101 (0x6D)
- 数字 6: 1111101 (0x7D)
- 数字 7: 0000111 (0x07)
- 数字 8: 1111111 (0x7F)
- 数字 9: 1101111 (0x6F)

Sam 的时钟：显示每个数时，所有位段都先打开再关闭。若数字 $x$ 的段数为 $s(x)$，则 $x$ 的开启消耗 $s(x)$，关闭消耗 $s(x)$，共 $2s(x)$。

Max 的时钟：只关闭不需要的段。从状态 $a$ 变为状态 $b$ 的消耗 = $\text{popcount}(a \oplus b)$（异或后 1 的个数）。

对于数根序列 $n \to d_1 \to d_2 \to \dots \to d_k$（$d_k$ 为一位数且 $d_k = d_{k-1}$ 时停止），分别计算两种策略的总消耗。

### 方向二：Fast 数字根

数字根 = $1 + (n-1) \bmod 9$。数根序列中忽略重复的最后一项。

对每个质数 $p$：
- Sam: 对所有显示的数，每位数码管段数 × 2 之和（包括最后的关屏）。
- Max: 相邻显示之间的 Hamming 距离（段掩码异或的 popcount）之和。

### 方向三：批量筛法 + 逐数处理

用线性筛或埃氏筛生成 $[A,B]$ 内所有质数。对每个质数计算数根序列，累加 Sam 和 Max 的消耗。复杂度 $O((B-A) \log \log B + (B-A) \cdot d)$，$d$ 为数字位数。

### 时间复杂度

筛法 $O(B \log \log B)$，若 $B \le 2 \times 10^7$，可在 0.5s 内完成。逐质数处理：质数密度约 $1/\ln B \approx 5\%$，处理量约 $10^5$，极快。
