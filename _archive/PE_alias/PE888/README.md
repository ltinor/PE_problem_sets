# PE888 — 1249 Numbers（1249数）

来源：改编自 Project Euler Problem 888

## 原题意

"1249 数"是指十进制表示中仅由数字 1、2、4、9 组成的整数。

问题涉及统计或求和在某个范围内所有 1249 数的某种属性（计数、求和、满足整除性条件等）。

## 算法

1. **组合计数**：
   - $d$ 位 1249 数的个数为 $4^d$
   - 每位有 4 种选择（1、2、4、9），首位不能为 0 自动满足

2. **数位 DP**：
   - 对于上界 $N$，使用数位 DP 统计不超过 $N$ 的 1249 数
   - 状态：(位置, 是否受限)

3. **求和公式**：
   - $d$ 位 1249 数的和 = $16 \cdot 4^{d-1} \cdot \frac{10^d - 1}{9}$
   - 每位数字的期望贡献均等

4. **模运算**：
   - 所有计算在模 $M = 10^9 + 7$ 下进行
