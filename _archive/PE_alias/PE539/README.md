# PE539 - 奇流数 (Odd Streaming Numbers)

来源：改编自 Project Euler Problem 539

## 原题意

考虑所有正奇数的无穷序列：$1, 3, 5, 7, 9, 11, \ldots$。
应用以下筛选过程（类似于幸运数筛法，但从奇数开始）：
- 第 1 步：初始序列为所有 $\ge 1$ 的奇数。
- 第 k 步（$k \ge 2$）：取当前序列中第 k 个存活的数（记为 $p$），然后删除序列中所有位置是 $p$ 的倍数的数。

设 $P(n)$ 为筛选中最终剩余的数中不超过 $n$ 的所有数之和。
求 $P(4 \times 10^7)$。

PE 答案：134426190。

## 题目

给定 N，计算筛选过程后所有不超过 N 的幸存奇数之和。

## 算法

- 模拟幸运数筛法（从奇数开始）：
  1. 初始化序列为 $[1, 3, 5, \ldots, N]$（所有不超过 N 的奇数）。
  2. 从第 2 步开始（索引 1，即值为 3 的数）：设当前步的"筛数"为 $p = \text{seq}[\text{step}]$。
  3. 删除序列中位置为 $p, 2p, 3p, \ldots$ 的元素。
  4. 步数递增，重复直到筛数超过序列长度。
- 时间复杂度：$O(N \log N)$ 量级（对于 N=100 级别可行）。

## 改编方向

1. **不同起始序列**：从偶数开始、从完全平方数开始等。
2. **不同删除规则**：删除位置满足 $i \equiv 0 \pmod p$ 的数，或删除值满足条件的数。
3. **乘积而非求和**：计算幸存数的乘积。
4. **第 k 个幸存数**：求第 k 个幸存数而非求和。
