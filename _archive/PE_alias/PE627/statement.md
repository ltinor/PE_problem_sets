# 乘积计数

## 题目描述

记 S 为所有 n 个不超过 m 的正整数连乘的乘积所构成的集合，即：

S = {x₁ × x₂ × ... × xₙ | 1 ≤ x₁, x₂, ..., xₙ ≤ m}

记 F(m,n) 为 S 中不同元素的个数（重复的乘积只计一次）。

例如，F(9,2) = 36，F(30,2) = 308。

求 F(30, 10001)，并将答案对 1,000,000,007 取模。

## 输入格式

一行，字符串 `PE` 或 `verify` 或 `compute`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案（取模后的值）。

若输入为 `verify`，输出 F(9,2) 及小规模验证结果。

若输入为 `compute`，计算 F(9,2)。

## 样例

### 输入
```
PE
```

### 输出
```
1619163
```

## 数据范围

- 完整问题：m = 30，n = 10001
- 验证模式：m ≤ 9，n ≤ 3
- 取模：1,000,000,007
