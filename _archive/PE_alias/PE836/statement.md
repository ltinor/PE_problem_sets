# 混乱中的信息（A Message in a Mess）

## 题目描述

在一个博物馆里，一些珍贵的卷轴（scrolls）被混杂在一起。每个卷轴上写着一个大写字母（'A' 到 'Z'）。策展人需要重新排列这些卷轴，使它们按照字母顺序排列。

然而，由于卷轴非常脆弱，在移动时，你只能进行一种操作：选择两个相邻的卷轴，并将它们交换位置。

假设有 N 个卷轴，你需要通过交换相邻卷轴的操作，将它们重新排列成非递减顺序（即按字母顺序排列）。交换操作有一个特殊的成本规则：每次交换两个相邻的字母，成本取决于这两个字母。成本表由字母之间的距离（字符编码差的绝对值）决定。

请找出将所有 N 个卷轴排序所需的最小总成本。

## 输入格式

无输入（固定参数问题）。

## 输出格式

输出一个字符串（或数值），表示最终的 PE 答案。
