# 积分融合（Integral Fusion）

## 题目描述

定义**融合积分** $F(a, b, c) = \int_0^1 x^a (1-x)^b (-\ln x)^c \, dx$，其中 $a, b, c$ 为非负整数。

已知当 $c = 0$ 时，$F(a, b, 0) = \frac{a! \, b!}{(a+b+1)!}$（Beta 积分）。当 $c > 0$ 时，其结果可表示为有理数乘以特殊常数的线性组合。

若对某个三元组 $(a, b, c)$，$F(a, b, c)$ 乘以某个规范化因子后成为整数，则称该三元组是"融合积分"的。求所有满足 $a + b + c \leq N$ 的融合积分三元组对应的整数之和。

## 输入格式

无输入（固定参数问题）。

## 输出格式

输出一个整数，表示所求之和。
