# PE723 — Pythagorean Quadrilaterals (毕达哥拉斯四边形)

来源：改编自 Project Euler Problem 723

## 原题意

若四边形 $ABCD$ 的四边长分别为 $a,b,c,d$，内接于半径为 $r$ 的圆，且满足 $a^2+b^2+c^2+d^2=8r^2$，则称之为**毕达哥拉斯四边形**。

如果该四边形的四个顶点都在格点上，且到原点 $O$ 的距离均为 $r$，则称之为**毕达哥拉斯格点四边形**。

定义 $f(r)$ 为内接于半径为 $r$ 的圆的格点四边形的个数。已知：
- $f(1)=1,\;f(\sqrt{2})=1,\;f(\sqrt{5})=38,\;f(5)=167$

定义 $S(n)=\sum_{d\mid n}f(\sqrt{d})$。已知：
- $S(325)=S(5^2\cdot 13)=2370$
- $S(1105)=S(5\cdot 13\cdot 17)=5535$

求 $S(5^6\cdot 13^3\cdot 17^2\cdot 29\cdot 37\cdot 41\cdot 53\cdot 61)$。

PE 答案：1390820171。

## 算法

1. **等价条件**：对于按角度排序的凸四边形顶点 $\mathbf{v}_1,\mathbf{v}_2,\mathbf{v}_3,\mathbf{v}_4$，条件 $a^2+b^2+c^2+d^2=8r^2$ 等价于 $(\mathbf{v}_1+\mathbf{v}_3)\cdot(\mathbf{v}_2+\mathbf{v}_4)=0$。

2. **格点枚举**：对每个除数 $d$，找出所有满足 $x^2+y^2=d$ 的整数格点。由于所有质因数 $\equiv 1\pmod 4$，每个除数都可表示为两平方和。格点数为 $r_2(d)=4\tau(d)$。

3. **按角度排序**：将格点按极角排序后，凸四边形由四个位置 $i<j<k<l$ 唯一确定，条件为 $(x_i+x_k)(x_j+x_l)+(y_i+y_k)(y_j+y_l)=0$。

4. **四重循环枚举**：对每个除数 $d$（最多 2688 个），枚举四个格点位置。格点数最大为 $4\tau(n)=10752$，四重循环为 $O(m^4)$ 不可行，但大部分除数的格点数远小于此上限。

5. **复杂度**：对大规模除数需优化（如使用角度公式 $\sum\cos\Delta\theta_i=0$ 的组合计数），小规模除数直接暴力。

## 改编方向

1. 改变素数集合（使用不同的 $\equiv 1\pmod 4$ 质数组合）
2. 推广到 $n$ 边形（如五边形、六边形）
3. 计数非凸四边形（自交四边形）
4. 使用不同的几何条件（如 $a^2+b^2+c^2+d^2=k r^2$）
