# PE768 — Chandelier（吊灯）

来源：改编自 Project Euler Problem 768

## 原题意

一个吊灯有 $N$ 个呈圆形排列的灯座，每个灯座上可以放置不同颜色或类型的蜡烛。由于吊灯可以从不同角度观看，绕中心旋转后相同的布局视为同一种。有时还需要考虑镜像对称（翻转）。

问题要求：在给定约束下（如相邻灯座不能同时点亮、蜡烛数量限制等），计算本质不同的吊灯布局数量。

涉及 Burnside 引理 / Pólya 计数定理，用于计算具有对称性的环形排列（项链/手镯问题）。

PE 答案：789215551。

## 算法

1. **欧拉函数**：计算 $\phi(d)$ 用于 Burnside 引理中的旋转求和。
2. **Burnside 引理**：项链数 $= \frac{1}{N} \sum_{d|N} \phi(d) \cdot 2^{N/d}$（二元情况）。
3. **手镯数**：在项链基础上加入反射对称 $= \frac{1}{2N}(\sum_{d|N} \phi(d) \cdot 2^{N/d} + N \cdot 2^{\lceil N/2 \rceil})$。
4. **相邻约束**：使用 Fibonacci 递推处理无相邻点亮的线性/环形问题。
5. **约束 + 对称**：结合 Burnside 和组合约束，对每个旋转因子处理局部约束。

## 改编方向

1. 推广到多种蜡烛颜色（C 种颜色，Q 种类型）
2. 加入层级结构（多层吊灯）
3. 约束推广到距离 > 1 的排斥规则
4. 三维球面布局（足球/富勒烯）
5. 带权重的计数（每种配置有权重）
