# 变种考拉兹序列 (A Modified Collatz sequence)

来源：改编自 Project Euler Problem 277

## 原题意

求最小的 $a_1 > 10^{15}$ 使得其操作序列以 "UDDDUdddDDUDDddDdDddDDUDDdUUDd" 开头。PE 答案：1125977393124310。

## 题目

输入操作序列 $S$ 和阈值 $T$，输出最小的 $a_1 > T$ 满足条件。

## 数据范围

$1 \le |S| \le 100$，$0 \le T \le 10^{15}$。

## 算法

### 方向一：逆向递推 + 中国剩余定理 (CRT)

从 $S$ 的末尾向前逆向处理每一步操作。每一步对 $a_i$ 施加模约束：

- **D 的逆**：$a_i = 3a_{i+1}$，自动满足 $a_i \equiv 0 \pmod 3$。
- **U 的逆**：需 $a_{i+1} \equiv 2 \pmod 4$，然后 $a_i = (3a_{i+1}-2)/4$。
- **d 的逆**：需 $a_{i+1}$ 为奇数，然后 $a_i = (3a_{i+1}+1)/2$。

每步用 CRT 合并模约束，最终得到 $a_1 \equiv R \pmod M$。答案为满足该同余且 $> T$ 的最小整数。

### 方向二：正向搜索（暴力，仅适用于小数据）

从小阈值开始枚举 $a_1$，正向模拟检验前缀是否匹配。仅适用于 $T$ 较小时验证。

### 方向三：正向分式表示

正向推导 $a_{m+1} = (A \cdot a_1 + B) / 3^m$，结合反向约束确定 $a_1$。本质与方向一等价，但公式化程度更高。

### 时间复杂度

$O(|S|)$，逆向一次扫描即可。
