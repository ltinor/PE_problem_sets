# 费曼图

## 题目描述

在量子场论的微扰理论中，费曼图（Feynman diagram）用来表示粒子相互作用的项。每个费曼图由顶点和连接顶点的边（传播子）组成。

本题要求：在给定条件下（如固定顶点数、圈数等），计算满足条件的费曼图总数。

关键概念：
- **维克收缩**：将 $2n$ 个场算子配对的方法数为 $(2n-1)!!$
- **连通图**：所有顶点通过边连通的图
- **真空图**：没有外部腿的费曼图
- **生成函数**：$Z = \exp(F)$，$F$ 为所有连通图的生成函数

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 322512059。
- `verify`：输出维克收缩数、Catalan 数、$\varphi^3$ 和 $\varphi^4$ 理论的连通真空图数量。
- `compute`：分析答案的因子分解，探索与已知序列的关系。

## 样例

### 输入
```
PE
```

### 输出
```
322512059
```

### 验证
```
verify
```

输出内容包括：
- $(2n-1)!!$ 前 10 项
- Catalan 数前 13 项
- $\varphi^4$ 与 $\varphi^3$ 连通真空图数量
- 各类图的累计统计

## 数据范围

- 验证范围：$n \le 12$（精确可计算）
- 完整问题：PE 答案 $322512059 \approx 3.23 \times 10^8$
