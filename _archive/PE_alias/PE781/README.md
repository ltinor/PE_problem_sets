# PE781 — Feynman diagram（费曼图）

来源：改编自 Project Euler Problem 781

## 原题意

在量子场论中，费曼图表示散射振幅的微扰展开项。问题要求计算或统计特定约束下的费曼图数量，例如给定顶点数、圈数或外部腿数。

PE 答案：322512059（约 $3.23 \times 10^8$）。

## 算法

1. **维克收缩（Wick contractions）**：将 $2n$ 个外部点完全配对的方法数为 $(2n-1)!!$。
2. **连通图与不连通图**：$\varphi^4$ 理论中连通真空图的数量满足递推关系。
3. **生成函数方法**：配分函数 $Z = \exp(F)$，其中 $F$ 为连通图的生成函数。
4. **Catalan 数**：$C_n = \frac{(2n)!}{n!(n+1)!}$，与平面费曼图（非交叉配对）有关。
5. **$\varphi^3$ 与 $\varphi^4$ 理论**：不同相互作用顶点产生不同类型的费曼图。

## 改编方向

1. 推广到含有不同种类顶点（如 $\varphi^3 + \varphi^4$）的混合理论
2. 计算给定圈数下的费曼图数量
3. 考虑带外部腿的非真空图
4. 限制图的对称性（如平面图、无蝌蚪图等）
5. 计算费曼图的组合权值（考虑对称因子）
