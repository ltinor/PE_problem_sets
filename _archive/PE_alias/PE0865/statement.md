# 万亿Zeckendorf表示（Trillion Zeckendorf Representation）

## 题目描述

Zeckendorf 定理：每个正整数可以唯一地表示为若干个不相邻的斐波那契数之和（规定使用 $F_2 = 1, F_3 = 2, F_4 = 3, F_5 = 5, \ldots$，不使用 $F_1 = 1$）。

对于 $1$ 到 $10^{12}$（一万亿）之间的每个整数，计算其 Zeckendorf 表示中所用斐波那契数的个数。求所有整数表示中项数的期望值（算术平均值）。

## 输入格式

无输入（固定参数问题）。

## 输出格式

输出一个浮点数，保留 9 位小数。

## 样例

（无样例输入输出，直接计算并输出最终答案。）
