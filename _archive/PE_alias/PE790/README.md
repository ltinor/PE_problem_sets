# PE790 — Clock Grid（时钟网格）

来源：改编自 Project Euler Problem 790

## 原题意

考虑一个由时钟组成的网格。每个时钟有一个读数（0 到某模数），代表角度或时刻。网格按照某种规则演化（例如，每个时钟根据其邻居的读数更新自己）。问题可能需要求经过若干步后的状态、可到达状态的数量，或所有时钟对齐所需步数。

PE 答案：73597483551591773（约 $7.36 \times 10^{16}$）。

## 算法

1. **加性元胞自动机**：每个时钟的更新规则是邻居状态之和（模 $M$），构成线性系统。
2. **周期分析**：由于状态空间有限（$M^{nm}$），系统必然进入循环，可计算周期。
3. **状态空间维度**：可达状态数量由更新矩阵（模各素因子）的秩决定。
4. **Lights Out 变体**：当 $M=2$ 时，退化为经典的 Lights Out 游戏。

## 改编方向

1. 推广到非正交邻居（如六边形网格、三角形网格）
2. 不同模数混合（每个时钟可能有不同的模数）
3. 带随机扰动的异步更新
4. 求使所有时钟归零的最小步数（最短路径问题）
5. 引入中国剩余定理：各时钟的模数是不同素数的乘积
