# PE455 - 尾数幂 (Powers with trailing digits)

来源：改编自 Project Euler Problem 455

## 原题意

f(n) = 最大正整数 x < 10^9 使得 nˣ 的末 9 位恰好等于 x。如果不存在则 f(n)=0。

例如：f(4)=411728896, f(10)=0, f(157)=743757。

验证：Σ_{n=2}^{1000} f(n) = 442530011399。

原题求 Σ_{n=2}^{10^6} f(n) = 450186511399999。

## 题目

给定 n 求 f(n)；或给定 N 求 Σ_{n=2}^N f(n)。

## 算法

- 解同余方程 nˣ ≡ x (mod 10^9)
- 利用中国剩余定理分别解 mod 2^9 和 mod 5^9
- 对于奇 n：使用 Hensel 引理从 mod 2 提升到 mod 2^9
- 对于与 5 互质的 n：从 mod 5 提升到 mod 5^9
- 对于有公因子的情况特殊处理

## 改编方向

1. **不同模数**：末 k 位而非 9 位
2. **最小解**：求最小的满足条件的 x
3. **双参数**：nˣ ≡ y (mod 10^k) 且 nʸ ≡ x (mod 10^k)
