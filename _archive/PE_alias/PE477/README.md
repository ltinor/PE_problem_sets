# PE477 - 数列游戏

来源：改编自 Project Euler Problem 477

## 原题意

数列游戏：N 个数排成一行。两名玩家轮流从两端取数，每人都试图最大化自己的总得分。

序列 S 定义：s₁ = 0，s_{i+1} = (s_i² + 45) mod 1,000,000,007。

记 F(N) 为双方都采用最优策略时玩家 1 的得分。

已知：F(2)=45，F(4)=4284990，F(100)=26365463243，F(10⁴)=2495838522951。

求 F(10⁸)。PE 答案：25044905874565165。

## 题目

给定 N，求 F(N)。

## 算法

- 经典的两端取数博弈，标准 O(N²) DP
- dp[l][r] = max(S[l] + total[l+1..r] - dp[l+1][r], S[r] + total[l..r-1] - dp[l][r-1])
- N=10⁸ 太大无法 DP，需利用序列的伪随机特性
- 序列由二次递推生成，值在模数范围内均匀分布
- 大 N 下最优策略近似于"每次取较大端"，可用数学推导

## 改编方向

1. **不同序列生成**：改变递推公式
2. **三人游戏**：三个玩家轮流取
3. **取中间**：可选任意位置的数
4. **得分计算**：改为差值而非总和
