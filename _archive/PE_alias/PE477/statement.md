# 数列游戏

## 题目描述

数列游戏从写成一行的 $N$ 个数组成的序列 $S$ 开始。

两名玩家轮流进行游戏。在自己的回合，玩家必须选择并擦去剩余数列的**第一个**或**最后一个**数。

玩家的得分是他选择的所有数的和。每个玩家都试图**最大化自己的得分**。

序列 $S = \{s_1, s_2, \dots, s_N\}$ 的定义如下：
- $s_1 = 0$
- $s_{i+1} = (s_i^2 + 45) \bmod 1\,000\,000\,007$

记 $F(N)$ 为双方都采用最优策略时玩家 1 的得分。

已知：
- $F(2) = 45$
- $F(4) = 4\,284\,990$
- $F(100) = 26\,365\,463\,243$
- $F(10^4) = 2\,495\,838\,522\,951$

---

## 输入格式

一个整数 $N$。

---

## 输出格式

一个整数，表示 $F(N)$。

---

## 样例

### 输入
```
2
```

### 输出
```
45
```

---

## 数据范围

- 对于 30% 数据：$N \le 100$
- 对于 60% 数据：$N \le 2000$
- 对于 100% 数据：$N \le 10^8$
