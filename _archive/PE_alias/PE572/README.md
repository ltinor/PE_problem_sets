# PE572 - 幂等矩阵 (Idempotent Matrices)

来源：改编自 Project Euler Problem 572

## 原题意

设 M 为所有 3×3 矩阵的集合，其中每个元素 aᵢⱼ 属于集合 S = {-1, 0, 1}。称矩阵 A 是幂等的，若 A² = A。

求满足 A² = A 且迹（对角线元素之和）tr(A) ≤ 2 的矩阵个数。

此题在原始 PE 中涉及高斯整数环 ℤ[i] 上的矩阵计数，矩阵元素取自更广泛的集合。

PE 答案：197376647192681。

## 算法

幂等矩阵的特征值满足 λ² = λ，因此 λ ∈ {0, 1}。迹 = Σλᵢ，而 tr(A) ≤ 2 意味着最多两个特征值为 1。

对于 {-1, 0, 1} 上的矩阵：
- 暴力枚举 3⁹ = 19683 种可能的矩阵
- 对每个矩阵检查 A² = A（9 个等式）
- 检查迹 ≤ 2

对于 ℤ[i] 上的完整问题，矩阵元素取自更丰富的集合，需要利用幂等矩阵的结构性质进行组合计数。

## 改编方向

1. 将矩阵大小扩展到 n×n，研究计数公式的渐近行为。
2. 限制矩阵元素为其他有限集合，分析计数变化。
3. 研究迹的不同约束条件（如 tr(A) = 0, 1, 2, 3 分别计数）。
