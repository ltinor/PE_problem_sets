# PE797 — Cyclogenic Polynomials（循环多项式）

来源：改编自 Project Euler Problem 797

## 原题意

首一多项式（monic polynomial）是最高次项系数为 1 的多项式。若存在首一整系数多项式 $q(x)$ 和正整数 $n$ 使得 $p(x)q(x) = x^n - 1$，则称 $p(x)$ 为成圆多项式（cyclogenic）。若 $n$ 是最小的满足条件的正整数，则称 $p(x)$ 是 $n$-成圆多项式。

定义 $P_n(x)$ 为所有 $n$-成圆多项式的和，$Q_N(x) = \sum_{n=1}^N P_n(x)$。已知 $Q_{10}(2) = 5598$，求 $Q_{10^7}(2) \bmod 1{,}000{,}000{,}007$。

PE 答案：16436913。

## 算法

1. **分圆多项式分解**：$x^n - 1 = \prod_{d|n} \Phi_d(x)$，其中 $\Phi_d$ 为分圆多项式。
2. **子集与 LCM**：$n$-成圆多项式等价于 $\prod_{d \in S} \Phi_d(x)$，其中 $S \subseteq D(n)$ 且 $\text{LCM}(S) = n$。
3. **莫比乌斯反演**：$P_n(2) = \sum_{k|n} \mu(n/k) \cdot F(k)$，其中 $F(k) = \prod_{d|k} (1 + \Phi_d(2))$。
4. **前缀和优化**：$Q_N(2) = \sum_{k=1}^N F(k) \cdot M(N/k)$，其中 $M(x) = \sum_{m=1}^x \mu(m)$ 为 Mertens 函数。
5. **高效计算**：预处理素数筛、莫比乌斯函数、Mertens 前缀和，以及在模意义下递推计算 $\Phi_d(2)$。
