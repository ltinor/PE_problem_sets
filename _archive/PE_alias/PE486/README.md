# PE486 - 类回文序列

来源：改编自 Project Euler Problem 486

## 原题意

$F_5(n)$ 是满足某种回文相关性质的序列个数。涉及二进制字符串的特定结构。

PE 答案：1140845050。

## 题目

给定 n，计算满足类回文性质的二进制字符串个数。

## 算法

- 回文序列的递推结构
- 使用 DP：dp[n] 表示长度为 n 的类回文序列个数
- 递推关系可能涉及二项式系数或 Catalan 数
- 可使用矩阵快速幂优化到 O(log n)

## 改编方向

1. **不同字母表大小**：k 元字母表
2. **不同回文定义**：近似回文、k-回文
3. **计数子序列**：子序列中的回文数量
4. **多维回文**：二维回文矩阵
