# 类回文序列

## 题目描述

定义 $F_5(n)$ 为长度为 $n$ 的满足某种"类回文"性质的二进制字符串个数。

类回文性质定义为：字符串在某种变换下成为回文串。

给定 $n$，求 $F_5(n)$。

---

## 输入格式

一个整数 $n$。

---

## 输出格式

一个整数，表示 $F_5(n)$。

---

## 样例

### 输入
```
3
```

### 输出
```
...
```

---

## 数据范围

- 对于 30% 数据：$n \le 10$
- 对于 60% 数据：$n \le 30$
- 对于 100% 数据：$n \le 10^5$
