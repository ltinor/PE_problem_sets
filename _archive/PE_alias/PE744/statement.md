# 什么？哪里？何时？

## 题目描述

"什么？哪里？何时？"（Что? Где? Когда?）是一款专家与观众对抗的问答类真人秀电视节目。

节目规则如下：

1. 初始有 $2n+1$ 个信封，其中 $2n$ 个装有**问题**，1 个装有**红牌**
2. 每轮从剩余信封中**均匀随机**抽取一个：
   - 抽到**红牌** → 游戏**非正常结束**（无人获胜）
   - 抽到**问题** → 专家回答。专家答对的固定概率为 $p$：
     - 答对 → 专家得 1 分
     - 答错 → 观众得 1 分
3. 如果红牌一直未被抽到，当专家或观众**任意一方先获得 $n$ 分**时，游戏**正常结束**

定义 $f(n,p)$ 为游戏正常结束（即结束前未抽到红牌）的概率。

已知：
- $f(6, \frac{1}{2}) = 0.2851562500$
- $f(10, \frac{3}{7}) = 0.2330040743$
- $f(10^4, 0.3) = 0.2857499982$

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出原题答案 `8.56605648`
- `verify`：展示精确概率公式及小规模验证
- `compute`：输出最终答案

## 样例

### 输入
```
PE
```

### 输出
```
8.56605648
```

### 公式推导

设 $T$ 为有人达到 $n$ 分时已处理的问题数（$n \le T \le 2n-1$），红牌在 $2n+1$ 个位置中均匀分布：

$$f(n,p) = \sum_{t=n}^{2n-1} \binom{t-1}{n-1}\left[p^n(1-p)^{t-n} + (1-p)^n p^{t-n}\right] \cdot \frac{2n+1-t}{2n+1}$$

第一项为专家在第 $t$ 题达到 $n$ 分，第二项为观众达到。

## 数据范围

- 验证范围：$n \le 10$（精确二项式计算）
- 完整问题：$n = 10^{11}, p = 0.4999$
- 答案精度：保留小数点后 10 位（输出 8 位有效数字）
