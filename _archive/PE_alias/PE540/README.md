# PE540 - 勾股三元组计数 (Counting Pythagorean Triples)

来源：改编自 Project Euler Problem 540

## 原题意

勾股三元组 $(a, b, c)$ 满足 $a < b < c$ 且 $a^2 + b^2 = c^2$。三元组是本原的当且仅当 $\gcd(a, b, c) = 1$。

本原勾股三元组可由欧几里得公式生成：
$$a = m^2 - n^2, \quad b = 2mn, \quad c = m^2 + n^2$$
其中 $m > n > 0$，$\gcd(m, n) = 1$，且 $m - n$ 为奇数。

设 $F(N)$ 为满足 $\max(a, b) \le N$ 的所有（包括非本原）勾股三元组 $(a, b, c)$ 的个数。非本原三元组是本原三元组的整数倍：$(ka, kb, kc)$，其中 $k \ge 1$。

求 $F(10^6)$。

PE 答案：500000000210。

## 题目

给定 N，计算所有满足 $\max(a, b) \le N$ 的勾股三元组 $(a, b, c)$（$a < b < c$）的个数。

## 算法

- 枚举所有本原三元组的生成参数 $(m, n)$：
  - 对于每个满足条件的 $(m, n)$，生成本原三元组 $(a_0, b_0, c_0)$。
  - 对于每个倍数 $k \ge 1$，$(ka_0, kb_0, kc_0)$ 也是合法的三元组。
  - 约束条件：$\max(ka_0, kb_0) = k \cdot b_0 \le N$，即 $k \le \lfloor N / b_0 \rfloor$。
  - 累计 $\lfloor N / b_0 \rfloor$ 到答案中。
- 时间复杂度：$O(N)$（枚举所有 $m, n$ 使得 $2mn \le N$）。

## 改编方向

1. **不同约束**：要求 $c \le N$（斜边不超过 N）、$a + b + c \le N$（周长不超过 N）。
2. **统计面积/周长**：求所有三元组的面积之和或周长之和。
3. **广义勾股数**：$a^2 + b^2 = c^2 + 1$ 等变体。
4. **高维扩展**：$a^2 + b^2 + c^2 = d^2$ 的四元组计数。
