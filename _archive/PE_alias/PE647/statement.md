# PE 647 — Linear Transformations of Polygonal Numbers（多边形数线性变换）

## 题目描述

对于给定的奇数 k，记第 n 个 k 边形数为 P_k(n) = ½ n(n(k-2) + 4 − k)，n ≥ 1。k = 3 时为三角形数。

若存在正整数 A、B 使得对任意 n ≥ 1，A·P_k(n) + B 仍为 k 边形数，则称 (A,B) 为一个有效对。

F_k(N) 表示所有满足 max(A, B) ≤ N 的有效对 (A,B) 的 (A+B) 之和。

## 已知数据

- F₃(100) = 184
- Σ_{k=3,5,7,…} F_k(10³) = 14993

## 求解

对所有奇数 k = 3, 5, 7, …，求 Σ_k F_k(10¹²)。

## 数据范围

- N = 10¹²
- k 为大于等于 3 的奇数
