# PE806 — Nim on a Triangular Grid（三角网格Nim）

来源：改编自 Project Euler Problem 806

## 原题意

在一个由 $n$ 行组成的三角形网格上（第 $i$ 行有 $i$ 个格子，共 $n(n+1)/2$ 个格子），每个格子可以放若干枚代币。两名玩家轮流操作：选择一个格子，从中移走若干枚代币，然后将移走的代币任意分配给该格子下方的两个格子（若存在）。无法操作者输。

求在特定初始条件下，先手必败的代币配置方案数。

PE 答案：773410946。

## 算法

1. **计算 Grundy 值**：从网格底部向上递推，每个格子的 Grundy 值为其两个子格子 Grundy 值可达组合的 MEX。
2. **Nim 和**：整个游戏的 Nim 和为所有格子 Grundy 值的异或。Nim 和为 0 时为 P 态（先手必败）。
3. **计数优化**：使用组合数学或 DP 统计满足 Nim 和为 0 的配置数。

## 改编方向

1. 推广到不同形状的网格（如六边形网格）
2. 允许代币向上移动
3. 更换为多玩家博弈

5. 扩展到连续代币数量（非离散）
