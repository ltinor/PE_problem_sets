# PE405 - 矩形铺砖

来源：改编自 Project Euler Problem 405

## 原题意

在长是宽两倍的矩形（2×1）上铺地砖。T(0) 为初始状态（一整块砖）。对于 n>0，T(n) 由 T(n-1) 的每块砖等分为 4 块更小的砖（排列为 2×2 网格）得到。

f(n) 表示 T(n) 中恰好四块地砖相遇的点的数量。
已知：f(0)=0，f(1)=0，f(2)=1，f(3)=7，f(4)=35。

原题求 Σ_{k=1}^{10^18} f(10^k) mod 17⁷，答案为 237696125。

## 题目

给定整数 n，求 f(n) mod 17⁷（17⁷=410338673）。

## 算法

- 递推关系：f(0)=f(1)=0，f(n)=4·f(n-1)+2^(n-1)-1（n≥2）
- 封闭形式：f(n) = (4^n - 3·2^n + 2) / 6
- 使用模运算：f(n) mod 17⁷ = (4^n - 3·2^n + 2) × inv(6) mod 17⁷
- 由于 gcd(6, 17⁷)=1，用扩展欧几里得求 inv(6)
- 时间复杂度 O(log n)（使用快速幂）

## 改编方向

1. **改变地砖形状**：使用不同长宽比的矩形砖
2. **改变分割规则**：将每块砖分为 k×k 块（k>2）
3. **计算多于四砖相遇的点**：如六砖或八砖相遇点
4. **改变模数**：使用不同的质数幂模数
5. **使用不同初始形状**：初始矩形不为 2×1
