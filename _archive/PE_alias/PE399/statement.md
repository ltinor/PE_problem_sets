# 无平方因子斐波那契数

## 题目描述

斐波那契数列：F1=1, F2=1, Fn=Fn-1+Fn-2 (n>2)。

无平方因子数：不能被任何大于 1 的完全平方数整除的正整数。

求第 K 个无平方因子的斐波那契数。输出格式：该数的最后 16 位数字，然后逗号，然后该数的科学计数法表示（四舍五入保留一位小数）。

---

## 输入格式

一个整数 K。

---

## 输出格式

格式：`最后16位,科学计数法`

---

## 样例

### 输入
```
200
```

### 输出
```
1608739584170445,9.7e53
```

---

## 数据范围

- 对于 30% 数据：K ≤ 200
- 对于 100% 数据：K ≤ 10^8
