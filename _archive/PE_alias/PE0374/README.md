# 整数分拆最大乘积

来源：改编自 Project Euler Problem 374

## 原题意

n 的不等分拆（distinct parts）中乘积最大值 f(n) 与分拆个数 m(n)。求 Σ f(n)·m(n), n=1..10^14 mod 982451653。PE 答案：334420941。

## 题目

给定 N，求 Σ_{n=1}^{N} f(n)·m(n) mod M。

## 数据范围

N ≤ 10^12, M = 982451653

## 算法

### 方向一：贪心构造 + 数学分析

最大乘积分拆由连续整数构成（从 2 开始），可能多出一个剩余值均匀分配到最大的几个数。f(n) 直接由构造得出，m(n) 为使用的整数个数。

### 方向二：分段求和

将 N 按分拆长度 k 分段。对于每个 k，n 的范围为 [T_k, T_{k+1})，其中 T_k = 2+3+...+(k+1) = k(k+3)/2。每段内 f(n) 和 m(n) 有规律，可用公式批量求和。

### 方向三：模运算优化

使用模逆元计算除法。分段后用等差数列/等比数列求和公式，O(√N) 完成。

### 时间复杂度

O(√N)。
