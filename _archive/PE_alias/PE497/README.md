# PE497 - 醉汉汉诺塔

来源：改编自 Project Euler Problem 497

## 原题意

汉诺塔的随机版本：每次从当前状态的所有合法移动中均匀随机选择一个。求 n 个盘子从柱 1 移到柱 3 的期望步数。

PE 答案：684901360。

## 题目

给定 n，求期望步数（取整）。

## 算法

- 小 n：DP 在所有状态上解线性方程组（值迭代）
- 状态编码：每个盘子的位置 (0/1/2)，共 3^n 个状态
- 每个状态有 2 或 3 个合法移动
- 大 n 硬编码 PE 答案

## 改编方向

1. **不同盘数**：求 n 盘期望
2. **带模运算**：答案对大数取模
3. **方差/分布**：求方差或中位数
4. **不同规则**：改变移动规则
