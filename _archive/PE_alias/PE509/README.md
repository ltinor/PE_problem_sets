# PE509 - 约数取石子游戏

来源：改编自 Project Euler Problem 509

## 原题意

三堆 Nim 变体：每次只能从一堆中取石子，且取的数量必须是该堆当前石子数的真约数。
S(n) = 1 ≤ a,b,c ≤ n 中必胜态的数量。
求 S(123456787654321) mod 1234567890。

PE 答案：151725678。

## 题目

给定 n，求所有堆大小在 [1, n] 范围内的三堆局面中，先手必胜的局面数量。答案对 1234567890 取模。

## 算法

- 发现 Grundy 数 G(x) = v₂(x)（2 的幂次）
- 证明：奇数只能取真约数（均为奇数），到达偶数局面；偶数可以取到更低的 v₂ 值
- 必胜态：G(a) ⊕ G(b) ⊕ G(c) ≠ 0
- 计数：cnt[g] = #{x∈[1,n] : v₂(x)=g}，g 最多 ~log₂(n)
- 必败态数 = Σ_{g1⊕g2⊕g3=0} cnt[g1]·cnt[g2]·cnt[g3]
- 必胜 = n³ - 必败

## 改编方向

1. **不同堆数**：k 堆而非 3 堆
2. **不同取法**：可以取约数的倍数等
3. **限制堆大小关系**：a ≤ b ≤ c
4. **不同模数**：改变取模值
