# PE612 — 朋友数 (Friend Numbers)

来源：改编自 Project Euler Problem 612

## 原题意

称两个数为朋友数，如果它们的十进制表示中至少有一位数字相同。例如，1123 和 3981 是朋友数。

令 f(n) 为满足 1 ≤ p < q < n 且 p 和 q 为朋友数的数对 (p,q) 的数量。已知 f(100)=1539。

求 f(10¹⁸) mod 1000267129。

PE 答案：819963842。

## 算法

1. **补集转换**：总数对 C(n-1,2)，非朋友数对定义为两数无公共数字。
2. **位掩码表示**：用 10 位二进制掩码表示一个数的数字集合。
3. 两数为非朋友数当且仅当其掩码不相交（按位与为 0）。
4. **数位 DP**：对 n = 10¹⁸（19 位十进制），计算所有 2¹⁰ = 1024 种掩码对应的数字个数。
5. 非朋友数对 = Σ_{A&B=0} cnt[A] × cnt[B]，则 f(n) = 总数对 - 非朋友数对。

状态设计：(位置, 掩码, 是否受限, 是否开始非零数字)，时间复杂度 O(位数 × 2¹⁰ × 10)。

## 改编方向

1. 改变进制（如二进制、十六进制）。
2. 改变"朋友"定义（如至少两个公共数字、数字和相等）。
3. 求 f(n) 对多个不同模数的结果。
4. 推广到 k 元组而非数对。
