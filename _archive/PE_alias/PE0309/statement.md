# 整数梯子

## 题目描述

在经典问题"穿越梯子"中，两架长度分别为 x 和 y 的梯子相对靠在一条狭长街道的两侧墙上。两架梯子相交处的高度为 h，街道宽度为 w。

四个变量满足关系式：

$$\\frac{1}{h} = \\frac{1}{\\sqrt{x^2 - w^2}} + \\frac{1}{\\sqrt{y^2 - w^2}}$$

我们只关心所有四个变量均为正整数的情况。给定 N，求满足 x < y < N 且能解出整数 w 的三元组 (x, y, h) 的个数。

---

## 输入格式

一行一个整数 N。

---

## 输出格式

一行一个整数，表示满足条件的三元组个数。

---

## 样例

### 输入
```
200
```

### 输出
```
5
```

---

## 数据范围

- $2 \\le N \\le 2 \\times 10^5$
