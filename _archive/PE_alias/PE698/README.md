# PE698 — 123 Numbers (123数)

来源：改编自 Project Euler Problem 698

## 原题意

定义"123数"为满足特定数字性质的十进制正整数。
具体定义可能为：
- 各位数字仅由 $1, 2, 3$ 组成；且/或
- 相邻数字满足某种递增/递减关系；且/或
- 子序列/子串中包含模式"123"。

求第 $k$ 个（或不超过某上界的）"123数"的某种统计量。

PE 答案：57808202。

## 算法

1. **数字 DP**：根据"123数"的具体定义设计状态机。
   - 若限定数字只含 $\{1,2,3\}$：逐位枚举，类似三进制。
   - 若需包含"123"作为子序列：使用自动机状态（是否已匹配 $1$、$12$、$123$）。

2. **组合计数**：对于给定的上限 $N$，统计满足条件的数字个数。
   使用数位 DP：
   $$dp[pos][state][tight]$$
   其中 $state$ 表示模式匹配的进度。

3. **效率**：数位 DP 的复杂度为 $O(\text{位数} \times \text{状态数} \times 10)$，非常高效。

## 改编方向

1. 参数化数字集合（如 $\{3,4,5\}$）
2. 改变模式（如"321"、"1234"等）
3. 求所有"123数"的和而非第 $k$ 个
4. 在不同进制下考虑
5. 添加更多约束（如数字和、乘积等）
