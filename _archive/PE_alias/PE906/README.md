# PE906 — A Collective Decision（集体决定）

来源：改编自 Project Euler Problem 906

## 原题意

三位投票者各有 $\{1,\ldots,n\}$ 的一个随机排列作为偏好序。当存在某个选项在所有两两比较中获得至少两票时，该选项胜出（Condorcet 胜者）。$P(n)$ 为存在 Condorcet 胜者的概率。

PE 答案：0.0000000000

## 算法

1. **组合计数**：
   - 对 $n \leq 5$ 可精确枚举所有 $n!^3$ 种投票组合
   - $P(3) = 204/216 = 17/18$

2. **蒙特卡洛模拟**：
   - 对中等 $n$ 使用随机抽样估计概率
   - 生成随机排列，构建偏好矩阵，检测 Condorcet 胜者

3. **渐近分析**：
   - $n \to \infty$ 时，Condorcet 胜者存在的概率指数衰减
   - $P(n) \approx C \cdot e^{-\alpha n}$

4. **极限行为**：
   - $P(20000)$ 在十位小数精度下为 $0.0000000000$

## 改编方向

1. 研究不同投票人数下的 Condorcet 胜者概率
2. 加权投票和偏好强度的推广
3. 放宽到 $\geq k/3$ 多数规则
4. 分析 Condorcet 循环（悖论）的概率
