# PE496 - 内心和外心

来源：改编自 Project Euler Problem 496

## 原题意

对于整数边长的三角形，考虑其内心 I 和外心 O。求满足某条件的三角形周长之和。

PE 答案：666577909。

## 题目

求所有边长均为不超过 N 的整数、且内切圆半径和外接圆半径均为整数的三角形的周长之和。

## 算法

- 枚举三边 a ≤ b ≤ c ≤ N，满足 a+b > c
- 海伦公式计算面积的平方，验证为完全平方数
- 计算 r = Δ/s 和 R = abc/(4Δ)
- 验证 r 和 R 均为整数
- 累加周长

## 改编方向

1. **不同条件**：仅要求内切圆半径整数
2. **计数而非求和**：统计三角形个数
3. **面积限制**：加入面积上限
4. **直角三角形**：仅限直角三角形
