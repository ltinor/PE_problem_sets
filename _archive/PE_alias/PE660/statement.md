# 全数字三角形

## 题目描述

若一个边长为整数的三角形有一个内角为 120°，且其三边长在 n 进制下恰好使用了全部 n 个数字各一次，则称该三角形为 n-全数字三角形。

例如，三角形 (217, 248, 403) 是 9-全数字三角形：
- 含有一个 120° 角（满足 403² = 217² + 248² + 217×248）
- 217 = 261₉，248 = 305₉，403 = 487₉，恰好使用 0-8 全部 9 个数字各一次

对于 9 ≤ n ≤ 18，求所有 n-全数字三角形中最长边的长度之和。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 400107221768。
- `verify`：验证已知样例（含 (217,248,403) 的 9-全数字检测）。
- `compute`：搜索 n=9..18 的全数字三角形并求和。

## 样例

### 输入
```
PE
```

### 输出
```
400107221768
```

## 数据范围

- n 范围：9 到 18
- 三角形边长可达 n^9 量级
- 120° 条件：c² = a² + b² + ab
