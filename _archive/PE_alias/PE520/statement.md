# 辛伯数

## 题目描述

一个正整数称为 **辛伯数**（Simber），如果其十进制表示中的各位数字从左到右非递减排列。即每一个数字都不小于其左边的数字。

例如：123、112、299、333、4、18 都是辛伯数；而 321、198、20 不是（20 中 0 < 2）。

给定 D，求所有不超过 10^D（即不超过 D 位）的辛伯数的总和。

## 输入格式

一个整数 D（1 ≤ D ≤ 40），或字符串 `PE`。

## 输出格式

一个整数，表示所有不超过 10^D 的辛伯数之和。

## 样例

### 输入
```
2
```

### 输出
```
1980
```

解释：不超过 100 的辛伯数有：
1 位数：1,2,3,4,5,6,7,8,9（和 45）
2 位数：11,12,13,14,15,16,17,18,19,22,23,24,25,26,27,28,29,33,34,35,36,37,38,39,44,45,46,47,48,49,55,56,57,58,59,66,67,68,69,77,78,79,88,89,99（和 1935）
总计：45 + 1935 = 1980。

## 数据范围

- 对于 30% 数据：D ≤ 3
- 对于 60% 数据：D ≤ 10
- 对于 100% 数据：D ≤ 40
