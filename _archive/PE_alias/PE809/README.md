# PE809 — Rational Polynomials（有理多项式）

来源：改编自 Project Euler Problem 809

## 原题意

给定一个有理函数 $R(x) = \frac{P(x)}{Q(x)}$（$P, Q$ 为整系数多项式），从某个有理初始值 $x_0$ 出发迭代 $x_{n+1} = R(x_n)$。研究序列 $\{x_n\}$ 的性质，如周期性、整数项、收敛行为等。

PE 答案：152246599。

## 算法

1. **Möbius 变换**：一次有理函数 $R(x) = \frac{ax+b}{cx+d}$ 对应于矩阵 $\begin{pmatrix} a & b \\ c & d \end{pmatrix}$，迭代对应于矩阵幂。
2. **不动点和周期点**：求解方程 $R^{(k)}(x) = x$。
3. **整数序列判定**：寻找使所有项为整数的初始值，涉及丢番图逼近。
4. **连分数**：有理函数的迭代与连分数展开密切相关。

## 改编方向

1. 研究二次及以上有理函数的迭代
2. 考虑 $p$-进数下的迭代行为
3. 统计满足特定整数条件的初始值数量
4. 研究吸引子和分形行为
5. 推广到多元有理函数系统
