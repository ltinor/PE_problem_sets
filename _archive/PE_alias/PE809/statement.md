# 有理多项式（Rational Polynomials）

## 题目描述

给定一个有理函数 $R(x) = \frac{P(x)}{Q(x)}$，其中 $P$ 和 $Q$ 是整系数多项式。从某个有理数 $x_0$ 出发，定义序列 $x_{n+1} = R(x_n)$（$n = 0, 1, 2, \dots$）。

研究该序列的性质：在特定条件下，统计满足某种性质（如所有项为整数、序列最终循环、收敛到特定值等）的初始值 $x_0$ 的数量或对其进行求和。

答案对 $1,000,000,007$ 取模。

## 输入格式

无输入（固定参数问题）。

## 输出格式

输出一个整数，表示统计结果对 $10^9+7$ 取模的值。

## 样例

（无样例输入输出，直接计算并输出最终答案。）
