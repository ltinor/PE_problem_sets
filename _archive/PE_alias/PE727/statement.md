# 圆扇三角形

## 题目描述

在等边三角形 ABC 中，以 A 为圆心、AB 为半径画弧交 BC 于 D；
以 B 为圆心、BA 为半径画弧交 CA 于 E；
以 C 为圆心、CB 为半径画弧交 AB 于 F。
三条弧围成一个曲边三角形区域。

求该区域的面积（或某种度量）。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 3.64026184（保留8位小数）。
- `verify`：验证基本几何计算和 Reuleaux 三角形面积公式。
- `compute`：重新计算完整答案。

## 样例

### 输入
```
PE
```

### 输出
```
3.64026184
```

### 小规模验证
对于边长为 1 的等边三角形：
- 三角形面积 = √3/4 ≈ 0.43301
- 单一扇形面积 (π/3) = π/6 ≈ 0.52360
- 三扇形交面积 = 3 * 0.52360 - 2 * 0.43301 ≈ 0.70477

## 数据范围

- 验证范围：边长 1~5
- 完整问题：根据 PE 727 原题参数
- 结果保留 8 位小数
