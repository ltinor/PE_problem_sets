# 配对抛掷硬币游戏

## 题目描述

n 名玩家循环进行两两对战。第 r 轮：玩家 ((r-1) mod n)+1 对阵 (r mod n)+1。
每轮公平硬币定胜负。某玩家若连续赢得其参加的两轮即获胜。

P_n(k) = 玩家 k 获胜概率（最简分数）。
M_n(k) = 分子 × 分母。

已知：
- P_3(1) = 12/49，M_3(1) = 588
- P_6(2) = 368/1323，M_6(2) = 486864

求 M_{10⁸+7}(10⁴+7) 的最后 8 位数字。

## 输入格式

一行，字符串 `PE` 或 `verify`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案：59992576（最后 8 位数字）。
若输入为 `verify`，验证已知的 P_3(1)、M_3(1)、P_6(2)、M_6(2)，并展示小规模概率。

## 样例

### 输入
```
PE
```

### 输出
```
59992576
```

## 数据范围

- 完整问题：n = 10⁸+7，k = 10⁴+7
- n 和 k 极大，需通过数学推导和模运算求解
- 验证模式仅适用于小 n（≤ 10）
