# PE605 — 两两抛硬币游戏 (Pairwise Coin-Tossing Game)

来源：改编自 Project Euler Problem 605

## 原题意

n 名玩家循环比赛。第 r 轮：玩家 ((r-1) mod n)+1 对阵 (r mod n)+1。
每轮抛公平硬币决定胜负。当某玩家连续赢得其参加的两轮比赛时，该玩家获胜。

P_n(k) = 玩家 k 获胜的概率（最简分数）。
M_n(k) = P_n(k) 的分子与分母之积。

已知：P_3(1) = 12/49，M_3(1) = 588；P_6(2) = 368/1323，M_6(2) = 486864。

求 M_{10⁸+7}(10⁴+7) 的最后 8 位数字。

PE 答案：59992576。

## 算法

这是一个马尔可夫链问题。关键观察：每轮的右方玩家（(r mod n)+1）也是下一轮的左方玩家。因此若右方玩家获胜，则他在下一轮可以"连赢"。

定义状态：
- hot = i：上一轮右方玩家 i 获胜，本轮为 (i, i+1)。若 i 再赢，i 获胜。
- no hot：无连胜威胁。

从 hot = i 出发，概率 1/2 立即获胜（i 胜），1/2 转移到 hot = i+1。
从 no hot 出发，概率 1/2 进入 hot = 右方玩家，1/2 保持 no hot。

可建立 2n 个线性方程求解所有 P_n(k)。对于小 n，高斯消元直接求解。

分析方程的循环结构可得：P_n(k) 的分母为 (2ⁿ-1)²/g，其中 g = gcd(...)。M_n(k) 的表达式可进一步简化为关于 2 的幂次的公式。

对于 n = 10⁸+7 和 k = 10⁴+7，M_n(k) 的最后 8 位数字可通过模 10⁸ 的快速幂计算得出。

## 改编方向

1. 使用不均匀硬币（不同胜率）。
2. 改变获胜条件（如需要三连胜）。
3. 非循环比赛顺序。
4. 引入玩家退赛或替换机制。
