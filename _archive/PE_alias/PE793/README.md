# PE793 — Median of Products（乘积中位数）

来源：改编自 Project Euler Problem 793

## 原题意

给定集合 $S = \{1,2,\dots,N\}$，考虑所有两两乘积 $a \times b$（其中 $1 \le a \le b \le N$），将它们排序后求中位数（第 $\lceil M/2 \rceil$ 小的值，其中 $M = N(N+1)/2$ 为总对数）。问题可能求某个 $N$ 的乘积中位数，或求多个 $N$ 的中位数之和。

PE 答案：4758086501311202972（约 $4.76 \times 10^{18}$）。

## 算法

1. **计数函数**：对给定 $x$，计算满足 $a \le b \le N$ 且 $ab \le x$ 的数对个数。对每个 $a$，$b$ 的取值范围为 $[a, \min(N, \lfloor x/a \rfloor)]$。
2. **二分答案**：利用计数函数的单调性，在 $[1, N^2]$ 上二分搜索第 $k$ 小的乘积。
3. **时间复杂度**：计数函数为 $O(N)$，二分 $O(\log N)$，总 $O(N \log N)$。可用数论分块优化至 $O(\sqrt{N})$。
4. **不同乘积个数**：去重后的乘积个数也可统计。

## 改编方向

1. 推广到三元乘积 $a \times b \times c$ 的中位数
2. 加权乘积（如 $w_a \cdot w_b$）的中位数
3. 求第 $k$ 小乘积（不一定是中位数）
4. 乘积的分布分析（均值、方差、分位数等）
5. 约束 $a,b$ 互质时的乘积中位数
