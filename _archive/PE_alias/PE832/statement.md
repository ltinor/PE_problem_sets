# 图腾铺砖（Totem Tiling）

## 题目描述

T-tetromino（T 形四格骨牌）是由 4 个单元格组成的如下形状：

```
###     .#.     #.     .#
.#.     ###     ##     ##
                #.     .#
```

现有 $H \times W$ 的矩形棋盘，问有多少种用 T-tetromino 恰好铺满整个棋盘的方式（不允许重叠、不允许超出边界）。旋转和翻转视为相同骨牌的不同放置方式。

## 输入格式

无输入（固定参数问题）。

## 输出格式

输出一个整数，表示不同铺砖方式的总数。

## 样例

（无样例输入输出，直接计算并输出最终答案。）
