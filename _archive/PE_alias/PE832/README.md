# PE832 — Totem Tiling（图腾铺砖）

来源：改编自 Project Euler Problem 832

## 原题意

用 T 形四格骨牌（T-tetromino，形状如"T"字）铺满一个矩形棋盘，问有多少种不同的铺砖方式。T-tetromino 由 4 个单元格组成：一行三格，中间格下方或上方再附一格（共 4 种旋转方向）。

由于 T 形骨牌不是简单的 domino，其铺砖计数是一个经典的组合枚举问题。对于小棋盘可以直接搜索，对于大棋盘需要使用状态压缩 DP 或转移矩阵方法。

PE 答案：595318643547。

## 算法

1. **精确覆盖（小棋盘）**：回溯搜索，尝试在每个空格放置 T 形骨牌的四种旋转。
2. **轮廓线 DP**：逐格扫描棋盘，用位掩码表示当前轮廓线上哪些格子已被填充；每格尝试放置 T 形骨牌。
3. **DP 状态**：轮廓线宽度为 $2W$ 位（当前行 $W$ 位 + 下一行 $W$ 位），逐列转移，行末将下一行轮廓提升为当前行。
4. **转移矩阵（大棋盘）**：对固定的宽度 $W$，可将一行到下一行的转移编码为矩阵，用矩阵快速幂加速。
