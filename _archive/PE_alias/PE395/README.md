# PE395 - 毕达哥拉斯树

来源：改编自 Project Euler Problem 395

## 原题意

毕达哥拉斯树分形的最小外接矩形面积。

## 题目

求 3-4-5 直角三角形的毕达哥拉斯树最小外接矩形面积。

## 算法

- 递归生成树的边界坐标
- 旋转/平移变换追踪每个正方形的角点
- 累积 min/max 的 x 和 y 坐标

## 改编方向

1. **改变三角形比例**：使用 a-b-c 比例的直角三角形，参数化
2. **不同方向**：直角三角形可以放在左侧或任意方向
3. **迭代深度**：给定深度 d，求 d 次迭代后的外接矩形面积
4. **外接圆**：求最小外接圆而非最小外接矩形
