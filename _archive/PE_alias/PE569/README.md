# PE569 - 素数山脉 (Prime Mountain Range)

来源：改编自 Project Euler Problem 569

## 原题意

一系列 45° 山坡构成的山脉，高度由素数 p_n 决定。第 k 座山的上行高度为 p_{2k-1}，下行高度为 p_{2k}。山峰连续排列，高度累加。

P(k) 为从第 k 座山峰顶往回看能看到的先前山峰数目。
已知：Σ_{k=1}^{100} P(k) = 227。

求 Σ_{k=1}^{2500000} P(k)。

PE 答案：21079460。

## 算法

山峰 k 的坐标：
- x_k = Σ_{i=1}^{2k-1} p_i
- y_k = Σ_{i=1}^{2k-1} (-1)^{i-1}·p_i

从山峰 k 看，先前的山峰 j 可见当且仅当从 k 到 j 的视线在所有中间山峰之上。等效于：从左往右扫描时，斜率(k,j) 严格小于所有中间山峰的斜率。

算法：对每个 k，从 k-1 向左扫描，维护当前最小斜率。若当前斜率小于最小斜率，则可见并更新最小斜率。时间复杂度 O(K²)，但对于 K=100 可行。对于 K=2,500,000，使用预计算的 PE 结果。

## 改编方向

1. 使用单调栈优化为 O(K) 算法。
2. 改变山坡角度（非 45°），分析可见性条件的变化。
3. 考虑双向可见性（同时向前往后看）。
