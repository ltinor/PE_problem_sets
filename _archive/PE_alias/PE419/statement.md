# 看图说话序列

## 题目描述

看图说话序列从 1 开始：1, 11, 21, 1211, 111221, 312211, ...

每项通过描述前一项的连续数字得到：
- 1 → "一个 1" → 11
- 11 → "两个 1" → 21
- 21 → "一个 2 和一个 1" → 1211

记 A(n), B(n), C(n) 分别表示第 n 项中数字 1、2、3 的数量。

已知 A(40)=31254, B(40)=20259, C(40)=11625。

给定 n，求 A(n), B(n), C(n)。若 n=10^12，答案需模 2^30。

---

## 输入格式

一个整数 n。

---

## 输出格式

三个整数 A, B, C，用逗号分隔。

---

## 样例

### 输入
```
5
```

### 输出
```
3,1,1
```

### 输入
```
40
```

### 输出
```
31254,20259,11625
```

---

## 数据范围

- 对于 30% 数据：n ≤ 20
- 对于 60% 数据：n ≤ 40
- 对于 100% 数据：n ≤ 10^12
