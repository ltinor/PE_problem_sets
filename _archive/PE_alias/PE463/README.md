# PE463 - 怪异递推 (A weird recurrence)

来源：改编自 Project Euler Problem 463

## 原题意

定义函数 f：
- f(1) = 1, f(3) = 3
- f(2n) = f(n)
- f(4n+1) = 2·f(2n+1) - f(n)
- f(4n+3) = 3·f(2n+1) - 2·f(n)

S(n) = Σ_{i=1}^{n} f(i)

已知 S(8)=22, S(100)=3604。

原题求 S(3^37) 的最后 9 位数字。

## 题目

给定 n，求 S(n)。

## 算法

- 使用分治递归计算 S(N) = A(N) = Σ_{i=1}^{N} f(i)
- 利用递推的性质：A(N) = A(N/2) + O((N-1)/2)
- 其中 O(M) = Σ_{k=0}^{M} f(2k+1) 有独立的递归关系
- 递归深度 O(log N)，使用记忆化搜索

## 改编方向

1. **不同初值**：修改 f(1) 和 f(3) 的值
2. **递归变种**：修改 4n+1 和 4n+3 的递推系数
3. **前缀积**：求 Π f(i) 而非 Σ f(i)
