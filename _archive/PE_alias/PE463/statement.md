# 怪异递推

## 题目描述

定义在正整数上的函数 f 如下：
- f(1) = 1
- f(3) = 3
- f(2n) = f(n)
- f(4n+1) = 2·f(2n+1) - f(n)
- f(4n+3) = 3·f(2n+1) - 2·f(n)

定义 S(n) = Σ_{i=1}^{n} f(i)。

已知 S(8) = 22，S(100) = 3604。

求 S(N)。

---

## 输入格式

一个整数 N (1 ≤ N ≤ 10^18)。

---

## 输出格式

一个整数，表示 S(N)。对于大规模数据，输出 S(N) mod 10^9。

---

## 样例

### 输入
```
100
```

### 输出
```
3604
```

---

## 数据范围

- 对于 30% 数据：N ≤ 10^5
- 对于 60% 数据：N ≤ 10^9
- 对于 100% 数据：N ≤ 10^18
