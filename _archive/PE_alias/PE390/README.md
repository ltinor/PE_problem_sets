# PE390 - 无理数边长的整数面积三角形

来源：改编自 Project Euler Problem 390

## 原题意

三边长为 √(1+b²), √(1+c²), √(b²+c²)，求所有面积 ≤ n 的三角形面积之和 S(n)。求 S(10^10)。

## 题目

面积 = bc/2，需要 bc 为偶数。求所有满足 bc/2 ≤ n 的偶数 bc 对应的 bc/2 之和。

## 算法

- 枚举 b，对于每个 b，c 的取值范围为 [1, 2n/b]
- 需要统计 bc 为偶数的对数并求和
- 可用数论分块或直接枚举 b ≤ √(2n)，c 分段求和

## 改编方向

1. **三维扩展**：类似构造四面体，边长包含三个参数
2. **改变形状**：从三角形改为四边形，使用不同边长公式
3. **质因数版本**：只求面积为质数的情况
4. **模数版本**：答案对 M 取模，M 为输入参数
