# PE484 - 算术导数

来源：改编自 Project Euler Problem 484

## 原题意

算术导数 $n'$ 满足 $p'=1$（$p$ 素数）和 Leibniz 法则。
对于 $n = \prod p_i^{e_i}$，$n' = n \sum e_i/p_i$。

考虑导数序列的终止行为。PE 答案：8907904768686152599。

## 题目

给定 N，对 2 ≤ n ≤ N，求导数序列到达 0 或固定点的相关信息之和。

## 算法

- 算术导数可用质因数分解计算
- 对于 n，导数序列严格递减（除了 4→4 固定点）
- 序列最终到达 0（经过足够多步），最多经过 O(log n) 步
- 需要高效计算大范围（N ≤ 5×10^15）的统计量
- 使用分段筛法或数论函数求和技巧

## 改编方向

1. **不同终止条件**：循环检测
2. **部分导数**：只对特定素数求导
3. **高階导数**：n^(k) 的求和
4. **对数导数**：n'/n 的相关统计
