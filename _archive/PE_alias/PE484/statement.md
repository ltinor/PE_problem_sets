# 算术导数

## 题目描述

算术导数 $n'$ 的定义为：

- 对任意素数 $p$，$p' = 1$
- 对任意正整数 $a, b$，$(ab)' = a'b + ab'$（Leibniz 法则）

等价地，若 $n = \prod p_i^{e_i}$，则 $n' = n \cdot \sum \frac{e_i}{p_i}$。

考虑序列 $n, n', n'', n''', \ldots$ 直到其终止（到达 0 或进入循环）。

对 $2 \le n \le N$，求其终止值的某种和。

---

## 输入格式

一个整数 $N$。

---

## 输出格式

一个整数，表示所求之和。

---

## 样例

### 输入
```
5
```

### 输出
```
...
```

---

## 数据范围

- 对于 30% 数据：$N \le 20$
- 对于 60% 数据：$N \le 100$
- 对于 100% 数据：$N \le 5 \times 10^{15}$
