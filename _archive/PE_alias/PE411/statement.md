# 上行路径

## 题目描述

记 n 为正整数。在所有坐标为 (x, y) = (2^i mod n, 3^i mod n) 的位置安设站点，其中 0 ≤ i ≤ 2n。如果多个站点有相同坐标，我们就合并为同一个站点。

我们希望找到一条从 (0, 0) 到 (n, n) 的路径，路径上 x 和 y 坐标单调不减（可以相等）。

记 S(n) 是这样一条路径最多能够穿过的站点数目。

例如，当 n = 22 时，一共有 11 个不同的站点，一条可行路径最多能穿过 5 个站点，因此 S(22) = 5。
同样可以验证 S(123) = 14 以及 S(10000) = 48。

给定 n，求 S(n)。

---

## 输入格式

一个整数 n。

---

## 输出格式

一个整数，表示 S(n)。

---

## 样例

### 输入
```
22
```

### 输出
```
5
```

### 输入
```
123
```

### 输出
```
14
```

### 输入
```
10000
```

### 输出
```
48
```

---

## 数据范围

- 对于 30% 数据：n ≤ 50
- 对于 60% 数据：n ≤ 500
- 对于 100% 数据：n ≤ 10000
