# PE545 - 福尔哈贝尔公式 (Faulhaber's Formulas)

来源：改编自 Project Euler Problem 545

## 原题意

前 n 个正整数的 k 次幂和可用 k+1 次有理系数多项式（福尔哈贝尔公式）表示：
$$1^k + 2^k + \dots + n^k = \sum_{i=1}^{k+1} a_i n^i$$

其中系数 a_i = p_i/q_i 为最简分数（若 a_i=0，约定 q_i=1）。

例如：1^4+2^4+…+n^4 = −1/30 n + 1/3 n^3 + 1/2 n^4 + 1/5 n^5。

定义 D(k) 为 k 次幂公式中 q_1 的值（即一次项系数 a_1 的分母）。
由 Faulhaber 公式，a_1 = B_k（第 k 个伯努利数），故 D(k) 即 B_k 的最简分母。

由冯·施陶特-克劳森定理：对于偶数 k ≥ 2，
$$D(k) = \prod_{p-1 \mid k} p$$
（即所有满足 p−1 整除 k 的素数 p 的乘积）。对于奇数 k > 1，B_k = 0，D(k)=1。

已知 D(4)=30，D(308)=20010，F(1)=308，F(10)=96404。
定义 F(m) 为第 m 个满足 D(k)=20010 的 k。

求 F(10^5)。

PE 答案：921107572。

## 题目

给定 m，求第 m 个满足 D(k)=20010 的正整数 k。

## 算法

- 20010 = 2 × 3 × 5 × 23 × 29。需要 D(k)=20010，即 {p : p−1 | k} = {2,3,5,23,29}。
- 因此 k 必须是 L = lcm(1,2,4,22,28) = 308 的倍数，且不能有额外的素数 q 满足 q−1 | k。
- 遍历 k = m·308，检查是否有其他素数 q 满足 q−1 | k：
  - 对 k 的每个因数 d，检查 d+1 是否为额外素数。
  - 高效检查：只需检查到 sqrt(k) 的素数。
- 由于只需找第 10^5 个合法 k，可直接扫描 m=1,2,3,… 直至计数达标。
- k 的上界约为 m·L·log(m)，对于 m=10^5 在 10^8 量级，可行。

## 改编方向

1. **不同目标分母**：求 D(k) = X 的第 m 个 k，其中 X 为任意无平方因子偶数。
2. **伯努利数研究**：直接计算 B_k 的分子分母、或求 B_k 取特定值的 k。
3. **幂和系数**：研究高次项系数 a_{k+1}（总是 1/(k+1)）以外的系数分布。
4. **冯·施陶特-克劳森定理变体**：考虑 D(k) 的乘积表示在模意义下的性质。
