# PE350 - 约束最小最大和最大最小 (Constraining the least greatest and the greatest least)

来源：改编自 Project Euler Problem 350

## 原题意

定义 f(G, L, N) 为满足 gcd ≥ G 且 lcm ≤ L 的长度为 N 的整数序列个数。求 f(10^6, 10^12, 10^18) mod 101^4。原题答案：84664213。

## 题目

输入 G, L, N, M，求 f(G, L, N) mod M。其中 f(G, L, N) 为满足以下条件的长为 N 的正整数序列 (a_1, ..., a_N) 的数量：

- gcd(a_1, ..., a_N) ≥ G
- lcm(a_1, ..., a_N) ≤ L

## 算法

使用数论方法：

1. 由于 lcm ≤ L，每个元素必须 ≤ L。由于 gcd ≥ G，每个元素必须是某个 ≥ G 的数的倍数，且所有元素的最小公约数 ≥ G。

2. 令 g(d) = 长度为 N、gcd 恰好为 d、每个元素 ≤ L 的序列数。则答案为 sum_{d=G}^{L} g(d)。

3. 使用 Möbius 反演：g(d) = sum_{k≥1} μ(k) · ⌊L/(kd)⌋^N。

4. 因此 f(G, L, N) = sum_{m=G}^{L} ⌊L/m⌋^N · h(m)，其中 h(m) = sum_{d|m, d≥G} μ(m/d)。

5. 利用 ⌊L/m⌋ 只取 O(√L) 个不同值的性质，使用整除分块加速计算。

## 改编方向

1. **三维扩展**：增加约束条件，如要求序列元素互不相同。
2. **乘积约束**：将 lcm 约束改为乘积约束。
3. **求和版本**：求所有满足条件的序列的元素之和而非序列个数。
4. **确切相等**：改为 gcd 恰好等于 G 且 lcm 恰好等于 L。
