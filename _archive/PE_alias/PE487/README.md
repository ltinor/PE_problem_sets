# PE487 - 幂和之和

来源：改编自 Project Euler Problem 487

## 原题意

涉及幂和 $\sum_{k=1}^n k^p$ 的多重求和。PE 答案：24973710987372。

## 题目

给定 N 和 K，计算幂和的双重求和。

## 算法

- 幂和可用 Faulhaber 公式：$\sum_{k=1}^n k^p = \frac{1}{p+1} \sum_{j=0}^p \binom{p+1}{j} B_j n^{p+1-j}$
- $B_j$ 为 Bernoulli 数，可预计算
- 双重求和可交换次序减少复杂度
- 使用多项式求值或递推优化
