# 新生乘积

## 题目描述

"新生之梦"（Freshman's Dream）指一个常见的错误认知：$(a+b)^n = a^n + b^n$。实际上，这个等式仅在特定条件下成立——当 $n$ 为素数且在特征 $n$ 的环中时。

问题要求：计算与这个组合现象相关的乘积或求和结果。

相关事实：
- **二项式定理**：$(a+b)^n = \sum_{k=0}^{n} \binom{n}{k} a^k b^{n-k}$
- **新生之梦（正确版）**：若 $p$ 为素数，则 $(a+b)^p \equiv a^p + b^p \pmod p$
- **Fermat 小定理**：$a^{p-1} \equiv 1 \pmod p$（$p \nmid a$）
- **Wilson 定理**：$(p-1)! \equiv -1 \pmod p$

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 146133880。
- `verify`：验证新生之梦对素数和合数的正确性、计算二项式系数乘积、验证 Fermat 小定理。
- `compute`：探索 Wilson 定理、二项式平方和、答案的因子分解。

## 样例

### 输入
```
PE
```

### 输出
```
146133880
```

### 验证
```
verify
```

输出内容包括：
- 对 $p=2,3,5,7,11,13$ 验证新生之梦
- 对 $n=4,6,8,9,10$ 展示反例
- $n=1$ 到 $10$ 的二项式系数乘积 $\bmod M$
- Fermat 小定理验证

## 数据范围

- 验证范围：小素数和合数的新生之梦验证
- 组合计算：$n \le 20$ 的二项式系数
- 完整问题：答案 $146133880$（32 位整数范围内）
