# PE778 — Freshman's Product（新生乘积）

来源：改编自 Project Euler Problem 778

## 原题意

"新生之梦"（Freshman's Dream）指数论中的著名错误认知：误以为 $(a+b)^p = a^p + b^p$ 对所有 $p$ 成立。实际上，这在一般环中仅当 $p$ 为素数（且在特征 $p$ 的环中）时才成立。

问题可能涉及计算与二项式系数的乘积、或与"新生之梦"相关的模运算结果。

PE 答案：146133880（约 $1.46 \times 10^8$）。

## 算法

1. **新生之梦验证**：对素数 $p$，验证 $(a+b)^p \equiv a^p + b^p \pmod p$。
2. **二项式系数乘积**：计算 $\prod_{k=1}^{n} \binom{n}{k} \bmod M$。
3. **Lucas 定理**：用于在模素数下快速计算大二项式系数。
4. **组合恒等式**：利用 $\sum \binom{n}{k}^2 = \binom{2n}{n}$ 等恒等式进行分析。
5. **Wilson 定理**：$(p-1)! \equiv -1 \pmod p$。

## 改编方向

1. 推广到多项式环上的"新生之梦"
2. 计算 $\prod_{i=1}^{M} \prod_{j=1}^{N} \binom{i+j}{i}$ 类型的乘积
3. 在一般交换环中研究 $(a+b)^n$ 展开的模性质
4. 计算与"新生之梦"相关的生成函数
5. 对非素数的 Carmichael 数研究类似性质
