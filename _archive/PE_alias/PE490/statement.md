# 跳跃的青蛙

## 题目描述

一只青蛙在数轴上跳跃。它从位置 $0$ 出发，每次向右跳跃的距离在 $1$ 到 $K$ 之间（均匀随机或所有可能）。

求青蛙经过恰好 $N$ 步后，到达的各个位置的相关统计量（如期望位置、总方案数等）。

---

## 输入格式

两个整数 $N$ 和 $K$。

---

## 输出格式

一个整数，表示所求统计量。

---

## 样例

### 输入
```
3 1
```

### 输出
```
...
```

---

## 数据范围

- 对于 30% 数据：$N \le 10$
- 对于 60% 数据：$N \le 100$
- 对于 100% 数据：$N \le 10^5, K \le 100$
