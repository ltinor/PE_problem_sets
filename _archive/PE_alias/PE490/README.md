# PE490 - 跳跃的青蛙

来源：改编自 Project Euler Problem 490

## 原题意

青蛙在数轴上跳跃。每次向右跳 1 到 K 之间的整数距离。
计算与青蛙位置相关的统计量（可能是期望位置、概率加权和等）。

PE 答案：777577439507945。

## 题目

给定步数 N 和最大跳跃距离 K，求青蛙位置的相关统计量。

## 算法

- 标准 DP：dp[pos] = 到达位置 pos 的方案数
- 递推：dp[pos] = Σ_{j=1}^K dp[pos-j]
- 这是广义 Fibonacci 数列（K-bonacci）
- 对于大 N，使用矩阵快速幂 O(K³ log N)
- 期望位置 = Σ pos × P(pos) = Σ pos × dp[pos] / K^N

## 改编方向

1. **不同跳跃分布**：非均匀概率、带权的跳跃
2. **多只青蛙**：多只青蛙的相遇概率
3. **二维跳跃**：平面上的青蛙跳跃
4. **吸收边界**：到达某位置后停止
