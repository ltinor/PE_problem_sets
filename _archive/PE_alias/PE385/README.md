# PE385 - 三角形内的椭圆

来源：改编自 Project Euler Problem 385

## 原题意

顶点整数坐标 ≤ n，最大内椭圆焦点为 (±√13, 0) 的三角形面积之和 A(n)。求 A(10^9)。

## 题目

给定 n，求所有满足条件的三角形面积之和。

## 算法

- 最大内椭圆（Steiner inellipse）的焦点与三角形顶点关系
- 焦点 (±√13, 0) → 约束三角形顶点坐标满足特定方程
- 转化为数论/枚举问题

## 改编方向

1. **修改焦点坐标**：将焦点改为 (±√k, 0)，k 作为输入参数
2. **最小面积椭圆**：改为求最小外接椭圆满足条件的三角形
3. **任意多边形**：推广到四边形，求最大内椭圆面积为整数的条件
4. **三维版本**：在三维空间中求最大内椭球满足条件的四面体
