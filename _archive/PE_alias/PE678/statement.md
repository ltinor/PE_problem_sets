# 类费马方程

## 题目描述

若正整数三元组 $(a, b, c)$ 满足 $a^2+b^2=c^2$，则称之为毕达哥拉斯三元组。根据费马大定理，对于任意 $e \ge 3$，不存在三元组 $(a, b, c)$ 满足 $a^e+b^e=c^e$。

不过，若等号左侧和右侧所选择的指数不同，则方程可能有解。例如，$3^3+6^3=3^5$。

令 $a, b, c, e, f$ 为正整数，且满足 $0 < a < b$，$e \ge 2$，$f \ge 3$，$c^f \le N$。

记 $F(N)$ 为使得 $a^e+b^e=c^f$ 的数组 $(a, b, c, e, f)$ 总数。

已知：$F(10^3) = 7$，$F(10^5) = 53$，$F(10^7) = 287$。

求 $F(10^{18})$。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 1986065。
- `verify`：验证小样例（含 $F(10^3)$、$F(10^5)$、$F(10^7)$ 以及具体解的列举）。
- `compute`：重新计算完整答案。

## 样例

### 输入
```
PE
```

### 输出
```
1986065
```

## 数据范围

- 完整问题：$N = 10^{18}$
- $e \ge 2$，$f \ge 3$
- $a < b$ 且 $a,b,c,e,f$ 均为正整数
- 验证范围：$N \le 10^7$ 可直接枚举计算
