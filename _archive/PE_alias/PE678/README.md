# PE678 — 类费马方程 (Fermat-like Equations)

来源：改编自 Project Euler Problem 678

## 原题意

若正整数三元组 $(a,b,c)$ 满足 $a^2+b^2=c^2$，则称之为毕达哥拉斯三元组。根据费马大定理，对于 $e \ge 3$，不存在三元组 $(a,b,c)$ 满足 $a^e+b^e=c^e$。

然而，若等号左右两侧的指数不同，方程可能有解。例如 $3^3+6^3=3^5$。

令 $a,b,c,e,f$ 均为正整数，满足 $0<a<b$，$e \ge 2$，$f \ge 3$，$c^f \le N$。记 $F(N)$ 为使得 $a^e+b^e=c^f$ 的数组总数。

已知：$F(10^3)=7$，$F(10^5)=53$，$F(10^7)=287$。

求 $F(10^{18})$。

PE 答案：1986065。

## 算法

1. **枚举策略**：
   - 枚举 $(c,f)$ 对，满足 $c^f \le N$
   - $f \ge 3$，所以 $c \le \sqrt[3]{N}$
   - 对于 $N=10^{18}$，$c \le 10^6$

2. **对固定的 $c^f$ 求解 $a^e+b^e=c^f$**：
   - 枚举 $e \ge 2$，枚举 $a$（满足 $a^e < c^f/2$）
   - 计算 $b^e = c^f - a^e$，验证 $b^e$ 是否为某个整数的 $e$ 次幂
   - 对于 $e=2$，检查是否为完全平方数
   - 对于 $e>2$，使用二分查找或直接求 $e$ 次方根

3. **去重处理**：
   - 同一组 $(a,b,c)$ 可能对应多组 $(e,f)$
   - 需按定义中的五元组 $(a,b,c,e,f)$ 计数

4. **复杂度**：
   - $c \le 10^6$，$f \ge 3$ 的组合数约为 $O(\log N)$
   - 对每个 $c^f$，$e$ 和 $a$ 的枚举量较小（$a^e$ 增长很快）

## 改编方向

1. 参数化 $N$ 的范围
2. 推广到 $a^e + b^e = c^f + d^g$ 形式
3. 考虑 $a,b$ 互质的约束
4. 寻找方程的无限族解
