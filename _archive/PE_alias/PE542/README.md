# PE542 - 和最大的几何级数 (Geometric Progression with Maximum Sum)

来源：改编自 Project Euler Problem 542

## 原题意

记 S(k) 为满足以下条件的至少三个不同正整数的和：
- 正整数不超过 k
- 这些数构成**几何级数**（等比数列）
- 是所有可能和中的最大值

例如：S(4)=4+2+1=7，S(10)=9+6+4=19，S(12)=12+6+3=21，S(1000)=1000+900+810+729=3439。

令 T(n) = Σ_{k=4}^n (-1)^k S(k)。已知 T(1000) = 2268。求 T(10^17)。

PE 答案：85867114。

## 题目

给定 N，计算 T(N) = Σ_{k=4}^N (-1)^k S(k)，其中 S(k) 为不超过 k 的至少三项等比数列的最大和。

## 算法

- 等比数列公比 r = p/q（最简分数，p > q）。m ≥ 3 项时：
  - 末项 = a·p^{m-1} ≤ k，和 = a·(p^m - q^m)/(p - q)
  - a = ⌊k/p^{m-1}⌋ → S(k) = ⌊k/p^{m-1}⌋ · (p^m - q^m)/(p - q)
- S(k) 是阶梯函数，仅在 k 是 p^{m-1} 的倍数时跳跃。
- 枚举所有 (p,q,m) 组合（p^{m-1} ≤ N），计算它们对应的 S(k) 递增序列。
- 对区间内保持常值的 S(k)，计算交错和 Σ(-1)^k S(k) 的贡献。
- 利用等差数列求和公式高效聚合区间贡献。

## 改编方向

1. **项数约束**：恰好 m 项（而非至少 3 项）、最多 m 项。
2. **乘积最大化**：将"和最大"改为"乘积最大"或"末项最大"。
3. **非交错和**：直接求 Σ S(k) 或 Σ k·S(k)。
4. **多维扩展**：二维等比点阵的最优子集。
