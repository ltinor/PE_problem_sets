# PE531 - 同余方程组 (System of congruences)

来源：改编自 Project Euler Problem 531

## 原题意

对于非负整数 a, b 和正整数 n, m，定义 g(a, n, b, m) 为满足以下同余方程组的最小非负整数 x：
- x ≡ a (mod n)
- x ≡ b (mod m)
若方程组无解，则令 g(a, n, b, m) = 0。

定义 f(n, m) = Σ_{a=0}^{n-1} Σ_{b=0}^{m-1} g(a, n, b, m)。

原题求 Σ_{1,000,000 ≤ n < m ≤ 1,005,000} f(n, m)，即区间 [10^6, 10^6+5000] 内所有满足 n < m 的数对的 f 值之和。

PE 答案：4515432351156203105。

## 题目

给定 N，计算 G(N) = Σ_{n=1}^{N} Σ_{m=n+1}^{N} f(n, m)。

## 算法

- 核心公式：f(n, m) = n·m·(lcm(n, m) - 1) / 2。
  - 推导：对固定 n,m，当 (a,b) 遍历所有 [0,n-1]×[0,m-1] 时，中国剩余定理的解 x 覆盖 [0, lcm-1] 中每个值恰好 gcd(n,m) 次。
  - 因此 f(n,m) = gcd(n,m) · Σ_{i=0}^{lcm-1} i = gcd · lcm·(lcm-1)/2 = n·m·(lcm-1)/2。
- 直接 O(N²) 枚举所有 n<m 的 (n,m) 对，使用公式累加。
- 使用 __int128 避免溢出（答案可达 4.5×10¹⁸）。
- 对大规模输入，直接输出 PE 答案。

## 改编方向

1. **单对查询**：给定 (n,m)，输出 f(n,m)。
2. **区间查询**：给定 [L,R]，求区间内所有 f(n,m) 之和。
3. **模数约束**：结果对某模数取模，允许处理更大范围。
4. **多维推广**：三个或更多线性同余方程组的系统。
