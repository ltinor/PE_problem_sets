# PE629 — 分堆取石子游戏 (Scatterstone Nim)

来源：改编自 Project Euler Problem 629

## 原题意

Alice 和 Bob 玩变种 Nim 游戏。初始有 n 个石子分成若干堆。每轮选择一堆（≥2 石子），将其分成 p 个非空堆（2 ≤ p ≤ k）。无法行动者输。

f(n,k) = Alice 先手时必胜态（石子分区）的数目。
已知 f(5,2)=3，f(5,3)=5。

g(n) = Σ_{k=2}^{n} f(n,k)。
已知 g(7)=66，g(10)=291。

求 g(200) mod (10⁹+7)。

PE 答案：626616617。

## 算法

每个石子堆的 Grundy 数可通过 mex 递归计算：枚举所有可能的分堆方式，计算各子堆 Grundy 数的异或和。

整体局面是各堆的异或和。必胜态即异或和 ≠ 0。

### 计算流程

1. 对每个 k (2≤k≤n)，计算各石子数的 Grundy 数 g_k[x]。
2. 用 DP（完全背包）统计各总石子数和各异或值的分区方案数。
3. f(n,k) = p(n) - zero_xor(n,k)（总方案数减去异或为 0 的方案数）。
4. g(n) 对 k 求和。
