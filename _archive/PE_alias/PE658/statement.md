# 不完整的单词II

## 题目描述

在形式语言中，记 I(α,n) 为字母表大小为 α 时，长度不超过 n 的不完整单词（未使用全部字母）的数量。

记 S(k,n) = Σ_{α=1}^{k} I(α,n)。

已知：S(4,4)=406，S(8,8)=27902680，S(10,100) ≡ 983602076 (mod 1,000,000,007)。

求 S(10^7, 10^12) mod 1,000,000,007。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 958280177。
- `verify`：验证已知小样例。
- `compute`：完整计算 S(10^7, 10^12) mod 1e9+7（约需 3-8 秒）。

## 样例

### 输入
```
PE
```

### 输出
```
958280177
```

## 数据范围

- k = 10^7
- n = 10^12
- 模数：1,000,000,007
