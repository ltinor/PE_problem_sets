# 朋友与字符串

## 题目描述

两个正整数 a 和 b 被称为**朋友**（friends），当且仅当：

φ(a) / a = φ(b) / b

其中 φ(n) 是欧拉函数（Euler's totient function）。

等价地，a 和 b 具有**完全相同的不重复质因子集合**（相同的 radical），因为：

φ(n) / n = Π_{p|n} (1 - 1/p)

定义 F(N) 为满足 1 ≤ a < b ≤ N 的**无序朋友对** (a, b) 的数量。

已知 F(100) = 356。

求 F(10¹¹) 模 1,000,000,007 的值。

## 输入格式

一行，字符串 `PE` 或 `verify` 或 `compute`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案。

若输入为 `verify`，输出 F(10)、F(30)、F(100) 的结果及朋友分组示例。

若输入为 `compute`，计算 F(1000)。

## 样例

### 输入
```
PE
```

### 输出
```
968274181
```

## 数据范围

- 完整问题：N = 10¹¹
- 答案模 1,000,000,007
