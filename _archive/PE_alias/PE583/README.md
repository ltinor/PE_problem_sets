# PE583 — 海伦信封 (Heron envelopes)

来源：改编自 Project Euler Problem 583

## 原题意

一个标准信封由一个在上的等腰三角形（翻折面 BCD）和一个在下的长方形 ABDE 组成的凸多边形。一个海伦信封满足：所有边长均为整数，且所有对角线（AC, AD, BD, BE, CE）的长度也都是整数。

令 S(p) 表示所有周长 ≤ p 的海伦信封的周长之和。
已知：S(10⁴) = 884680。
求 S(10⁷)。

PE 答案：11741372990012608。

## 算法

设矩形宽 w = AB = DE，高 h = AE = BD。翻折面为等腰三角形，顶点 C 在 BD 中点上方，高度为 f（f < h）。

需要同时满足：
1. w² + h² = d²（矩形对角线为整数，勾股三元组）
2. (w/2)² + f² = s²（翻折面斜边为整数）
3. w² + f² = t²（全宽翻折面对角线为整数）
4. f < h

从条件可知 w 为偶数。设 w = 2u，则 u² + f² 和 4u² + h² 都必须是完全平方数。这构成一组耦合的勾股三元组，可以通过参数化方法求解。

所有解都可以通过两个勾股三元组的参数化生成，然后检查对角线条件和 f < h 约束。

## 改编方向

1. 改变翻折面形状（如不等腰三角形、梯形翻折面）。
2. 研究更高维的"信封"（如在长方体上加金字塔形翻折面）。
3. 分析海伦信封周长的分布规律。
4. 研究满足更强条件（如所有面为海伦三角形）的信封。
