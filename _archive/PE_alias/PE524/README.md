# PE524 - 首位排序 II

来源：改编自 Project Euler Problem 524

## 原题意

同 PE523 的排序算法。
按字典序排列所有 n! 个排列，I_n(P) 为排列 P 的字典序位置（1-indexed）。
Q(n, k) = min{I_n(P) | F(P) = k}，首个需要恰好 k 次移至首位的排列的字典序位置。
R(k) = min{Q(n, k)}，在所有定义 Q(n, k) 的 n 中取最小值。
求 R(12¹²)。

PE 答案：560744502。

## 题目

给定 k，求 R(k)。

## 算法

- 暴力搜索：从小到大枚举 n，按字典序遍历排列，找到首个 F(P)=k 的排列。
- 使用 next_permutation 按字典序生成排列。
- 对于小 k，搜索空间可控；大 k 需要数学分析排列结构与 F(P) 的关系。

## 改编方向

1. **不同排序算法**：其他排序算法的操作计数。
2. **逆问题**：给定字典序位置，求操作次数。
3. **最大字典序**：max I_n(P) for F(P)=k。
4. **多维或约束排列**：部分元素固定的情况。
