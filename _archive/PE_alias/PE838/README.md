# PE838 — Not Relatively Prime（不互质）

来源：改编自 Project Euler Problem 838

## 原题意

给定正整数 N，对所有满足 1 ≤ a < b ≤ N 且 gcd(a, b) > 1 的数对 (a, b)，计算某种组合函数 f(a, b) 的和（如 a×b、lcm(a,b)、或与素因数相关的函数）。

PE 答案：3610283147900864（≈ 3.6 × 10^15，是个很大的整数，暗示 N 大约在 10^6 ~ 10^7 量级）。

## 算法

1. **容斥原理**：
   - 总对数 T = N(N-1)/2。
   - 互质对数 C = Σ_{k=1}^{N} φ(k)（欧拉函数前缀和）。
   - 不互质对数 = T - C。

2. **Möbius 反演**：对于求和 Σ f(a,b)，如果 f 可分解为与 gcd 相关的形式，可用 Möbius 反演化简：
   - Σ_{d>1} Σ_{a<b, d|a, d|b} g(a/d, b/d)

3. **Dirichlet 卷积**：利用数论函数的卷积性质加速求和。关键是使用整除分块（Dirichlet hyperbola method）。

4. **前缀和优化**：预计算 φ(k) 和 μ(k) 的前缀和，用 O(N) 或 O(N^(2/3)) 的时间处理大规模求和。

5. **分块求和**：使用 min(N/(N/i), N) 技巧将 O(N) 优化到 O(√N)。

5. 研究随机数对互质概率的渐近行为
