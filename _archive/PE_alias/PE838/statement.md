# 不互质（Not Relatively Prime）

## 题目描述

给定正整数 $N$，考虑所有满足 $1 \le a < b \le N$ 的数对 $(a, b)$。

定义数对 $(a, b)$ 是**不互质的**，如果 $\gcd(a, b) > 1$（即它们有大于 1 的公因数）。

求 $\displaystyle \sum_{1 \le a < b \le N, \gcd(a,b) > 1} f(a, b)$，其中 $f(a, b)$ 是某个与 $a, b$ 相关的函数。

此题要求计算所有不互质数对的某种组合求和结果。

## 输入格式

无输入（固定参数问题）。

## 输出格式

输出一个整数，表示最终计算结果。

## 样例

（无样例输入输出，直接计算并输出最终答案。）
