# 抛物线上的三角形

## 题目描述

在抛物线 y = x²/k 上取三点 A(a, a²/k), B(b, b²/k), C(c, c²/k)。

若四元整数组 (k, a, b, c) 满足 1 ≤ k ≤ K，-X ≤ a < b < c ≤ X，且三角形 ABC 至少有一个角为 45°，则称其为合法四元组。

记 F(K, X) 为合法四元组的数量。

给定 K 和 X，求 F(K, X)。

---

## 输入格式

两个整数 K, X。

---

## 输出格式

一个整数，表示 F(K, X)。

---

## 样例

### 输入
```
1 10
```

### 输出
```
41
```

### 输入
```
10 100
```

### 输出
```
12492
```

---

## 数据范围

- 对于 30% 数据：K ≤ 5, |X| ≤ 10
- 对于 60% 数据：K ≤ 100, |X| ≤ 100
- 对于 100% 数据：K ≤ 10^6, |X| ≤ 10^9
