# 不完整的单词

## 题目描述

在形式语言中，由字母表 Σ 中的字母构成的有限序列称为 Σ 上的单词。如果一个单词不包含 Σ 中的全部字母，则称该单词是不完整的。

若字母表 Σ 包含 α 个字母，记 I(α,n) 为 Σ 上长度不超过 n 的不完整单词的数目。

例如，I(3,0)=1，I(3,2)=13，I(3,4)=79。

求 I(10^7, 10^12) mod 1,000,000,007。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 219493139。
- `verify`：验证已知小样例（含 I(3,0)=1, I(3,2)=13, I(3,4)=79）。
- `compute`：完整计算 I(10^7, 10^12) mod 1e9+7（约需 2-5 秒）。

## 样例

### 输入
```
PE
```

### 输出
```
219493139
```

## 数据范围

- α = 10^7
- n = 10^12
- 模数：1,000,000,007
