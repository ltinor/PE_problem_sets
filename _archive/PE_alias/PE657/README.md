# PE657 — 不完整的单词 (Incomplete words)

来源：改编自 Project Euler Problem 657

## 原题意

I(α,n) = 字母表大小为 α 时，长度不超过 n 的不完整单词（未使用全部 α 个字母）的数量。

已知：I(3,0)=1，I(3,2)=13，I(3,4)=79。

求 I(10^7, 10^12) mod 1,000,000,007。

PE 答案：219493139。

## 算法

使用容斥原理：

I(α,n) = Σ_{j=1}^{α} (−1)^{j−1} C(α,j) · g(α−j, n)

其中 g(x,n) = (x^{n+1}−1)/(x−1) mod MOD（x≠1），g(1,n)=n+1。

直接计算：O(α) = 10^7 项。预计算阶乘与逆阶乘，每项 O(1) 得到二项式系数。对每项计算快速幂求几何级数和。总复杂度 ~10^7 × log(MOD)。

## 改编方向

1. 求完整单词数目 C(α,n) = 总单词 − I(α,n)
2. 考虑单词不允许空单词
3. 推广到加权字母表
4. 求 I(α,n) 在多个 (α,n) 组合下的和
