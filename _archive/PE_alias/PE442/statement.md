# 无11整数

## 题目描述

一个正整数被称为**无11整数**，当且仅当它的十进制表示中不包含除了 1 以外的任何 11 的幂作为子串。

11 的幂（除 1 外）包括：11, 121, 1331, 14641, 161051, 1771561, 19487171, ...

例如：
- 2404 和 13431 都是无11整数
- 911（包含 "11"）和 4121331（包含 "121" 和 "1331"）不是

定义 E(n) 为第 n 个无11正整数。例如：E(3) = 3，E(200) = 213，E(500000) = 531563。

给定 n，求 E(n)。

---

## 输入格式

一个整数 n (1 ≤ n ≤ 10^10)。

---

## 输出格式

一个整数，表示第 n 个无11正整数。

---

## 样例

### 输入
```
200
```

### 输出
```
213
```

---

## 数据范围

- 对于 30% 数据：n ≤ 1000
- 对于 60% 数据：n ≤ 10^5
- 对于 100% 数据：n ≤ 10^10
