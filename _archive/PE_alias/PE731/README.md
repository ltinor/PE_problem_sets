# PE731 — A Stoneham Number (斯通汉姆数)

来源：改编自 Project Euler Problem 731

## 原题意

斯通汉姆数（Stoneham number）是一类特殊的实数，定义为：
$$\alpha_{b,c} = \sum_{k=1}^{\infty} \frac{1}{c^k \cdot b^{c^k}}$$

其中 $b$ 和 $c$ 是大于等于 2 的整数。

斯通汉姆常数在数论中具有重要意义——当 $c$ 是奇素数且 $b$ 是 $c^2$ 的原根时，$\alpha_{b,c}$ 在进制 $b$ 下是正规数（normal number）。

PE 731 要求计算特定的斯通汉姆数 $\alpha_{10,3}$ 的值（或其高精度十进制展开）。

PE 答案：2.12685887（展开的前若干位）。

## 算法

1. **级数定义**：$\alpha_{10,3} = \sum_{k=1}^{\infty} \frac{1}{3^k \cdot 10^{3^k}}$

2. **快速收敛**：分母 $10^{3^k}$ 以双指数速度增长，级数收敛极快。
   只需约 20 项即可达到完全精度。

3. **逐项十进制计算**：
   - 第 $k$ 项的小数点后第一位出现在第 $3^k+1$ 位
   - 各项的非零数字块互不重叠（自 $k \ge 2$ 起）
   - 使用高精度十进制算术逐项累加

4. **大整数模拟**：使用向量存储十进制位，模拟手工竖式加法进位。

5. **复杂度**：$O(D \cdot K)$，其中 $D$ 是所需小数位数，$K \approx \log_3 D$。
