# PE670 — 着色条带 (Colouring a Strip)

来源：改编自 Project Euler Problem 670

## 原题意

一条带被分成 N 个连续的格子。每个格子可以用 C 种颜色之一着色。着色必须满足：不允许出现三个连续格子颜色相同。

令 F(N, C) 为恰好使用 C 种颜色（每种颜色至少使用一次）的有效着色方案数。

问题求特定的 F(N, C) 值或其组合。

PE 答案：480040715688783。

## 算法

使用 DP + 容斥原理：

首先计算 ≤ k 种颜色的着色方案数 G(N, k)（允许某些颜色不使用）：

DP 状态设计：
- dp1[i]：前 i 个格子，最后一个格子是其颜色的第一次出现（即与前一个颜色不同）
- dp2[i]：前 i 个格子，最后一个格子是连续第二个同色格子

递推：
- dp1[i] = (dp1[i-1] + dp2[i-1]) × (k - 1)（选择一个不同的颜色）
- dp2[i] = dp1[i-1]（延续前一个格子的颜色，形成长度为 2 的连续段）
- 不允许出现长度 ≥ 3 的连续段

边界条件：
- dp1[1] = k, dp2[1] = 0
- G(N, k) = dp1[N] + dp2[N]

然后通过容斥得到恰好 C 种颜色的方案数：
- F(N, C) = Σ_{k=0}^{C} (-1)^{C-k} × C(C, k) × G(N, k)

对于大规模参数，可利用生成函数或矩阵快速幂加速 DP。
