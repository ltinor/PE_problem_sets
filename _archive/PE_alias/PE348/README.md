# PE348 - 平方数与立方数之和 (Sum of a square and a cube)

来源：改编自 Project Euler Problem 348

## 原题意

求出最小的五个恰好有 4 种不同表示方式（a^2 + b^3，其中 a,b > 1）的回文数之和。原题答案：1004195061。

## 题目

输出最小的五个恰好有 4 种表示方式为 a^2 + b^3（a,b > 1）的回文数之和。

## 算法

- 枚举 a（上限 ~50000）和 b（上限 ~6000），计算 a^2 + b^3。
- 使用哈希表统计每种和的表示方式数量。
- 筛选出恰好有 4 种表示方式的回文数。
- 排序后取前 5 个求和。

复杂度：O(MAX_A × MAX_B)。

## 改编方向

1. **参数化**：输入需要的表示方式数 K，求最小的若干个数之和。
2. **更高次幂**：改为 a^3 + b^4 或其他指数组合。
3. **非回文限制**：去掉回文条件，求所有满足条件的数。
4. **不同计数**：求恰好有 K 种方式的数的总个数（而非求和）。
