# 平方数与立方数之和

## 题目描述

许多正整数可以表示为一个平方数与一个立方数之和，即 a^2 + b^3（其中 a, b > 1）。有些数甚至有多种不同的表示方式。

考虑那些恰好有 4 种不同表示方式的回文数（即正读反读都相同的数）。

例如，5229225 是一个回文数，它恰好有 4 种不同的表示方式：
- 2285^2 + 20^3 = 5229225
- 2223^2 + 66^3 = 5229225
- 1810^2 + 125^3 = 5229225
- 1197^2 + 156^3 = 5229225

求这类回文数中最小的五个之和。

---

## 输入格式

本题无输入（固定题目）。

---

## 输出格式

一个整数，表示最小的五个满足条件的回文数之和。

---

## 样例

### 输入
```
0
```

### 输出
```
1004195061
```

---

## 数据范围

固定题目，保证答案在 64 位有符号整数范围内。
