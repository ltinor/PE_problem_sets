# PE796 — A Grand Shuffle（大洗牌）

来源：改编自 Project Euler Problem 796

## 原题意

一副标准扑克牌包含 52 张牌（4 种花色 × 13 种点数），外加 2 张王牌（大小王），共计 54 张。假设有 10 副不同背面花纹的牌，全部 540 张牌混洗后不放回抽牌，求抽齐所有花色、点数和背面花纹各至少一张的期望抽牌数。

PE 答案：42.52546609（保留 8 位小数）。

## 算法

1. **广义礼券收集问题**：27 个类别（4 花色 + 13 点数 + 10 背面），每张牌同时属于多个类别。
2. **容斥原理**：使用容斥原理计算期望值，枚举所有类别子集，计算"缺失某类别集合"的概率。
3. **不放回抽样**：有限总体不放回抽样的期望公式：$E[\max_i T_i] = \sum_{\emptyset \neq T} (-1)^{|T|+1} \frac{N+1}{|U_T|+1}$，其中 $U_T$ 是属于 $T$ 中任一类别卡牌的数量。
4. **计算优化**：540 张牌，类别集合枚举（$2^{27} \approx 1.34 \times 10^8$），可利用对称性减少枚举量。

4. 蒙特卡洛模拟验证理论结果
