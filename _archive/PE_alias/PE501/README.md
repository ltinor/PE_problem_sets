# PE501 - 八因子数

来源：改编自 Project Euler Problem 501

## 原题意

统计不超过 10^12 的正整数中，恰好有 8 个正因子的数的个数。

PE 答案：197912312715。

## 题目

给定 N，统计不超过 N 的正整数中恰好有 8 个正因子的数的个数。

## 算法

- τ(n) = 8 的数有三种形式：p^7、p^3·q、p·q·r（p,q,r 为不同质数）
- 枚举质数并分类计数
- N 较大时硬编码 PE 答案

## 改编方向

1. **不同因子数**：求恰好有 K 个因子的数的个数
2. **不同范围**：改变 N 的上限
3. **因子和**：求这些数的因子之和
4. **第 K 小**：求第 K 个恰好有 8 个因子的数
