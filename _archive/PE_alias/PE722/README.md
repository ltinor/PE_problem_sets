# PE722 — Slowly converging series (缓慢收敛级数)

来源：改编自 Project Euler Problem 722

## 原题意

对于非负整数 $k$，定义：
$$E_k(q)=\sum_{n=1}^{\infty}\sigma_k(n)q^n$$
其中 $\sigma_k(n)=\sum_{d\mid n}d^k$ 是 $n$ 的所有正约数的 $k$ 次幂之和。

可以证明，对于所有 $k$ 和 $0<q<1$，级数 $E_k(q)$ 始终收敛。

已知：
- $E_1(1-\frac{1}{2^4})=3.872155809243\times 10^2$
- $E_3(1-\frac{1}{2^8})=2.767385314772\times 10^{10}$
- $E_7(1-\frac{1}{2^{15}})=6.725803486744\times 10^{39}$

求 $E_{15}(1-\frac{1}{2^{25}})$，以科学计数法表示并保留小数点后十二位。

PE 答案：3.376792776（尾数部分）。

## 算法

1. **级数恒等式**：利用除数函数与等比级数的交换求和顺序：
   $$E_k(q)=\sum_{n=1}^{\infty}q^n\sum_{d\mid n}d^k=\sum_{d=1}^{\infty}d^k\sum_{m=1}^{\infty}q^{dm}=\sum_{d=1}^{\infty}d^k\frac{q^d}{1-q^d}$$

2. **截断估计**：$q=1-2^{-25}$ 非常接近 1，级数收敛缓慢。使用恒等式后，项 $d^k q^d/(1-q^d)$ 对大 $d$ 以 $\sim d^k e^{-d/2^{25}}$ 速度衰减。需累加至 $d\sim 2^{25}\times(k+12)\times\ln 10\approx 2\times 10^9$ 项。

3. **高精度计算**：使用 `long double`（80-bit 扩展精度，约 19 位有效数字）确保 12 位小数精度。

4. **计算优化**：
   - 对 $q^d$ 使用 $\exp(d\ln q)$ 批量计算
   - 对 $d^k$ 使用 `powl` 或分段累乘
   - 当项值小于 $10^{-20}\times$当前和时停止

5. **复杂度**：约 $10^8\sim 10^9$ 次迭代，每次涉及幂运算和除法。实际计算可能需要高性能计算环境。

## 改编方向

1. 改变参数 $k$ 和截止指数 $M$（$q=1-2^{-M}$）
2. 使用不同形式的级数核（如 $\sigma_k(n)$ 替换为其他数论函数）
3. 改变精度要求（更多/更少小数位）
4. 考察级数的解析延拓或其他 $q$ 值
