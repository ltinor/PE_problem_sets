# 双曲线上的点序列

## 题目描述

双曲线 H 由方程 12x<sup>2</sup> + 7xy - 12y<sup>2</sup> = 625 定义。

点 X = (7, 1) 在 H 上。

定义 H 上的点序列 {P<sub>i</sub> : i ≥ 1}：
- P<sub>1</sub> = (13, 61/4)
- P<sub>2</sub> = (-43/6, -4)
- 对于 i > 2，P<sub>i</sub> 是 H 上不同于 P<sub>i-1</sub> 的唯一一点，满足直线 P<sub>i</sub>P<sub>i-1</sub> 平行于直线 P<sub>i-2</sub>X

已知：P<sub>3</sub> = (-19/2, -229/24)，P<sub>4</sub> = (1267/144, -37/12)

给定 n，求 P<sub>n</sub>。若 P<sub>n</sub> = (a/b, c/d)（最简分数且分母为正），输出 (a + b + c + d) mod 1000000007。

---

## 输入格式

一个整数 n。

---

## 输出格式

一个整数，表示 (a + b + c + d) mod 1000000007。

---

## 样例

### 输入
```
7
```

### 输出
```
806236837
```

---

## 数据范围

- 对于 30% 数据：n ≤ 10
- 对于 60% 数据：n ≤ 100
- 对于 100% 数据：n ≤ 11<sup>14</sup>
