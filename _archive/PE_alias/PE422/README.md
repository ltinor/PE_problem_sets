# PE422 - 双曲线上的点序列

来源：改编自 Project Euler Problem 422

## 原题意

双曲线 H: 12x²+7xy-12y²=625，X=(7,1) 在 H 上。点列 Pi 由递推定义：Pi 在 H 上且 PiPi-1 ∥ Pi-2X。原题求 n=11^14 时的 Pn，答案为 92060460。

## 题目

给定 n，求 Pn = (a/b, c/d)，输出 (a+b+c+d) mod 1e9+7。

## 算法

- 双曲线判别式 D=7²+4·12·12=625=25²，为可有理参数化双曲线
- 利用群运算（弦切线法）建立递推关系
- 斜率 m = (1 - y_{i-2})/(7 - x_{i-2})
- 代入双曲线方程解二次方程得 t，进而求出 Pi
- 对大规模 n，使用矩阵快速幂加速递推
