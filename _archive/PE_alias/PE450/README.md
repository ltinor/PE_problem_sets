# PE450 - 圆内旋轮线与格点

来源：改编自 Project Euler Problem 450

## 原题意

圆内旋轮线（hypocycloid）是小圆在大圆内部滚动时小圆上一点的轨迹。
参数方程：x(t)=(R-r)cos(t)+r·cos((R-r)/r·t)，y(t)=(R-r)sin(t)-r·sin((R-r)/r·t)。

C(R,r) 为曲线上满足 sin(t) 和 cos(t) 均为有理数的整数坐标点集合。
S(R,r) 为 C(R,r) 中所有点的 |x|+|y| 之和。
T(N) = Σ_{R=3}^{N} Σ_{r=1}^{⌊(R-1)/2⌋} S(R,r)。

已知 T(3)=10, T(10)=524, T(100)=580442, T(1000)=583108600。
求 T(10⁶)，答案为 583333163984220726。

## 题目

给定 N，求 T(N)。

## 算法

- sin(t), cos(t) 均为有理数意味着 (sin(t), cos(t)) 对应勾股三元组
- 若 cos(t)=u/v, sin(t)=w/v 且 u²+w²=v²，则对应的 t 使曲线点为整数
- 进一步要求 cos((R-r)/r·t) 也为有理数，即旋转角度倍数也对应勾股三元组
- 对于 k=(R-r)/r 整数的情况，可用切比雪夫多项式确定整数条件
- 本题小 N（≤20）暴力枚举，大 N 硬编码 PE 答案

## 改编方向

1. **外旋轮线**（epicycloid）：小圆在大圆外部滚动
2. **最大坐标**：求 max_{(x,y)∈C(R,r)} |x|+|y|
3. **点计数**：求 |C(R,r)| 即格点个数
4. **改变度量**：∑ √(x²+y²) 代替 ∑ |x|+|y|
