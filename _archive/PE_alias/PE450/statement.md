# 圆内旋轮线与格点

## 题目描述

在大圆内部有一小圆与其相切并不断滚动，由小圆上一点所构成的曲线称为**圆内旋轮线**。
以原点为圆心、最右侧点为起点的圆内旋轮线参数方程为：

$$x(t) = (R-r)\cos(t) + r\cos\left(\frac{R-r}{r}t\right)$$
$$y(t) = (R-r)\sin(t) - r\sin\left(\frac{R-r}{r}t\right)$$

其中 R 为大圆半径，r 为小圆半径。

记 C(R,r) 为圆内旋轮线上满足以下条件的整数坐标格点集合：
对应参数 t 使得 sin(t) 和 cos(t) 均为有理数。

记 S(R,r) = ∑_{(x,y)∈C(R,r)} (|x|+|y|) 为集合中所有点坐标绝对值之和。

记 T(N) = ∑_{R=3}^{N} ∑_{r=1}^{⌊(R-1)/2⌋} S(R,r)。

已知：
- C(3,1) = {(3,0), (-1,2), (-1,0), (-1,-2)}，S(3,1)=10
- T(3)=10, T(10)=524, T(100)=580442, T(1000)=583108600

---

## 输入格式

一个整数 N（3 ≤ N ≤ 20，或 N = 10³, 10⁶）。

---

## 输出格式

一个整数，表示 T(N)。

---

## 样例

### 输入
```
3
```

### 输出
```
10
```

---

## 数据范围

- 对于 30% 数据：N ≤ 5
- 对于 60% 数据：N ≤ 10
- 对于 100% 数据：N ≤ 20 或 N = 10³, 10⁶（PE 答案硬编码）
