# 最大素数幂

## 题目描述

对于正整数 $n$，定义 $M(n)$ 为整除 $n$ 的最大素数幂：
$$M(n) = \max\{p^k : p \text{ 为素数},\; k \ge 1,\; p^k \mid n\}$$
特别地，$M(1) = 1$。

例如：
- $M(12) = 4$，因为 $4 = 2^2 \mid 12$，而 $3^1 = 3 < 4$。
- $M(100) = 25$，因为 $25 = 5^2 \mid 100$，而 $2^2 = 4 < 25$。

求 $\sum_{n=1}^{N} M(n)$。

## 输入格式

一行字符串：`PE`、`verify` 或 `compute`。

## 输出格式

- `PE`：输出 PE 原题答案 75640242。
- `verify`：展示小规模 $M(n)$ 的值、素数幂分析、累积和。
- `compute`：展示较大范围的 $M(n)$ 和及平均值。

## 样例

### 输入
```
PE
```

### 输出
```
75640242
```

### 验证
```
verify
```

输出内容包括：
- $n = 1$ 到 $50$ 的 $M(n)$ 值表
- 素数幂列表（$\le 100$）
- 累积和（$N=10,100,1000,10000$）

## 数据范围

- 验证范围：$n \le 100$，精确枚举
- 计算范围：$N \le 10^5$，$O(N \log \log N)$ 筛法 + 更新
- 完整问题：PE 答案 $7.56 \times 10^7$，暗示 $N$ 在 $10^6 \sim 10^7$ 量级
