# PE909 — $L$-expressions I（$L$-表达式一）

来源：改编自 Project Euler Problem 909

## 原题意

定义基于 SKI 组合子逻辑的 $L$-表达式系统。规则为：
- $A(x) \to x+1$（后继）
- $Z(u)(v) \to v$（$K I$ 组合子）
- $S(u)(v)(w) \to v(u(v)(w))$（翻转 $S$ 组合子）

求 $S(S)(S(S))(S(S))(S(Z))(A)(0)$ 的最后九位数字。

PE 答案：463372544

## 算法

1. **组合子语义**：
   - $Z = \lambda x.\lambda y.y$（丢弃首参数）
   - $A = \lambda n.n+1$（后继函数）
   - $S$ 为翻转的 $S$ 组合子

2. **Church 编码**：
   - $S(Z)$ 等价于恒等组合子 $I = \lambda x.x$
   - $S(S)(S(S))\cdots$ 结构编码快速迭代

3. **直接归约**：
   - 实现项重写系统，左最外归约策略
   - 小规模表达式可直接求值验证

4. **模运算优化**：
   - 只需要最后九位数字 $(\bmod 10^9)$
   - 后继操作是唯一改变数值的规则
   - 结果 $= 0 + (\text{A 的应用次数}) \bmod 10^9$
