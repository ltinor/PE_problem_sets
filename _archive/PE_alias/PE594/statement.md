# 菱形铺砖

## 题目描述

对多边形 P，记 t(P) 为用边长为 1 的菱形和正方形铺满 P 的方法数。旋转和翻转后相同的铺法视为不同。

O_{a,b} 是边长交替为 a 和 b 的等角凸八边形（内角均为 135°）。

已知：
- t(O_{1,1}) = 8
- t(O_{2,1}) = 76
- t(O_{3,2}) = 456572

求 t(O_{4,2})。

## 输入格式

一行，字符串 `PE` 或 `verify`。

## 输出格式

若输入为 `PE`，输出 PE 原题的答案：47067598。
若输入为 `verify`，验证已知的 t(O_{1,1})、t(O_{2,1})、t(O_{3,2})。

## 样例

### 输入
```
PE
```

### 输出
```
47067598
```

## 数据范围

- 完整问题：a = 4, b = 2
- 验证模式：a, b ≤ 3
