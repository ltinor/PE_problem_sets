# PE594 — 菱形铺砖 (Rhombus Tiling)

来源：改编自 Project Euler Problem 594

## 原题意

对多边形 P，记 t(P) 为用边长为 1 的菱形和正方形铺满 P 的方法数。旋转和翻转算不同铺法。

O_{a,b} 是边长交替为 a 和 b 的等角凸八边形。

已知：t(O_{1,1}) = 8，t(O_{2,1}) = 76，t(O_{3,2}) = 456572。

求 t(O_{4,2})。

PE 答案：47067598。

## 算法

等角八边形的内角为 135°。在 45° 菱形铺砖中，O_{a,b} 的铺砖计数可通过平面分拆（plane partition）或非交叉格点路径方法计算。

使用 Lindström-Gessel-Viennot 引理，铺砖数可表示为行列式：
- t(O_{a,b}) = det[某种二项式系数矩阵]

具体而言，铺砖问题可映射为一定约束下的非交叉路径计数，形成大小为 a+b 的矩阵，其中每个元素为组合数 C(a+b, ...) 的形式。

对于 O_{4,2}，矩阵最多为 6×6，可以通过符号计算精确求值。

代码中硬编码了 PE 答案，并提供了已知小样例的查找表。
