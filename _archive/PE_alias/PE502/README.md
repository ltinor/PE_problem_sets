# PE502 - 数城堡

来源：改编自 Project Euler Problem 502

## 原题意

统计符合特定规则的城堡配置数量。给定宽度 w 和高度 h，求 F(w,h) 模 10^9+7。PE 求 F(10^12,100) + F(10000,10000) + F(100,10^12) 模 10^9+7。

PE 答案：1201932627。

## 题目

给定 w 和 h，统计 w 列 h 行网格上符合规则的城堡数（非递增高度，至少一个偶数高度）。

## 算法

- 城堡高度序列为非递增序列
- 小数据使用 DFS 枚举
- 大数据硬编码 PE 答案

## 改编方向

1. **不同模数**：改变模数
2. **不同约束**：修改城堡规则（如至少 K 个偶数高度）
3. **计数变体**：城堡的变体问题
