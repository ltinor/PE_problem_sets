# PE465 - 极点多边形 (Polar polygons)

来源：改编自 Project Euler Problem 465

## 原题意

多边形的核心（kernel）是能看到整个多边形边界的点集。极点多边形是指核心严格包含原点的多边形。

顶点坐标为整数，|x|,|y| ≤ n。允许连续的共线顶点，但不允许自交，面积不能为零。

P(n) 为满足条件的极点多边形个数（边集不同则视为不同）。

已知 P(1)=131, P(2)=1648531, P(3)=1099461296175, P(343) mod 1e9+7 = 937293740。

原题求 P(7^13) mod 1,000,000,007 = 585965659。

## 题目

给定 n，求 P(n)。

## 算法

- 极点多边形的充要条件：顶点按极角排序后，相邻顶点的叉积符号全部相同（全正或全负）
- 这保证了原点到每条边的有向距离为正，即原点在核心内
- 对于小规模 n（≤1）使用枚举验证
- 大规模 n 的计算涉及复杂的组合计数

## 改编方向

1. **三维极点多面体**：推广到三维空间
2. **不同原点位置**：内核包含特定点而非原点
3. **限定边数**：只考虑特定顶点数的多边形
