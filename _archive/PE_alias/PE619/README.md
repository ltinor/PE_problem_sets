# PE619 — 平方子集 (Square subsets)

来源：改编自 Project Euler Problem 619

## 原题意

对于正整数集 $\{a,a+1,\ldots,b\}$，记 $C(a,b)$ 为其非空子集中满足所有元素之积为完全平方数的子集的数目。

已知：$C(5,10)=3$，$C(40,55)=15$，$C(1000,1234) \bmod 10^9+7 = 975523611$。

求 $C(1000000, 1234567) \bmod 1000000007$。

PE 答案：3268573801。

## 算法

乘积为完全平方数等价于每个质因子出现偶数次。这是 $\text{GF}(2)$ 上的线性代数问题。

对于 $[a,b]$ 中的每个数 $n$，计算其**无平方核** $s(n)$：指数为奇数的质数的乘积。将 $s(n)$ 表示为 $\text{GF}(2)^P$ 上的向量（$P$ 为质数集合）。

一个子集的乘积为完全平方数当且仅当对应向量的 XOR（对称差）为零向量。

$$C(a,b) = 2^{N - \text{rank}} - 1$$

其中 $N = b-a+1$ 为元素个数，$\text{rank}$ 为 $N \times |P|$ 二元矩阵的秩。

**增量式计算秩**：使用无平方核整数的 GCD 归约：
- $\text{reduce}(x, y) = x \cdot y / \gcd(x, y)^2$
- 此运算给出两个无平方数质数集合的对称差

维护一组基向量，按最小质因子索引。对每个新核 $s$：
1. 与基中具有相同最小质因子的向量归约
2. 若归约到 1 → 相关（计入零空间）
3. 若归约到 $>1$ → 独立（加入基）

总体复杂度：$O(N \log N)$（借助最小质因子索引的摊销归约）。
