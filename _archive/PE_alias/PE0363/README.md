# 贝塞尔曲线

来源：改编自 Project Euler Problem 363

## 原题意

用三次贝塞尔曲线逼近四分之一圆，求曲线长度与四分之一圆弧长度的百分比误差。PE 答案：0.0000372091。

## 题目

给定控制点参数 v，计算贝塞尔曲线与四分之一圆的面积/长度偏差。

## 数据范围

v 为浮点数，精度要求 10 位小数。

## 算法

### 方向一：数值积分

贝塞尔曲线参数方程：B(t) = (1-t)³P₀ + 3(1-t)²tP₁ + 3(1-t)t²P₂ + t³P₃。面积用 Green 公式计算，长度用弧长积分公式 + Simpson 自适应积分。

### 方向二：二分查找 v

使用二分法寻找使贝塞尔曲线面积 = π/4 的 v 值。每次迭代用数值积分计算面积，收敛到所需精度。

### 方向三：解析求解

贝塞尔曲线的面积可解析表达为控制点的函数。代入 P₀=(1,0), P₁=(1,v), P₂=(v,1), P₃=(0,1) 得到面积关于 v 的多项式，直接求根。

### 时间复杂度

数值方法 O(log(1/ε)) 次积分，每次积分 O(1/√ε)。
