# PE388 - 不同的直线

来源：改编自 Project Euler Problem 388

## 原题意

三维格点 (a,b,c)，0≤a,b,c≤N。从原点引直线到其他格点，求不同直线数 D(N)。求 D(10^10)。

## 题目

D(N) = 从原点看到的非原点格点数，等价于 gcd(a,b,c)=1 的 (a,b,c) 数量。

## 算法

- D(N) = Σ_{d=1}^{N} μ(d) · ((⌊N/d⌋+1)^3 - 1)
- 需要快速计算莫比乌斯函数前缀和（杜教筛或直接线性筛）

## 改编方向

1. **二维简化版**：求平面上的 D(N)，降低难度
2. **带权版本**：每条直线的权重为其方向向量长度
3. **非原点视角**：从任意点 (x0,y0,z0) 而非原点出发
4. **限制视角**：只计算在某个锥体内的直线
