# 不同的直线

## 题目描述

在三维空间中，考虑所有满足 0 ≤ a, b, c ≤ N 的格点 (a, b, c)。

从原点 O(0, 0, 0) 向所有其他格点引直线。记 D(N) 为这些直线中本质不同的直线条数（方向向量化简后不同的直线）。

给定 N，求 D(N)。

---

## 输入格式

一个整数 N。

---

## 输出格式

一个整数，表示 D(N)。

---

## 样例

### 输入
```
10
```

### 输出
```
1251
```

---

## 数据范围

- 对于 30% 数据：N ≤ 100
- 对于 60% 数据：N ≤ 10^6
- 对于 100% 数据：N ≤ 10^10
