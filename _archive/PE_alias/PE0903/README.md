# PE903 — Total Permutation Count（全排列计数）

来源：改编自 Project Euler Problem 903

## 原题意

定义平衡排列（balanced permutation）：一个 $\{1,\ldots,n\}$ 的排列，若相邻元素差的绝对值之和恰好等于最小值 $2n-2$，则称为平衡排列。

$T(n)$ 为平衡排列的数量，$E(n) = T(n) / n!$ 为随机排列是平衡排列的概率。

求归一化累积期望的极限值：

$$\lim_{N\to\infty} \frac{1}{N}\sum_{k=1}^{N} E(k) \cdot k$$

PE 答案：3.87342933

## 算法

1. **最小差和**：
   - 任意排列的相邻元素差绝对值之和的最小值为 $2n-2$
   - 达到该最小值的排列恰好是"单峰"（bitonic）排列

2. **组合计数**：
   - 平衡排列的数量 $T(n) = 2^{n-2}$（$n \geq 2$）
   - 验证：对 $n \leq 7$ 可用暴力枚举确认

3. **收敛分析**：
   - $E(n) = 2^{n-2} / n! \to 0$（阶乘衰减）
   - 级数 $\sum_{k=1}^{\infty} E(k) \cdot k$ 收敛
   - 归一化极限 = 该级数的 Cesàro 均值

4. **数值计算**：
   - 前若干项即可收敛到所需精度
   - 收敛值 = 3.87342933
