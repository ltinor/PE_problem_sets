# PE905 — Pandigital Parametrization（全数字参数化）

来源：改编自 Project Euler Problem 905

## 原题意

一个正整数称为"$b$ 进制全数字"，如果其 $b$ 进制表示包含每个数字 $0,\ldots,b-1$ 至少一次。

$f(b,k)$ 为恰好有 $k$ 位（无前导零）的 $b$ 进制全数字正整数的数量。

定义 $G(N) = \sum_{b=2}^{N} \sum_{k=b}^{b+5} f(b,k) \pmod{10^9+7}$。

求 $G(100)$。

PE 答案：40489374

## 算法

1. **容斥原理**：
   - $k$ 位 $b$ 进制串总数（首非零）：$(b-1) \cdot b^{k-1}$
   - 排除缺失某些数字的串：使用容斥原理

2. **分类讨论**：
   - 情况 1：$0$ 被保留（排除 $t$ 个非零数字）
     - 首位选择数：$b-t-1$（不能选 $0$）
     - 其余位：$(b-t)^{k-1}$ 种
   - 情况 2：$0$ 被排除（排除 $t$ 个非零数字 + $0$）
     - 首位选择数：$b-t-1$（$0$ 已被排除）
     - 其余位：$(b-t-1)^{k-1}$ 种

3. **容斥系数**：
   - 排除 $s$ 个数字对总和的贡献为 $(-1)^s$
   - 使用二项式系数 $\binom{b-1}{t}$ 选择排除的非零数字

4. **模运算**：
   - 使用二分快速幂进行模指数运算
   - 预计算阶乘和逆元用于组合数
   - 模数 $M = 10^9 + 7$（质数）

5. **求和范围**：
   - $b$ 从 $2$ 到 $100$（$99$ 个进制）
   - $k$ 从 $b$ 到 $b+5$（每个进制 $6$ 个数字长度）
   - 总计约 $600$ 次 $f(b,k)$ 计算

## 改编方向

1. 将限制放宽到任意数字长度范围
2. 要求每个数字出现恰好一次（排列问题）
3. 研究 $f(b,k)$ 的渐近公式
4. 推广到部分数字出现约束的情况
