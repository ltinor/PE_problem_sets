# 椭圆内接三角形

## 题目描述

三角形 ΔABC 内接于椭圆：

$$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$$

其中 $0 < 2b < a$，$a$ 和 $b$ 均为整数。

已知三角形 ΔABC 的内接圆圆心坐标为 $(2b, 0)$，顶点 A 的坐标为 $(\frac{a}{2}, \frac{\sqrt{3}}{2}b)$。记 $r(a,b)$ 为此时内接圆的半径。

例如：$r(3,1) = \frac{1}{2}$，$r(6,2) = 1$，$r(12,3) = 2$。

定义：

$$G(n) = \sum_{a=3}^{n} \sum_{b=1}^{\lfloor \frac{a-1}{2} \rfloor} r(a,b)$$

已知 $G(10) = 20.59722222$，$G(100) = 19223.60980$。

---

## 输入格式

一个整数 $N$（$3 \leq N \leq 5$ 或 $N = 10, 100, 10^{11}$）。

---

## 输出格式

对于 $N \leq 5$：输出 $G(N)$，保留 10 位小数。

对于 $N = 10, 100$：输出 $G(N)$ 的 10 位有效数字。

对于 $N = 10^{11}$：输出 PE 验证码（整数）。

---

## 样例

### 输入
```
10
```

### 输出
```
20.59722222
```

---

## 数据范围

- 对于 30% 数据：$N \leq 4$
- 对于 60% 数据：$N \leq 5$
- 对于 100% 数据：$N \leq 5$ 或 $N = 10, 100, 10^{11}$
