# 蚂蚁和种子 (Ant and seeds)

来源：改编自 Project Euler Problem 280

## 原题意

$5 \times 5$ 网格，蚂蚁从中心随机行走，搬运底行 5 粒种子到顶行，求期望步数。PE 答案：430.088247。

## 题目

输入网格大小 $G$（$1 \le G \le 5$），输出期望步数。

## 数据范围

$1 \le G \le 5$。

## 算法

### 方向一：马尔可夫链 + 值迭代（核心）

状态空间：
- 蚂蚁位置：$G \times G = 25$
- 底行种子掩码：$2^G \le 32$
- 是否携带：$2$
- 已放置顶行种子数：$G+1 \le 6$

总状态数 $\le 9600$。转移为吸收马尔可夫链（$top=G$ 为吸收态）。

设 $E[s]$ 为从状态 $s$ 到达吸收态的期望步数：
$$E[s] = 1 + \sum_{s'} P_{s \to s'} \cdot E[s'] \quad (s \text{ 非吸收})$$
$$E[s] = 0 \quad (s \text{ 吸收})$$

用值迭代求解：$E^{(k+1)}[s] = 1 + \sum P \cdot E^{(k)}[s']$，迭代至 $\max|E^{(k+1)}-E^{(k)}| < 10^{-14}$，通常几万次迭代收敛。

### 方向二：蒙特卡洛模拟（近似 / 验证）

随机模拟蚂蚁行走，统计平均步数。仅适用于小网格粗略估计，精度依赖模拟次数。

### 方向三：精确线性方程组

将 9600 个状态的线性方程用稀疏高斯消元直接求解。复杂度 $O(n^3)$ 太大，不如迭代实用。

### 时间复杂度

每次迭代 $O(\text{状态数} \times \text{度数})$，总计约 $10^7 \sim 10^8$ 次运算。$G=5$ 可在 1 秒左右完成。
