# PE912 — 素数在哪（Where are the Primes?）

来源：改编自 Project Euler Problem 912

## 原题意

定义函数 \(f(n, m)\) 为满足 \(1 \le a, b \le n\) 且 \(a^2 + b^2 + m^2\) 是素数的有序对 \((a, b)\) 的个数。

给定 \(m\) 的值，计算对足够大的 \(N\) 时 \(f(N, m)\) 的某种渐近行为或限制条件。

具体而言，本题要求计算 \(\displaystyle\sum_{m=1}^{M} g(m)\)，其中 \(g(m)\) 是一个与 \(f(\cdot, m)\) 相关的计数函数。

PE 答案：**562685338**。

## 算法

极难的数论问题，涉及：
1. 二次型表示素数的分布
2. 圆内格点计数
3. 狄利克雷特征和
4. 大规模筛法的数值实现

## 改编方向

1. 修改二次型（如 \(a^2 + ab + b^2\)）
2. 改变限制区域形状
3. 统计不同素数的分布
