# 10子串友好数

## 题目描述

一个数的 10-子串 是各位数字之和恰好为 10 的连续子串。例如，3523014 的 10-子串包括 352、523、5230 和 23014。

若一个数的每一位数字都属于某个 10-子串，则称该数为 10-子串友好数。例如，3523014 是友好的，而 28546 不是。

记 T(n) 为 1 到 10ⁿ（含）之间所有 10-子串友好数的个数。
已知：T(2) = 9，T(5) = 3492。

给定 n，求 T(n) mod 1000000007。

## 输入格式

一行，一个整数 n，或字符串 `PE`。

## 输出格式

一个整数，表示 T(n) mod 1000000007。

## 样例

### 输入
```
2
```

### 输出
```
9
```

### 输入
```
5
```

### 输出
```
3492
```

## 数据范围

- 对于 30% 数据：n ≤ 6
- 对于 60% 数据：n ≤ 12
- 对于 100% 数据：n ≤ 18
