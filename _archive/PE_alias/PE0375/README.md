# 子序列最小值

来源：改编自 Project Euler Problem 375

## 原题意

伪随机序列 S_n，求所有子区间最小值的总和 M(N)。PE 答案：7435327983715286168 (N=2×10^9)。

## 题目

给定 N 和伪随机生成器参数，求所有子区间最小值之和。

## 数据范围

N ≤ 10^7

## 算法

### 方向一：单调栈 + 贡献法

对每个位置 i，计算以 S_i 为最小值的区间 [L, R] 数量。使用单调栈 O(N) 找出每个元素作为最小值的左右边界。贡献 = S_i × (i-L+1) × (R-i+1)。

### 方向二：分治 + 笛卡尔树

构建笛卡尔树（最小值作为根），递归计算每个子树内跨根节点的区间贡献。

### 方向三：线段树 / RMQ

使用线段树维护区间最小值，分治处理。每次找区间最小值位置，累加跨过该位置的区间贡献，然后递归处理左右子区间。

### 时间复杂度

O(N)。
