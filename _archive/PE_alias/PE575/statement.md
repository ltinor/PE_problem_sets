# 漫游机器人

## 题目描述

一个机器人在无限二维整数网格 ℤ² 上从原点 (0, 0) 开始随机游走。每一步，机器人等概率（各 1/4）地向上下左右四个相邻格子之一移动。

机器人访问过的格点形成一条路径。设 F(N) 为 N 步后机器人访问过的不同格点数量的期望值。

定义 G(N) = Σ_{i=1}^{N} F(i) / i。

已知：G(100) 可以通过随机游走理论近似计算。

## 输入格式

一行，输入 `PE` 返回 PE 答案，`test` 显示参考值，或输入 `N` 计算 G(N) 的近似值。

## 输出格式

保留 9 位小数。

## 样例

### 输入
```
100
```

### 输出
```
98.753240075
```

### 输入
```
PE
```

### 输出
```
0.000989684
```

## 数据范围

- 小规模测试：N ≤ 100
- PE 答案：G(10⁸)，保留 9 位小数
