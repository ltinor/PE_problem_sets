# 递归序列

## 题目描述

已知函数 f(x) = ⌊2^(30.403243784 - x²)⌋ × 10^(-9)，其中 ⌊ ⌋ 表示下取整。

序列 u_n 定义为：
- u_0 = -1
- u_{n+1} = f(u_n)

给定 N，求 u_N + u_{N+1}。

---

## 输入格式

一行，一个整数 N。

---

## 输出格式

一个实数，保留小数点后9位数字。

---

## 样例

### 输入
```
0
```

### 输出
```
...
```

---

## 数据范围

- 0 ≤ N ≤ 10^12
- PE 答案: N=10^12 → 1.710637717
