# Recursive Sequence

来源：改编自 Project Euler Problem 197

## 原题意

已知函数 f(x) = ⌊2^(30.403243784-x²)⌋ × 10^(-9)，序列 u_n 定义为 u_0 = -1, u_{n+1} = f(u_n)。求 n = 10^12 时 u_n + u_{n+1}，保留9位小数。

## 题目

给定 N，求 u_N + u_{N+1}，保留9位小数。

## 数据范围

- 0 ≤ N ≤ 10^12
- PE 答案: N=10^12 → 1.710637717

## 算法

序列快速收敛到长度为2的循环（两个稳定值交替出现）。迭代直到 u_n + u_{n+1} 稳定即可。双精度浮点数。
