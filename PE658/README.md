# PE658 — 不完整的单词II (Incomplete words II)

来源：改编自 Project Euler Problem 658

## 原题意

S(k,n) = Σ_{α=1}^{k} I(α,n)，其中 I(α,n) 为字母表大小 α 时长不超过 n 的不完整单词数。

已知：S(4,4)=406，S(8,8)=27902680，S(10,100) ≡ 983602076 (mod 1e9+7)。

求 S(10^7, 10^12) mod 1,000,000,007。

PE 答案：958280177。

## 算法

将双重求和 I(α,n) = Σ_{j=1}^{α} (−1)^{j−1} C(α,j) g(α−j,n) 代入 S 并交换求和次序：

S(k,n) = Σ_{d=0}^{k−1} g(d,n) · W(k,d)

其中 W(k,d) = Σ_{j=1}^{k−d} (−1)^{j−1} C(d+j, j) 满足递推关系：

- W(k,0) = (1−(−1)^k)/2
- W(k,d+1) = [W(k,d) + (−1)^{k−d}·(C(k,d)−C(k,d+1)) + 1] / 2

使用此递推和迭代二项式系数，可在 O(k) = 10^7 时间内计算 S(k,n)。每步需计算 g(d,n)（需一次快速幂），以及模逆运算。

## 改编方向

1. 改变 k 和 n 的相对大小
2. 求完整单词的类似求和
3. 限制字母使用次数上限
4. 推广到非均匀字母概率
