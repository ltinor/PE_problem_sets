# PE613 — 毕达哥拉斯蚂蚁 (Pythagorean Ant)

来源：改编自 Project Euler Problem 613

## 原题意

戴夫从硬纸板上剪下一个边长分别为 30cm、40cm 和 50cm 的直角三角形（即 3-4-5 三角形的 10 倍）。一阵风把三角形吹到花园中，另一阵风把一只小蚂蚁吹到了三角形上。

蚂蚁完全迷失了方向，以均匀随机的方式落在三角形内任意位置，并以均匀随机的方向直线向前爬行，直到离开三角形。

假设蚂蚁在三角形内的初始位置和爬行方向都是等可能的，求蚂蚁从最长边（50cm 的斜边）离开三角形的概率。答案四舍五入到小数点后 10 位。

PE 答案：0.3916721504。

## 算法

1. 对于三角形内一点 P，蚂蚁从 P 出发以随机方向离开，从边 S 离开的概率 = α_S(P) / (2π)，其中 α_S(P) 是边 S 在 P 点所张的视角。
2. 在整个三角形面积 A 上积分：
   P(从斜边离开) = (1 / 2πA) ∬_T α_AB(P) dA
3. 视角 α_AB(P) = arccos((PA·PB) / (|PA|·|PB|))。
4. 解析求解该二重积分，或使用蒙特卡洛方法进行数值验证。
5. 将三角形置于坐标系：直角顶点 C=(0,0)，B=(40,0)，A=(0,30)，斜边 AB 的方程为 3x+4y=120。

## 改编方向

1. 改变三角形形状（非直角、一般三角形）。
2. 推广到凸多边形。
3. 求从特定边离开的期望时间（考虑速度）。
4. 多只蚂蚁同时掉落的概率问题。
