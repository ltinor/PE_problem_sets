# 毕达哥拉斯蚂蚁

## 题目描述

戴夫正在阳台上做家庭作业，准备一个关于毕达哥拉斯三角形的展示。他刚刚从硬纸板上剪下了一个边长分别为 30 厘米、40 厘米和 50 厘米的直角三角形。一阵风吹来，把三角形吹到了花园中。另一阵风把一只小蚂蚁径直吹到了三角形上。

这只可怜的蚂蚁完全迷失了方向，只能随机选了个方向一直向前爬，想要回到草丛中。

假设蚂蚁以等可能的概率落在三角形内的任意位置，并以等可能的概率选择任意方向直线爬行，求它最终从最长边（50 厘米的斜边）离开三角形的概率。

将答案四舍五入到小数点后 10 位。

## 输入格式

一行，字符串 `PE` 或 `verify`。

## 输出格式

- 若输入为 `PE`，输出 PE 原题的答案：0.3916721504。
- 若输入为 `verify`，使用蒙特卡洛方法（200000 次采样）进行近似验证。

## 样例

### 输入
```
PE
```

### 输出
```
0.3916721504
```

## 数据范围

- 三角形边长：30、40、50（3-4-5 直角三角形）
- 验证模式：蒙特卡洛模拟，200000 次采样
