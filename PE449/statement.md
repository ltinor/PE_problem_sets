# 巧克力糖衣

## 题目描述

糖果师傅菲尔正在制造巧克力糖衣糖果。每块糖果的中心是一个旋转椭球体，
其方程为：

$$b^2x^2 + b^2y^2 + a^2z^2 = a^2b^2$$

菲尔想知道给这样一个糖果裹上均匀的 1 毫米厚巧克力糖衣需要多少巧克力。

已知：
- 当 a=1, b=1 时，需要 28π/3 mm³ 巧克力
- 当 a=2, b=1 时，需要约 60.35475635 mm³ 巧克力

---

## 输入格式

一个整数 a（b 恒为 1），表示椭球的赤道半径（单位 mm）。

---

## 输出格式

一个浮点数，保留 8 位小数，表示所需巧克力体积（mm³）。

---

## 样例

### 输入
```
2
```

### 输出
```
60.35475635
```

---

## 数据范围

- 对于 30% 数据：a = 1
- 对于 60% 数据：a = 2
- 对于 100% 数据：a ≤ 10 或 a = 3（PE 答案硬编码）
