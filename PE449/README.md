# PE449 - 巧克力糖衣

来源：改编自 Project Euler Problem 449

## 原题意

糖果中心是一个旋转椭球体：b²x²+b²y²+a²z²=a²b²。
需要计算包裹 1mm 厚均匀巧克力涂层所需的巧克力体积。

已知 a=1,b=1 时需要 28π/3 mm³，a=2,b=1 时约 60.35475635 mm³。
求 a=3,b=1 时的体积（保留 8 位小数）。
答案为 103.37870096。

## 题目

给定椭球参数 a（b 恒为 1），求包裹 1mm 巧克力涂层的体积（mm³）。

## 算法

- 椭球体积：V₀ = 4πa²b/3
- 涂层体积使用 Steiner 公式：V_d = S·d + M·d² + 4πd³/3
  其中 S 为表面积，M 为平均曲率积分
- 旋转椭球表面积：S = 2πa² + 2πab·arcsin(e)/e（长椭球 a>b）
- 平均曲率积分：M = 2πa + πa²(1-e²)·ln((1+e)/(1-e))/e
- 离心率 e = √(1-b²/a²)

## 改编方向

1. **三轴椭球**：x²/a²+y²/b²+z²/c²=1 的一般情况
2. **不同厚度**：d = 2, 0.5 等不同涂层厚度
3. **双层涂层**：不同材料的双层包裹
4. **表面积问题**：只求椭球表面积
