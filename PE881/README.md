# PE881 — Divisor Graph Width（约数图宽度）

来源：改编自 Project Euler Problem 881

## 原题意

对于正整数 N，构造约数图：顶点为 N 的所有约数，若 a|b 且 b/a 为素数，则在 a、b 间连边。该图的"宽度"定义为最大反链的大小，即最大的一组两两不可整除的约数的数量。

对于约数格 N = ∏ p_i^{e_i}，宽度等于多项式 ∏(1 + x + ... + x^{e_i}) 中系数的最大值。

PE 答案：183182007700

## 算法

1. **多项式系数法**：
   - 对 N 的每个素因子幂次 e_i，构造多项式 (1 + x + ... + x^{e_i})
   - 计算这些多项式的卷积
   - 取卷积结果中的最大值即为宽度

2. **组合解释**：
   - 宽度 = max_k C_k，其中 C_k 是恰好具有 k 个素因子（计重数）的约数个数
   - 这等价于多重集合的 Sperner 定理

3. **求和变体**：
   - 可以计算 Σ_{n=1}^{N} width(n)
   - 或计算 n! 的约数宽度

## 改编方向

1. 计算 N 以内所有数的约数图宽度之和
2. 对于特殊形式的数（如阶乘、primorial）计算宽度
3. 研究宽度与 N 的渐近关系
4. 推广到带权约数图
