# $L$-表达式（二）（$L$-expressions II）

## 题目描述

在 $L$-表达式系统中，定义：
- $C_0 = Z$
- $C_i = S(C_{i-1})$（$i \ge 1$）
- $D_i = C_i(S)(S)$

对于自然数 $a, b, c, d, e$，令 $F(a, b, c, d, e)$ 表示 $D_a(D_b)(D_c)(C_d)(A)(e)$ 的归约结果。

求 $F(12, 345678, 9012345, 678, 90)$ 的最后九位数字。

## 输入格式

无输入（固定参数问题）。

## 输出格式

输出一个整数，表示结果的最后九位数字。

## 样例

（无样例输入输出，直接计算并输出最终答案。）
