# PE 958 · Euclid's Labour（欧几里得的劳作）— 简单版本

来源：改编自 Project Euler Problem 958

## 原题意

$d(n,m)$ 为欧几里得算法（减法版）求 $\gcd(n,m)$ 的减法次数。$f(n)$ 为与 $n$ 互质且使 $d(n,m)$ 最小的最小 $m$。求 $f(10^{12}+39)$。

## 简单版本改动

原题 $n$ 达 $10^{12}$ 级，需连分数/Stern-Brocot 高效方法。改为：给定小 $n$，暴力枚举求 $f(n)$。

## 缩数据范围

$2 \le n \le 10^6$。

## 算法

暴力枚举 $m=1..n-1$：

- 用除法加速求减法次数：互质时 $d(n,m)=\sum(\text{欧几里得除法商})-1$（最后一步只差 1 次减法）；
- 对 $\gcd(n,m)=1$ 的 $m$ 求 $d(n,m)$，取最小值对应的最小 $m$。

复杂度 $O(n\log n)$。

## 验证结果

| 验证点 | 期望 | 实际 | 结果 |
|--------|------|------|------|
| $f(7)$ | 2 | 2（$d=4$ 步） | ✓ |
| $f(89)$ | 34 | 34 | ✓ |
| $f(8191)$ | 1856 | 1856 | ✓ |

$n=7$ 时各互质 $m$ 的 $d$ 值：$d(7,1)=6,\ d(7,2)=4,\ d(7,3)=4,\ d(7,4)=4,\ d(7,5)=4,\ d(7,6)=6$，最小为 4（对应 $m=2,3,4,5$，取最小 $m=2$），与题面「至少四步、$f(7)=2$」一致。
