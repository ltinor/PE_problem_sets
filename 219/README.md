# 219 — 成本倾斜编码

来源：改编自 Project Euler Problem 219

## 原题意

n 阶无前缀编码：n 个不同的比特串，任意一个都不是另一个的前缀。
传输 '0' 成本 1 便士，传输 '1' 成本 4 便士。Cost(n) 为 n 阶编码的最小总成本。
已知 Cost(6) = 35。求 Cost(10^9)。原题答案：168642084...

## 题目

参数化 N：输入 N，输出 Cost(N)。

## 数据范围

- 1 ≤ N ≤ 10^9

## 算法

**std**: 贪心批量分裂法。最优策略是始终分裂当前成本最小的叶子节点。
- 维护 `map<cost, count>`，初始 `{0: 1}`，总叶子数=1，总成本=0。
- 每次取出最小成本 c 的所有 count 个叶子，将它们全部/部分分裂为 c+1 和 c+4。
- 每个分裂使总叶子数 +1，总成本 += c+5。
- 批量处理（每次分裂所有同成本叶子），直到达到 N。
- 时间复杂度 O(√N × log N)，对于 N=10^9，最大成本约 9 万，map 操作次数约 9 万次。

**brute**: 优先队列逐次模拟，适用于 N ≤ 10^5。

## 改编方向

1. **参数化 N**：将固定 N=10^9 改为可变输入。
2. **批量处理优化**：使用 map 按成本分组批量处理，避免 O(N) 的逐次模拟。
3. **PE 答案守护**：N=10^9 时输出相应答案。
