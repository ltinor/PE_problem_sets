# 成本倾斜编码

## 题目描述

记 A 和 B 均为比特串（由 0 和 1 组成的序列）。如果在 B 的最左端取和 A 的长度相等的比特位，所构成的比特串恰好等于 A，则称 A 为 B 的前缀。举例来说，00110 是 001101001 的前缀，但不是 00111 或 100110 的前缀。

n 阶无前缀编码是指 n 个不同的比特串，其中任意一个都不是另一个的前缀。例如，6 阶无前缀编码的其中一种是：

    0000, 0001, 001, 01, 10, 11

现在假设传输比特位"0"的成本是 1 个便士，而传输比特位"1"的成本是 4 个便士。那么，上述无前缀编码的总成本是 35 便士，恰好是这个成本倾斜编码问题最便宜的一种可能。我们将其简记为 Cost(6) = 35。

给定 N，求 Cost(N)。

## 输入格式

一行一个整数 N。

## 输出格式

一行一个整数，表示 Cost(N)。

---

## 样例

### 输入
```
1
```

### 输出
```
0
```

### 输入
```
6
```

### 输出
```
35
```

---

## 数据范围

- 1 ≤ N ≤ 10^9
- 标准时限：1 秒

---

## 提示

最优策略为贪心：始终分裂当前成本最小的叶子节点。分裂成本为 c 的叶子会得到成本为 c+1 和 c+4 的两个新叶子，总成本增加 c+5。可以通过按成本分组批量处理来高效计算。
