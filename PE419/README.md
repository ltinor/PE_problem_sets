# PE419 - 看图说话序列

来源：改编自 Project Euler Problem 419

## 原题意

看图说话（Look-and-say）序列：1, 11, 21, 1211, 111221, ...，每项通过描述前一项的连续数字得到。A(n)、B(n)、C(n) 分别表示第 n 项中数字 1、2、3 的数量。原题求 n=10^12 时的 A,B,C（模 2^30），答案中 A = 998567043。

## 题目

给定 n，求 A(n), B(n), C(n)（对 n=10^12 模 2^30，小 n 直接计算）。

## 算法

- 小 n（n ≤ 40）：直接模拟序列生成并统计
- 大 n：利用 Conway 宇宙学定理，序列分解为 92 种基本元素，使用矩阵快速幂

## 改编方向

1. **统计所有数字**：统计 0-9 的出现次数
2. **不同起始值**：从非 1 的起始值开始
3. **模不同值**：改为模其他值
4. **求序列长度**：求第 n 项的总长度
