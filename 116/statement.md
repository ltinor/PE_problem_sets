# 红色、绿色或蓝色的地砖

## 题目描述

将一行 N 块黑色方形地砖的一部分替换为彩色长方形地砖。可选的颜色有：**红色**（长度为 2）、**绿色**（长度为 3）、**蓝色**（长度为 4）。

每次只能使用**一种**颜色的地砖（不能混合颜色），且**至少使用一块**彩色地砖。求所有可能的替换方式总数。

例如 N = 5 时：
- 只用红色：7 种
- 只用绿色：3 种
- 只用蓝色：2 种
- 总计：12 种

---

## 输入格式

一行，一个整数 N。

---

## 输出格式

一行，一个整数，表示答案。

---

## 样例

### 输入
```
5
```

### 输出
```
12
```

### 输入
```
50
```

### 输出
```
20492570929
```

---

## 数据范围

- 1 ≤ N ≤ 50
