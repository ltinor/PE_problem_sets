# 107 — Minimal Network

来源：改编自 Project Euler Problem 107

## 原题意

给定一个无向网络的邻接矩阵（"-"表示无边），求移除冗余边后仍保持连通的前提下，最多能节省多少权重（= 总权重 - 最小生成树权重）。

原题：40 个顶点的网络，答案 259679。

## 题目

输入顶点数 $V$，然后 $V$ 行邻接矩阵（"-"表示无边，其余为整数权重）。输出最大节省权重。

## 数据范围

- $2 \\le V \\le 40$
- 边权为不超过 $10^5$ 的正整数
- 保证图连通

## 算法

Kruskal 最小生成树：对所有边按权重排序，用并查集维护连通性，贪心选取 $V-1$ 条边。最大节省 = 总权重 - MST 权重。

时间复杂度 $O(E \\log E)$，其中 $E \\le V(V-1)/2$。

## 改编方向与取舍

### 改编方向
1. **参数化输入** → 从标准输入读取，而非固定文件（本题采用）
2. **输出 MST 边集** → 输出移除的边列表及其权重
3. **多组测试数据** → 一次运行处理多个网络
4. **有向图变体** → 改为有向图的最小树形图（朱刘算法）

### 取舍理由
- 选择参数化输入：最自然，支持任意网络而非固定文件
- 不选择输出边集：增加输出复杂度，与原题求和的简洁目标不符
- 不选多组数据：网络输入本身较复杂，多组增加解析难度
