# 没有裂纹的墙

## 题目描述

用大小为 2×1 和 3×1 的砖块（宽×高）来筑墙。为保证强度，相邻两层之间的砖缝不能垂直对齐——也就是说，不能有从顶部延伸到底部的"裂纹"。

给定墙的宽度 W 和高度 H，求没有裂纹的筑墙方案总数。

---

## 输入格式

一行，两个整数 W 和 H（2 ≤ W ≤ 40，1 ≤ H ≤ 20）。

---

## 输出格式

一个整数，表示方案总数。

---

## 样例

### 输入
```
9 3
```

### 输出
```
8
```

### 解释
宽度 9、高度 3 的无裂纹墙共有 8 种筑法（PE 示例）。

---

## 数据范围

- 2 ≤ W ≤ 40
- 1 ≤ H ≤ 20
- PE 答案: W=32, H=10 → 806844323190414
